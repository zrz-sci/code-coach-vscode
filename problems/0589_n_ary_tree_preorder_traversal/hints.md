# 589. N-ary Tree Preorder Traversal - N叉树的前序遍历

## 核心思路

将二叉树前序遍历的思想推广到 N 叉树。前序遍历的访问顺序是：**先访问根节点，再从左到右依次递归访问每个子节点的子树**。题目的 Follow-up 要求用迭代法实现，核心是用栈模拟递归调用栈，注意子节点入栈的顺序需要**从右到左**（这样出栈时才是从左到右）。

## 思维链

1. **回顾前序遍历定义**：根 -> 子节点1的子树 -> 子节点2的子树 -> ... -> 子节点k的子树
2. **递归法**：直接按定义递归，先记录当前节点值，再遍历每个子节点
3. **迭代法**：用栈模拟。每次弹出栈顶节点并记录值，然后将其子节点**从右到左**压栈
4. **从右到左压栈的原因**：栈是 LIFO，最左子节点最后压入 -> 最先弹出 -> 最先被访问

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 递归 | O(n) | O(h) 栈深度 | 最直观，代码最短 |
| 迭代（栈） | O(n) | O(n) | 面试首选，显式栈控制 |

## 关键提示

1. N 叉树每个节点有 `children` 数组（可能为空），替代了二叉树的 `left/right`
2. 递归法：遍历 `children` 数组即可，无需单独处理左右
3. 迭代法的核心：**子节点从右到左入栈**，保证出栈顺序为从左到右
4. 空树（root 为 nullptr）需要直接返回空数组
5. 叶子节点的 `children` 是空数组，循环自然跳过

## 解法详解

### 解法一：递归

```
preorder(node):
    if node is null: return
    result.add(node.val)          // 先访问根
    for child in node.children:   // 再依次访问子树
        preorder(child)
```

**流程示例**（树: 1->[3->[5,6], 2, 4]）：
- 访问 1 -> 递归 3 -> 访问 3 -> 递归 5 -> 访问 5（叶子）
- 回到 3 -> 递归 6 -> 访问 6（叶子）
- 回到 1 -> 递归 2 -> 访问 2（叶子）
- 回到 1 -> 递归 4 -> 访问 4（叶子）
- 结果: [1, 3, 5, 6, 2, 4]

### 解法二：迭代（栈）

```
stack = [root]
while stack not empty:
    node = stack.pop()
    result.add(node.val)
    // 子节点从右到左入栈
    for i from children.size()-1 down to 0:
        stack.push(children[i])
```

**流程示例**（树: 1->[3, 2, 4]）：
- 栈: [1] -> 弹出 1, 压入 [4, 2, 3]
- 栈: [4, 2, 3] -> 弹出 3, 压入 [4, 2, 6, 5]
- 栈: [4, 2, 6, 5] -> 弹出 5 (叶子)
- 栈: [4, 2, 6] -> 弹出 6 (叶子)
- 栈: [4, 2] -> 弹出 2 (叶子)
- 栈: [4] -> 弹出 4 (叶子)
- 结果: [1, 3, 5, 6, 2, 4]

## 易错点

1. **忘记判空**：root 为 nullptr 时直接返回空数组
2. **入栈顺序错误**：子节点应从右到左入栈（`rbegin` 到 `rend`），而非从左到右
3. **混淆前序和后序**：前序是"根-子"，后序是"子-根"
4. **children 可能为空**：叶子节点的 children 是空数组，不要访问越界
5. **递归中使用成员变量**：用成员变量存 result 虽然方便，但多次调用时需注意清空；更推荐传引用参数

## 面试追问

1. **递归和迭代的空间复杂度分别是多少？**
   - 递归：O(h)，h 为树高，最坏 O(n)（链状树）
   - 迭代：O(w)，w 为树的最大宽度（栈中最多存一层的节点），最坏 O(n)
2. **如何将前序遍历改为后序遍历？**
   - 递归：把 `result.add(node.val)` 移到循环之后
   - 迭代：先按"根-右-左"的顺序收集结果（子节点从左到右入栈），最后反转数组
3. **N 叉树和二叉树遍历的本质区别？**
   - 二叉树有固定的左右两个子节点，N 叉树有任意多个子节点
   - 二叉树有中序遍历，N 叉树没有标准中序定义
4. **如果树非常深（接近1000层），递归安全吗？**
   - 取决于系统栈大小，通常默认栈为 1-8MB，1000 层递归一般安全
   - 如果担心栈溢出，使用迭代法更安全
5. **能否用 Morris 遍历实现 O(1) 空间的 N 叉树前序遍历？**
   - Morris 遍历依赖线索化（threading），仅适用于二叉树，不适用于 N 叉树
