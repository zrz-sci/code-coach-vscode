# 784. Letter Case Permutation

## 核心思路

对于字符串中的每个字母字符，都有"变大写"和"变小写"两种选择；数字字符则保持不变。这是一个典型的**子集/组合枚举**问题，可以用回溯法、BFS 迭代法、或位掩码法来枚举所有可能的大小写组合。

## 思维链

1. **字符分类**：字符串中有两类字符：字母（有两种选择）和数字（只有一种选择）。
2. **组合数量**：如果字符串中有 k 个字母，则总共有 2^k 种不同的字符串。
3. **枚举策略**：可以从左到右逐字符处理。遇到数字直接保留，遇到字母则分叉为大写和小写两条路径。
4. **回溯法**：经典 DFS，当前位置选择后递归处理下一位置。
5. **BFS/迭代法**：维护一个结果集，每遇到一个字母就把当前结果集翻倍。
6. **位掩码法**：给每个字母分配一个 bit，枚举所有 2^k 种掩码。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 回溯法 (DFS) | O(2^k * n) | O(n) | 经典回溯模板，最推荐面试 |
| BFS 迭代法 | O(2^k * n) | O(2^k * n) | 不需要递归，逐层扩展 |
| 位掩码枚举 | O(2^k * n) | O(2^k * n) | 直观但实现稍复杂 |

其中 k 为字母字符数量，n 为字符串长度。

## 关键提示

1. 大小写转换技巧：`ch ^ 32` 可以在大小写之间切换（利用 ASCII 特性：'a' ^ 32 = 'A'）。
2. 判断字母：`isalpha(ch)` 或者 `(ch >= 'a' && ch <= 'z') || (ch >= 'A' && ch <= 'Z')`。
3. 回溯时的"选择-递归-撤销"模式：选择一种大小写 -> 递归到下一位 -> 撤销（换另一种）。
4. BFS 法的思路："已有结果集" 遇到字母时翻倍：对每个已有字符串，复制一份并修改当前字母的大小写。
5. 字母只有 12 个字符最多，2^12 = 4096，暴力枚举完全可行。
6. 回溯可以原地修改字符串（传引用），不需要额外拷贝。

## 解法详解

### 解法一：回溯法 DFS（推荐）

**思路**：
- 从位置 0 开始，逐字符处理。
- 如果当前字符是数字，直接递归到下一位。
- 如果当前字符是字母，先以当前大小写递归，然后切换大小写再递归。
- 当处理到字符串末尾时，将当前字符串加入结果集。

**关键实现**：
- 原地修改字符串，避免大量拷贝。
- 用 `s[i] ^= 32` 进行大小写切换，再用 `s[i] ^= 32` 还原。

### 解法二：BFS 迭代法

**思路**：
- 初始化结果集为 `{s}`（原始字符串）。
- 从左到右扫描每个字符。遇到字母时：
  - 对结果集中每个字符串，创建一个副本，并将该位置的字母大小写翻转。
  - 将所有副本加入结果集。
- 遍历完成后，结果集中包含所有排列。

### 解法三：位掩码枚举

**思路**：
- 先找出字符串中所有字母的位置，记为 positions 数组。
- 枚举 0 到 2^k - 1 的所有掩码，掩码的第 i 位决定 positions[i] 处字母的大小写。
- 对每个掩码构建一个新字符串加入结果。

## 易错点

1. **XOR 32 的适用范围**：这个技巧只对英文字母有效（ASCII 范围内大小写差 32）。对数字字符使用会产生错误。必须先判断是否为字母再做切换。
2. **回溯中忘记还原**：如果修改了字符串中的字符，在回溯返回后必须恢复原状。不过在本题中，用 `^=32` 两次天然还原。
3. **BFS 法中的并发修改**：在遍历结果集的同时修改它会导致问题。应该先记录当前大小，只遍历前 size 个元素。
4. **重复结果**：如果同一个字母出现在大写和小写不同分支中，可能产生重复。但本题的 DFS/BFS 结构天然避免了这一点。
5. **字符串长度 <= 12**：意味着最多 2^12 = 4096 个结果，所有方法都不会超时。

## 面试追问

1. **Q: 如果字符串非常长（比如 10^6），但只有少量字母，哪种方法最好？**
   A: 位掩码法或 BFS 法更好，因为它们只对字母位置分叉，不需要递归到每个字符。回溯法虽然也只在字母处分叉，但递归深度可能很大。

2. **Q: `ch ^ 32` 的原理是什么？**
   A: ASCII 中大写字母范围 65-90，小写 97-122，差值恰好为 32（即第 5 位的差异）。XOR 32 就是翻转第 5 位，实现大小写互转。比如 'a'=97=0b01100001, 'A'=65=0b01000001。

3. **Q: 能否用动态规划的思路解决？**
   A: 可以看成一种自底向上的构建。dp[i] 代表前 i 个字符的所有排列，dp[i+1] 在 dp[i] 基础上扩展。本质上等价于 BFS 迭代法。

4. **Q: 如果要求字典序输出结果，如何修改？**
   A: 在回溯中，先处理小写再处理大写（或反过来），就能保证字典序。或者最后对结果排序。

5. **Q: 这个问题和子集问题有什么联系？**
   A: 字母位置相当于"元素"，选择大写/小写相当于"选或不选"。本质上就是 2^k 个子集的枚举。
