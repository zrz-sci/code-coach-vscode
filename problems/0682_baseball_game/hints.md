# 682. Baseball Game

## 题目理解

你是一场特殊规则棒球赛的记分员。初始记录为空。给定操作列表 `operations`，每个操作为以下四种之一：

| 操作 | 含义 |
|------|------|
| 整数 `x` | 记录新分数 `x` |
| `"+"` | 记录新分数 = 前两次得分之和 |
| `"D"` | 记录新分数 = 前一次得分的两倍 |
| `"C"` | 前一次得分无效，从记录中移除 |

返回所有操作完成后**记录中所有得分的总和**。

### 约束条件
- `1 <= operations.length <= 1000`
- `operations[i]` 是 `"C"`, `"D"`, `"+"`，或 `[-30000, 30000]` 范围内的整数字符串
- `"+"` 操作时保证前面至少有两个有效分数
- `"C"` 和 `"D"` 操作时保证前面至少有一个有效分数
- 答案和所有中间计算都能放入 32 位整数

---

## 示例详细模拟

### 示例 1: ops = ["5","2","C","D","+"]

```
操作    动作                          记录(栈)          说明
────    ────                          ────────          ────
"5"     push 5                        [5]               直接入栈
"2"     push 2                        [5, 2]            直接入栈
"C"     pop (移除2)                   [5]               删除上一次
"D"     push 5*2=10                   [5, 10]           上次得分翻倍
"+"     push 5+10=15                  [5, 10, 15]       前两次之和

总分 = 5 + 10 + 15 = 30
```

### 示例 2: ops = ["5","-2","4","C","D","9","+","+"]

```
操作    动作                          记录(栈)                说明
────    ────                          ────────                ────
"5"     push 5                        [5]
"-2"    push -2                       [5, -2]                 负数也可以
"4"     push 4                        [5, -2, 4]
"C"     pop (移除4)                   [5, -2]                 4被删除
"D"     push -2*2=-4                  [5, -2, -4]             -2的两倍
"9"     push 9                        [5, -2, -4, 9]
"+"     push -4+9=5                   [5, -2, -4, 9, 5]       前两次之和
"+"     push 9+5=14                   [5, -2, -4, 9, 5, 14]   前两次之和

总分 = 5 + (-2) + (-4) + 9 + 5 + 14 = 27
```

## 核心思路

这是一道纯**模拟题**，数据结构选择**栈**（或 vector 当栈用）。

为什么用栈？
- `"C"` 操作需要**移除最后一个**元素 → 栈的 pop
- `"D"` 操作需要访问**最后一个**元素 → 栈的 top
- `"+"` 操作需要访问**最后两个**元素 → 用 vector 比 stack 方便（可以 `stk[size-2]`）
- 数字直接 push

---

## 思维链 (Step-by-Step Reasoning)

### Step 1: 选择数据结构
- 需要频繁在末尾添加/删除 → 栈
- `"+"` 需要访问倒数第二个元素 → `std::stack` 只能看 top，不方便
- **最佳选择**: `vector<int>` 当栈用，`back()` 看栈顶，`[size()-2]` 看倒数第二个

### Step 2: 区分操作类型
```
对每个 op:
  if op == "C"  → pop_back()
  if op == "D"  → push_back(back() * 2)
  if op == "+"  → push_back(back() + [size()-2])
  else          → push_back(stoi(op))     // 数字（含负数）
```

### Step 3: 判断是数字还是操作符
- `"C"`, `"D"`, `"+"` 都是单字符特殊操作
- 其他都是数字字符串（可能带负号如 `"-2"`）
- C++ 的 `stoi()` 自动处理负数

### Step 4: 最终求和
- 遍历栈中所有元素求和
- 也可以在操作过程中维护 running sum（加入时 sum += val，移除时 sum -= val）

## 关键提示序列

### Hint 1: 数据结构选择
> 需要在末尾添加/删除元素 → 栈。但 `"+"` 需要访问倒数第二个元素，用 `vector` 比 `stack` 方便。

### Hint 2: 操作分类
> 四种操作：数字入栈、`"C"` 弹出、`"D"` 栈顶翻倍入栈、`"+"` 栈顶两元素之和入栈。

### Hint 3: 字符串转数字
> C++ 用 `stoi()`，Python 用 `int()`。都能正确处理负数字符串如 `"-2"`。

### Hint 4: 判断操作类型
> 先检查是否是 `"C"`, `"D"`, `"+"` 三个特殊操作，其他情况一律按数字处理。

### Hint 5: vector 栈操作
> `push_back()` = push, `pop_back()` = pop, `back()` = top, `stk[stk.size()-2]` = 倒数第二个。

### Hint 6: running sum 优化
> 可以在操作过程中维护总和：push 时加，pop 时减，最后直接返回 sum，省去最后的遍历。

## 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 用 `std::stack` | 无法访问倒数第二个元素 | 用 `vector` 代替 |
| `"+"` 时只用了 `back()` | 只加了一个元素 | 需要 `back() + stk[size()-2]` |
| 忘记负数 | `"-2"` 被误判为操作符 | `stoi()` 自动处理负数 |
| `"C"` 后忘记检查是否还有元素 | 越界访问 | 题目保证操作合法，但防御性编程不会错 |
| 用 `if-else if` 顺序错误 | 数字 `"0"` 被误判 | 先判断 C/D/+，else 才是数字 |

## 复杂度分析

- **时间**: O(n) -- 遍历一遍操作列表，每个操作 O(1)
- **空间**: O(n) -- 栈最多存 n 个分数（如果没有 C 操作的话）

## 编码技巧

### vector 作为栈的常用操作速查

```cpp
vector<int> stk;

// push
stk.push_back(val);

// pop
stk.pop_back();

// top (栈顶)
stk.back();

// 倒数第二个元素
stk[stk.size() - 2];
// 或者
stk.rbegin()[1];     // 更现代的写法
// 或者
*(stk.end() - 2);    // 迭代器写法

// 求和
int sum = accumulate(stk.begin(), stk.end(), 0);
```

### 判断字符串是否为数字

```cpp
// 方法1: 排除法 (推荐, 最简洁)
if (op != "C" && op != "D" && op != "+") {
    // 是数字
}

// 方法2: 检查首字符
if (op[0] == '-' || isdigit(op[0])) {
    // 是数字 (含负数)
}
```

## 面试追问

1. **如果操作序列不保证合法（比如空栈时执行"C"），你怎么处理？**
   - 每次 `pop_back()` / `back()` 前检查 `stk.empty()`
   - 不合法时抛异常或跳过

2. **如果新增一个操作 "M" 表示取栈中所有元素的中位数并入栈，怎么做？**
   - 方案1: 维护额外的 sorted multiset，O(log n) 取中位数
   - 方案2: 双堆（max-heap + min-heap）经典中位数流结构
   - 注意 "C" 撤销时也要从辅助结构中移除

3. **如果需要支持 undo/redo（撤销任意历史操作），数据结构怎么设计？**
   - Command 模式: 每个操作封装成 `{execute, undo}` 对象
   - 用两个栈: undoStack 和 redoStack
   - 这是编辑器撤销/重做的经典设计模式

这是一道 Easy 级别的**栈模拟题**，没有复杂算法，考查的是：
1. 正确选择数据结构（vector 当栈用）
2. 仔细读题、准确实现四种操作
