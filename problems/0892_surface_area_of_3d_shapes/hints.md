# 892. 三维形体的表面积

## 核心思路

本质上是一个**几何模拟问题**：每个格子上放若干个 1x1x1 的方块组成柱子，需要计算所有方块粘合后暴露出来的总表面积。关键洞察是**逐柱子算贡献，再减去相邻柱子之间的重叠面**。

## 思维链

1. **读完题第一反应**：每个方块有 6 个面，先算总面数 = `6 * 方块总数`，然后减去被遮挡的面。但哪些面被遮挡？上下相邻的方块之间（同柱子内部堆叠），以及左右前后相邻的柱子之间。

2. **换个角度——逐柱子思考**：一根高度为 v 的柱子（v > 0），它自身贡献：顶面 1 + 底面 1 + 四周 4v = `2 + 4v`。但如果旁边也有柱子，两根柱子相邻的面会相互遮挡。

3. **遮挡量化**：两个相邻柱子高度分别为 a 和 b，它们之间的遮挡面数 = `2 * min(a, b)`（每个方向各 min(a,b) 个面被遮住）。

4. **最终公式**：遍历整个网格，对每个非零柱子加 `2 + 4v`；对每对水平相邻的柱子（右邻居和下邻居），减去 `2 * min(a, b)`。

5. **也可以从另一个角度理解**：总表面积 = 所有方块的 6 个面 - 2 * (内部接触面)。内部接触面包括同柱子上下堆叠的 `(v-1)` 个面，以及相邻柱子之间的 `min(a,b)` 个面。两种理解方式结果一致。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 逐柱子加法 | 每个柱子贡献 2+4v，减相邻重叠 | O(n^2) | O(1) | ⭐ 面试首选 |
| 总面减遮挡 | 6*总方块数 - 2*所有接触面 | O(n^2) | O(1) | 等价写法 |

> n = grid.length (网格边长)

## 关键提示

1. **柱子自身贡献**：高度为 v 的柱子（v > 0），顶面和底面各 1，四周暴露面为 4v。所以自身贡献为 `2 + 4v`。当 v = 0 时没有任何贡献，需要跳过。

2. **相邻柱子遮挡**：两个相邻柱子高度 a 和 b，被遮挡的面数 = `2 * min(a, b)`。这是因为矮的那根柱子有多少层，就有多少对面被遮住，而每对面算 2 个（一个属于 a 柱子，一个属于 b 柱子）。

3. **只看右邻居和下邻居**：为了不重复计算，只在 `(i, j)` 与 `(i, j+1)` 以及 `(i+1, j)` 之间计算遮挡。这样每对相邻柱子恰好被算一次。

4. **等价理解——逐面分析法**：也可以分六个方向（上下左右前后）逐面计算。对于上面：每个非零柱子贡献 1。对于侧面：如果旁边没有柱子或自己比旁边高，暴露面 = `max(0, v - 邻居高度)`。这个方法更通用但代码稍长。

5. **边界处理**：网格边缘的柱子，其外侧没有邻居，相当于邻居高度为 0。在逐柱子加法中，边缘自然不会产生遮挡减法，所以无需特殊处理。

## 解法详解

### 解法1: 逐柱子加法 — O(n^2) / O(1) ⭐ 面试首选

**思考过程**：遍历每个格子，如果有方块（v > 0），先加上这根柱子的独立贡献 `2 + 4v`。然后检查右邻居和下邻居，减去相邻面的遮挡 `2 * min(当前, 邻居)`。

```cpp
class Solution {
public:
    int surfaceArea(vector<vector<int>>& grid) {
        int n = grid.size();
        int area = 0;
        
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                int v = grid[i][j];
                if (v > 0) {
                    // 柱子自身: 顶面1 + 底面1 + 四周4v
                    area += 2 + 4 * v;
                }
                // 减去与右邻居的重叠
                if (j + 1 < n) {
                    area -= 2 * min(v, grid[i][j + 1]);
                }
                // 减去与下邻居的重叠
                if (i + 1 < n) {
                    area -= 2 * min(v, grid[i + 1][j]);
                }
            }
        }
        
        return area;
    }
};
```

**关键点**：`2 + 4v` 是一根独立柱子的表面积。`2 * min(a, b)` 是两根相邻柱子的遮挡面数。只检查右和下避免重复计数。

### 解法2: 总面减遮挡 — O(n^2) / O(1)

**等价的另一种表达**：先计算所有方块的总面数 `6 * total_cubes`，然后减去所有内部接触面（包括同柱子内上下堆叠和相邻柱子之间的水平接触）的两倍。

```cpp
class Solution {
public:
    int surfaceArea(vector<vector<int>>& grid) {
        int n = grid.size();
        int totalCubes = 0;
        int overlap = 0;
        
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                int v = grid[i][j];
                totalCubes += v;
                // 同柱子内部上下堆叠的接触面
                if (v > 1) overlap += v - 1;
                // 与右邻居的接触面
                if (j + 1 < n) overlap += min(v, grid[i][j + 1]);
                // 与下邻居的接触面
                if (i + 1 < n) overlap += min(v, grid[i + 1][j]);
            }
        }
        
        return 6 * totalCubes - 2 * overlap;
    }
};
```

**关键点**：overlap 计算了所有接触面的单面数量（每个接触处算 1 次），乘以 2 是因为每个接触处遮挡了两个面（各属于两个方块）。同柱子内部 v 个方块有 v-1 个上下接触面。

## 解法对比

| | 逐柱子加法 | 总面减遮挡 |
|--|---------|----------|
| 时间 | O(n^2) | O(n^2) |
| 空间 | O(1) | O(1) |
| 思路直觉 | 高 | 中 |
| 代码简洁 | ⭐ 更简洁 | 稍长 |
| 面试建议 | 首选 | 作为等价解释 |

**选择建议**：
- 面试首选逐柱子加法：公式 `2 + 4v` 直觉且好记
- 如果面试官追问另一种理解方式，给出总面减遮挡的思路
- 两者复杂度完全相同，只是思维角度不同

## 易错点

1. **忘记 v = 0 时不贡献表面积**
   - x 对所有格子都加 `2 + 4v` -> 当 v=0 时多加了 2
   - o 加 `2 + 4v` 前先判断 `v > 0`

2. **相邻遮挡算了两次**
   - x 对每对邻居 (i,j)-(i,j+1) 和 (i,j+1)-(i,j) 都减了遮挡 -> 减了双倍
   - o 只在一个方向（右和下）计算，每对恰好算一次

3. **遮挡公式用了 max 而不是 min**
   - x `2 * max(a, b)` -> 遮挡面会超过矮柱子的高度
   - o `2 * min(a, b)` -> 遮挡面数等于较矮柱子的高度

4. **总面减遮挡法中忘记柱子内部堆叠**
   - x 只减了相邻柱子之间的接触面，忘了同柱子内部 v-1 个接触面
   - o 需要同时计算 `v - 1`（柱子内上下接触）和 `min(a,b)`（柱子间水平接触）

5. **边界索引越界**
   - x 检查右邻居时没有判断 `j + 1 < n`
   - o 所有邻居访问前先检查边界

## 面试追问

**Q1: 你能不能从六个方向分别计算每个面的暴露情况？**
-> 可以。上面：每个非零柱子贡献 1。下面同理。左面：`max(0, grid[i][j] - grid[i][j-1])`（边缘时邻居为0）。右前后同理。这是逐面分析法，代码更长但逻辑更透明。

**Q2: 如果方块不是在网格底部而是悬浮的呢（比如有些层是空的）？**
-> 那就不能用柱子高度模型了，需要三维数组标记每个位置是否有方块，然后每个方块检查六个方向是否有邻居。时间从 O(n^2) 变成 O(n^3)。

**Q3: 这题的时间复杂度能优化吗？**
-> 不能。必须遍历每个格子才能知道它的高度，所以 O(n^2) 是下界。

**Q4: 如果网格非常大但大部分格子为0（稀疏），怎么优化？**
-> 可以只存储非零格子的坐标和高度（稀疏表示），遍历时只处理非零格子。但最坏情况仍是 O(n^2)。
