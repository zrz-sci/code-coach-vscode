# 1470. 重新排列数组

## 核心思路

给定 `[x1, x2, ..., xn, y1, y2, ..., yn]`，要交错输出 `[x1, y1, x2, y2, ..., xn, yn]`。本质上是一个**索引映射**问题：结果数组的第 `2*i` 位放 `nums[i]`（前半段），第 `2*i+1` 位放 `nums[n+i]`（后半段）。

看似简单的一道 Easy 题，但如果追问 O(1) 空间的 in-place 做法，难度会直接飙升到 Medium+。

## 思维链

1. **读完题第一反应** → 前 n 个元素是 x 组，后 n 个元素是 y 组。结果就是交替取一个 x 和一个 y。最直接的做法：开一个新数组，用一个循环 i 从 0 到 n-1，把 `nums[i]` 和 `nums[n+i]` 依次放进去。
2. **怎么确定新数组中的位置？** → 对于第 i 对 (xi, yi)：`result[2*i] = nums[i]`，`result[2*i+1] = nums[n+i]`。或者用一个 index 变量递增：先放 xi（index++），再放 yi（index++）。
3. **能不能不用额外数组？** → 如果要 O(1) 空间原地操作，难度大幅增加。因为移动一个元素到目标位置会覆盖原有元素。需要"循环置换"或"位编码"技巧。
4. **位编码的思路** → 题目限制 `nums[i] <= 1000 < 2^10`，只需要 10 位。我们可以把"旧值"和"新值"编码到同一个 int 里：低 10 位存旧值，高位存新值。最后右移 10 位就得到新值。
5. **有没有更直观的 O(1) 空间方法？** → 可以利用"从后往前"的循环置换方式。但最实用的面试答案就是开一个新数组的 O(n) 解法。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 新数组直接映射 | 开新数组，按索引公式填充 | O(n) | O(n) | ⭐ 面试首选 |
| 位编码原地 | 利用 nums[i] < 1024，高位存新值 | O(n) | O(1) | 进阶加分 |
| 循环置换 | 追踪每个元素的最终位置，原地交换 | O(n) | O(1) | 难度较高 |

## 关键提示

1. **索引映射公式**：前半段 `nums[i]` 应该放在结果的 `2*i` 位置；后半段 `nums[n+i]` 应该放在结果的 `2*i+1` 位置。理解这个公式是解题核心。
2. **为什么不能直接原地交换？** 因为移动 `nums[i]` 到 `result[2*i]` 时，会覆盖原来在位置 `2*i` 的元素。除非用特殊技巧保存被覆盖的值。
3. **位编码的前提条件**：`nums[i] <= 10^3 < 1024 = 2^10`。所以 10 位就够存原始值，剩余的位（int 有 32 位）可以存新值。这个技巧在很多"原地标记"题目中都能用到。
4. **面试策略**：先写出 O(n) 空间的解法，再主动提出可以用位编码优化到 O(1) 空间。这展示了你的思考深度。

## 解法详解

### 解法1: 新数组直接映射 — O(n) / O(n) ⭐ 面试首选

**思考过程**: 最直觉的想法——开一个新数组，遍历 0 到 n-1，把每对 (xi, yi) 依次放进去。

```
示例: nums = [2,5,1,3,4,7], n = 3

前半段 (x): nums[0]=2, nums[1]=5, nums[2]=1
后半段 (y): nums[3]=3, nums[4]=4, nums[5]=7

交错填充:
i=0: result[0] = nums[0] = 2, result[1] = nums[3] = 3
i=1: result[2] = nums[1] = 5, result[3] = nums[4] = 4
i=2: result[4] = nums[2] = 1, result[5] = nums[5] = 7

result = [2, 3, 5, 4, 1, 7] ✓
```

```cpp
class Solution {
public:
    vector<int> shuffle(vector<int>& nums, int n) {
        vector<int> result(2 * n);
        for (int i = 0; i < n; i++) {
            result[2 * i] = nums[i];         // xi 放偶数位
            result[2 * i + 1] = nums[n + i]; // yi 放奇数位
        }
        return result;
    }
};
```

**关键点**:
- 索引公式：`result[2*i]` 对应 `nums[i]`，`result[2*i+1]` 对应 `nums[n+i]`。
- 也可以用一个 index 变量递增来写：`result[index++] = nums[i]; result[index++] = nums[n+i];`，效果相同。
- 时间 O(n)，空间 O(n)（结果数组）。题目要求返回新数组，所以 O(n) 空间是必需的。

**另一种等价写法（push_back 版）**:

```cpp
class Solution {
public:
    vector<int> shuffle(vector<int>& nums, int n) {
        vector<int> result;
        result.reserve(2 * n); // 预分配，避免动态扩容
        for (int i = 0; i < n; i++) {
            result.push_back(nums[i]);     // xi
            result.push_back(nums[n + i]); // yi
        }
        return result;
    }
};
```

### 解法2: 位编码原地操作 — O(n) / O(1)

**从解法1优化**: 如果我们想原地修改 nums 而不使用额外数组呢？关键观察：`nums[i] <= 1000 < 1024 = 2^10`，所以每个 int 只用了低 10 位。我们可以把"新值"编码到高位，最后统一提取。

```
编码思路:
- 每个 nums[i] 最多 10 位
- 我们把 "新值" 左移 10 位后加到原值上: nums[pos] += newVal << 10
- 提取旧值: nums[pos] & 1023 (即低 10 位)
- 提取新值: nums[pos] >> 10  (即高位)

示例: nums = [2,5,1,3,4,7], n = 3

目标映射:
result[0] = nums[0] = 2   (从原 nums[0] 取)
result[1] = nums[3] = 3   (从原 nums[3] 取)
result[2] = nums[1] = 5   (从原 nums[1] 取)
result[3] = nums[4] = 4   (从原 nums[4] 取)
result[4] = nums[2] = 1   (从原 nums[2] 取)
result[5] = nums[5] = 7   (从原 nums[5] 取)

从后往前编码 (避免覆盖还没处理的值):
i=2: nums[4] += (nums[2] & 1023) << 10   // 存 x2=1 的新值
     nums[5] += (nums[5] & 1023) << 10   // 存 y2=7 的新值
i=1: nums[2] += (nums[1] & 1023) << 10   // 存 x1=5 的新值
     nums[3] += (nums[4] & 1023) << 10   // 存 y1=4 的旧值
i=0: nums[0] += (nums[0] & 1023) << 10   // 存 x0=2 的新值
     nums[1] += (nums[3] & 1023) << 10   // 存 y0=3 的旧值
最后所有位置 >>10 得到新值。
```

```cpp
class Solution {
public:
    vector<int> shuffle(vector<int>& nums, int n) {
        const int MASK = 1023; // 2^10 - 1, 低10位掩码
        // 从后往前，把新值编码到高位
        for (int i = n - 1; i >= 0; i--) {
            int xi = nums[i] & MASK;       // 旧的 x 值
            int yi = nums[n + i] & MASK;   // 旧的 y 值
            nums[2 * i] |= (xi << 10);     // 编码 x 到高位
            nums[2 * i + 1] |= (yi << 10); // 编码 y 到高位
        }
        // 提取高位作为新值
        for (int i = 0; i < 2 * n; i++) {
            nums[i] >>= 10;
        }
        return nums;
    }
};
```

**关键点**:
- **为什么从后往前？** 从前往后处理时，写入 `nums[2*i]` 和 `nums[2*i+1]` 可能覆盖还没读取的 `nums[i]` 或 `nums[n+i]`。从后往前时，目标位置 `2*i` 和 `2*i+1` 总是 >= `i`，所以不会覆盖尚未读取的源数据。
- **1023 = 0x3FF = (1 << 10) - 1**，用来取低 10 位。
- 这个技巧要求值的范围足够小（本题 <= 1000，刚好满足 10 位）。
- 注意使用 `|=` 而非 `+=`，避免在低位已经有值时产生进位干扰（虽然对于这个特定情况效果相同，但 `|=` 语义更准确）。

### 解法3: 乘法编码变体 — O(n) / O(1)

**另一个角度**: 用乘法代替位移，对不熟悉位运算的人更直观。

```cpp
class Solution {
public:
    vector<int> shuffle(vector<int>& nums, int n) {
        const int BASE = 1024; // 大于 max(nums[i]) 的值
        // 编码: nums[pos] = old + new * BASE
        for (int i = n - 1; i >= 0; i--) {
            int xi = nums[i] % BASE;       // 旧的 x 值
            int yi = nums[n + i] % BASE;   // 旧的 y 值
            nums[2 * i] += xi * BASE;      // 编码 x 到高位
            nums[2 * i + 1] += yi * BASE;  // 编码 y 到高位
        }
        // 解码: 取高位
        for (auto& x : nums) x /= BASE;
        return nums;
    }
};
```

**关键点**:
- 用 `% BASE` 取旧值，`/ BASE` 取新值。逻辑等价于位运算版本。
- BASE 必须大于所有可能的 nums[i] 值（1024 > 1000 满足）。

| 时间 | O(n) | O(n) |
| 空间 | O(n) | **O(1)** |
| 代码复杂度 | ⭐ 极简 | ⭐⭐⭐ 需要理解编码 |
| 适用场景 | **通用首选** | 面试追问"能否O(1)空间" |
| 前提条件 | 无 | 需要值的范围足够小 |

## 易错点

1. **后半段索引写错**：
   - ✗ `nums[i + 1]` 或 `nums[n - i]` → 错误的后半段索引
   - ✓ `nums[n + i]`（i 从 0 开始，后半段第 i 个元素）

2. **结果数组大小错误**：
   - ✗ `vector<int> result(n)` → 只分配了 n 个位置，需要 2n
   - ✓ `vector<int> result(2 * n)` 或 `result.reserve(2 * n)`

3. **位编码时忘记取旧值**：
   - ✗ 直接用 `nums[i]` 而不是 `nums[i] & 1023` → 如果之前编码过，高位已经有值了
   - ✓ 始终用 `nums[i] & 1023`（或 `% 1024`）来提取旧值

4. **位编码处理顺序错误**：
   - ✗ 从前往后编码 → i=0 时写入 nums[0] 和 nums[1]，但后续还需要读取 nums[0] 的旧值
   - ✓ 从后往前编码 → 目标位置 >= 源位置，不会提前覆盖

5. **push_back vs 预分配**：
   - 不是 bug 但影响性能：`push_back` 可能触发多次内存重新分配
   - ✓ 用 `reserve(2*n)` 预分配或直接 `vector<int> result(2*n)`

## 面试追问

**Q1: 这道题的时间和空间复杂度是什么？能优化吗？**
> 新数组解法是 O(n) 时间 O(n) 空间。空间可以用位编码优化到 O(1)（前提是值的范围足够小，本题 <= 1000）。时间无法优于 O(n) 因为每个元素至少要被读取一次。

**Q2: 如果数组非常大（比如 10 亿个元素），内存装不下一个额外数组怎么办？**
> 必须用 O(1) 空间的原地算法。位编码在值范围小的时候可行。如果值范围大，可以用"循环置换"：计算每个元素的目标位置，沿着置换环移动。每个元素最多被移动一次，总时间 O(n)。

**Q3: 如果 nums[i] 的范围很大（比如 <= 10^9），位编码还能用吗？**
> 不能，因为 int 只有 32 位。这时候可以用循环置换，或者如果可以修改数据类型，用 long long（64 位）来编码。另一个思路是把两个值打包到一个 long long 里：`packed = ((long long)newVal << 32) | oldVal`。

**Q4: 如果是逆操作——把 [x1,y1,x2,y2,...] 还原成 [x1,x2,...,y1,y2,...] 呢？**
> 索引映射反转：`result[i] = nums[2*i]`，`result[n+i] = nums[2*i+1]`。代码结构几乎一样，只是映射关系反过来。

**Q5: 泛化问题：如果把数组分成 k 组（而不是 2 组），要怎么交错？**
> 设数组有 `k*n` 个元素，分成 k 组。结果中第 i 位置（0-indexed）应该是原数组中第 `(i % k) * n + (i / k)` 个元素。循环填充即可。
