# 1190. 反转每对括号间的子串

## 核心思路

处理**嵌套括号内反转**的问题。最直观的方法是用**栈模拟**：遇到 `(` 开新层，遇到 `)` 反转当前层并合并回上一层。进阶方法是**虫洞穿越（Wormhole）**：预处理括号配对，遍历时遇到括号就"跳"到配对位置并反转方向，实现 O(n) 一次遍历。

关键洞察（虫洞法）：每对括号代表一次反转。遍历到 `(` 时，如果我们"穿越"到匹配的 `)` 并反转方向（向左走），效果等同于对括号内容做一次反转。这样多层嵌套的反转都能通过方向切换来模拟。

## 思维链

1. **读完题第一反应** → 从最内层括号开始反转，逐层向外。这是递归/栈的天然应用场景。
2. **栈模拟的思路** → 维护一个 `stack<string>`。遇到 `(` 压入空串开启新层；遇到 `)` 弹出栈顶，反转后拼接到新的栈顶；遇到字母追加到栈顶。最后栈里只剩一个字符串就是答案。
3. **栈模拟的复杂度** → 每次遇到 `)` 要反转一次。最坏情况如 `(((...)))` 有 n/2 层嵌套，每层反转 O(n/2) 个字符，总共 O(n^2/4) = O(n^2)。对于 n <= 2000 是可以接受的。
4. **能否做到 O(n)？** → 虫洞穿越法！观察到每对括号的效果是"遍历方向反转"。预处理出每个 `(` 对应的 `)` 位置（互相映射），然后线性遍历字符串：遇到括号就跳到配对位置并切换方向（从向右变向左，或反之）。遇到字母就收集。
5. **虫洞法的正确性** → 一对括号代表一次反转。向右遍历时遇到 `(`，跳到 `)` 并改为向左，相当于把括号内的内容倒着读了一遍。多层嵌套时方向会反复切换，效果等同于逐层反转。
6. **复杂度分析** → 虫洞法每个字符最多被访问一次（因为遍历不会回头访问已收集的字母），所以 O(n)。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 栈模拟 | 括号压栈，反转合并 | O(n^2) | O(n) | ⭐ 面试首选 |
| 虫洞穿越 | 预处理配对，方向切换 | O(n) | O(n) | ⭐ 进阶加分 |

## 关键提示

1. **栈模拟的核心操作**：`(` → `push("")`，`)` → `pop + reverse + 拼接到栈顶`，字母 → `top += c`。初始栈中先 push 一个空串作为最外层。
2. **虫洞法的配对预处理**：用栈在一次遍历中建立 `pair[]` 映射——`pair[i]` 表示第 `i` 个括号的配对位置。`(` 入栈，遇到 `)` 时 pop 出 `(` 的位置，互相映射。
3. **虫洞法的方向切换**：维护 `dir = +1`（向右）或 `dir = -1`（向左）。遇到括号时 `i = pair[i]` 然后 `dir = -dir`，再 `i += dir` 进入下一个字符。遇到字母时收集并 `i += dir`。
4. **虫洞法不需要真正反转字符串**：所有反转操作都通过方向切换来隐式完成，所以没有实际的 reverse 调用。

## 解法详解

### 解法1: 栈模拟 — O(n^2) / O(n) ⭐ 面试首选

**思考过程**: 嵌套括号从内到外处理 → 栈是天然的数据结构。每一层括号对应栈中的一个字符串。遇到 `)` 时反转并合并，模拟了"从内到外逐层反转"的过程。

```
示例: s = "(u(love)i)"

遍历:
'(' → push("")        栈: ["", ""]
'u' → top += 'u'      栈: ["", "u"]
'(' → push("")        栈: ["", "u", ""]
'l' → top += 'l'      栈: ["", "u", "l"]
'o' → top += 'o'      栈: ["", "u", "lo"]
'v' → top += 'v'      栈: ["", "u", "lov"]
'e' → top += 'e'      栈: ["", "u", "love"]
')' → pop "love", reverse → "evol", top += "evol"
                       栈: ["", "uevol"]
'i' → top += 'i'      栈: ["", "uevoli"]
')' → pop "uevoli", reverse → "iloveu", top += "iloveu"
                       栈: ["iloveu"]

结果: "iloveu" ✓
```

```cpp
class Solution {
public:
    string reverseParentheses(string s) {
        stack<string> stk;
        stk.push(""); // 最外层容器
        
        for (char c : s) {
            if (c == '(') {
                stk.push(""); // 开启新的括号层
            } else if (c == ')') {
                string cur = stk.top(); stk.pop();
                reverse(cur.begin(), cur.end()); // 反转当前层
                stk.top() += cur; // 拼接到上一层
            } else {
                stk.top() += c; // 字母追加到当前层
            }
        }
        return stk.top();
    }
};
```

**关键点**:
- 初始压入一个空串作为"最外层容器"，这样最后栈中只剩这一个元素就是答案。
- `reverse` 操作在最坏情况下（深度嵌套）会导致 O(n^2)，但对于 n <= 2000 完全够用。
- 代码极其简洁（不到 15 行），面试中能快速写出且不容易出错。

---

### 解法2: 虫洞穿越 (Wormhole Teleportation) — O(n) / O(n) ⭐ 进阶加分

**优化思路**: 栈模拟的瓶颈是 `reverse` 操作。能否避免实际反转？虫洞法的核心想法：每对括号相当于一个"传送门"，遍历到括号时跳转到配对位置并反转遍历方向。

```
示例: s = "(ed(et(oc))el)"
索引:    0123456789...13

预处理配对 pair[]:
  pair[0] = 13, pair[13] = 0    (最外层括号)
  pair[3] = 10, pair[10] = 3    (第二层括号)
  pair[6] = 9,  pair[9] = 6     (最内层括号)

虫洞遍历 (从 i=0, dir=+1 向右):
  i=0: '(' → 跳到 pair[0]=13, dir=-1(向左), i=13-1=12
  i=12: 'l' → 收集 'l', i=11
  i=11: 'e' → 收集 'e', i=10
  i=10: ')' → 跳到 pair[10]=3, dir=+1(向右), i=3+1=4
  i=4:  'e' → 收集 'e', i=5
  i=5:  't' → 收集 't', i=6
  i=6:  '(' → 跳到 pair[6]=9, dir=-1(向左), i=9-1=8
  i=8:  'c' → 收集 'c', i=7
  i=7:  'o' → 收集 'o', i=6... 不对!
  
  更正: i=6 跳到 pair[6]=9, dir=-1, i=9+(-1)=8
  i=8:  'c' → 收集 'c', i=8+(-1)=7
  i=7:  'o' → 收集 'o', i=7+(-1)=6
  i=6:  '(' → 跳到 pair[6]=9, dir=+1, i=9+1=10
  ... 这样不对, 让我重新整理

正确过程:
  i=0, dir=1:  '(' → i=pair[0]=13, dir=-1, i+=dir → i=12
  i=12, dir=-1: 'l' → 收集, i=11
  i=11, dir=-1: 'e' → 收集, i=10
  i=10, dir=-1: ')' → i=pair[10]=3, dir=1, i+=dir → i=4
  i=4, dir=1:  'e' → 收集, i=5
  i=5, dir=1:  't' → 收集, i=6
  i=6, dir=1:  '(' → i=pair[6]=9, dir=-1, i+=dir → i=8
  i=8, dir=-1: 'c' → 收集, i=7
  i=7, dir=-1: 'o' → 收集, i=6
  i=6, dir=-1: '(' → i=pair[6]=9, dir=1, i+=dir → i=10
  i=10, dir=1: ')' → i=pair[10]=3, dir=-1, i+=dir → i=2
  i=2, dir=-1: 'd' → 收集, i=1
  i=1, dir=-1: 'e' → 收集, i=0
  i=0, dir=-1: '(' → i=pair[0]=13, dir=1, i+=dir → i=14 (越界, 停止)

收集: l-e-e-t-c-o-d-e → "leetcode" ✓
```

```cpp
class Solution {
public:
    string reverseParentheses(string s) {
        int n = s.size();
        vector<int> pair_idx(n);
        stack<int> stk;
        
        // 预处理: 建立括号配对映射
        for (int i = 0; i < n; i++) {
            if (s[i] == '(') {
                stk.push(i);
            } else if (s[i] == ')') {
                int j = stk.top(); stk.pop();
                pair_idx[i] = j;
                pair_idx[j] = i;
            }
        }
        
        // 虫洞遍历
        string result;
        int i = 0, dir = 1; // dir=1向右, dir=-1向左
        while (i >= 0 && i < n) {
            if (s[i] == '(' || s[i] == ')') {
                i = pair_idx[i]; // 跳到配对位置
                dir = -dir;      // 反转方向
            } else {
                result += s[i];  // 收集字母
            }
            i += dir; // 按当前方向前进
        }
        return result;
    }
};
```

**关键点**:
- `pair_idx[]` 用栈在 O(n) 内预处理完成。
- 遍历时只收集字母（不收集括号），每个字母恰好被收集一次。
- 虽然遍历路径看起来可能来回跳跃，但因为每次遇到括号只是"传送+转向"，实际上每个位置被处理的次数是 O(1)（分析：遍历过程中指针不会重复访问同一个字母）。
- 总时间 O(n)，没有任何 reverse 调用。

## 易错点

1. **栈初始状态忘记 push 空串**：
   - ✗ 栈为空，第一个字母无处放 → crash 或逻辑错误
   - ✓ `stk.push("")` 作为最外层容器

2. **虫洞法方向切换时机**：
   - ✗ 先 `i += dir` 再跳 → 位置错位
   - ✓ 先跳到配对位置，再反转方向，最后 `i += dir`

3. **虫洞法遍历终止条件**：
   - ✗ `while (i < n)` → 方向向左时 i 可能变负
   - ✓ `while (i >= 0 && i < n)`

4. **字符串拼接性能**：
   - ✗ 在栈模拟中用 `cur = cur + stk.top()` → 多次拷贝
   - ✓ `stk.top() += cur` 直接追加到上一层，避免额外拷贝

5. **括号配对映射忘记双向建立**：
   - ✗ 只建了 `pair[j] = i`（`(` 指向 `)`）
   - ✓ 需要双向：`pair[i] = j` 和 `pair[j] = i`，因为从两个方向都可能遇到括号

## 面试追问

**Q1: 栈模拟的时间复杂度具体是多少？最坏情况是什么？**
> 最坏 O(n^2)。例如 `(((...)))` 有 n/2 层嵌套，每层包含约 n/2 个字符需要反转。但由于 n <= 2000，O(n^2) = 4 * 10^6 完全可以接受。

**Q2: 虫洞法为什么是 O(n)？看起来指针在来回跳。**
> 虽然指针在括号间跳跃，但对于每个字母字符，指针只经过它一次就收集了。括号字符虽然可能被经过两次（正向和反向各一次），但总的步数 <= 2n。更精确地说：遍历过程中指针走的总步数 = 字符串长度 n（每步要么收集一个字母，要么在括号间跳转）。

**Q3: 如果括号可能不平衡怎么办？**
> 题目保证括号平衡，但如果要处理不平衡情况：先验证平衡性（栈检查），不平衡则返回空串或原串。栈模拟中不平衡会导致 `pop` 空栈崩溃；虫洞法中配对映射建不全，遍历时可能跳到错误位置。
