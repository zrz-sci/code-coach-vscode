# 750. Number Of Corner Rectangles - 角矩形的数量

## 核心思路

本题要在 0/1 矩阵中找出所有「角矩形」——即找出四个位置 `(r1,c1), (r1,c2), (r2,c1), (r2,c2)` 都为 1 的矩形。核心思路是：**固定两行，统计这两行中同时为 1 的列对数量**。如果两行在 `cnt` 个列位置上同时为 1，则这两行能贡献 `C(cnt, 2) = cnt*(cnt-1)/2` 个角矩形。

## 思维链

1. 暴力方法：枚举四个角 O(m^2 * n^2)，超时
2. 优化观察：一旦固定了两行 r1 和 r2，矩形只需找到两列 c1, c2 使得四角均为 1
3. 关键转化：固定两行后，统计同时为 1 的列数 cnt，从中任选 2 列即形成一个矩形
4. 进一步优化：可以逐行扫描，用计数数组记录之前所有行中每对列同时为 1 的累计次数
5. 复杂度分析：方法一 O(m^2 * n)，方法二 O(m * n^2)，根据 m 和 n 的关系选择

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|-----------|-----------|---------|
| 枚举行对 + 计数列 | O(m^2 * n) | O(1) | m 较小时 |
| 列对计数 DP | O(m * n^2) | O(n^2) | n 较小时 |
| 位运算优化 | O(m^2 * n/64) | O(n) | n 较大时使用 bitset |

## 关键提示

1. **组合数公式**：cnt 个共同列选 2 个 = `cnt * (cnt - 1) / 2`
2. **行对 vs 列对**：当 m < n 时枚举行对更优，反之枚举列对
3. **增量更新思想**：逐行处理时，对于当前行中值为 1 的每对列 (c1, c2)，之前已出现的次数就是新增矩形数
4. **矩阵约束**：1 的总数 <= 6000，说明大多数格子是 0，可以只对值为 1 的列做处理

## 解法详解

### 解法一：枚举行对 + 统计共同列（推荐）

对每对行 (r1, r2)，遍历所有列，统计两行同时为 1 的列数 cnt，答案累加 `cnt*(cnt-1)/2`。

**核心逻辑**：
- 外层两重循环枚举行对 (r1, r2)
- 内层遍历列，统计 `grid[r1][c] == 1 && grid[r2][c] == 1` 的个数
- 每个行对贡献 C(cnt, 2) 个矩形

### 解法二：列对计数 DP（增量法）

维护一个二维计数数组 `count[c1][c2]`，逐行扫描，对于当前行每对值为 1 的列 (c1, c2)：
- 答案累加 `count[c1][c2]`（与之前行配对形成的矩形数）
- 然后 `count[c1][c2]++`

**优势**：只需遍历值为 1 的列，当 1 稀疏时效率高。

### 解法三：位运算优化

将每行表示为 bitset，两行做 AND 运算后计算 popcount，即可得到共同列数 cnt。
适用于 n 很大的场景，实际面试中较少使用。

## 易错点

1. **重复计数**：行对 (r1, r2) 中必须保证 r1 < r2，避免重复
2. **组合数公式**：`cnt*(cnt-1)/2` 不要写成 `cnt*cnt`
3. **列对计数法中列的顺序**：确保 c1 < c2 避免重复
4. **只有一行时**：不可能形成矩形，答案为 0
5. **int 溢出**：虽然本题数据范围小不会溢出，但养成好习惯

## 面试追问

1. **Q: 如何根据 m 和 n 的大小关系自动选择最优策略？**
   A: 如果 m < n，枚举行对 O(m^2 * n)；如果 m > n，转置矩阵或枚举列对 O(m * n^2)。

2. **Q: 如果矩阵非常稀疏（1 很少），如何进一步优化？**
   A: 对每行只记录值为 1 的列索引列表，枚举行对时只对这些列求交集。

3. **Q: 如果改为统计所有子矩形（不只是角矩形），怎么做？**
   A: 使用直方图 + 单调栈方法，逐行构建柱状图，计算每行的子矩形数量。

4. **Q: 能否用哈希表优化？**
   A: 可以将每行的 1 的位置编码为集合，用哈希加速交集计算。

5. **Q: 该算法能否并行化？**
   A: 行对枚举天然可并行，每个行对的计算互不依赖。
