# 699. Falling Squares

## 核心思路

模拟方块从上方掉落到 X 轴上的过程。每个方块落下时，其底部高度取决于它覆盖的 X 轴区间内已有方块的最大高度。核心难点在于高效维护区间最大高度。可以用**坐标压缩 + 线段树/有序集合**实现 O(N log N)，也可以用**暴力 O(N^2)** 的方法（N <= 1000 可以接受）逐一检查每个已落方块是否与新方块有交叠。

## 思维链

1. 每个方块由 [left, sideLength] 定义，占据 X 轴区间 [left, left + sideLength)
2. 方块掉落后的顶部高度 = 区间 [left, left+sideLength) 内已有最大高度 + sideLength
3. 每次掉落后记录全局最大高度
4. N <= 1000，暴力 O(N^2) 可行：对每个新方块遍历所有已落方块检查区间重叠
5. 更优解：坐标压缩 + 线段树，支持区间查询最大值和区间更新
6. 关键判断：两个区间 [l1, r1) 和 [l2, r2) 重叠当且仅当 l1 < r2 且 l2 < r1（严格小于，擦边不算）

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 暴力模拟 | O(N^2) | O(N) | 简单直接，N<=1000 足够 |
| 坐标压缩+线段树 | O(N log N) | O(N) | 最优，支持区间查询/更新 |
| 有序 Map 区间管理 | O(N log N) | O(N) | 用 std::map 维护不重叠高度区间 |

## 关键提示

1. **区间重叠判断**：方块 A [l1, l1+s1) 和方块 B [l2, l2+s2) 有重叠当且仅当 l1 < l2+s2 且 l2 < l1+s1。注意是**严格小于**，因为"擦边"不算重叠（题目明确说明 brushing 不算 landing）。
2. **高度累加逻辑**：新方块落在区间 [l, l+s) 上的高度 = 该区间内已有最大高度 maxH + s。新方块顶部高度为 maxH + s。
3. **全局最大高度追踪**：每次掉落后的结果不是当前方块的高度，而是所有已落方块中的最大高度。需要用一个变量 globalMax 追踪。
4. **坐标压缩**：坐标范围最大 10^8，但方块最多 1000 个，坐标最多 2000 个不同值。离散化后线段树大小可控。

## 解法详解

### 解法一：暴力模拟 O(N^2)（推荐面试首选）

**思路**：
维护一个已落方块列表，每个方块记录 [left, right, height]。对于每个新方块，遍历已落方块列表找出所有与新方块区间有重叠的方块，取其中最大高度 maxH，新方块高度为 maxH + sideLength。

**步骤**：
1. 初始化空列表 intervals，结果数组 ans
2. 对每个新方块 [left, size]：
   a. right = left + size
   b. maxH = 0
   c. 遍历 intervals，对每个 [l, r, h]，如果 left < r && l < right，则 maxH = max(maxH, h)
   d. curH = maxH + size
   e. 将 [left, right, curH] 加入 intervals
   f. globalMax = max(globalMax, curH)，加入 ans
3. 返回 ans

**复杂度**：
- 时间：O(N^2)，每次掉落遍历所有已落方块
- 空间：O(N)

### 解法二：坐标压缩 + 线段树

**思路**：
将所有坐标离散化，建立线段树维护每个区间的最大高度。每次新方块落下时：
1. 查询区间 [left, right) 的最大高度 maxH
2. 将区间 [left, right) 更新为 maxH + sideLength

**步骤**：
1. 收集所有坐标值并排序去重，建立坐标映射
2. 建立线段树，支持区间最大值查询和区间赋值更新
3. 对每个方块做一次查询 + 一次更新
4. 维护全局最大高度

**复杂度**：
- 时间：O(N log N)
- 空间：O(N)

### 解法三：有序 Map 区间管理

**思路**：
用 std::map<int, int> 维护一组不重叠的区间-高度映射。key 是区间左端点，value 是该区间的高度。每次新方块落下时，找出所有被覆盖的区间，取最大高度，然后更新区间。

**步骤**：
1. 用 map 维护 {坐标点 -> 从该点开始的高度}
2. 新方块 [L, R) 落下时，找 map 中与 [L, R) 重叠的所有条目
3. 取最大高度，删除被完全覆盖的条目，插入新区间
4. 需要小心处理边界切割

## 易错点

1. **擦边判断错误**：区间 [1,3) 和 [3,6) 不重叠（left2 == right1 不算重叠）。必须用严格小于：l1 < r2 && l2 < r1。
2. **混淆区间端点**：题目给的是 [left, sideLength]，right = left + sideLength，不是 left + sideLength - 1。区间是左闭右开的。
3. **忘记追踪全局最大值**：每次结果是全局最高高度，不是当前方块高度。需要维护一个 running maximum。
4. **线段树 lazy 传播遗漏**：区间赋值更新需要 lazy propagation，忘记下推会导致查询结果错误。
5. **坐标压缩后区间映射错误**：离散化时需要保证连续坐标之间的"间隙"也被正确处理，通常需要将左端点和右端点都加入坐标集合。

## 面试追问

1. **O(N^2) 解法在 N=1000 时够用，什么场景下必须用线段树？**
   - 当 N 达到 10^5 或更大时，O(N^2) 会 TLE。线段树的 O(N log N) 在大数据量下优势明显。

2. **如果方块可以左右滑动到最低点（而不是直接下落），问题如何变化？**
   - 变成一个更复杂的优化问题，需要考虑每个可能的左端点位置，类似贪心/搜索。

3. **如何处理方块掉落后可能需要合并的情况？**
   - 本题不需要合并，因为每个方块作为独立实体存在。但如果要优化区间存储，可以合并高度相同的相邻区间。

4. **如何输出每次掉落后的完整高度轮廓线？**
   - 维护有序 map 或线段树，输出所有区间的高度变化点即为天际线。

5. **这题与天际线问题 (218. The Skyline Problem) 有什么关系？**
   - 都涉及区间高度管理和区间重叠处理。但天际线问题是静态的，本题是动态增量的（逐个掉落）。
