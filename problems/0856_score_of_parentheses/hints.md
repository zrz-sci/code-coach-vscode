# 856. 括号的分数

## 核心思路

本质是一个**递归结构解析**问题：括号字符串天然具有嵌套结构，`()` 得1分，并列相加，嵌套翻倍。可以用**栈**模拟递归过程，或者用**深度计数法**观察到每个 `()` 的贡献是 `2^depth`。

## 思维链

1. **读完题第一反应** → 这是一个递归定义：`()` = 1，`AB` = A+B，`(A)` = 2*A。直觉上可以用递归解析。
2. **能用栈吗？** → 括号匹配经典用栈。遇到 `(` 入栈一个标记，遇到 `)` 弹出并计算。
3. **栈里存什么？** → 存当前层的分数。遇到 `(` 压入0（新层初始分数0），遇到 `)` 弹出栈顶 `inner`，如果 `inner == 0` 说明是 `()`，贡献1分；否则贡献 `2 * inner`。
4. **有没有更巧妙的方法？** → 观察：最终分数可以分解为所有叶子 `()` 的贡献之和。每个 `()` 被嵌套了 d 层，贡献 `2^d`。例如 `(()(()))` = `2^1 + 2^2` = 6。
5. **深度法怎么实现？** → 维护当前深度 `depth`。遇到 `(` 则 `depth++`，遇到 `)` 则 `depth--`。如果遇到 `()` 模式（`s[i]=='(' && s[i+1]==')'`），加上 `2^depth`（这里 depth 是 `(` 已经增加后的值，所以用 `1 << depth`）。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 栈模拟 | 用栈维护每层分数，逐字符处理 | O(n) | O(n) | ⭐ 推荐 |
| 深度计数法 | 每个 `()` 贡献 2^depth | O(n) | O(1) | ⭐ 最优 |
| 递归解析 | 递归处理括号结构 | O(n) | O(n) | 可写 |

## 关键提示

1. **栈中存数字**：栈中的每个值代表当前层已经累积的分数。遇到 `(` 入栈0（新层开始），遇到 `)` 弹出栈顶并合并到下一层。
2. **`)` 时的计算逻辑**：弹出 `inner`。若 `inner == 0`：是 `()`，得1分。若 `inner > 0`：是 `(A)`，得 `2*inner` 分。将这个分数加到新的栈顶。
3. **深度法的直觉**：`(A)` = 2*A 意味着每多一层嵌套，分数翻倍。所以最内层的 `()` 被嵌套 d 层，贡献 `2^d`。
4. **深度法只关心 `()` 对**：只有相邻的 `()` 才产生分数，其他括号只改变深度。
5. **栈底的哨兵**：初始在栈底压一个0，代表最外层的累计分数。遍历完后栈中唯一的元素就是答案。

## 解法详解

### 解法1: 栈模拟 — O(n) / O(n) ⭐ 面试推荐

**思考过程**: 栈中每个元素代表当前括号层级已累计的分数。

```
示例: s = "(()(()))"

处理过程 (栈从底到顶展示):
初始: [0]                    ← 哨兵，最外层分数
'(': [0, 0]                  ← 第1层
'(': [0, 0, 0]               ← 第2层
')': inner=0, 是"()", 得1分
     [0, 0+1] = [0, 1]       ← 回到第1层，累计1分
'(': [0, 1, 0]               ← 新的第2层
'(': [0, 1, 0, 0]            ← 第3层
')': inner=0, 是"()", 得1分
     [0, 1, 0+1] = [0, 1, 1] ← 回到第2层
')': inner=1, 是"(A)", 得2分
     [0, 1+2] = [0, 3]       ← 回到第1层
')': inner=3, 是"(A)", 得6分
     [0+6] = [6]              ← 回到最外层
答案: 6 ✓
```

```cpp
class Solution {
public:
    int scoreOfParentheses(string s) {
        stack<int> stk;
        stk.push(0); // 哨兵：最外层分数
        for (char c : s) {
            if (c == '(') {
                stk.push(0); // 新层开始，初始分数0
            } else {
                int inner = stk.top(); stk.pop();
                int score = (inner == 0) ? 1 : 2 * inner;
                stk.top() += score;
            }
        }
        return stk.top();
    }
};
```

**关键点**:
- 栈底的0是哨兵，保证 `)` 弹出后总有栈顶可加。
- `inner == 0` 对应 `()` 得1分；`inner > 0` 对应 `(A)` 得 `2*inner` 分。
- `AB = A + B` 自动通过 `stk.top() += score` 实现。

---

### 解法2: 深度计数法 — O(n) / O(1) ⭐ 最优

**关键洞察**: 分数可以分解为所有叶子 `()` 的贡献之和。每个 `()` 如果被嵌套 d 层，贡献 `2^d`。

```
示例: s = "(()(()))"

深度分析:
( ( ) ( ( ) ) )
0 1 1 1 2 2 1 0   ← depth 变化
    ^       ^
    |       |
    ()深度1  ()深度2

贡献: 2^1 + 2^2 = 2 + 4 = 6 ✓

为什么？
  "(()(()))" = 2 * ("()" + "(())") = 2 * (1 + 2*1) = 2*3 = 6
  拆成叶子: 内层第一个() 被嵌套1层 → 2^1 = 2
           内层第二个() 被嵌套2层 → 2^2 = 4
           总和 = 6 ✓
```

```cpp
class Solution {
public:
    int scoreOfParentheses(string s) {
        int depth = 0, ans = 0;
        for (int i = 0; i < (int)s.size(); i++) {
            if (s[i] == '(') {
                depth++;
            } else {
                depth--;
                // 只有 "()" 对贡献分数
                if (s[i - 1] == '(') {
                    ans += (1 << depth); // 2^depth
                }
            }
        }
        return ans;
    }
};
```

**关键点**:
- `depth` 在遇到 `(` 后增加，遇到 `)` 后减少。
- 只有 `s[i-1]=='(' && s[i]==')'` 时（即匹配到 `()`），才计入分数。
- 此时 depth 已经减过了，所以用 `1 << depth` 正好是嵌套深度对应的 `2^d`。
- 空间 O(1)，是最优解。

---

### 解法3: 递归解析 — O(n) / O(n)

**直觉**: 按递归定义解析。设指针 `pos`，递归处理每个子表达式。

```cpp
class Solution {
public:
    int pos;
    int scoreOfParentheses(string s) {
        pos = 0;
        return parse(s);
    }
    int parse(string& s) {
        int score = 0;
        while (pos < (int)s.size() && s[pos] != ')') {
            // 遇到 '('
            pos++; // 跳过 '('
            if (s[pos] == ')') {
                score += 1; // "()" 得1分
            } else {
                score += 2 * parse(s); // "(A)" 得 2*A
            }
            pos++; // 跳过 ')'
        }
        return score;
    }
};
```

## 易错点

1. **栈底忘记放哨兵**：
   - 错: 空栈开始 → 第一个 `)` 弹出后栈空，`stk.top()` 未定义
   - 对: `stk.push(0)` 初始化

2. **深度法中 depth 更新时机**：
   - 错: 先判断 `()` 再更新 depth → depth 值不对
   - 对: 遇到 `)` 先 `depth--`，再判断 `s[i-1]=='('`

3. **深度法中用乘法而非位运算**：
   - 不算错，但 `1 << depth` 比 `pow(2, depth)` 更高效且无浮点问题
   - 注意 depth 最大25（s.length <= 50），`1 << 25` 不会溢出 int

4. **递归解法中 pos 传递问题**：
   - 错: pos 作为参数传值 → 递归返回后 pos 没更新
   - 对: pos 作为类成员变量或引用传递

## 面试追问

**Q1: 三种解法哪个最好？**
> 深度计数法 O(n)/O(1) 时空最优。但栈解法更通用、更容易理解和扩展。面试中建议先写栈解法，再提深度法作为优化。

**Q2: 深度法为什么只看 `()` 对？**
> 因为所有分数最终都来自叶子 `()`。`(A)` = 2*A 只是把 A 中的所有叶子分数翻倍。所以每个叶子 `()` 被嵌套 d 层，贡献 `2^d`，总分 = 所有叶子贡献之和。

**Q3: 如果括号不平衡怎么办？**
> 题目保证平衡。如果不保证，栈解法可以在最后检查栈大小是否为1来判断合法性。

**Q4: 如果规则改为 `(A)` = 3*A，怎么改？**
> 栈解法：`score = (inner == 0) ? 1 : 3 * inner`。深度法：`ans += pow(3, depth)`。结构不变。
