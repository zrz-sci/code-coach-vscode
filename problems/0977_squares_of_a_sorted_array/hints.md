# 977. 有序数组的平方

## 核心思路

原数组是**有序的**，负数平方后会变大，导致平方后的数组"两头大、中间小"（呈 V 形）。利用这个特性，用**双指针从两端向中间收缩**，每次取绝对值更大的那个放到结果数组末尾，就能 O(n) 得到有序结果。

## 思维链

1. **读完题第一反应**：每个元素平方一下，然后排序不就行了？→ 暴力解 O(n log n)
2. **暴力解的瓶颈在哪？** 平方本身 O(n) 没问题，瓶颈在排序的 O(n log n)。题目说原数组已经有序，我们能不能利用这个信息避免排序？
3. **关键观察**：原数组有序 `[-4, -1, 0, 3, 10]`，平方后 `[16, 1, 0, 9, 100]`。虽然中间乱了，但注意——**绝对值最大的元素一定在数组两端**！负数越小绝对值越大（在左端），正数越大绝对值越大（在右端）。
4. **突破瓶颈**：既然最大值一定在两端之一，我们可以用**左右双指针**，每次比较两端的绝对值，把大的那个的平方放到结果数组的**末尾**（从后往前填充），然后指针向内收缩。
5. **为什么是从后往前填？** 因为我们每次找到的是"当前剩余中最大的"，所以应该放在结果数组的最后面。下一轮再找次大的，放在倒数第二个位置，以此类推。
6. **结束条件**：当左指针越过右指针时，所有元素都已处理完毕。

```
// 可视化过程: nums = [-4, -1, 0, 3, 10]
//
// 平方后的"V形"结构 (绝对值从两端向中间递减):
//
// |abs|:  4   1   0   3   10
//         ↑               ↑
//        left            right
//
// Step1: |10| > |-4| → result[4] = 100, right--
//         ↑          ↑
//        left      right
//
// Step2: |-4| > |3|  → result[3] = 16,  left++
//            ↑    ↑
//           left right
//
// Step3: |3| > |-1|  → result[2] = 9,   right--
//            ↑  ↑
//          left right
//
// Step4: |-1| > |0|  → result[1] = 1,   left++
//             ↑↑
//          left/right
//
// Step5: left == right, |0| → result[0] = 0
//
// result = [0, 1, 9, 16, 100] ✓
```

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力排序 | 平方后直接排序 | O(n log n) | O(1)~O(n) | 能说出即可 |
| 双指针（从两端到中间） | 利用绝对值最大在两端，从后往前填 | O(n) | O(n) | ⭐ 必须写出 |
| 双指针（从中间到两端） | 找到正负分界点，类似归并两个有序段 | O(n) | O(n) | 加分项 |

## 关键提示

1. **平方后的数组什么形状？** 画出来：原数组有负有正，平方后绝对值大的数在两头，绝对值小的在中间，整体呈 V 形。
2. **从哪里开始填结果数组？** 我们每次容易确定的是"当前最大值"（两端之一），所以从结果数组**末尾**开始往前填。
3. **双指针为什么不会漏？** 左指针只往右走，右指针只往左走，每次恰好处理一个元素，总共 n 次，不多不少。
4. **不需要真的算绝对值**：比较时用 `abs(nums[left])` 和 `abs(nums[right])` 即可，或者直接比 `nums[left]*nums[left]` 和 `nums[right]*nums[right]`。
5. **Follow-up 要求 O(n)**：暴力排序是 O(n log n)，双指针解法天然就是 O(n)，正好满足。

## 解法详解

### 解法1: 暴力排序 — O(n log n) / O(1)~O(n)

**思考过程**：这是最直觉的做法——题目让平方后排序，我们就真的平方后排序。不需要任何巧思，直接翻译题意。

```cpp
class Solution {
public:
    vector<int> sortedSquares(vector<int>& nums) {
        // 先把每个元素原地平方
        for (int i = 0; i < nums.size(); i++) {
            nums[i] = nums[i] * nums[i];
        }
        // 再排序
        sort(nums.begin(), nums.end());
        return nums;
    }
};
```

**关键点**：
- 时间瓶颈在 `sort` 的 O(n log n)，平方本身只是 O(n)。
- 完全没利用原数组有序的信息，所以有优化空间。
- 面试中作为起点说出来，然后主动提出"原数组有序可以利用"来引出最优解。

---

### 解法2: 双指针（从两端到中间）— O(n) / O(n) ⭐ 面试首选

**从解法1优化**：暴力解的瓶颈是排序 O(n log n)。关键观察是平方后的数组"两头大、中间小"，绝对值最大的一定在 `nums[0]` 或 `nums[n-1]`。所以用左右双指针，每次把绝对值更大的那个平方放到结果数组末尾，实现一次遍历出结果。

```cpp
class Solution {
public:
    vector<int> sortedSquares(vector<int>& nums) {
        int n = nums.size();
        vector<int> result(n);
        int left = 0, right = n - 1;
        
        // 从结果数组的最后一个位置开始填（因为每次找到的是当前最大值）
        for (int pos = n - 1; pos >= 0; pos--) {
            if (abs(nums[left]) >= abs(nums[right])) {
                // 左端绝对值更大（或相等），取左端
                result[pos] = nums[left] * nums[left];
                left++;
            } else {
                // 右端绝对值更大，取右端
                result[pos] = nums[right] * nums[right];
                right--;
            }
        }
        return result;
    }
};
```

**关键点**：
- `pos` 从 `n-1` 递减到 `0`，恰好填满整个结果数组。
- 循环结束时 `left > right`，所有元素恰好被处理一次。
- 相等时取哪边都行（取左取右都不影响正确性）。

---

### 解法3: 双指针（从中间到两端，归并思想）— O(n) / O(n)

**另一个角度**：原数组有序，可以找到"正负分界点"（第一个非负数的位置），这样左半段的平方是递减的，右半段的平方是递增的。相当于两个有序数组的归并。

```cpp
class Solution {
public:
    vector<int> sortedSquares(vector<int>& nums) {
        int n = nums.size();
        
        // 找到第一个非负数的位置（正负分界点）
        int pivot = 0;
        while (pivot < n && nums[pivot] < 0) {
            pivot++;
        }
        
        // left 指向最后一个负数（向左走，平方递增）
        // right 指向第一个非负数（向右走，平方递增）
        int left = pivot - 1, right = pivot;
        vector<int> result;
        result.reserve(n);
        
        // 归并两个"有序段"
        while (left >= 0 && right < n) {
            int lsq = nums[left] * nums[left];
            int rsq = nums[right] * nums[right];
            if (lsq <= rsq) {
                result.push_back(lsq);
                left--;   // 负数段向左 = 绝对值变大
            } else {
                result.push_back(rsq);
                right++;  // 正数段向右 = 值变大
            }
        }
        
        // 处理剩余元素
        while (left >= 0) {
            result.push_back(nums[left] * nums[left]);
            left--;
        }
        while (right < n) {
            result.push_back(nums[right] * nums[right]);
            right++;
        }
        
        return result;
    }
};
```

**关键点**：
- 这本质上是**归并排序的 merge 步骤**：两个有序序列合并成一个。
- 比解法2代码多一些（要处理剩余元素），但思路直觉——"从最小的开始挑"。
- 面试时如果面试官追问"还有没有其他 O(n) 做法"，可以说这个。

## 解法对比

|  | 解法1: 暴力排序 | 解法2: 双指针(两端→中间) | 解法3: 双指针(中间→两端) |
|--|--|--|--|
| 时间 | O(n log n) | O(n) | O(n) |
| 空间 | O(1)（原地改）或 O(n) | O(n) 结果数组 | O(n) 结果数组 |
| 代码量 | 最少 | 适中 | 较多 |
| 核心思路 | 无技巧 | 最大值在两端 | 归并两个有序段 |
| 面试推荐 | 说出来即可 | ⭐ 首选 | 展示归并思想 |

**选哪个？** 面试首选解法2，代码简洁、思路清晰、一个 for 循环搞定。解法3展示了归并的思想，但代码多且需要额外找分界点。

## 易错点

1. **结果数组填充方向搞反**：
   - ✗ `for (int pos = 0; pos < n; pos++)` 从前往后填 → 每次取的是最大值，应该放在末尾
   - ✓ `for (int pos = n - 1; pos >= 0; pos--)` 从后往前填

2. **比较时忘记取绝对值**：
   - ✗ `if (nums[left] >= nums[right])` → 当 `nums[left]=-4, nums[right]=3` 时，-4 < 3 但平方后 16 > 9
   - ✓ `if (abs(nums[left]) >= abs(nums[right]))` 或直接比较平方值

3. **解法3中分界点找错**：
   - ✗ 找到第一个正数 `nums[pivot] > 0` → 漏掉了 0 的情况
   - ✓ 找到第一个非负数 `nums[pivot] >= 0`（即 `while (nums[pivot] < 0)`）

4. **整数溢出（本题不会但要有意识）**：
   - 本题 `nums[i]` 最大 10⁴，平方后 10⁸，在 int 范围内安全
   - 如果范围更大（如 10⁵），`nums[i] * nums[i]` 可能溢出 int，需要用 `long long`

## 面试追问

**Q1: 暴力解能过吗？瓶颈在哪？**
> 能过（n ≤ 10⁴ 很小），但瓶颈在排序 O(n log n)。原数组已经有序，这个信息被浪费了。

**Q2: 能否做到 O(n)？为什么双指针能做到？**
> 关键观察：平方后绝对值最大的数一定在原数组两端。用左右指针每次取较大的那个放到结果末尾，每个元素只被处理一次，所以 O(n)。

**Q3: 如果要求不使用额外数组（原地操作），能做到 O(n) 吗？**
> 不能。原地操作的话，双指针填充会覆盖还没处理的元素。要么接受 O(n) 额外空间，要么退回 O(n log n) 的原地排序。这是一个空间-时间权衡的经典问题。

**Q4: 如果数组全是正数或全是负数呢？**
> 全正数：平方后天然有序，双指针仍然正确（right 一直被选中）。全负数：平方后是逆序，双指针也正确（left 一直被选中，从后往前填刚好翻转）。不需要特殊处理。
