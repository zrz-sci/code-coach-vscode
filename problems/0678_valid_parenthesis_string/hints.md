# 678. 有效的括号字符串

## 核心思路

这道题本质上是：在 `*` 可以变成 `(`、`)` 或空字符串的情况下，判断是否存在一种分配方案使得括号序列合法。关键在于如何处理 `*` 带来的**不确定性**。

## 思维链

1. **读完题第一反应**：没有 `*` 的话就是经典括号匹配（用计数器或栈）。加了 `*` 后，每个 `*` 有 3 种可能，暴力枚举所有组合？
2. **暴力解的瓶颈**：如果有 k 个 `*`，暴力枚举是 3^k 种组合，最多 3^100 —— 完全不可行。但可以用 DP 减少重复计算。
3. **DP 怎么想**：遍历字符串时，维护"当前未匹配的左括号数量"。没有 `*` 时这个数量是确定的；有 `*` 时，这个数量变成一个**集合**（因为 `*` 可以是三种字符）。用 `dp[i][j]` 表示前 i 个字符能否使未匹配左括号数恰好为 j。
4. **贪心怎么想**：既然未匹配左括号数量是一个范围，不需要记录所有可能值，只需要维护这个范围的**最小值和最大值** `[lo, hi]`。遇到 `(` 两者都 +1，遇到 `)` 两者都 -1，遇到 `*` 最小值 -1 最大值 +1（因为 `*` 可以是 `)` 也可以是 `(`）。
5. **关键约束**：`hi < 0` 说明即使所有 `*` 都当 `(` 也不够，直接 false。`lo < 0` 时把 lo 修正为 0（不能有负数个未匹配左括号）。最后检查 `lo == 0`。
6. **双栈法**：另一个角度——用两个栈分别记录 `(` 和 `*` 的索引，先用 `*` 匹配 `)`，再检查剩余的 `(` 能否被其右边的 `*` 匹配。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力 DP | dp[i][j] = 前 i 个字符能否使左括号余量为 j | O(n²) | O(n) | 能说出即可 |
| 贪心（区间追踪） | 维护未匹配左括号数的可能范围 [lo, hi] | O(n) | O(1) | ⭐ 必须写出 |
| 双栈法 | 分别记录 `(` 和 `*` 的索引，贪心匹配 | O(n) | O(n) | 加分项 |

## 关键提示

1. **没有 `*` 时怎么做？** 用一个计数器 count：遇 `(` 加 1，遇 `)` 减 1。任何时刻 count < 0 就非法，最终 count == 0 就合法。
2. **`*` 引入了不确定性**：count 不再是一个确定值，而是一个**可能值的范围**。想想怎么用两个变量追踪这个范围。
3. **lo 为什么要修正为 0？** 未匹配左括号数量不可能为负（负数意味着右括号多了，但我们可以选择让 `*` 当空字符串来避免这种情况）。
4. **双栈法的关键**：`(` 必须被它右边的 `)` 或 `*` 匹配。所以最后检查每个剩余 `(` 的索引是否小于对应 `*` 的索引。
5. **ASCII 模拟 `(*))` 的贪心过程**：
```
字符:  (     *     )     )
lo:    1     0     0     0    ← 最乐观(尽量消耗左括号)
hi:    1     2     1     0    ← 最悲观(尽量积攒左括号)
       ↑lo修正: max(lo-1, 0)=0
最终 lo==0 → true
```

## 解法详解

### 解法1: 动态规划 — O(n²) / O(n)

**思考过程**：每个位置的"未匹配左括号数量"可能有多种取值。用 `dp[j]` 表示当前位置处，未匹配左括号数为 j 是否可达。对每个字符，更新所有可能的 j 值。

```cpp
class Solution {
public:
    bool checkValidString(string s) {
        int n = s.size();
        // dp[j] = 处理到当前字符时，未匹配的左括号数为 j 是否可能
        vector<bool> dp(n + 1, false);
        dp[0] = true; // 初始：0个未匹配左括号
        
        for (char c : s) {
            vector<bool> ndp(n + 1, false);
            for (int j = 0; j <= n; j++) {
                if (!dp[j]) continue;
                if (c == '(') {
                    // 左括号数 +1
                    if (j + 1 <= n) ndp[j + 1] = true;
                } else if (c == ')') {
                    // 左括号数 -1（j 必须 >= 1 才能消耗）
                    if (j - 1 >= 0) ndp[j - 1] = true;
                } else { // '*'
                    // 当空字符串：j 不变
                    ndp[j] = true;
                    // 当 '('：j + 1
                    if (j + 1 <= n) ndp[j + 1] = true;
                    // 当 ')'：j - 1
                    if (j - 1 >= 0) ndp[j - 1] = true;
                }
            }
            dp = ndp;
        }
        
        return dp[0]; // 最终未匹配左括号数为 0
    }
};
```

**关键点**：
- dp 数组大小是 n+1，因为最多有 n 个未匹配的左括号。
- 每次转移后用新数组 ndp，因为同一轮内不能重复使用。
- 最终只需检查 `dp[0]`，即"是否存在一种分配使得所有括号都匹配"。

### 解法2: 贪心（区间追踪）— O(n) / O(1) ⭐ 面试首选

**从解法1优化**：观察 DP 中 dp[j] 为 true 的 j 值，它们总是构成一个**连续区间** [lo, hi]。这是因为如果 j 和 j+2 都可达，j+1 一定也可达（某个 `*` 少变一次就行）。所以不需要布尔数组，只需两个变量追踪区间边界。

```cpp
class Solution {
public:
    bool checkValidString(string s) {
        // lo: 未匹配左括号数的最小可能值
        // hi: 未匹配左括号数的最大可能值
        int lo = 0, hi = 0;
        
        for (char c : s) {
            if (c == '(') {
                lo++; // 最少也多了一个未匹配的 (
                hi++; // 最多也多了一个
            } else if (c == ')') {
                lo--; // 最少消耗一个 (
                hi--; // 最多消耗一个 (
            } else { // '*'
                lo--; // 当 ')': 消耗一个 (，使最小值减少
                hi++; // 当 '(': 增加一个未匹配 (，使最大值增加
                // 当 ""：不变，但 lo-- 和 hi++ 已经涵盖了
            }
            
            // hi < 0：即使所有 * 都当 (，右括号仍然过多 → 无解
            if (hi < 0) return false;
            
            // lo 不能为负：未匹配左括号数不可能为负
            // 负了说明我们"过度消耗"了，实际上那些 * 应该当空串
            lo = max(lo, 0);
        }
        
        // 最终需要 0 在 [lo, hi] 范围内
        return lo == 0;
    }
};
```

**为什么 `lo = max(lo, 0)` 是正确的？**
- `lo < 0` 意味着"如果让尽可能多的 `*` 当 `)`，左括号数会变负"。
- 但我们有选择权！那些导致 lo 变负的 `*` 可以不当 `)`，而是当空串。
- 所以把 lo 修正为 0，表示"最乐观情况下，可以刚好匹配完"。

```
// 模拟 s = "(*))" 的过程:
//
// 字符    lo    hi    说明
// ─────────────────────────────────────
// 初始     0     0
//  '('     1     1    左括号 +1
//  '*'     0     2    lo: *当), hi: *当(
//  ')'     0     1    lo: max(-1,0)=0, hi=2-1=1
//  ')'     0     0    lo: max(-1,0)=0, hi=1-1=0
// ─────────────────────────────────────
// 最终 lo == 0 → true ✓
//
// 实际对应: ( 当(, * 当(, 第一个) 匹配*, 第二个) 匹配(
// 即 "(())" → 合法
```

### 解法3: 双栈法 — O(n) / O(n)

**另一个角度**：用两个栈分别记录 `(` 和 `*` 的索引。遇到 `)` 时优先用 `(` 匹配，没有 `(` 就用 `*`。最后检查剩余的 `(` 能否被其右边的 `*` 匹配。

```cpp
class Solution {
public:
    bool checkValidString(string s) {
        stack<int> leftStack;  // 存 '(' 的索引
        stack<int> starStack;  // 存 '*' 的索引
        
        for (int i = 0; i < s.size(); i++) {
            if (s[i] == '(') {
                leftStack.push(i);
            } else if (s[i] == '*') {
                starStack.push(i);
            } else { // ')'
                // 优先用 ( 匹配
                if (!leftStack.empty()) {
                    leftStack.pop();
                } else if (!starStack.empty()) {
                    // 没有 ( 了，用 * 当 (
                    starStack.pop();
                } else {
                    // 既没有 ( 也没有 *，无法匹配
                    return false;
                }
            }
        }
        
        // 检查剩余的 ( 能否被右边的 * 匹配
        // 关键：( 必须在 * 的左边，* 才能当 ) 来匹配它
        while (!leftStack.empty() && !starStack.empty()) {
            if (leftStack.top() > starStack.top()) {
                // ( 在 * 右边，* 无法当 ) 来匹配这个 (
                return false;
            }
            leftStack.pop();
            starStack.pop();
        }
        
        // 如果还有剩余的 (，说明无法匹配
        return leftStack.empty();
    }
};
```

**关键点**：为什么要比较索引？
```
// 反例: "*(" → * 在 ( 左边
// leftStack: [1]  (索引1处的 '(')
// starStack: [0]  (索引0处的 '*')
// leftStack.top()=1 > starStack.top()=0 → * 在 ( 左边
// * 不能当 ) 来匹配右边的 ( → return false ✓
```

## 解法对比

| | 解法1: DP | 解法2: 贪心 | 解法3: 双栈 |
|---|---|---|---|
| 时间 | O(n²) | O(n) | O(n) |
| 空间 | O(n) | O(1) | O(n) |
| 思维难度 | 中等，标准 DP | 较高，需要理解区间追踪 | 中等，栈的变体 |
| 面试推荐 | 如果想不到贪心可以先说 | ⭐ 首选 | 作为补充方案 |
| 适用场景 | 通用性好，容易扩展 | 最优，但需要证明连续性 | 直觉好理解 |

**选择建议**：面试先说贪心解法2，如果面试官追问"你怎么证明这个贪心是对的？"，可以从 DP 的角度解释"可达的 j 值构成连续区间"。

## 易错点

1. **贪心解法忘记 `lo = max(lo, 0)`**
   - ✗ `lo--; // 直接减，可能变负`
   - ✓ `lo--; lo = max(lo, 0); // 负数没有意义，修正为0`
   - 原因：未匹配左括号数不可能为负，负了说明那些 `*` 应该当空串

2. **贪心解法只检查 `hi >= 0` 忘记检查 `lo == 0`**
   - ✗ `return hi >= 0;`
   - ✓ `return lo == 0;`
   - 反例：`"("` → 遍历后 lo=1, hi=1，hi >= 0 但不合法

3. **双栈法忘记比较索引**
   - ✗ 只检查 `leftStack.size() <= starStack.size()`
   - ✓ 还要检查每个 `(` 的索引 < 对应 `*` 的索引
   - 反例：`"*("` → `*` 在 `(` 左边，不能当 `)` 来匹配

4. **DP 解法初始化错误**
   - ✗ `dp[0] = false` 或所有 dp 都初始化为 true
   - ✓ 只有 `dp[0] = true`，其余为 false
   - 原因：初始状态只有"0个未匹配左括号"是可达的

## 面试追问

**Q1（基础理解）**：如果没有 `*`，怎么判断括号是否有效？
> 用计数器 count，遇 `(` 加1，遇 `)` 减1。任何时刻 count < 0 则 false，最终 count == 0 则 true。

**Q2（核心优化）**：加了 `*` 后，暴力枚举 3^k 种组合太慢，怎么优化？
> 观察到我们只关心"未匹配左括号数量"，这个数量的可能值构成一个连续区间 [lo, hi]。每个字符只影响区间边界，所以 O(n) 时间 O(1) 空间就够了。

**Q3（证明追问）**：你怎么证明可达值一定是连续区间？
> 假设 j 和 j+2 都可达。那么在达到 j+2 的方案中，必然有某个 `*` 被当成了 `(` 或空串使得余量比 j 多了 2。把那个 `*` 的选择"降一级"（`(` → 空串，或空串 → `)`），就能得到余量为 j+1 的方案。所以 j+1 也可达。

**Q4（变体）**：如果 `*` 只能当 `(` 或 `)` 不能当空串呢？
> 贪心方法只需修改 `*` 的处理：lo 仍然 -1（当 `)`），hi 仍然 +1（当 `(`），但 lo 的修正条件需要更细致：当 lo 为负奇数时无法修正为 0（因为不能当空串跳过）。实际上此变体需要额外判断奇偶性。
