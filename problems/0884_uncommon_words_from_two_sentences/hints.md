# LeetCode 884: Uncommon Words from Two Sentences

## 核心思路

本题要求找出两个句子中"不常见"的单词——即在所有单词中恰好只出现一次的单词。核心洞察是：一个单词是"uncommon"的，当且仅当它在两个句子的所有单词中**总共只出现了一次**。因此，只需将两个句子的所有单词合并统计词频，然后筛选出词频为 1 的单词即可。不需要分别记录每个单词属于哪个句子。

## 思维链

1. **理解"uncommon"的定义**：一个单词出现在一个句子中恰好一次，且不出现在另一个句子中。
2. **等价转换**：如果一个单词在 s1 中出现两次，即使不在 s2 中出现，也不是 uncommon（因为在 s1 中不是恰好一次）。因此 uncommon 等价于"在两个句子合并后的词频表中，词频恰好为 1"。
3. **选择数据结构**：使用哈希表（unordered_map）统计每个单词的出现次数。
4. **实现步骤**：解析两个句子的单词，统计词频，筛选词频为 1 的单词。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 哈希表统计法 | O(n + m) | O(n + m) | 最优解，一次统计即可 |
| 两个集合对比法 | O(n + m) | O(n + m) | 分别统计再对比，逻辑更冗余 |

其中 n, m 分别为两个句子的总字符数。

## 关键提示

1. **合并统计是关键简化** -- 不需要知道单词属于哪个句子，只需全局词频为 1。
2. **字符串分割** -- 需要按空格拆分句子为单词。C++ 可用 istringstream 或手动遍历。
3. **"恰好一次"不是"至少一次"** -- 如果 apple 在 s1 中出现两次，它不是 uncommon，即使 s2 中没有。
4. **返回顺序任意** -- 题目允许任意顺序返回结果。
5. **无前导/尾随空格** -- 题目保证句子格式正确，单词间用单个空格分隔。

## 解法详解

### 解法一：合并词频统计

**原理**：将两个句子视为一个整体的单词集合，统计每个单词的出现次数，频次为 1 的就是答案。

**算法步骤**：

1. **解析 s1**：按空格拆分 s1 为单词列表，每个单词在哈希表中计数 +1。
2. **解析 s2**：按空格拆分 s2 为单词列表，每个单词在哈希表中计数 +1。
3. **筛选结果**：遍历哈希表，将计数为 1 的单词加入结果数组。

**正确性论证**：
- 词频 = 1 意味着该单词在 s1 和 s2 中总共只出现了一次。
- 如果它在 s1 中出现一次且不在 s2 中 -> uncommon（符合定义）。
- 如果它在 s2 中出现一次且不在 s1 中 -> uncommon（符合定义）。
- 如果它在两个句子中各出现一次 -> 词频 = 2，不会被选中（不是 uncommon）。

**复杂度分析**：
- 时间：O(n + m)，遍历两个句子 + 遍历哈希表
- 空间：O(n + m)，哈希表存储所有不同的单词

### 解法二：双集合法（不推荐，仅做对比）

**原理**：分别为 s1 和 s2 建立词频表，然后找出在一个句子中词频为 1 且不在另一个句子中出现的单词。

**步骤**：
1. 分别统计 s1 和 s2 的词频
2. 遍历 s1 词频表：词频=1 且 s2 词频表中不存在 -> 加入结果
3. 遍历 s2 词频表：词频=1 且 s1 词频表中不存在 -> 加入结果

这种方法逻辑等价但代码更冗余，合并统计法更简洁。

## 易错点

1. **没有合并统计** -- 分开处理两个句子增加了代码复杂度和出错可能性。
2. **字符串分割错误** -- C++ 没有内置 split 函数，需要正确使用 istringstream 或手动处理。
3. **将"出现在一个句子中"理解为"只属于一个句子"** -- 如果一个单词在同一个句子中出现两次，它不是 uncommon。
4. **忘记处理边界** -- s1 或 s2 可能只有一个单词。
5. **使用 set 而非 map** -- set 只记录是否出现，无法区分出现一次和多次。

## 面试追问

1. **如何处理大小写不敏感的情况？**
   - 在统计前将所有单词转为小写。

2. **如果句子可能有多个连续空格怎么办？**
   - istringstream 默认跳过连续空格，天然处理。手动分割需注意跳过空串。

3. **如果要求返回结果按字典序排列？**
   - 最后对结果数组排序，或使用 map（有序映射）代替 unordered_map。

4. **如果有三个句子呢？**
   - 同样的思路：合并三个句子的词频，筛选频次恰好为 1 的单词。

5. **时间复杂度能否优化？**
   - 已经是 O(n + m)，无法进一步优化。
