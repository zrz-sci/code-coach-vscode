# 227. 基本计算器 II

## 核心思路

这道题本质上是：**在只有四则运算（无括号）的表达式中，如何正确处理运算符优先级**——乘除先算，加减后算。

## 思维链

1. **读完题第一反应**：表达式求值，需要处理 `+`、`-`、`*`、`/` 四种运算符，难点在于乘除的优先级高于加减。如果全是加减就简单了——从左到右一路算下去。

2. **暴力做法**：先扫描一遍处理所有乘除，把结果替换回字符串，然后再扫描一遍处理所有加减。但字符串修改/替换操作非常麻烦且低效。

3. **瓶颈分析**：问题在于遇到 `+` 或 `-` 时，后面的数可能还要参与乘除运算，所以不能立即计算加减。但反过来想——**遇到乘除时，可以立即和前面的数算掉**！

4. **关键观察**：如果我们把每个数都带着它前面的运算符来看，`3+2*2` 可以理解为 `(+3) (+2*2)`。我们只需要"延迟"加减操作，"立即"执行乘除操作。用什么来延迟？——**栈**！

5. **具体做法**：维护一个栈和一个 `prevOp` 记录当前数前面的运算符。遇到 `+`/`-` 就把数（带符号）压入栈；遇到 `*`/`/` 就从栈顶弹出一个数，立即和当前数运算后压回栈。最后把栈里所有数加起来就是答案。

6. **进一步优化**：观察到栈里最终是一堆数求和。其实我们可以不用栈，只用一个变量 `lastNum` 记录栈顶元素（因为只有乘除才需要回看栈顶），从而把空间优化到 O(1)。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 栈模拟优先级 | 加减入栈，乘除立即算 | O(n) | O(n) | ⭐ 必须写出 |
| 无栈（O(1)空间） | 用 result + lastNum 代替栈 | O(n) | O(1) | 加分项 |

## 关键提示

1. **不要试图同时处理优先级和计算**——把"延迟加减"和"立即乘除"分开想，栈是实现"延迟"的天然工具。

2. **prevOp 初始化为 `+`**：第一个数前面没有运算符，默认为 `+` 就能统一处理（相当于 `0 + firstNum`）。

3. **触发计算的时机**：不是遇到运算符时才处理，而是**当一个完整的数字解析完毕时**（遇到下一个运算符或到达字符串末尾），根据 `prevOp` 决定怎么处理这个数。

4. **处理多位数和空格**：数字可能是多位的（`123`），需要逐字符累积；空格直接跳过，但注意**字符串末尾也要触发最后一个数的处理**。

5. **整数除法截断方向**：C++ 中整数除法天然向零截断，符合题意。但如果用 Python 需要用 `int()` 截断。

```
// "3+2*2" 的栈模拟过程：
//
// 字符  prevOp  num  栈状态         说明
//  3      +      3                   解析数字
//  +      +      3   [+3]           遇到+，prevOp是+，压入+3
//  2      +      2                   解析数字
//  *      +      2   [+3, +2]       遇到*，prevOp是+，压入+2
//  2      *      2                   解析数字
// END     *      2   [+3, +4]       到末尾，prevOp是*，弹出2，2*2=4压入
//
// 最终：sum(栈) = 3 + 4 = 7 ✓
```

## 解法详解

### 解法1: 栈模拟优先级 — O(n) / O(n) ⭐ 面试首选

**思考过程**：

加减和乘除的优先级不同。乘除可以立即算（因为优先级最高），加减要"等一等"（后面可能有乘除要先算）。用栈来暂存加减的操作数：
- 遇到 `+`/`-`：把当前数（带正负号）压入栈，等最后统一求和
- 遇到 `*`/`/`：弹出栈顶，和当前数运算后压回栈

这样栈里存的都是"处理完所有乘除后的中间结果"，最后全部加起来就行。

```cpp
class Solution {
public:
    int calculate(string s) {
        stack<int> stk;
        int num = 0;
        char prevOp = '+';  // 第一个数前面默认是+
        
        for (int i = 0; i < s.size(); i++) {
            char c = s[i];
            
            // 累积多位数字
            if (isdigit(c)) {
                num = num * 10 + (c - '0');
            }
            
            // 遇到运算符或到达末尾 → 根据 prevOp 处理前一个数
            // 注意：空格不触发处理（除非是末尾），但运算符和末尾都要触发
            if ((!isdigit(c) && c != ' ') || i == s.size() - 1) {
                if (prevOp == '+') stk.push(num);
                else if (prevOp == '-') stk.push(-num);
                else if (prevOp == '*') {
                    int top = stk.top(); stk.pop();
                    stk.push(top * num);
                }
                else if (prevOp == '/') {
                    int top = stk.top(); stk.pop();
                    stk.push(top / num);
                }
                prevOp = c;   // 更新运算符
                num = 0;      // 重置数字
            }
        }
        
        // 栈中所有数求和
        int result = 0;
        while (!stk.empty()) {
            result += stk.top();
            stk.pop();
        }
        return result;
    }
};
```

**关键点**：
- `prevOp` 是"当前数前面的运算符"，初始为 `+`
- 处理时机是"遇到下一个运算符或到末尾"，而不是"遇到当前运算符"
- `-` 号通过 `push(-num)` 转化为加法，统一最后求和

### 解法2: 无栈 O(1) 空间 — O(n) / O(1)

**从解法1优化**：

观察解法1中栈的使用模式：
- `+`/`-` 时只是压入，最终求和
- `*`/`/` 时只回看**栈顶一个元素**

也就是说，我们只需要记住"上一个压入栈的数"（`lastNum`），以及"已经确定的累加结果"（`result`）。当遇到乘除时，操作 `lastNum`；当遇到加减时，把 `lastNum` 并入 `result`，开始新的 `lastNum`。

```cpp
class Solution {
public:
    int calculate(string s) {
        int result = 0;    // 已确认的累加和（相当于栈底部分的总和）
        int lastNum = 0;   // 栈顶元素（可能被乘除修改）
        int num = 0;
        char prevOp = '+';
        
        for (int i = 0; i < s.size(); i++) {
            char c = s[i];
            
            if (isdigit(c)) {
                num = num * 10 + (c - '0');
            }
            
            if ((!isdigit(c) && c != ' ') || i == s.size() - 1) {
                if (prevOp == '+') {
                    result += lastNum;     // 把旧的 lastNum 并入 result
                    lastNum = num;         // 当前数成为新的 lastNum
                }
                else if (prevOp == '-') {
                    result += lastNum;
                    lastNum = -num;
                }
                else if (prevOp == '*') {
                    lastNum *= num;        // 乘除直接修改 lastNum
                }
                else if (prevOp == '/') {
                    lastNum /= num;
                }
                prevOp = c;
                num = 0;
            }
        }
        
        // 别忘了最后的 lastNum 还没并入 result
        return result + lastNum;
    }
};
```

**关键点**：
- `result` 保存"不会再被乘除影响的部分"
- `lastNum` 保存"可能还要参与乘除运算的最近一个数"
- 遇到 `+`/`-` 时，意味着 `lastNum` 不会再被乘除了，可以安全并入 `result`
- 遇到 `*`/`/` 时，修改 `lastNum` 本身

## 解法对比

| | 解法1: 栈 | 解法2: 无栈 |
|---|---|---|
| 空间 | O(n) — 栈最多存 n/2 个数 | O(1) — 只用两个变量 |
| 可读性 | 高，栈的逻辑直观 | 中等，需要理解 lastNum 的含义 |
| 可扩展性 | 容易扩展到有括号的情况（递归+栈） | 有括号时需要改造 |
| 面试推荐 | ⭐ 先写这个，安全稳妥 | 追问空间优化时再给 |

## 易错点

1. **忘记处理字符串末尾的数字**
   - ✗ 只在遇到运算符时处理 → 最后一个数被丢弃
   - ✓ 条件中加 `|| i == s.size() - 1`，末尾也触发处理

2. **多位数没有正确累积**
   - ✗ `num = c - '0'`（每次覆盖）
   - ✓ `num = num * 10 + (c - '0')`（逐位累积）

3. **空格导致误触发处理**
   - ✗ `if (!isdigit(c))` → 空格也触发，num=0 被错误处理
   - ✓ `if (!isdigit(c) && c != ' ')` → 空格跳过

4. **prevOp 初始化遗漏**
   - ✗ `prevOp` 不初始化或初始化为 `\0` → 第一个数不知道怎么处理
   - ✓ `prevOp = '+'` → 第一个数被当作 `+num` 压入

5. **无栈解法忘记最后加 lastNum**
   - ✗ `return result;` → lastNum 没并入
   - ✓ `return result + lastNum;`

## 面试追问

**Q1: 为什么用栈？不用栈行不行？**
→ 栈的作用是"延迟"加减运算。因为乘除优先级高，遇到加减时不能立即算，需要看后面有没有乘除。栈暂存这些待定的数。可以不用栈，用两个变量模拟（解法2）。

**Q2: 如果表达式中有括号呢？（→ LeetCode 224）**
→ 遇到 `(` 时，把当前的 `result` 和 `prevOp` 压入栈，开始新的计算；遇到 `)` 时，弹出栈恢复外层状态。或者用递归：遇到 `(` 递归调用，遇到 `)` 返回。

**Q3: 如果要支持一元负号，比如 `-3+2`？**
→ 在字符串开头或 `(` 后面遇到 `-`，把它当作 `0-3` 处理。实现上可以在 prevOp='+' 的前提下，让 num 不变直接触发减法逻辑。

**Q4: 时间能优化到 O(n) 以下吗？**
→ 不能。必须读完每个字符才能计算，O(n) 已经是下界。
