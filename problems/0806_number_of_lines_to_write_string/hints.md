# 806. 写字符串需要的行数

## 核心思路

本质是一个**简单模拟**问题：逐个字符写入，维护当前行的已用宽度。如果加上当前字符的宽度超过 100 像素，就换到下一行。最终返回行数和最后一行的宽度。

## 思维链

1. **读完题第一反应** → 模拟写入过程，逐字符处理。
2. **需要维护什么？** → 当前行数 `lines` 和当前行已用宽度 `width`。
3. **什么时候换行？** → 当 `width + widths[ch - 'a'] > 100` 时换行。
4. **换行操作** → `lines++`，`width` 重置为当前字符的宽度。
5. **结果** → `{lines, width}`。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 直接模拟 | 逐字符处理，维护行数和宽度 | O(n) | O(1) | ⭐ 直接写出 |

## 关键提示

1. **行数初始为 1**：第一个字符写在第一行，所以初始行数为 1（不是 0）。
2. **换行的条件**：加上当前字符后是否超过 100，而不是是否等于 100。恰好等于 100 不需要换行。
3. **每个字符的宽度**：`widths[s[i] - 'a']` — 用字符的 ASCII 值减去 `'a'` 作为索引。
4. **题目保证每个字符宽度 2-10**：不存在宽度为 0 的字符，不用担心单个字符超过行宽的情况（单字符最大宽度 10 < 100）。
5. **空字符串**：题目约束 `s.length >= 1`，不需要特判空串。

## 解法详解

### 解法1: 直接模拟 -- O(n) / O(1) ⭐

**思考过程**: 就像真的在写字一样——一行最多 100 像素宽，写不下就换行。

```
示例: widths 全部 = 10, s = "abcdefghijklmnopqrstuvwxyz"

行1: a(10) b(20) c(30) d(40) e(50) f(60) g(70) h(80) i(90) j(100) → 100
行2: k(10) l(20) m(30) n(40) o(50) p(60) q(70) r(80) s(90) t(100) → 100
行3: u(10) v(20) w(30) x(40) y(50) z(60) → 60

结果: [3, 60] ✓
```

```cpp
class Solution {
public:
    vector<int> numberOfLines(vector<int>& widths, string s) {
        int lines = 1, width = 0;
        
        for (char c : s) {
            int w = widths[c - 'a'];
            if (width + w > 100) {
                lines++;       // 换行
                width = w;     // 当前字符写到新行
            } else {
                width += w;    // 当前字符写到当前行
            }
        }
        
        return {lines, width};
    }
};
```

**关键点**:
- 初始 `lines = 1`：至少有一行。
- 初始 `width = 0`：第一行还没写任何字符。
- 换行时 `width = w` 而不是 `width = 0`：当前字符已经写到新行了。

## 易错点

1. **行数初始化为 0**：
   - ✗ `lines = 0` → 如果字符串非空，最后结果会少一行
   - ✓ `lines = 1` → 第一个字符写在第一行

2. **换行后 width 清零而非设为当前字符宽度**：
   - ✗ `lines++; width = 0; width += w;` → 虽然结果一样但多一步（不影响正确性但不够简洁）
   - ✓ `lines++; width = w;` → 直接设为当前字符宽度

3. **换行条件用 >= 而非 >**：
   - ✗ `if (width + w >= 100)` → 恰好 100 时也换行，但应该不换（100 是合法宽度）
   - ✓ `if (width + w > 100)` → 只有超过 100 才换行

4. **字符索引错误**：
   - ✗ `widths[c]` → c 是 ASCII 值（97-122），越界
   - ✓ `widths[c - 'a']` → 转换为 0-25 的索引

## 面试追问

**Q1: 如果行宽不是固定的 100，而是每行不同（如按行递减），怎么改？**
> 增加一个参数 `lineWidths[]`，换行时用 `lineWidths[lines]` 作为新行的宽度上限。逻辑基本不变，只是 100 替换为动态值。

**Q2: 如果需要支持单词级别的换行（不拆单词），怎么处理？**
> 先将字符串按空格分成单词。对每个单词计算总宽度，如果当前行放不下整个单词就换行。这就是经典的 Word Wrap / Text Justification 问题（LeetCode 68）。

**Q3: 如果要返回每一行的具体内容（而非只返回行数和末行宽度），怎么改？**
> 用 `vector<string>` 存储每行的内容。换行时 push_back 当前行，开始新的一行。最终返回这个 vector 和最后一行的宽度。
