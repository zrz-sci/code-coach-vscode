# 893. 特殊等价字符串组

## 核心思路

本质上是一个**分组归类问题**：两个字符串是"特殊等价"的，当且仅当它们偶数位上的字符集合相同（排序后相同）且奇数位上的字符集合相同。因此，我们可以为每个字符串构造一个**规范键（canonical key）**——偶数位排序 + 奇数位排序，用这个键来分组，最终统计不同键的数量。

## 思维链

1. **读完题第一反应**：可以任意交换偶数位之间的字符，也可以任意交换奇数位之间的字符。这意味着偶数位上的字符可以自由排列，奇数位上的字符也可以自由排列。但偶数位和奇数位之间的字符不能互换。

2. **什么时候两个字符串等价？** 两个字符串等价 ⇔ 偶数位上的字符"多重集"相同 AND 奇数位上的字符"多重集"相同。比如 "abcd" 偶数位是 {a,c}，奇数位是 {b,d}；"cbad" 偶数位是 {b,d}... 不对，等等——要注意下标从 0 开始，所以 "abcd" 中 index 0,2 是偶数位 = {a,c}，index 1,3 是奇数位 = {b,d}。

3. **如何表示"多重集相同"？** 最简单的方法是把对应位置的字符提取出来排序，排序后的字符串作为标识。或者用计数数组也行，但排序更简洁。

4. **分组的标准做法**：构造规范键 → 放入 set → set 的大小就是组数。具体的规范键 = `sorted(偶数位字符) + sorted(奇数位字符)`。

5. **优化思考**：字符串长度最大 20，words 最多 1000 个。排序每个字符串的偶数位和奇数位是 O(L log L)，总时间 O(N * L log L)，完全够用。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 排序构造键 + Set | 偶数位排序 + 奇数位排序作为键 | O(N * L log L) | O(N * L) | ⭐ 面试首选 |
| 计数数组构造键 | 用字符频率代替排序 | O(N * L) | O(N * L) | 等价写法 |

> N = words.length, L = words[i].length

## 关键提示

1. **下标从 0 开始**：题目说"偶数下标"和"奇数下标"，注意是 0-indexed。所以 index 0, 2, 4, ... 是偶数位，index 1, 3, 5, ... 是奇数位。

2. **规范键的构造**：对每个字符串，提取偶数位字符并排序得到字符串 A，提取奇数位字符并排序得到字符串 B，规范键 = A + B（或用分隔符 A + "#" + B 更安全，但由于偶数位和奇数位字符数是固定的，直接拼接不会产生歧义）。

3. **为什么排序就够了？** 因为可以任意交换同类位置的字符，所以偶数位的字符可以排成任意顺序，奇数位也一样。两个字符串等价 ⇔ 偶数位的字符多重集相同 + 奇数位的字符多重集相同 ⇔ 偶数位排序后相同 + 奇数位排序后相同。

4. **用 set 还是 unordered_set？** 由于键是字符串，`set<string>` 更简单直接。用 `unordered_set<string>` 理论上更快（均摊 O(1) 插入），但在这个数据量下差异不大。

5. **计数数组方法**：也可以用 26 个字母的频率数组代替排序。偶数位的 26 个计数 + 奇数位的 26 个计数组成一个 52 维向量作为键。需要将向量转成字符串或用 map<vector<int>, int>。复杂度稍优但代码更长。

## 解法详解

### 解法1: 排序构造键 + Set — O(N * L log L) / O(N * L) ⭐ 面试首选

**思考过程**：对每个单词，分别提取偶数位和奇数位的字符，各自排序后拼接成规范键。把所有键放入 set，set 的大小即为答案。

```cpp
class Solution {
public:
    int numSpecialEquivGroups(vector<string>& words) {
        set<string> groups;
        
        for (const string& w : words) {
            string even_chars, odd_chars;
            for (int i = 0; i < (int)w.size(); i++) {
                if (i % 2 == 0) even_chars += w[i];
                else odd_chars += w[i];
            }
            sort(even_chars.begin(), even_chars.end());
            sort(odd_chars.begin(), odd_chars.end());
            groups.insert(even_chars + odd_chars);
        }
        
        return groups.size();
    }
};
```

**关键点**：规范键 = sorted(偶数位) + sorted(奇数位)，不需要分隔符，因为所有字符串等长，偶数位和奇数位的字符数是固定的。

### 解法2: 计数数组构造键 — O(N * L) / O(N * L)

**从排序优化到计数**：用两个长度 26 的计数数组分别统计偶数位和奇数位的字符频率，然后将 52 个计数值编码为字符串作为键。

```cpp
class Solution {
public:
    int numSpecialEquivGroups(vector<string>& words) {
        set<string> groups;
        
        for (const string& w : words) {
            // 52 个计数: 前 26 个是偶数位字符频率，后 26 个是奇数位
            vector<int> count(52, 0);
            for (int i = 0; i < (int)w.size(); i++) {
                // 偶数位 -> count[0..25], 奇数位 -> count[26..51]
                count[(i % 2) * 26 + (w[i] - 'a')]++;
            }
            // 将计数数组编码为字符串作为键
            string key;
            for (int c : count) {
                key += to_string(c) + ",";
            }
            groups.insert(key);
        }
        
        return groups.size();
    }
};
```

**关键点**：利用 `(i % 2) * 26` 来区分偶数位和奇数位的计数区间。编码时需要分隔符（逗号），否则 "1,12" 和 "11,2" 无法区分。

## 解法对比

| | 排序构造键 | 计数数组构造键 |
|--|---------|------------|
| 时间 | O(N * L log L) | O(N * L) |
| 空间 | O(N * L) | O(N * L) |
| 代码简洁 | ⭐ 更简洁 | 稍长 |
| 思路直觉 | 高 | 中 |
| 面试建议 | 首选 | 追问优化时 |

**选择建议**：
- 面试首选排序方法：代码简短，思路清晰，不容易出错
- 追问时间优化时给出计数数组方法：去掉了排序的 O(L log L) 因子
- 数据量小（L <= 20），两种方法实际差异极小

## 易错点

1. **混淆偶数位和奇数位**
   - x 认为第 1 个字符（index 0）是奇数位 -> 偶数位和奇数位反了
   - o 题目的"偶数下标"是 0-indexed，所以 index 0,2,4... 是偶数位

2. **规范键拼接产生歧义**
   - x 直接拼接偶数位和奇数位字符串，但字符串长度不同时可能冲突（本题所有字符串等长所以不会）
   - o 使用分隔符或固定长度保证无歧义

3. **忘记排序**
   - x 直接用偶数位字符串（不排序）作为键 -> "ac" 和 "ca" 被认为不等价
   - o 必须排序或用频率统计，才能体现"可以任意交换"

4. **计数数组编码缺少分隔符**
   - x 将计数直接转成字符串 "1120..." -> 无法区分 "1,1,20" 和 "11,2,0"
   - o 用逗号或其他分隔符分隔每个计数值

5. **用 unordered_set 时自定义 hash 不当**
   - x 用 vector<int> 作为 unordered_set 的键但没提供 hash 函数 -> 编译错误
   - o 用 set<vector<int>> 或将 vector 编码成 string 再用 unordered_set<string>

## 面试追问

**Q1: 为什么偶数位之间可以任意排列？**
-> 因为可以无限次交换任意两个偶数位的字符。通过若干次两两交换，可以达成任意排列（冒泡排序的思想）。奇数位同理。

**Q2: 如果题目改成"可以交换任意两个位置的字符"，问题变成什么？**
-> 那就是标准的"字母异位词分组"（LeetCode 49），规范键变成整个字符串排序后的结果。

**Q3: 如果字符串很长（L = 10^6），哪种方法更好？**
-> 计数数组方法更好，O(N * L) vs O(N * L log L)。对于 L = 10^6，log L ≈ 20，差距明显。

**Q4: 能不能用 Union-Find？**
-> 可以但不实用。需要 O(N^2) 时间两两比较字符串是否等价再合并，不如直接分组。
