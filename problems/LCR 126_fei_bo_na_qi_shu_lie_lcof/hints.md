# LCR 126. 斐波那契数 - 提示与详解

## 题目理解

**斐波那契数列**：F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2) (n>1)。给定 n，求 F(n) mod 1000000007。

**关键约束**：
- 0 <= n <= 100
- 答案需要取模 1e9+7（防止大数溢出）
- n 最大为 100，F(100) 是一个 21 位数，远超 int 范围

---

## 核心思路

这道题虽然是 Easy 难度，但它是**动态规划的入门基石**。斐波那契数列本身就是最经典的递推关系，从它出发可以引申出所有 DP 问题的核心思想：**用已知子问题的解构建更大问题的解**。

本题有三个层次的解法：
1. **递归 + 记忆化**：最直观，自顶向下
2. **动态规划（迭代）**：自底向上，避免递归开销
3. **空间优化**：只保留两个变量，O(1) 空间

更进阶的还有**矩阵快速幂** O(log n) 解法，在 n 极大时有意义。

---

## 思维链：从暴力到最优

### Step 1: 朴素递归 -- 理解问题结构

最直接的想法就是按定义递归：

```
fib(n) = fib(n-1) + fib(n-2)
```

但这会导致**指数级时间复杂度** O(2^n)，因为存在大量重复计算。比如计算 fib(5) 时，fib(3) 被计算了 2 次，fib(2) 被计算了 3 次。

**关键观察**：递归树中有大量重叠子问题（Overlapping Subproblems）。

### Step 2: 加入记忆化 -- 消除重复

用一个数组 memo[] 记录已经算过的值。每次递归前先查 memo，如果已有结果直接返回。

这把时间从 O(2^n) 降到 O(n)，空间 O(n)（递归栈 + memo 数组）。

**思考**：记忆化递归是"自顶向下"的思路 -- 从大问题出发，遇到子问题再去解决。

### Step 3: 转为迭代 DP -- 自底向上

既然知道了依赖关系（每个状态只依赖前两个状态），何不从小到大直接算？

```
dp[0] = 0, dp[1] = 1
for i in [2, n]: dp[i] = dp[i-1] + dp[i-2]
```

去掉了递归栈开销，时间 O(n)，空间 O(n)。

### Step 4: 空间优化 -- 滚动变量

观察 dp[i] 只依赖 dp[i-1] 和 dp[i-2]，不需要保留整个数组。用两个变量 a, b 交替滚动即可。

```
a = 0, b = 1
for i in [2, n]: (a, b) = (b, a + b)
return b
```

时间 O(n)，空间 O(1)。这是面试中最推荐的写法。

### Step 5: 取模的注意事项

n 最大 100，F(100) = 354224848179261915075，已远超 long long 范围。必须在**每一步加法时取模**，而不是最后一次性取模。

```
b = (a + b) % MOD
```

取模的数学性质保证：(a + b) % MOD == ((a % MOD) + (b % MOD)) % MOD。

### Step 6: 矩阵快速幂（进阶）

斐波那契数列可以表示为矩阵乘法：

```
| F(n+1) |   | 1  1 |^n   | F(1) |
| F(n)   | = | 1  0 |   * | F(0) |
```

通过**快速幂**，可以在 O(log n) 时间内计算矩阵的 n 次方，从而得到 F(n)。当 n 极大（如 10^18）时，这是唯一可行的方法。

## 关键提示

### 提示 1: 取模时机
不要等到最后才取模！每一步加法都需要取模，否则 n=100 时数值溢出。

### 提示 2: 边界条件
n=0 返回 0，n=1 返回 1。这两个 base case 必须显式处理。

### 提示 3: 滚动变量的更新顺序
使用两个变量滚动时，注意更新顺序：先算 sum = a + b，再 a = b，b = sum。如果顺序错了，a 被覆盖后 b 就算错了。

### 提示 4: 数据类型
C++ 中，int 最大约 2*10^9，两个取模后的数相加最大约 2*10^9，不会溢出 int。但为了安全，可以用 long long。

## 解法详解

### 解法 1: 记忆化递归（自顶向下）

**完整代码**：
```cpp
class Solution {
public:
    static const int MOD = 1000000007;
    int memo[101];
    
    int fib(int n) {
        memset(memo, -1, sizeof(memo));
        return helper(n);
    }
    
    int helper(int n) {
        if (n <= 1) return n;
        if (memo[n] != -1) return memo[n];
        memo[n] = ((long long)helper(n - 1) + helper(n - 2)) % MOD;
        return memo[n];
    }
};
```

**思考过程**：
1. 自然递归 F(n) = F(n-1) + F(n-2) 会有指数级重复计算
2. 加一个 memo 数组，初始化为 -1 表示未计算
3. 递归前先查 memo，计算后存入 memo
4. 加法时取模，防止溢出

**关键点**：
- memset(memo, -1, ...) 利用了 -1 的二进制表示（全1），对 int 数组有效
- 递归深度最大 100，不会栈溢出
- 用 long long 做加法中间结果，避免 int 溢出

### 解法 2: 迭代 DP + 空间优化（推荐）⭐

**完整代码**：
```cpp
class Solution {
public:
    int fib(int n) {
        if (n <= 1) return n;
        const int MOD = 1000000007;
        int a = 0, b = 1;
        for (int i = 2; i <= n; i++) {
            int sum = (a + b) % MOD;
            a = b;
            b = sum;
        }
        return b;
    }
};
```

**思考过程**：
1. F(i) 只依赖 F(i-1) 和 F(i-2)，不需要存整个数组
2. 用 a 表示 F(i-2)，b 表示 F(i-1)
3. 每轮循环：sum = a + b，然后 a 前移到 b，b 前移到 sum
4. 循环结束后 b 就是 F(n)

**DP 表模拟**（以 n=6 为例）：

```
i:    0  1  2  3  4  5  6
F(i): 0  1  1  2  3  5  8

滚动过程：
初始:      a=0, b=1
i=2: sum=1, a=1, b=1  -> F(2)=1
i=3: sum=2, a=1, b=2  -> F(3)=2
i=4: sum=3, a=2, b=3  -> F(4)=3
i=5: sum=5, a=3, b=5  -> F(5)=5
i=6: sum=8, a=5, b=8  -> F(6)=8
```

**关键点**：
- 必须先处理 n<=1 的边界
- 取模在加法时进行，(a + b) % MOD 不会溢出 int（两个 < 10^9 的数之和 < 2*10^9 < INT_MAX）
- 滚动变量法是 DP 空间优化的核心模式，在很多题中复用

### 解法 3: 矩阵快速幂（O(log n)）

**完整代码**：
```cpp
class Solution {
public:
    static const int MOD = 1000000007;
    
    // 2x2 矩阵乘法
    vector<vector<long long>> multiply(vector<vector<long long>>& A,
                                       vector<vector<long long>>& B) {
        int n = A.size();
        vector<vector<long long>> C(n, vector<long long>(n, 0));
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                for (int k = 0; k < n; k++)
                    C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD;
        return C;
    }
    
    // 矩阵快速幂
    vector<vector<long long>> matPow(vector<vector<long long>>& M, int p) {
        int n = M.size();
        vector<vector<long long>> result(n, vector<long long>(n, 0));
        for (int i = 0; i < n; i++) result[i][i] = 1; // 单位矩阵
        while (p > 0) {
            if (p & 1) result = multiply(result, M);
            M = multiply(M, M);
            p >>= 1;
        }
        return result;
    }
    
    int fib(int n) {
        if (n <= 1) return n;
        vector<vector<long long>> M = {{1, 1}, {1, 0}};
        auto result = matPow(M, n - 1);
        return result[0][0];
    }
};
```

**思考过程**：
1. 利用矩阵表示递推关系：[F(n+1), F(n)] = [1,1;1,0]^n * [F(1), F(0)]
2. 矩阵快速幂：类似数字快速幂，将 M^n 分解为 M^(n/2) * M^(n/2)
3. 时间复杂度从 O(n) 降到 O(log n)，当 n 达到 10^18 量级时优势明显

**关键点**：
- 矩阵乘法中要用 long long 防止溢出
- 快速幂的核心：如果 p 是奇数，先乘一次 M；然后 M 自乘，p 减半
- 单位矩阵是矩阵快速幂的"初始值"，类似数字快速幂中的 1

## 易错点

### Bug 1: 忘记取模
```cpp
// 错误：n=100 时 int/long long 溢出
b = a + b;

// 正确：每步取模
b = (a + b) % MOD;
```

### Bug 2: 滚动变量更新顺序错误
```cpp
// 错误：a 被覆盖后，b 的计算就错了
a = b;
b = a + b;  // 此时 a 已经是新值了！

// 正确：用临时变量
int sum = (a + b) % MOD;
a = b;
b = sum;
```

### Bug 3: 边界遗漏
```cpp
// 错误：没有处理 n=0 的情况
// 循环从 i=2 开始，如果 n=0 则 b=1 是错的

// 正确：显式处理
if (n <= 1) return n;
```

### Bug 4: 矩阵快速幂中的取模遗漏
```cpp
// 错误：乘法中间结果溢出
C[i][j] += A[i][k] * B[k][j];

// 正确：每次加法都取模
C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD;
```

## 面试追问

### Q1: 如果不需要取模，n 最大是多少时 long long 不会溢出？
**A1**: F(92) = 7540113804746346429，接近 long long 上限（9.2 * 10^18）。F(93) 会溢出。所以不取模时 n 最大为 92。

### Q2: 如果 n 可以达到 10^18，怎么优化？
**A2**: 矩阵快速幂，O(log n) 时间。核心是把递推关系表示为 2x2 矩阵乘法，然后用快速幂加速矩阵的 n 次方运算。

### Q3: 斐波那契数列和爬楼梯问题有什么关系？如何推广到"一次走1~k步"的情况？
**A3**: 爬楼梯（LeetCode 70）本质就是斐波那契：f(n) = f(n-1) + f(n-2)。推广到 k 步时，f(n) = f(n-1) + f(n-2) + ... + f(n-k)，可以用 k*k 矩阵快速幂优化到 O(k^3 * log n)。这个递推关系也可以用滑动窗口 + 前缀和优化到 O(n) 时间。
