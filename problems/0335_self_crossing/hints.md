# 335. Self Crossing - 路径交叉

## 核心思路

在 X-Y 平面上按逆时针方向（北→西→南→东→...）移动，判断路径是否自交。关键在于识别三种交叉模式：当前线段只可能与前 3~5 步内的线段相交。通过检查固定的几种几何条件即可判定。

## 思维链

1. **观察规律**：路径按固定方向循环（北西南东），每条线段只可能与同方向的之前线段相交
2. **收缩/扩展模式**：路径要么持续向外扩展（不交叉），要么开始收缩（可能交叉）
3. **交叉窗口**：第 i 条线段只可能与第 i-3、i-4、i-5 条线段相交
4. **三种交叉情况**：
   - Case 1: d[i] >= d[i-2] 且 d[i-1] <= d[i-3]（第 i 条碰到第 i-3 条）
   - Case 2: d[i-1] == d[i-3] 且 d[i] + d[i-4] >= d[i-2]（第 i 条碰到第 i-4 条）
   - Case 3: d[i-1] <= d[i-3] 且 d[i-3] <= d[i-1]+d[i-5] 且 d[i-2] > d[i-4] 且 d[i] + d[i-4] >= d[i-2]（第 i 条碰到第 i-5 条）

## 解法概览

| 解法 | 时间 | 空间 | 特点 | 推荐 |
|------|------|------|------|------|
| 三种交叉模式判定 | O(n) | O(1) | 枚举三种几何条件 | ⭐⭐⭐ |

## 关键提示

1. 从 i=3 开始检查（至少需要 4 条线段才能交叉）
2. 三种 case 覆盖了所有可能的交叉情况，无需更复杂的几何计算
3. Case 2 和 Case 3 需要额外检查 i-4 和 i-5 是否存在（下标越界保护）
4. 画图理解每种 case 是解题的关键

## 解法详解

### 解法一：三种交叉模式（推荐）

```
Case 1: 第 i 条穿过第 i-3 条
         ┌───d[i-2]───┐
         │             │
   d[i-1]│             │d[i-3]
         │             │
         └─────────────┘──→ d[i] >= d[i-2]
                        且 d[i-1] <= d[i-3]

Case 2: 第 i 条刚好碰到第 i-4 条
         ┌───d[i-2]───┐
   d[i-4]│             │
    ──────┤             │d[i-3] = d[i-1]
         │             │
         └─────────────┘
         d[i] + d[i-4] >= d[i-2]

Case 3: 第 i 条穿过第 i-5 条（最复杂）
```

```cpp
class Solution {
public:
    bool isSelfCrossing(vector<int>& d) {
        int n = d.size();
        for (int i = 3; i < n; i++) {
            // Case 1: 第 i 条碰到第 i-3 条
            if (d[i] >= d[i-2] && d[i-1] <= d[i-3])
                return true;

            // Case 2: 第 i 条碰到第 i-4 条
            if (i >= 4 && d[i-1] == d[i-3] &&
                d[i] + d[i-4] >= d[i-2])
                return true;

            // Case 3: 第 i 条碰到第 i-5 条
            if (i >= 5 && d[i-2] > d[i-4] &&
                d[i-1] <= d[i-3] && d[i-1] + d[i-5] >= d[i-3] &&
                d[i] + d[i-4] >= d[i-2])
                return true;
        }
        return false;
    }
};
```

**复杂度**：时间 O(n)，空间 O(1)

## 易错点

- ✗ Case 2 忘记判等条件 `d[i-1] == d[i-3]` → ✓ 这是"刚好重叠"的边界情况
- ✗ Case 3 条件不完整 → ✓ 需要同时满足 4 个子条件
- ✗ 下标越界未保护 → ✓ Case 2 需要 i>=4，Case 3 需要 i>=5
- ✗ 混淆 >= 和 > → ✓ Case 1 中 d[i] >= d[i-2] 包含等于（刚好碰到也算交叉）

## 面试追问

**Q1: 为什么只需要检查 i-3 到 i-5，不需要更远？**
→ 因为路径按固定方向循环（每4步一圈），第 i 条线段的方向与第 i-4 条相同。几何上，如果到第 i-5 条都不交叉，更远的线段不可能被触及。

**Q2: 这题能不能用线段相交的通用判定？**
→ 可以，但需要 O(n^2) 遍历所有线段对。利用方向循环特性可以降到 O(n)。

**Q3: 如果方向不是固定的逆时针，而是任意方向呢？**
→ 退化为一般的线段交叉判定问题，需要扫描线算法 O(n log n) 或暴力 O(n^2)。
