# 691. Stickers to Spell Word

## 核心思路

这是一道经典的**状态压缩 DP** 问题。target 长度最多 15，可以用一个 bitmask 表示 target 中每个字符是否已被拼出。对于每个状态，尝试使用每张贴纸，贪心地消耗贴纸中能匹配 target 剩余字符的字母，转移到新状态。用 BFS 或记忆化搜索求最少贴纸数。

## 思维链

1. target 长度 <= 15 -> 状态总数 2^15 = 32768，适合状态压缩
2. 用 bitmask 表示 target 中哪些位置的字符已经被覆盖
3. 初始状态 mask = 0（无字符被覆盖），目标状态 mask = (1 << n) - 1（全部覆盖）
4. 对于每个状态，枚举每张贴纸，计算使用该贴纸后能转移到哪个新状态
5. 优化：对于当前状态，找到第一个未被覆盖的字符位置，只尝试包含该字符的贴纸
6. 这个优化保证了至少覆盖一个新位置，避免无效转移
7. 如果所有贴纸的字母并集无法覆盖 target 中的某个字符，返回 -1

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 状压 DP + BFS | O(2^n * m * L) | O(2^n) | 广度优先，天然求最短路径 |
| 状压 DP + 记忆化搜索 | O(2^n * m * L) | O(2^n) | 自顶向下，代码直观 |
| 状压 DP + 底部向上 | O(2^n * m * L) | O(2^n) | 经典 DP 转移 |

其中 n = target.length, m = stickers.length, L = 贴纸平均长度。

## 关键提示

1. **状态压缩是核心**：target 最多 15 个字符，2^15 = 32768 个状态完全可控。每一位代表 target 中对应位置的字符是否已拼出。
2. **贪心优化：锁定第一个未覆盖位**：对于当前状态，找到最低位的 0（第一个未拼出的字符），只尝试包含该字符的贴纸。这样每次转移至少推进一位，大幅剪枝。
3. **预处理贴纸频次**：将每张贴纸转为 26 长度的频次数组，方便快速计算匹配。
4. **不可能情况判断**：先检查 target 中每个字符是否至少被某张贴纸包含，否则直接返回 -1。

## 解法详解

### 解法一：状压 DP + BFS（推荐）

**思路**：
将问题建模为最短路径：从状态 0 出发，每次"使用一张贴纸"相当于走一步，到达新状态。BFS 天然保证找到最少步数。

**步骤**：
1. 预处理每张贴纸的字符频次数组
2. 初始化 BFS 队列，放入状态 0，距离为 0
3. 对于当前状态 mask：
   a. 找到第一个未覆盖位 i（mask 中第一个 0 位）
   b. 枚举每张贴纸，如果贴纸包含 target[i]：
      - 模拟使用该贴纸：从贴纸的字符频次中尽可能多地覆盖 target 的未覆盖位
      - 得到新状态 newMask
      - 如果 newMask 未访问过，入队
4. 当达到全 1 状态时返回当前步数

**复杂度**：
- 时间：O(2^n * m * max(n, L))，n=target长度，m=贴纸数，L=贴纸长度
- 空间：O(2^n)

### 解法二：记忆化搜索

**思路**：
定义 dp(mask) 为从状态 mask 到达全覆盖状态所需的最少贴纸数。对每个 mask，尝试所有包含第一个未覆盖字符的贴纸，取最小值。

**递推关系**：
```
dp(all_ones) = 0
dp(mask) = 1 + min(dp(newMask)) for each valid sticker
```

**步骤**：
1. 从 mask=0 开始递归
2. 找到第一个未覆盖位
3. 枚举包含该字符的贴纸，模拟使用后得到 newMask
4. dp(mask) = 1 + min(dp(newMask))
5. 用 memo 数组缓存结果

### 解法三：底部向上 DP

**思路**：
dp[mask] 表示达到状态 mask 所需的最少贴纸数。从 dp[0] = 0 开始，遍历所有状态并尝试扩展。

**步骤**：
1. dp 数组大小 2^n，初始化为 INT_MAX，dp[0] = 0
2. 对每个已到达的状态 mask（dp[mask] != INT_MAX）：
   a. 找到第一个未覆盖位 i
   b. 枚举每张贴纸，模拟使用后得到 newMask
   c. dp[newMask] = min(dp[newMask], dp[mask] + 1)
3. 返回 dp[(1<<n)-1]

## 易错点

1. **不做"第一个未覆盖位"优化**：如果对每个状态枚举所有贴纸而不锁定第一个未覆盖位，同一个目标状态会被多条路径重复到达，效率极差且可能 TLE。
2. **贴纸中同一字符的重复使用**：一张贴纸中如果有 2 个 'a'，可以同时覆盖 target 中 2 个未被覆盖的 'a'。模拟时必须用频次数组而非集合。
3. **忘记判断不可能情况**：如果 target 中某个字符在所有贴纸中都不存在，应返回 -1。不判断会导致无限循环或错误结果。
4. **状态转移时遗漏字符**：模拟贴纸使用时，必须对 target 的每个未覆盖位逐一匹配，而不是只匹配第一个字符。
5. **BFS 中重复入队**：必须用 visited 数组标记已访问状态，否则同一状态被多次处理。

## 面试追问

1. **为什么锁定"第一个未覆盖位"不会漏解？**
   - 因为无论用什么顺序覆盖字符，最终结果相同。锁定第一个未覆盖位只是固定了搜索顺序，不会遗漏最优解。本质是消除了排列重复。

2. **如果 target 长度超过 15 怎么办？**
   - 状态压缩不再适用。可以用字符频次作为状态进行记忆化搜索，但状态空间可能爆炸。实际中可以尝试贪心+ILP 近似。

3. **能否用贪心解这题？**
   - 不能。贪心无法保证全局最优，因为某张贴纸虽然当前匹配最多字符，但可能导致后续需要更多贴纸。

4. **如何优化预处理？**
   - 如果贴纸 A 的每个字符频次都 >= 贴纸 B 的对应频次，则 B 是被 A "支配"的，可以移除 B。

5. **BFS vs 记忆化搜索的优劣？**
   - BFS 天然求最短路径，找到答案即可终止；记忆化搜索需要探索所有可达状态。实践中 BFS 通常更快。
