# 122. 买卖股票的最佳时机 II

## 核心思路

本题本质上是：在允许无限次交易的前提下，找到所有"上涨段"并把利润全部吃掉。关键洞察是**任何一段连续上涨都可以拆解为相邻两天的差值之和**。

## 思维链

1. **读完题第一反应**：可以买卖无限次，但任何时候最多持有一股。暴力做法是什么？→ 枚举所有可能的买卖组合，递归尝试每天"买/卖/不动"三种选择。

2. **暴力解的瓶颈**：每天有3种选择，n天就是 O(3^n)，指数级爆炸。但发现很多子问题重复计算——比如"第5天持有股票时的最大利润"会被多个路径重复计算。

3. **加记忆化 → DP**：定义状态 `dp[i][0]` = 第i天结束时不持有股票的最大利润，`dp[i][1]` = 第i天结束时持有股票的最大利润。每天只需根据前一天的状态转移，O(n) 就能解决。

4. **发现贪心更简洁**：画出价格曲线，会发现最优策略就是**捕获每一段上涨**。而连续上涨 `prices[i] → prices[j]` 的利润 = `(prices[i+1]-prices[i]) + (prices[i+2]-prices[i+1]) + ... + (prices[j]-prices[j-1])`，也就是所有正的相邻差值之和！

5. **贪心的正确性**：只要 `prices[i] > prices[i-1]`，这段差值就对总利润有正贡献，我们就该"吃掉"它。不用真的决定哪天买哪天卖，只需累加所有正差值。

6. **与 Stock I 的对比**：Stock I 限制只能交易1次，所以需要追踪全局最低买入价。本题无限次交易，所以可以贪心地"每段涨都赚"。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力递归 | 枚举每天的所有选择 | O(3^n) | O(n) | 能说出即可 |
| 动态规划 | 两个状态(持有/不持有)逐日转移 | O(n) | O(n) | ⭐ 必须写出 |
| DP空间优化 | 滚动变量替代数组 | O(n) | O(1) | 加分项 |
| 贪心 | 累加所有正的相邻差值 | O(n) | O(1) | ⭐ 必须写出 |

## 关键提示

1. **画价格折线图**：把示例1 `[7,1,5,3,6,4]` 画出来，你会发现最优策略就是"每段上坡都赚"。

2. **连续上涨可拆分**：`prices = [1,2,3,4,5]` 时，一次性从1买5卖赚4，等价于 `(2-1)+(3-2)+(4-3)+(5-4) = 4`。这是贪心的数学基础。

3. **DP 状态设计**：每天结束时你要么持有股票、要么不持有。用这两个状态就足以描述所有情况。

4. **DP 的 dp[i][1] 转移注意**：和 Stock I 的区别在于，这里买入时是从 `dp[i-1][0] - prices[i]`（而不是 `0 - prices[i]`），因为之前可能已经有利润了。

5. **贪心不代表"真的"频繁买卖**：贪心只是数学等价——累加正差值等于捕获所有上涨段的利润。

## 解法详解

### 解法1: 动态规划 — O(n) / O(n)

**思考过程**: 每天结束后只有两种状态：持有股票 or 不持有股票。定义 `dp[i][0]` 为第i天结束不持有的最大利润，`dp[i][1]` 为持有的最大利润。

```
// DP 状态转移示意 (prices = [7,1,5,3,6,4]):
//
// day:      0     1     2     3     4     5
// price:    7     1     5     3     6     4
//
// dp[i][0]: 0     0     4     4     7     7   ← 不持有
// dp[i][1]: -7    -1    -1    1     1     3   ← 持有
//
// dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])
//            保持不持有      今天卖出
//
// dp[i][1] = max(dp[i-1][1], dp[i-1][0] - prices[i])
//            保持持有        今天买入(用之前利润买!)
//                            ↑ 这里是和Stock I的关键区别
//                              Stock I 是 0 - prices[i]
//                              Stock II 是 dp[i-1][0] - prices[i]
```

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        if (n <= 1) return 0;
        
        // dp[i][0] = 第i天结束不持有股票的最大利润
        // dp[i][1] = 第i天结束持有股票的最大利润
        vector<vector<int>> dp(n, vector<int>(2));
        dp[0][0] = 0;            // 第0天不买，利润0
        dp[0][1] = -prices[0];   // 第0天买入，利润为负
        
        for (int i = 1; i < n; i++) {
            // 不持有：要么昨天就不持有，要么今天卖出
            dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i]);
            // 持有：要么昨天就持有，要么今天买入
            // 关键：买入时基于 dp[i-1][0]，因为之前的交易利润可以累积
            dp[i][1] = max(dp[i-1][1], dp[i-1][0] - prices[i]);
        }
        
        // 最后一天不持有肯定 >= 持有
        return dp[n-1][0];
    }
};
```

**关键点**: `dp[i][1]` 的转移中 `dp[i-1][0] - prices[i]` 是和 Stock I 唯一的代码区别。Stock I 中因为只能交易一次，所以买入时从 `0 - prices[i]` 开始。

### 解法2: DP 空间优化 — O(n) / O(1)

**从解法1优化**: `dp[i]` 只依赖 `dp[i-1]`，不需要整个数组，用两个变量滚动即可。

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        if (n <= 1) return 0;
        
        int cash = 0;              // 不持有股票时的最大利润
        int hold = -prices[0];     // 持有股票时的最大利润
        
        for (int i = 1; i < n; i++) {
            int newCash = max(cash, hold + prices[i]);
            int newHold = max(hold, cash - prices[i]);
            cash = newCash;
            hold = newHold;
        }
        
        return cash;
    }
};
```

**关键点**: 必须用临时变量 `newCash`、`newHold`，不能直接更新 `cash` 后再用更新后的 `cash` 去算 `hold`——那样 `hold` 用的就不是"昨天"的 `cash` 了。

### 解法3: 贪心 — O(n) / O(1) ⭐ 面试首选

**核心观察**: 任何一段上涨的利润，等于这段内每两天正差值之和。所以只需遍历一遍，把所有正差值加起来。

```
// 价格折线图 (prices = [7,1,5,3,6,4]):
//
// 7 *
// 6          *  *
// 5       *
// 4               *
// 3            *
// 2
// 1    *
//   day: 0  1  2  3  4  5
//
// 差值: -6  +4  -2  +3  -2
//        ×   ✓   ×   ✓   ×    ← 只累加正差值
//
// 总利润 = 4 + 3 = 7 ✓
//
// 数学证明：一次从谷到峰的利润
//   prices[j] - prices[i]
// = (prices[i+1]-prices[i]) + (prices[i+2]-prices[i+1]) + ... + (prices[j]-prices[j-1])
// = 这段内所有相邻差值之和
// 而负差值(下跌段)不选，正好跳过了下跌，等价于在谷买峰卖！
```

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int profit = 0;
        for (int i = 1; i < prices.size(); i++) {
            // 只要今天比昨天贵，就"收割"这段涨幅
            if (prices[i] > prices[i-1]) {
                profit += prices[i] - prices[i-1];
            }
        }
        return profit;
    }
};
```

**关键点**: 贪心的正确性来自"连续上涨可拆分为相邻差值之和"这个数学性质。面试时需要能解释为什么贪心是最优的。

## 解法对比

| | DP (二维) | DP (空间优化) | 贪心 |
|---|---|---|---|
| 时间 | O(n) | O(n) | O(n) |
| 空间 | O(n) | O(1) | O(1) |
| 通用性 | 高，可扩展到 Stock III/IV/Cooldown/Fee | 高 | 低，仅适用于无限次无限制交易 |
| 代码量 | 中等 | 较少 | 最少 |
| 面试推荐 | 系列题统一框架时用 | 优化后展示 | 本题最佳答案 |

**关键区别**: 贪心只能解决"无限次交易、无附加限制"的情况。一旦加了交易次数限制(Stock III/IV)或冷冻期(Cooldown)或手续费(Fee)，就必须用 DP。所以 DP 解法的学习价值更高。

## 易错点

1. **DP 滚动变量同时更新问题**
   - ✗ `cash = max(cash, hold + prices[i]); hold = max(hold, cash - prices[i]);` — 第二行用了已更新的 `cash`
   - ✓ 用临时变量 `newCash` 和 `newHold`，或者利用语言特性同时赋值

2. **和 Stock I 混淆买入转移**
   - ✗ `dp[i][1] = max(dp[i-1][1], -prices[i])` — 这是 Stock I 的写法，只允许一次交易
   - ✓ `dp[i][1] = max(dp[i-1][1], dp[i-1][0] - prices[i])` — Stock II 允许累积之前利润

3. **贪心时漏掉边界**
   - ✗ `for (int i = 0; i < prices.size(); i++)` 然后访问 `prices[i-1]` — 越界
   - ✓ `for (int i = 1; i < prices.size(); i++)` 从第1天开始

4. **误以为贪心需要记录买卖天数**
   - 题目只要求返回最大利润值，不需要输出具体哪天买哪天卖。累加正差值即可。

## 面试追问

**Q1: 暴力解怎么做？复杂度是多少？**
> 每天可以选择买/卖/不动，递归枚举所有可能。时间 O(3^n)，不可接受。但面试时能说出来表示理解了问题。

**Q2: 能用 O(1) 空间的 DP 吗？**
> 可以。`dp[i]` 只依赖 `dp[i-1]`，用两个滚动变量 `cash` 和 `hold` 即可。注意同时更新问题。

**Q3: 贪心为什么是对的？能证明吗？**
> 数学上，一段从 valley 到 peak 的利润等于这段内所有相邻正差值之和。贪心选所有正差值 = 捕获所有上涨段 = 最优。

**Q4: 如果加了交易手续费呢？（→ LeetCode 714）**
> 贪心失效。改用 DP，转移时减去手续费：`dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i] - fee)`。框架完全一样，改一行。

**Q5: 如果限制最多交易 k 次呢？（→ LeetCode 188）**
> 状态加一维：`dp[i][k][0/1]`，表示第i天最多完成k次交易的持有/不持有最大利润。本题相当于 k = ∞ 的特殊情况。
