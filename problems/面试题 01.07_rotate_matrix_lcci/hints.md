# 面试题 01.07. 旋转矩阵

## 核心思路

将 N x N 矩阵**原地**顺时针旋转 90 度。经典的两步法：**先沿主对角线转置，再每行左右翻转**。也可以用**四角轮转法**逐层逐位置旋转四个元素。两种方法都是 O(n^2) 时间、O(1) 额外空间。本题与主站 48 题完全相同。

## 思维链

1. **读完题第一反应**：矩阵顺时针转 90 度，最简单的想法是新建一个矩阵，把 `(i,j)` 的元素放到 `(j, n-1-i)` 的位置。但题目要求**原地操作**（不使用额外矩阵）。

2. **寻找坐标变换规律**：
   - 顺时针 90 度：`(i, j) → (j, n-1-i)`
   - 逆时针 90 度：`(i, j) → (n-1-j, i)`
   - 旋转 180 度：`(i, j) → (n-1-i, n-1-j)`

3. **方法一 — 转置+翻转（两步法）**：
   - 观察：顺时针 90 度 = 沿主对角线转置 + 水平翻转（每行reverse）
   - 转置：`(i,j) → (j,i)`
   - 水平翻转：`(i,j) → (i, n-1-j)`
   - 组合：`(i,j) → (j,i) → (j, n-1-i)` = 顺时针 90 度 ✓

4. **方法二 — 四角轮转（逐层旋转）**：
   - 从外层到内层，每层有若干个"旋转组"
   - 每个旋转组涉及 4 个元素循环交换
   - 用一个 temp 变量完成 4 元素的原地轮转

```
旋转过程可视化 — 方法一(转置+翻转):

原矩阵:              转置后:              翻转每行后:
[ 1  2  3 ]          [ 1  4  7 ]          [ 7  4  1 ]
[ 4  5  6 ]    →     [ 2  5  8 ]    →     [ 8  5  2 ]
[ 7  8  9 ]          [ 3  6  9 ]          [ 9  6  3 ]

  (1,2)↔(2,1): 6↔8
  只遍历上三角(j > i), 避免交换两次
```

## 解法详解

### 解法1: 转置 + 水平翻转 -- O(n^2) / O(1)

**思考过程**：发现数学关系 → 顺时针90度 = 转置 + 水平翻转。两步都是简单的原地操作。

**数学推导**：
```
原坐标:  (i, j)
转置后:  (j, i)        — 沿主对角线翻折
翻转后:  (j, n-1-i)    — j行的第i列变成j行的第(n-1-i)列

验证: (i,j) → (j, n-1-i) 正是顺时针90度的坐标变换 ✓
```

```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();
        // 步骤1: 沿主对角线转置
        // 只遍历上三角(j > i), 避免交换两次
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                swap(matrix[i][j], matrix[j][i]);
            }
        }
        // 步骤2: 每行左右翻转
        for (int i = 0; i < n; i++) {
            reverse(matrix[i].begin(), matrix[i].end());
        }
    }
};
```

**为什么只遍历上三角**：
```
转置操作是 swap(matrix[i][j], matrix[j][i])
如果遍历全部(i,j), 每对会被交换两次 → 等于没交换!
所以只遍历 j > i 的部分(上三角)

  [1  2  3]        上三角部分:
  [4  5  6]          .  (0,1)  (0,2)
  [7  8  9]          .   .     (1,2)
                     .   .      .
交换: (0,1)↔(1,0), (0,2)↔(2,0), (1,2)↔(2,1)
```

### 解法2: 四角轮转（逐层旋转） -- O(n^2) / O(1)

**思考过程**：从矩阵外层到内层，每层处理若干个"旋转组"。每个旋转组涉及4个对称位置的元素循环交换。

**层数**：总共 `n/2` 层（向下取整）
**每层旋转组数**：第 `layer` 层有 `n - 2*layer - 1` 个旋转组

```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();
        // 逐层处理, 从外到内
        for (int layer = 0; layer < n / 2; layer++) {
            int first = layer;
            int last = n - 1 - layer;
            // 当前层的每个旋转组
            for (int k = 0; k < last - first; k++) {
                // 四个位置的坐标
                // 位置1: 上边 (first, first+k)
                // 位置2: 右边 (first+k, last)
                // 位置3: 下边 (last, last-k)
                // 位置4: 左边 (last-k, first)
                
                int temp = matrix[first][first + k];        // 保存位置1
                matrix[first][first + k] = matrix[last - k][first];   // 位置4→位置1
                matrix[last - k][first] = matrix[last][last - k];     // 位置3→位置4
                matrix[last][last - k] = matrix[first + k][last];     // 位置2→位置3
                matrix[first + k][last] = temp;                       // 位置1→位置2
            }
        }
    }
};
```

## 关键提示

- **提示1**：顺时针 90 度的坐标变换公式 `(i,j) → (j, n-1-i)` 是核心。所有方法都围绕这个公式展开。
- **提示2**：转置+翻转法中，转置只遍历上三角 `j > i`，否则会重复交换回来。
- **提示3**：其他旋转方向的两步法：
  - 逆时针 90 度 = 转置 + 上下翻转（垂直翻转）
  - 旋转 180 度 = 上下翻转 + 左右翻转
- **提示4**：四角轮转法中，交换顺序很重要——从 temp 开始保存，然后**逆时针赋值**，最后把 temp 放到目标位置。
- **提示5**：四角轮转的层数是 `n/2`（奇数矩阵中心元素不动），每层旋转组数为 `n-2*layer-1`。

## 易错点

1. **转置范围错误**：转置时用 `j = i+1` 而非 `j = 0`，否则每个元素交换两次等于没交换。
2. **四角轮转的赋值方向**：需要明确是顺时针还是逆时针赋值。保存 temp 后，按逆旋转方向依次赋值。
3. **坐标公式搞混**：`(first, first+k)` 等坐标容易写错，建议先在纸上画出来。
4. **奇数矩阵的中心**：转置+翻转法自动处理了中心元素（它在对角线上，转置不变；翻转后仍在中间）。四角轮转法中心元素所在层不参与旋转。
5. **混淆原地和非原地**：题目要求原地修改，不能新建矩阵。

## 复杂度分析

| 维度 | 分析 |
|------|------|
| 时间 | O(n^2)：需要移动矩阵中的每个元素（n^2个元素） |
| 空间 | O(1)：两种方法都只用常数额外空间（swap/temp） |

## 各种旋转的两步法总结

```
顺时针 90°:   转置 + 每行reverse        (i,j) → (j, n-1-i)
逆时针 90°:   转置 + 上下reverse         (i,j) → (n-1-j, i)
旋转 180°:    上下reverse + 每行reverse  (i,j) → (n-1-i, n-1-j)

或者:
顺时针 90° = 逆时针 90° 做三次
逆时针 90° = 顺时针 90° 做三次
```

## Follow-up 思考

1. **如果矩阵不是方阵（M x N）？** 不能原地旋转（维度改变了），需要新建一个 N x M 矩阵。
2. **如果要旋转 k 次（k 可能很大）？** k % 4 即可，因为旋转 4 次回到原样。
3. **如果矩阵是稀疏的？** 只需要移动非零元素，可以用坐标变换公式直接计算新位置。
