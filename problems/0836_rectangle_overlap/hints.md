# 836. Rectangle Overlap - 提示与解析

## 核心思路

判断两个轴对齐矩形是否重叠。核心思路有两种：**正向判断重叠**和**反向排除不重叠**。反向思维更简单——两个矩形不重叠只有四种情况：一个在另一个的左边、右边、上边或下边。排除这四种情况后就是重叠。正向思维则是分别检查x轴和y轴上的投影是否都有交集（区间重叠）。

## 思维链

1. **理解矩形表示**：`[x1, y1, x2, y2]` 其中 (x1,y1) 是左下角，(x2,y2) 是右上角
2. **重叠的充要条件**：x方向有交集 AND y方向有交集
3. **一维区间重叠条件**：区间 [a,b] 和 [c,d] 重叠当且仅当 `a < d && c < b`
4. **二维推广**：两个方向都满足区间重叠即可
5. **或者用反向思维**：不重叠的四种情况取反

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 推荐度 | 说明 |
|------|-----------|-----------|--------|------|
| 区间重叠法（正向） | O(1) | O(1) | ⭐⭐⭐⭐⭐ | 分别检查x、y方向区间 |
| 反向排除法 | O(1) | O(1) | ⭐⭐⭐⭐⭐ | 排除四种不重叠情况 |
| 计算交集面积法 | O(1) | O(1) | ⭐⭐⭐⭐ | 计算重叠面积是否>0 |

## 关键提示

1. **严格不等号**：题目说"only touch at corner or edges do not overlap"，所以用 `<` 而不是 `<=`
2. **一维推广到二维**：矩形重叠 = x轴投影重叠 AND y轴投影重叠
3. **反向思维更简单**：不重叠只有四种互斥情况
4. **坐标对应关系**：rec1[0]=x1, rec1[1]=y1, rec1[2]=x2, rec1[3]=y2
5. **退化矩形**：题目保证矩形面积非零，但重叠判断时仍需注意边界

## 解法详解

### 解法一：区间重叠法（正向）⭐⭐⭐⭐⭐

将二维问题分解为两个一维问题：

**X方向：** 矩形1的x范围是 [rec1[0], rec1[2]]，矩形2的x范围是 [rec2[0], rec2[2]]。两个区间重叠的条件是 `rec1[0] < rec2[2] && rec2[0] < rec1[2]`。

**Y方向：** 同理，`rec1[1] < rec2[3] && rec2[1] < rec1[3]`。

两个方向同时重叠则矩形重叠。

### 解法二：反向排除法 ⭐⭐⭐⭐⭐

四种不重叠的情况：
- rec1在rec2的**左边**：`rec1[2] <= rec2[0]`
- rec1在rec2的**右边**：`rec1[0] >= rec2[2]`
- rec1在rec2的**下边**：`rec1[3] <= rec2[1]`
- rec1在rec2的**上边**：`rec1[1] >= rec2[3]`

只要满足其中任意一个就不重叠，全部不满足则重叠。

### 解法三：计算交集面积 ⭐⭐⭐⭐

计算重叠区域的宽和高：
- 重叠宽度 = `min(rec1[2], rec2[2]) - max(rec1[0], rec2[0])`
- 重叠高度 = `min(rec1[3], rec2[3]) - max(rec1[1], rec2[1])`

如果宽和高都大于0，则有重叠。

## 易错点

1. **等号问题**：`<=` vs `<`，题目明确说仅边或角接触不算重叠，必须用严格不等号
2. **坐标索引混淆**：x1=rec[0], y1=rec[1], x2=rec[2], y2=rec[3]，容易搞混
3. **反向法的逻辑**：四种情况用 OR 连接，最外层取反；或者直接用 AND 连接四个"非"条件
4. **退化情况**：虽然题目保证矩形面积非零，但逻辑上要理解线段（面积为0）的情况
5. **整数范围**：坐标范围到10^9，计算面积时可能溢出int，但本题只需比较不需乘法

## 面试追问

1. **如果是3D长方体重叠呢？** - 增加z轴方向的区间重叠判断，三个方向都重叠即可
2. **如何计算N个矩形的总覆盖面积？** - 扫描线 + 线段树，LC 850
3. **如果矩形可以旋转（非轴对齐）？** - 需要SAT（分离轴定理），复杂度大增
4. **如何判断一个点是否在矩形内？** - 四个不等式同时满足
5. **如果要计算两个矩形的交集矩形坐标？** - 取四个坐标的max/min
6. **如果给定N个矩形，找出所有重叠对？** - 扫描线 + 活跃集合，O(NlogN + K)
