# 205. 同构字符串

## 核心思路

这道题本质上在问：两个字符串的**字符出现模式（结构）是否相同**？即 s 到 t 的映射必须是**双射（一一对应）**，不允许多对一，也不允许一对多。

## 思维链

1. **读完题第一反应**：遍历两个字符串，对每个位置 `s[i] → t[i]` 建立映射关系。如果 `s[i]` 之前已经映射过，检查是否映射到同一个 `t[i]`。
2. **只用一个 map 够吗？** 考虑 `s = "ab", t = "aa"`：`a→a, b→a`，一个 map 检查 s→t 没有冲突，但 `a` 和 `b` 都映射到了 `a`，这不是双射！所以**只检查 s→t 方向不够**。
3. **怎么保证双射？** 两种方案：
   - 方案A：用**两个 map**，同时维护 s→t 和 t→s 两个方向的映射
   - 方案B：转化思路——不存映射关系，而是比较两个字符串的**结构模式**是否相同
4. **什么是"结构模式"？** 把每个字符替换成它**第一次出现的位置索引**。`egg → [0,1,1]`，`add → [0,1,1]`，模式相同即同构。这就是"记录首次出现位置"的思路。
5. **最简洁的实现**：不需要真的构建模式数组，只需检查 `s[i]` 和 `t[i]` 的**上次出现位置是否一致**。用两个数组记录每个字符上次出现在哪个位置即可。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 双哈希表 | 维护 s→t 和 t→s 两个映射 | O(n) | O(字符集) | ⭐ 必须写出 |
| 首次出现位置 | 比较两字符的首次出现索引 | O(n) | O(字符集) | 加分项 |
| 数组替代哈希表 | 用定长数组记录上次出现位置 | O(n) | O(1)* | ⭐ 必须写出 |

> *ASCII 字符集大小固定为 256，空间 O(256) 视为 O(1)

## 关键提示

1. **单方向映射不够**：`s="ab", t="aa"` 只检查 s→t 会误判为 true，必须同时检查 t→s（或用等价方法保证双射）。
2. **核心不变量**：在任何位置 i，如果 `s[i]` 之前出现过，那么 `t[i]` 也必须在**完全相同的位置**出现过，反之亦然。
3. **用"上次出现位置"代替显式映射**：不需要存储 `s[i]→t[i]` 的映射，只需要比较两个字符各自的上次出现位置是否相同。
4. **初始化陷阱**：如果用数组记录"上次出现位置"，初始值不能是 0（因为索引 0 是合法位置），应该用 -1 或者记录 `i+1`。

## 解法详解

### 解法1: 双哈希表 — O(n) / O(字符集) ⭐ 面试首选

**思考过程**：最直觉的想法——边遍历边建映射。遇到 `s[i]`，如果它还没有映射目标，就建立 `s[i]→t[i]`；如果已有映射，检查是否和当前 `t[i]` 一致。但这只保证了 s→t 方向的一致性，还需要反向检查 t→s，所以用两个 map。

```cpp
class Solution {
public:
    bool isIsomorphic(string s, string t) {
        unordered_map<char, char> s2t, t2s;
        for (int i = 0; i < s.size(); i++) {
            char a = s[i], b = t[i];
            // 检查 s→t 方向：a 之前映射过，但目标不是 b
            if (s2t.count(a) && s2t[a] != b) return false;
            // 检查 t→s 方向：b 之前被映射过，但来源不是 a
            if (t2s.count(b) && t2s[b] != a) return false;
            s2t[a] = b;
            t2s[b] = a;
        }
        return true;
    }
};
```

**关键点**：两个 map 缺一不可。只用 s2t 会漏掉"不同字符映射到同一字符"的情况。

---

### 解法2: 首次出现位置对比 — O(n) / O(字符集)

**从解法1换个角度**：不存映射关系，而是比较"结构模式"。两个字符串同构，等价于：对于任意位置 i，`s[i]` 在 s 中首次出现的位置 == `t[i]` 在 t 中首次出现的位置。

```
// s = "paper"  →  首次出现位置: [0, 1, 0, 3, 4]
//     p→0, a→1, p→0(已有), e→3, r→4
// t = "title"  →  首次出现位置: [0, 1, 0, 3, 4]
//     t→0, i→1, t→0(已有), l→3, e→4
// 模式相同 → 同构 ✓

// s = "foo"    →  首次出现位置: [0, 1, 1]
// t = "bar"    →  首次出现位置: [0, 1, 2]
// 位置2不同(1≠2) → 不同构 ✗
```

```cpp
class Solution {
public:
    bool isIsomorphic(string s, string t) {
        // 记录每个字符首次出现的位置（用 find 或 预处理）
        // 简洁写法：用 map 记录首次出现位置
        unordered_map<char, int> firstS, firstT;
        for (int i = 0; i < s.size(); i++) {
            // 如果字符还没出现过，记录它首次出现的位置
            if (!firstS.count(s[i])) firstS[s[i]] = i;
            if (!firstT.count(t[i])) firstT[t[i]] = i;
            // 两个字符的首次出现位置必须相同
            if (firstS[s[i]] != firstT[t[i]]) return false;
        }
        return true;
    }
};
```

**关键点**：这个方法天然保证了双射，不需要两个映射方向的检查，因为它比较的是"结构"而不是"具体映射"。

---

### 解法3: 定长数组 + 上次出现位置 — O(n) / O(1) ⭐ 最优写法

**从解法2优化**：用定长数组代替哈希表（ASCII 只有 256 个字符），并且改为记录"上次出现位置"——效果等价，但更简洁。

```cpp
class Solution {
public:
    bool isIsomorphic(string s, string t) {
        // 记录每个字符上一次出现的位置（初始化为 -1 表示未出现）
        int lastS[256], lastT[256];
        memset(lastS, -1, sizeof(lastS));
        memset(lastT, -1, sizeof(lastT));
        
        for (int i = 0; i < s.size(); i++) {
            // 两个字符的"上次出现位置"必须相同
            // 如果都是 -1（都是首次出现），OK
            // 如果都是同一个位置 j，说明上次在同一个位置配对过，OK
            // 如果不同，结构不匹配
            if (lastS[(unsigned char)s[i]] != lastT[(unsigned char)t[i]])
                return false;
            // 更新为当前位置
            lastS[(unsigned char)s[i]] = i;
            lastT[(unsigned char)t[i]] = i;
        }
        return true;
    }
};
```

**关键点**：
- 初始值用 -1 而不是 0，因为索引 0 是合法位置。如果初始化为 0，`s="ab", t="aa"` 在 i=1 时 `lastS['b']=0, lastT['a']=0` 会误判相等。
- 用 `(unsigned char)` 防止 char 为 signed 时出现负索引。

## 解法对比

| | 双哈希表 | 首次出现位置 | 定长数组 |
|---|---|---|---|
| 核心思想 | 显式维护双向映射 | 比较结构模式 | 比较结构模式 |
| 空间 | 两个 unordered_map | 两个 unordered_map | 两个 int[256] |
| 代码清晰度 | 最直觉 | 较巧妙 | 最简洁 |
| 实际速度 | 哈希表有常数开销 | 同上 | 数组访问最快 |
| 面试推荐 | ✅ 首选讲解 | ✅ 展示思维深度 | ✅ 追问优化时给出 |

**选择建议**：面试先讲解法1（思路清晰），再优化到解法3（体现对底层的理解）。

## 易错点

1. **只用单方向映射**
   - ✗ 只维护 `s2t` 一个 map → `s="ab", t="aa"` 会误判为 true
   - ✓ 必须同时维护 `t2s`，或使用"位置对比"方法

2. **上次出现位置初始化为 0**
   - ✗ `int lastS[256] = {0}` → 索引 0 处的字符会和"未出现"混淆
   - ✓ 初始化为 -1，或者记录 `i+1`（让未出现时为 0，第一个位置为 1）

3. **忘记 unsigned char 转换**
   - ✗ `lastS[s[i]]` 当 char 为 signed 且值 > 127 时，索引为负数 → 越界
   - ✓ `lastS[(unsigned char)s[i]]` 确保索引在 [0, 255]

4. **忽略题目说"长度相等"**
   - 题目保证 `s.length == t.length`，不需要额外判断。但如果面试官没保证，要先检查长度。

## 面试追问

**Q1（基础理解）**：为什么只用一个 map（s→t）不够？
> 因为只检查 s→t 不能保证双射。例如 `s="ab", t="aa"`，`a→a` 和 `b→a` 在 s→t 方向都不冲突，但 `a` 和 `b` 都映射到了 `a`，违反了"不同字符不能映射到同一字符"。

**Q2（优化）**：能不能不用哈希表？
> 可以。ASCII 字符集只有 256 个，用两个 `int[256]` 数组记录上次出现位置，用数组下标直接访问，O(1) 查找且无哈希冲突。

**Q3（变体）**：如果两个字符串不是逐字符映射，而是逐**单词**映射呢？（参考 LeetCode 290）
> 同样的思路，只是把"字符"换成"单词"。用 `unordered_map<string, string>` 做双向映射，或者用单词的首次出现索引做模式对比。
