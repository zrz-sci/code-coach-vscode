# 435. 无重叠区间

## 核心思路

这道题本质上是**区间调度问题 (Interval Scheduling)**：从一堆可能重叠的区间中，选出**最多**互不重叠的区间，剩下的就是要移除的。移除最少 = 保留最多。

## 思维链

1. **读完题第一反应**：要移除最少的区间让剩余互不重叠。暴力做法是枚举所有子集，检查哪个最大的子集互不重叠 → 指数级复杂度，不可行。

2. **换个角度想**：移除最少 ↔ **保留最多**。问题变成"最多能保留多少个互不重叠的区间？"这就是经典的**活动选择问题 (Activity Selection Problem)**。

3. **为什么要排序？** 区间是无序的，没法高效判断选哪些。如果按某种规则排序，就能贪心地从左到右扫一遍。

4. **按什么排序？** 按**结束时间**排序。直觉：结束越早的区间，给后面留的空间越大，能塞下更多区间。这就是贪心策略。

5. **贪心过程**：排序后，维护上一个保留区间的结束时间 `end`。对于每个新区间：
   - 如果 `start >= end`：不重叠，保留它，更新 `end`
   - 如果 `start < end`：重叠，移除它（计数+1）

6. **为什么贪心是对的？** 这可以用"交换论证"证明：如果最优解里选了一个结束更晚的区间 A，我们把它换成结束更早的区间 B，不会让情况变差（B 结束更早，后面能容纳的区间只多不少）。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 贪心（按结束时间排序） | 保留尽可能多的不重叠区间 | O(n log n) | O(log n)（排序栈空间） | ⭐ 必须写出 |
| 贪心（按开始时间排序） | 重叠时移除结束更晚的区间 | O(n log n) | O(log n) | 能说出即可 |
| 动态规划 | dp[i] = 前 i 个区间的最大不重叠数 | O(n²) 或 O(n log n) | O(n) | 加分项（展示 DP 思维） |

## 关键提示

1. **逆向思维**：不要直接想"移除哪些"，而是想"最多能保留多少个"，答案 = 总数 - 最多保留数。

2. **排序是关键**：按**结束时间**升序排序。为什么不按开始时间？因为按结束时间排序后，贪心选第一个不重叠的就是最优的。

3. **判断重叠**：两个区间 `[a,b]` 和 `[c,d]`（b ≤ d）重叠当且仅当 `c < b`。注意题目说端点相同不算重叠，所以是严格小于。

4. **ASCII 示意图 — 为什么按结束时间排序更优？**
   ```
   按结束时间排序后:
   [1,2)  ████
   [1,3)  ██████        ← 与 [1,2) 重叠，移除这个（结束更晚）
   [2,3)      ████      ← start=2 >= end=2，保留！
   [3,4)          ████  ← start=3 >= end=3，保留！
   
   保留 3 个，移除 1 个 → 答案 = 1
   ```

5. **DP 思路**（如果面试追问）：按结束时间排序后，`dp[i]` = 以第 i 个区间结尾的最大不重叠区间数。对每个 i，找它前面所有不重叠的 j，取 `max(dp[j]) + 1`。暴力 O(n²)，用二分优化到 O(n log n)。

## 解法详解

### 解法1: 贪心（按结束时间排序） — O(n log n) / O(log n) ⭐ 面试首选

**思考过程**：
这是经典的活动选择问题。想象你是一个会议室管理员，要在一间会议室里安排尽可能多的会议。策略：每次选**最早结束**的会议，这样能给后面的会议留出最多时间。

```cpp
class Solution {
public:
    int eraseOverlapIntervals(vector<vector<int>>& intervals) {
        // 按结束时间升序排序
        // 为什么按结束时间？结束越早，给后面留的空间越大
        sort(intervals.begin(), intervals.end(), [](const vector<int>& a, const vector<int>& b) {
            return a[1] < b[1];
        });
        
        int kept = 1;  // 第一个区间一定保留（它结束最早）
        int end = intervals[0][1];  // 上一个保留区间的结束时间
        
        for (int i = 1; i < intervals.size(); i++) {
            if (intervals[i][0] >= end) {
                // 不重叠（端点相同也不算重叠），保留这个区间
                kept++;
                end = intervals[i][1];
            }
            // 重叠的直接跳过（等价于移除）
        }
        
        return intervals.size() - kept;  // 移除数 = 总数 - 保留数
    }
};
```

**关键点**：
- 排序比较器写 `a[1] < b[1]`（按结束时间），不是按开始时间
- 不重叠的判断是 `>=`（端点相同不算重叠），写成 `>` 就错了

### 解法2: 贪心（按开始时间排序） — O(n log n) / O(log n)

**从解法1的另一个角度**：如果按开始时间排序，遇到重叠时，应该移除哪个？移除**结束时间更晚**的那个——因为它占的空间更大，更容易和后面的区间冲突。

```cpp
class Solution {
public:
    int eraseOverlapIntervals(vector<vector<int>>& intervals) {
        // 按开始时间升序排序
        sort(intervals.begin(), intervals.end());
        
        int removed = 0;
        int end = intervals[0][1];  // 上一个保留区间的结束时间
        
        for (int i = 1; i < intervals.size(); i++) {
            if (intervals[i][0] < end) {
                // 重叠了！移除结束时间更晚的那个
                removed++;
                end = min(end, intervals[i][1]);  // 保留结束更早的
            } else {
                // 不重叠，保留当前区间
                end = intervals[i][1];
            }
        }
        
        return removed;
    }
};
```

**关键理解 — 为什么 `end = min(end, intervals[i][1])`？**
```
情况1: 前一个区间"包含"当前区间（前大后小）
  prev: [==========]
  curr:   [====]        ← 移除 prev，保留 curr（更短），end = curr.end
  
情况2: 部分重叠
  prev: [======]
  curr:     [======]    ← 移除 curr，保留 prev，end 不变
  
两种情况统一为: end = min(end, intervals[i][1])
```

### 解法3: 动态规划 — O(n²) / O(n)

**DP 视角**：排序后，`dp[i]` 表示以第 i 个区间结尾时，最多能保留多少个不重叠区间。

```cpp
class Solution {
public:
    int eraseOverlapIntervals(vector<vector<int>>& intervals) {
        int n = intervals.size();
        // 按结束时间排序
        sort(intervals.begin(), intervals.end(), [](const vector<int>& a, const vector<int>& b) {
            return a[1] < b[1];
        });
        
        // dp[i] = 以第 i 个区间结尾的最大不重叠区间数
        vector<int> dp(n, 1);  // 每个区间自身至少是1
        
        // dp 填表过程 (以示例1排序后 [1,2],[1,3],[2,3],[3,4] 为例):
        //   i=0: dp[0]=1                     → [1,2] 独立
        //   i=1: j=0, [1,2]与[1,3]重叠      → dp[1]=1
        //   i=2: j=0, [1,2]不重叠, dp[2]=2  → 选 [1,2]+[2,3]
        //         j=1, [1,3]与[2,3]重叠     → 跳过
        //   i=3: j=2, [2,3]不重叠, dp[3]=3  → 选 [1,2]+[2,3]+[3,4]
        
        int maxKept = 1;
        for (int i = 1; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (intervals[j][1] <= intervals[i][0]) {
                    dp[i] = max(dp[i], dp[j] + 1);
                }
            }
            maxKept = max(maxKept, dp[i]);
        }
        
        return n - maxKept;
    }
};
```

**注意**：O(n²) 对于 n=10⁵ 可能超时。可以用二分查找优化内层循环到 O(log n)，总体 O(n log n)，但实现更复杂且不如贪心直观。

## 解法对比

| | 贪心（按结束时间） | 贪心（按开始时间） | DP |
|---|---|---|---|
| 时间 | O(n log n) | O(n log n) | O(n²) |
| 空间 | O(log n) | O(log n) | O(n) |
| 代码量 | 最少 | 中等 | 最多 |
| 面试推荐 | ⭐ 首选 | 备选 | 展示 DP 能力 |
| 核心思想 | 最早结束 = 最优选择 | 重叠时移除结束晚的 | 状态转移 |

**两种贪心的本质相同**：都是"保留结束时间更早的区间"。按结束时间排序的版本更简洁直观。

## 易错点

1. **排序方向搞错**：
   - ✗ `sort by start time` 然后用解法1的逻辑 → 反例：`[[1,100],[2,3],[3,4]]`，按开始时间排后保留了 `[1,100]`，但最优应该保留 `[2,3]` 和 `[3,4]`
   - ✓ 解法1必须按**结束时间**排序

2. **端点相同判断写错**：
   - ✗ `intervals[i][0] > end`（严格大于）→ 把 `[1,2]` 和 `[2,3]` 当成重叠了
   - ✓ `intervals[i][0] >= end`（题目说端点相同不算重叠）

3. **返回值搞反**：
   - ✗ 直接返回 `kept`（保留的数量）
   - ✓ 返回 `n - kept`（移除的数量）

4. **按开始时间排序时，重叠后 end 更新错误**：
   - ✗ `end = intervals[i][1]`（无脑更新为当前区间的结束时间）
   - ✓ `end = min(end, intervals[i][1])`（保留结束更早的那个）

## 面试追问

**Q1: 为什么贪心策略"选结束最早的"是正确的？能证明吗？**
> 交换论证：假设最优解 OPT 中第一个选的区间 A 不是结束最早的 B。因为 B.end ≤ A.end，把 A 换成 B 后，OPT 中后续的区间仍然不冲突（B 结束更早，空间只多不少），所以新解至少和 OPT 一样好。对后续区间重复此论证，贪心解 = 最优解。

**Q2: 如果区间有权重，要求保留的区间权重和最大，贪心还能用吗？**
> 不能。加了权重后贪心不再成立（结束早但权重低的可能不是最优选择）。此时需要用 **带权区间调度 DP**：按结束时间排序，`dp[i]` = 前 i 个区间的最大权重和，用二分找到最后一个不冲突的区间 j，`dp[i] = max(dp[i-1], dp[j] + w[i])`。时间 O(n log n)。

**Q3: 如果不是区间而是"圆形"排列（首尾相连），怎么处理？**
> 类似 House Robber II 的思路：环形问题 = 两个线性问题。分别处理"包含第一个区间"和"不包含第一个区间"两种情况，取较优解。
