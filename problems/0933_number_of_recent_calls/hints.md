# 933. 最近的请求次数 (Number of Recent Calls)

## 难度: Easy | 标签: Design, Queue, Data Stream

---

## 核心思路

设计一个计数器，每次调用 `ping(t)` 时返回过去 3000 毫秒内（包括当前请求）的请求总数。由于调用时间严格递增，过期的请求一定在最前面，使用**队列（FIFO）**维护一个滑动时间窗口即可。

## 思维链

1. **读完题第一反应**：需要维护一个滑动时间窗口 `[t - 3000, t]`。每次 `ping(t)` 需要快速知道窗口内有多少请求。

2. **时间严格递增是关键条件**：这意味着新请求一定在旧请求之后，过期的请求一定在队列最前面。不需要排序，不需要随机删除。

3. **什么数据结构？** 
   - 需要在尾部添加（新请求入队）
   - 需要从头部移除（过期请求出队）
   - → 这就是**队列**的经典应用场景

4. **每次 ping(t) 的操作**：
   - 将 t 入队（新请求加到队尾）
   - 把队首所有 `< t - 3000` 的元素弹出（清除过期请求）
   - 返回队列大小（窗口内的请求数）

5. **复杂度分析**：每个元素最多入队一次、出队一次，所以 N 次 `ping` 调用的总时间是 O(N)，均摊每次 O(1)。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 队列（FIFO） | 维护滑动窗口 | 均摊 O(1) 每次 | O(W) W 为窗口大小 | ⭐⭐⭐ 唯一解法 |

## 关键提示

1. **严格递增保证了队列天然有序**：新元素永远是最大的，过期元素永远在最前面。所以只需要从队首弹出，不需要从中间删除。

2. **窗口大小有上界**：最多 3001 个元素在窗口内（t 到 t-3000 的整数范围是 3001 个，但实际取决于 ping 的频率）。题目限制最多 10^4 次 ping 调用。

3. **均摊 O(1) 而不是 O(1)**：单次 ping 最坏可能弹出所有旧元素 O(n)，但每个元素整个生命周期只入队一次出队一次，所以总操作 O(N)，均摊每次 O(1)。

4. **不需要检查队列是否为空**：因为我们刚刚 push 了 t，while 循环中 `q.front() < t - 3000` 最坏会弹到只剩 t 本身（`t < t - 3000` 不成立），不会弹空。

## 解法详解

### 队列滑动窗口 — 均摊 O(1) / O(W) ⭐

**思考过程**：这是"滑动窗口"数据结构题的最简单形式。窗口由时间范围定义，队列维护窗口内的所有元素。

```
操作过程模拟:

ping(1):
  队列: [1]
  窗口 [-2999, 1]: 弹出 < -2999 的 → 没有
  返回 size = 1

ping(100):
  队列: [1, 100]
  窗口 [-2900, 100]: 弹出 < -2900 的 → 没有
  返回 size = 2

ping(3001):
  队列: [1, 100, 3001]
  窗口 [1, 3001]: 弹出 < 1 的 → 没有 (1 == 1, 不弹)
  返回 size = 3

ping(3002):
  队列: [1, 100, 3001, 3002]
  窗口 [2, 3002]: 弹出 < 2 的 → 弹出 1 (1 < 2)
  队列变为: [100, 3001, 3002]
  返回 size = 3

时间线可视化:
  
  t=1     t=100                t=3001  t=3002
  |       |                    |       |
  v       v                    v       v
  --+-------+----···-----------+---+---→ 时间轴
                               |       |
                               |←3000→|
                               窗口=[2, 3002]
                               
  t=1 不在窗口内 (1 < 2) → 弹出
  t=100 在窗口内 (100 >= 2) → 保留
  t=3001 在窗口内 → 保留
  t=3002 在窗口内 → 保留
  答案 = 3
```

```cpp
class RecentCounter {
    queue<int> q;  // 存储窗口内的请求时间

public:
    RecentCounter() {}

    int ping(int t) {
        q.push(t);  // 新请求入队

        // 弹出所有过期请求（时间 < t-3000 的）
        while (q.front() < t - 3000) {
            q.pop();
        }

        return q.size();  // 窗口内的请求数
    }
};
```

**为什么这么简单的题也值得掌握？**
- 它是"滑动窗口"和"队列"两个概念的最纯净体现
- 是 LC 239 Sliding Window Maximum、LC 862 Shortest Subarray with Sum at Least K 等困难题的基础
- 面试中考察是否理解"均摊复杂度"——看似 while 循环很慢，实际均摊 O(1)

---

### 变体：用 deque 实现（支持更灵活的操作）

```cpp
class RecentCounter2 {
    deque<int> dq;

public:
    RecentCounter2() {}

    int ping(int t) {
        dq.push_back(t);
        while (!dq.empty() && dq.front() < t - 3000) {
            dq.pop_front();
        }
        return dq.size();
    }
};
```

---

### 变体：用 vector + 二分查找（面试追问时展示）

```cpp
class RecentCounter3 {
    vector<int> times;  // 所有请求时间（已排序）

public:
    RecentCounter3() {}

    int ping(int t) {
        times.push_back(t);
        // 二分查找第一个 >= t-3000 的位置
        int left = lower_bound(times.begin(), times.end(), t - 3000) - times.begin();
        return times.size() - left;
    }
};
```

**注意**：这个变体不删除旧数据，空间是 O(N)（N = 总调用次数）而不是 O(W)。但 `ping` 是严格 O(log N) 而不是均摊 O(1)。面试中提到这个变体可以展示你知道多种方法。

## 解法对比

| | 队列 | deque | vector+二分 |
|---|---|---|---|
| 时间(单次) | 均摊 O(1) | 均摊 O(1) | O(log N) |
| 空间 | O(W) 窗口大小 | O(W) 窗口大小 | O(N) 总调用次数 |
| 代码复杂度 | 最简单 | 简单 | 中等 |
| 面试推荐度 | ⭐⭐⭐ | ⭐⭐⭐ | 追问时提及 |

## 易错点

1. **while 条件用 `<=` 导致窗口左端点排除错误**
   - 错: `while (q.front() <= t - 3000)` — 把刚好在边界的请求也弹出了
   - 对: `while (q.front() < t - 3000)` — 窗口是闭区间 `[t-3000, t]`，等于边界的应保留

2. **忘记先 push 再 pop**
   - 错: 先弹出过期的，再入队当前的 → 如果队列变空再 pop 会段错误
   - 对: 先 push(t) 保证队列非空，再 while pop

3. **误以为单次 ping 是 O(1)**
   - 单次最坏 O(N)（所有旧请求同时过期），均摊才是 O(1)
   - 面试时说清楚"均摊 O(1)"，不是"严格 O(1)"

## 面试追问

**Q1: 均摊 O(1) 怎么理解？**
→ 每个请求最多入队一次、出队一次。N 次 ping 总共最多 N 次 push + N 次 pop = O(N) 操作，均摊每次 O(1)。虽然某一次 ping 可能弹出很多元素（O(N) 最坏），但这些元素之后不会再被操作。

**Q2: 如果 ping 的时间不是严格递增怎么办？**
→ 如果允许时间无序，队列不再保证有序，不能只从队首弹出。需要用 multiset 或 sorted container，每次 ping(t) 后 erase 所有 < t-3000 的元素，单次 O(log N)。

**Q3: 如果需要支持"查询任意时间窗口内的请求数"怎么办？**
→ 用 sorted array + 二分查找。`count(l, r)` = `upper_bound(r) - lower_bound(l)`，O(log N) 每次查询。

**Q4: 这道题和 LC 239 Sliding Window Maximum 有什么关系？**
→ 都是"滑动窗口"题。本题窗口由时间范围定义，只需要计数，用普通队列。LC 239 窗口由数组下标定义，需要快速取最大值，用单调递减队列（deque）。
