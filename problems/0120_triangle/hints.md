# 120. 三角形最小路径和 (Triangle) - 提示与详解

## 题目理解

给定一个三角形数组 `triangle`，找出自顶向下的**最小路径和**。每一步只能移动到下一行中**相邻**的节点（即下标 i 或 i+1）。

**关键约束**：
- 1 <= triangle.length <= 200（最多 200 行）
- -10^4 <= triangle[i][j] <= 10^4（有负数！不能贪心）
- Follow-up: 能否用 O(n) 额外空间解决？

**示例**：
```
   2
  3 4
 6 5 7
4 1 8 3
最小路径: 2 -> 3 -> 5 -> 1 = 11
```

---

## 核心思路

这道题是**路径型 DP** 的经典代表。关键洞察是：

1. **不能贪心**：因为有负数，局部最小不代表全局最小
2. **自底向上 vs 自顶向下**：自底向上更优雅，因为不需要处理边界
3. **空间优化**：每层只依赖下一层，可以用一维数组滚动

**DP 方向选择的核心原则**：哪个方向的边界处理更简单，就用哪个方向。自底向上时，每个节点都有两个"孩子"（dp[j] 和 dp[j+1]），不需要判断越界。自顶向下时，j=0 和 j=i 只有一个"父亲"，必须特殊处理。

---

## 思维链：从暴力到最优

### Step 1: 暴力 DFS -- 枚举所有路径

从顶部出发，每一步走左或右，共 2^(n-1) 条路径。取所有路径和的最小值。

时间 O(2^n)，n=200 时不可行。

**关键观察**：很多路径共享前缀，存在大量重叠子问题。

### Step 2: 记忆化递归 -- 自顶向下

定义 `dfs(i, j)` = 从 (i, j) 出发到底部的最小路径和。

```
dfs(i, j) = triangle[i][j] + min(dfs(i+1, j), dfs(i+1, j+1))
```

用 memo[i][j] 缓存结果。时间 O(n^2)，空间 O(n^2)。

### Step 3: 自底向上迭代 DP

定义 `dp[i][j]` = 从 (i, j) 到底部的最小路径和。

**转移方程**：
```
dp[i][j] = triangle[i][j] + min(dp[i+1][j], dp[i+1][j+1])
```

**Base case**：最后一行 dp[n-1][j] = triangle[n-1][j]。

从倒数第二行向上计算，最终 dp[0][0] 就是答案。

### Step 4: 空间优化 -- 一维数组滚动

由于 dp[i] 只依赖 dp[i+1]，可以把二维数组压缩为一维。

关键技巧：**从左到右**遍历 j（因为 dp[j] 依赖旧的 dp[j] 和 dp[j+1]，从左到右时 dp[j+1] 还是旧值）。

```
dp[j] = triangle[i][j] + min(dp[j], dp[j+1])
```

时间 O(n^2)，空间 O(n)。

### Step 5: 原地修改（O(1) 额外空间）

如果允许修改输入，可以直接在 triangle 数组上做 DP，省去额外空间。但面试中通常不建议修改输入。

### Step 6: 自顶向下 DP 的对比

定义 `dp[i][j]` = 从顶部到 (i, j) 的最小路径和。

```
dp[i][j] = triangle[i][j] + min(dp[i-1][j-1], dp[i-1][j])
```

**边界麻烦**：j=0 时没有 dp[i-1][j-1]，j=i 时没有 dp[i-1][j]。需要特判。

答案 = min(dp[n-1][0..n-1])，还需要最后扫一遍。

相比之下，自底向上直接得到 dp[0]，无需额外处理。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 解法1: 自底向上一维DP ⭐ | O(n^2) | O(n) | 面试首选，无边界问题 |
| 解法2: 自顶向下一维DP | O(n^2) | O(n) | 需处理边界，最后扫min |
| 解法3: 原地修改 | O(n^2) | O(1) | 不推荐，修改了输入 |

---

## 关键提示

### 提示 1: 自底向上 vs 自顶向下
自底向上不需要处理边界条件（每个节点都有两个子节点），答案直接是 dp[0]。自顶向下需要特判 j=0 和 j=i，且答案需要扫描整个最后一行。

### 提示 2: 一维滚动时的遍历方向
自底向上做空间优化时，内层循环 j 从左到右遍历。因为 dp[j] 新值依赖旧的 dp[j] 和 dp[j+1]，从左到右时 dp[j+1] 尚未被覆盖。

### 提示 3: 初始化
一维 dp 数组初始化为三角形最后一行的值，然后从倒数第二行开始向上更新。

### 提示 4: 不能贪心
三角形中有负数。例如 [[1],[2,-3],[4,5,-6]]，贪心选 -3 会到达 5 或 -6，但最优路径可能是 1->2->4=7 或 1->-3->-6=-8。

## 解法详解

### 解法 1: 自底向上一维 DP（推荐）⭐

**完整代码**：
```cpp
class Solution {
public:
    int minimumTotal(vector<vector<int>>& triangle) {
        int n = triangle.size();
        vector<int> dp(triangle.back());  // 初始化为最后一行
        for (int i = n - 2; i >= 0; i--)
            for (int j = 0; j <= i; j++)
                dp[j] = triangle[i][j] + min(dp[j], dp[j + 1]);
        return dp[0];
    }
};
```

**思考过程**：
1. dp[j] 表示从当前行第 j 个位置到底部的最小路径和
2. 从最后一行开始（base case），逐层向上计算
3. 每个位置选择下方两个相邻位置中较小的那个
4. 最终 dp[0] 就是从顶到底的最小路径和

**DP 表模拟**（triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]）：

```
三角形:         DP表（自底向上）:
   2               [11]
  3 4             [9, 10]
 6 5 7          [7, 6, 10]
4 1 8 3        [4, 1,  8, 3]  <-- 初始化

详细推导:
初始 dp = [4, 1, 8, 3]

i=2 (第3行 [6,5,7]):
  j=0: dp[0] = 6 + min(4, 1) = 7
  j=1: dp[1] = 5 + min(1, 8) = 6
  j=2: dp[2] = 7 + min(8, 3) = 10
  dp = [7, 6, 10, 3]

i=1 (第2行 [3,4]):
  j=0: dp[0] = 3 + min(7, 6) = 9
  j=1: dp[1] = 4 + min(6, 10) = 10
  dp = [9, 10, 10, 3]

i=0 (第1行 [2]):
  j=0: dp[0] = 2 + min(9, 10) = 11
  dp = [11, 10, 10, 3]

答案: dp[0] = 11
路径: 2 -> 3 -> 5 -> 1
```

**空间优化原理**：
```
原始二维 DP:
  dp[i][j] = triangle[i][j] + min(dp[i+1][j], dp[i+1][j+1])

dp[i][j] 只依赖 dp[i+1] 这一行 -> 压缩为一维
从左到右更新: dp[j] 用到旧 dp[j] 和旧 dp[j+1]
  - dp[j] 被覆盖没关系，后续 j+1 不再需要旧 dp[j]
  - dp[j+1] 还是旧值，因为还没被更新到
```

**关键点**：
- `vector<int> dp(triangle.back())` 是 C++ 的拷贝构造，直接用最后一行初始化
- 内层 j 的范围是 [0, i]，恰好对应第 i 行有 i+1 个元素
- 不需要任何边界判断，代码极其简洁

### 解法 2: 自顶向下一维 DP

**完整代码**：
```cpp
class Solution {
public:
    int minimumTotal(vector<vector<int>>& triangle) {
        int n = triangle.size();
        vector<int> dp(n, INT_MAX);
        dp[0] = triangle[0][0];
        for (int i = 1; i < n; i++) {
            // 从右到左更新，避免覆盖问题
            for (int j = i; j >= 0; j--) {
                int left = (j > 0) ? dp[j - 1] : INT_MAX;
                int right = (j < i) ? dp[j] : INT_MAX;
                dp[j] = triangle[i][j] + min(left, right);
            }
        }
        return *min_element(dp.begin(), dp.begin() + n);
    }
};
```

**思考过程**：
1. dp[j] 表示从顶部到当前行第 j 个位置的最小路径和
2. 到达 (i, j) 可以从 (i-1, j-1) 或 (i-1, j) 转移来
3. 需要处理边界：j=0 只能从上方来，j=i 只能从左上方来
4. 从右到左更新，因为 dp[j] 的新值依赖旧的 dp[j-1] 和 dp[j]
5. 最终答案是最后一行的最小值

**关键点**：
- 自顶向下必须处理 j=0 和 j=i 的边界
- 需要额外 `min_element` 扫描最后一行
- 内层循环从右到左（否则 dp[j-1] 被覆盖）

---

### 解法 3: 原地修改（O(1) 额外空间）

**完整代码**：
```cpp
class Solution {
public:
    int minimumTotal(vector<vector<int>>& triangle) {
        for (int i = triangle.size() - 2; i >= 0; i--)
            for (int j = 0; j <= i; j++)
                triangle[i][j] += min(triangle[i+1][j], triangle[i+1][j+1]);
        return triangle[0][0];
    }
};
```

**思考过程**：
1. 直接在 triangle 上累加，不需要额外数组
2. O(1) 额外空间，但修改了输入数据
3. 面试中应先说明"如果允许修改输入"

**关键点**：
- 代码最短，但修改了输入是个缺点
- 在实际工程中，函数应该有"不修改输入"的保证

## 解法对比

| 维度 | 解法1: 自底向上 ⭐ | 解法2: 自顶向下 | 解法3: 原地修改 |
|------|------------------|----------------|----------------|
| 时间 | O(n^2) | O(n^2) | O(n^2) |
| 空间 | O(n) | O(n) | O(1) |
| 边界处理 | 无需 | 需判断 j=0, j=i | 无需 |
| 答案获取 | dp[0] 直接 | 需扫描最后一行 | triangle[0][0] |
| 修改输入 | 否 | 否 | 是 |
| 面试推荐 | **首选** | 可以提到 | 知道即可 |

**面试策略**：直接写自底向上一维 DP。如果被问到自顶向下，能分析其边界处理更复杂即可。

## 易错点

### Bug 1: 自顶向下遍历方向错误
```cpp
// 错误：从左到右更新，dp[j-1] 已被覆盖
for (int j = 0; j <= i; j++)
    dp[j] = triangle[i][j] + min(dp[j-1], dp[j]);

// 正确：从右到左更新
for (int j = i; j >= 0; j--)
    dp[j] = triangle[i][j] + min(dp[j-1], dp[j]);
```

### Bug 2: 自顶向下忘记边界判断
```cpp
// 错误：j=0 时 dp[j-1] 越界
dp[j] = triangle[i][j] + min(dp[j-1], dp[j]);

// 正确：加边界判断
int left = (j > 0) ? dp[j-1] : INT_MAX;
int right = (j < i) ? dp[j] : INT_MAX;
dp[j] = triangle[i][j] + min(left, right);
```

### Bug 3: dp 初始化错误
```cpp
// 错误：没有正确初始化
vector<int> dp(n, 0);  // 0 不是正确的初始值

// 正确：自底向上初始化为最后一行
vector<int> dp(triangle.back());
```

### Bug 4: 自顶向下忘记取最后一行最小值
```cpp
// 错误：直接返回 dp[0]
return dp[0];  // 自顶向下时 dp[0] 不是答案！

// 正确：扫描最后一行
return *min_element(dp.begin(), dp.begin() + n);
```

## 面试追问

### Q1: 为什么自底向上比自顶向下更好？
**A1**: 两个原因：(1) 自底向上无需处理边界条件，每个节点都有两个子节点可以取 min；(2) 答案直接是 dp[0]，不需要扫描最后一行。代码更简洁，更不容易出错。

### Q2: 如果要输出最小路径本身（而不只是和），怎么做？
**A2**: 额外维护一个 choice[i][j] 数组记录每步的选择方向（向下还是向右下）。DP 完成后从 (0,0) 沿 choice 回溯即可。这需要 O(n^2) 额外空间。

### Q3: 如果三角形非常大（百万行），空间优化到 O(n) 还不够怎么办？
**A3**: 可以考虑原地修改输入（O(1) 额外空间）。如果连输入都放不下，需要分块 I/O 或流式处理。但这种场景在实际中很少见，面试中答到 O(n) 通常就够了。
