# 664. 奇怪的打印机 (Strange Printer)

[Hard] | String, Dynamic Programming

## 题目理解

打印机有两个特殊性质:
1. 每次只能打印**一连串相同字符**
2. 每次打印可以选择任意起止位置，新打印会**覆盖**原有字符

给定字符串 s，求打印它所需的**最少打印次数**。

```
示例 1: s = "aaabbb" -> 2次 (先打 "aaa"，再打 "bbb")
示例 2: s = "aba"    -> 2次 (先打 "aaa"，再打 "b" 覆盖中间位置)
```

**约束**: `1 <= s.length <= 100`，仅小写字母

---

## 第一步：建立直觉 — 打印机如何工作

### 关键观察 1: 打印的覆盖性

打印机可以先打一个大范围，再用后续打印覆盖其中一部分。

```
目标: "aba"

方法1 (3次): 打 "a" 在位置0, 打 "b" 在位置1, 打 "a" 在位置2
方法2 (2次): 打 "aaa" 覆盖位置0-2, 打 "b" 覆盖位置1
             第一步: [a][a][a]
             第二步: [a][b][a]  -> 只用2次!
```

### 关键观察 2: 首尾相同时可以"捎带"

```
目标: "aba"
因为 s[0]='a' == s[2]='a'
可以在打印 s[0] 的时候顺便把 s[2] 也打了 (打一整段 "aaa")
然后只需要处理中间的部分 "b" => 问题规模缩小!

  dp("aba") = dp("b") + (s[0]和s[2]相同，不需要额外1次)
             = 1 + 1 = 2
```

### 关键观察 3: 相邻重复字符可以压缩

连续相同字符打印次数等于去重后的次数:
```
"aaabbb" -> 去重后 "ab" -> 2次
"aabbcc" -> 去重后 "abc" -> 3次 (但可能更少，需要看有无优化)
```

先去重是一个有效的预处理优化（减少 DP 状态数）。

---

## 第二步：区间 DP 状态定义

### 状态

```
dp[i][j] = 打印 s[i..j] 这个子串所需的最少打印次数
```

### Base Case

```
dp[i][i] = 1    (单个字符只需1次打印)
```

### 转移方程

**情况 1: s[i] 单独打印**

```
dp[i][j] = dp[i+1][j] + 1
```

s[i] 单独需要一次打印，然后处理 s[i+1..j]。

**情况 2: 利用 s[i] 的"捎带"效果**

如果 s[i] == s[m] (i < m <= j)，那么打印 s[i] 的时候可以顺便覆盖到 s[m]，
相当于 s[m] 不需要额外打印一次。

```
如果 s[i] == s[m]:
    dp[i][j] = min(dp[i][j], dp[i+1][m] + dp[m+1][j])
```

**为什么是 dp[i+1][m] 而不是 dp[i+1][m-1] + 1？**

这是理解本题**最核心**的地方:

```
当 s[i] == s[m] 时:
  - 我们打 s[i] 的时候，把打印范围延伸到 s[m] 的位置
  - s[i+1..m-1] 的内容会被后续打印覆盖
  - s[m] 已经被 s[i] 那次打印搞定了（值正确）

  对于区间 s[i+1..m]:
    - s[m] 的值已经正确（被 s[i] 的延伸覆盖）
    - 只需要把 s[i+1..m-1] 打印正确
    - 这恰好就是 dp[i+1][m] 的含义!

  关键洞察:
    dp[i+1][m] 中，s[m] 作为区间末尾，会在打印 s[i+1..m] 时"免费"获得
    因为 s[i] 的打印延伸到了 s[m]，s[m] 不需要额外一次
    这就等价于在 dp[i+1][m] 内部，s[m] 可以和其他相同字符合并
```

**特殊情况**: 当 s[i] == s[i+1] 时 (m = i+1):

```
dp[i][j] = min(dp[i][j], dp[i+1][i+1] + dp[i+2][j])
         = min(dp[i][j], 1 + dp[i+2][j])

但实际上 dp[i+1][j] + 0 更好，因为 s[i] 可以和 s[i+1] 的打印合并。
更精确地: 当 s[i]==s[i+1] 时，dp[i][j] = dp[i+1][j]（s[i]"搭便车"）
```

## 第三步：画 DP 表填充过程

### 示例 1: s = "aba" (n=3)

**初始化 (长度=1)**:
```
dp[0][0] = 1  (打印 "a")
dp[1][1] = 1  (打印 "b")
dp[2][2] = 1  (打印 "a")
```

**长度=2**:

```
dp[0][1]: s[0..1] = "ab"
  默认: dp[1][1] + 1 = 1 + 1 = 2  (s[0]='a' 单独一次)
  检查 s[0]='a' == s[m]?
    m=1: 'a' != 'b'  -> 无优化
  dp[0][1] = 2

dp[1][2]: s[1..2] = "ba"
  默认: dp[2][2] + 1 = 1 + 1 = 2
  检查 s[1]='b' == s[m]?
    m=2: 'b' != 'a'  -> 无优化
  dp[1][2] = 2
```

**长度=3**:

```
dp[0][2]: s[0..2] = "aba"
  默认: dp[1][2] + 1 = 2 + 1 = 3  (s[0]='a' 单独一次)
  检查 s[0]='a' == s[m]?
    m=1: 'a' != 'b'  -> 跳过
    m=2: 'a' == 'a'  -> 可以合并!
         dp[1][2] + dp[3][2]
         = 2 + 0  (dp[3][2] 是空区间，值为 0)
         = 2
  dp[0][2] = min(3, 2) = 2
```

**最终 DP 表**:
```
     j=0  j=1  j=2
i=0 [ 1    2    2 ]
i=1 [ -    1    2 ]
i=2 [ -    -    1 ]

答案 = dp[0][2] = 2
```

---

### 示例 2: s = "abab" (n=4)

**初始化**: dp[i][i]=1 (i=0,1,2,3)

**长度=2**:
```
dp[0][1] = "ab": 默认 dp[1][1]+1=2, s[0]='a'!=s[1]='b' -> 2
dp[1][2] = "ba": 默认 dp[2][2]+1=2, s[1]='b'!=s[2]='a' -> 2
dp[2][3] = "ab": 默认 dp[3][3]+1=2, s[2]='a'!=s[3]='b' -> 2
```

**长度=3**:
```
dp[0][2] = "aba":
  默认: dp[1][2]+1 = 3
  m=2: s[0]='a'==s[2]='a' -> dp[1][2]+dp[3][2] = 2+0 = 2
  dp[0][2] = 2

dp[1][3] = "bab":
  默认: dp[2][3]+1 = 3
  m=3: s[1]='b'==s[3]='b' -> dp[2][3]+dp[4][3] = 2+0 = 2
  dp[1][3] = 2
```

**长度=4**:
```
dp[0][3] = "abab":
  默认: dp[1][3]+1 = 2+1 = 3
  m=1: s[0]='a'!=s[1]='b' -> 跳过
  m=2: s[0]='a'==s[2]='a' -> dp[1][2]+dp[3][3] = 2+1 = 3
  m=3: s[0]='a'!=s[3]='b' -> 跳过
  dp[0][3] = min(3, 3) = 3
```

**最终 DP 表**:
```
     j=0  j=1  j=2  j=3
i=0 [ 1    2    2    3 ]
i=1 [ -    1    2    2 ]
i=2 [ -    -    1    2 ]
i=3 [ -    -    -    1 ]

答案 = dp[0][3] = 3
```

验证: "abab" -> 打 "aaaa", 覆盖 "b" 在位置1, 覆盖 "b" 在位置3 = 3次。

---

### 示例 3: s = "abcba" (n=5) — 回文结构

**初始化**: dp[i][i]=1 (i=0..4)

**长度=2**:
```
dp[0][1]="ab" -> 2,  dp[1][2]="bc" -> 2
dp[2][3]="cb" -> 2,  dp[3][4]="ba" -> 2
```

**长度=3**:
```
dp[0][2]="abc": 默认3, s[0]='a' 无匹配 -> 3
dp[1][3]="bcb": 默认3, s[1]='b'==s[3]='b' -> dp[2][3]+0 = 2
dp[2][4]="cba": 默认3, s[2]='c' 无匹配 -> 3
```

**长度=4**:
```
dp[0][3]="abcb": 默认 dp[1][3]+1=3
  m=3: s[0]='a'!=s[3]='b' -> 无优化 -> 3

dp[1][4]="bcba": 默认 dp[2][4]+1=4
  m=4: s[1]='b'!=s[4]='a' -> 跳过
  但 m=3: s[1]='b'!=s[3]='b'? 等等 s[3]='b'? 
  s="abcba", s[3]='b', s[1]='b' -> 匹配!
  dp[2][3]+dp[4][4] = 2+1 = 3
  dp[1][4] = min(4, 3) = 3
```

**长度=5**:
```
dp[0][4]="abcba": 默认 dp[1][4]+1=4
  m=4: s[0]='a'==s[4]='a' -> dp[1][4]+dp[5][4] = 3+0 = 3
  dp[0][4] = min(4, 3) = 3
```

**答案 = 3** (打 "aaaaa", 覆盖 "b" 在1和3, 覆盖 "c" 在2)

## 第四步：去重预处理优化

连续相同字符只需要保留一个:

```
"aaabbb"   -> "ab"   (从n=6缩到n=2)
"aabbccaa" -> "abca"  (从n=8缩到n=4)
```

为什么安全？因为连续相同字符可以在一次打印中一起搞定，不影响最优次数。
去重后 DP 的状态数从 O(n^2) 缩减到 O(m^2)，其中 m 是去重后长度。

---

## 第五步：遍历顺序 — 区间 DP 经典模式

区间 DP 必须按**区间长度从小到大**填充:

```
for (int len = 2; len <= n; len++) {        // 区间长度
    for (int i = 0; i + len - 1 < n; i++) { // 左端点
        int j = i + len - 1;                 // 右端点
        dp[i][j] = dp[i+1][j] + 1;          // 默认: s[i] 单独打
        for (int m = i+1; m <= j; m++) {     // 枚举匹配点
            if (s[i] == s[m]) {
                dp[i][j] = min(dp[i][j], dp[i+1][m] + (m+1<=j ? dp[m+1][j] : 0));
            }
        }
    }
}
```

**依赖分析**: dp[i][j] 依赖的所有子问题:
- dp[i+1][j]: 长度 = j - i，比当前 len 少 1
- dp[i+1][m]: 长度 = m - i，更短
- dp[m+1][j]: 长度 = j - m，更短

所有依赖区间长度都小于当前 len，从小到大填充保证依赖已就绪。

## 解法对比

| 解法 | 时间 | 空间 | 面试推荐 |
|------|------|------|----------|
| 区间DP (Bottom-up) | O(n^3) | O(n^2) | 首选 |
| 记忆化搜索 (Top-down) | O(n^3) | O(n^2) | 备选 (代码更直觉) |

n <= 100，O(n^3) = 10^6，完全可以通过。

## 易错点与面试要点

### 1. 转移方程的正确性

最容易写错的地方:

```
错误: dp[i][j] = min(dp[i][j], dp[i][m-1] + dp[m][j])  // 没有利用"捎带"
正确: dp[i][j] = min(dp[i][j], dp[i+1][m] + dp[m+1][j])  // s[i]和s[m]合并打印
```

### 2. 空区间的处理

当 m = j 时，dp[m+1][j] = dp[j+1][j]，这是空区间，值为 0。
代码中需要用 `(m+1 <= j ? dp[m+1][j] : 0)` 来处理。

### 3. 去重预处理

不去重也能 AC，但面试中提出去重优化是加分项:
```cpp
string t;
for (char c : s) {
    if (t.empty() || t.back() != c) t += c;
}
s = t;
```

### 4. 与 "Burst Balloons (312)" 的对比

| 特征 | 664 Strange Printer | 312 Burst Balloons |
|------|--------------------|--------------------|
| DP 类型 | 区间 DP | 区间 DP |
| 状态 | dp[i][j] = 最少打印次数 | dp[i][j] = 最大得分 |
| 转移关键 | 首字符匹配合并 | 最后戳破的气球 |
| 遍历 | 长度从小到大 | 长度从小到大 |

两题都是区间 DP 的经典代表，掌握一道有助于理解另一道。

### 5. 时间复杂度分析

- 外层: 枚举区间长度 O(n)
- 中层: 枚举左端点 O(n)
- 内层: 枚举匹配点 O(n)
- 总计: O(n^3)
