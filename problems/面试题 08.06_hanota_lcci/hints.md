# 面试题 08.06. 汉诺塔问题 (Hanota LCCI)

## 题目理解

经典汉诺塔问题：三根柱子 A、B、C 和 N 个不同大小的盘子。初始时所有盘子按从小到大的顺序从上到下叠放在柱子 A 上。目标是把所有盘子从 A 移到 C。

**三条规则**：
1. 每次只能移动一个盘子
2. 盘子只能从柱子顶部取出，放到另一根柱子顶部
3. 大盘子不能放在小盘子上面

**约束**：`A.length <= 14`

本题的核心是 **递归思维** —— 不要尝试追踪每一步的状态变化，而是相信递归会正确处理子问题。

---

## 递归树可视化 (n=3)

以 A=[2,1,0], B=[], C=[] 为例（数字越大表示盘子越大）：

```
                          hanota(3, A→C, buf=B)
                         "把3个盘从A移到C"
                        /          |          \
                       /           |           \
           hanota(2, A→B, buf=C)  move盘2:    hanota(2, B→C, buf=A)
           "2个盘从A到B"          A→C         "2个盘从B到C"
           /      |      \                    /      |      \
          /       |       \                  /       |       \
  hanota(1,     move盘1:  hanota(1,   hanota(1,    move盘1:  hanota(1,
  A→C,buf=B)   A→B       C→B,buf=A)  B→A,buf=C)   B→C       A→C,buf=B)
     |                       |           |                       |
  move盘0:                move盘0:    move盘0:                move盘0:
  A→C                     C→B         B→A                     A→C
```

**对应的 7 次移动序列（2^3 - 1 = 7 步）**：

```
步骤   操作         盘号   A状态       B状态       C状态
初始    —           —     [2,1,0]     []          []
 1     A→C         盘0    [2,1]       []          [0]
 2     A→B         盘1    [2]         [1]         [0]
 3     C→B         盘0    [2]         [1,0]       []
 4     A→C         盘2    []          [1,0]       [2]        ← 最大盘到位
 5     B→A         盘0    [0]         [1]         [2]
 6     B→C         盘1    [0]         []          [2,1]
 7     A→C         盘0    []          []          [2,1,0]    ← 完成!
```

**递归结构一目了然**：
- 步骤 1-3：把上面 2 个盘从 A 移到 B（子问题 n=2）
- 步骤 4：把最大盘直接从 A 移到 C
- 步骤 5-7：把 2 个盘从 B 移到 C（子问题 n=2）

---

## 核心思路：递归分治三步法

把 N 个盘子从 `src` 移到 `dst`（借助 `buf`）分解为三步：

```
move(n, src, buf, dst):
    if n == 0: return               // base case
    move(n-1, src, dst, buf)        // Step 1: n-1个盘 src→buf (dst做缓冲)
    将 src 顶端盘移到 dst            // Step 2: 最大盘 src→dst
    move(n-1, buf, src, dst)        // Step 3: n-1个盘 buf→dst (src做缓冲)
```

### 为什么这是正确的？

1. **Step 1 后**：最大盘暴露在 src 顶部，其余 n-1 个盘在 buf 上
2. **Step 2 可安全执行**：因为 dst 上没有任何比它小的盘子（dst 要么是空的，要么只有更大的盘子）
3. **Step 3 后**：所有 n-1 个盘从 buf 移到 dst，叠在最大盘上面，大小关系始终正确

### 参数角色切换 — 递归的精妙之处

注意在递归调用中，参数的"角色"发生了对调：

```
move(n,   src,  buf,  dst)     // 原始调用
move(n-1, src,  dst,  buf)     // 第一步: dst 变成了缓冲!
move(n-1, buf,  src,  dst)     // 第三步: src 变成了缓冲!
```

这是汉诺塔递归最容易出错的地方 —— 面试时一定要画出参数对应关系。

## 递归展开可视化 (n=2)

更小的例子帮助理解每层递归的参数角色切换：

```
hanota(2, A, B, C)                    // 把2个盘从A移到C, B做缓冲
├─ move(1, A, C, B)                   // 把1个盘从A移到B, C做缓冲
│   └─ 移动盘0: A→B                   // base case: n=1直接移动
├─ 移动盘1: A→C                       // 最大盘从A到C
└─ move(1, B, A, C)                   // 把1个盘从B移到C, A做缓冲
    └─ 移动盘0: B→C                   // base case: n=1直接移动

3步移动: A→B, A→C, B→C
```

---

## 思维链：面试中如何推导

### Step 1: 从最简单情况开始

**n=1**：直接移动。一步搞定。

**n=2**：
```
1. 小盘 A→B（腾出空间）
2. 大盘 A→C
3. 小盘 B→C
```

### Step 2: 发现递归结构

**n=3**：把上面 2 个盘看作一个整体——
```
1. "整体"从 A 到 B  → 这就是 n=2 的子问题!
2. 最大盘 A→C
3. "整体"从 B 到 C  → 又是 n=2 的子问题!
```

### Step 3: 抽象成递归

```
move(n, from, buf, to):
    if n == 0: return
    move(n-1, from, to, buf)     // from→buf, to做缓冲
    move top of from to to       // 移动最大盘
    move(n-1, buf, from, to)     // buf→to, from做缓冲
```

### Step 4: 翻译成代码

vector 的操作：
- "取出顶部"：`from.back()` + `from.pop_back()`
- "放到顶部"：`to.push_back(val)`
- 顺序不能反——必须先读取 back() 的值，再 pop_back()

### Step 5: 验证

- base case n=0：不做任何操作
- n=1：直接移动一次
- 每次递归 n 减 1，一定能到达 base case
- 总移动次数 T(n) = 2*T(n-1) + 1 = 2^n - 1

## 完整代码

```cpp
class Solution {
public:
    void hanota(vector<int>& A, vector<int>& B, vector<int>& C) {
        move(A.size(), A, B, C);
    }

private:
    // move: 把 n 个盘从 from 移到 to，buf 做缓冲
    void move(int n, vector<int>& from, vector<int>& buf, vector<int>& to) {
        if (n == 0) return;

        // Step 1: 上面 n-1 个盘从 from → buf (to 做缓冲)
        move(n - 1, from, to, buf);

        // Step 2: 最大盘从 from → to
        to.push_back(from.back());  // 先读值
        from.pop_back();             // 再删除

        // Step 3: n-1 个盘从 buf → to (from 做缓冲)
        move(n - 1, buf, from, to);
    }
};
```

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 备注 |
|------|------|------|------|------|
| 递归分治 | 三步法 | O(2^n) | O(n) 递归栈 | **唯一标准解法** |

- 时间 O(2^n) 是数学最优——不存在少于 2^n - 1 步的解法
- n = 14（题目上限）时，2^14 - 1 = 16383 次操作

## 关键提示序列

### 提示 1（方向性）
> 这是经典递归问题。如果你已经知道怎么移 n-1 个盘子，那移动 n 个盘子需要几步？

### 提示 2（分解）
> 三步：(1) n-1 个盘从 src 到 buf，(2) 最大盘从 src 到 dst，(3) n-1 个盘从 buf 到 dst。

### 提示 3（参数设计）
> 函数签名 `move(n, from, buffer, to)` —— 注意参数在递归调用时角色会互换。

### 提示 4（base case）
> n == 0 时直接 return。不要用 n == 1 —— n == 0 更简洁，且能正确处理空输入。

### 提示 5（实现细节）
> `to.push_back(from.back()); from.pop_back();` —— 顺序不能反，先读值再删除。

### 提示 6（移动次数）
> T(n) = 2*T(n-1) + 1 = 2^n - 1。这是最优解的数学证明下界。

## 易错点

| 错误 | 后果 | 修正 |
|------|------|------|
| 递归参数顺序搞混 | 盘子移到错误的柱子 | 画出角色切换: 第一次递归 dst↔buf |
| base case 用 n==1 | 空输入（n==0）时可能出错 | 用 n==0 |
| 先 pop_back 再 push_back | 值丢失 | 先 push_back(back())，再 pop_back |
| 试图追踪每一步状态 | 思路混乱 | 信任递归: 定义清楚函数语义即可 |

## 数学补充

### 移动次数递推证明

设 T(n) 为移动 n 个盘子所需的最少步数：

```
T(0) = 0
T(n) = T(n-1) + 1 + T(n-1) = 2 * T(n-1) + 1

展开:
T(n) = 2*T(n-1) + 1
     = 2*(2*T(n-2)+1) + 1 = 4*T(n-2) + 3
     = 4*(2*T(n-3)+1) + 3 = 8*T(n-3) + 7
     ...
     = 2^n * T(0) + (2^n - 1)
     = 2^n - 1
```

| n | 移动次数 2^n - 1 |
|---|-----------------|
| 1 | 1 |
| 2 | 3 |
| 3 | 7 |
| 4 | 15 |
| 5 | 31 |
| 10 | 1023 |
| 14 | 16383 |

### 为什么这是最优的？

归纳法证明：要移动最大的盘子，上面的 n-1 个盘子必须全部移走（至少 T(n-1) 步），然后移动最大盘（1 步），再把 n-1 个盘放回来（至少 T(n-1) 步）。所以 T(n) >= 2\*T(n-1) + 1，恰好等于我们递归解的步数。

## 递归思维的通用模板

```
1. 明确函数定义（语义是什么）
2. 确定 base case（最简单的情况）
3. 递归调用（问题规模必须缩小）
4. 合并/后处理
```

汉诺塔是递归教学的"Hello World"—— 掌握了它，就理解了递归的核心哲学：**定义清楚、信任递归、分解问题**。

## 面试追问

**Q1: 能否不用递归?**
> 有迭代规律。n 为奇数时循环 A<->C, A<->B, B<->C；n 为偶数时交换 B/C 角色。但实现复杂，面试中递归解法是标准答案。

**Q2: 4 柱的汉诺塔怎么解?**
> Frame-Stewart 算法：先把上面 k 个盘移到某柱(用4柱)，再用3柱经典方式移剩下 n-k 个，最后把 k 个移回。k 的最优选择使总步数最小。非经典考点。

**Q3: 移动次数是多少? 能否更少?**
> 2^n - 1 步。用递推 T(n) = 2*T(n-1) + 1 或数学归纳可证明这是下界，不可能更快。
