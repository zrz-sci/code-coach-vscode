# 129. 求根节点到叶节点数字之和

## 核心思路

每条根到叶子的路径构成一个十进制数字。核心操作是 **DFS 传递累积值**：每往下走一层，当前数字 `num = num * 10 + node->val`，到达叶子节点时把这个完整的数字累加到总和中。

## 思维链

1. **读完题第一反应** → 需要遍历所有从根到叶子的路径。树的路径遍历 = DFS（深度优先搜索），自然联想到递归。
2. **路径上的数字怎么形成？** → 从根节点 `4` 走到 `9` 走到 `5`，数字从 `4 → 49 → 495`。每次往下走一层就是"乘以10再加当前节点值"。
3. **什么时候收割结果？** → 到达叶子节点时（左右子节点都为空），当前 `num` 就是这条路径代表的完整数字。
4. **总和怎么算？** → 把所有叶子节点处收割的数字加起来。递归的返回值可以直接是"以当前节点为根的子树中所有路径数字之和"。
5. **能不能用 BFS？** → 可以，用队列存 `(节点, 当前数字)` 的 pair，层序遍历时同步更新数字。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| DFS 递归（传参） | 递归传递 num，叶子处收割 | O(n) | O(h) | ⭐ 必须写出 |
| DFS 迭代（栈） | 用显式栈模拟递归 | O(n) | O(h) | 追问迭代时写 |
| BFS（队列） | 队列存 (node, num) 对 | O(n) | O(n) | 追问 BFS 时写 |

## 关键提示

1. **"乘10加当前值"是核心公式**：`num = num * 10 + node->val`，它把路径上的数字逐步组合成完整的十进制数。
2. **叶子节点判定**：`!node->left && !node->right`，而不是 `!node`。空节点和叶子节点是不同概念。
3. **空节点处理**：如果 `node == nullptr`，返回 0（不贡献任何数字）。这是递归的 base case。
4. **不会溢出**：题目约束树的深度不超过 10，节点值 0~9，最大数字是 `9999999999`，大约 10^10，在 32 位 int 范围 (2^31 - 1 ≈ 2.1 * 10^9) 之外！但题目保证答案在 32 位 int 范围内，所以总和不会溢出。
5. **路径数 = 叶子节点数**：有多少个叶子节点就有多少条路径，每条路径贡献一个数字。

```
树的 ASCII 图:

示例1:         示例2:
    1               4
   / \             / \
  2   3           9   0
                 / \
                5   1

路径:           路径:
1->2 = 12       4->9->5 = 495
1->3 = 13       4->9->1 = 491
                4->0    = 40
                
总和:           总和:
12+13 = 25      495+491+40 = 1026
```

## 解法详解

### 解法1: DFS 递归（传参） — O(n) / O(h) ⭐ 面试首选

**思考过程**: 每条路径从根开始构建一个数字，DFS 时把"当前已构建的数字"作为参数传递下去。到叶子时返回该数字，非叶子时返回左右子树的数字之和。

```
DFS 执行过程 (示例2: root = [4,9,0,5,1]):

                    dfs(4, num=0)
                    num = 0*10+4 = 4
                   /              \
          dfs(9, num=4)        dfs(0, num=4)
          num = 4*10+9 = 49    num = 4*10+0 = 40
         /             \       叶子! 返回 40
   dfs(5, num=49)  dfs(1, num=49)
   num=49*10+5=495 num=49*10+1=491
   叶子! 返回 495  叶子! 返回 491

汇总:
dfs(9, 4) = 495 + 491 = 986
dfs(4, 0) = 986 + 40 = 1026 ✓
```

```cpp
class Solution {
public:
    int sumNumbers(TreeNode* root) {
        return dfs(root, 0);
    }
    
    int dfs(TreeNode* node, int num) {
        // base case: 空节点不贡献数字
        if (!node) return 0;
        
        // 当前数字 = 上层传下来的数字 * 10 + 当前节点值
        num = num * 10 + node->val;
        
        // 叶子节点：这条路径的数字构建完毕，返回它
        if (!node->left && !node->right) {
            return num;
        }
        
        // 非叶子节点：返回左右子树所有路径数字之和
        return dfs(node->left, num) + dfs(node->right, num);
    }
};
```

**关键点**:
- `num` 作为参数传递（而非全局变量或成员变量），不同路径之间互不干扰。左子树的 DFS 不会影响右子树的 `num` 值。
- 递归函数返回值的语义：以 `node` 为根的子树中，所有根到叶路径的数字之和。
- 空间复杂度 O(h)，h 是树的高度。最坏情况链状树 h = n，最优平衡树 h = log n。

---

### 解法2: DFS 迭代（显式栈） — O(n) / O(h)

**从解法1转化**: 把递归改成迭代，用栈存 `(节点, 当前数字)` 对。

```
栈模拟过程 (示例1: root = [1,2,3]):

初始: stack = [(1, 1)], sum = 0

弹出 (1, 1):
  不是叶子，压入:
  右子 (3, 1*10+3=13)
  左子 (2, 1*10+2=12)
  stack = [(3,13), (2,12)]

弹出 (2, 12):
  是叶子! sum += 12 → sum = 12
  stack = [(3,13)]

弹出 (3, 13):
  是叶子! sum += 13 → sum = 25
  stack = []

返回 25 ✓
```

```cpp
class Solution {
public:
    int sumNumbers(TreeNode* root) {
        if (!root) return 0;
        
        int sum = 0;
        // 栈存储 (节点指针, 当前累积数字)
        stack<pair<TreeNode*, int>> stk;
        stk.push({root, root->val});
        
        while (!stk.empty()) {
            auto [node, num] = stk.top();
            stk.pop();
            
            // 叶子节点：收割数字
            if (!node->left && !node->right) {
                sum += num;
                continue;
            }
            
            // 非叶子：子节点入栈（先右后左，保证左子树先处理）
            if (node->right) {
                stk.push({node->right, num * 10 + node->right->val});
            }
            if (node->left) {
                stk.push({node->left, num * 10 + node->left->val});
            }
        }
        
        return sum;
    }
};
```

**关键点**:
- 初始入栈时 `num = root->val`（不是 0），因为根节点的值已经是路径的一部分。
- 子节点入栈时计算好了 `num * 10 + child->val`，而不是等弹出时计算。这样弹出时 `num` 已经是"到达该节点时的完整数字"。
- 先压右后压左，保证左子树先被处理（模拟前序遍历的顺序），但对本题来说顺序无所谓。

---

### 解法3: BFS（队列） — O(n) / O(n)

**不同视角**: 用层序遍历，队列中存 `(节点, 当前数字)` 对。

```cpp
class Solution {
public:
    int sumNumbers(TreeNode* root) {
        if (!root) return 0;
        
        int sum = 0;
        queue<pair<TreeNode*, int>> q;
        q.push({root, root->val});
        
        while (!q.empty()) {
            auto [node, num] = q.front();
            q.pop();
            
            // 叶子节点：收割
            if (!node->left && !node->right) {
                sum += num;
                continue;
            }
            
            // 子节点入队
            if (node->left) {
                q.push({node->left, num * 10 + node->left->val});
            }
            if (node->right) {
                q.push({node->right, num * 10 + node->right->val});
            }
        }
        
        return sum;
    }
};
```

**关键点**:
- 代码结构和解法2几乎一样，只是把 `stack` 换成 `queue`。
- 空间 O(n) 最坏情况（最后一层有 n/2 个节点）。
- BFS 的优势在某些需要"最短路径"的场景，但本题无此需求，DFS 递归最简洁。

## 解法对比

|  | DFS 递归 | DFS 迭代 | BFS |
|--|---------|---------|-----|
| 时间 | O(n) | O(n) | O(n) |
| 空间 | O(h) | O(h) | O(n) |
| 代码量 | **最少** | 中等 | 中等 |
| 理解难度 | 最直观 | 稍复杂 | 直观 |

**面试选择**: DFS 递归（解法1）是标准答案，代码最简洁。面试官追问"迭代怎么写？"时给解法2或3。

## 易错点

1. **空节点 vs 叶子节点混淆**：
   - ✗ 在 `!node` 时返回 `num` → 空节点会错误地贡献数字
   - ✓ 在 `!node` 时返回 0，在 `!node->left && !node->right` 时返回 `num`

2. **num 计算时机错误**：
   - ✗ 先递归再计算 `num = num * 10 + node->val` → 数字少一位
   - ✓ 进入节点时立即计算 `num`，再判断是否叶子、再递归

3. **迭代版初始值错误**：
   - ✗ `stk.push({root, 0})` 然后弹出时 `num = num * 10 + node->val` → 正确但容易搞混
   - ✓ `stk.push({root, root->val})` 然后子节点入栈时 `num * 10 + child->val` → 语义更清晰

4. **只有一个子节点的情况**：
   - ✗ 把只有右子节点的节点当作叶子 → 遗漏了右子树的路径
   - ✓ 叶子判断必须是 `!left && !right`，只有一侧为空不算叶子

5. **把 `dfs(node->left, num) + dfs(node->right, num)` 写成 `dfs(node->left, num) + dfs(node->right, num + ...)`**：
   - ✗ 把左子树返回值和右子树参数搞混
   - ✓ `num` 在当前层已经算好了，左右子树共享同一个 `num`

## 面试追问

**Q1: 能不能用迭代实现？**
> 可以，用栈（DFS迭代）或队列（BFS）。栈/队列中存 `pair<TreeNode*, int>`，第二个元素是到达该节点时的累积数字。叶子节点处累加到 `sum`。

**Q2: 如果节点值是 0~1（二进制路径），怎么改？**
> 把 `num * 10 + node->val` 改成 `num * 2 + node->val`。这就是 LeetCode 1022 的题目。核心框架完全不变，只是"进位制"从十进制变成二进制。

**Q3: 如果路径数字可能非常大（超过 int 范围），怎么处理？**
> 两个方向：1) 用 `long long` 存储（64位）。2) 如果连 `long long` 也不够，用字符串模拟大数加法。但本题约束深度 <= 10，最大数字 10^10，实际总和保证在 int 范围内。

**Q4: 如果不止是根到叶子，还要求所有根到任意节点的路径数字之和呢？**
> 去掉叶子节点的判断，每个节点都累加 `num`。递归函数改为：`return num + dfs(node->left, num) + dfs(node->right, num)`。

**Q5: 如果要返回具体是哪条路径构成了最大/最小的数字呢？**
> DFS 时额外维护一个 `vector<int> path`，进入节点时 push，回溯时 pop。在叶子节点处比较当前 `num` 是否是最大/最小，如果是就保存当前 `path` 的拷贝。
