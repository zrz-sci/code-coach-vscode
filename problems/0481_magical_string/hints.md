# 481. 神奇字符串

## 核心思路
利用神奇字符串的自描述性质，用双指针模拟生成：一个指针读取当前组的长度，一个指针追加新字符，1和2交替出现。

## 思维链
1. **理解自描述**: 字符串 s = "1221121221..."，分组后每组长度序列恰好是 s 本身
2. **初始种子**: 已知 s 的前 3 个字符是 "122"，这对应前 3 组：{1}, {22}, {11}
3. **双指针模拟**: 读指针 i 指向 s[i]（当前组长度），写指针在末尾追加字符
4. **交替规则**: 每组的字符在 1 和 2 之间交替，用 num = 3 - num 切换
5. **生成到 n**: 持续生成直到长度 >= n，最后统计前 n 个字符中 1 的个数

## 解法概览

| 方法 | 时间 | 空间 | 适用场景 | 推荐 |
|------|------|------|----------|------|
| 双指针模拟生成 | O(n) | O(n) | 通用最优解 | ⭐ |
| 队列模拟 | O(n) | O(n) | 等价实现 | |

## 关键提示
1. 初始化 s = {1, 2, 2}，读指针 i = 2 开始（因为前 3 个字符已确定）
2. 当前要添加的字符与 s 中最后一组相反：用 num = 3 - num 切换 1 和 2
3. s[i] 决定当前组添加几个字符（1 个或 2 个）
4. 可能生成超过 n 个字符，但最后只统计前 n 个
5. n <= 3 时直接返回 1（"122" 中只有一个 1，但前 1/2/3 个字符中 1 的个数都是 1）

## 解法详解

### 解法1: 双指针模拟生成 ⭐

**思路**: 利用神奇字符串的自描述性质，读指针告诉我们当前组有多长，写指针追加对应字符。

**模拟过程**:
```
初始: s = [1, 2, 2], i = 2, num = 1
i=2: s[2]=2, 追加 2 个 1 → s = [1,2,2,1,1], num=2
i=3: s[3]=1, 追加 1 个 2 → s = [1,2,2,1,1,2], num=1
i=4: s[4]=1, 追加 1 个 1 → s = [1,2,2,1,1,2,1], num=2
...
```

```cpp
class Solution {
public:
    int magicalString(int n) {
        if (n == 0) return 0;
        if (n <= 3) return 1;
        
        vector<int> s = {1, 2, 2};
        int i = 2;       // 读指针：指向当前组的长度
        int num = 1;     // 下一组要写的字符（1 和 2 交替）
        
        while ((int)s.size() < n) {
            int groupLen = s[i];          // 当前组的长度
            for (int j = 0; j < groupLen; ++j) {
                s.push_back(num);
            }
            num = 3 - num;                // 切换 1 <-> 2
            ++i;
        }
        
        // 统计前 n 个字符中 1 的个数
        int count = 0;
        for (int j = 0; j < n; ++j) {
            if (s[j] == 1) count++;
        }
        return count;
    }
};
```

### 解法2: 使用 string 模拟

**思路**: 与解法1 相同，但使用 string 类型代替 vector，代码更简洁。

```cpp
class Solution {
public:
    int magicalString(int n) {
        if (n == 0) return 0;
        if (n <= 3) return 1;
        
        string s = "122";
        int i = 2;
        char ch = '1';
        
        while ((int)s.size() < n) {
            int groupLen = s[i] - '0';
            s.append(groupLen, ch);
            ch = (ch == '1') ? '2' : '1';
            ++i;
        }
        
        int count = 0;
        for (int j = 0; j < n; ++j) {
            if (s[j] == '1') count++;
        }
        return count;
    }
};
```

## 易错点
- ✗ 读指针 i 从 0 开始，导致重复生成已有字符 → ✓ 从 i=2 开始，因为 "122" 已确定
- ✗ 交替字符的逻辑写错，始终追加 1 或始终追加 2 → ✓ 每次追加一组后用 num = 3 - num 切换
- ✗ 生成完后统计整个数组的 1 的个数，没有截断到前 n 个 → ✓ 只统计 s[0..n-1] 中的 1
- ✗ 没有处理 n=0 或 n<=3 的边界情况 → ✓ 提前返回

## 面试追问
- **Q1**: 这个字符串为什么叫"神奇"？ → 它是自描述的(self-describing)：分组长度序列就是字符串本身
- **Q2**: 前 n 个字符中 1 和 2 的比例趋近于多少？ → 趋近于 1:1，即 1 的比例约 50%
- **Q3**: 能否不存储整个字符串，用 O(1) 空间？ → 不行，因为读指针需要访问之前生成的字符来决定组长度
