# 812. Largest Triangle Area - 提示与解析

## 核心思路

本题要求在给定的二维平面点集中，找出三个不同点构成的最大三角形面积。由于点的数量最多只有50个，暴力枚举所有三元组是完全可行的。计算三角形面积的关键公式是**向量叉积法（Shoelace Formula）**：给定三点 (x1,y1), (x2,y2), (x3,y3)，面积 = 0.5 * |x1*(y2-y3) + x2*(y3-y1) + x3*(y1-y2)|。这个公式的本质是利用两个向量的叉积来计算平行四边形面积，再除以2得到三角形面积。

## 思维链

1. **理解问题**：从 n 个点中选3个点，求能构成的最大三角形面积
2. **分析规模**：n <= 50，三元组数量 C(50,3) = 19600，完全可以暴力
3. **选择公式**：向量叉积法（Shoelace Formula）直接通过坐标计算面积，无需求边长再用海伦公式
4. **实现策略**：三重循环枚举所有三元组，对每组计算面积，维护最大值
5. **注意取绝对值**：叉积可能为负（取决于点的顺序），必须取绝对值
6. **进阶思考**：如果点数极大（比如10^5），可以用凸包优化，因为最大三角形的三个顶点一定在凸包上

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|-----------|-----------|---------|
| 暴力枚举 | O(n^3) | O(1) | n <= 50，本题最优 |
| 凸包 + 旋转卡壳 | O(n^2) after O(n log n) | O(n) | n 极大时 |

## 关键提示

1. **Shoelace Formula**：面积 = 0.5 * |x1*(y2-y3) + x2*(y3-y1) + x3*(y1-y2)|，这是最简洁高效的三角形面积公式
2. **为什么不用海伦公式**：海伦公式需要先算三条边长（涉及开方），再代入公式，精度和效率都不如叉积法
3. **退化情况**：三点共线时面积为0，公式自动处理，无需特判
4. **绝对值不可忘**：叉积的符号取决于向量方向，必须取abs
5. **返回类型**：double，注意精度要求 10^-5

## 解法详解

### 解法一：暴力枚举（推荐）

**思路**：三重循环遍历所有可能的三点组合，用叉积公式计算面积，取最大值。

```
遍历 i = 0 to n-3:
  遍历 j = i+1 to n-2:
    遍历 k = j+1 to n-1:
      area = 0.5 * |points[i][0] * (points[j][1] - points[k][1])
                   + points[j][0] * (points[k][1] - points[i][1])
                   + points[k][0] * (points[i][1] - points[j][1])|
      maxArea = max(maxArea, area)
返回 maxArea
```

**为什么叉积公式成立**：
- 向量 AB = (x2-x1, y2-y1)，向量 AC = (x3-x1, y3-y1)
- 叉积 = (x2-x1)*(y3-y1) - (x3-x1)*(y2-y1)
- 展开后等价于 x1*(y2-y3) + x2*(y3-y1) + x3*(y1-y2)
- 这个值的绝对值是平行四边形面积，除以2就是三角形面积

### 解法二：凸包优化（面试拓展）

**思路**：最大面积三角形的三个顶点一定在凸包上。先求凸包（Andrew算法 O(n log n)），再只在凸包顶点上枚举。如果凸包顶点数为 h，时间从 O(n^3) 降为 O(h^3)（最坏仍是 O(n^3) 但通常 h << n）。更进一步可以用旋转卡壳将枚举优化到 O(h^2)。

## 易错点

1. **忘记取绝对值**：叉积可以为负数，不取绝对值会导致结果错误或漏掉正确答案
2. **整数溢出**：虽然本题坐标范围 [-50, 50]不会溢出，但养成用 double 或 long long 计算中间结果的习惯
3. **循环边界**：三重循环应该是 i < j < k，避免重复计算和自身比较
4. **精度问题**：虽然输入是整数坐标，但面积可能是 0.5 的倍数（非整数），必须用浮点数返回
5. **三点共线**：不需要特判，叉积为0时面积自然为0

## 面试追问

1. **Q: 如果点的数量是 10^5 级别怎么办？**
   A: 先求凸包（Andrew算法 O(n log n)），最大三角形的三点必在凸包上。凸包点数通常远小于 n，然后在凸包上用旋转卡壳 O(h^2) 枚举。

2. **Q: 除了叉积法和海伦公式，还有什么方法算三角形面积？**
   A: 行列式法（本质与叉积相同），坐标差积法，以及将三角形投影分解的方法。实际上叉积法和行列式法是最推荐的。

3. **Q: 如何扩展到求最大的 k 边形面积？**
   A: 同样利用凸包。对于凸多边形，可以用旋转卡壳的推广。但随着 k 增大，问题的复杂度会迅速增加。

4. **Q: 如果要求面积最小的非退化三角形呢？**
   A: 仍然暴力枚举所有三元组，但需排除面积为0的情况（共线），取最小正面积。
