# 654. 最大二叉树

## 核心思路

本题本质上是一个**分治**问题：在数组中找最大值作为根，然后递归地对左半段和右半段分别构建子树。这个过程和**快速排序的 partition** 思想非常类似——每次选一个"枢纽"把数组分成两部分。

## 思维链

1. **读完题第一反应**：题目已经把算法告诉你了——找最大值、分左右、递归构建。直接翻译成代码就是暴力递归解法。
2. **暴力解的瓶颈在哪？** 每一层递归都要遍历子数组找最大值，最坏情况（数组递减）每层只切掉一个元素，总共 O(n²)。
3. **能否优化找最大值？** 如果用线段树/稀疏表预处理 RMQ（区间最大值查询），可以 O(1) 找到任意区间的最大值，但建树需要 O(n log n)。不过此题 n≤1000，暴力完全够用。
4. **有没有完全不同的思路？** 观察构建过程：从左到右扫描数组，每个新元素要么成为之前某个节点的右子树，要么把之前某些节点"抢"过来作为自己的左子树。这个过程可以用**单调递减栈**一次扫描完成，O(n)！
5. **单调栈的核心直觉**：栈中维护一条从根到最右节点的路径（值递减）。新元素比栈顶小则成为栈顶的右孩子，比栈顶大则弹出栈顶作为自己的左孩子。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 分治递归 | 找最大值→分左右→递归 | O(n²) 最坏, O(n log n) 平均 | O(n) | ⭐ 必须写出 |
| 单调递减栈 | 从左到右扫描，用栈维护右链 | O(n) | O(n) | 加分项 |

## 解法详解

### 解法1: 分治递归 — O(n²) / O(n) ⭐ 面试首选

**思考过程**：题目本身就给了递归定义，直接翻译即可。每次在 `[left, right)` 区间找最大值的索引 `maxIdx`，创建节点，然后递归构建 `[left, maxIdx)` 和 `[maxIdx+1, right)`。

```
// 构建过程 (nums = [3,2,1,6,0,5]):
//
// build([3,2,1,6,0,5]) → max=6(idx=3)
//       根: 6
//      /         \
// build([3,2,1])  build([0,5])
//   max=3(idx=0)   max=5(idx=1)
//   根: 3           根: 5
//    \              /
// build([2,1])  build([0])
//   max=2          根: 0
//   根: 2
//    \
// build([1])
//   根: 1
//
// 最终结果:
//         6
//        / \
//       3   5
//        \ /
//        2 0
//         \
//          1
```

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    TreeNode* constructMaximumBinaryTree(vector<int>& nums) {
        return build(nums, 0, nums.size());
    }
    
    // 在 nums[left..right) 上构建最大二叉树
    TreeNode* build(vector<int>& nums, int left, int right) {
        if (left >= right) return nullptr;  // 空区间，返回空节点
        
        // 找区间内最大值的索引
        int maxIdx = left;
        for (int i = left + 1; i < right; i++) {
            if (nums[i] > nums[maxIdx]) maxIdx = i;
        }
        
        // 最大值作为根，左右分别递归
        TreeNode* root = new TreeNode(nums[maxIdx]);
        root->left = build(nums, left, maxIdx);       // 最大值左边
        root->right = build(nums, maxIdx + 1, right);  // 最大值右边
        return root;
    }
};
```

**关键点**：
- 用 `[left, right)` 左闭右开区间，避免边界混乱
- 最坏情况是数组有序（递增或递减），每次只切掉一个元素，退化为 O(n²)
- 平均情况类似快排，O(n log n)

### 解法2: 单调递减栈 — O(n) / O(n)

**从解法1优化**：解法1的瓶颈是每层递归都要 O(n) 扫描找最大值。单调栈解法换了一个视角——不是"自顶向下分治"，而是"从左到右逐个插入"，用栈维护从根到最右叶子的路径。

**核心规则**：
- 栈中元素**值递减**（父节点 > 子节点）
- 新元素 `nums[i]` 来了：
  - 比栈顶**小**：成为栈顶节点的**右孩子**（在数组中它在栈顶右边，且更小）
  - 比栈顶**大**：不断弹出，**最后弹出的**成为新元素的**左孩子**（这些元素在数组中在新元素左边，且更小）

```cpp
class Solution {
public:
    TreeNode* constructMaximumBinaryTree(vector<int>& nums) {
        // 栈中维护从根到最右节点的路径，值递减
        vector<TreeNode*> stk;
        
        for (int num : nums) {
            TreeNode* node = new TreeNode(num);
            TreeNode* lastPopped = nullptr;
            
            // 弹出所有比当前值小的节点
            // 最后弹出的那个成为当前节点的左孩子
            while (!stk.empty() && stk.back()->val < num) {
                lastPopped = stk.back();
                stk.pop_back();
            }
            node->left = lastPopped;  // 左边比它小的最大值做左孩子
            
            // 如果栈非空，当前节点成为栈顶的右孩子
            if (!stk.empty()) {
                stk.back()->right = node;
            }
            
            stk.push_back(node);
        }
        
        // 栈底就是根节点（最大值）
        return stk.front();
    }
};
```

**为什么正确？**
- 栈中始终维护一条"右链"（从根一路向右走的路径）
- 当新元素比栈顶大时，栈顶在新元素左边且更小，所以是新元素的左子树
- 当新元素比栈顶小时，新元素在栈顶右边且更小，所以是栈顶的右孩子
- 每个元素入栈一次、出栈一次，总时间 O(n)

## 解法对比

| | 分治递归 | 单调递减栈 |
|------|------|------|
| **时间** | O(n²) 最坏 / O(n log n) 平均 | O(n) |
| **空间** | O(n) 递归栈 | O(n) 栈空间 |
| **思路** | 自顶向下：先找根再递归 | 从左到右：逐个插入维护结构 |
| **代码复杂度** | 简单直观 | 需要理解单调栈 |
| **面试推荐** | ⭐ 首选，直接翻译题意 | 追问时展示 |

## 易错点

1. **区间边界混淆**
   - ✗ `build(nums, left, maxIdx - 1)` — 如果用闭区间 `[left, right]`，空区间判断是 `left > right` 而不是 `left >= right`
   - ✓ 统一用左闭右开 `[left, right)`，空区间条件 `left >= right`，简单不易错

2. **单调栈的左孩子赋值错误**
   - ✗ 每次弹出都 `node->left = popped`（覆盖了之前的赋值，但其实这样恰好是对的，因为最后弹出的才是直接左孩子）
   - ✓ 可以用 `lastPopped` 只记录最后弹出的那个，也可以直接每次覆盖——两者等价，但用 `lastPopped` 语义更清晰

3. **单调栈忘记处理栈非空时的右孩子关系**
   - ✗ 只处理了弹出（左孩子），忘了 `stk.back()->right = node`
   - ✓ 弹出完成后，如果栈还有元素，当前节点一定是栈顶的右孩子

4. **递归解法中 maxIdx 初始化错误**
   - ✗ `int maxIdx = 0;` — 应该从 `left` 开始，不是 0
   - ✓ `int maxIdx = left;`

## 面试追问

**Q1（基础理解）**：这道题的时间复杂度是多少？什么情况下最坏？
> 分治解法最坏 O(n²)，当数组递增或递减时，每次只切掉一个元素（类似快排最坏情况）。平均 O(n log n)。

**Q2（优化）**：能否做到 O(n)？
> 用单调递减栈。从左到右扫描，栈中维护从根到最右叶的路径。每个元素入栈出栈各一次，总 O(n)。

**Q3（变体 — LeetCode 998）**：如果已经有一棵最大二叉树，现在在数组末尾追加一个新元素，怎么更新树？
> 新元素在所有现有元素的右边，所以它只可能出现在根到最右叶的路径上。从根开始沿右链走，找到第一个比新元素小的节点，新元素插入到那个位置（那个节点变成新元素的左孩子）。这正是单调栈解法中"处理一个新元素"的逻辑。

**Q4（深入思考）**：这棵树和"笛卡尔树"有什么关系？
> 最大二叉树就是数组的**笛卡尔树**（Cartesian Tree）。笛卡尔树满足：①堆性质（父 > 子）②BST 的中序遍历等于原数组顺序。单调栈 O(n) 建树就是经典的笛卡尔树构建算法。
