# 839. Similar String Groups - 提示与解析

## 核心思路

本题要求将字符串数组按"相似性"分组，两个字符串相似当且仅当它们相同或恰好交换两个位置可以从一个变成另一个。相似性具有传递性，因此问题转化为求**连通分量数目**。使用**并查集（Union-Find）**或**DFS/BFS**遍历图，其中每对相似的字符串之间有一条边。判断两个字符串是否相似只需比较不同位置的数量：恰好为0（相同）或2（可交换）。

## 思维链

1. **理解相似性**：两个字符串相似 = 不同位置数为0或2
2. **传递性**：如果A~B且B~C，则A和C在同一组（即使A和C不直接相似）
3. **建模为图**：每个字符串是节点，相似的字符串之间连边
4. **求连通分量**：用并查集或DFS/BFS统计连通分量数
5. **复杂度分析**：N个字符串，每个长度M，比较一对O(M)，总共O(N^2 * M)
6. **优化考量**：当M很大时，可以考虑枚举交换位置（O(M^2)对）而非枚举字符串对（O(N^2)对）

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 推荐度 | 说明 |
|------|-----------|-----------|--------|------|
| 并查集 | O(N^2 * M) | O(N) | ⭐⭐⭐⭐⭐ | 两两比较 + Union-Find |
| DFS/BFS | O(N^2 * M) | O(N^2) | ⭐⭐⭐⭐ | 建图 + 遍历求连通分量 |
| 优化：枚举交换 | O(N * M^2) | O(N * M) | ⭐⭐⭐⭐ | 当N >> M时更优 |

## 关键提示

1. **相似判断优化**：比较两个字符串时，一旦发现超过2个不同位置立即返回false
2. **N和M的权衡**：N最大300，M最大300。N^2*M = 2.7*10^7，可接受
3. **所有字符串互为anagram**：题目保证，所以不同位置数一定是偶数
4. **并查集的路径压缩和按秩合并**：确保近乎O(1)的union/find操作
5. **去重**：可能存在重复字符串，需要正确处理

## 解法详解

### 解法一：并查集 ⭐⭐⭐⭐⭐

**步骤：**
1. 初始化并查集，每个字符串一个独立集合
2. 对所有字符串对 (i, j)，检查 strs[i] 和 strs[j] 是否相似
3. 如果相似，执行 `union(i, j)`
4. 最终统计不同的根节点数，即为分组数

**相似性检查函数：**
```
isSimilar(s1, s2):
    diff_count = 0
    for each position:
        if s1[pos] != s2[pos]:
            diff_count++
            if diff_count > 2: return false
    return diff_count == 0 || diff_count == 2
```

### 解法二：DFS/BFS ⭐⭐⭐⭐

先建立邻接表（对每对相似字符串连边），然后用DFS/BFS遍历图，统计连通分量数。空间上需要额外的邻接表存储。

### 解法三：枚举交换位置 ⭐⭐⭐⭐

当字符串长度M远小于N时，可以对每个字符串枚举所有 C(M,2) 种交换，检查结果是否在字符串集合中。用哈希表存储所有字符串来实现O(M)的查找。

## 易错点

1. **相同字符串也是相似的**：diff_count == 0 的情况不要漏掉
2. **提前终止比较**：diff_count > 2 时立即返回，否则大量无用比较
3. **并查集初始化**：parent[i] = i，初始每个节点自成一组
4. **统计连通分量数**：不要数union的次数，要数最终不同的根节点数
5. **重复字符串**：如果有重复的字符串，它们一定在同一组（因为相同=相似）
6. **字符串长度**：题目保证所有字符串等长，但代码中仍应使用实际长度

## 面试追问

1. **如果允许交换最多k个位置呢？** - 相似判断改为diff_count <= 2k，但传递性可能不再简单成立
2. **如果字符串长度不同怎么办？** - 不同长度的字符串一定不相似，可以先按长度分组
3. **如何优化当N很大但M很小的情况？** - 枚举所有C(M,2)种交换 + 哈希查找
4. **并查集和DFS各有什么优劣？** - 并查集空间更优且支持在线查询，DFS代码更直观
5. **如果要输出每个分组的成员？** - 并查集find后用map<root, vector<string>>收集
6. **能否并行化这个算法？** - 相似性检查可以并行，但并查集的合并需要同步
