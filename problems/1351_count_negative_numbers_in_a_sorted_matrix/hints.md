# 1351. 统计有序矩阵中的负数

## 核心思路

给定一个 `m x n` 矩阵，每行和每列都按**非递增顺序**排列（从左到右递减，从上到下递减）。统计矩阵中负数的个数。

关键信息：**行和列都是有序的**，这意味着我们不需要检查每一个元素，可以利用有序性来跳过大量不必要的比较。

## 思维链

1. **读完题第一反应** → 遍历整个矩阵，对每个元素判断是否 < 0，计数。O(m*n)，绝对能过，但没用到"有序"这个条件。
2. **有序能给我什么？** → 每一行是非递增的，说明负数一定在行的右侧部分。对每行做二分查找，找到第一个负数的位置，那么这个位置到行尾都是负数。
3. **只用行有序够了吗？** → 够了，每行二分 O(log n)，总 O(m log n)。但列也有序——能不能也利用起来？
4. **行列双有序怎么利用？** → 这就是经典的"阶梯形"思路：从矩阵的**右上角**或**左下角**出发，利用行列两个方向的有序性，像走阶梯一样一次消去一行或一列。这能做到 O(m + n)。
5. **为什么叫"阶梯形"？** → 如果你在矩阵里画一条分界线，分开"非负"和"负数"区域，这条线恰好是一个阶梯形状（单调不增）。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力遍历 | 遍历每个元素计数 | O(m*n) | O(1) | 能说出即可 |
| 每行二分查找 | 每行找第一个负数位置 | O(m log n) | O(1) | 不错的解法 |
| 阶梯形（右上角出发） | 利用行列双有序 | O(m + n) | O(1) | 最优解 |

## 关键提示

1. **矩阵的排序方向**：题目说"非递增"，即 `grid[i][j] >= grid[i][j+1]` 且 `grid[i][j] >= grid[i+1][j]`。所以**右下角最小，左上角最大**。
2. **二分查找目标**：每行找"第一个 < 0 的位置"。如果这个位置是 `pos`，那么该行的负数个数就是 `n - pos`。
3. **阶梯形的核心观察**：从右上角 `(0, n-1)` 出发：
   - 如果当前值 < 0，说明这一列从当前行到最后一行都 <= 当前值（列非递增），全是负数，加上 `m - row` 个，然后**左移** `col--`。
   - 如果当前值 >= 0，这一行右边的负数已经被上面的列处理过了，**下移** `row++`。
4. **lower_bound 的变体**：因为是非递增（降序），不能直接用标准 `lower_bound`（它假设升序）。需要自己写二分，或者用 `upper_bound` 配合反向比较器。

## 解法详解

### 解法1: 暴力遍历 -- O(m*n) / O(1)

**思考过程**: 最直接的做法，遍历矩阵中每个元素，负数就 +1。

```cpp
class Solution {
public:
    int countNegatives(vector<vector<int>>& grid) {
        int count = 0;
        for (auto& row : grid) {
            for (int val : row) {
                if (val < 0) count++;
            }
        }
        return count;
    }
};
```

**关键点**:
- 完全没利用有序性，但代码最简洁。
- m, n 最大都是 100，所以 O(m*n) = O(10000)，非常快。
- 这个解法的价值：明确了**瓶颈在于每个元素都检查一遍**。

---

### 解法2: 每行二分查找 -- O(m log n) / O(1)

**从解法1优化**: 既然每行是非递增的，负数一定在右边连续的一段。找到分界点就知道有多少个负数。

```
示例: grid = [[4,3,2,-1],[3,2,1,-1],[1,1,-1,-2],[-1,-1,-2,-3]]

逐行二分:
行0: [4, 3, 2, -1]    → 第一个负数在 index=3  → 负数个数: 4-3 = 1
行1: [3, 2, 1, -1]    → 第一个负数在 index=3  → 负数个数: 4-3 = 1
行2: [1, 1, -1, -2]   → 第一个负数在 index=2  → 负数个数: 4-2 = 2
行3: [-1,-1, -2, -3]  → 第一个负数在 index=0  → 负数个数: 4-0 = 4
                                                        总计: 8
```

**二分查找的收缩过程图解**:
```
目标: 找第一个 < 0 的元素位置（降序数组）

行0: [4, 3, 2, -1]     n = 4

轮次1: lo=0, hi=4
        mid = 2, row[2]=2 >= 0 → lo = 3
        [4, 3, 2, -1]
                  ^mid
         lo───────────→lo'

轮次2: lo=3, hi=4
        mid = 3, row[3]=-1 < 0 → hi = 3
        [4, 3, 2, -1]
                    ^mid
                   hi'←hi

结束: lo=3, hi=3 → 第一个负数在 index 3
      负数个数 = 4 - 3 = 1

---

行2: [1, 1, -1, -2]    n = 4

轮次1: lo=0, hi=4
        mid = 2, row[2]=-1 < 0 → hi = 2
        [1, 1, -1, -2]
               ^mid
         hi'←──────hi

轮次2: lo=0, hi=2
        mid = 1, row[1]=1 >= 0 → lo = 2
        [1, 1, -1, -2]
            ^mid
         lo──→lo'

结束: lo=2, hi=2 → 第一个负数在 index 2
      负数个数 = 4 - 2 = 2

---

行3: [-1, -1, -2, -3]  n = 4

轮次1: lo=0, hi=4, mid=2, row[2]=-2 < 0 → hi = 2
轮次2: lo=0, hi=2, mid=1, row[1]=-1 < 0 → hi = 1
轮次3: lo=0, hi=1, mid=0, row[0]=-1 < 0 → hi = 0

结束: lo=0, hi=0 → 第一个负数在 index 0
      负数个数 = 4 - 0 = 4
```

```cpp
class Solution {
public:
    int countNegatives(vector<vector<int>>& grid) {
        int count = 0;
        int n = grid[0].size();
        for (auto& row : grid) {
            // 二分找第一个 < 0 的位置
            int lo = 0, hi = n;
            while (lo < hi) {
                int mid = lo + (hi - lo) / 2;
                if (row[mid] >= 0) {
                    lo = mid + 1;  // 非负，去右半边找
                } else {
                    hi = mid;      // 负数，可能是第一个，收缩右边界
                }
            }
            count += n - lo;  // lo 到末尾都是负数
        }
        return count;
    }
};
```

**关键点**:
- 注意这是**降序**数组的二分，不能直接用 `lower_bound`。
- `lo` 维护的含义：`[0, lo)` 区间都是 >= 0 的。`lo` 是第一个负数的位置（或等于 n 表示该行无负数）。
- 时间 O(m log n)，对于 m=n=100 约 700 次操作。

---

### 解法3: 阶梯形（右上角出发） -- O(m + n) / O(1) -- 最优解

**核心观察**: 从右上角出发，利用行列两个方向的单调性。

```
矩阵（非递增排列）:
  col ->  0    1    2    3
row   +----+----+----+----+
  0   |  4 |  3 |  2 | -1 |   <- 从右上角(0,3)开始
      +----+----+----+----+
  1   |  3 |  2 |  1 | -1 |
      +----+----+----+----+
  2   |  1 |  1 | -1 | -2 |
      +----+----+----+----+
  3   | -1 | -1 | -2 | -3 |
      +----+----+----+----+

"阶梯"分界线 (>=0 | <0):
      +----+----+----+----+
      | >=0| >=0| >=0| <0 |   <- 1个负数
      +----+----+----+----+
      | >=0| >=0| >=0| <0 |   <- 1个负数
      +----+----+----+----+
      | >=0| >=0| <0 | <0 |   <- 2个负数
      +----+----+----+----+
      | <0 | <0 | <0 | <0 |   <- 4个负数
      +----+----+----+----+
                                总计: 8

右上角出发的行走路线:
  (0,3)=-1 < 0: col3 从row0到row3都<=−1 → 加 m−0=4个 → col--
  (0,2)=2 >= 0: 这行这个位置非负 → row++
  (1,2)=1 >= 0: → row++
  (2,2)=-1 < 0: col2 从row2到row3 → 加 m−2=2个 → col--
  (2,1)=1 >= 0: → row++
  (3,1)=-1 < 0: col1 从row3到row3 → 加 m−3=1个 → col--
  (3,0)=-1 < 0: col0 从row3到row3 → 加 m−3=1个 → col--
  col=-1, 结束. 总计: 4+2+1+1 = 8
```

```cpp
class Solution {
public:
    int countNegatives(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        int count = 0;
        int row = 0, col = n - 1;  // 从右上角出发

        while (row < m && col >= 0) {
            if (grid[row][col] < 0) {
                // 当前值是负数
                // 列是非递增的，所以从 row 到 m-1 这一列都是负数
                count += m - row;
                col--;  // 向左移，看更多列
            } else {
                // 当前值 >= 0，这个位置不是负数
                row++;  // 向下移，找这一列中更小的值
            }
        }
        return count;
    }
};
```

**另一种阶梯写法（逐行扫描，col 不重置）**:
```cpp
class Solution {
public:
    int countNegatives(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        int count = 0, col = n - 1;
        for (int row = 0; row < m; row++) {
            // col 不重置：列非递增 → 下一行负数起始位置 <= 当前行
            while (col >= 0 && grid[row][col] < 0) col--;
            count += n - 1 - col;  // col+1 到 n-1 都是负数
        }
        return count;
    }
};
```

**关键点**:
- **为什么从右上角出发？** 右上角有特殊性质：向左值不减（行非递增），向下值不增（列非递增）。使得每一步都能做出明确的决策——要么排除整列剩余行，要么跳过当前行。
- **每步只做一个动作**：要么 `row++`，要么 `col--`，最多走 `m + n` 步。
- **等价地可以从左下角出发**：`(m-1, 0)` 出发，向右走遇到负数加 `row+1` 然后 `row--`，遇到非负就 `col++`。

## 解法对比

|  | 暴力遍历 | 每行二分 | 阶梯形 |
|--|---------|---------|--------|
| 时间 | O(m*n) | O(m log n) | **O(m+n)** |
| 空间 | O(1) | O(1) | O(1) |
| 利用有序性 | 不利用 | 利用行有序 | **利用行+列双有序** |
| 适用场景 | 无排序保证时 | 仅行有序 | 行+列都有序 |

**面试选择**: 先说暴力，说出"行有序可以二分"展现二分能力，然后推导出阶梯形最优解展现矩阵搜索能力。

## 易错点

1. **二分的边界方向搞反**：
   - 这是**降序**数组找第一个负数，不能直接套升序模板。
   - 错: `if (row[mid] < 0) lo = mid + 1;` → 这是在升序中找大于等于0的
   - 对: `if (row[mid] >= 0) lo = mid + 1;` → 在降序中跳过非负部分

2. **阶梯形遇到负数时加错数量**：
   - 错: `count += m;` → 不是整列都是负数
   - 对: `count += m - row;` → 从当前行到最后一行才是负数

3. **阶梯形的起点选错**：
   - 错: 从左上角 `(0, 0)` 或右下角 `(m-1, n-1)` 出发 → 两个方向同向，无法做决策
   - 对: 右上角 `(0, n-1)` 或左下角 `(m-1, 0)` → 两个方向一增一减

4. **逐行扫描版本忘记 col 不重置**：
   - 错: 每行开始时 `col = n - 1` 重置 → 退化成 O(m*n)
   - 对: col 在整个外层循环只初始化一次，利用列的单调性

## 面试追问

**Q1: 为什么阶梯形能做到 O(m+n)？**
> 因为每一步要么 row+1，要么 col-1。row 最多增加 m 次，col 最多减少 n 次，所以总步数最多 m + n。这和"搜索二维有序矩阵"(LC 240) 是相同的技巧。

**Q2: 如果矩阵是"非递减"排列（升序），怎么改？**
> 负数会在左上角区域。从左下角出发，向右找第一个 >= 0 的位置，该行左边都是负数。核心框架不变，只是比较符号和移动方向翻转。

**Q3: 如果要统计零的个数呢？**
> 不能直接用阶梯形（零不在矩阵的某一角），但可以做两次查找：一次找"第一个 <= 0 的位置"，一次找"第一个 < 0 的位置"，两者之差就是零的个数。每行二分两次，O(m log n)。

**Q4: 这个阶梯形技巧还能用在哪些题里？**
> - **240. 搜索二维矩阵 II**：行列有序矩阵中搜索目标值，同样从右上角出发，O(m+n)。
> - **378. 有序矩阵中第 K 小的元素**：二分答案 + 阶梯形用于统计"<= 某个值的元素个数"。

## 相关题型

- **240. 搜索二维矩阵 II** -- 同样行列双有序矩阵，搜索特定值。直接复用阶梯形思路，从右上角出发，等于返回 true，小于向下，大于向左。
- **74. 搜索二维矩阵** -- 每行有序且下一行开头大于上一行末尾（严格全局有序），可以展开成一维数组做一次二分。区别于本题的"行列分别有序"。
- **378. 有序矩阵中第 K 小的元素** -- 行列有序矩阵找第 K 小元素。二分答案 + 阶梯形统计 <= mid 的元素个数，复用本题解法3的统计技巧。
- **668. 乘法表中第 K 小的数** -- 乘法表可以视为特殊的有序矩阵，同样用二分答案 + 阶梯统计。
