# 488. Zuma Game - 祖玛游戏

## 题目理解
桌面上有一排彩球，手中有一些球，每次可以将手中的球插入任意位置。连续三个及以上同色球会被消除（可连锁）。求清空桌面所需的最少球数，无法清空返回 -1。

## 提示

### 提示 1 - 搜索思路
数据范围小（board <= 16, hand <= 5），适合 DFS/BFS + 记忆化搜索。

### 提示 2 - DFS + 剪枝
核心策略：
- 找到 board 中连续相同颜色的段
- 对每一段，尝试从 hand 中补充同色球使其达到 3 个以消除
- 消除后递归处理剩余的 board

### 提示 3 - 消除函数
需要一个辅助函数模拟消除过程：插入球后，不断移除 >= 3 个连续同色球，直到没有可消除的为止。

### 提示 4 - 关键剪枝
1. 只在颜色匹配的位置插入球（不需要尝试所有位置）
2. 如果一段已有 2 个同色球，只需补 1 个；如果只有 1 个，需要补 2 个
3. 手中没有对应颜色球就跳过该段
4. 使用记忆化（board + hand 状态）避免重复计算

### 提示 5 - 状态压缩（可选）
hand 最多 5 个球，可以用位掩码或排序后的字符串作为状态。

## 复杂度
- 时间：指数级，但由于数据范围小 + 剪枝，实际可行
- 空间：O(状态数)
