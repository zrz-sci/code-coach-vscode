# 67. 二进制求和

## 核心思路
这道题本质上就是**模拟竖式加法**——和你小学学的十进制加法完全一样，只不过逢二进一而不是逢十进一。

## 思维链

1. **读完题第一反应**：两个二进制字符串相加，最朴素的想法是把它们转成十进制整数相加，再转回二进制字符串。但注意字符串长度可达 10⁴，远超 `long long` 的表示范围（64 位），所以**不能用整数直接算**。

2. **既然不能转数字，怎么办？**：回忆一下我们手动做加法的过程——从最低位（最右边）开始，逐位相加，如果 ≥ 2 就进位。这就是竖式加法！

3. **竖式加法的关键要素**：每一位的计算只需要三个输入：`a 的当前位` + `b 的当前位` + `进位 carry`。结果的当前位是 `sum % 2`，新的进位是 `sum / 2`。

4. **两个字符串长度不同怎么办？**：短的那个用 0 补齐即可。实现上不需要真的补零，只要指针越界后当作 0 就行。

5. **最后别忘了**：遍历完所有位之后，如果 carry 还是 1，需要在最高位再加一个 '1'。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 模拟竖式加法（反向遍历） | 从末尾逐位相加，处理进位 | O(max(m,n)) | O(max(m,n)) | ⭐ 必须写出 |
| 位运算（不用加法） | 用 XOR 做无进位加法，AND+左移做进位 | O(max(m,n)²) 最坏 | O(max(m,n)) | 加分项 |

## 关键提示

1. **从右往左遍历**：二进制加法从最低位（字符串末尾）开始，用两个指针分别从 `a` 和 `b` 的末尾向前移动。

2. **字符到数字的转换**：`a[i] - '0'` 即可把字符 '0'/'1' 转成整数 0/1。

3. **循环终止条件**：不是两个指针都到头就停，是 `i >= 0 || j >= 0 || carry > 0`，三个条件任一满足就要继续。

4. **结果是倒序构建的**：每次算出一位，追加到结果末尾，最后翻转。或者用 `insert(0, ...)` 但那样每次都是 O(n)，不推荐。

5. **竖式加法示意图**：
```
    a:    1 0 1 0
    b:    1 0 1 1
         --------
         carry=0:  0+1+0=1 → 写1, carry=0
         carry=0:  1+1+0=2 → 写0, carry=1
         carry=1:  0+0+1=1 → 写1, carry=0
         carry=0:  1+1+0=2 → 写0, carry=1
         carry=1:  最后进位  → 写1
         --------
  结果:  1 0 1 0 1
```

## 解法详解

### 解法1: 模拟竖式加法 — O(max(m,n)) / O(max(m,n)) ⭐ 面试首选

**思考过程**：和十进制竖式加法完全一样。从最低位开始，每位做 `digitA + digitB + carry`，当前位写 `sum % 2`，进位更新为 `sum / 2`。两个字符串长度不一样？短的那个越界后当 0 处理。全部算完 carry 还有？在最前面补个 1。

```cpp
class Solution {
public:
    string addBinary(string a, string b) {
        string result;
        int i = a.size() - 1;  // a 的指针，从末尾开始
        int j = b.size() - 1;  // b 的指针，从末尾开始
        int carry = 0;
        
        // 只要还有位没处理，或者还有进位，就继续
        while (i >= 0 || j >= 0 || carry) {
            int sum = carry;
            if (i >= 0) sum += a[i--] - '0';  // 取 a 的当前位
            if (j >= 0) sum += b[j--] - '0';  // 取 b 的当前位
            
            result += (sum % 2) + '0';  // 当前位：sum 对 2 取余
            carry = sum / 2;            // 进位：sum 除以 2
        }
        
        reverse(result.begin(), result.end());  // 我们是从低位往高位算的，翻转
        return result;
    }
};
```

**关键点**：
- 循环条件是 `i >= 0 || j >= 0 || carry`，不能漏掉 `carry`，否则 "11" + "1" = "00" 而不是 "100"。
- 结果需要翻转，因为我们是从低位开始追加的。

### 解法2: 位运算模拟（不用 +） — O(max(m,n)²) 最坏 / O(max(m,n))

**从解法1延伸**：如果面试官追问"能否不用加法运算符？"，可以用位运算：`a XOR b` 得到无进位和，`a AND b` 左移一位得到进位，循环直到进位为 0。但对字符串操作较复杂，这里给出思路和实现。

```cpp
class Solution {
public:
    string addBinary(string a, string b) {
        // 先对齐长度，短的前面补 '0'
        while (a.size() < b.size()) a = "0" + a;
        while (b.size() < a.size()) b = "0" + b;
        
        while (hasOne(b)) {  // b 不全为 '0' 时循环
            string xorStr = bitwiseXor(a, b);    // 无进位和
            string andStr = bitwiseAnd(a, b);     // 进位（未左移）
            string carryStr = leftShift(andStr);  // 进位左移一位
            
            a = xorStr;
            b = carryStr;
            // 对齐长度
            while (a.size() < b.size()) a = "0" + a;
            while (b.size() < a.size()) b = "0" + b;
        }
        
        // 去除前导零
        int start = 0;
        while (start < (int)a.size() - 1 && a[start] == '0') start++;
        return a.substr(start);
    }
    
private:
    bool hasOne(const string& s) {
        for (char c : s) if (c == '1') return true;
        return false;
    }
    
    string bitwiseXor(const string& a, const string& b) {
        string res = a;
        for (int i = 0; i < (int)a.size(); i++)
            res[i] = ((a[i] - '0') ^ (b[i] - '0')) + '0';
        return res;
    }
    
    string bitwiseAnd(const string& a, const string& b) {
        string res = a;
        for (int i = 0; i < (int)a.size(); i++)
            res[i] = ((a[i] - '0') & (b[i] - '0')) + '0';
        return res;
    }
    
    string leftShift(const string& s) {
        return s + "0";  // 二进制左移就是末尾加 '0'
    }
};
```

**关键点**：这种解法虽然不用 `+`，但实现复杂且最坏情况需要多轮迭代（如 "111...1" + "1"），面试中了解原理即可，写出解法1 足够。

## 易错点

1. **忘记处理最后的进位**
   - ✗ 循环条件 `while (i >= 0 || j >= 0)` — "11" + "1" 输出 "00"
   - ✓ 循环条件 `while (i >= 0 || j >= 0 || carry)` — 正确输出 "100"

2. **字符和数字搞混**
   - ✗ `result += sum % 2;` — 追加的是 ASCII 0/1（不可见字符），不是字符 '0'/'1'
   - ✓ `result += (sum % 2) + '0';` — 整数转字符

3. **忘记翻转结果**
   - ✗ 直接返回 `result` — 得到的是反序的二进制串
   - ✓ `reverse(result.begin(), result.end())` 后再返回

4. **用 `string::insert(0, ...)` 代替翻转**
   - 功能正确但每次 insert 到头部是 O(n) 操作，总体 O(n²)
   - 更好的做法：`push_back` + 最后 `reverse`，总体 O(n)

## 面试追问

**Q1**（基础理解）：为什么不能直接把字符串转成 `int` 或 `long long` 再相加？
> 因为字符串长度可达 10⁴ 位，远超任何内置整数类型的范围。即使用 `unsigned long long` 也只能表示 64 位二进制。

**Q2**（细节追问）：如果两个字符串长度差距很大（一个 1 位，一个 10000 位），你的算法会浪费时间吗？
> 不会。循环次数是 `max(m, n)`，指针越界的那一方直接当 0，没有额外开销。

**Q3**（变体）：如果输入是十进制字符串呢？需要改哪里？
> 只需要把 `% 2` 改成 `% 10`，`/ 2` 改成 `/ 10`。竖式加法的框架完全一样，只是进制不同。这就是 LeetCode 415（字符串相加）。

**Q4**（位运算追问）：能否不用 `+` 运算符完成加法？
> 可以。用 `XOR` 得到无进位和，用 `AND` + 左移得到进位，循环直到进位为 0。这是计算机硬件加法器的工作原理。
