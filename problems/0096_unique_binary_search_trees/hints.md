# 96. 不同的二叉搜索树

## 核心思路

本质上在问：**n 个节点能构成多少种不同结构的 BST？** 由于 BST 的性质（左 < 根 < 右），选定根节点后，左右子树的节点数就确定了，问题递归地分解为两个更小的子问题。这其实就是经典的**卡特兰数 (Catalan Number)**。

## 思维链

1. **读完题第一反应**：n 个节点的 BST 有多少种？可以枚举每个节点作为根，递归地计算左右子树的组合数 → 暴力递归。

2. **关键观察 — BST 性质决定了结构**：如果选 `k` 作为根，那么 `1..k-1` 必须在左子树，`k+1..n` 必须在右子树。左子树有 `k-1` 个节点，右子树有 `n-k` 个节点。

3. **更深一层观察 — 结构只和节点数有关**：`1,2,3` 组成的 BST 数量和 `4,5,6` 组成的 BST 数量是一样的！因为 BST 的**结构种数只取决于节点个数**，不取决于具体值。这意味着我们可以定义 `G(n)` = n 个节点的 BST 种数。

4. **发现递推关系**：`G(n) = Σ G(k-1) * G(n-k)`，其中 k 从 1 到 n 枚举根节点。左子树 `G(k-1)` 种 × 右子树 `G(n-k)` 种（乘法原理）。

5. **识别重叠子问题**：计算 `G(5)` 需要 `G(0)` 到 `G(4)`，而 `G(4)` 也需要 `G(0)` 到 `G(3)` → 经典 DP！从小到大填表即可。

6. **数学视角**：这个递推式就是卡特兰数的定义，有闭合公式 `C(n) = C(2n, n) / (n+1)`。

## 关键提示

1. **从小例子入手**：先手动画出 n=1,2,3 的所有 BST，观察规律：
```
n=1: 只有 1 棵
n=2: 2 棵 (根1右2, 根2左1)
n=3: 5 棵 (根1→2棵, 根2→1棵, 根3→2棵, 共5棵)
```

2. **选定根后，左右子树是独立的子问题**：选 k 为根 → 左边 k-1 个节点，右边 n-k 个节点，组合数用乘法原理。

3. **结构只和个数有关**：`{1,2,3}` 的 BST 种数 = `{5,6,7}` 的 BST 种数。这是能用 DP 的关键！

4. **DP 状态**：`dp[i]` = i 个节点组成的 BST 种数，base case `dp[0] = dp[1] = 1`。

5. **ASCII 图示 — n=3 枚举根节点**：
```
根=1:          根=2:         根=3:
  1              2             3
   \            / \           /
    ?          1   3         ?
  (2个节点)   (各1个)     (2个节点)

G(3) = G(0)*G(2) + G(1)*G(1) + G(2)*G(0)
     = 1*2      + 1*1       + 2*1
     = 5
```

## 解法详解

### 解法1: 暴力递归 — O(指数级) / O(n)

**思考过程**：最直觉的做法——枚举每个节点作为根，递归计算左右子树各有多少种，用乘法原理组合。

```cpp
class Solution {
public:
    int numTrees(int n) {
        // base case: 0个或1个节点只有1种BST（空树也算1种，因为它是合法的子树）
        if (n <= 1) return 1;
        
        int total = 0;
        // 枚举根节点k (1到n)
        for (int k = 1; k <= n; k++) {
            int leftCount = numTrees(k - 1);   // 左子树有k-1个节点
            int rightCount = numTrees(n - k);   // 右子树有n-k个节点
            total += leftCount * rightCount;    // 乘法原理
        }
        return total;
    }
};
```

**关键点**：`G(0) = 1` 而不是 0！空树代表"没有子树"这一种情况，如果设为 0，乘法结果就全是 0 了。

---

### 解法2: 记忆化搜索 — O(n²) / O(n)

**从解法1优化**：解法1 中 `numTrees(3)` 会被多次重复计算。加个 memo 数组缓存即可。

```cpp
class Solution {
public:
    int numTrees(int n) {
        vector<int> memo(n + 1, -1);
        return helper(n, memo);
    }
    
    int helper(int n, vector<int>& memo) {
        if (n <= 1) return 1;
        if (memo[n] != -1) return memo[n];
        
        int total = 0;
        for (int k = 1; k <= n; k++) {
            total += helper(k - 1, memo) * helper(n - k, memo);
        }
        memo[n] = total;
        return total;
    }
};
```

---

### 解法3: 动态规划（自底向上）— O(n²) / O(n) ⭐ 面试首选

**从记忆化翻译成递推**：既然 `G(n)` 只依赖 `G(0)` 到 `G(n-1)`，从小到大填表即可。

```
// dp 填表过程:
// dp[0] = 1 (空树)
// dp[1] = 1 (单节点)
// dp[2] = dp[0]*dp[1] + dp[1]*dp[0] = 1+1 = 2
// dp[3] = dp[0]*dp[2] + dp[1]*dp[1] + dp[2]*dp[0] = 2+1+2 = 5
// dp[4] = dp[0]*dp[3] + dp[1]*dp[2] + dp[2]*dp[1] + dp[3]*dp[0]
//       = 5 + 2 + 2 + 5 = 14
//
// 依赖关系: dp[i] 依赖 dp[0]..dp[i-1]，所以从小到大填
```

```cpp
class Solution {
public:
    int numTrees(int n) {
        vector<int> dp(n + 1, 0);
        dp[0] = 1;  // 空树也是1种（乘法的单位元）
        dp[1] = 1;  // 1个节点1种
        
        for (int i = 2; i <= n; i++) {
            // 枚举根节点j (1到i)
            for (int j = 1; j <= i; j++) {
                // 左子树j-1个节点 × 右子树i-j个节点
                dp[i] += dp[j - 1] * dp[i - j];
            }
        }
        return dp[n];
    }
};
```

**关键点**：外层循环 `i` 是节点总数（从 2 开始），内层循环 `j` 是根节点编号（1 到 i）。

---

### 解法4: 卡特兰数数学公式 — O(n) / O(1)

**数学背景**：解法3 的递推式恰好就是**卡特兰数**的定义。卡特兰数有闭合公式：

```
C(n) = C(2n, n) / (n + 1)
```

也有递推关系（避免大数组合数溢出）：

```
C(n) = C(n-1) * 2(2n-1) / (n+1)
```

```cpp
class Solution {
public:
    int numTrees(int n) {
        // 卡特兰数递推: C(n) = C(n-1) * 2*(2n-1) / (n+1)
        // 用 long 防止中间结果溢出
        long catalan = 1;
        for (int i = 1; i <= n; i++) {
            // 先乘后除，保证整除（卡特兰数一定是整数）
            catalan = catalan * 2 * (2 * i - 1) / (i + 1);
        }
        return (int)catalan;
    }
};
```

**关键点**：必须用 `long` 类型，因为 `catalan * 2 * (2*i-1)` 中间结果可能溢出 int。另外先乘后除的顺序保证整除。

## 解法对比

| | 暴力递归 | 记忆化搜索 | DP递推 | 卡特兰数 |
|---|---|---|---|---|
| 时间 | O(指数级) | O(n²) | O(n²) | O(n) |
| 空间 | O(n) 栈 | O(n) | O(n) | O(1) |
| 代码量 | 最少 | 中等 | 中等 | 最少 |
| 适合面试 | ❌ | ✓ | ⭐ 首选 | 加分项 |
| 核心价值 | 理解递归结构 | 理解重叠子问题 | 标准 DP | 数学素养 |

**面试建议**：先说清楚递归思路（展示理解），然后直接写 DP 解法。如果面试官问"有没有更快的"，提卡特兰数公式。

## 易错点

1. **`dp[0]` 初始化为 0**
   - ✗ `dp[0] = 0` → 所有结果都变成 0（乘法中有 0 因子）
   - ✓ `dp[0] = 1` → 空树代表"这边没有子树"的 1 种情况，是乘法单位元

2. **内层循环边界搞错**
   - ✗ `for (int j = 0; j < i; j++)` → j 代表根节点编号，应该从 1 开始
   - ✓ `for (int j = 1; j <= i; j++)` → 根节点从 1 到 i

3. **卡特兰数公式溢出**
   - ✗ `int catalan = ...` 中间乘法溢出
   - ✓ 使用 `long catalan` 并注意先乘后除的顺序

4. **混淆"节点数"和"节点值"**
   - BST 结构数只和节点个数有关，和具体的值无关。`dp[i]` 表示 i 个节点的结构数，不是"值为 1 到 i"。

## 面试追问

**Q1: 为什么 BST 的结构数只和节点个数有关，和具体值无关？**
> 因为 BST 的结构由大小关系决定。任何 k 个不同数的大小关系是固定的（排序后第 1 小、第 2 小...），所以它们能构成的 BST 结构和 `{1,2,...,k}` 完全一样。

**Q2: 如果不是 BST 而是普通二叉树，n 个节点有多少种？**
> 结构上仍然是卡特兰数（因为二叉树结构和 BST 结构一一对应）。但如果节点有不同的标签（labeled），还要乘以 n!（排列方式）。

**Q3: 如果不仅要求数量，还要输出所有的 BST 怎么办？（LeetCode 95）**
> 不能只用 DP 记数量了，需要回溯/递归枚举每个根节点，递归生成所有左右子树的组合，返回树节点列表。思路从"计数"变成"枚举构建"。

**Q4: 卡特兰数还出现在哪些问题中？**
> 合法括号序列数（n 对括号）、凸多边形三角剖分数、出栈序列数（n 个元素的合法出栈顺序）、从 (0,0) 到 (n,n) 不越过对角线的路径数。
