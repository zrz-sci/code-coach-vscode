# 50. Pow(x, n)

## 核心思路

这道题本质上是**快速幂**问题：如何高效地计算 x 的 n 次方，核心在于利用幂的二分性质 `x^n = (x^(n/2))^2` 将线性次数的乘法降到对数次。

## 思维链

1. **读完题第一反应**：循环乘 n 次不就行了？`x * x * x * ... * x`（n 个 x）→ 暴力法 O(n)
2. **暴力解的瓶颈**：n 最大可达 2^31 - 1 ≈ 21 亿，循环 21 亿次必然超时
3. **关键观察**：`x^10 = x^5 * x^5`，`x^5 = x^2 * x^2 * x`。也就是说，算 x^10 不需要乘 10 次，只需要知道 x^5 就行，而 x^5 只需要知道 x^2 …… 每次问题规模减半！
4. **这就是快速幂**：把指数不断二分，偶数 `x^n = (x^(n/2))^2`，奇数 `x^n = x * (x^(n/2))^2`，递归深度只有 O(log n)
5. **处理负指数**：`x^(-n) = 1 / x^n`，但 n = INT_MIN 时取反会溢出，需要用 `long long`
6. **递归 vs 迭代**：递归直观，迭代用位运算更高效，两种都要掌握

```
// 快速幂的递归分解过程 (x=2, n=10):
//
// pow(2, 10)
//   = pow(2, 5) * pow(2, 5)                    — 10是偶数，二分
//       = 2 * pow(2, 2) * pow(2, 2)            — 5是奇数，提出一个x
//             = pow(2, 1) * pow(2, 1)           — 2是偶数
//                 = 2 * pow(2, 0) * pow(2, 0)   — 1是奇数
//                       = 1                      — base case
//
// 总共只做了 4 次递归，而不是 10 次乘法！
```

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力循环 | 逐个相乘 n 次 | O(n) | O(1) | 能说出即可 |
| 递归快速幂 | 指数折半递归 | O(log n) | O(log n) | ⭐ 必须写出 |
| 迭代快速幂 | 位运算逐位处理 | O(log n) | O(1) | 加分项 |

## 关键提示

1. **负指数处理**：`x^(-n) = 1 / x^n`，但当 `n = INT_MIN` 时，`-n` 会溢出 int 范围。怎么避免？
2. **偶数 vs 奇数**：`n` 为偶数时 `x^n = (x^(n/2))^2`；`n` 为奇数时要多乘一个 `x`。只需要算一次 `x^(n/2)` 再平方，不要算两次！
3. **迭代版的思路**：把指数 `n` 看成二进制，比如 `10 = 1010₂ = 8 + 2`，所以 `x^10 = x^8 * x^2`。遍历 n 的每一位，遇到 1 就乘入结果。
4. **base case**：任何数的 0 次方都是 1（题目保证不会出现 `0^0`）。
5. **精度问题**：本题用 `double` 运算，注意浮点误差是不可避免的，但题目精度要求不严格。

## 解法详解

### 解法1: 暴力循环 — O(n) / O(1)

**思考过程**: 最直觉的方法——把 x 乘 n 次。负指数就先算正的，最后取倒数。

```cpp
class Solution {
public:
    double myPow(double x, int n) {
        // 用 long long 避免 n = INT_MIN 取反溢出
        long long N = n;
        if (N < 0) {
            x = 1.0 / x;
            N = -N;
        }
        double result = 1.0;
        for (long long i = 0; i < N; i++) {
            result *= x;
        }
        return result;
    }
};
```

**关键点**: 
- 当 n = 2^31 - 1 ≈ 21亿时，循环 21 亿次，**必然 TLE**
- 但这个思路帮我们理清了负指数的处理方式，后续解法直接复用

### 解法2: 递归快速幂 — O(log n) / O(log n) ⭐ 面试首选

**从解法1优化**: 暴力的瓶颈是乘法次数 O(n)。利用 `x^n = (x^(n/2))^2` 把指数折半，乘法次数从 n 降到 log n。

```cpp
class Solution {
public:
    double myPow(double x, int n) {
        // 转成 long long 防止 n = INT_MIN 取反溢出
        long long N = n;
        if (N < 0) {
            x = 1.0 / x;
            N = -N;
        }
        return fastPow(x, N);
    }
    
private:
    double fastPow(double x, long long n) {
        // base case: 任何数的0次方 = 1
        if (n == 0) return 1.0;
        
        // 只递归一次，算 x^(n/2)
        double half = fastPow(x, n / 2);
        
        if (n % 2 == 0) {
            return half * half;           // 偶数: x^n = (x^(n/2))^2
        } else {
            return half * half * x;       // 奇数: x^n = (x^(n/2))^2 * x
        }
    }
};
```

```
// 递归调用栈示意 (x=2, n=10):
//
// fastPow(2, 10)
//   half = fastPow(2, 5) = 32
//     half = fastPow(2, 2) = 4
//       half = fastPow(2, 1) = 2
//         half = fastPow(2, 0) = 1    ← base case
//         return 1 * 1 * 2 = 2        ← 奇数
//       return 2 * 2 = 4              ← 偶数
//     return 4 * 4 * 2 = 32           ← 奇数
//   return 32 * 32 = 1024             ← 偶数
```

**关键点**: 
- `half` 只算一次，然后 `half * half`。如果写成 `fastPow(x, n/2) * fastPow(x, n/2)` 就变成 O(n) 了！
- 递归深度 O(log n)，即栈空间 O(log n)

### 解法3: 迭代快速幂（位运算） — O(log n) / O(1)

**从解法2优化**: 递归有 O(log n) 栈空间开销。用迭代+位运算可以做到 O(1) 空间。

**核心思想**: 把指数 n 看作二进制数。例如 `n=13 = 1101₂ = 8+4+1`，所以 `x^13 = x^8 * x^4 * x^1`。

从低位到高位遍历 n 的每一个 bit：
- `x` 每轮自乘（`x → x² → x⁴ → x⁸ → ...`）
- 当前 bit 为 1 时，把当前的 x 乘入结果

```cpp
class Solution {
public:
    double myPow(double x, int n) {
        long long N = n;
        if (N < 0) {
            x = 1.0 / x;
            N = -N;
        }
        
        double result = 1.0;
        double current_product = x;  // 依次为 x^1, x^2, x^4, x^8, ...
        
        while (N > 0) {
            if (N & 1) {             // 当前最低位是 1
                result *= current_product;
            }
            current_product *= current_product;  // x → x² → x⁴ → ...
            N >>= 1;                // 右移一位，处理下一个 bit
        }
        
        return result;
    }
};
```

```
// 迭代过程 (x=2, n=10, 二进制 1010):
//
// 初始: result=1, cur=2, N=1010₂
//
// bit0=0: result不变=1,   cur=2*2=4,   N=101₂
// bit1=1: result=1*4=4,   cur=4*4=16,  N=10₂
// bit2=0: result不变=4,   cur=16*16=256, N=1₂
// bit3=1: result=4*256=1024, cur=256*256, N=0
//
// 结果: 1024 ✓
// 只用了 4 次迭代（log₂10 ≈ 3.3，向上取整 4 次）
```

**关键点**: 完全不用递归，O(1) 空间，面试中写出这个会加分。

## 解法对比

| | 暴力循环 | 递归快速幂 | 迭代快速幂 |
|---|---|---|---|
| 时间 | O(n) — 超时 | O(log n) | O(log n) |
| 空间 | O(1) | O(log n) 栈 | O(1) |
| 代码量 | 最少 | 适中，逻辑清晰 | 稍多，位运算 |
| 面试推荐 | 开场说明即可 | **首选**，容易讲清楚 | 追问时给出 |

递归版更直观，面试先写递归版，面试官追问空间优化时再给迭代版。

## 易错点

1. **INT_MIN 取反溢出**
   - ✗ `long long N = -n;`（当 n = INT_MIN 时，`-n` 在 int 范围内已经溢出了再赋值给 long long 没用）
   - ✓ `long long N = n; N = -N;`（先转成 long long，再取反）

2. **递归中重复计算 half**
   - ✗ `return fastPow(x, n/2) * fastPow(x, n/2);`（两次递归，时间退化为 O(n)）
   - ✓ `double half = fastPow(x, n/2); return half * half;`（只算一次）

3. **负指数的处理位置**
   - ✗ 在递归内部每次都判断负号 → 逻辑混乱
   - ✓ 在入口统一处理：`x = 1/x, N = -N`，然后递归只处理非负指数

4. **x = 0 的情况**
   - 题目保证"要么 x 不为零，要么 n > 0"，所以不会出现 `0^负数` 的情况，但 `0^0` 按题意也不会出现

## 面试追问

**Q1（基础理解）**: "暴力法为什么不行？瓶颈在哪？"
→ n 最大 2^31，循环 21 亿次超时。瓶颈在乘法次数与 n 线性相关。

**Q2（核心优化）**: "怎么把 O(n) 降到 O(log n)？"
→ 利用 `x^n = (x^(n/2))^2`，每次把指数减半。递归深度 log n，每层 O(1) 工作。

**Q3（空间优化）**: "能不能做到 O(1) 空间？"
→ 迭代快速幂：把 n 看作二进制，从低位到高位扫描，x 每轮自平方，bit 为 1 时乘入结果。

**Q4（边界细节）**: "n = INT_MIN 时怎么处理？为什么直接取反会出问题？"
→ INT_MIN = -2^31，取反后 2^31 超出 int 范围（int 最大 2^31-1）。必须先转 long long 再取反。

**Q5（变体）**: "如果要求 x^n mod p（大数取模），怎么改？"
→ 同样的快速幂框架，每次乘法后取模：`half = (half * half) % p`。这就是**快速幂取模**，密码学中常用。
