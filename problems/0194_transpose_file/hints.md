# 194. 转置文件

## 核心思路

本质上就是一个**矩阵转置**的问题：把文件内容看成一个矩阵（行×列），将行变列、列变行。Shell 没有二维数组，需要用 awk 的关联数组或循环读取列来模拟。

## 思维链

1. **读完题第一反应** → 矩阵转置：原来的第 j 列变成新的第 j 行。需要知道列数（NF）和行数（NR）。
2. **难点在哪？** → Shell 按行读取文件，但转置需要**按列**收集数据。要么读一遍存到数组中再按列输出，要么多次扫描文件每次提取一列。
3. **awk 方案** → 用二维关联数组 `a[行][列]` 存所有数据，END 块中按列输出。
4. **纯 Shell 方案** → 循环列号，每次用 `cut -d' ' -f$i` 或 `awk '{print $i}'` 提取第 i 列。
5. **输出格式** → 每行用空格分隔，末尾不能有多余空格。

## 解法概览

| 解法 | 思路 | 工具 | 面试 |
|------|------|------|------|
| awk 二维数组 | 一次遍历存储，END块转置输出 | awk | ⭐ 必须写出 |
| Shell 循环 + cut/awk | 按列号循环，每次提取一列 | bash + cut/awk | 可选 |
| head + awk 组合 | 先获取列数，再逐列提取 | head + awk | 可选 |

## 关键提示

1. **NF 和 NR**：`NF` 是当前行的字段数（列数），`NR` 是当前行号。两者是 awk 的核心内置变量。
2. **awk 关联数组**：`a[i,j]` 实际上是 `a["i\034j"]`（awk 用 SUBSEP 连接下标）。也可以用字符串拼接 `a[i" "j]`。
3. **末尾空格问题**：`printf "%s ", val` 会在末尾多加一个空格。解决方案：第一列不加前导空格，后续列加 `" " val`。
4. **列数获取**：用 `head -1 file.txt | awk '{print NF}'` 获取第一行的列数（题目保证每行列数相同）。

## 解法详解

### 解法1: awk 二维数组 — ⭐ 面试首选

**思路**: 第一遍读取文件，存入二维数组 `a[行号][列号]`。读完后知道总行数和列数，按列输出。

```
示例:
输入:                   awk数组:
name age                a[1,1]="name"  a[1,2]="age"
alice 21                a[2,1]="alice" a[2,2]="21"
ryan 30                 a[3,1]="ryan"  a[3,2]="30"

转置输出:               按列遍历:
name alice ryan         a[1,1] a[2,1] a[3,1]
age 21 30               a[1,2] a[2,2] a[3,2]
```

```bash
awk '{
    for (i = 1; i <= NF; i++) {
        a[NR,i] = $i          # 存入二维数组
    }
}
NR == 1 { cols = NF }         # 记录列数（第一行）
END {
    for (j = 1; j <= cols; j++) {       # 遍历每列
        str = a[1,j]                     # 第一个元素
        for (i = 2; i <= NR; i++) {      # 拼接该列剩余元素
            str = str " " a[i,j]
        }
        print str                        # 输出一行（原来的一列）
    }
}' file.txt
```

---

### 解法2: awk 字符串拼接 — 更简洁

**思路**: 不用二维数组，直接在读取时把每列的值拼接到一个字符串数组中。

```bash
awk '{
    for (i = 1; i <= NF; i++) {
        if (NR == 1) {
            row[i] = $i           # 第一行直接赋值
        } else {
            row[i] = row[i] " " $i  # 后续行拼接到对应列
        }
    }
}
END {
    for (i = 1; i <= NF; i++) {
        print row[i]
    }
}' file.txt
```

---

### 解法3: Shell 循环逐列提取

**思路**: 先获取列数，然后循环每列，用 awk 提取该列所有值拼成一行。

```bash
cols=$(head -1 file.txt | awk '{print NF}')
for ((i = 1; i <= cols; i++)); do
    awk -v col="$i" '{printf "%s%s", (NR==1?"": " "), $col} END {print ""}' file.txt
done
```

## 易错点

1. **END 块中 NF 不可用**：
   - ✗ `END { for (i=1; i<=NF; ...) }` → END 块中 NF 是0（没有当前行）
   - ✓ 在处理第一行时记录列数：`NR==1 { cols = NF }`，END 中用 `cols`

2. **末尾多余空格**：
   - ✗ `for (i=1;i<=NR;i++) printf "%s ", a[i,j]` → 最后一个元素后多一个空格
   - ✓ 第一个元素直接赋值，后续拼接 `" " a[i,j]`，用 `print` 输出（自动换行无尾空格）

3. **awk 解法2中 NF 在 END 的陷阱**：
   - ✗ `END { for(i=1;i<=NF;i++) print row[i] }` → END 中 NF=0
   - ✓ 需要保存列数或使用其他方式获取数组长度

4. **Shell 循环效率**：
   - ✗ 对大文件用 Shell 循环逐列读取 → 每列都要扫描一遍文件，总共扫描 cols 遍
   - ✓ 用 awk 一次遍历方案（解法1/2），只扫描一遍文件

## 面试追问

**Q1: 解法2的 awk 方案中，END 块里怎么知道列数？**
> 方法一：在主块中用 `cols = NF` 每行更新（题目保证每行列数相同）。方法二：用 `length(row)` 获取数组长度（GNU awk 支持）。方法三：额外保存 `NR==1 { cols = NF }`。

**Q2: 如果文件非常大（内存放不下），怎么办？**
> 用解法3的循环方案：每次只提取一列，不需要把整个文件存入内存。代价是扫描文件 cols 次。或者用 `paste` 命令配合临时文件。

**Q3: 如果分隔符不是空格而是逗号呢？**
> 两种方法：① `awk -F',' ...` 设置字段分隔符。② 先 `sed 's/,/ /g'` 替换分隔符，再用原方案处理。输出时用 `OFS=","` 或手动拼接。
