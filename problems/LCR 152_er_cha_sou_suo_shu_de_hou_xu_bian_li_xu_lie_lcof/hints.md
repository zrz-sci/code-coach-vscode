# LCR 152. 验证二叉搜索树的后序遍历序列

## 核心思路

判断给定的整数数组是否可能是某棵二叉搜索树(BST)的后序遍历结果。后序遍历的顺序是**左-右-根**，所以数组的最后一个元素是根节点。利用BST性质（左子树 < 根 < 右子树）和后序遍历的结构特征，递归地验证每个子树的合法性。

## 思维链

1. **读完题第一反应**：后序遍历是"左-右-根"，最后一个元素是整棵树的根。能否根据这个性质递归判断？

2. **后序遍历的结构分析**：
   - 给定后序数组 `[...左子树..., ...右子树..., 根]`
   - 左子树部分的所有元素 **< 根**
   - 右子树部分的所有元素 **> 根**
   - 从左到右扫描，第一个 >= 根的位置就是右子树的起点

3. **验证流程**：
   - 取最后一个元素作为根
   - 从左到右找到第一个 >= 根的位置 m（左子树和右子树的分界点）
   - 验证右子树部分（从 m 到倒数第二个）是否全部 > 根
   - 递归验证左子树 `[l, m-1]` 和右子树 `[m, r-1]`

4. **分治递归 vs 单调栈**：
   - 递归分治：直观易懂，最坏 O(n^2)（退化为链时）
   - 单调栈：O(n) 时间，利用"逆序遍历 = 根-右-左"性质维护递减栈

```

postorder = [4, 6, 5, 9, 8]
```

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试推荐 |
|------|------|------|------|----------|
| 递归分治 | 根据后序性质划分+验证 | O(n^2) 最坏 | O(n) 栈 | ⭐ 首选（直观） |
| 单调栈 | 逆序遍历维护递减栈 | O(n) | O(n) | 加分项（最优） |

## 解法详解

### 解法1: 递归分治 -- O(n^2) / O(n)

**思考过程**：利用后序遍历"左-右-根"的结构，每次取最后一个元素作为根，划分左右子树，验证BST性质后递归处理。

**关键步骤**：
1. 基准情况：`l >= r` 时区间为空或单元素，直接返回 true
2. `root = post[r]`（最后一个元素是根）
3. 从 l 开始扫描找第一个 >= root 的位置 m（右子树起点）
4. 验证：`post[m..r-1]` 全部 > root
5. 递归：验证 `[l, m-1]`（左子树）和 `[m, r-1]`（右子树）

```cpp
class Solution {
public:
    bool verifyTreeOrder(vector<int>& postorder) {
        return verify(postorder, 0, (int)postorder.size() - 1);
    }
    bool verify(vector<int>& post, int l, int r) {
        if (l >= r) return true; // 空区间或单元素
        int root = post[r];      // 后序最后一个是根
        int m = l;
        while (m < r && post[m] < root) m++; // 找右子树起点
        // 验证右子树部分全 > root
        for (int i = m; i < r; i++) {
            if (post[i] < root) return false;
        }
        return verify(post, l, m - 1) && verify(post, m, r - 1);
    }
};
```

**时间复杂度分析**：
- 最好情况 O(n log n)：平衡BST，每层递归总共扫描 O(n)，共 O(log n) 层
- 最坏情况 O(n^2)：退化为链（如 `[1,2,3,4,5]`），每次只划分出一个元素

### 解法2: 单调栈 -- O(n) / O(n)

**思考过程**：逆序遍历后序数组，相当于按"根-右-左"的顺序访问。维护一个**单调递减栈**，当遇到一个比栈顶小的元素时，说明从右子树转到了左子树，需要找到对应的祖先节点作为上界。

**核心逻辑**：
- 逆序遍历 `postorder`，当前元素是某个节点
- 如果当前值 > 栈顶：是栈顶的右子树部分，直接入栈
- 如果当前值 < 栈顶：说明进入了某个祖先的左子树，不断弹栈找到正确的祖先作为上界
- 如果当前值 > 上界：违反BST性质，返回 false

```
单调栈执行过程:

postorder = [4, 6, 5, 9, 8],  逆序遍历: 8, 9, 5, 6, 4

  8: stack=[], 8入栈           stack=[8], upper=MAX
  9: 9>8(栈顶), 9入栈          stack=[8,9], upper=MAX  (9是8的右子树)
  5: 5<9(栈顶), 弹栈找上界
     弹出9, upper=9
     弹出8, upper=8
     5入栈                     stack=[5], upper=8  (5是8的左子树)
  6: 6>5(栈顶), 6入栈          stack=[5,6], upper=8  (6是5的右子树)
     6<8(upper) ✓
  4: 4<6(栈顶), 弹栈找上界
     弹出6, upper=6
     弹出5, upper=5
     4入栈                     stack=[4], upper=5  (4是5的左子树)
     4<5(upper) ✓

全部通过 → true ✓
```

```cpp
class Solution {
public:
    bool verifyTreeOrder(vector<int>& postorder) {
        stack<int> stk;
        int upper = INT_MAX; // 当前节点的上界
        // 逆序遍历：根-右-左
        for (int i = postorder.size() - 1; i >= 0; i--) {
            if (postorder[i] > upper) return false;
            // 弹栈找到正确的祖先作为上界
            while (!stk.empty() && postorder[i] < stk.top()) {
                upper = stk.top();
                stk.pop();
            }
            stk.push(postorder[i]);
        }
        return true;
    }
};
```

## 关键提示

- **提示1**：后序遍历的核心性质——最后一个元素是根。这是整个算法的出发点。
- **提示2**：分界点 m 的含义——`post[l..m-1]` 全 < root，`post[m..r-1]` 全 > root。这完美对应了BST的"左 < 根 < 右"。
- **提示3**：左子树的验证是"自动"的——扫描找 m 时已经确认了 `post[l..m-1] < root`。只需额外验证右子树部分。
- **提示4**：单调栈方法的直觉——逆序遍历后序 = "根-右-左"的顺序，这类似于前序遍历的镜像。
- **提示5**：空数组和单元素数组都是合法的后序遍历序列。
- **提示6**：题目保证无重复数字，简化了判断（不用处理相等的情况）。

## 易错点

1. **忘记处理空数组**：`postorder` 为空时应返回 true。
2. **分界点找错**：应该找**第一个 >= root**的位置，不是 **> root**（题目保证无重复，所以 >= 和 > 等价，但 >= 更严谨）。
3. **递归范围错误**：右子树的递归范围是 `[m, r-1]`（不包含 r，因为 r 是根），不是 `[m, r]`。
4. **单调栈中 upper 的更新**：弹栈时要持续更新 upper，不能只取最后一个弹出的值（实际上就是最后一个弹出的，但逻辑要清晰）。
5. **面试时忘记说明最坏复杂度**：递归分治最坏是 O(n^2)，需要主动提及并提供 O(n) 的单调栈优化。

## 复杂度分析

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 递归分治 | O(n^2) 最坏 | O(n) 递归栈 | 平衡时 O(n log n) |
| 单调栈 | O(n) | O(n) 栈空间 | 每个元素最多入栈出栈各一次 |

## BST 遍历性质总结

```
BST 的三种遍历与性质:

前序(根-左-右): 第一个元素是根, 根后面先是左子树(全<根)再是右子树(全>根)
中序(左-根-右): 结果是严格递增序列
后序(左-右-根): 最后一个元素是根, 根前面先是左子树(全<根)再是右子树(全>根)

验证BST的后序遍历:
  [left_part, right_part, root]
   全 < root   全 > root
  
  找分界: 第一个 >= root 的位置
  验证: 右子树部分无 < root 的值
  递归: 分别验证两部分
```

## Follow-up 思考

1. **如果数组中有重复元素怎么办？** 需要用 `<=` 和 `>` 来划分左右子树（取决于BST对相等元素的处理方式），且分界点可能不唯一。
2. **如果要求输出构造的BST？** 在验证的同时可以顺便构造树：每层递归创建节点，连接左右子树。
3. **如果给的是前序遍历序列？** 类似思路，但第一个元素是根，接下来先是左子树（全 < 根）再是右子树（全 > 根）。
