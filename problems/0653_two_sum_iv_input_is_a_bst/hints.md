# 653. 两数之和 IV - 输入二叉搜索树 (Two Sum IV - Input is a BST)

**难度**: Easy | **标签**: Tree, DFS, BFS, BST, Hash Table, Two Pointers

## 核心思路

本题是经典 Two Sum 在 BST 上的变体。核心有三种策略：

1. **DFS/BFS + HashSet**：遍历树的同时，用集合记录已访问节点值，检查 `k - val` 是否存在。简单直接。
2. **中序遍历 + 双指针**：利用 BST 中序遍历有序的特性，先转化为有序数组，再用双指针 Two Sum。
3. **BST 迭代器双指针**：不转化为数组，用两个栈模拟正向和反向中序遍历迭代器，空间 O(h)。

## 思维链

1. **识别题型**：Two Sum 变体 -> 需要找两个数和为 k
2. **利用数据结构特性**：输入是 BST -> 中序遍历有序 -> 可用双指针
3. **权衡方案**：
   - HashSet 方案最简单，O(n) 时间 O(n) 空间
   - 中序 + 双指针同样 O(n) 时间 O(n) 空间，但利用了 BST 性质
   - BST 迭代器方案 O(n) 时间 O(h) 空间，最优但实现复杂
4. **面试选择**：先写 HashSet 方案快速 AC，再讨论优化

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| DFS + HashSet | O(n) | O(n) | 最简单，不利用 BST 性质 |
| 中序遍历 + 双指针 | O(n) | O(n) | 利用 BST 有序性 |
| BST 迭代器双指针 | O(n) | O(h) | 空间最优，面试加分 |

## 关键提示

1. **HashSet 方案**：遍历每个节点时检查 `set.count(k - node->val)`，注意不要把同一个节点和自己配对（但本题节点值可重复，所以 `k = 2 * val` 时需要确认集合里已有该值）
2. **BST 中序有序**：中序遍历 BST 得到升序数组，直接使用 Two Sum II（有序数组双指针）
3. **双指针逻辑**：`left` 从最小值开始，`right` 从最大值开始，`sum < k` 则 `left++`，`sum > k` 则 `right--`
4. **BST 迭代器**：正向迭代器用栈维护"一路向左"，反向迭代器用栈维护"一路向右"
5. **避免 left == right**：双指针在数组方案中用下标判断，在迭代器方案中用节点指针判断

## 解法详解

### 解法一：DFS + HashSet

**思路**：最直接的方法，遍历树的每个节点，在 HashSet 中查找互补值。

**步骤**：
1. 创建一个 `unordered_set<int>`
2. DFS 遍历树（前序/中序/后序均可）
3. 对每个节点：
   - 检查 `k - node->val` 是否在 set 中
   - 若在，返回 true
   - 若不在，将 `node->val` 加入 set
4. 遍历完毕仍未找到，返回 false

### 解法二：中序遍历 + 双指针

**思路**：先中序遍历 BST 得到有序数组，再用经典双指针解 Two Sum。

**步骤**：
1. 中序遍历 BST，将所有节点值存入 `vector<int> sorted`
2. 初始化 `left = 0, right = sorted.size() - 1`
3. 循环 `while (left < right)`:
   - `sum = sorted[left] + sorted[right]`
   - `sum == k` -> 返回 true
   - `sum < k` -> `left++`
   - `sum > k` -> `right--`
4. 循环结束返回 false

### 解法三：BST 迭代器双指针（最优空间）

**思路**：用两个栈分别模拟正向和反向的中序遍历迭代器，无需将整棵树转为数组。

**步骤**：
1. 正向迭代器：栈中维护从根一路向左的节点，`next()` 弹出栈顶并将右子树一路向左压栈
2. 反向迭代器：对称地一路向右
3. 取正向的最小值和反向的最大值，进行双指针判断
4. 当正向和反向指向同一节点时停止

## 易错点

1. **同一节点不能用两次**：虽然本题数据中 BST 节点值不重复（BST 性质），但面试中需确认这一点。如果值可重复，HashSet 方案中 `k = 2*val` 需要注意
2. **中序遍历顺序错误**：必须是左 -> 根 -> 右，才能得到升序序列
3. **双指针终止条件**：数组方案是 `left < right`（不是 `<=`），迭代器方案需比较节点指针
4. **空树处理**：root 为 null 时直接返回 false
5. **BST 迭代器方案中栈的初始化**：正向栈初始化时要把根节点一路向左全部压入，反向对称

## 面试追问

1. **Q: 如果输入不是 BST 而是普通二叉树，哪些解法还能用？**
   - A: HashSet 方案完全不依赖 BST 性质，仍然可用。双指针方案不能直接用，因为中序遍历结果不再有序。

2. **Q: BST 迭代器方案的空间复杂度为什么是 O(h)？**
   - A: 每个栈最多存储从根到叶的路径长度 h 个节点。两个栈共 O(h)。对平衡 BST，h = O(log n)。

3. **Q: 如果 BST 很大，不能全部加载到内存怎么办？**
   - A: BST 迭代器方案只需 O(h) 空间，h = O(log n) 对平衡树来说非常小。也可以考虑 B-Tree 等磁盘友好的数据结构。

4. **Q: 能否只用 BST 的搜索特性，不遍历全部节点？**
   - A: 可以对每个节点 val，在 BST 中搜索 k-val。时间 O(n * h)，空间 O(h)。但总时间比其他方案差。

5. **Q: 如果要求返回所有满足条件的节点对呢？**
   - A: 双指针方案最合适，找到一对后不停止，继续移动两个指针。HashSet 方案需要用 multiset 处理重复值情况。
