# 548. 将数组分割成和相等的子数组

## 核心思路

用前缀和 + 固定中间切割点 j 的策略：枚举 j，对每个 j，分别在左半和右半找合法的切割点 i 和 k。用 HashSet 记录左半所有可能的子数组和，然后在右半查找匹配。

## 思维链

1. **读完题第一反应**：三刀切四段，每段和相等。暴力枚举 i, j, k 三个切割点是 O(n^3)，n=2000 约 8*10^9，超时。

2. **优化方向**：能否固定一个变量，降低枚举维度？如果固定 j（中间切割点），则左半 `[0, j-1]` 中找 i，右半 `[j+1, n-1]` 中找 k，各需 O(n)。

3. **前缀和加速**：先计算前缀和 `prefix[i]`。四段的和可以用前缀和 O(1) 求出：
   - 第一段：`prefix[i]`
   - 第二段：`prefix[j] - prefix[i+1]`
   - 第三段：`prefix[k] - prefix[j+1]`
   - 第四段：`prefix[n] - prefix[k+1]`

4. **HashSet 技巧**：对固定的 j，遍历左半所有合法 i，如果第一段 == 第二段，将该值加入 set。然后遍历右半所有合法 k，如果第三段 == 第四段且该值在 set 中，返回 true。

5. **总复杂度**：枚举 j 为 O(n)，每个 j 内遍历 i 和 k 共 O(n)，总 O(n^2)。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 前缀和 + 枚举 j + HashSet | 固定 j，左右各扫一遍 | O(n^2) | O(n) | ⭐ 必须掌握 |
| 暴力三重循环 | 枚举 i, j, k | O(n^3) | O(n) | 超时，仅说思路 |

## 关键提示

- **提示 1**：先求前缀和数组。四段的和都能用 O(1) 表示。

- **提示 2**：固定 j 后，问题拆成两个独立子问题：左半找 i 使第一段==第二段，右半找 k 使第三段==第四段。再用 HashSet 连接两边。

- **提示 3**：j 的范围是 `[3, n-4]`（确保四段都非空），i 的范围是 `[1, j-2]`，k 的范围是 `[j+2, n-2]`。

- **提示 4（ASCII 图解）**：
```
// nums = [1, 2, 1, 2, 1, 2, 1]
// prefix = [0, 1, 3, 4, 6, 7, 9, 10]
//
// 固定 j=3:
//   左半 [0..2], 枚举 i:
//     i=1: 第一段=prefix[1]=1, 第二段=prefix[3]-prefix[2]=4-3=1
//          1==1 ✓, 加入 set={1}
//   右半 [4..6], 枚举 k:
//     k=5: 第三段=prefix[5]-prefix[4]=7-6=1
//          第四段=prefix[7]-prefix[6]=10-9=1
//          1==1 ✓, 且 1 在 set 中 ✓ → 返回 true
```

## 解法详解

### 解法 1: 前缀和 + 枚举 j + HashSet -- O(n^2) / O(n) ⭐ 面试首选

```cpp
class Solution {
public:
    bool splitArray(vector<int>& nums) {
        int n = nums.size();
        if (n < 7) return false;
        
        // 前缀和
        vector<int> prefix(n + 1, 0);
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }
        
        // 枚举中间切割点 j
        for (int j = 3; j < n - 3; j++) {
            unordered_set<int> seen;
            
            // 左半：枚举 i ∈ [1, j-2]
            for (int i = 1; i < j - 1; i++) {
                int sum1 = prefix[i];                    // 第一段 [0, i-1]
                int sum2 = prefix[j] - prefix[i + 1];    // 第二段 [i+1, j-1]
                if (sum1 == sum2) {
                    seen.insert(sum1);
                }
            }
            
            // 右半：枚举 k ∈ [j+2, n-2]
            for (int k = j + 2; k < n - 1; k++) {
                int sum3 = prefix[k] - prefix[j + 1];    // 第三段 [j+1, k-1]
                int sum4 = prefix[n] - prefix[k + 1];    // 第四段 [k+1, n-1]
                if (sum3 == sum4 && seen.count(sum3)) {
                    return true;
                }
            }
        }
        
        return false;
    }
};
```

**关键点**：
- 前缀和让区间求和变成 O(1)
- 固定 j 后，左右独立扫描，用 HashSet 桥接
- n < 7 时不可能切出四段非空

## 易错点

1. **✗ j 的范围写成 `[1, n-2]`**：导致某些段为空。
   **✓ j 的范围是 `[3, n-4]`**，确保四段都至少有一个元素。

2. **✗ 前缀和下标搞混**：`prefix[i]` 代表 `nums[0..i-1]` 的和还是 `nums[0..i]`？
   **✓ 统一定义**：`prefix[0] = 0`, `prefix[i] = nums[0] + ... + nums[i-1]`。第一段 `[0, i-1]` 的和 = `prefix[i]`。

3. **✗ 忘记 n < 7 的提前返回**：至少需要 7 个元素（4段+3个切割点）。
   **✓ 开头加 `if (n < 7) return false;`**。

4. **✗ 只检查 sum3 == sum4 忘了和 set 比较**：三段都相等才行。
   **✓ 条件是 `sum3 == sum4 && seen.count(sum3)`**。

## 面试追问

**Q1：为什么选择固定 j 而不是 i 或 k？**
→ j 是中间切割点，固定它后左右两半完全独立，可以分别处理。如果固定 i，则 j 和 k 的搜索仍然耦合。

**Q2：能否进一步优化到 O(n)？**
→ 很难。问题本质上需要在两个独立区间内找匹配的和值，HashSet 已经是最优的桥接方式。

**Q3：如果允许段可以为空（长度为 0），怎么改？**
→ 放宽 i, j, k 的范围即可。但空段的和为 0，可能产生大量假阳性匹配。
