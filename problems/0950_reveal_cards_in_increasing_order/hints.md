# 950. Reveal Cards In Increasing Order

## 核心思路

要求对牌组重新排列，使得按照"揭示顶牌、把下一张放到底部"的操作流程后，揭示顺序恰好递增。核心方法是**模拟逆过程**：先将牌排序得到目标揭示顺序，再用一个**队列模拟索引分配**。队列初始化为 [0, 1, 2, ..., n-1]，每次从队首取出一个索引放入结果对应位置（对应当前最小牌），然后把下一个队首索引移到队尾（模拟"跳过"操作），直到队列为空。

## 思维链

1. **理解操作流程**：每次取顶牌揭示，然后把下一张移到底部。我们需要安排初始顺序使揭示结果递增
2. **正向思考很难**：直接从操作推导初始排列需要逆向模拟，不直观
3. **转换为索引分配**：将排序后的牌按顺序分配到"模拟揭示顺序"对应的位置
4. **用队列模拟揭示顺序**：队列存放位置索引 [0..n-1]，模拟揭示过程确定每个牌应放在哪个位置
5. **填充结果数组**：排序后第 i 小的牌放在队列第 i 次弹出的索引位置

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 队列模拟索引分配 | O(n log n) | O(n) | 最直观清晰的标准解法 |
| 逆向模拟（deque） | O(n log n) | O(n) | 从最大牌开始，逆向还原 |

## 关键提示

1. **队列存索引不存值**：队列模拟的是"位置的揭示顺序"，不是牌本身
2. **排序是前提**：必须先排序牌组，才能按从小到大分配位置
3. **"揭示+跳过"模式**：每取一个索引分配后，要把下一个索引从队首移到队尾
4. **逆向法的关键操作**：每次把队尾移到队首（逆转"移到底部"），再把当前牌插到队首
5. **结果数组大小**：与输入 deck 大小一致，n 个位置一一对应

## 解法详解

### 解法一：队列模拟索引分配（推荐）

**思路**：排序后我们知道揭示顺序应该是 sorted[0], sorted[1], ..., sorted[n-1]。问题变成：模拟揭示流程，确定每张牌应该放在初始牌组的哪个位置。

**步骤**：
1. 对 deck 排序得到 sorted 数组
2. 创建队列 q，初始化为 [0, 1, 2, ..., n-1]（代表初始牌组的位置索引）
3. 创建结果数组 result[n]
4. 遍历 sorted 中的每张牌：
   - 从队列前端取出索引 idx = q.front()，将当前牌放在 result[idx]
   - 如果队列非空，再把 q.front() 移到 q.back()（模拟"把下一张移到底部"）
5. 返回 result

**为什么正确**：队列模拟了揭示过程中位置的访问顺序。第一个被揭示的位置是 q[0]=0，我们把最小的牌放那里；第二个被揭示的位置由模拟确定，我们放第二小的牌，以此类推。

**复杂度**：时间 O(n log n)（排序主导），空间 O(n)。

### 解法二：逆向模拟（deque）

**思路**：从最大的牌开始，逆向模拟操作过程。每步先把当前结果的最后一张移到最前面（逆转"移到底部"），然后把当前牌插入最前面（逆转"揭示"）。

**步骤**：
1. 对 deck 降序排序
2. 创建空的 deque
3. 对每张牌（从大到小）：
   - 如果 deque 非空，把 deque 的最后一个元素移到最前面
   - 把当前牌插到 deque 最前面
4. 将 deque 转为 vector 返回

**直觉**：正向过程是"取顶 -> 移顶到底"，逆向就是"底移到顶 -> 插入顶部"。

**复杂度**：时间 O(n log n)，空间 O(n)。

## 易错点

1. **队列弹出后忘记跳过操作**：分配一个索引后，必须把下一个队首移到队尾
2. **最后一步不需要跳过**：当队列只剩一个元素时，取出后不需要再做跳过
3. **逆向模拟顺序错误**：必须先"底到顶"再"插入顶"，顺序不能反
4. **没有排序就开始模拟**：排序是必须的前提步骤
5. **索引越界**：在队列操作中确保检查队列是否为空再做跳过操作

## 面试追问

1. **Q: 如果操作规则变为"揭示一张，跳过k张"（k不一定为1），怎么修改？**
   A: 队列模拟中，每次分配一个索引后，循环 k 次将队首移到队尾即可。复杂度变为 O(n*k)。

2. **Q: 如何验证你的输出是否正确？**
   A: 用输出结果模拟一遍原始操作流程，检查揭示顺序是否严格递增。

3. **Q: 如果 deck 中有重复元素怎么办？**
   A: 算法不变，排序后相同元素的相对顺序不影响结果正确性（揭示顺序变为非递减）。

4. **Q: 这道题的队列模拟思想还能用在哪些场景？**
   A: 约瑟夫环问题、循环调度问题、任何需要模拟"循环取出"过程的场景。
