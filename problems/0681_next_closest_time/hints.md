# 681. Next Closest Time - 最近时刻

## 核心思路

给定一个合法时间字符串 "HH:MM"，用其中出现过的数字重新组合出下一个最近的合法时间。两种主要思路：(1) 模拟法 -- 从当前时间开始逐分钟推进，检查每个新时间的四位数字是否都在可用数字集合中，最多循环 1440 次。(2) 枚举法 -- 用可用数字的所有四元组合枚举所有合法时间，找出"下一个最近"的。模拟法实现最简单，枚举法效率略高但差别不大。

## 思维链

1. 读题：从 "19:34" 中提取数字 {1,9,3,4}，用这些数字组成下一个最近的时间。
2. "下一个最近"的定义：时间 t2 在 t1 之后最近。如果当天没有更大的时间，则跨天到第二天。
3. 关键观察：一天只有 1440 分钟，数字集合最多 4 个不同数字，解空间很小。
4. 模拟法：cur+1, cur+2, ...（模 1440），检查每个时间的 4 位数字是否都在集合中。
5. 枚举法：4^4 = 256 种组合，过滤出合法时间（小时<24, 分钟<60），找最近的。
6. 特殊情况：所有 4 位数字都相同（如 "11:11"），则结果就是原时间本身（24 小时后的同一时间）。
7. 时间复杂度：两种方法都是 O(1)，因为常数上界固定。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 优劣 |
|------|-----------|-----------|------|
| 模拟法（逐分钟推进） | O(1440) = O(1) | O(1) | 实现最简单，面试首选 |
| 枚举法（四重循环） | O(4^4) = O(1) | O(1) | 略快，逻辑稍复杂 |

## 关键提示

1. **提取数字集合**：从 "HH:MM" 中提取 4 个数字字符（跳过 ':'），去重后放入 set。注意可能只有 1-4 个不同数字。
2. **时间转分钟**：`minutes = h * 60 + m`，方便做模运算 `(minutes + delta) % 1440`。
3. **合法性检查**：小时 `h` 满足 `0 <= h < 24`，分钟 `m` 满足 `0 <= m < 60`。
4. **格式化输出**：结果需要补零，如 `02:05` 而不是 `2:5`。用 `sprintf` 或 `to_string` 手动补零。
5. **最小差值不为零**：找的是"下一个"时间，差值 > 0。如果所有候选时间都等于当前时间，差值为 1440（一整天），结果是当前时间本身。

## 解法详解

### 解法一：模拟法 -- 逐分钟推进（推荐）

**步骤**：
1. 提取当前时间中出现的所有数字到一个集合
2. 将当前时间转为分钟数 `cur`
3. 从 `cur + 1` 开始，每次加 1 分钟（对 1440 取模）
4. 将新的分钟数转回 `h:m` 格式，检查 4 个数字是否都在集合中
5. 第一个满足条件的时间就是答案
6. 最多循环 1440 次一定能找到（至少原时间本身满足条件）

**为什么正确**：逐分钟向前推进，第一个满足条件的就是最近的。

### 解法二：枚举法 -- 四重循环

**步骤**：
1. 提取数字集合（去重），设集合大小为 D（D <= 4）
2. 四重循环枚举所有 d1, d2, d3, d4 的组合（D^4 种）
3. 组成时间 `h = d1*10 + d2`，`m = d3*10 + d4`
4. 过滤合法时间（h < 24, m < 60）
5. 将合法时间转为分钟数，计算与当前时间的差值 `(candidate - cur + 1440) % 1440`
6. 差值最小且 > 0 的就是答案

**优点**：直接精确地找到所有候选，适合候选数很少的场景。

## 易错点

1. **差值为 0 也返回**：差值为 0 说明候选等于当前时间，不是"下一个"。但如果所有候选差值都为 0，结果就是当前时间（24小时循环）。
2. **格式化缺少前导零**：小时 `2` 应输出 `"02"`，分钟 `5` 应输出 `"05"`。
3. **模拟法的循环范围**：应从 `i = 1` 开始到 `i = 1440`，不是 `i = 0` 到 `i = 1439`（跳过自身）。
4. **数字提取时包含冒号**：遍历 "HH:MM" 时必须跳过 ':' 字符。
5. **枚举法忘记去重**：如果输入是 "11:11"，数字集合只有 {1}，四重循环只有 1 种组合 "11:11"，差值 = 1440，结果正确。

## 面试追问

1. **Q: 如果时间格式是 24 小时制含秒 "HH:MM:SS" 呢？**
   A: 模拟法推进单位变为秒，上界变为 86400。枚举法变成六重循环（D^6 种组合），检查 h < 24, m < 60, s < 60。

2. **Q: 如果要求用可用数字组成最大的合法时间呢？**
   A: 枚举所有合法时间后取最大值即可。也可以贪心：从高位到低位，在约束范围内选最大数字。

3. **Q: 如果允许使用额外的数字（0-9 任选），求下一个最近时间？**
   A: 直接逐分钟推进（当前时间 +1 分钟就是答案），因为没有数字约束。

4. **Q: 如果同时给你多个时间，求所有的下一个最近时间？**
   A: 可以一次性枚举出所有合法候选时间并排序。然后对每个输入时间用二分搜索找下一个。

5. **Q: 如何扩展到 12 小时制（AM/PM）？**
   A: 小时范围变为 1-12（或 01-12），需要处理 AM/PM 切换和 12:00 边界情况。
