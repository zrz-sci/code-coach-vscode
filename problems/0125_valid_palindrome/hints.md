# 125. 验证回文串

## 核心思路
这道题本质上是：**忽略非字母数字字符后，判断字符串是否对称**。关键在于如何高效地"跳过"无关字符并比较两端。

## 思维链
1. **读完题第一反应**：先把字符串"清洗"一下（去掉非字母数字、统一小写），然后判断是不是回文 → 这就是最朴素的做法。
2. **暴力解能不能更省？** 清洗需要额外建一个新字符串，能不能不建新字符串？
3. **怎么跳过无关字符？** 用两个指针从两端往中间走，遇到非字母数字字符就跳过，只在遇到有效字符时才比较。
4. **双指针的好处**：不需要额外空间存清洗后的字符串，原地操作，O(1) 空间。

## 解法概览
| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 预处理 + 反转比较 | 清洗字符串后反转对比 | O(n) | O(n) | 能说出即可 |
| 预处理 + 双指针 | 清洗字符串后首尾指针 | O(n) | O(n) | 能说出即可 |
| 原地双指针 | 不建新串，左右指针跳过无效字符 | O(n) | O(1) | ⭐ 必须写出 |

## 关键提示
- **提示1**：`isalnum()` 可以判断一个字符是否是字母或数字，`tolower()` 可以转小写。
- **提示2**：双指针从两端向中间走时，如果 `left` 指向非字母数字字符，只需要 `left++` 跳过即可，右边同理。
- **提示3**：注意循环内跳过字符时，也要检查 `left < right`，否则可能越界。
- **提示4**：空字符串（或全是非字母数字字符的字符串）应该返回 `true`。

```
// 双指针跳过无效字符的过程示意:
// 输入: "A man, a plan, a canal: Panama"
//        L                            R
//
// Step1: s[L]='A'(有效), s[R]='a'(有效), 'a'=='a' ✓ → L++, R--
//         L                          R
// Step2: s[L]=' '(无效) → L++
//          L                         R
// Step3: s[L]='m'(有效), s[R]='m'(有效), 'm'=='m' ✓ → L++, R--
//           L                       R
// ... 以此类推，始终对称匹配 → true
```

## 解法详解

### 解法1: 预处理 + 反转比较 — O(n) / O(n)
**思考过程**: 最直觉的想法——先把"噪音"去掉，得到一个纯净的字符串，然后判断它是不是回文。判断回文最简单的方式就是反转后看是否相同。

```cpp
class Solution {
public:
    bool isPalindrome(string s) {
        string cleaned;
        for (char c : s) {
            if (isalnum(c)) {
                cleaned += tolower(c);  // 只保留字母数字，统一小写
            }
        }
        string reversed = cleaned;
        reverse(reversed.begin(), reversed.end());
        return cleaned == reversed;     // 反转后与原串相同 → 回文
    }
};
```
**关键点**: 这种方法简单直观，但需要 O(n) 额外空间存储清洗后的字符串和反转后的副本。面试中可以作为第一步说出来，然后主动优化。

### 解法2: 预处理 + 双指针 — O(n) / O(n)
**从解法1优化**: 反转整个字符串其实没必要，回文的定义就是"首尾对称"，直接用两个指针从两端向中间比较即可。省去了反转的步骤（虽然复杂度量级不变）。

```cpp
class Solution {
public:
    bool isPalindrome(string s) {
        string cleaned;
        for (char c : s) {
            if (isalnum(c)) {
                cleaned += tolower(c);
            }
        }
        int left = 0, right = (int)cleaned.size() - 1;
        while (left < right) {
            if (cleaned[left] != cleaned[right]) return false;
            left++;
            right--;
        }
        return true;
    }
};
```
**关键点**: 比解法1少了一次字符串拷贝和反转，但仍需要 O(n) 空间存 `cleaned`。

### 解法3: 原地双指针 — O(n) / O(1) ⭐ 面试首选
**从解法2优化**: 解法2的"瓶颈"是需要 O(n) 空间来存清洗后的字符串。能不能直接在原字符串上操作？**可以！** 左右指针遇到无效字符直接跳过，只在有效字符处比较。

```cpp
class Solution {
public:
    bool isPalindrome(string s) {
        int left = 0, right = (int)s.size() - 1;
        while (left < right) {
            // 左指针跳过非字母数字字符
            while (left < right && !isalnum(s[left])) left++;
            // 右指针跳过非字母数字字符
            while (left < right && !isalnum(s[right])) right--;
            // 比较（忽略大小写）
            if (tolower(s[left]) != tolower(s[right])) return false;
            left++;
            right--;
        }
        return true;
    }
};
```
**关键点**:
- 内层 `while` 跳过无效字符时，**必须同时检查 `left < right`**，否则全是无效字符的字符串会导致指针越界。
- `tolower()` 在比较时调用，不需要修改原字符串。

## 解法对比
| | 预处理+反转 | 预处理+双指针 | 原地双指针 |
|---|---|---|---|
| 时间 | O(n) | O(n) | O(n) |
| 空间 | O(n) | O(n) | **O(1)** |
| 代码复杂度 | 最简单 | 简单 | 稍复杂（跳过逻辑） |
| 面试推荐 | 说思路即可 | 过渡 | **首选** |

**什么时候选哪个？**
- 原地双指针是面试标准答案，空间 O(1) 是明显优势。
- 预处理方式适合快速验证想法、在笔试中快速 AC。

## 易错点

1. **内层 while 漏掉 `left < right` 检查**
   - ✗ `while (!isalnum(s[left])) left++;` → 字符串全是空格/符号时，`left` 会越界
   - ✓ `while (left < right && !isalnum(s[left])) left++;`

2. **忘记转小写就比较**
   - ✗ `if (s[left] != s[right]) return false;` → `'A'` 和 `'a'` 会被判为不同
   - ✓ `if (tolower(s[left]) != tolower(s[right])) return false;`

3. **`isalnum` 和 `isalpha` 搞混**
   - `isalpha` 只判断字母，**不包含数字**
   - `isalnum` 判断字母**和**数字，本题需要 `isalnum`

4. **数字字符的处理**
   - 容易以为只有字母才算有效字符，题目明确说"字母和数字都属于字母数字字符"
   - 如 `"0P"` → 清洗后 `"0p"` → 不是回文 → `false`

## 面试追问

**Q1（基础理解）**: 你的暴力解是什么？时间空间各多少？
> 预处理清洗字符串 + 反转比较，O(n) 时间，O(n) 空间。

**Q2（优化）**: 能否不用额外空间？
> 原地双指针，左右指针跳过无效字符直接比较，O(1) 空间。

**Q3（变体）**: 如果允许最多删除一个字符，还能判断是否回文吗？
> 这就是 **LeetCode 680 验证回文串 II**。当 `s[left] != s[right]` 时，尝试跳过左边或右边各一个字符，分别检查剩余部分是否回文。复用本题的双指针框架，加一个"容错"分支。

**Q4（扩展）**: 如果输入是 Unicode 字符串（比如中文），你的方案需要改什么？
> `isalnum`/`tolower` 只适用于 ASCII。需要用 locale-aware 的函数或自行定义什么是"有效字符"和"大小写转换"规则。
