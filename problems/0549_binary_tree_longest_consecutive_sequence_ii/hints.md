# 549. 二叉树最长连续序列 II

## 核心思路

DFS 后序遍历，每个节点返回两个值：以它为端点的最长递增长度和最长递减长度。在当前节点处尝试合并左右子树的递增和递减路径形成"子-父-子"路径，更新全局最大值。

## 思维链

1. **读完题第一反应**：和 298 题类似但有两个关键区别：(1) 路径可以递增也可以递减；(2) 路径可以经过"子-父-子"（不一定纯粹从上到下）。

2. **子-父-子路径**：比如 [1,2,3]，路径 1→2→3 经过了父节点 2，方向是"左子→父→右子"。这意味着不能只维护单方向的连续长度。

3. **关键洞察**：对每个节点，维护两个信息 —— 以它为端点的「向下递增长度 inc」和「向下递减长度 dec」。如果左子 = 当前-1 且右子 = 当前+1，就能拼出一条"递减-当前-递增"路径。

4. **合并策略**：在当前节点 node 处，最长路径 = `left_inc + right_dec - 1` 或 `left_dec + right_inc - 1`（减 1 是因为 node 被算了两次）。取所有情况的最大值。

5. **递归返回值**：返回 `(inc, dec)` 给父节点。父节点只能从一侧延伸，不能同时用子节点的两个方向。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| DFS 返回 (inc, dec) | 后序遍历，每个节点返回递增递减长度 | O(n) | O(n) | ⭐ 必须掌握 |

## 关键提示

- **提示 1**：对每个节点，维护两个值 `inc`（以该节点为顶端的递增路径长度）和 `dec`（递减路径长度）。初始值都是 1（只有节点自身）。

- **提示 2**：如果 `left.val == node.val - 1`，则 `inc = max(inc, left_inc + 1)`（左子递增路径延伸到当前节点）。如果 `left.val == node.val + 1`，则 `dec = max(dec, left_dec + 1)`。

- **提示 3**：全局答案在当前节点处更新：可以用左子的 inc + 右子的 dec - 1（或反过来）形成经过当前节点的完整路径。

- **提示 4（ASCII 图解）**：
```
//       2          对于节点 2:
//      / \         左子=1, 1==2-1 → inc_from_left = 2
//     1   3        右子=3, 3==2+1 → inc_from_right = 2
//                  但路径 1→2→3 是「递增」的:
//                  全局答案 = inc_from_left + inc_from_right - 1
//                           = 2 + 2 - 1 = 3 ✓
//
//  换个角度：左边递增(1→2) + 右边递增(2→3)
//  合并: 左子给出 inc=2，右子给出 inc=2
//  但要从「递减→父→递增」角度看：
//  left_dec 是从左子往下递减（即往上递增到父）
```

## 解法详解

### 解法 1: DFS 返回 (inc, dec) -- O(n) / O(n) ⭐ 面试首选

**思考过程**：后序遍历，每个节点返回「以它为端点的递增/递减路径长度」。在当前节点合并左右子树路径更新全局答案。

```cpp
class Solution {
public:
    int longestConsecutive(TreeNode* root) {
        int ans = 0;
        dfs(root, ans);
        return ans;
    }
    
    // 返回 {inc, dec}
    // inc: 以 node 为顶端，向下的最长递增序列长度
    // dec: 以 node 为顶端，向下的最长递减序列长度
    pair<int, int> dfs(TreeNode* node, int& ans) {
        if (!node) return {0, 0};
        
        int inc = 1, dec = 1;  // 自身长度为 1
        
        auto [li, ld] = dfs(node->left, ans);
        auto [ri, rd] = dfs(node->right, ans);
        
        if (node->left) {
            if (node->left->val == node->val + 1) {
                inc = max(inc, li + 1);  // 左子递增延伸
            }
            if (node->left->val == node->val - 1) {
                dec = max(dec, ld + 1);  // 左子递减延伸
            }
        }
        
        if (node->right) {
            if (node->right->val == node->val + 1) {
                inc = max(inc, ri + 1);  // 右子递增延伸
            }
            if (node->right->val == node->val - 1) {
                dec = max(dec, rd + 1);  // 右子递减延伸
            }
        }
        
        // 合并：经过当前节点的最长路径
        // inc + dec - 1：递增一侧 + 递减一侧，node 被算了两次减 1
        ans = max(ans, inc + dec - 1);
        
        return {inc, dec};
    }
};
```

**关键点**：
- 每个节点返回的 `inc` 和 `dec` 是给父节点用的（父节点只能取一个方向延伸）
- 全局答案在每个节点处通过 `inc + dec - 1` 更新（合并两个方向）
- 和 543 题（直径）模式相同：「返回值 != 答案」

## 易错点

1. **✗ 只考虑单方向路径**：只维护递增或只维护递减。
   **✓ 必须同时维护 inc 和 dec**，因为路径可以"子-父-子"经过拐点。

2. **✗ 合并路径时忘记 -1**：`ans = inc + dec` 导致当前节点被算两次。
   **✓ `ans = inc + dec - 1`**。

3. **✗ 递增/递减方向搞反**：左子 == 父+1 应该更新 inc（从父到子是递增的），不是 dec。
   **✓ 子 == 父+1 → 递增方向 → 更新 inc**。

4. **✗ 合并左右子树时只考虑一种组合**：比如只考虑"左递增+右递减"，忽略"左递减+右递增"。
   **✓ 不需要显式考虑两种组合**，因为 inc 和 dec 分别取了左右两侧的最大值。

## 面试追问

**Q1：和 298 题 (Binary Tree Longest Consecutive Sequence I) 的区别？**
→ 298 只允许从上到下的递增路径，只需维护一个方向。549 允许递增/递减且可经过"子-父-子"，需要同时维护 inc 和 dec 并在每个节点合并。

**Q2：为什么 `inc + dec - 1` 就是经过当前节点的最长路径？**
→ inc 是从当前节点往一侧递增的长度，dec 是往另一侧递减的长度。合在一起形成一条单调路径（或经过拐点的路径），当前节点在两边各被计数一次，所以减 1。

**Q3：能否用 BFS 解？**
→ 可以但不自然。BFS 是逐层扩展，难以自底向上合并信息。DFS 后序遍历天然适合"先算子节点，再合并到父节点"的场景。
