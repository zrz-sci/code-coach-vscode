# 629. K 个逆序对数组

## 难度: Hard
## 标签: Dynamic Programming

## 题目理解
给定 n 和 k，求由 1~n 组成的排列中，恰好有 k 个逆序对的排列数目。结果对 10^9+7 取模。

## 关键观察
1. 把数字 n 插入到 1~(n-1) 的排列中，n 可以放在 n 个不同位置
2. 如果 n 放在从右往左第 j 个位置（j=0,1,...,n-1），则新增恰好 j 个逆序对
3. 这给出了递推关系：`dp[i][j] = sum(dp[i-1][j-x])` 其中 x 从 0 到 min(j, i-1)

## 解题思路

### 方法：DP + 前缀和优化
- 定义 `dp[i][j]` = 用 1~i 组成的排列中恰好有 j 个逆序对的方案数
- 转移方程：`dp[i][j] = dp[i-1][j] + dp[i-1][j-1] + ... + dp[i-1][j-(i-1)]`
- 直接求和是 O(n*k*n)，太慢。利用前缀和优化：
  - `dp[i][j] = prefix[i-1][j] - prefix[i-1][j-i]`（其中 prefix 是 dp[i-1] 的前缀和）
- 最终时间复杂度降为 O(n*k)

## 提示序列
1. 考虑将数字 i 插入已有排列，插入位置决定了新增的逆序对数
2. 定义 `dp[i][j]` 为用 1~i 恰好 j 个逆序对的方案数
3. 转移是连续区间求和，使用前缀和优化到 O(1) 单次转移

## 复杂度
- 时间：O(n * k)
- 空间：O(k)（可滚动数组优化）
