# 342. 4的幂

## 核心思路
判断一个整数是否是 4 的幂。关键观察：4 的幂一定是 2 的幂，且其唯一的 1-bit 在偶数位（bit0, bit2, bit4...）上。因此先判断是否为 2 的幂，再用位掩码 `0x55555555`（二进制 `01010101...`）检查 1-bit 是否在偶数位。

## 思维链
1. 4^x = (2^2)^x = 2^(2x) → 4 的幂一定是 2 的幂
2. 2 的幂的判断：`n > 0 && (n & (n-1)) == 0`
3. 但 2 的幂不一定是 4 的幂（如 8 = 2^3，不是 4 的幂）
4. 区别在于：4 的幂的二进制中，1 出现在 bit0, bit2, bit4...（偶数位）
5. 用掩码 `0x55555555`（32 位中偶数位全为 1）做 AND，结果不为 0 即可
6. 或者用数学方法：4^x % 3 = 1（而非 4 的幂的 2 的幂 mod 3 = 2）

## 解法概览表

| 解法 | 时间 | 空间 | 特点 |
|------|------|------|------|
| ⭐ 位运算（掩码法） | O(1) | O(1) | 最优雅，面试首选 |
| 位运算 + 取模法 | O(1) | O(1) | 数学证明简洁 |
| 循环除法 | O(log n) | O(1) | 最直观，但面试不够巧妙 |

## 关键提示
1. **n 必须 > 0**：0 和负数都不是 4 的幂
2. **掩码值 `0x55555555`**：二进制是 `01010101010101010101010101010101`，覆盖了 32 位 int 的所有偶数位
3. **为什么 4^x % 3 == 1？** 因为 4 = 3 + 1，所以 4^x = (3+1)^x，展开后除最后一项 1 外，其余都含 3 因子
4. **Follow-up 要求不用循环/递归**：位运算和取模法都满足

## 解法详解

### 解法一：位运算 + 掩码（推荐）

**思路**：先判断是 2 的幂（只有一个 1-bit），再判断 1-bit 在偶数位上。

```cpp
class Solution {
public:
    bool isPowerOfFour(int n) {
        // 1. n > 0
        // 2. n 是 2 的幂：只有一个 1-bit
        // 3. 1-bit 在偶数位：与 0x55555555 做 AND 不为 0
        return n > 0 && (n & (n - 1)) == 0 && (n & 0x55555555) != 0;
    }
};
```

**复杂度**：时间 O(1)，空间 O(1)

### 解法二：位运算 + 取模

**思路**：4 的幂 mod 3 恒等于 1，而非 4 的幂的 2 的幂（如 2, 8, 32...）mod 3 等于 2。

```cpp
class Solution {
public:
    bool isPowerOfFour(int n) {
        return n > 0 && (n & (n - 1)) == 0 && n % 3 == 1;
    }
};
```

**复杂度**：时间 O(1)，空间 O(1)

### 解法三：循环除法

**思路**：不断除以 4，如果最终等于 1 就是 4 的幂。

```cpp
class Solution {
public:
    bool isPowerOfFour(int n) {
        if (n <= 0) return false;
        while (n % 4 == 0) n /= 4;
        return n == 1;
    }
};
```

**复杂度**：时间 O(log n)，空间 O(1)

## 易错点

| ✗ 错误写法 | ✓ 正确写法 | 说明 |
|-----------|-----------|------|
| `n > 0 && (n & (n-1)) == 0` | 还需加 `&& (n & 0x55555555)` | 仅判断 2 的幂不够 |
| `n & 0x55555555 != 0` | `(n & 0x55555555) != 0` | 运算符优先级：`!=` 高于 `&` |
| 忘记 `n > 0` 的判断 | `n > 0 && ...` | n=0 时 `n & (n-1)` 也是 0 |
| `n & (n-1) != 0` | `(n & (n-1)) == 0` | 同样注意优先级和等号方向 |

## 面试追问

**Q1: 如何判断是否是 2 的幂？3 的幂？区别在哪？**
> - 2 的幂：`n > 0 && (n & (n-1)) == 0`，利用位运算
> - 3 的幂：不能用位运算，可以用 `3^19 % n == 0`（3^19 是 int 范围内最大的 3 的幂）
> - 4 的幂：结合 2 的幂判断 + 额外约束

**Q2: `0x55555555` 这个掩码怎么推导出来的？**
> 4^0 = 1 (bit0), 4^1 = 4 (bit2), 4^2 = 16 (bit4)... 所以 4 的幂的 1-bit 都在偶数位。将所有偶数位设为 1 得到 `0101...0101`，即 `0x55555555`。

**Q3: 如果要求判断是否是 k 的幂（k 为任意正整数），通用解法是什么？**
> - 如果 k 是质数：找 int 范围内最大的 k 的幂 M，判断 `M % n == 0`
> - 如果 k 是合数：循环除以 k 判断最终是否为 1
> - 如果 k 是 2 的幂（如 4=2^2, 8=2^3）：可以用位运算优化
