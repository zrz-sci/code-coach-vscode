# 781. 森林中的兔子 (Rabbits in Forest)

## 核心思路

本题是一个**贪心 + 分组计数**问题。如果一只兔子说"还有 k 只和我同色"，那么这一种颜色一共有 k+1 只兔子。为了最小化总数，我们应该尽可能让回答相同数字的兔子属于同一颜色组。一个颜色组最多容纳 k+1 只兔子，超出的需要分配新的颜色组。最终答案 = 所有颜色组的数量 * 每组大小。

## 思维链

1. **理解答案含义**：兔子回答 `k` 表示"除我以外还有 k 只同色兔子"，所以这个颜色共有 `k + 1` 只。
2. **贪心策略**：回答相同数字 `k` 的兔子应尽量归入同一组，每组最多 `k + 1` 只。
3. **分组计算**：统计回答 `k` 的兔子有 `count` 只。需要的组数 = `ceil(count / (k + 1))`。每组贡献 `k + 1` 只兔子。
4. **向上取整公式**：`ceil(count / (k+1)) = (count + k) / (k + 1)`（整数除法）。
5. **累加所有组**：对每个不同的回答值，累加 `组数 * (k + 1)`。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 哈希表计数 + 贪心 | O(n) | O(n) | 最优解，统计后一次性计算 |
| 排序 + 分组 | O(n log n) | O(1) | 排序后顺序扫描分组 |
| 在线处理 | O(n) | O(n) | 边遍历边分配槽位 |

## 关键提示

1. 回答 `k` 的兔子，同色组大小是 `k + 1`，不是 `k`（别忘了兔子自己）
2. 回答不同数字的兔子**不可能**同色（否则答案矛盾）
3. 回答相同数字的兔子**可能**不同色——当数量超过 `k + 1` 时必须分成多组
4. 向上取整是核心计算：`ceil(a/b) = (a + b - 1) / b`
5. 回答 `0` 的兔子每只都是独一无二的颜色——每只贡献 1

## 解法详解

### 解法一：哈希表计数 + 贪心（推荐）

**核心思想**：用哈希表统计每个回答值的出现次数，然后对每个回答值计算需要的最少兔子数。

**算法步骤**：
1. 遍历 `answers`，用 `unordered_map<int, int>` 统计每个值的出现次数
2. 对于每个 `(k, count)` 对：
   - 每组大小 = `k + 1`
   - 需要的组数 = `ceil(count / (k + 1))` = `(count + k) / (k + 1)`
   - 该回答值贡献的兔子数 = 组数 * `(k + 1)`
3. 累加所有贡献

**示例推演** `[1, 1, 2]`：
- 回答 1 的有 2 只。组大小 = 2，需要 1 组。贡献 = 1 * 2 = 2
- 回答 2 的有 1 只。组大小 = 3，需要 1 组。贡献 = 1 * 3 = 3
- 总计 = 2 + 3 = **5**

**示例推演** `[10, 10, 10]`：
- 回答 10 的有 3 只。组大小 = 11，需要 ceil(3/11) = 1 组。贡献 = 1 * 11 = 11
- 总计 = **11**

### 解法二：排序 + 分组

**核心思想**：排序后，连续相同值的兔子可以分组处理。

**算法步骤**：
1. 对 `answers` 排序
2. 遍历排序后的数组，用一个计数器跟踪当前组的剩余容量
3. 对于每只兔子：
   - 如果和前一只回答相同且当前组还有空间 -> 加入当前组
   - 否则 -> 开一个新组，总数 += `k + 1`

### 解法三：在线处理

**核心思想**：遍历过程中维护每个回答值当前组的剩余容量。当剩余容量用完或第一次遇到该值时，开一个新组。

**算法步骤**：
1. 用哈希表 `remaining` 记录每个回答值当前组的剩余槽位
2. 遍历每只兔子：
   - 如果 `remaining[k] == 0` 或未见过 -> 开新组，`total += k+1`，`remaining[k] = k`
   - 否则 -> `remaining[k]--`

## 易错点

1. **忘记 +1**：兔子说的是"其他"同色兔子数，加上自己才是组大小。`k=0` 表示只有自己，组大小 = 1
2. **回答不同的兔子归入同组**：回答 1 和回答 2 的兔子绝对不同色，必须分开处理
3. **整数除法的向上取整**：直接 `count / (k+1)` 是向下取整，必须用 `(count + k) / (k + 1)`
4. **回答 0 的特殊处理**：回答 0 的每只兔子都是唯一颜色，每只贡献 1。用通用公式也能正确处理：组大小=1，组数=count
5. **count > k+1 的处理**：例如 3 只兔子都回答 1，但组大小是 2，所以需要 2 组，共 4 只兔子（有 1 只没出现在数组中）

## 面试追问

1. **为什么回答不同数字的兔子不能同色？**
   - 如果兔子 A 说"还有 1 只同色"，兔子 B 说"还有 2 只同色"，若它们同色，那它们看到的同色兔子数应该相同（因为颜色相同意味着组大小固定），矛盾。

2. **为什么 count > k+1 时需要多个组？**
   - 一个颜色组只有 k+1 只兔子。如果有 count 只兔子都回答 k，但 count > k+1，说明它们不可能全是同一颜色。至少需要 `ceil(count/(k+1))` 种不同颜色来容纳。

3. **如果允许兔子说谎呢？**
   - 如果兔子可以说谎，问题变为一个无法确定下界的开放问题。当前解法建立在"所有回答都真实"的假设上。

4. **时间复杂度能优化到 O(n) 吗？**
   - 哈希表解法已经是 O(n) 了。排序解法是 O(n log n)。在这个约束下（n <= 1000），两者都很快。

5. **如果 answers 中有负数？**
   - 题目保证 `0 <= answers[i] < 1000`，不会有负数。但如果有，含义不明确（"负数只同色兔子"没有意义），应视为无效输入。
