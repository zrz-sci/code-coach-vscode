# 193. 有效电话号码

## 核心思路

本质上就是一个**正则表达式匹配**的问题：从文件中筛选出符合两种格式之一的电话号码行。格式为 `xxx-xxx-xxxx` 或 `(xxx) xxx-xxxx`，x 代表数字。Shell 中 grep、awk、sed 都能做正则匹配。

## 思维链

1. **读完题第一反应** → 两种合法格式，写正则匹配就行。关键是正则要精确匹配**整行**（不能是子串匹配）。
2. **格式分析**：
   - 格式A: `xxx-xxx-xxxx` → `[0-9]{3}-[0-9]{3}-[0-9]{4}`
   - 格式B: `(xxx) xxx-xxxx` → `\([0-9]{3}\) [0-9]{3}-[0-9]{4}`
3. **怎么确保整行匹配？** → 用 `^` 和 `$` 锚定行首行尾，防止 "abc987-123-4567xyz" 这样的误匹配。
4. **用什么工具？** → `grep -E`（扩展正则）最简洁；`awk` 和 `sed` 也可以。

## 解法概览

| 解法 | 思路 | 工具 | 面试 |
|------|------|------|------|
| grep -E | 扩展正则匹配整行 | grep | ⭐ 必须写出 |
| grep -P | Perl正则 | grep | 可选 |
| awk 正则 | awk 内置正则匹配 | awk | 加分项 |
| sed 正则 | sed 删除不匹配行 | sed | 可选 |

## 关键提示

1. **`^` 和 `$` 的重要性**：不加锚点的正则会做子串匹配。`grep '123'` 会匹配包含 "123" 的任何行。必须 `^...$` 精确匹配整行。
2. **`(` 和 `)` 的转义**：
   - 基本正则 (BRE, `grep`): `(` 是普通字符，`\(` 是分组
   - 扩展正则 (ERE, `grep -E`): `(` 是分组，`\(` 是匹配字面括号
   - 题目中电话号码格式包含字面括号 `(xxx)`，在 `grep -E` 中要写 `\(`。
3. **`[0-9]` vs `\d`**：`grep -E` 不支持 `\d`，要用 `[0-9]`。`grep -P`（Perl模式）支持 `\d`。
4. **注意空格**：`(xxx) xxx-xxxx` 中括号后有一个空格，正则中必须包含这个空格。

## 解法详解

### 解法1: grep -E 扩展正则 — ⭐ 面试首选

**正则分析**:
```
格式A: ^[0-9]{3}-[0-9]{3}-[0-9]{4}$
  ^          → 行首
  [0-9]{3}   → 3个数字
  -          → 字面横杠
  [0-9]{3}   → 3个数字
  -          → 字面横杠
  [0-9]{4}   → 4个数字
  $          → 行尾

格式B: ^\([0-9]{3}\) [0-9]{3}-[0-9]{4}$
  \(         → 字面左括号（在ERE中(是分组，要\转义匹配字面括号）
  [0-9]{3}   → 3个数字
  \)         → 字面右括号
  (空格)     → 字面空格
  [0-9]{3}-[0-9]{4} → 同格式A的后半部分
```

```bash
# 解法1: grep -E，用 | 连接两种格式
grep -E '^([0-9]{3}-|\([0-9]{3}\) )[0-9]{3}-[0-9]{4}$' file.txt
```

---

### 解法2: awk 正则

```bash
# 解法2: awk 正则匹配
awk '/^([0-9]{3}-|\([0-9]{3}\) )[0-9]{3}-[0-9]{4}$/' file.txt
```

---

### 解法3: sed 删除不匹配行

```bash
# 解法3: sed 保留匹配行（删除不匹配的行）
sed -n -E '/^([0-9]{3}-|\([0-9]{3}\) )[0-9]{3}-[0-9]{4}$/p' file.txt
```

---

### 解法4: grep 基本正则（不用 -E）

```bash
# 解法4: 基本正则（BRE），{} 和 | 需要转义
grep '^\([0-9]\{3\}-\|([0-9]\{3\}) \)[0-9]\{3\}-[0-9]\{4\}$' file.txt
```

## 易错点

1. **忘记行首行尾锚点**：
   - ✗ `grep -E '[0-9]{3}-[0-9]{3}-[0-9]{4}'` → 子串匹配，"abc123-456-7890xyz" 也会被匹配
   - ✓ `grep -E '^[0-9]{3}-[0-9]{3}-[0-9]{4}$'` → 精确整行匹配

2. **括号转义方向搞反**：
   - ✗ `grep -E '(xxx)'` → 这是分组，不是匹配字面括号
   - ✓ `grep -E '\(xxx\)'` → `\(` 在 ERE 中匹配字面左括号

3. **漏掉括号格式中的空格**：
   - ✗ `\([0-9]{3}\)[0-9]{3}` → `(123)456` 没有空格
   - ✓ `\([0-9]{3}\) [0-9]{3}` → `(123) 456` 括号后有空格

4. **数字位数写错**：
   - ✗ `[0-9]{3}-[0-9]{3}-[0-9]{3}` → 最后应该是4位不是3位
   - ✓ `[0-9]{3}-[0-9]{3}-[0-9]{4}`

## 面试追问

**Q1: grep -E 和 grep -P 有什么区别？**
> `-E` 是 POSIX 扩展正则（ERE），不支持 `\d`、`\b` 等简写。`-P` 是 Perl 正则（PCRE），功能更强，支持 `\d`、lookahead/lookbehind 等。macOS 的 grep 默认不支持 `-P`。

**Q2: 如果要从字符串中提取电话号码（子串匹配），怎么改？**
> 去掉 `^` 和 `$` 锚点，并加 `-o` 参数只输出匹配的部分：`grep -oE '([0-9]{3}-|\([0-9]{3}\) )[0-9]{3}-[0-9]{4}'`。

**Q3: 如果电话号码格式更复杂（如允许 +1 前缀、允许点分隔），正则怎么写？**
> 可以用 `(\+1[- ]?)?` 匹配可选的国际前缀，用 `[.-]` 匹配多种分隔符。复杂正则建议拆开写，或用命名分组增强可读性。
