# 899. 有序队列

## 核心思路

本质上是一个**数学观察题**，关键的分水岭在 k 的值：当 k=1 时只能做"循环旋转"，找所有旋转中字典序最小的；当 k>=2 时可以实现任意排列（等价于冒泡排序），所以直接排序就是答案。理解"k>=2 为什么能实现任意排列"是这道题的精髓。

## 思维链

1. **读完题第一反应** → 操作是：从前 k 个字符中选一个移到末尾。可以执行任意多次。要找字典序最小的结果。
2. **先看简单情况 k=1** → 只能把第一个字符移到末尾，这就是字符串的循环旋转。n 个字符有 n 种旋转，比较所有旋转取字典序最小即可。
3. **再看 k=2** → 可以把第1个或第2个字符移到末尾。这多了什么能力？试几个例子发现：可以交换相邻两个字符的顺序！
4. **为什么 k=2 能交换相邻字符？** → 设字符串是 `ab...`。先移 `b` 到末尾得 `a...b`，再移 `a` 到末尾得 `...ba`。然后通过旋转把 `...ba` 调整回来，效果就是原来的 `ab` 变成了 `ba`。能交换相邻字符 = 冒泡排序 = 能实现任意排列。
5. **k>=3 呢？** → k>=2 就已经能实现任意排列了，k>=3 只是多了更多选择，不会改变"能排成任意顺序"这个结论。
6. **总结** → if k==1: 枚举所有旋转取最小；if k>=2: 直接排序。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 分类讨论 (k=1 vs k>=2) | k=1 枚举旋转，k>=2 排序 | O(n²) / O(n log n) | O(n) | ⭐ 唯一正解 |
| k=1 用最小旋转优化 | Booth's algorithm 找最小旋转 | O(n) | O(n) | 竞赛加分 |

## 关键提示

1. **k=1 的本质是循环旋转**：把第一个字符移到末尾 = 字符串旋转一位。所以 k=1 时只能在 n 种旋转中选最小的。
2. **k>=2 能实现冒泡排序**：能交换相邻两个字符就等价于能做冒泡排序，冒泡排序能把字符串排成任意顺序。所以 k>=2 时答案就是字符串排序后的结果。
3. **为什么 k>=2 能交换相邻字符**：设前两个字符是 `ab`，其余是 `S`。操作序列：`abS → aSb → Sba → ... → baS`（后面通过旋转调回来）。效果：`a` 和 `b` 交换了位置。
4. **k=1 的暴力实现**：生成字符串的所有旋转 `s[i:] + s[:i]`（i = 0 到 n-1），取字典序最小。时间 O(n²)。
5. **k=1 的进阶**：Booth's algorithm 可以 O(n) 找到最小旋转，但面试中通常不要求。

## 解法详解

### 解法: 分类讨论 — O(n²) or O(n log n) / O(n)

**思考过程**: 这道 Hard 题的难度不在编码，而在数学推理。一旦理解了 k=1 和 k>=2 的本质区别，代码非常简短。

**k=1 的详细推导:**
```
s = "cba", k = 1
可能的旋转:
  "cba"  (原始)
  "bac"  (c移到末尾)
  "acb"  (b移到末尾)
最小: "acb" ✓

s = "baaca", k = 1
可能的旋转:
  "baaca"
  "aacab"
  "acaba"
  "cabaa"
  "abaac"
最小: "aacab"

但题目说答案是 "aaabc"，因为 k=3 >= 2，可以排序！
```

**k>=2 的证明（交换相邻字符）:**
```
字符串: a b [rest]，k>=2，可以选第1个或第2个移到末尾

步骤1: 选第2个字符 b，移到末尾
  a b [rest] → a [rest] b

步骤2: 选第1个字符 a，移到末尾  
  a [rest] b → [rest] b a

步骤3: 通过连续旋转把 [rest] 从前面移到后面
  （每次选第1个移到末尾，重复 len(rest) 次）
  [rest] b a → b a [rest]

最终效果: a b [rest] → b a [rest]
  a 和 b 交换了！这就是冒泡排序的基本操作。
  任意相邻交换 = 冒泡排序 = 能生成任意排列。
```

```cpp
class Solution {
public:
    string orderlyQueue(string s, int k) {
        if (k == 1) {
            // k=1: 只能循环旋转，枚举所有旋转取最小
            string minStr = s;
            for (int i = 1; i < (int)s.size(); i++) {
                string rotated = s.substr(i) + s.substr(0, i);
                if (rotated < minStr) {
                    minStr = rotated;
                }
            }
            return minStr;
        } else {
            // k>=2: 能实现任意排列，直接排序
            sort(s.begin(), s.end());
            return s;
        }
    }
};
```

**关键点**:
- k=1 时，`s.substr(i) + s.substr(0, i)` 生成以位置 i 开头的旋转。比较 n 个长度为 n 的字符串，时间 O(n²)。
- k>=2 时，`sort` 时间 O(n log n)。
- 代码极其简短——这道题的价值在于推理，不在编码。

---

### 优化: k=1 用拼接技巧 — O(n²) / O(n)

```cpp
class Solution {
public:
    string orderlyQueue(string s, int k) {
        if (k == 1) {
            // 技巧：s+s 包含了 s 的所有旋转作为子串
            string doubled = s + s;
            string minStr = s;
            int n = s.size();
            for (int i = 1; i < n; i++) {
                string rotated = doubled.substr(i, n);
                if (rotated < minStr) {
                    minStr = rotated;
                }
            }
            return minStr;
        } else {
            sort(s.begin(), s.end());
            return s;
        }
    }
};
```

**关键点**:
- `s + s` 包含了 s 的所有 n 种旋转。`doubled[i..i+n-1]` 就是以 `s[i]` 开头的旋转。
- 这是处理"循环字符串"的经典技巧——把字符串复制一份拼接。

## 解法对比

|  | 枚举旋转 (k=1) | Booth's algorithm (k=1) | 排序 (k>=2) |
|--|---------------|------------------------|-------------|
| 时间 | O(n²) | O(n) | O(n log n) |
| 空间 | O(n) | O(n) | O(1) in-place |
| 难度 | 简单 | 复杂 | 简单 |

**面试选择**: 直接写分类讨论。k=1 用 O(n²) 枚举旋转，k>=2 用 sort。Booth's algorithm 是竞赛内容，面试不要求。

## 易错点

1. **k>=2 时还在模拟操作**：
   - ✗ 写 BFS/DFS 模拟所有可能的移动序列 → 状态空间爆炸，超时
   - ✓ 直接 `sort(s.begin(), s.end())`，因为 k>=2 等价于能做任意排列

2. **k=1 时只枚举了部分旋转**：
   - ✗ 只尝试了几种旋转就返回 → 可能不是最小的
   - ✓ 必须枚举所有 n 种旋转

3. **没有理解 k 的分水岭**：
   - ✗ 认为 k=2, k=3, k=4 各有不同策略 → 过度复杂化
   - ✓ 只有两种情况：k=1 和 k>=2。k>=2 全部等价。

4. **字符串比较的效率**：
   - k=1 枚举旋转时，每次比较两个长度 n 的字符串是 O(n)
   - 总时间 O(n²)，对于 n <= 1000 完全够用

## 面试追问

**Q1: 为什么 k>=2 就能实现任意排列？能更严格地证明吗？**
> 核心：k>=2 时能交换相邻字符。证明见上面的步骤推导。而"能交换任意相邻字符"等价于"能做冒泡排序"，冒泡排序能产生任意排列（群论中，相邻对换生成整个对称群 S_n）。

**Q2: k=1 时有没有比 O(n²) 更快的方法？**
> 有。Booth's algorithm 可以 O(n) 找到字符串的最小旋转。核心思想是利用失败函数（类似 KMP）在双倍字符串上做匹配。面试中通常不要求，但可以提一下展示知识面。

**Q3: 如果字符集不是小写字母而是任意字符呢？**
> 算法不变。k>=2 的结论不依赖于字符集大小（冒泡排序对任意可比较元素有效）。k=1 的枚举旋转也不依赖字符集。

**Q4: 如果操作有次数限制（最多操作 m 次），怎么办？**
> 这就变成了一个更难的问题。k=1 时需要考虑哪些旋转可以在 m 步内达到（旋转 i 步需要 i 次操作）。k>=2 时需要分析冒泡排序的最小交换次数（等于逆序对数量），判断 m 次操作是否够用。这是一个完全不同的问题。
