# 587. Erect the Fence - 安装栅栏

## 核心思路

本题本质是经典的**凸包（Convex Hull）**问题。给定一组平面上的点（树的位置），需要找出所有位于凸包边界上的点。与标准凸包不同的是，本题要求返回所有位于凸包**边上**的点（包括共线的点），而不仅仅是凸包的顶点。

关键算法选择：
- **Andrew's Monotone Chain**（推荐）：按坐标排序后分别构建上凸包和下凸包
- **Graham Scan**：选取极点后按极角排序扫描
- **Jarvis March (Gift Wrapping)**：从最左点出发逐步"包裹"

## 思维链

1. **识别为凸包问题**：最小周长的围栏包围所有树 -> 凸包
2. **注意特殊要求**：返回凸包边界上所有点，包括边上的共线点
3. **选择合适算法**：Andrew's Monotone Chain 实现最简洁
4. **处理共线**：标准凸包算法使用严格逆时针（`< 0`），这里需要修改叉积判断条件
5. **去重**：上下凸包可能有重复端点，需要用 set 去重

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| Andrew's Monotone Chain | O(n log n) | O(n) | 最容易实现，排序后双向扫描 |
| Graham Scan | O(n log n) | O(n) | 极角排序，需处理极角相同的情况 |
| Jarvis March | O(nh) | O(n) | h为凸包顶点数，最坏O(n^2) |

## 关键提示

1. **叉积公式**：`cross(O, A, B) = (A.x - O.x) * (B.y - O.y) - (A.y - O.y) * (B.x - O.x)`
   - 正值：O->A->B 逆时针（左转）
   - 零值：共线
   - 负值：顺时针（右转）
2. **包含共线点的处理**：标准 Monotone Chain 用 `cross <= 0` 弹出栈顶（严格凸包），本题需改为 `cross < 0`（允许共线，只弹严格右转的点）
3. **Andrew's 算法推荐做法**：构建上下凸包时都用 `< 0` 弹栈，然后用 set 去重合并。共线点会被自然保留在上凸包或下凸包之一中
4. **排序**：先按 x 升序，x 相同按 y 升序
5. **退化情况**：n <= 3 时直接返回所有点

## 解法详解

### 解法一：Andrew's Monotone Chain（推荐）

**算法步骤**：
1. 将所有点按 (x, y) 排序
2. 构建下凸包：从左到右扫描，维护一个栈，遇到"严格顺时针"就弹出
3. 构建上凸包：从右到左扫描，同样维护栈
4. 合并上下凸包，去重

**叉积判断的关键**：
- 标准严格凸包弹栈条件：`cross <= 0`（不允许共线）
- 本题要保留共线点，弹栈条件改为 `cross < 0`（允许共线，即只弹顺时针）

**下凸包构建过程（示例: [1,1],[2,0],[2,2],[2,4],[3,3],[4,2]）**：
1. 压入 (1,1)
2. 压入 (2,0)：cross 判断通过
3. 压入 (2,2)：cross((1,1),(2,0),(2,2)) > 0，左转，保留
4. 压入 (2,4)：依次检查，保留
5. 压入 (3,3)：cross((2,4),(3,3)) 检查
6. 压入 (4,2)：继续检查

**实现要点**：用索引而非点本身存入栈，最后通过索引 set 去重。

### 解法二：Jarvis March（Gift Wrapping）

1. 从最左的点出发
2. 每一步选择"最逆时针"方向的下一个点
3. 同时收集与当前方向共线的所有点
4. 直到回到起点

优点：天然能收集共线点。缺点：最坏 O(n^2)。

### 解法三：Graham Scan

1. 找到最下方（y 最小，y 相同则 x 最小）的点作为锚点
2. 按极角排序所有其他点
3. 极角相同的点按距离排序（近的在前）
4. 逐个处理，用叉积判断是否左转/右转
5. 特殊处理：最后一组共线的点需按距离从远到近排列

## 易错点

1. **忽略共线点**：标准凸包算法只返回顶点，本题需要返回所有边界上的点（包括共线点）
2. **叉积精度**：本题坐标为整数且范围小（0~100），不用担心浮点精度，使用整数叉积即可
3. **重复点**：上下凸包合并时端点可能重复，必须去重
4. **退化情况**：所有点共线时应返回全部点
5. **单点/两点**：n=1 或 n=2 时直接返回全部点
6. **Graham Scan 的极角排序陷阱**：极角相同的最后一组点需要按距离从远到近排，否则会遗漏

## 面试追问

1. **叉积为什么能判断转向？**
   - 叉积是两个向量组成的平行四边形的有向面积，正值表示逆时针旋转，负值表示顺时针
2. **如何处理所有点共线的情况？**
   - 此时凸包退化为一条线段，所有点都在"边"上，应全部返回
3. **Andrew's 和 Graham Scan 的优劣比较？**
   - Andrew's 不需要极角计算（避免 atan2 精度问题），只需坐标排序，实现更简单
   - Graham Scan 对极角相同点的排序处理比较棘手
4. **时间复杂度的瓶颈在哪？**
   - 排序 O(n log n)，扫描 O(n)，整体 O(n log n)
5. **如果坐标是浮点数，需要注意什么？**
   - 叉积比较零时需要引入 epsilon 容差
   - 排序时也需要容差比较
6. **Jarvis March 的最坏时间复杂度是多少？**
   - O(nh)，当所有点都在凸包上时退化为 O(n^2)
