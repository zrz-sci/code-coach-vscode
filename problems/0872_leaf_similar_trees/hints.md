# 872. Leaf-Similar Trees

## 核心思路

本题要求判断两棵二叉树的"叶子值序列"是否相同。叶子值序列是所有叶子节点的值按从左到右的顺序排列。最直接的方法是分别对两棵树做 DFS（深度优先搜索），收集各自的叶子节点值序列，然后比较两个序列是否相同。DFS 天然按照左子树优先的顺序访问节点，因此叶子节点的访问顺序就是从左到右的顺序。

## 思维链

1. **理解叶子节点**：没有左右子节点的节点就是叶子节点。
2. **从左到右的顺序**：DFS 先访问左子树再访问右子树，叶子的访问顺序自然是从左到右。
3. **收集叶子序列**：对每棵树做一次 DFS，将叶子值依次放入一个数组。
4. **比较两个数组**：直接用 == 比较两个 vector 即可。
5. **优化思考**：可以用迭代器/生成器同步遍历两棵树，提前终止。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 两次 DFS + 收集比较 | O(n1 + n2) | O(n1 + n2) | 简单直观，最常用 |
| 迭代 DFS + 逐一比较 | O(n1 + n2) | O(h1 + h2) | 空间优化，可提前终止 |

## 关键提示

1. **叶子节点判定**：`node->left == nullptr && node->right == nullptr`。
2. **DFS 顺序保证从左到右**：先递归左子树再递归右子树，叶子自然按从左到右的顺序被访问。
3. **空树处理**：题目保证每棵树至少有 1 个节点，但仍需注意空子树。
4. **迭代 DFS 用栈**：将递归转为显式栈操作，每次弹出栈顶，先压右子再压左子。
5. **序列长度可能不同**：两棵树叶子数量可能不同，比较时需检查长度。

## 解法详解

### 解法一：两次 DFS 收集叶子序列

**算法步骤**：

1. 定义辅助函数 `collectLeaves(root, leaves)`：
   - 若 root 为空，返回。
   - 若 root 是叶子节点，将 `root->val` 加入 `leaves`。
   - 否则，递归左子树，再递归右子树。
2. 分别对 `root1` 和 `root2` 调用 `collectLeaves`，得到 `leaves1` 和 `leaves2`。
3. 返回 `leaves1 == leaves2`。

**复杂度分析**：
- 时间：O(n1 + n2)，每个节点访问一次。
- 空间：O(n1 + n2)，存储叶子序列 + 递归栈深度。

### 解法二：迭代 DFS + 逐一比较

**算法步骤**：

1. 用两个显式栈分别维护两棵树的 DFS 状态。
2. 每次从栈中"弹出下一个叶子节点"：
   - 弹出栈顶节点，若不是叶子则压入其子节点（先右后左）并继续弹出。
   - 直到找到叶子节点或栈为空。
3. 同步获取两棵树的下一个叶子，比较值是否相同。
4. 若某一时刻值不同或一棵树先耗尽叶子，返回 false。
5. 两棵树同时耗尽叶子，返回 true。

**优势**：不需要存储完整的叶子序列，空间只需 O(h1 + h2)（树高），且可以在发现不同时立即返回。

## 易错点

1. **DFS 顺序搞反**：如果先右后左会得到反序的叶子序列，结果错误。
2. **忘记处理只有一个子节点的情况**：一个节点有左子但没右子（反之亦然）时，它不是叶子节点。
3. **迭代 DFS 的压栈顺序**：由于栈是 LIFO，要先压右子节点再压左子节点，这样左子节点会先被弹出。
4. **直接比较树结构**：题目不要求两棵树结构相同，只要叶子值序列相同即可。
5. **测试单节点树**：一个节点既是根又是叶子，叶子序列只有一个元素。

## 面试追问

1. **如何只使用 O(1) 额外空间？** 可以用 Morris 遍历变体，但实现较复杂。
2. **如果是 N 叉树怎么办？** 叶子定义变为"没有任何子节点的节点"，DFS 遍历所有子节点。
3. **如果要求叶子序列的最长公共前缀长度？** 同步迭代 DFS，计数匹配的叶子数量。
4. **如果树非常深（链状），递归 DFS 会栈溢出怎么办？** 使用迭代 DFS（显式栈）。
5. **能否用 BFS 代替 DFS 来收集叶子？** BFS 按层序遍历，同一层的叶子顺序是对的，但不同层的叶子顺序可能有交叉，不能保证从左到右。必须用 DFS。
