# 224. 基本计算器

## 核心思路

这道题本质上是：**如何在只有 `+`、`-` 和括号的表达式中，正确处理括号带来的符号翻转问题**。括号不改变运算优先级（因为只有加减），它唯一的作用是可能翻转内部所有数字的符号（当括号前是 `-` 时）。

## 思维链

1. **读完题第一反应**：表达式求值，需要处理数字解析、运算符、括号嵌套。最朴素想法——找到最内层括号，先算它，替换回字符串，重复直到没有括号。但这涉及字符串修改，效率极低。

2. **括号的本质是什么？** 没有乘除法，只有加减法，所以括号唯一的作用是：当括号前面是 `-` 时，括号内的所有符号取反。比如 `-(2+3-1)` 等价于 `-2-3+1`。

3. **怎么处理嵌套？** 括号可以嵌套多层，每进入一层括号，当前的"符号环境"可能翻转一次。这天然是一个**栈结构**——遇到 `(` 就把当前状态压栈，遇到 `)` 就弹栈恢复。

4. **栈里存什么？** 有两种经典思路：
   - **思路A（存结果+符号）**：把括号前已经算好的结果和括号前的符号压栈，括号内重新开始计算，遇到 `)` 时把栈顶弹出来合并。
   - **思路B（存符号）**：栈只维护"当前层的符号"，每个数字的实际符号 = 栈顶符号 × 自身符号。

5. **递归也是天然的括号处理方式**：遇到 `(` 就递归进去算子表达式，遇到 `)` 就返回结果。递归调用栈天然模拟了括号的嵌套。

6. **一元负号怎么处理？** `-1` 或 `-(2+3)` 中的 `-` 是一元运算符。关键判断：如果 `-` 出现在表达式开头、或紧跟在 `(` 后面，它就是一元负号。可以将其视为 `0 - ...`。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 栈（存结果+符号） | 遇到 `(` 压入已有结果和符号，`)`时弹出合并 | O(n) | O(n) | ⭐ 必须写出 |
| 栈（只存符号） | 栈维护符号环境，每个数字乘以栈顶符号 | O(n) | O(n) | 加分项 |
| 递归 | 遇到 `(` 递归求值，遇到 `)` 返回 | O(n) | O(n) | 能说出即可 |

## 关键提示

1. **只有加减没有乘除**，意味着不需要考虑运算符优先级，括号的唯一作用是翻转符号。这大大简化了问题。

2. **数字可能是多位数**：`"123+456"` 中 `123` 需要逐字符累加得到，公式是 `num = num * 10 + (ch - '0')`。别忘了在遇到非数字字符时"结算"当前数字。

3. **一元负号**：`"-1+2"` 或 `"(-1+2)"` 是合法的。如果当前 sign 初始化为 `+1`，遇到第一个字符就是数字，那一元负号需要特别处理——最简单的方法是在表达式开头或 `(` 后面碰到 `-` 时，把当前数字视为 0。

4. **栈的 `(` 和 `)` 处理**：
   ```
   表达式: 1 - (2 + 3)
   
   处理 '1':  result=1
   处理 '-':  sign=-1
   处理 '(':  压栈 [result=1, sign=-1], 重置 result=0, sign=1
   处理 '2':  result=2
   处理 '+':  sign=1
   处理 '3':  result=5
   处理 ')':  弹栈, result = 1 + (-1)*5 = -4
   ```

5. **字符串末尾的数字别忘了结算**：循环结束后，最后一个数字可能还没加到 result 里。

## 解法详解

### 解法1: 栈（存结果+符号） — O(n) / O(n) ⭐ 面试首选

**思考过程**：

从左到右扫描表达式，维护当前的 `result` 和 `sign`。没有括号时，这就是简单的逐步累加。

括号怎么办？遇到 `(` 时，当前已经算了一部分结果（比如 `5 - (...)` 中的 `5`），以及括号前的符号（`-`）。我们需要把这两个信息"暂存"起来，等括号内的子表达式算完后再合并。这正好是栈的用途。

遇到 `)` 时，括号内的子表达式已经算完存在 `result` 中，从栈里弹出之前的符号和结果，合并：`result = 栈顶result + 栈顶sign * result`。

```
// 处理 "1 - (4 + 5)" 的完整过程:
//
// 字符   操作                          result  sign  栈
// '1'    num=1                         0       1     []
//        结算: result += 1*1           1       1     []
// '-'    sign = -1                     1       -1    []
// '('    压栈(1, -1), 重置             0       1     [(1,-1)]
// '4'    num=4, 结算: result += 1*4    4       1     [(1,-1)]
// '+'    sign = 1                      4       1     [(1,-1)]
// '5'    num=5, 结算: result += 1*5    9       1     [(1,-1)]
// ')'    弹出: result = 1 + (-1)*9     -8      1     []
//        最终答案: -8
```

```cpp
class Solution {
public:
    int calculate(string s) {
        stack<int> stk;
        int result = 0;
        int sign = 1;   // 当前数字前面的符号: +1 或 -1
        int num = 0;
        
        for (int i = 0; i < s.size(); i++) {
            char ch = s[i];
            
            if (isdigit(ch)) {
                // 多位数：逐位累加
                num = num * 10 + (ch - '0');
            } else {
                // 遇到非数字字符，先结算之前积累的数字
                result += sign * num;
                num = 0;  // 重置
                
                if (ch == '+') {
                    sign = 1;
                } else if (ch == '-') {
                    sign = -1;
                } else if (ch == '(') {
                    // 把当前的 result 和 sign 压栈，然后重置
                    // 为什么先压 result 再压 sign？因为弹出时先弹 sign
                    stk.push(result);
                    stk.push(sign);
                    result = 0;
                    sign = 1;
                } else if (ch == ')') {
                    // 括号内结果已经在 result 中
                    // 弹出括号前的 sign 和 result，合并
                    int prevSign = stk.top(); stk.pop();
                    int prevResult = stk.top(); stk.pop();
                    result = prevResult + prevSign * result;
                }
                // 空格直接跳过（num已重置，sign不变）
            }
        }
        // 别忘了最后一个数字（字符串末尾没有运算符来触发结算）
        result += sign * num;
        return result;
    }
};
```

**关键点**：
- 栈里交替存 `result` 和 `sign`（或者用 pair），弹出顺序别搞反。
- 字符串最后一个数字在循环结束后需要额外结算。
- 空格不需要特别处理，只要在非数字分支里自然跳过即可。

### 解法2: 栈（只存符号环境） — O(n) / O(n)

**从解法1换一个角度**：既然括号只影响符号，我们可以让栈只记录"当前层的符号环境"。

核心思想：维护一个符号栈，栈顶表示"当前括号层的符号乘数"。
- 初始栈顶为 `+1`
- 遇到 `(`：将 `栈顶 × 当前sign` 压入栈（新的符号环境）
- 遇到 `)`：弹栈（恢复上层的符号环境）
- 每个数字的实际符号 = `栈顶 × 自身的sign`

```
// 处理 "1 - (2 + 3)" 的符号栈过程:
//
// 符号栈初始: [1]  (全局正号环境)
//
// '1': 实际符号 = 栈顶(1) × sign(1) = +1  → result += 1
// '-': sign = -1
// '(': 压入 栈顶(1) × sign(-1) = -1  → 栈=[1, -1], sign重置为1
// '2': 实际符号 = 栈顶(-1) × sign(1) = -1 → result += -2
// '+': sign = 1
// '3': 实际符号 = 栈顶(-1) × sign(1) = -1 → result += -3
// ')': 弹栈 → 栈=[1]
//
// result = 1 + (-2) + (-3) = -4  ✓
```

```cpp
class Solution {
public:
    int calculate(string s) {
        stack<int> signStack;
        signStack.push(1);  // 全局符号环境为正
        
        int result = 0;
        int sign = 1;
        int num = 0;
        
        for (int i = 0; i < s.size(); i++) {
            char ch = s[i];
            
            if (isdigit(ch)) {
                num = num * 10 + (ch - '0');
            } else {
                // 结算当前数字，实际符号 = 栈顶环境 × 自身sign
                result += signStack.top() * sign * num;
                num = 0;
                
                if (ch == '+') {
                    sign = 1;
                } else if (ch == '-') {
                    sign = -1;
                } else if (ch == '(') {
                    // 新的符号环境 = 当前环境 × 括号前的sign
                    signStack.push(signStack.top() * sign);
                    sign = 1;  // 括号内重新开始，默认正号
                } else if (ch == ')') {
                    signStack.pop();  // 恢复上层环境
                }
            }
        }
        // 最后一个数字
        result += signStack.top() * sign * num;
        return result;
    }
};
```

**关键点**：这个解法更优雅——不需要在 `)` 时做复杂的合并运算，每个数字直接一步到位算出最终贡献。

### 解法3: 递归 — O(n) / O(n)

**思考过程**：括号结构天然是递归的。遇到 `(` 就递归处理子表达式，遇到 `)` 就返回。用全局索引 `i` 来追踪当前扫描位置（或传引用）。

```cpp
class Solution {
public:
    int i = 0;  // 全局扫描指针
    
    int calculate(string s) {
        return eval(s);
    }
    
    int eval(const string& s) {
        int result = 0;
        int sign = 1;
        int num = 0;
        
        while (i < s.size()) {
            char ch = s[i];
            
            if (isdigit(ch)) {
                num = num * 10 + (ch - '0');
            } else if (ch == '+' || ch == '-') {
                result += sign * num;  // 结算前一个数
                num = 0;
                sign = (ch == '+') ? 1 : -1;
            } else if (ch == '(') {
                i++;           // 跳过 '('
                num = eval(s); // 递归求括号内的值，当作一个"数字"
                // 注意：递归返回时 i 指向 ')' 或已经跳过了
                // 不需要 i++，因为外层 for 会处理
            } else if (ch == ')') {
                result += sign * num;
                return result; // 返回括号内的计算结果
            }
            // 空格跳过
            i++;
        }
        result += sign * num;  // 最后一个数
        return result;
    }
};
```

**关键点**：
- 全局变量 `i` 是关键——递归调用和返回时，`i` 必须正确指向下一个要处理的位置。
- 递归返回后，`i` 指向 `)` 的位置，外层的 `i++` 会跳过它。
- 面试中用全局变量不太优雅，也可以传 `int& idx` 引用参数。

## 解法对比

| | 栈（存结果+符号） | 栈（只存符号） | 递归 |
|---|---|---|---|
| 栈里存什么 | result + sign | 只存符号乘数 | 调用栈 |
| `)` 时的操作 | 弹栈合并 `prev + prevSign*result` | 简单弹栈 | 直接 return |
| 代码直觉性 | 最直观 | 需要理解"符号环境"概念 | 最自然但要管理全局索引 |
| 面试推荐 | ⭐ 首选 | 追问时展示 | 作为思路讨论 |
| 扩展到乘除 | 需要改造 | 较难扩展 | 容易扩展（加优先级递归） |

## 易错点

1. **多位数忘记累加**：
   - ✗ `num = ch - '0'`（每次覆盖，`123` 变成 `3`）
   - ✓ `num = num * 10 + (ch - '0')`（逐位构建）

2. **最后一个数字没结算**：
   - ✗ 循环结束直接 `return result`（丢失最后一个数字）
   - ✓ 循环结束后 `result += sign * num`，然后再返回

3. **栈弹出顺序搞反**（解法1）：
   - 压入顺序是先 `result` 再 `sign`，弹出时先拿到的是 `sign` 再 `result`
   - ✗ `int prevResult = stk.top(); stk.pop(); int prevSign = stk.top(); stk.pop();`
   - ✓ `int prevSign = stk.top(); stk.pop(); int prevResult = stk.top(); stk.pop();`

4. **一元负号处理不当**：
   - 表达式 `"-1+2"` 中，初始 `sign=1`，`result=0`，遇到 `-` 后 `sign=-1`，然后数字 `1` 被结算为 `-1`。这实际上自动处理了一元负号（因为 `result` 初始为 0，等价于 `0-1`）。
   - 但如果 `sign` 初始化不为 `1`，或者 `result` 不为 `0`，就会出 bug。

5. **`(` 后忘记重置 sign**：
   - ✗ 遇到 `(` 压栈后不重置 `sign`，导致括号内第一个数字用了括号外的符号
   - ✓ 遇到 `(` 压栈后 `sign = 1`

## 面试追问

**Q1: 暴力做法是什么？为什么不行？**
→ 反复找最内层括号，计算后替换回字符串。时间 O(n²)（每次替换都可能扫描整个字符串），且字符串修改很烦。栈/递归能一趟扫完。

**Q2: 如果表达式还包含 `*` 和 `/`，怎么改？**
→ 需要处理运算符优先级。经典做法：用两个栈（操作数栈+运算符栈），或者递归下降解析（`expr → term → factor`）。本题因为只有 `+` `-`，所以可以简化。这就是 LeetCode 227 的内容。

**Q3: 如果没有括号但有四则运算（LeetCode 227），核心改动是什么？**
→ 遇到 `*` `/` 时要立即和前一个数字计算（因为优先级高），用栈存中间结果：遇到 `+` `-` 压栈，遇到 `*` `/` 弹出栈顶和当前数字先算。

**Q4: 能否不用栈做到 O(1) 空间？**
→ 对于只有 `+` `-` 和括号的情况，理论上不行——括号可以嵌套 O(n) 层，必须记住每层的状态。但如果没有括号，只需要 sign 和 result 两个变量，O(1) 空间。
