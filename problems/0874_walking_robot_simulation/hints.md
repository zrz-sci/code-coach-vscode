# 874. 模拟行走机器人

## 核心思路

这是一道**纯模拟题**。机器人在二维平面上根据指令移动，遇到障碍物停下。关键技巧：(1) 用**方向数组**管理上下左右转向，(2) 用 **HashSet 存障碍物坐标**实现 O(1) 碰撞检测，(3) 移动时**逐步走**而不是直接跳到目标位置。

## 思维链

1. **读完题第一反应** → 模拟机器人运动。需要维护：当前位置 (x,y)、当前朝向、障碍物集合。每一步检查是否撞墙。
2. **方向如何管理？** → 经典技巧：用方向数组 dx = {0,1,0,-1}, dy = {1,0,-1,0} 分别对应 北、东、南、西。左转 = (dir+3)%4，右转 = (dir+1)%4。
3. **障碍物如何存储？** → 如果用 vector 存然后遍历查找，每步检查是 O(obstacles.size())。用 HashSet 存坐标，查找 O(1)。坐标编码：将 (x,y) 编码为字符串 "x,y" 或用 pair + set。
4. **移动逻辑** → 指令 k 表示走 k 步，但不是跳 k 格！需要一格一格走，每走一格检查下一格是否是障碍物。如果是就停在当前位置。
5. **答案是什么？** → 求的是移动过程中 **最大欧几里得距离的平方**（不是最终距离），所以每移动一步后都要更新 max(x^2 + y^2)。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 模拟 + HashSet | 方向数组+逐步移动+集合存障碍 | O(N*K + M) | O(M) | 唯一正解 |

其中 N = commands.length，K = 每条指令最大步数(9)，M = obstacles.length。

## 关键提示

1. **方向数组是核心技巧**：dx = {0,1,0,-1}, dy = {1,0,-1,0}。索引 0=北(+y)，1=东(+x)，2=南(-y)，3=西(-x)。右转 dir = (dir+1)%4，左转 dir = (dir+3)%4（等价于 (dir-1+4)%4）。
2. **逐步移动，不能跳跃**：指令 k=5 意味着尝试走 5 步，每走一步检查前方是否有障碍。遇到障碍就停住，不是"跳过"也不是"弹回"。
3. **坐标编码技巧**：将 (x,y) 编码为单个 long long：`(long long)(x+30001) * 60003 + (y+30001)`，或直接用 `set<pair<int,int>>`。字符串编码 `to_string(x)+","+to_string(y)` 也行但较慢。
4. **求最大距离平方**：注意是途中的最大值，不是最终位置的距离。每移动一步后都要 `ans = max(ans, x*x + y*y)`。
5. **原点障碍物特殊处理**：题目说 (0,0) 处可以有障碍物，但机器人从 (0,0) 出发时忽略它。一旦离开就不能回来。实际编码中不需要特殊处理——因为机器人从 (0,0) 开始，逐步移动时只检查"下一格"，(0,0) 的障碍只在试图返回时才生效。

## 解法详解

### 解法1: 模拟 + HashSet — O(N*K + M) / O(M)

**思考过程**: 经典模拟题，按指令逐步执行。

```
示例: commands = [4,-1,4,-2,4], obstacles = [[2,4]]

初始: pos=(0,0), dir=0(北)

cmd=4: 走4步 → (0,1)→(0,2)→(0,3)→(0,4), 到达(0,4)
  max_dist = 16

cmd=-1: 右转, dir=1(东)

cmd=4: 走4步 → 尝试(1,4)✓→尝试(2,4)✗障碍! 停在(1,4)
  max_dist = 17

cmd=-2: 左转, dir=0(北)

cmd=4: 走4步 → (1,5)→(1,6)→(1,7)→(1,8)
  max_dist = 65

答案: 65
```

```cpp
class Solution {
public:
    int robotSim(vector<int>& commands, vector<vector<int>>& obstacles) {
        // 方向数组: 北(0), 东(1), 南(2), 西(3)
        int dx[] = {0, 1, 0, -1};
        int dy[] = {1, 0, -1, 0};
        
        // 用 set 存障碍物坐标
        set<pair<int,int>> obs;
        for (auto& o : obstacles) obs.insert({o[0], o[1]});
        
        int x = 0, y = 0, dir = 0;
        int ans = 0;
        
        for (int cmd : commands) {
            if (cmd == -2) {
                dir = (dir + 3) % 4; // 左转
            } else if (cmd == -1) {
                dir = (dir + 1) % 4; // 右转
            } else {
                // 走 cmd 步，每步检查障碍
                for (int i = 0; i < cmd; i++) {
                    int nx = x + dx[dir];
                    int ny = y + dy[dir];
                    if (obs.count({nx, ny})) break;
                    x = nx;
                    y = ny;
                    ans = max(ans, x * x + y * y);
                }
            }
        }
        return ans;
    }
};
```

**关键点**:
- 方向数组的顺序 (北东南西) 配合 +1/-1 取模实现左右转，非常优雅。
- 用 `set<pair<int,int>>` 最清晰，用 `unordered_set<long long>` 编码坐标则更快。
- 每走一步就更新 ans，不要只在指令结束后更新。

### 解法1 优化: 用 unordered_set + 坐标编码

```cpp
class Solution {
public:
    int robotSim(vector<int>& commands, vector<vector<int>>& obstacles) {
        int dx[] = {0, 1, 0, -1};
        int dy[] = {1, 0, -1, 0};
        
        // 坐标编码为 long long，避免 set<pair> 的红黑树开销
        auto encode = [](int x, int y) -> long long {
            return (long long)(x + 30001) * 60003 + (y + 30001);
        };
        
        unordered_set<long long> obs;
        for (auto& o : obstacles) obs.insert(encode(o[0], o[1]));
        
        int x = 0, y = 0, dir = 0, ans = 0;
        
        for (int cmd : commands) {
            if (cmd == -2) dir = (dir + 3) % 4;
            else if (cmd == -1) dir = (dir + 1) % 4;
            else {
                for (int i = 0; i < cmd; i++) {
                    int nx = x + dx[dir], ny = y + dy[dir];
                    if (obs.count(encode(nx, ny))) break;
                    x = nx; y = ny;
                    ans = max(ans, x * x + y * y);
                }
            }
        }
        return ans;
    }
};
```

## 易错点

1. **直接跳到目标位置而非逐步走**：
   - 指令 k=5 不是直接 `x += 5*dx[dir]`，而是一格一格走，遇障碍立刻停。
   - 跳跃会穿过障碍物，导致结果错误。

2. **方向数组顺序与左右转逻辑不匹配**：
   - dx,dy 必须是 北→东→南→西 的顺时针顺序，右转才是 (dir+1)%4。
   - 如果顺序搞反（比如 北→西→南→东），右转应该是 (dir+3)%4。

3. **忘记每步都更新最大距离**：
   - 题目求的是途中最大距离平方，不是最终位置的距离。
   - 如果只在每条指令结束后更新，可能错过中途经过的更远点（虽然本题中不太可能，但逻辑上应该每步更新）。

4. **坐标编码溢出**：
   - x,y 范围 [-30000, 30000]，如果用 x*60001+y 编码要注意用 long long。
   - 或者直接用 string/pair 避免编码问题。

## 面试追问

**Q1: 为什么用方向数组而不是 if-else 判断方向？**
> 方向数组把"方向"抽象为索引，转向操作变成简单的加减取模。代码更简洁，不容易出错，且容易扩展（比如加入对角线方向）。if-else 需要为每个方向的每种转向写独立逻辑，容易遗漏。

**Q2: 障碍物用什么数据结构存最优？**
> unordered_set 查找 O(1) 最优。如果用 vector 排序后二分查找是 O(log M)，也可以但常数较大。set<pair> 内部是红黑树 O(log M)。对于本题数据量（10^4），差别不大，但 unordered_set 是最佳选择。

**Q3: 如果障碍物是动态添加/删除的怎么办？**
> 继续用 unordered_set，insert/erase 都是 O(1)。如果需要范围查询（比如"某区域有无障碍"），可以用 2D 分桶或 kd-tree。

**Q4: 如果步数 k 可以很大（比如 10^9），如何优化？**
> 不能逐步走了。对于当前方向，可以在障碍物集合中二分查找当前行/列上最近的障碍物，直接跳到障碍前一格。需要按行和按列分别建立有序索引。
