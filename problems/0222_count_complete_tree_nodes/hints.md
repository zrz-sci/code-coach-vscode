# 222. 完全二叉树的节点个数

## 核心思路

这道题表面上是数节点，但核心考点是：**如何利用"完全二叉树"这个特殊性质，把遍历整棵树的 O(n) 优化到 O(log²n)**。关键洞察是——完全二叉树的左子树或右子树中，必有一个是满二叉树，满二叉树的节点数可以直接用公式 `2^h - 1` 算出，不需要遍历。

## 思维链

1. **读完题第一反应**：数节点？递归/BFS 遍历一遍不就行了？→ O(n) 解法，任何树都能用。
2. **题目强调"完全二叉树"**：这个条件一定有用，否则为什么要强调？进阶也要求 < O(n)。
3. **完全二叉树有什么特殊的？**：除了最后一层，每层都满。最后一层从左到右连续。也就是说——左右子树中，至少有一个是**满二叉树**。
4. **怎么判断哪个是满二叉树？**：从根节点分别沿左边和右边走到底，算出左右高度。如果左高 == 右高，整棵树就是满二叉树；否则递归处理左右子树。
5. **满二叉树直接用公式**：高度为 h 的满二叉树有 `2^h - 1` 个节点。这样每次递归至少砍掉一半节点，递归深度 O(log n)，每次算高度 O(log n)，总共 O(log²n)。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力递归/迭代 | 遍历所有节点计数 | O(n) | O(log n) | 能说出即可 |
| 利用完全二叉树性质 | 左右高度判断满子树 + 公式 | O(log²n) | O(log n) | ⭐ 必须写出 |
| 二分查找 + 位运算 | 在最后一层二分查找最后一个节点 | O(log²n) | O(1) | 加分项 |

## 关键提示

- **提示1**：完全二叉树的左子树一定是高度为 h 或 h-1 的完全二叉树，右子树也一定是完全二叉树。
- **提示2**：如果一棵完全二叉树的最左路径和最右路径长度相同，它就是满二叉树（每层都满）。
- **提示3**：满二叉树节点数 = `2^h - 1`，可以用位运算 `(1 << h) - 1` 快速计算。
- **提示4（进阶）**：最后一层有 `2^h` 个位置，实际只填了一部分（从左到右连续），可以用二分查找找到最后一个存在的节点。
- **树的结构示意**：
```
//  完全二叉树示例:
//         1              左高度 = 3 (1→2→4)
//        / \             右高度 = 2 (1→3→6? 不，3→6存在但3的右子为空)
//       2   3            
//      / \ /             实际: 沿最左走到底=3层, 沿最右走到底=2层
//     4  5 6             左高 ≠ 右高 → 不是满二叉树 → 递归左右子树
//
//  满二叉树 (左高==右高):
//         1              左高度 = 2
//        / \             右高度 = 2
//       2   3            节点数 = 2^2 - 1 = 3  ✓ (不含根用高度h)
//                        若把根也算进去，高度h层有 2^h - 1 个节点
```

## 解法详解

### 解法1: 暴力递归 — O(n) / O(log n)

**思考过程**：最直觉的方式——把每个节点都访问一遍，数一数。不管是不是完全二叉树，任何树都可以这样做。递归公式：`count(root) = 1 + count(left) + count(right)`。

```cpp
class Solution {
public:
    int countNodes(TreeNode* root) {
        if (!root) return 0;
        // 当前节点(1个) + 左子树节点数 + 右子树节点数
        return 1 + countNodes(root->left) + countNodes(root->right);
    }
};
```

**迭代版本（BFS层序遍历）：**

```cpp
class Solution {
public:
    int countNodes(TreeNode* root) {
        if (!root) return 0;
        queue<TreeNode*> q;
        q.push(root);
        int count = 0;
        while (!q.empty()) {
            TreeNode* node = q.front();
            q.pop();
            count++;
            if (node->left) q.push(node->left);
            if (node->right) q.push(node->right);
        }
        return count;
    }
};
```

**关键点**：这个解法完全没利用"完全二叉树"的性质，面试中只是起点。

---

### 解法2: 利用完全二叉树性质 — O(log²n) / O(log n) ⭐ 面试首选

**从解法1优化**：解法1 的瓶颈是每个节点都要访问。但完全二叉树有个关键性质——**如果某个子树是满二叉树，可以直接用公式算节点数，不用遍历**。

**核心逻辑**：
1. 计算从根沿最左路径走到底的深度 `leftDepth`
2. 计算从根沿最右路径走到底的深度 `rightDepth`
3. 如果 `leftDepth == rightDepth`，说明是满二叉树，直接返回 `2^depth - 1`
4. 否则，递归计算左右子树：`1 + countNodes(left) + countNodes(right)`

**为什么这是 O(log²n)？**
- 每次递归，左子树和右子树中**至少有一个是满二叉树**（完全二叉树的性质保证了这一点）
- 满二叉树那一侧直接返回公式结果，只有另一侧需要继续递归
- 所以递归深度 = O(log n)，每次递归计算高度 = O(log n)
- 总时间 = O(log n × log n) = O(log²n)

```
//  递归过程演示 (root = [1,2,3,4,5,6]):
//
//         1           leftDepth=3, rightDepth=2 → 不等，递归左右
//        / \
//       2   3
//      / \ /
//     4  5 6
//
//  左子树(2):           右子树(3):
//       2               3
//      / \             /
//     4   5           6
//  leftD=2, rightD=2  leftD=2, rightD=1
//  相等! → 满二叉树     不等，继续递归
//  返回 2^2 - 1 = 3
//                      左子树(6):    右子树(null):
//                         6            返回 0
//                      leftD=1, rightD=1
//                      相等! → 返回 2^1 - 1 = 1
//                      
//                      节点3 = 1 + 1 + 0 = 2
//
//  总计: 1 + 3 + 2 = 6  ✓
```

```cpp
class Solution {
public:
    int countNodes(TreeNode* root) {
        if (!root) return 0;
        
        // 计算沿最左路径的深度
        int leftDepth = 0;
        TreeNode* left = root;
        while (left) {
            leftDepth++;
            left = left->left;
        }
        
        // 计算沿最右路径的深度
        int rightDepth = 0;
        TreeNode* right = root;
        while (right) {
            rightDepth++;
            right = right->right;
        }
        
        // 如果左右深度相同，是满二叉树，直接公式
        // 高度为 leftDepth 层（含根），节点数 = 2^leftDepth - 1
        if (leftDepth == rightDepth) {
            return (1 << leftDepth) - 1;  // 2^depth - 1
        }
        
        // 否则递归计算左右子树
        return 1 + countNodes(root->left) + countNodes(root->right);
    }
};
```

**关键点**：
- `(1 << leftDepth) - 1` 是位运算算 `2^h - 1`，比 `pow()` 快且无精度问题。
- 这里的 depth 是"从根到叶的节点数"（不是边数），所以 `2^depth - 1` 是正确的公式。

### 解法3: 二分查找 + 位运算 — O(log²n) / O(1)

**思考方式完全不同**：
- 完全二叉树的高度 h 很容易算（沿最左路径走到底）
- 最后一层最多有 `2^h` 个位置（编号 0 到 2^h - 1）
- 问题变成：最后一层的最后一个节点在哪个位置？→ **二分查找**！
- 前 h-1 层的节点数 = `2^h - 1`（满的），加上最后一层的节点数就是答案

**怎么判断最后一层的第 k 个位置有没有节点？**
- 利用二进制编码！从根到第 k 个叶子的路径可以用 k 的二进制表示：0 = 往左，1 = 往右
- 例如高度 3 的树，最后一层位置编号 0~3（二进制 00, 01, 10, 11），从高位到低位决定走左还是右

```
//  二分查找最后一层的最后一个节点:
//
//         1          高度 h=2 (从0开始，根是第0层)
//        / \         最后一层编号: 0, 1, 2, 3
//       2   3        实际存在: 4(编号0), 5(编号1), 6(编号2)
//      / \ /
//     4  5 6
//
//  二分: lo=0, hi=3
//  mid=1 → 编号1(节点5)存在吗？ 1的二进制=01, 路径: 根→左→右 = 节点5 ✓
//          → lo=2
//  mid=2 → 编号2(节点6)存在吗？ 2的二进制=10, 路径: 根→右→左 = 节点6 ✓
//          → lo=3
//  mid=3 → 编号3存在吗？ 3的二进制=11, 路径: 根→右→右 = null ✗
//          → hi=2
//  lo > hi, 最后一个存在的 = 2, 最后一层有 3 个节点
//  总计 = (2^2 - 1) + 3 = 3 + 3 = 6  ✓
//
//  路径解码 (h=2, 编号用h位二进制):
//  编号2 = 二进制 "10"
//        第1位=1 → 往右(到节点3)
//        第0位=0 → 往左(到节点6) ✓ 存在
```

```cpp
class Solution {
public:
    int countNodes(TreeNode* root) {
        if (!root) return 0;
        
        // 计算树的高度（从0开始，根是第0层）
        int h = 0;
        TreeNode* node = root;
        while (node->left) {
            h++;
            node = node->left;
        }
        
        // 如果只有根节点
        if (h == 0) return 1;
        
        // 最后一层的节点编号范围: [0, 2^h - 1]
        // 二分查找最后一个存在的节点
        int lo = 0, hi = (1 << h) - 1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (exists(root, h, mid)) {
                lo = mid + 1;    // mid 存在，答案可能更靠右
            } else {
                hi = mid - 1;    // mid 不存在，答案在左边
            }
        }
        
        // lo - 1 = 最后一个存在的编号，最后一层有 lo 个节点
        // 前 h 层（满的）有 2^h - 1 个节点
        return (1 << h) - 1 + lo;
    }
    
private:
    // 判断最后一层编号为 idx 的节点是否存在
    // 用 idx 的二进制从高位到低位决定走左/走右
    bool exists(TreeNode* root, int h, int idx) {
        TreeNode* node = root;
        // 从第 h-1 位到第 0 位（共 h 位）
        for (int i = h - 1; i >= 0; i--) {
            if ((idx >> i) & 1) {
                node = node->right;   // 该位为1，走右
            } else {
                node = node->left;    // 该位为0，走左
            }
            if (!node) return false;
        }
        return true;
    }
};
```

**关键点**：
- 空间复杂度 O(1)（不算递归栈），是真正的常数空间。
- 位运算解码路径的技巧非常巧妙，理解了就能举一反三。

## 易错点

1. **满二叉树公式搞错**：
   - ✗ `return (1 << leftDepth)` → 少减了 1，高度 2 的满二叉树应该是 3 个节点不是 4 个
   - ✓ `return (1 << leftDepth) - 1`

2. **深度定义不统一**：
   - 如果 depth 定义为"节点数"（根到叶经过的节点数），满二叉树 = `2^depth - 1`
   - 如果 depth 定义为"边数"（根到叶经过的边数），满二叉树 = `2^(depth+1) - 1`
   - ✗ 混用两种定义会导致结果偏差

3. **位运算优先级**：
   - ✗ `return 1 << leftDepth - 1;` → `-` 优先级高于 `<<`，实际是 `1 << (leftDepth - 1)`
   - ✓ `return (1 << leftDepth) - 1;` → 加括号！

4. **解法3中 idx 的位数**：
   - 最后一层有 `2^h` 个位置，编号需要 h 位二进制表示
   - 循环应该从 `i = h-1` 开始到 `i = 0`，共 h 次
   - ✗ 从 `i = h` 开始会多走一步到错误的位置

## 面试追问

**Q1（基础理解）**：你的暴力解法时间复杂度是 O(n)，题目要求 < O(n)，你怎么利用"完全二叉树"这个条件？
> **回答**：完全二叉树除最后一层外都满，意味着很多子树是满二叉树。满二叉树的节点数可以直接用公式 `2^h - 1` 算出，不用遍历。关键是快速判断一棵子树是不是满的——沿最左和最右走到底，深度相同就是满的。

**Q2（复杂度分析）**：解法2 为什么是 O(log²n) 而不是 O(n)？能详细分析吗？
> **回答**：每次递归，左右子树至少有一个是满二叉树（完全二叉树性质保证），满的那一侧直接返回公式，只递归另一侧。所以递归深度 = O(log n)。每次递归要算高度 = O(log n)。总计 O(log n) × O(log n) = O(log²n)。

**Q3（变体/进阶）**：能否不用递归，做到 O(1) 空间？
> **回答**：可以，用二分查找。先算出高度 h，最后一层有 2^h 个位置。在这些位置上二分查找最后一个存在的节点。判断某个位置是否存在用位运算解码路径，每次 O(log n)。二分 O(log n) 次，总共 O(log²n) 时间 O(1) 空间。

**Q4（扩展思考）**：如果树不是完全二叉树呢？有没有比 O(n) 更快的方法？
> **回答**：如果是任意二叉树，没有比 O(n) 更快的方法，因为任何节点都可能存在或不存在，必须访问每个节点才能确定。O(log²n) 的优化完全依赖于完全二叉树"最后一层从左到右连续"的结构特性。
