# 866. Prime Palindrome

## 核心思路

本题要求找到大于等于 `n` 的最小素数回文数。暴力地逐一检查每个数是否既是回文又是素数会超时。关键优化在于：**不要枚举所有数，而是只枚举回文数，再检查它是否是素数**。回文数的数量远远少于所有整数，因此这种方法极为高效。另一个关键数学性质是：除了 11 以外，所有偶数位的回文数都能被 11 整除，因此不可能是素数。这意味着我们只需要枚举奇数位的回文数（和 11 这个特例）。

## 思维链

1. **暴力思路**：从 n 开始逐一检查 → 既要判断回文又要判断素数 → 当 n 较大时极慢。
2. **反转思路**：回文数由其前半部分决定 → 枚举前半部分即可生成所有回文数。
3. **数学优化**：偶数位回文数（除 11）必被 11 整除 → 不是素数 → 跳过偶数位。
4. **枚举策略**：按位数递增枚举奇数位回文数（1位、3位、5位、7位、9位），对每个回文数检查是否 >= n 且是素数。
5. **素数检查**：试除法到 sqrt(x) 即可，回文数数量少所以总开销很小。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 枚举回文 + 素数检查 | O(N^{1/2} * N^{1/4}) 近似 | O(1) | 最优解，枚举回文数远少于枚举所有数 |
| 逐一枚举 + 双重检查 | O(N * sqrt(N)) | O(1) | 暴力，会超时 |

## 关键提示

1. **生成回文数**：给定前半部分 `123`，奇数位回文为 `12321`（中间数字不重复）。
2. **偶数位回文被 11 整除的证明**：偶数位回文 `abba` = `1001a + 110b`，都是 11 的倍数。
3. **特殊处理 11**：11 是唯一的偶数位素数回文，需要单独判断。
4. **搜索范围**：n <= 10^8，答案保证 <= 2*10^8，最多是 9 位回文数。
5. **按位数分组枚举**：先枚举 1 位（2~9），再枚举 3 位（100~999 的前半），以此类推。

## 解法详解

### 枚举回文数 + 素数判定

**算法步骤**：

1. **生成所有奇数位回文数**：
   - 1 位回文：1~9（只枚举 2, 3, 5, 7 即可）。
   - 3 位回文：前半 `10~99`，中间数字 `0~9`，实际只需前半 `10~99` 的首位和镜像。
   - 更一般地：对于 `2k+1` 位回文，枚举前 `k+1` 位数字，后 `k` 位由镜像决定。
   - 具体实现：枚举前半部分数字，将其转为字符串，翻转拼接生成完整回文。

2. **加入 11 的特殊处理**：在枚举 1 位和 3 位之间，插入检查 11。

3. **对每个生成的回文数**：
   - 若 < n，跳过。
   - 判断是否为素数（试除法到 sqrt）。
   - 第一个满足条件的即为答案。

**为什么高效**：1~2*10^8 范围内的回文数仅约 20000 个，每个做 O(sqrt) 的素数检查，总计算量极小。

**直接枚举法（更简洁）**：

也可以直接从 n 开始逐一检查，但加入跳过偶数位数的优化：
- 如果当前数字位数为偶数（且 > 11），直接跳到下一个奇数位数的最小值。
- 例如从 1000 直接跳到 10001。

## 易错点

1. **遗漏 11**：11 是偶数位的素数回文，是唯一例外，必须特殊处理。
2. **n <= 2 的边界**：2 本身就是素数回文，需要正确返回。
3. **n 在 8~11 之间时**：需要正确返回 11。
4. **回文生成越界**：生成回文数时要注意不超过 int 范围或题目给定范围。
5. **偶数位跳过逻辑错误**：只跳过偶数位范围，不能跳过 11。
6. **isPrime(1) 返回 true**：1 不是素数，需特判。

## 面试追问

1. **为什么偶数位回文一定是 11 的倍数？** 用数位分析证明：每一对对称位的系数差都是 11 的倍数。
2. **如果范围扩大到 10^18？** 回文数仍然很少（约 200000 个），但素数检查需要 Miller-Rabin 等概率算法。
3. **能否预计算所有素数回文？** 可以离线筛法，但在线枚举回文更简洁。
4. **时间复杂度的精确分析？** 枚举回文数 O(sqrt(upper_bound))，每个做 O(N^{1/4}) 的素数检查。
5. **如果要求第 k 大的素数回文？** 用同样的枚举方法，维护一个计数器。
