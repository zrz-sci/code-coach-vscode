# 733. 图像渲染 (Flood Fill)

**难度**: Easy | **标签**: Depth-First Search, Breadth-First Search, Array, Matrix

## 核心思路

Flood Fill 是图形学中的经典算法，本质上是在矩阵上进行**连通区域搜索**。从起始像素出发，将所有与起始像素颜色相同且通过上下左右相连的像素全部染成新颜色。

这就是标准的 **BFS/DFS 遍历连通分量**问题。唯一需要注意的边界条件是：如果新颜色与原颜色相同，则无需任何操作（否则会死循环）。

## 思维链

1. **识别问题类型**: 矩阵连通区域遍历 => BFS 或 DFS
2. **确定起点**: 从 `(sr, sc)` 出发
3. **扩展条件**: 相邻格子颜色 == 起始格子的原始颜色
4. **终止条件**: 所有可达的同色格子都已被染色
5. **关键边界**: 若 `color == originalColor`，直接返回原图（防止无限递归）
6. **访问标记**: 染色操作本身就是标记 -- 改了颜色就不会再被访问（前提是新旧颜色不同）

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| DFS（递归） | O(m * n) | O(m * n) 栈深度 | 代码最简洁 |
| BFS（队列） | O(m * n) | O(m * n) 队列 | 层序扩展，无栈溢出风险 |
| DFS（显式栈） | O(m * n) | O(m * n) | 避免递归栈溢出 |

## 关键提示

1. **先记录原始颜色**: 在开始染色前保存 `originalColor = image[sr][sc]`
2. **提前返回条件**: 如果 `originalColor == color`，直接返回，否则 DFS 会无限递归
3. **四方向遍历**: 上下左右四个方向，可以用方向数组 `dx = {0,0,1,-1}, dy = {1,-1,0,0}`
4. **边界检查**: 坐标必须在 `[0, m) x [0, n)` 范围内
5. **无需额外 visited 数组**: 因为我们把格子染成新颜色后，它就不再等于 originalColor，天然不会被重复访问

## 解法详解

### 解法一：DFS 递归（推荐）

**步骤**:
1. 记录 `originalColor = image[sr][sc]`
2. 如果 `originalColor == color`，直接返回
3. 调用递归函数 `dfs(image, sr, sc, originalColor, color)`
4. 在 `dfs` 中：
   - 将当前格子染成 `color`
   - 对四个方向的邻居，如果在边界内且颜色等于 `originalColor`，递归调用 `dfs`

**时间复杂度**: O(m * n)，每个格子最多访问一次  
**空间复杂度**: O(m * n)，递归栈深度最坏为整个矩阵大小

### 解法二：BFS

**步骤**:
1. 记录 `originalColor`，检查提前返回条件
2. 创建队列，将 `(sr, sc)` 入队，同时染色
3. 循环出队，对每个出队格子检查四个邻居：
   - 在边界内且颜色等于 `originalColor` => 染色并入队

BFS 保证了层序扩展，不存在递归栈溢出问题。

**时间复杂度**: O(m * n)  
**空间复杂度**: O(m * n)

### 解法三：DFS 显式栈

与 BFS 类似，用栈替代队列，实现 DFS 的非递归版本。在矩阵较大时可以避免递归栈溢出。

**时间复杂度**: O(m * n)  
**空间复杂度**: O(m * n)

## 易错点

1. **新颜色等于原颜色**: 这是最常见的 bug。如果 `color == originalColor`，DFS/BFS 的"已访问"机制失效（染色后颜色不变），导致无限循环。**必须在开头特判**
2. **忘记记录原始颜色**: 染色过程中起始格子的颜色会被修改，必须在开始前保存
3. **方向数组写错**: 确保四个方向没有遗漏或重复
4. **边界检查顺序**: 先检查坐标是否越界，再检查颜色值，避免数组越界访问
5. **修改 image 后返回**: 注意函数需要返回修改后的 image 引用/拷贝
6. **对角线不算相邻**: 题目明确说"directly adjacent"是水平和垂直方向，不包括对角线

## 面试追问

1. **DFS 和 BFS 在这道题上的实际差异是什么？**
   - DFS 代码更简洁但有栈溢出风险（矩阵很大时）；BFS 用队列无此问题。结果完全相同。实际应用中 BFS 更安全

2. **如果要支持八方向连通（包括对角线）怎么改？**
   - 将方向数组从 4 个扩展到 8 个：加上 `{1,1}, {1,-1}, {-1,1}, {-1,-1}`

3. **Flood Fill 在实际工程中有哪些应用？**
   - 画图软件的油漆桶工具、图像分割、扫雷游戏展开空白区域、区域生长算法

4. **如何处理超大矩阵（10^6 x 10^6）的 flood fill？**
   - 使用迭代 BFS/DFS（非递归）避免栈溢出；必要时用分块处理或外存算法

5. **如果不想修改原始 image，怎么做？**
   - 方法一：深拷贝 image 后操作副本；方法二：使用额外的 visited 数组标记已访问格子

6. **时间复杂度能否低于 O(m*n)？**
   - 不能。最坏情况下所有格子都需要染色，必须至少访问一次
