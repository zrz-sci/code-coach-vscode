# 1072. 按列翻转得到最大值等行数

## 核心思路

翻转列是**全局操作**——翻转某一列会影响**所有行**。关键洞察：两行能**同时**通过列翻转变成全相同（全0或全1），当且仅当它们的行向量**相同或互为取反**。将每行"标准化"后用哈希表计数，最大计数就是答案。

## 思维链

1. **读完题第一反应** → 暴力枚举所有翻转方案？列数 n 最大 300，有 2^300 种翻转组合，不可能枚举。
2. **换个角度想** → 不要想"选哪些列翻转"，而是想"哪些行能同时变成全相同"。
3. **什么条件下两行能同时变全相同？** → 假设行 A = `[0,1,0]`，行 B = `[1,0,1]`。如果翻转第 1,3 列，A 变成 `[1,1,1]` 全 1，B 变成 `[0,0,0]` 全 0。它们都变成了全相同！
4. **发现规律** → A 和 B 互为取反。翻转某些列使 A 全 0，那**同样的翻转**使 B 全 1（因为 B 的每一位都和 A 相反）。同理，如果 A 和 C 完全相同，翻转使 A 全 0 也使 C 全 0。
5. **总结等价关系** → 两行能同时满足，当且仅当它们**相同或互为取反**。这定义了一个等价类。
6. **标准化** → 为了把"相同或互为取反"的行归为一类，对每行做标准化：如果第一个元素是 1，就把整行取反。这样等价的行会变成相同的模式。
7. **计数** → 用哈希表统计每种标准化模式出现的次数，最大的计数就是答案。

```
示例: matrix = [[0,0,0],[0,0,1],[1,1,0]]

原始行:       标准化 (首位为1则取反):    模式:
[0,0,0]  →  首位=0, 不变           →  "000"
[0,0,1]  →  首位=0, 不变           →  "001"
[1,1,0]  →  首位=1, 取反 → [0,0,1] →  "001"

哈希表: {"000": 1, "001": 2}
答案 = max(1, 2) = 2

验证: [0,0,1] 和 [1,1,0] 互为取反
      翻转第1,2列后: [1,1,1] 和 [0,0,0]，都全相同 ✓
```

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试推荐 |
|------|------|------|------|----------|
| 行模式哈希 | 标准化 + 计数 | O(m*n) | O(m*n) | 推荐 |

## 关键提示

1. **提示1 — 翻转是全局的**: 翻转一列影响所有行。所以不要对单行思考，要对"行的集合"思考。
2. **提示2 — 等价关系**: 行 A 和行 B 能同时通过列翻转变成全相同 ⟺ A 和 B 相同或互为取反。直觉：A 全 0 时 B 全 1（如果 B=~A），反之亦然。
3. **提示3 — 标准化技巧**: 用 `val ^ row[0]` 来标准化。如果 `row[0]=0`，异或 0 不变；如果 `row[0]=1`，异或 1 相当于取反。这样 `[0,1,0]` 和 `[1,0,1]` 都变成 `"010"`。
4. **提示4 — 为什么用字符串作 key**: C++ 中 `vector` 不能直接作为 `unordered_map` 的 key（没有默认哈希函数）。将标准化后的行转成字符串即可。
5. **提示5 — 复杂度分析**: 遍历 m 行，每行处理 n 列 → O(m*n)。哈希表最多 m 个条目，每个长度 n → 空间 O(m*n)。

## 解法详解

### 解法: 行模式哈希 -- O(m*n) / O(m*n)

**核心思想**: 将"选哪些列翻转"的搜索问题，转化为"哪些行具有相同的翻转模式"的计数问题。

```
为什么标准化有效？详细推导:

假设答案是翻转列集合 S，使得行 A 变成全 0:
  → A 的第 j 列: 如果 j∈S，则 A[j]^1=0 → A[j]=1
                  如果 j∉S，则 A[j]^0=0 → A[j]=0
  → 所以 S = {j | A[j]=1}，即 S 就是 A 中值为 1 的列的集合

对于行 B，同样的翻转 S 后:
  B'[j] = B[j]^1 (j∈S) 或 B[j] (j∉S)
  要使 B' 全相同:
    情况1: B'全0 → B[j]=1 当 j∈S, B[j]=0 当 j∉S → B = A
    情况2: B'全1 → B[j]=0 当 j∈S, B[j]=1 当 j∉S → B = ~A

结论: 行 B 能和行 A 同时满足 ⟺ B=A 或 B=~A
```

```cpp
class Solution {
public:
    int maxEqualRowsAfterFlips(vector<vector<int>>& matrix) {
        unordered_map<string, int> count;
        int res = 0;

        for (auto& row : matrix) {
            string pattern;
            // 标准化: 用 XOR row[0] 使等价行有相同模式
            // row[0]=0 → 不变; row[0]=1 → 取反整行
            for (int val : row) {
                pattern += (val ^ row[0]) ? '1' : '0';
            }
            res = max(res, ++count[pattern]);
        }
        return res;
    }
};
```

**关键点**:
- `val ^ row[0]`: 当 `row[0]=0` 时，`val ^ 0 = val`（不变）；当 `row[0]=1` 时，`val ^ 1 = ~val`（取反）。
- `++count[pattern]` 先自增再取值，所以 `res = max(res, ...)` 能正确包含当前行。
- 不需要额外判断"同或互反"，标准化后直接比较字符串相等即可。

## 易错点

1. **没有标准化，只统计相同行**:
   - 错误: 直接把每行转字符串计数 → `[0,1]` 和 `[1,0]` 被当作不同模式
   - 正确: 标准化后 `[0,1]→"01"`, `[1,0]→(取反)"01"`, 归为同一类

2. **标准化方向不一致**:
   - 错误: 有时按首位标准化，有时按末位 → 同一等价类可能产生两种模式
   - 正确: 统一按 `row[0]` 标准化，所有等价行一定产生相同字符串

3. **用 vector 做哈希 key**:
   - 错误: `unordered_map<vector<int>, int>` → 编译错误，vector 没有默认哈希
   - 正确: 转成 `string` 或用 `map<vector<int>, int>`（O(n log n) 但能过）

4. **忽略全 1 也算全相同**:
   - 误解: 以为"全相同"只是全 0 → 忘了全 1 也行
   - 正确: 全 0 和全 1 都算。所以互反的两行一个变全 0 另一个变全 1，都满足

## 面试追问

**Q1: 如何证明等价关系是"相同或互反"？**
> 见上面的"详细推导"部分。核心是：翻转列集合 S 由行 A 唯一确定（S = A 中 1 的位置），然后验证对行 B 应用相同的 S 后，B 只能全 0（B=A）或全 1（B=~A）。

**Q2: 如果矩阵不是二进制的（元素可以是 0~9），问题怎么变？**
> 翻转操作不再有意义（0-1 互换），需要重新定义操作。如果操作是"对某列所有值加减某个数"，问题会变成寻找"行间差异模式"相同的最大行数。

**Q3: 时间复杂度能更优吗？**
> O(m*n) 已经是最优了。因为必须至少读取矩阵中的每个元素一次，这就是 O(m*n)。

**Q4: 如果矩阵很大（300x300），字符串哈希会不会有冲突？**
> 用 `std::string` 作为 key，`unordered_map` 内部的哈希虽然理论上可能冲突，但对于 300 长度的字符串，实际不会出问题。如果追求极致，可以用多项式哈希或改用 `map<string,int>`（红黑树，O(log m * n)）。
