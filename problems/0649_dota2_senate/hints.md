# 649. Dota2 参议院 (Dota2 Senate)

**难度**: Medium | **标签**: Greedy, Queue, String

## 核心思路

本题模拟一个投票过程：每个参议员可以禁止一个对方阵营的参议员，或在所有剩余参议员都是己方时宣布胜利。关键洞察是**贪心策略**：每个参议员在行使禁止权时，应该禁止**最近的下一个对手**（按轮次顺序），因为这样可以阻止对手最快地行使权利。

最优实现使用**两个队列**分别存储 R 和 D 参议员的索引。每轮比较两个队列的队首：索引小的先行动，禁止索引大的，然后"胜者"加上 n 重新入队（代表进入下一轮）。

## 思维链

1. **理解投票规则**：每个参议员按位置顺序行动，可以 ban 对方一人，多轮进行
2. **贪心直觉**：每个参议员应该 ban 距离自己最近的下一个对手（贪心最优）
3. **数据结构选择**：两个队列分别存储 R 和 D 的索引
4. **模拟过程**：比较两个队列的队首索引，小的获胜，ban 大的
5. **循环处理**：获胜者的索引 + n 后重新入队，模拟"下一轮"
6. **终止条件**：某一方队列为空时，另一方获胜

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 双队列贪心 | O(n) | O(n) | 最优解，简洁优雅 |
| 模拟 + 标记数组 | O(n^2) 最坏 | O(n) | 直观但效率低 |
| 计数贪心 | O(n) | O(n) | 不用队列的变体 |

## 关键提示

1. **贪心策略的正确性**：每个参议员都应该 ban 离自己最近的对手（即在投票序列中下一个出现的对方成员）。如果 ban 更远的对手，离得近的对手会先 ban 自己
2. **队列索引 + n 的技巧**：将获胜参议员的索引加上 n 后入队，巧妙地模拟了"进入下一轮"的效果，同时保持了正确的顺序
3. **两个队列的比较**：索引小的参议员先行动，所以 queue 的队首索引小的一方获胜本轮
4. **终止条件判断**：当某一方的队列完全清空，另一方剩余成员可以宣布胜利

## 解法详解

### 解法一：双队列贪心（最优）

**核心思路**：用两个队列分别管理 R 和 D 参议员的行动顺序。

**步骤**：
1. 遍历 senate 字符串，将 R 的索引入队 qR，D 的索引入队 qD
2. 循环直到某个队列为空：
   - 取出 qR 和 qD 的队首索引 rIdx 和 dIdx
   - 如果 rIdx < dIdx：R 先行动，ban D。R 获胜，将 rIdx + n 入队 qR
   - 如果 dIdx < rIdx：D 先行动，ban R。D 获胜，将 dIdx + n 入队 qD
3. 如果 qR 非空返回 "Radiant"，否则返回 "Dire"

**为什么 + n 入队？**
- 原始索引范围是 [0, n-1]，代表第一轮
- 加上 n 后索引变为 [n, 2n-1]，代表第二轮
- 这样可以正确地与第一轮中尚未行动的参议员比较
- 同时保持了参议员之间的相对顺序

### 解法二：模拟 + 贪心标记

**思路**：直接模拟投票过程，用标记数组记录已被 ban 的参议员。

**步骤**：
1. 维护 banR 和 banD 计数器，表示待 ban 的对方数量
2. 多轮遍历 senate：
   - 如果是 R 且 banR > 0：被 ban，banR--
   - 如果是 R 且 banR == 0：行使权利，banD++
   - D 同理
3. 每轮结束检查是否只剩一方

## 易错点

1. **索引 + n 而非 + 1**：胜者重新入队时必须加 n（字符串长度），不是加 1。加 1 会打乱轮次逻辑
2. **队列比较的含义**：索引小的先行动，不是"值小的更优"。这是模拟行动顺序，不是优先级
3. **ban 最近的对手**：贪心策略是 ban 下一个出现的对手，不是随机 ban。双队列自然实现了这一点
4. **循环结构**：用 while(!qR.empty() && !qD.empty()) 同时检查两个队列都非空
5. **字符串长度 n 的含义**：每一轮的长度，用于计算"下一轮"的偏移量

## 面试追问

1. **Q: 为什么每个参议员应该 ban 最近的对手而不是最远的？**
   A: 如果 ban 最远的对手，最近的对手在你行动之后就会紧接着行动并 ban 你的队友（甚至你自己在下一轮的权利）。ban 最近的对手可以最大化阻止对方的"最紧迫威胁"。

2. **Q: 双队列的时间复杂度为什么是 O(n)？**
   A: 每个参议员最多被处理两次（一次加入队列，一次被 ban 或者胜出并加入下一轮）。总的操作次数不超过 2n。虽然可能有多轮，但每轮淘汰至少一个参议员，所以总轮数不超过 n。

3. **Q: 这道题能用优先队列（堆）解吗？**
   A: 可以但没必要。双队列已经保持了正确的顺序，用堆反而增加了 O(log n) 的开销。

4. **Q: 如果规则改为"可以 ban 任意一个对手"（不限最近），结果会不同吗？**
   A: 最优策略下结果不变，因为 ban 最近的对手就是最优策略（数学上可以证明）。但如果参议员不够聪明，结果可能不同。

5. **Q: 如何证明贪心的正确性？**
   A: 通过交换论证：假设最优策略中某个参议员 ban 了更远的对手 x，而没有 ban 更近的对手 y。那么 y 会先行动并可能 ban 我方成员。将策略改为 ban y，不会比原策略更差。
