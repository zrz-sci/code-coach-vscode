# 730. 统计不同回文子序列 (Count Different Palindromic Subsequences)

## 难度：Hard

## 标签：String, Dynamic Programming

## 提示

### 提示 1
字符集只有 `{a, b, c, d}` 四个字符，这是解题的关键约束。可以对每个字符分别考虑以该字符开头和结尾的回文子序列数量。

### 提示 2
定义 `dp[i][j]` 为 `s[i..j]` 中不同回文子序列的个数。对于区间 `[i, j]`，可以按四个字符分别枚举：找到字符 `c` 在区间内的最左和最右出现位置。

### 提示 3
设字符 `c` 在 `s[i..j]` 中的最左位置为 `lo`，最右位置为 `hi`：
- 若 `lo > j`：字符 `c` 不在区间内，贡献 0
- 若 `lo == hi`：只有单个字符 `c`，贡献 1（即 "c"）
- 若 `lo < hi`：贡献 `dp[lo+1][hi-1] + 2`（内部回文子序列外包一层 `c`，加上 "c" 和 "cc" 两个）

### 提示 4
注意对 `10^9 + 7` 取模，防止溢出。

## 解题思路

**区间 DP + 按字符分类**

1. 预处理每个字符的出现位置，或使用 `next[i][c]` / `prev[i][c]` 快速找最近的字符
2. `dp[i][j]` = 对四个字符 c 分别计算贡献之和
3. 按区间长度从小到大填表
4. 答案为 `dp[0][n-1]`

## 复杂度分析
- 时间：O(n^2)，n 为字符串长度
- 空间：O(n^2)
