# 687. Longest Univalue Path - 最长同值路径

## 难度：Medium

## 标签：Tree, DFS, Binary Tree, Recursion

---

## 核心思路

这是一道经典的"树上路径问题"，核心模式是**后序遍历 + 单侧返回 / 双侧更新全局**。对每个节点，递归计算从左子树和右子树向下延伸的最长同值边数。如果子节点与当前节点值相同，该侧的臂长就可以 +1。全局答案在每个节点处用"左臂 + 右臂"更新，但返回给父节点的只能是较长的一侧（路径不能分叉）。

---

## 思维链

1. 路径是树中任意两个节点之间的连线，不一定经过根。路径长度按**边数**计（不是节点数）。
2. 对于树上路径问题，通常的策略是：在每个节点处"拐弯"计算经过该节点的最优路径，同时向父节点返回单侧最优值。
3. 后序遍历保证：处理当前节点时，子树的信息已经计算完成。
4. 对于节点 `node`，递归返回的 `leftLen` 和 `rightLen` 是子节点为起点的最长同值单侧边数。
5. 如果 `node->left` 存在且 `node->left->val == node->val`，则 `leftArm = leftLen + 1`（从 node 经过左子延伸）。否则 `leftArm = 0`（值不同，路径中断）。
6. 同理 `rightArm`。
7. 经过 node 的最长同值路径 = `leftArm + rightArm`，用于更新全局答案。
8. 返回 `max(leftArm, rightArm)` 给父节点（只能选一侧）。

| 解法 | 时间 | 空间 | 特点 |
|------|------|------|------|
| DFS 后序遍历 + 全局变量 | O(n) | O(h) | 标准做法，最简洁 |
| DFS 后序遍历 + 引用参数 | O(n) | O(h) | 避免全局变量，更函数式 |
| 迭代后序遍历 + 栈 | O(n) | O(n) | 面试中展示非递归能力 |

## 关键提示

### 提示 1 - 路径 vs 单侧链
在树上，一条路径最多有一个"拐弯点"（即路径的最高节点）。在该拐弯点处，路径由左臂和右臂组成。而向父节点返回的值只能是不拐弯的单侧链。

### 提示 2 - 递归返回值的含义
递归函数 `dfs(node)` 返回的是"以 node 为起点向下延伸的最长同值**边数**"。注意是边数不是节点数。空节点返回 0。

### 提示 3 - 值不同时的处理
当子节点值与当前节点不同时，该方向的臂长直接归零。递归返回的 `leftLen`/`rightLen` 不会被使用（因为路径在此中断）。

### 提示 4 - 为什么需要全局变量
如果只看递归返回值，我们只能得到单侧的最长路径。但实际答案可能是某个节点处"左臂 + 右臂"的路径。这个双侧路径不能作为返回值传给父节点，所以用全局变量单独维护。

### 提示 5 - 与 LC 124 的类比
LC 124 (Binary Tree Maximum Path Sum) 的递归结构几乎一模一样：递归返回单侧最大贡献，全局变量维护双侧路径最优值。唯一的区别是 LC 124 考虑路径和，本题考虑同值路径长度。

## 解法详解

### DFS 后序遍历

```
dfs(node):
    if node is null: return 0

    leftLen = dfs(node.left)    // 左子树的单侧最长
    rightLen = dfs(node.right)  // 右子树的单侧最长

    leftArm = 0, rightArm = 0

    if node.left exists AND node.left.val == node.val:
        leftArm = leftLen + 1   // 当前节点到左子方向可以延伸

    if node.right exists AND node.right.val == node.val:
        rightArm = rightLen + 1  // 当前节点到右子方向可以延伸

    // 更新全局答案: 经过 node 的完整路径
    globalAns = max(globalAns, leftArm + rightArm)

    // 返回单侧最长给父节点
    return max(leftArm, rightArm)
```

**示例推演：**
```
      1
     / \
    4   5
   / \   \
  4   4    5
```
- 节点 4（左下叶子）：无子节点，返回 0
- 节点 4（右下叶子）：无子节点，返回 0
- 节点 4（左上）：leftArm=1（左子值4=自身4）, rightArm=1（右子值4=自身4），全局更新为 2，返回 1
- 节点 5（右下叶子）：返回 0
- 节点 5（右上）：rightArm=1，全局不更新（1 < 2），返回 1
- 节点 1（根）：leftArm=0（左子值4≠1）, rightArm=0（右子值5≠1），全局不更新
- 最终答案：2

## 易错点

1. **返回边数 vs 节点数**：题目要求的是边数。如果 node 和 child 值相同，臂长是 childLen + 1（加的是一条边），而不是 childLen + 2。
2. **空树返回 0 而不是 -1**：空树没有边，最长同值路径为 0。
3. **全局变量初始化**：必须在主函数入口处将 `ans` 重置为 0（不能依赖类初始化，因为 LeetCode 可能复用对象）。
4. **忘记在值不同时归零**：如果子节点值与当前节点不同，该方向的臂长必须重置为 0，不能直接用子节点返回的值。
5. **路径不必经过根**：答案可能在子树深处。全局变量在每个节点处更新，确保不会遗漏。
6. **单节点树**：只有根节点时，没有边，答案为 0（不是 1）。

## 面试追问

1. **如果要求最长路径经过根节点呢？**
   → 只需在根节点处计算 leftArm + rightArm，不需要全局变量。

2. **如果不是二叉树而是 N 叉树，怎么修改？**
   → 对每个子节点计算臂长，全局答案用"最大的两个臂长之和"更新，返回"最大的一个臂长"。

3. **如何不用全局变量？**
   → 让递归函数返回一个 pair<int, int>，分别是单侧最长和子树内的全局最优。或者通过引用参数传递全局最优值。

4. **如果要求返回具体路径而不是长度？**
   → 在更新全局答案时同时记录路径的两个端点节点，最后用 DFS 重建路径。

5. **时间复杂度能否优于 O(n)？**
   → 不能。每个节点至少要访问一次才能确定它的值是否与邻居相同。
