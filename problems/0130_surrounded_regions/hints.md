# 130. 被围绕的区域

## 核心思路

**逆向思维**：与其判断哪些 `'O'` 被围绕（正向很难判断），不如找出哪些 `'O'` **没有**被围绕（即与边界相连的 `'O'`），剩下的就是被围绕的。

## 思维链

1. **读完题第一反应**：遍历每个 `'O'`，用 BFS/DFS 找出它所在的连通区域，如果这个区域**没有**触碰边界，就全部变成 `'X'`。这是最朴素的做法。

2. **暴力解的麻烦在哪？** 对每个 `'O'` 区域做 BFS/DFS，还要在搜索过程中检测"是否碰到边界"。如果碰到了就不翻转，没碰到才翻转。逻辑复杂，需要先搜一遍确认，再搜一遍翻转，或者用额外标记。

3. **逆向突破**：换个角度——**从边界出发**！边界上的 `'O'` 一定不会被围绕，与边界 `'O'` 相连的所有 `'O'` 也不会被围绕。其余的 `'O'` 一定是被围绕的。

4. **具体做法**：
   - 第一步：扫描四条边界，对每个边界上的 `'O'` 做 DFS/BFS，标记所有与边界相连的 `'O'`（比如改为 `'#'`）
   - 第二步：遍历整个矩阵，`'O'` → `'X'`（被围绕），`'#'` → `'O'`（恢复，没被围绕）

5. **进阶**：还可以用并查集(Union-Find)，把所有边界 `'O'` 连到一个虚拟节点，最后检查每个 `'O'` 是否和虚拟节点连通。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| DFS 边界标记 | 从边界 `'O'` 出发 DFS 标记安全区域 | O(m×n) | O(m×n) 递归栈 | ⭐ 必须写出 |
| BFS 边界标记 | 从边界 `'O'` 出发 BFS 标记安全区域 | O(m×n) | O(m×n) 队列 | ⭐ 必须写出 |
| 并查集 | 边界 `'O'` 与虚拟节点合并 | O(m×n·α) | O(m×n) | 加分项 |

## 关键提示

1. **逆向思维**：不要正向找"被围绕的"，而是反向找"没被围绕的"——即与边界相连的 `'O'`。

2. **起点在边界**：只需从矩阵的四条边上的 `'O'` 作为搜索起点，不需要从内部的 `'O'` 开始。

3. **原地标记**：用第三种字符（如 `'#'`）做临时标记，避免额外的 visited 数组。

4. 矩阵示意（以示例1为例）：
```
原始:           标记边界连通:     最终结果:
X X X X         X X X X          X X X X
X O O X    →    X O O X     →    X X X X
X X O X         X X O X          X X X X
X O X X         X # X X          X O X X
                ↑
           (3,1)的O在边界，标记为#
```

5. **BFS vs DFS**：两者时间复杂度相同。DFS 代码更简洁，但大矩阵可能栈溢出；BFS 用队列更安全。

## 解法详解

### 解法1: DFS 边界标记 — O(m×n) / O(m×n) ⭐ 面试首选

**思考过程**：题目要求把被围绕的 `'O'` 变成 `'X'`。什么样的 `'O'` 不被围绕？与边界直接或间接相连的。所以从边界的 `'O'` 开始 DFS，把它们标记为安全（改成 `'#'`），然后把剩下的 `'O'` 都变成 `'X'`，再把 `'#'` 恢复成 `'O'`。

```cpp
class Solution {
public:
    void solve(vector<vector<char>>& board) {
        int m = board.size(), n = board[0].size();
        
        // 第一步：从四条边界的 'O' 出发 DFS，标记所有与边界相连的 'O' 为 '#'
        for (int i = 0; i < m; i++) {
            if (board[i][0] == 'O') dfs(board, i, 0);         // 左边界
            if (board[i][n-1] == 'O') dfs(board, i, n - 1);   // 右边界
        }
        for (int j = 0; j < n; j++) {
            if (board[0][j] == 'O') dfs(board, 0, j);         // 上边界
            if (board[m-1][j] == 'O') dfs(board, m - 1, j);   // 下边界
        }
        
        // 第二步：遍历整个矩阵，翻转
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 'O') board[i][j] = 'X';      // 被围绕的 → X
                else if (board[i][j] == '#') board[i][j] = 'O';  // 安全的 → 恢复O
            }
        }
    }
    
private:
    void dfs(vector<vector<char>>& board, int i, int j) {
        int m = board.size(), n = board[0].size();
        // 越界、不是'O'就返回（'X'和已标记的'#'都不需要继续）
        if (i < 0 || i >= m || j < 0 || j >= n || board[i][j] != 'O') return;
        
        board[i][j] = '#';  // 标记为安全（替代 visited 数组）
        
        dfs(board, i + 1, j);  // 下
        dfs(board, i - 1, j);  // 上
        dfs(board, i, j + 1);  // 右
        dfs(board, i, j - 1);  // 左
    }
};
```

**关键点**：
- DFS 中直接用 `board[i][j] = '#'` 代替 visited 数组，因为我们本来就要原地修改
- 递归终止条件 `board[i][j] != 'O'` 同时排除了越界后的非法访问（先检查越界）、`'X'` 和已标记的 `'#'`

### 解法2: BFS 边界标记 — O(m×n) / O(m×n) ⭐ 面试首选

**从解法1的考量出发**：DFS 在极端情况下（如 200×200 全是 `'O'`）递归深度可达 40000，可能栈溢出。BFS 用队列替代递归栈，更稳健。

```cpp
class Solution {
public:
    void solve(vector<vector<char>>& board) {
        int m = board.size(), n = board[0].size();
        queue<pair<int,int>> q;
        
        // 第一步：把所有边界上的 'O' 入队
        for (int i = 0; i < m; i++) {
            if (board[i][0] == 'O')     { board[i][0] = '#'; q.push({i, 0}); }
            if (board[i][n-1] == 'O')   { board[i][n-1] = '#'; q.push({i, n-1}); }
        }
        for (int j = 0; j < n; j++) {
            if (board[0][j] == 'O')     { board[0][j] = '#'; q.push({0, j}); }
            if (board[m-1][j] == 'O')   { board[m-1][j] = '#'; q.push({m-1, j}); }
        }
        
        // BFS 扩展：标记所有与边界相连的 'O'
        int dx[] = {0, 0, 1, -1};
        int dy[] = {1, -1, 0, 0};
        while (!q.empty()) {
            auto [x, y] = q.front(); q.pop();
            for (int d = 0; d < 4; d++) {
                int nx = x + dx[d], ny = y + dy[d];
                if (nx >= 0 && nx < m && ny >= 0 && ny < n && board[nx][ny] == 'O') {
                    board[nx][ny] = '#';  // 入队时就标记，避免重复入队
                    q.push({nx, ny});
                }
            }
        }
        
        // 第二步：统一翻转
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 'O') board[i][j] = 'X';
                else if (board[i][j] == '#') board[i][j] = 'O';
            }
        }
    }
};
```

**关键点**：
- **入队时标记**，而不是出队时标记。如果出队时才标记，同一个节点可能被多次入队，浪费时间和空间。

### 解法3: 并查集(Union-Find) — O(m×n·α) / O(m×n) — 加分项

**不同视角**：把每个 `'O'` 看作一个节点，相邻的 `'O'` 合并到同一集合。额外创建一个虚拟节点 `dummy`，所有边界上的 `'O'` 与 `dummy` 合并。最后，与 `dummy` 不连通的 `'O'` 就是被围绕的。

```cpp
class Solution {
public:
    vector<int> parent, rank_;
    
    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);  // 路径压缩
        return parent[x];
    }
    
    void unite(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return;
        // 按秩合并
        if (rank_[px] < rank_[py]) swap(px, py);
        parent[py] = px;
        if (rank_[px] == rank_[py]) rank_[px]++;
    }
    
    void solve(vector<vector<char>>& board) {
        int m = board.size(), n = board[0].size();
        int dummy = m * n;  // 虚拟节点，代表"与边界相连"
        
        parent.resize(m * n + 1);
        rank_.resize(m * n + 1, 0);
        iota(parent.begin(), parent.end(), 0);  // parent[i] = i
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] != 'O') continue;
                
                int id = i * n + j;
                
                // 边界上的 'O' 连接到 dummy
                if (i == 0 || i == m - 1 || j == 0 || j == n - 1) {
                    unite(id, dummy);
                }
                
                // 与右边和下边的 'O' 合并（只需两个方向，避免重复）
                if (i + 1 < m && board[i+1][j] == 'O') unite(id, (i+1)*n + j);
                if (j + 1 < n && board[i][j+1] == 'O') unite(id, i*n + j + 1);
            }
        }
        
        // 不与 dummy 连通的 'O' 就是被围绕的
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 'O' && find(i * n + j) != find(dummy)) {
                    board[i][j] = 'X';
                }
            }
        }
    }
};
```

**关键点**：
- 虚拟节点 `dummy` 的巧妙之处：不用特判哪些边界 `'O'` 互相连通，统一和 `dummy` 连就行
- 合并时只往右和下看（两个方向），因为左和上的合并已经在之前的遍历中处理了

## 解法对比

| | DFS 边界标记 | BFS 边界标记 | 并查集 |
|---|---|---|---|
| 时间 | O(m×n) | O(m×n) | O(m×n·α) ≈ O(m×n) |
| 空间 | O(m×n) 递归栈 | O(m×n) 队列 | O(m×n) 父数组 |
| 代码量 | 最少 | 适中 | 最多 |
| 栈溢出风险 | 有（大矩阵） | 无 | 无 |
| 面试推荐 | 小矩阵/简洁优先 | 稳健首选 | 展示并查集能力 |

**核心区别**：DFS 和 BFS 本质相同，都是"从边界出发标记安全区域"，区别只在遍历顺序。并查集是完全不同的思路——不做搜索标记，而是维护连通性。

## 易错点

1. **DFS 中先检查越界再访问 `board[i][j]`**
   - ✗ `if (board[i][j] != 'O' || i < 0 || ...)` — 越界后访问 `board[i][j]` 是未定义行为
   - ✓ `if (i < 0 || i >= m || j < 0 || j >= n || board[i][j] != 'O')` — 短路求值保证安全

2. **BFS 入队时标记，不是出队时标记**
   - ✗ 出队时才 `board[x][y] = '#'` → 同一个格子被相邻多个格子重复入队，导致队列膨胀
   - ✓ 入队时立即 `board[nx][ny] = '#'` → 每个格子最多入队一次

3. **第二步翻转顺序不能反**
   - ✗ 先恢复 `'#'→'O'`，再翻转 `'O'→'X'` → 刚恢复的 `'O'` 又被翻成 `'X'`
   - ✓ 先翻转 `'O'→'X'`（或用 if-else 保证互斥），`'#'→'O'` 不受影响

4. **并查集中忘记路径压缩**
   - 不加路径压缩，最坏情况 `find()` 退化成 O(n)，整体退化成 O(m×n×m×n)

5. **边界遍历漏掉角落**
   - 分别遍历行和列时，四个角落可能被处理两次。这不会出错（已标记为 `'#'` 第二次不会处理），但要理解为什么。

## 面试追问

**Q1: 为什么不从内部的 `'O'` 开始搜索，而要从边界开始？（基础理解）**
- 从内部开始，需要搜完整个连通区域后才能判断"是否碰到边界"。如果碰到了，还要撤销所有标记。逆向从边界开始，天然保证标记的都是安全的，不需要撤销。

**Q2: 如果矩阵非常大（如 10000×10000），DFS 会有什么问题？怎么解决？（优化）**
- 递归深度可达 10^8，远超栈空间限制。解决方案：(1) 用 BFS 替代 DFS；(2) 用显式栈模拟 DFS；(3) 用并查集避免搜索。

**Q3: 如果题目改成"找出所有被围绕的区域的面积总和"呢？（变体）**
- 用同样的边界标记方法。标记完安全区域后，遍历矩阵统计仍然是 `'O'` 的格子数量即可。

**Q4: 如果允许对角线也算相连呢？**
- 方向数组从 4 个方向扩展到 8 个方向：`dx[] = {-1,-1,-1,0,0,1,1,1}`, `dy[] = {-1,0,1,-1,1,-1,0,1}`。其余逻辑不变。
