# 918. 环形子数组的最大和 (Maximum Sum Circular Subarray)

## 题目理解

给定一个长度为 n 的**环形**整数数组 `nums`，返回其非空子数组的最大可能和。
"环形"意味着数组末尾连接到开头：`nums[n-1]` 的下一个元素是 `nums[0]`。

```
示例 1: nums = [1,-2,3,-2] → 输出 3  (子数组 [3])
示例 2: nums = [5,-3,5]    → 输出 10 (子数组 [5,5]，跨越边界)
示例 3: nums = [-3,-2,-3]  → 输出 -2 (子数组 [-2]，全负数时选最大的单个元素)
```

---

## 核心思路

环形子数组的最大和只可能有两种情况：

```
情况 1: 最大子数组在中间（不跨越边界）
┌─────────────────────────┐
│  ...  [===最大===]  ... │
└─────────────────────────┘
    → 用经典 Kadane 算法求 maxSum

情况 2: 最大子数组跨越首尾（绕过边界）
┌─────────────────────────┐
│ [==]  ...最小段...  [==]│
└──↑──────────────────↑───┘
   └──跨越边界的子数组──┘
    → 等价于 totalSum - minSum
```

**关键洞察**：跨越边界的子数组 = 整个数组 - 中间不选的一段。要让跨越部分尽量大，就要让中间不选的部分尽量小，即求**最小子数组和**。

最终答案：`max(maxSum, totalSum - minSum)`

---

## 思维链：从零到最优

### Level 1：暴力 O(n^2)

对于环形数组，可以枚举每个起点，向右扩展最多 n 个元素：

```
for i in 0..n:
    for len in 1..n:
        sum of nums[i..i+len] (mod n)
```

时间 O(n^2)，不够优。

### Level 2：拆分成两种情况 + Kadane O(n)

**情况 1 - 不跨越边界**：就是经典的 [53. 最大子数组和](https://leetcode.cn/problems/maximum-subarray/)，用 Kadane 算法。

**Kadane 算法回顾**：
```
curMax = max(curMax + nums[i], nums[i])  // 要么延续，要么从头开始
maxSum = max(maxSum, curMax)              // 更新全局最优
```

**情况 2 - 跨越边界**：

```
数组:    [a, b, c, d, e, f, g]
totalSum = a+b+c+d+e+f+g

如果跨越的子数组选了 [e,f,g] + [a,b]
那么不选的是 [c,d]
跨越子数组和 = totalSum - (c+d) = totalSum - minSubarraySum
```

所以只需要同时求最小子数组和！用 Kadane 的"镜像版"：
```
curMin = min(curMin + nums[i], nums[i])
minSum = min(minSum, curMin)
```

### Level 3：处理全负数边界

当所有元素都是负数时：
- `maxSum` 是最大的那个负数（比如 -2）
- `minSum = totalSum`（整个数组就是最小子数组）
- `totalSum - minSum = 0`

但题目要求**非空子数组**！`0` 对应空子数组，不合法。

**特判**：如果 `maxSum < 0`（所有元素都是负数），直接返回 `maxSum`。

## Kadane 变体详细推演

以 `nums = [5, -3, 5]` 为例：

```
┌────────┬────────┬────────┬─────────┬────────┬─────────┬──────────┐
│  i     │ num    │ curMax │ maxSum  │ curMin │ minSum  │ totalSum │
├────────┼────────┼────────┼─────────┼────────┼─────────┼──────────┤
│ 初始   │  -     │   0    │ -INF    │   0    │ +INF    │    0     │
│  0     │  5     │   5    │   5     │   5    │   5     │    5     │
│  1     │ -3     │   2    │   5     │  -3    │  -3     │    2     │
│  2     │  5     │   7    │   7     │   2    │  -3     │    7     │
└────────┴────────┴────────┴─────────┴────────┴─────────┴──────────┘

情况1: maxSum = 7    (子数组 [5,-3,5])
情况2: totalSum - minSum = 7 - (-3) = 10  (子数组 [5,5] 跨越边界!)
答案 = max(7, 10) = 10 ✓
```

以 `nums = [1, -2, 3, -2]` 为例：

```
┌────────┬────────┬────────┬─────────┬────────┬─────────┬──────────┐
│  i     │ num    │ curMax │ maxSum  │ curMin │ minSum  │ totalSum │
├────────┼────────┼────────┼─────────┼────────┼─────────┼──────────┤
│ 初始   │  -     │   0    │ -INF    │   0    │ +INF    │    0     │
│  0     │  1     │   1    │   1     │   1    │   1     │    1     │
│  1     │ -2     │  -1→-2 │   1     │  -1→-2 │  -2     │   -1     │
│  2     │  3     │   3    │   3     │   1    │  -2     │    2     │
│  3     │ -2     │   1    │   3     │  -1→-2 │  -2     │    0     │
└────────┴────────┴────────┴─────────┴────────┴─────────┴──────────┘
注: curMax=max(curMax+num, num), curMin=min(curMin+num, num)

情况1: maxSum = 3       (子数组 [3])
情况2: totalSum - minSum = 0 - (-2) = 2
答案 = max(3, 2) = 3 ✓
```

以 `nums = [-3, -2, -3]` 为例（全负数）：

```
┌────────┬────────┬────────┬─────────┬────────┬─────────┬──────────┐
│  i     │ num    │ curMax │ maxSum  │ curMin │ minSum  │ totalSum │
├────────┼────────┼────────┼─────────┼────────┼─────────┼──────────┤
│ 初始   │  -     │   0    │ -INF    │   0    │ +INF    │    0     │
│  0     │ -3     │  -3    │  -3     │  -3    │  -3     │   -3     │
│  1     │ -2     │  -2    │  -2     │  -5    │  -5     │   -5     │
│  2     │ -3     │  -3    │  -2     │  -8    │  -8     │   -8     │
└────────┴────────┴────────┴─────────┴────────┴─────────┴──────────┘

情况1: maxSum = -2
情况2: totalSum - minSum = -8 - (-8) = 0  ← 非法! 对应空子数组
maxSum < 0 → 全负数，返回 maxSum = -2 ✓
```

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 推荐度 |
|------|------|------|------|--------|
| Kadane 变体 | max(maxKadane, totalSum - minKadane) | O(n) | O(1) | 强烈推荐 |
| 前缀和 + 单调队列 | 双倍数组上滑动窗口 | O(n) | O(n) | 了解即可 |
| 暴力枚举 | 枚举所有子数组 | O(n^2) | O(1) | 面试不推荐 |

## 关键提示

### 提示 1：两种情况覆盖所有

任何环形子数组：
- 要么完全在 `[0, n-1]` 内部（不跨边界）→ Kadane 求最大
- 要么跨越 `n-1` 到 `0` 的边界 → `totalSum - 最小子数组和`

**证明**：跨越边界时，选中的元素 = 全部元素 - 中间不选的连续段。不选的段一定是一个不跨边界的子数组。

### 提示 2：一次遍历同时维护四个变量

```
curMax  → 当前位置结尾的最大子数组和（Kadane 标准）
maxSum  → 全局最大子数组和
curMin  → 当前位置结尾的最小子数组和（Kadane 镜像）
minSum  → 全局最小子数组和
```

### 提示 3：全负数特判的本质

当所有元素为负：
- `minSum = totalSum`（整个数组是最小子数组）
- `totalSum - minSum = 0` 对应选空集，违反"非空"约束
- 判断条件：`maxSum < 0`（或等价地 `minSum == totalSum`）

### 提示 4：与 Leetcode 53 的关系

本题 = Kadane 求最大 + Kadane 求最小 + 全负数特判。如果你会 53 题，这道题只需要加一个"求最小的 Kadane"和一个 if 判断。

## 易错点

### 1. 忘记全负数特判

```cpp
// 错误：全负数时 totalSum - minSum = 0，返回 0 不对
return max(maxSum, totalSum - minSum);

// 正确：加特判
if (maxSum < 0) return maxSum;
return max(maxSum, totalSum - minSum);
```

### 2. 初始化错误

```cpp
// 错误：maxSum 初始化为 0
int maxSum = 0;  // 如果所有元素都是负数，maxSum 永远不会更新

// 正确：初始化为 INT_MIN
int maxSum = INT_MIN;
```

### 3. curMax/curMin 的 Kadane 更新

```cpp
// 错误：用 if-else 容易漏掉情况
if (curMax + num > num) curMax = curMax + num;
else curMax = num;

// 正确：直接用 max/min，简洁不易错
curMax = max(curMax + num, num);
curMin = min(curMin + num, num);
```

## 拓展思考

### 为什么不能直接把数组复制一遍变成长度 2n？

可以！但子数组长度不能超过 n。需要用前缀和 + 单调队列维护窗口大小为 n 的最大差值，复杂度 O(n) 但空间 O(n)，代码更复杂。

### 面试追问

1. **如果要求返回具体的子数组区间？** → 在 Kadane 中记录 start/end 索引
2. **如果数组可以绕多圈？** → 不同问题，需要用其他方法
3. **空间能否 O(1)？** → Kadane 变体已经是 O(1) 了
