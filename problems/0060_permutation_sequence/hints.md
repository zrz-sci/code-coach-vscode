# 60. 排列序列 (Permutation Sequence)

## 核心思路

给定 `n` 和 `k`，返回 `[1, 2, ..., n]` 的所有排列中，按字典序排列的第 `k` 个排列。

本质上就是一个**康托展开逆运算 / 阶乘进制转换**问题：利用阶乘数系统，逐位确定每一位数字，不需要枚举所有排列。

## 思维链

1. **读完题第一反应** → 生成所有 n! 个排列，返回第 k 个。但 n 最大 9，9! = 362880，暴力虽然能过但面试官肯定不满意。
2. **关键观察** → n 个数的排列共 n! 种。如果固定第一位，剩下 (n-1)! 种排列。这意味着：
   - 第一位确定后，后面的排列数量是固定的。
   - 我们可以用除法确定第一位是哪个数字。
3. **数学推导** → k-1 除以 (n-1)! 得到第一位在候选数组中的下标；取模后得到新的 k，继续确定第二位...直到所有位确定。
4. **为什么 k-1？** → 排列是 1-indexed 的（第 1 个排列是最小的），但数组下标是 0-indexed。`k-1` 转换为 0-indexed 让除法和取模自然对齐。

```
示例: n=3, k=3

候选数字: [1, 2, 3]
阶乘: 0!=1, 1!=1, 2!=2

k = 3 - 1 = 2 (转0-indexed)

第1位: 2 / 2! = 2 / 2 = 1 → 候选[1] = 2, 移除2 → 候选 [1, 3]
       2 % 2! = 2 % 2 = 0 → 新 k = 0

第2位: 0 / 1! = 0 / 1 = 0 → 候选[0] = 1, 移除1 → 候选 [3]
       0 % 1! = 0 % 1 = 0 → 新 k = 0

第3位: 0 / 0! = 0 / 1 = 0 → 候选[0] = 3, 移除3 → 候选 []

结果: "213" ✓

验证: n=3 的排列按字典序:
  第1个: 123
  第2个: 132
  第3个: 213 ✓
  第4个: 231
  第5个: 312
  第6个: 321
```

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 回溯枚举 | 生成所有排列取第k个 | O(n!) | O(n) | TLE / 太慢 |
| 阶乘数系统 | 逐位确定，数学直算 | O(n^2) | O(n) | ⭐⭐ 唯一正解 |

## 关键提示

1. **k 先减 1 转为 0-indexed**：这是最关键的一步。不做这一步，后面所有除法和取模的结果都会偏移。
2. **候选数组 + 移除操作**：用一个 vector 存候选数字 `[1, 2, ..., n]`，每确定一位就从中移除。`erase` 操作是 O(n)，所以总时间是 O(n^2)。
3. **阶乘预计算**：先算好 `factorial[0..n-1]`，避免重复计算。`factorial[0] = 1`（0! = 1）。
4. **循环方向**：从最高位（第 1 位）到最低位（第 n 位），每轮确定一位。对应阶乘从 `(n-1)!` 递减到 `0!`。
5. **康托展开的逆运算**：本题正是康托展开逆运算 — 给定排名 k，还原排列。正向的康托展开则是给定排列，求排名。

## 解法详解

### 解法1: 回溯暴力 — O(n!) / O(n) (不推荐)

**思考过程**: 用 next_permutation 或回溯生成所有排列，跳到第 k 个。

```cpp
class Solution {
public:
    string getPermutation(int n, int k) {
        string s = "";
        for (int i = 1; i <= n; i++) s += to_string(i);
        // 调用 k-1 次 next_permutation
        for (int i = 1; i < k; i++) {
            next_permutation(s.begin(), s.end());
        }
        return s;
    }
};
```

**关键点**:
- `next_permutation` 单次 O(n)，调用 k-1 次 → O(kn)。最坏 k = n!，总时间 O(n * n!)。
- n=9 时 9! = 362880，勉强能过但效率极低。
- 这个解法只用来说明"为什么需要数学方法"。

---

### 解法2: 阶乘数系统（康托展开逆运算） — O(n^2) / O(n) ⭐⭐

**从暴力优化**: 不需要枚举前面的排列，可以直接通过数学计算"跳"到第 k 个。

**核心算法**:
```
输入: n=4, k=14

阶乘表: [1, 1, 2, 6]  (即 0!, 1!, 2!, 3!)
候选数: [1, 2, 3, 4]
k = 14 - 1 = 13 (0-indexed)

第1位: 13 / 3! = 13/6 = 2 → 候选[2] = 3
       13 % 3! = 13%6 = 1 → k=1
       候选: [1, 2, 4]

第2位: 1 / 2! = 1/2 = 0 → 候选[0] = 1
       1 % 2! = 1%2 = 1 → k=1
       候选: [2, 4]

第3位: 1 / 1! = 1/1 = 1 → 候选[1] = 4
       1 % 1! = 1%1 = 0 → k=0
       候选: [2]

第4位: 0 / 0! = 0/1 = 0 → 候选[0] = 2
       候选: []

结果: "3142" ✓
```

```cpp
class Solution {
public:
    string getPermutation(int n, int k) {
        // 1. 预计算阶乘
        vector<int> factorial(n, 1);
        for (int i = 1; i < n; i++) {
            factorial[i] = factorial[i - 1] * i;
        }
        
        // 2. 候选数字 [1, 2, ..., n]
        vector<int> nums;
        for (int i = 1; i <= n; i++) {
            nums.push_back(i);
        }
        
        // 3. k 转为 0-indexed
        k--;
        
        // 4. 逐位确定
        string result;
        for (int i = n - 1; i >= 0; i--) {
            int idx = k / factorial[i];       // 当前位在候选中的下标
            result += to_string(nums[idx]);   // 取出数字
            nums.erase(nums.begin() + idx);   // 从候选中移除
            k %= factorial[i];                // 更新 k
        }
        
        return result;
    }
};
```

**关键点**:
- **时间 O(n^2)**：循环 n 次，每次 erase 是 O(n)。对于 n <= 9 完全够用。
- **空间 O(n)**：阶乘数组 + 候选数字数组。
- `factorial[i]` 存的是 i!，注意 `factorial[0] = 1`（0! = 1）。
- 循环中 `i` 从 `n-1` 到 `0`，对应阶乘从 `(n-1)!` 到 `0!`。

---

### 解法2b: 使用链表/BIT 优化候选集合

**进阶**: `vector::erase` 是 O(n)，如果 n 很大，可以用：
- **链表**：删除 O(1)，但查找第 idx 个需要遍历 O(n)，总体仍 O(n^2)。
- **树状数组 (BIT / Fenwick Tree)**：O(log n) 查找第 idx 个 + O(log n) 删除 → 总 O(n log n)。

对于面试（n <= 9），vector 版本足够。BIT 版本作为追问提及即可。

## 解法对比

|  | 回溯/暴力 | 阶乘数系统 | 阶乘+BIT |
|--|----------|-----------|----------|
| 时间 | O(n * n!) | **O(n^2)** | O(n log n) |
| 空间 | O(n) | O(n) | O(n) |
| n=9 可行性 | 勉强 | 极快 | 极快 |
| n=100 可行性 | 不可能 | O(10000) | O(700) |

## 易错点

1. **忘记 k-1**：
   - ✗ 直接用 `k` 做除法 → 所有结果偏移一位
   - ✓ `k--` 转为 0-indexed

2. **候选数组忘记移除已选数字**：
   - ✗ 不 erase → 同一个数字被选多次
   - ✓ 每选一个数字后 `nums.erase(nums.begin() + idx)`

3. **阶乘下标搞混**：
   - ✗ `factorial[i]` 存的是 `(i+1)!` → 除法结果全错
   - ✓ `factorial[i]` 存的是 `i!`，即 `factorial[0]=1, factorial[1]=1, factorial[2]=2, ...`

4. **循环方向搞反**：
   - ✗ `for (int i = 0; i < n; i++)` 配合 `factorial[n-1-i]` → 易混淆
   - ✓ `for (int i = n-1; i >= 0; i--)` 配合 `factorial[i]` → 自然对应

5. **大 n 的阶乘溢出**：
   - n=13 时 13! = 6,227,020,800 > INT_MAX
   - 本题 n <= 9，9! = 362880，int 安全
   - 如果 n 更大，需要用 long long

## 面试追问

**Q1: 时间复杂度 O(n^2) 能优化吗？**
> erase 操作 O(n) 导致总体 O(n^2)。可以用树状数组 (BIT) 维护候选集合，支持 O(log n) 的"查找第 idx 个存在的元素" + "删除"，总体 O(n log n)。但面试中 n <= 9，O(n^2) 足够。

**Q2: 反过来，给定排列求它是第几个（康托展开正向）？**
> 对排列的每一位，统计候选数字中有多少个比当前数字小，乘以对应阶乘，累加即可。这就是标准的康托展开。

**Q3: 如何求下一个排列（Next Permutation）？**
> 这是 LeetCode 31 题。从右到左找第一个"下降"位置 i（nums[i] < nums[i+1]），再从右到左找第一个大于 nums[i] 的位置 j，交换 i 和 j，然后反转 i+1 到末尾。

**Q4: 如果 n 很大（比如 n=1000），k 用大整数表示，怎么处理？**
> 需要大整数除法和取模，以及 BIT/线段树维护候选集合。阶乘本身也要用大整数存储。核心思路不变。
