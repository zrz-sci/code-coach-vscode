# LeetCode 882: Reachable Nodes In Subdivided Graph

## 核心思路

本题在一个无向图中，每条边被细分为若干小节点，要求从节点 0 出发，在最多 maxMoves 步内能到达多少个节点（包括原始节点和细分后的新节点）。核心思路是使用 **Dijkstra 最短路径算法**来计算从节点 0 到每个原始节点的最短距离，然后基于剩余步数计算每条边上能覆盖的细分节点数量。对于每条边，分别从两端计算能延伸多少个细分节点，取两端覆盖的并集（但不超过该边的细分节点总数）。

## 思维链

1. **建模分析**：图的每条边 (u, v, cnt) 被细分为 cnt 个新节点。从 u 到 v 经过这条边需要 cnt+1 步。因此在 Dijkstra 中，边权为 cnt+1。
2. **Dijkstra 求最短路**：从节点 0 出发，用 Dijkstra 算法计算到每个原始节点的最短距离 dist[u]。
3. **计算可达原始节点**：dist[u] <= maxMoves 的原始节点都是可达的。
4. **计算可达细分节点**：对于每条边 (u, v, cnt)：
   - 从 u 端能延伸 max(0, maxMoves - dist[u]) 个细分节点
   - 从 v 端能延伸 max(0, maxMoves - dist[v]) 个细分节点
   - 该边上被覆盖的细分节点数 = min(cnt, 从u端延伸 + 从v端延伸)
5. **汇总**：可达原始节点数 + 所有边上可达细分节点数之和。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| Dijkstra + 边遍历 | O(E log N) | O(N + E) | 最优解，标准最短路应用 |

其中 N 为原始节点数（最大 3000），E 为边数（最大 10^4）。

## 关键提示

1. **边权是 cnt+1 而非 cnt** -- 从 u 到 v 经过细分边需要经过 cnt 个新节点再加上到 v 的一步。
2. **dist 数组初始化**：dist[0] = 0，其余为 INT_MAX。未被 Dijkstra 松弛到的节点视为不可达。
3. **细分节点的双向覆盖** -- 一条边上的细分节点可能从两端同时被覆盖，需取 min(cnt, left + right) 防止重复计数。
4. **maxMoves 可能为 0** -- 此时只有节点 0 本身可达，答案为 1。
5. **节点 0 可能孤立** -- 如果节点 0 没有边相连，答案为 1。

## 解法详解

### Dijkstra + 边遍历

**算法步骤**：

1. **建图**：用邻接表存储图，每条边 (u, v, cnt) 的权重为 cnt + 1。

2. **Dijkstra 求最短路**：
   - 使用最小堆（优先队列），初始将 (0, 0) 入堆（距离0，节点0）
   - 每次取出距离最小的节点 u，松弛其所有邻居
   - 得到 dist[i] 表示从节点 0 到节点 i 的最短距离

3. **统计可达原始节点**：
   - 遍历所有原始节点，统计 dist[i] <= maxMoves 的数量

4. **统计可达细分节点**：
   - 遍历每条边 (u, v, cnt)
   - 从 u 端可延伸：`a = max(0, maxMoves - dist[u])`
   - 从 v 端可延伸：`b = max(0, maxMoves - dist[v])`
   - 该边贡献：`min(cnt, a + b)`

5. **返回总和**。

**正确性论证**：
- Dijkstra 保证 dist[u] 是最短距离。从 u 出发还有 maxMoves - dist[u] 步余量，可以沿 (u,v) 边深入该余量步数的细分节点。
- 两端可能覆盖同一个细分节点（当余量之和 >= cnt），因此取 min(cnt, a+b) 避免重复。

**复杂度分析**：
- 时间：O(E log N) -- Dijkstra 使用最小堆
- 空间：O(N + E) -- 邻接表和距离数组

## 易错点

1. **边权理解错误**：边权是 cnt+1（经过 cnt 个细分节点 + 到达对端），不是 cnt。
2. **忘记处理不可达节点**：如果 dist[u] == INT_MAX，则该节点不可达，从该端延伸的细分节点数为 0。
3. **细分节点重复计数**：必须用 min(cnt, a+b)，不能简单相加。
4. **整数溢出**：maxMoves 和 dist 都可能很大，相减前需检查 dist[u] <= maxMoves。
5. **自环和重边**：题目保证无重边且 u < v，但仍需注意建图时是无向图（双向添加边）。

## 面试追问

1. **为什么选择 Dijkstra 而非 BFS？**
   - 因为边权不是 1（而是 cnt+1），BFS 只适用于无权图。如果在细分后的图上做 BFS，节点数可能高达 10^8，不可行。

2. **如果有负权边怎么办？**
   - cnt >= 0 所以边权 >= 1，不存在负权边。若存在负权需用 Bellman-Ford。

3. **能否用 Floyd-Warshall？**
   - 可以但效率低（O(N^3)），Dijkstra 更优。

4. **如何处理极大的 maxMoves？**
   - Dijkstra 不受 maxMoves 大小影响，只要正确比较 dist[u] 与 maxMoves 即可。

5. **这道题和普通的"图中可达节点"有什么区别？**
   - 区别在于"细分节点"的概念，它不是真实图节点，而是通过边权和剩余步数推断的虚拟节点。
