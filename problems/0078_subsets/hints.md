# 78. 子集 (Subsets)

## 核心思路

这道题的本质是：**对于数组中的每一个元素，你只有两种选择——选它或不选它**。所有元素的选择组合起来，就构成了所有可能的子集（即幂集）。n 个元素一共有 2^n 个子集。

## 思维链

1. **读完题第一反应**：要列举所有子集，这是一个"穷举"问题。对于 `[1,2,3]`，结果有 `[], [1], [2], [3], [1,2], [1,3], [2,3], [1,2,3]` 共 2³ = 8 个。每个元素要么在子集中，要么不在——这就是"选/不选"的二叉决策树！

2. **怎么系统地生成所有子集？** 想到两种视角：
   - **视角A（回溯）**：从左到右依次考虑每个元素，对每个元素做"选"或"不选"的决策，递归到底就得到一个子集。
   - **视角B（位运算）**：每个子集对应一个 n 位二进制数，第 i 位为 1 表示选 nums[i]，0 表示不选。从 `000...0` 到 `111...1` 枚举所有二进制数就能得到所有子集。

3. **还有没有其他角度？** 有！**迭代法**：从空集开始，每来一个新元素，在已有的所有子集基础上各加上这个新元素，就得到新的一批子集。比如已有 `[[], [1]]`，加入 2 后，把 2 追加到每个已有子集得 `[[2], [1,2]]`，和原来合并得 `[[], [1], [2], [1,2]]`。

4. **复杂度分析**：不管哪种方法，所有子集总共有 2^n 个，每个子集平均长度 n/2，所以输出本身的大小就是 O(n · 2^n)。这是无法优化的下界——我们只能保证不做多余的工作。

5. **面试中选哪个？** 回溯法最万能（子集/组合/排列都用这个框架），位运算法最简洁优雅，迭代法最直觉。三种都值得掌握，但回溯是面试首选。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 回溯（选/不选） | 对每个元素做选或不选的二叉递归 | O(n · 2^n) | O(n) 递归栈 | ⭐ 必须写出 |
| 回溯（逐个枚举） | 用 start 控制起点，每层选一个元素加入 | O(n · 2^n) | O(n) 递归栈 | ⭐ 必须写出 |
| 位运算枚举 | 用 0 到 2^n-1 的二进制表示选取方案 | O(n · 2^n) | O(1) 额外 | 加分项 |
| 迭代扩展 | 每个新元素追加到已有所有子集 | O(n · 2^n) | O(1) 额外 | 能说出即可 |

## 关键提示

1. **选/不选的思维模型**：把每个元素想象成一个开关（ON/OFF），n 个开关的所有组合就是幂集。你能画出这棵决策树吗？

2. **回溯 vs 组合/排列的区别**：子集问题在决策树的**每个节点**都是一个合法答案（包括中间节点），而组合问题只在叶子节点收集答案。

3. **用 `start` 避免重复**：如果你用"逐个枚举"的回溯方式，`start` 参数保证只往后选，不会选到前面已经跳过的元素，所以不会产生重复子集。

4. **位运算的对应关系**：对于 `nums = [1,2,3]`，二进制 `101` 对应选 nums[0] 和 nums[2]，即子集 `{1, 3}`。

5. **ASCII 决策树**（选/不选视角）：
```
                        []
                   /          \
              选1 /            \ 不选1
              [1]              []
            /     \          /     \
       选2 /       \不选2  选2/       \不选2
        [1,2]     [1]      [2]       []
        / \       / \      / \       / \
      选3 不选3 选3 不选3 选3 不选3 选3 不选3
  [1,2,3][1,2][1,3][1] [2,3] [2] [3]  []
```
叶子节点就是所有 2³ = 8 个子集。

## 解法详解

### 解法1: 回溯 —— 选/不选（二叉决策树）— O(n · 2^n) / O(n)

**思考过程**：最自然的思维——站在每个元素面前，只有"选"和"不选"两条路。递归到末尾（所有元素都决策完了）就得到一个完整子集。

```cpp
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        vector<vector<int>> result;
        vector<int> path;   // 当前已选择的元素
        dfs(nums, 0, path, result);
        return result;
    }
    
    void dfs(vector<int>& nums, int i, vector<int>& path, 
             vector<vector<int>>& result) {
        // 递归终止：所有元素都做过决策了
        if (i == nums.size()) {
            result.push_back(path);  // 收集这个子集
            return;
        }
        
        // 选择1：选 nums[i]
        path.push_back(nums[i]);
        dfs(nums, i + 1, path, result);
        path.pop_back();  // 撤销选择（回溯）
        
        // 选择2：不选 nums[i]
        dfs(nums, i + 1, path, result);
    }
};
```

**关键点**：
- 只在叶子节点（`i == nums.size()`）收集结果，因为只有所有元素都决策完才是一个完整子集。
- `push_back` 和 `pop_back` 配对出现，这就是回溯的核心。

---

### 解法2: 回溯 —— 逐个枚举（用 start 控制）— O(n · 2^n) / O(n) ⭐ 面试首选

**思考过程**：另一种视角——不是对每个元素做"选/不选"，而是"当前位置可以放哪个元素？"。用 `start` 保证只往后选，避免重复。**每个递归节点都是一个合法子集**。

```
// 决策树（逐个枚举视角，nums=[1,2,3]）:
//                    []
//               /     |     \
//             [1]    [2]    [3]
//            / \      |
//        [1,2] [1,3] [2,3]
//          |
//       [1,2,3]
// 
// 每个节点（包括根节点 []）都是一个合法子集！
```

```cpp
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        vector<vector<int>> result;
        vector<int> path;
        backtrack(nums, 0, path, result);
        return result;
    }
    
    void backtrack(vector<int>& nums, int start, vector<int>& path,
                   vector<vector<int>>& result) {
        // 每到一个节点就收集当前路径（不需要等到叶子）
        result.push_back(path);
        
        // 从 start 开始枚举，保证不回头选
        for (int i = start; i < nums.size(); i++) {
            path.push_back(nums[i]);       // 做选择
            backtrack(nums, i + 1, path, result);  // 注意是 i+1 不是 start+1
            path.pop_back();               // 撤销选择
        }
    }
};
```

**关键点**：
- 与解法1的区别：解法1只在叶子收集，解法2在每个节点收集。
- `i + 1` 而不是 `start + 1`：下一层从当前选择的下一个位置开始，不是从 start 的下一个。
- 这个模板是"子集/组合"类问题的万能框架，掌握它后做 77(组合)、90(子集II) 几乎只需微调。

### 解法3: 位运算枚举 — O(n · 2^n) / O(1) 额外空间

**思考过程**：每个元素选或不选 → 1 或 0 → n 个元素对应 n 位二进制数。从 `0` 到 `2^n - 1` 遍历所有整数，每个整数解码成一个子集。

```
// nums = [1, 2, 3]，n=3，枚举 0~7:
//
// mask  二进制  选取情况       子集
//  0    000    不选 不选 不选  []
//  1    001    不选 不选 选    [3]
//  2    010    不选 选   不选  [2]
//  3    011    不选 选   选    [2,3]
//  4    100    选   不选 不选  [1]
//  5    101    选   不选 选    [1,3]
//  6    110    选   选   不选  [1,2]
//  7    111    选   选   选    [1,2,3]
```

```cpp
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        int n = nums.size();
        int total = 1 << n;  // 2^n
        vector<vector<int>> result;
        
        for (int mask = 0; mask < total; mask++) {
            vector<int> subset;
            for (int i = 0; i < n; i++) {
                // 检查 mask 的第 i 位是否为 1
                if (mask & (1 << i)) {
                    subset.push_back(nums[i]);
                }
            }
            result.push_back(subset);
        }
        return result;
    }
};
```

**关键点**：
- `1 << n` 就是 2^n。当 n=10 时，`1 << 10 = 1024`，完全可行。
- `mask & (1 << i)` 检查第 i 位是否为 1，这是位运算的基本操作。
- 这种方法代码最短，但不如回溯法灵活——如果题目加约束（如子集大小限制、元素有重复），位运算法改起来不方便。

### 解法4: 迭代扩展法 — O(n · 2^n) / O(1) 额外空间

**思考过程**：从数学归纳的角度——如果已经有了前 k 个元素的所有子集，加入第 k+1 个元素后，新增的子集就是"把第 k+1 个元素追加到每个已有子集后面"。

```
// nums = [1, 2, 3]
//
// 初始:    [[]]
// 加入1:   [[], [1]]              ← [] 各加1 → [[1]]，合并
// 加入2:   [[], [1], [2], [1,2]]  ← 前面每个加2 → [[2],[1,2]]，合并
// 加入3:   [[], [1], [2], [1,2], [3], [1,3], [2,3], [1,2,3]]
```

```cpp
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        vector<vector<int>> result = {{}};  // 从空集开始
        
        for (int num : nums) {
            int size = result.size();  // 必须先记住当前大小！
            for (int i = 0; i < size; i++) {
                // 复制已有子集，追加当前元素
                vector<int> newSubset = result[i];
                newSubset.push_back(num);
                result.push_back(newSubset);
            }
        }
        return result;
    }
};
```

**关键点**：
- `int size = result.size()` 必须在内层循环前保存！否则 result 在内层循环中不断增长，会死循环。
- 这种方法不需要递归，思路非常直觉，适合不熟悉回溯的初学者。

## 解法对比

| | 回溯（选/不选） | 回溯（枚举 start） | 位运算 | 迭代扩展 |
|---|---|---|---|---|
| **思维模型** | 二叉决策树 | N叉决策树 | 二进制编码 | 数学归纳 |
| **模板复用** | 有限 | ⭐ 子集/组合/排列通用 | 仅限子集 | 仅限子集 |
| **扩展性** | 中 | 高（加剪枝/去重很方便） | 低 | 低 |
| **代码简洁度** | 中 | 中 | 最简洁 | 简洁 |
| **面试推荐** | 可以 | ⭐ 首选 | 加分项 | 能说出即可 |

**什么时候选哪个：**
- **面试**：首选解法2（回溯+start），因为同一个框架可以直接搞定组合、排列等题。
- **追求简洁**：用位运算法，一个双重循环搞定。
- **不熟悉递归**：用迭代扩展法，逻辑最直觉。

## 易错点

1. **回溯忘记 `pop_back`**
   - ✗ `path.push_back(nums[i]); backtrack(...);`（漏了撤销）
   - ✓ `path.push_back(nums[i]); backtrack(...); path.pop_back();`
   - 不撤销选择的话，后续分支会带着前面的选择，导致结果全错。

2. **逐个枚举法中 `i + 1` 写成 `start + 1`**
   - ✗ `backtrack(nums, start + 1, path, result);`
   - ✓ `backtrack(nums, i + 1, path, result);`
   - `start + 1` 意味着不管选了谁，下一层都从同一个位置开始，会产生重复。

3. **迭代法内层循环边界没提前保存**
   - ✗ `for (int i = 0; i < result.size(); i++)` — result.size() 在循环中增长，死循环！
   - ✓ `int size = result.size(); for (int i = 0; i < size; i++)`

4. **位运算法 n 过大导致溢出**
   - 本题 n ≤ 10 所以没问题，但如果 n > 30，`1 << n` 会溢出 int。
   - 安全写法：`1LL << n` 用 long long。

## 面试追问

**Q1: 你能写出暴力解吗？时间复杂度是多少？**
→ 回溯或位运算都行。时间 O(n · 2^n)，因为一共 2^n 个子集，每个子集平均长度 n/2，拷贝到结果中需要 O(n)。这个复杂度已经是下界——你至少要"看一眼"每个子集。

**Q2: 如果数组中有重复元素呢？（即 LeetCode 90. 子集 II）**
→ 先排序，然后在回溯的 for 循环中加一行去重：
```cpp
if (i > start && nums[i] == nums[i-1]) continue;
```
排序让相同元素相邻，`i > start` 保证同一层不选重复元素（但不同层可以选）。

**Q3: 你能用位运算处理有重复元素的情况吗？**
→ 可以但不优雅。需要先排序，然后对于生成的每个子集去重或用 set 过滤。不如回溯法直接在生成过程中剪枝高效。

**Q4: 如果要求子集按字典序输出呢？**
→ 先对 nums 排序，回溯法自然就按字典序生成了（因为 for 循环从小到大枚举）。

## 相关题型

- **90. 子集 II** — 元素有重复，复用解法2的框架，只需加一行 `if (i > start && nums[i] == nums[i-1]) continue;` 去重。
- **77. 组合** — 复用解法2的框架，区别：不在每个节点收集，只在 `path.size() == k` 时收集。代码改动：把 `result.push_back(path)` 移到 `if (path.size() == k)` 的条件里。
- **46. 全排列** — 复用回溯框架，区别：不用 `start` 控制起点（因为排列可以回头选），改用 `used[]` 数组标记已选元素。
- **39. 组合总和** — 复用解法2的框架，区别：递归时传 `i` 而不是 `i+1`（因为元素可以重复使用），加上和的约束剪枝。
