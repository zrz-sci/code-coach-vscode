# 459. 重复的子字符串

## 核心思路

本质上在问：字符串 `s` 是否可以由某个长度为 `len` 的前缀重复 `k` 次（k ≥ 2）拼接而成。关键约束是 `len` 必须是 `n` 的因子。

## 思维链

1. **读完题第一反应**：枚举所有可能的子串长度 `len`，检查 `s` 是否由该子串重复构成。子串长度范围是 `[1, n/2]`，因为至少重复 2 次。
2. **暴力解的瓶颈**：对每个候选长度 `len`，需要 O(n) 验证，而候选长度最多 n/2 个，最坏 O(n²)。但注意只有 `n % len == 0` 的长度才可能，实际候选数远小于 n/2（是 n 的因子个数，约 O(√n) 级别），所以暴力其实够用。
3. **有没有更巧妙的方法？** 观察一个数学性质：如果 `s` 是由子串重复构成的，那么把两个 `s` 拼起来得到 `s+s`，去掉首尾各一个字符后，原串 `s` 一定还能在中间找到。这就是"拼接法"。
4. **还有什么方法？** KMP 算法的 `next` 数组（又称 failure function）能告诉我们字符串的最长公共前后缀长度。如果字符串有重复子串结构，`next[n-1]` 会揭示这个周期。具体来说：周期长度 = `n - next[n-1]`，如果 `n` 能被这个周期整除且周期不等于 `n`，就说明存在重复子串。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 枚举因子 | 枚举子串长度，逐字符验证 | O(n√n) | O(1) | ⭐ 必须写出 |
| 拼接法 | `(s+s)` 去首尾后找 `s` | O(n) | O(n) | ⭐ 必须写出 |
| KMP / next数组 | 利用最长公共前后缀判断周期 | O(n) | O(n) | 加分项 |

## 关键提示

1. **子串长度的约束**：如果 `s` 由长度为 `len` 的子串重复 `k` 次构成，那么 `n = len × k`，所以 `len` 必须是 `n` 的因子，且 `len ≤ n/2`。
2. **拼接法的直觉**：`s = "abab"`，拼接得 `"abababab"`，去首尾得 `"bababa"`。如果原串有重复结构，去掉首尾各一个字符只是"错开"了一点，内部的重复模式还在，所以还能找到完整的 `s`。
3. **KMP 的核心洞察**：KMP 的 `next` 数组记录"最长相等前后缀"。对于 `"abcabc"`，`next = [-1, -1, -1, 0, 1, 2]`（0-indexed），`next[5] = 2` 表示前缀 `"abc"` 和后缀 `"abc"` 匹配了 3 个字符。周期 = `6 - 3 = 3`，`6 % 3 == 0`，说明 `"abc"` 重复了 2 次。
4. **为什么只检查因子就够了**：假设有长度 `len` 不整除 `n`，那么最后一段子串是"不完整的"，不可能拼出完整的 `s`。

```
// 拼接法可视化:
// s = "abab"
// s+s = "abab|abab"
//        ↓去首尾↓
//        "bab aba b"  →  "babab" 中包含 "abab"? → 是
//                         去掉第一个和最后一个字符后:
//  s+s = "a b a b a b a b"
//  去首尾: "b a b a b a b"
//  在其中找 "abab":
//         "b [a b a b] a b"  ← 找到了! → true

// s = "aba"
// s+s = "abaaba"
// 去首尾: "baab"
// 在其中找 "aba": 找不到 → false
```

## 解法详解

### 解法1: 枚举因子长度 — O(n√n) / O(1) ⭐ 面试首选

**思考过程**：最直接的想法——子串重复 k 次构成 s，那子串长度 `len` 一定整除 `n`。枚举所有整除 `n` 的 `len`（从 1 到 n/2），取出前 `len` 个字符作为候选子串，逐字符检查 `s[i]` 是否等于 `s[i % len]`。

```cpp
class Solution {
public:
    bool repeatedSubstringPattern(string s) {
        int n = s.size();
        // 枚举子串长度 len，必须是 n 的因子且 len <= n/2
        for (int len = 1; len <= n / 2; len++) {
            if (n % len != 0) continue; // 不是因子，跳过
            
            bool match = true;
            // 检查每个位置是否等于 "对应周期内的位置"
            for (int i = len; i < n; i++) {
                if (s[i] != s[i % len]) {
                    match = false;
                    break;
                }
            }
            if (match) return true;
        }
        return false;
    }
};
```

**关键点**：
- `i` 从 `len` 开始而不是 0，因为前 `len` 个字符就是候选子串本身，不需要比较。
- `i % len` 巧妙地实现了"循环比较"，不需要真的截取子串。

### 解法2: 拼接法 — O(n) / O(n) ⭐ 面试首选

**从解法1优化**：解法1需要枚举所有因子长度，能否一步判断？

**数学直觉**：如果 `s` 有重复结构，把两个 `s` 拼起来形成 `t = s + s`。在 `t` 中，除了位置 0 和位置 n 处的 `s` 以外，中间还会出现完整的 `s`。去掉 `t` 的首尾各一个字符（破坏位置 0 和位置 n 处的匹配），如果仍能找到 `s`，说明中间确实存在由重复结构产生的匹配。

**为什么正确？**
- 如果 `s = "abcabc"`（由 "abc" 重复 2 次），那么 `t = "abcabcabcabc"`，去首尾得 `"bcabcabcabc"`，在其中能找到 `"abcabc"`。
- 如果 `s = "abc"`（无重复），`t = "abcabc"`，去首尾得 `"bcab"`，长度才 4，找不到长度 3 的 `"abc"`... 等等，`"bcab"` 中确实没有 `"abc"`。

```cpp
class Solution {
public:
    bool repeatedSubstringPattern(string s) {
        string t = s + s;
        // 去掉首尾各一个字符，在剩余部分中查找 s
        // 等价于：在 t[1..2n-2] 中找 s
        // 用 find 从位置 1 开始搜索，如果找到的位置 < n，说明存在
        return t.find(s, 1) != s.size();
    }
};
```

**关键点**：
- `t.find(s, 1)` 从索引 1 开始搜索，跳过了 `t[0]` 开始的那个 `s`。
- 找到的位置如果 `< n`，说明不是从 `t[n]` 开始的那个（也就是第二个完整 `s`），而是"中间"冒出来的 → 有重复结构。
- `find` 返回 `string::npos` 如果没找到，这里判断 `!= s.size()` 是因为如果有重复结构，找到的位置一定 `< n = s.size()`，而原始的第二个 s 起始于位置 n。

### 解法3: KMP next 数组 — O(n) / O(n) — 加分项

**思路**：KMP 算法中的 `next` 数组（前缀函数 / failure function）记录了字符串每个位置的"最长相等前后缀长度"。

如果字符串 `s` 由子串 `p` 重复 `k` 次构成，那么 `s` 有一个长度为 `n - len(p)` 的相等前后缀。换句话说，`next[n-1] = n - period`，其中 `period = len(p)`。

判断条件：`next[n-1] > 0` 且 `n % (n - next[n-1]) == 0`。

```
// KMP next 数组可视化 (s = "abcabcabc"):
//
// 下标:   0  1  2  3  4  5  6  7  8
// 字符:   a  b  c  a  b  c  a  b  c
// next:   0  0  0  1  2  3  4  5  6
//                                 ↑
// next[8] = 6，表示前缀 "abcabc" == 后缀 "abcabc"（长度6）
// 周期 period = n - next[n-1] = 9 - 6 = 3
// 9 % 3 == 0 → true，"abc" 重复 3 次
//
// 再看 s = "aba":
// 下标:   0  1  2
// 字符:   a  b  a
// next:   0  0  1
// next[2] = 1，period = 3 - 1 = 2
// 3 % 2 == 1 ≠ 0 → false
```

```cpp
class Solution {
public:
    bool repeatedSubstringPattern(string s) {
        int n = s.size();
        // 构建 KMP 的 next 数组 (前缀函数)
        // next[i] = s[0..i] 的最长相等真前缀和真后缀的长度
        vector<int> next(n, 0);
        for (int i = 1; i < n; i++) {
            int j = next[i - 1];
            // 不匹配时，回退到更短的前缀
            while (j > 0 && s[i] != s[j]) {
                j = next[j - 1];
            }
            if (s[i] == s[j]) {
                j++;
            }
            next[i] = j;
        }
        
        // next[n-1] 是整个字符串的最长相等前后缀长度
        int longestPrefixSuffix = next[n - 1];
        int period = n - longestPrefixSuffix;
        
        // 周期必须 < n（至少重复2次）且能整除 n
        return longestPrefixSuffix > 0 && n % period == 0;
    }
};
```

**关键点**：
- `next[n-1] > 0` 确保存在非空的相等前后缀（否则没有重复结构）。
- `n % period == 0` 确保周期能整除字符串长度（否则最后一个"周期"是不完整的）。
- 这两个条件缺一不可。

## 易错点

1. **枚举法中子串长度范围写错**
   - ✗ `for (int len = 1; len < n; len++)` — 会检查 `len = n` 即"整个字符串"，这不算"重复"
   - ✓ `for (int len = 1; len <= n / 2; len++)` — 至少重复 2 次，所以 `len ≤ n/2`

2. **枚举法中忘记检查因子**
   - ✗ 不加 `if (n % len != 0) continue;` — 功能上仍然正确，但会浪费大量时间检查不可能的长度
   - ✓ 加上因子检查，大幅剪枝

3. **拼接法 find 的起始位置**
   - ✗ `t.find(s)` — 会在位置 0 找到 `s`，永远返回 true
   - ✓ `t.find(s, 1)` — 跳过位置 0，从位置 1 开始搜索

4. **拼接法判断条件写错**
   - ✗ `t.find(s, 1) != string::npos` — 这也能 work，但更精确的理解是找到的位置必须 `< n`
   - ✓ `t.find(s, 1) != s.size()` 或 `t.find(s, 1) < s.size()` — 更清晰表达意图

5. **KMP 中 next 数组的最后判断**
   - ✗ 只检查 `n % period == 0` 而不检查 `longestPrefixSuffix > 0` — 当 `next[n-1] = 0` 时 `period = n`，`n % n == 0` 为 true，会错误返回 true
   - ✓ 必须同时检查 `longestPrefixSuffix > 0 && n % period == 0`

## 面试追问

**Q1: 为什么子串长度只需要枚举 n 的因子？**
→ 如果 `s` 由子串 `p` 重复 `k` 次构成，则 `n = len(p) × k`，所以 `len(p)` 必须整除 `n`。非因子长度不可能构成完整重复。

**Q2: 拼接法为什么是正确的？能否给出严格证明？**
→ 充分性：若 `s = p^k`（p 重复 k 次），则 `s+s = p^{2k}`，去首尾后仍有 `2k-2 ≥ k` 个完整周期的"碎片"拼在一起，其中必然包含 k 个连续的 p。必要性：若 `s+s` 去首尾后包含 `s`，设找到位置为 `i`（`0 < i < n`），则对所有 `j`，`s[j] = (s+s)[(i+j) mod 2n]`。由 `(s+s)` 的构造，这意味着 `s[j] = s[(i+j) mod n]`，即 `s` 有周期 `i`，且 `i | n`（否则不可能在位置 `i` 完整匹配长度为 `n` 的 `s`）。

**Q3: 如果不让用库函数的 find（面试官要求手写字符串匹配），怎么办？**
→ 可以手写 KMP 匹配，或者用 Rabin-Karp 哈希匹配。这就自然过渡到解法3。也可以直接用 KMP 的 next 数组性质，不需要做字符串匹配。

**Q4: KMP 方法能否推广到"找字符串的最短重复单元"？**
→ 可以。最短重复单元长度就是 `n - next[n-1]`。如果这个值整除 `n`，则该长度就是最短重复单元；否则最短重复单元就是整个字符串本身。
