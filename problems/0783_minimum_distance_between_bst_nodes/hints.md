# 783. Minimum Distance Between BST Nodes

## 核心思路

利用 BST 的中序遍历有序性。BST 的中序遍历会产生一个严格递增的序列，因此任意两节点的最小差值一定出现在中序遍历的**相邻元素**之间。只需在中序遍历过程中维护前驱节点，逐步计算相邻差值并取最小值即可。

## 思维链

1. **BST 性质回顾**：BST 的中序遍历产生有序序列。
2. **最小差值在哪里**：有序序列的最小差值一定出现在相邻元素之间（非相邻元素差值 >= 相邻元素差值）。
3. **无需额外数组**：在遍历过程中用一个变量记录前驱节点值即可。
4. **遍历方式选择**：递归中序遍历最直观；Morris 遍历可以做到 O(1) 空间。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 递归中序遍历 | O(n) | O(h) | 最直观，利用前驱节点 |
| 迭代中序遍历 | O(n) | O(h) | 用显式栈 |
| Morris 中序遍历 | O(n) | O(1) | 空间最优 |
| 中序遍历 + 数组 | O(n) | O(n) | 最简单但空间开销大 |

## 关键提示

1. BST 中序遍历 = 升序排列，最小差值一定在相邻元素之间。
2. 用一个全局/引用变量 prev 记录中序遍历的前一个节点值。
3. 初始 prev 可以设为 -1 或 INT_MIN/INT_MAX 来标识"尚无前驱"。
4. 每次访问当前节点时，计算 `current.val - prev` 并更新最小值。
5. 本题与 LeetCode 530 完全相同。
6. 树的节点数至少为 2，无需处理空树或单节点。
7. Morris 遍历通过修改指针实现 O(1) 空间，面试中是加分项。

## 解法详解

### 解法一：递归中序遍历（推荐）

**思路**：
- 对 BST 进行中序遍历（左 -> 根 -> 右），得到的值是递增的。
- 维护一个变量 `prev` 记录上一个访问的节点值。
- 每次访问节点时，若 prev 有效，则计算 `node->val - prev` 并与当前最小值比较。
- 更新 prev = node->val 后继续遍历。

**复杂度**：时间 O(n)，空间 O(h)，h 为树高（递归栈）。

### 解法二：迭代中序遍历

**思路**：
- 使用显式栈模拟递归过程。
- 先把所有左子节点压栈，然后弹出处理，再转向右子树。
- 处理逻辑与递归版完全一致。

**复杂度**：时间 O(n)，空间 O(h)。

### 解法三：Morris 中序遍历

**思路**：
- 利用线索二叉树的思想，不使用栈和递归。
- 找到当前节点的中序前驱（左子树的最右节点），将其右指针指向当前节点作为线索。
- 通过这种方式，遍历完左子树后可以回到当前节点。
- 遍历完成后恢复树结构。

**复杂度**：时间 O(n)，空间 O(1)。

## 易错点

1. **prev 的初始化**：如果用 int 类型且初始化为 0，当节点值包含 0 时会导致错误。应该用 -1 配合标志位，或使用指针/可选类型（如 TreeNode* prev = nullptr）。
2. **忘记 BST 性质**：直接用任意两节点比较会导致 O(n^2) 复杂度。BST 保证中序有序是本题的关键。
3. **递归中全局变量的使用**：如果把 prev 和 result 定义在函数内部而不是类成员或引用传递，每次递归调用会创建新的副本，导致结果不正确。
4. **混淆最小差值和最小绝对差值**：BST 中序是升序，所以 `current - prev` 一定非负，不需要取绝对值。
5. **认为答案可能出现在非相邻节点**：在有序序列中，|a[i] - a[j]| (j > i+1) >= |a[i+1] - a[i]|，所以只需比较相邻对。

## 面试追问

1. **Q: 如果题目改为"任意二叉树"而不是 BST，怎么做？**
   A: 需要先收集所有节点值到数组中，排序后比较相邻元素。时间复杂度变为 O(n log n)。或者使用 set 等有序结构维护，同样 O(n log n)。

2. **Q: Morris 遍历会修改树结构吗？是否线程安全？**
   A: Morris 遍历会临时修改树结构（建立线索），遍历完成后会恢复。但在多线程环境下不安全，不能并发访问同一棵树。

3. **Q: 如果 BST 非常大，内存有限，你会选择哪种方法？**
   A: Morris 遍历，因为它只需要 O(1) 额外空间。递归和迭代都需要 O(h) 的栈空间，对于极端偏斜的树可能需要 O(n)。

4. **Q: 能否在构建 BST 的过程中就维护最小差值？**
   A: 可以。每次插入时，与前驱和后继比较。但维护前驱后继需要平衡 BST（如 AVL/红黑树）或额外数据结构。

5. **Q: 这道题和 LeetCode 530 有什么关系？**
   A: 完全一样的题目。LeetCode 530 题目描述为 "Minimum Absolute Difference in BST"，两题的输入输出和约束完全相同。
