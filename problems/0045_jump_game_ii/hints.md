# 45. 跳跃游戏 II

## 核心思路

本质上这是一个**BFS 最短路径问题**：从位置 0 出发，每个位置可以跳到若干后续位置，问到达终点的最少跳跃次数。贪心解法将其转化为"每一跳能覆盖的最远范围"问题，像 BFS 一样逐层扩展。

## 思维链

1. **读完题第一反应**：每个位置有多种跳法，要找最少跳跃次数 → 最短路径 → 可以用 BFS 或 DP。
2. **暴力 DP 怎么做？** `dp[i]` = 到达位置 i 的最少跳跃次数。对每个位置 j < i，如果 j 能跳到 i（即 `j + nums[j] >= i`），则 `dp[i] = min(dp[i], dp[j] + 1)`。时间 O(n²)。
3. **瓶颈在哪？** 对每个位置 i，我们遍历所有前面的位置 j 来找谁能到达 i，这个"回头看"的过程很浪费。
4. **换个思路 — 向前看**：不要问"谁能到达 i"，而是问"当前这一跳最远能到哪"。这就像 BFS 的层序扩展：第 1 跳能覆盖的范围是一个区间，第 2 跳能覆盖的范围是下一个区间…
5. **贪心核心**：维护当前跳跃能到达的边界 `curEnd`，遍历过程中不断更新"下一跳最远能到" `farthest`。当走到 `curEnd` 时，必须再跳一次，将边界更新为 `farthest`。
6. **为什么贪心正确？** 每一跳都尽可能扩展覆盖范围，这样用最少的跳次覆盖到终点。这本质就是 BFS 的隐式层序遍历。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| DP（暴力） | dp[i] = 到达 i 的最少跳次 | O(n²) | O(n) | 能说出即可 |
| BFS（显式层） | 每一跳看作一层，层序扩展 | O(n) | O(1) | ⭐ 必须写出 |
| 贪心（隐式 BFS） | 维护当前边界和最远可达 | O(n) | O(1) | ⭐ 必须写出 |

> 解法 2 和解法 3 本质相同，只是思考角度不同。面试时用任一种解释都可以。

## 关键提示

1. **把数组想象成 BFS 的图**：位置 0 是起点，从位置 i 可以跳到 `[i+1, i+nums[i]]` 的所有位置。BFS 天然找最短路径。
2. **不需要真的用队列**：因为 BFS 每一层覆盖的是一段连续区间，用两个变量 `curEnd` 和 `farthest` 就够了。
3. **遍历只需到 `n-2`**：如果遍历到 `n-1`，当 `curEnd` 恰好等于 `n-1` 时会多跳一次。

```
示例 nums = [2, 3, 1, 1, 4]

位置:     0   1   2   3   4
值:       2   3   1   1   4

第0跳: 站在位置0，能跳到 [1,2]
       ├── curEnd = 0 → 更新 farthest = max(0+2) = 2
       └── 到达 curEnd=0 → jumps=1, curEnd=2

第1跳: 覆盖范围 [1,2]
       ├── 位置1: farthest = max(2, 1+3) = 4
       ├── 位置2: farthest = max(4, 2+1) = 4
       └── 到达 curEnd=2 → jumps=2, curEnd=4

curEnd=4 >= n-1=4 → 到达终点！答案 = 2
```

4. **和 LeetCode 55（跳跃游戏 I）的关系**：55 题只需判断能否到达终点（维护 `farthest` 即可），本题需要计数最少跳次（多维护一个 `curEnd` 来标记每一跳的边界）。

5. **DP 解法中填表方向是从左到右**，`dp[i]` 依赖所有 `dp[j]`（j < i 且 j 能跳到 i）。

## 解法详解

### 解法1: 动态规划 — O(n²) / O(n)

**思考过程**：最自然的想法 — 定义 `dp[i]` 为从起点到位置 i 的最少跳跃次数。对每个位置，看前面所有能跳到它的位置中，谁的跳次最小。

```cpp
class Solution {
public:
    int jump(vector<int>& nums) {
        int n = nums.size();
        // dp[i]: 从位置0到位置i的最少跳跃次数
        vector<int> dp(n, INT_MAX);
        dp[0] = 0;  // 起点不需要跳
        
        for (int i = 1; i < n; i++) {
            for (int j = 0; j < i; j++) {
                // j 能跳到 i 且 j 本身可达
                if (j + nums[j] >= i && dp[j] != INT_MAX) {
                    dp[i] = min(dp[i], dp[j] + 1);
                }
            }
        }
        return dp[n - 1];
    }
};
```

**关键点**：
- 内循环其实可以提前 break：因为 `dp` 数组是非递减的，第一个能跳到 i 的位置 j 就给出了最小值。但最坏情况仍是 O(n²)。
- 这个解法对 n = 10⁴ 可能超时（约 10⁸ 操作量边界）。

```
// DP 填表过程 (nums = [2,3,1,1,4]):
//
// 位置:  0  1  2  3  4
// dp:   [0, ∞, ∞, ∞, ∞]  初始
//       [0, 1, ∞, ∞, ∞]  i=1: j=0可达(0+2>=1), dp[1]=dp[0]+1=1
//       [0, 1, 1, ∞, ∞]  i=2: j=0可达(0+2>=2), dp[2]=dp[0]+1=1
//       [0, 1, 1, 2, ∞]  i=3: j=0不可达(0+2<3), j=1可达(1+3>=3), dp[3]=dp[1]+1=2
//       [0, 1, 1, 2, 2]  i=4: j=1可达(1+3>=4), dp[4]=dp[1]+1=2
```

---

### 解法2: 贪心（隐式 BFS）— O(n) / O(1) ⭐ 面试首选

**从解法1优化**：解法1对每个位置都回头看谁能到达它，时间 O(n²)。换个角度 — 把问题看成 BFS 层序遍历：

- **第 k 跳能覆盖的位置**构成 BFS 的第 k 层
- 从第 k 层的所有位置出发，能到达的最远位置决定了第 k+1 层的范围
- 用 `curEnd` 标记当前层的右边界，`farthest` 记录下一层能到的最远处

**为什么这就是贪心？** 每一跳都选"让下一跳覆盖范围最大"的策略，保证用最少跳次覆盖到终点。

```cpp
class Solution {
public:
    int jump(vector<int>& nums) {
        int n = nums.size();
        int jumps = 0;      // 跳跃次数
        int curEnd = 0;     // 当前这一跳能到的最远边界
        int farthest = 0;   // 遍历过程中记录的下一跳最远可达
        
        // 只遍历到 n-2：如果 curEnd 恰好在 n-1，不需要额外跳
        for (int i = 0; i < n - 1; i++) {
            farthest = max(farthest, i + nums[i]);
            
            // 走到了当前跳跃的边界，必须再跳一次
            if (i == curEnd) {
                jumps++;
                curEnd = farthest;
                
                // 优化：如果已经能到终点，提前退出
                if (curEnd >= n - 1) break;
            }
        }
        return jumps;
    }
};
```

**逐步执行过程**：
```
nums = [2, 3, 1, 1, 4]，n = 5

i=0: farthest = max(0, 0+2) = 2
     i==curEnd(0) → jumps=1, curEnd=2
     
i=1: farthest = max(2, 1+3) = 4
     i!=curEnd(2) → 继续

i=2: farthest = max(4, 2+1) = 4
     i==curEnd(2) → jumps=2, curEnd=4
     curEnd=4 >= n-1=4 → break!

返回 jumps = 2
```

**关键点**：
- `for` 循环只到 `n-2`，这不是随意的——如果遍历到 `n-1`，当最后一个位置恰好是边界时，会多计一次跳跃。
- 这本质上是**不用队列的 BFS**：`curEnd` 标记了"当前层结束"，遍历到它就意味着进入下一层。

---

### 解法3: 显式 BFS 思考 — O(n) / O(1)

**换一种写法更直观地体现 BFS 逻辑**：用 `curStart` 和 `curEnd` 显式维护当前层的左右边界。

```cpp
class Solution {
public:
    int jump(vector<int>& nums) {
        int n = nums.size();
        if (n == 1) return 0;
        
        int jumps = 0;
        int curStart = 0, curEnd = 0;
        
        while (curEnd < n - 1) {
            int farthest = 0;
            // 遍历当前层 [curStart, curEnd] 的所有位置
            for (int i = curStart; i <= curEnd; i++) {
                farthest = max(farthest, i + nums[i]);
            }
            curStart = curEnd + 1;  // 下一层的起点
            curEnd = farthest;      // 下一层的终点
            jumps++;
        }
        return jumps;
    }
};
```

**和解法2的关系**：
- 解法2把两层循环合并成了一层（因为 BFS 每层的范围是连续的，正好对应数组的顺序遍历）
- 解法3更直观，但写法稍长；解法2更简洁，是面试中的首选写法

```
// BFS 层序扩展过程:
//
// nums = [2, 3, 1, 1, 4]
//         ↑
// 第0层: [0, 0]  → 扫描位置0 → farthest=2
// 第1层: [1, 2]  → 扫描位置1,2 → farthest=max(4,3)=4
// 第2层: [3, 4]  → 但 curEnd=4 >= n-1 → 结束!
//
// jumps = 2
```

## 解法对比

| | 解法1 (DP) | 解法2 (贪心) | 解法3 (显式BFS) |
|---|---|---|---|
| **时间** | O(n²) | O(n) | O(n) |
| **空间** | O(n) | O(1) | O(1) |
| **思维难度** | 低（标准DP） | 中（需要理解隐式BFS） | 中（BFS模型直观） |
| **面试推荐** | 作为起点展示 | ⭐ 首选 | 用来解释思路 |

解法2和解法3本质完全相同，只是代码组织不同。解法2更简洁（一个for循环），解法3的双层结构更清晰地体现BFS思想。面试时建议：**先用解法3的思路解释，然后写解法2的代码**。

## 易错点

1. **遍历范围写到 `n-1` 导致多跳一次**
   - ✗ `for (int i = 0; i < n; i++)` — 当 `i = n-1` 且恰好是边界时，jumps 多加了 1
   - ✓ `for (int i = 0; i < n - 1; i++)` — 到达 `n-1` 就是终点，不需要再跳

2. **忘记处理 `n == 1` 的特殊情况**（解法3中）
   - ✗ 直接进入 while 循环 → `curEnd=0 < n-1=0` 为 false，其实没问题…但如果 n=1，while 不进入，返回 0 是对的
   - 解法2天然处理：`n-1=0`，for 循环不执行，返回 jumps=0 ✓

3. **DP 解法中内循环遗漏可达性检查**
   - ✗ `dp[i] = min(dp[i], dp[j] + 1)` — 没检查 `dp[j] != INT_MAX`
   - ✓ 必须确保 `dp[j] != INT_MAX`（即 j 本身是可达的），否则 `INT_MAX + 1` 溢出

4. **`farthest` 初始化错误**
   - ✗ `farthest = nums[0]` — 如果后面的逻辑依赖 `farthest` 从 0 开始累加就会出错
   - ✓ `farthest = 0`，在循环中统一更新

## 面试追问

**Q1: 这道题和 LeetCode 55（跳跃游戏 I）有什么关系？代码怎么从55改到45？**

> 55题只需判断能否到达终点，只维护 `farthest`。45题需要计数最少跳次，多维护一个 `curEnd` 来标记"当前这一跳的边界在哪"。核心区别就是加了 `curEnd` 和 `jumps` 两个变量。

**Q2: 为什么贪心是正确的？能否严格证明？**

> 这本质是 BFS：每一跳相当于 BFS 的一层，BFS 天然保证最短路径。贪心选择"使下一跳覆盖范围最大"，等价于 BFS 逐层扩展——而 BFS 在无权图上一定找到最短路径。反证：如果存在更优解，那意味着某一跳没有用到最远可达范围，但那样后续层数只会更多不会更少，矛盾。

**Q3: 如果跳跃可以向前也可以向后（双向跳跃），怎么修改？**

> 不能再用贪心了，因为向后跳破坏了"覆盖范围是连续区间"的性质。需要用真正的 BFS + visited 数组：从位置 i 可以跳到 `[i-nums[i], i+nums[i]]` 的所有位置，标记已访问避免重复。时间 O(n·max(nums[i]))，空间 O(n)。

**Q4: 如果不保证一定能到达终点，怎么修改？**

> 在贪心解法中，如果 `farthest <= curEnd`（无法扩展），说明被卡住了，返回 -1。具体：在 `if (i == curEnd)` 块中，更新 `curEnd = farthest` 后检查 `curEnd <= i`（即没有进展），则返回 -1。
