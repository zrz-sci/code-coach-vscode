# 775. 全局倒置与局部倒置 (Global and Local Inversions)

**难度**: Medium | **标签**: Array, Math

## 核心思路

全局倒置(Global Inversion)是所有 i < j 且 nums[i] > nums[j] 的数对。局部倒置(Local Inversion)是所有 nums[i] > nums[i+1] 的相邻对。显然**每个局部倒置都是全局倒置**，因此 global >= local 恒成立。

题目问的是 global == local，等价于问：**是否不存在"非局部的全局倒置"**，即不存在 i+2 <= j 且 nums[i] > nums[j] 的情况。换言之，每个元素最多只能偏离其"正确位置"一格：`|nums[i] - i| <= 1`。

## 思维链

1. **关系分析**: local inversions 是 global inversions 的子集。所以 global >= local 总成立。
2. **等价转换**: global == local 等价于不存在"距离>=2的倒置"，即不存在 i, j 满足 j >= i+2 且 nums[i] > nums[j]。
3. **充要条件推导**: 对于 [0,n-1] 的排列，没有距离>=2的倒置，意味着每个数最多只比它的"标准位置"偏移1个位置：`|nums[i] - i| <= 1`。
4. **最优检查方法**: 只需检查每个 nums[i] 是否满足 `|nums[i] - i| <= 1`，或者等价地，检查是否存在 nums[i] > 前缀最大值 之类的条件。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|-----------|-----------|---------|
| 偏移量检查 | O(n) | O(1) | 最简洁，推荐 |
| 前缀最大值 | O(n) | O(1) | 等价做法，更直观 |
| 归并排序计数 | O(n log n) | O(n) | 通用但过度设计 |

## 关键提示

1. **核心等价条件**: `|nums[i] - i| <= 1` 对所有 i 成立，等价于 global == local。
2. **为什么偏移 <= 1**: 如果 nums[i] = i+2，说明至少有一个值在 [i+1, i+2-1] 区间被"挤"到了更后面的位置，必然产生距离>=2的倒置。
3. **前缀最大值法**: 从左到右维护 `nums[0..i-2]` 的最大值 maxSoFar。如果 `maxSoFar > nums[i]`（i >= 2），说明存在非局部全局倒置。
4. **不需要真正计数**: 不需要分别计算 global 和 local 的数量再比较。只需检查是否存在非局部倒置即可。

## 解法详解

### 解法一：偏移量检查 (最简洁)

**思路**: 对于 [0, n-1] 的排列，global == local 当且仅当每个元素最多偏离其标准位置1格。

**直觉**: 排列 nums 是 [0,1,2,...,n-1] 的重排。如果某个数 nums[i] 与 i 的差距超过1，那么必然有某个更远的元素被"推"到了更远的位置，造成非局部倒置。

**实现**: 遍历数组，检查 `abs(nums[i] - i) > 1`，若存在则返回 false。

**复杂度**:
- 时间: O(n)。一次遍历。
- 空间: O(1)。

### 解法二：前缀最大值

**思路**: 维护 `nums[0..i-2]` 中的最大值。如果这个最大值大于 nums[i]，说明存在一个距离 >= 2 的倒置对。

**详细步骤**:
1. 从 i=2 开始遍历（因为距离>=2才算非局部倒置）。
2. 维护 `nums[0..i-2]` 的最大值 prefixMax。
3. 如果 prefixMax > nums[i]，返回 false。
4. 遍历完成返回 true。

**为什么是 nums[0..i-2]**: 因为 nums[i-1] > nums[i] 只是局部倒置，不算非局部。我们需要检查的是 i-2 及之前的元素是否大于 nums[i]。

**复杂度**:
- 时间: O(n)。一次遍历。
- 空间: O(1)。

### 解法三：后缀最小值 (等价变体)

**思路**: 从右往左维护后缀最小值。如果 nums[i] > suffixMin[i+2]，存在非局部倒置。

**复杂度**:
- 时间: O(n)。
- 空间: O(1)（滚动变量）或 O(n)（数组存储）。

## 易错点

1. **搞混全局和局部的包含关系**: 局部倒置一定是全局倒置。所以 global >= local 总成立，我们只需要检查是否有"多出来的"全局倒置。
2. **偏移量检查只适用于排列**: 这个 `|nums[i]-i| <= 1` 的判断条件依赖于 nums 是 [0,n-1] 的排列这一前提。如果不是排列，不能用此方法。
3. **前缀最大值的范围**: 必须是 `nums[0..i-2]`，不是 `nums[0..i-1]`。因为 nums[i-1] 与 nums[i] 的倒置是局部的。
4. **i 的起始值**: 前缀最大值法从 i=2 开始，不是 i=0 或 i=1。
5. **单元素/两元素数组**: n=1 或 n=2 时一定满足条件，返回 true。

## 面试追问

1. **Q: 如何严格证明 |nums[i]-i|<=1 是充要条件？**
   A: 充分性：偏移<=1意味着只可能发生相邻交换，只产生局部倒置。必要性：若存在 nums[i]=i+d (d>=2)，则区间 [i+1, i+d-1] 中有d-1个数要占据 d-1 个位置但少了一个"自然位置"，必然有远距离倒置。可用鸽巢原理证明。

2. **Q: 如果要求计算 global inversions 的确切数量怎么办？**
   A: 用归并排序在合并过程中计数（经典的求逆序对问题），或用 BIT/树状数组，时间 O(n log n)。

3. **Q: 这道题的数学本质是什么？**
   A: 等价于判断排列是否可以只通过相邻交换（adjacent transpositions）从恒等排列得到。这样的排列称为"321-avoiding permutation"。

4. **Q: 如果数组不是排列（有重复元素），如何解决？**
   A: 偏移量法不适用。需要用前缀最大值法或归并排序计数法，这些方法不依赖排列性质。

5. **Q: 时间复杂度能否优于 O(n)？**
   A: 不能。必须至少检查每个元素一次，O(n) 是最优下界。
