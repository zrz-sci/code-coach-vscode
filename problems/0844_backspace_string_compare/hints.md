# 844. 比较含退格的字符串

## 核心思路

本质上就是**模拟文本编辑器的输入过程**：遇到普通字符就追加，遇到 `#` 就删除前一个字符，最后比较两个编辑器的最终结果是否相同。

## 思维链

1. **读完题第一反应**：直接模拟！遍历字符串，遇到普通字符就加入结果，遇到 `#` 就删掉最后一个字符，最后比较两个结果字符串。用什么数据结构来"加入末尾"和"删除末尾"最方便？→ 栈！（或者直接用 string 当栈）

2. **暴力解（栈模拟）分析**：时间 O(n+m)，空间 O(n+m)。已经很快了，但空间能不能更省？题目 Follow-up 要求 O(1) 空间。

3. **瓶颈在哪？** 栈模拟需要额外空间来存储处理后的字符串。如果不想存储最终结果，能不能**边比较边处理**？

4. **关键洞察**：`#` 影响的是它**前面**的字符。如果我们**从后往前**遍历，遇到 `#` 就知道要跳过接下来的若干个字符。这样不需要额外空间存储结果，用两个指针分别从两个字符串末尾往前走，逐字符比较。

5. **双指针怎么做？** 维护一个 `skip` 计数器，遇到 `#` 就 `skip++`，遇到普通字符时如果 `skip > 0` 就跳过并 `skip--`，否则这就是当前应该比较的字符。两个字符串各自找到下一个"有效字符"后进行比较。

6. **终止条件**：两个指针都走完了（都 < 0）则相等；一个走完一个没走完则不等；两个都有有效字符但字符不同则不等。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 栈模拟 | 用栈/string模拟退格过程，最后比较结果 | O(n+m) | O(n+m) | ⭐ 必须写出 |
| 双指针逆序 | 从后往前遍历，skip计数跳过被退格的字符 | O(n+m) | O(1) | 加分项（Follow-up） |

## 关键提示

1. **栈的"后进先出"天然对应退格操作**：退格删除的是最后输入的字符，正好是栈顶元素。
2. **为什么从后往前？** 因为 `#` 影响的是它前面（左边）的字符。从右往左扫描时，遇到 `#` 可以立刻知道要跳过多少个字符，不需要"回头"修改。
3. **skip 计数器可以累积**：`"ab##"` 中连续两个 `#` 意味着跳过前面两个字符，skip 会累加到 2。
4. **双指针比较时的终止判断**：不要忘记处理"一个字符串还有有效字符，另一个已经没有了"的情况。
5. **对空文本退格，文本仍为空**：用栈时，`#` 对空栈不操作；用双指针时，skip 不会变成负数但可能指针已经越界。

```
模拟过程 s = "ab#c":

栈模拟（从左到右）:
  'a' → 栈: [a]
  'b' → 栈: [a, b]
  '#' → 弹出 → 栈: [a]
  'c' → 栈: [a, c]
  结果: "ac"

双指针（从右到左）:
  i=3: 'c', skip=0 → 有效字符 'c'
  i=2: '#', skip=1
  i=1: 'b', skip=1 → 跳过, skip=0
  i=0: 'a', skip=0 → 有效字符 'a'
  有效序列(逆序): c, a
```

## 解法详解

### 解法1: 栈模拟 — O(n+m) / O(n+m) ⭐ 面试首选

**思考过程**: 最直觉的模拟——"编辑器怎么工作，我就怎么写代码"。遇到普通字符就入栈，遇到 `#` 且栈非空就弹栈。最后栈里剩下的就是最终文本。两个字符串各处理一遍，比较结果即可。

这里直接用 `string` 当栈（`push_back` 相当于 push，`pop_back` 相当于 pop），省去了 `stack → string` 的转换。

```cpp
class Solution {
public:
    bool backspaceCompare(string s, string t) {
        return build(s) == build(t);
    }
    
private:
    string build(const string& str) {
        string result;
        for (char c : str) {
            if (c != '#') {
                result.push_back(c);  // 普通字符，追加
            } else if (!result.empty()) {
                result.pop_back();     // 退格：删除最后一个字符
            }
            // 如果 c=='#' 且 result 为空，什么都不做（对空文本退格）
        }
        return result;
    }
};
```

**关键点**: 退格时必须先检查 `!result.empty()`，否则对空串 `pop_back` 是未定义行为。

---

### 解法2: 双指针逆序比较 — O(n+m) / O(1)（Follow-up 解法）

**从解法1优化**: 解法1的瓶颈是需要 O(n+m) 的额外空间存储处理后的字符串。如果我们**从后往前**遍历，就可以用一个 `skip` 计数器来记录"还需要跳过几个字符"，不需要存储任何中间结果。

**为什么从后往前？** `#` 消除的是它左边的字符。从右往左走时，先遇到 `#`，然后知道要跳过后面（左边）的字符——这是一个"先知道规则，再应用"的顺序，非常自然。

```
双指针比较 s="ab#c", t="ad#c" 的过程:

s: a  b  #  c       t: a  d  #  c
   0  1  2  3          0  1  2  3

Step1: i=3 → 'c'(有效), j=3 → 'c'(有效), 'c'=='c' ✓
Step2: i=2 → '#' skip=1, i=1 → 'b' skip跳过, i=0 → 'a'(有效)
       j=2 → '#' skip=1, j=1 → 'd' skip跳过, j=0 → 'a'(有效)
       'a'=='a' ✓
Step3: i=-1, j=-1, 都结束 → true
```

```cpp
class Solution {
public:
    bool backspaceCompare(string s, string t) {
        int i = s.size() - 1;
        int j = t.size() - 1;
        int skipS = 0, skipT = 0;
        
        // 只要有一个指针还没走完，就继续
        while (i >= 0 || j >= 0) {
            // 找到 s 中下一个有效字符
            while (i >= 0) {
                if (s[i] == '#') {
                    skipS++;
                    i--;
                } else if (skipS > 0) {
                    skipS--;  // 跳过被退格的字符
                    i--;
                } else {
                    break;    // s[i] 是有效字符，停下来等比较
                }
            }
            
            // 找到 t 中下一个有效字符
            while (j >= 0) {
                if (t[j] == '#') {
                    skipT++;
                    j--;
                } else if (skipT > 0) {
                    skipT--;
                    j--;
                } else {
                    break;
                }
            }
            
            // 比较当前两个有效字符
            if (i >= 0 && j >= 0) {
                if (s[i] != t[j]) return false;  // 有效字符不同
            } else if (i >= 0 || j >= 0) {
                // 一个还有有效字符，另一个已经没有了
                return false;
            }
            
            i--;
            j--;
        }
        
        return true;
    }
};
```

**关键点**:
- 内层 while 循环有三个分支：遇 `#` 累加 skip → skip>0 跳过字符 → 否则找到有效字符 break。
- 外层比较时，`i >= 0 && j >= 0` 和 `i >= 0 || j >= 0` 两个条件缺一不可：前者比较字符，后者检测长度不一致。

## 解法对比

| | 栈模拟 | 双指针逆序 |
|---|---|---|
| 时间 | O(n+m) | O(n+m) |
| 空间 | O(n+m) | O(1) |
| 代码难度 | 简单 | 中等 |
| 思路直觉性 | 非常直觉 | 需要想到逆序遍历 |
| 面试推荐 | 先写出来 | Follow-up 追问时给出 |

**面试策略**: 先快速写出栈模拟（2分钟），面试官追问 O(1) 空间时再给出双指针。

## 易错点

1. **对空栈退格**:
   - ✗ 遇到 `#` 直接 `result.pop_back()` — 空串时崩溃
   - ✓ 先检查 `!result.empty()` 再 `pop_back()`

2. **双指针比较时忘记处理长度不等**:
   - ✗ 只检查 `s[i] != t[j]` — 如果 `i < 0` 但 `j >= 0`，访问越界
   - ✓ 先分别判断 `i >= 0 && j >= 0` 和 `i >= 0 || j >= 0`

3. **双指针内层循环漏掉连续 `#` 的累积**:
   - ✗ 遇到 `#` 只 skip 一个字符 — `"ab##"` 应该跳过两个字符
   - ✓ 用 while 循环累积 skip 计数器

4. **双指针外层循环条件写成 `&&`**:
   - ✗ `while (i >= 0 && j >= 0)` — 一个走完另一个可能还有有效字符未比较
   - ✓ `while (i >= 0 || j >= 0)` — 确保两边都走完

## 面试追问

**Q1: 暴力解怎么做？复杂度多少？**
→ 栈模拟，分别处理两个字符串后比较。时间 O(n+m)，空间 O(n+m)。这已经是时间最优了。

**Q2: 能否 O(1) 空间？**
→ 从后往前双指针，用 skip 计数器跳过被退格的字符，逐个比较有效字符。

**Q3: 如果 `#` 的语义变成"删除前面所有字符"（类似 Ctrl+U 清行），怎么改？**
→ 栈模拟中改成 `result.clear()`；双指针中遇到 `#` 直接让指针跳到 -1（或将 skip 设为一个极大值）。核心框架不变。

**Q4: 如果输入是流式的（一个字符一个字符到达），怎么处理？**
→ 用栈模拟天然支持流式输入。双指针方案需要知道完整字符串长度，不适合流式场景。
