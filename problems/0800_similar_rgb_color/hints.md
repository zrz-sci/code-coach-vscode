# 800. Similar RGB Color - 相似 RGB 颜色

## 核心思路

每个可简写的颜色 "#XXYYZZ" 中，每个通道的两个十六进制位相同。可简写值只有 16 种：0x00, 0x11, 0x22, ..., 0xFF，恰好等于 `x * 17`（x 从 0 到 15）。由于相似度的计算公式是各通道差值平方和的负数，各通道互相独立，因此 **可以分别对每个通道找最接近的可简写值**，最终拼接即可。

核心观察：对单个通道值 v，最近的可简写值 = `round(v / 17.0) * 17`，等价于整数运算 `(v + 8) / 17 * 17`。

## 思维链

1. **理解可简写颜色**：形如 "#XXYYZZ"，每个通道两位相同，如 "#112233"
2. **可简写值的数学表示**：十六进制 "XX" = X * 16 + X = X * 17，X 从 0 到 F（即 0 到 15）
3. **候选值枚举**：0, 17, 34, 51, 68, 85, 102, 119, 136, 153, 170, 187, 204, 221, 238, 255
4. **独立性**：相似度公式 `-(r1-r2)^2 - (g1-g2)^2 - (b1-b2)^2` 中三个通道互不影响
5. **最优化**：各通道独立最小化差值平方 -> 各通道独立找最近的候选值
6. **快速计算**：`round(v / 17.0)` 得到最近的 x，然后 x * 17 得到最近候选值

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 核心技巧 | 适用场景 |
|------|-----------|-----------|---------|---------|
| 数学直接计算 | O(1) | O(1) | round(v/17)*17 | 面试首选 |
| 枚举 16 个候选 | O(1) | O(1) | 遍历所有 x*17 取最小差 | 更直观但略冗余 |

## 关键提示

### 提示 1 - 三通道独立处理
RGB 颜色由三个独立通道组成。相似度公式中每个通道的贡献是独立的平方差项。因此全局最优等价于三个通道分别局部最优。对每个通道独立求解，最后拼接。

### 提示 2 - 可简写值的规律
十六进制 "XX"（两位相同）对应十进制 X * 16 + X = X * 17。X 取 0 到 15，共 16 个候选值。候选值间距为 17（等间距），所以最近候选总是唯一的（除非恰好在两个候选中间，此时四舍五入到较近的一个）。

### 提示 3 - 数学快捷方式
给定通道值 v（0 到 255）：
- 浮点方式：`x = round(v / 17.0)`，最近值 = `x * 17`
- 整数方式：`x = (v + 8) / 17`（整数除法，+8 实现四舍五入），最近值 = `x * 17`

两种方式等价。整数方式避免浮点运算，更可靠。

### 提示 4 - 十六进制字符串处理
- 输入 "#ABCDEF" 中，AB 是 R 通道，CD 是 G 通道，EF 是 B 通道
- 解析：取子串 color[1..2], color[3..4], color[5..6]，用 stoi(hex, nullptr, 16) 转整数
- 输出：对每个通道的最近值用 sprintf 或 format 转回两位小写十六进制 "%02x"
- 注意输出格式要求小写十六进制

### 提示 5 - 枚举法作为替代
如果不想推导数学公式，可以暴力枚举 16 个候选值，找与 v 差的绝对值最小的那个。虽然是 O(16) = O(1)，但代码略长。枚举法的好处是不容易出错。

## 解法详解

### 解法一：数学直接计算（面试首选）

**Step 1**：解析输入字符串，提取三个通道的十六进制子串并转为整数。

**Step 2**：对每个通道值 v，计算最近的可简写值：
```
x = (v + 8) / 17     // 四舍五入到最近的倍数索引
nearest = x * 17     // 对应的可简写值
```

**Step 3**：将 nearest 转回两位十六进制字符串（小写），拼接三个通道，加上 "#" 前缀。

**正确性证明**：
候选值是 0, 17, 34, ..., 255，间距 17。对于任意 v：
- 下方候选 = `(v / 17) * 17`
- 上方候选 = `(v / 17 + 1) * 17`
- v 到下方距离 = `v % 17`
- v 到上方距离 = `17 - v % 17`
- 如果 `v % 17 <= 8`，选下方（四舍）；否则选上方（五入）
- `(v + 8) / 17 * 17` 正好实现这个逻辑

**举例**：
- v = 153 -> x = (153+8)/17 = 161/17 = 9 -> nearest = 153 = 0x99 -> "99"
- v = 128 -> x = (128+8)/17 = 136/17 = 8 -> nearest = 136 = 0x88 -> "88"
- v = 0   -> x = (0+8)/17 = 0 -> nearest = 0 = 0x00 -> "00"
- v = 255 -> x = (255+8)/17 = 15 -> nearest = 255 = 0xFF -> "ff"
- v = 9   -> x = (9+8)/17 = 1 -> nearest = 17 = 0x11 -> "11"
- v = 8   -> x = (8+8)/17 = 0 -> nearest = 0 = 0x00 -> "00"

### 解法二：枚举 16 个候选值

对每个通道值 v，遍历 x = 0 到 15，计算 |v - x*17|，取最小差对应的 x*17。

```
int bestVal = 0, bestDiff = 256;
for (int x = 0; x <= 15; x++) {
    int candidate = x * 17;
    int diff = abs(v - candidate);
    if (diff < bestDiff) {
        bestDiff = diff;
        bestVal = candidate;
    }
}
```

逻辑简单但代码量稍大。面试中先给出这个思路，再优化为数学公式。

## 易错点

1. **十六进制大小写问题**
   - 错误：输出 "FF" 或 "Ff"
   - 正确：题目要求小写，使用 "%02x"（不是 "%02X"）

2. **整数除法四舍五入偏差**
   - 错误：`v / 17 * 17`（总是向下取整，不是四舍五入）
   - 正确：`(v + 8) / 17 * 17`（+8 实现四舍五入）

3. **子串提取偏移量错误**
   - 错误：color.substr(0, 2) 包含了 '#' 字符
   - 正确：color.substr(1, 2) 跳过 '#'，然后是 substr(3, 2) 和 substr(5, 2)

4. **格式化输出不足两位**
   - 错误：值为 0 时输出 "0" 而非 "00"
   - 正确："%02x" 保证始终输出两位，不足补零

5. **忽略边界值验证**
   - v = 0 时应返回 "00"（0x00），v = 255 时应返回 "ff"（0xFF）
   - (0+8)/17 = 0，(255+8)/17 = 15，都在 [0, 15] 范围内，正确

6. **混淆相似度和距离**
   - 相似度 = -(r差^2 + g差^2 + b差^2)，越大越好（负值越接近 0 越好）
   - 最小化距离等价于最大化相似度
   - 分通道独立最小化差值平方即可

## 面试追问

**Q1: 为什么三个通道可以独立处理？**
相似度公式 `-(r1-r2)^2 - (g1-g2)^2 - (b1-b2)^2` 是三个独立项的和。最大化整体等价于分别最小化每个 `(c1-c2)^2`，因为选择一个通道的最优值不影响其他通道。这是优化中"可分离"的典型性质。

**Q2: 候选值为什么是 x * 17？**
十六进制两位相同 "XX" 意味着高位和低位相等。X 的十进制值是 X * 16 + X = X * 17。例如 "AA" = 10 * 16 + 10 = 170 = 10 * 17。

**Q3: 如果要找最相似的颜色但不限于可简写形式呢？**
不限制时，最相似的颜色就是原颜色本身（距离为 0）。题目的约束在于目标颜色必须是可简写的（每通道两位相同），这限制了候选空间为 16^3 = 4096 种颜色。

**Q4: (v+8)/17 的四舍五入在 v=8 时选择 0 而非 17，这对吗？**
v=8 时，到 0 的距离是 8，到 17 的距离是 9，选 0 是对的。(8+8)/17 = 0（整数除法），nearest = 0。如果 v=9，到 0 距离 9，到 17 距离 8，选 17。(9+8)/17 = 1，nearest = 17。正确。

**Q5: 如果颜色空间是 RGBA（四通道），怎么改？**
增加一个 Alpha 通道的独立处理即可。四个通道依然互不影响，各自找最近可简写值后拼接。

**Q6: 如果不是找最近而是找"不超过"原值的最大可简写值呢？**
改为向下取整：`x = v / 17`，nearest = x * 17。不再需要四舍五入。
