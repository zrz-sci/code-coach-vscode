# 867. 转置矩阵

## 核心思路

矩阵转置就是行列互换：`result[j][i] = matrix[i][j]`。原矩阵 `m x n`，转置后变成 `n x m`。关键考点是正确处理**非方阵**（行数 != 列数）的情况。

## 思维链

1. **读完题第一反应** → 转置矩阵是线性代数基础操作。沿主对角线翻转，行变列、列变行。
2. **非方阵能原地转置吗？** → 不能！2x3 的矩阵转置后是 3x2，内存布局完全不同。必须创建新矩阵。
3. **方阵能原地转置吗？** → 可以！交换 `matrix[i][j]` 和 `matrix[j][i]`（只遍历上三角或下三角）。但本题不保证是方阵，所以统一用新矩阵。
4. **新矩阵的大小？** → 原矩阵 `m` 行 `n` 列，转置后 `n` 行 `m` 列。初始化 `res(n, vector<int>(m))`。
5. **遍历顺序？** → 遍历原矩阵的每个 `(i, j)`，赋值 `res[j][i] = matrix[i][j]`。也可以反过来遍历结果矩阵的 `(j, i)`，赋值 `res[j][i] = matrix[i][j]`。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 创建新矩阵 | 遍历赋值 result[j][i] = matrix[i][j] | O(m*n) | O(m*n) | ⭐ 唯一正确做法 |
| 方阵原地转置 | 上三角交换 swap(m[i][j], m[j][i]) | O(n^2) | O(1) | 仅方阵可用 |

## 关键提示

1. **转置的几何意义**：

   ```
   原矩阵 (2x3):          转置后 (3x2):
   
   ┌─────────────┐         ┌─────────┐
   │  1   2   3  │         │  1   4  │
   │  4   5   6  │         │  2   5  │
   └─────────────┘         │  3   6  │
                           └─────────┘
   
   映射关系:
   matrix[0][0]=1 → res[0][0]=1
   matrix[0][1]=2 → res[1][0]=2    ← 行列交换
   matrix[0][2]=3 → res[2][0]=3
   matrix[1][0]=4 → res[0][1]=4
   matrix[1][1]=5 → res[1][1]=5
   matrix[1][2]=6 → res[2][1]=6
   
   规则: res[j][i] = matrix[i][j]
   ```

2. **方阵的原地转置**（面试可能追问）：

   ```
   方阵 (3x3):
   
   原始:                    转置后:
   ┌───────────┐           ┌───────────┐
   │ 1  2  3   │           │ 1  4  7   │
   │ 4  5  6   │    →      │ 2  5  8   │
   │ 7  8  9   │           │ 3  6  9   │
   └───────────┘           └───────────┘
   
   原地操作: 只交换上三角 (i < j 的部分)
   swap(m[0][1], m[1][0]): 2 ↔ 4
   swap(m[0][2], m[2][0]): 3 ↔ 7
   swap(m[1][2], m[2][1]): 6 ↔ 8
   
   主对角线 (1, 5, 9) 不动
   ```

3. **新矩阵的初始化**：
   - C++: `vector<vector<int>> res(n, vector<int>(m));` — n 行 m 列
   - 注意不是 `res(m, vector<int>(n))`！行列要反过来
   - Python: `[[0] * m for _ in range(n)]`

4. **遍历方式的选择**：
   - 方式A：遍历原矩阵 `for i in [0,m), for j in [0,n)` → `res[j][i] = matrix[i][j]`
   - 方式B：遍历结果矩阵 `for j in [0,n), for i in [0,m)` → `res[j][i] = matrix[i][j]`
   - 两种等价，方式B 对结果矩阵的访问是按行顺序的，cache友好

## 解法详解

### 解法1: 创建新矩阵 — O(m*n) / O(m*n) ⭐

**思考过程**: 非方阵不能原地转置，必须创建新矩阵。

```cpp
class Solution {
public:
    vector<vector<int>> transpose(vector<vector<int>>& matrix) {
        int m = matrix.size();      // 原矩阵的行数
        int n = matrix[0].size();   // 原矩阵的列数
        
        // 转置后: n 行 m 列
        vector<vector<int>> res(n, vector<int>(m));
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                res[j][i] = matrix[i][j];
            }
        }
        
        return res;
    }
};
```

**执行过程**:
```
matrix = [[1,2,3],     m=2, n=3
          [4,5,6]]

初始化 res(3, vector<int>(2)):  3行2列
res = [[0,0],
       [0,0],
       [0,0]]

遍历:
i=0, j=0: res[0][0] = matrix[0][0] = 1
i=0, j=1: res[1][0] = matrix[0][1] = 2
i=0, j=2: res[2][0] = matrix[0][2] = 3
i=1, j=0: res[0][1] = matrix[1][0] = 4
i=1, j=1: res[1][1] = matrix[1][1] = 5
i=1, j=2: res[2][1] = matrix[1][2] = 6

res = [[1,4],
       [2,5],
       [3,6]]  ✓
```

### 解法1b: 遍历结果矩阵（cache友好版本）

```cpp
class Solution {
public:
    vector<vector<int>> transpose(vector<vector<int>>& matrix) {
        int m = matrix.size();
        int n = matrix[0].size();
        
        vector<vector<int>> res(n, vector<int>(m));
        
        // 遍历结果矩阵的每个位置
        for (int j = 0; j < n; j++) {       // 结果的行
            for (int i = 0; i < m; i++) {    // 结果的列
                res[j][i] = matrix[i][j];
            }
        }
        
        return res;
    }
};
```

**关键点**:
- 外层循环 `j`（结果的行），内层循环 `i`（结果的列）
- 对 `res` 的写入是按行顺序的（`res[j][0], res[j][1], ...`），cache友好
- 对 `matrix` 的读取是按列的（`matrix[0][j], matrix[1][j], ...`），cache不友好
- 但由于矩阵通常不大（本题 m*n <= 10^5），差别可忽略

### 解法2: 方阵原地转置（仅方阵可用）

```cpp
// 注意：本题矩阵可能不是方阵，此解法仅作为知识点展示
class Solution_SquareOnly {
public:
    void transposeInPlace(vector<vector<int>>& matrix) {
        int n = matrix.size(); // 必须 n == matrix[0].size()
        
        // 只遍历上三角 (i < j)，交换对称位置
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                swap(matrix[i][j], matrix[j][i]);
            }
        }
        // 主对角线元素不需要动
    }
};
```

**关键点**:
- 只适用于方阵！2x3 矩阵不能原地变成 3x2
- 遍历上三角（`j = i + 1` 开始），每对只交换一次
- 如果写成 `j = 0` 开始，每对会交换两次，相当于没转置
- 在旋转矩阵90度（LC 48）中常配合行翻转使用

## 易错点

1. **结果矩阵行列搞反**：
   - ✗ `vector<vector<int>> res(m, vector<int>(n));` → 大小和原矩阵一样，赋值越界
   - ✓ `vector<vector<int>> res(n, vector<int>(m));` → 行列互换

2. **赋值方向搞反**：
   - ✗ `res[i][j] = matrix[j][i]` → 没有转置，只是换了个名字
   - ✓ `res[j][i] = matrix[i][j]` → 行列互换

3. **方阵原地转置遍历整个矩阵**：
   - ✗ `for j = 0..n` → 每对交换两次，等于没转
   - ✓ `for j = i+1..n` → 只遍历上三角，每对交换一次

4. **对非方阵尝试原地转置**：
   - ✗ 修改原矩阵大小再赋值 → 复杂且容易出错
   - ✓ 直接创建新矩阵

5. **下标混淆**：
   - 原矩阵用 `(i, j)` 表示第 i 行第 j 列
   - 结果矩阵中同一个元素在第 j 行第 i 列
   - 容易写混，建议用变量名提示（如 `row, col`）

## 面试追问

**Q1: 非方阵能不能原地转置？**
> 理论上可以，但极其复杂。需要找到所有的"置换环"（permutation cycle），沿环路逐个移动元素。实现复杂度高且没有实际意义，面试中创建新矩阵即可。

**Q2: 转置 + 行翻转 = 什么变换？**
> 转置后每行反转 = 顺时针旋转 90 度（LC 48）。
> 转置后每列反转 = 逆时针旋转 90 度。
> 这是矩阵旋转的标准技巧，面试高频。

**Q3: 如果矩阵存在磁盘上（太大放不进内存），怎么转置？**
> 分块转置（block transpose）：
> 1. 把矩阵分成小块（能放进内存的大小）
> 2. 块级别做转置（块的位置交换）
> 3. 块内部做转置
> 这利用了空间局部性，减少磁盘随机访问。

**Q4: 稀疏矩阵怎么转置？**
> 稀疏矩阵通常用三元组 `(row, col, value)` 存储。转置只需交换 row 和 col：`(row, col, val) → (col, row, val)`，然后按新的 row 排序。时间 O(nnz * log nnz)，nnz 是非零元素数。

**Q5: 这题的时间复杂度能优化到低于 O(m*n) 吗？**
> 不能。每个元素至少要被读取一次才能写入结果，所以 O(m*n) 是最优下界。
