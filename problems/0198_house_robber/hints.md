# 198. 打家劫舍

## 核心思路

本质上是一个**线性选择问题**：在一个数组中选出若干不相邻的元素，使它们的和最大。每个房屋只有"偷"或"不偷"两种选择，且相邻房屋不能同时选择——这是经典的线性 DP 入门题。

## 思维链

1. **读完题的第一反应**：每间房有"偷"和"不偷"两个选择，约束是不能连续偷两间。暴力做法就是枚举所有合法的选取组合，对每个组合求和取最大值。
2. **暴力解的瓶颈**：每间房 2 种选择，n 间房就有 2^n 种组合（虽然约束会剪掉一些），指数级复杂度不可接受。
3. **发现重叠子问题**：如果我用递归 `rob(i)` 表示"从第 i 间到最后能偷的最大金额"，那 `rob(i)` 的结果会被多个路径反复计算。比如 `rob(0)` 调用 `rob(2)` 和 `rob(3)`，而 `rob(1)` 也调用 `rob(3)` —— `rob(3)` 被重复计算了！
4. **加记忆化 → 记忆化搜索**：用 memo 数组缓存已计算的结果，避免重复计算，时间从指数降到 O(n)。
5. **翻译成递推 DP**：`dp[i]` 表示"考虑前 i 间房能偷到的最大金额"，状态转移：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`。含义非常直观——第 i 间要么不偷（沿用 `dp[i-1]`），要么偷（加上 `dp[i-2]`，跳过第 i-1 间）。
6. **空间优化**：`dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`，所以只需要两个变量即可，空间从 O(n) 降到 O(1)。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力递归 | 每间房选/不选，穷举所有组合 | O(2^n) | O(n) 递归栈 | 能说出即可 |
| 记忆化搜索 | 暴力递归 + memo 缓存 | O(n) | O(n) | 能说出即可 |
| 递推 DP | 自底向上填表 | O(n) | O(n) | ⭐ 必须写出 |
| 递推 DP + 空间优化 | 滚动变量替代数组 | O(n) | O(1) | 加分项 |

## 关键提示

- **提示 1**：对于第 i 间房屋，你只有两种选择——偷或不偷。如果偷第 i 间，那第 i-1 间就不能偷，你的收益是 `nums[i] + 前 i-2 间的最优`。如果不偷第 i 间，你的收益就是 `前 i-1 间的最优`。
- **提示 2**：试着定义 `dp[i]` = "考虑前 i 间房屋（0 到 i）能偷到的最大金额"，写出状态转移方程。
- **提示 3**：注意 `dp[i]` 只依赖前两个状态——这意味着什么？能否用更少的空间？
- **提示 4**：初始化时 `dp[0]` 和 `dp[1]` 分别是什么？`dp[1]` 不是 `nums[1]`，想想为什么。

```
DP 填表过程 (nums = [2, 7, 9, 3, 1]):

下标 i:   0    1    2    3    4
nums:     2    7    9    3    1
dp:       2    7   11   11   12

dp[0] = 2                         (只有一间，偷它)
dp[1] = max(2, 7) = 7             (两间取较大)
dp[2] = max(dp[1], dp[0]+9) = max(7, 11) = 11   ← 偷第0和第2间
dp[3] = max(dp[2], dp[1]+3) = max(11, 10) = 11  ← 不偷第3间
dp[4] = max(dp[3], dp[2]+1) = max(11, 12) = 12  ← 偷第2和第4间
```

## 解法详解

### 解法 1: 暴力递归 — O(2^n) / O(n)

**思考过程**：最直觉的做法——站在第 i 间房前，我可以选择偷（跳到 i+2）或不偷（走到 i+1），递归到底后取最大值。

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        return helper(nums, 0);
    }
    
    int helper(vector<int>& nums, int i) {
        if (i >= nums.size()) return 0;
        // 选择1: 偷第 i 间，下一间只能从 i+2 开始
        // 选择2: 不偷第 i 间，下一间从 i+1 开始
        return max(helper(nums, i + 2) + nums[i],  // 偷
                   helper(nums, i + 1));              // 不偷
    }
};
```

**关键点**：这个递归有大量重复计算。画出递归树就能看到：

```
决策树 (nums = [2, 7, 9, 3]):

                  rob(0)
                /        \
          rob(2)+2       rob(1)
          /     \        /     \
     rob(4)+9  rob(3)  rob(3)+7  rob(2)    ← rob(3) 和 rob(2) 被重复计算！
               /   \    /   \    /    \
             ...   ...  ...  ... ...   ...
```

### 解法 2: 记忆化搜索 — O(n) / O(n)

**从解法 1 优化**：解法 1 的瓶颈是重复计算子问题。加一个 memo 数组，计算过的直接返回。

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        vector<int> memo(nums.size(), -1);
        return helper(nums, 0, memo);
    }
    
    int helper(vector<int>& nums, int i, vector<int>& memo) {
        if (i >= nums.size()) return 0;
        if (memo[i] != -1) return memo[i]; // 已计算过，直接返回
        
        memo[i] = max(helper(nums, i + 2, memo) + nums[i],
                      helper(nums, i + 1, memo));
        return memo[i];
    }
};
```

**关键点**：memo 初始化为 -1（因为金额 >= 0，-1 表示未计算）。每个状态只计算一次，时间 O(n)。

### 解法 3: 递推 DP — O(n) / O(n) ⭐ 面试首选

**从记忆化到递推**：把自顶向下的递归翻译成自底向上的 for 循环。

**状态定义**：`dp[i]` = 考虑下标 0 到 i 的房屋，能偷到的最大金额

**状态转移**：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`
- 不偷第 i 间：最优就是 `dp[i-1]`
- 偷第 i 间：得加上 `dp[i-2]`（跳过第 i-1 间）

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        if (n == 1) return nums[0];
        
        vector<int> dp(n);
        dp[0] = nums[0];              // 只有一间，必偷
        dp[1] = max(nums[0], nums[1]); // 两间取较大的那间
        
        for (int i = 2; i < n; i++) {
            dp[i] = max(dp[i - 1],          // 不偷第 i 间
                        dp[i - 2] + nums[i]); // 偷第 i 间
        }
        
        return dp[n - 1];
    }
};
```

```
dp 填表方向 (→ 从左到右):

dp[i] 依赖 dp[i-1] 和 dp[i-2]，所以从左往右填即可。

  dp[i-2]  dp[i-1]  dp[i]
    ↘                ↑
     ————————————————┘
              ↗      ↑
    dp[i-1] ——————————┘
```

**关键点**：`dp[1] = max(nums[0], nums[1])`，不是 `dp[1] = nums[1]`！因为"考虑前两间"的最优可能是只偷第一间。

### 解法 4: 递推 DP + 空间优化 — O(n) / O(1)

**从解法 3 优化**：`dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`，不需要整个数组，两个变量就够了。

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        if (n == 1) return nums[0];
        
        int prev2 = nums[0];              // 对应 dp[i-2]
        int prev1 = max(nums[0], nums[1]); // 对应 dp[i-1]
        
        for (int i = 2; i < n; i++) {
            int curr = max(prev1, prev2 + nums[i]);
            prev2 = prev1;  // 滚动: dp[i-2] ← dp[i-1]
            prev1 = curr;   // 滚动: dp[i-1] ← dp[i]
        }
        
        return prev1;
    }
};
```

**关键点**：滚动变量的更新顺序不能反——必须先用旧的 prev2 算出 curr，然后再更新 prev2 和 prev1。

## 解法对比

| | 暴力递归 | 记忆化搜索 | 递推 DP | 递推 + 空间优化 |
|---|---|---|---|---|
| 时间 | O(2^n) | O(n) | O(n) | O(n) |
| 空间 | O(n) 栈 | O(n) | O(n) | **O(1)** |
| 思维方向 | 自顶向下 | 自顶向下 | 自底向上 | 自底向上 |
| 面试推荐 | ✗ 太慢 | ✓ 能展示递归思维 | ⭐ 首选 | ⭐⭐ 追问时给出 |

**何时选哪个**：面试先写递推 DP（解法3），面试官追问空间优化时给出解法4。如果思路不清楚，可以先从记忆化搜索（解法2）入手再翻译。

## 易错点

1. **`dp[1]` 初始化错误**
   - ✗ `dp[1] = nums[1]`（忽略了可能只偷第0间更优）
   - ✓ `dp[1] = max(nums[0], nums[1])`
   - 原因：`dp[1]` 代表"考虑前两间的最优"，不是"一定偷第1间"

2. **忘记处理 `n == 1` 的边界**
   - ✗ 直接写 `dp[1] = max(nums[0], nums[1])` 会越界
   - ✓ 先 `if (n == 1) return nums[0]`

3. **空间优化时滚动变量更新顺序错误**
   - ✗ `prev2 = prev1; prev1 = max(prev1, prev2 + nums[i]);`（先更新了 prev2，导致计算 curr 时用了错误的值）
   - ✓ 先算 `curr = max(prev1, prev2 + nums[i])`，再更新 `prev2 = prev1; prev1 = curr`

4. **误以为"偷奇数位"或"偷偶数位"就是最优**
   - ✗ 贪心选奇数位或偶数位（反例：`[2, 1, 1, 2]`，最优是偷第0间和第3间，不是纯奇数或偶数位）
   - ✓ 必须用 DP 考虑所有可能

## 面试追问

**Q1: 暴力解的时间复杂度是多少？瓶颈在哪里？**
→ O(2^n)，瓶颈是子问题被重复计算。画出递归树可以看到 `rob(3)` 等子问题被多次调用。

**Q2: 能否将空间从 O(n) 优化到 O(1)？**
→ 可以。`dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`，用两个滚动变量 prev1、prev2 即可。见解法4。

**Q3: 如果房屋排成环形（首尾相邻），怎么办？**
→ 这就是 [213. 打家劫舍 II](https://leetcode.com/problems/house-robber-ii/)。核心思路：第一间和最后一间不能同时偷，所以分两种情况——`rob(nums[0..n-2])` 和 `rob(nums[1..n-1])`，取两者的较大值。**代码改动：调用两次本题的函数，传入不同的起止下标。**

**Q4: 如果房屋排成二叉树形状呢？**
→ 这就是 [337. 打家劫舍 III](https://leetcode.com/problems/house-robber-iii/)。在树上做 DP，每个节点返回一对值 `(偷该节点的最大值, 不偷该节点的最大值)`。
