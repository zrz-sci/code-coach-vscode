# 136. 只出现一次的数字

## 核心思路

本质上是在一堆"成对出现"的数中，找出那个"落单"的数。关键在于如何高效地"消除"成对的元素。

## 思维链

1. **读完题第一反应**：最朴素的想法——遍历数组，对每个元素再遍历一次看它出现了几次，出现一次的就是答案。这是 O(n²) 的暴力法。

2. **暴力解的瓶颈**：对每个元素，"数它出现几次"需要遍历整个数组 O(n)，总共 O(n²)。瓶颈在于**查找/计数**操作太慢。

3. **用空间换时间**：哈希表可以把计数操作降到 O(1)。遍历一次建频率表，再遍历一次找出现1次的。时间 O(n)，空间 O(n)。但题目要求常量空间……

4. **题目的特殊约束是突破口**：不是任意频次，而是"其余都出现**恰好两次**"。两个相同的数有什么运算能互相抵消？→ **异或 (XOR)**！`a ^ a = 0`，`a ^ 0 = a`。

5. **最终方案**：把数组所有元素异或起来，成对的元素互相抵消变成0，最后剩下的就是那个只出现一次的元素。时间 O(n)，空间 O(1)，完美满足题目要求。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力计数 | 对每个元素遍历数组计数 | O(n²) | O(1) | 能说出即可 |
| 哈希表计数 | 频率表记录出现次数 | O(n) | O(n) | 能说出即可 |
| 排序 | 排序后相邻比较 | O(n log n) | O(1) | 能说出即可 |
| 异或 | 全员异或，成对抵消 | O(n) | O(1) | ⭐ 必须写出 |

## 关键提示

1. **异或的三个关键性质**：`a ^ a = 0`（自反性）、`a ^ 0 = a`（零元素）、交换律 + 结合律（顺序无关）。这三条合在一起就是本题的全部核心。

2. **为什么哈希表不够好**：题目明确要求 O(1) 空间。哈希表虽然时间 O(n)，但空间也是 O(n)，不满足要求。

3. **异或过程可视化**（以 `[4,1,2,1,2]` 为例）：
   ```
   0 ^ 4 = 4
   4 ^ 1 = 5
   5 ^ 2 = 7
   7 ^ 1 = 6    ← 1 和之前的 1 抵消了
   6 ^ 2 = 4    ← 2 和之前的 2 抵消了，剩下 4
   ```

4. **排序法的思路**：排序后相同元素必然相邻，两两一组检查，不成对的就是答案。虽然直觉上好理解，但时间复杂度不够优。

5. **边界情况**：数组只有一个元素时，它自己就是答案。异或方法天然处理了这种情况（`0 ^ nums[0] = nums[0]`）。

## 解法详解

### 解法1: 哈希表计数 — O(n) / O(n)

**思考过程**：最自然的优化暴力的方式——用哈希表把"计数"加速到 O(1)。第一遍遍历建频率表，第二遍找频率为1的元素。

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        unordered_map<int, int> freq;
        // 第一遍：记录每个元素出现的次数
        for (int num : nums) {
            freq[num]++;
        }
        // 第二遍：找出只出现一次的元素
        for (int num : nums) {
            if (freq[num] == 1) return num;
        }
        return -1; // 题目保证有答案，不会执行到这
    }
};
```

**关键点**：
- 这是通用做法，即使元素出现次数不限于"两次"也能用。
- 缺点是空间 O(n)，不满足题目 Follow-up 要求的 O(1) 空间。

---

### 解法2: 排序后相邻比较 — O(n log n) / O(1)

**思考过程**：如果数组有序，相同元素一定相邻。两两一组检查，如果 `nums[i] != nums[i+1]`，那 `nums[i]` 就是落单的。

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        // 两两一组检查
        for (int i = 0; i < (int)nums.size() - 1; i += 2) {
            if (nums[i] != nums[i + 1]) {
                // nums[i] 没有配对，它就是落单的
                return nums[i];
            }
        }
        // 如果前面都配对了，最后一个元素就是落单的
        return nums.back();
    }
};
```

**关键点**：
- 步长是 2（`i += 2`），因为正常情况下每两个元素是一对。
- 如果落单元素在最后，循环内不会触发 return，所以最后返回 `nums.back()`。
- 空间 O(1)（原地排序），但时间 O(n log n)，不满足线性要求。

---

### 解法3: 全员异或 — O(n) / O(1) ⭐ 面试首选

**从解法1优化**：解法1 的瓶颈是需要 O(n) 额外空间来存计数。我们需要一种"不存储"就能消除成对元素的方法。异或运算恰好有这个性质：**两个相同的数异或为0，任何数和0异或等于自身**。

```
// 异或性质证明这个方法的正确性：
// nums = [a, b, a, c, b]  (c是落单的)
// a ^ b ^ a ^ c ^ b
// = (a ^ a) ^ (b ^ b) ^ c    ← 交换律+结合律重新组合
// = 0 ^ 0 ^ c                ← 自反性: x ^ x = 0
// = c                        ← 零元素: x ^ 0 = x
```

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int result = 0;
        for (int num : nums) {
            // 成对的数异或后互相抵消为0
            // 最终只剩下出现一次的数
            result ^= num;
        }
        return result;
    }
};
```

**关键点**：
- 初始值 `result = 0` 是因为 0 是异或的单位元（`0 ^ x = x`）。
- 异或满足交换律和结合律，所以数组中元素的顺序不影响结果——成对元素总能"找到对方"抵消掉。
- 这道题是位运算的经典入门题，面试中几乎必须给出 O(n)/O(1) 的异或解法。

## 解法对比

| | 哈希表计数 | 排序比较 | 全员异或 |
|---|---|---|---|
| 时间 | O(n) | O(n log n) | O(n) |
| 空间 | O(n) | O(1)* | O(1) |
| 优点 | 通用性强 | 直觉简单 | 时空最优 |
| 缺点 | 空间不满足要求 | 时间不满足要求 | 依赖"恰好两次"的约束 |
| 适用场景 | 频次不限的通用计数 | 允许修改原数组 | 成对出现+找落单 |

> *排序如果不能原地排序（如 Python 的 sorted），空间其实是 O(n)。

## 易错点

1. **异或初始值写错**
   - ✗ `int result = nums[0]; for (int i = 0; ...)` — 从 `nums[0]` 开始又从 i=0 遍历，导致 `nums[0]` 被异或了两次
   - ✓ `int result = 0; for (int num : nums)` — 从 0 开始遍历全部，或从 `nums[0]` 开始遍历 i=1

2. **排序法步长写错**
   - ✗ `i += 1` — 一个一个比较，逻辑完全错误
   - ✓ `i += 2` — 两两一组检查，配对的跳过

3. **排序法漏掉最后一个元素**
   - ✗ 循环结束没有 `return nums.back()`，当落单元素在末尾时无法返回
   - ✓ 循环外兜底返回最后一个元素

## 面试追问

**Q1（基础理解）**：为什么异或能解决这道题？
> 异或的自反性 `a ^ a = 0` 让成对元素互相抵消，零元素性质 `a ^ 0 = a` 保证落单元素被保留。交换律和结合律保证顺序无关。

**Q2（变体-出现三次）**：如果其余元素出现**三次**，只有一个出现一次呢？（[LeetCode 137](https://leetcode.com/problems/single-number-ii/)）
> 异或无法直接处理三次的情况（`a ^ a ^ a = a ≠ 0`）。需要逐位统计每一位上 1 出现的次数，对 3 取余，余数构成答案。可以用有限状态机优化到两个变量。

**Q3（变体-两个落单）**：如果有**两个**元素各出现一次，其余出现两次呢？（[LeetCode 260](https://leetcode.com/problems/single-number-iii/)）
> 全员异或得到 `a ^ b`（两个落单数的异或）。取其中任一位为 1 的位（用 `xor_all & (-xor_all)` 取最低位），按该位是否为 1 将数组分成两组，每组内分别异或就得到 a 和 b。

**Q4（空间约束）**：如果不允许使用位运算，只用 O(1) 空间，能做到 O(n) 吗？
> 数学方法：`2 * sum(set(nums)) - sum(nums)` = 落单的数。但要注意溢出风险（可用 long long）。
