# 696. 计数二进制子串

## 核心思路

将字符串按**连续相同字符分组**，统计每组的长度。相邻两组能构成的合法子串数 = `min(前一组长度, 当前组长度)`。一次遍历，用 `prev` 和 `curr` 两个变量滚动统计即可。

## 思维链

1. **读完题第一反应** → 要找满足条件的子串：(1) 0 和 1 的数量相等，(2) 所有 0 连续且所有 1 连续。比如 `"0011"` 合法，`"0101"` 不合法（0 和 1 没有各自连续）。
2. **暴力怎么做？** → 枚举所有子串，检查是否满足条件。O(n^2) 甚至 O(n^3)，太慢。
3. **观察合法子串的结构** → 合法子串一定是 `000...111...` 或 `111...000...` 的形式（一段连续的 0 后面跟一段等长的连续 1，或反过来）。这意味着合法子串只可能出现在**两个不同字符分组的交界处**。
4. **关键洞察** → 把字符串按连续相同字符分组！例如 `"00110011"` → 分组 `[2, 2, 2, 2]`（两个0，两个1，两个0，两个1）。相邻两组 `(prev, curr)` 能贡献 `min(prev, curr)` 个合法子串。
5. **为什么是 min(prev, curr)?** → 从交界处向两边扩展：`prev` 组提供 0（或 1），`curr` 组提供 1（或 0）。合法子串要求两边等长，最多取到较短那一组的长度。
6. **不需要真的存分组数组** → 只需要 `prev`（上一组的长度）和 `curr`（当前组的长度）两个变量滚动即可，空间 O(1)。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 分组计数（滚动） | prev/curr + min 累加 | O(n) | O(1) | ⭐ 面试首选 |
| 分组计数（数组） | 先存分组数组，再遍历 | O(n) | O(n) | 辅助理解 |
| 暴力枚举 | 枚举子串检查 | O(n^2) | O(1) | 仅口述 |

## 关键提示

1. **分组思想是核心**：`"00110011"` → `[2, 2, 2, 2]`。理解了分组，这道题就解了。
2. **min(prev, curr) 的直觉**：两组长度分别为 3 和 2，能构成的合法子串是 `"01"` 和 `"0011"`（2个），取决于较短组的长度。
3. **滚动变量**：不需要存整个分组数组。每当字符变化时：`ans += min(prev, curr); prev = curr; curr = 1;`。遍历结束后还要再加一次 `min(prev, curr)`（处理最后两组）。
4. **结束时别忘最后一次累加**：循环结束时 `curr` 是最后一组的长度，`prev` 是倒数第二组的长度，还没有被累加进 `ans`。

## 解法详解

### 解法1: 分组计数（滚动变量） — O(n) / O(1) ⭐ 面试首选

**思考过程**: 把字符串按连续相同字符分组后，相邻两组贡献 `min(prev, curr)` 个合法子串。用两个变量滚动，不需要存分组数组。

```cpp
class Solution {
public:
    int countBinarySubstrings(string s) {
        int ans = 0, prev = 0, curr = 1;
        for (int i = 1; i < (int)s.size(); i++) {
            if (s[i] == s[i - 1]) {
                curr++;  // 同一组，长度+1
            } else {
                // 字符切换！相邻两组贡献 min(prev, curr)
                ans += min(prev, curr);
                prev = curr;  // 当前组变成"上一组"
                curr = 1;     // 新组从长度1开始
            }
        }
        // 最后两组还没加，补上
        ans += min(prev, curr);
        return ans;
    }
};
```

**关键点**:
- `prev` 初始为 0：第一组之前没有"上一组"，`min(0, anything) = 0`，不影响结果。
- `curr` 初始为 1：第一个字符 `s[0]` 就是当前组的第一个元素，长度为 1。
- 循环从 `i=1` 开始：比较 `s[i]` 和 `s[i-1]` 来判断是否同组。
- **循环结束后必须再加一次**：最后一次字符切换之后的那一组（`curr`）和倒数第二组（`prev`）还没被计入 `ans`。

---

### 解法2: 分组计数（显式数组） — O(n) / O(n)

**辅助理解**: 先把所有分组长度存进数组，再两两取 min 求和。逻辑更清晰，但多用了 O(n) 空间。

```cpp
class Solution {
public:
    int countBinarySubstrings(string s) {
        // Step 1: 建分组数组
        vector<int> groups;
        int count = 1;
        for (int i = 1; i < (int)s.size(); i++) {
            if (s[i] == s[i - 1]) {
                count++;
            } else {
                groups.push_back(count);
                count = 1;
            }
        }
        groups.push_back(count);  // 最后一组

        // Step 2: 相邻两组取 min 求和
        int ans = 0;
        for (int i = 1; i < (int)groups.size(); i++) {
            ans += min(groups[i - 1], groups[i]);
        }
        return ans;
    }
};
```

**关键点**:
- 理解了这个解法后，解法1就是它的空间优化版（用 prev/curr 代替数组）。
- 面试时可以先讲这个，让面试官理解思路，然后优化到解法1。

## 解法对比

|  | 滚动变量 | 显式数组 |
|--|---------|---------|
| 时间 | **O(n)** | O(n) |
| 空间 | **O(1)** | O(n) |
| 可读性 | 需要理解 prev/curr | 更直观 |
| 面试推荐 | ⭐ 最终答案 | 讲思路时用 |

## 易错点

1. **循环结束后忘记最后一次累加**：
   - ✗ 只在 `s[i] != s[i-1]` 时累加 → 最后两组没计入
   - ✓ 循环结束后 `ans += min(prev, curr);`

2. **prev 初始值设错**：
   - ✗ `prev = 1` → 第一次字符切换时 `ans += min(1, curr)` 多加了
   - ✓ `prev = 0`，第一次切换时 `min(0, curr) = 0`，不影响

3. **混淆"子串"和"子序列"**：
   - 子串必须连续，子序列可以不连续。本题是子串。
   - 合法子串：`"0011"` ✓  不是合法子串：`"0101"`（0 和 1 没有各自分组连续）

4. **误以为需要枚举子串**：
   - ✗ 双重循环枚举所有子串 O(n^2) 或 O(n^3)
   - ✓ 分组后一次遍历 O(n)

## 面试追问

**Q1: 为什么 min(prev, curr) 就是相邻两组贡献的合法子串数？**
> 从两组的交界处出发，向左扩展到 prev 组，向右扩展到 curr 组。合法子串要求两边等长（等量的 0 和 1），最多扩展到较短组的长度。所以长度为 1 到 min(prev, curr) 的合法子串各一个，共 min(prev, curr) 个。

**Q2: 能否用 O(1) 空间，不用分组的思路？**
> 本质上解法1的 prev/curr 就是 O(1) 空间。换一种理解方式：对每个相邻不同字符的位置 `(i, i+1)`，向两边等距扩展，统计有多少步能扩展成功。但这样是 O(n^2)，不如分组 O(n) 好。

**Q3: 如果字符串不是二进制（比如 "aaabbcc"），怎么推广？**
> 同样按连续相同字符分组。但"合法子串"的定义需要明确：如果要求**恰好两种**字符且各自连续，那只有相邻两组之间才能产生合法子串，逻辑一样。
