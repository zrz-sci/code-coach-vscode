# 760. 找出变位映射 (Find Anagram Mappings)

## 核心思路

本题是一道简单的**哈希表**应用题。给定两个互为变位词的数组 nums1 和 nums2，需要找到一个映射数组使得 `mapping[i] = j` 表示 `nums1[i]` 出现在 `nums2[j]` 位置。核心做法是：先遍历 nums2 建立值到索引的映射，然后遍历 nums1 查表得到每个元素在 nums2 中的位置。需要注意处理重复元素的情况。

## 思维链

1. **观察**：nums2 是 nums1 的变位词，意味着两个数组包含完全相同的元素（含重复）
2. **目标**：对 nums1 中的每个元素找到它在 nums2 中的一个位置
3. **查找优化**：暴力查找每个元素需要 O(n^2)，用哈希表可以 O(1) 查找
4. **重复元素**：如果有重复值，题目允许返回任意合法映射，所以只需存储一个索引即可
5. **更严格处理**：若需要每个映射唯一（不重复映射到同一索引），可以用队列存储同一值的所有索引

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 哈希表（简单版） | O(n) | O(n) | 允许重复映射到同一索引 |
| 哈希表 + 队列（严格版） | O(n) | O(n) | 保证一一映射，处理重复元素 |
| 暴力搜索 | O(n^2) | O(1) | 无需额外空间，但效率低 |

## 关键提示

1. **建立反向索引**：遍历 nums2，用 `map[value] = index` 存储每个值最后一次出现的位置
2. **查表构建结果**：遍历 nums1，对每个元素查表 `mapping[i] = map[nums1[i]]`
3. **重复元素的处理策略**：
   - 简单做法：`map[value] = index` 后出现的覆盖先出现的，返回任意合法结果
   - 严格做法：`map[value] = queue{idx1, idx2, ...}`，每次取一个并弹出，保证一一映射
4. **题目保证**：nums2 一定是 nums1 的变位词，所以不需要处理找不到的情况

## 解法详解

### 解法一：简单哈希表（推荐）

**算法步骤**：
1. 创建哈希表 `indexMap`，遍历 nums2：`indexMap[nums2[j]] = j`
2. 创建结果数组 `result`，遍历 nums1：`result[i] = indexMap[nums1[i]]`
3. 返回 result

**关于重复元素**：如果 nums1 = [1,1]，nums2 = [1,1]，这种做法会映射为 [1,1]（因为第二个1覆盖了第一个1的索引）。题目允许任意合法映射，所以 [1,1] 和 [0,0] 都是可接受的答案。但更理想的答案是 [0,1] 或 [1,0]，需要用解法二。

**复杂度分析**：
- 时间复杂度：O(n)，两次遍历
- 空间复杂度：O(n)，哈希表存储

### 解法二：哈希表 + 队列（严格一一映射）

**算法步骤**：
1. 创建 `unordered_map<int, queue<int>>` 类型的 indexMap
2. 遍历 nums2：`indexMap[nums2[j]].push(j)`，将同一值的所有索引存入队列
3. 遍历 nums1：`result[i] = indexMap[nums1[i]].front()`，取队首索引
4. 取完后 `indexMap[nums1[i]].pop()`，弹出队首保证不重复使用

**优势**：保证了一一映射关系，每个 nums2 的索引最多被使用一次。

### 解法三：暴力搜索

**算法步骤**：
1. 对 nums1 中每个元素，遍历 nums2 找到匹配位置
2. 为避免重复使用同一索引，可用 visited 数组标记已使用的位置

**复杂度**：O(n^2) 时间，不推荐但无需额外哈希空间。

## 易错点

1. **重复元素导致映射冲突**：如果 nums1 = [3,3]，nums2 = [3,3]，简单哈希表会让两个3都映射到同一个索引。虽然题目允许，但如果面试官要求严格一一映射，需要用队列方案
2. **哈希表的 key 类型**：值可达 10^5，用 unordered_map<int, int> 即可，不需要排序
3. **返回类型**：返回值是 `vector<int>`，不要误写成其他类型
4. **不需要检查查找失败**：题目保证 nums2 是 nums1 的变位词，所以 nums1 中的每个值一定能在 nums2 中找到

## 面试追问

1. **Q: 如果需要保证映射是双射（一一对应），如何修改？**
   - A: 使用解法二，用队列存储同一值的所有索引，每次取一个并弹出。这保证了每个 nums2 中的索引最多被使用一次。

2. **Q: 如果数组非常大（10^8 元素），如何优化内存？**
   - A: 可以先将两个数组分别排序（带索引），然后双指针扫描配对。排序 O(n log n)，但空间从 O(n) 哈希表降为 O(1) 额外空间（如果用原地排序）。

3. **Q: 这道题能用排序解决吗？**
   - A: 可以。将 `(value, original_index)` 对排序后，nums1 和 nums2 中相同值会对齐，直接建立映射。时间 O(n log n)，空间 O(n)。

4. **Q: 如果两个数组不保证是变位词关系，如何处理？**
   - A: 需要在查表时处理"找不到"的情况。可以用 -1 表示 nums1[i] 在 nums2 中不存在。

5. **Q: unordered_map 和 map 在这里的选择有什么影响？**
   - A: unordered_map 平均 O(1) 查找，map O(log n) 查找。本题不需要有序性，unordered_map 是更好的选择。但如果担心哈希冲突，map 提供稳定的 O(log n) 保证。
