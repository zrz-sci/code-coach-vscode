# 847. Shortest Path Visiting All Nodes - 提示与解析

## 核心思路

在无向图中找到访问所有节点的最短路径（可重复访问节点和边）。经典的状态压缩 BFS 问题。用 bitmask 表示已访问的节点集合，BFS 的状态为 `(当前节点, 已访问集合)`。由于可以从任意节点出发，初始时将所有节点都加入 BFS 队列。当 bitmask 等于 `(1 << n) - 1`（全部访问）时，当前步数即为答案。

## 思维链

1. **状态定义**：`(node, mask)` 表示当前在节点 node，已访问的节点集合为 mask（bitmask）。
2. **初始化**：每个节点都可以作为起点，所以 BFS 初始队列包含 `(i, 1 << i)` 对于所有节点 i。
3. **状态转移**：从 `(node, mask)` 出发，走到邻居 `next`，新状态为 `(next, mask | (1 << next))`。
4. **终止条件**：当 `mask == (1 << n) - 1` 时，所有节点都被访问，返回当前步数。
5. **去重**：用 `visited[node][mask]` 避免重复状态。因为 n <= 12，mask 最多 2^12 = 4096 种。
6. **BFS 保证最短**：BFS 层序遍历，首次到达全访问状态时步数即为最短。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 推荐度 | 特点 |
|------|-----------|-----------|--------|------|
| 状态压缩 BFS | O(n * 2^n) | O(n * 2^n) | ⭐⭐⭐⭐⭐ | 最优解，面试首选 |
| 状态压缩 DP | O(n^2 * 2^n) | O(n * 2^n) | ⭐⭐⭐⭐ | DP 思路，不如 BFS 直观 |
| Floyd + 状态压缩 DP | O(n^3 + n^2 * 2^n) | O(n * 2^n) | ⭐⭐⭐ | 先求最短路再 TSP |

## 关键提示

1. **n <= 12 是关键信号**：看到 n <= 12 就应该联想到状态压缩（bitmask），因为 2^12 = 4096 是可接受的状态数。
2. **可重复访问**：不同于一般最短路，这里允许重复访问节点。所以不能简单用 visited[node] 去重，必须用 visited[node][mask]。
3. **多源 BFS**：从所有节点同时出发，等价于添加一个虚拟起点连接所有节点（但更好的是直接多源 BFS）。
4. **BFS vs DFS**：BFS 天然保证最短路径，DFS 需要额外记忆化且不保证最优性。
5. **TSP 变体**：本题本质是旅行商问题（TSP）在无权图上的变体，但由于可重复访问且 n 很小，BFS + bitmask 足够高效。

## 解法详解

### 解法一：状态压缩 BFS（推荐）

**思路**：
BFS 的状态是 `(当前节点, 已访问节点的 bitmask)`。从所有节点同时出发（多源 BFS），每次扩展一步。用二维数组 `visited[node][mask]` 去重。首次使 mask 变为全 1 的状态即为最短路径。

**关键细节**：
- 初始状态：对每个节点 i，状态为 `(i, 1 << i)`，步数 = 0
- 转移：从 `(u, mask)` 到 `(v, mask | (1 << v))`，步数 + 1
- 终止：`mask == (1 << n) - 1`

**复杂度分析**：
- 时间：O(n * 2^n)，总共 n * 2^n 种状态，每个状态处理一次
- 空间：O(n * 2^n)，visited 数组 + 队列

### 解法二：状态压缩 DP

**思路**：
`dp[mask][i]` = 访问了 mask 中的节点，最后停在节点 i 的最短路径长度。转移需要预计算所有节点对之间的最短距离（用 BFS 或 Floyd）。

**复杂度分析**：
- 时间：O(n^2 * 2^n)
- 空间：O(n * 2^n)

### 解法三：Floyd 预处理 + TSP DP

**思路**：
先用 Floyd-Warshall 求所有节点对的最短距离，然后用经典 TSP DP 求解。`dp[mask][i]` 表示访问了 mask 中的节点、最后在节点 i 的最短路径。

**复杂度分析**：
- 时间：O(n^3 + n^2 * 2^n)
- 空间：O(n^2 + n * 2^n)

## 易错点

1. **状态不包含 mask**：如果只用 visited[node] 去重，会错过 "已访问不同节点集合但回到同一节点" 的情况。
2. **忘记多源起点**：不能只从节点 0 出发，必须考虑所有可能的起始节点。
3. **bitmask 溢出**：n = 12 时 `1 << 12 = 4096`，int 足够，但注意不要用 `1 << n` 而是 `1 << i`。
4. **BFS 层次计数错误**：确保是在弹出队列元素时检查终止条件，而非入队时。
5. **图未连通的误判**：题目保证图是连通的，但如果不是，应返回 -1（实际题目不会出现此情况）。

## 面试追问

1. **Q: 为什么 BFS 而不是 Dijkstra？**
   A: 图是无权的（每条边权重为 1），BFS 等价于 Dijkstra，且更高效。

2. **Q: 这道题和 TSP 的关系？**
   A: 经典 TSP 要求访问所有节点且回到起点，不允许重复访问。本题允许重复访问且不需回到起点，是 TSP 的简化变体。

3. **Q: 如果边有权重怎么办？**
   A: 改用 Dijkstra + bitmask，或者 Floyd 预处理 + TSP DP。状态相同，但转移需要考虑边权。

4. **Q: n = 20 还能用这个方法吗？**
   A: 2^20 = 1M，乘以 n = 20 就是 20M 状态，勉强可以但已接近极限。更大的 n 需要近似算法。

5. **Q: 如何恢复具体路径？**
   A: 用 parent 数组记录每个状态的前驱 `(prev_node, prev_mask)`，从终态回溯。
