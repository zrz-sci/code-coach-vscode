# 面试题 16.26. 计算器 (Calculator LCCI)

## 难度: Medium | 标签: Stack, Math, String

---

## 核心思路

实现一个不带括号的基本计算器，支持 `+, -, *, /` 四种运算和空格。核心难点在于**运算符优先级**的处理：乘除优先于加减。经典解法是用**栈**来延迟加减运算、即时处理乘除运算。

> 本题与 LeetCode 227. Basic Calculator II 完全相同。

## 思维链

1. **读完题第一反应** → 字符串解析 + 四则运算。难点是 `*` `/` 要比 `+` `-` 先算。
2. **如何处理优先级？** → 两种经典方法：
   - **方法 A：栈**。遇到 `+`/`-` 时把数字（带符号）压栈，遇到 `*`/`/` 时从栈顶取出来立即计算。最后把栈中所有数求和。
   - **方法 B：双变量**。用 `prevNum` 记录上一个待定数字，`result` 累积已确定的加减结果。遇到 `*`/`/` 时更新 `prevNum`，遇到 `+`/`-` 时把 `prevNum` 加入 `result`。
3. **统一处理第一个数字** → 初始化 `op = '+'`。这样第一个数字被当作"前面有个 +"来处理，统一逻辑。
4. **何时触发计算？** → 遇到运算符或到达字符串末尾时，用**上一个运算符** `op` 来决定如何处理刚解析完的数字 `num`。
5. **空格处理** → 空格不是运算符也不是数字，直接跳过。但注意：空格不能触发计算，除非它是最后一个字符（这就是为什么条件是 `!isdigit && !space || i == end`）。

## 运算过程可视化

```
输入: "3+2*2"

初始: op='+', num=0, stack=[]

字符 '3': num = 3
字符 '+': op='+' → push 3, stack=[3] → op='+'(新), num=0
字符 '2': num = 2
字符 '*': op='+' → push 2, stack=[3,2] → op='*'(新), num=0
字符 '2': num = 2
末尾触发: op='*' → pop 2, push 2*2=4, stack=[3,4]

求和: 3 + 4 = 7 ✓
```

```
输入: " 3+5 / 2 "

初始: op='+', num=0, stack=[]

' ': 跳过
'3': num = 3
'+': op='+' → push 3, stack=[3] → op='+', num=0
'5': num = 5
' ': 跳过
'/': op='+' → push 5, stack=[3,5] → op='/', num=0
' ': 跳过
'2': num = 2
' ': 跳过
末尾触发: op='/' → pop 5, push 5/2=2, stack=[3,2]

求和: 3 + 2 = 5 ✓
```

```
输入: "14-3/2"

初始: op='+', num=0, stack=[]

'1': num = 1
'4': num = 14  (多位数: num = 1*10 + 4)
'-': op='+' → push 14, stack=[14] → op='-', num=0
'3': num = 3
'/': op='-' → push -3, stack=[14,-3] → op='/', num=0
'2': num = 2
末尾触发: op='/' → pop -3, push -3/2=-1, stack=[14,-1]

求和: 14 + (-1) = 13 ✓

注意: C++ 中整数除法向零截断: -3/2 = -1 (不是 -2)
```

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 栈（延迟加减，即时乘除） | 经典栈模拟 | O(n) | O(n) | ⭐ 面试首选，易理解 |
| 双变量（无栈） | prevNum + result | O(n) | O(1) | 进阶优化，空间最优 |

## 关键提示

1. **初始运算符设为 `+`**：这样第一个数字会被当作 `+num` 压入栈，统一处理逻辑，无需特殊处理第一个数字。
2. **解析多位数**：连续的数字字符要组合成完整的数：`num = num * 10 + (s[i] - '0')`。
3. **触发计算的条件**：`(!isdigit(s[i]) && s[i] != ' ') || i == s.size()-1`。即遇到运算符或到达末尾时，用**上一个运算符**处理当前数字。
4. **整数除法截断方向**：C++ 中 `-3/2 = -1`（向零截断），这正好是题目要求的。Python 中 `-3//2 = -2`（向下取整），需要用 `int(-3/2)` 代替。
5. **栈中数的含义**：`+` 压正数，`-` 压负数，`*`/`/` 立即和栈顶计算。最终栈中所有数之和就是答案。这巧妙地避免了处理运算符优先级。

## 解法详解

### 解法1: 栈 — O(n) / O(n) ⭐ 面试首选

**核心逻辑**：
- 用栈存放"待加的数"
- 遇到 `+`：把 num 压栈
- 遇到 `-`：把 -num 压栈
- 遇到 `*`：弹出栈顶 × num，结果压回
- 遇到 `/`：弹出栈顶 ÷ num，结果压回
- 最后对栈求和

```cpp
class Solution {
public:
    int calculate(string s) {
        stack<int> stk;
        int num = 0;
        char op = '+';
        for (int i = 0; i < (int)s.size(); i++) {
            if (isdigit(s[i]))
                num = num * 10 + (s[i] - '0');
            if ((!isdigit(s[i]) && s[i] != ' ') || i == (int)s.size() - 1) {
                if (op == '+') stk.push(num);
                else if (op == '-') stk.push(-num);
                else if (op == '*') { int t = stk.top(); stk.pop(); stk.push(t * num); }
                else if (op == '/') { int t = stk.top(); stk.pop(); stk.push(t / num); }
                op = s[i];
                num = 0;
            }
        }
        int res = 0;
        while (!stk.empty()) { res += stk.top(); stk.pop(); }
        return res;
    }
};
```

### 解法2: 双变量（O(1) 空间） — O(n) / O(1)

**思考过程**：栈中的数最终都要求和，能不能边走边求和？可以。用 `prevNum` 记录"最近一个可能参与乘除的数"，用 `result` 记录"已经确定不会再参与乘除的部分和"。

```
输入: "3+2*2"

i=0 '3': num=3
i=1 '+': op='+' → result += prevNum(0), prevNum = 3 → result=0, prev=3 → op='+', num=0
i=2 '2': num=2
i=3 '*': op='+' → result += prevNum(3), prevNum = 2 → result=3, prev=2 → op='*', num=0
i=4 '2': num=2
末尾: op='*' → prevNum = 2*2 = 4 → result=3, prev=4

结果: result + prevNum = 3 + 4 = 7 ✓
```

## 易错点

1. **多位数解析**：`"42"` 不是 `4` 和 `2`，是 `42`。必须连续累积 `num = num*10 + digit`。
2. **最后一个数字的处理**：字符串末尾没有运算符来触发计算。需要额外检查 `i == s.size()-1`。
3. **空格不触发计算**：空格只是分隔符，不应触发运算。所以条件中有 `s[i] != ' '`。
4. **栈解法中乘除后的符号**：`"-3*2"` → 栈中先有 `-3`，然后 `*2` 时弹出 `-3`，计算 `-3*2=-6` 压回。符号在数字里，不会丢失。
5. **整数溢出**：本题输入是 int 范围，但如果扩展到大数需要用 long long。

## 面试追问递进链

1. **"如果有括号呢？"** → [224. Basic Calculator](../0224_basic_calculator/)，用递归处理括号嵌套，或者双栈（数字栈 + 运算符栈）。
2. **"如果有一元负号呢？"** → 需要区分 `-` 是减号还是负号。在字符串开头或左括号后的 `-` 是负号。
3. **"能否不用栈？"** → 可以，用双变量解法（解法2），O(1) 空间。
4. **"如何支持浮点数？"** → 解析时处理小数点，用 double 代替 int。
5. **"如何写一个通用表达式求值器？"** → Shunting-yard 算法（调度场算法），或者递归下降解析器。
