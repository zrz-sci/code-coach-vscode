# LCR 074. 合并区间

> 本题与主站第 56 题相同

## 核心思路

**排序 + 线性扫描**。先按区间起点排序，然后顺序遍历：如果当前区间和前一个区间有重叠（`start <= 前一个的 end`），就合并（取更大的 `end`）；否则开启新的合并区间。排序保证了只需要和前一个比较，不需要回头看更早的区间。

这道题是**区间问题**的入门经典，排序后线性扫描的模式在插入区间、区间交集、会议室等题中反复出现。

## 思维链

1. **读完题第一反应** → 对每对区间检查是否重叠，如果重叠就合并。暴力做法：每次合并后重新检查所有区间对，直到没有重叠为止。O(n^2) 甚至更差。
2. **排序的好处** → 如果区间按起点排序，那么对于相邻两个区间 A 和 B（A.start <= B.start），A 和 B 重叠的充要条件是 `B.start <= A.end`。而且不需要和更前面的区间比较——因为如果 A 已经和前面的合并了，A.end 已经更新为所有已合并区间中最大的 end。
3. **线性扫描** → 排序后，维护一个结果数组。遍历每个区间：如果和结果数组的最后一个区间重叠，就更新 end 为两者的最大值；否则直接加入结果数组。
4. **为什么排序后只需比较相邻？** → 排序后 `a.start <= b.start <= c.start`。如果 a 和 c 重叠（`c.start <= a.end`），那么 b.start <= c.start <= a.end，所以 a 和 b 也重叠。也就是说，排序后重叠区间一定是连续的，不会出现"隔一个重叠"的情况。
5. **edge case** → (1) 只有一个区间 → 直接返回。(2) 区间完全包含关系：`[1,10]` 和 `[2,3]` → 合并后还是 `[1,10]`，用 `max(end)` 自然处理。(3) 区间端点相等：`[1,4]` 和 `[4,5]` → 题目说视为重叠，`4 <= 4` 满足合并条件。

## 关键提示

1. **排序方式**：按起点升序排序即可。起点相同时按终点排序与否不影响正确性（因为合并时取 `max(end)`），但按默认 `sort` 就是先按第一个元素、再按第二个元素排序，已经足够。
2. **合并条件**：`intervals[i][0] <= merged.back()[1]`。注意是 `<=` 不是 `<`，因为 `[1,4]` 和 `[4,5]` 题目视为重叠。
3. **合并操作**：`merged.back()[1] = max(merged.back()[1], intervals[i][1])`。必须取 max 而非直接赋值，因为可能有包含关系（如 `[1,10]` 和 `[2,3]`，合并后应该是 `[1,10]` 而非 `[1,3]`）。
4. **排序的必要性**：未排序时重叠区间可能不相邻（如 `[1,3],[8,10],[2,6]`），无法通过一次线性扫描完成。排序后重叠区间必定连续。
5. **in-place 与否**：可以在原数组上操作（原地合并），但用新数组存结果更清晰。面试中推荐新数组写法，不容易出错。

## 解法详解

### 解法1: 排序 + 线性扫描 — O(n log n) / O(1) ⭐ 面试首选

**思考过程**: 排序后只需要和前一个合并区间比较。维护结果数组 `res`，遍历排序后的区间：如果当前区间起点 <= `res` 最后一个区间的终点，说明重叠，更新终点为两者最大值；否则直接加入 `res`。

```
示例: intervals = [[1,3],[2,6],[8,10],[15,18]]

排序后: [[1,3],[2,6],[8,10],[15,18]] (已经有序)

遍历:
[1,3]: res 为空, 直接加入 → res = [[1,3]]
[2,6]: 2 <= 3 (重叠), max(3,6) = 6 → res = [[1,6]]
[8,10]: 8 > 6 (不重叠), 加入 → res = [[1,6],[8,10]]
[15,18]: 15 > 10 (不重叠), 加入 → res = [[1,6],[8,10],[15,18]]

结果: [[1,6],[8,10],[15,18]] ✓


示例2: intervals = [[1,4],[4,5]]
排序后: [[1,4],[4,5]]

[1,4]: 加入 → res = [[1,4]]
[4,5]: 4 <= 4 (重叠!), max(4,5) = 5 → res = [[1,5]]

结果: [[1,5]] ✓  (端点相同视为重叠)


示例3 (包含关系): intervals = [[1,10],[2,3],[4,5]]
排序后: [[1,10],[2,3],[4,5]]

[1,10]: 加入 → res = [[1,10]]
[2,3]:  2 <= 10, max(10,3) = 10 → res = [[1,10]] (不变)
[4,5]:  4 <= 10, max(10,5) = 10 → res = [[1,10]] (不变)

结果: [[1,10]] ✓  (大区间"吃掉"了小区间)
```

```cpp
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        // 按起点排序 (起点相同时按终点排序, sort 默认行为)
        sort(intervals.begin(), intervals.end());
        
        vector<vector<int>> res;
        for (auto& iv : intervals) {
            // 如果结果为空, 或当前区间与 res 最后一个不重叠
            if (res.empty() || iv[0] > res.back()[1]) {
                res.push_back(iv);
            } else {
                // 重叠: 合并, 取更大的终点
                res.back()[1] = max(res.back()[1], iv[1]);
            }
        }
        return res;
    }
};
```

**关键点**:
- `sort(intervals.begin(), intervals.end())` 默认按第一个元素升序，第一个元素相同时按第二个元素升序，完全满足需求。
- 合并条件 `iv[0] > res.back()[1]` 判断不重叠（注意是 `>` 而非 `>=`，因为端点相等也要合并）。
- `max(res.back()[1], iv[1])` 处理包含关系。

### 解法2: 排序 + 双指针写法 — O(n log n) / O(1)

**同样的思路，不同的代码风格**: 用双指针 `start`/`end` 追踪当前合并区间的范围。

```cpp
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        sort(intervals.begin(), intervals.end());
        
        vector<vector<int>> res;
        int start = intervals[0][0], end = intervals[0][1];
        
        for (int i = 1; i < (int)intervals.size(); i++) {
            if (intervals[i][0] <= end) {
                // 重叠: 扩展当前合并区间的终点
                end = max(end, intervals[i][1]);
            } else {
                // 不重叠: 保存当前合并区间, 开始新的
                res.push_back({start, end});
                start = intervals[i][0];
                end = intervals[i][1];
            }
        }
        // 别忘了最后一个合并区间
        res.push_back({start, end});
        return res;
    }
};
```

**关键点**:
- 需要在循环结束后 push 最后一个合并区间，这是一个常见的"收尾"操作。
- 解法1 不需要收尾（每次直接操作 `res.back()`），所以代码更简洁，推荐解法1的写法。

### 解法3: 连通分量（了解思路即可） — O(n^2) / O(n^2)

**不同视角**: 把每个区间看作图中的一个节点，两个区间重叠就连一条边。合并后的区间对应图中的连通分量。用 BFS/DFS 或并查集求连通分量。

```cpp
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        int n = intervals.size();
        // 建图: 重叠区间连边
        vector<vector<int>> graph(n);
        for (int i = 0; i < n; i++)
            for (int j = i + 1; j < n; j++)
                if (overlaps(intervals[i], intervals[j])) {
                    graph[i].push_back(j);
                    graph[j].push_back(i);
                }
        
        // BFS 求连通分量
        vector<bool> visited(n, false);
        vector<vector<int>> res;
        for (int i = 0; i < n; i++) {
            if (visited[i]) continue;
            // BFS 找到所有与 i 连通的区间
            queue<int> q;
            q.push(i);
            visited[i] = true;
            int lo = intervals[i][0], hi = intervals[i][1];
            while (!q.empty()) {
                int cur = q.front(); q.pop();
                lo = min(lo, intervals[cur][0]);
                hi = max(hi, intervals[cur][1]);
                for (int nb : graph[cur]) {
                    if (!visited[nb]) {
                        visited[nb] = true;
                        q.push(nb);
                    }
                }
            }
            res.push_back({lo, hi});
        }
        return res;
    }
    
private:
    bool overlaps(vector<int>& a, vector<int>& b) {
        return a[0] <= b[1] && b[0] <= a[1];
    }
};
```

**关键点**:
- 建图 O(n^2)，BFS O(n)，总 O(n^2)。比排序法慢得多。
- 价值在于展示"区间问题可以转化为图论问题"的思维。面试中不推荐，但如果面试官问"还有别的方法吗？"可以提。

**面试策略**: 直接写排序+线性扫描（解法1），代码最短，不需要收尾操作，最不容易出错。

## 易错点

1. **合并时直接赋值而非取 max**：
   - ✗ `res.back()[1] = iv[1]` → `[1,10]` 和 `[2,3]` 合并后变成 `[1,3]`，丢失了范围
   - ✓ `res.back()[1] = max(res.back()[1], iv[1])` → 正确保持 `[1,10]`

2. **合并条件用 `<` 而非 `<=`**：
   - ✗ `iv[0] < res.back()[1]` → `[1,4]` 和 `[4,5]` 不合并，但题目要求合并
   - ✓ `iv[0] <= res.back()[1]`（或等价地，不重叠条件为 `iv[0] > res.back()[1]`）

3. **忘记排序**：
   - ✗ 不排序直接线性扫描 → `[[1,3],[8,10],[2,6]]` 中 `[1,3]` 和 `[2,6]` 不相邻，漏合并
   - ✓ 必须先排序，保证重叠区间连续

4. **双指针写法忘记收尾**：
   - ✗ 循环结束后没有 `push_back({start, end})` → 最后一组合并区间丢失
   - ✓ 循环后追加最后一个合并区间

5. **空数组未处理**：
   - ✗ `intervals` 为空时 `intervals[0]` 崩溃
   - ✓ 加 `if (intervals.empty()) return {};`（虽然题目保证 `n >= 1`，但防御性编程是好习惯）

## 面试追问

**Q1: 时间复杂度能否优于 O(n log n)？**
> 排序的下界是 O(n log n)（基于比较的排序），所以在不做额外假设的情况下不能更快。但如果区间端点范围有限（如 `[0, 10^4]`），可以用桶排序/计数排序做到 O(n + k)，其中 k 是值域范围。这是一个有趣的理论讨论点。

**Q2: 如果区间是以数据流形式输入的（一个一个来），怎么维护合并结果？**
> 用一个有序集合（如 `std::set`）维护已合并的区间。每次新区间到来，找到所有重叠的已有区间（利用有序性用 `lower_bound` 快速定位），合并后删除旧区间、插入新区间。每次操作 O(k log n)，k 是被合并的区间数。

**Q3: 如果不是合并，而是求所有区间的交集呢？**
> 不同问题。区间交集需要同时考虑两组区间的 overlap 部分。参考 LC986（区间列表的交集）：双指针分别扫描两组有序区间，每对重叠区间的交集 = `[max(start), min(end)]`。
