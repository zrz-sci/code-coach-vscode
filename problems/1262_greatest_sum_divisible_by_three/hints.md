# 1262. 可被三整除的最大和

## 核心思路

给一个正整数数组，选出一些元素使得和最大且能被 3 整除。本质是一道 **DP + 余数分类**问题。关键洞察：我们不需要记录选了哪些数，只需要追踪"当前和对 3 取余的结果"。只需维护 3 个状态 dp[0], dp[1], dp[2]，分别表示余数为 0/1/2 时的最大和。

## 思维链

1. **读完题第一反应**：选子集使和最大且能被 3 整除。子集选择问题 → 可能是 DP 或贪心。

2. **暴力思路**：枚举所有子集 (2^n)，计算每个子集的和，过滤出被 3 整除的，取最大值。n 可达 4*10^4，暴力不可行。

3. **关键观察 — 余数只有 3 种**：任何整数对 3 取余只有 0, 1, 2 三种结果。如果我们知道"前 i 个数中，余数为 r 的最大和"，加入第 i+1 个数时，余数会从 r 变为 (r + nums[i] % 3) % 3。

4. **DP 状态设计**：
   - `dp[r]` = 考虑到当前数字时，所选子集和对 3 取余为 r 的最大和
   - 初始值：dp[0] = 0（空集，和为 0，余数为 0），dp[1] = dp[2] = -INF（不可达）

5. **状态转移**：对于新数字 num，它的余数 r = num % 3。对于旧状态 dp[j]，加上 num 后余数变为 (j + r) % 3，和变为 dp[j] + num。

6. **答案**：dp[0]，即余数为 0 的最大和。

7. **贪心解法也可以**：先求总和 S，如果 S % 3 == 0 直接返回。如果 S % 3 == 1，需要减去最小的一个余数为 1 的数，或者减去最小的两个余数为 2 的数。S % 3 == 2 类似。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| DP（余数状态） | dp[3] 追踪三种余数 | O(n) | O(1) | ⭐ 必须写出 |
| 贪心（总和减去） | 总和 - 最小代价 | O(n) | O(1) | 加分项 |
| 暴力枚举子集 | 2^n 枚举 | O(2^n) | O(1) | 能说出即可 |

## 关键提示

1. **只有 3 个状态**：这是本题的精妙之处。不管数组有多长，我们只需要 3 个变量。余数的世界只有 {0, 1, 2}。

2. **初始化很关键**：dp[0] = 0（合法初态），dp[1] = dp[2] = -INF 或 INT_MIN（表示不可达）。如果初始化为 0，会错误地认为"余数为 1 的子集和可以是 0"。

3. **更新时必须用旧值**：不能在遍历 j = 0,1,2 时直接修改 dp，否则新值会影响后续计算。要用临时变量保存旧 dp。

4. **贪心的关键**：总和 S 余 1 时，要么去掉一个最小的余 1 的数，要么去掉两个最小的余 2 的数，取代价最小的方案。

5. **不存在合法方案时返回 0**：如果所有数都不能被 3 整除且无法凑出余 0 的组合，dp[0] 保持为 0（空集的和），自然返回 0。

## 解法详解

### 解法1: DP（余数状态） ⭐

**思考过程**：

以 nums = [3, 6, 5, 1, 8] 为例，画 DP 表：

```
初始状态:
dp = [0, -INF, -INF]
     r=0  r=1   r=2

处理 num=3 (3%3=0):
  旧 dp[0]=0   → 新 dp[(0+0)%3] = dp[0] = max(0, 0+3) = 3
  旧 dp[1]=-INF → 新 dp[(1+0)%3] = dp[1] = max(-INF, -INF+3) = -INF
  旧 dp[2]=-INF → 新 dp[(2+0)%3] = dp[2] = max(-INF, -INF+3) = -INF
dp = [3, -INF, -INF]

处理 num=6 (6%3=0):
  旧 dp[0]=3 → 新 dp[0] = max(3, 3+6) = 9
dp = [9, -INF, -INF]

处理 num=5 (5%3=2):
  旧 dp[0]=9   → 新 dp[(0+2)%3] = dp[2] = max(-INF, 9+5) = 14
  旧 dp[1]=-INF → 新 dp[(1+2)%3] = dp[0] = max(9, -INF) = 9
  旧 dp[2]=-INF → 新 dp[(2+2)%3] = dp[1] = max(-INF, -INF) = -INF
dp = [9, -INF, 14]

处理 num=1 (1%3=1):
  旧 dp[0]=9   → 新 dp[(0+1)%3] = dp[1] = max(-INF, 9+1) = 10
  旧 dp[1]=-INF → dp[2] 不变
  旧 dp[2]=14  → 新 dp[(2+1)%3] = dp[0] = max(9, 14+1) = 15
dp = [15, 10, 14]

处理 num=8 (8%3=2):
  旧 dp[0]=15 → 新 dp[(0+2)%3] = dp[2] = max(14, 15+8) = 23
  旧 dp[1]=10 → 新 dp[(1+2)%3] = dp[0] = max(15, 10+8) = 18
  旧 dp[2]=14 → 新 dp[(2+2)%3] = dp[1] = max(10, 14+8) = 22
dp = [18, 22, 23]

答案: dp[0] = 18 (选 3+6+1+8=18)
```

```cpp
class Solution {
public:
    int maxSumDivThree(vector<int>& nums) {
        // dp[r] = 余数为 r 时的最大子集和
        // 初始: 空集和为 0, 余数 0; 余数 1,2 不可达
        vector<int> dp = {0, INT_MIN, INT_MIN};
        
        for (int num : nums) {
            // 必须用旧值更新，所以先拷贝
            vector<int> temp = dp;
            for (int j = 0; j < 3; j++) {
                int newR = (j + num % 3) % 3;
                dp[newR] = max(dp[newR], temp[j] + num);
            }
        }
        
        return dp[0];
    }
};
```

**复杂度分析**：
- 时间：O(n)，遍历数组一次，每个元素更新 3 个状态
- 空间：O(1)，只用了固定 3 个变量

### 解法2: 贪心（总和减去最小代价）

**思考过程**：
- 先把所有数加起来得 S
- 如果 S % 3 == 0：直接返回 S
- 如果 S % 3 == 1：
  - 方案 A：减去最小的一个 余数为 1 的数
  - 方案 B：减去最小的两个 余数为 2 的数
  - 取代价最小的方案
- 如果 S % 3 == 2：
  - 方案 A：减去最小的一个 余数为 2 的数
  - 方案 B：减去最小的两个 余数为 1 的数

```cpp
class Solution {
public:
    int maxSumDivThree(vector<int>& nums) {
        int S = 0;
        // mod1: 余数为1的数（升序保留最小的两个）
        // mod2: 余数为2的数（升序保留最小的两个）
        vector<int> mod1, mod2;
        
        for (int num : nums) {
            S += num;
            if (num % 3 == 1) mod1.push_back(num);
            if (num % 3 == 2) mod2.push_back(num);
        }
        
        sort(mod1.begin(), mod1.end());
        sort(mod2.begin(), mod2.end());
        
        if (S % 3 == 0) return S;
        
        if (S % 3 == 1) {
            int optA = (mod1.size() >= 1) ? S - mod1[0] : 0;
            int optB = (mod2.size() >= 2) ? S - mod2[0] - mod2[1] : 0;
            return max(optA, optB);
        }
        
        // S % 3 == 2
        int optA = (mod2.size() >= 1) ? S - mod2[0] : 0;
        int optB = (mod1.size() >= 2) ? S - mod1[0] - mod1[1] : 0;
        return max(optA, optB);
    }
};
```

**复杂度分析**：
- 时间：O(n log n)，排序占主导。可以用 partial_sort 或手动维护最小两个，优化到 O(n)
- 空间：O(n)，存储 mod1, mod2 数组。可优化到 O(1)

### 解法3: 贪心优化版（O(n) 时间 O(1) 空间）

```cpp
class Solution {
public:
    int maxSumDivThree(vector<int>& nums) {
        int S = 0;
        // 维护余数为1的最小两个，余数为2的最小两个
        int m1a = INT_MAX, m1b = INT_MAX; // mod1 最小 和 次小
        int m2a = INT_MAX, m2b = INT_MAX; // mod2 最小 和 次小
        
        for (int num : nums) {
            S += num;
            int r = num % 3;
            if (r == 1) {
                if (num <= m1a) { m1b = m1a; m1a = num; }
                else if (num < m1b) { m1b = num; }
            } else if (r == 2) {
                if (num <= m2a) { m2b = m2a; m2a = num; }
                else if (num < m2b) { m2b = num; }
            }
        }
        
        if (S % 3 == 0) return S;
        if (S % 3 == 1) {
            int optA = (m1a != INT_MAX) ? S - m1a : 0;
            int optB = (m2b != INT_MAX) ? S - m2a - m2b : 0;
            return max(optA, optB);
        }
        // S % 3 == 2
        int optA = (m2a != INT_MAX) ? S - m2a : 0;
        int optB = (m1b != INT_MAX) ? S - m1a - m1b : 0;
        return max(optA, optB);
    }
};
```

## 解法对比

| 维度 | DP（余数状态） | 贪心（排序） | 贪心（优化） |
|------|---------------|-------------|-------------|
| 时间 | O(n) | O(n log n) | O(n) |
| 空间 | O(1) | O(n) | O(1) |
| 代码简洁度 | 最简洁 | 中等 | 较长 |
| 思维难度 | 需理解余数 DP | 直观分类讨论 | 需维护最小值 |
| 面试推荐 | 首选 | 次选 | 展示优化能力 |
| 扩展性 | 容易推广到 mod k | 仅适用 mod 3 | 仅适用 mod 3 |

## 易错点

1. **DP 初始化用 0 而非 -INF**
   ```cpp
   // 错误：dp 全初始化为 0
   vector<int> dp = {0, 0, 0};
   // 这表示"余数为 1 的子集和可以为 0"，但实际上没有这样的空子集
   // 正确：dp = {0, INT_MIN, INT_MIN}
   ```

2. **更新时用了新值而非旧值**
   ```cpp
   // 错误：直接在 dp 上修改
   for (int j = 0; j < 3; j++) {
       int newR = (j + num % 3) % 3;
       dp[newR] = max(dp[newR], dp[j] + num); // dp[j] 可能已被更新！
   }
   // 正确：先复制 temp = dp，用 temp[j] 更新
   ```

3. **贪心中减去多个数后可能为负**
   ```cpp
   // 错误：没检查 mod1/mod2 是否有足够元素
   int optB = S - mod2[0] - mod2[1]; // mod2 可能不到 2 个！
   // 正确：先检查 size >= 2
   ```

4. **INT_MIN + num 溢出**
   ```cpp
   // 潜在问题：INT_MIN + num 可能溢出
   // 解法: 用一个足够小但不溢出的值, 如 -1e9
   // 或者在转移前检查 temp[j] 是否为 INT_MIN
   ```

5. **贪心中忘记处理"全部余数相同"的边界情况**
   ```cpp
   // 如 nums = [4]，S = 4, S%3 = 1
   // mod1 = [4], mod2 = []
   // optA = 4 - 4 = 0, optB = 0 (mod2 不够)
   // 正确返回 0
   ```

## 面试追问

### 追问链1: DP 深入

**Q1: 为什么 dp 只需要 3 个状态？**

因为我们关心的是"子集和对 3 取余"的结果，而余数只有 0, 1, 2 三种。具体选了哪些数、选了多少个，都不影响最终判断。这是一种**状态压缩** — 用余数代替了完整的和。

**Q2: 如果题目变成"可被 k 整除"怎么办？**

直接把 dp 从 3 个状态扩展到 k 个即可。时间 O(nk)，空间 O(k)。

```cpp
vector<int> dp(k, INT_MIN);
dp[0] = 0;
for (int num : nums) {
    vector<int> temp = dp;
    for (int j = 0; j < k; j++) {
        int newR = (j + num % k) % k;
        dp[newR] = max(dp[newR], temp[j] + num);
    }
}
return dp[0];
```

**Q3: 如果要求恰好选 m 个数，怎么加维度？**

加一个维度：dp[j][r] = 选了 j 个数，余数为 r 时的最大和。

### 追问链2: 贪心证明

**Q4: 为什么 S%3==1 时只需考虑"减一个余1"和"减两个余2"两种方案？**

如果 S%3==1，要让 (S - removed) % 3 == 0，即 removed % 3 == 1。
- removed 可以由若干个数组成，但为了最大化剩余和，removed 应尽可能小
- 最小的 removed：一个余1的数（至少1个）或 两个余2的数（2+2 ≡ 1 mod 3）
- 三个余1的数 ≡ 0 mod 3，不行；一个余1 + 一个余2 ≡ 0 mod 3，不行
- 所以只有这两种最小选择

**Q5: 这道题的贪心和 DP 哪个更好写？**

DP 更好写也更不容易出错。贪心需要分类讨论 S%3 的三种情况，还要维护最小值，代码更复杂。DP 是通用方法，面试中推荐。

### 追问链3: 空间优化

**Q6: DP 解法的空间已经是 O(1) 了，还能怎么优化？**

空间已经是最优的了。但可以考虑**去掉临时数组**的写法（需要注意更新顺序）：

当 num%3 == 0 时，dp[j] = max(dp[j], dp[j] + num) 对所有 j，不会相互影响，可以直接原地更新。
当 num%3 != 0 时，三个状态的更新会交叉，必须用临时变量。
