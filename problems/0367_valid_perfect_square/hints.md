# 367. 有效的完全平方数

## 核心思路
本质上就是在 `[1, num]` 的整数范围内，找是否存在一个整数 `x` 使得 `x * x == num`。这是一个典型的**搜索问题**，而搜索空间是有序的，所以可以用二分查找。

## 思维链
1. **读完题第一反应**：从 1 开始一个一个试，`1*1, 2*2, 3*3, ...`，直到 `x*x >= num`，看是否等于 num。
2. **暴力解的瓶颈**：线性枚举需要 O(√n) 次，虽然已经不慢了，但能不能更快？
3. **观察搜索空间的结构**：`f(x) = x*x` 是单调递增函数！既然搜索空间有序，我们可以用**二分查找**把 O(√n) 降到 O(log n)。
4. **二分怎么用**：在 `[1, num]` 上二分，每次算 `mid*mid`，和 num 比较，就能排除一半的搜索空间。
5. **额外思路（数学）**：完全平方数还有个性质 — 它等于前 n 个奇数之和：`1 + 3 + 5 + ... + (2n-1) = n²`。不断减去递增的奇数，看最后是否恰好减到 0。

## 解法概览
| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 线性枚举 | 从1开始逐个试 x² | O(√n) | O(1) | 能说出即可 |
| 二分查找 | 在 [1, num] 上二分 | O(log n) | O(1) | ⭐ 必须写出 |
| 奇数求和（数学） | 利用 1+3+5+...=(n²) | O(√n) | O(1) | 加分项 |
| 牛顿迭代法 | 数值逼近求平方根 | O(log n) | O(1) | 加分项 |

## 关键提示
- **提示1**：不要想复杂了，`x*x == num` 就是在找一个特定的 x，搜索空间是 `[1, num]`。
- **提示2**：`mid * mid` 可能溢出 int！当 num 接近 2³¹-1 时，mid 大约在 46340 附近，`mid*mid` 大约 2×10⁹，刚好在 int 边界。用 `long long` 更安全。
- **提示3**：二分的右边界不需要是 num，可以是 `num/2 + 1`（因为当 num ≥ 4 时，√num ≤ num/2），但要特判 num=1。
- **提示4**：完全平方数 = 连续奇数之和，这是一个纯数学性质，面试中提到会加分。

## 解法详解

### 解法1: 线性枚举 — O(√n) / O(1)
**思考过程**: 最直觉的做法，从 x=1 开始，计算 x²，如果 x² < num 就继续，x² == num 就返回 true，x² > num 就返回 false。

```cpp
class Solution {
public:
    bool isPerfectSquare(int num) {
        // 从1开始逐个尝试，直到 x*x >= num
        long long x = 1;
        while (x * x < num) {
            x++;
        }
        return x * x == num;
    }
};
```
**关键点**: 用 `long long` 避免溢出。循环条件是 `<` 不是 `<=`，否则 num 本身是完全平方数时会多走一步。

---

### 解法2: 二分查找 — O(log n) / O(1) ⭐ 面试首选
**从解法1优化**: 解法1线性扫描搜索空间 [1, num]，但这个空间是有序的（x² 单调递增），所以可以二分查找，每次排除一半。

```
// 在 [1, 16] 中查找 x 使得 x*x == 16:
//
// Round1: left=1, right=16, mid=8  → 8*8=64 > 16  → right=7
// Round2: left=1, right=7,  mid=4  → 4*4=16 == 16  → 找到! return true
//
// 在 [1, 14] 中查找 x 使得 x*x == 14:
//
// Round1: left=1, right=14, mid=7  → 7*7=49 > 14  → right=6
// Round2: left=1, right=6,  mid=3  → 3*3=9  < 14  → left=4
// Round3: left=4, right=6,  mid=5  → 5*5=25 > 14  → right=4
// Round4: left=4, right=4,  mid=4  → 4*4=16 > 14  → right=3
// Round5: left=4, right=3  → left > right, 退出 → return false
```

```cpp
class Solution {
public:
    bool isPerfectSquare(int num) {
        long long left = 1, right = num;
        while (left <= right) {
            long long mid = left + (right - left) / 2;
            long long square = mid * mid;
            if (square == num) {
                return true;
            } else if (square < num) {
                left = mid + 1;   // mid 太小，答案在右半边
            } else {
                right = mid - 1;  // mid 太大，答案在左半边
            }
        }
        return false;  // 搜索空间耗尽，没找到
    }
};
```
**关键点**:
- 这里用 `left <= right` 模板（找确切值），因为我们要判断的是"是否存在"某个 x 使 x²==num。
- `mid * mid` 必须用 `long long`，否则 num 接近 INT_MAX 时溢出。

---

### 解法3: 奇数求和（数学性质） — O(√n) / O(1)
**思考过程**: 有一个数学事实：
```
1 = 1              = 1²
1 + 3 = 4          = 2²
1 + 3 + 5 = 9      = 3²
1 + 3 + 5 + 7 = 16 = 4²
...
前 n 个奇数之和 = n²
```
所以，如果 num 是完全平方数，从 num 中不断减去 1, 3, 5, 7, ...，最终会恰好减到 0。

```cpp
class Solution {
public:
    bool isPerfectSquare(int num) {
        int odd = 1;
        while (num > 0) {
            num -= odd;
            odd += 2;  // 下一个奇数
        }
        return num == 0;  // 恰好减到0说明是完全平方数
    }
};
```
**关键点**: 不会溢出，因为 num 一直在减小，odd 一直在增大，循环一定会终止。时间复杂度和线性枚举一样是 O(√n)，但代码更巧妙。

---

### 解法4: 牛顿迭代法 — O(log n) / O(1)
**思考过程**: 牛顿法是一种数值逼近方法，用来求 `f(x) = x² - num = 0` 的根。迭代公式：`x_{n+1} = (x_n + num / x_n) / 2`。收敛后检查 `x * x == num`。

```cpp
class Solution {
public:
    bool isPerfectSquare(int num) {
        long long x = num;
        // 牛顿迭代: x = (x + num/x) / 2，直到 x*x <= num
        while (x * x > num) {
            x = (x + num / x) / 2;
        }
        return x * x == num;
    }
};
```
**关键点**:
- 初始值选 num 本身（一定 ≥ √num），然后不断逼近。
- 整数除法天然向下取整，收敛后 x 就是 floor(√num)。
- 牛顿法收敛极快（二次收敛），实际迭代次数很少。

**选择建议**：面试首选二分查找，因为它展示了"在有序空间上高效搜索"的通用思维。奇数求和和牛顿法作为 follow-up 提一嘴即可。

## 易错点
- **✗ `mid * mid` 用 int**：当 num = 2147483647 时，mid 约为 10⁹，`mid*mid` 溢出 int。
  **✓** 用 `long long mid` 或者改用 `num / mid == mid && num % mid == 0`（但后者逻辑更复杂，不推荐）。

- **✗ 二分右边界写 `num/2`**：当 num = 1 时，`num/2 = 0`，搜索空间为空，返回 false（错误，1 是完全平方数）。
  **✓** 右边界写 `num`，或者写 `num/2 + 1` 并特判 `num == 1`。

- **✗ 牛顿法初始值选 `num/2`**：当 num = 1 时，初始值为 0，`num/x` 除零。
  **✓** 初始值选 `num` 本身。

## 面试追问
**Q1: 暴力法的时间复杂度是多少？能过吗？**
→ O(√n)，n 最大约 2×10⁹，√n ≈ 46340，完全能过。但面试官期望你用更高效的方法。

**Q2: 二分查找的搜索空间是什么？为什么能二分？**
→ 搜索空间是 [1, num]，因为 f(x) = x² 是单调递增函数，满足二分的前提条件。每次可以确定性地排除一半。

**Q3: 如果不让用乘法呢？（极端变体）**
→ 可以用奇数求和法（只用加减法），或者位运算模拟乘法。

**Q4: 这道题和 LeetCode 69 (Sqrt(x)) 有什么关系？**
→ 69 题求 floor(√x)，本题判断 √x 是否为整数。本质上是同一个二分框架，69 题返回 right，本题在二分过程中检查是否精确命中。

- **633. Sum of Square Numbers** — 判断 c = a² + b²，复用本题的"判断完全平方数"作为子过程，或用双指针。
