# 513. 找树左下角的值

## 核心思路

这道题本质上在问：**二叉树最后一层的第一个节点的值是什么？** 关键要拆成两步理解——"最底层"确定深度，"最左边"确定同层顺序。

## 思维链

1. **读完题第一反应**：需要找到"最深的那一层"的"最左边节点"。最直觉的方式就是层序遍历（BFS），因为 BFS 天然按层访问，最后一层的第一个就是答案。

2. **BFS 怎么做？** 逐层遍历，每层记录第一个节点的值。遍历完所有层后，最后记录的那个"第一个节点"就是最底层最左边的。

3. **能不能用 DFS？** 当然可以。DFS 遍历时带上深度参数，每次发现更深的层，就更新答案。关键观察：**如果先递归左子树再递归右子树，那么同一层中最先被访问到的就是最左边的节点**。所以当 `depth > maxDepth` 时更新答案，就能保证记录的是每一层最左边的。

4. **还有没有更巧妙的 BFS？** 有！从右往左遍历（先入右孩子再入左孩子），这样最后出队的节点就是最底层最左边的，代码更简洁。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| BFS 层序（从左到右） | 逐层遍历，记录每层第一个 | O(n) | O(n) | ⭐ 必须写出 |
| BFS（从右到左） | 先右后左入队，最后出队即答案 | O(n) | O(n) | 加分项 |
| DFS 先序遍历 | 带深度递归，首次到达新深度时更新 | O(n) | O(h) | ⭐ 必须写出 |

## 解法详解

### 解法1: BFS 层序遍历（从左到右） — O(n) / O(n) ⭐ 面试首选

**思考过程**：题目要"最底层最左边"，BFS 天然按层遍历。每一层从左到右访问，我们只需记录每层的第一个节点值。当 BFS 结束时，最后一次记录的值就是最底层最左边的。

```cpp
class Solution {
public:
    int findBottomLeftValue(TreeNode* root) {
        queue<TreeNode*> q;
        q.push(root);
        int result = root->val;
        
        while (!q.empty()) {
            int size = q.size();
            for (int i = 0; i < size; i++) {
                TreeNode* node = q.front();
                q.pop();
                // 每层第一个节点(i==0)就是该层最左边的
                if (i == 0) result = node->val;
                if (node->left)  q.push(node->left);
                if (node->right) q.push(node->right);
            }
        }
        return result;
    }
};
```

**关键点**：`i == 0` 确保只记录每层第一个节点。最终 `result` 保存的是最后一层的第一个，即答案。

---

### 解法2: BFS 从右到左遍历 — O(n) / O(n)

**从解法1优化**：解法1需要用 `size` 分层 + `i==0` 判断。换个思路：如果每层先入右孩子再入左孩子，那整棵树最后一个出队的节点就是最底层最左边的！代码更简洁。

```
BFS 从右到左入队过程（示例2）:
  队列变化:
  [1] → 弹出1, 入3,2 → [3,2]
  [3,2] → 弹出3, 入6,5 → [2,6,5]
  [2,6,5] → 弹出2, 入4 → [6,5,4]
  [6,5,4] → 弹出6(无子) → [5,4]
  [5,4] → 弹出5, 入7 → [4,7]
  [4,7] → 弹出4(无子) → [7]
  [7] → 弹出7(无子) → []
  最后弹出的是 7，即答案！
```

```cpp
class Solution {
public:
    int findBottomLeftValue(TreeNode* root) {
        queue<TreeNode*> q;
        q.push(root);
        TreeNode* node = nullptr;
        
        while (!q.empty()) {
            node = q.front();
            q.pop();
            // 关键：先右后左入队
            // 这样同一层中左边的节点会后出队
            // 最后一个出队的就是最底层最左边的
            if (node->right) q.push(node->right);
            if (node->left)  q.push(node->left);
        }
        return node->val; // 最后一个出队的节点
    }
};
```

**关键点**：不需要分层逻辑，不需要 `size` 变量，整体更简洁。核心思想是利用入队顺序让最底层最左边的节点最后出队。

---

### 解法3: DFS 先序遍历 — O(n) / O(h) ⭐ 面试首选

**不同角度**：不用 BFS，用 DFS 也能解。带一个 `depth` 参数递归，维护全局的 `maxDepth`。当首次到达一个更深的层时，更新答案。因为先递归左子树，所以同一深度中最先到达的一定是最左边的节点。

```
DFS 遍历过程（示例2）:
         1 (depth=0)
        / \
       2   3 (depth=1)
      /   / \
     4   5   6 (depth=2)
        /
       7 (depth=3)

遍历顺序: 1→2→4→3→5→7→6
  访问1: depth=0 > maxDepth=-1 → 更新 result=1, maxDepth=0
  访问2: depth=1 > maxDepth=0  → 更新 result=2, maxDepth=1
  访问4: depth=2 > maxDepth=1  → 更新 result=4, maxDepth=2
  访问3: depth=1 ≤ maxDepth=2  → 不更新
  访问5: depth=2 ≤ maxDepth=2  → 不更新
  访问7: depth=3 > maxDepth=2  → 更新 result=7, maxDepth=3 ✓
  访问6: depth=2 ≤ maxDepth=3  → 不更新
  
最终 result = 7
```

```cpp
class Solution {
public:
    int maxDepth = -1;
    int result = 0;
    
    int findBottomLeftValue(TreeNode* root) {
        dfs(root, 0);
        return result;
    }
    
    void dfs(TreeNode* node, int depth) {
        if (!node) return;
        
        // 首次到达更深的层 → 一定是该层最左边的
        // 因为我们先递归左子树，左边的节点先被访问
        if (depth > maxDepth) {
            maxDepth = depth;
            result = node->val;
        }
        
        dfs(node->left, depth + 1);   // 先左
        dfs(node->right, depth + 1);  // 后右
    }
};
```

**关键点**：
- 判断条件是 `>` 而不是 `>=`，因为只需要每层**第一个**到达的节点
- 先左后右的递归顺序保证了"最左边"这个条件
- 空间复杂度 O(h)，h 是树高。最坏 O(n)（退化成链表），平衡树 O(log n)，优于 BFS 的 O(n)

## 解法对比

| | BFS 从左到右 | BFS 从右到左 | DFS |
|---|---|---|---|
| 代码复杂度 | 中等（需要分层） | 最简洁 | 中等（递归+全局变量） |
| 空间 | O(n)（队列最大存一层） | O(n) | O(h)（递归栈） |
| 直觉性 | 最直觉 | 需要想到逆序技巧 | 需要理解"先左后右+首次更深" |
| 面试推荐 | ✅ 首选 | 加分项 | ✅ 追问DFS时必须会 |

**什么时候选哪个？**
- 面试中先写 BFS 从左到右，最安全最好解释
- 如果面试官追问"能不能 DFS？"，给出解法3
- 如果想展示技巧性，提一下解法2

## 易错点

1. **DFS 用 `>=` 而不是 `>`**
   - ✗ `if (depth >= maxDepth)` — 同一层后面的节点也会更新，结果可能不是"最左边"
   - ✓ `if (depth > maxDepth)` — 只在首次到达更深层时更新，保证是最左边

2. **DFS 先递归右子树**
   - ✗ `dfs(node->right, ...); dfs(node->left, ...);` — 同深度中右边的先被访问，结果是"最右边"
   - ✓ `dfs(node->left, ...); dfs(node->right, ...);` — 左边先访问，首次更深的一定在最左

3. **BFS 从右到左忘记最后判空**
   - ✗ 如果 root 为 nullptr 就直接 `node->val` 会崩（但本题保证至少一个节点）
   - ✓ 养成好习惯，面试中可以先说明假设条件

4. **BFS 分层时漏掉 `size` 变量**
   - ✗ 直接用 `q.size()` 做循环条件 — 队列大小在循环中会变化！
   - ✓ `int size = q.size();` 先存下来再循环

## 面试追问

**Q1: 这道题最直觉的做法是什么？时间空间多少？**
→ BFS 层序遍历，每层记录第一个节点，O(n)/O(n)。

**Q2: 能不能用 DFS？空间能否比 BFS 更优？**
→ 可以。DFS 带深度参数，先左后右递归，首次到达更深层时更新答案。空间 O(h)，对于平衡树是 O(log n)，优于 BFS 的 O(n)。

**Q3: 如果要找的不是最底层最左边，而是最底层最右边呢？**
→ BFS：记录每层最后一个节点（`i == size-1`），或从左到右入队取最后出队的。
→ DFS：改成先递归右子树，或保持先左后右但条件改为 `>=`。

**Q4: 如果同时要返回最底层最左边节点的值和它的深度呢？**
→ BFS：用层数计数器；DFS：`maxDepth` 本身就记录了深度。
