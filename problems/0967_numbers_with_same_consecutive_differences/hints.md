# LeetCode 967 - Numbers With Same Consecutive Differences

## 核心思路

从高位到低位逐位构建数字。第一位数字从 1-9 中选（避免前导零），之后每一位数字必须与前一位的差的绝对值恰好为 k。使用 BFS 或 DFS/回溯逐位扩展，每次从当前末位数字 d 出发，尝试 d+k 和 d-k 作为下一位（需在 0-9 范围内）。当数字长度达到 n 时收集结果。

## 思维链

1. **分析约束** - n 位数字，相邻两位差的绝对值为 k。第一位不能是 0（n >= 2）。
2. **构建思路** - 不需要枚举所有 n 位数再验证，而是逐位构建。每一位只有最多 2 个选择（+k 或 -k），效率很高。
3. **BFS 方法** - 初始化一组种子数字 {1, 2, ..., 9}（一位数），每一步对每个数字追加一位有效数字。重复 n-1 次得到 n 位数。
4. **DFS/回溯方法** - 从每个首位数字开始，递归地选择下一位，直到达到 n 位。
5. **特殊情况** - k = 0 时，+k 和 -k 是同一个数字，避免重复添加。
6. **数字范围** - n 最大为 9，所以结果都在 int 范围内。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|----------|----------|------|
| BFS 逐层扩展 | O(2^n) | O(2^n) | 迭代，直观 |
| DFS/回溯 | O(2^n) | O(n) 递归栈 | 递归，代码简洁 |
| 迭代构建 | O(2^n) | O(2^n) | 不用递归的 DFS |

实际上每一位最多 2 个选择，n 最大 9，总结果数不超过 9 * 2^8 = 2304。

## 关键提示

1. 首位数字范围是 1-9（不允许前导零），后续位 0-9。
2. 每一位有最多两个候选：当前末位 + k 和 当前末位 - k。
3. 候选数字必须在 [0, 9] 范围内。
4. 当 k = 0 时，d + k == d - k，只添加一次避免重复。
5. 构建数字时用 num = num * 10 + nextDigit 逐位追加。
6. n = 1 时特殊处理：结果是 0-9 所有一位数（但题目约束 n >= 2）。

## 解法详解

### 解法一：BFS 逐层扩展（推荐）

**思路**：从所有一位数 {1, 2, ..., 9} 开始，逐层向后追加一位数字，直到长度为 n。

**算法**：
1. 初始化当前层 cur = {1, 2, 3, 4, 5, 6, 7, 8, 9}
2. 重复 n - 1 次：
   a. 创建新列表 next
   b. 对于 cur 中的每个数字 num：
      - 取末位 d = num % 10
      - 如果 d + k <= 9，将 num * 10 + (d + k) 加入 next
      - 如果 k != 0 且 d - k >= 0，将 num * 10 + (d - k) 加入 next
   c. cur = next
3. 返回 cur

**为什么 BFS 合适？** 因为所有目标数字长度相同（都是 n 位），BFS 天然地按层处理，层数就是位数。

### 解法二：DFS/回溯

**思路**：对于每个首位数字 1-9，递归地构建完整的 n 位数字。

递归函数 `dfs(num, remaining)`：
- 如果 remaining == 0，将 num 加入结果
- 否则取末位 d = num % 10，尝试 d+k 和 d-k

**优势**：空间只需 O(n) 递归栈（加上结果数组）。

### 解法三：迭代 DFS（栈模拟）

和解法二逻辑相同，但用显式栈替代递归。栈中存储 (当前数字, 剩余位数) 的 pair。

### 复杂度分析

每一位最多两个分支（当 k != 0 且两个候选都在 [0,9] 内时）。n 位数字树的最大节点数为 9 * 2^(n-1)。n 最大为 9，所以最多 9 * 256 = 2304 个结果，非常小。

## 易错点

1. **k = 0 时重复** - d + 0 == d - 0，如果不特判会每个数字添加两次。必须检查 k != 0 才尝试 d - k。
2. **首位不能为 0** - BFS 初始集合从 1 开始，DFS 循环从 1 开始，不包括 0。
3. **候选数字越界** - d + k 可能大于 9，d - k 可能小于 0，必须检查范围。
4. **n = 1 的情况** - 如果 n = 1（虽然题目约束 n >= 2），结果应该是 0-9。BFS 方法需要特殊处理初始集合包含 0。
5. **数字追加方式** - 用 num * 10 + digit 而不是字符串拼接，效率更高且结果类型直接是 int。
6. **结果无需排序** - 题目说可以按任何顺序返回。

## 面试追问

1. **如果 n 可以非常大（比如 100 位），怎么处理？** - 数字用字符串表示避免溢出。BFS/DFS 逻辑不变，但不能用 int 存储。
2. **如何计算满足条件的数字个数而不列举？** - 用 DP：dp[位数][末位数字] 表示方案数。转移：dp[i][d] = sum(dp[i-1][d'] for d' where |d-d'| == k)。
3. **如果约束改为"差的绝对值不超过 k"怎么办？** - 每一位的候选从最多 2 个变成最多 2k+1 个，BFS/DFS 的分支增加。
4. **如果要按升序返回所有结果？** - BFS 天然按首位排序（因为 1-9 有序），但同首位的数字顺序取决于扩展顺序。可以最后排序。
5. **BFS 和 DFS 在这题中哪个更好？** - BFS 代码更直观，DFS 栈空间更小。实际差异极小（n <= 9）。
