# 91. 解码方法 (Decode Ways)

## 难度: Medium | 标签: String, Dynamic Programming

---

## 核心思路

类似爬楼梯问题，但增加了**合法性约束**。`dp[i]` 表示解码 `s[0..i-1]` 的方法数。每步可以取 1 位或 2 位数字进行解码，但必须满足合法条件：
- 1 位解码：`s[i-1] != '0'`（'0' 不能单独解码）
- 2 位解码：两位数在 `10-26` 范围内（不能有前导零，且不超过 26）

---

## 思维链

1. **读完题第一反应**：字符串分割问题，每步可以切 1 位或 2 位。和爬楼梯一样，每步走 1 阶或 2 阶。自然想到 DP。

2. **状态定义**：`dp[i]` = 解码 `s` 的前 `i` 个字符的方法数。

3. **转移方程**：
   - 如果 `s[i-1] != '0'`：单字符合法，`dp[i] += dp[i-1]`
   - 如果 `s[i-2..i-1]` 组成的两位数在 `10-26`：双字符合法，`dp[i] += dp[i-2]`

4. **为什么不是 1-26 而是 10-26？**
   - 两位数 "01"-"09" 有前导零，不是合法编码
   - 合法的两位编码只有 "10"-"26"

5. **初始化**：
   - `dp[0] = 1`：空字符串有 1 种"解码"（什么都不做）。这是 DP 的基准值。
   - `dp[1]`：如果 `s[0] != '0'` 则 1，否则 0。

6. **空间优化**：`dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`，可以用两个变量替代数组。

---

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 推荐 |
|------|------|------|------|------|
| ⭐ 解法1: 一维 DP | dp 数组 | O(n) | O(n) | 首选（清晰） |
| 解法2: 空间优化 DP | 两个变量 | O(n) | O(1) | 进阶（最优） |
| 解法3: 递归 + 记忆化 | 自顶向下 | O(n) | O(n) | 理解用 |

---

## 关键提示

- **提示1 (入门)**：这道题和爬楼梯几乎一样——每步可以走 1 步或 2 步，只是增加了"某些步不能走"的限制。

- **提示2 (核心约束)**：'0' 不能单独解码！`s[i]='0'` 时，`dp[i+1]` 不能从 `dp[i]` 转移。它只能作为两位数的第二位（如 "10", "20"）。

- **提示3 (两位数范围)**：不是 1-26，而是 **10-26**。"01"-"09" 有前导零，不是合法的两位编码。

- **提示4 (dp[0] = 1)**：空字符串的 `dp[0] = 1` 不是"有一种解码"，而是 DP 的**数学基准**，使得 `dp[2] += dp[0]` 能正确累加。

- **提示5 ('0' 陷阱)**：`s = "06"` → 0 不能单独解码，"06" 不是合法两位数 → dp[2] = 0 → 无法解码。

---

## 解法详解

### DP 状态表（s = "226"）

```
下标 i:    0    1    2    3
s[i-1]:         '2'  '2'  '6'
dp[i]:     1    1    2    3

详细推导:
dp[0] = 1  (空串基准)

dp[1]: s[0]='2' != '0' → dp[1] += dp[0] = 1
       (只有一种: "2"→B)

dp[2]: s[1]='2' != '0' → dp[2] += dp[1] = 1   (单字符 "2")
       s[0..1]="22", 10<=22<=26 → dp[2] += dp[0] = 1  (双字符 "22")
       dp[2] = 2  ("2,2"→BB 或 "22"→V)

dp[3]: s[2]='6' != '0' → dp[3] += dp[2] = 2   (单字符 "6")
       s[1..2]="26", 10<=26<=26 → dp[3] += dp[1] = 1  (双字符 "26")
       dp[3] = 3  ("2,2,6"→BBF, "22,6"→VF, "2,26"→BZ)
```

### DP 状态表（s = "1206"）

```
下标 i:    0    1    2    3    4
s[i-1]:         '1'  '2'  '0'  '6'
dp[i]:     1    1    2    1    1

dp[3]: s[2]='0' → 不能单独解码, dp[3] 不从 dp[2] 转移
       s[1..2]="20", 10<=20<=26 → dp[3] += dp[1] = 1
       dp[3] = 1 ("1,20,...")

dp[4]: s[3]='6' != '0' → dp[4] += dp[3] = 1
       s[2..3]="06", 06<10 → 不合法, 不转移
       dp[4] = 1 ("1,20,6"→ATF)
```

### DP 状态表（s = "06"）

```
下标 i:    0    1    2
s[i-1]:         '0'  '6'
dp[i]:     1    0    0

dp[1]: s[0]='0' → 不能单独解码, dp[1] = 0
dp[2]: s[1]='6' != '0' → dp[2] += dp[1] = 0
       s[0..1]="06", 06<10 → 不合法
       dp[2] = 0 → 无法解码!
```

---

### 解法1: 一维 DP (推荐)

**思考过程**：
> "`dp[i]` 代表前 i 个字符的解码方法数。每个位置检查两种可能：取 1 位（单字符须非 '0'）或取 2 位（须在 10-26）。dp[0]=1 是空串基准。"

```cpp
// 解法1: 一维 DP — O(n) / O(n)
// dp[i]: 解码 s[0..i-1] 的方法数
// 转移:
//   s[i-1] != '0' → dp[i] += dp[i-1]  (单字符解码)
//   10 <= s[i-2..i-1] <= 26 → dp[i] += dp[i-2]  (双字符解码)
class Solution {
public:
    int numDecodings(string s) {
        int n = s.size();
        vector<int> dp(n + 1, 0);
        dp[0] = 1;  // 空串基准

        for (int i = 1; i <= n; i++) {
            // 单字符解码: s[i-1] 不能是 '0'
            if (s[i-1] != '0') {
                dp[i] += dp[i-1];
            }
            // 双字符解码: 两位数必须在 10-26 范围
            if (i >= 2) {
                int two = (s[i-2] - '0') * 10 + (s[i-1] - '0');
                if (two >= 10 && two <= 26) {
                    dp[i] += dp[i-2];
                }
            }
        }
        return dp[n];
    }
};
```

**关键点**：
- `dp[0] = 1` 是数学基准，不是"空串有一种解码"
- 单字符：检查 `s[i-1] != '0'`
- 双字符：检查 `10 <= two <= 26`（不是 `1 <= two <= 26`，因为 "06" 不合法）
- 用 `(s[i-2]-'0')*10 + (s[i-1]-'0')` 避免 `stoi(substr)` 的开销

---

### 解法2: O(1) 空间优化 (最优)

**思考过程**：
> "`dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`。用两个变量 `prev1`、`prev2` 替代数组即可。就像斐波那契数列的空间优化。"

```cpp
// 解法2: 空间优化 DP — O(n) / O(1)
// prev2 = dp[i-2], prev1 = dp[i-1]
// 只用两个变量滚动更新
class Solution {
public:
    int numDecodings(string s) {
        if (s[0] == '0') return 0;  // 首字符为 '0', 无法解码

        int prev2 = 1;  // dp[0] = 1 (空串基准)
        int prev1 = 1;  // dp[1] = 1 (s[0] != '0' 已检查)

        for (int i = 2; i <= (int)s.size(); i++) {
            int curr = 0;
            // 单字符解码
            if (s[i-1] != '0') {
                curr += prev1;
            }
            // 双字符解码
            int two = (s[i-2] - '0') * 10 + (s[i-1] - '0');
            if (two >= 10 && two <= 26) {
                curr += prev2;
            }
            // 滚动更新
            prev2 = prev1;
            prev1 = curr;
        }
        return prev1;
    }
};
```

**关键点**：
- 先检查 `s[0] == '0'`，避免 `prev1` 初始化错误
- `prev2` 对应 `dp[i-2]`，`prev1` 对应 `dp[i-1]`
- 滚动更新顺序：先算 `curr`，再更新 `prev2 = prev1`，`prev1 = curr`
- 和爬楼梯的空间优化完全相同

---

### 解法3: 递归 + 记忆化

**思考过程**：
> "自顶向下思考：从位置 idx 开始，可以取 1 位或 2 位。用 memo 避免重复计算。"

```cpp
// 解法3: 递归 + 记忆化 — O(n) / O(n)
class Solution {
public:
    int numDecodings(string s) {
        vector<int> memo(s.size(), -1);
        return dfs(s, 0, memo);
    }

private:
    int dfs(const string& s, int idx, vector<int>& memo) {
        if (idx == (int)s.size()) return 1;  // 成功解码到末尾
        if (s[idx] == '0') return 0;          // '0' 开头无法解码
        if (memo[idx] != -1) return memo[idx];

        // 取 1 位
        int ways = dfs(s, idx + 1, memo);
        // 取 2 位
        if (idx + 1 < (int)s.size()) {
            int two = (s[idx] - '0') * 10 + (s[idx+1] - '0');
            if (two <= 26) {
                ways += dfs(s, idx + 2, memo);
            }
        }
        return memo[idx] = ways;
    }
};
```

**关键点**：
- 递归终止：`idx == n` 返回 1（成功解码完）
- `s[idx] == '0'` 返回 0（当前位是 '0' 无法继续）
- 取 2 位时只需检查 `two <= 26`（因为 `s[idx] != '0'` 已保证 `two >= 10`）
- `memo` 避免指数级重复计算

## 易错点

1. **'0' 不能单独解码**
   ```cpp
   // 错误: 不检查 '0'
   dp[i] += dp[i-1];  // s[i-1]='0' 时也加了
   // 正确: 必须检查
   if (s[i-1] != '0') dp[i] += dp[i-1];
   ```

2. **两位数范围错误 (1-26 vs 10-26)**
   ```cpp
   // 错误: 允许前导零
   if (two >= 1 && two <= 26) dp[i] += dp[i-2];
   // "06" 的 two=6, 1<=6<=26 → 错误地认为合法
   // 正确: 排除前导零
   if (two >= 10 && two <= 26) dp[i] += dp[i-2];
   ```

3. **dp[0] = 0 而非 1**
   ```cpp
   // 错误: dp[0] = 0 (认为空串0种解码)
   // 导致 dp[2] 无法正确累加 dp[0]
   // 正确: dp[0] = 1 是 DP 的数学基准
   ```

4. **空间优化时初始化 prev1 错误**
   ```cpp
   // 错误: 没检查 s[0] 就设 prev1=1
   int prev1 = 1;  // 如果 s[0]=='0', 应该是 0!
   // 正确: 先检查
   if (s[0] == '0') return 0;
   int prev1 = 1;
   ```

5. **混淆下标**
   ```cpp
   // dp[i] 对应 s[0..i-1], 所以:
   // 单字符: s[i-1] (不是 s[i])
   // 双字符: s[i-2..i-1] (不是 s[i-1..i])
   ```

6. **"30" 被当作合法两位数**
   ```cpp
   // two = 30, 30 > 26 → 不合法 ✓
   // 但 "30" 的 '0' 也不能单独解码 → dp[2] = 0
   // 需要两个条件都正确检查
   ```

## 面试追问

1. **"如果有 '*' 通配符代表 1-9？"**
   - 即 LC 639 Decode Ways II。
   - '*' 单独解码有 9 种（'1'-'9'），双字符解码需分类讨论。
   - 结果要取模 10^9 + 7。

2. **"输出所有解码方案而非计数？"**
   - 回溯法：从位置 0 开始，每步尝试取 1 位或 2 位，合法时递归。
   - 到达末尾时记录一条方案。

3. **"空间优化的思路？"**
   - `dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`，和斐波那契一样，用两个变量滚动。
   - 即解法2。

4. **"和爬楼梯的关系？"**
   - 爬楼梯：`dp[i] = dp[i-1] + dp[i-2]`，无条件限制。
   - 解码方法：同样的转移，但加了合法性约束（'0' 和 10-26 范围）。
   - 核心结构相同，解码方法是"有约束的爬楼梯"。

5. **"如果字符串很长（10^6），有问题吗？"**
   - 解法2 O(1) 空间，无问题。
   - 注意 int 溢出——题目保证答案在 32-bit 范围内，所以安全。
   - 如果担心中间值溢出，可以用 long long。

6. **"能否用矩阵快速幂优化？"**
   - 理论上可以：转移方程是线性递推，可以用矩阵快速幂做到 O(log n)。
   - 但因为转移系数不是常数（取决于当前字符），不能直接套用。需要每步构造不同的转移矩阵，失去了快速幂的意义。
