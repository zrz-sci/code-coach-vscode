# 231. 2 的幂

## 核心思路

2 的幂在二进制中只有一个 `1` 位（如 `1=1, 2=10, 4=100, 8=1000`）。利用位运算 `n & (n-1)` 可以消除最低位的 1——如果消除后变成 0，说明原来只有一个 1，即为 2 的幂。前提是 n 必须为正数。

## 思维链

1. **理解 2 的幂的本质**：二进制表示中恰好只有一个 `1` 位
2. **排除非正数**：0 和负数不可能是 2 的幂
3. **选择判断方法**：位运算 `n & (n-1)` 或 `n & (-n)`
4. **理解 `n & (n-1)` 的含义**：消除 n 最低位的 1
5. **验证**：若消除后为 0，则 n 只有一个 1 位 -> 是 2 的幂

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 推荐度 | 特点 |
|------|-----------|-----------|--------|------|
| n & (n-1) | O(1) | O(1) | ⭐⭐⭐⭐⭐ | 最经典的位运算技巧 |
| n & (-n) | O(1) | O(1) | ⭐⭐⭐⭐ | lowbit 思想 |
| 循环除 2 | O(log n) | O(1) | ⭐⭐⭐ | 直觉简单但非最优 |

## 关键提示

```
位运算核心原理:

n = 8:   1000        n = 12:  1100
n-1 = 7: 0111        n-1= 11: 1011
n&(n-1): 0000 = 0    n&(n-1): 1000 != 0
-> 是 2 的幂 ✓        -> 不是 2 的幂 ✗

n & (n-1) 的作用: 消除最低位的 1
  n   = ...1000...0    (最低位的1及其后面全是0)
  n-1 = ...0111...1    (最低位的1变0，后面全变1)
  &   = ...0000...0    (最低位的1被消除)

若 n 是 2 的幂 (只有一个1):
  消除后 = 0    ✓
若 n 不是 2 的幂 (多个1):
  消除后 != 0   ✗

lowbit: n & (-n) 提取最低位的 1
  若 n & (-n) == n，说明 n 只有一个 1 位
  n = 8:  1000, -n = ...11000 (补码), n&(-n) = 1000 == n ✓
  n = 12: 1100, -n = ...10100 (补码), n&(-n) = 0100 != n ✗
```

## 解法详解

### 解法1: n & (n-1)

**核心思想**：`n & (n-1)` 消除最低位的 1。2 的幂只有一个 1，消除后结果为 0。

```cpp
class Solution {
public:
    bool isPowerOfTwo(int n) {
        return n > 0 && (n & (n - 1)) == 0;
    }
};
```

**复杂度**：时间 O(1)，空间 O(1)

### 解法2: n & (-n) — lowbit

**核心思想**：`n & (-n)` 提取最低位的 1。若提取出的值等于 n 本身，说明只有一个 1 位。

```cpp
class Solution {
public:
    bool isPowerOfTwo(int n) {
        return n > 0 && (n & (-n)) == n;
    }
};
```

**复杂度**：时间 O(1)，空间 O(1)

### 解法3: 循环除 2

**核心思想**：反复除以 2，如果最终能变成 1 则是 2 的幂。

```cpp
class Solution {
public:
    bool isPowerOfTwo(int n) {
        if (n <= 0) return false;
        while (n % 2 == 0) {
            n /= 2;
        }
        return n == 1;
    }
};
```

**复杂度**：时间 O(log n)，空间 O(1)

## 易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| ✗ `return (n & (n-1)) == 0;` | ✓ `return n > 0 && (n & (n-1)) == 0;` | n=0 时 0&(-1)=0 也满足，但 0 不是 2 的幂 |
| ✗ 不考虑负数 | ✓ 先判断 `n > 0` | 负数不可能是 2 的幂 |
| ✗ `n & (n-1) == 0` (运算符优先级) | ✓ `(n & (n-1)) == 0` (加括号) | `==` 优先级高于 `&`，不加括号逻辑错误 |
| ✗ 用 `__builtin_popcount` | ✓ 面试中用 `n & (n-1)` | popcount 是编译器扩展，面试可能不被认可 |

## 面试追问

**Q1: `n & (n-1)` 还有什么应用？**
→ 统计二进制中 1 的个数（LC 191 Hamming Weight）：循环执行 `n = n & (n-1)` 直到 n=0，执行次数就是 1 的个数。

**Q2: 如何判断 n 是否是 4 的幂？**
→ 首先是 2 的幂，其次 1 只出现在奇数位：`n > 0 && (n & (n-1)) == 0 && (n & 0x55555555) != 0`。

**Q3: 如何不用循环/递归判断 3 的幂（LC 326）？**
→ 利用 int 范围内最大的 3 的幂 `3^19 = 1162261467`，若 `1162261467 % n == 0` 则 n 是 3 的幂。这个技巧只对质数底数有效。
