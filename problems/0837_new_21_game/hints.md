# 837. New 21 Game - 提示与解析

## 核心思路

本题本质上是一个概率DP问题。定义 `dp[x]` 为最终得分恰好为x的概率。Alice从0开始，每次从 [1, maxPts] 中等概率抽取一个数。当总分 >= k 时停止。我们需要计算最终得分 <= n 的概率。关键优化是用**滑动窗口**维护 dp 值的前缀和，将转移从O(maxPts)优化到O(1)。

## 思维链

1. **定义状态**：`dp[x]` = 最终得分恰好为x的概率
2. **转移方程**：`dp[x] = (dp[x-1] + dp[x-2] + ... + dp[x-maxPts]) / maxPts`（当x < k时）
3. **当 x >= k 时**：Alice已停止抽牌，不再转移，dp[x]直接由之前的状态确定
4. **滑动窗口优化**：维护一个窗口和 `windowSum`，每次移动窗口时加一个减一个
5. **最终答案**：`sum(dp[k] + dp[k+1] + ... + dp[n])`
6. **边界处理**：k=0时答案为1.0；n >= k+maxPts-1时答案也为1.0

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 推荐度 | 说明 |
|------|-----------|-----------|--------|------|
| 滑动窗口DP | O(n) | O(n) | ⭐⭐⭐⭐⭐ | 最优解，窗口维护概率和 |
| 朴素DP | O(n * maxPts) | O(n) | ⭐⭐⭐ | 直接枚举转移，超时风险 |
| 数学公式 | O(n) | O(n) | ⭐⭐⭐ | 复杂的组合数学推导 |

## 关键提示

1. **dp[0] = 1.0**：初始得分为0的概率是1
2. **只有 dp[0] 到 dp[k-1] 会参与转移**：因为得分达到k后就停止了
3. **dp[x] 的转移范围**：只能从 dp[max(0, x-maxPts)] 到 dp[min(k-1, x-1)] 转移
4. **滑动窗口的含义**：维护的窗口是"当前还在抽牌的状态的概率和"
5. **特殊情况**：k=0时Alice不抽牌，得分0 <= n必定成立

## 解法详解

### 解法一：滑动窗口DP ⭐⭐⭐⭐⭐

**核心转移：**
- 对于 x < k：`dp[x] = windowSum / maxPts`，其中 windowSum 是 dp[x-maxPts] 到 dp[x-1] 的和
- 对于 x >= k：dp[x] 也由窗口中 < k 的部分贡献

**窗口维护：**
- 初始 windowSum = dp[0] = 1.0
- 每步 x：先计算 `dp[x] = windowSum / maxPts`
- 如果 x < k，将 dp[x] 加入窗口（因为x还在抽牌范围内）
- 如果窗口大小超过 maxPts，减去滑出的 dp[x - maxPts]

**最终答案**是 dp[k] + dp[k+1] + ... + dp[n] 的总和。

### 解法二：朴素DP ⭐⭐⭐

直接对每个状态x，枚举从 x-maxPts 到 x-1 的所有状态进行转移。时间复杂度 O(n * maxPts)，当 n 和 maxPts 都很大时会超时。

### 关键数学推导

为什么窗口只包含 < k 的状态？因为一旦得分 >= k，Alice就停止抽牌了。所以只有得分在 [0, k-1] 范围内的状态会"继续抽牌"，对后续状态有贡献。

## 易错点

1. **窗口大小不是固定的**：在 x < maxPts 时窗口逐渐增大，之后才固定为 maxPts
2. **k=0 的特殊处理**：如果k=0，Alice不抽牌，答案直接为1.0
3. **n >= k + maxPts - 1 的优化**：此时所有可能的最终得分都 <= n，答案为1.0
4. **浮点精度**：不要累积除法误差，windowSum 用 double 维护
5. **dp[x] 对窗口的贡献**：只有 x < k 的 dp[x] 才加入窗口和（因为 >= k 停止抽牌）
6. **转移来源的上界是 min(k-1, x-1)**：不是 x-1，因为 >= k 的状态不抽牌

## 面试追问

1. **为什么不能用 dp[x] = dp[x-1] + dp[x-1] 类似的递推？** - 因为转移来源不止前一个，而是前maxPts个
2. **如果每次抽取的概率不均等怎么办？** - 无法用简单滑动窗口，需要加权前缀和或其他方法
3. **如果maxPts很大而n很小，如何优化？** - 窗口实际大小为 min(maxPts, x)，不影响O(n)
4. **如何验证答案的正确性？** - 所有 dp[k] 到 dp[k+maxPts-1] 之和应等于1.0（概率总和）
5. **这道题和赌徒破产问题有什么关系？** - 都是概率DP，但状态转移结构不同
6. **能否改为自顶向下的记忆化搜索？** - 可以，但需要注意边界和缓存
