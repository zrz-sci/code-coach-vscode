# 546. 移除盒子

## 核心思路

三维区间 DP：`dp[i][j][k]` 表示移除 `boxes[i..j]` 且 `boxes[i]` 前面已经累积了 k 个与 `boxes[i]` 同色的盒子时，能获得的最大积分。关键在于"将同色盒子攒在一起再一次性消除"能获得更高分数（因为得分是 k^2）。

## 思维链

1. **读完题第一反应**：每次移除一段连续同色盒子，得 k^2 分。要最大化总分。贪心不行（先消哪段会影响后续的合并），需要搜索所有可能。

2. **尝试二维 DP**：`dp[i][j]` = 移除 `boxes[i..j]` 的最大分数？不够！因为 `boxes[i]` 左边可能还有同色的盒子等着一起消除，而这些信息在 `[i..j]` 里体现不出来。

3. **关键洞察**：得分是 k^2，所以 (k+1)^2 > k^2 + 1。把同色盒子攒在一起消除比分开消除划算。我们需要记录"当前段左边已经有多少个同色盒子在等待合并"。

4. **三维状态定义**：`dp[i][j][k]` = 移除 `boxes[i..j]`，且 `boxes[i]` 左边已有 k 个与它同色的盒子（这些盒子会和 `boxes[i]` 一起消除）时的最大分数。

5. **状态转移**：
   - 选择 1：直接把 `boxes[i]` 连同它左边的 k 个一起消除，得 (k+1)^2 + dp[i+1][j][0]
   - 选择 2：在 `[i+1, j]` 中找某个 m 使得 `boxes[m] == boxes[i]`，先消掉 `[i+1, m-1]`，让 `boxes[m]` 和前面的 k+1 个同色盒子合并

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 三维区间 DP（记忆化） | dp[i][j][k] 带记忆化搜索 | O(n^4) | O(n^3) | ⭐ 必须掌握 |
| 三维区间 DP（自底向上） | 自底向上填表 | O(n^4) | O(n^3) | 理解即可 |

## 关键提示

- **提示 1**：为什么二维 DP 不够？因为 `boxes[i]` 可能要和它左边（不在 `[i,j]` 范围内）的同色盒子一起消除。需要额外维度 k 记录"左边已有几个同色的在等待"。

- **提示 2**：状态转移的两种选择：
  - 立即消除 `boxes[i]`（连同左边的 k 个）：得 `(k+1)^2 + dp[i+1][j][0]`
  - 跳过中间段，找 `boxes[m] == boxes[i]`：得 `dp[i+1][m-1][0] + dp[m][j][k+1]`

- **提示 3**：`dp[m][j][k+1]` 的含义 —— 把 `boxes[i]` 和它左边的 k 个"传递"给 `boxes[m]`，相当于 `boxes[m]` 左边现在有 k+1 个同色等待合并。

- **提示 4（ASCII 图解）**：
```
// boxes = [1, 3, 2, 2, 2, 3, 4, 3, 1]
//
// 考虑 dp[0][8][0]，即移除整个数组，boxes[0]=1
// 选择1: 直接消 boxes[0]=1，得 1 + dp[1][8][0]
// 选择2: 找到 boxes[8]=1 == boxes[0]
//        先消 boxes[1..7]（dp[1][7][0]），
//        然后 boxes[8] 前面有 1 个同色 → dp[8][8][1]
//        dp[8][8][1] = (1+1)^2 = 4
```

- **提示 5**：n <= 100，所以 O(n^4) 时间和 O(n^3) 空间是可接受的。

## 解法详解

### 解法 1: 三维区间 DP（记忆化搜索）-- O(n^4) / O(n^3) ⭐ 面试首选

**思考过程**：自顶向下记忆化搜索，定义 `dfs(i, j, k)` 表示移除 `boxes[i..j]` 且 `boxes[i]` 左边已有 k 个同色盒子时的最大分数。

```cpp
class Solution {
public:
    int dp[100][100][100];
    
    int removeBoxes(vector<int>& boxes) {
        memset(dp, 0, sizeof(dp));
        return dfs(boxes, 0, boxes.size() - 1, 0);
    }
    
    int dfs(vector<int>& boxes, int i, int j, int k) {
        if (i > j) return 0;
        if (dp[i][j][k]) return dp[i][j][k];
        
        // 优化：合并 boxes[i] 开头的连续同色段
        int i0 = i, k0 = k;
        while (i + 1 <= j && boxes[i + 1] == boxes[i]) {
            i++; k++;
        }
        
        // 选择1: 直接消除 boxes[i0..i] 连同左边的 k0 个
        int res = (k + 1) * (k + 1) + dfs(boxes, i + 1, j, 0);
        
        // 选择2: 在 [i+1, j] 中找 boxes[m] == boxes[i] 的位置
        for (int m = i + 1; m <= j; m++) {
            if (boxes[m] == boxes[i]) {
                res = max(res, dfs(boxes, i + 1, m - 1, 0) + dfs(boxes, m, j, k + 1));
            }
        }
        
        dp[i0][j][k0] = res;
        return res;
    }
};
```

**关键点**：
- `dp[i][j][k]` 三个维度：左端点 i，右端点 j，左边已累积的同色数 k
- 连续同色段的优化：将 `boxes[i]` 开头的连续同色段一起处理
- 状态转移的核心：要么立即消，要么跳过中间找同色合并

### 解法 2: 自底向上填表 -- O(n^4) / O(n^3)

**思考过程**：自底向上枚举区间长度，从小区间逐步扩展。

```cpp
class Solution {
public:
    int removeBoxes(vector<int>& boxes) {
        int n = boxes.size();
        int dp[100][100][100] = {};
        
        // 基础情况：单个元素
        for (int i = 0; i < n; i++) {
            for (int k = 0; k <= i; k++) {
                dp[i][i][k] = (k + 1) * (k + 1);
            }
        }
        
        // 枚举区间长度
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                for (int k = 0; k <= i; k++) {
                    // 直接消除 boxes[i]
                    dp[i][j][k] = (k + 1) * (k + 1) + dp[i + 1][j][0];
                    // 找同色合并
                    for (int m = i + 1; m <= j; m++) {
                        if (boxes[m] == boxes[i]) {
                            dp[i][j][k] = max(dp[i][j][k],
                                dp[i + 1][m - 1][0] + dp[m][j][k + 1]);
                        }
                    }
                }
            }
        }
        
        return dp[0][n - 1][0];
    }
};
```

## 易错点

1. **✗ 用二维 dp[i][j] 定义状态**：丢失了"左边有多少同色盒子在等待"的信息。
   **✓ 必须三维 dp[i][j][k]**，k 记录左侧已累积的同色数量。

2. **✗ 状态转移时忘了 `dp[m][j][k+1]` 中的 k+1**：把 k 写成 0 或 1。
   **✓ 是 k+1**，因为 `boxes[i]` 和它左边的 k 个都"传递"给了 `boxes[m]`。

3. **✗ 没有处理连续同色段优化**：每次只看 `boxes[i]` 一个元素。
   **✓ 先合并 `boxes[i]` 开头的连续同色段**，可以显著减少递归深度。

4. **✗ 边界条件 i > j 返回非零值**：空区间没有盒子可消除。
   **✓ i > j 时返回 0**。

## 面试追问

**Q1：为什么贪心策略不行？**
→ 得分是 k^2，有超线性增长。先消除一些盒子可能让其他同色盒子连在一起，从而获得更高的平方分。局部最优不一定全局最优。例如 [1,3,1]：先消 3 让两个 1 合并得 1+4=5，比分开消 1+1+1=3 好。

**Q2：第三维 k 的上界是多少？**
→ k 最大为 n-1（极端情况下整个数组都是同一颜色）。但实际上 k 不会超过 `boxes[i]` 这个颜色在数组中出现的次数。

**Q3：如何优化？**
→ (1) 连续同色段合并优化。(2) 只在 `boxes[m] == boxes[i]` 时才尝试合并，跳过不同色的位置。(3) 实际面试中记忆化搜索比自底向上更直观。
