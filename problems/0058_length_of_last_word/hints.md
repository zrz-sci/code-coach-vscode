# 58. 最后一个单词的长度

## 核心思路

本质上就是一个**从右往左扫描**的问题：字符串末尾可能有空格（尾部空格），跳过它们后，从第一个非空格字符开始计数，直到遇到空格或到达字符串开头为止。

## 思维链

1. **读完题第一反应** → 直接从前往后遍历，找到所有单词，返回最后一个的长度。但这样需要遍历整个字符串，且逻辑处理比较绕。
2. **能不能更高效？** → 既然只关心"最后一个"单词，为什么不从后往前扫描呢？这样一找到就可以立刻返回，最优情况下只扫描最后几个字符。
3. **从后往前扫描的难点？** → 字符串末尾可能有空格（如 `"moon  "`），需要先跳过尾部空格。
4. **具体步骤？** → Phase 1: 从末尾向前跳过所有空格。Phase 2: 从当前位置向前计数非空格字符，直到遇到空格或 index < 0。
5. **有没有更"偷懒"的写法？** → 可以用库函数，比如先 `trim` 再 `split`，或者用 `stringstream`，但面试中最好手写展示对边界条件的掌控力。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 反向扫描（双阶段） | 跳过尾部空格 + 计数最后一个单词 | O(n) | O(1) | ⭐ 必须写出 |
| 正向遍历记录 | 从前往后遍历，每遇到非空格就更新长度 | O(n) | O(1) | 备选方案 |
| 库函数法（stringstream） | 利用流自动分词 | O(n) | O(n) | 聊一下即可 |

## 关键提示

1. **尾部空格是核心陷阱**：`"Hello World  "` 末尾有两个空格，如果不先跳过它们，会直接返回 0。
2. **只需要一个指针**：从 `s.size()-1` 开始，先跳空格再数字母，最终 `count` 就是答案。
3. **正向遍历技巧**：遇到非空格字符时 `count++`，遇到空格时 `count = 0`，但这样最终 `count` 恰好就是最后一个单词的长度——**前提是字符串不以空格结尾**。若以空格结尾需要额外处理。
4. **边界保证**：题目说"至少存在一个单词"，所以不用担心全空格的情况。
5. **时间复杂度的微妙之处**：反向扫描最优可以 O(k)（k 是最后一个单词长度 + 尾部空格数），但最坏仍是 O(n)（如 `"a  ...  "` 大量尾部空格）。

## 解法详解

### 解法1: 反向扫描（双阶段） — O(n) / O(1) ⭐ 面试首选

**思考过程**: 只需要最后一个单词的长度，自然想到从末尾开始处理。但末尾可能有空格，所以分两步走。

```
示例: s = "   fly me   to   the moon  "

Phase 1 — 跳过尾部空格:
索引:  26 25      (空格位置)
       ↓  ↓
   "   fly me   to   the moon  "
                              ^^  <- 跳过这两个空格
                              i 从 26 移到 24

Phase 2 — 计数字母:
索引:  24 23 22 21
       ↓  ↓  ↓  ↓
   "   fly me   to   the moon  "
                      ^^^^      <- "moon" 长度 = 4

遇到索引 20 是空格 -> 停止 -> 返回 4
```

```cpp
class Solution {
public:
    int lengthOfLastWord(string s) {
        int i = s.size() - 1;
        
        // Phase 1: 跳过尾部空格
        while (i >= 0 && s[i] == ' ') {
            i--;
        }
        
        // Phase 2: 计数最后一个单词的字母
        int count = 0;
        while (i >= 0 && s[i] != ' ') {
            count++;
            i--;
        }
        
        return count;
    }
};
```

**关键点**:
- 两个 while 循环各自职责清晰，Phase 1 跳空格，Phase 2 数字母。
- 循环条件 `i >= 0` 防止越界（例如 `"hello"` 无尾部空格，Phase 1 不移动指针；`"a"` 单字符情况下 Phase 2 数完后 i = -1）。
- 题目保证至少有一个单词，所以 Phase 1 不会把指针跳过所有字符。

---

### 解法2: 正向遍历记录 — O(n) / O(1)

**不同视角**: 不从右边扫描，而是从头到尾扫一遍，实时维护"当前单词长度"。遇到空格就重置，遇到字母就累加。遍历完毕后 `count` 里保存的就是最后一个单词的长度。

```
示例: s = "Hello World"

遍历过程:
'H' -> count=1
'e' -> count=2
'l' -> count=3
'l' -> count=4
'o' -> count=5
' ' -> count=0   <- 遇到空格，重置！
'W' -> count=1
'o' -> count=2
'r' -> count=3
'l' -> count=4
'd' -> count=5

最终 count = 5 (最后一个单词 "World")
```

**但这里有一个坑**：如果字符串以空格结尾呢？

```
示例: s = "Hello World  "

...'d' -> count=5, ' ' -> count=0, ' ' -> count=0

最终 count = 0，错了！
```

**修复**：需要在遇到空格时，只有当 `count > 0` 时才保存到另一个变量 `lastLen`，最终返回 `lastLen`。

```cpp
class Solution {
public:
    int lengthOfLastWord(string s) {
        int count = 0, lastLen = 0;
        for (char c : s) {
            if (c != ' ') {
                count++;
            } else {
                if (count > 0) {
                    lastLen = count;  // 保存刚结束的单词长度
                }
                count = 0;
            }
        }
        // 如果字符串不以空格结尾，count 就是最后一个单词长度
        // 如果以空格结尾，lastLen 是最后一个单词长度
        return count > 0 ? count : lastLen;
    }
};
```

**关键点**:
- 正向遍历的代码逻辑稍微复杂一些，需要同时维护 `count` 和 `lastLen`。
- 相比解法1，这种写法无论字符串多长都要遍历完整，而解法1可以在找到最后一个单词后立即返回。
- 面试中如果先写了这个，面试官可能会问"能不能更高效？"引导你写解法1。

---

### 解法3: 库函数法（stringstream） — O(n) / O(n)

**偷懒写法**: 面试中可以先提一嘴表明你知道库函数，但面试官一定会要求手写。

```cpp
class Solution {
public:
    int lengthOfLastWord(string s) {
        // stringstream 自动按空格分词
        istringstream iss(s);
        string word;
        while (iss >> word) {
            // 不断读取，最终 word 就是最后一个单词
        }
        return word.size();
    }
};
```

**关键点**:
- `istringstream` + `>>` 自动跳过空格，非常简洁。
- 缺点：需要 O(n) 额外空间（创建流和存储中间字符串），且必须遍历整个字符串。
- 面试中仅作为"我知道这种方式"来加分，不可作为主解法。

## 解法对比

|  | 反向扫描（双阶段） | 正向遍历记录 | 库函数法 |
|--|-------------------|------------|---------|
| 时间 | O(n) 最优 O(k) | O(n) 必须扫全 | O(n) |
| 空间 | **O(1)** | **O(1)** | O(n) |
| 代码复杂度 | 最简洁 | 需维护两个变量 | 取决于方式 |
| 提前终止 | **支持** | 不支持 | 不支持 |

**面试选择**: 优先写解法1（反向扫描），代码最简洁且展示了"从问题目标出发"的思维方式——既然只关心最后一个单词，就从末尾开始。

## 易错点

1. **忘记跳过尾部空格**：
   - ✗ 直接从末尾开始计数非空格字符 → `"Hello World  "` 返回 0
   - ✓ 先跳过尾部空格，再开始计数

2. **循环条件缺少越界检查**：
   - ✗ `while (s[i] == ' ') i--;` → 如果全是单词无空格如 `"hello"`，Phase 2 数完后 i = -1，Phase 1 访问 `s[-1]` 越界
   - ✓ `while (i >= 0 && s[i] == ' ') i--;`

3. **正向遍历法忘记处理尾部空格**：
   - ✗ 遇到空格直接 `count = 0`，最终返回 `count` → 以空格结尾时返回 0
   - ✓ 遇到空格时先保存 `lastLen = count`（如果 count > 0），最终返回 `count > 0 ? count : lastLen`

4. **off-by-one：用下标差算长度时**：
   - ✗ `end - start + 1`（如果 start 指向空格位置）→ 多算了一个
   - ✓ 搞清楚 start 到底指向最后一个空格还是单词首字母，画图确认

## 面试追问

**Q1: 如果字符串非常长（比如几 GB），但最后一个单词很短，怎么优化？**
> 反向扫描天然适合这种场景。只需要读取尾部的少量字符就能得出答案，时间是 O(k)（k = 尾部空格数 + 最后一个单词长度），远小于 O(n)。如果是流式数据（只能从后往前读），这一点更重要。

**Q2: 如果要求返回最后一个单词本身（而不仅仅是长度）呢？**
> 在反向扫描的基础上，记录 `end`（最后一个非空格字符位置）和 `start`（单词起始位置），然后 `s.substr(start, end - start + 1)` 截取。注意 Phase 2 结束时 `i` 已经指向了空格或 -1，所以 `start = i + 1`。

**Q3: 如果字符串中可能包含多种空白字符（制表符、换行符等），怎么改？**
> 把 `s[i] == ' '` 改为 `isspace(s[i])`，或者自定义判断函数 `isWhitespace(c)` 来检查所有空白字符。核心算法完全不变。

**Q4: 如果要统计每个单词的长度并返回数组呢？**
> 正向遍历更方便：维护当前单词长度，遇到空格时如果 `count > 0` 就 push 进结果数组并重置。遍历结束后如果 `count > 0` 再 push 一次（处理不以空格结尾的情况）。时间 O(n)，空间 O(单词数)。
