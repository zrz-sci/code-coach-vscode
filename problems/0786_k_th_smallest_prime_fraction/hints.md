# 786. K-th Smallest Prime Fraction

## 核心思路

在一个已排序的质数数组中，枚举所有 arr[i]/arr[j]（i < j）的分数，找到第 K 小的分数。暴力方法是生成所有分数排序后取第 K 个（O(n^2 log n)），更优的方法有两种：**小根堆多路归并**（O(K log n)）和**二分答案**（O(n log(max_val))）。二分答案是最优解，利用了数组有序的性质。

## 思维链

1. **分数总数**：n 个元素可以构成 n*(n-1)/2 个分数（i < j）。
2. **排序结构**：固定分母 arr[j]，分子从小到大排列，形成有序的分数链。
3. **多路归并**：每个分母对应一条有序链，用小根堆归并 K 次即可找到第 K 小。
4. **二分答案**：二分分数的值 mid，统计有多少分数 <= mid。若恰好有 K 个，则找到答案。
5. **计数技巧**：对于固定分母 arr[j]，满足 arr[i]/arr[j] <= mid 的分子数量可以用二分查找或双指针 O(1) 判断。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 二分答案 | O(n log(max_val^2)) | O(1) | 最优，利用有序性 |
| 小根堆多路归并 | O(K log n) | O(n) | 经典堆归并模板 |
| 暴力排序 | O(n^2 log n) | O(n^2) | 简单但不高效 |

## 关键提示

1. **二分答案的对象是分数值**：在 [0, 1] 区间内二分。对于每个 mid 值，统计所有 arr[i]/arr[j] <= mid 的对数。
2. **双指针计数**：固定 j，找到最大的 i 使得 arr[i]/arr[j] <= mid。由于 arr 有序，i 单调递增，整体 O(n)。
3. **堆的初始化**：把每条链的最小分数（arr[0]/arr[j]，j 从 1 到 n-1）放入堆中。
4. **堆弹出后的补充**：弹出 arr[i]/arr[j] 后，将 arr[i+1]/arr[j] 推入堆（如果 i+1 < j）。
5. **二分终止条件**：当 count == K 时，追踪使 count 恰好等于 K 时的最大分数就是答案。
6. **注意浮点精度**：二分答案法中使用浮点数，迭代次数设为 100 左右足够精度。

## 解法详解

### 解法一：二分答案（推荐，O(n log W)）

**详细步骤**：
1. 二分范围 lo = 0, hi = 1（所有分数都在 (0, 1) 区间内）。
2. 对于每个 mid = (lo + hi) / 2：
   - 统计满足 arr[i] / arr[j] <= mid 的分数对数 count。
   - 同时记录满足条件的最大分数（即最接近 mid 且 <= mid 的分数）。
   - 使用双指针：j 从 1 到 n-1，i 从 0 开始向右移动。
3. 如果 count < K：lo = mid（答案在右半区间）。
4. 如果 count >= K：hi = mid（答案在左半区间）。
5. 当 count == K 时，记录的最大分数就是答案。

**双指针细节**：
- 外层循环 j: 1 -> n-1
- 内层 i 从上一轮的位置继续（不回退），因为 j 增大时分母增大，能满足条件的 i 不会减少
- 对于每个 j，`while (i < j && arr[i] <= mid * arr[j]) i++`
- count += i（在 i 之前的所有分子都满足条件）
- 同时追踪最大分数：比较 arr[i-1]/arr[j] 与当前最大值

### 解法二：小根堆多路归并（O(K log n)）

**详细步骤**：
1. 创建一个小根堆，每个元素是 (fraction_value, i, j)。
2. 初始化：将所有 arr[0]/arr[j]（j = 1..n-1）放入堆中。
3. 弹出 K-1 次后，堆顶就是第 K 小的分数。
4. 每次弹出 (val, i, j) 后，若 i+1 < j，将 (arr[i+1]/arr[j], i+1, j) 入堆。

**为什么正确**：每条以 arr[j] 为分母的链中，arr[0]/arr[j] < arr[1]/arr[j] < ...，堆保证每次取出全局最小。

### 解法三：暴力排序

**详细步骤**：
1. 枚举所有 i < j，生成分数对 (arr[i], arr[j])。
2. 按分数值排序。
3. 取第 K 个。

## 易错点

1. **二分答案中的精度问题**：使用浮点数二分时，循环固定次数（如 100 次）比用 `hi - lo > eps` 更安全，避免无限循环。
2. **双指针 i 不回退**：在二分答案的计数中，j 增大时 i 不需要重置为 0，否则时间复杂度退化为 O(n^2)。但注意：如果是二分的新一轮（新的 mid），i 需要重置。
3. **堆中存储的顺序**：小根堆比较的是分数值，但返回的是分子和分母。需要正确存储 (i, j) 索引。
4. **分数比较用乘法代替除法**：比较 a/b < c/d 可以用 a*d < c*b，避免浮点误差。在堆解法中尤其重要。
5. **K 的范围**：K 最大为 n*(n-1)/2，堆解法在 K 很大时可能不如二分答案。

## 面试追问

1. **Q: 二分答案的精度怎么保证？**
   A: 由于我们追踪的是满足条件的最大分数的分子和分母（整数对），精度不是问题。二分只是用来逼近目标区间，最终答案通过追踪的整数对得到。

2. **Q: 这道题和 "第 K 小的矩阵元素"（LC 378）有什么联系？**
   A: 两者都是"多路归并"的变体。矩阵每行有序，等价于多条有序链。同样可以用小根堆或二分答案求解。

3. **Q: 如果 arr 没有排序呢？**
   A: 先排序 O(n log n)，然后用相同方法。或者直接暴力枚举所有分数。

4. **Q: 为什么双指针在二分答案中是正确的？**
   A: 因为 arr 是升序的。固定分母 arr[j]，满足 arr[i]/arr[j] <= mid 的最大 i 随着 j 增大（分母增大）而不减。所以 i 不需要回退。

5. **Q: 堆解法和二分解法分别在什么场景下更好？**
   A: K 较小时堆更好（O(K log n)），K 接近 n^2/2 时二分更好（O(n log W)）。二分解法的时间不依赖 K。
