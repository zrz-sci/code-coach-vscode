# 757. 设置交集大小至少为2 (Set Intersection Size At Least Two)

## 核心思路

本题是经典的**贪心 + 排序**问题。需要找到一个最小的集合 S，使得 S 与每个区间的交集至少有2个元素。核心贪心策略是：按区间右端点升序排序（右端点相同时左端点降序），然后从左到右扫描，尽量复用已选的元素。对每个区间，检查当前已选集合中有多少个元素落在该区间内，根据缺少的数量在区间右端补充元素。

## 思维链

1. **问题本质**：从数轴上选最少的点，使每个区间至少包含2个被选的点 -- 这是经典的区间覆盖贪心变体
2. **排序策略**：按右端点升序排序可以让我们从小到大处理区间，尽量让后续区间复用前面已选的点
3. **右端点相同时左端点降序**：这样较短区间先处理（它的约束更严格），避免在较长区间中选了不必要的点
4. **贪心选点**：对当前区间，如果已选集合中落入该区间的元素不足2个，从区间右端（end, end-1）补充
5. **选右端的原因**：右端点的值尽可能大，更容易被后续区间（右端点更大的）复用

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 贪心 + 排序 | O(n log n) | O(1) | 最优解法，按右端点排序贪心选点 |

## 关键提示

1. **排序规则**：先按右端点升序，右端点相同则按左端点降序。左端点降序确保短区间先被处理
2. **维护两个变量**：只需跟踪已选集合中最大的两个值 `p1` 和 `p2`（p1 < p2），因为只有这两个值可能被后续区间复用
3. **三种情况判断**：
   - 区间左端点 > p2：当前区间没有已选点落入，需要新增2个点（end-1, end）
   - 区间左端点 > p1：只有 p2 落入区间，需要新增1个点（end）
   - 否则：p1 和 p2 都落入区间，无需新增
4. **选点位置**：始终选区间的右端点或右端点-1，这是贪心最优的选择

## 解法详解

### 解法一：贪心 + 排序（推荐）

**算法步骤**：
1. 将所有区间按右端点升序排序；若右端点相同，则按左端点降序排序
2. 初始化 `p1 = -1, p2 = -1`，分别表示已选集合中最大的两个值（p1 < p2），初始为无效值
3. 初始化答案 `result = 0`
4. 遍历每个排序后的区间 `[left, right]`：
   - **情况A**：如果 `left > p2`，说明已选的两个最大值都不在当前区间内
     - 选 `right - 1` 和 `right` 两个点
     - 更新 `p1 = right - 1, p2 = right`
     - `result += 2`
   - **情况B**：如果 `left > p1`，说明只有 p2 在当前区间内
     - 需要再选1个点，选 `right`
     - 更新 `p1 = p2, p2 = right`
     - `result += 1`
   - **情况C**：如果 `left <= p1`，说明 p1 和 p2 都在当前区间内，无需操作
5. 返回 `result`

**为什么只需要维护最大的两个值？**
- 排序后区间按右端点递增处理。对于后续区间 `[left', right']`，`right' >= right`
- 只有足够大的值才有可能落入后续区间（`left' <= value <= right'`）
- 因此我们只关心已选集合中最大的两个值

**复杂度分析**：
- 时间复杂度：O(n log n)，排序主导
- 空间复杂度：O(1)，只需常数额外空间（不计排序空间）

### 排序策略的正确性证明

**右端点升序**：让我们先处理约束范围在左侧的区间，选出的点值较小。这些点如果落入后续区间（右端点更大），就被复用了。

**右端点相同时左端点降序**：假设两个区间 `[1,5]` 和 `[3,5]`。若先处理 `[1,5]`，选 `4,5`，然后 `[3,5]` 检查到 `4,5` 都在其中，OK。若先处理 `[3,5]`，选 `4,5`，然后 `[1,5]` 也OK。但如果有三个区间 `[1,5], [3,5], [4,5]`，先处理更宽的区间可以避免遗漏。左端点降序保证宽区间先处理（或者说约束更松的先处理），避免对紧约束区间做不必要的额外选点。

## 易错点

1. **排序规则**：右端点相同时必须左端点降序排。如果也用升序，会导致先处理更紧约束的区间，可能多选不必要的点
2. **初始值**：p1 和 p2 必须初始化为不可能落入任何区间的值（如 -1 或 INT_MIN），不能初始化为0
3. **更新顺序**：情况B中更新时必须先 `p1 = p2`，再 `p2 = right`，顺序不能反
4. **边界条件**：区间长度为1（如 `[3,4]`）也是合法的，此时选 `3,4` 两个点
5. **不要用集合模拟**：虽然用 set 存储所有已选点并逐一检查是正确的，但 O(n * max_points) 效率不如只维护两个变量

## 面试追问

1. **Q: 如果要求交集大小至少为 K 而不是 2，算法如何推广？**
   - A: 维护已选集合中最大的 K 个值而非2个。对每个区间检查有多少个值落入，不足 K 个时从右端补足。维护可以用有序数组或优先队列。

2. **Q: 为什么选区间右端点而不是左端点？**
   - A: 因为区间按右端点升序排列，选右端点让值尽可能大，更容易被后续右端点更大的区间复用，从而全局最少选点。

3. **Q: 如果区间有重叠但不包含的情况，排序策略还正确吗？**
   - A: 完全正确。排序策略只要求按右端点排序即可处理所有重叠/不重叠/包含情况。关键是贪心选择始终在右端。

4. **Q: 能否用动态规划解决？**
   - A: 可以但不必要。可以将区间按右端点排序后用 DP 记录每个前缀的最优选择，但贪心更简洁高效。

5. **Q: 端点值可能高达 10^8，为什么不需要离散化？**
   - A: 因为我们只在区间端点处选值，不需要枚举整个数轴。贪心算法只关心相对位置关系。
