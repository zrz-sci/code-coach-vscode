# 112. 路径总和

## 核心思路

这道题本质上是：**从根节点出发，沿着树的路径往下走，到达叶子节点时，路径上所有节点值的累加和是否等于 targetSum**。核心思想是"逐步扣减"——每经过一个节点就把 targetSum 减去当前节点值，到叶子节点时检查剩余值是否为 0。

## 思维链

1. **读完题第一反应**：需要遍历所有从根到叶子的路径，计算每条路径的节点值之和，看是否等于 targetSum。
2. **怎么遍历所有路径？** 树的路径天然适合递归/DFS——从根出发，每次走到一个节点就"消耗"掉当前节点的值。
3. **关键观察**：不需要真的把路径记录下来再求和。可以把问题"传递"给子树——如果根节点值为 `val`，那么问题变成：左子树或右子树中是否存在一条根到叶路径，和等于 `targetSum - val`？
4. **递归终止条件**：到达叶子节点时（左右孩子都为空），检查剩余的 targetSum 是否刚好等于该叶子节点的值。
5. **迭代怎么做？** DFS 用栈模拟递归，BFS 用队列逐层扩展，两者都需要在栈/队列中同时记录节点和"到达该节点时的累加和"。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 递归 DFS | 自顶向下递归，逐步扣减 targetSum | O(n) | O(h) | ⭐ 必须写出 |
| 迭代 DFS (栈) | 用栈模拟递归，同时记录路径和 | O(n) | O(h) | 能说出即可 |
| BFS (队列) | 逐层扩展，每个节点记录累加和 | O(n) | O(w) | 加分项 |

> n = 节点数，h = 树高（平衡时 log n，最坏 n），w = 最大层宽

## 关键提示

- **提示1**：递归时不要"累加"，而要"扣减"——每经过一个节点就减去它的值，这样到叶子节点只需判断剩余值是否为 0，代码更简洁。

- **提示2**：叶子节点的定义是**左右孩子都为空**。一个只有右孩子的节点不是叶子！这是最常见的错误来源。

- **提示3**：空树（root == nullptr）应该返回 false，即使 targetSum == 0。因为不存在"根到叶"的路径。

- **提示4（树形可视化）**：
```
//       5              targetSum = 22
//      / \
//     4   8            路径 5→4→11→2: 5+4+11+2 = 22 ✓
//    /   / \
//   11  13  4          递归扣减过程:
//  / \       \         hasPathSum(5, 22)
// 7   2       1          → hasPathSum(4, 17)     // 22-5=17
//                          → hasPathSum(11, 13)  // 17-4=13
//                            → hasPathSum(7, 2)  // 13-11=2, 叶子, 2≠7 ✗
//                            → hasPathSum(2, 2)  // 13-11=2, 叶子, 2==2 ✓
```

- **提示5**：迭代版的关键是——栈/队列里不能只存节点，还要存"到达该节点时的累积和"（或"剩余目标和"），否则无法判断路径和。

## 解法详解

### 解法1: 递归 DFS（自顶向下扣减）— O(n) / O(h) ⭐ 面试首选

**思考过程**：
树的路径问题天然适合递归。从根节点出发，每次递归把 targetSum 减去当前节点值，传给左右子树。当到达叶子节点时，如果 targetSum 恰好等于叶子节点值，说明找到了一条满足条件的路径。

```
// 递归三要素:
// 1. 返回值: bool — 子树中是否存在满足条件的路径
// 2. 终止条件: 空节点返回false; 叶子节点判断值是否匹配
// 3. 单层逻辑: 当前节点不是叶子, 递归检查左/右子树(target减去当前值)
```

```cpp
class Solution {
public:
    bool hasPathSum(TreeNode* root, int targetSum) {
        if (!root) return false;
        
        // 叶子节点：左右孩子都为空
        if (!root->left && !root->right) {
            return root->val == targetSum;
        }
        
        // 非叶子：把"剩余目标"传给左右子树
        int remaining = targetSum - root->val;
        return hasPathSum(root->left, remaining) 
            || hasPathSum(root->right, remaining);
    }
};
```

**关键点**：
- 终止条件必须先判断 `!root`，再判断叶子。顺序不能反。
- 叶子节点的判断是 `!root->left && !root->right`，不是 `!root->left || !root->right`。

---

### 解法2: 迭代 DFS（栈模拟）— O(n) / O(h)

**从解法1到解法2**：递归的本质是函数调用栈，我们用显式的栈来模拟。栈中每个元素存一对 `(节点, 到达该节点时的剩余目标和)`。

```
// 栈模拟递归过程 (示例: targetSum=22):
//
// 初始: push(5, 22)
// pop(5, 22) → 非叶子 → push(8, 22-5=17), push(4, 17)
// pop(4, 17) → 非叶子 → push(11, 17-4=13)
// pop(11, 13) → 非叶子 → push(2, 13-11=2), push(7, 2)
// pop(7, 2)  → 叶子, 7≠2 → 继续
// pop(2, 2)  → 叶子, 2==2 → return true!
```

```cpp
class Solution {
public:
    bool hasPathSum(TreeNode* root, int targetSum) {
        if (!root) return false;
        
        // 栈存 {节点, 到达该节点时的剩余目标和}
        stack<pair<TreeNode*, int>> stk;
        stk.push({root, targetSum});
        
        while (!stk.empty()) {
            auto [node, remaining] = stk.top();
            stk.pop();
            
            // 叶子节点：检查剩余值是否等于节点值
            if (!node->left && !node->right) {
                if (node->val == remaining) return true;
                continue;  // 不匹配，继续检查其他路径
            }
            
            // 非叶子：把子节点和更新后的剩余值压栈
            int newRemaining = remaining - node->val;
            if (node->right) stk.push({node->right, newRemaining});
            if (node->left)  stk.push({node->left, newRemaining});
        }
        
        return false;
    }
};
```

**关键点**：栈中存的是"剩余目标和"而不是"已累加和"，这样判断叶子时直接比较 `node->val == remaining`，逻辑更清晰。

---

### 解法3: BFS（队列逐层扩展）— O(n) / O(w)

**不同视角**：DFS 是深入一条路径到底再回溯，BFS 是逐层检查。对于这道题两者效率相同，但 BFS 能展示另一种思维方式。

```
// BFS 逐层扩展 (targetSum=22):
// Level 0: {(5, 5)}
// Level 1: {(4, 9), (8, 13)}
// Level 2: {(11, 20), (13, 26), (4, 17)}
// Level 3: {(7, 27), (2, 22), (1, 18)}
//           叶子7: 27≠22  叶子2: 22==22 ✓ 找到!
```

```cpp
class Solution {
public:
    bool hasPathSum(TreeNode* root, int targetSum) {
        if (!root) return false;
        
        // 队列存 {节点, 从根到该节点的路径累加和}
        queue<pair<TreeNode*, int>> q;
        q.push({root, root->val});
        
        while (!q.empty()) {
            auto [node, pathSum] = q.front();
            q.pop();
            
            // 叶子节点：检查累加和
            if (!node->left && !node->right) {
                if (pathSum == targetSum) return true;
                continue;
            }
            
            // 非叶子：扩展子节点，累加路径和
            if (node->left)  q.push({node->left,  pathSum + node->left->val});
            if (node->right) q.push({node->right, pathSum + node->right->val});
        }
        
        return false;
    }
};
```

**关键点**：BFS 版这里用的是"累加"方式（pathSum 存的是从根到当前节点的总和），而不是"扣减"方式。两种风格都可以，选一种保持一致即可。

## 解法对比

| | 递归 DFS | 迭代 DFS | BFS |
|--|---------|---------|-----|
| 时间复杂度 | O(n) | O(n) | O(n) |
| 空间复杂度 | O(h) 递归栈 | O(h) 显式栈 | O(w) 队列 |
| 代码简洁度 | ⭐⭐⭐ 最简洁 | ⭐⭐ 中等 | ⭐⭐ 中等 |
| 面试推荐 | 首选 | 追问"不用递归" | 展示 BFS 能力 |
| 最坏空间 | O(n) 链状树 | O(n) 链状树 | O(n/2) 满二叉树最后一层 |

**选择建议**：面试先写递归（3行核心代码），面试官追问"用迭代实现"时写栈版本。BFS 版用来展示你对多种遍历方式的掌握。

## 易错点

1. **空树返回 false，而非 true**
   - ✗ `if (!root) return targetSum == 0;` — 空树没有叶子节点，不存在路径
   - ✓ `if (!root) return false;`
   - 题目说"根节点到叶子节点"，空树连根都没有

2. **叶子节点判断条件写错**
   - ✗ `if (!root->left || !root->right)` — 这会把只有一个孩子的节点误判为叶子
   - ✓ `if (!root->left && !root->right)` — 必须两个孩子都为空
   - 例如树 `[1,2]`，节点 1 不是叶子（它有左孩子 2），但按错误写法会在节点 1 就判断

3. **在非叶子的空孩子上误判**
   - 考虑树 `[1,2]`（根节点1，只有左孩子2），targetSum=1：
   - 如果递归到 `root->right`（null），用 `if (!root) return targetSum == 0` 会返回 true（因为 1-1=0）
   - 但正确答案是 false，因为节点1不是叶子！唯一的叶子是节点2，路径和为3≠1
   - ✓ 正确做法：`if (!root) return false;` 然后只在叶子节点处判断

4. **迭代版忘记在栈/队列中存路径和**
   - ✗ 只存节点，出栈时想用全局变量记录路径和 — 回溯时会出错
   - ✓ 每个栈元素都带上对应的剩余值/累加和

## 面试追问

**Q1: 这道题你的递归终止条件是什么？为什么空节点返回 false 而不是 targetSum == 0？**
> 因为空节点不是叶子节点。题目要求的是"根到叶子"的路径，空节点不构成路径的终点。比如树 `[1,2]` targetSum=1，节点1的右孩子为空，但不应在此处匹配成功。

**Q2: 如果面试官要求不用递归，怎么实现？**
> 用栈模拟 DFS。关键是栈中每个元素不仅存节点指针，还要存"到达该节点时的剩余目标和"。弹出节点时若是叶子就判断，否则将子节点和更新后的剩余值压栈。（即解法2）

**Q3: 如果题目改成"返回所有满足条件的路径"（LeetCode 113），代码需要怎么改？**
> 需要额外维护一个路径数组 `path`：
> - 进入节点时 push_back 当前值
> - 到叶子节点且满足条件时，把 path 拷贝到结果集
> - 回溯时 pop_back
> 
> 核心框架不变，只是从"返回 bool"变成"收集所有路径"。

**Q4: 节点值可以为负数，这对算法有影响吗？**
> 没有影响。因为我们遍历的是所有根到叶路径，没有剪枝（不能因为当前和已超过 target 就停止，因为后面可能有负数拉回来）。算法的正确性不依赖节点值非负。
