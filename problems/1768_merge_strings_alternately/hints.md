# 1768. 交替合并字符串

## 核心思路

本质上就是一个**拉链合并**问题：两个字符串像拉链一样交错插入，短的那边用完后，长的那边剩余部分直接追加到末尾。

## 思维链

1. **读完题第一反应**：需要从两个字符串中交替取字符。最朴素的想法就是先处理公共长度的部分（交替取），再把多余部分追加。
2. **有没有更优雅的写法？** 上面的思路需要分成"交替阶段"和"追加阶段"两段代码，能不能用一个循环搞定？
3. **双指针统一处理**：用两个指针 `i` 和 `j` 分别指向两个字符串，只要任意一个没走完就继续循环。每轮循环里，`i` 没越界就取 `word1[i]`，`j` 没越界就取 `word2[j]`。
4. **这样做的好处**：一个 while 循环搞定所有情况，不需要额外处理剩余部分，代码简洁不易出错。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 分段拼接 | 先交替取公共部分，再追加剩余 | O(n+m) | O(1)* | 能说出即可 |
| 双指针一趟遍历 | 一个循环，按条件依次取 | O(n+m) | O(1)* | ⭐ 必须写出 |

> *空间 O(1) 指除输出字符串外不使用额外空间。

## 关键提示

1. **提示1**：你不需要真的"分两段"处理——想想怎样在一个循环里同时处理"两边都有字符"和"只有一边有字符"的情况。
2. **提示2**：双指针什么时候停？不是"两个都走完"就停，而是"两个都走完"才停——用 `||` 不是 `&&`。
3. **提示3**：这道题数据量很小（长度 ≤ 100），不需要追求花哨的优化，关键是代码简洁正确。
4. **提示4**：用一个索引 `i` 也可以——`i < len1` 时取 `word1[i]`，`i < len2` 时取 `word2[i]`，条件是 `i < max(len1, len2)`。

交替合并的可视化：
```
word1:  a   b   c   d
        ↓   ↓   ↓   ↓
result: a p b q c r d     ← 交替插入，word1 多出的 'd' 追加末尾
        ↑   ↑   ↑
word2:  p   q   r

指针移动过程:
i=0,j=0 → 取 a,p → "ap"
i=1,j=1 → 取 b,q → "apbq"
i=2,j=2 → 取 c,r → "apbqcr"
i=3,j=3 → j越界，只取 d → "apbqcrd"
i=4,j=3 → 都越界，结束
```

## 解法详解

### 解法1: 分段拼接 — O(n+m) / O(1)

**思考过程**：最直觉的做法——先把两个字符串对齐的部分交替拼接，然后把较长字符串的剩余部分直接追加。

```cpp
class Solution {
public:
    string mergeAlternately(string word1, string word2) {
        string result;
        int minLen = min(word1.size(), word2.size());
        
        // 阶段1：交替拼接公共长度部分
        for (int i = 0; i < minLen; i++) {
            result += word1[i];
            result += word2[i];
        }
        
        // 阶段2：追加较长字符串的剩余部分
        // substr 会处理好"没有剩余"的情况（返回空串）
        result += word1.substr(minLen);
        result += word2.substr(minLen);
        
        return result;
    }
};
```

**关键点**：`substr(minLen)` 当 `minLen == word.size()` 时返回空串，所以不需要判断哪个更长，两行都写上即可——只有较长的那个会真正追加内容。

---

### 解法2: 双指针一趟遍历 — O(n+m) / O(1) ⭐ 面试首选

**从解法1优化**：解法1 分成了"交替"和"追加"两个阶段，逻辑上有些割裂。用双指针可以在一个循环内统一处理所有情况，代码更优雅。

```cpp
class Solution {
public:
    string mergeAlternately(string word1, string word2) {
        string result;
        int i = 0, j = 0;
        int n = word1.size(), m = word2.size();
        
        // 只要任意一个字符串还没遍历完，就继续
        while (i < n || j < m) {
            // word1 还有字符就取一个
            if (i < n) result += word1[i++];
            // word2 还有字符就取一个
            if (j < m) result += word2[j++];
        }
        
        return result;
    }
};
```

**为什么这样就能交替？**  
每轮循环固定先取 `word1[i]` 再取 `word2[j]`。当两边都有字符时，自然就是交替取。当一边用完后，`if` 条件不满足就跳过，只取另一边的字符，效果等同于"追加剩余部分"。

**关键点**：循环条件是 `||`（或），不是 `&&`（与）。如果用 `&&`，一边用完就停了，另一边的剩余字符就丢了。

---

### 解法2变体: 单指针 — O(n+m) / O(1)

**思路**：观察到 `i` 和 `j` 始终同步递增（都是每轮 +1），所以可以只用一个指针 `i`，循环到 `max(n, m)` 为止。

```cpp
class Solution {
public:
    string mergeAlternately(string word1, string word2) {
        string result;
        int n = word1.size(), m = word2.size();
        
        for (int i = 0; i < max(n, m); i++) {
            if (i < n) result += word1[i];
            if (i < m) result += word2[i];
        }
        
        return result;
    }
};
```

**为什么能用一个指针？** 因为两个字符串的消费速率相同——每轮各取一个。如果题目要求"word1 取两个 word2 取一个"这种不对称模式，就必须用双指针了。

## 解法对比

| | 解法1: 分段拼接 | 解法2: 双指针 | 解法2变体: 单指针 |
|---|---|---|---|
| 循环次数 | 两段 | 一趟 | 一趟 |
| 代码行数 | 稍多 | 简洁 | 最简洁 |
| 可读性 | 逻辑分明 | 统一优雅 | 最直观 |
| 扩展性 | 较差 | 好（不对称场景也适用） | 仅对称场景 |

面试推荐：**解法2 双指针**。它是通用模板，适用于两个序列合并的各种变体（如归并排序的 merge 步骤）。

## 易错点

1. **✗ 循环条件用 `&&`**
   ```cpp
   while (i < n && j < m)  // 错！较短的用完就停了，较长的剩余字符丢失
   ```
   **✓ 应该用 `||`**
   ```cpp
   while (i < n || j < m)  // 对！两边都用完才停
   ```

2. **✗ 忘记边界检查直接取字符**
   ```cpp
   while (i < n || j < m) {
       result += word1[i++];  // 错！i 可能已经越界
       result += word2[j++];  // 错！j 可能已经越界
   }
   ```
   **✓ 取字符前必须检查指针是否越界**
   ```cpp
   if (i < n) result += word1[i++];
   if (j < m) result += word2[j++];
   ```

3. **✗ `max` 未加 `(int)` 强转导致签名/无符号比较警告**
   ```cpp
   for (int i = 0; i < max(word1.size(), word2.size()); i++)
   // size() 返回 size_t (unsigned)，i 是 int (signed) → 可能警告
   ```
   **✓ 提前用 int 变量存储长度**
   ```cpp
   int n = word1.size(), m = word2.size();
   for (int i = 0; i < max(n, m); i++)
   ```

## 面试追问

**Q1（基础理解）**：这道题的时间复杂度能比 O(n+m) 更低吗？  
→ 不能。结果字符串长度就是 n+m，构建它至少需要 O(n+m) 时间。

**Q2（代码优化）**：能否提前 `reserve` 字符串空间来避免多次扩容？  
→ 可以。`result.reserve(n + m);` 提前分配空间，避免 string 动态扩容时的拷贝开销。对于大字符串场景，这是一个实用的常数优化。

**Q3（变体题）**：如果不是两个字符串，而是 K 个字符串交替合并呢？  
→ 用 K 个指针（或一个指针数组），外层循环按轮次，内层循环遍历 K 个字符串，每轮每个字符串取一个字符。当所有字符串都用完时停止。时间 O(所有字符串长度之和)。

**Q4（变体题）**：如果要求 word1 每次取 2 个字符、word2 每次取 1 个字符呢？  
→ 这时就不能用单指针了，必须用双指针，每轮 `i += 2`、`j += 1`，取字符时逐个检查边界。
