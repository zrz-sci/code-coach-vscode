# 368. 最大整除子集 (Largest Divisible Subset)

## 核心思路

**排序 + DP + 路径回溯**，本质是**最长递增子序列 (LIS) 的变种**。关键洞察：排序后，只需保证相邻元素整除就能保证任意两元素互除——因为**整除具有传递性**（a|b 且 b|c 则 a|c）。定义 `dp[i]` = 以 `nums[i]` 结尾的最长整除链长度，转移条件从 LIS 的 `<` 变为 `%==0`。额外用 `parent[i]` 记录前驱索引来恢复实际子集。

## 思维链

1. **暴力思路** → 枚举 2^n 个子集，逐个验证任意两元素互除。指数级，n=1000 不可行。

2. **发现整除传递性** → 子集排序后 `a1 < a2 < ... < ak`，只要 `a1|a2, a2|a3, ..., a_{k-1}|a_k`，传递性保证任意 `a_i|a_j`（i<j）。证明：`a_j = a_{j-1} * m_{j-1} = a_{j-2} * m_{j-2} * m_{j-1} = ... = a_i * (m_i * ... * m_{j-1})`，所以 `a_i` 整除 `a_j`。

3. **联想 LIS** → 排序后，问题变成：找最长子序列使相邻元素满足整除关系。这与 LIS（相邻元素满足 `<` 关系）框架完全一致。

4. **DP 定义** → `dp[i]` = 以排序后 `nums[i]` 结尾的最长整除链长度。
   - 初始化：`dp[i] = 1`（每个元素自身是长度 1 的链）
   - 转移：`dp[i] = max(dp[j] + 1)` 对所有 `j < i` 且 `nums[i] % nums[j] == 0`

5. **路径恢复** → 用 `parent[i]` 记录 dp[i] 从哪个 j 转移而来。找到 dp 最大值位置 maxIdx 后，沿 parent 回溯到 -1，收集并反转得到答案。

## DP 状态转移表

```
输入: nums = [1, 2, 3, 4, 8] (已排序)

i=0: nums[0]=1
  无前驱可选
  dp[0]=1, parent[0]=-1

i=1: nums[1]=2
  j=0: 2%1==0 ✓ → dp[0]+1=2 > dp[1]=1 → 更新
  dp[1]=2, parent[1]=0

i=2: nums[2]=3
  j=0: 3%1==0 ✓ → dp[0]+1=2 > dp[2]=1 → 更新
  j=1: 3%2==1 ✗ → 跳过
  dp[2]=2, parent[2]=0

i=3: nums[3]=4
  j=0: 4%1==0 ✓ → dp[0]+1=2 > dp[3]=1 → 更新 dp[3]=2, parent=0
  j=1: 4%2==0 ✓ → dp[1]+1=3 > dp[3]=2 → 更新 dp[3]=3, parent=1
  j=2: 4%3==1 ✗ → 跳过
  dp[3]=3, parent[3]=1

i=4: nums[4]=8
  j=0: 8%1==0 ✓ → dp[0]+1=2 > dp[4]=1 → 更新 dp[4]=2, parent=0
  j=1: 8%2==0 ✓ → dp[1]+1=3 > dp[4]=2 → 更新 dp[4]=3, parent=1
  j=2: 8%3!=0 ✗ → 跳过
  j=3: 8%4==0 ✓ → dp[3]+1=4 > dp[4]=3 → 更新 dp[4]=4, parent=3
  dp[4]=4, parent[4]=3

最终 DP 表:
┌───────┬─────┬─────┬─────┬─────┬─────┐
│ index │  0  │  1  │  2  │  3  │  4  │
├───────┼─────┼─────┼─────┼─────┼─────┤
│ nums  │  1  │  2  │  3  │  4  │  8  │
│ dp    │  1  │  2  │  2  │  3  │  4  │ ← 最大值 dp[4]=4
│parent │ -1  │  0  │  0  │  1  │  3  │
└───────┴─────┴─────┴─────┴─────┴─────┘

路径回溯:
  maxIdx = 4
  4 → parent[4]=3 → parent[3]=1 → parent[1]=0 → parent[0]=-1 (终止)
  收集: [8, 4, 2, 1]
  反转: [1, 2, 4, 8] ✓

验证: 2%1=0 ✓, 4%2=0 ✓, 8%4=0 ✓
传递性保证: 4%1=0 ✓, 8%1=0 ✓, 8%2=0 ✓ (自动满足)
```

## 另一个例子

```
输入: nums = [3, 4, 16, 8]
排序: [3, 4, 8, 16]

┌───────┬─────┬─────┬─────┬──────┐
│ index │  0  │  1  │  2  │  3   │
├───────┼─────┼─────┼─────┼──────┤
│ nums  │  3  │  4  │  8  │  16  │
│ dp    │  1  │  1  │  2  │  3   │
│parent │ -1  │ -1  │  1  │  2   │
└───────┴─────┴─────┴─────┴──────┘

i=2: 8%3!=0, 8%4==0 → dp[2]=dp[1]+1=2, parent=1
i=3: 16%3!=0, 16%4==0→dp[1]+1=2, 16%8==0→dp[2]+1=3>2 → dp[3]=3, parent=2

回溯: 3→2→1→-1 → [16,8,4] → 反转 [4,8,16]
注意: 3 被排除因为 4%3!=0
```

## 解法概览

| 解法 | 时间 | 空间 | 特点 | 面试 |
|------|------|------|------|------|
| 排序 + DP + parent | O(n^2) | O(n) | 标准 LIS 变种 | ⭐ 必须写出 |
| DP + HashMap 约数枚举 | O(n * sqrt(max)) | O(n) | 大数值场景优化 | Follow-up |
| 递归记忆化 | O(n^2) | O(n) | 自顶向下 DP | 等价写法 |

## 关键提示

1. **排序是第一步**：排序让整除检查变为单向——只需 `nums[i] % nums[j]`（i > j 保证 nums[i] >= nums[j]）。不排序则需双向检查 `a%b==0 || b%a==0`，且无法用 DP。

2. **传递性是正确性的核心保障**：
   ```
   子集 {1, 2, 8}
   链式检查: 2%1==0 ✓, 8%2==0 ✓
   传递性保证: 8%1==0 ✓（自动满足，无需 O(k^2) 两两检查）
   ```

3. **与 LIS 的差异**：
   | | LIS | 本题 |
   |--|-----|------|
   | 转移条件 | `nums[j] < nums[i]` | `nums[i] % nums[j] == 0` |
   | 输出要求 | 仅长度 | 实际子集元素 |
   | 二分优化 | 可以 O(n log n) | 不行（整除不具备二分搜索的单调性） |
   | 路径恢复 | 可选 | 必须 |

4. **dp 初始化为 1 不是 0**：每个元素自身构成长度 1 的合法子集。

5. **parent 初始化为 -1**：表示"无前驱"，也是路径回溯的终止条件。

## 解法详解

### 解法 1: 排序 + DP — O(n^2) / O(n)

**核心步骤**：
```cpp
// 1. 排序
sort(nums.begin(), nums.end());
// 2. DP 填表
for (int i = 1; i < n; i++)
    for (int j = 0; j < i; j++)
        if (nums[i] % nums[j] == 0 && dp[j] + 1 > dp[i]) {
            dp[i] = dp[j] + 1;
            parent[i] = j;
        }
// 3. 找 dp 最大值位置 maxIdx
// 4. 沿 parent 回溯: maxIdx → parent[maxIdx] → ... → -1
// 5. 反转得到答案
```

### 解法 2: HashMap 约数枚举优化 — O(n * sqrt(max)) / O(n)

**优化思路**：解法 1 对每个 i 遍历所有 j < i，O(n)。但实际上只需检查 nums[i] 的约数中存在于数组中的那些。用 HashMap `{值 → (dp长度, 前驱值)}` 存储，然后枚举 nums[i] 的约数（仅 O(sqrt(nums[i]))）进行转移。

**适用场景**：n 大但数值范围有限时更优。

### 解法 3: 递归 + 记忆化

**定义**：`dfs(i)` = 从索引 i 向后能构成的最长整除链长度。
**转移**：`dfs(i) = 1 + max(dfs(j))` 对所有 `j > i` 且 `nums[j] % nums[i] == 0`。
**路径**：用 `next_idx[i]` 记录 i 的后继，最后正向收集。

## 易错点

1. **忘记排序**：不排序则 DP 方向不确定，转移方程无法正确工作。排序是将"无序子集问题"转化为"有序子序列问题"的关键一步。

2. **dp 初始化为 0 而非 1**：每个元素自身是合法子集（长度 1），初始化为 0 会导致所有 dp 值偏小 1。

3. **回溯路径忘记 reverse**：parent 链从后往前（从大到小），输出需要从小到大。

4. **maxIdx 的更新位置**：应在外层 for 循环中（每个 i 填完 dp[i] 后）更新全局最优，不能在内层 j 循环中更新（此时 dp[i] 可能尚未确定最终值）。

5. **只返回长度不返回子集**：题目要求返回实际元素列表，不是长度。必须用 parent 数组恢复路径。

## 复杂度分析

| 解法 | 时间 | 空间 |
|------|------|------|
| 排序 + DP | O(n log n + n^2) = O(n^2) | O(n) |
| HashMap 约数 | O(n log n + n * sqrt(max_val)) | O(n) |
| 递归记忆化 | O(n^2) | O(n) 栈 + 缓存 |

> n = nums.length, max_val = max(nums)

## 面试追问

**Q1: 能否用 O(n log n) 二分优化像 LIS 那样？**
> 不行。LIS 的二分优化依赖"严格递增"的单调性——新元素要么接在某个 tail 后面，要么替换某个 tail。但整除关系不满足这种单调替换性质（例如 6 整除 2 和 3，但 2 和 3 之间无整除关系），所以无法维护类似的 tail 数组。

**Q2: 如果允许重复元素怎么办？**
> 题目保证 distinct。如果有重复（如 [1,1,2]），重复元素互相整除（a%a==0），需要特殊处理——多个相同值都可以放进子集。

**Q3: 为什么不能用贪心？**
> 贪心策略（如"每次选最小的能整除的"）无法保证全局最优。例如 [1,2,3,6,24]：贪心可能走 1→2→6→24（长度4），但 1→3→6→24 也是长度4。DP 穷举所有可能路径才能保证最优。
