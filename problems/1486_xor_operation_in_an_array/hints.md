# 1486. 数组异或操作

## 核心思路

给定 `n` 和 `start`，数组 `nums[i] = start + 2*i`，返回所有元素的 XOR 值。最直观的做法就是**直接模拟**，O(n) 遍历累计 XOR。进阶可以利用**XOR 前缀和的数学规律**做到 O(1)。

## 思维链

1. **读完题的第一反应**：这题很简单，直接 for 循环 XOR 一遍就行了。O(n) 时间 O(1) 空间，n <= 1000 完全没问题。

2. **写代码注意**：`nums[i] = start + 2 * i`，不需要真的创建数组，直接在循环里计算。

3. **有没有更优解？**：其实可以用数学做到 O(1)。先理解一个基础：`XOR(0, n) = 0 ^ 1 ^ 2 ^ ... ^ n` 有四种模式（根据 n % 4）：
   - n % 4 == 0 → n
   - n % 4 == 1 → 1
   - n % 4 == 2 → n + 1
   - n % 4 == 3 → 0

4. **数学推导**：`start + 2*i` 是等差数列，公差为 2。所有元素都是偶数（start 为偶时）或奇数（start 为奇时）。可以把每个数除以 2，利用 XOR(0..n) 的规律计算后再处理最低位。

5. **面试取舍**：直接模拟 O(n) 足够好且不易出错。数学 O(1) 解法是加分项，但容易推导出错。

## 关键提示

1. **XOR 的基本性质**：
   - `a ^ a = 0`（自己 XOR 自己 = 0）
   - `a ^ 0 = a`（任何数 XOR 0 = 自身）
   - 交换律和结合律：顺序无关

2. **不需要创建数组**：题目说"定义数组 nums"，但不需要真的 `new`/`push_back`，直接在循环里计算 `start + 2*i` 即可。

3. **XOR 前缀和规律**（进阶）：
   ```
   f(n) = 0 ^ 1 ^ 2 ^ ... ^ n
   
   n % 4 == 0 → f(n) = n
   n % 4 == 1 → f(n) = 1
   n % 4 == 2 → f(n) = n + 1
   n % 4 == 3 → f(n) = 0
   
   验证:
     f(0) = 0         (0%4=0, ans=0 ✓)
     f(1) = 0^1 = 1   (1%4=1, ans=1 ✓)
     f(2) = 0^1^2 = 3 (2%4=2, ans=2+1=3 ✓)
     f(3) = 3^3 = 0   (3%4=3, ans=0 ✓)
     f(4) = 0^4 = 4   (4%4=0, ans=4 ✓)
   ```

4. **从 XOR 前缀和到本题**：
   ```
   XOR(a..b) = f(b) ^ f(a-1)
   
   本题: XOR of (start, start+2, start+4, ..., start+2*(n-1))
   每个数除以 2: (start/2, start/2+1, ..., start/2+n-1)
   XOR 后乘回 2，再处理最低位
   ```

5. **示例手动推演**：
   ```
   n = 5, start = 0
   nums = [0, 2, 4, 6, 8]
   0 ^ 2 = 2
   2 ^ 4 = 6
   6 ^ 6 = 0
   0 ^ 8 = 8
   答案: 8 ✓
   
   n = 4, start = 3
   nums = [3, 5, 7, 9]
   二进制: 011 ^ 101 = 110(6)
          110 ^ 111 = 001(1)
          001 ^ 1001 = 1000(8)
   答案: 8 ✓
   ```

## 解法详解

### 解法1: 直接模拟 -- O(n) / O(1)  推荐

**思路**：直接循环 n 次，每次 XOR 上 `start + 2*i`。

```cpp
class Solution {
public:
    int xorOperation(int n, int start) {
        int result = 0;
        for (int i = 0; i < n; i++)
            result ^= start + 2 * i;
        return result;
    }
};
```

**简洁明了**，n <= 1000 完全够用。面试中先写这个，被追问再给数学解。

---

### 解法2: 数学 O(1) -- 利用 XOR 前缀和

**核心推导**：

设 `s = start / 2`，`e = start / 2 + n - 1`，每个元素除以 2 后是连续整数 `s, s+1, ..., e`。

利用 `f(n) = 0^1^...^n` 的规律，`XOR(s..e) = f(e) ^ f(s-1)`。

但除以 2 丢掉了最低位。最低位的 XOR 只取决于：n 个奇数中有奇数个 1 → 最低位为 1。

```cpp
class Solution {
public:
    // f(n) = 0 ^ 1 ^ 2 ^ ... ^ n 的 O(1) 计算
    int xorUpTo(int n) {
        switch (n % 4) {
            case 0: return n;
            case 1: return 1;
            case 2: return n + 1;
            case 3: return 0;
        }
        return 0; // unreachable
    }
    
    int xorOperation(int n, int start) {
        // nums[i] = start + 2*i, i = 0..n-1
        // 所有元素右移1位: s, s+1, ..., s+n-1 (s = start/2)
        int s = start / 2;
        int e = s + n - 1;
        
        // XOR(s..e) = f(e) ^ f(s-1)
        int xorShifted = xorUpTo(e) ^ (s > 0 ? xorUpTo(s - 1) : 0);
        
        // 左移回来
        int result = xorShifted << 1;
        
        // 处理最低位: 如果 start 是奇数且 n 是奇数，最低位为 1
        if (n % 2 == 1 && start % 2 == 1) result |= 1;
        
        return result;
    }
};
```

**推导细节**：
- `nums[i] = start + 2*i`，每个数除以 2（右移 1 位）后是 `start/2, start/2+1, ..., start/2+n-1`
- 最低位：每个 `nums[i]` 的最低位等于 `start` 的最低位（因为 `2*i` 最低位是 0）
- n 个相同最低位的 XOR：奇数个 1 → 1，偶数个 1 → 0
- 所以 `start` 为奇数且 `n` 为奇数时最低位为 1

## XOR 知识速查

```
XOR 基本性质:
  a ^ a = 0          (消除)
  a ^ 0 = a          (恒等)
  a ^ b = b ^ a      (交换律)
  (a^b)^c = a^(b^c)  (结合律)

XOR 前缀和 f(n) = 0^1^2^...^n:
  n%4==0 → n
  n%4==1 → 1
  n%4==2 → n+1
  n%4==3 → 0

XOR 区间和:
  XOR(a..b) = f(b) ^ f(a-1)
```

## 易错点

1. **数学解中忘记处理最低位**：右移再左移会丢失最低位信息，必须单独处理。

2. **数学解中 `s = 0` 的边界**：`f(s-1) = f(-1)` 未定义，需要特判 `s > 0`。

3. **混淆 XOR 和 OR**：`^` 是 XOR，`|` 是 OR，面试紧张时容易写错运算符。

4. **不需要创建数组**：声明一个 vector 再 push_back 是浪费，直接循环计算即可。

## 面试追问

**Q1（基础）**：XOR 有哪些基本性质？
> 自反性 `a^a=0`、恒等性 `a^0=a`、交换律、结合律。

**Q2（进阶）**：能否做到 O(1)？
> 可以，利用 `f(n) = 0^1^...^n` 的四周期规律，把等差数列 XOR 转化为连续整数 XOR。

**Q3（相关）**：`0^1^2^...^n` 的规律是怎么来的？
> 核心是相邻两个数（如 2k 和 2k+1）XOR = 1（只有最低位不同）。每 4 个连续整数的 XOR = 0。所以只需看 n % 4 的余数。

**Q4（变体）**：如果数组元素不是等差的而是任意的，怎么找"XOR 和最大的子数组"？
> 这就是 **Maximum XOR Subarray** 问题，需要用 Trie（字典树）+ 前缀 XOR，O(n * 32)。
