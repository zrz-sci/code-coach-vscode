# 3070. 元素和小于等于 k 的子矩阵的数目

## 核心思路

**二维前缀和**。由于所有合法子矩阵必须包含左上角元素 `(0,0)`，所以子矩阵的形态只能是 `grid[0..i][0..j]`（从左上角到某个右下角）。问题简化为：对每个 `(i, j)`，计算从 `(0,0)` 到 `(i,j)` 的矩形元素总和，统计有多少个总和 <= k。

## 思维链

1. **读完题第一反应**：子矩阵要包含左上角 `(0,0)` —— 这个约束极大地简化了问题！一般的"子矩阵计数"需要枚举四个边界 O(n^2 * m^2)，但左上角固定后只需枚举右下角 `(i, j)`，共 O(m * n) 种可能。

2. **怎么计算每个子矩阵的和**：如果对每个 `(i, j)` 都遍历一遍 `grid[0..i][0..j]` 来求和，总时间 O(m^2 * n^2)，太慢了。需要更快的方式 —— **二维前缀和**。

3. **二维前缀和的递推公式**：
   ```
   prefix[i][j] = grid[i][j]
                + prefix[i-1][j]      (上方)
                + prefix[i][j-1]      (左方)
                - prefix[i-1][j-1]    (重叠区域, 减去多加的)
   ```
   这是经典的容斥原理。处理边界：当 `i=0` 或 `j=0` 时，对应的 `prefix[i-1][...]` 或 `prefix[...][j-1]` 视为 0。

4. **可以原地修改**：不需要额外的前缀和数组，直接在 grid 上修改即可（因为每个位置只被读取一次后就可以覆盖）。这样空间从 O(m*n) 降到 O(1)。

5. **最终方案**：遍历所有 `(i, j)`，在遍历过程中原地计算前缀和，如果 `grid[i][j] <= k` 则计数 +1。一遍遍历搞定。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 推荐 |
|------|------|------|------|------|
| 暴力枚举 | 对每个 (i,j) 遍历求和 | O(m^2 * n^2) | O(1) | 理解题意 |
| 二维前缀和 (额外数组) | 用独立的 prefix 数组 | O(m*n) | O(m*n) | 清晰 |
| 二维前缀和 (原地修改) | 直接修改 grid | O(m*n) | O(1) | 面试首选 ⭐ |

## 关键提示

1. **左上角固定 = 只需枚举右下角**：这是本题最重要的简化。一般子矩阵问题需要 O(n^2 * m^2) 枚举四个边界，本题只需 O(n * m)。

2. **二维前缀和的本质是容斥**：
   ```
   ┌────────┬──────┐
   │        │      │
   │  A     │  B   │
   │        │      │
   ├────────┼──────┤
   │  C     │grid  │
   │        │[i][j]│
   └────────┴──────┘
   
   prefix[i][j] = grid[i][j] + (A+B) + (A+C) - A
                = grid[i][j] + prefix[i-1][j] + prefix[i][j-1] - prefix[i-1][j-1]
   ```

3. **原地修改的正确性**：因为我们按行从上到下、列从左到右遍历，当计算 `grid[i][j]` 时，`grid[i-1][j]`、`grid[i][j-1]`、`grid[i-1][j-1]` 都已经被更新为前缀和值了，所以可以直接使用。

4. **不要忘记减去重叠部分**：容斥原理中 `prefix[i-1][j-1]` 被加了两次（一次来自上方，一次来自左方），必须减去一次。

5. **手动模拟验证**（grid = [[7,6,3],[6,6,1]], k = 18）：
   ```
   原始 grid:         前缀和 grid:
   7  6  3             7  13  16
   6  6  1            13  25  29
   
   <= 18 的有: 7, 13, 16, 13 → 4 个  (25 > 18, 29 > 18)
   ```

## 解法详解

### 解法1: 暴力枚举 — O(m^2 * n^2) / O(1)

**思考过程**：对每个右下角 `(i, j)`，从 `(0,0)` 遍历到 `(i,j)` 计算总和。

```cpp
class Solution {
public:
    int countSubmatrices(vector<vector<int>>& grid, int k) {
        int m = grid.size(), n = grid[0].size();
        int count = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                // 计算 grid[0..i][0..j] 的元素总和
                int sum = 0;
                for (int r = 0; r <= i; r++) {
                    for (int c = 0; c <= j; c++) {
                        sum += grid[r][c];
                    }
                }
                if (sum <= k) count++;
            }
        }
        return count;
    }
};
```

**问题**：m, n 最大 1000，暴力是 O(m^2 * n^2) = O(10^12)，超时。但理解这个解法有助于看到前缀和的动机：反复计算的重叠子矩阵和可以复用。

---

### 解法2: 二维前缀和 (额外数组) — O(m*n) / O(m*n)

**思考过程**：预计算一个 prefix 数组，`prefix[i][j]` 存储 `grid[0..i][0..j]` 的总和。然后遍历所有位置，统计 `prefix[i][j] <= k` 的数量。

```
前缀和计算过程 (grid = [[7,2,9],[1,5,0],[2,6,6]], k = 20):

原始:        prefix:
7  2  9      7   9  18
1  5  0      8  15  24
2  6  6     10  23  35

<= 20 的有: 7, 9, 18, 8, 15, 10 → 6 个
```

```cpp
class Solution {
public:
    int countSubmatrices(vector<vector<int>>& grid, int k) {
        int m = grid.size(), n = grid[0].size();
        vector<vector<int>> prefix(m, vector<int>(n, 0));
        int count = 0;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                prefix[i][j] = grid[i][j];
                if (i > 0) prefix[i][j] += prefix[i - 1][j];
                if (j > 0) prefix[i][j] += prefix[i][j - 1];
                if (i > 0 && j > 0) prefix[i][j] -= prefix[i - 1][j - 1];

                if (prefix[i][j] <= k) count++;
            }
        }
        return count;
    }
};
```

---

### 解法3: 二维前缀和 (原地修改) — O(m*n) / O(1) ⭐ 面试首选

**从解法2优化**：不需要额外数组，直接在 grid 上原地计算前缀和。因为每个 `grid[i][j]` 在被覆盖前，只需要它的原始值，而这个原始值在当前步骤中就用到了。

```cpp
class Solution {
public:
    int countSubmatrices(vector<vector<int>>& grid, int k) {
        int m = grid.size(), n = grid[0].size();
        int count = 0;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                // 容斥原理: 加上方 + 加左方 - 减去重叠
                if (i > 0) grid[i][j] += grid[i - 1][j];
                if (j > 0) grid[i][j] += grid[i][j - 1];
                if (i > 0 && j > 0) grid[i][j] -= grid[i - 1][j - 1];

                if (grid[i][j] <= k) count++;
            }
        }
        return count;
    }
};
```

**注意**：原地修改会改变输入数组。如果题目要求不能修改输入，或者后续还需要原始 grid，就用解法2。

## 易错点

1. **漏掉减去重叠部分**：
   ```
   ✗ prefix[i][j] = grid[i][j] + prefix[i-1][j] + prefix[i][j-1];
   ✓ prefix[i][j] = grid[i][j] + prefix[i-1][j] + prefix[i][j-1] - prefix[i-1][j-1];
   ```
   不减去 `prefix[i-1][j-1]` 会导致左上角区域被加了两次。

2. **边界处理遗漏**：
   ```
   ✗ grid[i][j] += grid[i-1][j] + grid[i][j-1] - grid[i-1][j-1]; // i=0 或 j=0 时越界!
   ✓ 需要分别判断 i > 0、j > 0、i > 0 && j > 0
   ```

3. **混淆 "包含左上角" 和 "任意子矩阵"**：
   - 本题左上角固定为 (0,0)，只需枚举右下角
   - 如果子矩阵可以在任意位置，就需要用更复杂的方法（枚举四个边界或前缀和 + 差分）

4. **整数溢出**：
   - 每个元素最大 1000，矩阵最大 1000x1000，前缀和最大 10^9
   - 用 int 类型足够（int 最大约 2.1 * 10^9），但如果元素更大就需要 long long

## 面试追问

**Q1: 为什么原地修改是安全的？**
因为我们按行从上到下、列从左到右遍历。当处理 `(i,j)` 时，`(i-1,j)`、`(i,j-1)`、`(i-1,j-1)` 都已经被更新为前缀和了。而 `grid[i][j]` 的原始值只在当前步骤中使用（加到前缀和公式中），之后就不再需要了。

**Q2: 如果子矩阵不需要包含左上角，而是任意位置呢？**
那就是经典的"子矩阵和 <= k"问题。需要先计算完整的二维前缀和，然后枚举所有子矩阵（四个边界）。用前缀和可以 O(1) 计算任意子矩阵的和，总时间 O(m^2 * n^2)。进一步优化可以固定上下边界、压缩成一维，再配合有序集合做到 O(m^2 * n * log n)。

**Q3: 如果矩阵元素可以为负数，本题的解法还成立吗？**
完全成立。前缀和递推公式对负数同样有效。唯一的区别是前缀和不再单调递增，所以不能用"一旦超过 k 就 break"的剪枝。

**Q4: 如果要求"严格小于 k"而不是"小于等于 k"？**
只需把 `grid[i][j] <= k` 改成 `grid[i][j] < k`，其余完全一样。
