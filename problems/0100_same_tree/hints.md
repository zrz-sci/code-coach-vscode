# 100. 相同的树

## 核心思路

这道题本质上是**同步遍历两棵树**：在同一个位置上，结构和值都必须一致。只要有一处不同（一个有节点一个没有，或值不同），就不是相同的树。

## 思维链

1. **读完题第一反应**：我需要逐个节点比较两棵树。最自然的方式——递归：如果当前两个节点一样，就递归比较它们的左子树和右子树。
2. **什么叫"一样"？** 三个层面：(a) 两个都是 null → 相同；(b) 一个 null 一个不是 → 不同；(c) 都不是 null → 比较值，再递归比较左右子树。
3. **递归好理解，但能不能迭代？** 可以。用栈（DFS）或队列（BFS）同时遍历两棵树，每次取出一对节点做比较。
4. **迭代有什么好处？** 避免递归调用栈深度过大（极端情况下链状树深度 100 层，虽然这题范围很小），并且练习用栈/队列模拟递归是面试常考技能。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 递归 DFS | 同步递归比较两棵树 | O(n) | O(h) | ⭐ 必须写出 |
| 迭代 DFS（栈） | 用栈模拟同步前序遍历 | O(n) | O(h) | 能说出即可 |
| 迭代 BFS（队列） | 用队列逐层同步比较 | O(n) | O(w) | 加分项 |

> n = min(两棵树节点数)，h = 树高，w = 树最大宽度

## 关键提示

- **提示1**：递归终止条件不是一个，而是三个分支：都为 null、一个为 null、都不为 null。把这三个想清楚，递归就写完了。
- **提示2**：这是"双参数递归"——函数接收两棵树的节点，同步向下走。这个框架在 101（对称二叉树）、572（子树）等题中反复出现。
- **提示3**：迭代版本的核心思想——把"递归调用栈"手动变成一个显式的栈/队列，每次放入的是**一对节点**。

```
// 示例1: p = [1,2,3], q = [1,2,3]
//
//     p:       q:
//      1        1        ← 值相同，继续比较子树
//     / \      / \
//    2   3    2   3      ← 左子树(2==2)✓  右子树(3==3)✓
//
// 结果: true

// 示例2: p = [1,2], q = [1,null,2]
//
//     p:       q:
//      1        1        ← 值相同，继续比较子树
//     /          \
//    2            2      ← p.left=2, q.left=null → 结构不同!
//
// 结果: false
```

## 解法详解

### 解法1: 递归 DFS — O(n) / O(h) ⭐ 面试首选

**思考过程**：树天然是递归结构。要判断两棵树是否相同，我只需要回答三个问题：
1. 当前两个节点是不是都为 null？→ 都为 null 说明这条路径上完全匹配，返回 true。
2. 一个为 null 另一个不为 null？→ 结构不同，返回 false。
3. 都不为 null？→ 比较值，再递归比较左子树和右子树。

```cpp
class Solution {
public:
    bool isSameTree(TreeNode* p, TreeNode* q) {
        // 终止条件1: 两个都走到了空节点 — 这条路径完全匹配
        if (!p && !q) return true;
        
        // 终止条件2: 只有一个为空 — 结构不同
        if (!p || !q) return false;
        
        // 终止条件3: 值不同
        if (p->val != q->val) return false;
        
        // 递归比较左子树 AND 右子树（两边都相同才行）
        return isSameTree(p->left, q->left) 
            && isSameTree(p->right, q->right);
    }
};
```

**关键点**：
- 终止条件的顺序很重要：必须先判断 `!p && !q`，再判断 `!p || !q`。如果反过来，两个都为 null 时会被 `!p || !q` 截获返回 false（因为 !null == true）。
- `&&` 短路求值：左子树不同时不会再递归右子树，天然剪枝。

---

### 解法2: 迭代 DFS（栈） — O(n) / O(h)

**从解法1转换**：递归本质上使用的是系统调用栈。我们可以用一个显式栈来模拟同样的过程。每次压入一对节点 (p_node, q_node)，弹出时做比较。

```cpp
class Solution {
public:
    bool isSameTree(TreeNode* p, TreeNode* q) {
        // 栈中存放的是"待比较的节点对"
        stack<pair<TreeNode*, TreeNode*>> stk;
        stk.push({p, q});
        
        while (!stk.empty()) {
            auto [node1, node2] = stk.top();
            stk.pop();
            
            // 都为空 — 这对匹配，继续检查栈中其他对
            if (!node1 && !node2) continue;
            
            // 结构不同 或 值不同 — 立即返回 false
            if (!node1 || !node2) return false;
            if (node1->val != node2->val) return false;
            
            // 把左子树对和右子树对压入栈（顺序不影响正确性）
            stk.push({node1->left, node2->left});
            stk.push({node1->right, node2->right});
        }
        
        return true;  // 所有节点对都匹配
    }
};
```

**关键点**：栈里存的是 **pair**，这是迭代法处理"双参数递归"的通用技巧。

---

### 解法3: 迭代 BFS（队列） — O(n) / O(w)

**换个遍历顺序**：用队列逐层同步比较两棵树。逻辑和栈版本几乎完全一样，只是换成了层序遍历的顺序。

```cpp
class Solution {
public:
    bool isSameTree(TreeNode* p, TreeNode* q) {
        queue<pair<TreeNode*, TreeNode*>> que;
        que.push({p, q});
        
        while (!que.empty()) {
            auto [node1, node2] = que.front();
            que.pop();
            
            if (!node1 && !node2) continue;
            if (!node1 || !node2) return false;
            if (node1->val != node2->val) return false;
            
            // 按层序加入子节点对
            que.push({node1->left, node2->left});
            que.push({node1->right, node2->right});
        }
        
        return true;
    }
};
```

**关键点**：BFS 的空间复杂度取决于树的最大宽度 w（完全二叉树时约 n/2），DFS 取决于树的高度 h（最坏链状树时为 n）。

---

## 解法对比

| | 递归 DFS | 迭代 DFS（栈） | 迭代 BFS（队列） |
|---|---|---|---|
| 代码量 | 最少（5行核心代码） | 中等 | 中等 |
| 空间 | O(h) 调用栈 | O(h) 显式栈 | O(w) 队列 |
| 可读性 | 最直观 | 稍复杂 | 稍复杂 |
| 适用场景 | 日常刷题/面试首选 | 面试追问"不用递归" | 需要层序信息时 |
| 递归深度风险 | 有（但本题 n≤100，无风险） | 无 | 无 |

**面试建议**：先写递归解法（30秒搞定），面试官追问再写迭代版本。

## 易错点

1. **终止条件遗漏 "两个都为 null" 的情况**
   - ✗ 只写 `if (!p || !q) return false;` → 当 p 和 q 都为 null 时返回 false，但它们应该返回 true
   - ✓ 必须先判断 `if (!p && !q) return true;`，再判断 `if (!p || !q) return false;`

2. **迭代版本中 null 节点也要入栈/入队**
   - ✗ 只在非空时才 push → 无法检测"一个有左孩子、一个没有"的情况
   - ✓ 把 null 也 push 进去，在取出时统一判断

3. **混淆"相同的树"和"对称的树"（101题）**
   - 相同的树：`isSame(p->left, q->left) && isSame(p->right, q->right)` — **同侧配对**
   - 对称的树：`isMirror(p->left, q->right) && isMirror(p->right, q->left)` — **交叉配对**

## 面试追问

**Q1: 时间和空间复杂度是多少？最坏情况是什么？**
> 时间 O(n)，n 是两棵树节点数的较小值（最多遍历每个位置一次）。空间最坏 O(n)，当树退化为链表时递归深度为 n。

**Q2: 如果面试官要求不用递归，怎么做？**
> 用显式栈或队列模拟。核心思想：把"递归时隐式传递的参数对"变成栈/队列中显式存储的 pair。参见解法2和解法3。

**Q3: 如果改成判断"对称二叉树"（LeetCode 101），代码要怎么改？**
> 只需改一行：递归调用从 `(p->left, q->left) && (p->right, q->right)` 改为 `(p->left, q->right) && (p->right, q->left)`。其余逻辑完全不变。

**Q4: 如果两棵树非常大，分布在不同机器上，怎么判断？**
> 分别对两棵树做**同一种确定性遍历**（如前序遍历，null 用特殊标记），生成序列化字符串，比较两个字符串是否相同。也可以同步流式遍历，边遍历边比较，不需要先完整序列化。
