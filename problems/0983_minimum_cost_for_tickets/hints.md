# 983. 最低票价 (Minimum Cost For Tickets)

## 难度：Medium | 标签：Array, Dynamic Programming

---

## 题目描述

你提前一年计划了火车旅行。旅行日由数组 `days` 给出（严格递增，1~365）。

三种票：
- 1 天通行证：`costs[0]` 美元
- 7 天通行证：`costs[1]` 美元
- 30 天通行证：`costs[2]` 美元

求覆盖所有旅行日的最低花费。

---

## Hint 1：每个旅行日面临三种决策

在每个旅行日，你可以买 1 天票、7 天票或 30 天票。不同的选择覆盖不同的天数范围，影响后续还需要花多少钱。

```
Day 4 需要旅行:
  选择 A: 买 1 天票 $2, 覆盖 Day 4      → 接下来从 Day 5 继续
  选择 B: 买 7 天票 $7, 覆盖 Day 4~10   → 接下来从 Day 11 继续
  选择 C: 买30天票 $15, 覆盖 Day 4~33   → 接下来从 Day 34 继续
```

**关键**：非旅行日不需要买票，直接跳过。

**贪心为什么不行？** 无法简单比较性价比。例如 days=[1,4,8], costs=[3,7,15]：三张 1 天票 $9，一张 7 天票只能覆盖 2 天但价格 $7。具体选哪个取决于全局，需要 DP。

---

## Hint 2：定义 DP 状态

**dp[i] = 从第 i 天到最后一个旅行日的最低花费**

转移方程：
- 非旅行日：`dp[i] = dp[i+1]`（不用花钱）
- 旅行日：`dp[i] = min(costs[0]+dp[i+1], costs[1]+dp[i+7], costs[2]+dp[i+30])`

从后往前填表。超过最后旅行日的 dp 值全为 0。

## Hint 5：实现细节

**边界处理**：`dp[i+7]` 和 `dp[i+30]` 可能越界。两种解决方式：
1. dp 数组多开 30 个位置（推荐，简单）
2. 用 `min(i+7, lastDay+1)` 截断索引

**判断旅行日**：用 `unordered_set` 存 `days`，O(1) 查询。

**从前往后 DP 也行**：
- `dp[i]` = 覆盖前 i 个旅行日的最低花费
- 对每个旅行日 `days[i]`，向前找 7 天/30 天覆盖范围的起点
- 两种方向等价，从后往前更直观

---

## 完整代码

```cpp
class Solution {
public:
    int mincostTickets(vector<int>& days, vector<int>& costs) {
        unordered_set<int> travelDays(days.begin(), days.end());
        int lastDay = days.back();

        // 多开 30 个位置避免越界
        vector<int> dp(lastDay + 31, 0);

        for (int i = lastDay; i >= 1; i--) {
            if (travelDays.count(i) == 0) {
                dp[i] = dp[i + 1];  // 非旅行日
            } else {
                dp[i] = min({
                    costs[0] + dp[i + 1],   // 1 天票
                    costs[1] + dp[i + 7],   // 7 天票
                    costs[2] + dp[i + 30]   // 30 天票
                });
            }
        }

        return dp[1];
    }
};
```

## 常见错误

1. **dp 数组不够大**：`i+30` 越界，需要多开 30 个位置或做边界检查。
2. **忘记非旅行日直接跳过**：非旅行日 `dp[i] = dp[i+1]`，不要也做三种选择。
3. **dp 初始值设错**：超出最后旅行日的 dp 值应为 0，不是 INT_MAX。
4. **误以为 costs 有单调性**：costs[2] 不一定 > costs[1]，DP 自动选最优。

## 面试追问

| 追问 | 关键点 |
|------|--------|
| 新增 365 天年票？ | 加一个分支 `costs[3] + dp[i+365]` |
| 通行证天数不固定？ | 泛化为 `durations[]` 数组，循环尝试每种 |
| 要输出具体买票方案？ | DP 同时记录每个状态的最优选择，回溯重建方案 |
| 为什么贪心不行？ | 无法简单比较性价比，7 天票可能覆盖多个旅行日更划算 |
