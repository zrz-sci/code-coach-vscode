# 610. Triangle Judgement (判断三角形)

**难度**: Easy | **标签**: Database

## 核心思路

三角形成立的充要条件: **任意两边之和大于第三边**。即需要同时满足:
- `x + y > z`
- `x + z > y`
- `y + z > x`

在 SQL 中使用 `CASE WHEN` 或 `IF` 函数对三个条件取 AND, 满足则输出 `'Yes'`, 否则输出 `'No'`。

## 思维链

1. **回忆三角形判定定理**: 任意两边之和 > 第三边
2. **三个不等式**: x+y>z AND x+z>y AND y+z>x
3. **SQL 实现**: CASE WHEN 三个条件 AND 连接 → 'Yes' ELSE 'No'
4. **输出列**: 保留原始 x, y, z 列, 新增 `triangle` 列
5. **边界情况**: 等腰/等边三角形也满足严格不等式 (题目用的是边长, 都是正整数)
6. **简化**: 由于 x, y, z 都是正整数, 实际上只需检查最大边 < 另外两边之和

## 解法概览

| 解法 | 思路 | 时间复杂度 | 推荐度 |
|------|------|-----------|--------|
| CASE WHEN 三条件 | 三个不等式 AND 判断 | O(n) | ⭐⭐⭐⭐⭐ |
| IF 函数 | MySQL IF 简写 | O(n) | ⭐⭐⭐⭐ |
| 只判最大边 | 找最大边, 判断 < 另两边和 | O(n) | ⭐⭐⭐ |

## 关键提示

1. 三个条件必须同时满足, 用 `AND` 连接
2. 严格大于号 `>`, 不是 `>=` (等于时退化为直线, 不构成三角形)
3. 题目保证 x, y, z 都是正整数, 无需处理零或负数
4. 输出列名必须是 `triangle`, 值为 `'Yes'` 或 `'No'` (注意大小写)
5. 数学优化: 对正整数, 只要 `最大边 < 另两边之和` 即可, 但直接写三个条件更直观

## 解法详解

### 解法一: CASE WHEN (推荐)

```sql
SELECT
    x, y, z,
    CASE
        WHEN x + y > z AND x + z > y AND y + z > x THEN 'Yes'
        ELSE 'No'
    END AS triangle
FROM Triangle;
```

**思路**: 直接翻译三角形不等式定理。三个条件全部满足就是三角形。

### 解法二: IF 函数 (MySQL)

```sql
SELECT
    x, y, z,
    IF(x + y > z AND x + z > y AND y + z > x, 'Yes', 'No') AS triangle
FROM Triangle;
```

**思路**: IF 是 CASE 的语法糖, 更简洁但仅限 MySQL。

### 解法三: 只判最大边 (数学优化)

```sql
SELECT
    x, y, z,
    CASE
        WHEN GREATEST(x, y, z) < (x + y + z - GREATEST(x, y, z)) THEN 'Yes'
        ELSE 'No'
    END AS triangle
FROM Triangle;
```

**思路**: 三角形不等式等价于 "最大边 < 另两边之和"。用 `GREATEST` 找最大边, 另两边和 = 总和 - 最大边。

## 易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| ✗ `WHEN x + y > z` 只写一个条件 | ✓ 三个条件全部 AND | 必须检查所有三组两边之和 |
| ✗ `x + y >= z` 用了大于等于 | ✓ `x + y > z` 严格大于 | 等于时三点共线, 不构成三角形 |
| ✗ 输出 `'yes'` 小写 | ✓ 输出 `'Yes'` 首字母大写 | 需与题目要求的格式严格匹配 |
| ✗ 只判断 `x + y > z` 因为 "x,y 较小" | ✓ 不能假设列的大小关系 | 表中 x, y, z 没有排序保证 |

## 面试追问

**Q1: 如果列中可能包含 0 或负数, 需要额外处理吗?**

A: 需要。如果存在非正数, 应先过滤 `WHERE x > 0 AND y > 0 AND z > 0`, 或在 CASE 中增加额外分支。非正数边长在几何学上无意义, 应输出 'No'。不过本题保证都是正整数。

**Q2: 为什么 "任意两边之和大于第三边" 是充要条件?**

A: 必要性: 在三角形中, 两点间直线最短, 所以经过第三个顶点的折线一定比直线长。充分性: 当三条边满足该不等式时, 可以证明存在唯一三角形 (SSS 定理)。等价简化形式: 最长边严格小于其余两边之和。

**Q3: 如果表有百万行, 这个查询有性能问题吗? 如何优化?**

A: 没有性能问题。查询是逐行判断, 无 JOIN 无子查询, 时间复杂度 O(n)。每行只做三次加法和三次比较, 是全表扫描的最优模式。唯一可优化的是确保不存在不必要的索引扫描。
