# 62. 不同路径

## 核心思路

从网格左上角到右下角，每步只能向右或向下，总共需要走 `(m-1)` 步下 + `(n-1)` 步右，本质上是一个**路径计数问题**，可以用 DP 填表，也可以用组合数学直接算"从 (m+n-2) 步中选 (m-1) 步向下"。

## 思维链

1. **读完题第一反应**：从起点到终点有多少条路？每一步有两个选择（下/右），可以用递归穷举所有路径。
2. **暴力递归的瓶颈**：画出递归树发现大量重叠子问题——到达同一个格子 `(i, j)` 的路径数被反复计算。例如 `(1,1)` 可以从 `(0,1)` 向下到达，也可以从 `(1,0)` 向右到达，两条分支都会再去算 `(1,1)` 到终点的路径数。
3. **加记忆化 → DP**：既然有重叠子问题，加 memo 就变成记忆化搜索；翻译成递推就是经典二维 DP：`dp[i][j] = dp[i-1][j] + dp[i][j-1]`。
4. **空间优化**：`dp[i][j]` 只依赖上一行的 `dp[i-1][j]` 和同行左边的 `dp[i][j-1]`，所以可以用一维滚动数组。
5. **数学直接算**：总共走 `m-1+n-1 = m+n-2` 步，其中选 `m-1` 步向下（或 `n-1` 步向右），答案就是组合数 `C(m+n-2, m-1)`，O(min(m,n)) 即可算出。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力递归 | DFS 穷举所有路径 | O(2^(m+n)) | O(m+n) | 能说出即可 |
| 二维 DP | `dp[i][j] = dp[i-1][j] + dp[i][j-1]` | O(m×n) | O(m×n) | ⭐ 必须写出 |
| 一维 DP（空间优化） | 滚动数组压缩到一行 | O(m×n) | O(n) | ⭐ 必须写出 |
| 组合数学 | `C(m+n-2, m-1)` | O(min(m,n)) | O(1) | 加分项 |

## 关键提示

1. **想想终点的前一步**：机器人到达 `(i, j)` 只能从上面 `(i-1, j)` 或左边 `(i, j-1)` 来，这直接给出了状态转移方程。
2. **第一行和第一列**：机器人只能一直向右走到第一行的任意格子，只能一直向下走到第一列的任意格子，所以 `dp[0][j] = dp[i][0] = 1`。
3. **空间优化的关键**：当你逐行填表时，`dp[i-1][j]` 其实就是"当前一维数组中还没被更新的旧值"，`dp[i][j-1]` 是"刚更新完的左边的值"，所以 `dp[j] += dp[j-1]` 就搞定了（`dp[j]` 旧值 = 上方，`dp[j-1]` 新值 = 左方）。
4. **组合数思路**：不需要排列组合公式表，只需要意识到"总共走 m+n-2 步，选哪几步向下"——这是高中排列组合的直接应用。
5. **组合数计算时防溢出**：不要先算分子再除分母，应该边乘边除，保证中间结果是整数。

```
// 3×7 网格的 DP 填表过程:
//
//   j→  0  1  2  3  4  5  6
// i↓
//  0   [1  1  1  1  1  1  1]   ← 第一行全是1
//  1   [1  2  3  4  5  6  7]
//  2   [1  3  6 10 15 21 28]   ← dp[2][6] = 28 = 答案
//
// dp[i][j] = dp[i-1][j] + dp[i][j-1]
//            (上方)       (左方)
```

## 解法详解

### 解法1: 暴力递归 — O(2^(m+n)) / O(m+n)

**思考过程**: 最直觉的做法——站在 `(i, j)`，要去 `(m-1, n-1)`，可以向下走或向右走，递归地把两个方向的路径数加起来。到达终点返回 1，越界返回 0。

```cpp
class Solution {
public:
    int uniquePaths(int m, int n) {
        return dfs(0, 0, m, n);
    }
    
    int dfs(int i, int j, int m, int n) {
        if (i == m - 1 && j == n - 1) return 1;  // 到达终点，找到一条路径
        if (i >= m || j >= n) return 0;            // 越界，无效路径
        return dfs(i + 1, j, m, n) + dfs(i, j + 1, m, n);
    }
};
```

**关键点**: 这个解法会 TLE。画出递归树你会发现 `dfs(1,1)` 被 `dfs(0,1)` 和 `dfs(1,0)` 分别调用了一次，越往下重复越多。这就是经典的"重叠子问题"，提示我们用 DP。

```
// 递归树 (m=3, n=3):
//                    (0,0)
//                   /     \
//               (1,0)      (0,1)
//              /    \      /    \
//          (2,0)  (1,1) (1,1)  (0,2)    ← (1,1) 重复计算!
//          / \    / \    / \    / \
//        ... ... ... ... ... ... ... ...
```

### 解法2: 记忆化搜索（自顶向下 DP）— O(m×n) / O(m×n)

**从解法1优化**: 暴力递归的瓶颈是重复计算。加一个 memo 数组，算过的 `(i, j)` 直接返回，每个格子只算一次。

```cpp
class Solution {
public:
    int uniquePaths(int m, int n) {
        vector<vector<int>> memo(m, vector<int>(n, -1));
        return dfs(0, 0, m, n, memo);
    }
    
    int dfs(int i, int j, int m, int n, vector<vector<int>>& memo) {
        if (i == m - 1 && j == n - 1) return 1;
        if (i >= m || j >= n) return 0;
        if (memo[i][j] != -1) return memo[i][j];  // 已经算过，直接返回
        memo[i][j] = dfs(i + 1, j, m, n, memo) + dfs(i, j + 1, m, n, memo);
        return memo[i][j];
    }
};
```

### 解法3: 二维 DP（自底向上）— O(m×n) / O(m×n) ⭐ 面试首选

**从记忆化到递推**: 把递归翻译成 for 循环。`dp[i][j]` 表示从起点 `(0,0)` 到 `(i,j)` 的路径数。

```cpp
class Solution {
public:
    int uniquePaths(int m, int n) {
        vector<vector<int>> dp(m, vector<int>(n, 1));
        // 第一行和第一列都是1（只有一种走法：一直向右或一直向下）
        
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                // 只能从上方或左方到达 (i,j)
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }
        return dp[m - 1][n - 1];
    }
};
```

**关键点**: 初始化时整个数组填 1，这样第一行和第一列自动正确，不需要单独处理。

### 解法4: 一维 DP（空间优化）— O(m×n) / O(n) ⭐ 必须掌握

**空间优化思路**: `dp[i][j]` 只依赖 `dp[i-1][j]`（正上方）和 `dp[i][j-1]`（左边）。逐行填表时，用一维数组 `dp[j]`：更新前的 `dp[j]` 就是上一行的值（上方），`dp[j-1]` 是本行刚更新的值（左方）。

```cpp
class Solution {
public:
    int uniquePaths(int m, int n) {
        vector<int> dp(n, 1);  // 初始化第一行，全是1
        
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                // dp[j](旧) = 上方的值, dp[j-1](新) = 左方的值
                dp[j] += dp[j - 1];
            }
        }
        return dp[n - 1];
    }
};
```

```
// 一维滚动过程 (m=3, n=4):
//
// 初始 (第0行): [1, 1, 1, 1]
//
// i=1: j=1: dp[1] += dp[0] → 1+1=2
//      j=2: dp[2] += dp[1] → 1+2=3
//      j=3: dp[3] += dp[2] → 1+3=4
//      结果: [1, 2, 3, 4]
//
// i=2: j=1: dp[1] += dp[0] → 2+1=3
//      j=2: dp[2] += dp[1] → 3+3=6
//      j=3: dp[3] += dp[2] → 4+6=10
//      结果: [1, 3, 6, 10]  → dp[3]=10 就是答案
```

### 解法5: 组合数学 — O(min(m,n)) / O(1) — 加分项

**完全不同的角度**: 从 `(0,0)` 到 `(m-1, n-1)` 必须走 `(m-1)` 步下 + `(n-1)` 步右，共 `m+n-2` 步。问题变成：从 `m+n-2` 个位置中选 `m-1` 个放"下"，其余放"右"。答案 = `C(m+n-2, m-1)`。

```cpp
class Solution {
public:
    int uniquePaths(int m, int n) {
        // C(m+n-2, min(m-1, n-1))
        // 选较小的那个作为 k，减少计算量
        int N = m + n - 2;
        int k = min(m - 1, n - 1);
        
        // C(N, k) = N! / (k! * (N-k)!)
        //         = (N * (N-1) * ... * (N-k+1)) / (1 * 2 * ... * k)
        // 边乘边除，保证中间结果是整数
        long long result = 1;
        for (int i = 0; i < k; i++) {
            result *= (N - i);    // 分子：N, N-1, ..., N-k+1
            result /= (i + 1);   // 分母：1, 2, ..., k
        }
        return (int)result;
    }
};
```

**为什么边乘边除是安全的？** 因为连续 k 个整数的乘积一定能被 k! 整除。具体来说，`N*(N-1)*...*(N-i+1)` 一定能被 `(i+1)!` 整除（这是组合数的性质，组合数永远是整数）。

## 解法对比

| | 暴力递归 | 记忆化搜索 | 二维 DP | 一维 DP | 组合数学 |
|---|---|---|---|---|---|
| 时间 | O(2^(m+n)) | O(m×n) | O(m×n) | O(m×n) | O(min(m,n)) |
| 空间 | O(m+n) | O(m×n) | O(m×n) | O(n) | O(1) |
| 难度 | 最简单 | 简单 | 简单 | 需理解滚动 | 需数学直觉 |
| 面试 | 说思路 | 过渡用 | 必须写 | 必须写 | 加分项 |

**关键区别**: 
- 暴力→记忆化：只加了一个 memo 数组，消除重叠子问题
- 记忆化→递推：自顶向下变自底向上，消除递归栈开销
- 二维→一维：利用"只依赖上一行"的特性，压缩空间
- DP→组合数：跳出"逐格计算"思维，直接用数学公式

## 易错点

1. **一维 DP 内层循环从 j=1 开始，不是 j=0**
   - ✗ `for (int j = 0; j < n; j++)` → `dp[0]` 会被错误累加
   - ✓ `for (int j = 1; j < n; j++)` → `dp[0]` 始终是 1（最左列只有一条路）

2. **组合数计算用 int 会溢出**
   - ✗ `int result = 1; result *= (N - i);` → 中间乘积可能超过 int 范围
   - ✓ `long long result = 1;` → 用 long long 存中间结果

3. **组合数先乘后除的顺序不能反**
   - ✗ 先算完所有分子再除 → 中间结果爆 long long
   - ✓ 每乘一个分子就除一个分母 → `result = result * (N-i) / (i+1)`

4. **二维 DP 初始化漏掉边界**
   - ✗ `dp` 全初始化为 0，忘了设第一行第一列 → 答案全是 0
   - ✓ 全初始化为 1，或者显式设 `dp[i][0] = dp[0][j] = 1`

## 面试追问

**Q1: 暴力递归的时间复杂度是多少？为什么？**
→ O(2^(m+n-2))。每一步有两个选择（下/右），总共走 m+n-2 步，所以是指数级。但实际上因为有些路径提前到达终点，比 2^(m+n-2) 小一些，精确值就是 C(m+n-2, m-1)。

**Q2: 能否把空间优化到 O(min(m,n))？**
→ 一维 DP 用的是 O(n)，如果 m < n，可以交换 m 和 n（因为 C(m+n-2, m-1) = C(m+n-2, n-1)），让较短的维度做数组长度，空间变为 O(min(m,n))。

**Q3: 如果网格中有障碍物（某些格子不能走），怎么改？**
→ 这就是 [63. 不同路径 II](https://leetcode.cn/problems/unique-paths-ii/)。只需在状态转移时判断：如果 `grid[i][j] == 1`（有障碍），则 `dp[i][j] = 0`。一维 DP 版本中，遇到障碍直接 `dp[j] = 0`。

**Q4: 如果允许向四个方向走（上下左右），但不能重复访问，怎么算？**
→ 这就不能用 DP 了（因为有"回头"的可能，不满足无后效性）。需要用回溯/DFS + visited 数组来穷举所有路径。
