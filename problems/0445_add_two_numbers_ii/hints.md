# 445. 两数相加 II

## 核心思路

链表从**高位到低位**存储数字，但加法需要从**低位开始**。核心问题：**如何在不反转链表的情况下实现从低位到高位的加法？**

本题是 LeetCode 2 (两数相加) 的变体。LC 2 中链表是低位在前，可以直接从头遍历相加。本题链表高位在前，必须先到达末尾（低位），才能开始加法。

## 思维链

1. **读完题第一反应** -- 链表版的大数相加，但数字是正序存放（高位在前），加法却要从低位开始。和 LC 2 的区别就在于数字存储方向。

2. **最直接的做法** -- 反转两个链表，变成 LC 2 的形式，加完再反转回来。这是最好理解的方式。

3. **不反转怎么办？** -- 需要一种数据结构，让我们"先进后出"地访问链表节点 -- 这就是**栈**！把链表元素依次入栈，弹出时自然从低位开始。

4. **怎么构建结果链表？** -- 我们从低位开始计算，但结果链表需要高位在前。如果用常规的尾插法，最后还得反转。用**头插法**就完美解决：每次把新计算出的节点插到链表头部，自然形成高位在前的顺序。

5. **进位如何处理？** -- 和 LC 2 一样，用一个 `carry` 变量。循环条件是"栈不空 OR carry > 0"，确保最高位的进位不会丢失。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 反转链表 | 反转后按 LC 2 的方式加，加完再反转 | O(n+m) | O(1) | 基础做法 |
| 双栈法 | 用栈模拟从低位到高位访问 | O(n+m) | O(n+m) | 推荐（不修改原链表） |

## 关键提示

1. **栈的作用**：将链表从"高位->低位"的访问顺序变为"低位->高位"。本质上是用栈模拟了反转链表的效果，但不修改原始链表。

2. **头插法建链表**：`new ListNode(digit, head)` 每次把新节点插到头部。因为我们是从低位到高位计算的，但结果链表要求高位在前，头插法正好把后算出的高位放在前面。

3. **进位处理**：和 LC 2 完全一样，别忘了最后 `carry > 0` 时还要再加一个节点。例如 999 + 1 = 1000，最后 carry=1 必须处理。

4. **Follow-up**：题目问能否不反转输入链表？双栈法就是答案。栈空间 O(n+m)，但保持了输入链表不变。

## 解法详解

### 解法1: 反转链表 -- O(n+m) / O(1)

**思考过程**：最直觉的做法 -- 反转两个链表，就变成了 LC 2 的标准问题。加完之后把结果再反转回来。

```
原始链表:
  l1: 7 -> 2 -> 4 -> 3     (代表 7243)
  l2: 5 -> 6 -> 4           (代表 564)

Step 1: 反转
  l1: 3 -> 4 -> 2 -> 7
  l2: 4 -> 6 -> 5

Step 2: 从低位到高位相加 (和 LC 2 一样)
  3+4 = 7, carry=0   -> 7
  4+6 = 10, carry=1  -> 0
  2+5+1 = 8, carry=0 -> 8
  7+0 = 7, carry=0   -> 7
  结果: 7 -> 0 -> 8 -> 7

Step 3: 反转结果
  7 -> 8 -> 0 -> 7  (代表 7807)
```

```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        while (head) {
            ListNode* next = head->next;
            head->next = prev;
            prev = head;
            head = next;
        }
        return prev;
    }

    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        l1 = reverseList(l1);
        l2 = reverseList(l2);

        ListNode dummy(0);
        ListNode* cur = &dummy;
        int carry = 0;

        while (l1 || l2 || carry) {
            int sum = carry;
            if (l1) { sum += l1->val; l1 = l1->next; }
            if (l2) { sum += l2->val; l2 = l2->next; }
            carry = sum / 10;
            cur->next = new ListNode(sum % 10);
            cur = cur->next;
        }

        return reverseList(dummy.next);
    }
};
```

**优缺点**：空间 O(1)（不计输出），但修改了原始链表。如果题目要求不修改输入，则不能用此方法。

---

### 解法2: 双栈法 -- O(n+m) / O(n+m)（推荐）

**思考过程**：不修改原链表，用两个栈分别存放两个链表的值。弹栈时自然从低位开始，用头插法构建结果。

```
指针图 -- 双栈法过程:

Step 1: 遍历链表，值入栈
  l1: 7 -> 2 -> 4 -> 3
  s1: | 3 |    (栈顶)
      | 4 |
      | 2 |
      | 7 |    (栈底)

  l2: 5 -> 6 -> 4
  s2: | 4 |    (栈顶)
      | 6 |
      | 5 |    (栈底)

Step 2: 弹栈相加 + 头插法建链表

  弹出 s1=3, s2=4  -> sum=7+0=7,  carry=0, digit=7
  head: [7] -> null

  弹出 s1=4, s2=6  -> sum=10+0=10, carry=1, digit=0
  head: [0] -> [7] -> null

  弹出 s1=2, s2=5  -> sum=7+1=8,  carry=0, digit=8
  head: [8] -> [0] -> [7] -> null

  弹出 s1=7, s2空  -> sum=7+0=7,  carry=0, digit=7
  head: [7] -> [8] -> [0] -> [7] -> null

结果: 7 -> 8 -> 0 -> 7  (代表 7807)
```

```cpp
class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        stack<int> s1, s2;
        for (ListNode* p = l1; p; p = p->next) s1.push(p->val);
        for (ListNode* p = l2; p; p = p->next) s2.push(p->val);

        int carry = 0;
        ListNode* head = nullptr;

        while (!s1.empty() || !s2.empty() || carry) {
            int sum = carry;
            if (!s1.empty()) { sum += s1.top(); s1.pop(); }
            if (!s2.empty()) { sum += s2.top(); s2.pop(); }
            carry = sum / 10;
            head = new ListNode(sum % 10, head); // 头插法
        }
        return head;
    }
};
```

**头插法详解**：`new ListNode(sum % 10, head)` 创建新节点，其 next 指向当前 head，然后更新 head 为新节点。这样每次新节点都插在最前面，最先算出的低位在最后，最后算出的高位在最前，正好符合题目要求。

## 解法对比

| | 反转链表 | 双栈法 |
|---|---|---|
| 时间 | O(n+m) | O(n+m) |
| 空间 | O(1) | O(n+m) |
| 修改原链表 | 是 | 否 |
| 代码简洁度 | 中 | 高 |
| Follow-up | 不满足 | 满足 |
| 推荐场景 | 允许修改输入时 | 面试首选 |

## 易错点

1. **忘记处理最终进位**：如 999 + 1 = 1000，最后 carry=1 要额外创建节点。循环条件写成 `while (!s1.empty() || !s2.empty() || carry)` 就能自动处理。

2. **头插法方向搞反**：结果链表应该是高位在前。我们从低位开始算，用头插法自然把低位放到后面、高位放到前面。如果误用尾插法，结果就是低位在前，需要额外反转。

3. **栈弹出前忘记判空**：弹栈时必须先检查 `!s1.empty()`，否则对空栈调用 `top()` 和 `pop()` 是未定义行为。

4. **反转法忘记反转结果**：反转法需要三次反转：反转 l1、反转 l2、反转结果。漏掉任何一次都会得到错误答案。

## 面试追问

**Q1: 双栈法和反转法的本质区别是什么？**
反转法修改了原始链表结构（破坏性操作），双栈法用额外空间保存数据，不修改原链表。如果调用方后续还需要使用原链表，反转法就不适合（除非加完后再反转回来，但那样代码更复杂）。

**Q2: 能否不用栈也不反转链表？**
可以。先遍历两个链表得到长度，对齐后从高位到低位相加（不处理进位），再从低位到高位处理进位。这种方法实现更复杂，面试中不推荐。

**Q3: 如果两个链表长度差距很大（比如一个 100 位一个 1 位），有什么影响？**
没有影响。栈/反转法都是 O(n+m)，不会因为长度不均匀而性能下降。短链表遍历完后，循环中对应的 `if (!s2.empty())` 自动跳过。

**Q4: 和 LC 2 相比，本题的核心难度在哪？**
LC 2 链表低位在前，直接从头遍历就能配对对应位。本题高位在前，需要先到达末尾才能开始相加。解决的关键是"反转访问顺序"，栈是最优雅的选择。
