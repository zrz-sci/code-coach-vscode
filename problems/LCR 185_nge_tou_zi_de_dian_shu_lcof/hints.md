# LCR 185. 统计结果概率

## 核心思路

**动态规划**。n 个骰子，求所有可能总和的概率分布。用 DP 逐个骰子累加：`dp[j]` 表示当前骰子数下总和为 j 的概率。每增加一个骰子，新概率从旧概率转移而来（每个面的概率为 1/6）。

## 思维链

1. **读完题第一反应**：n 个骰子，每个骰子有 1-6 六个面。总和范围是 [n, 6n]，共 5n+1 个可能的值。需要求每个可能总和的概率。

2. **暴力方法**：枚举所有可能的组合（6^n 种），统计每种总和的出现次数，再除以 6^n。时间 O(6^n)，n=11 时约 3.6 亿，勉强可以但不优雅。

3. **DP 的直觉**：骰子是一个个扔的。扔完第 i 个骰子后，总和的概率分布只取决于扔完前 i-1 个骰子后的概率分布。这是典型的"阶段性决策"→ 动态规划。

4. **状态定义**：
   - `dp[j]` = 当前扔了 i 个骰子，总和恰好为 j 的概率
   - 初始状态（1 个骰子）：`dp[0..5] = 1/6`（总和 1-6 各有 1/6 概率）
   - 注意：这里用 0-indexed，`dp[j]` 对应实际总和 `j + i`

5. **状态转移**：增加第 i 个骰子时，对于旧状态中的每个总和 j（概率为 `dp[j]`），新骰子可以出 1-6，所以新的总和 j+0, j+1, ..., j+5 各增加 `dp[j] * 1/6` 的概率。

6. **空间优化**：每轮创建新数组 `tmp`，避免覆盖旧值。也可以理解为"滚动数组"。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 推荐 |
|------|------|------|------|------|
| 暴力枚举 | 枚举 6^n 种组合 | O(6^n) | O(5n) | n 很小时可行 |
| DP + 二维数组 | dp[i][j] = i个骰子总和j的概率 | O(n^2) | O(n^2) | 清晰 |
| DP + 滚动数组 | 每轮用新数组替换旧数组 | O(n^2) | O(n) | 面试首选 ⭐ |

> 更精确的时间: O(n * 5n * 6) = O(30n^2) = O(n^2)

## 关键提示

1. **总和的范围**：n 个骰子的总和范围是 [n, 6n]，共 5n+1 种可能。dp 数组大小为 5n+1。

2. **0-indexed 技巧**：把实际总和偏移，`dp[j]` 对应实际总和 `j + n`。这样数组下标从 0 开始，大小为 5n+1。1 个骰子时，`dp[0..5]` 对应总和 1-6。

3. **转移方向**：对旧 dp 中的每个状态 j，向新数组的 j+0, j+1, ..., j+5 转移（骰子新出的点数 1-6 对应偏移 0-5）。

4. **概率而非计数**：每次转移乘以 1/6（新骰子每个面的概率）。也可以用计数（整数），最后统一除以 6^n，但用概率更直观。

5. **滚动数组**：每轮创建新数组 `tmp`，旧的 `dp` 用完后被替换。不需要保留历史数据。

6. **DP 转移可视化**：
   ```
   骰子 i:  dp = [...旧概率...]
                    ↓
   骰子 i+1: tmp[j+0] += dp[j]/6  (新骰子出1)
              tmp[j+1] += dp[j]/6  (新骰子出2)
              tmp[j+2] += dp[j]/6  (新骰子出3)
              tmp[j+3] += dp[j]/6  (新骰子出4)
              tmp[j+4] += dp[j]/6  (新骰子出5)
              tmp[j+5] += dp[j]/6  (新骰子出6)
   ```

## 解法详解

### 解法1: DP + 滚动数组 — O(n^2) / O(n) ⭐ 面试首选

```cpp
class Solution {
public:
    vector<double> statisticsProbability(int num) {
        // 初始化: 1个骰子, 6个面各 1/6 概率
        vector<double> dp(6, 1.0 / 6.0);

        // 逐个增加骰子
        for (int i = 2; i <= num; i++) {
            // i 个骰子的总和范围: [i, 6i], 共 5i+1 个值
            vector<double> tmp(5 * i + 1, 0.0);

            for (int j = 0; j < (int)dp.size(); j++) {
                // 对旧 dp[j], 新骰子出 1-6 → 偏移 0-5
                for (int k = 0; k < 6; k++) {
                    tmp[j + k] += dp[j] / 6.0;
                }
            }
            dp = tmp; // 滚动: 新数组替换旧数组
        }
        return dp;
    }
};
```

### 解法2: DP + 二维数组 — O(n^2) / O(n^2)

**更清晰的状态定义**，方便理解但空间更大：

```cpp
class Solution {
public:
    vector<double> statisticsProbability(int num) {
        // dp[i][j] = i个骰子总和为 j+i 的概率
        // 第 i 个骰子的 dp 数组大小为 5*i+1
        vector<vector<double>> dp(num + 1);

        // 基础: 1个骰子
        dp[1].resize(6, 1.0 / 6.0);

        // 递推
        for (int i = 2; i <= num; i++) {
            dp[i].resize(5 * i + 1, 0.0);
            for (int j = 0; j < (int)dp[i - 1].size(); j++) {
                for (int k = 0; k < 6; k++) {
                    dp[i][j + k] += dp[i - 1][j] / 6.0;
                }
            }
        }
        return dp[num];
    }
};
```

| | 暴力枚举 | DP + 二维 | DP + 滚动 |
|---|---|---|---|
| 时间 | O(6^n) | O(n^2) | O(n^2) |
| 空间 | O(5n) | O(n^2) | O(n) |
| n=11 运行 | ~3.6亿次 | ~3300次 | ~3300次 |
| 推荐 | 不推荐 | 理解用 | 面试首选 |

## 易错点

1. **新数组 tmp 用旧数组 dp 的循环混淆**：
   ```
   ✗ 直接在 dp 上修改 (dp[j+k] += dp[j]/6.0)
     → 旧值被覆盖, 后续转移使用了已被修改的值
   ✓ 创建新数组 tmp, tmp[j+k] += dp[j]/6.0
   ```

2. **数组大小错误**：
   ```
   ✗ tmp 大小 = 6 * i  (太大了, 浪费空间)
   ✗ tmp 大小 = 5 * i  (少1, 最大总和放不下)
   ✓ tmp 大小 = 5 * i + 1  (范围 [i, 6i] 共 5i+1 个值)
   ```

3. **0-indexed 和 1-indexed 混淆**：
   ```
   dp[0] 对应总和 n (最小值)
   dp[5n] 对应总和 6n (最大值)
   如果搞混了偏移量, 转移公式 j+k 的范围会错
   ```

4. **概率精度问题**：
   ```
   ✗ 用整数计数, 最后除以 6^n (6^11 ≈ 3.6 * 10^8, 可能溢出)
   ✓ 每步都用 double 概率, 避免大整数
   ```

5. **初始化错误**：
   ```
   ✗ dp = {1/6, 1/6, 1/6, 1/6, 1/6, 1/6}  (整数除法! 全是0)
   ✓ dp = {1.0/6.0, ...} 或 vector<double>(6, 1.0/6.0)
   ```

## 面试追问

**Q1: 为什么概率分布是对称的？**
因为骰子的面值 {1,2,3,4,5,6} 关于 3.5 对称（1 和 6 互补，2 和 5 互补，3 和 4 互补）。n 个骰子的总和关于 3.5n 对称。数学上可以证明 P(总和 = s) = P(总和 = 7n - s)。

**Q2: 这个 DP 和"爬楼梯"有什么关系？**
非常类似。爬楼梯是"每步走 1 或 2 级"，这里是"每步走 1-6 级"。本质都是有限选择的路径计数/概率问题。转移公式结构一样：`dp[j] = sum(dp[j-k])` for k in choices。

**Q3: 时间复杂度为什么是 O(n^2) 而不是 O(n^3)？**
外层循环 n 次（骰子数），内层循环 O(5n) 次（dp 数组大小），最内层循环 6 次（常数）。总计 n * 5n * 6 = 30n^2 = O(n^2)。

**Q4: 如果骰子不是 6 面而是 k 面，怎么改？**
把所有的 6 替换为 k：初始化 dp 大小 k，概率 1/k；转移时内层循环 k 次；tmp 大小 (k-1)*i + 1。

**Q5: 能不能用数学公式直接算，不用 DP？**
可以，n 个骰子总和为 s 的方案数可以用组合数学的"星和条"方法加容斥原理推导：
```
C(s-1, n-1) - C(n,1)*C(s-7,n-1) + C(n,2)*C(s-13,n-1) - ...
```
但这个公式实现起来比 DP 更复杂，且容易出错。面试中 DP 方案更实用。
