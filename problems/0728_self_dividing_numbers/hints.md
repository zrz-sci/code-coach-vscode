# 728. 自除数 (Self Dividing Numbers)

**难度**: Easy | **标签**: Math

## 核心思路

自除数是指能被自身包含的每一个数字整除的数（且不包含 0）。解题方法直截了当：遍历 `[left, right]` 范围内的每个数，对每个数逐位检查是否满足自除数条件。逐位提取数字可以通过反复取模和整除实现（`n % 10` 取个位，`n / 10` 去掉个位）。

本题虽然简单，但在面试中考察的是**代码整洁度**、**边界处理能力**，以及将判断逻辑封装为辅助函数的习惯。

## 思维链

1. **理解定义**: 自除数 n 必须满足：对 n 的每一位数字 d，都有 `n % d == 0`，且 d 不能为 0
2. **暴力可行性分析**: 范围最大 [1, 10000]，每个数最多 5 位，总计算量约 50000 次取模，完全可行
3. **设计辅助函数**: `isSelfDividing(n)` 封装判断逻辑，主函数只做遍历和收集
4. **逐位检查**: 用 `while (tmp > 0)` 循环取每一位数字，检查是否为 0 以及是否能整除原数

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 暴力枚举 + 逐位检查 | O((right - left) * D) | O(1) | 最直接，D 为最大位数 |
| 字符串转换法 | O((right - left) * D) | O(D) | 用字符串提取各位数字 |
| 预计算查表 | O(10000) 预处理 + O(1) 查询 | O(10000) | 多次查询场景适用 |

其中 D 为数字的最大位数（本题最多 5 位）。

## 关键提示

1. 数字 0 不能作为除数，包含 0 的数（如 10, 20, 30）一定不是自除数
2. 提取各位数字使用 `digit = n % 10; n /= 10;` 循环
3. 检查时用原始值做取模运算，不要用不断被整除的临时值
4. 单位数 1-9 全部是自除数（1 能被 1 整除，2 能被 2 整除，...，9 能被 9 整除）
5. 一旦某一位不满足条件可以立即返回 false（短路优化）

## 解法详解

### 解法一：暴力枚举 + 取模逐位检查（推荐）

**步骤**:
1. 遍历 `[left, right]` 中的每个数 `num`
2. 对每个 `num`，用临时变量 `tmp = num`，循环提取每一位：
   - `digit = tmp % 10`
   - 若 `digit == 0` 或 `num % digit != 0`，则 `num` 不是自除数，跳出
   - `tmp /= 10`
3. 如果所有位都满足条件，将 `num` 加入结果

**时间复杂度**: O((right - left + 1) * D)，D 最大为 5  
**空间复杂度**: O(1)（不计输出空间）

### 解法二：字符串转换法

**步骤**:
1. 将数字转为字符串，遍历每个字符
2. 字符 `'0'` 直接判断不合法
3. 其余字符转为数字后检查整除性

这种方法代码更短但有额外的字符串转换开销。

**时间复杂度**: O((right - left + 1) * D)  
**空间复杂度**: O(D)

### 解法三：数学性质优化

**观察**:
- 所有包含 0 的数直接排除
- 1 位数全部满足
- 可以跳过明显不满足的数（如个位为 0 的数）

但由于范围小（最大 10000），优化意义不大，面试中写清楚即可。

## 易错点

1. **包含数字 0**: 10, 20, 100 等包含 0 的数必须排除，忘记检查 `digit == 0` 会导致除以零错误
2. **用临时变量提取位数**: 取模和整除操作应作用于临时变量 `tmp`，但整除性检查 `num % digit` 应使用原始值 `num`
3. **范围边界**: 题目说 `left` 和 `right` 都是包含的（inclusive），不要漏掉边界值
4. **返回类型**: 需要返回 vector 而非 set，结果天然有序（因为从小到大遍历）
5. **整数溢出**: 本题范围 <= 10000，无溢出风险，但养成习惯也很重要

## 面试追问

1. **如果范围扩大到 [1, 10^9]，如何优化？**
   - 可以用数位 DP 枚举所有自除数，避免逐一检查每个数。状态包括当前位数、已有位的 LCM、是否受上界约束等

2. **如何证明 1-9 都是自除数？**
   - 单位数 d，唯一的位就是 d 本身，而 d % d == 0 恒成立（d != 0）

3. **能否生成所有自除数而不遍历范围？**
   - 可以通过 BFS/DFS 构造：从 1-9 出发，每次在末尾追加一个能整除当前数的数字。但实现复杂度较高

4. **自除数的分布有什么规律？**
   - 随着位数增加，自除数越来越稀疏。因为更多位数字意味着更多整除约束需要同时满足

5. **如何测试你的解法的正确性？**
   - 手动验证边界值（1, 9, 10, 11, 22），确认包含 0 的数被排除，确认所有单位数被包含
