# 998. 最大二叉树 II

[./solution.cpp)

## 核心思路

给定一个最大二叉树的根节点（由数组 a 构造）和一个值 val，将 val 追加到数组末尾后重新构造最大二叉树。**关键观察：val 追加在数组末尾，所以它只可能出现在根的右子树路径上。沿着右子树链往下走，找到第一个 val > node.val 的位置，将 val 插入，原来的右子树变成 val 的左子树。**

## 思维链

1. **读完题第一反应** -> 理解最大二叉树的构造规则：数组中最大值做根，左边做左子树，右边做右子树。现在要在数组末尾加一个 val，重新构造。

2. **朴素思路** -> 重新构造整棵树。但题目没有给原始数组 a，只有 root 和 val。而且重新构造需要 O(n) 时间（先中序遍历恢复 a，再构造）。

3. **关键观察** -> val 被追加到数组的最右边。在最大二叉树的构造中，新元素只会影响根的右子树链。因为 val 在所有现有元素的右边，它不可能出现在任何节点的左子树中。

4. **分两种情况**：
   - 如果 val > root.val：val 成为新的根，原来的整棵树变成 val 的左子树。
   - 如果 val < root.val：沿着根的右子树链往下走，找到第一个 node 使得 val > node.val，或者走到 null。val 插入那个位置，原来那个 node（及其子树）变成 val 的左子树。

5. **为什么原子树变成左子树？** 因为在原始数组中，被 val "顶替"的那些元素都在 val 的左边（它们在数组中出现更早），所以按最大二叉树的规则，它们构成 val 的左子树。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 递归（右子树插入） | 沿右子树链递归找插入位置 | O(n) | O(n) | 面试首选 |
| 迭代（右子树链遍历） | 沿右子树链迭代找插入位置 | O(n) | O(1) | 同样优秀 |

## 关键提示

1. **为什么只看右子树链？** 最大二叉树的构造方式：最大值做根，左半部分做左子树，右半部分做右子树。val 在数组最右端，所以从根开始，val 总是在右半部分，递归地落入右子树。

2. **图解插入过程**：
```
原树（对应 a = [2,1,5,3]）:
        5
       / \
      2   3
       \
        1

插入 val = 4:
b = [2,1,5,3,4]

新树:
        5
       / \
      2   4    ← val=4 > 3，顶替了 3 的位置
       \  /
        1 3    ← 3 变成 4 的左子树

过程: root=5, 5>4 → 看右子树
      root.right=3, 3<4 → val=4 取代 3 的位置
      3 变成 4 的左子树
```

3. **另一个例子：val 是最大值**：
```
原树: a = [1,4,2,3], root = 4
        4
       / \
      1   3
         /
        2

插入 val = 5:
5 > 4 → val=5 成为新根，原整棵树变成 5 的左子树

新树:
    5
   /
  4
 / \
1   3
   /
  2
```

4. **val 是最小值的情况**：val 会一直往右子树走到 null，然后作为最右边的叶子节点插入。

5. **递归的终止条件**：(1) root == null：返回一个值为 val 的新节点。(2) val > root.val：创建新节点，原 root 变成新节点的左子树。(3) 否则：递归插入到 root 的右子树。

## 解法详解

### 解法1: 递归（右子树插入） -- O(n) / O(n) -- 面试首选

**思考过程**: 利用最大二叉树的性质，val 只能沿着右子树链找到自己的位置。递归地在右子树中插入。

```cpp
class Solution {
public:
    TreeNode* insertIntoMaxTree(TreeNode* root, int val) {
        // 情况1: 走到空节点，创建新节点
        if (root == nullptr) {
            return new TreeNode(val);
        }
        
        // 情况2: val 比当前节点大，val 成为新根
        // 当前子树变成 val 的左子树（因为当前子树的所有元素在数组中都在 val 左边）
        if (val > root->val) {
            TreeNode* node = new TreeNode(val);
            node->left = root;
            return node;
        }
        
        // 情况3: val 比当前节点小，递归到右子树
        root->right = insertIntoMaxTree(root->right, val);
        return root;
    }
};
```

**关键点**:
- 每次递归只往右子树走，不会进入左子树。
- 最坏情况：树是一条右链（原数组严格递增），递归深度 O(n)。
- 找到插入位置后，原来该位置的子树变成新节点的左子树。

---

### 解法2: 迭代（右子树链遍历） -- O(n) / O(1)

**思路**: 不用递归，显式沿着右子树链遍历。需要维护 parent 指针来完成插入。

```cpp
class Solution {
public:
    TreeNode* insertIntoMaxTree(TreeNode* root, int val) {
        TreeNode* node = new TreeNode(val);
        
        // 特殊情况: val 是最大值，成为新根
        if (root == nullptr || val > root->val) {
            node->left = root;
            return node;
        }
        
        // 沿右子树链寻找插入位置
        TreeNode* curr = root;
        while (curr->right != nullptr && curr->right->val > val) {
            curr = curr->right;
        }
        
        // curr->right == null 或 curr->right->val < val
        // 在 curr 和 curr->right 之间插入 node
        node->left = curr->right; // 原右子树变成 node 的左子树
        curr->right = node;       // node 成为 curr 的右子树
        
        return root;
    }
};
```

**关键点**: 迭代版本空间 O(1)（不算递归栈），逻辑稍复杂但效率更高。循环条件 `curr->right->val > val` 保证找到第一个比 val 小的右子节点。

## 解法对比

| | 递归 | 迭代 |
|---|---|---|
| 时间 | O(n) | O(n) |
| 空间 | O(n) 递归栈 | O(1) |
| 代码量 | 少 | 中 |
| 思维难度 | 低 | 中 |
| 面试推荐 | 首选（简洁清晰） | 追问空间优化 |

## 易错点

1. **把原子树挂到新节点的右子树而不是左子树**
   - 原子树的所有元素在数组中都在 val 的左边，按最大二叉树规则应该是左子树。
   - `node->left = root`（或 `node->left = curr->right`），不是 `node->right`。

2. **递归时忘记 `root->right = insertIntoMaxTree(root->right, val)`**
   - 必须把递归结果赋值回 `root->right`，否则新节点挂不上去。

3. **迭代时没处理 val > root->val 的特殊情况**
   - 此时整棵原树变成新节点的左子树，返回的根节点改变了。
   - 必须在循环之前单独处理。

4. **忽略 val 恰好是中间值的情况**
   - val 不一定是最大或最小，可能落在右子树链的中间某个位置。
   - 递归和迭代都能正确处理。

5. **混淆了 LC 654（最大二叉树）和本题**
   - LC 654 是从数组构造整棵树，本题是在已有树上追加一个值。
   - 本题利用了"追加到末尾"的特殊性质，不需要重新构造。

## 面试追问

**Q1: 时间复杂度是多少？最坏情况是什么？**
> O(n)，最坏当原数组严格递增时（如 [1,2,3,4]），树是一条右链，val 需要遍历整条链才能到底部。

**Q2: 如果 val 是插入到数组开头而不是末尾呢？**
> 对称地，val 只会出现在左子树链上。沿左子树链往下找即可。

**Q3: 如果 val 插入到数组任意位置呢？**
> 需要先恢复原数组（中序遍历），插入 val，再重新构造。O(n) 时间。无法利用"只看一条链"的优化。

**Q4: 这和二叉搜索树的插入有什么区别？**
> BST 插入也是沿一条路径走到叶子。但最大二叉树不是 BST，插入位置由值的大小关系决定（大的在上），且只看右子树链。另一个区别是插入后可能需要"顶替"现有节点（不只是加叶子）。
