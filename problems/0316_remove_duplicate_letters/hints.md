# 316. 去除重复字母

## 核心思路

本质上是在所有"只包含每个字母恰好一次"的子序列中，找字典序最小的那个。关键在于：什么时候可以安全地把一个"大"的字母踢掉换成后面更小的字母？——当且仅当这个大字母在后面还会出现时。

## 思维链

1. **读完题第一反应**：要从字符串中选出一组不重复的字母，保持相对顺序，使结果字典序最小。暴力做法：枚举所有可能的子序列（每个字符选/不选），筛选出每种字母恰好一次的，取字典序最小的。这显然是指数级别，不可行。

2. **贪心直觉**：要字典序最小，我们希望尽量把小的字母放在前面。比如遇到 `'a'`，如果前面已经放了 `'c'`、`'b'`，能不能把它们踢掉让 `'a'` 排到前面？

3. **踢掉的条件是什么？** 如果 `'c'` 在后面还会出现，那现在踢掉它没关系，后面还能再选。但如果 `'c'` 后面不再出现了，踢掉就永远丢了，不行！所以关键信息是：**每个字母最后一次出现的位置**。

4. **用什么数据结构维护"已选字母"？** 我们需要能从末尾弹出（踢掉不合适的大字母），又能从末尾追加（加入新字母）——这就是**栈**！而且弹出时要求栈顶 > 当前字母，即维护一个**单调递增栈**的趋势。

5. **还需要什么？** 一个 `inStack` 标记：如果某字母已经在栈里了，就跳过（因为结果中每个字母只能出现一次，而且已经在栈中的位置已经是当前最优的了）。

6. **综合起来**：预处理每个字母最后出现位置 → 遍历字符串，用贪心单调栈维护结果。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力枚举 | 枚举所有子序列取最小 | O(2^n) | O(n) | 能说出即可 |
| 贪心+单调栈 | 栈中维护递增趋势，后面还有的字母可以踢掉 | O(n) | O(1) | ⭐ 必须写出 |

## 关键提示

1. **预处理**：先统计每个字母最后出现的位置（或剩余出现次数），这是贪心决策的关键依据。

2. **单调栈的弹出条件有三个同时满足**：① 栈非空，② 栈顶字母 > 当前字母，③ 栈顶字母在后面还会出现（`lastIndex[top] > i`）。缺一不可。

3. **跳过已在栈中的字母**：如果当前字母已经在栈里了，直接跳过。为什么？因为它在栈中的位置已经是在"尽量靠前且尽量小"的策略下放好的。

4. 用一个例子手动模拟：`"cbacdcbc"`
```
处理 c: 栈 [c]
处理 b: b<c, c后面还有 → 弹c, 栈 [b]
处理 a: a<b, b后面还有 → 弹b, 栈 [a]
处理 c: c>a, 栈 [a,c]
处理 d: d>c, 栈 [a,c,d]
处理 c: c已在栈中 → 跳过
处理 b: b<d, 但d后面没有了! 不能弹 → 栈 [a,c,d,b]
处理 c: c已在栈中 → 跳过
结果: "acdb"
```

5. 栈的大小最多26（英文字母数），所以空间是 O(1)（字符集大小）。

## 解法详解

### 解法1: 暴力枚举 — O(2^n · n) / O(n)

**思考过程**: 最直觉的方法——枚举所有子序列，找到每个字母恰好出现一次的，取字典序最小的。

```cpp
class Solution {
public:
    string removeDuplicateLetters(string s) {
        // 找出s中有哪些不同的字母
        set<char> chars(s.begin(), s.end());
        int target = chars.size(); // 结果长度必须是这个
        
        string best = "";
        // 用位掩码枚举所有子序列 (仅适用于短字符串)
        int n = s.size();
        for (int mask = 0; mask < (1 << n); mask++) {
            string sub = "";
            for (int i = 0; i < n; i++) {
                if (mask & (1 << i)) sub += s[i];
            }
            // 检查是否每个字母恰好出现一次
            set<char> used(sub.begin(), sub.end());
            if ((int)used.size() == target && (int)sub.size() == target) {
                if (best.empty() || sub < best) best = sub;
            }
        }
        return best;
    }
};
```

**关键点**: 这个解法 n ≤ 20 才能跑，题目 n ≤ 10^4 完全不可行。但它帮我们理解了题意——我们在所有合法子序列中找字典序最小的。

### 解法2: 贪心 + 单调栈 — O(n) / O(1) ⭐ 面试首选

**从解法1优化**: 暴力枚举了所有子序列，瓶颈在于指数级的搜索。贪心的核心思想是：**逐步构建结果，每一步都做出局部最优选择**。具体来说，我们维护一个栈（代表当前结果），对每个新字符决定：

- 如果它已在栈中 → 跳过
- 如果它比栈顶小，且栈顶字母后面还会出现 → 弹出栈顶（用更小的替换）
- 否则 → 直接入栈

```
// 手动模拟 "cbacdcbc":
// lastIndex: a=2, b=6, c=7, d=4
//
// i=0, 'c': 栈空 → push         栈: [c]         inStack: {c}
// i=1, 'b': b<c, last[c]=7>1 → pop c, push b
//                                栈: [b]         inStack: {b}
// i=2, 'a': a<b, last[b]=6>2 → pop b, push a
//                                栈: [a]         inStack: {a}
// i=3, 'c': c>a → push          栈: [a,c]       inStack: {a,c}
// i=4, 'd': d>c → push          栈: [a,c,d]     inStack: {a,c,d}
// i=5, 'c': c ∈ inStack → skip  栈: [a,c,d]
// i=6, 'b': b<d, last[d]=4<6 → 不能弹d!
//           直接 push b          栈: [a,c,d,b]   inStack: {a,b,c,d}
// i=7, 'c': c ∈ inStack → skip  栈: [a,c,d,b]
//
// 结果: "acdb" ✓
```

```cpp
class Solution {
public:
    string removeDuplicateLetters(string s) {
        // Step1: 预处理每个字母最后出现的位置
        int lastIndex[26] = {};
        for (int i = 0; i < (int)s.size(); i++) {
            lastIndex[s[i] - 'a'] = i;
        }
        
        bool inStack[26] = {};  // 标记字母是否已在结果中
        string stk;             // 用 string 模拟栈（方便最后直接返回）
        
        for (int i = 0; i < (int)s.size(); i++) {
            char c = s[i];
            
            // 如果当前字母已在栈中，跳过
            // 为什么？它已经在一个更优的位置了
            if (inStack[c - 'a']) continue;
            
            // 贪心弹出：栈顶比当前大 且 栈顶后面还会出现 → 弹出
            while (!stk.empty() && stk.back() > c && lastIndex[stk.back() - 'a'] > i) {
                inStack[stk.back() - 'a'] = false;
                stk.pop_back();
            }
            
            stk.push_back(c);
            inStack[c - 'a'] = true;
        }
        
        return stk;
    }
};
```

**关键点**:
- `while` 循环的三个条件缺一不可：栈非空、栈顶>当前、栈顶后面还有。
- `inStack` 标记必须在弹出时清除，入栈时设置。
- 用 `string` 当栈比 `stack<char>` 方便——最后不用逐个弹出拼接。

## 解法对比

| | 暴力枚举 | 贪心+单调栈 |
|---|---|---|
| 时间 | O(2^n · n) | O(n) |
| 空间 | O(n) | O(1)（26个字母） |
| 适用 | 理解题意 | 面试/竞赛 |
| 核心 | 穷举 | 贪心决策+栈维护 |

贪心+单调栈之所以能 O(n)，是因为每个字符最多入栈一次、出栈一次，总操作 ≤ 2n。

## 易错点

1. **漏掉 `inStack` 跳过逻辑**：
   - ✗ 不检查 `inStack`，导致同一字母被多次加入结果
   - ✓ `if (inStack[c - 'a']) continue;` 必须放在弹栈循环之前

2. **弹栈条件漏掉 `lastIndex > i`**：
   - ✗ `while (!stk.empty() && stk.back() > c)` — 把最后一次出现的字母也弹了，结果缺字母
   - ✓ 必须确认栈顶字母后面还会出现，才能安全弹出

3. **弹栈时忘记更新 `inStack`**：
   - ✗ 弹出后不清 `inStack[top]`，导致后面该字母被误跳过
   - ✓ 弹出后 `inStack[stk.back() - 'a'] = false;`

4. **用剩余次数代替 lastIndex 也可以，但要注意在循环开头就递减**：
   - 如果用 `count[]` 记录剩余次数，需要在每次处理字符时（不管跳不跳过）都递减 `count[c]`
   - ✗ 只在入栈时递减 → 剩余次数计算错误
   - ✓ 循环一开始就 `count[c]--`，然后判断 `inStack` 是否跳过

## 面试追问

**Q1: 暴力解的思路是什么？为什么不可行？**
枚举所有 2^n 子序列，检查哪些是合法的（每个字母恰好一次），取字典序最小。时间 O(2^n)，n=10^4 时完全不可行。

**Q2: 为什么贪心策略是正确的？即为什么每次弹出栈顶不会错过最优解？**
弹出栈顶的前提是它后面还会出现。所以我们只是把它"推迟"了，不是丢掉了。而推迟换来的好处是让更小的字母排在前面，字典序一定更小。如果栈顶后面不再出现，我们不弹它，保证不丢字母。

**Q3: 如果字符集不是 26 个小写字母，而是任意 Unicode 字符，怎么改？**
把固定大小的数组 `inStack[26]` 和 `lastIndex[26]` 换成 `unordered_map<char, int>` 和 `unordered_map<char, bool>`，逻辑完全不变，空间从 O(1) 变为 O(字符集大小)。

**Q4: 这道题和 LeetCode 402（移掉 K 位数字）有什么关系？**
核心框架完全一样——都是用单调栈贪心地维护字典序最小的结果。区别：402 是"最多删 k 个"，本题是"每个字母只保留一个"，弹出条件不同。
