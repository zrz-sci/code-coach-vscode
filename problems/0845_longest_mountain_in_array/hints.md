# 845. 数组中的最长山脉

## 核心思路

在数组中找最长的"山脉"子数组——先严格递增、后严格递减，且两侧各至少一个元素。核心做法是**枚举每个可能的山峰**，向两侧扩展计算山脉长度。也可以用**一次遍历状态机**，追踪 up/down 阶段完成 O(1) 空间。

## 思维链

1. **读完题第一反应**：找子数组中先升后降的最长段。关键约束：山峰不能在两端（两侧都要有元素），且是**严格**递增/递减（相等不算）。

2. **暴力思路**：对每个位置检查它是否是山峰（比左右邻居都大），然后向左数上升长度，向右数下降长度。山脉长度 = 左扩展 + 右扩展 + 1。看起来是 O(n^2)？其实每个元素最多被左扫一次、右扫一次，均摊 O(n)。

3. **更优雅的一次遍历**：用两个计数器 `up` 和 `down` 跟踪当前上升和下降的连续长度。遇到上升就增加 up（如果正在下降则重置）；遇到下降就增加 down；遇到相等就全部重置。当 up > 0 && down > 0 时更新答案。

4. **DP 预处理思路**：预计算 `inc[i]` = 以 i 结尾的连续上升长度，`dec[i]` = 以 i 开头的连续下降长度。如果 `inc[i] >= 2 && dec[i] >= 2`，则以 i 为峰的山脉长度 = `inc[i] + dec[i] - 1`。

5. **Follow-up**：题目问能否一次遍历 + O(1) 空间。状态机解法完美满足。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 枚举山峰 + 双向扩展 | 对每个峰向两侧扩展 | O(n) | O(1) | 推荐 |
| 一次遍历状态机 | up/down 计数器 | O(n) | O(1) | Follow-up |
| DP 预处理 | inc[]/dec[] 数组 | O(n) | O(n) | 最直观 |

## 关键提示

1. **提示1**：山脉的定义有三个要求：(a) 长度 >= 3；(b) 存在严格递增的左侧；(c) 存在严格递减的右侧。注意"严格"——相等的元素会打断山脉。

2. **提示2**：枚举山峰法——找到所有 `arr[i-1] < arr[i] && arr[i] > arr[i+1]` 的位置 i，然后从 i 向左右扩展。左边扩展条件 `arr[left-1] < arr[left]`，右边扩展条件 `arr[right+1] < arr[right]`。

3. **提示3**：一次遍历时，状态转换规则如下：
   - `arr[i] > arr[i-1]`：如果 `down > 0`（之前在下降），说明上一个山脉结束了，重置 `up=1, down=0`；否则 `up++`。
   - `arr[i] < arr[i-1]`：如果 `up > 0`，`down++`（正在下山）；否则说明没有上坡，不构成山脉。
   - `arr[i] == arr[i-1]`：重置 `up=0, down=0`。

4. **提示4**：答案更新时机——当 `up > 0 && down > 0` 时，当前山脉长度 = `up + down + 1`。

5. **提示5**：常见边界情况：全相等的数组 `[2,2,2]` → 返回 0；单调递增/递减 → 返回 0（没有先升后降）。

```
山脉识别示意 (arr = [2, 1, 4, 7, 3, 2, 5]):

下标:  0  1  2  3  4  5  6
值:    2  1  4  7  3  2  5
         ↓  ↑  ↑  ↓  ↓  ↑

分析:
- i=3, arr[3]=7 是山峰 (4<7 且 7>3)
  左扩展: arr[1]=1 < arr[2]=4 < arr[3]=7 → left=1
  右扩展: arr[3]=7 > arr[4]=3 > arr[5]=2 → right=5
  山脉长度 = 5-1+1 = 5 → [1,4,7,3,2]

- i=6, arr[6]=5... 不是山峰 (只有左侧上升, 右边没有下降)

最长山脉 = 5
```

## 解法详解

### 解法1: 枚举山峰 + 双向扩展 — O(n) / O(1)

**思考过程**：
- 找到每个"山峰"位置（比左右邻居都大）
- 从山峰向左扩展（严格递增方向），向右扩展（严格递减方向）
- 山脉长度 = right - left + 1
- 虽然有嵌套循环，但每个元素最多被扩展访问两次，均摊 O(n)

```
// 枚举山峰示意:
//
// arr = [2, 1, 4, 7, 3, 2, 5]
//              ↑  ★  ↓  ↓
//           left=1  peak=3  right=5
//           山脉 = [1,4,7,3,2], 长度 5
```

```cpp
class Solution {
public:
    int longestMountain(vector<int>& arr) {
        int n = arr.size(), ans = 0;

        for (int i = 1; i < n - 1; i++) {
            // 检查 i 是否是山峰
            if (arr[i] > arr[i - 1] && arr[i] > arr[i + 1]) {
                int left = i - 1, right = i + 1;
                // 向左扩展上坡
                while (left > 0 && arr[left - 1] < arr[left]) left--;
                // 向右扩展下坡
                while (right < n - 1 && arr[right + 1] < arr[right]) right++;
                ans = max(ans, right - left + 1);
            }
        }
        return ans;
    }
};
```

**关键点**：
- `i` 从 1 到 n-2 遍历（山峰不可能在两端）
- 扩展停止条件：到达边界，或者不再严格单调
- 均摊 O(n)：每个元素最多被两个山峰各扩展一次

---

### 解法2: 一次遍历状态机 — O(n) / O(1) Follow-up 最优

**从解法1优化**：不需要对每个山峰回头扫，用两个计数器 `up` 和 `down` 在一次遍历中完成。

```
// 状态机转换:
//
// arr[i] > arr[i-1]:
//   if down > 0: 新山开始, up=1, down=0
//   else: up++  (继续上坡)
//
// arr[i] < arr[i-1]:
//   if up > 0: down++ (正在下坡)
//   else: 无效 (纯下坡不是山脉)
//
// arr[i] == arr[i-1]:
//   up=0, down=0 (平地打断一切)
//
// 答案更新: 当 up>0 && down>0 时, 山脉长度 = up+down+1
```

```cpp
class Solution {
public:
    int longestMountain(vector<int>& arr) {
        int n = arr.size(), ans = 0;
        int up = 0, down = 0;

        for (int i = 1; i < n; i++) {
            // 情况1: 下降后又上升 → 新山脉开始
            // 情况2: 平地 → 重置
            if ((down > 0 && arr[i] > arr[i - 1]) || arr[i] == arr[i - 1]) {
                up = 0;
                down = 0;
            }

            if (arr[i] > arr[i - 1]) up++;
            if (arr[i] < arr[i - 1]) down++;

            // 有上坡且有下坡 → 有效山脉
            if (up > 0 && down > 0) {
                ans = max(ans, up + down + 1);
            }
        }
        return ans;
    }
};
```

### 解法3: DP 预处理 — O(n) / O(n)

**最直观的思路**：预计算两个数组，然后合并。

```
// inc[i] = 以 i 结尾的连续严格上升长度
// dec[i] = 以 i 开头的连续严格下降长度
//
// arr = [2, 1, 4, 7, 3, 2, 5]
// inc = [1, 1, 2, 3, 1, 1, 2]  (从左到右)
// dec = [1, 1, 1, 3, 2, 1, 1]  (从右到左)
//
// i=3: inc[3]=3, dec[3]=3 → 山脉长度 = 3+3-1 = 5
```

```cpp
class Solution {
public:
    int longestMountain(vector<int>& arr) {
        int n = arr.size();
        if (n < 3) return 0;

        vector<int> inc(n, 1), dec(n, 1);

        // inc[i]: 以 i 结尾的连续上升长度
        for (int i = 1; i < n; i++)
            if (arr[i] > arr[i - 1]) inc[i] = inc[i - 1] + 1;

        // dec[i]: 以 i 开头的连续下降长度
        for (int i = n - 2; i >= 0; i--)
            if (arr[i] > arr[i + 1]) dec[i] = dec[i + 1] + 1;

        // 合并: i 是山峰当且仅当 inc[i]>=2 且 dec[i]>=2
        int ans = 0;
        for (int i = 1; i < n - 1; i++) {
            if (inc[i] >= 2 && dec[i] >= 2) {
                ans = max(ans, inc[i] + dec[i] - 1);
            }
        }
        return ans;
    }
};
```

## 易错点

1. **忘记"严格"递增/递减**
   ```cpp
   // 错误: arr[i] >= arr[i-1]  ← 相等也算上升
   // 正确: arr[i] > arr[i-1]   ← 必须严格递增
   ```

2. **山脉长度不足 3**
   ```cpp
   // 错误: 只有上坡没有下坡也算山脉
   // 正确: 必须 up > 0 && down > 0, 即两侧都至少有一个元素
   ```

3. **状态机中下降后上升时忘记重置**
   ```cpp
   // 错误: 下坡阶段遇到上升, 继续增加 up
   // 正确: down>0 && arr[i]>arr[i-1] 时, 重置 up=0, down=0, 然后 up++
   ```

4. **DP 解法中 inc[i] + dec[i] 重复计算了山峰**
   ```cpp
   // 错误: 山脉长度 = inc[i] + dec[i]
   // 正确: 山脉长度 = inc[i] + dec[i] - 1  (山峰被算了两次)
   ```

## 面试追问

**Q1: 枚举山峰看起来有嵌套循环，为什么是 O(n)？**
→ 每个元素最多被"向左扩展"访问一次、被"向右扩展"访问一次。不同山峰的扩展区间不会重叠（如果重叠说明中间还有更高的峰，那个才是真正的山峰）。所以总访问次数 <= 3n = O(n)。

**Q2: 如果允许相等（非严格递增/递减），怎么改？**
→ 把 `<` 改成 `<=` 即可。但要注意"山峰"处仍然需要严格大于左右，否则整个数组全相等也会被算作"山脉"。

**Q3: 如果要求返回最长山脉的起止下标呢？**
→ 在枚举山峰解法中，记录 `left` 和 `right` 对应的最大山脉即可。在状态机解法中，额外维护一个 `start` 变量记录当前山脉的起始位置。
