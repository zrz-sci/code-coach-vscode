# 802. 找到最终的安全状态

## 核心思路

本质是**检测有向图中哪些节点不在任何环上**。一个节点是"安全"的当且仅当从它出发的所有路径最终都到达终端节点（出度为0的节点）。等价地说，安全节点就是不在任何环中、且不能到达任何环的节点。

## 思维链

1. **读完题第一反应** → 每个节点需要判断是否所有路径都通向终端节点。直觉上需要某种图遍历。
2. **什么样的节点不安全？** → 如果一个节点在环上，或者能到达环上的节点，那它就不安全。因为从它出发可以走一条路径进入环，永远到不了终端节点。
3. **方法一: DFS + 三色标记** → 用 DFS 检测环：白色（未访问）、灰色（当前路径上）、黑色（已确认安全）。如果 DFS 过程中遇到灰色节点，说明有环。
4. **方法二: 反向拓扑排序** → 建反图，从终端节点（出度为0）开始 BFS，能被"反向"到达的节点都是安全的。等价于反向图上的拓扑排序。
5. **结果排序** → 题目要求答案升序排列。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| DFS + 三色标记 | 递归DFS检测环，标记安全节点 | O(V+E) | O(V) | ⭐ 必须写出 |
| 反向拓扑排序 (BFS) | 反图上从终端节点BFS，反向传播安全性 | O(V+E) | O(V+E) | ⭐ 进阶方案 |

## 关键提示

1. **三色标记法**：白色(0)=未访问，灰色(1)=正在当前DFS路径上，黑色(2)=已确认安全。遇到灰色说明有环→不安全；遇到黑色说明已确认安全→跳过。
2. **DFS 返回值**：返回 true 表示该节点安全，false 表示不安全（在环上或能到达环）。
3. **反向拓扑排序思路**：在原图中出度为 0 的节点是终端节点（天然安全）。反向BFS：将这些节点入队，每处理一个安全节点就把它的前驱节点的出度减 1，出度减为 0 的前驱也变安全。
4. **图可能有自环**：`graph[i]` 可能包含 `i` 本身。DFS 中自环会被灰色检测捕获；拓扑排序中自环使节点永远不可能出度为 0。
5. **答案需要排序**：DFS 法天然不保证顺序，需要最后排序。拓扑排序法也不保证，同样需要排序。

## 解法详解

### 解法1: DFS + 三色标记 -- O(V+E) / O(V) ⭐ 面试首选

**思考过程**: 图中找环的经典方法是 DFS + 三色标记。安全节点 = 不在环上 + 不能到达环上的节点。

```
DFS 三色标记过程（graph = [[1,2],[2,3],[5],[0],[5],[],[]]）:

节点0: 标灰→访问1→标灰→访问2→标灰→访问5→标灰→无邻居→标黑(安全)
       →回到2→访问完→标黑(安全)
       →回到1→访问3→标灰→访问0(灰色!有环)→返回不安全→1标不安全
       →回到0→有不安全邻居→0标不安全

节点4: 标灰→访问5(已黑)→标黑(安全)

最终: 安全节点 = {2, 4, 5, 6}
```

```cpp
class Solution {
public:
    vector<int> eventualSafeNodes(vector<vector<int>>& graph) {
        int n = graph.size();
        // 0: 白(未访问), 1: 灰(当前路径), 2: 黑(安全)
        vector<int> color(n, 0);
        vector<int> result;
        
        for (int i = 0; i < n; i++) {
            if (dfs(graph, i, color)) {
                result.push_back(i);
            }
        }
        return result;  // 因为按 0..n-1 顺序遍历，天然有序
    }
    
    // 返回 true 表示节点 u 是安全的
    bool dfs(vector<vector<int>>& graph, int u, vector<int>& color) {
        if (color[u] != 0) {
            return color[u] == 2;  // 灰色=不安全, 黑色=安全
        }
        color[u] = 1;  // 标灰：进入当前 DFS 路径
        for (int v : graph[u]) {
            if (!dfs(graph, v, color)) {
                return false;  // 邻居不安全 → 自己也不安全
            }
        }
        color[u] = 2;  // 所有邻居都安全 → 标黑
        return true;
    }
};
```

### 解法2: 反向拓扑排序 (BFS) -- O(V+E) / O(V+E)

**不同视角**: 安全节点最终都通向终端节点。从终端节点反向传播安全性。

```cpp
class Solution {
public:
    vector<int> eventualSafeNodes(vector<vector<int>>& graph) {
        int n = graph.size();
        vector<vector<int>> rg(n);  // 反向图
        vector<int> outDeg(n, 0);
        
        // 建反图 + 计算出度
        for (int u = 0; u < n; u++) {
            outDeg[u] = graph[u].size();
            for (int v : graph[u]) {
                rg[v].push_back(u);  // 反向边 v → u
            }
        }
        
        // 出度为0的终端节点入队
        queue<int> q;
        for (int i = 0; i < n; i++) {
            if (outDeg[i] == 0) q.push(i);
        }
        
        vector<bool> safe(n, false);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            safe[u] = true;
            for (int v : rg[u]) {    // 反向图的邻居 = 原图的前驱
                outDeg[v]--;
                if (outDeg[v] == 0) {
                    q.push(v);
                }
            }
        }
        
        vector<int> result;
        for (int i = 0; i < n; i++) {
            if (safe[i]) result.push_back(i);
        }
        return result;
    }
};
```

## 易错点

1. **DFS 中不安全节点没有标记**：
   - ✗ DFS 发现环后直接 `return false`，但 color 还是灰色(1)，下次访问到又重新 DFS → TLE
   - ✓ 可以不显式标记不安全（因为灰色节点再次遇到会返回 false），但要确保逻辑一致

2. **DFS 结果不排序**：
   - ✗ 按 DFS 完成顺序收集结果 → 不是升序
   - ✓ 按 0 到 n-1 顺序遍历并判断，天然升序；或最后 sort

3. **反图中忘记正确计算出度**：
   - ✗ 用反图的入度当出度 → 概念混淆
   - ✓ 出度 = `graph[u].size()`（原图的出度），反图只用来反向传播

4. **自环未处理**：
   - ✗ 假设图无自环 → 自环节点应该是不安全的，DFS 中自环被灰色检测自动捕获
   - ✓ 三色标记法天然处理自环：`graph[u]` 包含 `u` 时，DFS(u) 遇到灰色的 u，返回 false

## 面试追问

**Q1: DFS 解法中，不安全的节点需要额外标记吗？**
> 严格来说不需要额外的"不安全"颜色。灰色节点在 DFS 返回 false 后保持灰色，后续遇到灰色直接返回 false。但有些实现用 color=3 表示"已确认不安全"来加速。关键是保证每个节点最多被完整 DFS 一次，总复杂度 O(V+E)。

**Q2: 拓扑排序解法为什么需要建反图？**
> 因为拓扑排序是从入度为0的节点开始的，但我们要从出度为0的终端节点开始传播安全性。建反图后，原图出度为0的节点在反图中入度为0，就可以用标准拓扑排序了。

**Q3: 如果图是无向图，问题会如何变化？**
> 无向图中所有连通的非孤立节点都在"环"中（因为无向边 u-v 既可以从 u 到 v 也可以从 v 到 u）。只有孤立节点是安全的。问题变得trivial。
