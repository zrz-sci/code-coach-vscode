# 747. 至少是其他数字两倍的最大数

## 核心思路

找到数组中的最大值，判断它是否至少是**所有其他元素**的两倍。关键优化：只需要比较最大值和**第二大值**的关系即可。如果最大值 >= 2 * 第二大值，则必然满足所有其他元素的两倍条件。

## 思维链

1. **朴素想法**：找到最大值，遍历所有其他元素检查是否 >= 2 倍 => O(n) 两遍
2. **优化思考**：如果最大值 >= 2 * 第二大值，那么对所有更小的值自然也满足
3. **一次遍历**：同时跟踪最大值和第二大值，以及最大值的下标
4. **边界处理**：数组只有两个元素时也要正确处理；最大值唯一（题目保证）
5. **特殊值**：第二大值可能为 0，此时 `maxVal >= 0` 恒成立

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 一次遍历找最大和第二大 | O(n) | O(1) | 最优解 |
| 排序后比较 | O(n log n) | O(1) 或 O(n) | 简单但效率不如一次遍历 |
| 朴素两遍遍历 | O(n) | O(1) | 先找最大，再验证所有元素 |

## 关键提示

1. **只需关注第二大值**：最大值 >= 2 * 第二大值 等价于 最大值 >= 2 * 所有其他值
2. **最大值唯一**：题目保证最大元素唯一，不需要处理并列最大的情况
3. **值可以为 0**：`nums[i]` 可以是 0，最大值 >= 2 * 0 = 0 恒成立
4. **返回下标不是值**：答案要求返回最大元素的下标，不是值本身

## 解法详解

### 解法一：一次遍历找最大和第二大（推荐）

**思路**：用两个变量 `maxVal` 和 `secondMax` 分别跟踪最大值和第二大值，同时记录最大值的下标。

**步骤**：
1. 初始化 `maxVal = -1, secondMax = -1, maxIdx = 0`
2. 遍历数组每个元素 `nums[i]`：
   - 如果 `nums[i] > maxVal`：`secondMax = maxVal, maxVal = nums[i], maxIdx = i`
   - 否则如果 `nums[i] > secondMax`：`secondMax = nums[i]`
3. 判断 `maxVal >= 2 * secondMax`，是则返回 `maxIdx`，否则返回 `-1`

**正确性**：由于题目保证最大元素唯一，所以最大值和第二大值一定不同。如果最大值 >= 2 * 第二大值，那么对所有 `nums[j] <= secondMax` 的元素也自然满足 `maxVal >= 2 * nums[j]`。

### 解法二：排序后比较

**思路**：排序后，最大值在最后位置，第二大值在倒数第二位置。比较即可。但需要先保存原始下标。

**步骤**：
1. 记录最大值的原始下标
2. 排序数组
3. 比较 `nums[n-1] >= 2 * nums[n-2]`

### 解法三：朴素两遍遍历

**思路**：第一遍找最大值和下标，第二遍验证所有其他元素是否满足两倍条件。

**步骤**：
1. 第一遍遍历找 `maxVal` 和 `maxIdx`
2. 第二遍遍历检查所有 `i != maxIdx` 的元素是否满足 `maxVal >= 2 * nums[i]`
3. 全部满足返回 `maxIdx`，否则返回 `-1`

## 易错点

1. **初始化错误**：`secondMax` 如果初始化为 `INT_MIN`，需要确保后续比较 `maxVal >= 2 * secondMax` 不会溢出。建议初始化为 -1（因为 nums[i] >= 0）
2. **更新顺序**：更新 maxVal 之前必须先把旧的 maxVal 赋给 secondMax，否则会丢失第二大值
3. **nums[i] == 0 的处理**：如果第二大值是 0，那么 `maxVal >= 0` 恒成立（maxVal >= 0 已由约束保证）
4. **返回值混淆**：要返回**下标**而不是值本身
5. **数组只有两个元素**：`[0, 3]` 应该返回下标 1（3 >= 2 * 0 = 0）
6. **整数溢出**：虽然本题 nums[i] <= 100 不会溢出，但面试中应注意 `2 * secondMax` 的溢出可能

## 面试追问

1. **Q: 如果不保证最大值唯一怎么办？**
   A: 如果有并列最大值，那么 maxVal == secondMax，`maxVal >= 2 * secondMax` 即 `maxVal >= 2 * maxVal` 不可能成立（除非 maxVal == 0），所以直接返回 -1。

2. **Q: 能否在一次遍历中同时找到前 k 大的值？**
   A: 可以维护一个大小为 k 的最小堆，遍历时更新。时间 O(n log k)。

3. **Q: 如果数组可能为空怎么处理？**
   A: 题目保证 n >= 2，但实际面试中应先检查边界。

4. **Q: 如何用排序解但不丢失下标信息？**
   A: 创建 (value, index) 对排序，或者使用 `max_element` 先找到原始下标。

5. **Q: 如果要求「严格两倍」（> 2 * secondMax 而非 >= 2 * secondMax）？**
   A: 只需将条件从 `>=` 改为 `>`。
