# LeetCode 965 - Univalued Binary Tree

## 核心思路

判断二叉树是否所有节点值相同。记录根节点的值，然后遍历整棵树（DFS 或 BFS 均可），检查每个节点是否与根节点值一致。只要发现一个不同的节点就返回 false。这是一道基础的树遍历题，核心在于选择合适的遍历方式并正确处理空节点。

## 思维链

1. **理解问题** - "单值二叉树"就是所有节点的 val 都相等。最简单的方法是把根节点的值记下来，然后遍历所有节点逐一比对。
2. **选择遍历方式** - DFS（前序/中序/后序）或 BFS 都可以。DFS 递归最简洁：检查当前节点值是否等于目标值，然后递归检查左右子树。
3. **递归终止条件** - 空节点返回 true（空子树不影响单值性），当前节点值不等于目标值返回 false。
4. **优化提前终止** - 一旦发现不匹配，可以立即短路返回 false，不需要继续遍历剩余节点。
5. **迭代实现** - 也可以用栈（DFS）或队列（BFS）迭代实现，适合面试中展示多种方法。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|----------|----------|------|
| DFS 递归 | O(n) | O(h) 栈深度 | 代码最简洁 |
| BFS 迭代 | O(n) | O(w) 队列宽度 | 层序遍历风格 |
| DFS 迭代（栈） | O(n) | O(h) | 避免递归栈溢出 |
| 分治法 | O(n) | O(h) | 左右子树分别判断再合并 |

其中 n 为节点数，h 为树高，w 为最大层宽度。

## 关键提示

1. 空节点（nullptr）视为满足条件，返回 true。
2. 只需要一个参考值（根节点的 val），所有节点都与之比较。
3. 短路求值：`return root->val == val && check(root->left, val) && check(root->right, val)` 可以在发现不匹配时提前终止。
4. 不需要额外的数据结构存储所有节点值，遍历过程中直接比较即可。
5. 树为空（root == nullptr）的情况题目保证不会出现（节点数 >= 1），但代码中仍建议处理。
6. 注意值的范围 0 <= Node.val < 100，不需要特殊处理溢出。

## 解法详解

### 解法一：DFS 递归（推荐）

**思路**：用根节点的值作为参考值，递归地检查每个节点。

递归函数 `check(node, val)`:
- 如果 node 为空，返回 true
- 如果 node->val != val，返回 false
- 否则递归检查左子树和右子树

根函数直接调用 `check(root, root->val)`。

**优势**：代码极其简洁，只需 3-4 行核心逻辑。

### 解法二：BFS 迭代

**思路**：用队列进行层序遍历，逐个检查节点值。

1. 将根节点入队，记录目标值 val = root->val
2. 每次出队一个节点，检查其值是否等于 val
3. 如果不等，返回 false
4. 将非空的左右子节点入队
5. 队列清空后返回 true

**优势**：不依赖递归，避免栈溢出问题（虽然本题节点数最多 100，不会溢出）。

### 解法三：分治法

**思路**：自底向上判断。

对于每个节点，分别检查：
- 左子树是否单值且值等于当前节点
- 右子树是否单值且值等于当前节点

两者都满足则当前子树是单值的。

**本质**与解法一相同，但思维角度不同，更适合理解递归的"信任"原则。

### 解法四：收集所有值

最直观但不推荐的方式：遍历整棵树把所有值放入 set，最后检查 set.size() == 1。空间浪费，但逻辑清晰。

## 易错点

1. **忘记处理空节点** - 递归中如果不判断 nullptr，会段错误。
2. **参考值传递错误** - 应该始终与根节点的值比较，而不是与父节点比较（虽然对此题等价，但概念上有区别）。
3. **BFS 中忘记检查子节点是否为空** - 入队前必须判断 left/right 是否为 nullptr。
4. **递归短路写反** - 应该先检查当前节点，再递归子树，避免无效递归。
5. **混淆"所有值相同"和"有序"** - 单值树不是 BST，只是所有值恰好相同。

## 面试追问

1. **如果要返回树中出现次数最多的值，怎么做？** - 遍历树统计频率，用 map 记录。对于 BST 可以利用中序遍历的有序性用 O(1) 额外空间。
2. **如果是 N 叉树怎么处理？** - 递归逻辑不变，只是从检查左右子树变成遍历所有 children。
3. **如果树非常大（百万节点），递归会有什么问题？** - 栈溢出风险。改用迭代 DFS 或 BFS。
4. **如何只用一次遍历同时统计是否单值和节点总数？** - 在递归中同时维护计数器，每访问一个节点 count++。
5. **如果允许最多 k 个不同值，怎么判断？** - 用 set 收集所有值，最后检查 set.size() <= k。
