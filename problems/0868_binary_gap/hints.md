# 868. 二进制间距

## 核心思路

给定正整数 `n`，找到其二进制表示中**两个相邻 1 之间的最长距离**。如果只有一个 1 或没有两个相邻的 1，返回 0。

本质上就是**遍历二进制位，记录每个 1 的位置，计算相邻 1 之间的间距**。

## 思维链

1. **读完题第一反应** → 把 n 转成二进制字符串，找出所有 1 的位置，计算相邻位置之差的最大值。
2. **需要真的转成字符串吗？** → 不需要。可以用位运算逐位检查（`n & 1` 取最低位，`n >> 1` 右移），边遍历边记录上一个 1 的位置。
3. **怎么记录"上一个 1"？** → 维护一个变量 `last`，初始为 -1（表示还没遇到 1）。每次遇到 1 时，如果 `last != -1`，更新最大间距 `ans = max(ans, pos - last)`，然后把 `last = pos`。
4. **遍历方向有讲究吗？** → 无所谓，从低位到高位（右移）或从高位到低位都行。右移更自然。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 位运算逐位扫描 | 右移 + 记录上一个1的位置 | O(log n) | O(1) | 首选 |
| 转字符串 | 转成 "10110" 再扫描 | O(log n) | O(log n) | 简单但不优雅 |
| lowbit 技巧 | 用 n&(n-1) 逐个处理1 | O(k)，k为1的个数 | O(1) | 进阶 |

## 关键提示

1. **"相邻的1"是什么意思？** 不是说两个1中间没有0，而是说在所有1的序列中，相邻的两个1。比如 `10010001` 中，位0和位4的1是"相邻的1"（它们之间没有其他1），间距是4。
2. **遍历位数**：int 最多 32 位，直接遍历 32 次即可。或者用 `while (n > 0)` 更灵活。
3. **初始化 `last = -1`**：-1 表示还没遇到第一个 1，此时不应计算间距。
4. **只有一个 1 的情况**（如 n=8=`1000`）：`last` 只会被设置一次，`ans` 保持 0，正确返回 0。
5. **`n & 1` 取最低位，`n >>= 1` 右移**：这是位运算遍历的标准模板。

## 解法详解

### 解法1: 位运算逐位扫描 -- O(log n) / O(1)

**思考过程**: 遍历每一位，遇到 1 就计算与上一个 1 的距离。

```
示例: n = 22 → 二进制 10110

逐位扫描（从低位到高位）:
  位置 0: 10110 & 1 = 0  → 跳过
  位置 1: 1011  & 1 = 1  → last=-1, 第一个1, 设 last=1
  位置 2: 101   & 1 = 1  → last=1, 间距=2-1=1, 更新 ans=1, 设 last=2
  位置 3: 10    & 1 = 0  → 跳过
  位置 4: 1     & 1 = 1  → last=2, 间距=4-2=2, 更新 ans=2, 设 last=4

最大间距: 2 ✓

示例: n = 8 → 二进制 1000
  位置 0: 1000 & 1 = 0  → 跳过
  位置 1: 100  & 1 = 0  → 跳过
  位置 2: 10   & 1 = 0  → 跳过
  位置 3: 1    & 1 = 1  → last=-1, 第一个1, 设 last=3

只有一个 1, ans 保持 0 ✓

示例: n = 5 → 二进制 101
  位置 0: 101 & 1 = 1 → last=-1, 第一个1, 设 last=0
  位置 1: 10  & 1 = 0 → 跳过
  位置 2: 1   & 1 = 1 → last=0, 间距=2-0=2, 更新 ans=2, 设 last=2

最大间距: 2 ✓
```

```cpp
class Solution {
public:
    int binaryGap(int n) {
        int ans = 0;
        int last = -1;  // 上一个 1 的位置，-1 表示还没遇到
        
        for (int pos = 0; n > 0; pos++, n >>= 1) {
            if (n & 1) {  // 当前位是 1
                if (last != -1) {
                    ans = max(ans, pos - last);
                }
                last = pos;
            }
        }
        return ans;
    }
};
```

**关键点**:
- `for (int pos = 0; n > 0; pos++, n >>= 1)` 比固定 32 次更优，n 变为 0 就停。
- `last = -1` 处理了"第一个 1"的边界情况。
- 时间 O(log n)，因为 n 最多有 log n 位。空间 O(1)。

### 解法2: 转字符串扫描 -- O(log n) / O(log n)

**不同视角**: 先把 n 转成二进制字符串，然后扫描字符串中 '1' 的位置。

```cpp
class Solution {
public:
    int binaryGap(int n) {
        // 转成二进制字符串（低位在前）
        string binary;
        while (n > 0) {
            binary += (char)('0' + (n & 1));
            n >>= 1;
        }
        // binary 是反向的，但间距计算只看"位置差"，不受方向影响
        
        int ans = 0, last = -1;
        for (int i = 0; i < (int)binary.size(); i++) {
            if (binary[i] == '1') {
                if (last != -1) {
                    ans = max(ans, i - last);
                }
                last = i;
            }
        }
        return ans;
    }
};
```

**关键点**:
- 字符串是低位在前（反向），但间距计算只看"位置差"，不受方向影响。
- 额外使用了 O(log n) 空间存字符串，不如解法1优。
- 适合不太熟悉位运算的人，用字符串处理更直观。

---

### 解法3: lowbit 技巧 -- O(k) / O(1)

**另一种视角**: 用 `__builtin_ctz(n)` 获取最低位 1 的位置，用 `n &= (n - 1)` 去掉最低位的 1。这样只遍历"1的个数"次。

```
n & (n-1) 的原理:
  n   = 10100
  n-1 = 10011
  n & (n-1) = 10000 → 去掉最低位的1

__builtin_ctz(n) 返回末尾0的个数 = 最低位1的位置

示例: n = 22 = 10110
  第1轮: ctz(10110)=1, last=-1 → 设 last=1, n&=(n-1) → 10100
  第2轮: ctz(10100)=2, last=1 → 间距=2-1=1, ans=1, last=2, n&=(n-1) → 10000
  第3轮: ctz(10000)=4, last=2 → 间距=4-2=2, ans=2, last=4, n&=(n-1) → 00000
  
  最大间距: 2 ✓
```

```cpp
class Solution {
public:
    int binaryGap(int n) {
        int ans = 0;
        int last = -1;
        
        while (n > 0) {
            // __builtin_ctz: 返回末尾0的个数 = 最低位1的位置
            int pos = __builtin_ctz(n);
            if (last != -1) {
                ans = max(ans, pos - last);
            }
            last = pos;
            n &= (n - 1);  // 去掉最低位的1
        }
        return ans;
    }
};
```

**关键点**:
- `__builtin_ctz(n)` 返回 n 最低位 1 的位置（count trailing zeros）。
- `n &= (n - 1)` 去掉最低位的 1 -- 这是经典的 Brian Kernighan 位运算技巧。
- 只遍历 k 次（k 为 1 的个数），当 1 很稀疏时比逐位扫描快。
- 这个技巧在"计算二进制中 1 的个数"等问题中也很常见。

## 解法对比

|  | 逐位扫描 | 转字符串 | lowbit技巧 |
|--|---------|---------|-----------|
| 时间 | O(log n) | O(log n) | O(k), k=popcount |
| 空间 | **O(1)** | O(log n) | **O(1)** |
| 代码复杂度 | **最简单** | 简单 | 中等 |
| 面试推荐 | **首选** | 备选 | 加分项 |

**面试选择**: 解法1最稳妥，简洁正确。如果想展示位运算能力，补充解法3。

## 易错点

1. **忘记初始化 `last = -1`**：
   - 错: `last = 0`，当第一个 1 恰好在位置 0 时误认为"已有前一个1在位置0"
   - 对: `last = -1`，显式标记"还没有遇到 1"

2. **循环条件写错**：
   - 错: `for (int pos = 0; pos < 32; pos++)` 但忘记右移 → 永远读的是同一位
   - 对: 每次 `n >>= 1`，或者用 `(n >> pos) & 1` 检查

3. **混淆"相邻1的距离"和"两个1之间0的个数"**：
   - `10010001`: 位0和位4之间距离是4（不是3）。距离 = 位置差，不是中间0的数量。

4. **负数的右移**：
   - C++ 中 `>>` 对有符号整数是算术右移（高位补符号位），可能死循环
   - 题目保证 n >= 1，用 `n > 0` 作为循环条件即可

5. **只有一个 1 的情况**（如 n=1, n=2, n=4...）：
   - 应返回 0，因为"没有两个 1 形成间距"

## 面试追问

**Q1: 如果 n 可能是 0 呢？**
> n = 0 没有任何 1，返回 0。我们的解法1中 `while (n > 0)` 直接不进循环，返回 `ans = 0`，正确处理。

**Q2: 如果要找最小间距呢？**
> 同样的框架，把 `max` 改成 `min`。注意初始值设为 INT_MAX，并且最后检查是否真的找到了两个 1（如果 `last` 只被设置了一次，返回 0 或 -1）。

**Q3: 如果 n 是 64 位整数呢？**
> 把 `int` 换成 `long long` 或 `uint64_t`，循环最多 64 次。逻辑完全不变。`__builtin_ctz` 换成 `__builtin_ctzll`。

**Q4: `__builtin_ctz` 不能用怎么办？**
> 手写：`int pos = 0; while (!(n & (1 << pos))) pos++;`。或者用解法1的逐位扫描，不依赖任何编译器内置函数。
