# 415. 字符串相加

## 核心思路

这道题本质上就是**模拟竖式加法**：从个位（字符串末尾）开始，逐位相加，处理进位，和我们小学学的手算加法完全一样。

## 思维链

1. **读完题第一反应**：题目不让用 BigInteger，也不让转成整数。那如果字符串很长（比如 10000 位），`int` 和 `long long` 根本存不下，所以只能逐位操作。
2. **怎么逐位操作？** 回想小学竖式加法：从最右边（个位）开始，对齐两个数，逐位相加，满 10 进 1。
3. **字符串的末尾就是个位**：用两个指针分别从 `num1` 和 `num2` 的末尾往前走，每一步取出对应位的数字相加。
4. **处理长度不等的情况**：短的那个数高位视为 0，继续加就行。
5. **别忘了最后的进位**：比如 "999" + "1" = "1000"，最后一步加完还有进位，要额外加一位。
6. **结果是倒序构建的**：我们从低位加到高位，结果字符串最后要反转。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 模拟竖式加法 | 双指针从末尾往前，逐位相加处理进位 | O(max(m,n)) | O(max(m,n)) | ⭐ 必须写出 |
| 模拟竖式（预分配优化） | 预先确定结果长度，避免反转 | O(max(m,n)) | O(max(m,n)) | 加分项 |

> 这道题不存在"暴力解 → 优化解"的演进，因为逐位模拟本身就是 O(n) 最优解。区别只在实现的优雅程度。

## 关键提示

1. **字符 '0'-'9' 和数字 0-9 的转换**：`char - '0'` 得到数字，`digit + '0'` 得到字符。你的代码里有没有正确处理这个转换？
2. **两个指针不一定同时走到头**：一个 3 位数加一个 5 位数，短的走完了怎么办？（提示：把越界的位视为 0）
3. **循环什么时候结束？** 不仅是两个指针都走完，还要考虑——如果此时还有进位呢？
4. **结果字符串是倒着拼接的**：你打算最后反转，还是用头部插入？（提示：反转更高效）

```
模拟竖式加法示意图:

    num1:    1 1       ← i 从右往左
    num2:  1 2 3       ← j 从右往左
    ──────────────
           1 3 4       ← 结果

详细过程:
  Step1: i=1, j=2 → 1+3=4, carry=0, 写入4
  Step2: i=0, j=1 → 1+2=3, carry=0, 写入3
  Step3: i=-1, j=0 → 0+1=1, carry=0, 写入1
  结果(拼接顺序): "431" → 反转 → "134"
```

## 解法详解

### 解法1: 模拟竖式加法（反转法） — O(max(m,n)) / O(max(m,n)) ⭐ 面试首选

**思考过程**：
- 竖式加法是从右往左的，所以两个指针 `i` 和 `j` 分别从两个字符串的末尾开始。
- 每一步：取出当前位的数字（越界则取 0），加上进位 `carry`，计算当前位结果和新的进位。
- 把当前位结果追加到结果字符串，最后整体反转。

```cpp
class Solution {
public:
    string addStrings(string num1, string num2) {
        string result;
        int i = num1.size() - 1;  // num1 的指针，从末尾开始
        int j = num2.size() - 1;  // num2 的指针，从末尾开始
        int carry = 0;            // 进位
        
        // 只要还有位没处理完，或者还有进位，就继续
        while (i >= 0 || j >= 0 || carry) {
            int sum = carry;
            
            // 取 num1 当前位，越界视为 0
            if (i >= 0) {
                sum += num1[i] - '0';
                i--;
            }
            // 取 num2 当前位，越界视为 0
            if (j >= 0) {
                sum += num2[j] - '0';
                j--;
            }
            
            carry = sum / 10;              // 新的进位
            result += (char)(sum % 10 + '0'); // 当前位结果（注意是倒序）
        }
        
        reverse(result.begin(), result.end()); // 反转得到正序
        return result;
    }
};
```

**关键点**：
- 循环条件是 `i >= 0 || j >= 0 || carry`，三个条件缺一不可。尤其 `carry` 那个条件——没有它，"999"+"1" 就会输出 "000" 而不是 "1000"。
- `sum % 10` 是当前位结果，`sum / 10` 是进位，这和竖式加法完全一致。


### 解法2: 模拟竖式（无需反转） — O(max(m,n)) / O(max(m,n))

**从解法1优化**：解法1 最后需要 `reverse`，虽然时间复杂度不变，但我们可以预先分配好结果字符串的大小，直接从高位往低位填写，省去反转这一步。

```cpp
class Solution {
public:
    string addStrings(string num1, string num2) {
        int i = num1.size() - 1;
        int j = num2.size() - 1;
        int carry = 0;
        
        // 结果最多比较长的那个多一位（进位）
        int maxLen = max(num1.size(), num2.size());
        string result(maxLen + 1, '0'); // 预分配，多一位给可能的最高进位
        int k = maxLen; // 从结果的最后一位开始填
        
        while (i >= 0 || j >= 0 || carry) {
            int sum = carry;
            if (i >= 0) sum += num1[i--] - '0';
            if (j >= 0) sum += num2[j--] - '0';
            
            carry = sum / 10;
            result[k--] = (char)(sum % 10 + '0');
        }
        
        // 如果最高位没用到（没有最终进位），跳过前导 '0'
        // k+1 是我们最后写入的位置
        return result.substr(k + 1);
    }
};
```

**关键点**：
- 预分配 `maxLen + 1` 的空间，因为两个 n 位数相加最多得到 n+1 位数。
- 最后用 `substr(k+1)` 截掉可能的前导零。这里 `k+1` 正好指向结果的最高有效位。

## 解法对比

| | 解法1（反转法） | 解法2（预分配法） |
|---|---|---|
| 核心逻辑 | 倒序拼接 + 最后反转 | 预分配空间 + 从右往左填 |
| 代码简洁度 | ⭐ 更简洁，推荐面试写 | 稍复杂，需要处理 substr |
| 实际性能 | reverse 有一次额外遍历 | 无需反转，但 substr 也会拷贝 |
| 选择建议 | **面试首选**，不容易写错 | 追求极致可以提一下 |

> 两种解法的时间和空间复杂度完全相同，面试中写解法1即可。

## 易错点

1. **忘记处理最后的进位**
   - ✗ 循环条件写成 `while (i >= 0 || j >= 0)`，漏掉 `carry`
   - ✓ `while (i >= 0 || j >= 0 || carry)`
   - 反例："999" + "1"，最后 carry=1 没有被处理，输出 "000" 而不是 "1000"

2. **字符和数字混淆**
   - ✗ `sum += num1[i];` — 这里加的是 ASCII 码（如 '1' = 49）
   - ✓ `sum += num1[i] - '0';` — 减去 '0' 才得到数字 1

3. **拼接结果时忘记转回字符**
   - ✗ `result += sum % 10;` — 追加的是 int，不是 char
   - ✓ `result += (char)(sum % 10 + '0');`

4. **指针方向搞反**
   - ✗ `int i = 0;` 从头开始（这是高位！）
   - ✓ `int i = num1.size() - 1;` 从末尾开始（个位）

## 面试追问

**Q1（基础理解）**：为什么不能直接 `stoi(num1) + stoi(num2)` 再转回字符串？
> 因为字符串长度可达 10^4 位，远超 `long long` 的范围（约 19 位）。这道题的本意就是考大数运算。

**Q2（变体）**：如果要实现大数乘法（LeetCode 43），在本题基础上怎么扩展？
> 乘法可以分解为"逐位相乘再逐位相加"。本题的加法逻辑可以直接复用。核心区别：乘法需要对 num2 的每一位和 num1 相乘，每次错一位（相当于乘以 10 的幂），再把所有中间结果加起来。

**Q3（变体）**：如果要实现大数减法呢？
> 思路类似，改为逐位相减处理借位。但要额外处理：先比较大小确定结果正负，再用大的减小的。借位时当前位 +10 再减，向高位借 1。
