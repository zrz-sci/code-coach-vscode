# 48. 旋转图像

## 核心思路

顺时针旋转90度 = **先沿主对角线转置，再左右翻转每一行**。这道题本质上是把一个复杂的几何变换分解为两个简单操作的组合。

## 思维链

1. **读完题第一反应**：旋转后每个元素去了哪里？位置 `(i, j)` 旋转后到了 `(j, n-1-i)`。如果不要求原地，直接 new 一个矩阵按规则填就行。

2. **原地要求是关键约束**：不能用额外矩阵。直接赋值会覆盖原值，怎么办？要么用 temp 变量做"四元素循环替换"，要么把旋转拆成两步简单操作。

3. **能不能拆成更简单的操作？** 回忆线性代数：旋转矩阵可以分解为转置 + 翻转。具体地，顺时针90° = 转置（沿主对角线翻）+ 水平翻转（左右镜像）。这两步都容易原地完成！

4. **验证拆解的正确性**：`(i,j)` → 转置后 `(j,i)` → 左右翻转后 `(j, n-1-i)`。和直接旋转公式一致 ✓

5. **另一种思路——直接循环替换**：旋转时4个位置形成一个"旋转环"，每次把4个元素同时挪到下一个位置，只需1个 temp 变量。

6. **选哪种？** 转置+翻转代码最简洁、最不容易出错，面试首选。循环替换也常考，展示对坐标变换的理解。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 辅助矩阵 | 新矩阵按规则填入 | O(n²) | O(n²) | 能说出即可 |
| 转置 + 翻转 | 分解为两步简单操作 | O(n²) | O(1) | ⭐ 必须写出 |
| 四元素循环替换 | 一圈一圈旋转 | O(n²) | O(1) | 加分项 |

## 关键提示

1. **坐标映射规则**：顺时针旋转90°后，`matrix[i][j]` 去了 `matrix[j][n-1-i]`。先在纸上画个 3×3 验证。

2. **转置是什么**：沿主对角线翻转，`matrix[i][j]` ↔ `matrix[j][i]`。注意只遍历上三角（`j > i`），否则交换两次等于没换。

3. **循环替换的关键**：4个位置形成环路，只需1个 temp。难点在于确定遍历范围——外层 `i ∈ [0, n/2)`，内层 `j ∈ [i, n-1-i)`。

4. **ASCII 示意图——3×3 旋转的拆解**：
```
原始:          转置:          左右翻转:
1  2  3       1  4  7       7  4  1
4  5  6  →    2  5  8  →    8  5  2    ← 即顺时针90°结果
7  8  9       3  6  9       9  6  3
```

5. **循环替换的四元素环路**：
```
对 3×3 矩阵，位置(0,0)的旋转环:
(0,0) → (0,2) → (2,2) → (2,0) → (0,0)
  1   →   3   →   9   →   7   →   1

即: top→right→bottom→left→top
     1 覆盖原来 3 的位置
     3 覆盖原来 9 的位置
     9 覆盖原来 7 的位置
     7 覆盖原来 1 的位置
```

## 解法详解

### 解法1: 辅助矩阵 — O(n²) / O(n²)

**思考过程**：最直觉的做法——创建一个新矩阵，根据旋转规则 `new[j][n-1-i] = old[i][j]` 逐个填入，最后把新矩阵复制回去。

```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();
        vector<vector<int>> temp = matrix; // 拷贝一份
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                // 旋转公式：(i,j) → (j, n-1-i)
                matrix[j][n - 1 - i] = temp[i][j];
            }
        }
    }
};
```

**关键点**：虽然简单，但题目要求 **原地操作**，O(n²) 额外空间不满足要求。面试中可以先说这个思路展示理解，然后引出原地解法。

---

### 解法2: 转置 + 左右翻转 — O(n²) / O(1) ⭐ 面试首选

**从解法1优化**：解法1的瓶颈是需要额外矩阵防止覆盖。我们能不能把"旋转"拆成两个可以原地完成的简单操作？

**数学原理**：
```
顺时针旋转 90° 的坐标变换: (i, j) → (j, n-1-i)

可以拆成两步:
  Step 1 - 转置:       (i, j) → (j, i)
  Step 2 - 左右翻转:   (j, i) → (j, n-1-i)   ✓ 与旋转公式一致
```

**可视化过程（4×4 矩阵）**：
```
原始矩阵:              Step1 转置(沿\对角线翻):   Step2 左右翻转(每行reverse):
 5   1   9  11          5   2  13  15             15  13   2   5
 2   4   8  10    →     1   4   3  14       →     14   3   4   1
13   3   6   7          9   8   6  12             12   6   8   9
15  14  12  16         11  10   7  16             16   7  10  11
                                                   ↑ 最终结果 ✓
```

```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();
        
        // Step 1: 沿主对角线转置
        // 只遍历上三角 (j > i)，避免交换两次抵消
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                swap(matrix[i][j], matrix[j][i]);
            }
        }
        
        // Step 2: 每一行左右翻转
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n / 2; j++) {
                swap(matrix[i][j], matrix[i][n - 1 - j]);
            }
        }
    }
};
```

**关键点**：
- 转置时 `j` 从 `i+1` 开始，不是从 `0` 开始。从 `0` 开始会把每对元素交换两次，等于没换。
- 两步操作的顺序不能反：先翻转再转置得到的是**逆时针** 90°。

---

### 解法3: 四元素循环替换 — O(n²) / O(1)

**思考过程**：不拆成两步，直接在原地旋转。观察发现：旋转时，4个位置形成一个"旋转环"，可以用1个 temp 变量完成4个元素的循环搬移。

**四元素环路推导**：
```
设 n=4, 考虑位置 (i, j):

位置1: (i, j)           → 旋转到 → (j, n-1-i)        = 位置2
位置2: (j, n-1-i)       → 旋转到 → (n-1-i, n-1-j)    = 位置3
位置3: (n-1-i, n-1-j)   → 旋转到 → (n-1-j, i)        = 位置4
位置4: (n-1-j, i)       → 旋转到 → (i, j)             = 位置1 ← 回来了！

四元素循环替换:
temp = matrix[i][j]
matrix[i][j]             = matrix[n-1-j][i]
matrix[n-1-j][i]         = matrix[n-1-i][n-1-j]
matrix[n-1-i][n-1-j]     = matrix[j][n-1-i]
matrix[j][n-1-i]         = temp
```

**遍历范围的确定**：
```
n=4 的矩阵, 我们需要处理的起始位置:
┌──────────────────┐
│ (0,0) (0,1) (0,2)│(0,3)     i ∈ [0, n/2)     = [0, 2)
│ (1,1)            │(1,3)     j ∈ [i, n-1-i)   = 动态范围
│                  │
│                  │
└──────────────────┘
外圈: i=0, j=0,1,2  (3个四元组)
内圈: i=1, j=1      (1个四元组)
总共 4 个四元组 × 4 = 16 个元素, 刚好覆盖整个矩阵
```

```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();
        
        // 从外圈到内圈，逐层旋转
        for (int i = 0; i < n / 2; i++) {
            // 每层处理 j ∈ [i, n-1-i)，最后一个元素属于下一个四元组
            for (int j = i; j < n - 1 - i; j++) {
                int temp = matrix[i][j];
                
                // 左 → 上 (逆时针方向搬移，等效于顺时针旋转)
                matrix[i][j]             = matrix[n-1-j][i];
                // 下 → 左
                matrix[n-1-j][i]         = matrix[n-1-i][n-1-j];
                // 右 → 下
                matrix[n-1-i][n-1-j]     = matrix[j][n-1-i];
                // temp(上) → 右
                matrix[j][n-1-i]         = temp;
            }
        }
    }
};
```

**关键点**：
- 赋值方向是**逆时针搬移**（左→上→右→下），这样每个元素顺时针移到了正确位置。
- 内层循环 `j < n-1-i` 而不是 `j <= n-1-i`，因为最后一个位置属于第一个四元组的第二个位置，已经被处理了。

|---|---|---|---|

| 空间 | O(n²) | O(1) | O(1) |
| 代码复杂度 | 最简单 | 简单 | 较复杂 |
| 原地 | ✗ | ✓ | ✓ |
| 面试推荐 | 展示理解 | ⭐ 首选 | 展示深度 |

**选择建议**：
- 面试开场先说辅助矩阵展示理解，然后写**转置+翻转**（代码简洁不易错）。
- 如果面试官追问"能不能一次遍历完成"，再给循环替换。

## 易错点

1. **转置时遍历范围错误**
   - ✗ `for (int j = 0; j < n; j++)` → 每对交换两次，矩阵不变
   - ✓ `for (int j = i + 1; j < n; j++)` → 只遍历上三角

2. **循环替换的赋值方向搞反**
   - ✗ 按顺时针方向赋值：`matrix[j][n-1-i] = matrix[i][j]` ... → 覆盖了还没保存的值
   - ✓ 按逆时针方向赋值：先保存 `temp = matrix[i][j]`，然后从"来源"方向依次赋值

3. **循环替换的内层边界多了1**
   - ✗ `j <= n - 1 - i` → 角上的元素被处理两次
   - ✓ `j < n - 1 - i` → 每个四元组恰好处理一次

4. **先翻转再转置 ≠ 先转置再翻转**
   - 先转置再左右翻转 = 顺时针 90°
   - 先左右翻转再转置 = 逆时针 90°
   - 面试时搞混顺序会得到错误结果

## 面试追问

**Q1: 如果要逆时针旋转 90°，代码怎么改？**
→ 两种方式：(a) 转置 + 上下翻转，(b) 上下翻转 + 转置。只需把"左右翻转"换成"上下翻转"（或调换两步顺序）。

**Q2: 如果要旋转 180°，怎么做最简单？**
→ 180° = 上下翻转 + 左右翻转（两步都是镜像操作，顺序无所谓）。或者直接 `matrix[i][j] ↔ matrix[n-1-i][n-1-j]`。

**Q3: 如果矩阵不是正方形（m×n），能原地旋转吗？**
→ 不能简单原地旋转，因为旋转后矩阵维度变为 n×m。如果底层是一维数组存储，可以用"置换环"原地重排，但很复杂。面试中说明"正方形才能原地"即可。

**Q4: 如果要旋转 k×90°，怎么优化？**
→ `k %= 4`，然后 k=1 顺时针90°，k=2 旋转180°，k=3 逆时针90°。不需要旋转 k 次。
