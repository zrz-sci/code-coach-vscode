# 1047. 删除字符串中的所有相邻重复项

## 核心思路

这道题本质上就是"对对碰消除"——每当两个相同字符相邻就消掉，消掉后可能产生新的相邻重复，继续消，直到没有可消的为止。这和"有效括号匹配"是同一类栈问题。

## 思维链

1. **读完题第一反应**：模拟题意，扫一遍找到相邻重复就删掉，然后再扫，直到没有重复。→ 这就是暴力模拟。
2. **暴力的瓶颈在哪？**：每次删除后字符串变短，需要重新扫描。最坏情况如 `"aabbccddee..."`，每轮只删一对，要扫 O(n/2) 轮，每轮 O(n)，总计 O(n²)。
3. **瓶颈的本质是什么？**：删除一对后，它前后的字符变成了新的"相邻"关系，我们需要回头检查——这恰好是"后进先出"的场景！
4. **什么数据结构支持这种操作？**：**栈**！每次看到一个新字符，和栈顶比较：相同就弹出（消除），不同就压入。一次遍历 O(n) 搞定。
5. **还有更简洁的写法吗？**：直接用 `string` 当栈——`push_back` 当压栈，`pop_back` 当弹栈，最后这个 string 就是答案，省去了栈转字符串的步骤。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力模拟 | 反复扫描删除相邻重复 | O(n²) | O(n) | 能说出即可 |
| 栈 | 遍历字符，栈顶相同则弹出 | O(n) | O(n) | ⭐ 必须写出 |
| 字符串当栈 | 用 string 的 back/pop_back 模拟栈 | O(n) | O(n) | 加分项（代码最简洁） |

## 关键提示

1. **联想括号匹配**：`"())"` 遇到配对的就消除 → 这道题 `"abb"` 遇到相同的就消除，逻辑完全一致。
2. **栈顶就是"上一个未被消除的字符"**：当前字符和栈顶比较，就能判断是否形成新的相邻重复。
3. **删除后的连锁反应**：`"abbaca"` → 删 `bb` 后变 `"aaca"` → 删 `aa` 变 `"ca"`。栈天然处理了这种"消除后回看前一个"的行为。
4. **string 可以当栈用**：C++ 的 `string` 有 `back()` 和 `pop_back()`，完美模拟栈，且最后不需要额外翻转。

```
// 处理 "abbaca" 的栈过程:
//
// 字符   操作           栈状态
//  a     栈空,压入       [a]
//  b     a≠b,压入       [a, b]
//  b     b==b,弹出!     [a]        ← "bb" 消除
//  a     a==a,弹出!     []         ← "aa" 消除（连锁反应！）
//  c     栈空,压入       [c]
//  a     c≠a,压入       [c, a]
//
// 最终栈内容: "ca" ✓
```

## 解法详解

### 解法1: 暴力模拟 — O(n²) / O(n)

**思考过程**：最直觉的做法，完全模拟题意。用一个标志位记录本轮是否有删除发生，如果有就继续扫描，直到一轮扫完没有任何删除。

```cpp
class Solution {
public:
    string removeDuplicates(string s) {
        bool found = true;
        while (found) {
            found = false;
            string next;
            for (int i = 0; i < s.size(); i++) {
                // 如果当前字符和下一个相同，跳过这一对
                if (i + 1 < s.size() && s[i] == s[i + 1]) {
                    found = true;
                    i++; // 跳过下一个字符（一对一起跳）
                } else {
                    next += s[i];
                }
            }
            s = next;
        }
        return s;
    }
};
```

**关键点**：
- 每轮只删除"当前相邻"的重复对，删除后可能产生新的相邻重复，所以需要多轮。
- 最坏情况如 `"aabbccdd"`，每轮删一层，需要 O(n/2) 轮，每轮 O(n)，总计 O(n²)。

### 解法2: 栈 — O(n) / O(n) ⭐ 面试首选

**从解法1优化**：暴力解的瓶颈在于"删除后需要回头看前一个字符"，反复扫描很低效。栈天然支持"看上一个元素"的操作（栈顶），一次遍历就够了。

```cpp
class Solution {
public:
    string removeDuplicates(string s) {
        stack<char> stk;
        for (char c : s) {
            // 栈顶和当前字符相同 → 消除（弹出栈顶）
            if (!stk.empty() && stk.top() == c) {
                stk.pop();
            } else {
                // 不同 → 压入栈
                stk.push(c);
            }
        }
        // 栈中剩余字符就是结果（注意是逆序的）
        string result;
        while (!stk.empty()) {
            result += stk.top();
            stk.pop();
        }
        reverse(result.begin(), result.end()); // 栈是后进先出，需要翻转
        return result;
    }
};
```

**关键点**：
- 每个字符最多入栈一次、出栈一次，总操作 O(n)。
- 栈底到栈顶的顺序是正序的，但弹出时是逆序的，所以最后需要 `reverse`。

### 解法3: 字符串当栈 — O(n) / O(n)（最简洁写法）

**优化点**：解法2最后需要从栈中逐个弹出再翻转，不够优雅。C++ 的 `string` 本身就支持 `back()` 和 `pop_back()`，可以直接当栈用，结果字符串就是最终答案，无需翻转。

```cpp
class Solution {
public:
    string removeDuplicates(string s) {
        string result; // 既是栈，也是最终答案
        for (char c : s) {
            // result.back() 等价于 stack.top()
            if (!result.empty() && result.back() == c) {
                result.pop_back(); // 等价于 stack.pop()
            } else {
                result.push_back(c); // 等价于 stack.push()
            }
        }
        return result; // 直接返回，不需要翻转！
    }
};
```

**关键点**：
- `string` 的末尾操作（`back`, `push_back`, `pop_back`）都是 O(1)，和栈完全一样。
- 省去了栈→字符串的转换和翻转步骤，代码更简洁。

| 时间 | O(n²) 最坏 | O(n) | O(n) |
| 空间 | O(n) | O(n) 栈 + O(n) 结果 | O(n) 仅结果 |
| 代码量 | 中等 | 中等 | 最少 |
| 需要翻转 | 不需要 | 需要 | 不需要 |

**何时选哪个**：面试中直接写解法3（字符串当栈），简洁且高效。如果面试官问"你用了什么数据结构"，回答"用 string 模拟栈"。

## 易错点

1. **忘记处理空栈/空字符串**：
   - ✗ `if (result.back() == c)` → 当 result 为空时 UB（未定义行为）
   - ✓ `if (!result.empty() && result.back() == c)` → 先检查非空

2. **用 stack 时忘记翻转结果**：
   - ✗ 直接从栈中弹出拼接字符串，结果是反的
   - ✓ 弹出后 `reverse`，或者用 `string` 当栈避免这个问题

3. **暴力模拟时一对只跳一个字符**：
   - ✗ 发现 `s[i] == s[i+1]` 后只 `continue`，没有跳过 `i+1`
   - ✓ 必须 `i++` 额外跳一步，把这一对都跳过

## 面试追问

**Q1: 能用 O(1) 额外空间吗？（不算输出空间）**
> 可以。用双指针原地操作：`i` 是"栈顶指针"，`j` 遍历原字符串。`s[i] == s[j]` 时 `i--`（弹栈），否则 `s[++i] = s[j]`（压栈）。最后 `s.substr(0, i+1)` 就是结果。严格来说输出也是 O(n)，但不需要额外的栈空间。

**Q2: 如果不是删除 2 个相邻相同，而是删除 k 个相邻相同呢？（LeetCode 1209）**
> 栈中不只存字符，还要存连续出现次数 `pair<char, int>`。当计数达到 k 时弹出。思路完全一致，只是"消除条件"从 `count==2` 变成 `count==k`。

**Q3: 这道题和括号匹配（LeetCode 20）有什么关系？**
> 本质相同——都是"遇到配对就消除"。括号匹配是左右括号配对，本题是相同字符配对。核心模式：遍历序列，用栈记录待匹配的元素，栈顶满足匹配条件就弹出。
