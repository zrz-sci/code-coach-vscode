# 609. Find Duplicate File in System - 在系统中查找重复文件

## 题目理解
给定目录信息列表，每条字符串包含目录路径和该目录下的文件及其内容。找出所有内容相同的重复文件，按组返回完整路径。

## 提示

### 提示 1 - 哈希表分组
核心思路：以**文件内容**作为 key，将所有相同内容的文件路径归为一组。用 `unordered_map<string, vector<string>>` 实现。

### 提示 2 - 字符串解析
每条路径字符串格式为：`"root/d1 f1.txt(content1) f2.txt(content2)"`
- 先按空格分割，第一个是目录路径，后面是文件信息
- 对每个文件信息，找到 `(` 和 `)` 的位置来提取文件名和内容
- 拼接完整路径：`目录 + "/" + 文件名`

### 提示 3 - 过滤结果
最终只返回包含 **2个及以上** 文件的分组（至少有两个重复才算）。

### 提示 4 - Follow-up 思考
- 真实文件系统：用 BFS（节省内存）或 DFS
- GB 级大文件：先比较文件大小 -> 再比较哈希（MD5/SHA256）-> 最后逐字节比较
- 每次只能读 1KB：分块计算哈希

## 复杂度
- 时间复杂度：O(n * k)，n 为路径数，k 为平均每条路径的文件数
- 空间复杂度：O(n * k)，哈希表存储所有文件路径

## 关键词
`哈希表`, `字符串解析`, `分组`
