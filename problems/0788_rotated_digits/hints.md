# 788. Rotated Digits (旋转数字)

## 核心思路

将数字逐位检查，判断是否满足两个条件：(1) 每一位都是合法旋转数字 {0,1,2,5,6,8,9}；(2) 至少有一位属于"变化数字" {2,5,6,9}，从而旋转后整体与原数不同。可以暴力枚举也可用数位 DP 在 O(logN) 时间内统计。

## 思维链

1. **理解旋转规则**：0,1,8 旋转后不变；2<->5, 6<->9 旋转后改变但仍合法；3,4,7 旋转后变成非法形状。
2. **"好数"的判定**：一个数是"好数"当且仅当所有位都是合法数字，且至少有一位是变化数字。
3. **暴力法**：N <= 10^4，逐一枚举每个数，逐位检查即可，时间 O(N * D) 其中 D 为位数。
4. **优化思路 — 数位 DP**：如果 N 很大，可以用数位 DP。状态为当前位、是否已受到上界约束（tight）、是否已经出现过变化数字。
5. **DP 状态定义**：dp(pos, tight, hasChanged) 表示从第 pos 位到最低位，满足上界约束 tight，且之前是否已有变化数字 hasChanged 的合法好数数量。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 暴力枚举 | O(N * logN) | O(1) | 简单直接，适合 N <= 10^4 |
| 底层 DP (按位构建) | O(N) | O(N) | 递推式，不递归 |
| 数位 DP (记忆化搜索) | O(logN) | O(logN) | 可处理极大 N，面试加分 |

## 关键提示

1. **合法数字集合**：{0, 1, 2, 5, 6, 8, 9} 共 7 个。
2. **变化数字集合**：{2, 5, 6, 9} 共 4 个，出现任一个即保证旋转后不同。
3. **不变数字集合**：{0, 1, 8} 共 3 个，如果全是这些数字，则旋转后相同，不是好数。
4. **非法数字集合**：{3, 4, 7} 共 3 个，出现任一个则整个数非法。
5. 数位 DP 中要注意前导零的处理——前导零不影响合法性判断。
6. 暴力法中一旦发现非法数字可以提前 break，略微加速。

## 解法详解

### 解法一：暴力枚举（推荐面试首选）

**思路**：遍历 [1, N] 每个数，写辅助函数 isGood(x) 判断。

**isGood(x) 逻辑**：
- 逐位取出数字 d = x % 10
- 如果 d 属于 {3, 4, 7}，直接返回 false
- 如果 d 属于 {2, 5, 6, 9}，标记 hasChanged = true
- 循环结束后返回 hasChanged

**复杂度**：O(N * logN) 时间，O(1) 空间。

### 解法二：底层 DP (按位构建)

**思路**：dp[i] 表示数字 i 的状态：0 = 含非法数字，1 = 合法但旋转后不变，2 = 好数。

**转移规则**：`dp[i]` 由 `dp[i/10]`（高位部分）和 `dp[i%10]`（最低位）组合决定：
- 任一部分为 0 => dp[i] = 0（非法传染）
- 任一部分为 2 => dp[i] = 2（有变化数字）
- 都为 1 => dp[i] = 1（全部不变）

**复杂度**：O(N) 时间，O(N) 空间。

### 解法三：数位 DP（记忆化搜索）

**思路**：将 N 转为数字数组，从高位到低位递归，维护状态 (pos, tight, hasChanged)。

**转移**：对当前位枚举合法数字 {0,1,2,5,6,8,9}，如果 tight 则上界为 N 的当前位。

**复杂度**：O(logN * 2 * 2 * 7) = O(logN) 时间和空间。

## 易错点

1. **忘记"必须变化"条件**：只判断了合法性而忘记检查是否至少有一位属于 {2,5,6,9}，导致把 1, 8, 10 等也算作好数。
2. **数字 0 的处理**：题目范围从 1 开始，但 0 本身不算好数。单独检查也旋转后不变，所以从 1 开始枚举即可。
3. **数位 DP 中前导零**：前导零本身是合法的（0 旋转后仍是 0），不会导致非法，但也不算"变化"。要正确处理 leading zero 状态。
4. **混淆"旋转"与"翻转"**：这里的旋转是 180 度旋转（上下颠倒），不是左右翻转。2 旋转后看起来像 5，这是特定的视觉规则。
5. **底层 DP 中 i < 10 的基底情况**：必须单独处理个位数的三种状态，作为后续递推的基础。

## 面试追问

1. **Q: 如果 N 扩展到 10^18，暴力还能用吗？** A: 不能，必须用数位 DP。时间复杂度降为 O(logN)。
2. **Q: 能否用数学公式直接算？** A: 可以。对于 d 位数，全部由合法数字组成的数有 7^d 个（含前导零），全部由不变数字组成的有 3^d 个，好数 = 7^d - 3^d。但需要用类似数位 DP 的分段统计来处理上界约束。
3. **Q: 如果旋转规则改变（比如增加新的映射），代码需要改哪里？** A: 只需修改合法数字集合和变化数字集合的定义即可，整体框架不变。
4. **Q: 如何优化暴力法的常数？** A: 可以预处理每一位的合法性到查找表中，用数组下标直接查询，避免多重条件判断。
5. **Q: 数位 DP 的记忆化搜索和迭代哪个更好？** A: 记忆化搜索更直观，面试推荐；迭代版本省去递归栈开销，实际工程更优。
