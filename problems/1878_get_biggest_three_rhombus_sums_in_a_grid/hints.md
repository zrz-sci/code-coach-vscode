# 1878. 矩阵中最大的三个菱形和 (Get Biggest Three Rhombus Sums in a Grid)

## 核心思路

**枚举所有菱形 + 维护 Top-3 不同值**。菱形由中心 `(i, j)` 和半径 `d` 唯一确定。三重循环枚举所有可能的菱形，计算每个菱形的边界元素和，用 `set<int>` 自动去重 + 保持排序，维护最大的三个不同值。进阶可用对角线前缀和将单次求和从 O(d) 优化到 O(1)。

## 思维链

1. **读题审题**：
   - 菱形 = 正方形旋转45度，四个角在网格格子中心
   - 菱形和 = 菱形**边界**上元素之和（不含内部）
   - 面积为 0 的菱形（单点）也算
   - 返回最大的三个**不同的**菱形和，降序

2. **菱形的几何定义**：

```
以 (i, j) 为中心, 半径 d 的菱形:

四个顶点:
  上: (i-d, j)
  右: (i, j+d)
  下: (i+d, j)
  左: (i, j-d)

半径 d=0: 退化为单点 (i,j)
半径 d=1 的菱形 (以 * 标记边界):

        *         ← (i-1, j) 上顶点
       / \
      *   *       ← (i, j-1) 和 (i, j+1) 左右顶点
       \ /
        *         ← (i+1, j) 下顶点

半径 d=2 的菱形:

          *               ← (i-2, j)
         / \
        *   *             ← (i-1, j-1) 和 (i-1, j+1)
       /     \
      *       *           ← (i, j-2) 和 (i, j+2)
       \     /
        *   *             ← (i+1, j-1) 和 (i+1, j+1)
         \ /
          *               ← (i+2, j)
```

3. **如何遍历菱形的四条边？**

```
以中心 (i,j), 半径 d 为例, 参数 k 从 0 到 d-1:

上→右边: (i - d + k, j + k)       从上顶点向右下走
右→下边: (i + k,     j + d - k)   从右顶点向左下走
下→左边: (i + d - k, j - k)       从下顶点向左上走
左→上边: (i - k,     j - d + k)   从左顶点向右上走

当 k = 0, 1, ..., d-1 时:
  每条边包含起始顶点, 不含终止顶点
  四条边合计恰好 4d 个点, 无重复

验证 d=1:
  上→右: k=0: (i-1, j)     ← 上顶点
  右→下: k=0: (i, j+1)     ← 右顶点
  下→左: k=0: (i+1, j)     ← 下顶点
  左→上: k=0: (i, j-1)     ← 左顶点
  共 4 个点 = 4*1 ✓
```

4. **边界约束——菱形必须在矩阵内**：

```
中心 (i, j), 半径 d 的菱形需满足:
  i - d >= 0      上顶点不越上边界
  i + d < m       下顶点不越下边界
  j - d >= 0      左顶点不越左边界
  j + d < n       右顶点不越右边界

最大可能半径: d_max = min(i, m-1-i, j, n-1-j)
```

5. **维护 Top-3 不同值**：

```
使用 set<int> (自动去重 + 升序排序):
  每次插入新的菱形和
  如果 set.size() > 3, 删除最小值: set.erase(set.begin())
  最终 set 中最多 3 个元素

为什么用 set 而不是 priority_queue?
  - set 天然去重 (题目要求"不同的"菱形和)
  - priority_queue 不去重, 需要额外处理

输出降序: vector<int>(set.rbegin(), set.rend())
```

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 适用 |
|------|------|------|------|------|
| 暴力枚举 | 三重循环 + 逐点求和 | O(m*n*min(m,n)^2) | O(1) | m,n<=50 直接过 |
| 对角线前缀和 | 预处理后 O(1) 求和 | O(m*n*min(m,n)) | O(m*n) | 更大矩阵 |

## 关键提示

- **提示1**: 半径 d=0 的单点菱形不要漏掉！它也是合法的菱形，和就是 grid[i][j] 本身。
- **提示2**: 四条边的遍历参数 k 从 0 到 d-1，恰好让每条边包含起始顶点不含终止顶点，合计 4d 个点无重复。
- **提示3**: 用 `set<int>` 维护 Top-3。`set` 天然去重+排序。超过 3 个时 `erase(begin())` 删最小。最终 `rbegin→rend` 得到降序。
- **提示4**: 矩阵最大 50x50，暴力 O(m*n*min^2) 最坏 ~1.6M 次操作，完全够用。不需要前缀和优化也能 AC。
- **提示5**: 进阶的对角线前缀和——定义 `d1[i][j]` 为 (i,j) 沿右下对角线的前缀和，`d2[i][j]` 为沿左下对角线的前缀和。菱形四条边恰好对应四段对角线，求和变成 O(1) 减法。但要注意四个顶点被两条边共享，需减去重复。

```
对角线前缀和:
  d1[i][j] = grid[i][j] + d1[i+1][j+1]   (↘ 方向)
  d2[i][j] = grid[i][j] + d2[i+1][j-1]   (↙ 方向)

从 (r,c) 沿 ↘ 走 len 步的和 = d1[r][c] - d1[r+len][c+len]
从 (r,c) 沿 ↙ 走 len 步的和 = d2[r][c] - d2[r+len][c-len]
```

## 解法详解

### 解法1: 暴力枚举（推荐，面试够用）

**算法**：
```
for i = 0..m-1:
  for j = 0..n-1:
    top3.insert(grid[i][j])         ← d=0 单点
    if top3.size > 3: top3.erase(top3.begin())
    
    d_max = min(i, m-1-i, j, n-1-j)
    for d = 1..d_max:
      sum = 0
      for k = 0..d-1:
        sum += grid[i-d+k][j+k]     ← 上→右
        sum += grid[i+k][j+d-k]     ← 右→下
        sum += grid[i+d-k][j-k]     ← 下→左
        sum += grid[i-k][j-d+k]     ← 左→上
      top3.insert(sum)
      if top3.size > 3: top3.erase(top3.begin())

return vector(top3.rbegin(), top3.rend())
```

### 解法2: 对角线前缀和优化

预处理 `d1`, `d2` 两个前缀和数组。菱形四条边的求和变为：
```
sum = sumD1(上顶点, d) + sumD2(右顶点, d) + sumD1(左顶点, d) + sumD2(上顶点, d)
    - grid[上] - grid[右] - grid[下] - grid[左]   ← 四个顶点去重
```

## 完整代码

```cpp
class Solution {
public:
    vector<int> getBiggestThree(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        set<int> top3;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                // 半径 0: 单点菱形
                top3.insert(grid[i][j]);
                if ((int)top3.size() > 3) top3.erase(top3.begin());

                // 半径 1, 2, ...
                int maxD = min({i, m - 1 - i, j, n - 1 - j});
                for (int d = 1; d <= maxD; d++) {
                    int sum = 0;
                    for (int k = 0; k < d; k++) {
                        sum += grid[i - d + k][j + k];       // 上→右
                        sum += grid[i + k][j + d - k];       // 右→下
                        sum += grid[i + d - k][j - k];       // 下→左
                        sum += grid[i - k][j - d + k];       // 左→上
                    }
                    top3.insert(sum);
                    if ((int)top3.size() > 3) top3.erase(top3.begin());
                }
            }
        }
        return vector<int>(top3.rbegin(), top3.rend());
    }
};
```

```python
class Solution:
    def getBiggestThree(self, grid: List[List[int]]) -> List[int]:
        m, n = len(grid), len(grid[0])
        top3 = set()
        
        def add(val):
            top3.add(val)
            if len(top3) > 3:
                top3.remove(min(top3))
        
        for i in range(m):
            for j in range(n):
                add(grid[i][j])  # d=0 单点
                
                max_d = min(i, m - 1 - i, j, n - 1 - j)
                for d in range(1, max_d + 1):
                    s = 0
                    for k in range(d):
                        s += grid[i - d + k][j + k]       # 上→右
                        s += grid[i + k][j + d - k]       # 右→下
                        s += grid[i + d - k][j - k]       # 下→左
                        s += grid[i - k][j - d + k]       # 左→上
                    add(s)
        
        return sorted(top3, reverse=True)
```

## 面试追问

1. **"为什么用 set 而不是堆？"** → set 天然去重。priority_queue 不去重，需额外处理。且只维护 3 个元素，性能差异可忽略。
2. **"暴力够用吗？"** → m, n <= 50，最坏 ~1.6M 操作，远小于 10^8 的经验上限。完全够用。
3. **"前缀和优化能用在什么场景？"** → 矩阵更大（比如 m, n <= 500）时，暴力 ~10^9 会超时，前缀和将内层 O(d) 降为 O(1)。
4. **"四条边遍历时为什么 k < d 而不是 k <= d？"** → k <= d 会让每个顶点被相邻两条边各计算一次（重复）。k < d 让每条边只含起始顶点，不含终止顶点，合计 4d 个点无重复。
5. **"维护 Top-K 的通用方法？"** → 小根堆 `priority_queue<int, vector<int>, greater<>>` 维护 K 个最大值。本题因为要去重，set 更方便。
