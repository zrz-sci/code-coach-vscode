# 1314. 矩阵区域和

## 核心思路

**二维前缀和**的直接应用。对每个位置 `(i, j)`，`answer[i][j]` 是以 `(i, j)` 为中心、半径为 `k` 的矩形区域内所有元素之和。如果暴力对每个位置遍历 `(2k+1) x (2k+1)` 的区域，时间复杂度为 `O(m*n*k^2)`。使用二维前缀和预处理后，每次查询子矩阵和只需 `O(1)`，总时间降为 `O(m*n)`。

## 思维链

1. **读完题第一反应** -- 对每个 `(i,j)`，在以它为中心的矩形区域内求和。暴力做法就是四重循环（两层枚举中心，两层枚举区域内的点），时间 `O(m*n*k^2)`。当 `m=n=k=100` 时约 `10^8`，可能刚好卡时间。

2. **优化的关键** -- 子矩阵求和是经典的二维前缀和问题。和一维前缀和 `prefix[r] - prefix[l-1]` 类似，二维前缀和用容斥原理 O(1) 查询任意矩形区域和。

3. **前缀和公式** -- `pre[i][j]` = 从 `(0,0)` 到 `(i-1, j-1)` 的矩形区域和（注意偏移 1 方便处理边界）。

4. **边界处理** -- `i-k` 可能小于 0，`i+k` 可能大于 `m-1`。用 `max(0, i-k)` 和 `min(m-1, i+k)` 来 clamp 坐标。

5. **这道题本质上就是 LeetCode 304 (二维区域和检索) 的应用版**。

## 二维前缀和原理图解

```
一维前缀和回顾:
  数组: [a, b, c, d, e]
  前缀和: pre[0]=0, pre[1]=a, pre[2]=a+b, pre[3]=a+b+c, ...
  区间和 [l, r]: pre[r+1] - pre[l]

二维前缀和:
  pre[i][j] = mat 中从 (0,0) 到 (i-1,j-1) 的矩形区域和

  构建公式:
  pre[i+1][j+1] = mat[i][j] + pre[i][j+1] + pre[i+1][j] - pre[i][j]

  直观理解 (容斥原理):
  ┌─────────┬───────┐
  │ pre[i][j]│       │    pre[i+1][j+1] = mat[i][j]
  │    A     │   B   │                  + pre[i][j+1]   (A + B)
  ├─────────┼───────┤                  + pre[i+1][j]   (A + C)
  │    C     │mat[i][j]│                - pre[i][j]     (A 被加了两次，减掉一次)
  └─────────┴───────┘

查询公式:
  求 (r1,c1) 到 (r2,c2) 的矩形区域和:
  sum = pre[r2+1][c2+1] - pre[r1][c2+1] - pre[r2+1][c1] + pre[r1][c1]

  直观理解:
  ┌─────┬─────────┬───┐
  │  D  │    E    │   │    sum(r1,c1,r2,c2) = 总矩形 - 上方 - 左方 + 左上
  ├─────┼─────────┤   │    = pre[r2+1][c2+1]  (D+E+F+目标)
  │  F  │ 目标区域 │   │    - pre[r1][c2+1]    (D+E)
  │     │(r1,c1)- │   │    - pre[r2+1][c1]    (D+F)
  │     │(r2,c2)  │   │    + pre[r1][c1]      (D，被减了两次，加回一次)
  └─────┴─────────┴───┘
```

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力 | 对每个位置遍历区域求和 | O(m*n*k^2) | O(m*n) | 能说出即可 |
| 二维前缀和 | 预处理 + O(1) 查询 | O(m*n) | O(m*n) | 必须写出 |

## 关键提示

1. **前缀和数组偏移 1**: `pre` 数组的大小为 `(m+1) x (n+1)`，`pre[0][*]` 和 `pre[*][0]` 全为 0。这样做是为了避免处理 `i-1 < 0` 的边界情况。`pre[i+1][j+1]` 对应 `mat[0..i][0..j]` 的和。

2. **clamp 坐标**: 题目说 `(r,c)` 必须是合法位置，所以需要将坐标裁剪到 `[0, m-1]` 和 `[0, n-1]` 范围内。

3. **容斥公式**: 查询 `(r1,c1)` 到 `(r2,c2)` 的矩形和 = `pre[r2+1][c2+1] - pre[r1][c2+1] - pre[r2+1][c1] + pre[r1][c1]`。四项：总的减去上方减去左方加回左上角（被减了两次）。

4. **本题与 LeetCode 304 的关系**: LC304 要求实现一个 `NumMatrix` 类，支持多次查询矩形区域和。本题就是对每个 `(i,j)` 做一次查询，完全复用 304 的前缀和技术。

5. **空间能否优化?** -- 前缀和数组必须 O(m*n)，因为查询时需要任意位置的前缀和值。结果数组也是 O(m*n)。所以总空间 O(m*n) 是最优的。

## 解法详解

### 解法: 二维前缀和 -- O(m*n) / O(m*n)

**阶段 1: 构建前缀和数组**
```
pre[i+1][j+1] = mat[i][j] + pre[i][j+1] + pre[i+1][j] - pre[i][j]
```

**阶段 2: 对每个 (i,j) 用容斥公式查询**
```
r1 = max(0, i-k), c1 = max(0, j-k)
r2 = min(m-1, i+k), c2 = min(n-1, j+k)
ans[i][j] = pre[r2+1][c2+1] - pre[r1][c2+1] - pre[r2+1][c1] + pre[r1][c1]
```

```cpp
class Solution {
public:
    vector<vector<int>> matrixBlockSum(vector<vector<int>>& mat, int k) {
        int m = mat.size(), n = mat[0].size();
        // 构建二维前缀和，多一行一列（初始为0）避免边界判断
        vector<vector<int>> pre(m + 1, vector<int>(n + 1, 0));
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                pre[i+1][j+1] = mat[i][j] + pre[i][j+1] + pre[i+1][j] - pre[i][j];

        vector<vector<int>> ans(m, vector<int>(n));
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                // clamp 坐标到合法范围
                int r1 = max(0, i - k), c1 = max(0, j - k);
                int r2 = min(m - 1, i + k), c2 = min(n - 1, j + k);
                // 容斥公式查询子矩阵和
                ans[i][j] = pre[r2+1][c2+1] - pre[r1][c2+1] - pre[r2+1][c1] + pre[r1][c1];
            }
        }
        return ans;
    }
};
```

## 易错点

1. **边界 clamp 遗漏**: `i-k` 可能是负数，`i+k` 可能超过 `m-1`。忘记 clamp 会导致数组越界。

2. **前缀和数组索引偏移**: 查询时用的是 `r2+1, c2+1`（因为前缀和数组多了一行一列），容易忘记 `+1` 导致少算一行或一列。

3. **构建前缀和时的容斥**: `pre[i+1][j+1] = mat[i][j] + pre[i][j+1] + pre[i+1][j] - pre[i][j]`，最后一项 `-pre[i][j]` 容易漏掉，导致重复计算左上区域。

4. **查询容斥符号搞错**: 四项公式为 `+总 -上 -左 +左上`。如果符号搞反（比如 `+左上` 写成 `-左上`），结果会全部偏差。

## 面试追问

**Q1: 二维前缀和的查询公式怎么理解？**
-> 容斥原理。`pre[r2+1][c2+1]` 是从 `(0,0)` 到 `(r2,c2)` 的总和，减去上方矩形 `pre[r1][c2+1]` 和左方矩形 `pre[r2+1][c1]`，但左上角 `pre[r1][c1]` 被减了两次，加回来。

**Q2: 如果 k 很大（大于矩阵尺寸），会怎样？**
-> `min/max` clamp 之后，`(r1,c1)` 到 `(r2,c2)` 就是整个矩阵的范围，所有 `answer[i][j]` 都等于整个矩阵的元素总和。示例 2 中 `k=2` 就是这种情况。

**Q3: 能否推广到更高维度？**
-> 可以。三维前缀和用于 3D 空间的子区域求和，容斥公式从 4 项变为 8 项（2^d 项，d 是维度）。

**Q4: 这道题和 LeetCode 304 有什么关系？**
-> LC304 是"实现二维前缀和数据结构"，本题是"使用二维前缀和解决问题"。本题就是对每个 `(i,j)` 调用一次 LC304 的 `sumRegion(r1,c1,r2,c2)`。
