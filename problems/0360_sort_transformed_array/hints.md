# 360. 有序转化数组

## 核心思路

这道题本质上是**利用二次函数的抛物线性质**：对于有序输入，二次函数值的最大值/最小值一定出现在两端或中间（取决于抛物线开口方向），因此可以用双指针从两端向内收拢，直接 O(n) 构建有序结果。

## 思维链

1. **读完题第一反应**：对每个元素算 f(x)，然后排序，O(n log n)，简单直接。
2. **能不能更快？** 题目说了输入是**有序**的，而且 Follow-up 要求 O(n)，说明排序没有充分利用输入的有序性。
3. **二次函数有什么特殊性质？** 回忆高中数学：`f(x) = ax² + bx + c` 是抛物线，对称轴为 `x = -b/(2a)`。
   - **a > 0**：开口向上，两端大、中间小 → 最大值在两端
   - **a < 0**：开口向下，两端小、中间大 → 最小值在两端
   - **a = 0**：退化为线性函数，单调递增或递减
4. **关键洞察**：输入有序，二次函数的"极值分布"决定了结果的**两端是确定的**！
   - a > 0 时，f(nums[0]) 和 f(nums[n-1]) 中较大的一定是全局最大 → 从结果数组**末尾**往前填
   - a < 0 时，f(nums[0]) 和 f(nums[n-1]) 中较小的一定是全局最小 → 从结果数组**开头**往后填
5. **双指针**：左指针指向 nums 开头，右指针指向 nums 末尾，每次比较两端的 f(x) 值，选择该放的那个，然后移动指针。
6. **时间 O(n)**：每个元素只算一次 f(x)，双指针总共移动 n 步。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力计算+排序 | 算所有 f(x)，排序 | O(n log n) | O(n) | 能说出即可 |
| 双指针（抛物线性质）| 利用开口方向，两端向内收拢 | O(n) | O(n) | ⭐ 必须写出 |

## 关键提示

1. **画一条抛物线**：把 nums 的值标在 x 轴上，画出 f(x) 的图像。观察当 a > 0 时，离对称轴越远的点 f(x) 越大；a < 0 则相反。

2. **a > 0 vs a < 0 决定了填充方向**：
   - a > 0：两端的 f(x) 大 → 先确定结果数组的**最大值**（从右往左填）
   - a < 0：两端的 f(x) 小 → 先确定结果数组的**最小值**（从左往右填）

3. **a = 0 是特殊情况**：退化为 f(x) = bx + c，b ≥ 0 时已经有序，b < 0 时反序。但双指针方法天然处理了这种情况（归入 a ≥ 0 或 a < 0 的分支即可）。

4. **双指针的终止条件**：`left <= right`，不要漏掉 `left == right` 的最后一个元素。

5. **可视化示例 (a=1, b=3, c=5, nums=[-4,-2,2,4])**：
   ```
   抛物线 f(x) = x² + 3x + 5，对称轴 x = -1.5
   
   x 轴:   -4    -2    2    4
   f(x):    9     3    15   33
                ↑
            对称轴 x=-1.5
   
   离对称轴远的 f(x) 大：
   左端 f(-4)=9, 右端 f(4)=33
   → 33 最大，放结果末尾，右指针左移
   → 比较 f(-4)=9 vs f(2)=15，15大，放倒数第二...
   
   最终: [3, 9, 15, 33]
   ```

## 解法详解

### 解法1: 暴力计算 + 排序 — O(n log n) / O(n)

**思考过程**: 最直觉的做法——对每个 nums[i] 计算 f(nums[i])，存入新数组，然后排序。

```cpp
class Solution {
public:
    vector<int> sortTransformedArray(vector<int>& nums, int a, int b, int c) {
        int n = nums.size();
        vector<int> result(n);
        for (int i = 0; i < n; i++) {
            int x = nums[i];
            result[i] = a * x * x + b * x + c;
        }
        sort(result.begin(), result.end());
        return result;
    }
};
```

**关键点**: 完全没有利用 nums 已排序的条件。数据量小（n ≤ 200）完全能过，但面试官一定会追问 O(n) 解法。

### 解法2: 双指针（抛物线性质）— O(n) / O(n) ⭐ 面试首选

**从解法1优化**: 解法1的瓶颈是排序的 O(n log n)。利用二次函数的数学性质，输入有序时输出有确定的"两端大/中间小"或"两端小/中间大"的模式，可以用双指针 O(n) 归并。

核心逻辑：
- **a > 0**（开口向上）：两端 f(x) 最大。左右指针比较，**较大的**放到结果数组**末尾**，指针向内移动。
- **a < 0**（开口向下）：两端 f(x) 最小。左右指针比较，**较小的**放到结果数组**开头**，指针向内移动。
- **a = 0**：归入 a ≥ 0 分支即可（线性函数，b ≥ 0 时已有序，双指针自然处理）。

```cpp
class Solution {
public:
    vector<int> sortTransformedArray(vector<int>& nums, int a, int b, int c) {
        int n = nums.size();
        vector<int> result(n);
        int left = 0, right = n - 1;
        // a >= 0: 两端大，从结果末尾开始填
        // a < 0:  两端小，从结果开头开始填
        int idx = (a >= 0) ? n - 1 : 0;
        
        while (left <= right) {
            int fLeft = f(nums[left], a, b, c);
            int fRight = f(nums[right], a, b, c);
            
            if (a >= 0) {
                // 开口向上：取较大的放末尾
                if (fLeft >= fRight) {
                    result[idx--] = fLeft;
                    left++;
                } else {
                    result[idx--] = fRight;
                    right--;
                }
            } else {
                // 开口向下：取较小的放开头
                if (fLeft <= fRight) {
                    result[idx++] = fLeft;
                    left++;
                } else {
                    result[idx++] = fRight;
                    right--;
                }
            }
        }
        return result;
    }
    
private:
    int f(int x, int a, int b, int c) {
        return a * x * x + b * x + c;
    }
};
```

**关键点**:
- `idx` 的初始位置和移动方向由 `a` 的符号决定
- `left <= right` 中的等号不能漏，否则最后一个元素会被跳过
- 每次循环恰好处理一个元素，总共 n 次，O(n)

## 解法对比

| | 解法1: 暴力排序 | 解法2: 双指针 |
|---|---|---|
| 时间 | O(n log n) | O(n) |
| 空间 | O(n)（排序可能需要额外空间） | O(n)（结果数组） |
| 是否利用输入有序 | ✗ | ✓ |
| 是否利用数学性质 | ✗ | ✓（抛物线对称性） |
| 面试场景 | 说完暴力立刻优化 | 最优解 |

**选择建议**: 面试中先说暴力解展示理解，然后讲数学性质推导出双指针，这是面试官期望的思维过程。

## 易错点

1. **`left <= right` 写成 `left < right`**
   - ✗ `while (left < right)` → 当 `left == right` 时退出循环，漏掉一个元素
   - ✓ `while (left <= right)` → 确保所有元素都被处理

2. **a = 0 时的处理**
   - ✗ 单独处理 a = 0（写三个分支：a>0, a<0, a==0）→ 代码冗余且易出错
   - ✓ 将 a = 0 归入 `a >= 0` 分支，双指针逻辑自然正确（线性函数从两端选大的/小的一样 work）

3. **idx 初始值和方向搞反**
   - ✗ a > 0 时 `idx = 0, idx++`（从开头填最大值）→ 结果是降序
   - ✓ a > 0 时 `idx = n-1, idx--`（从末尾填最大值）→ 结果是升序

4. **f(x) 计算溢出**
   - 本题约束 |nums[i]| ≤ 100, |a| ≤ 100 → 最大 100×10000 + 100×100 + 100 = 1,010,100，int 安全
   - 但如果约束更大，需要用 `long long`

## 面试追问

**Q1: 暴力解的复杂度是多少？能优化吗？**
→ O(n log n)，瓶颈在排序。输入已有序没被利用，可以优化到 O(n)。

**Q2: 为什么双指针能保证正确性？**
→ 二次函数 f(x) = ax²+bx+c 在对称轴两侧单调（a>0: 远离对称轴越大；a<0: 远离对称轴越小）。输入有序意味着两端是离对称轴最远的点，所以两端的 f(x) 一定是极值。每次取走一个极值后，新的两端仍然是剩余元素中离对称轴最远的，归纳法可证。

**Q3: 如果不是二次函数，而是任意函数 f(x)，输入有序，如何高效排序输出？**
→ 如果 f 是单调的，直接顺序/逆序输出 O(n)。如果 f 是先降后升（或先升后降，即"V形"/"倒V形"），可以找到转折点后双指针归并 O(n)。如果 f 有多个极值点，需要在每个单调区间分别处理再归并，复杂度取决于极值点个数。
