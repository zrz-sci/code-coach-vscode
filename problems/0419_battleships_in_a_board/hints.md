# 419. 棋盘上的战舰

## 核心思路

本质上是**计数连通区域**，但因为战舰只能水平或垂直放置且互不相邻，所以可以利用这个特殊性质：只数每个战舰的"头部"（左上角的那个 `'X'`），就等于战舰总数。

## 思维链

1. **读完题第一反应**：这不就是"岛屿数量"的变种吗？遍历矩阵，每遇到一个 `'X'` 就 DFS/BFS 把整个战舰标记为已访问，计数 +1。
2. **暴力解可以 work**：DFS/BFS 确实能解，时间 O(m×n)，空间 O(m×n)（递归栈或 visited 数组），而且需要修改 board 或用额外空间。
3. **注意到题目的特殊性质**：战舰只能水平或垂直，且两个战舰之间至少有一个空格。这意味着不会出现 L 形或 T 形，每个 `'X'` 连通块一定是一条直线。
4. **关键洞察**：既然每个战舰是一条线段，那它一定有一个"起点"——最左上角的那个格子。这个格子的特征是：**它的上方和左方都不是 `'X'`**。
5. **一次扫描解法**：遍历每个格子，如果是 `'X'` 且上方不是 `'X'` 且左方不是 `'X'`，就是一个战舰的起点，计数 +1。O(1) 额外空间，不修改 board！

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| DFS/BFS 标记 | 经典岛屿计数，遇到 X 就 flood fill | O(m×n) | O(m×n) | 能说出即可 |
| DFS + 修改原矩阵 | 同上但原地标记，省掉 visited | O(m×n) | O(min(m,n)) 递归栈 | 能说出即可 |
| 数战舰头部 | 只数左上角没有相邻 X 的起点 | O(m×n) | O(1) | ⭐ 必须写出 |

## 关键提示

1. **想想"岛屿数量"怎么做的**：DFS/BFS flood fill 是通用解法，但本题有更简单的方式。

2. **战舰的形状是受限的**：只能是水平或垂直的一条线段，不会有分叉。利用这个性质能大幅简化。

3. **如何避免重复计数同一艘战舰？** 关键观察：每艘战舰只在它的"头部"计数一次。头部 = 最左上角的 `'X'`。

4. **头部的判定条件**：当前格子是 `'X'`，并且上方（如果存在）不是 `'X'`，左方（如果存在）不是 `'X'`。

5. **ASCII 示意图**：
```
矩阵:
  X . . X      战舰1的头部: (0,0) ← 上方无、左方无 ✓
  . . . X      战舰2的头部: (0,3) ← 上方无、左方是'.' ✓
  . . . X      (1,3) 上方是'X' → 不是头部 ✗
               (2,3) 上方是'X' → 不是头部 ✗
  
  所以答案 = 2
```

## 解法详解

### 解法1: DFS Flood Fill — O(m×n) / O(m×n)

**思考过程**：这道题和 LeetCode 200（岛屿数量）几乎一样——遍历矩阵，每遇到一个未访问的 `'X'`，就把整个连通的战舰全部标记为已访问，计数 +1。

```cpp
class Solution {
public:
    int countBattleships(vector<vector<char>>& board) {
        int m = board.size(), n = board[0].size();
        vector<vector<bool>> visited(m, vector<bool>(n, false));
        int count = 0;
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 'X' && !visited[i][j]) {
                    // 找到一艘新战舰的起点，DFS 标记整艘
                    dfs(board, visited, i, j, m, n);
                    count++;
                }
            }
        }
        return count;
    }
    
private:
    void dfs(vector<vector<char>>& board, vector<vector<bool>>& visited,
             int i, int j, int m, int n) {
        if (i < 0 || i >= m || j < 0 || j >= n) return;
        if (board[i][j] != 'X' || visited[i][j]) return;
        
        visited[i][j] = true;
        // 战舰只能水平或垂直，四个方向都探索也没问题
        dfs(board, visited, i + 1, j, m, n);
        dfs(board, visited, i - 1, j, m, n);
        dfs(board, visited, i, j + 1, m, n);
        dfs(board, visited, i, j - 1, m, n);
    }
};
```

**关键点**：
- 这个解法完全正确，但需要 O(m×n) 额外的 visited 数组。
- 也可以直接修改 board（把 `'X'` 改成 `'.'`），省掉 visited 但修改了输入。
- 面试中如果先写这个，面试官一定会追问："能不能不用额外空间？不修改 board？"

### 解法2: 数战舰头部（一次扫描）— O(m×n) / O(1) ⭐ 面试首选

**从解法1优化**：解法1的"问题"不在时间（都是 O(m×n)），而在空间和对 board 的修改。核心优化来自一个观察——

**关键观察**：因为战舰是直线且互不相邻，每艘战舰恰好有一个"头部"，即最左上角的 `'X'`。这个 `'X'` 的特征是**上方和左方都没有 `'X'`**。

```
//  遍历过程:
//  
//  X . . X     (0,0): X, 上=无, 左=无 → 头部! count=1
//  . . . X     (0,3): X, 上=无, 左=. → 头部! count=2
//  . . . X     (1,3): X, 上=X  → 不是头部，跳过
//              (2,3): X, 上=X  → 不是头部，跳过
//  
//  最终 count = 2
```

```cpp
class Solution {
public:
    int countBattleships(vector<vector<char>>& board) {
        int m = board.size(), n = board[0].size();
        int count = 0;
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] != 'X') continue;
                // 如果上方有 'X'，说明当前格属于一艘垂直战舰的中间/尾部
                if (i > 0 && board[i - 1][j] == 'X') continue;
                // 如果左方有 'X'，说明当前格属于一艘水平战舰的中间/尾部
                if (j > 0 && board[i][j - 1] == 'X') continue;
                // 上方和左方都没有 'X' → 这是一艘战舰的头部
                count++;
            }
        }
        return count;
    }
};
```

**为什么这是正确的？**
- 每艘水平战舰：只有最左边的 `'X'` 左方没有 `'X'`，其余都有，所以只计数一次。
- 每艘垂直战舰：只有最上面的 `'X'` 上方没有 `'X'`，其余都有，所以只计数一次。
- 单独一个 `'X'`（1×1 战舰）：上方和左方都没有 `'X'`，计数一次。✓
- 不会多数：题目保证不存在 L 形，所以不会出现一个 `'X'` 既属于水平又属于垂直战舰的情况。

**关键点**：这个解法满足 Follow-up 的所有要求——一次扫描、O(1) 额外空间、不修改 board。

## 解法对比

|  | 解法1: DFS | 解法2: 数头部 |
|--|-----------|-------------|
| 时间 | O(m×n) | O(m×n) |
| 空间 | O(m×n) visited 或修改 board | O(1)，不修改 board |
| 适用性 | 通用（任意形状连通块都能数） | 仅适用于直线形、互不相邻的特殊条件 |
| 代码量 | 较多（DFS 函数） | 极简（单个双重循环） |
| 面试推荐 | 先说这个展示基础功 | 再优化到这个拿高分 |

**什么时候选哪个？**
- 如果题目条件变了（战舰可以是任意形状），只能用 DFS/BFS。
- 如果题目就是这个限制条件（直线 + 不相邻），数头部法是最优解。

## 易错点

1. **忘记检查边界导致越界**：
   - ✗ `board[i-1][j] == 'X'`（i=0 时越界）
   - ✓ `i > 0 && board[i-1][j] == 'X'`

2. **DFS 解法中忘记标记 visited**：
   - ✗ 不标记 → 同一个 `'X'` 被反复访问 → 无限递归或重复计数
   - ✓ 进入 DFS 第一件事就 `visited[i][j] = true`

3. **误以为只检查左方或只检查上方就够了**：
   - ✗ 只检查 `i > 0 && board[i-1][j] == 'X'`（漏掉水平战舰的中间部分）
   - ✓ 必须同时检查上方和左方都不是 `'X'`

4. **混淆"或"和"与"的逻辑**：
   - ✗ `if (上方是X || 左方是X) count++`（逻辑完全反了）
   - ✓ `if (上方是X) continue; if (左方是X) continue; count++`（都不是才计数）

## 面试追问

**Q1（基础理解）**：这道题和"岛屿数量"有什么区别？
> 区别在于战舰只能是直线形状且互不相邻。岛屿数量中岛屿可以是任意形状，必须用 DFS/BFS。但本题的特殊约束允许用更简单的"数头部"方法。

**Q2（优化追问，即 Follow-up）**：能否 O(1) 空间、不修改 board、一次扫描？
> 可以。利用"头部"特征：当前是 `'X'` 且上方和左方都不是 `'X'` 就计数。这不需要任何额外空间，也不修改 board。

**Q3（变体）**：如果战舰可以是任意形状（变成真正的岛屿问题），这个 O(1) 解法还能用吗？
> 不能。"数头部"依赖"直线 + 不相邻"的约束。任意形状的连通块必须用 DFS/BFS 标记已访问节点，空间至少 O(m×n)。（除非允许修改 board 来原地标记。）

**Q4（拓展）**：如果要求输出每艘战舰的坐标范围呢？
> 找到头部后，向右和向下分别探索直到非 `'X'`，就能确定战舰的起止坐标。仍然 O(1) 额外空间（不算输出）。
