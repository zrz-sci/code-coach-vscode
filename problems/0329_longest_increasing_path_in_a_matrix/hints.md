# 329. 矩阵中的最长递增路径

## 核心思路

本质上是在一个 **有向无环图 (DAG)** 上求最长路径。矩阵中每个格子是节点，如果相邻格子的值严格更大，就有一条有向边。因为边只从小值指向大值，所以不可能有环 —— 这是能高效求解的关键。

## 思维链

1. **读完题第一反应**：从每个格子出发 DFS，尝试所有四个方向，只走比当前值大的格子，记录最长路径。对每个格子都跑一次 DFS，取最大值。

2. **暴力 DFS 的瓶颈**：从不同起点出发的 DFS 会大量重复计算同一个格子的最长路径。例如格子 A 和格子 B 的路径都会经过格子 C，那么从 C 出发的最长路径被计算了多次。

3. **怎么消除重复？** 每个格子出发的"最长递增路径长度"是固定的（因为图是 DAG，没有环），所以可以 **记忆化**：算过一次就缓存，下次直接查表。这就是 DFS + Memo。

4. **换个角度思考**：既然这是 DAG，可以用 **拓扑排序** 逐层剥离。把"没有更小邻居"的格子（入度为0，即局部最小值）作为起点入队，BFS 逐层扩展。层数就是最长路径。

5. **为什么拓扑排序也行？** 在 DAG 上，拓扑排序的"层数"等于最长路径。每一层代表路径长度 +1。当所有节点都被处理完，层数就是答案。

6. **两种方法对比**：DFS + Memo 是自顶向下，拓扑排序 BFS 是自底向上，本质都是利用了 DAG 的无环性。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力 DFS（无记忆化） | 每个格子出发 DFS 穷举 | O(m·n·4^(m·n)) 最坏指数级 | O(m·n) 递归栈 | 能说出即可 |
| DFS + 记忆化 | 缓存每个格子的最长路径 | O(m·n) | O(m·n) | ⭐ 必须写出 |
| 拓扑排序 BFS | 从局部最小值逐层扩展 | O(m·n) | O(m·n) | 加分项 |

## 关键提示

- **提示1**：从格子 (i,j) 出发的最长递增路径长度，只取决于它的"比它大的邻居"的结果。这个子问题有最优子结构。

- **提示2**：为什么不需要 visited 数组？因为只走严格递增的方向，不可能走回来形成环。

- **提示3**：记忆化的 memo[i][j] 表示"从 (i,j) 出发的最长递增路径长度"。如果 memo[i][j] > 0，说明已经算过，直接返回。

- **提示4**：拓扑排序思路 — 把矩阵看成图，计算每个格子的"入度"（有多少个更小的邻居指向它）。入度为 0 的是路径起点。

- **提示5 (ASCII 示意图)**：
```
矩阵:          DAG 关系 (箭头从小指向大):
9 9 4           1 → 2 → 6 → 9
6 6 8           1 → 8
2 1 1           4 → 8

从值1出发的最长路径: 1 → 2 → 6 → 9, 长度=4
```

## 解法详解

### 解法1: 暴力 DFS（无记忆化） — O(指数级) / O(m·n)

**思考过程**：最直觉的做法，对每个格子做 DFS，四个方向只走更大的值，返回最长路径长度。

```cpp
class Solution {
public:
    int m, n;
    int dx[4] = {0, 0, 1, -1};
    int dy[4] = {1, -1, 0, 0};
    
    int dfs(vector<vector<int>>& matrix, int i, int j) {
        int maxLen = 1;
        for (int d = 0; d < 4; d++) {
            int ni = i + dx[d], nj = j + dy[d];
            if (ni >= 0 && ni < m && nj >= 0 && nj < n 
                && matrix[ni][nj] > matrix[i][j]) {
                maxLen = max(maxLen, 1 + dfs(matrix, ni, nj));
            }
        }
        return maxLen;
    }
    
    int longestIncreasingPath(vector<vector<int>>& matrix) {
        m = matrix.size(); n = matrix[0].size();
        int ans = 0;
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                ans = max(ans, dfs(matrix, i, j));
        return ans;
    }
};
```

**关键点**：这个解法正确但超时。同一个格子会被不同起点的 DFS 重复访问指数次。注意不需要 visited 数组，因为严格递增保证无环。

---

### 解法2: DFS + 记忆化 — O(m·n) / O(m·n) ⭐ 面试首选

**从解法1优化**：解法1的瓶颈是重复计算。从 (i,j) 出发的最长路径长度是确定的（DAG 无环），用 memo[i][j] 缓存结果，每个格子最多计算一次。

```
// 记忆化过程示意 (matrix = [[9,9,4],[6,6,8],[2,1,1]]):
//
// 第一次从(2,1)=1出发 DFS:
//   dfs(2,1) → 尝试上(1,1)=6 > 1 ✓
//     dfs(1,1) → 尝试上(0,1)=9 > 6 ✓
//       dfs(0,1) → 四周无更大值 → memo[0][1]=1
//     → memo[1][1] = 1 + 1 = 2
//   → 尝试左(2,0)=2 > 1 ✓
//     dfs(2,0) → 尝试上(1,0)=6 > 2 ✓
//       dfs(1,0) → 尝试上(0,0)=9 > 6 ✓
//         dfs(0,0) → memo[0][0]=1 (已算或直接算)
//       → memo[1,0] = 1 + 1 = 2
//     → memo[2][0] = 1 + 2 = 3
//   → memo[2][1] = max(1+2, 1+3) = 4  ← 答案路径!
//
// 之后再从(1,0)出发时, memo[1][0]=2 已缓存, 直接返回
```

```cpp
class Solution {
public:
    int m, n;
    int dx[4] = {0, 0, 1, -1};
    int dy[4] = {1, -1, 0, 0};
    vector<vector<int>> memo;
    
    int dfs(vector<vector<int>>& matrix, int i, int j) {
        if (memo[i][j] != 0) return memo[i][j]; // 已计算过，直接返回
        
        int maxLen = 1; // 至少包含自身，长度为1
        for (int d = 0; d < 4; d++) {
            int ni = i + dx[d], nj = j + dy[d];
            if (ni >= 0 && ni < m && nj >= 0 && nj < n 
                && matrix[ni][nj] > matrix[i][j]) {
                // 只走严格递增方向，无环 → 不需要 visited
                maxLen = max(maxLen, 1 + dfs(matrix, ni, nj));
            }
        }
        memo[i][j] = maxLen; // 缓存结果
        return maxLen;
    }
    
    int longestIncreasingPath(vector<vector<int>>& matrix) {
        m = matrix.size(); n = matrix[0].size();
        memo.assign(m, vector<int>(n, 0)); // 0表示未计算
        
        int ans = 0;
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                ans = max(ans, dfs(matrix, i, j));
        return ans;
    }
};
```

**为什么是 O(m·n)**：每个格子最多计算一次（计算后被缓存），每次计算只看4个邻居，所以总时间 O(4·m·n) = O(m·n)。

**关键点**：memo 初始化为 0，用 0 表示"未计算"。因为计算结果最小是 1（格子本身），所以 0 作为哨兵值是安全的。

### 解法3: 拓扑排序 BFS — O(m·n) / O(m·n)

**换个角度**：把矩阵看成 DAG，边从小值指向大值。计算每个节点的入度（有多少个更小的邻居）。入度为 0 的节点是"路径起点"（局部最小值），从它们开始 BFS 逐层扩展，层数就是最长路径。

```
// 拓扑排序过程 (matrix = [[9,9,4],[6,6,8],[2,1,1]]):
//
// 入度计算 (有几个严格更小的邻居):
//   9:2  9:2  4:0      ← 4的邻居没有比4小的
//   6:1  6:1  8:2
//   2:1  1:0  1:0      ← 两个1都是局部最小值
//
// BFS 层序:
// Level 1: 入度=0 的格子入队 → (0,2)=4, (2,1)=1, (2,2)=1
// Level 2: 减去Level1后入度变0 → (2,0)=2, (1,2)=8  [4→8, 1→2]
// Level 3: → (1,0)=6, (1,1)=6
// Level 4: → (0,0)=9, (0,1)=9
// 总共4层 → 答案=4
```

```cpp
class Solution {
public:
    int longestIncreasingPath(vector<vector<int>>& matrix) {
        int m = matrix.size(), n = matrix[0].size();
        int dx[4] = {0, 0, 1, -1};
        int dy[4] = {1, -1, 0, 0};
        
        // Step 1: 计算每个格子的入度（有多少个严格更小的邻居）
        vector<vector<int>> indegree(m, vector<int>(n, 0));
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                for (int d = 0; d < 4; d++) {
                    int ni = i + dx[d], nj = j + dy[d];
                    if (ni >= 0 && ni < m && nj >= 0 && nj < n
                        && matrix[ni][nj] < matrix[i][j]) {
                        indegree[i][j]++; // 有一个更小的邻居指向我
                    }
                }
            }
        }
        
        // Step 2: 入度为0的格子入队（它们是路径的起点）
        queue<pair<int,int>> q;
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                if (indegree[i][j] == 0)
                    q.push({i, j});
        
        // Step 3: BFS 逐层扩展，层数 = 最长路径长度
        int layers = 0;
        while (!q.empty()) {
            int sz = q.size();
            layers++;
            for (int k = 0; k < sz; k++) {
                auto [i, j] = q.front(); q.pop();
                for (int d = 0; d < 4; d++) {
                    int ni = i + dx[d], nj = j + dy[d];
                    if (ni >= 0 && ni < m && nj >= 0 && nj < n
                        && matrix[ni][nj] > matrix[i][j]) {
                        // 我指向的更大邻居，减少它的入度
                        if (--indegree[ni][nj] == 0) {
                            q.push({ni, nj}); // 入度变0，可以处理了
                        }
                    }
                }
            }
        }
        return layers;
    }
};
```

**为什么层数 = 最长路径？** 拓扑排序中，第 k 层的节点意味着它前面至少有 k-1 层节点。最后一层被处理时，layers 就是 DAG 的"最长链"。

## 解法对比

| | 暴力 DFS | DFS + 记忆化 | 拓扑排序 BFS |
|---|---|---|---|
| 时间 | 指数级 | O(m·n) | O(m·n) |
| 空间 | O(m·n) 递归栈 | O(m·n) memo + 栈 | O(m·n) indegree + 队列 |
| 思维方式 | 自顶向下穷举 | 自顶向下 + 缓存 | 自底向上层序 |
| 递归栈风险 | 有（200×200可能溢出） | 有 | 无（迭代） |
| 面试推荐 | 说思路即可 | ⭐ 首选 | 加分项 |

**什么时候选哪个？**
- 面试首选 DFS + 记忆化：代码短、思路直觉、容易从暴力优化而来。
- 如果面试官追问"能否避免递归栈溢出"，给出拓扑排序 BFS 方案。

## 易错点

- **✗ memo 初始化为 -1，判断 `memo[i][j] != -1`**
  → ✓ 初始化为 0 即可，因为合法结果最小为 1。用 0 当哨兵更简洁。两种都对，但 0 更自然。

- **✗ 加了 visited 数组防止重复访问**
  → ✓ 不需要 visited！严格递增条件天然保证无环。加 visited 反而会导致从不同入口访问同一格子时得到错误结果。

- **✗ 拓扑排序中入度计算方向搞反**：`matrix[ni][nj] < matrix[i][j]` 时给 (i,j) 加入度，不是给 (ni,nj) 加。入度 = "有多少更小的邻居指向我"。

- **✗ DFS 返回值忘记 +1**：`maxLen = max(maxLen, dfs(ni, nj))` 少了 `1 +`。自身要算 1 步。

- **✗ 认为 memo 数组需要重置**：每个格子的最长路径是全局确定的，不会因起点不同而变化（DAG 性质），所以 memo 全局共享，不需要重置。

## 面试追问

**Q1: 暴力 DFS 为什么不需要 visited？这和普通图遍历有什么区别？**
→ 普通图可能有环，不标记 visited 会死循环。但这里只走严格递增方向，值不可能回到原点，所以天然无环。本质上这个图是 DAG。

**Q2: 记忆化搜索的正确性为什么能保证？会不会出现"从 A 出发经过 B 的最长路径"和"从 C 出发经过 B 的最长路径"不一样的情况？**
→ 不会。memo[i][j] 代表"从 (i,j) 出发的最长递增路径长度"，这个值只取决于 (i,j) 本身和它后续的格子，与谁先到达 (i,j) 无关。这正是 DAG 上 DP 的子问题独立性。

**Q3: 如果矩阵非常大 (如 1000×1000)，递归深度可能达到 10^6，有栈溢出风险。怎么办？**
→ 用拓扑排序 BFS（解法3），完全迭代，无递归栈风险。或者将 DFS 改为显式栈的迭代版本。

**Q4: 如果要输出最长路径本身（而不只是长度），怎么改？**
→ 在 memo 基础上额外记录"从 (i,j) 出发的下一步是哪个格子"，即 next[i][j]。DFS 时更新 maxLen 的同时记录对应的邻居。最后从全局最优起点沿 next 链输出路径。
