# 829. 连续整数求和

## 核心思路

本质上是一道数学题：把 `n` 表示为从某个正整数 `a` 开始的 `k` 个连续整数之和，即 `n = a + (a+1) + ... + (a+k-1)`，问有多少种合法的 `(a, k)` 组合。利用等差数列求和公式，将问题转化为对 `k` 的枚举和整除性判断。

## 思维链

1. **读完题第一反应**：连续正整数求和等于 `n`，最暴力的做法是枚举起点 `a` 和终点，逐个求和判断。但 `n` 最大 10⁹，双重循环肯定超时。

2. **用数学简化**：连续 `k` 个从 `a` 开始的整数之和 = `k*a + k*(k-1)/2 = n`。只要固定 `k`，就可以解出 `a = (n - k*(k-1)/2) / k`，不需要枚举 `a`！

3. **瓶颈转移**：现在只需要枚举 `k`（连续几个数），对每个 `k` 检查 `a` 是否为正整数。关键问题变成：`k` 的范围是多少？

4. **确定 `k` 的上界**：要求 `a ≥ 1`，即 `n - k*(k-1)/2 ≥ k`，化简得 `k*(k+1)/2 ≤ n`，所以 `k ≤ O(√n)`。这样枚举量只有 √n 级别！

5. **整除性判断**：对每个 `k`，检查 `(n - k*(k-1)/2)` 能否被 `k` 整除且商为正数，是就计数 +1。

6. **数论角度（进阶）**：也可以从奇因子分解的角度理解——答案等于 `n` 的奇因子个数。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力枚举起点 | 枚举起点 a，累加直到 ≥n | O(n) | O(1) | 能说出即可 |
| 枚举连续个数 k | 等差数列公式，枚举 k 检查 a 是否正整数 | O(√n) | O(1) | ⭐ 必须写出 |
| 奇因子计数 | n 的奇因子个数即为答案 | O(√n) | O(1) | 加分项 |

## 关键提示

1. **等差数列求和公式**：连续 k 个从 a 开始的整数之和 = `k*a + k*(k-1)/2`。固定 k 后，a 可以直接算出来。

2. **k 的上界不是 n**：从 `a ≥ 1` 出发推导，`k*(k+1)/2 ≤ n`，所以 `k` 最多约 `√(2n)`。这是从 O(n) 到 O(√n) 的关键。

3. **两个条件缺一不可**：`(n - k*(k-1)/2)` 必须能被 `k` 整除（a 是整数），且商必须 > 0（a 是正整数）。

4. **数论进阶**：`n = k*a + k*(k-1)/2 = k*(2a+k-1)/2`。令 `m = 2a+k-1`，则 `2n = k*m`，且 `k` 和 `m` 一奇一偶、`m > k`。这等价于找 `n` 的奇因子。

5. **别忘记 k=1**：`n` 本身就是一组（只有它自己），这也算一种方案。

## 解法详解

### 解法1: 暴力枚举起点 — O(n) / O(1)

**思考过程**: 最朴素的想法——枚举连续序列的起点 `a`，从 `a` 开始往后累加，如果恰好等于 `n` 就计数。但 n 最大 10⁹，这个方法会超时（实际约 O(√n) 到 O(n) 之间）。

```cpp
class Solution {
public:
    int consecutiveNumbersSum(int n) {
        int count = 0;
        // 枚举起点 a，从 1 开始
        // a 的上界：至少两个数 a+(a+1) ≤ n → a ≤ (n-1)/2
        // 但 a=n 也算（单独一个数），所以特殊处理或统一循环
        for (int a = 1; a <= n; a++) {
            int sum = 0;
            for (int j = a; sum < n; j++) {
                sum += j;
            }
            if (sum == n) count++;
        }
        return count;
    }
};
```

**关键点**: 这个解法 n=10⁹ 时必然超时，但帮助理解题意。实际上内层循环平均很短，整体大约 O(n) 级别。

---

### 解法2: 枚举连续个数 k — O(√n) / O(1) ⭐ 面试首选

**从解法1优化**: 解法1枚举起点 `a`，对每个起点要累加求和。换个角度——枚举连续个数 `k`，用等差数列公式直接算出起点 `a`，一步到位。

**数学推导**:
```
连续 k 个从 a 开始的正整数之和:
  S = a + (a+1) + ... + (a+k-1) = k*a + k*(k-1)/2

令 S = n:
  k*a + k*(k-1)/2 = n
  k*a = n - k*(k-1)/2
  a = (n - k*(k-1)/2) / k

要求: a 是正整数
  ① n - k*(k-1)/2 > 0  →  k*(k-1)/2 < n  →  k < √(2n)
  ② (n - k*(k-1)/2) % k == 0
```

```
// 示例 n=15 的枚举过程:
// k=1: remain = 15-0 = 15,  15%1==0, a=15  → [15]         ✓
// k=2: remain = 15-1 = 14,  14%2==0, a=7   → [7,8]        ✓
// k=3: remain = 15-3 = 12,  12%3==0, a=4   → [4,5,6]      ✓
// k=4: remain = 15-6 = 9,   9%4!=0                         ✗
// k=5: remain = 15-10 = 5,  5%5==0, a=1    → [1,2,3,4,5]  ✓
// k=6: remain = 15-15 = 0,  a=0 不是正整数                  ✗ (停止)
// 答案: 4
```

```cpp
class Solution {
public:
    int consecutiveNumbersSum(int n) {
        int count = 0;
        // 枚举连续个数 k，从 1 开始
        // 上界: k*(k-1)/2 < n，即 k*(k+1)/2 <= n 时 a >= 1
        for (int k = 1; (long long)k * (k - 1) / 2 < n; k++) {
            int remain = n - k * (k - 1) / 2;
            // a 必须是正整数：remain > 0 且能被 k 整除
            if (remain % k == 0) {
                count++;
            }
        }
        return count;
    }
};
```

**关键点**: 
- 循环条件 `k*(k-1)/2 < n` 保证 `remain > 0`（即 `a ≥ 1`）
- 注意 `k*(k-1)` 可能溢出 int（当 n 接近 10⁹ 时 k 约 45000，不会溢出，但用 long long 更安全）

---

### 解法3: 奇因子计数 — O(√n) / O(1)

**数论视角**: 将等差数列公式进一步变形：

```
2n = k * (2a + k - 1)

令 m = 2a + k - 1，则 2n = k * m

注意:
- k ≥ 1, m ≥ k（因为 a ≥ 1 → m = 2a+k-1 ≥ k+1 > k）
- k 和 m 奇偶性相反（因为 m-k = 2a-1 是奇数）

所以问题转化为: 把 2n 分解为两个因子 k * m，使得
  ① k < m
  ② k 和 m 一奇一偶

这等价于: n 的每个奇因子都对应一种分解方式
```

**为什么等于奇因子个数**:
- 去掉 n 中所有因子 2，得到 n 的奇数部分 `odd_part`
- `odd_part` 的因子个数就是答案
- 原因：每个奇因子 d，要么作为 k（d 是奇数），要么作为 m（2n/d 中配对），都能构造出一组合法的连续整数

```cpp
class Solution {
public:
    int consecutiveNumbersSum(int n) {
        // 去掉 n 的所有因子 2
        while (n % 2 == 0) {
            n /= 2;
        }
        // 现在 n 是奇数，计算 n 的因子个数
        int count = 1; // 1 和 n 自身都是因子
        for (int d = 3; (long long)d * d <= n; d += 2) {
            int exp = 0;
            while (n % d == 0) {
                n /= d;
                exp++;
            }
            count *= (exp + 1); // 因子个数公式
        }
        if (n > 1) {
            count *= 2; // 剩下的 n 本身是一个奇素数因子，指数为1
        }
        return count;
    }
};
```

**关键点**: 
- 这实际上是在做质因数分解，利用因子个数公式 `(e1+1)*(e2+1)*...`
- 先去掉所有 2 的因子，只对奇数部分做分解
- 最后如果 n > 1，说明还剩一个大于 √n 的素因子

## 解法对比

| | 解法1: 暴力 | 解法2: 枚举 k | 解法3: 奇因子 |
|---|---|---|---|
| **时间** | O(n) | O(√n) | O(√n) |
| **核心操作** | 累加求和 | 整除判断 | 质因数分解 |
| **直觉性** | 最直觉 | 中等（需要等差公式） | 需要数论知识 |
| **面试推荐** | ✗ 超时 | ✓ 首选 | ✓ 加分项 |

解法2 和解法3 时间复杂度相同，但解法3 的常数更小（只遍历奇数）。面试中解法2 是最合理的推导路径，解法3 如果能说清数论原理会是加分项。

## 易错点

1. **k 的循环上界写错**:
   - ✗ `for (int k = 1; k <= n; k++)` — 循环 n 次，退化为 O(n)
   - ✓ `for (int k = 1; k*(k-1)/2 < n; k++)` — 只循环 O(√n) 次

2. **忘记 k=1 的情况**:
   - k=1 时 `remain = n`，`n % 1 == 0`，所以 `n` 本身单独算一组。确保循环从 k=1 开始。

3. **整数溢出**:
   - ✗ `k * (k - 1) / 2` 在 k 较大时可能溢出 int
   - ✓ 使用 `(long long)k * (k - 1) / 2 < n` 或提前判断

4. **解法3 中最后忘记处理大素数**:
   - ✗ 分解完循环后直接返回 `count`
   - ✓ 如果剩余 `n > 1`，说明还有一个大素因子，`count *= 2`

## 面试追问

**Q1: 暴力做法的复杂度是多少？能通过吗？**
枚举起点 a 从 1 到 n，对每个起点累加。最坏 O(n)，n=10⁹ 时约 10⁹ 次操作，会超时。需要 O(√n) 的做法。

**Q2: 如何从 O(n) 优化到 O(√n)？核心数学推导是什么？**
利用等差数列求和公式 `n = k*a + k*(k-1)/2`，固定 k 可以直接解出 a。由 a ≥ 1 推出 `k*(k-1)/2 < n`，即 k = O(√n)，只需枚举 k 再做一次整除判断。

**Q3: 你能从数论角度解释吗？答案和 n 的什么性质有关？**
答案等于 n 的奇因子个数。核心推导：`2n = k * m`，其中 k 和 m 一奇一偶，这等价于把 n 的奇数部分分解因子。利用 `n = 2^a * p1^e1 * p2^e2 * ...`，答案 = `(e1+1)*(e2+1)*...`（只取奇素因子的指数）。

**Q4: 如果改成"连续非负整数"（即起点可以是 0），怎么修改？**
只需将 `a ≥ 1` 的约束改为 `a ≥ 0`，即 `remain ≥ 0` 且 `remain % k == 0`。循环上界变为 `k*(k-1)/2 ≤ n`（允许等号）。
