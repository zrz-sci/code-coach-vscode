# 1653. 使字符串平衡的最少删除次数

## 核心思路

平衡字符串的形态是 `aaa...bbb...`（所有 `a` 在左，所有 `b` 在右），本质上是在字符串中找一个"分割点"，分割点左边删掉所有 `b`，右边删掉所有 `a`，使总删除次数最少。

## 思维链

1. **读完题第一反应**：平衡 = 不存在 `b` 在 `a` 左边的情况 → 最终结果一定是 `aaa...bbb...` 的形式（可以全是 `a`、全是 `b`、或空串）。
2. **最朴素的想法**：枚举每个位置作为分割点（左边全 `a`，右边全 `b`），计算要删多少个字符。需要知道"前缀中 `b` 的个数"和"后缀中 `a` 的个数"。
3. **暴力枚举分割点**：对每个位置 `i`，扫一遍左边数 `b`，扫一遍右边数 `a` → O(n²)，太慢。
4. **瓶颈突破**：用前缀和！预处理 `countB[i]` = 前 i 个字符中 `b` 的个数，`countA_suffix[i]` = 位置 i 及之后 `a` 的个数，然后 O(1) 查询每个分割点的代价。
5. **进一步优化**：其实不需要两个数组，可以一边遍历一边维护 `b` 的计数，遇到 `a` 时做决策 → 这就是 DP / 贪心的思路。
6. **栈的视角**：维护一个栈，遇到 `b` 入栈，遇到 `a` 时如果栈顶是 `b`（形成逆序对），弹出 `b` 并计数删除一次 → 用栈消除逆序对。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 枚举分割点 + 前缀和 | 每个位置切一刀，左删b右删a | O(n) | O(n) | 能说出即可 |
| DP（滚动变量） | dp[i] = 处理完前i个字符的最小删除数 | O(n) | O(1) | ⭐ 必须写出 |
| 栈消除逆序对 | 遇到 ba 逆序就消除 | O(n) | O(n) | 加分项 |

## 关键提示

1. **什么是"平衡"？** 最终形态一定是 `aaa...bbb...`，意味着存在一个分界线，左边全 `a`，右边全 `b`。分界线可以在最左边（全是 `b`）或最右边（全是 `a`）。

2. **分割点思维**：想象在每个位置 `i` 放一道"墙"，墙左边的 `b` 都要删，墙右边的 `a` 都要删。总代价 = `左边b的个数 + 右边a的个数`，取所有位置的最小值。

3. **DP 转移关键**：遍历到字符 `s[i]` 时：
   - 如果是 `'b'`：不影响已有平衡，dp 不变（`b` 放在末尾是合法的）
   - 如果是 `'a'`：要么删掉这个 `a`（代价+1），要么保留它但删掉前面的一个 `b`

4. **栈的直觉**：`ba` 是唯一违规的模式。用栈维护，遇到 `a` 时如果前面有 `b`（栈顶），消掉这对逆序 — 类似括号匹配的思路。

5. **注意分割点有 n+1 个位置**（包括最左和最右），不要漏掉"全删 `b`"或"全删 `a`"的情况。

## 解法详解

### 解法1: 枚举分割点 + 前缀和 — O(n) / O(n)

**思考过程**：最终字符串形如 `aaa...bbb...`，那我在每个位置画一条竖线，左边应该全是 `a`（有 `b` 就删），右边应该全是 `b`（有 `a` 就删）。预处理前缀 `b` 计数和后缀 `a` 计数即可。

```
示例: s = "aababbab"
位置:    0 1 2 3 4 5 6 7

前缀b数: 0 0 1 1 2 2 3 3   (prefixB[i] = s[0..i-1]中b的个数)
后缀a数: 3 2 2 2 1 1 1 0   (suffixA[i] = s[i..n-1]中a的个数)

分割点 0: 删0个b + 删3个a = 3
分割点 1: 删0个b + 删2个a = 2
分割点 2: 删0个b + 删2个a = 2
分割点 3: 删1个b + 删2个a = 3
分割点 4: 删1个b + 删1个a = 2  ← 最小
分割点 5: 删2个b + 删1个a = 3
分割点 6: 删2个b + 删1个a = 3
分割点 7: 删3个b + 删0个a = 3
分割点 8: 删3个b + 删0个a = 3

答案: min = 2
```

```cpp
class Solution {
public:
    int minimumDeletions(string s) {
        int n = s.size();
        // suffixA[i] = s[i..n-1] 中 'a' 的个数
        vector<int> suffixA(n + 1, 0);
        for (int i = n - 1; i >= 0; i--) {
            suffixA[i] = suffixA[i + 1] + (s[i] == 'a' ? 1 : 0);
        }
        
        int ans = n; // 最坏情况全删
        int prefixB = 0; // 前缀中 'b' 的个数
        for (int i = 0; i <= n; i++) {
            // 在位置 i 切一刀: 左边删 b，右边删 a
            ans = min(ans, prefixB + suffixA[i]);
            if (i < n && s[i] == 'b') prefixB++;
        }
        return ans;
    }
};
```

**关键点**：分割点有 `n+1` 个（0 到 n），代表"所有字符都在右边"到"所有字符都在左边"。

### 解法2: DP（滚动变量优化）— O(n) / O(1) ⭐ 面试首选

**从解法1优化**：解法1需要 O(n) 的后缀数组，但其实可以一边遍历一边决策。

**DP 状态定义**：`dp[i]` = 使 `s[0..i]` 成为平衡字符串的最少删除次数。

**转移方程**：
- 如果 `s[i] == 'b'`：`b` 放在末尾不会破坏平衡 → `dp[i] = dp[i-1]`
- 如果 `s[i] == 'a'`：两个选择取较小值
  - **删掉这个 `a`**：`dp[i-1] + 1`
  - **保留这个 `a`，但前面所有的 `b` 都得删**：不对，这太贵了。实际上保留 `a` 意味着"删掉前面某个 `b`"就够了 → `dp[i-1] - 1 + 1`？也不对。
  
让我重新理清：`dp[i] = dp[i-1] + 1`（删掉 `a`）或 `countB`（删掉到目前为止的所有 `b`）中的较小值... 换个思路。

**更清晰的定义**：`dp` = 到当前位置为止使字符串平衡的最小删除数，`countB` = 到当前位置已经遇到的 `b` 的个数。

```
遍历 s = "aababbab":

i=0, s[i]='a': 遇到a, countB=0, dp = min(dp+1, countB) = min(1, 0) = 0
i=1, s[i]='a': 遇到a, countB=0, dp = min(dp+1, countB) = min(1, 0) = 0  
i=2, s[i]='b': 遇到b, countB=1, dp不变 = 0
i=3, s[i]='a': 遇到a, countB=1, dp = min(0+1, 1) = 1
i=4, s[i]='b': 遇到b, countB=2, dp不变 = 1
i=5, s[i]='b': 遇到b, countB=3, dp不变 = 1
i=6, s[i]='a': 遇到a, countB=3, dp = min(1+1, 3) = 2
i=7, s[i]='b': 遇到b, countB=4, dp不变 = 2

答案: dp = 2 ✓
```

```cpp
class Solution {
public:
    int minimumDeletions(string s) {
        int dp = 0;      // 到当前位置的最小删除次数
        int countB = 0;   // 到当前位置遇到的 'b' 的个数
        
        for (char c : s) {
            if (c == 'b') {
                // b 放在当前末尾不破坏平衡，dp 不变
                countB++;
            } else {
                // c == 'a'，两个选择:
                // 1) 删掉这个 a: dp + 1
                // 2) 保留这个 a，但要删掉前面所有 b: countB
                //    (不是真的全删，而是 dp 重新从 countB 开始计算)
                dp = min(dp + 1, countB);
            }
        }
        return dp;
    }
};
```

**为什么 `min(dp+1, countB)` 是对的？**
- `dp+1`：沿用之前的最优方案，额外删掉这个 `a`
- `countB`：换一种策略——不删任何 `a`（包括当前这个），而是把前面所有的 `b` 都删掉。前面一共 `countB` 个 `b`，删掉后所有字符都是 `a`，一定平衡

**关键点**：`dp` 只用一个变量就够了，因为 `dp[i]` 只依赖 `dp[i-1]`。

### 解法3: 栈消除逆序对 — O(n) / O(n)

**思路来源**：不平衡的根源是 `ba` 逆序对（`b` 在 `a` 前面）。用栈来检测和消除这种逆序。

**类比括号匹配**：把 `b` 看作左括号，`a` 看作右括号。`b` 后面跟 `a` 就是一对"需要消除的逆序"。

```
栈模拟 s = "aababbab":

i=0, 'a': 栈空，不管，栈: []
i=1, 'a': 栈空，不管，栈: []
i=2, 'b': 入栈，栈: [b]
i=3, 'a': 栈顶是b! 弹出b，删除+1。栈: []    删除数=1
i=4, 'b': 入栈，栈: [b]
i=5, 'b': 入栈，栈: [b, b]
i=6, 'a': 栈顶是b! 弹出b，删除+1。栈: [b]   删除数=2
i=7, 'b': 入栈，栈: [b, b]

答案: 2 ✓
```

```cpp
class Solution {
public:
    int minimumDeletions(string s) {
        int deletions = 0;
        int bCount = 0; // 用计数代替真实的栈（因为栈里只有 'b'）
        
        for (char c : s) {
            if (c == 'b') {
                bCount++; // 相当于入栈
            } else {
                // c == 'a'
                if (bCount > 0) {
                    // 栈顶有 b，形成 ba 逆序对，消除它
                    bCount--; // 弹出一个 b（删掉这个 b）
                    deletions++;
                }
                // 如果栈空（前面没有 b），这个 a 不造成问题
            }
        }
        return deletions;
    }
};
```

**关键点**：栈里只存 `b`，所以用一个计数器 `bCount` 就够了，不需要真的用 `stack`。

**为什么消除逆序对是对的？** 每个 `ba` 逆序对至少要删一个字符（`b` 或 `a`）。贪心地选择"遇到就消"，每次消除恰好花费 1 次删除，不会有多余的操作。

## 解法对比

| | 枚举分割点 | DP（滚动变量） | 栈消除逆序对 |
|---|---|---|---|
| 时间 | O(n) | O(n) | O(n) |
| 空间 | O(n) | **O(1)** | O(n) 最坏 / O(1) 用计数器 |
| 思维模型 | 几何切割 | 逐步决策 | 匹配消除 |
| 面试推荐 | ✓ 容易讲清楚 | ⭐ **最推荐** | ✓ 展示多角度思维 |

- **枚举分割点**：最直观，容易向面试官解释"为什么是对的"
- **DP**：代码最简洁，空间最优，面试首选
- **栈**：体现了"把问题转化为匹配消除"的思维，是加分项

## 易错点

1. **DP 遇到 `b` 时忘记 `countB++`**
   - ✗ `if (c == 'b') { /* 什么都不做 */ }`
   - ✓ `if (c == 'b') { countB++; }` — `countB` 要持续更新，它代表"如果选择删所有 b 需要多少次"

2. **分割点只枚举了 `n` 个而不是 `n+1` 个**
   - ✗ `for (int i = 0; i < n; i++)` — 漏掉了"所有字符都在左边"的情况
   - ✓ `for (int i = 0; i <= n; i++)` — 分割点从 0（全在右）到 n（全在左）

3. **DP 转移搞反了 `a` 和 `b`**
   - 遇到 `b` 时 dp 不变（b 放末尾合法），遇到 `a` 时才需要决策
   - 如果搞反，遇到 `a` 不处理，结果就错了

4. **栈解法中忘记判断 `bCount > 0`**
   - ✗ 遇到 `a` 直接 `bCount--; deletions++;` — 当 `bCount == 0` 时会减成负数
   - ✓ 先检查 `if (bCount > 0)` 再操作

## 面试追问

**Q1: 暴力解的复杂度是多少？能不能用？**
> 暴力枚举每个字符删或不删，2^n 种可能，O(2^n) 完全不可行。但枚举分割点只有 n+1 个位置，配合前缀和是 O(n)，这是一个好的起点。

**Q2: DP 中 `min(dp+1, countB)` 的两个选项分别代表什么？**
> `dp+1`：延续之前的最优策略，把当前 `a` 删掉。`countB`：换一种策略，保留所有 `a`（包括当前的），但把前面遇到的所有 `b` 都删掉。两者取最小值。

**Q3: 如果字符不只是 `a` 和 `b`，而是要求字符串变成非递减序列（如 `a ≤ b ≤ c ≤ ...`），怎么推广？**
> 这变成了"最长非递减子序列"问题的补问题。答案 = `n - LIS的长度`（这里 LIS 改为最长非递减子序列）。对于只有 `a` 和 `b` 两种字符的特殊情况，分割点枚举和 DP 是更高效的特化解法。

**Q4: 能否不修改字符串，只返回删除后的平衡字符串本身？**
> 可以。在 DP 过程中记录每一步的选择（删 `a` 还是删 `b`），最后回溯构造结果。或者用分割点方法，找到最优分割点后，输出左边的 `a` 和右边的 `b`。
