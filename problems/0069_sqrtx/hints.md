# 69. x 的平方根

## 核心思路

本质上在问：**找到最大的整数 `k`，使得 `k * k <= x`**。这是一个在有序搜索空间 `[0, x]` 上找满足条件的最大值的问题 —— 天然适合二分查找。

## 思维链

1. **读完题第一反应**：从 0 开始一个个试，`0*0`, `1*1`, `2*2`...直到 `k*k > x`，返回 `k-1`。这就是线性扫描，O(√x)。

2. **暴力解的瓶颈**：虽然 O(√x) 已经不慢了，但我们在一个有序序列 `[0, 1, 2, ..., x]` 上找目标值，这个序列的平方值是单调递增的。遇到"有序 + 查找"，应该条件反射想到 **二分查找**。

3. **二分怎么用？** 搜索空间是 `[0, x]`，对于每个 `mid`，判断 `mid * mid` 和 `x` 的关系：
   - `mid * mid <= x`：`mid` 可能是答案，但更大的值也可能，所以往右找 → `left = mid + 1`
   - `mid * mid > x`：`mid` 太大了 → `right = mid - 1`

4. **最终答案是什么？** 循环结束时 `right` 就是满足 `k*k <= x` 的最大 `k`。

5. **还有别的方法吗？** 牛顿迭代法，数学上求 `f(k) = k² - x = 0` 的根，收敛速度更快（O(log x) 但常数更小）。这是面试加分项。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 线性扫描 | 从0逐个试到k²>x | O(√x) | O(1) | 能说出即可 |
| 二分查找 | 在[0,x]上二分找最大的k²≤x | O(log x) | O(1) | ⭐ 必须写出 |
| 牛顿迭代 | 数学迭代逼近√x | O(log x) | O(1) | 加分项 |

## 关键提示

1. **搜索空间**：答案一定在 `[0, x]` 范围内（实际上在 `[0, min(x, 46340)]`，因为 46340² < 2³¹-1 < 46341²）

2. **溢出陷阱**：`mid * mid` 当 `mid` 较大时会溢出 int。用 `long long` 或者改成 `mid <= x / mid`（但要小心 `mid = 0` 除零）

3. **二分找的是"最后一个满足条件的"**：这是一个经典的二分模板 —— 找右边界。循环结束时答案在 `right`

4. **牛顿法的直觉**：从一个初始猜测出发，每次用切线与x轴的交点作为新的猜测，迭代收敛到答案

```
// 二分搜索空间收缩过程 (x = 8):
// Round1: [0, 8]  mid=4, 4*4=16 > 8  → right=3
//                  ↑
// Round2: [0, 3]  mid=1, 1*1=1  ≤ 8  → left=2
//                  ↑
// Round3: [2, 3]  mid=2, 2*2=4  ≤ 8  → left=3
//                  ↑
// Round4: [3, 3]  mid=3, 3*3=9  > 8  → right=2
//                  ↑
// left=3 > right=2 → 退出循环，返回 right=2 ✓
```

## 解法详解

### 解法1: 线性扫描 — O(√x) / O(1)

**思考过程**: 最直觉的方法，从小到大逐个检查。当 `k*k` 刚好超过 `x` 时，答案就是 `k-1`。

```cpp
class Solution {
public:
    int mySqrt(int x) {
        // 特殊情况：0的平方根是0
        if (x == 0) return 0;
        
        // 用 long long 避免 k*k 溢出
        long long k = 1;
        while (k * k <= x) {
            k++;
        }
        // 循环退出时 k*k > x，所以答案是 k-1
        return (int)(k - 1);
    }
};
```

**关键点**: 循环条件是 `k*k <= x` 而不是 `k*k < x`，否则完全平方数（如 x=4）会多减一个。

---

### 解法2: 二分查找 — O(log x) / O(1) ⭐ 面试首选

**从解法1优化**: 解法1在 `[0, √x]` 上线性扫描，但这个搜索空间是有序的（k 越大，k² 越大），可以用二分将 O(√x) 优化到 O(log x)。

**核心问题转化**: 在 `[0, x]` 中找最大的 `k`，使得 `k² ≤ x`。

```cpp
class Solution {
public:
    int mySqrt(int x) {
        // 搜索空间：[0, x]
        int left = 0, right = x;
        
        while (left <= right) {
            int mid = left + (right - left) / 2;
            
            // 用 long long 防止 mid*mid 溢出
            long long square = (long long)mid * mid;
            
            if (square <= x) {
                // mid² ≤ x：mid可能是答案，但更大的值也可能满足
                // 记录候选，继续往右找
                left = mid + 1;
            } else {
                // mid² > x：mid太大，往左找
                right = mid - 1;
            }
        }
        
        // 循环结束时 left = right + 1
        // right 是最后一个满足 mid² ≤ x 的值
        return right;
    }
};
```

**为什么答案是 `right`？**
- 每次 `square <= x` 时，`left = mid + 1` 把 left 推到 mid 右边
- 每次 `square > x` 时，`right = mid - 1` 把 right 拉到 mid 左边
- 循环结束时 `left > right`，`right` 停在最后一个满足 `k² ≤ x` 的位置

**关键点**: 这道题是二分查找中"找满足条件的最大值（右边界）"的经典模板。

---

### 解法3: 牛顿迭代法 — O(log x) / O(1)

**另一个角度**: 求 √x 等价于求方程 `f(k) = k² - x = 0` 的正根。牛顿法用切线逼近：

$$k_{n+1} = k_n - \frac{f(k_n)}{f'(k_n)} = k_n - \frac{k_n^2 - x}{2k_n} = \frac{k_n + x/k_n}{2}$$

```
// 牛顿法收敛过程 (x = 8):
//
//  f(k) = k² - 8
//  
//  k₀ = 8
//  k₁ = (8 + 8/8) / 2 = 4.5
//  k₂ = (4.5 + 8/4.5) / 2 = 3.139
//  k₃ = (3.139 + 8/3.139) / 2 = 2.844
//  k₄ = (2.844 + 8/2.844) / 2 = 2.828  ≈ √8
//  取整 → 2 ✓
```

```cpp
class Solution {
public:
    int mySqrt(int x) {
        if (x == 0) return 0;
        
        // 初始猜测值，从 x 开始
        long long k = x;
        
        // 牛顿迭代：k = (k + x/k) / 2
        // 当 k² ≤ x 时停止（已收敛到整数解）
        while (k * k > x) {
            k = (k + x / k) / 2;
        }
        
        return (int)k;
    }
};
```

**为什么收敛？** 牛顿法对凸函数 f(k) = k²-x 总是从右侧逼近根，每次迭代至少将误差平方级缩小（二阶收敛）。实际上只需要很少的迭代次数。

**关键点**: 初始值取 `x` 而不是 `x/2`。虽然 `x/2` 更接近答案，但从 `x` 开始能保证牛顿法始终从右侧逼近（k 单调递减直到收敛），逻辑更简单。

## 解法对比

| | 线性扫描 | 二分查找 | 牛顿迭代 |
|---|---|---|---|
| 时间 | O(√x) | O(log x) | O(log x)，常数更小 |
| 空间 | O(1) | O(1) | O(1) |
| 实现难度 | 简单 | 中等 | 需要数学推导 |
| 面试推荐度 | 暖场用 | ⭐首选 | 加分展示 |
| 核心思想 | 暴力枚举 | 有序空间折半 | 数学迭代逼近 |

**什么时候选哪个？**
- 面试：先说线性扫描思路展示理解，然后写二分查找，如果面试官追问可以提牛顿法
- 竞赛/实际：牛顿法常数最小，但二分更通用、不易出错

## 易错点

1. **溢出 `mid * mid`**
   - ✗ `if (mid * mid <= x)` — 当 `mid` 接近 46340 时，`int` 乘法溢出
   - ✓ `long long square = (long long)mid * mid;` — 强制转 long long
   - 或者 ✓ `if (mid <= x / mid)` — 但要特判 `mid == 0`

2. **二分返回值搞混**
   - ✗ 返回 `left` — left 在循环结束时已经越过了答案
   - ✓ 返回 `right` — right 停在最后一个满足 `k² ≤ x` 的位置

3. **忘记处理 x=0**
   - 牛顿法中 `x/k` 会除零（如果 k 初始化为 0）
   - 线性扫描中如果从 k=1 开始会返回 0，恰好正确，但要想清楚

4. **牛顿法终止条件写错**
   - ✗ `while (k != (k + x/k) / 2)` — 整数除法可能在两个值之间震荡
   - ✓ `while (k * k > x)` — 直接判断收敛到整数解

## 面试追问

**Q1: 暴力解的时间复杂度是多少？能优化吗？**
> O(√x)。搜索空间 [0, x] 上 k² 单调递增，可以二分查找优化到 O(log x)。

**Q2: 二分查找时怎么处理溢出？**
> `mid * mid` 可能溢出 int。两种方法：① 转 long long，② 用 `mid <= x / mid` 代替（注意 mid=0 的除零保护）。

**Q3: 如果要求返回浮点数精确到小数点后 6 位呢？**
> 二分仍然适用，只是搜索空间变成浮点数 `[0, x]`，终止条件改为 `right - left < 1e-7`。或者用牛顿法迭代到精度足够为止。

**Q4: 你知道牛顿法吗？它比二分快在哪？**
> 牛顿法用 `k = (k + x/k) / 2` 迭代，二阶收敛（每次迭代有效数字翻倍），而二分是线性收敛（每次排除一半）。对于高精度浮点计算，牛顿法优势明显。
