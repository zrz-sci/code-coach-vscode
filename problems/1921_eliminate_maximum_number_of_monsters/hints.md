# 1921. 消灭怪物的最大数量

## 核心思路

本质上问的是：**每分钟只能消灭一个怪物，按什么顺序消灭才能在游戏失败前消灭最多怪物？** 关键转化是把"距离+速度"统一转换为"到达时间"，然后贪心地优先消灭最早到达的怪物。

## 思维链

1. **读完题第一反应**：每个怪物有距离和速度，我需要决定每一分钟消灭哪个怪物。这是一个调度/排序问题——"先处理谁"。

2. **统一度量**：每个怪物的距离和速度不同，直接比较很混乱。但我们真正关心的是：**每个怪物什么时候到达城市？** 到达时间 = dist[i] / speed[i]。这把两个变量降成了一个变量。

3. **贪心直觉**：第 0 分钟消灭一个，第 1 分钟消灭一个……第 k 分钟消灭第 k+1 个怪物。应该**优先消灭最早到达的怪物**——如果不先处理它，它就会在我们还在对付别的怪物时到达城市。

4. **贪心验证**：把到达时间排序后，第 i 个怪物（0-indexed）必须在第 i 分钟被消灭。只要 arrivalTime[i] > i，我们就来得及。一旦某个 arrivalTime[i] <= i，游戏结束。

5. **向上取整 vs 直接比较**：到达时间可能是小数（如 dist=5, speed=3，到达时间=1.67分钟）。我们可以用 `ceil(dist/speed)` 取整，也可以直接用浮点比较。用 `ceil` 更直觉——它表示"怪物在第几分钟到达"。

6. **复杂度**：排序 O(n log n)，遍历 O(n)，总体 O(n log n)。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力模拟 | 每分钟遍历所有怪物，选一个消灭 | O(n²) | O(n) | 能说出即可 |
| 贪心排序 | 算到达时间，排序，依次检查 | O(n log n) | O(n) | ⭐ 必须写出 |

## 关键提示

1. **关键转化**：不要同时考虑距离和速度两个维度，把它们合并成一个维度——**到达城市的时间**。

2. **贪心策略**：到达时间最早的怪物最紧迫，应该最先消灭。反证：如果不先消灭最紧迫的，它可能在你处理别的怪物时到达。

3. **判定条件**：排序后，第 i 个怪物（0-indexed）在第 i 分钟被消灭。只要它的到达时间 **严格大于** i，就来得及。等于 i 也算输（题目说"恰好到达也算输"）。

4. **整数除法的陷阱**：`ceil(dist[i] / speed[i])` 用整数除法会截断！要么用 `(dist[i] + speed[i] - 1) / speed[i]`（整数向上取整技巧），要么用浮点除法 `(double)dist[i] / speed[i]`。

5. **示例演示**：
```
dist  = [1, 1, 2, 3]
speed = [1, 1, 1, 1]
到达时间 = [1, 1, 2, 3]
排序后   = [1, 1, 2, 3]

第0分钟: 消灭到达时间=1的怪物 → 1 > 0 ✓ 来得及
第1分钟: 消灭到达时间=1的怪物 → 1 > 1 ✗ 来不及！
答案 = 1
```

## 解法详解

### 解法1: 暴力模拟 — O(n²) / O(n)

**思考过程**：最直接的想法——模拟每一分钟的过程。每分钟选一个"最紧迫"的怪物消灭，然后所有存活怪物前进一步。

```cpp
class Solution {
public:
    int eliminateMaximum(vector<int>& dist, vector<int>& speed) {
        int n = dist.size();
        vector<bool> alive(n, true);
        int killed = 0;
        
        for (int minute = 0; minute < n; minute++) {
            // 检查是否有怪物已经到达（除了第0分钟，怪物还没移动）
            if (minute > 0) {
                for (int i = 0; i < n; i++) {
                    if (alive[i]) {
                        dist[i] -= speed[i]; // 怪物前进
                        if (dist[i] <= 0) return killed; // 有怪物到达，游戏结束
                    }
                }
            }
            
            // 选择最紧迫的怪物消灭（到达时间最早的）
            int target = -1;
            double minTime = INT_MAX;
            for (int i = 0; i < n; i++) {
                if (alive[i]) {
                    double t = (double)dist[i] / speed[i];
                    if (t < minTime) {
                        minTime = t;
                        target = i;
                    }
                }
            }
            if (target != -1) {
                alive[target] = false;
                killed++;
            }
        }
        return killed;
    }
};
```

**关键点**：这个解法正确但效率低。每分钟都要遍历所有怪物找最紧迫的，O(n) 每次 × O(n) 分钟 = O(n²)。而且模拟过程容易出错——移动和检查的顺序很重要。

### 解法2: 贪心 + 排序 — O(n log n) / O(n) ⭐ 面试首选

**从解法1优化**：解法1的瓶颈是"每分钟找最紧迫的怪物"。但其实我们可以提前算出所有怪物的到达时间，排序后就知道消灭顺序了。不需要逐分钟模拟。

**核心观察**：
- 第 i 分钟（0-indexed）消灭第 i 个最紧迫的怪物
- 只要第 i 个怪物的到达时间 > i，我们就来得及

```cpp
class Solution {
public:
    int eliminateMaximum(vector<int>& dist, vector<int>& speed) {
        int n = dist.size();
        
        // 步骤1: 计算每个怪物的到达时间（向上取整）
        // 为什么向上取整？因为怪物在"整分钟"才会到达
        // dist=5, speed=3 → 实际1.67分钟到达 → ceil=2，在第2分钟开始时还没到
        vector<int> arrival(n);
        for (int i = 0; i < n; i++) {
            // 整数向上取整技巧: ceil(a/b) = (a + b - 1) / b
            arrival[i] = (dist[i] + speed[i] - 1) / speed[i];
        }
        
        // 步骤2: 排序——最紧迫的在前面
        sort(arrival.begin(), arrival.end());
        
        // 步骤3: 贪心检查
        // 第 i 分钟消灭排序后第 i 个怪物
        // 条件: arrival[i] > i (严格大于，等于就来不及)
        for (int i = 0; i < n; i++) {
            if (arrival[i] <= i) {
                return i; // 第 i 个怪物已经到达，只消灭了 i 个
            }
        }
        return n; // 全部消灭
    }
};
```

**为什么贪心是正确的？** 反证法：假设不优先消灭最早到达的怪物 A，而是先消灭后到达的怪物 B。那么 A 的到达时间更早，推迟消灭 A 只会增加 A 到达城市的风险，而提前消灭 B 并不会带来额外收益（B 反正还有时间）。所以贪心策略——优先消灭最紧迫的——一定不会比其他策略差。

## 解法对比

| | 暴力模拟 | 贪心排序 |
|---|---|---|
| 时间复杂度 | O(n²) | O(n log n) |
| 空间复杂度 | O(n) | O(n) |
| 代码复杂度 | 高（模拟细节多） | 低（三步走） |
| 面试推荐 | 仅用于说明思路 | **首选** |

关键区别：暴力模拟是"走一步看一步"，贪心排序是"提前规划好消灭顺序"。排序天然把"找最紧迫怪物"的 O(n) 查找降为 O(1)（直接取下一个）。

## 易错点

1. **向上取整写错**：
   - ✗ `arrival[i] = dist[i] / speed[i];` — 整数除法向下取整，dist=5, speed=3 得到 1 而不是 2
   - ✓ `arrival[i] = (dist[i] + speed[i] - 1) / speed[i];` — 正确的向上取整
   - 或者用浮点：`arrival[i] = ceil((double)dist[i] / speed[i]);`

2. **判定条件用 `>=` 还是 `>`**：
   - ✗ `if (arrival[i] < i)` — 漏掉了"恰好到达"的情况
   - ✓ `if (arrival[i] <= i)` — 题目明确说"恰好到达也算输"
   - 解释：第 i 分钟开始时，如果怪物恰好到达（arrival == i），游戏在你使用武器之前就结束了

3. **返回值搞混**：
   - ✗ `return i - 1;` — 第 i 个怪物来不及消灭，说明已经成功消灭了 i 个（0 到 i-1）
   - ✓ `return i;` — 0-indexed，第 i 个失败意味着成功消灭了 i 个

4. **到达时间为0的怪物**：
   - 如果 dist[i] = 0（怪物初始就在城市），arrival = 0，排序后第一个就是 0 <= 0，返回 0。这是正确的——游戏还没开始就输了。但题目约束 dist[i] >= 1，所以不会出现这种情况。

## 面试追问

**Q1: 为什么优先消灭最早到达的怪物？能否用交换论证证明？**
> 假设某个最优方案在第 t 分钟消灭了怪物 B（到达时间晚），而没消灭怪物 A（到达时间早）。那把第 t 分钟改为消灭 A，B 推迟消灭。由于 B 到达时间更晚，推迟一分钟不影响（它还没到）；A 提前消灭更安全。所以交换后不会变差，贪心成立。

**Q2: 如果武器每次充电需要 k 分钟而不是 1 分钟，怎么改？**
> 第 i 次开火时间变成 `i * k`（第0次在第0分钟，第1次在第k分钟，第2次在第2k分钟...）。判定条件改为 `arrival[i] <= i * k`。

**Q3: 如果每分钟可以消灭 m 个怪物（m 把武器），怎么改？**
> 第 i 个怪物（排序后）可以在第 `i / m` 分钟被消灭。判定条件改为 `arrival[i] <= i / m`。

**Q4: 时间复杂度能否优于 O(n log n)？**
> 瓶颈在排序。如果到达时间范围有限（如最大值为 M），可以用计数排序 O(n + M)。一般情况下 O(n log n) 是最优的。
