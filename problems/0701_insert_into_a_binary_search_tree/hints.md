# 701. 二叉搜索树中的插入操作

## 核心思路

BST 的插入本质上就是**利用 BST 性质做一次查找，找到 val 应该存在的空位，直接挂上去**。不需要调整树的结构，因为任何新值一定可以插入到某个叶子节点的空孩子位置。

## 思维链

1. **读完题第一反应**：BST 有严格的左小右大性质，新值 val 在树中不存在，我需要找到合适的位置插入。最简单的做法——从根出发，比当前节点小就往左走，比当前节点大就往右走，走到空位就插入。

2. **这个做法有瓶颈吗？** 没有！这已经是最优做法了。每次只走一条路径（左或右），时间就是树的高度 O(h)。这和 BST 的查找操作完全一致。

3. **递归 vs 迭代？** 递归写法更直觉——空节点就是终止条件，直接创建新节点返回。迭代写法需要手动维护一个 parent 指针，找到空位后把新节点挂到 parent 的左或右孩子。

4. **有没有其他插入方式？** 题目说"可以返回任意有效结果"。理论上可以把 val 放到树中间（比如替换某个节点，把原子树重新挂），但这没必要——插入到叶子是最简单的。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 递归 | 利用 BST 性质递归找空位插入 | O(h) | O(h) 递归栈 | ⭐ 必须写出 |
| 迭代 | 用循环 + parent 指针找空位 | O(h) | O(1) | ⭐ 必须写出 |

> h 为树的高度。平衡 BST 时 h = O(log n)，退化为链表时 h = O(n)。

## 关键提示

1. **BST 的关键性质**：任何值在 BST 中的位置是唯一确定的路径。val 比当前节点小，它一定在左子树；比当前节点大，一定在右子树。顺着这个路径走到底（null），那就是插入位置。

2. **递归的返回值妙用**：如果递归函数返回的是"插入后该子树的根节点"，那么 `root->left = insertIntoBST(root->left, val)` 这一行既处理了"左子树为空时创建新节点"，也处理了"左子树不为空时递归下去"。

3. **别忘了空树**：root 为 nullptr 时，直接返回新节点即可。这既是边界条件，也是递归的终止条件。

4. **ASCII 示意图**：
```
    插入 val=5 到下面这棵 BST:
    
         4
        / \
       2   7
      / \
     1   3
    
    查找路径: 5 > 4 → 往右 → 5 < 7 → 往左 → null → 插入!
    
    结果:
         4
        / \
       2   7
      / \ /
     1  3 5
```

## 解法详解

### 解法1: 递归 — O(h) / O(h) ⭐ 面试首选

**思考过程**：BST 的递归结构天然适合递归处理。递归三要素：
- **返回值**：插入 val 后，该子树的根节点
- **终止条件**：当前节点为 null，说明找到了空位，创建新节点返回
- **单层逻辑**：val 比当前节点小，递归插入左子树；否则递归插入右子树

```cpp
class Solution {
public:
    TreeNode* insertIntoBST(TreeNode* root, int val) {
        // 终止条件：找到空位，创建新节点
        if (!root) return new TreeNode(val);
        
        // 利用 BST 性质决定方向
        if (val < root->val)
            root->left = insertIntoBST(root->left, val);   // 插入左子树
        else
            root->right = insertIntoBST(root->right, val);  // 插入右子树
        
        return root;  // 返回当前子树的根（未改变）
    }
};
```

**关键点**：`root->left = insertIntoBST(root->left, val)` 这行的精妙之处——当 `root->left` 为 null 时，递归返回新节点并赋值给 `root->left`，完成了"挂载"操作；当 `root->left` 不为 null 时，递归返回的还是原来的左子树根，赋值是"无害"的。

### 解法2: 迭代 — O(h) / O(1)

**从解法1转化**：递归的本质是沿着一条路径往下走直到 null。用迭代完全可以模拟：用一个循环往下走，同时记录 parent 节点。走到 null 时，根据 val 和 parent 的关系把新节点挂到 parent 的左或右。

```cpp
class Solution {
public:
    TreeNode* insertIntoBST(TreeNode* root, int val) {
        // 空树特判
        if (!root) return new TreeNode(val);
        
        TreeNode* curr = root;
        TreeNode* parent = nullptr;
        
        // 沿路径下行，找到 null 位置
        while (curr) {
            parent = curr;
            if (val < curr->val)
                curr = curr->left;
            else
                curr = curr->right;
        }
        
        // curr 为 null，parent 是要挂载的父节点
        if (val < parent->val)
            parent->left = new TreeNode(val);
        else
            parent->right = new TreeNode(val);
        
        return root;
    }
};
```

**关键点**：迭代版本必须单独处理空树（root == nullptr），因为此时没有 parent 可以挂载。递归版本不需要，因为 null 直接是终止条件。

## 解法对比

| | 递归 | 迭代 |
|------|------|------|
| 时间 | O(h) | O(h) |
| 空间 | O(h) 递归栈 | O(1) |
| 代码量 | 极简，5行核心 | 稍多，需要 parent 指针 |
| 可读性 | 非常直观 | 需要理解 parent 追踪逻辑 |
| 适用场景 | 面试首选，快速写出 | 树很深时避免栈溢出 |

面试中优先写递归版（简洁不易错），如果面试官追问空间优化再给迭代版。

## 易错点

1. **递归版忘记 `return root`**：
   - ✗ 递归完直接没有返回值 → 函数未定义行为
   - ✓ 最后 `return root;`，非叶子节点的递归要把自身返回给上层

2. **迭代版忘记空树特判**：
   - ✗ `TreeNode* curr = root;` 然后直接 while 循环 → root 为 null 时 parent 也为 null，后面 `parent->val` 崩溃
   - ✓ 开头 `if (!root) return new TreeNode(val);`

3. **递归方向写反**：
   - ✗ `if (val < root->val) root->right = ...` → 小的值插到了右子树，破坏 BST 性质
   - ✓ `val < root->val` 对应 `root->left`

## 面试追问

**Q1: 这样插入后 BST 还平衡吗？**  
不一定。如果按有序序列依次插入（如 1,2,3,4,5），BST 会退化为链表，高度 O(n)。要保持平衡需要用 AVL 树或红黑树，在插入后通过旋转操作维持平衡。

**Q2: 如果要求插入后保持平衡，怎么做？**  
使用自平衡 BST（AVL / 红黑树）。以 AVL 为例：插入后从插入点向上回溯，检查每个祖先节点的平衡因子（左右子树高度差），如果超过 1 就通过 LL/RR/LR/RL 旋转恢复平衡。

**Q3: 如果要删除一个节点呢？（LeetCode 450）**  
删除比插入复杂，要分三种情况：(1) 叶子节点直接删；(2) 只有一个孩子，孩子替代自己；(3) 有两个孩子，找中序后继（右子树最小值）替代自己的值，然后递归删除后继节点。
