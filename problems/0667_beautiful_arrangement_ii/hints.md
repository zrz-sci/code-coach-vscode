# 667. 优美的排列 II (Beautiful Arrangement II)

## 题目理解

给定两个整数 `n` 和 `k`，构造一个包含 `1` 到 `n` 的排列，使得相邻元素差的绝对值恰好有 `k` 个不同的值。

```
示例 1: n=3, k=1 → [1,2,3]    差值=[1,1]    不同差值={1}      → 1种 ✓
示例 2: n=3, k=2 → [1,3,2]    差值=[2,1]    不同差值={1,2}    → 2种 ✓
约束:   1 <= k < n <= 10^4
```

---

## 核心思路

**构造法**：利用"交替放最大最小"的技巧恰好产生 k 个不同差值。

**关键观察**：
- `[1, 2, 3, ..., n]` 只有 1 种差值（全是 1）
- `[1, n, 2, n-1, 3, ...]` 交替放置可以产生 `n-1` 种差值（最多）
- 想要恰好 k 种？**前面顺序放产生差值 1，后面交替放产生额外的差值**

---

## 思维链：从观察到构造

### 第一步：观察差值的产生规律

让我们看一组数字 `[1, 2, 3, 4, 5]` 的不同排列：

```
排列          差值序列           不同差值集合    k
[1,2,3,4,5]   [1,1,1,1]          {1}            1
[1,5,2,4,3]   [4,3,2,1]          {1,2,3,4}      4 (= n-1)
[1,2,3,5,4]   [1,1,2,1]          {1,2}          2
[1,2,5,3,4]   [1,3,2,1]          {1,2,3}        3
```

### 第二步：发现构造模式

对 `[lo, lo+1, ..., hi]` 这段数进行交替放置（先小后大交替）：

```
lo=1, hi=5: [1, 5, 2, 4, 3]
差值:        [4, 3, 2, 1]
不同差值:     4 种 = hi - lo 种
```

**规律**：对一段连续的 m 个数交替放置，能产生 `m-1` 种不同差值。

### 第三步：组合策略

要恰好 k 种不同差值：
1. 前 `n-k-1` 个位置顺序放 `[1, 2, ..., n-k-1]` → 产生差值全是 1（只有 1 种）
2. 后 `k+1` 个位置对 `[n-k, n-k+1, ..., n]` 交替放置 → 产生 k 种不同差值

总共差值种类 = k（因为顺序段的差值 1 已被交替段包含）。

### 构造过程可视化

以 `n=7, k=4` 为例：

```
Step 1: 顺序放前 n-k-1 = 2 个数
  result = [1, 2]
  差值 = [1]

Step 2: 交替放后 k+1 = 5 个数: [3, 4, 5, 6, 7]
  lo=3, hi=7
  放 lo=3 → result = [1, 2, 3]
  放 hi=7 → result = [1, 2, 3, 7]
  放 lo=4 → result = [1, 2, 3, 7, 4]
  放 hi=6 → result = [1, 2, 3, 7, 4, 6]
  放 lo=5 → result = [1, 2, 3, 7, 4, 6, 5]

最终: [1, 2, 3, 7, 4, 6, 5]
差值: [1, 1, 4, 3, 2, 1]
不同差值: {1, 2, 3, 4} → 4 种 ✓
```

更多示例：

```
n=5, k=1: [1, 2, 3, 4, 5]        差值=[1,1,1,1]     → {1}       k=1 ✓
n=5, k=2: [1, 2, 3, 5, 4]        差值=[1,1,2,1]     → {1,2}     k=2 ✓
n=5, k=3: [1, 2, 5, 3, 4]        差值=[1,3,2,1]     → {1,2,3}   k=3 ✓
n=5, k=4: [1, 5, 2, 4, 3]        差值=[4,3,2,1]     → {1,2,3,4} k=4 ✓
```

**规律很清晰**：k 越大，交替段越长，顺序段越短。

## 解法概览

| 解法 | 思路 | 时间 | 空间 |
|------|------|------|------|
| 构造法（双指针交替） | 前面顺序 + 后面交替 | O(n) | O(n) |

本题只有构造法，没有其他实质不同的解法。变体在于具体的构造方式。

---

## 关键提示

### 提示 1：交替放置产生递减差值

对 `[lo, lo+1, ..., hi]` 交替放 `lo, hi, lo+1, hi-1, ...`：
- 差值依次是 `hi-lo`, `hi-lo-1`, `hi-lo-2`, ..., `1`
- 共 `hi - lo` 种不同差值

### 提示 2：前面顺序段不增加新差值

`[1, 2, ..., m]` 的差值都是 1。只要交替段也包含差值 1（它一定包含），顺序段就不会引入新的差值种类。

### 提示 3：k+1 个数交替放产生 k 种差值

这是核心等式。所以交替段需要 `k+1` 个数。

### 提示 4：双指针实现交替放置

```
lo = n - k, hi = n
while (lo <= hi):
    放 lo, lo++
    如果 lo <= hi: 放 hi, hi--
```

---

## 易错点

### 1. 顺序段和交替段的分界

```
错误: 前 n-k 个数顺序，后 k 个数交替
→ k 个数交替只产生 k-1 种差值

正确: 前 n-k-1 个数顺序，后 k+1 个数交替
→ k+1 个数交替产生 k 种差值
```

### 2. 交替放置的边界

```cpp
// 错误: 忘记检查 lo <= hi
while (lo <= hi) {
    result.push_back(lo++);
    result.push_back(hi--);  // 如果 lo > hi 了还放，会重复！
}

// 正确: 放 hi 前检查
while (lo <= hi) {
    result.push_back(lo++);
    if (lo <= hi) result.push_back(hi--);
}
```

### 3. k=1 或 k=n-1 的特殊情况

- `k=1`：整个顺序放 `[1,2,...,n]`
- `k=n-1`：整个交替放 `[1,n,2,n-1,...]`

这两种情况都被通用构造自然覆盖，不需要额外特判。

---

## 构造正确性证明

**定理**：对连续整数 `[a, a+1, ..., a+m]`（共 m+1 个数），交替放置 `a, a+m, a+1, a+m-1, ...` 产生的差值集合恰好是 `{1, 2, ..., m}`。

**证明**：
- 第 1 个差值：`|(a+m) - a| = m`
- 第 2 个差值：`|(a+1) - (a+m)| = m - 1`
- 第 3 个差值：`|(a+m-1) - (a+1)| = m - 2`
- ...
- 第 m 个差值：`1`

差值依次为 `m, m-1, m-2, ..., 1`，恰好是 `{1, 2, ..., m}` 共 m 种。

## 拓展思考

### 面试追问

1. **如果要求差值恰好是给定的集合 S（不一定是 {1,...,k}）怎么办？** → 更复杂的构造问题，不一定总有解。

2. **如果要求字典序最小的排列？** → 需要贪心地让前面尽量小。当前构造法恰好满足字典序较小的特性（前面是顺序递增的）。

3. **与 526. Beautiful Arrangement (I) 的关系？** → 526 是回溯搜索问题（要求 perm[i] 整除 i 或反之），与本题的"差值个数"完全不同。
