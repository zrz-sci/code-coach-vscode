# 807. 保持城市天际线

## 核心思路

对于矩阵中的每个建筑 `grid[r][c]`，它能增长到的最大高度取决于其所在行的最大值和所在列的最大值中**较小的那个**。因为如果超过了其中任一方向的天际线高度，就会改变该方向的天际线。所以答案就是 `sum(min(rowMax[r], colMax[c]) - grid[r][c])`。

## 思维链

1. **读完题第一反应**：天际线就是从某个方向看过去的轮廓，也就是每行/每列的最大值。从北/南方向看到的是每列的最大值，从东/西方向看到的是每行的最大值。

2. **什么约束了建筑增高？** 建筑 `grid[r][c]` 增高后，不能超过第 `r` 行的最大值（否则东西方向天际线变了），也不能超过第 `c` 列的最大值（否则南北方向天际线变了）。所以它最多只能增高到 `min(rowMax[r], colMax[c])`。

3. **为什么取 min？** 如果行最大值是 9，列最大值是 7，那么建筑最多增到 7。因为如果增到 8，从南北方向看这一列的天际线就从 7 变成了 8，违反了约束。

4. **算法步骤**：先预计算每行最大值 `rowMax` 和每列最大值 `colMax`，然后遍历每个格子，将 `min(rowMax[r], colMax[c]) - grid[r][c]` 累加即可。

5. **复杂度分析**：两遍遍历矩阵（一遍求最大值，一遍计算差值），时间 O(n^2)，空间 O(n)。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 贪心 + 行列最大值 | 预计算 rowMax/colMax，每格增到 min(rowMax, colMax) | O(n^2) | O(n) | ⭐ 必须写出 |

> 本题只有一种核心解法。关键在于理解天际线的定义以及 min 约束的由来。面试中需要清晰表达"为什么取 min"的逻辑。

## 关键提示

1. **天际线 = 投影最大值**：从东/西看是每行最大值，从南/北看是每列最大值。这是理解题意的第一步。

2. **每个建筑独立受约束**：`grid[r][c]` 同时被 `rowMax[r]` 和 `colMax[c]` 两个方向约束，取较小的那个就是它能达到的极限。

3. **原始最大值的建筑不变**：如果 `grid[r][c]` 恰好是行最大值或列最大值，它的增量为 0（因为它自己就是天际线的一部分）。

4. 模拟过程：
```
grid = [[3,0,8,4],     rowMax = [8, 7, 9, 3]
        [2,4,5,7],     colMax = [9, 4, 8, 7]
        [9,2,6,3],
        [0,3,1,0]]

grid[0][0] = 3, min(8,9) = 8, 增量 = 8 - 3 = 5
grid[0][1] = 0, min(8,4) = 4, 增量 = 4 - 0 = 4
grid[0][2] = 8, min(8,8) = 8, 增量 = 8 - 8 = 0  ← 本身就是行最大值
grid[1][3] = 7, min(7,7) = 7, 增量 = 7 - 7 = 0  ← 同时是行和列最大值
```

## 解法详解

### 解法1: 贪心 + 行列最大值 -- O(n^2) / O(n) ⭐ 面试首选

**思考过程**：

天际线是从某方向观察时建筑高度的投影轮廓。关键洞察：每个建筑能增高的上限受两个方向的天际线同时约束，取 min 保证两个方向的天际线都不被破坏。

```cpp
class Solution {
public:
    int maxIncreaseKeepingSkyline(vector<vector<int>>& grid) {
        int n = grid.size();
        vector<int> rowMax(n, 0), colMax(n, 0);
        
        // 第一遍：预计算每行最大值和每列最大值
        for (int r = 0; r < n; r++) {
            for (int c = 0; c < n; c++) {
                rowMax[r] = max(rowMax[r], grid[r][c]);
                colMax[c] = max(colMax[c], grid[r][c]);
            }
        }
        
        // 第二遍：累加每个建筑的最大增量
        int totalIncrease = 0;
        for (int r = 0; r < n; r++) {
            for (int c = 0; c < n; c++) {
                // 建筑最多增到 min(行天际线, 列天际线)
                int maxHeight = min(rowMax[r], colMax[c]);
                totalIncrease += maxHeight - grid[r][c];
            }
        }
        
        return totalIncrease;
    }
};
```

**关键点**：
- `rowMax[r]` 对应东/西方向天际线，`colMax[c]` 对应南/北方向天际线。
- `min(rowMax[r], colMax[c])` 保证不超过两个方向中更严格的那个限制。
- 差值一定 >= 0，因为 `grid[r][c] <= rowMax[r]` 且 `grid[r][c] <= colMax[c]`。

## 易错点

1. **混淆行和列的方向**：
   - ✗ 认为行对应南北、列对应东西
   - ✓ 无论怎么定义方向，只要 rowMax 和 colMax 计算正确，取 min 的逻辑不变

2. **忘记预计算，在内层循环重复求最大值**：
   - ✗ 每次都遍历整行/整列求最大值 -> O(n^3)
   - ✓ 预计算 rowMax 和 colMax -> O(n^2)

3. **只考虑一个方向的约束**：
   - ✗ `totalIncrease += rowMax[r] - grid[r][c]`（忘了列的约束）
   - ✓ `totalIncrease += min(rowMax[r], colMax[c]) - grid[r][c]`

4. **对 n=1 的边界情况**：
   - ✗ 认为 1x1 矩阵不需要处理
   - ✓ 代码天然处理：唯一元素就是行列最大值，增量为 0

## 面试追问

**Q1: 为什么 min(rowMax, colMax) 是每个建筑的上限而非下限？为什么不取 max？**

> 如果取 max，超出的那个方向的天际线就会被改变。例如行最大值 9、列最大值 7，如果增到 9，那从列方向看天际线就从 7 变成 9。取 min 保证两个方向的天际线都不被突破。这是一个"多约束取交集"的思想。

**Q2: 如果允许降低建筑高度（增量可以为负），该如何处理？**

> 如果可以降低，那么每个建筑高度应该恰好等于 `min(rowMax[r], colMax[c])` 才能使天际线不变且总增量最大化。但注意降低某个行/列最大值的建筑会改变天际线，所以原始最大值所在的建筑不能被降低。问题会变得更复杂，需要考虑天际线的定义约束。

**Q3: 如果矩阵不是方阵 (m x n)，算法需要改动吗？**

> 不需要本质改动。rowMax 大小变为 m，colMax 大小变为 n，其余逻辑完全一致。时间复杂度变为 O(m*n)，空间 O(m+n)。
