# 123. 买卖股票的最佳时机 III

## 核心思路

本题本质是：在一维价格序列上，**最多切两刀**（两次买卖），使得两段利润之和最大。关键难点在于"最多两笔交易"这个限制，以及两笔交易之间不能重叠。

## 思维链

1. **读完题第一反应**：如果只有1次交易，就是经典的 Stock I（维护左边最小值）。现在变成最多2次，能不能枚举分割点，把数组分成左右两半，各做一次 Stock I？

2. **暴力的想法**：枚举分割点 `day`，左半部分 `[0..day]` 的最大一次利润 + 右半部分 `[day..n-1]` 的最大一次利润。但如果每次都重新算左右两半的利润，每个分割点都是 O(n)，总共 O(n²)。

3. **瓶颈在哪？** 对每个分割点重复计算左右部分的利润。如果能预处理出 `left[i]` = `[0..i]` 的最大一次利润，`right[i]` = `[i..n-1]` 的最大一次利润，枚举分割点就只要 O(1) 查询了！

4. **前后缀分解法**：`left[i]` 从左到右扫描维护最小价格即可（就是 Stock I）；`right[i]` 从右到左扫描维护最大价格。最终答案 = max(left[i] + right[i])。这是 O(n) 时间 O(n) 空间。

5. **另一条思路：状态机 DP**。不再枚举分割点，而是对每一天定义状态：当前处于"第几次交易"的"持有/不持有"阶段。这是股票系列的通用框架，可以推广到 k 次交易。

6. **空间优化**：状态机 DP 中 `dp[i]` 只依赖 `dp[i-1]`，可以用 4 个变量滚动，达到 O(1) 空间。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 前后缀分解 | 预处理左右最大利润，枚举分割点 | O(n) | O(n) | ⭐ 必须写出 |
| 状态机 DP（二维表） | 5种状态转移 | O(n) | O(n) | 能说出即可 |
| 状态机 DP（空间优化） | 4个滚动变量 | O(n) | O(1) | ⭐ 加分项 |

## 关键提示

1. **Stock I 的复习**：只允许1次交易时，从左到右扫描，维护 `min_price`，`max_profit = max(max_profit, price - min_price)`。本题是在此基础上扩展到2次。

2. **前后缀分解的核心直觉**：两笔交易不重叠 → 一定存在某个分割日，左边完成第一笔，右边完成第二笔。注意"不交易"也是合法的（利润=0），所以分割点可以在任何位置。

3. **状态机的状态定义**：每天结束时你可能处于以下5种状态之一：
   - 未操作
   - 第1次持有
   - 第1次卖出（不持有）
   - 第2次持有
   - 第2次卖出（不持有）

4. **为什么4个变量就够？** "未操作"状态的利润永远是0，不需要单独维护。剩下4个状态只依赖前一天的值。

5. **系列题关联**：Stock I (k=1) → Stock III (k=2) → Stock IV (k=任意)。从 III 到 IV 只需要把"4个变量"泛化成"2k个变量"的循环。

## 解法详解

### 解法1: 前后缀分解 — O(n) / O(n) ⭐ 面试首选

**思考过程**：两笔不重叠的交易，一定可以被某个日期分开。如果我提前算好"到第 i 天为止做一次交易的最大利润"和"从第 i 天起做一次交易的最大利润"，枚举分割点取最大值即可。

```
prices:  [3, 3, 5, 0, 0, 3, 1, 4]

left[i] (从左到右, 维护min_price):
  min:    3  3  3  0  0  0  0  0
  left:   0  0  2  2  2  3  3  4

right[i] (从右到左, 维护max_price):
  max:    5  5  5  4  4  4  4  4
  right:  4  4  4  4  4  3  3  0
  
  (right计算修正 — 从右到左):
  i=7: max=4, right[7]=0
  i=6: max=4, right[6]=3
  i=5: max=4, right[5]=1  → 不对，应该是 max(4-3)=1? 
  
  重新仔细算:
  i=7: max_price=4, right[7]=4-4=0
  i=6: max_price=4, right[6]=4-1=3
  i=5: max_price=4, right[5]=max(right[6], 4-3)=3
  i=4: max_price=4, right[4]=max(3, 4-0)=4
  i=3: max_price=4, right[3]=max(4, 4-0)=4
  i=2: max_price=5, right[2]=max(4, 5-5)=4
  i=1: max_price=5, right[1]=max(4, 5-3)=4
  i=0: max_price=5, right[0]=max(4, 5-3)=4

left[i] + right[i]:
  i=0: 0+4=4
  i=1: 0+4=4
  i=2: 2+4=6  ← 最大!
  i=3: 2+4=6  ← 也是6
  ...
答案 = 6 ✓
```

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        if (n <= 1) return 0;
        
        // left[i]: 在 [0..i] 内完成最多1次交易的最大利润
        vector<int> left(n, 0);
        int minPrice = prices[0];
        for (int i = 1; i < n; i++) {
            minPrice = min(minPrice, prices[i]);
            left[i] = max(left[i - 1], prices[i] - minPrice);
        }
        
        // right[i]: 在 [i..n-1] 内完成最多1次交易的最大利润
        vector<int> right(n, 0);
        int maxPrice = prices[n - 1];
        for (int i = n - 2; i >= 0; i--) {
            maxPrice = max(maxPrice, prices[i]);
            right[i] = max(right[i + 1], maxPrice - prices[i]);
        }
        
        // 枚举分割点（分割点 i 表示第一笔在 [0..i]，第二笔在 [i..n-1]）
        // 注意：两笔交易可以在同一天分割（第一笔卖+第二笔买同一天）
        int result = 0;
        for (int i = 0; i < n; i++) {
            result = max(result, left[i] + right[i]);
        }
        return result;
    }
};
```

**关键点**：`right[i]` 从右往左扫描，维护的是右边的最大价格（未来的卖出价），`maxPrice - prices[i]` 是在第 i 天买入的最大利润。

### 解法2: 状态机 DP（二维表） — O(n) / O(n)

**思考过程**：前后缀分解虽然巧妙但不够通用。如果交易次数从2变成k怎么办？我们需要一个**通用框架**。

每天结束后，你处于5种状态之一：

```
状态转移图:
  
  s0(未操作) ──买入──→ s1(第1次持有) ──卖出──→ s2(第1次完成)
                                                    │
                                                   买入
                                                    ↓
                                              s3(第2次持有) ──卖出──→ s4(第2次完成)

每个状态也可以选择"不动"（保持原状态）
```

状态转移方程：
- `s1[i] = max(s1[i-1], -prices[i])`           — 保持持有 or 今天买入（从s0=0出发）
- `s2[i] = max(s2[i-1], s1[i-1] + prices[i])`  — 保持空仓 or 今天卖出第1次
- `s3[i] = max(s3[i-1], s2[i-1] - prices[i])`  — 保持持有 or 今天买入第2次
- `s4[i] = max(s4[i-1], s3[i-1] + prices[i])`  — 保持空仓 or 今天卖出第2次

```
DP 填表过程 (prices = [3,3,5,0,0,3,1,4]):

  day     price    s1       s2       s3       s4
  ─────────────────────────────────────────────
   0       3       -3        0       -3        0
   1       3       -3        0       -3        0
   2       5       -3        2       -3        2
   3       0        0        2        2        2
   4       0        0        2        2        2
   5       3        0        3        2        5
   6       1        0        3        2        5
   7       4        0        4        2        6  ← 答案
```

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        if (n <= 1) return 0;
        
        // s1[i]: 第i天结束后，第1次买入还未卖出时的最大"利润"（负数表示花了钱）
        // s2[i]: 第i天结束后，第1次交易完成时的最大利润
        // s3[i]: 第i天结束后，第2次买入还未卖出时的最大"利润"
        // s4[i]: 第i天结束后，第2次交易完成时的最大利润
        vector<int> s1(n), s2(n), s3(n), s4(n);
        
        // 初始化第0天
        s1[0] = -prices[0];       // 第0天买入
        s2[0] = 0;                // 不可能第0天完成一次交易，利润为0（或理解为买卖同一天）
        s3[0] = -prices[0];       // 同上，第0天完成第1次后立即第2次买入
        s4[0] = 0;                // 同理
        
        for (int i = 1; i < n; i++) {
            s1[i] = max(s1[i - 1], -prices[i]);
            s2[i] = max(s2[i - 1], s1[i - 1] + prices[i]);
            s3[i] = max(s3[i - 1], s2[i - 1] - prices[i]);
            s4[i] = max(s4[i - 1], s3[i - 1] + prices[i]);
        }
        
        // 最大利润：可能做了0次、1次、2次交易
        // s4[n-1] 包含了所有情况（因为"不交易"对应利润0，初始值已覆盖）
        return max(0, s4[n - 1]);
    }
};
```

**关键点**：`s3[0] = -prices[0]` 的含义是"第0天买卖第1次（利润0），然后立即第2次买入"，这保证了状态的一致性。

### 解法3: 状态机 DP（空间优化）— O(n) / O(1) ⭐ 加分项

**从解法2优化**：观察到 `s1[i], s2[i], s3[i], s4[i]` 只依赖前一天的值，无需数组，4个变量即可。

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        // buy1: 完成第1次买入后的最大"余额"（越大越好，初始为-∞表示还没买）
        // sell1: 完成第1次卖出后的最大利润
        // buy2: 完成第2次买入后的最大"余额"
        // sell2: 完成第2次卖出后的最大利润
        int buy1 = INT_MIN, sell1 = 0;
        int buy2 = INT_MIN, sell2 = 0;
        
        for (int price : prices) {
            // 顺序：先更新 buy1，再 sell1，再 buy2，再 sell2
            // 因为 buy1 只依赖自身和 price，sell1 依赖旧 buy1...
            // 实际上即使用了当天更新的值也不影响正确性（相当于同天买卖，利润0）
            buy1  = max(buy1, -price);           // 第1次买入
            sell1 = max(sell1, buy1 + price);    // 第1次卖出
            buy2  = max(buy2, sell1 - price);    // 第2次买入（基于第1次的利润）
            sell2 = max(sell2, buy2 + price);    // 第2次卖出
        }
        
        return sell2;  // sell2 >= sell1 >= 0，已包含0次和1次交易的情况
    }
};
```

**为什么更新顺序不需要"暂存旧值"？** 假设 `buy1` 在当天被更新了（选择今天买入），然后 `sell1 = max(sell1, buy1 + price)` 用了更新后的 `buy1`，这相当于"今天买今天卖"，利润为0，不会比原来的 `sell1` 更大，所以不影响结果。

| **时间** | O(n) | O(n) | O(n) |
| **空间** | O(n) | O(n) | O(1) |
| **直觉性** | 非常直观，"分两段" | 需要理解状态机 | 同左，更简洁 |
| **可扩展性** | 仅适用于 k=2 | 可扩展到 k 次 | 可扩展到 k 次 |
| **面试推荐** | ⭐ 首选讲出 | 作为通用框架说明 | ⭐ 写代码首选 |

## 易错点

1. **前后缀法中 right 数组扫描方向搞反**：
   - ✗ `right[i]` 从左到右计算，维护 `minPrice` — 这算的还是从左到右的利润
   - ✓ `right[i]` 从右到左计算，维护 `maxPrice`（未来的最高卖出价），`profit = maxPrice - prices[i]`

2. **状态机初始化 buy1 = 0**：
   - ✗ `buy1 = 0` — 这意味着"没花钱就持有了股票"
   - ✓ `buy1 = INT_MIN`（或 `-prices[0]`）— 持有状态初始要么不可能(INT_MIN)要么花了第一天的钱

3. **sell2 返回值忘记处理"不交易"的情况**：
   - 实际上 `sell1` 和 `sell2` 初始化为0已经覆盖了"不交易利润=0"的情况，所以直接返回 `sell2` 即可，无需额外 `max(0, sell2)`

4. **前后缀法枚举分割点的范围**：
   - ✗ `for (int i = 0; i < n-1; i++) result = max(result, left[i] + right[i+1])` — 这会漏掉只做一次交易的情况
   - ✓ `for (int i = 0; i < n; i++) result = max(result, left[i] + right[i])` — `right[i]` 已经包含"不交易=0"

## 面试追问

**Q1: 如果只允许1次交易，你怎么做？（确认基础）**
→ 从左到右扫描，维护已见最小价格 `min_price`，每天计算 `price - min_price` 取最大值。O(n) 时间 O(1) 空间。这就是 Stock I。

**Q2: 从1次到2次，你的思路是怎么演进的？**
→ 方法一：两次不重叠交易一定被某天分隔，预处理前后缀数组，枚举分割点。
→ 方法二：状态机，定义(交易次数, 持有/不持有)的状态，每天转移。

**Q3: 如果是最多 k 次交易呢？（Stock IV 的追问）**
→ 状态机方法直接泛化：`buy[j]` 和 `sell[j]`（j = 1..k），循环更新。注意当 `k >= n/2` 时退化为无限次交易（Stock II），可以贪心。

**Q4: 能否 O(1) 空间？**
→ 状态机优化版已经是 O(1) 空间，4个变量。推广到 k 次是 O(k) 空间。
