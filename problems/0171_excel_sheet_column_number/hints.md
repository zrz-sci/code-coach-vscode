# 171. Excel 表列序号

## 核心思路
将 Excel 列名转换为数字，本质是一个 26 进制转 10 进制的问题，其中 A=1, B=2, ..., Z=26（注意不是从 0 开始的标准进制）。

## 思维链
1. **观察规律**: A=1, B=2, ..., Z=26, AA=27, AB=28，这是一个 26 进制系统
2. **类比十进制**: 十进制 "123" = 1*100 + 2*10 + 3*1，同理 "AB" = 1*26 + 2 = 28
3. **从左到右处理**: 对每个字符，result = result * 26 + (char - 'A' + 1)
4. **验证**: "ZY" = 26*26 + 25 = 676 + 25 = 701，正确

## 解法概览
| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 迭代累乘 ⭐ | 从左到右，每次 *26 + 当前字符值 | O(n) | O(1) | 必知 |
| 幂次求和 | 从右到左，每位乘以 26^i | O(n) | O(1) | 了解 |

## 关键提示
1. **不是标准 26 进制**: A 对应 1 而非 0，所以转换时是 `c - 'A' + 1`
2. **从左到右处理**: 类似 Horner 法则，避免计算次幂，result = result * 26 + digit
3. **整数范围**: 最大 "FXSHRXW" = 2^31-1，用 int 即可存储
4. **与 #168 互逆**: 168 题是数字转列名（逆操作），注意进制偏移问题

## 解法详解

### 解法1: 迭代累乘 (Horner 法则)

**思路**: 从左到右扫描字符串，每次将当前结果乘以 26 再加上当前字符对应的数值，类似十进制的 "逐位累加" 方法。

```cpp
class Solution {
public:
    int titleToNumber(string columnTitle) {
        int result = 0;
        for (char c : columnTitle) {
            result = result * 26 + (c - 'A' + 1);
        }
        return result;
    }
};
```

**思考过程**:
- 为什么用 Horner 法则？避免显式计算 26 的幂次，更简洁且不需要知道字符串长度
- "AB" 的计算过程：result=0 -> 0*26+1=1 -> 1*26+2=28

**复杂度**: 时间 O(n), 空间 O(1)

### 解法2: 幂次求和

**思路**: 从右到左，每一位字符乘以对应的 26 的幂次，累加求和。

```cpp
class Solution {
public:
    int titleToNumber(string columnTitle) {
        int result = 0;
        long base = 1;  // 26^0 = 1
        for (int i = columnTitle.size() - 1; i >= 0; i--) {
            result += (columnTitle[i] - 'A' + 1) * base;
            base *= 26;
        }
        return result;
    }
};
```

**思考过程**:
- 从右到左更直观理解每一位的"权重"
- 需要维护一个 base 变量，代码略长于解法1

**复杂度**: 时间 O(n), 空间 O(1)

## 易错点
- ✗ `c - 'A'` (A 变成 0，但 A 应该是 1)
- ✓ `c - 'A' + 1` (A=1, B=2, ..., Z=26)
- ✗ 使用 `result * 26 + c` 忘记减去 'A'
- ✓ 使用 `result * 26 + (c - 'A' + 1)`

## 面试追问
- **Q1**: 如果要做逆操作（数字转列名）怎么做？
  - A: 即 #168 题，注意不是标准 26 进制，每次取余前需要 n-- 将 1-26 映射到 0-25
- **Q2**: 如果字母包含小写怎么处理？
  - A: 先 toupper() 统一转大写，或 `(c & 0xDF) - 'A' + 1`
- **Q3**: 如何验证输入的合法性？
  - A: 检查每个字符是否在 A-Z 范围内，字符串长度是否在 [1, 7] 范围内
