# 932. 漂亮数组

[file://./solution.cpp](file://./solution.cpp)

## 核心思路

构造一个 `[1, n]` 的排列，使得对任意三个下标 `i < k < j`，不存在 `2 * nums[k] == nums[i] + nums[j]`（即没有三元算术级数）。关键洞察：**奇数 + 偶数 = 奇数，永远不是偶数，所以 `2 * nums[k]`（偶数）不可能等于一个奇数加一个偶数**。利用这个性质进行分治构造。

## 思维链

1. **读完题第一反应** → 要构造一个无算术级数的排列。暴力枚举所有排列检查是不现实的（n! 级别）。需要找到构造性的方法。
2. **关键数学性质** → `2 * nums[k] == nums[i] + nums[j]` 意味着 `nums[i] + nums[j]` 是偶数。偶数只能由"奇+奇"或"偶+偶"产生。"奇+偶"产生奇数，不可能等于 `2 * nums[k]`。
3. **分治思路** → 如果把所有奇数放左半边，所有偶数放右半边，那么跨越两半的 `(i, k, j)` 组合中 `nums[i] + nums[j]` 一定是奇数，不可能等于偶数 `2 * nums[k]`，所以跨越两半的三元组自动不违规。
4. **递归保证** → 只需要保证左半边内部和右半边内部也分别满足条件。递归处理即可。
5. **从小到大构建** → 如果已知长度为 `m` 的漂亮数组 `A`，则 `2*A[i] - 1`（映射到奇数）和 `2*A[i]`（映射到偶数）也是漂亮数组。将奇数部分放前、偶数部分放后，拼接起来。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 分治构造 | 奇偶分离 + 递归 | O(n log n) | O(n log n) | 必须掌握 |
| 迭代构造 | 从 [1] 开始逐步扩展 | O(n log n) | O(n) | 更优空间 |

## 关键提示

1. **漂亮数组的仿射不变性**：如果 `A` 是漂亮数组，那么 `k*A[i] + b`（线性变换后）仍然是漂亮数组。因为 `2*(k*a[k]+b) != (k*a[i]+b) + (k*a[j]+b)` 等价于 `2*a[k] != a[i]+a[j]`。
2. **利用仿射不变性做递归**：假设 `beautifulArray(m)` 返回 `[1..m]` 的漂亮排列。对每个元素做 `2*x-1` 映射到 `{1,3,5,...,2m-1}`（奇数），做 `2*x` 映射到 `{2,4,6,...,2m}`（偶数）。两部分各自是漂亮的，合并后跨部分也安全。
3. **递归的基准情况**：`n = 1` 时返回 `[1]`。
4. **处理 n 的奇偶**：奇数部分取 `beautifulArray((n+1)/2)` 的映射，偶数部分取 `beautifulArray(n/2)` 的映射。然后过滤掉超过 n 的数。
5. **记忆化**：递归中 `beautifulArray(k)` 会被重复调用（不同 n 可能递归到相同的 k），用 map 缓存。

## 解法详解

### 解法1: 分治递归构造 — O(n log n) / O(n log n)

**思考过程**: 利用"奇 + 偶 = 奇 != 2k（偶数）"的性质，将问题分为奇数子问题和偶数子问题。

```
构造过程 (n=5):
beautifulArray(5):
  奇数部分: beautifulArray(3) → [1,3,2] → 映射 2x-1 → [1,5,3]
  偶数部分: beautifulArray(2) → [1,2]   → 映射 2x   → [2,4]
  合并: [1,5,3,2,4]

beautifulArray(3):
  奇数部分: beautifulArray(2) → [1,2] → 映射 2x-1 → [1,3]
  偶数部分: beautifulArray(1) → [1]   → 映射 2x   → [2]
  合并: [1,3,2]

beautifulArray(2):
  奇数部分: beautifulArray(1) → [1] → 映射 2x-1 → [1]
  偶数部分: beautifulArray(1) → [1] → 映射 2x   → [2]
  合并: [1,2]

验证 [1,5,3,2,4]:
  任取 i<k<j，检查 2*nums[k] != nums[i]+nums[j]
  (0,1,2): 2*5=10, 1+3=4 ✓
  (0,1,3): 2*5=10, 1+2=3 ✓
  ... 全部满足
```

```cpp
class Solution {
public:
    unordered_map<int, vector<int>> memo;

    vector<int> beautifulArray(int n) {
        if (memo.count(n)) return memo[n];

        vector<int> result;

        if (n == 1) {
            result = {1};
        } else {
            // 奇数部分：beautifulArray((n+1)/2) 映射为 2x-1
            for (int x : beautifulArray((n + 1) / 2)) {
                result.push_back(2 * x - 1);
            }
            // 偶数部分：beautifulArray(n/2) 映射为 2x
            for (int x : beautifulArray(n / 2)) {
                result.push_back(2 * x);
            }
        }

        memo[n] = result;
        return result;
    }
};
```

**关键点**:
- 奇数个数 = `(n+1)/2`，偶数个数 = `n/2`。
- 映射 `2x-1` 产生的奇数范围恰好是 `{1,3,...,2*((n+1)/2)-1}`，最大值不超过 n。
- 映射 `2x` 产生的偶数范围恰好是 `{2,4,...,2*(n/2)}`，最大值不超过 n。

---

### 解法2: 迭代构造 — O(n log n) / O(n)

**自底向上**: 从 `[1]` 开始，每步将当前数组中的元素映射为奇数和偶数，然后合并。

```cpp
class Solution {
public:
    vector<int> beautifulArray(int n) {
        vector<int> result = {1};

        while ((int)result.size() < n) {
            vector<int> next;
            // 先放奇数映射
            for (int x : result) {
                if (2 * x - 1 <= n) {
                    next.push_back(2 * x - 1);
                }
            }
            // 再放偶数映射
            for (int x : result) {
                if (2 * x <= n) {
                    next.push_back(2 * x);
                }
            }
            result = next;
        }

        return result;
    }
};
```

**关键点**:
- 迭代版本不需要记忆化，空间更优。
- 每次迭代数组大小翻倍（最多），所以迭代 O(log n) 次，每次遍历 O(n)，总计 O(n log n)。
- 条件 `2*x-1 <= n` 和 `2*x <= n` 过滤掉超出范围的数。

## 解法对比

|  | 分治递归 | 迭代构造 |
|--|---------|---------|
| 时间 | O(n log n) | O(n log n) |
| 空间 | O(n log n) 递归栈+memo | O(n) |
| 代码量 | 简短 | 略多但无递归 |
| 理解难度 | 需理解递归分解 | 自底向上更直观 |
| 面试推荐 | 递归更容易讲解 | 空间优化加分 |

## 易错点

1. **奇偶个数算错**：
   - `n = 5`：奇数 `(5+1)/2 = 3` 个，偶数 `5/2 = 2` 个。
   - 如果反过来或者都用 `n/2`，构造出的数组元素个数不对或有缺失。

2. **映射公式搞混**：
   - 奇数映射：`2*x - 1`（不是 `2*x + 1`）。当 `x=1` 时得1，`x=2` 时得3。
   - 偶数映射：`2*x`。当 `x=1` 时得2，`x=2` 时得4。

3. **迭代版本忘记过滤越界值**：
   - `2*x-1` 或 `2*x` 可能超过 n，必须加 `<= n` 的检查。
   - 递归版本天然不会越界（因为子问题规模已经正确分配）。

4. **忘记记忆化导致指数爆炸**：
   - 递归版本不加 memo 时，`beautifulArray(n)` 会重复计算相同的子问题。
   - 虽然实际上递归树不大（最多 O(log n) 层），但加 memo 更安全。

## 面试追问

**Q1: 为什么"奇数放前面、偶数放后面"就不会产生算术级数？**
> 如果 `nums[i]` 在奇数部分、`nums[j]` 在偶数部分（或反过来），则 `nums[i] + nums[j]` 是奇数，而 `2 * nums[k]` 一定是偶数，所以不可能相等。跨部分的三元组自动安全。

**Q2: 时间复杂度怎么分析？**
> 每层递归处理的总元素数是 O(n)（所有子问题的大小之和）。递归深度是 O(log n)（每次问题规模大约减半）。所以总时间 O(n log n)。

**Q3: 构造的结果是唯一的吗？**
> 不是。漂亮数组有很多种。比如 n=4 时 `[2,1,4,3]` 和 `[1,3,2,4]` 都是有效的。本方法每次固定"奇数在前、偶数在后"，所以对相同的 n 总是产生相同的结果。

**Q4: 能否用随机化方法？**
> 理论上可以随机排列后验证，但验证一次需要 O(n^2)，且没有保证成功的随机策略。分治构造是确定性的 O(n log n)，远优于随机化。
