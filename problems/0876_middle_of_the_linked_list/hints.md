# 876. 链表的中间结点

## 核心思路

本题本质上在问：**如何在单链表中定位到中点位置？** 难点在于单链表无法像数组那样通过下标直接跳到中间，只能从头往后遍历。

## 思维链

1. **读完题第一反应**：如果是数组，直接 `arr[n/2]` 就行。但链表不知道总长度，也不能随机访问。
2. **最朴素做法**：那就先遍历一遍数链表长度 n，再遍历第二遍走 n/2 步到中间。需要两次遍历。
3. **能不能只遍历一次？** 瓶颈在于"不知道总长度就不知道中点在哪"。有没有办法边走边知道自己到中间了？
4. **快慢指针的灵感**：如果有两个人同时从起点出发，一个走得快（每次走2步），一个走得慢（每次走1步），当快的人到终点时，慢的人刚好在中点！这就是经典的**龟兔赛跑**思想。
5. **验证**：奇数长度 `1→2→3→4→5`，快指针走到5时慢指针在3 ✓；偶数长度 `1→2→3→4→5→6`，快指针走到 null 时慢指针在4（第二个中间节点）✓。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 两次遍历 | 先数长度，再走到中点 | O(n) | O(1) | 能说出即可 |
| 数组存储 | 遍历时存入数组，直接取中间 | O(n) | O(n) | 能说出即可 |
| 快慢指针 | 快走2步慢走1步，快到头时慢在中间 | O(n) | O(1) | ⭐ 必须写出 |

## 关键提示

- **提示1**：链表不能随机访问，但你可以先把长度数出来。数完之后，怎么找到中间？
- **提示2**：如果嫌两次遍历麻烦，想想两个速度不同的指针同时出发会怎样。
- **提示3**：偶数长度有两个中间节点，题目要求返回**第二个**。快慢指针的终止条件要仔细想：是 `fast != null` 还是 `fast->next != null`？
- **提示4**：画图！把奇数和偶数两种情况的指针移动过程画出来，终止条件自然就清楚了。

```
奇数长度 (5个节点):
1 → 2 → 3 → 4 → 5 → NULL

Step0: s=1, f=1
Step1: s=2, f=3
Step2: s=3, f=5       ← f->next == NULL, 停！slow=3 ✓

偶数长度 (6个节点):
1 → 2 → 3 → 4 → 5 → 6 → NULL

Step0: s=1, f=1
Step1: s=2, f=3
Step2: s=3, f=5
Step3: s=4, f=NULL     ← f == NULL, 停！slow=4 ✓ (第二个中间)
```

## 解法详解

### 解法1: 两次遍历 — O(n) / O(1)

**思考过程**：最直接的想法——链表不知道长度？那就先数一遍。知道长度 n 后，中间节点在第 `n/2`（0-indexed）个位置，再走一遍即可。

```cpp
class Solution {
public:
    ListNode* middleNode(ListNode* head) {
        // 第一遍：数长度
        int n = 0;
        ListNode* curr = head;
        while (curr) {
            n++;
            curr = curr->next;
        }
        
        // 第二遍：走到第 n/2 个节点（0-indexed）
        // 奇数: n=5, n/2=2 → 第3个(val=3) ✓
        // 偶数: n=6, n/2=3 → 第4个(val=4) ✓
        curr = head;
        for (int i = 0; i < n / 2; i++) {
            curr = curr->next;
        }
        return curr;
    }
};
```

**关键点**：`n/2` 的整数除法恰好满足"偶数时返回第二个中间节点"的要求。比如 n=6，n/2=3，从 head 走3步到第4个节点。

---

### 解法2: 数组存储 — O(n) / O(n)

**思考过程**：链表访问不方便？那把它变成数组就方便了！遍历一遍存入数组，直接取 `arr[size/2]`。

```cpp
class Solution {
public:
    ListNode* middleNode(ListNode* head) {
        vector<ListNode*> nodes;
        ListNode* curr = head;
        while (curr) {
            nodes.push_back(curr);
            curr = curr->next;
        }
        // 直接随机访问中间位置
        return nodes[nodes.size() / 2];
    }
};
```

**关键点**：用了 O(n) 额外空间，换来了数组的随机访问能力。面试中如果先说这个，面试官一定会追问"能否 O(1) 空间"。

---

### 解法3: 快慢指针 — O(n) / O(1) ⭐ 面试首选

**从解法1优化**：解法1需要两次遍历，本质瓶颈是"不知道走到哪里是一半"。快慢指针的核心洞察：**让快指针走两倍速度，它走完全程时，慢指针刚好走了一半。**

```
快慢指针过程（奇数 5个节点）:
  1 → 2 → 3 → 4 → 5 → NULL
  s    
  f                            初始: slow=1, fast=1

  1 → 2 → 3 → 4 → 5 → NULL
       s    
            f                  Step1: slow=2, fast=3

  1 → 2 → 3 → 4 → 5 → NULL
            s    
                      f        Step2: slow=3, fast=5
                               fast->next==NULL → 停，返回slow(3) ✓

快慢指针过程（偶数 6个节点）:
  1 → 2 → 3 → 4 → 5 → 6 → NULL
  s    
  f                            初始

  1 → 2 → 3 → 4 → 5 → 6 → NULL
       s    
            f                  Step1: slow=2, fast=3

  1 → 2 → 3 → 4 → 5 → 6 → NULL
            s    
                      f        Step2: slow=3, fast=5

  1 → 2 → 3 → 4 → 5 → 6 → NULL
                 s    
                           f→NULL  Step3: slow=4, fast=NULL
                               fast==NULL → 停，返回slow(4) ✓
```

```cpp
class Solution {
public:
    ListNode* middleNode(ListNode* head) {
        ListNode* slow = head;
        ListNode* fast = head;
        // 快指针每次走2步，慢指针每次走1步
        // 循环条件：fast 和 fast->next 都不为空才继续
        // 这保证了 fast 能安全地走两步
        while (fast && fast->next) {
            slow = slow->next;         // 慢指针走1步
            fast = fast->next->next;   // 快指针走2步
        }
        // 快指针到头时，慢指针恰好在中间
        return slow;
    }
};
```

**关键点**：循环条件 `while (fast && fast->next)` 的顺序不能反！必须先检查 `fast != nullptr`，再检查 `fast->next != nullptr`（短路求值）。

## 解法对比

| | 两次遍历 | 数组存储 | 快慢指针 |
|---|---|---|---|
| 遍历次数 | 2次 | 1次 | 1次 |
| 额外空间 | O(1) | O(n) | O(1) |
| 代码量 | 中等 | 简单 | 最简洁 |
| 面试推荐 | 作为铺垫提一下 | 不推荐 | **首选** |

**什么时候选哪个？** 面试中直接说快慢指针。如果面试官想看你的思考过程，可以先提两次遍历（展示你理解问题），再优化到快慢指针。

## 易错点

1. **快慢指针循环条件写反**
   - ✗ `while (fast->next && fast)` — 当 fast 为 NULL 时先访问 `fast->next` 导致空指针崩溃
   - ✓ `while (fast && fast->next)` — 利用短路求值，fast 为 NULL 时不会继续判断

2. **想返回第一个中间节点却用了同样条件**
   - 本题要求返回**第二个**中间节点，`while (fast && fast->next)` 恰好满足
   - 如果要返回第一个中间节点（如链表归并排序中找中点断开），应改为 `while (fast->next && fast->next->next)`

3. **忘记处理单节点链表**
   - 单节点时 `fast = head, fast->next = NULL`，循环不执行，直接返回 head ✓（不需要特判）

## 面试追问

**Q1: 暴力怎么做？瓶颈在哪？**
> 先遍历一遍数长度，再遍历一遍到中间。瓶颈是需要两次遍历，因为链表不支持随机访问。

**Q2: 能否一次遍历且 O(1) 空间？**
> 快慢指针。快指针速度是慢指针的2倍，快指针到终点时慢指针恰好在中间。核心思想是"速度差"映射到"位置差"。

**Q3: 如果要求返回第一个中间节点呢？（链表归并排序中常见）**
> 修改循环条件为 `while (fast->next && fast->next->next)`。这样偶数长度时 fast 停在倒数第二个节点，slow 停在第一个中间节点。

**Q4: 快慢指针还能解决什么问题？**
> - 检测链表是否有环（LeetCode 141）
> - 找环的入口（LeetCode 142）
> - 找链表倒数第 k 个节点（快指针先走 k 步）
> 这些都是利用"两个指针速度/起点不同"来获取链表的结构信息。
