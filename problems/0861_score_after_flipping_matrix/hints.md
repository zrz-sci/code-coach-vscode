# 861. Score After Flipping Matrix

## 核心思路

本题要求通过翻转行和列来最大化二进制矩阵的分数（每行作为二进制数求和）。关键贪心策略：

1. **行翻转优先保证最高位为 1**：在二进制表示中，最高位（最左列）的权重大于所有低位之和。因此首先确保每行的第一列为 1。如果某行的第一列是 0，翻转该行。
2. **列翻转保证多数为 1**：对于每一列（从第二列开始），统计该列 1 的个数。如果 1 的个数少于 0 的个数，翻转该列使多数变为 1。

这两步操作的顺序很重要：先行后列。行翻转只关注第一列，列翻转在行翻转之后执行，此时第一列已经全为 1，不会被列翻转影响。

## 思维链

1. **分析权重**：第 j 列的权重是 2^(n-1-j)。最左列权重最大。
2. **贪心行翻转**：遍历每行，若 grid[i][0] == 0，翻转整行。这保证了每行获得最高位的贡献。
3. **贪心列翻转**：从第 1 列到第 n-1 列，统计该列 1 的个数 count。若 count < m/2（0 比 1 多），翻转该列。
4. **计算结果**：对每一列，贡献 = max(count, m - count) * 2^(n-1-j)。
5. **优化**：可以不实际修改矩阵，而是用数学方式直接计算每列的有效 1 的个数。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 贪心（原地修改） | O(m*n) | O(1) | 直观，实际翻转矩阵 |
| 贪心（数学计算） | O(m*n) | O(1) | 不修改矩阵，直接计算贡献 |

## 关键提示

1. **最高位决定一切**：二进制中第 0 位（最左）的值 2^(n-1) 大于第 1 到第 n-1 位的总和 2^(n-1)-1。所以必须优先保证第 0 列全为 1。
2. **行列翻转顺序无关**：数学上，行翻转和列翻转的效果是可交换的。但分析时"先行后列"更容易理解。
3. **不需要真的翻转**：可以通过判断 grid[i][0] 的值来推断第 i 行是否被翻转，然后用 XOR 计算每个元素的"有效值"。
4. **列翻转的判断标准**：每列中 1 的个数超过半数则保持，否则翻转。

## 解法详解

### 解法一：贪心 - 原地修改

**思路**：

第一步，遍历每行，若首列为 0 则翻转整行。第二步，遍历每列（跳过第 0 列），若 1 的个数少于半数则翻转该列。最后计算每行的二进制值并求和。

**步骤**：
1. 行翻转：对每行 i，若 grid[i][0] == 0，翻转该行所有元素（0->1, 1->0）。
2. 列翻转：对每列 j（j >= 1），统计该列 1 的个数 count。若 count * 2 < m，翻转该列。
3. 计算分数：对每行转为二进制数，求和返回。

### 解法二：贪心 - 数学计算（不修改矩阵）

**思路**：

不实际翻转，而是为每列直接计算贡献。对于第 j 列：
- 先确定每行是否"逻辑翻转"（grid[i][0] == 0 的行视为已翻转）。
- 对第 j 列，元素的"有效值" = grid[i][j] XOR (grid[i][0] == 0)。
- 统计该列有效值为 1 的个数 ones = count。
- 该列贡献 = max(ones, m - ones) * 2^(n-1-j)。

**步骤**：
1. 初始化 result = 0。
2. 第 0 列：贡献固定为 m * 2^(n-1)（所有行首列必为 1）。
3. 第 j 列（j >= 1）：
   - ones = 0
   - 对每行 i：若 grid[i][j] == grid[i][0]，则有效值为 1，ones++。
   - 贡献 = max(ones, m - ones) * (1 << (n-1-j))
4. result += 各列贡献。

**复杂度分析**：
- 时间：O(m * n) 遍历整个矩阵
- 空间：O(1) 不需要额外空间

## 易错点

1. **忘记先翻转行再翻转列**：如果先翻转列，可能破坏行的最高位。
2. **第 0 列也参与列翻转判断**：第 0 列在行翻转后全为 1，不需要也不应该翻转。
3. **数学解法中 XOR 逻辑错误**：grid[i][j] XOR flip[i] 中 flip[i] = (grid[i][0] == 0)，注意不是 grid[i][0] 本身。
4. **二进制权重计算方向**：第 j 列的权重是 2^(n-1-j) 不是 2^j。
5. **矩阵只有一列的边界情况**：只翻转行使第 0 列全为 1 即可，无需列翻转。

## 面试追问

1. **如何证明"先行后列"的贪心策略是最优的？**
   - 第 0 列权重最大，保证其为 1 的收益一定大于改变其他列可能的收益。后续列翻转独立于行翻转结果（因为第 0 列已固定）。

2. **如果限制只能翻转 k 次，怎么处理？**
   - 贪心不再直接适用，需要考虑每次翻转的边际收益。可以用优先队列按收益排序，贪心选取前 k 次。

3. **如果矩阵不是二进制（值为 0-9），类似的翻转问题怎么处理？**
   - 需要更复杂的分析，最高位仍然优先，但每位的翻转收益计算不同。

4. **操作顺序真的不影响结果吗？请严格证明。**
   - 行翻转 R_i 和列翻转 C_j 是对矩阵的线性变换（mod 2），它们可交换：R_i(C_j(M)) = C_j(R_i(M))。因此最终结果只取决于哪些行/列被翻转，与顺序无关。

5. **能否在 O(m + n) 时间内解决？**
   - 不能，因为必须读取整个 m*n 矩阵才能做出决策。
