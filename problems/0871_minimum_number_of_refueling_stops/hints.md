# 871. Minimum Number of Refueling Stops

## 核心思路

本题是经典的贪心 + 最大堆问题。汽车从起点出发前往终点，沿途有加油站，求最少加几次油能到终点。**贪心策略**：每次当油不够到达下一个加油站（或终点）时，从已经路过但没加油的加油站中选油量最大的那个加油。用最大堆（优先队列）维护所有"路过但没加油"的加油站的油量。这保证了每次加油的收益最大，从而加油次数最少。

## 思维链

1. **暴力思路**：每个加油站选或不选 → 2^n 种组合 → n 最大 500，不可行。
2. **DP 思路**：`dp[i]` = 加 i 次油能到达的最远距离 → 可行但 O(n^2)。
3. **贪心直觉**：能不加油就不加，非加不可时选最大的 → 用堆维护候选站。
4. **正确性论证**：选最大油量是最优子结构 → 每次选最大等价于"以最少次数获得最多续航"。
5. **实现**：按位置顺序扫描加油站，油量放入最大堆，油不够时从堆取最大的。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 贪心 + 最大堆 | O(n log n) | O(n) | 最优，直观且高效 |
| 动态规划 | O(n^2) | O(n) | dp[i] = 加 i 次油最远距离 |

## 关键提示

1. **堆中存的是油量**：路过的加油站的 `fuel` 值放入最大堆，位置信息不再需要（因为已经路过了）。
2. **"路过"的定义**：当前油量能到达的所有加油站都算"路过"。
3. **模拟驾驶过程**：按加油站位置顺序推进，当前位置 = 油量能到达的最远处。
4. **终止条件**：当前位置 >= target 时成功；堆为空且油不够时失败。
5. **DP 转移**：`dp[j] = max(dp[j], dp[j-1] + stations[i][1])`，倒序更新避免重复。

## 解法详解

### 解法一：贪心 + 最大堆

**算法步骤**：

1. 将终点看作一个油量为 0 的"虚拟加油站"，加到 stations 末尾。
2. 初始化 `fuel = startFuel`，`refuelCount = 0`，最大堆 `maxHeap` 为空。
3. 遍历每个加油站 `(position, fuelAmount)`：
   - 计算到达该站需要的油量 `needed = position - prevPosition`。
   - 用 `fuel -= needed` 消耗油量。
   - 如果 `fuel < 0`：从堆中取出最大油量补充，直到 `fuel >= 0` 或堆空。
     - 每取一次，`refuelCount++`。
     - 如果堆空仍 `fuel < 0`，返回 -1。
   - 将当前站的 `fuelAmount` 放入最大堆。
   - 更新 `prevPosition = position`。
4. 遍历完成后返回 `refuelCount`。

**为什么贪心正确**：假设最优解在某步选了油量较小的站 A 而非更大的站 B，我们可以将 A 替换为 B，总油量只会增加不会减少，加油次数不变。因此每次选最大的至少不会更差。

### 解法二：动态规划

**状态定义**：`dp[j]` = 恰好加 j 次油时，能到达的最远距离。

**转移**：对于第 i 个加油站 `(pos, fuel)`，若 `dp[j-1] >= pos`（加 j-1 次油能到达该站），则 `dp[j] = max(dp[j], dp[j-1] + fuel)`。

**答案**：最小的 j 使得 `dp[j] >= target`。

**注意**：j 需要倒序更新（类似 0-1 背包），避免同一个站被重复使用。

## 易错点

1. **prevPosition 初始值**：起点位置是 0，不是 `stations[0][0]`。
2. **空 stations 数组**：此时直接判断 `startFuel >= target`。
3. **最大堆用法**：C++ 中 `priority_queue<int>` 默认是最大堆，Python 中 heapq 是最小堆需要取负。
4. **终点处理**：终点不是加油站，但也需要检查能否到达。建议将终点作为哨兵加到数组末尾。
5. **DP 倒序更新**：如果正序更新，同一个加油站可能被加油多次，违反题意。
6. **fuel 和 position 可达 10^9**：注意数据类型，DP 用 long long。

## 面试追问

1. **为什么贪心 + 堆比 DP 更优？** O(n log n) vs O(n^2)，且贪心思路更直观。
2. **如果每个加油站有加油时间成本怎么办？** 变成带权重的选择问题，贪心不再适用，需要 DP。
3. **如果可以往回走？** 问题变为图搜索，需要 BFS/Dijkstra。
4. **如果油箱有容量上限？** 贪心策略需要修改，可能需要 DP 或更复杂的贪心。
5. **如何输出具体在哪些站加油？** 用堆时记录加油站索引，或用 DP 回溯。
