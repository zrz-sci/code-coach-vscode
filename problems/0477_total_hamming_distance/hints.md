# 477. 汉明距离总和

## 核心思路
按位独立统计每一位上1和0的个数，该位的贡献为 ones * zeros，对所有位求和即为总汉明距离。

## 思维链
1. **暴力分析**: 枚举所有数对 O(n^2) 再逐位比较 O(32)，共 O(32n^2)，n=10^4 时约 3*10^9 会超时
2. **关键观察**: 汉明距离是逐位独立的，可以把"所有对"的贡献拆到每一位上分别计算
3. **单位贡献**: 对第 b 位，统计有 c 个数该位为 1，则有 n-c 个数该位为 0，这一位的总贡献 = c * (n-c)
4. **遍历所有位**: 整数最多 30 位（0 <= nums[i] <= 10^9），枚举 bit 0..29
5. **累加求和**: 将所有位的贡献相加即为最终答案

## 解法概览

| 方法 | 时间 | 空间 | 适用场景 | 推荐 |
|------|------|------|----------|------|
| 按位统计 | O(30n) | O(1) | 通用最优解 | ⭐ |
| 暴力枚举所有对 | O(n^2 * 30) | O(1) | 仅小规模 | |

## 关键提示
1. 每一位是独立的，可以分别统计贡献再求和
2. 对于某一位，1 和 0 的配对数 = ones * zeros = c * (n - c)
3. 整数范围 0~10^9 只需考虑 30 位（2^30 > 10^9）
4. 不需要真的计算任何一对数的汉明距离

## 解法详解

### 解法1: 按位统计 ⭐

**思路**: 将问题从"逐对计算"转化为"逐位统计"。对于第 b 位，只有一个数该位为 1、另一个数该位为 0 的配对才会产生贡献 1。如果有 c 个数该位为 1，n-c 个数该位为 0，那么配对数为 c*(n-c)。

```cpp
class Solution {
public:
    int totalHammingDistance(vector<int>& nums) {
        int n = nums.size();
        int result = 0;
        
        // 枚举每一位 (0~29 足够覆盖 10^9)
        for (int bit = 0; bit < 30; ++bit) {
            int ones = 0;
            for (int x : nums) {
                ones += (x >> bit) & 1;
            }
            // 该位的贡献 = 1的个数 * 0的个数
            result += ones * (n - ones);
        }
        
        return result;
    }
};
```

### 解法2: 暴力枚举 (TLE，仅供理解)

**思路**: 直接枚举所有数对，计算每对的汉明距离。利用 XOR 找到不同位，再用 __builtin_popcount 统计。

```cpp
class Solution {
public:
    int totalHammingDistance(vector<int>& nums) {
        int n = nums.size();
        int result = 0;
        
        for (int i = 0; i < n; ++i) {
            for (int j = i + 1; j < n; ++j) {
                result += __builtin_popcount(nums[i] ^ nums[j]);
            }
        }
        
        return result;
    }
};
```

## 易错点
- ✗ 遍历 32 位但 nums[i] 最大只有 10^9，多算不影响正确性但浪费时间 → ✓ 遍历 30 位即可（2^30 > 10^9）
- ✗ 忘记统计的是**所有对**的汉明距离之和，只算了相邻对 → ✓ c*(n-c) 已经自动包含了所有对
- ✗ 用 int 可能溢出（极端情况 30 * 10^4 * 10^4 = 3*10^9 > 2^31） → ✓ 实际最大值远小于此，但用 long long 更安全

## 面试追问
- **Q1**: 这道题和 LC 461 汉明距离有什么关系？ → 461 是两个数的汉明距离，本题是所有对的总和，需要把思路从"逐对"升级到"逐位"
- **Q2**: 如果数组元素范围扩大到 64 位整数，需要改什么？ → 只需把外层循环从 30 改为 64，result 用 long long
- **Q3**: 能否用分治法解决？ → 理论上可以，但按位统计已经是 O(n) 最优解，分治反而更复杂
