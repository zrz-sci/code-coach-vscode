# 1552. 两球之间的磁力

## 核心思路

本题是经典的 **"最大化最小值"** 问题 —— 在所有放球方案中，找到使得**任意两球间最小距离**尽可能大的方案。这类"最大化最小值"或"最小化最大值"的问题，几乎都可以用 **二分答案** 来解决。

## 思维链

1. **读完题第一反应**：要在 n 个篮子中选 m 个放球，使得最近的两个球之间距离最大。暴力想法是枚举所有 C(n, m) 种选法，对每种计算最小间距，取最大值 —— 组合数太大，不可行。

2. **换个角度想**：与其枚举"怎么放球"，不如反过来问 —— **如果我要求任意两球间距离 ≥ d，最多能放多少个球？** 这个问题用贪心就能 O(n) 解决（排序后从左到右贪心放）。

3. **关键发现**：d 越小，能放的球越多；d 越大，能放的球越少。这是一个**单调关系**！所以我们可以对答案 d 进行**二分查找**。

4. **二分什么？** 二分的是"最小磁力"d 的值。搜索空间是 `[1, max_position - min_position]`。对每个 mid，贪心检查能否放下 m 个球。

5. **贪心怎么检查？** 排序后，第一个球放在最左边，然后从左到右扫描，每次找到距离上一个球 ≥ d 的篮子就放一个球，数一数总共能放几个。

6. **二分结束条件？** 当搜索空间收缩到一个值时，就是答案。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力枚举 | 枚举所有 C(n,m) 种选法 | O(C(n,m)·n) | O(m) | 能说出即可 |
| 二分答案 + 贪心 | 二分最小间距，贪心验证 | O(n log n + n log D) | O(1) | ⭐ 必须写出 |

> 其中 D = max(position) - min(position)，即位置的值域范围。

## 关键提示

1. **"最大化最小值" = 二分答案的信号词**。看到这类措辞，立刻想到二分。
2. **二分的对象不是数组下标，而是答案本身**（即最小间距 d）。搜索空间是 `[1, max_pos - min_pos]`。
3. **贪心验证是关键**：排序后贪心放球（每次找到够远的下一个篮子就放），如果能放 ≥ m 个球，说明 d 可行。
4. **为什么贪心是对的？** 排序后尽量靠前放，给后面的球留出更多空间。如果贪心都放不下 m 个球，任何策略都放不下。
5. **注意排序**：原始 position 是无序的，必须先排序！

```
// 二分搜索空间收缩过程 (示例1: position=[1,2,3,4,7], m=3):
// 排序后: [1, 2, 3, 4, 7]
// 搜索空间: [1, 6]  (7-1=6)
//
// Round1: lo=1, hi=6, mid=3
//   贪心: 放1, 跳过2(距离1<3), 跳过3(距离2<3), 放4(距离3≥3), 放7(距离3≥3)
//   放了3个 ≥ m=3 → 可行! lo=3
//
// Round2: lo=3, hi=6, mid=4
//   贪心: 放1, 跳过2,3,4(距离<4), 放7(距离6≥4)
//   放了2个 < m=3 → 不可行! hi=3
//
// lo=hi=3 → 答案=3 ✓
```

## 解法详解

### 解法1: 暴力枚举 — O(C(n,m)·n) / O(m)

**思考过程**: 最直觉的想法是枚举所有可能的放球方案。从 n 个篮子中选 m 个，计算每种方案的最小间距，取最大值。

```cpp
class Solution {
public:
    int maxDistance(vector<int>& position, int m) {
        sort(position.begin(), position.end());
        int n = position.size();
        int ans = 0;
        // combo 存储选中的篮子下标
        vector<int> combo;
        
        // 回溯枚举所有 C(n,m) 种选法
        function<void(int)> dfs = [&](int start) {
            if ((int)combo.size() == m) {
                // 计算最小间距
                int minDist = INT_MAX;
                for (int i = 1; i < m; i++) {
                    minDist = min(minDist, position[combo[i]] - position[combo[i-1]]);
                }
                ans = max(ans, minDist);
                return;
            }
            // 剪枝: 剩余篮子不够选
            if (n - start < m - (int)combo.size()) return;
            for (int i = start; i < n; i++) {
                combo.push_back(i);
                dfs(i + 1);
                combo.pop_back();
            }
        };
        
        dfs(0);
        return ans;
    }
};
```

**关键点**: 
- 时间复杂度是组合数级别的，n=10^5 时完全不可行。
- 但它帮我们理解了问题：本质是选 m 个位置使最小间距最大。
- **瓶颈**：枚举所有方案的代价太高。

### 解法2: 二分答案 + 贪心验证 — O(n log n + n log D) / O(1) ⭐ 面试首选

**从解法1优化**: 暴力的瓶颈是枚举所有方案。我们反转思路 —— **不枚举方案，而是二分答案**。对于一个候选答案 d（最小间距），用贪心 O(n) 验证能否放下 m 个球。由于"d 和能放的球数"之间存在单调关系，可以二分 d。

```cpp
class Solution {
public:
    int maxDistance(vector<int>& position, int m) {
        sort(position.begin(), position.end());
        int n = position.size();
        
        // 贪心检查: 最小间距 ≥ d 时，能否放下 m 个球
        // 策略: 排序后从最左边开始，每次找到距离 ≥ d 的下一个篮子就放球
        auto canPlace = [&](int d) -> bool {
            int count = 1;          // 第一个球放在 position[0]
            int lastPos = position[0];
            for (int i = 1; i < n; i++) {
                if (position[i] - lastPos >= d) {
                    count++;
                    lastPos = position[i];
                    if (count >= m) return true;  // 提前退出
                }
            }
            return count >= m;
        };
        
        // 二分答案: 在 [1, max-min] 中找最大的 d 使得 canPlace(d) 为 true
        int lo = 1;
        int hi = position[n-1] - position[0];
        
        while (lo < hi) {
            // 注意: 找最大可行值，用上取整 mid
            int mid = lo + (hi - lo + 1) / 2;
            if (canPlace(mid)) {
                lo = mid;       // mid 可行，答案 ≥ mid，收缩左边界
            } else {
                hi = mid - 1;   // mid 不可行，答案 < mid
            }
        }
        
        return lo;
    }
};
```

**关键点**:

**为什么贪心正确？** 排序后从左到右贪心放球，相当于给后面的球"让出最多的空间"。如果贪心策略都放不下 m 个球，说明最小间距 d 太大，任何放法都不行。反过来，如果贪心能放下，那 d 是可行的（虽然不一定是贪心找到的那种放法是最优的，但至少存在一种放法）。

**为什么 mid 上取整？** 因为我们在找"最大的可行 d"，`lo = mid` 时如果下取整可能导致 `lo` 不变（当 `hi = lo + 1` 时 `mid = lo`），造成死循环。上取整避免了这个问题。

## 解法对比

| | 暴力枚举 | 二分答案 + 贪心 |
|---|---|---|
| 时间 | O(C(n,m)·m) 指数级 | O(n log n + n log D) |
| 空间 | O(m) 递归栈 | O(1) 排序外无额外空间 |
| 适用性 | 仅限小数据 | 可处理 n=10^5 |
| 核心思想 | 枚举方案 | 二分答案 + 贪心验证 |

面试中只需写出解法2。解法1用于口头说明"暴力怎么做、为什么不行"。

## 易错点

1. **忘记排序**：position 数组是无序的，不排序则贪心完全错误。
   - ✗ 直接在原数组上贪心
   - ✓ 先 `sort(position.begin(), position.end())`

2. **二分取 mid 死循环**：找最大可行值时 `lo = mid`，必须上取整。
   - ✗ `int mid = lo + (hi - lo) / 2;` 当 `lo=3, hi=4` 时 `mid=3`，`lo` 不变，死循环
   - ✓ `int mid = lo + (hi - lo + 1) / 2;` 此时 `mid=4`，能正常收缩

3. **搜索空间上界错误**：上界是 `position[n-1] - position[0]`（排序后），不是 `position[n-1]`。
   - ✗ `hi = position[n-1]`
   - ✓ `hi = position[n-1] - position[0]`

4. **贪心里 count 初始值**：第一个球固定放在最左边，所以 count 从 1 开始。
   - ✗ `int count = 0;` 然后从 `i=0` 开始检查
   - ✓ `int count = 1; int lastPos = position[0];` 然后从 `i=1` 开始

## 面试追问

**Q1: 暴力解的复杂度是多少？为什么不可行？**
→ C(n, m) 种方案，n=10^5 时组合数是天文数字。即使 m=2 也有 ~5×10^9 种方案，超时。

**Q2: 为什么可以二分答案？单调性是什么？**
→ 设 f(d) = "最小间距≥d 时能放的最多球数"。d 越大，限制越严，能放的球越少，所以 f(d) 关于 d 单调递减。我们要找最大的 d 使得 f(d) ≥ m。

**Q3: 如果篮子位置不是整数而是实数，怎么处理？**
→ 二分仍然适用，但需要在实数域上二分，循环条件改为 `hi - lo > eps`（如 eps=1e-6），mid = (lo+hi)/2。贪心检查逻辑不变。

**Q4: 如果某些篮子有容量限制（每个篮子最多放 k 个球），怎么修改？**
→ 贪心检查中需要修改：每个篮子放满 k 个后才移动到下一个篮子。但此时同一篮子内的球间距为 0，所以需要重新定义"两球间最小距离"的含义。
