# 1574. 删除最短的子数组使剩余数组有序

## 核心思路

删除一个连续子数组后，剩下的部分由**左前缀**和**右后缀**拼接而成。本质上是：找到最长的非递减前缀和最长的非递减后缀，然后用双指针找到保留最多元素的拼接方式。

## 思维链

1. **读完题第一反应**：删除一个连续子数组，剩余部分非递减。暴力做法是枚举所有可能的子数组 `[i, j]`，检查删除后是否有序 → O(n³)，太慢。

2. **关键观察**：删除中间一段后，剩下的是 `arr[0..i]` + `arr[j..n-1]`。要让拼接结果非递减，需要：
   - `arr[0..i]` 自身非递减
   - `arr[j..n-1]` 自身非递减
   - 拼接处满足 `arr[i] <= arr[j]`

3. **预处理**：从左找最长非递减前缀（到位置 `left`），从右找最长非递减后缀（从位置 `right` 开始）。这两段是"候选保留区域"的极限。

4. **三种基础情况**：
   - 只保留左前缀：删除 `arr[left+1..n-1]`
   - 只保留右后缀：删除 `arr[0..right-1]`
   - 左前缀 + 右后缀拼接：需要找最优的拼接点

5. **双指针优化拼接**：左指针 `i` 从 0 遍历到 `left`，右指针 `j` 从 `right` 开始。对于每个 `i`，找到最小的 `j` 使得 `arr[i] <= arr[j]`。由于两段都是非递减的，`i` 增大时 `j` 只会向右移或不动 → O(n)。

6. **也可以用二分替代双指针**：对于每个 `i`，在后缀 `arr[right..n-1]` 中二分查找第一个 `>= arr[i]` 的位置 → O(n log n)。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力枚举 | 枚举所有删除区间 `[i,j]` | O(n²) | O(1) | 能说出即可 |
| 双指针 | 前缀+后缀+双指针拼接 | O(n) | O(1) | ⭐ 必须写出 |
| 二分查找 | 前缀+后缀+二分找拼接点 | O(n log n) | O(1) | 加分项 |

## 关键提示

1. **先找边界**：从左往右找最长非递减前缀 `left`，从右往左找最长非递减后缀 `right`。如果 `left == n-1`，整个数组已经有序，直接返回 0。

2. **别忘了只保留一侧的情况**：答案初始值应该是 `min(n - left - 1, right)`，分别对应"只保留左前缀"和"只保留右后缀"。

3. **双指针方向**：`i` 从 0 到 `left`，`j` 从 `right` 开始。当 `arr[i] <= arr[j]` 时，删除区间是 `[i+1, j-1]`，长度为 `j - i - 1`。

4. **拼接处的条件**：不是 `arr[i] < arr[j]`，而是 `arr[i] <= arr[j]`（非递减，不是严格递增）。

5. **示意图**：
   ```
   arr = [1, 2, 3, 10, 4, 2, 3, 5]
          ←左前缀→              ←右后缀→
          1  2  3  [10  4  2]  3  5
          left=2                right=6
   
   只保留左前缀: 删除 arr[3..7], 保留 [1,2,3], 删除长度=5
   只保留右后缀: 删除 arr[0..5], 保留 [3,5],   删除长度=6
   拼接 arr[0..2] + arr[6..7]: 删除 arr[3..5], 保留 [1,2,3,3,5], 删除长度=3 ✓
   ```

## 解法详解

### 解法1: 暴力枚举 — O(n²) / O(1)

**思考过程**：最直接的想法是枚举左前缀的右端点 `i` 和右后缀的左端点 `j`，检查 `arr[i] <= arr[j]` 是否成立。但朴素枚举是 O(n²)，对 n=10⁵ 勉强可能超时。

```cpp
class Solution {
public:
    int findLengthOfShortestSubarray(vector<int>& arr) {
        int n = arr.size();
        
        // 找最长非递减前缀
        int left = 0;
        while (left + 1 < n && arr[left] <= arr[left + 1]) left++;
        if (left == n - 1) return 0; // 已经有序
        
        // 找最长非递减后缀
        int right = n - 1;
        while (right - 1 >= 0 && arr[right - 1] <= arr[right]) right--;
        
        // 只保留左前缀 或 只保留右后缀
        int ans = min(n - left - 1, right);
        
        // 枚举拼接：对每个 i，线性扫描 j
        for (int i = 0; i <= left; i++) {
            for (int j = right; j < n; j++) {
                if (arr[i] <= arr[j]) {
                    ans = min(ans, j - i - 1);
                    break; // 后缀有序，第一个满足的 j 就是最优
                }
            }
        }
        return ans;
    }
};
```

**关键点**：对每个 `i`，后缀是有序的，所以找到第一个 `arr[j] >= arr[i]` 就可以 break。但最坏情况仍然是 O(n²)。

### 解法2: 双指针 — O(n) / O(1) ⭐ 面试首选

**从解法1优化**：解法1对每个 `i` 都从 `right` 开始找 `j`，但注意到：当 `i` 增大时，`arr[i]` 变大（前缀非递减），所以满足 `arr[i] <= arr[j]` 的最小 `j` 也只会变大或不变。这就是经典的**双指针不回退**性质。

```
// 双指针过程 (arr = [1,2,3,10,4,2,3,5], left=2, right=6):
//
// i=0, arr[0]=1:  j=6, arr[6]=3 >= 1 ✓  → 删除 [1,5] 长度5
// i=1, arr[1]=2:  j=6, arr[6]=3 >= 2 ✓  → 删除 [2,5] 长度3
// i=2, arr[2]=3:  j=6, arr[6]=3 >= 3 ✓  → 删除 [3,5] 长度3
//
// 最小删除长度 = 3
```

```cpp
class Solution {
public:
    int findLengthOfShortestSubarray(vector<int>& arr) {
        int n = arr.size();
        
        // Step1: 找最长非递减前缀
        int left = 0;
        while (left + 1 < n && arr[left] <= arr[left + 1]) left++;
        if (left == n - 1) return 0;
        
        // Step2: 找最长非递减后缀
        int right = n - 1;
        while (right > 0 && arr[right - 1] <= arr[right]) right--;
        
        // Step3: 只保留一侧的初始答案
        int ans = min(n - left - 1, right);
        
        // Step4: 双指针找最优拼接
        int i = 0, j = right;
        while (i <= left && j < n) {
            if (arr[i] <= arr[j]) {
                // 可以拼接 arr[0..i] + arr[j..n-1]
                // 删除的是 arr[i+1..j-1]，长度 = j - i - 1
                ans = min(ans, j - i - 1);
                i++; // 尝试保留更多左前缀
            } else {
                j++; // arr[i] > arr[j]，j 太小，右移
            }
        }
        
        return ans;
    }
};
```

**关键点**：
- `i` 只前进，`j` 只前进，总共走 O(n) 步
- 当 `arr[i] <= arr[j]` 时，移动 `i` 而不是 `j`，因为我们想尽量多保留左前缀元素
- 当 `arr[i] > arr[j]` 时，必须增大 `j` 让右后缀起点后移

### 解法3: 二分查找 — O(n log n) / O(1)

**思路**：对于每个左前缀端点 `i`，在有序的右后缀 `arr[right..n-1]` 中二分查找第一个 `>= arr[i]` 的位置。

```cpp
class Solution {
public:
    int findLengthOfShortestSubarray(vector<int>& arr) {
        int n = arr.size();
        
        int left = 0;
        while (left + 1 < n && arr[left] <= arr[left + 1]) left++;
        if (left == n - 1) return 0;
        
        int right = n - 1;
        while (right > 0 && arr[right - 1] <= arr[right]) right--;
        
        int ans = min(n - left - 1, right);
        
        // 对每个 i，在 arr[right..n-1] 中二分找第一个 >= arr[i]
        for (int i = 0; i <= left; i++) {
            // lower_bound 在 [right, n) 范围内找 >= arr[i] 的第一个位置
            int j = lower_bound(arr.begin() + right, arr.end(), arr[i]) - arr.begin();
            // 删除 arr[i+1..j-1]，长度 j - i - 1
            ans = min(ans, j - i - 1);
        }
        
        return ans;
    }
};
```

**关键点**：`lower_bound` 在已排序的后缀上是 O(log n)，外层循环 O(n)，总共 O(n log n)。虽然不如双指针的 O(n)，但思路更直接。

## 解法对比

| | 暴力枚举 | 双指针 ⭐ | 二分查找 |
|---|---|---|---|
| 时间 | O(n²) 最坏 | O(n) | O(n log n) |
| 空间 | O(1) | O(1) | O(1) |
| 核心思想 | 枚举所有拼接点 | 利用两段单调性，指针不回退 | 对有序后缀二分查找 |
| 适合场景 | 理解题意 | 面试首选 | 如果一时想不到双指针 |

双指针和二分的核心区别：双指针利用了**两侧同时单调**的性质（i 增大时 j 不减），而二分只利用了**右侧单调**。

## 易错点

1. **`left` 和 `right` 的计算边界**：
   - ✗ `while (left < n && arr[left] <= arr[left + 1])` → 越界！
   - ✓ `while (left + 1 < n && arr[left] <= arr[left + 1])` → `left+1` 先检查

2. **忘记只保留一侧的情况**：
   - ✗ 直接从双指针开始，`ans` 初始化为 `n`
   - ✓ `ans = min(n - left - 1, right)` 先考虑"删掉所有右边"和"删掉所有左边"

3. **删除长度的计算**：
   - ✗ `ans = min(ans, j - i)` → 少减了1
   - ✓ `ans = min(ans, j - i - 1)` → 删除的是 `[i+1, j-1]`，长度 = `j-1-(i+1)+1 = j-i-1`

4. **非递减 vs 严格递增**：
   - ✗ 用 `arr[i] < arr[j]` 判断拼接
   - ✓ 用 `arr[i] <= arr[j]`，题目说"非递减"允许相等

5. **整个数组已经有序的特判**：
   - ✗ 不判断 `left == n - 1` 直接进入双指针 → `right` 计算可能出错
   - ✓ 提前返回 0

## 面试追问

**Q1: 为什么只需要考虑前缀和后缀的拼接？**
因为删除的是一个连续子数组，删除后剩下的就是原数组的一个前缀和一个后缀。而这个前缀和后缀本身必须是非递减的，所以只需考虑最长非递减前缀和最长非递减后缀。

**Q2: 双指针为什么不会漏解？能证明 j 不需要回退吗？**
因为前缀 `arr[0..left]` 是非递减的，当 `i` 从 `i₀` 变到 `i₀+1` 时，`arr[i₀+1] >= arr[i₀]`。如果之前 `arr[i₀] <= arr[j₀]`，现在 `arr[i₀+1]` 更大，需要的 `j` 只会 `>= j₀`。所以 `j` 不需要回退。

**Q3: 如果题目改成"删除最多 k 个不连续的元素"呢？**
这就变成了 LIS（最长递增子序列）的变体。答案 = `n - LIS长度`，其中 LIS 是最长非递减子序列。LIS 可以用 O(n log n) 的二分方法求解，和本题的思路完全不同。

**Q4: 如果要返回具体删除哪个子数组呢？**
在双指针过程中记录取得最小 `ans` 时的 `i` 和 `j`，删除的子数组就是 `arr[i+1..j-1]`。
