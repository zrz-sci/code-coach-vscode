# 905. 按奇偶排序数组 (Sort Array By Parity)

## 核心思路

本题本质上是：**将数组原地分区，偶数在前、奇数在后**。这是经典的**双指针分区**问题，类似于快排的 partition 操作。左指针找奇数，右指针找偶数，交换即可。

## 思维链

1. **读完题的第一反应**：把偶数放前面、奇数放后面，返回任意一种合法排列。最直观的方法：新建两个数组分别收集偶数和奇数，再拼接。但这需要额外 O(n) 空间。

2. **关键观察 -- 这就是 partition**：和快排的 partition 一模一样，只是判断条件从"小于 pivot"变成了"是偶数"。我们可以用双指针原地完成。

3. **双指针策略**：
   - 左指针 `l` 从头开始，找到第一个奇数
   - 右指针 `r` 从尾开始，找到第一个偶数
   - 交换 `nums[l]` 和 `nums[r]`
   - 重复直到 `l >= r`

4. **也可以用单指针**：维护一个"偶数区域的边界" `boundary`。遍历数组，每遇到偶数就和 `boundary` 位置交换，然后 `boundary++`。这和荷兰国旗问题的简化版一致。

5. **STL 一行解**：`std::partition` 本身就是做这件事的。虽然面试中不建议直接调库，但知道这个能展示 C++ 功底。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 双指针对撞 | 左右指针交换奇偶 | O(n) | O(1) | ⭐ 必须写出 |
| 单指针(快慢) | 维护偶数边界，遇偶数交换 | O(n) | O(1) | ⭐ 同样好 |
| 额外数组 | 偶数放前、奇数放后 | O(n) | O(n) | 能说出即可 |
| STL partition | 一行代码 | O(n) | O(1) | 知道加分 |

## 关键提示

1. **判断奇偶用位运算**：`num % 2` 可以写成 `num & 1`，后者更快（避免除法）。偶数 `(num & 1) == 0`，奇数 `(num & 1) == 1`。

2. **原地交换不需要额外空间**：这是面试加分点。如果面试官问"能不能 O(1) 空间？"，双指针法是标准答案。

3. **ASCII 示意图 -- 双指针过程**：
```
nums = [3, 1, 2, 4]
        l           r

Step 1: nums[l]=3 (奇), nums[r]=4 (偶) → 交换
        [4, 1, 2, 3]
           l     r

Step 2: nums[l]=1 (奇), 继续
        nums[r]=2 (偶) → 交换
        [4, 2, 1, 3]
              l  r

Step 3: l < r, nums[l]=1 (奇), nums[r]=1 (same position area)
        l >= r → 结束

结果: [4, 2, 1, 3] ✓ (偶数在前，奇数在后)
```

4. **题目说"返回任意满足条件的数组"**：不要求偶数之间或奇数之间的相对顺序，所以双指针交换不会产生问题。

5. **edge case**：全偶数或全奇数数组 -- 双指针不会做任何交换，直接返回原数组。

## 解法详解

### 解法1: 双指针对撞 -- O(n) / O(1) ⭐ 面试首选

**思考过程**：

核心洞察：**偶数该在左边，奇数该在右边**。如果 `nums[l]` 是奇数且 `nums[r]` 是偶数，它们都在"错误的一侧"，交换即可。

```cpp
class Solution {
public:
    vector<int> sortArrayByParity(vector<int>& nums) {
        int l = 0, r = nums.size() - 1;
        
        while (l < r) {
            // 左指针跳过已经在正确位置的偶数
            while (l < r && (nums[l] & 1) == 0) l++;
            // 右指针跳过已经在正确位置的奇数
            while (l < r && (nums[r] & 1) == 1) r--;
            
            // 此时 nums[l] 是奇数, nums[r] 是偶数
            // 它们都在错误的一侧，交换
            if (l < r) {
                swap(nums[l], nums[r]);
                l++;
                r--;
            }
        }
        
        return nums;
    }
};
```

**关键点**：
- 每次交换后两个指针各前进一步（因为交换后两个位置都确定了）
- 循环不变量：`[0, l)` 全是偶数，`(r, n-1]` 全是奇数
- 时间 O(n)，每个元素最多被访问一次

### 解法2: 快慢指针(单指针) -- O(n) / O(1)

**从另一个角度**：维护一个"偶数区域右边界" `slow`。快指针 `fast` 遍历整个数组，遇到偶数就放到 `slow` 位置。

```cpp
class Solution {
public:
    vector<int> sortArrayByParity(vector<int>& nums) {
        int slow = 0; // 偶数区域的右边界(下一个偶数该放的位置)
        
        for (int fast = 0; fast < (int)nums.size(); fast++) {
            if ((nums[fast] & 1) == 0) {
                // 遇到偶数，放到偶数区域的尾部
                swap(nums[slow], nums[fast]);
                slow++;
            }
        }
        
        return nums;
    }
};
```

**关键点**：
- 循环不变量：`[0, slow)` 全是偶数
- 如果 `slow == fast`，交换等于没交换，不影响正确性
- 这种写法更简洁，也容易扩展到三路分区

### 解法3: 额外数组 -- O(n) / O(n)

**最直观的方法**：分两次遍历，先收集偶数，再收集奇数。

```cpp
class Solution {
public:
    vector<int> sortArrayByParity(vector<int>& nums) {
        vector<int> result;
        result.reserve(nums.size());
        
        // 第一遍: 收集所有偶数
        for (int num : nums) {
            if ((num & 1) == 0) result.push_back(num);
        }
        // 第二遍: 收集所有奇数
        for (int num : nums) {
            if ((num & 1) == 1) result.push_back(num);
        }
        
        return result;
    }
};
```

## 易错点

1. **✗ 双指针内层循环忘记 `l < r` 的保护条件**：
   ```cpp
   // 错误：while ((nums[l] & 1) == 0) l++;  // 可能越界或越过 r
   // 正确：while (l < r && (nums[l] & 1) == 0) l++;
   ```

2. **✗ 用 `% 2` 判断奇偶时对负数出错**：在 C++ 中 `-3 % 2 == -1`，不等于 1。虽然本题约束 `nums[i] >= 0` 不会触发，但面试中如果被问到负数情况，用 `& 1` 更安全。
   **✓ 用 `(num & 1)` 代替 `(num % 2)` 更健壮。**

3. **✗ 交换后忘记移动指针**：双指针法中交换后必须 `l++; r--;`，否则可能死循环。

4. **✗ 返回类型搞错**：函数签名是 `vector<int>& nums`（引用），可以原地修改后返回 `nums`。但如果创建了新数组，要返回新数组而非 `nums`。

## 面试追问

**Q1: 如果要求保持偶数和奇数各自的相对顺序呢？（稳定分区）**
→ 双指针交换法不稳定（会改变相对顺序）。需要使用**稳定分区算法**：(1) 额外 O(n) 空间，分两遍收集（解法3）；(2) 用 `std::stable_partition` (O(n) 时间 + O(n) 或 O(n log n) 空间)；(3) 原地稳定分区需要 O(n log n) 时间，类似归并排序的变种。

**Q2: 如果数组有三种元素（偶数/3 的倍数/其他），要按此顺序排列？**
→ 这就是**荷兰国旗问题** (Dutch National Flag)。使用三路分区：维护三个指针 low, mid, high。本质上是解法2 快慢指针的扩展版。

**Q3: 这和快排的 partition 有什么关系？**
→ 快排的 partition 是"小于 pivot 的放左边，大于的放右边"。本题是"偶数放左边，奇数放右边"。数据结构和操作完全一样，只是判断条件不同。掌握本题就掌握了 partition 的核心。
