# 711. Number of Distinct Islands II / 不同岛屿的数量 II

## 核心思路

本题是经典岛屿问题的升级版。不仅要找出所有岛屿，还要在考虑**旋转（90/180/270度）和翻转（水平/垂直）**后判断形状是否相同。两个岛屿如果经过任意旋转/翻转后形状一致，就视为同一个岛屿。

核心思路：对每个岛屿提取坐标集合，然后生成该形状在所有 8 种变换（4 种旋转 x 2 种翻转）下的标准化表示（canonical form）。将标准化后的形状放入 set 中去重，最终 set 的大小就是不同岛屿的数量。

**关键数学**：一个 2D 点 (r, c) 的 8 种对称变换为：
- (r, c), (r, -c), (-r, c), (-r, -c)
- (c, r), (c, -r), (-c, r), (-c, -r)

对每种变换后的坐标集合进行归一化（平移到原点）并排序，取字典序最小的作为 canonical form。

## 思维链

1. **DFS/BFS 提取岛屿**：遍历 grid，对每个未访问的 1 做 DFS/BFS，收集该岛屿所有格子的坐标
2. **生成 8 种变换**：对坐标集合分别应用 8 种变换（旋转 + 翻转）
3. **归一化处理**：每种变换后，将所有坐标平移使最小坐标为 (0, 0)，然后排序
4. **选取 canonical form**：8 种归一化结果中取字典序最小的作为该岛屿的标准表示
5. **去重计数**：用 set 存储所有岛屿的 canonical form，set 大小即为答案

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| DFS + 8变换标准化 | O(m*n * k*log(k)) | O(m*n) | 最清晰的解法 |
| BFS + 8变换标准化 | O(m*n * k*log(k)) | O(m*n) | BFS 替代 DFS |

其中 k 是单个岛屿的最大格子数，m*n 是网格大小。

## 关键提示

1. **8 种变换的来源**：2D 平面上保持距离不变的对称变换（等距变换）共 8 种——4 种旋转 (0/90/180/270) 加上一次镜像翻转后的 4 种旋转。数学上称为二面体群 D4。
2. **归一化的必要性**：变换后坐标可能有负值或偏移，必须平移到 (0,0) 起点才能正确比较。具体做法：找到所有坐标的最小 row 和最小 col，所有坐标减去它们。
3. **排序保证唯一性**：归一化后的坐标集合需要排序，否则遍历顺序不同会导致同一形状有不同表示。
4. **canonical form 的选取**：8 种归一化结果中取字典序最小的，保证同一形状（无论哪种变换）映射到同一个 canonical form。
5. **与 694 题的区别**：694 题只考虑平移，不考虑旋转和翻转，所以只需一种归一化；本题需要 8 种变换。

## 解法详解

### 解法一：DFS + 8 变换标准化

**步骤一：提取岛屿坐标**
- 遍历 grid，对每个值为 1 的未访问格子执行 DFS
- DFS 收集该岛屿所有格子坐标 `vector<pair<int,int>> island`

**步骤二：生成 8 种变换**
对 island 中的每个坐标 (r, c)，生成 8 种变换：
```
(r, c), (r, -c), (-r, c), (-r, -c),
(c, r), (c, -r), (-c, r), (-c, -r)
```

**步骤三：归一化**
对每种变换后的坐标集合：
1. 找 minR = 所有点中最小的 row，minC = 最小的 col
2. 每个点 (r, c) 变为 (r - minR, c - minC)
3. 排序

**步骤四：取 canonical form**
8 种归一化结果中取字典序最小的

**步骤五：去重**
将 canonical form 插入 `set<vector<pair<int,int>>>`，最终 set.size() 就是答案

### 解法二：BFS + 字符串哈希

与解法一类似，但用 BFS 代替 DFS 提取岛屿，并将 canonical form 序列化为字符串，用 unordered_set 去重，哈希可能更快。

## 易错点

1. **只做了 4 种旋转没做翻转**：一共 8 种变换（4 旋转 x 2 翻转状态），缺少翻转会导致某些镜像对称的岛屿被多算。
2. **归一化时只减了 row 没减 col**：必须同时将 row 和 col 都平移到 0 起点。
3. **忘记排序**：归一化后不排序，同一形状的不同 DFS 遍历顺序会产生不同表示。
4. **变换公式写错**：8 种变换是固定的数学公式，容易在符号上犯错。建议列出所有 8 种并逐一验证。
5. **DFS 未标记已访问**：忘记将访问过的格子标记（设为 0 或用 visited 数组），导致死循环或重复计数。
6. **坐标类型混淆**：注意 pair 中 first 是 row、second 是 col，变换时不要搞反。

## 面试追问

1. **Q: 如果只考虑旋转不考虑翻转，变换有几种？**
   A: 4 种（0/90/180/270 度旋转）。此时变换公式只有 (r,c), (-c,r), (-r,-c), (c,-r)。

2. **Q: 时间复杂度中 k*log(k) 是什么？**
   A: k 是单个岛屿的最大格子数。排序每种变换后的坐标集合需要 O(k log k)。

3. **Q: 能否用哈希代替 set 来去重？**
   A: 可以。将 canonical form 序列化为字符串作为哈希 key，用 unordered_set<string> 去重。但字符串拼接有额外开销。

4. **Q: 与 694. Number of Distinct Islands 相比，本题的额外难度在哪？**
   A: 694 只需平移归一化（一种），本题需要 8 种对称变换后取 canonical form，算法复杂度和实现复杂度都更高。

5. **Q: 如果网格非常大（1000x1000），如何优化？**
   A: DFS/BFS 本身是 O(m*n)。瓶颈在于每个岛屿的 8 种变换和排序。可以用哈希代替排序比较，或用更紧凑的形状编码。
