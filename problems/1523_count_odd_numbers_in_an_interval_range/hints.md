# 1523. 在区间范围内统计奇数数目

## 核心思路

数学推导题。求 [low, high] 中奇数个数，不需要遍历——用**前缀计数**思想：`[low, high] 中的奇数个数 = [0, high] 中的奇数个数 - [0, low-1] 中的奇数个数`。其中 [0, n] 中有 `(n+1)/2` 个奇数（整除），所以答案是 `(high+1)/2 - low/2`。

## 思维链

1. **读完题第一反应** → 遍历 [low, high] 计数？low 和 high 可达 10^9，O(n) 遍历绝对超时。必须 O(1) 数学公式。
2. **前缀计数思想** → 类比前缀和：`count(low, high) = count(0, high) - count(0, low-1)`。
3. **[0, n] 中有多少奇数？** → 列举几个例子：
   - [0, 0]: {0} → 0 个奇数 → (0+1)/2 = 0 ✓
   - [0, 1]: {0,1} → 1 个奇数 → (1+1)/2 = 1 ✓
   - [0, 2]: {0,1,2} → 1 个奇数 → (2+1)/2 = 1 ✓
   - [0, 3]: {0,1,2,3} → 2 个奇数 → (3+1)/2 = 2 ✓
   - [0, 4]: {0,1,2,3,4} → 2 个奇数 → (4+1)/2 = 2 ✓
   - 规律: `count(0, n) = (n+1)/2`（整除）
4. **[0, low-1] 中有多少奇数？** → `count(0, low-1) = ((low-1)+1)/2 = low/2`
5. **合并** → `count(low, high) = (high+1)/2 - low/2`

```
示例验证:

例1: low=3, high=7
  (7+1)/2 - 3/2 = 4 - 1 = 3
  验证: [3,5,7] → 3个奇数 ✓

例2: low=8, high=10
  (10+1)/2 - 8/2 = 5 - 4 = 1
  验证: [9] → 1个奇数 ✓

例3: low=0, high=0
  (0+1)/2 - 0/2 = 0 - 0 = 0
  验证: [0] → 0个奇数 ✓

例4: low=1, high=1
  (1+1)/2 - 1/2 = 1 - 0 = 1
  验证: [1] → 1个奇数 ✓

例5: low=0, high=9
  (9+1)/2 - 0/2 = 5 - 0 = 5
  验证: [1,3,5,7,9] → 5个奇数 ✓
```

## 解法概览

| 解法 | 思路 | 时间 | 空间 |
|------|------|------|------|
| 数学公式 | 前缀计数差值 | O(1) | O(1) |
| 分类讨论 | 按 low/high 奇偶分 4 种情况 | O(1) | O(1) |

## 关键提示

1. **提示1 — 不要遍历**: low, high 可达 10^9，必须 O(1) 解决。
2. **提示2 — 前缀计数**: `[low, high] = [0, high] - [0, low-1]`，这和前缀和完全相同的思路。
3. **提示3 — [0,n] 中奇数个数**: 等于 `(n+1)/2`（整除）。直觉：0~n 共 n+1 个数，奇偶各约一半，用整除取舍。
4. **提示4 — 另一种理解**: `(high+1)/2` 实际上是 `ceil(high/2.0)` 的整数写法。而 `low/2` 是 `floor(low/2.0)`。它们的差正好是 [low, high] 中的奇数个数。
5. **提示5 — 分类讨论验证**:
   - low 奇 high 奇: 如 [3,7] → 长度 5，奇数 3 个 = (5+1)/2 = (7-3)/2+1
   - low 奇 high 偶: 如 [3,8] → 奇数 3 个 = (8-3+1)/2
   - low 偶 high 奇: 如 [2,7] → 奇数 3 个 = (7-2+1)/2
   - low 偶 high 偶: 如 [2,8] → 奇数 3 个 = (8-2)/2

## 解法详解

### 解法1: 数学公式 — O(1) / O(1)

```cpp
class Solution {
public:
    int countOdds(int low, int high) {
        // (high+1)/2 = [0, high] 中的奇数个数
        // low/2      = [0, low-1] 中的奇数个数
        return (high + 1) / 2 - low / 2;
    }
};
```

**关键点**:
- 整除运算: C++ 中 `7/2=3`（向零取整），对正整数来说就是下取整。
- `(high+1)/2`: 如果 high=7，结果是 4（0~7 有 4 个奇数: 1,3,5,7）。
- `low/2`: 如果 low=3，结果是 1（0~2 有 1 个奇数: 1）。
- 差值 = 4-1 = 3，即 [3,7] 中有 3 个奇数: 3,5,7。

---

### 解法2: 分类讨论 — O(1) / O(1)

**另一种角度**: 根据 low 和 high 的奇偶性分别讨论。

```cpp
class Solution {
public:
    int countOdds(int low, int high) {
        int len = high - low + 1; // 区间长度
        if (low % 2 == 1 || high % 2 == 1) {
            // low或high至少一个是奇数
            return (len + 1) / 2;
        } else {
            // 都是偶数: 如 [2,8] → 奇数在中间: 3,5,7
            return len / 2;
        }
    }
};
```

**4 种情况的推导**:
```
low=奇, high=奇: [3,7] → 3,4,5,6,7 → 奇数:3,5,7 = 3个 = (5+1)/2
low=奇, high=偶: [3,8] → 3,4,5,6,7,8 → 奇数:3,5,7 = 3个 = (6+1)/2
low=偶, high=奇: [2,7] → 2,3,4,5,6,7 → 奇数:3,5,7 = 3个 = (6+1)/2
low=偶, high=偶: [2,8] → 2,3,4,5,6,7,8 → 奇数:3,5,7 = 3个 = 7/2

可以统一: 只要 low 或 high 是奇数, 结果 = (len+1)/2
          两个都是偶数, 结果 = len/2
```

## 易错点

1. **遍历 [low, high]**:
   - 错误: `for (int i = low; i <= high; i++) if (i%2) cnt++;` → low=0, high=10^9 超时
   - 正确: O(1) 公式

2. **公式记错**:
   - 错误: `(high - low) / 2` → [3,7] 得 2，实际是 3
   - 正确: `(high+1)/2 - low/2`

3. **整除取整方向错误**:
   - 容易搞混上取整和下取整。C++ 对正整数 `a/b` 是下取整。
   - `(high+1)/2` 对 high=7: (7+1)/2 = 4 ✓
   - `(high+1)/2` 对 high=8: (8+1)/2 = 4（下取整）✓

4. **忘记 low=0 的边界**:
   - `low/2` 当 low=0: 0/2 = 0 ✓
   - `(high+1)/2 - low/2` = `(0+1)/2 - 0/2 = 0 - 0 = 0`（[0,0] 中 0 个奇数）✓

## 面试追问

**Q1: 为什么 [0,n] 中奇数个数是 (n+1)/2？**
> [0,n] 共 n+1 个数。奇偶交替排列: 0(偶),1(奇),2(偶),3(奇)...。当 n 为奇数时，最后一个是奇数，共 (n+1)/2 个奇数。当 n 为偶数时，最后一个是偶数，共 n/2 个奇数 = (n+1)/2（整除）。两种情况统一为 (n+1)/2。

**Q2: 如果改成统计偶数呢？**
> [low, high] 中偶数个数 = 总个数 - 奇数个数 = (high - low + 1) - ((high+1)/2 - low/2)。或者直接用对偶公式: 偶数个数 = (high/2 + 1) - ((low+1)/2)，其中 [0,n] 中偶数个数 = n/2 + 1。

**Q3: 如果改成统计 [low, high] 中能被 k 整除的数呢？**
> 推广: `count(low, high, k) = high/k - (low-1)/k`。即 [1, high] 中 k 的倍数个数减去 [1, low-1] 中 k 的倍数个数。

**Q4: 这道题和前缀和有什么关系？**
> 前缀计数思想：`f(a, b) = g(b) - g(a-1)`，其中 g(n) 是前缀函数。前缀和是 g(n)=sum(0..n)，这里 g(n)=(n+1)/2。本质相同。
