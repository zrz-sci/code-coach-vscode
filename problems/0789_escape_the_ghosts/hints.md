# 789. Escape The Ghosts (逃脱阻碍者)

## 核心思路

在无限二维网格上，玩家从原点出发到目标点，鬼怪各自从其起点出发。所有角色每步只能走曼哈顿距离 1。关键洞察：**玩家能逃脱当且仅当所有鬼怪到目标点的曼哈顿距离都严格大于玩家到目标点的曼哈顿距离**。因为如果任何鬼怪到目标点不比玩家远，它可以先在目标点"等"着，无论玩家走什么路线都会被拦截。

## 思维链

1. **简化问题**：玩家最优策略是直奔目标点，最短路径长度 = |tx| + |ty|（曼哈顿距离）。
2. **鬼怪最优策略**：鬼怪的最优策略也是直奔目标点"堵截"。如果鬼怪不去目标点而是去中间拦截，那么它到目标点的距离只会更远，玩家可以绕过。
3. **核心证明**：假设某鬼怪到目标的曼哈顿距离 <= 玩家到目标的曼哈顿距离，那么鬼怪一定能在目标点"等着"玩家。玩家无论绕多远，鬼怪都已经先到或同时到。
4. **反之**：如果所有鬼怪到目标的距离都严格大于玩家，玩家直奔目标就安全了——鬼怪追不上。
5. **为什么不需要考虑中途拦截**：鬼怪如果去中途拦截，它消耗的步数 >= 到拦截点的曼哈顿距离。但此时它不在目标点，玩家可以绕路。而绕路后鬼怪如果再追目标点，已经浪费了步数，不可能比直接去目标点更优。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 曼哈顿距离比较 | O(G) | O(1) | 最优解，一次遍历 |

其中 G 为鬼怪数量。本题本质是数学证明题，代码极简。

## 关键提示

1. **曼哈顿距离公式**：`dist(a, b) = |a.x - b.x| + |a.y - b.y|`。
2. **玩家到目标的距离**：`|tx| + |ty|`（从原点出发）。
3. **鬼怪到目标的距离**：`|gx - tx| + |gy - ty|`。
4. **判定条件**：对所有鬼怪 i，`ghost_dist[i] > player_dist` 则能逃脱。**注意是严格大于**，等于也算被抓。
5. **不需要模拟**：这道题的核心是数学推理，不需要 BFS/DFS/模拟。
6. **为什么鬼怪最优策略一定是去目标点**：这是该题的核心数学证明。鬼怪去拦截中间路径不可能比直接去目标点更优。

## 解法详解

### 解法一：曼哈顿距离比较（唯一最优解）

**核心证明**：

设玩家位于 (0,0)，目标 (tx, ty)，某鬼怪位于 (gx, gy)。

- 玩家最短到目标: `d_player = |tx| + |ty|`
- 鬼怪最短到目标: `d_ghost = |gx-tx| + |gy-ty|`

**引理**：鬼怪能抓住玩家 <==> `d_ghost <= d_player`。

*充分性*：若 `d_ghost <= d_player`，鬼怪直接去目标等着。鬼怪到达需 d_ghost 步，玩家到达至少 d_player 步。鬼怪先到或同时到，玩家必被抓。

*必要性*：若 `d_ghost > d_player`，玩家直线走目标点。任何从鬼怪到玩家路径上某点的距离 + 从该点到目标的距离 >= 鬼怪到目标的距离 > 玩家到目标的距离。所以鬼怪不可能既拦截又赶回目标，玩家安全。

**算法**：遍历所有鬼怪，比较曼哈顿距离即可。

**复杂度**：O(G) 时间，O(1) 空间。

## 易错点

1. **等于也是被抓**：题目说"同时到达也不算逃脱"。所以判断条件是 **严格大于**，不是 >=。
2. **忘记绝对值**：坐标可以是负数，计算曼哈顿距离时必须取绝对值。
3. **误以为需要模拟或 BFS**：直觉上可能想模拟游戏过程，但这是不必要的。数学证明直接给出结论。
4. **误以为鬼怪会去拦截中途路径**：鬼怪的最优策略是去目标点等待。中途拦截只会浪费步数。
5. **忽略多个鬼怪的情况**：需要检查所有鬼怪，只要有一个鬼怪 `d_ghost <= d_player` 就返回 false。

## 面试追问

1. **Q: 为什么鬼怪不可能在中途拦截得更好？** A: 鬼怪去拦截中途某点 P，假设成功。但玩家是自由选择路线的——玩家可以不经过 P。玩家只要能保证"直奔目标"时没人挡路就行。鬼怪如果不在目标点等着，玩家就有机会绕过并先到目标。
2. **Q: 如果鬼怪不能穿墙（有障碍物）呢？** A: 此时需要 BFS 计算实际最短路径，曼哈顿距离不再适用。
3. **Q: 如果有多个目标点呢？** A: 变成博弈搜索问题。玩家选择去哪个目标，鬼怪选择去哪里拦截。需要枚举所有目标点，对每个目标检查是否有鬼怪能先到。
4. **Q: 如果同时到达算逃脱成功呢？** A: 只需把条件改成 `d_ghost >= d_player` 即可，严格改为非严格。
5. **Q: 这个结论在三维空间还成立吗？** A: 成立。曼哈顿距离推广到三维即 `|dx| + |dy| + |dz|`，同样的证明逻辑适用。
