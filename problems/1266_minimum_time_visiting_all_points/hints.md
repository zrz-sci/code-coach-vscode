# 1266. 访问所有点的最小时间

## 核心思路

本质上在问：在可以走对角线的网格上，两点之间的最短距离是什么？答案是**切比雪夫距离**（Chebyshev Distance），即 `max(|dx|, |dy|)`。

## 思维链

1. **读完题第一反应**：必须按顺序访问点，所以路径是固定的——从第1个到第2个，再到第3个……总时间 = 每对相邻点之间所需时间之和。问题简化为：给定两个点，最少需要几秒？

2. **两点之间怎么走最快？** 假设从 `(x1, y1)` 到 `(x2, y2)`，水平距离 `dx = |x2-x1|`，垂直距离 `dy = |y2-y1|`。如果只能走水平/垂直，需要 `dx + dy` 步。但我们还能走对角线！

3. **对角线的妙处**：走一步对角线，同时消耗 1 个水平距离和 1 个垂直距离。所以应该**尽量多走对角线**。能走多少步对角线？`min(dx, dy)` 步。

4. **走完对角线后**：还剩 `|dx - dy|` 的纯水平或纯垂直距离要走。总步数 = `min(dx, dy) + |dx - dy|` = `max(dx, dy)`。这就是**切比雪夫距离**。

5. **汇总答案**：遍历相邻点对，累加每对的切比雪夫距离即可。

6. **验证**：`[1,1] → [3,4]`，dx=2, dy=3，max=3 ✓；`[3,4] → [-1,0]`，dx=4, dy=4，max=4 ✓；总计 7 ✓。

## 解法概览

| 切比雪夫距离 | 每对相邻点取 max(\|dx\|, \|dy\|) 求和 | O(n) | O(1) | ⭐ 必须写出 |

> 这道题只有一种核心解法，关键是**推导出两点间最短时间 = max(|dx|, |dy|)**。

## 关键提示

1. **分解问题**：不要一次性想 n 个点，先想清楚"两个点之间最少要多久"，然后把相邻点对的时间加起来。

2. **对角线可以同时消耗两个方向的距离**：这是比曼哈顿距离更快的关键。想象一下，如果 dx=3, dy=5，先对角走 3 步到达 (x2, y1+3)，然后直走 2 步。

3. **数学化简**：`min(dx, dy) + |dx - dy|` 化简后就是 `max(dx, dy)`，这个公式叫**切比雪夫距离**。

4. **示意图**：
```
从 (1,1) 到 (3,4):
    
  y=4  . . . B        B = 目标 (3,4)
  y=3  . . ↗ .        
  y=2  . ↗ . .        先对角走 2 步
  y=1  A . . .        再垂直走 1 步
       1 2 3 4        总共 max(2,3) = 3 步
       
       A = 起点 (1,1)
       路径: (1,1)→(2,2)→(3,3)→(3,4)
```

## 解法详解

### 解法1: 切比雪夫距离 — O(n) / O(1) ⭐ 面试首选

**思考过程**：

从 A 到 B，水平差 `dx`，垂直差 `dy`。对角走能同时缩减两个方向的距离，所以先对角走 `min(dx, dy)` 步，把较短的那个方向走完。剩下的 `|dx - dy|` 只能水平或垂直走。

总步数 = `min(dx, dy) + |dx - dy|` = `max(dx, dy)`。

```cpp
class Solution {
public:
    int minTimeToVisitAllPoints(vector<vector<int>>& points) {
        int totalTime = 0;
        for (int i = 1; i < points.size(); i++) {
            int dx = abs(points[i][0] - points[i - 1][0]);
            int dy = abs(points[i][1] - points[i - 1][1]);
            // 切比雪夫距离：对角走 min(dx,dy) 步 + 直走 |dx-dy| 步 = max(dx,dy)
            totalTime += max(dx, dy);
        }
        return totalTime;
    }
};
```

**关键点**：
- 别忘了取绝对值，坐标可以是负数。
- 循环从 `i = 1` 开始，每次看 `points[i]` 和 `points[i-1]`。

## 解法对比

这道题只有一个解法核心，复杂度已经是最优的 O(n)。变化只在写法上：
- 可以用 `min(dx,dy) + abs(dx-dy)` 表达（更直观地展示"对角+直走"）
- 也可以直接用 `max(dx,dy)`（更简洁）
- 两者数学等价。

## 易错点

1. **忘记取绝对值**：
   - ✗ `int dx = points[i][0] - points[i-1][0];` → 如果从 (3,4) 到 (-1,0)，dx = -4，max(-4, -4) = -4，答案错误
   - ✓ `int dx = abs(points[i][0] - points[i-1][0]);`

2. **误用曼哈顿距离**：
   - ✗ `totalTime += dx + dy;` → 没有利用对角线，会多算
   - ✓ `totalTime += max(dx, dy);`

3. **只有一个点时**：`points.size() == 1`，循环不会执行，正确返回 0。不需要额外判断。

## 面试追问

**Q1: 为什么两点间最短时间是 max(|dx|, |dy|) 而不是 |dx| + |dy|？**

→ 因为可以走对角线，一步同时消耗水平和垂直各 1 个单位。对角走 min(dx,dy) 步后，剩余 |dx-dy| 步只能直走。总计 min(dx,dy) + |dx-dy| = max(dx,dy)。曼哈顿距离 dx+dy 是不能走对角线时的距离。

**Q2: 如果不要求按顺序访问，而是可以任意顺序，怎么求最短总时间？**

→ 这变成了旅行商问题（TSP），是 NP-hard 的。对于小 n 可以用状态压缩 DP：`dp[mask][i]` 表示已访问集合为 mask、当前在点 i 的最短时间，时间 O(2^n · n²)。

**Q3: 切比雪夫距离和曼哈顿距离有什么关系？**

→ 通过坐标变换 `(x, y) → (x+y, x-y)`，切比雪夫距离可以转化为曼哈顿距离，反之亦然。这个技巧在一些高级题中很有用（如 LeetCode 1131）。
