# 144. 二叉树的前序遍历

## 核心思路

前序遍历就是"根→左→右"的顺序访问每个节点。这道题的核心不在于理解前序遍历本身，而在于**能否用迭代（栈）模拟递归调用栈的行为**。

## 思维链

1. **读完题第一反应**：前序遍历 = 先访问根节点，再递归左子树，再递归右子树。用递归写非常直观，几行代码就搞定。
2. **题目 Follow-up 要求迭代**：递归本质上是利用了系统调用栈，那我们能不能自己用一个显式的栈来模拟这个过程？
3. **关键观察**：前序遍历的顺序是"根→左→右"。如果用栈，我们先处理根节点，然后需要先访问左子树再访问右子树。但栈是 LIFO（后进先出），所以要**先压右孩子，再压左孩子**，这样出栈时左孩子先出来。
4. **进阶思考**：还有一种 Morris 遍历，利用线索化（修改树的空指针）实现 O(1) 空间遍历，是面试加分项。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 递归 | 最直觉的 DFS | O(n) | O(h) | 能说出即可 |
| 迭代（显式栈） | 用栈模拟递归 | O(n) | O(h) | ⭐ 必须写出 |
| Morris 遍历 | 线索化实现 O(1) 空间 | O(n) | O(1) | 加分项 |

> h 为树的高度，最坏 h=n（链状树），最好 h=log n（平衡树）

## 关键提示

- **提示1**：递归的三要素是什么？返回值（void，结果用引用传）、终止条件（节点为空）、单层逻辑（先加当前值，再递归左右）。

- **提示2**：迭代版为什么先压右再压左？画一下栈的状态变化你就明白了：
```
示例树:
      1
       \
        2
       /
      3

栈操作过程:
  栈: [1]           → 弹出1, 访问1, 右孩子2入栈, 左孩子null不入
  栈: [2]           → 弹出2, 访问2, 右孩子null不入, 左孩子3入栈
  栈: [3]           → 弹出3, 访问3, 无孩子
  栈: []            → 结束
  结果: [1, 2, 3] ✓
```

- **提示3**：Morris 遍历的核心思想——利用叶子节点的空右指针指回前驱的后继节点，从而不用额外空间就能"回溯"到父节点。

- **提示4**：前序、中序、后序的迭代版本有统一框架吗？有的！前序最简单，中序需要"一路向左入栈"，后序可以用"根右左再反转"的技巧。

## 解法详解

### 解法1: 递归 — O(n) / O(h)

**思考过程**：前序遍历的定义就是递归定义的——先处理根，再处理左子树，再处理右子树。直接翻译成代码即可。

```
决策过程（以示例2为例）:
          1
        /   \
       2     3
      / \     \
     4   5     8
        / \   /
       6   7 9

前序: 根→左→右
访问1 → 进入左子树(2) → 进入左子树(4) → 4无子 → 回到2 → 
进入右子树(5) → 进入左(6) → 回到5 → 进入右(7) → 回到1 → 
进入右子树(3) → 进入右(8) → 进入左(9)

结果: [1, 2, 4, 5, 6, 7, 3, 8, 9]
```

```cpp
class Solution {
public:
    vector<int> preorderTraversal(TreeNode* root) {
        vector<int> result;
        dfs(root, result);
        return result;
    }
    
    void dfs(TreeNode* node, vector<int>& result) {
        if (!node) return;           // 终止条件: 空节点直接返回
        result.push_back(node->val); // 前序: 先访问根
        dfs(node->left, result);     // 再递归左子树
        dfs(node->right, result);    // 最后递归右子树
    }
};
```

**关键点**：递归三要素要明确——返回值（void，通过引用收集结果）、终止条件（node == null）、单层逻辑（加值→左→右）。如果要改成中序遍历，只需把 `push_back` 移到两个递归调用之间。

---

### 解法2: 迭代（显式栈） — O(n) / O(h) ⭐ 面试首选

**从解法1的思考出发**：递归之所以能工作，是因为系统帮我们维护了一个调用栈，记住"从哪回来"。迭代版我们自己用 `stack` 来模拟这个过程。

**核心逻辑**：
1. 将根节点压入栈
2. 每次弹出栈顶节点，访问它
3. **先压右孩子，再压左孩子**（因为栈 LIFO，要让左孩子先出栈）
4. 重复直到栈为空

```
迭代过程（以示例1为例）:
      1
       \
        2
       /
      3

Step1: 栈=[1]
Step2: 弹出1 → result=[1], 压右孩子2, 无左孩子 → 栈=[2]
Step3: 弹出2 → result=[1,2], 无右孩子, 压左孩子3 → 栈=[3]
Step4: 弹出3 → result=[1,2,3], 无孩子 → 栈=[]
结束! result = [1,2,3] ✓

更复杂的例子（示例2）:
          1
        /   \
       2     3
      / \     \
     4   5     8
        / \   /
       6   7 9

Step1: 栈=[1]
Step2: 弹出1 → result=[1], 压右3, 压左2 → 栈=[3,2]
Step3: 弹出2 → result=[1,2], 压右5, 压左4 → 栈=[3,5,4]
Step4: 弹出4 → result=[1,2,4], 无孩子 → 栈=[3,5]
Step5: 弹出5 → result=[1,2,4,5], 压右7, 压左6 → 栈=[3,7,6]
Step6: 弹出6 → result=[1,2,4,5,6] → 栈=[3,7]
Step7: 弹出7 → result=[1,2,4,5,6,7] → 栈=[3]
Step8: 弹出3 → result=[1,2,4,5,6,7,3], 压右8 → 栈=[8]
Step9: 弹出8 → result=[1,2,4,5,6,7,3,8], 压左9 → 栈=[9]
Step10: 弹出9 → result=[1,2,4,5,6,7,3,8,9] → 栈=[]
结束! ✓
```

```cpp
class Solution {
public:
    vector<int> preorderTraversal(TreeNode* root) {
        vector<int> result;
        if (!root) return result;
        
        stack<TreeNode*> stk;
        stk.push(root);
        
        while (!stk.empty()) {
            TreeNode* node = stk.top();
            stk.pop();
            result.push_back(node->val);  // 弹出时立即访问 (前序)
            
            // 先压右再压左，保证左孩子先被弹出处理
            if (node->right) stk.push(node->right);
            if (node->left)  stk.push(node->left);
        }
        
        return result;
    }
};
```

**关键点**：为什么先压右再压左？因为栈是后进先出，我们需要左子树先被处理。如果反过来先压左再压右，出栈顺序变成"根→右→左"，就不是前序了。

### 解法3: Morris 遍历 — O(n) / O(1) 加分项

**动机**：解法1和2的空间都是 O(h)，能否做到 O(1) 空间？Morris 遍历利用树中大量的空指针（null），临时将它们指向需要"回溯"的节点，实现不用栈的遍历。

**核心思想**：
- 如果当前节点没有左子树，直接访问并移到右子树
- 如果有左子树，找到左子树的**最右节点**（即当前节点在中序遍历中的前驱）
  - 如果前驱的右指针为 null → 建立线索：前驱的 right 指向当前节点，**访问当前节点**，然后移到左子树
  - 如果前驱的右指针已指向当前节点 → 说明左子树已遍历完，断开线索，移到右子树

```
Morris 前序遍历过程（简化示例）:
      1
     / \
    2   3
   / \
  4   5

当前=1: 左子树存在, 找左子树最右节点=5
  5->right=null → 建立线索 5->right=1, 访问1, 移到左(2)
当前=2: 左子树存在, 找左子树最右节点=4
  4->right=null → 建立线索 4->right=2, 访问2, 移到左(4)
当前=4: 无左子树 → 访问4, 移到右(2, 通过线索回来)
当前=2: 左子树存在, 找最右节点=4
  4->right=2(自己!) → 断开线索, 不访问, 移到右(5)
当前=5: 无左子树 → 访问5, 移到右(1, 通过线索回来)
当前=1: 左子树存在, 找最右节点=5
  5->right=1(自己!) → 断开线索, 不访问, 移到右(3)
当前=3: 无左子树 → 访问3, 移到右(null)
结束! result = [1, 2, 4, 5, 3] ✓
```

```cpp
class Solution {
public:
    vector<int> preorderTraversal(TreeNode* root) {
        vector<int> result;
        TreeNode* curr = root;
        
        while (curr) {
            if (!curr->left) {
                // 无左子树: 直接访问当前节点，移到右子树
                result.push_back(curr->val);
                curr = curr->right;
            } else {
                // 找左子树的最右节点 (中序前驱)
                TreeNode* predecessor = curr->left;
                while (predecessor->right && predecessor->right != curr) {
                    predecessor = predecessor->right;
                }
                
                if (!predecessor->right) {
                    // 第一次到达: 建立线索，访问当前节点(前序!)，进入左子树
                    predecessor->right = curr;
                    result.push_back(curr->val);  // 前序: 第一次到就访问
                    curr = curr->left;
                } else {
                    // 第二次到达: 左子树已遍历完，断开线索，进入右子树
                    predecessor->right = nullptr;
                    curr = curr->right;
                }
            }
        }
        
        return result;
    }
};
```

**关键点**：Morris 前序和 Morris 中序的唯一区别在于**访问时机**——前序在"第一次到达"时访问（建立线索时），中序在"第二次到达"时访问（断开线索时）。

| | 递归 | 迭代（栈） | Morris |
|------|------|------|------|
| 时间 | O(n) | O(n) | O(n) |
| 空间 | O(h) 调用栈 | O(h) 显式栈 | O(1) |
| 代码难度 | 最简单 | 中等 | 较难 |
| 是否修改树 | 否 | 否 | 临时修改，遍历完恢复 |
| 面试推荐 | 写完递归后面试官会追问迭代 | **面试首选** | 被问到O(1)空间时用 |

**选择建议**：
- 面试先写递归展示理解，然后主动写迭代版展示编码能力
- 如果面试官追问 O(1) 空间，再给 Morris

## 易错点

1. **迭代版压栈顺序搞反**
   - ✗ `先压left再压right` → 出栈顺序变成 根→右→左
   - ✓ `先压right再压left` → 出栈顺序才是 根→左→右

2. **递归版忘记处理空树**
   - ✗ 直接 `result.push_back(root->val)` 不检查 null → 空树崩溃
   - ✓ 递归函数开头 `if (!node) return;`

3. **Morris 遍历访问时机搞混**
   - ✗ 前序遍历在断开线索时访问 → 变成中序遍历了
   - ✓ 前序遍历在**建立线索时**（第一次到达）就访问

4. **Morris 遍历找前驱时死循环**
   - ✗ `while (predecessor->right)` 没有检查 `predecessor->right != curr`
   - ✓ 必须加 `&& predecessor->right != curr`，否则线索建立后会无限循环

## 面试追问

**Q1: 递归的空间复杂度是多少？最坏情况是什么？**
> O(h)，h 是树高。最坏情况是链状树（每个节点只有一个孩子），h = n，空间 O(n)。平衡树 h = log n。

**Q2: 能否用迭代实现？（Follow-up 原题）**
> 用显式栈模拟递归。关键技巧：先压右孩子再压左孩子，利用栈的 LIFO 特性保证左子树先被访问。

**Q3: 能否做到 O(1) 空间？可以修改树结构吗？**
> 可以用 Morris 遍历。利用叶子节点的空 right 指针建立临时线索指回祖先，遍历完后恢复原树结构。时间仍然是 O(n)，因为每条边最多被访问常数次。

**Q4: 前序遍历的迭代模板能否快速改成后序遍历？**
> 可以。前序是"根左右"，如果改压栈顺序变成"根右左"，再将结果反转就得到"左右根"即后序。具体改动：先压左再压右（出栈顺序变成根→右→左），最后 `reverse(result)`。
