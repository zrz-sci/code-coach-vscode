# 43. 字符串相乘

## 核心思路

本题本质上是**模拟竖式乘法**：你在小学数学课上是怎么手算多位数乘法的，代码就怎么写。关键洞察是 `num1[i] * num2[j]` 的结果会贡献到乘积的第 `i+j` 和 `i+j+1` 位上。

## 思维链

1. **读完题第一反应**：不能用 BigInteger 也不能直接转 int，那就只能逐位处理。这和我们手算竖式乘法是一样的道理。

2. **最朴素的做法**：模拟"逐位乘、逐行加"——用 num2 的每一位去乘整个 num1，得到若干中间结果（字符串），再把这些中间结果错位相加。这需要实现"大数加法"和"大数乘单个数字"两个辅助函数。

3. **朴素做法的瓶颈**：每次乘完一位后要做字符串加法，涉及大量字符串操作（拼接、进位），代码复杂且常数大。

4. **能否一步到位？** 观察竖式乘法的本质：`num1[i] * num2[j]` 产生的乘积，影响的是最终结果的特定位置。如果我们用一个**整数数组**先存所有位的累加值，最后再统一处理进位，就不需要中间的字符串加法了。

5. **位置映射的关键规律**：num1 长 m、num2 长 n，乘积最多 m+n 位。`num1[i] * num2[j]` 的结果（最多两位数）贡献到 `result[i+j]`（高位/十位）和 `result[i+j+1]`（低位/个位）。

6. **最终步骤**：遍历结果数组，跳过前导零，拼成字符串返回。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 逐行累加 | 模拟竖式：逐位乘+字符串加法 | O(m·n + m·(m+n)) | O(m+n) | 能说出即可 |
| 乘积数组 | 用数组存各位累加值，最后统一进位 | O(m·n) | O(m+n) | ⭐ 必须写出 |

## 关键提示

- **提示1**：两个数相乘，一个 m 位、一个 n 位，乘积最多有多少位？想想 99×99 = 9801（2位×2位 = 4位）。
- **提示2**：手算竖式时，你把 num2 的个位乘 num1 写在第一行，十位乘 num1 写在第二行（左移一位）。程序里"左移一位"对应什么操作？
- **提示3**：`num1[i] * num2[j]` 的乘积是个 ≤81 的两位数。这个两位数的十位和个位分别放到结果的哪个位置？试试 i=1, j=2 的例子。
- **提示4**：先别急着处理进位！让数组每个位置累加到很大的数都没关系，最后从低位到高位统一进位即可。
- **提示5**：别忘了特殊情况——如果其中一个数是 "0"，结果就是 "0"。

```
// 竖式乘法示意 (123 × 456):
//
//         1  2  3      ← num1 (索引 i: 0,1,2)
//      ×  4  5  6      ← num2 (索引 j: 0,1,2)
//      ---------
//         7  3  8      ← 123 × 6  (num2[2])
//      6  1  5  0      ← 123 × 5  (num2[1]), 左移1位
//   4  9  2  0  0      ← 123 × 4  (num2[0]), 左移2位
//   ----------------
//   5  6  0  8  8
//
// 关键规律: num1[i] × num2[j] 的结果落在 result[i+j] 和 result[i+j+1]
```

## 解法详解

### 解法1: 逐行累加（模拟竖式加法版）— O(m·n·(m+n)) / O(m+n)

**思考过程**: 最直觉的方式——完全照搬手算流程。用 num2 的每一位乘以整个 num1，得到一个中间结果字符串；然后把所有中间结果用大数加法累加起来。

```cpp
class Solution {
public:
    string multiply(string num1, string num2) {
        if (num1 == "0" || num2 == "0") return "0";
        
        string result = "0";
        int m = num1.size(), n = num2.size();
        
        // 用 num2 的每一位（从低位到高位）乘以整个 num1
        for (int j = n - 1; j >= 0; j--) {
            string cur;
            int carry = 0;
            
            // 末尾补 (n-1-j) 个零，模拟"左移"
            for (int k = 0; k < n - 1 - j; k++) {
                cur += '0';
            }
            
            int d2 = num2[j] - '0';
            // num1 的每一位与 num2[j] 相乘
            for (int i = m - 1; i >= 0; i--) {
                int d1 = num1[i] - '0';
                int prod = d1 * d2 + carry;
                cur += (char)('0' + prod % 10);
                carry = prod / 10;
            }
            if (carry) cur += (char)('0' + carry);
            
            // cur 是反序的，反转回来
            reverse(cur.begin(), cur.end());
            
            // 大数加法：result = result + cur
            result = addStrings(result, cur);
        }
        return result;
    }
    
private:
    string addStrings(const string& a, const string& b) {
        string res;
        int i = a.size() - 1, j = b.size() - 1, carry = 0;
        while (i >= 0 || j >= 0 || carry) {
            int sum = carry;
            if (i >= 0) sum += a[i--] - '0';
            if (j >= 0) sum += b[j--] - '0';
            res += (char)('0' + sum % 10);
            carry = sum / 10;
        }
        reverse(res.begin(), res.end());
        return res;
    }
};
```

**关键点**: 这种方法的缺点是反复做字符串加法，每次加法本身是 O(m+n) 的，做了 n 次，而且字符串的反转和拼接操作常数很大。面试中通常不会用这种，但它最直觉，有助于理解问题。

---

### 解法2: 乘积数组（位置映射）— O(m·n) / O(m+n) ⭐ 面试首选

**从解法1优化**: 解法1的瓶颈在于每乘完一行就要做一次大数加法。核心观察：我们完全不需要中间字符串，直接用一个整数数组记录每一位的累加值，最后统一处理进位。

**位置映射规律**：
```
//  num1:   索引 i (从左到右 0..m-1)
//  num2:   索引 j (从左到右 0..n-1)
//  result: 长度 m+n，索引 0..m+n-1
//
//  num1[i] × num2[j] 的乘积（最多两位数 p1p2）：
//     高位 p1 累加到 result[i+j]
//     低位 p2 累加到 result[i+j+1]
//
//  例: 123 × 456, i=0(数字1), j=0(数字4)
//      1×4=4, 高位0→result[0], 低位4→result[1]
//
//  例: 123 × 456, i=2(数字3), j=2(数字6)
//      3×6=18, 高位1→result[4], 低位8→result[5]
//
//  result 数组 (m+n=6 位):
//  索引:  [0]  [1]  [2]  [3]  [4]  [5]
//  初始:   0    0    0    0    0    0
//
//  累加所有 num1[i]*num2[j] 后:
//  索引:  [0]  [1]  [2]  [3]  [4]  [5]
//  值:     0    4   13   28   27   18
//
//  从右到左统一进位:
//  [5]: 18 → 写8进1  →  [0] [4] [13] [28] [28] [8]
//  [4]: 28 → 写8进2  →  [0] [4] [13] [30] [8]  [8]
//  [3]: 30 → 写0进3  →  [0] [4] [16] [0]  [8]  [8]
//  [2]: 16 → 写6进1  →  [0] [5] [6]  [0]  [8]  [8]
//  [1]: 5  → 写5进0  →  [0] [5] [6]  [0]  [8]  [8]
//  [0]: 0  → 前导零
//  结果: "56088" ✓
```

```cpp
class Solution {
public:
    string multiply(string num1, string num2) {
        int m = num1.size(), n = num2.size();
        // 乘积最多 m+n 位（如 99×99=9801, 2位×2位=4位）
        vector<int> result(m + n, 0);
        
        // 从低位到高位逐位相乘，累加到对应位置
        for (int i = m - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                int mul = (num1[i] - '0') * (num2[j] - '0');
                
                // 核心：i+j 是高位，i+j+1 是低位
                int p1 = i + j;     // 高位（十位）位置
                int p2 = i + j + 1; // 低位（个位）位置
                
                // 加上之前该位置已有的累加值
                int sum = mul + result[p2];
                
                result[p2] = sum % 10;  // 当前位保留个位
                result[p1] += sum / 10;  // 进位加到高位
            }
        }
        
        // 拼接结果，跳过前导零
        string str;
        for (int digit : result) {
            // 跳过前导零（但如果 str 已经有内容了就不跳）
            if (str.empty() && digit == 0) continue;
            str += (char)('0' + digit);
        }
        
        // 如果结果为空说明全是零
        return str.empty() ? "0" : str;
    }
};
```

**关键点**: 
- `sum = mul + result[p2]` 这一步很巧妙：不是只放 mul 的值，还要加上该位置已有的累加值（来自之前其他 i,j 对的贡献）。这样进位也一起处理了。
- 这种方法的进位是**局部处理**的：每次乘完一对就立即向高位进位。由于单次乘积最大 9×9=81，加上已有值和之前进位也不会很大，不会溢出 int。

## 解法对比

| | 解法1 逐行累加 | 解法2 乘积数组 |
|---|---|---|
| 核心思路 | 每行单独计算再字符串加法 | 直接累加到位置数组 |
| 时间 | O(m·n·(m+n)) 多次加法 | O(m·n) 纯计算 |
| 空间 | O(m+n) 中间字符串 | O(m+n) 数组 |
| 代码复杂度 | 高（需要 addStrings 辅助） | 低（核心只有双层循环） |
| 面试推荐 | 作为思路说明 | ⭐ 首选 |

## 易错点

1. **忘记处理 "0" 乘以任何数的情况**
   - ✗ 不做特判，对 "0" × "123" 输出空串或 "000"
   - ✓ 用 `str.empty() ? "0" : str` 兜底，或者一开始判断 `num1 == "0" || num2 == "0"` 直接返回

2. **位置映射搞反 p1 和 p2**
   - ✗ `p1 = i + j + 1; p2 = i + j;`（高低位反了）
   - ✓ `p1 = i + j`（高位），`p2 = i + j + 1`（低位）
   - 记忆方法：i 和 j 都是 0 时，乘积的高位在最左边 → `i+j = 0` 是高位

3. **累加时漏掉已有值**
   - ✗ `int sum = mul;`（忽略了 result[p2] 已有的累加值）
   - ✓ `int sum = mul + result[p2];`（必须加上之前累加到这个位置的值）

4. **前导零处理不当**
   - ✗ 直接把 result 数组所有位转成字符串 → 输出 "056088"
   - ✓ 遍历时跳过前导零：`if (str.empty() && digit == 0) continue;`

## 面试追问

**Q1: 为什么 m 位数乘 n 位数的结果最多 m+n 位？**
→ 最大的 m 位数是 10^m - 1，最大的 n 位数是 10^n - 1。它们的乘积 < 10^(m+n)，所以最多 m+n 位。实际上最小也是 m+n-1 位（比如 10×10=100，2位×2位=3位）。

**Q2: 能否不用数组，直接在字符串上操作？**
→ 可以，但字符串每个字符只能存 0-9，每次乘完必须立即处理进位，代码更复杂。数组可以让每个位置暂时存大于 9 的值，最后统一处理，更清晰。

**Q3: 如果要实现大数加法（LeetCode 415），和本题有什么关系？**
→ 大数加法是本题解法1的子模块。面试官可能先问加法热身，再问乘法。加法就是双指针从末尾对齐，逐位加+进位。

**Q4: 如果要求更快的大数乘法呢？**
→ Karatsuba 算法可以做到 O(n^1.585)，FFT/NTT 可以做到 O(n log n)。但面试中不会要求实现，了解即可。
