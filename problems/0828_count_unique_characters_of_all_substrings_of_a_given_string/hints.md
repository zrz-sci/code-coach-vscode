# 828. 统计所有子串中唯一字符的数量 (Count Unique Characters of All Substrings)

## 核心思路

本题本质上是：**对每个字符，计算它在多少个子串中是"唯一的"（只出现一次）**。通过贡献法，将"遍历所有子串"转化为"遍历每个字符的贡献区间"，从 O(n^2) 暴力降为 O(n)。

## 思维链

1. **读完题的第一反应**：暴力枚举所有子串，对每个子串数唯一字符数。O(n^2) 个子串，每个统计 O(n)，总共 O(n^3)。显然太慢。

2. **换个角度 — 贡献法**：不去"对每个子串数字符"，而是"对每个字符，数它对多少个子串有贡献（贡献 1）"。一个字符对子串的贡献 = 它在该子串中恰好出现一次。

3. **关键观察**：字符 `s[i]` 在子串 `s[l..r]` 中唯一，当且仅当 `l..r` 包含 `s[i]`，但不包含 `s[i]` 的前一个相同字符和后一个相同字符。

4. **定义前驱和后继**：对于位置 i，设 `prev[i]` = 字符 `s[i]` 上一次出现的位置（没有则为 -1），`next[i]` = 字符 `s[i]` 下一次出现的位置（没有则为 n）。

5. **贡献计算**：`s[i]` 是唯一的子串数 = 左边可选起点数 * 右边可选终点数 = `(i - prev[i]) * (next[i] - i)`。

6. **总答案** = 所有位置 i 的贡献之和。时间 O(n)，空间 O(n)。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 贡献法 — 记录前驱/后继 | 对每个字符算 (i-prev) * (next-i) | O(n) | O(n) | ⭐ 必须写出 |
| 贡献法 — 只记前两次出现 | 遍历时只维护每个字符最近两次位置 | O(n) | O(26) | 能说出即可 |

## 关键提示

1. **贡献法是核心技巧**：将"枚举子串再数"转化为"枚举元素再算贡献"。适用于所有"对所有子串求某种统计量之和"的题目。

2. **前驱/后继的含义**：
   - `prev[i]`：在位置 i 左侧，与 `s[i]` 相同的最近位置。如果没有，设为 -1。
   - `next[i]`：在位置 i 右侧，与 `s[i]` 相同的最近位置。如果没有，设为 n。

3. **乘法原理**：左边起点从 `prev[i]+1` 到 `i` 共 `i - prev[i]` 种选法，右边终点从 `i` 到 `next[i]-1` 共 `next[i] - i` 种选法。两者独立，所以相乘。

4. **ASCII 示意图 — "ABA" 的贡献计算**：
```
s = "A B A"
     0 1 2

字符 A@0: prev=-1, next=2 → 贡献 = (0-(-1)) * (2-0) = 1*2 = 2
字符 B@1: prev=-1, next=3 → 贡献 = (1-(-1)) * (3-1) = 2*2 = 4
字符 A@2: prev=0,  next=3 → 贡献 = (2-0) * (3-2) = 2*1 = 2

总和 = 2 + 4 + 2 = 8 ✓

验证: 子串 "A"(0)→1, "B"→1, "A"(2)→1, "AB"→2, "BA"→2, "ABA"→1
      总和 = 1+1+1+2+2+1 = 8 ✓
```

5. **只有 26 个大写字母**：可以用长度 26 的数组代替 HashMap 来记录每个字母的出现位置。

## 解法详解

### 解法1: 贡献法 — 前驱/后继数组 — O(n) / O(n) ⭐ 面试首选

**思考过程**：

对每个位置 i，找到相同字符的前驱 `prev[i]` 和后继 `next[i]`。`s[i]` 在子串中唯一的充要条件是：子串的左端点在 `(prev[i], i]`，右端点在 `[i, next[i])` 范围内。

```cpp
class Solution {
public:
    int uniqueLetterString(string s) {
        int n = s.size();
        vector<int> prev(n, -1), next(n, n);
        vector<int> lastSeen(26, -1);
        
        // 从左到右扫描，记录每个位置的前驱
        for (int i = 0; i < n; i++) {
            int c = s[i] - 'A';
            prev[i] = lastSeen[c];
            lastSeen[c] = i;
        }
        
        // 从右到左扫描，记录每个位置的后继
        fill(lastSeen.begin(), lastSeen.end(), n);
        for (int i = n - 1; i >= 0; i--) {
            int c = s[i] - 'A';
            next[i] = lastSeen[c];
            lastSeen[c] = i;
        }
        
        // 累加每个位置的贡献
        int result = 0;
        for (int i = 0; i < n; i++) {
            result += (i - prev[i]) * (next[i] - i);
        }
        return result;
    }
};
```

**关键点**：
- 两遍扫描：第一遍求 prev，第二遍求 next
- 边界值：prev 默认 -1，next 默认 n，这样乘法公式自然处理了边界
- 只用 26 大小的数组追踪每个字母的最近位置

### 解法2: 贡献法 — 只维护最近两次出现 — O(n) / O(26)

**思考过程**：

不需要显式的 prev/next 数组。对每个字符维护最近两次出现的位置。当第三次出现时，就能算出"中间那次"的贡献。最后扫尾处理。

```cpp
class Solution {
public:
    int uniqueLetterString(string s) {
        int n = s.size();
        // index[c] 存储字符 c 的所有出现位置
        vector<vector<int>> index(26);
        for (int i = 0; i < n; i++) {
            index[s[i] - 'A'].push_back(i);
        }
        
        int result = 0;
        for (int c = 0; c < 26; c++) {
            vector<int>& pos = index[c];
            for (int i = 0; i < (int)pos.size(); i++) {
                int prev = (i > 0) ? pos[i-1] : -1;
                int next = (i < (int)pos.size()-1) ? pos[i+1] : n;
                result += (pos[i] - prev) * (next - pos[i]);
            }
        }
        return result;
    }
};
```

## 易错点

1. **prev 和 next 的边界值错误**：prev 应该默认 -1（不是 0），next 应该默认 n（不是 n-1）。因为区间是开的：起点可以从 `prev+1` 开始。

2. **整数溢出**：`(i - prev[i]) * (next[i] - i)` 在极端情况下每项最大约 10^5 * 10^5 = 10^10，会溢出 int。题目保证答案在 32 位内，但中间乘法可能溢出，建议用 `long long` 累加。

3. **混淆"唯一字符"和"不同字符"**：唯一字符是出现恰好一次的，不是出现过的不同字符数。比如 "ABA" 中唯一字符是 B（出现 1 次），不是 A 和 B。

4. **贡献法的乘法原理理解错误**：左右区间是独立选择的，所以是乘法不是加法。

## 面试追问

**Q1: 为什么贡献法是 O(n) 而不是 O(n^2)？**
→ 每个字符只被处理一次（计算 prev 和 next 各一次），总共 2n 次操作。不需要枚举子串。贡献法将"枚举子串"转化为"枚举字符"，是一种常见的降维技巧。

**Q2: 如果字符集不是 26 个字母而是任意字符呢？**
→ 用 HashMap 代替长度 26 的数组，算法思路完全不变。时间仍然 O(n)，空间 O(字符集大小)。

**Q3: 如何推广到"出现恰好 k 次"的字符？**
→ 需要维护每个字符的最近 k+1 次出现位置。对位置 i，左边界是第前 k 次出现的位置，右边界是第后 k 次出现的位置。

**Q4: 如果要求"至少出现一次"而不是"恰好一次"呢？**
→ 那就是求所有子串的不同字符数之和。同样用贡献法：字符 c 在子串中出现至少一次的充要条件是子串覆盖了 c 的某个出现位置。用容斥或类似技巧。
