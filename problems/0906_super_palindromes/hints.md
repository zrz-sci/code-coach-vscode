# 906. 超级回文数 (Super Palindromes)

## 核心思路

本题本质上是：**找出 [left, right] 范围内所有"超级回文数" -- 既是回文数，又是某个回文数的平方**。关键洞察是**枚举回文数的"根"**（即被平方的回文数），而不是枚举平方结果。因为 right 最大 10^18，根最大约 10^9，而回文数的"左半部分"只有约 10^5 种可能。

## 思维链

1. **读完题的第一反应**：超级回文数 = 回文数且是某个回文数的平方。直接枚举 [left, right] 中所有数并检查？right 最大 10^18，完全不可行。

2. **关键观察 -- 从"根"入手**：如果 x^2 是超级回文数，则 x 必须是回文数，且 x^2 也是回文数。x^2 <= 10^18 意味着 x <= 10^9。所以我们只需枚举 <= 10^9 的回文数 x，检查 x^2 是否也是回文数。

3. **如何高效枚举回文数？** 一个 k 位回文数由其前 ceil(k/2) 位唯一确定。x <= 10^9 表示 x 最多 10 位，前半部分最多 5 位。所以我们只需枚举 1 到 99999 这些"种子"，通过"镜像"构造出所有回文数。

4. **奇数位和偶数位回文数**：
   - 种子 123 → 奇数位回文: 12321 (长度5)
   - 种子 123 → 偶数位回文: 123321 (长度6)
   两种都要枚举。

5. **最终流程**：枚举种子 → 构造回文数 x → 计算 x^2 → 检查 x^2 是否是回文数 → 检查 x^2 是否在 [left, right] 内 → 计数。

6. **复杂度**：种子数量约 10^5，每个种子构造 + 检查是 O(log(x^2)) = O(18)。总共约 2 * 10^5 次操作，非常快。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 枚举回文根 | 枚举种子→构造回文→平方→检查 | O(W^(1/4) * log W) | O(1) | ⭐ 必须写出 |
| 预计算打表 | 离线计算所有超级回文数 | O(1) 查询 | O(1) | 知道即可 |

其中 W = 10^18 是数值上限，W^(1/4) ~ 10^4.5 是种子的数量级。

## 关键提示

1. **枚举"种子"而非回文数本身**：回文数的前半部分就是种子。种子为 1~99999（对应回文数最多 10 位 = x <= 10^9）。每个种子构造两个回文数（奇数位和偶数位）。

2. **构造回文数的方法**：把种子转成字符串，翻转后拼接。
   - 奇数位：种子 + 翻转(去掉最后一位)。如 "123" → "12321"
   - 偶数位：种子 + 完整翻转。如 "123" → "123321"

3. **检查回文的方法**：将数字转字符串，判断是否等于其翻转。

4. **注意溢出**：x 最大约 10^9，x^2 最大约 10^18，刚好在 `long long` 范围内（最大约 9.2 * 10^18）。但要小心中间计算不要溢出。

5. **ASCII 示意 -- 超级回文数的构造链**：
```
种子 seed = 1, 2, 3, 11, 22, ...

seed=1 → 回文 x=1     → x^2=1       → 是回文? Yes → 超级回文!
seed=2 → 回文 x=2     → x^2=4       → 是回文? Yes → 超级回文!
seed=3 → 回文 x=3     → x^2=9       → 是回文? Yes → 超级回文!
seed=1 → 偶位 x=11    → x^2=121     → 是回文? Yes → 超级回文!
seed=2 → 偶位 x=22    → x^2=484     → 是回文? Yes → 超级回文!
seed=2 → 奇位 x=2     → (已统计)
seed=3 → 偶位 x=33    → x^2=1089    → 是回文? No
seed=11→ 奇位 x=111   → x^2=12321   → 是回文? Yes → 超级回文!
seed=26→ 奇位 x=262   → x^2=68644   → 是回文? No  (26不是回文,不过这里我们枚举种子时不需要种子本身是回文)

注意: 种子不需要是回文! 种子只是用来构造回文数的。
```

## 解法详解

### 解法1: 枚举回文根 -- O(W^(1/4) * log W) / O(1) ⭐ 面试首选

**思考过程**：

核心洞察：**超级回文数的"根"（被平方的回文数）最多约 10^9，而回文数由其前半部分唯一确定**。前半部分（种子）最多 5 位，即最多约 10^5 个种子。

```cpp
class Solution {
public:
    int superpalindromesInRange(string left, string right) {
        long long L = stoll(left), R = stoll(right);
        int count = 0;
        
        // 枚举种子: 1 到 99999 (对应回文数最多10位)
        // 对每个种子，构造奇数位和偶数位两种回文数
        for (long long seed = 1; seed < 100000; seed++) {
            string s = to_string(seed);
            
            // --- 构造奇数位回文: seed + reverse(seed去掉最后一位) ---
            // 例: seed="123" → "123" + "21" = "12321"
            string oddPalin = s;
            for (int i = s.size() - 2; i >= 0; i--) {
                oddPalin += s[i];
            }
            long long x = stoll(oddPalin);
            long long sq = x * x;
            // 检查: x^2 在范围内且是回文
            if (sq > R) break; // 后续种子只会更大，可以提前终止
            if (sq >= L && isPalindrome(sq)) {
                count++;
            }
            
            // --- 构造偶数位回文: seed + reverse(seed完整) ---
            // 例: seed="123" → "123" + "321" = "123321"
            string evenPalin = s;
            for (int i = s.size() - 1; i >= 0; i--) {
                evenPalin += s[i];
            }
            x = stoll(evenPalin);
            sq = x * x;
            if (sq > R) continue; // 偶数位更大，但不能break(奇数位还可能有)
            if (sq >= L && isPalindrome(sq)) {
                count++;
            }
        }
        
        return count;
    }
    
private:
    bool isPalindrome(long long n) {
        string s = to_string(n);
        int l = 0, r = s.size() - 1;
        while (l < r) {
            if (s[l] != s[r]) return false;
            l++; r--;
        }
        return true;
    }
};
```

**关键点**：
- 种子范围 [1, 99999]，约 10^5 个，非常快
- 奇数位回文的 break 优化：如果平方已超过 R，后续种子更大，奇数位回文都会超过
- 偶数位回文用 continue 而非 break，因为下一个种子的奇数位回文可能还在范围内
- `isPalindrome` 用字符串翻转判断最直观

## 易错点

1. **✗ 种子范围太小或太大**：种子上限是 99999（5位），对应回文数最多 10 位。如果写成 9999 会漏掉 5 位种子构造的 9-10 位回文数。
   **✓ 种子范围 [1, 99999]，因为 10^9 的回文数前半部分最多 5 位。**

2. **✗ 只枚举奇数位回文或只枚举偶数位回文**：两种都需要枚举，否则会漏掉答案（如 11^2 = 121，11 是偶数位回文）。
   **✓ 每个种子构造两种回文数，都检查。**

3. **✗ 溢出风险**：x 最大约 10^9，x*x 约 10^18。必须用 `long long`。如果用 `int` 存 x，平方会溢出。
   **✓ 所有中间变量用 `long long`。**

4. **✗ break 时机错误**：奇数位回文超过 R 时可以对奇数位 break，但偶数位不能直接 break（下一个种子的奇数位回文可能更小）。
   **✓ 奇数位用 break，偶数位用 continue。或者分开两个循环更清晰。**

5. **✗ stoll 参数类型错误**：`stoll` 需要 `string` 参数，不能传 `long long`。

## 面试追问

**Q1: 为什么不直接枚举 [left, right] 中的回文数，再检查它是否是某个回文数的平方？**
→ [left, right] 最大范围 10^18，即使只枚举其中的回文数也有约 2 * 10^9 个（18位数的回文数由前9位确定）。而从"根"入手，种子只有约 10^5 个，快了 4 个数量级。

**Q2: 实际有多少个超级回文数？**
→ 在 [1, 10^18] 范围内，超级回文数只有约 70 个左右。这是因为两个独立的回文性约束大幅缩减了候选集。可以预计算所有超级回文数做成打表，但面试中展示枚举过程更重要。

**Q3: 如果 right 可以更大（比如 10^36），怎么处理？**
→ 需要大数运算（Python 天然支持，C++ 需要自己实现或用库）。核心思路不变，只是种子范围扩大到约 10^9，需要处理大整数乘法和回文检查。
