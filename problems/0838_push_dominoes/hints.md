# 838. Push Dominoes - 提示与解析

## 核心思路

模拟多米诺骨牌倒下的过程。关键观察是：每个竖立的骨牌('.')的最终状态取决于它左右两侧最近的已推倒骨牌的方向和距离。可以用**力的模拟**（左右扫描计算净力）或**双指针/分段处理**来解决。最直观的方法是分别计算每个位置受到的右推力和左推力，然后比较力的大小来决定最终方向。

## 思维链

1. **分析物理规则**：R向右推，L向左推，'.'是竖立状态
2. **力的衰减**：距离推力源越远，影响越弱（可以用距离来衡量）
3. **分段思考**：在两个已推倒的骨牌之间的段，根据两端方向有四种情况
4. **两次扫描法**：从左到右计算右推力，从右到左计算左推力
5. **比较净力**：每个位置上，右推力大于左推力则倒向右，反之倒向左，相等则不倒

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 推荐度 | 说明 |
|------|-----------|-----------|--------|------|
| 两次扫描（力的模拟） | O(n) | O(n) | ⭐⭐⭐⭐⭐ | 计算左右推力后比较 |
| 双指针分段处理 | O(n) | O(1) | ⭐⭐⭐⭐⭐ | 按段处理四种情况 |
| BFS模拟 | O(n) | O(n) | ⭐⭐⭐⭐ | 多源BFS同时推进 |
| 暴力模拟 | O(n^2) | O(n) | ⭐⭐ | 每轮模拟一步 |

## 关键提示

1. **四种段类型**：两个相邻的非'.'字符之间的段可以是 R...L、L...R、R...R、L...L
2. **R...L** 是唯一产生对撞的情况：两端向中间推，中间可能有一个保持竖立
3. **力的大小用距离表示**：离R越近右推力越大，离L越近左推力越大
4. **虚拟边界**：可以在字符串左端加'L'、右端加'R'来统一处理边界
5. **BFS方法**：初始将所有R和L加入队列，每轮向外扩展一步

## 解法详解

### 解法一：两次扫描（力的模拟）⭐⭐⭐⭐⭐

**思路：** 用数组 `force[i]` 表示每个位置受到的净力。

**从左到右扫描（计算右推力）：**
- 遇到'R'，力设为n（最大值）
- 遇到'L'，力设为0
- 遇到'.'，力 = 前一个位置的力 - 1（衰减），但不低于0

**从右到左扫描（计算左推力）：**
- 遇到'L'，力设为n
- 遇到'R'，力设为0  
- 遇到'.'，力 = 后一个位置的力 - 1，但不低于0

**最终决定：** 比较每个位置的右推力和左推力。

### 解法二：双指针分段处理 ⭐⭐⭐⭐⭐

用两个指针i和j找到相邻的非'.'段标记，然后根据左右标记处理中间的'.'：
- **L...L**：全部变L
- **R...R**：全部变R
- **L...R**：全部保持'.'（力的方向相反，不影响）
- **R...L**：两端向中间推，中间奇数个时正中间保持'.'

### 解法三：BFS模拟 ⭐⭐⭐⭐

将所有初始的R和L作为BFS起点，每轮同时向外推进一步。如果某个'.'同时被左右方向到达则保持不动。

## 易错点

1. **R...L的中间处理**：当R和L之间有奇数个'.'时，正中间那个保持竖立
2. **边界处理**：字符串开头的'.'段和结尾的'.'段需要特别处理
3. **力的衰减不能为负**：`max(0, force - 1)`
4. **BFS中的同时到达**：需要在同一层BFS中检测碰撞
5. **虚拟哨兵**：加L和R作为边界哨兵时注意不影响原始字符串
6. **不要修改原字符串进行模拟**：需要用新数组记录结果

## 面试追问

1. **如果骨牌是环形排列的怎么办？** - 需要处理首尾相连的情况，找到第一个非'.'的位置作为起点
2. **如果推力有权重（有些推得更用力）？** - 力的衰减不再是-1，而是根据权重变化
3. **如果需要输出每一步的中间状态？** - BFS模拟法天然支持逐步输出
4. **时间复杂度能否做到更优？** - O(n)已是最优，每个位置至少需要看一次
5. **如果有些骨牌是"固定"的（不会倒）？** - 作为分段的天然边界处理
6. **双指针法如何保证O(1)空间？** - 直接在原字符串上修改结果
