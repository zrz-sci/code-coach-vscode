# 793. Preimage Size of Factorial Zeroes Function (阶乘函数后 K 个零)

## 核心思路

定义 f(x) = x! 末尾零的个数。给定 k，求满足 f(x) = k 的非负整数 x 的数量。核心洞察：f(x) 是单调非递减的阶梯函数，每次跳跃要么 +1（遇到 5 的倍数），要么跳过某些值（遇到 5^2, 5^3, ... 的倍数时一次增加多个零）。因此答案只有两种可能：**0 或 5**。用二分查找确定是否存在某个 x 使得 f(x) = k 即可。

## 思维链

1. **f(x) 的计算**：x! 末尾零的个数 = x 的质因数分解中 5 的个数（因为 2 的个数总是足够多）。即 `f(x) = x/5 + x/25 + x/125 + ...`。
2. **f(x) 的性质**：f(x) 是单调非递减函数。从 x 到 x+1，如果 x+1 不是 5 的倍数则 f 不变，如果是 5 的倍数则 f 增加。
3. **关键发现**：f(x) 的值从一个整数跳到下一个整数时，每次连续相同的值恰好有 5 个。例如 f(0)=f(1)=f(2)=f(3)=f(4)=0，f(5)=f(6)=f(7)=f(8)=f(9)=1，...。但某些值会被跳过！比如 f(24)=4, f(25)=6，值 5 被跳过了。
4. **为什么跳过**：25 = 5^2 贡献了两个因子 5，使得 f 从 4 直接跳到 6，跳过了 5。类似地 125 = 5^3 会跳过更多值。
5. **答案只有 0 或 5**：如果 k 是某个被跳过的值，答案为 0；否则答案恒为 5。
6. **如何判断 k 是否被跳过**：用二分查找找到最小的 x 使得 f(x) >= k。如果 f(x) == k 则答案为 5，否则为 0。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 双二分查找 | O(log^2(5k)) | O(1) | 最直观，推荐面试 |
| 单次二分 + 判断 | O(log^2(5k)) | O(1) | 代码更简洁 |
| 数学 (5进制分析) | O(log k) | O(1) | 最优但不直观 |

## 关键提示

1. **f(x) 公式**：`f(x) = sum_{i=1}^{inf} floor(x / 5^i)`，即 `x/5 + x/25 + x/125 + ...`。
2. **答案只有 0 或 5**：这是本题最重要的数学性质。不需要精确计算有多少个 x，只需判断 k 是否"可达"。
3. **二分搜索范围**：上界可取 `5 * (k + 1)`，因为 f(5k) >= k。更精确地可取 `5L` 其中 L = k + logBase5(k) 的近似。
4. **注意 k = 0 的特殊情况**：f(0) = f(1) = f(2) = f(3) = f(4) = 0，答案为 5。
5. **使用 long long**：当 k 接近 10^9 时，5k 接近 5*10^9，需要 long long 避免溢出。

## 解法详解

### 解法一：双二分查找（推荐面试首选）

**辅助函数 trailingZeroes(x)**：计算 x! 末尾零的个数。

```
count = 0
while x > 0:
    x /= 5
    count += x
return count
```
时间 O(log5(x))。

**主函数**：
1. 用二分查找找到满足 `trailingZeroes(x) >= k` 的最小 x（记为 left）。
2. 用二分查找找到满足 `trailingZeroes(x) >= k+1` 的最小 x（记为 right）。
3. 答案 = right - left。由数学性质保证结果只会是 0 或 5。

**为什么答案是 5**：如果存在 x 使得 f(x) = k，那么 x 到 x+4 这 5 个连续数都满足 f = k（因为下一个增加 f 的数是下一个 5 的倍数，至少间隔 5）。

**复杂度**：二分 O(log(5k)) 次，每次计算 f 需要 O(log5(x)) = O(log(k))。总 O(log(k) * log(k)) = O(log^2(k))。

### 解法二：单次二分 + 判断

直接二分搜索是否存在 x 使得 f(x) == k。找到则返回 5，否则返回 0。

### 解法三：数学方法 (5 进制分析)

将 k 反复除以 5，如果某步余数恰好为 4，说明 k 是被跳过的值，返回 0。否则返回 5。

**原理**：f 函数跳过的值在 5 进制下具有特殊模式。不断对 k 做 `k % 5` 和 `k / 5` 的分解，等价于检查 k 是否在某个"跳跃间隙"中。

## 易错点

1. **溢出**：k 最大 10^9，搜索上界 5 * 10^9 + 5 超过 int 范围，必须用 long long。
2. **二分的搜索上界设太小**：如果上界不够大，会错过正确答案。安全上界为 `5LL * (k + 1)`。
3. **把答案误以为可以是 1, 2, 3, 4**：不可能。由于 f(x) 在非 5 的倍数处不变，连续相同值的段长度总是 5。
4. **f(x) 计算的循环条件**：应该是 `while (x >= 5)` 或 `while (x > 0)` 配合 `x /= 5`，不要用 `5^i` 计算因为可能溢出。
5. **k = 0 时不要返回 1**：虽然感觉"只有 0! 末尾 0 个零"，实际上 0! 到 4! 都是 0 个末尾零，答案是 5。

## 面试追问

1. **Q: 为什么答案恒为 0 或 5，不可能是其他值？** A: 因为在 x 的连续 5 个值 {5m, 5m+1, 5m+2, 5m+3, 5m+4} 中，只有 5m 是 5 的倍数（贡献新的零），所以 f 值在这 5 个数中保持不变。下一次 f 值变化要到 5(m+1)。如果 5m 是 25/125/... 的倍数，f 可能一次跳过多个值。
2. **Q: 哪些 k 值会返回 0？** A: 被跳过的 k 值。例如 f(24)=4, f(25)=6, 所以 k=5 被跳过。f(124)=28, f(125)=31, 所以 k=29,30 被跳过。规律与 5 的幂次有关。
3. **Q: 如何直接判断 k 是否被跳过（不用二分）？** A: 将 k 反复除以 5 取余，如果某步余数为 4 则被跳过。这等价于检查 k 在某种广义 5 进制下的表示。
4. **Q: f(x) 的增长速度？** A: f(x) 约等于 x/4（因为 x/5 + x/25 + ... = x * (1/5 + 1/25 + ...) = x/4）。所以 f(x) = k 意味着 x 约等于 4k。
5. **Q: 这道题和 172. Trailing Zeroes 的关系？** A: 172 题求 f(n)，本题是 f 的"反函数"——给定 f 值求原像大小。本质上是 172 的逆向思维。
