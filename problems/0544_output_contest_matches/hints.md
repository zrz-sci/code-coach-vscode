# 544. 输出比赛匹配对

## 核心思路

模拟 NBA 季后赛配对过程：每轮将当前队列中最强的和最弱的配对，直到只剩一对。用字符串数组模拟每轮合并即可。

## 思维链

1. **读完题第一反应**：n 支队伍按强弱配对，第 1 名配第 n 名，第 2 名配第 n-1 名……每轮队伍数减半，直到只剩一组。这不就是模拟吗？

2. **数据结构选择**：初始化一个字符串数组 `["1", "2", ..., "n"]`。每轮首尾配对生成新数组 `["(1,n)", "(2,n-1)", ...]`。

3. **循环终止条件**：当数组长度变为 1 时，返回唯一的字符串。

4. **递归思路**：也可以用递归 —— 每轮对数组做一次首尾合并操作，然后递归处理新数组。

5. **n 的约束**：n = 2^x，保证每轮都能整除，不需要处理奇数情况。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 迭代模拟 | 每轮首尾配对合并字符串数组 | O(n log n) | O(n) | ⭐ 首选 |
| 递归模拟 | 递归地对数组进行首尾合并 | O(n log n) | O(n log n) | 加分项 |

## 关键提示

- **提示 1**：初始化字符串数组 `["1", "2", ..., "n"]`，每轮对 `teams[i]` 和 `teams[size-1-i]` 配对成 `"(teams[i],teams[size-1-i])"`。

- **提示 2**：每轮结束后数组长度减半，共需 log2(n) 轮。

- **提示 3**：配对规则 —— 当前排名第 i 的和第 (size-1-i) 的配对。注意配对后的"强弱顺序"自然保持（赢家假设是强队一方）。

- **提示 4（ASCII 图解）**：
```
// n = 8
// 初始: ["1", "2", "3", "4", "5", "6", "7", "8"]
//
// 第1轮: 1配8, 2配7, 3配6, 4配5
//        ["(1,8)", "(2,7)", "(3,6)", "(4,5)"]
//
// 第2轮: (1,8)配(4,5), (2,7)配(3,6)
//        ["((1,8),(4,5))", "((2,7),(3,6))"]
//
// 第3轮: 两组合并
//        ["(((1,8),(4,5)),((2,7),(3,6)))"]
```

## 解法详解

### 解法 1: 迭代模拟 -- O(n log n) / O(n) ⭐ 面试首选

**思考过程**：直接模拟配对过程，每轮将数组首尾配对生成新数组。

```cpp
class Solution {
public:
    string findContestMatch(int n) {
        vector<string> teams(n);
        for (int i = 0; i < n; i++) {
            teams[i] = to_string(i + 1);
        }
        
        while (teams.size() > 1) {
            int size = teams.size();
            vector<string> next(size / 2);
            for (int i = 0; i < size / 2; i++) {
                next[i] = "(" + teams[i] + "," + teams[size - 1 - i] + ")";
            }
            teams = next;
        }
        
        return teams[0];
    }
};
```

**关键点**：
- 每轮 `teams[i]` 与 `teams[size-1-i]` 配对
- 共 log2(n) 轮，每轮处理当前数组大小的一半

---

### 解法 2: 递归模拟 -- O(n log n) / O(n log n)

**思考过程**：将每轮合并操作封装成递归 —— 合并一轮后递归处理新数组。

```cpp
class Solution {
public:
    string findContestMatch(int n) {
        vector<string> teams(n);
        for (int i = 0; i < n; i++) {
            teams[i] = to_string(i + 1);
        }
        return solve(teams);
    }
    
    string solve(vector<string>& teams) {
        if (teams.size() == 1) return teams[0];
        
        int size = teams.size();
        vector<string> next(size / 2);
        for (int i = 0; i < size / 2; i++) {
            next[i] = "(" + teams[i] + "," + teams[size - 1 - i] + ")";
        }
        return solve(next);
    }
};
```

## 易错点

1. **✗ 配对顺序搞反**：`teams[size-1-i]` 写成 `teams[i+1]`
   **✓ 首尾配对**：第 i 强的和第 (size-1-i) 强的配对，不是相邻配对。

2. **✗ 忘记加括号和逗号**：直接拼接 `teams[i] + teams[j]`
   **✓ 格式是 `"(" + teams[i] + "," + teams[j] + ")"`**。

3. **✗ 原地修改数组导致索引错误**：在遍历过程中修改 teams 数组
   **✓ 每轮生成新数组**，不要在原数组上修改。

## 面试追问

**Q1：时间复杂度如何分析？**
→ 共 log2(n) 轮。第 k 轮处理 n/2^k 个元素，字符串拼接也有开销。总的字符操作量为 O(n log n)。

**Q2：能否不创建新数组，原地操作？**
→ 可以。每轮只用数组前半部分，`teams[i] = "(" + teams[i] + "," + teams[size-1-i] + ")"`，然后将有效长度减半。这样空间更优，但需注意遍历方向（从前往后，因为后面的元素还没被覆盖）。

**Q3：如果 n 不是 2 的幂怎么办（比如有 bye 轮）？**
→ 实际赛制中，部分强队会轮空（bye）。可以在首轮让排名靠前的队伍直接晋级，只让后面的队伍配对。需要额外处理奇数情况。
