# 344. 反转字符串

## 核心思路

本质上就是把数组首尾对称位置的元素两两交换。这是双指针技巧最基础的应用场景。

## 思维链

1. **读完题第一反应**：反转就是让第一个元素和最后一个交换，第二个和倒数第二个交换……直到中间相遇。
2. **需要额外空间吗？** 如果创建一个新数组，从后往前复制过去就行——但题目要求 O(1) 空间，原地修改。
3. **原地交换怎么做？** 用两个指针，一个从头开始（left），一个从尾开始（right），每次交换 `s[left]` 和 `s[right]`，然后两个指针向中间靠拢。
4. **什么时候停？** 当 `left >= right` 时，所有需要交换的对都处理完了。
5. **还有没有其他方式？** 可以用递归来做，但递归会消耗栈空间 O(n)，不如双指针优。

```
// 交换过程可视化 (s = "hello"):
//
// Step0: [h, e, l, l, o]
//         ↑           ↑
//        left        right
//
// Step1: [o, e, l, l, h]    ← 交换 h ↔ o
//            ↑     ↑
//           left  right
//
// Step2: [o, l, l, e, h]    ← 交换 e ↔ l
//               ↑
//           left=right       ← left >= right, 停止
//
// 结果: [o, l, l, e, h]  ✓
```

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 双指针 | 首尾指针向中间靠拢，逐对交换 | O(n) | O(1) | ⭐ 必须写出 |
| 递归 | 递归交换首尾，缩小范围 | O(n) | O(n) 栈空间 | 能说出即可 |
| STL reverse | 一行调用库函数 | O(n) | O(1) | 了解即可，面试不能只写这个 |

## 关键提示

- **提示1**：两个指针从两端出发，每次交换后同时向中间移动一步。
- **提示2**：循环终止条件是 `left < right`，不是 `left <= right`——想想为什么？（当 left == right 时指向同一个元素，不需要交换）
- **提示3**：交换操作可以用 `swap()`、临时变量、甚至异或，但面试中用 `swap()` 最清晰。
- **提示4**：递归解法虽然代码简洁，但栈深度 O(n) 不满足 O(1) 空间的严格要求。

## 解法详解

### 解法1: 双指针（对撞指针） — O(n) / O(1) ⭐ 面试首选

**思考过程**：反转的本质就是"第 i 个元素应该去到第 n-1-i 的位置"。那最直接的方式就是设两个指针分别指向两端，交换后向中间靠拢。每个元素最多被交换一次，所以是 O(n)。不需要任何额外空间，完美符合题目要求。

```cpp
class Solution {
public:
    void reverseString(vector<char>& s) {
        int left = 0, right = s.size() - 1;
        while (left < right) {
            // 交换对称位置的字符
            swap(s[left], s[right]);
            left++;
            right--;
        }
    }
};
```

**关键点**：
- 循环条件是 `left < right`，不是 `left <= right`。当两个指针重合时元素自己跟自己交换是多余操作。
- 每次循环处理一对，总共 n/2 次交换。

### 解法2: 递归 — O(n) / O(n)

**思考过程**：递归地思考——要反转整个数组，先交换首尾两个元素，然后递归地反转中间部分。这和双指针本质相同，只是用递归调用栈代替了 while 循环。

```cpp
class Solution {
public:
    void reverseString(vector<char>& s) {
        helper(s, 0, s.size() - 1);
    }
    
    void helper(vector<char>& s, int left, int right) {
        // 递归终止：指针相遇或交叉，不需要再交换
        if (left >= right) return;
        
        // 交换首尾
        swap(s[left], s[right]);
        
        // 递归处理中间部分（等价于 left++, right--）
        helper(s, left + 1, right - 1);
    }
};
```

**关键点**：
- 递归深度为 n/2，栈空间 O(n)，严格来说不满足 O(1) 空间要求。
- 面试中可以提及这种思路展示递归思维，但要说明它的空间劣势。

### 解法3: STL 库函数 — O(n) / O(1)

**思考过程**：C++ STL 提供了 `reverse()` 函数，内部实现就是双指针交换。了解即可，面试中不建议只写这一行——面试官想看你的实现能力。

```cpp
class Solution {
public:
    void reverseString(vector<char>& s) {
        reverse(s.begin(), s.end());
    }
};
```

## 解法对比

|  | 双指针 | 递归 | STL |
|---|---|---|---|
| 时间 | O(n) | O(n) | O(n) |
| 空间 | O(1) ✓ | O(n) 栈空间 ✗ | O(1) ✓ |
| 面试推荐 | ⭐ 首选 | 展示思维 | 不够 |
| 本质 | 迭代交换 | 递归交换 | 封装的迭代交换 |

**选择建议**：面试中直接写双指针。如果面试官追问"能不能递归实现"，再写递归版本并主动指出空间劣势。

## 易错点

1. **循环条件写成 `left <= right`**
   - ✗ `while (left <= right)` — 当 left == right 时，自己和自己交换，不报错但做了一次无意义操作（不是 bug，但不优雅）
   - ✓ `while (left < right)` — 精确控制

2. **忘记两个指针都要移动**
   - ✗ 只写了 `left++` 忘记 `right--` → 死循环或结果错误
   - ✓ 每次循环 `left++; right--;` 必须成对出现

3. **递归忘记终止条件**
   - ✗ 没有 `if (left >= right) return;` → 栈溢出
   - ✓ 递归第一行写终止条件是好习惯

## 面试追问

**Q1: 这道题的时间复杂度是多少？为什么？**
→ O(n)，每个元素最多被访问一次（准确说交换 n/2 次），所以线性。

**Q2: 如果不能用 swap，你怎么交换两个变量？**
→ 方法一：用临时变量 `char tmp = a; a = b; b = tmp;`
→ 方法二：异或 `a ^= b; b ^= a; a ^= b;`（但可读性差，且 a==b 时有陷阱——实际上异或法在 a 和 b 是同一个变量时会清零）

**Q3: 如果输入是字符串 string 而不是 vector<char>，有什么区别？**
→ C++ 中 string 也支持下标访问和 swap，代码几乎一样。但如果是其他语言（如 Java/Python）中字符串不可变，需要先转成字符数组再操作。

**Q4: 如果要反转字符串中的单词顺序（如 "hello world" → "world hello"），怎么做？**
→ 这是 LeetCode 151 的思路：先反转整个字符串，再逐个单词内部反转。复用本题的反转函数作为子操作。
