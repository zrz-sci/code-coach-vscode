# LCR 095. 最长公共子序列

## 核心思路

经典二维动态规划。两个字符串 text1 和 text2，求它们的最长公共子序列（LCS）长度。`dp[i][j]` 表示 text1 的前 i 个字符和 text2 的前 j 个字符的 LCS 长度。根据末尾字符是否匹配，决定状态转移。

> 本题与主站第 1143 题完全相同。

## 思维链

1. **读完题第一反应** -- "子序列"意味着可以跳着选（不需要连续），但选出的字符相对顺序不能变。这和"子串"（必须连续）不同。子序列问题通常用 DP 解决。

2. **暴力做法** -- 枚举 text1 的所有子序列（2^m 个），对每个子序列检查它是否也是 text2 的子序列。时间 O(2^m * n)，指数级，完全不可行。

3. **DP 思路** -- 考虑两个字符串的**末尾字符**：
   - 如果 `text1[i-1] == text2[j-1]`（末尾字符相同），那么这个字符一定在 LCS 中，`dp[i][j] = dp[i-1][j-1] + 1`
   - 如果 `text1[i-1] != text2[j-1]`（末尾字符不同），那么 LCS 不可能同时包含这两个字符，至少要丢掉一个：`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

4. **状态定义** -- `dp[i][j]` = text1 前 i 个字符 与 text2 前 j 个字符的 LCS 长度。用"前 i 个"而不是"下标 i"，是为了方便处理边界：`dp[0][*] = dp[*][0] = 0`（空串的 LCS 为 0）。

5. **空间优化** -- dp 只依赖上一行 `dp[i-1][*]` 和当前行左边 `dp[i][j-1]`，可以用一维滚动数组优化到 O(n) 空间。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力枚举 | 枚举所有子序列 | O(2^m * n) | O(m) | 不可行 |
| 二维 DP | dp[i][j] 状态转移 | O(m*n) | O(m*n) | 必须写出 |
| 一维滚动 DP | 空间优化 | O(m*n) | O(n) | 加分项 |

## 关键提示

1. **子序列 vs 子串**：子序列可以不连续（跳着选），子串必须连续。LCS（Longest Common Subsequence）是子序列问题，用 DP 而非滑动窗口。

2. **状态转移的直觉**：
   - 匹配时 (`text1[i-1] == text2[j-1]`)：两人都前进一步，LCS 长度 +1
   - 不匹配时：要么 text1 往前退一步（`dp[i-1][j]`），要么 text2 往前退一步（`dp[i][j-1]`），取较大值

3. **DP 表填充方向**：从左到右、从上到下。`dp[i][j]` 依赖左上 `dp[i-1][j-1]`、上方 `dp[i-1][j]`、左方 `dp[i][j-1]`。

4. **DP 表实例**（text1="abcde", text2="ace"）：
```
       ""  a  c  e
   ""   0  0  0  0
    a   0  1  1  1
    b   0  1  1  1
    c   0  1  2  2
    d   0  1  2  2
    e   0  1  2  3
                 ↑ 答案 = dp[5][3] = 3
```

填表过程解读：
- `dp[1][1]`: text1="a" vs text2="a", 匹配! dp[0][0]+1 = 1
- `dp[1][2]`: text1="a" vs text2="ac", 'a'!='c', max(dp[0][2], dp[1][1]) = max(0,1) = 1
- `dp[3][2]`: text1="abc" vs text2="ac", 'c'=='c', dp[2][1]+1 = 1+1 = 2
- `dp[5][3]`: text1="abcde" vs text2="ace", 'e'=='e', dp[4][2]+1 = 2+1 = 3

5. **空间优化的关键**：滚动数组中，`dp[i-1][j-1]` 会被 `dp[i][j-1]` 覆盖，需要用临时变量 `prev` 保存。

## 解法详解

### 解法1: 二维 DP -- O(m*n) / O(m*n)

**思考过程**：定义 `dp[i][j]` = text1 前 i 个字符 和 text2 前 j 个字符的 LCS 长度。

转移方程：
```
if text1[i-1] == text2[j-1]:
    dp[i][j] = dp[i-1][j-1] + 1    // 末尾匹配，LCS 加 1
else:
    dp[i][j] = max(dp[i-1][j], dp[i][j-1])  // 末尾不匹配，取两个子问题的较大值
```

```cpp
class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        int m = text1.size(), n = text2.size();
        // dp[i][j] = LCS(text1[0..i-1], text2[0..j-1])
        vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1[i - 1] == text2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        return dp[m][n];
    }
};
```

---

### 解法2: 一维滚动数组 DP -- O(m*n) / O(n)

**空间优化思路**：`dp[i][j]` 只依赖上一行的两个值和当前行左边的值。可以把二维数组压缩为一维。

关键：更新 `dp[j]` 时需要 `dp[j-1]`（当前行左边，已被更新为新值）和旧的 `dp[j-1]`（上一行的值，即 `dp[i-1][j-1]`）。所以需要一个临时变量 `prev` 保存更新前的 `dp[j-1]`。

```
一维 DP 滚动过程 (text1="abc", text2="ac"):

初始: dp = [0, 0, 0]  (对应 text2 的 "", "a", "ac")

i=1 (text1[0]='a'):
  j=1: 'a'=='a', dp[1] = prev + 1 = 0+1 = 1  → dp = [0, 1, 0]
  j=2: 'a'!='c', dp[2] = max(dp[1], dp[2]) = max(1, 0) = 1  → dp = [0, 1, 1]

i=2 (text1[1]='b'):
  j=1: 'b'!='a', dp[1] = max(dp[0], dp[1]) = max(0, 1) = 1  → dp = [0, 1, 1]
  j=2: 'b'!='c', dp[2] = max(dp[1], dp[2]) = max(1, 1) = 1  → dp = [0, 1, 1]

i=3 (text1[2]='c'):
  j=1: 'c'!='a', dp[1] = max(dp[0], dp[1]) = max(0, 1) = 1  → dp = [0, 1, 1]
  j=2: 'c'=='c', dp[2] = prev + 1 = 1+1 = 2  → dp = [0, 1, 2]

答案: dp[2] = 2  (LCS = "ac")
```

```cpp
class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        int m = text1.size(), n = text2.size();
        vector<int> dp(n + 1, 0);

        for (int i = 1; i <= m; i++) {
            int prev = 0; // 保存 dp[i-1][j-1]，即上一行左上角的值
            for (int j = 1; j <= n; j++) {
                int temp = dp[j]; // 保存当前 dp[j]（= dp[i-1][j]），下一轮作为 prev
                if (text1[i - 1] == text2[j - 1]) {
                    dp[j] = prev + 1; // 对应二维中的 dp[i-1][j-1] + 1
                } else {
                    dp[j] = max(dp[j], dp[j - 1]); // max(dp[i-1][j], dp[i][j-1])
                }
                prev = temp; // 更新 prev 为旧的 dp[j]
            }
        }

        return dp[n];
    }
};
```

## 解法对比

| | 二维 DP | 一维滚动 DP |
|---|---|---|
| 时间 | O(m*n) | O(m*n) |
| 空间 | O(m*n) | O(min(m,n)) |
| 代码简洁度 | 高（直观） | 中（需要 prev 变量） |
| 调试难度 | 低（可打印二维表） | 中 |
| 推荐场景 | 面试首选 | 追问空间优化时 |

> 优化提示：让较短的字符串作为 text2，这样一维 DP 的空间为 O(min(m,n))。

## 易错点

1. **下标偏移**：
   - `dp[i][j]` 对应的是 `text1[i-1]` 和 `text2[j-1]`（前 i 个字符，下标从 0 开始）
   - 忘记 -1 会导致数组越界或逻辑错误

2. **不匹配时取错子问题**：
   - 正确：`max(dp[i-1][j], dp[i][j-1])`（丢掉 text1 末尾 OR 丢掉 text2 末尾）
   - 易错：写成 `dp[i-1][j-1]`（同时丢掉两个末尾，漏掉了可能的更优解）

3. **空间优化中 prev 更新时机**：
   - `prev` 必须在 `dp[j]` 被更新**之前**保存旧值
   - 如果先更新 `dp[j]` 再保存，`prev` 就成了新值，导致后续匹配时算错

4. **忘记初始化**：
   - `dp[0][*] = 0` 和 `dp[*][0] = 0` 表示空串的 LCS 为 0
   - vector 默认初始化为 0，但如果用 C 数组需要手动 memset

## 面试追问

**Q1: LCS 和 LIS（最长递增子序列）有什么关系？**
当两个序列其中一个是有序的（比如排序后的数组），LCS 问题可以转化为 LIS 问题，从而用 O(n log n) 的算法加速。但一般情况下 LCS 是 O(m*n)。

**Q2: 如果要输出 LCS 本身（而不只是长度），怎么做？**
在填表的同时记录每个 `dp[i][j]` 的来源（"来自左上"、"来自上"、"来自左"），然后从 `dp[m][n]` 回溯路径，遇到"来自左上"的格子就把对应字符加入结果。

**Q3: 能否优化到 O(m*n) 以下？**
理论上一般的 LCS 目前没有严格低于 O(m*n) 的算法（在 SETH 假设下被认为不可能）。但有些特殊情况可以优化：比如字符集很小时可以用位并行（Bit Parallelism）技巧加速到 O(m*n/w)，w 是机器字长。

**Q4: 空间优化后还能回溯路径吗？**
一维滚动数组优化后无法回溯路径（因为上一行的信息被覆盖了）。如果需要路径，只能用二维 DP，或者用 Hirschberg 算法（分治 + 空间优化，O(n) 空间但可以恢复路径）。
