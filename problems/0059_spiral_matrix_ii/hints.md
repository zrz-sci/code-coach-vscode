# 59. 螺旋矩阵 II

## 核心思路

本质上是一道**模拟题**：按照螺旋的行走规则（右→下→左→上→右→...），依次把 1 到 n² 填入矩阵。关键在于如何优雅地控制"什么时候转弯"和"每条边填多少个"。

## 思维链

1. **读完题第一反应**：我需要按螺旋顺序填数。螺旋就是一圈一圈地走：先走最外圈，再走次外圈... 那我能不能一圈一圈地模拟？

2. **一圈怎么走？** 每一圈有四条边：上边(→右)、右边(→下)、下边(→左)、左边(→上)。每走完一圈，四条边界都往内收缩一步。

3. **怎么控制边界？** 用 top/bottom/left/right 四个变量标记当前还没填的区域边界。每填完一条边，对应边界收缩。

4. **会不会重复填？** 不会。因为每条边填完后立刻收缩边界，下一条边的起止范围自然避开了已填的位置。

5. **还有没有其他方式？** 可以用"方向数组 + 碰壁转向"的方式：一直往当前方向走，碰到墙壁或已填格子就右转。这种方式更通用（不依赖矩形结构），但边界层剥离法对本题更直观。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 边界层剥离 | 维护四个边界，一圈一圈填 | O(n²) | O(n²) | ⭐ 必须写出 |
| 方向模拟 | 方向数组 + 碰壁转向 | O(n²) | O(n²) | 加分项 |

> 注：O(n²) 的空间是存放结果矩阵本身，无法避免。两种解法额外空间都是 O(1)。

## 解法详解

### 解法1: 边界层剥离（Layer-by-Layer） — O(n²) / O(n²) ⭐ 面试首选

**思考过程**：

螺旋的规律是"一圈一圈从外到内"。每一圈有四段路径：
- 上边：从左到右
- 右边：从上到下
- 下边：从右到左
- 左边：从下到上

填完一圈后，四条边界各收缩一步，继续填下一圈。

```
// n=3 的填充过程:
//
// 初始边界: top=0, bottom=2, left=0, right=2
//
// 第1圈:
//   上边 → : (0,0)=1  (0,1)=2  (0,2)=3   → top++ → top=1
//   右边 ↓ : (1,2)=4  (2,2)=5             → right-- → right=1
//   下边 ← : (2,1)=6  (2,0)=7             → bottom-- → bottom=1
//   左边 ↑ : (1,0)=8                       → left++ → left=1
//
// 第2圈:
//   上边 → : (1,1)=9                       → top++ → top=2
//   此时 top > bottom，循环结束
//
// 结果:
//   1 2 3
//   8 9 4
//   7 6 5
```

```cpp
class Solution {
public:
    vector<vector<int>> generateMatrix(int n) {
        vector<vector<int>> matrix(n, vector<int>(n, 0));
        int top = 0, bottom = n - 1;
        int left = 0, right = n - 1;
        int num = 1;
        
        while (top <= bottom && left <= right) {
            // 上边：从左到右
            for (int j = left; j <= right; j++)
                matrix[top][j] = num++;
            top++;  // 上边界收缩
            
            // 右边：从上到下
            for (int i = top; i <= bottom; i++)
                matrix[i][right] = num++;
            right--;  // 右边界收缩
            
            // 下边：从右到左
            for (int j = right; j >= left; j--)
                matrix[bottom][j] = num++;
            bottom--;  // 下边界收缩
            
            // 左边：从下到上
            for (int i = bottom; i >= top; i--)
                matrix[i][left] = num++;
            left++;  // 左边界收缩
        }
        
        return matrix;
    }
};
```

**关键点**：
- 由于本题是 n×n 的正方形，填数从 1 到 n²，每个格子恰好填一次。所以不需要像 LeetCode 54（螺旋矩阵 I，读取）那样额外判断 `top <= bottom` 来防止下边和左边重复遍历。但加上判断也不会错，是更安全的写法。
- `num` 从 1 开始自增，自然保证填入顺序正确。

### 解法2: 方向模拟（Direction Simulation） — O(n²) / O(n²)

**思考过程**：

换个角度：我不按"一圈一圈"思考，而是模拟一个人在矩阵里走路：
- 初始方向是向右
- 一直往前走，碰到边界或已经填过的格子就"右转"
- 方向顺序：右→下→左→上→右→...

怎么判断"碰壁"？下一步的坐标越界或对应格子已经非零。

```
// n=3 方向模拟过程:
//
// 方向数组 dirs: 右(0,1) 下(1,0) 左(0,-1) 上(-1,0)
//
// 位置(0,0) 方向→右: 填1, 前进到(0,1)
// 位置(0,1) 方向→右: 填2, 前进到(0,2)
// 位置(0,2) 方向→右: 下一步(0,3)越界! 转向↓
//           方向→下: 填3, 前进到(1,2)
// 位置(1,2) 方向→下: 填4, 前进到(2,2)
// 位置(2,2) 方向→下: 下一步(3,2)越界! 转向←
//           方向→左: 填5, 前进到(2,1)
// ...以此类推直到填完 n²=9 个数
```

```cpp
class Solution {
public:
    vector<vector<int>> generateMatrix(int n) {
        vector<vector<int>> matrix(n, vector<int>(n, 0));
        // 方向数组：右、下、左、上
        int dx[] = {0, 1, 0, -1};
        int dy[] = {1, 0, -1, 0};
        int dir = 0;  // 当前方向索引，从"右"开始
        int x = 0, y = 0;
        
        for (int num = 1; num <= n * n; num++) {
            matrix[x][y] = num;
            
            // 计算下一步的位置
            int nx = x + dx[dir];
            int ny = y + dy[dir];
            
            // 如果下一步越界或已填过，就右转
            if (nx < 0 || nx >= n || ny < 0 || ny >= n || matrix[nx][ny] != 0) {
                dir = (dir + 1) % 4;  // 右转：方向索引+1，取模循环
                nx = x + dx[dir];
                ny = y + dy[dir];
            }
            
            x = nx;
            y = ny;
        }
        
        return matrix;
    }
};
```

**关键点**：
- 利用 `matrix[nx][ny] != 0` 判断是否已填过，所以矩阵初始化为 0 是必要的。
- 方向数组的顺序必须是"右下左上"（顺时针），对应 `(dir+1)%4` 实现右转。
- 这种方法更通用——如果矩阵不是正方形，或者螺旋起点/方向不同，改动更小。

## 解法对比

| | 边界层剥离 | 方向模拟 |
|---|---|---|
| 思维模型 | 一圈一圈，结构化 | 模拟行走，更直觉 |
| 代码长度 | 稍长（4个循环） | 较短（1个循环） |
| 扩展性 | 适合规则矩形 | 适合任意形状/起点 |
| 面试推荐 | ⭐ 首选，逻辑清晰好讲 | 备选，写起来更短 |
| 出错概率 | 边界收缩容易写错 | 转向判断容易遗漏 |

## 易错点

1. **边界层剥离法中，收缩时机写错**：
   - ✗ 先收缩 `top++`，再填上边 → 跳过了第一行
   - ✓ 先填上边，再 `top++`

2. **方向模拟法中，填数和移动的顺序搞反**：
   - ✗ 先移动再填数 → `(0,0)` 没填，且最后一步越界
   - ✓ 先填当前位置 `matrix[x][y] = num`，再计算下一步位置

3. **n=1 时的特殊情况**：
   - 边界层剥离法：`top=0, bottom=0`，上边循环填了 `(0,0)=1`，然后 `top++` 变成1，后续循环直接跳过。✓ 自然处理。
   - 方向模拟法：循环只执行一次，填 `(0,0)=1`。✓ 自然处理。
   - 两种方法都不需要特殊处理 n=1，但写代码时要**验证**这一点。

4. **边界层剥离法中，下边和左边的遍历方向写反**：
   - ✗ 下边 `for (j = left; j <= right; j++)` → 方向错了，应该从右到左
   - ✓ 下边 `for (j = right; j >= left; j--)`

## 面试追问

**Q1: 这道题和 LeetCode 54（螺旋矩阵 I）有什么区别？**

54 是"给定矩阵，按螺旋顺序读出元素"；59 是"按螺旋顺序填入元素生成矩阵"。核心遍历逻辑完全相同，区别在于一个是读、一个是写。但 54 的矩阵可能不是正方形（m×n），需要额外判断避免中间行/列重复遍历。

**Q2: 如果要求逆时针螺旋（下→右→上→左）怎么改？**

边界层剥离法：把四段遍历的顺序改为 左列↓→下行→→右列↑→上行←。
方向模拟法：把方向数组改为 `{1,0}, {0,1}, {-1,0}, {0,-1}`（下、右、上、左）。

**Q3: 如果矩阵是 m×n 的长方形呢？**

边界层剥离法需要在下边和左边的遍历前加判断 `if (top <= bottom)` 和 `if (left <= right)`，防止只剩一行或一列时重复遍历。这正是 LeetCode 54 需要处理的情况。
