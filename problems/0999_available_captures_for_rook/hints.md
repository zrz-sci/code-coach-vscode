# 999. 可以被一步捕获的棋子数

[./solution.cpp)

## 核心思路

给定 8x8 棋盘，有一个白色车 'R'、若干白色象 'B' 和黑色卒 'p'。车可以上下左右直线移动，遇到其他棋子或边界停止。**找到车的位置，向四个方向扫描，遇到卒 'p' 则计数加一，遇到象 'B' 或边界则停止。**

## 思维链

1. **读完题第一反应** -> 棋盘固定 8x8，找到车的位置，向四个方向搜索即可。棋盘很小，不需要复杂算法。

2. **步骤分析** -> (1) 遍历棋盘找到 'R' 的位置 (r, c)。(2) 从 (r, c) 向上、下、左、右各扫描一条直线。(3) 每个方向遇到第一个非 '.' 的格子就停止：如果是 'p' 则 count++，如果是 'B' 则该方向被阻挡。

3. **时间复杂度** -> 找 'R' 遍历棋盘 O(64)，四个方向各最多走 7 格，总共 O(28)。整体 O(1)（常数时间，因为棋盘大小固定）。

4. **实现细节** -> 用方向数组 `dx = {-1, 1, 0, 0}, dy = {0, 0, -1, 1}` 统一处理四个方向。对每个方向，从 'R' 的位置开始步进，直到越界或遇到非 '.' 格子。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 四方向线性扫描 | 找车位置，向四方向搜索 | O(1) | O(1) | 唯一解法 |

## 关键提示

1. **棋盘大小固定 8x8**：所有操作都是常数时间，不需要考虑优化。重点是代码的清晰性和正确性。

2. **车的移动规则**：车在国际象棋中沿行或列直线移动，遇到第一个棋子就停（如果是敌方棋子则可以吃掉）。本题中白象 'B' 会阻挡车的路径。

3. **四方向扫描演示**：
```
棋盘:
. . . . . . . .
. . . p . . . .
. . . R . . . p
. . . . . . . .
. . . . . . . .
. . . p . . . .
. . . . . . . .
. . . . . . . .

R 在 (2, 3):
  上: (1,3) = 'p' → count++ (捕获)
  下: (3,3)='.' → (4,3)='.' → (5,3)='p' → count++ (捕获)
  左: (2,2)='.' → (2,1)='.' → (2,0)='.' → 越界，停止
  右: (2,4)='.' → (2,5)='.' → (2,6)='.' → (2,7)='p' → count++ (捕获)
  总计: 3 ✓
```

4. **象阻挡的情况**：
```
棋盘:
. . . . . . . .
. p p p p p . .
. p p B p p . .
. p B R B p . .
. p p B p p . .
. p p p p p . .
. . . . . . . .
. . . . . . . .

R 在 (3, 3):
  上: (2,3)='B' → 被象阻挡，停止
  下: (4,3)='B' → 被象阻挡，停止
  左: (3,2)='B' → 被象阻挡，停止
  右: (3,4)='B' → 被象阻挡，停止
  总计: 0 ✓ (四个方向都被象阻挡)
```

5. **方向数组的使用**：`int dx[] = {-1, 1, 0, 0}; int dy[] = {0, 0, -1, 1};` 分别对应上、下、左、右。统一的循环结构避免了四段重复代码。

## 解法详解

### 解法1: 四方向线性扫描 -- O(1) / O(1) -- 唯一且最佳

**思考过程**: 这是一道简单的模拟题。找到车的位置后，向四个方向逐格扫描。

```cpp
class Solution {
public:
    int numRookCaptures(vector<vector<char>>& board) {
        // 第一步：找到车 'R' 的位置
        int rr = 0, rc = 0;
        for (int i = 0; i < 8; i++) {
            for (int j = 0; j < 8; j++) {
                if (board[i][j] == 'R') {
                    rr = i;
                    rc = j;
                }
            }
        }
        
        // 第二步：四个方向扫描
        int count = 0;
        int dx[] = {-1, 1, 0, 0};
        int dy[] = {0, 0, -1, 1};
        
        for (int d = 0; d < 4; d++) {
            int x = rr + dx[d], y = rc + dy[d];
            while (x >= 0 && x < 8 && y >= 0 && y < 8) {
                if (board[x][y] == 'B') break; // 被白象阻挡
                if (board[x][y] == 'p') {       // 遇到黑卒，可捕获
                    count++;
                    break;
                }
                x += dx[d];
                y += dy[d];
            }
        }
        
        return count;
    }
};
```

**关键点**:
- 找 'R' 时可以用 break 提前退出双重循环（用 goto 或标志变量），但 8x8 棋盘无所谓效率。
- 每个方向遇到 'B' 或 'p' 都 break，区别是 'p' 要先 count++。
- '.' 格子继续前进。

---

### 解法1的变体: 不用方向数组，四个循环分开写

**更直白的写法**，每个方向一个 for 循环。代码稍长但意图更明确：

```cpp
class Solution {
public:
    int numRookCaptures(vector<vector<char>>& board) {
        int rr = 0, rc = 0;
        for (int i = 0; i < 8; i++)
            for (int j = 0; j < 8; j++)
                if (board[i][j] == 'R') { rr = i; rc = j; }
        
        int count = 0;
        
        // 向上
        for (int i = rr - 1; i >= 0; i--) {
            if (board[i][rc] == 'B') break;
            if (board[i][rc] == 'p') { count++; break; }
        }
        // 向下
        for (int i = rr + 1; i < 8; i++) {
            if (board[i][rc] == 'B') break;
            if (board[i][rc] == 'p') { count++; break; }
        }
        // 向左
        for (int j = rc - 1; j >= 0; j--) {
            if (board[rr][j] == 'B') break;
            if (board[rr][j] == 'p') { count++; break; }
        }
        // 向右
        for (int j = rc + 1; j < 8; j++) {
            if (board[rr][j] == 'B') break;
            if (board[rr][j] == 'p') { count++; break; }
        }
        
        return count;
    }
};
```

| | 方向数组版 | 四循环版 |
|---|---|---|
| 时间 | O(1) | O(1) |
| 空间 | O(1) | O(1) |
| 代码量 | 中等 | 稍多 |
| 可读性 | 高（结构统一） | 高（意图明确） |
| 面试推荐 | 推荐（展示编码习惯） | 也可以 |

## 易错点

1. **找到 'R' 后忘记停止搜索**
   - 不影响正确性（题目保证只有一个 'R'），但如果面试官注意到可以提一句"找到后可以 break"。

2. **方向扫描时起点从 'R' 自身开始**
   - 应该从 'R' 的下一格开始：`x = rr + dx[d], y = rc + dy[d]`。
   - 如果从 (rr, rc) 开始，第一格就是 'R' 自己。

3. **只检查了 'p' 没检查 'B'**
   - 遇到 'B' 时路径被阻挡，不能穿过象去吃后面的卒。
   - 必须同时检查 'B' 和 'p'，两者都要 break。

4. **方向搞反了**
   - 上是 row 减小 (dx=-1)，下是 row 增大 (dx=1)，左是 col 减小 (dy=-1)，右是 col 增大 (dy=1)。

5. **边界检查遗漏**
   - while 循环条件必须检查 `0 <= x < 8 && 0 <= y < 8`，否则数组越界。

## 面试追问

**Q1: 如果棋盘是 n x n 而不是 8 x 8？**
> 算法完全相同，只是循环边界从 8 改为 n。时间 O(n^2) 找 'R' + O(n) 扫描四方向。总共 O(n^2)。

**Q2: 如果有多个车呢？**
> 分别找到每个车的位置，对每个车做四方向扫描，累加结果。注意车不会阻挡其他车（题目说白棋只有车和象，但如果扩展到多车场景需要考虑互相阻挡）。

**Q3: 如果要模拟完整的国际象棋吃子规则？**
> 需要区分更多棋子类型（王、后、马、兵等），每种有不同的移动规则。马可以跳过棋子，兵只能斜向吃子等。这就变成了设计题/模拟题，重点在清晰的代码结构。

**Q4: 这题有什么边界 case？**
> (1) 'R' 在角落：只有两个方向有效。(2) 所有方向都被 'B' 阻挡：返回 0。(3) 所有方向都有 'p' 紧挨 'R'：返回 4（最大值）。
