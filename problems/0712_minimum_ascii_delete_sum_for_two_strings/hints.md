# 712. 两个字符串的最小ASCII删除和 (Minimum ASCII Delete Sum for Two Strings)

## 核心思路

给定两个字符串 `s1` 和 `s2`，从两个字符串中各删除若干字符使它们相等，要求被删除字符的 ASCII 值之和最小。这是经典 **LCS（最长公共子序列）** 问题的变体 — 不是求最长公共子序列的长度，而是求使两串相等的最小删除代价（代价不是 1 而是字符的 ASCII 值）。

## 思维链

1. **读完题第一反应**：要让两个字符串相等，最终保留的部分一定是两个串的某个**公共子序列**。所以等价于：找一个公共子序列，使得被删除字符的 ASCII 总和最小。

2. **和 LCS 的关系**：
   - LCS 经典问题：找最长公共子序列（最大化保留长度）
   - LC 583：找最少删除次数使两串相同（每次删除代价为 1）
   - 本题：找最小删除 ASCII 和（每次删除代价为字符的 ASCII 值）
   - 本质相同，只是优化目标从"长度"变成了"ASCII 值之和"

3. **DP 状态定义**：
   - `dp[i][j]` = 使 `s1[0..i-1]` 和 `s2[0..j-1]` 相等所需的最小删除 ASCII 和
   - 答案是 `dp[m][n]`，其中 m = s1.length(), n = s2.length()

4. **状态转移**：
   - 如果 `s1[i-1] == s2[j-1]`：这对字符可以保留（不用删），`dp[i][j] = dp[i-1][j-1]`
   - 如果 `s1[i-1] != s2[j-1]`：至少要删一个
     - 删 s1[i-1]：代价 `dp[i-1][j] + ASCII(s1[i-1])`
     - 删 s2[j-1]：代价 `dp[i][j-1] + ASCII(s2[j-1])`
     - 取较小的

5. **边界条件**：
   - `dp[i][0]`：s2 为空，必须删除 s1 的前 i 个字符 → 它们 ASCII 值的累计和
   - `dp[0][j]`：s1 为空，必须删除 s2 的前 j 个字符 → 类似

6. **空间优化**：dp[i][j] 只依赖上一行和当前行，可以压缩到一维数组。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 二维 DP | dp[i][j] 最小删除和 | O(m*n) | O(m*n) | ⭐ 必须写出 |
| 一维 DP（空间优化）| 滚动数组压缩 | O(m*n) | O(min(m,n)) | 加分项 |
| 等价转化（最大ASCII公共子序列） | 总和 - 2*maxLCS_ASCII | O(m*n) | O(m*n) | 思路 |

## 关键提示

1. **字符匹配时不需要删除**：当 `s1[i-1] == s2[j-1]` 时，这对字符一定被保留，`dp[i][j] = dp[i-1][j-1]`。不需要考虑"匹配但还是删掉"的情况，因为保留一定不比删除差。

2. **边界条件是 ASCII 累计和，不是 0**：`dp[i][0]` 不是 0，而是 s1 前 i 个字符的 ASCII 值之和。因为如果 s2 为空，你必须把 s1 的字符全删掉。

3. **和 LCS 的等价关系**：`最小删除和 = s1 的总 ASCII 和 + s2 的总 ASCII 和 - 2 * 最大公共子序列 ASCII 和`。所以也可以反过来求最大 ASCII 公共子序列。

4. **转移方程不取三者的 min**：和经典 LCS 不同，这里不匹配时只有两个选择（删 s1[i-1] 或删 s2[j-1]），不需要 `dp[i-1][j-1] + 两者` 因为删两个一定不比只删一个好。

5. **ASCII 值**：小写字母 'a'=97, ..., 'z'=122。在 C++ 中直接用 `s1[i-1]` 作为 int 就是 ASCII 值。

## 解法详解

### 解法1: 二维 DP — O(m*n) / O(m*n)

**思考过程**：经典的二序列 DP。定义状态，列出转移，填表。

**DP 填表过程（s1 = "sea", s2 = "eat"）**：

```
ASCII: s='s'=115, e='e'=101, a='a'=97, t='t'=116

dp[i][j] = 使 s1[0..i-1] 和 s2[0..j-1] 相等的最小删除 ASCII 和

          ""(j=0)  "e"(j=1)  "ea"(j=2)  "eat"(j=3)
""(i=0)      0      101       198         314
"s"(i=1)    115     216       313         429
"se"(i=2)   216     115       212         328
"sea"(i=3)  313     212       115         231  ← 答案

填表过程:
  dp[0][0] = 0                    (两个空串已经相等)
  dp[1][0] = 115                  (删's', 代价115)
  dp[2][0] = 115+101 = 216       (删"se", 代价216)
  dp[3][0] = 216+97 = 313        (删"sea", 代价313)
  dp[0][1] = 101                  (删'e', 代价101)
  dp[0][2] = 101+97 = 198        (删"ea", 代价198)
  dp[0][3] = 198+116 = 314       (删"eat", 代价314)

  dp[1][1]: s1[0]='s' != s2[0]='e'
    删's': dp[0][1] + 115 = 101+115 = 216
    删'e': dp[1][0] + 101 = 115+101 = 216
    dp[1][1] = min(216, 216) = 216

  dp[2][1]: s1[1]='e' == s2[0]='e'  → dp[1][0] = 115

  dp[2][2]: s1[1]='e' != s2[1]='a'
    删'e': dp[1][2] + 101 = 313+101 = 414
    删'a': dp[2][1] + 97  = 115+97  = 212
    dp[2][2] = 212

  dp[3][2]: s1[2]='a' == s2[1]='a' → dp[2][1] = 115

  dp[3][3]: s1[2]='a' != s2[2]='t'
    删'a': dp[2][3] + 97  = 328+97  = 425
    删't': dp[3][2] + 116 = 115+116 = 231
    dp[3][3] = min(425, 231) = 231 ✓

  最终保留的公共子序列: "ea" (两串都变成 "ea")
  删除: s1 删 's'(115), s2 删 't'(116), 总计 231
```

```cpp
class Solution {
public:
    int minimumDeleteSum(string s1, string s2) {
        int m = s1.size(), n = s2.size();
        // dp[i][j] = 使 s1[0..i-1] 和 s2[0..j-1] 相等的最小删除 ASCII 和
        vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
        
        // 边界: s2 为空，需要删完 s1 的前 i 个字符
        for (int i = 1; i <= m; i++)
            dp[i][0] = dp[i-1][0] + s1[i-1];
        
        // 边界: s1 为空，需要删完 s2 的前 j 个字符
        for (int j = 1; j <= n; j++)
            dp[0][j] = dp[0][j-1] + s2[j-1];
        
        // 填表
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (s1[i-1] == s2[j-1]) {
                    // 匹配：保留这对字符，不需要删除
                    dp[i][j] = dp[i-1][j-1];
                } else {
                    // 不匹配：删 s1[i-1] 或删 s2[j-1]，取较小的
                    dp[i][j] = min(
                        dp[i-1][j] + s1[i-1],   // 删 s1[i-1]
                        dp[i][j-1] + s2[j-1]    // 删 s2[j-1]
                    );
                }
            }
        }
        
        return dp[m][n];
    }
};
```

### 解法2: 一维 DP（空间优化）— O(m*n) / O(n)

**思考过程**：dp[i][j] 只依赖三个位置：`dp[i-1][j-1]`（左上）、`dp[i-1][j]`（正上）、`dp[i][j-1]`（正左）。可以压缩到一维数组，用一个 `prev` 变量保存左上角的值。

**空间优化原理**：

```
二维 DP 依赖关系:
  dp[i][j] 依赖:
    dp[i-1][j-1] ← 左上（上一行、前一列）
    dp[i-1][j]   ← 正上（上一行、同列）
    dp[i][j-1]   ← 正左（同行、前一列）

  压缩为一维 dp[j]:
    "正上" = dp[j]（还没被当前行覆盖）
    "正左" = dp[j-1]（已被当前行覆盖）
    "左上" 需要额外变量 prev 保存

  遍历方向: j 从左到右（因为需要"正左"已更新）
  每次更新前: prev = dp[j]（保存即将被覆盖的"正上"值，作为下一列的"左上"）
```

```cpp
class Solution {
public:
    int minimumDeleteSum(string s1, string s2) {
        int m = s1.size(), n = s2.size();
        // 压缩到一维: dp[j] 代表当前行的 dp[i][j]
        vector<int> dp(n + 1, 0);
        
        // 边界: 第 0 行 (s1为空)
        for (int j = 1; j <= n; j++)
            dp[j] = dp[j-1] + s2[j-1];
        
        // 逐行填充
        for (int i = 1; i <= m; i++) {
            int prev = dp[0];     // 保存 dp[i-1][0]（即"左上"的起始值）
            dp[0] += s1[i-1];    // 更新 dp[i][0] = dp[i-1][0] + s1[i-1]
            
            for (int j = 1; j <= n; j++) {
                int temp = dp[j]; // 保存 dp[i-1][j]（"正上"，即将被覆盖）
                
                if (s1[i-1] == s2[j-1]) {
                    dp[j] = prev;  // dp[i-1][j-1]（左上）
                } else {
                    dp[j] = min(
                        dp[j] + s1[i-1],     // dp[i-1][j] + s1[i-1] （"正上"+删s1）
                        dp[j-1] + s2[j-1]    // dp[i][j-1] + s2[j-1] （"正左"+删s2）
                    );
                }
                
                prev = temp;  // 下一列的"左上" = 当前列的"正上"
            }
        }
        
        return dp[n];
    }
};
```

### 解法3: 等价转化（最大 ASCII 公共子序列）— O(m*n) / O(m*n)

**思考过程**：换一个角度 — 最小化删除的 ASCII 和，等价于最大化保留的 ASCII 和。保留的部分一定是公共子序列。

**等价关系**：
```
总删除 ASCII 和 = sum(s1 所有字符 ASCII) + sum(s2 所有字符 ASCII) - 2 * 公共子序列 ASCII 和
```
要最小化删除和，等价于最大化公共子序列的 ASCII 和。

```cpp
class Solution {
public:
    int minimumDeleteSum(string s1, string s2) {
        int m = s1.size(), n = s2.size();
        
        // 计算两个串的总 ASCII 和
        int totalSum = 0;
        for (char c : s1) totalSum += c;
        for (char c : s2) totalSum += c;
        
        // dp[i][j] = s1[0..i-1] 和 s2[0..j-1] 的最大 ASCII 公共子序列和
        vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
        
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (s1[i-1] == s2[j-1]) {
                    // 匹配: 保留这对字符，加上其 ASCII 值
                    dp[i][j] = dp[i-1][j-1] + s1[i-1];
                } else {
                    // 不匹配: 继承更大的子序列
                    dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
                }
            }
        }
        
        // 最小删除和 = 总和 - 2 * 最大公共子序列ASCII和
        return totalSum - 2 * dp[m][n];
    }
};
```

|------|------|------|-----------|---------|
| 二维 DP（直接定义） | O(m*n) | O(m*n) | 简单 | ⭐⭐⭐ |
| 一维 DP（空间优化） | O(m*n) | O(min(m,n)) | 中等 | 加分项 |
| 等价转化 | O(m*n) | O(m*n) | 简单 | 思维加分 |

**从解法1到解法2的演进逻辑**：
- 解法1：标准二维 DP，状态定义直观
- 解法2：观察到只依赖上一行 → 空间优化到一维
- 解法3：换角度思考（最小化删除 ↔ 最大化保留），本质和 LCS 更接近

**面试策略**：
1. 先说清状态定义和转移方程
2. 写解法1（标准二维 DP）
3. 面试官追问空间优化 → 解法2
4. 面试官追问"和 LCS 的关系" → 解法3

## 易错点

1. **边界条件初始化为 0 而不是 ASCII 累计和**：
   ```cpp
   // ✗ 错误: dp[i][0] 应该是删除 s1 前 i 个字符的代价，不是 0
   dp[i][0] = 0;  // 那 s1 的字符去哪了？
   
   // ✓ 正确: 累计 ASCII 和
   dp[i][0] = dp[i-1][0] + s1[i-1];
   ```

2. **不匹配时取三者最小（多此一举）**：
   ```cpp
   // ✗ 不需要: dp[i-1][j-1] + s1[i-1] + s2[j-1] 一定 >= 其他两个
   dp[i][j] = min({dp[i-1][j] + s1[i-1],
                    dp[i][j-1] + s2[j-1],
                    dp[i-1][j-1] + s1[i-1] + s2[j-1]});  // 第三项多余
   
   // ✓ 正确: 只取两者最小
   dp[i][j] = min(dp[i-1][j] + s1[i-1], dp[i][j-1] + s2[j-1]);
   ```

3. **空间优化忘记保存 prev（左上角）**：
   ```cpp
   // ✗ 错误: dp[j-1] 是"正左"不是"左上"
   if (s1[i-1] == s2[j-1]) dp[j] = dp[j-1];  // 用了更新后的dp[j-1]
   
   // ✓ 正确: 用 prev 保存更新前的 dp[j-1]
   int temp = dp[j];
   if (s1[i-1] == s2[j-1]) dp[j] = prev;
   prev = temp;
   ```

4. **下标偏移混淆**：
   ```cpp
   // ✗ 错误: s1[i] 和 s2[j] 不是当前比较的字符
   if (s1[i] == s2[j])  // 当 i 从 1 开始时，应该用 s1[i-1]
   
   // ✓ 正确: dp 索引比字符串索引多 1
   if (s1[i-1] == s2[j-1])
   ```

## 面试追问

**Q1: 和 LC 583 (Delete Operation for Two Strings) 的区别？**
A1: LC 583 每次删除代价为 1（求最少操作次数），本题每次删除代价为 ASCII 值。LC 583 等价于 `m + n - 2 * LCS长度`，本题等价于 `总ASCII和 - 2 * 最大ASCII公共子序列和`。状态转移结构相同，只是代价函数不同。

**Q2: 能不能用记忆化搜索（top-down DP）来做？**
A2: 可以。定义 `dfs(i, j)` = s1[i..] 和 s2[j..] 相等的最小删除和，用 memo[i][j] 缓存结果。对某些人来说 top-down 更直觉。时间空间复杂度相同。

**Q3: 如果删除操作的代价不是 ASCII 值而是任意权重呢？**
A3: 只需要把转移方程中的 `s1[i-1]` 替换成 `weight[s1[i-1]]` 即可。DP 结构完全不变。

**Q4: 如果要输出具体删了哪些字符（而不只是最小代价）呢？**
A4: 填完 DP 表后，从 dp[m][n] 开始回溯。如果 `s1[i-1] == s2[j-1]`，保留该字符，回到 (i-1, j-1)；否则看 dp[i-1][j] 和 dp[i][j-1] 哪个更小，选择对应方向。

**Q5: 空间优化后还能回溯路径吗？**
A5: 不能。空间优化后丢失了完整的 DP 表，无法回溯。如果需要路径，必须保留完整的二维 DP 表。这是空间优化的 trade-off。
