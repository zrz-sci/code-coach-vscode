# 1762. 能看到海景的建筑物

## 核心思路

本质上在问：**对于每个建筑物，它右边的所有建筑是否都比它矮？** 等价于找出所有"右侧最大值比自己小"的位置——这是一个**后缀最大值**问题。

## 思维链

1. **读完题第一反应**：对于每栋建筑 `i`，检查 `i+1` 到 `n-1` 的所有建筑是否都比它矮。最暴力的做法是对每个 `i` 往右扫一遍。

2. **暴力解的瓶颈**：每栋建筑都要往右扫到底，总共 O(n²)。但其实我们反复在计算"右边最高的建筑是多少"这个信息，有大量重复。

3. **突破瓶颈的关键观察**：一栋建筑能看到海景 ⟺ 它右边所有建筑的最大高度 < 它自己的高度。如果我们**从右往左遍历**，维护一个"已见过的最大高度"变量，就能 O(1) 判断当前建筑能否看到海。

4. **另一个视角——单调栈**：从左往右遍历，维护一个**单调递减栈**（栈底到栈顶高度递减）。遇到更高或等高的建筑，就把栈里矮的弹出（它们被挡住了）。最终栈里剩下的就是能看到海的建筑。

5. **选择最简洁的方案**：从右往左遍历 + 后缀最大值，一个变量搞定，代码最简。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力 | 每栋建筑往右扫描检查 | O(n²) | O(1) | 能说出即可 |
| 从右往左 + 后缀最大值 | 维护右侧最大高度 | O(n) | O(1)* | ⭐ 必须写出 |
| 单调递减栈 | 从左往右维护递减栈 | O(n) | O(n) | 加分项 |

> *O(1) 不计算结果数组的空间

## 关键提示

- **提示1**：最右边的建筑（最后一栋）一定能看到海景——它右边没有任何建筑。这暗示从右往左思考可能更自然。

- **提示2**：如果你已经知道 `i+1` 到 `n-1` 中最高的建筑是 `maxH`，那么建筑 `i` 能看到海 ⟺ `heights[i] > maxH`。这个 `maxH` 怎么递推更新？

- **提示3**：注意"严格矮"——相同高度也会挡住！`[2,2,2,2]` 只有最后一栋能看到海。

- **提示4（单调栈方向）**：能看到海的建筑形成一个从右往左看的"阶梯"——后面的必须比前面的矮。这就是单调递减栈的模式。

```
  建筑示意图 heights = [4,2,3,1]     🌊 海洋在右边
  
  idx:  0   1   2   3
       ┌─┐
       │4│ ┌─┐
       │ │ │ │ ┌─┐
       │ │ │2│ │3│ ┌─┐
       │ │ │ │ │ │ │1│
       └─┘ └─┘ └─┘ └─┘ ~~~🌊
  
  从右往左看：
  - idx=3: maxRight=0, 1>0 ✓, 更新 maxRight=1
  - idx=2: maxRight=1, 3>1 ✓, 更新 maxRight=3
  - idx=1: maxRight=3, 2>3 ✗ (被挡住了)
  - idx=0: maxRight=3, 4>3 ✓, 更新 maxRight=4
  
  结果: [0, 2, 3]
```

## 解法详解

### 解法1: 暴力 — O(n²) / O(1)

**思考过程**：最直觉的做法——对于每栋建筑，往右扫描看是否有建筑 ≥ 它的高度。如果没有，就能看到海。

```cpp
class Solution {
public:
    vector<int> findBuildings(vector<int>& heights) {
        int n = heights.size();
        vector<int> result;
        for (int i = 0; i < n; i++) {
            bool canSee = true;
            for (int j = i + 1; j < n; j++) {
                // 注意：>=，相同高度也挡住
                if (heights[j] >= heights[i]) {
                    canSee = false;
                    break;
                }
            }
            if (canSee) result.push_back(i);
        }
        return result;
    }
};
```

**关键点**：判断条件是 `>=` 不是 `>`，因为相同高度也算被挡住。这个解法虽然能过小数据，但 n=10⁵ 时 O(n²) 会超时。

---

### 解法2: 从右往左 + 后缀最大值 — O(n) / O(1) ⭐ 面试首选

**从解法1优化**：解法1的瓶颈是每栋建筑都要往右扫一遍找最大值。但注意：`maxRight[i] = max(heights[i+1], maxRight[i+1])`，这是一个递推关系！从右往左走一遍就够了。

```cpp
class Solution {
public:
    vector<int> findBuildings(vector<int>& heights) {
        int n = heights.size();
        vector<int> result;
        int maxRight = 0;  // 当前位置右边所有建筑的最大高度
        
        // 从右往左遍历
        for (int i = n - 1; i >= 0; i--) {
            // 能看到海 ⟺ 我比右边所有建筑都高（严格大于）
            if (heights[i] > maxRight) {
                result.push_back(i);
                maxRight = heights[i];  // 更新右侧最大值
            }
        }
        
        // 从右往左加入的，需要反转成升序
        reverse(result.begin(), result.end());
        return result;
    }
};
```

**关键点**：
- `maxRight` 初始化为 0（不是 INT_MIN），因为最右边建筑右边没有任何建筑，所以 maxRight=0，而 heights[i] >= 1，一定满足条件。
- 结果是倒序收集的，最后要 `reverse`。

---

### 解法3: 单调递减栈 — O(n) / O(n)

**换个视角**：从左往右遍历，维护一个栈，栈中存储"目前为止可能看到海的建筑的下标"。核心思想：如果新来的建筑 ≥ 栈顶建筑，那栈顶建筑就被挡住了，弹出。遍历完后栈里留下的就是答案。

```
  单调栈过程 heights = [4,2,3,1]:
  
  i=0: heights[0]=4, 栈空     → push 0      栈: [0]       (高度: 4)
  i=1: heights[1]=2, 2<4      → push 1      栈: [0,1]     (高度: 4,2)
  i=2: heights[2]=3, 3>=2     → pop 1       栈: [0]       (2被3挡住了)
       3<4                    → push 2      栈: [0,2]     (高度: 4,3)
  i=3: heights[3]=1, 1<3      → push 3      栈: [0,2,3]   (高度: 4,3,1)
  
  结果: [0, 2, 3] ✓
```

```cpp
class Solution {
public:
    vector<int> findBuildings(vector<int>& heights) {
        int n = heights.size();
        stack<int> stk;  // 存下标，维护单调递减（栈底到栈顶高度递减）
        
        for (int i = 0; i < n; i++) {
            // 当栈顶建筑 <= 当前建筑时，栈顶被挡住，弹出
            while (!stk.empty() && heights[stk.top()] <= heights[i]) {
                stk.pop();
            }
            stk.push(i);
        }
        
        // 栈中元素就是答案（从栈底到栈顶是升序下标）
        vector<int> result(stk.size());
        for (int i = result.size() - 1; i >= 0; i--) {
            result[i] = stk.top();
            stk.pop();
        }
        return result;
    }
};
```

**关键点**：弹出条件是 `<=`（等高也弹出），因为题目说"严格矮"才能看到海。

## 解法对比

| | 解法1: 暴力 | 解法2: 后缀最大值 | 解法3: 单调栈 |
|---|---|---|---|
| 时间 | O(n²) | O(n) | O(n) |
| 空间 | O(1) | O(1) | O(n) |
| 遍历方向 | 左→右，每个向右扫 | 右→左 | 左→右 |
| 代码量 | 最多 | 最少 | 中等 |
| 面试推荐 | 说思路即可 | ⭐首选 | 展示单调栈能力 |

**解法2 vs 解法3**：解法2更简洁高效（O(1) 额外空间），面试优先写解法2。解法3的价值在于展示单调栈思维，如果面试官追问"你知道单调栈吗"可以给出。

## 易错点

1. **相同高度判断错误**
   - ✗ `if (heights[j] > heights[i])` — 漏掉了等高的情况
   - ✓ `if (heights[j] >= heights[i])` — 等高也挡住视线
   - 题目明确说"右边所有建筑都比它**矮**"，等高不算矮

2. **后缀最大值初始化错误**
   - ✗ `int maxRight = INT_MIN;` — 会导致最后一栋建筑的判断出问题（虽然 heights[i]>=1 也能过，但语义不对）
   - ✓ `int maxRight = 0;` — 最后一栋右边没有建筑，"最大高度"为 0

3. **忘记反转结果**
   - 从右往左遍历收集的结果是降序的，题目要求升序
   - ✗ 直接返回 result
   - ✓ `reverse(result.begin(), result.end());`

4. **单调栈弹出条件写反**
   - ✗ `heights[stk.top()] < heights[i]` — 等高的不弹出，会多算
   - ✓ `heights[stk.top()] <= heights[i]` — 等高也要弹出

## 面试追问

**Q1: 暴力解的时间复杂度是多少？能否接受？**
A: O(n²)，n=10⁵ 时约 10¹⁰ 次操作，会超时。需要优化到 O(n)。

**Q2: 如果要求 O(1) 额外空间（不算结果数组），怎么做？**
A: 从右往左遍历，维护一个 `maxRight` 变量即可（解法2）。每个建筑只需和 `maxRight` 比较。

**Q3: 如果建筑物之间不是直线排列，而是在二维平面上，海洋在东边，怎么处理？**
A: 按 x 坐标排序后，相同 x 坐标的取最高。然后对有序序列做同样的后缀最大值判断。需要考虑"完全遮挡"的几何判断。

**Q4: 如果数组可以动态增加/删除建筑，如何高效维护结果？**
A: 可以用平衡 BST（如 `std::set`）维护一个从右往左的递减序列。插入/删除时维护不变量，每次操作 O(log n)。
