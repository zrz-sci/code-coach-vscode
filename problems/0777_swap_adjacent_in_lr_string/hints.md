# 777. 在 LR 字符串中交换相邻字符 (Swap Adjacent in LR String)

## 核心思路

本题本质是一个**不变量分析 + 双指针**问题。关键洞察：`L` 只能向左滑动（跨越 `X`），`R` 只能向右滑动（跨越 `X`），且 `L` 和 `R` 的相对顺序永远不会改变。因此可以忽略所有 `X`，检查 `L` 和 `R` 的相对顺序是否一致，再用双指针逐一比对每个 `L`/`R` 的位置约束。

## 思维链

1. **理解操作本质**：`XL -> LX` 意味着 `L` 向左移动一格；`RX -> XR` 意味着 `R` 向右移动一格。
2. **发现不变量**：去掉所有 `X` 后，`start` 和 `result` 的非 `X` 字符序列必须完全相同。
3. **位置约束**：对于每一对匹配的字符：
   - 如果是 `L`：`start` 中的位置 >= `result` 中的位置（`L` 只能左移）
   - 如果是 `R`：`start` 中的位置 <= `result` 中的位置（`R` 只能右移）
4. **双指针验证**：同时遍历 `start` 和 `result`，跳过 `X`，逐一检查上述约束。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 双指针法 | O(n) | O(1) | 最优解，直接在原字符串上操作 |
| 提取位置法 | O(n) | O(n) | 先提取所有 L/R 的位置，再逐一比对 |

## 关键提示

1. 先做快速判断：将 `start` 和 `result` 中的 `X` 全部去掉后，剩余字符串必须相同
2. `L` 和 `R` 不能互相穿越，这是隐含的不变量
3. 双指针移动时，跳过 `X` 字符，只在 `L`/`R` 位置停下做比较
4. 注意循环结束后的状态：两个指针必须同时到达末尾（或都只剩 `X`）

## 解法详解

### 解法一：双指针法（推荐）

**核心思想**：使用两个指针 `i` 和 `j` 分别遍历 `start` 和 `result`。每次都跳过 `X`，找到下一个 `L` 或 `R`，然后检查：
- 两者字符必须相同（不变量）
- 如果是 `L`，则 `i >= j`（L 只能左移）
- 如果是 `R`，则 `i <= j`（R 只能右移）

**算法步骤**：
1. 初始化 `i = 0, j = 0`
2. 循环执行：
   - `i` 跳过 `start` 中的 `X`
   - `j` 跳过 `result` 中的 `X`
   - 如果一个到达末尾而另一个没有 -> 返回 false
   - 如果都到达末尾 -> 返回 true
   - 比较 `start[i]` 和 `result[j]`，检查位置约束
   - `i++, j++`

### 解法二：提取位置法

**核心思想**：将所有非 `X` 字符连同其位置提取出来，形成 `(char, index)` 对的列表，然后逐一比对。

**算法步骤**：
1. 遍历 `start`，收集 `(char, index)` 到列表 `s_pairs`
2. 遍历 `result`，收集 `(char, index)` 到列表 `r_pairs`
3. 如果两个列表长度不同 -> false
4. 逐一比对：字符相同 + 位置满足移动约束

## 易错点

1. **忘记检查字符序列一致性**：光检查位置不够，必须先确认去掉 `X` 后的序列相同
2. **位置约束方向搞反**：`L` 是 `start_pos >= result_pos`（左移），`R` 是 `start_pos <= result_pos`（右移），千万不要搞反
3. **循环结束条件不严谨**：两个指针必须同时耗尽所有非 `X` 字符，一个有剩余非 `X` 而另一个没有时必须返回 false
4. **忽略 L 和 R 不能穿越**：虽然这个约束被"去掉 X 后序列相同"隐式保证了，但理解这个不变量对于证明算法正确性很重要
5. **边界情况**：空字符串、全 `X` 字符串、只有 `L` 或只有 `R` 的情况

## 面试追问

1. **为什么 L 和 R 不能互相穿越？**
   - 回答：操作 `XL -> LX` 和 `RX -> XR` 中，L 和 R 只与 X 交换位置。没有任何操作能让 L 和 R 互相越过，因为不存在 `RL -> LR` 或 `LR -> RL` 的操作。

2. **能否用 BFS/DFS 暴力搜索？**
   - 可以，但时间复杂度是指数级的。每个状态可以有多个转移，状态空间极大。双指针解法是 O(n) 的最优解。

3. **如果增加操作 `LR -> RL`，问题会如何变化？**
   - 那么 L 和 R 可以互相穿越，问题退化为只需要检查 L 和 R 的数量是否相同。

4. **如何证明算法的正确性？**
   - 充分性：如果三个条件都满足（序列相同、L 位置约束、R 位置约束），可以构造性地证明存在一个合法的操作序列。
   - 必要性：每个操作都不改变非 X 字符的相对顺序，L 只能左移，R 只能右移，因此三个条件都是必要的。

5. **这道题和"括号匹配"有什么联系？**
   - 都是不变量分析的思路：找到操作不改变的性质，用不变量做快速判断。
