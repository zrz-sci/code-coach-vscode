# 面试题 02.05. 链表求和 (Sum Lists LCCI)

[LeetCode 链接](https://leetcode.com/problems/sum-lists-lcci/)

## 题目理解

给定两个用链表表示的整数，每个节点包含一个数位。数位是**反向存储**的（个位在链表头部）。编写函数对这两个整数求和，并用链表形式返回结果。

```
示例:
  (7 -> 1 -> 6) + (5 -> 9 -> 2)
   即 617       +  295
                = 912
  输出: 2 -> 1 -> 9

链表存储方式 (逆序):
  数字 617: 个位7 → 十位1 → 百位6
  链表:     [7] -> [1] -> [6] -> null
             ^个位   ^十位   ^百位
```

**进阶**：如果数位是**正向存储**的（高位在链表头），又该如何解决？

**关键约束**：
- 链表长度可能不同
- 需要处理进位（carry）
- 最高位可能产生额外进位（如 999 + 1 = 1000）
- 不能转成整数再加（链表可能很长，超出整数范围）

## 第一步提示：类比小学竖式加法

<details>
<summary>展开提示</summary>

这道题的本质就是**模拟竖式加法**。

```
竖式加法:
    6 1 7
  + 2 9 5
  ─────────
    9 1 2

从右往左 (个位到高位) 逐位相加, 进位向左传递:
  个位: 7 + 5 = 12 → 写2, 进位1
  十位: 1 + 9 + 1(进位) = 11 → 写1, 进位1
  百位: 6 + 2 + 1(进位) = 9 → 写9, 进位0
```

**链表恰好是逆序存储**，所以从链表头开始遍历就是从个位开始——和竖式加法方向一致！不需要翻转链表。

</details>

## 第二步提示：哨兵节点 (dummy) 简化代码

<details>
<summary>展开提示</summary>

**问题**：构建结果链表时，第一个节点需要特殊处理（没有前驱节点）。

**解决**：创建一个 dummy 哨兵节点作为"伪头"：

```
不用 dummy (需要特判):
  ListNode* head = nullptr;
  ListNode* cur = nullptr;
  
  // 第一个节点
  head = new ListNode(digit);
  cur = head;
  
  // 后续节点
  cur->next = new ListNode(digit);
  cur = cur->next;

用 dummy (统一处理):
  ListNode dummy(0);      ← 伪头节点, 值不重要
  ListNode* cur = &dummy;
  
  // 所有节点统一:
  cur->next = new ListNode(digit);
  cur = cur->next;
  
  return dummy.next;      ← 跳过伪头, 返回真正的头
```

**指针关系图**：
```
   dummy ──→ [7] ──→ [0] ──→ [8] ──→ null
     |                              |
     └── 伪头(不是结果的一部分)     └── 结果尾部

   返回: dummy.next = [7] -> [0] -> [8]
```

</details>

## 第三步提示：统一循环条件

<details>
<summary>展开提示</summary>

核心循环条件：`while (l1 || l2 || carry)`

这一行覆盖了**所有情况**：

```
情况 1: 两链表都未遍历完
  l1 有值, l2 有值, carry 可能 0 或 1
  → 继续

情况 2: l1 遍历完, l2 还有 (链表长度不同)
  l1 = null, l2 有值
  → 继续, l1 的值视为 0

情况 3: 两链表都遍历完, 但还有进位
  l1 = null, l2 = null, carry = 1
  → 继续, 创建进位节点

  示例: 999 + 1 = 1000
  三轮循环后: [0] -> [0] -> [0], carry=1
  第四轮: sum=1, 创建 [1]
  结果: [0] -> [0] -> [0] -> [1]
```

**不用这个技巧的话**，需要在循环后额外判断：
```cpp
// 冗余写法:
while (l1 && l2) { ... }
while (l1) { ... }       // 处理 l1 剩余
while (l2) { ... }       // 处理 l2 剩余
if (carry) { ... }       // 处理最终进位
```

</details>

<details>
<summary>展开提示</summary>

```
输入: l1 = [2, 4, 3]  (表示 342)
      l2 = [5, 6, 4]  (表示 465)
      期望: 342 + 465 = 807 → [7, 0, 8]

==================================================================
初始状态:
==================================================================

  l1:    [2] ──→ [4] ──→ [3] ──→ null
          ^

  l2:    [5] ──→ [6] ──→ [4] ──→ null
          ^

  dummy:  [0] ──→ null
           ^
           cur

  carry = 0

==================================================================
第 1 轮: 个位相加
==================================================================

  sum = carry(0) + l1->val(2) + l2->val(5) = 7
  carry = 7 / 10 = 0

  创建新节点 [7], 接到 cur 后面:

  l1:    [2] ──→ [4] ──→ [3] ──→ null
                  ^

  l2:    [5] ──→ [6] ──→ [4] ──→ null
                  ^
                  l2 (前进一步)

  dummy:  [0] ──→ [7] ──→ null
                   ^
                   cur (前进一步)

==================================================================
第 2 轮: 十位相加
==================================================================

  sum = carry(0) + l1->val(4) + l2->val(6) = 10
  carry = 10 / 10 = 1    ← 产生进位!
  digit = 10 % 10 = 0

  l1:    [2] ──→ [4] ──→ [3] ──→ null
                          ^
                          l1

  l2:    [5] ──→ [6] ──→ [4] ──→ null
                          ^
                          l2

  dummy:  [0] ──→ [7] ──→ [0] ──→ null
                           ^
                           cur

==================================================================
第 3 轮: 百位相加
==================================================================

  sum = carry(1) + l1->val(3) + l2->val(4) = 8
  carry = 8 / 10 = 0
  digit = 8 % 10 = 8

  l1:    null (遍历完毕)
  l2:    null (遍历完毕)

  dummy:  [0] ──→ [7] ──→ [0] ──→ [8] ──→ null
                                    ^
                                    cur

==================================================================
循环结束: l1=null, l2=null, carry=0  → 全部为假, 退出
==================================================================

  返回 dummy.next = [7] ──→ [0] ──→ [8]
  即 807, 验证: 342 + 465 = 807 ✓
```

## 第五步提示：进位传播的特殊情况

<details>
<summary>展开提示</summary>

```
进位连锁: l1 = [9, 9, 9], l2 = [1]  (999 + 1 = 1000)

==================================================================
第 1 轮: sum = 0 + 9 + 1 = 10, carry=1, digit=0
  l1: [9]->[9]->[9]->null     l2: [1]->null
       l1→[9]->[9]->null           l2→null
  result: [0]

第 2 轮: sum = 1 + 9 + 0 = 10, carry=1, digit=0
  l1: →[9]->null              l2: null (视为 0)
  result: [0] -> [0]

第 3 轮: sum = 1 + 9 + 0 = 10, carry=1, digit=0
  l1: null                    l2: null
  result: [0] -> [0] -> [0]

第 4 轮: sum = 1 + 0 + 0 = 1, carry=0, digit=1
  (这轮由 carry=1 触发, l1 和 l2 都是 null!)
  result: [0] -> [0] -> [0] -> [1]
==================================================================

结果: 0001 (逆序) = 1000 ✓

关键: 如果循环条件不包含 carry, 会漏掉最后的 [1] 节点!
```

</details>

## 第六步提示：进阶 -- 正向存储

<details>
<summary>展开提示</summary>

如果数位是正向存储（高位在头部），有三种解法：

**方法 1：翻转链表**
```
(6 -> 1 -> 7) + (2 -> 9 -> 5)   正向存储

翻转 → (7 -> 1 -> 6) + (5 -> 9 -> 2)   变成逆序
相加 → (2 -> 1 -> 9)                    逆序结果
翻转 → (9 -> 1 -> 2)                    正向结果
```

**方法 2：用栈**
```
l1: 6 -> 1 -> 7    入栈 → [6, 1, 7]  (栈顶=7=个位)
l2: 2 -> 9 -> 5    入栈 → [2, 9, 5]  (栈顶=5=个位)

从栈顶开始逐位相加, 用头插法构建结果:
  7+5=12: carry=1, 头插[2]       result: [2]
  1+9+1=11: carry=1, 头插[1]    result: [1]->[2]
  6+2+1=9: carry=0, 头插[9]     result: [9]->[1]->[2]
```

**方法 3：递归（先对齐长度）**
```
先计算长度差, 短链表前面补零对齐
递归到最低位, 回溯时处理进位
```

</details>

## 思维链总结

```
输入: 两个逆序链表 l1, l2

Step 1: 创建哨兵节点 dummy, 指针 cur = dummy, carry = 0
Step 2: while (l1 || l2 || carry):
  ┌─ sum = carry
  ├─ if (l1): sum += l1->val, l1 = l1->next
  ├─ if (l2): sum += l2->val, l2 = l2->next
  ├─ carry = sum / 10
  └─ cur->next = new Node(sum % 10), cur = cur->next
Step 3: 返回 dummy.next
```

## 完整代码

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        ListNode dummy(0);
        ListNode* cur = &dummy;
        int carry = 0;

        while (l1 || l2 || carry) {
            int sum = carry;
            if (l1) { sum += l1->val; l1 = l1->next; }
            if (l2) { sum += l2->val; l2 = l2->next; }

            carry = sum / 10;
            cur->next = new ListNode(sum % 10);
            cur = cur->next;
        }

        return dummy.next;
    }
};
```

## 解法对比

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 迭代 + 哨兵节点 | O(max(m,n)) | O(max(m,n)) | 推荐，最直观 |
| 递归 | O(max(m,n)) | O(max(m,n)) 栈 | 简洁但栈开销 |
| 翻转 + 加 + 翻转 (进阶) | O(max(m,n)) | O(1) 额外 | 正向存储时适用 |
| 栈法 (进阶) | O(max(m,n)) | O(m+n) | 不修改原链表 |

## 复杂度分析

- 时间：O(max(m, n))，m 和 n 分别是两个链表的长度
- 空间：O(max(m, n))，结果链表长度最多为 max(m, n) + 1

## 常见错误

1. **忘记最后的进位**：`999 + 1 = 1000`，最后 carry=1 需要创建新节点
2. **链表长度不等时越界**：必须判断 `l1 != nullptr` 才能取 `l1->val`
3. **忘记推进指针**：`l1 = l1->next` 容易遗漏，导致死循环
4. **修改原链表**：应创建新节点，不要修改输入链表的值
5. **试图转成整数再加**：链表可能很长，超出 long long 范围

## 知识点

- **哨兵节点 (Dummy Node)**：简化链表头部处理的经典技巧
- **进位处理**：`carry = sum / 10`, `digit = sum % 10`
- **统一循环条件**：`while (l1 || l2 || carry)` 覆盖所有边界
- **链表反转**：进阶正向存储时用到
