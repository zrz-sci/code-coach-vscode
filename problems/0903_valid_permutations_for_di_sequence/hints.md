# 903. 有效的 DI 序列排列 (Valid Permutations for DI Sequence)

## 核心思路

本题本质上是：**给定一个由 'D'(递减) 和 'I'(递增) 组成的模式串，计算满足该模式的 [0,n] 排列数**。使用**动态规划**，其中 `dp[i][j]` 表示前 i+1 个位置已经放好，且第 i 个位置放的是剩余可用数中第 j 小的数的方案数。用**前缀和**优化转移到 O(n^2)。

## 思维链

1. **读完题的第一反应**：暴力枚举所有 (n+1)! 排列再逐个检查？n 最大 200，这完全不可行。需要 DP。

2. **关键观察 -- "相对大小"才重要**：我们不关心具体放了哪些数，只关心当前放的数在"剩余未用的数"中排第几。比如剩余 {0,2,4} 中放 2，等价于放"第 1 小的"（0-indexed）。

3. **DP 状态定义**：`dp[i][j]` = 已经填好前 i+1 个位置（即 perm[0..i]），且 perm[i] 是**剩余可用数中第 j 小**的方案数。初始时 n+1 个数全部可用，填到位置 i 时还剩 n+1-i 个数可选。

4. **DP 转移**：
   - 如果 `s[i] == 'D'`（perm[i] > perm[i+1]），那么 perm[i+1] 必须比 perm[i] 小。如果 perm[i] 是第 j 小，删除它后，perm[i+1] 可以是新剩余中第 0, 1, ..., j-1 小的 → `dp[i+1][k] += dp[i][j]` 对于 `k < j`（但因为删了一个，新排名要调整，实际上 `k` 的范围是 `[0, j-1]`）
   - 如果 `s[i] == 'I'`（perm[i] < perm[i+1]），那么 perm[i+1] 必须比 perm[i] 大。删除 perm[i] 后，原本排在它上面的数排名各减 1，所以 perm[i+1] 的新排名 k 对应的范围是 `[j, remaining-1]`

5. **前缀和优化**：直接转移是 O(n^3)，但每一步的转移都是对 dp[i] 的一段连续区间求和，可以用前缀和优化到 O(n^2)。

6. **最终答案**：`sum(dp[n][j])` 对所有 j。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| DP + 前缀和 | dp[i][j]=第i位放第j小 | O(n^2) | O(n^2) 或 O(n) | ⭐ 必须写出 |
| DP 空间优化 | 滚动数组优化到 O(n) | O(n^2) | O(n) | 能说出加分 |
| 暴力 DFS + 记忆化 | 枚举每个位置放什么 | O(n * 2^n) | O(n * 2^n) | 仅分析思路 |

## 关键提示

1. **"相对排名"是突破口**：不要纠结于具体放了哪些数字。只要知道当前放的数在"剩余数中排第几"，就能完全确定转移关系。这把状态空间从指数级降到了多项式级。

2. **转移方向**：
   - `s[i] == 'D'` → 下一个数的排名更小 → `dp[i+1][k] = sum(dp[i][k+1..n-i])`
   - `s[i] == 'I'` → 下一个数的排名不变或更大 → `dp[i+1][k] = sum(dp[i][0..k])`

3. **前缀和加速**：预计算 `prefix[j] = dp[i][0] + dp[i][1] + ... + dp[i][j]`，区间和就是 O(1)。

4. **取模**：每一步加法都要对 10^9+7 取模，避免溢出。

5. **ASCII 示意 -- "DID" 的 DP 表**：
```
s = "DID", 数集 {0,1,2,3}

dp[0]: 位置0可以放第0~3小的 → [1,1,1,1]  (各1种方案)

s[0]='D' → perm[0]>perm[1]
dp[1][j] = sum(dp[0][j+1..3])
dp[1][0] = dp[0][1]+dp[0][2]+dp[0][3] = 3
dp[1][1] = dp[0][2]+dp[0][3] = 2
dp[1][2] = dp[0][3] = 1
dp[1] = [3,2,1]

s[1]='I' → perm[1]<perm[2]
dp[2][j] = sum(dp[1][0..j])
dp[2][0] = dp[1][0] = 3
dp[2][1] = dp[1][0]+dp[1][1] = 5
dp[2] = [3,5]  (只剩2个位可填)

s[2]='D' → perm[2]>perm[3]
dp[3][j] = sum(dp[2][j+1..1])
dp[3][0] = dp[2][1] = 5
dp[3] = [5]

答案: sum(dp[3]) = 5 ✓
```

## 解法详解

### 解法1: DP + 前缀和优化 -- O(n^2) / O(n) ⭐ 面试首选

**思考过程**：

核心洞察：**第 i 个位置放的数在"剩余数中的相对排名"就是全部需要的信息**。转移时 'D' 对应"前缀和的尾部"，'I' 对应"前缀和的头部"。

```cpp
class Solution {
public:
    int numPermsDISequence(string s) {
        int n = s.size();
        long long MOD = 1e9 + 7;
        
        // dp[j] = 当前位置放"剩余数中第j小"的方案数
        // 初始: 位置0可以放0~n中任意一个，各1种
        vector<long long> dp(n + 1, 1);
        
        for (int i = 0; i < n; i++) {
            vector<long long> ndp(n - i, 0);
            
            if (s[i] == 'D') {
                // perm[i] > perm[i+1]
                // ndp[j] = sum(dp[j+1 .. n-i])
                // 从右到左累积后缀和
                long long suffix = 0;
                for (int j = n - i - 1; j >= 0; j--) {
                    suffix = (suffix + dp[j + 1]) % MOD;
                    ndp[j] = suffix;
                }
            } else {
                // perm[i] < perm[i+1]
                // ndp[j] = sum(dp[0 .. j])
                // 从左到右累积前缀和
                long long prefix = 0;
                for (int j = 0; j < n - i; j++) {
                    prefix = (prefix + dp[j]) % MOD;
                    ndp[j] = prefix;
                }
            }
            
            dp = ndp;
        }
        
        // 最终只剩1个数可放，答案就是 dp[0]
        return dp[0];
    }
};
```

**关键点**：
- 用滚动数组将空间优化到 O(n)
- 'D' 用后缀和，'I' 用前缀和，避免了 O(n^3) 的暴力求和
- 每轮 dp 的长度减少 1（因为可用数字少了一个）

### 解法2: 2D DP 完整版 -- O(n^2) / O(n^2)

**从更直观的角度**：保留完整的二维 DP 表，便于理解和调试。

```cpp
class Solution {
public:
    int numPermsDISequence(string s) {
        int n = s.size();
        long long MOD = 1e9 + 7;
        
        // dp[i][j]: 前i+1个位置填好，位置i放的是剩余数中第j小
        vector<vector<long long>> dp(n + 1, vector<long long>(n + 1, 0));
        
        // 初始: 位置0，可放0~n中任一个
        for (int j = 0; j <= n; j++) dp[0][j] = 1;
        
        for (int i = 1; i <= n; i++) {
            if (s[i - 1] == 'D') {
                // 后缀和: dp[i][j] = sum(dp[i-1][j+1..n-i+1])
                long long suffix = 0;
                for (int j = n - i; j >= 0; j--) {
                    suffix = (suffix + dp[i - 1][j + 1]) % MOD;
                    dp[i][j] = suffix;
                }
            } else {
                // 前缀和: dp[i][j] = sum(dp[i-1][0..j])
                long long prefix = 0;
                for (int j = 0; j <= n - i; j++) {
                    prefix = (prefix + dp[i - 1][j]) % MOD;
                    dp[i][j] = prefix;
                }
            }
        }
        
        // 答案: 最后一个位置只有1个数可放
        return dp[n][0];
    }
};
```

## 易错点

1. **✗ DP 转移方向搞反**：'D' 应该用后缀和（新排名 < 旧排名），'I' 应该用前缀和（新排名 >= 旧排名的对应位）。搞反会导致 WA。
   **✓ 记忆口诀**：D=Descend=后缀(从大到小)，I=Increase=前缀(从小到大)。

2. **✗ 忘记取模导致溢出**：dp 值可能非常大，每次加法后都必须 `% MOD`。
   **✓ 每一步累加都取模**：`suffix = (suffix + dp[j+1]) % MOD;`

3. **✗ 循环边界错误**：第 i 轮 dp 的有效范围是 `[0, n-i]`（剩余 n-i+1 个数可选）。如果边界写错会数组越界或漏算。
   **✓ 每轮可选数量 = n - i + 1，索引范围 [0, n-i]

4. **✗ 混淆"绝对值"和"相对排名"**：dp 中的 j 不是具体数字，是**在剩余可用数字中的排名**。每放一个数，剩余集合变了，排名也会变。

## 面试追问

**Q1: 为什么用"相对排名"而不是"具体数字"作为状态？**
→ 如果用具体数字，状态需要记录"哪些数字已经用过"，这是一个子集状态，复杂度 O(n * 2^n)。而"相对排名"的关键洞察是：排列的合法性只取决于相对大小关系，不取决于具体值。这把状态从指数级压缩到了 O(n^2)。

**Q2: 能否用组合数学/数论方法代替 DP？**
→ 可以用"交错排列"(alternating permutation) 相关的数论结论，但对一般的 DI 模式串没有简洁闭合公式。DP 是最通用的解法。对于全 D 或全 I 的特殊情况，答案就是 1。

**Q3: 如果 n 增大到 10^4，O(n^2) 够吗？有更快的方法吗？**
→ O(n^2) 对 n=200 绰绰有余。对更大的 n，可以研究分治 + NTT 的方法将某些子问题加速到 O(n log^2 n)，但这远超面试范围。
