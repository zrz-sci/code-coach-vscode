# 150. 逆波兰表达式求值

## 核心思路

逆波兰表达式（后缀表达式）天然适合用栈来求值：遇到数字压栈，遇到运算符弹出两个操作数计算后将结果压回栈。本质上就是**用栈模拟表达式的求值过程**。

## 思维链

1. **读完题第一反应**：逆波兰表达式是什么？它和我们平时写的中缀表达式有什么区别？关键特征是"运算符在操作数后面"，所以当我遇到一个运算符时，它要操作的两个数一定已经出现过了。

2. **怎么知道运算符操作哪两个数？** 对于 `["2","1","+"]`，遇到 `+` 时，它操作的是最近的两个数 `2` 和 `1`。"最近"——这不就是**后进先出**吗？

3. **栈的直觉浮现**：数字入栈，遇到运算符时弹出栈顶两个元素进行运算，结果压回栈。这样中间结果也被当作"数字"参与后续计算。

4. **验证思路**：用 `["4","13","5","/","+"]` 走一遍：
   - `4` 入栈 → [4]
   - `13` 入栈 → [4, 13]
   - `5` 入栈 → [4, 13, 5]
   - `/` → 弹出 5 和 13，计算 13/5=2，压入 → [4, 2]
   - `+` → 弹出 2 和 4，计算 4+2=6，压入 → [6]
   - 结果 = 6 ✓

5. **注意操作数顺序**：栈顶是第二个操作数（右操作数），栈顶下面才是第一个操作数（左操作数）。对减法和除法来说顺序很关键！

6. **遍历一遍完成，时间 O(n)，空间 O(n)**。这已经是最优解了。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 栈模拟 | 数字入栈，遇运算符弹两个操作数计算后压回 | O(n) | O(n) | ⭐ 必须写出 |
| 递归（逆向构建表达式树） | 从右往左递归解析 | O(n) | O(n) | 加分项 |

## 关键提示

1. **操作数的顺序**：弹出的第一个是右操作数，第二个才是左操作数。`a - b` 中 `a` 先入栈后弹出在下面，`b` 后入栈先弹出在上面。
2. **如何判断 token 是数字还是运算符？** 不能简单看长度——负数如 `"-11"` 也是数字。可以用 `stoi` 直接转换，也可以判断：长度 > 1 或者第一个字符是数字。
3. **除法向零截断**：C++ 的整数除法默认就是向零截断（如 `-7/2 = -3`），所以直接用 `/` 就对了。
4. **栈中最终只剩一个元素**：题目保证输入合法，所以遍历完后栈里恰好剩一个数就是结果。

```
// 示例 ["2","1","+","3","*"] 的栈变化过程:
//
// Token:   "2"    "1"    "+"    "3"    "*"
//          ┌─┐
//          │1│   弹出1,2           ┌─┐
//  ┌─┐     ├─┤   计算2+1=3  ┌─┐   │3│   弹出3,3
//  │2│     │2│   压入3      │3│   ├─┤   计算3*3=9  ┌─┐
//  └─┘     └─┘              └─┘   │3│   压入9      │9│
//                                  └─┘              └─┘
//  栈:     [2]   [2,1]     [3]   [3,3]             [9] ← 结果
```

## 解法详解

### 解法1: 栈模拟 — O(n) / O(n) ⭐ 面试首选

**思考过程**：逆波兰表达式的规则就是"遇到运算符，对最近的两个操作数运算"。"最近"意味着后进先出 → 栈。这是栈最经典的应用场景之一。

```cpp
class Solution {
public:
    int evalRPN(vector<string>& tokens) {
        stack<int> stk;
        for (const string& token : tokens) {
            if (token == "+" || token == "-" || token == "*" || token == "/") {
                // 注意：先弹出的是右操作数，后弹出的是左操作数
                int right = stk.top(); stk.pop();
                int left  = stk.top(); stk.pop();
                if (token == "+") stk.push(left + right);
                else if (token == "-") stk.push(left - right);
                else if (token == "*") stk.push(left * right);
                else stk.push(left / right); // C++ 整数除法默认向零截断
            } else {
                stk.push(stoi(token)); // 字符串转整数，自动处理负数
            }
        }
        return stk.top(); // 合法输入保证最终栈中恰好剩一个元素
    }
};
```

**关键点**：
- `left` 和 `right` 的弹出顺序绝对不能反！先弹出的是 `right`。
- `stoi` 会自动处理负数字符串如 `"-11"`。

### 解法2: 递归（逆向解析表达式树） — O(n) / O(n)

**思考过程**：逆波兰表达式的最后一个 token 一定是一个运算符（如果表达式不只一个数的话），它是整棵表达式树的根。我们可以从右往左递归地解析：遇到运算符就递归求解它的右子树和左子树（注意顺序：先解析右子树，因为在后缀中右子树更靠近运算符）。

```cpp
class Solution {
public:
    int evalRPN(vector<string>& tokens) {
        int idx = tokens.size() - 1; // 从最后一个 token 开始
        return helper(tokens, idx);
    }
    
    int helper(vector<string>& tokens, int& idx) {
        const string& token = tokens[idx--];
        if (token != "+" && token != "-" && token != "*" && token != "/") {
            return stoi(token); // 是数字，直接返回
        }
        // 是运算符：先递归解析右子表达式，再解析左子表达式
        // 因为从右往左扫描，后缀表达式中运算符右边的操作数更靠近它
        int right = helper(tokens, idx);
        int left  = helper(tokens, idx);
        if (token == "+") return left + right;
        if (token == "-") return left - right;
        if (token == "*") return left * right;
        return left / right;
    }
};
```

**关键点**：
- `idx` 必须是引用传递，因为递归过程中需要共享同一个索引位置。
- 先递归求 `right`，再求 `left`——这个顺序看似反直觉，但从右往左扫描时，紧跟运算符的是右操作数的子表达式。

## 解法对比

| | 栈模拟 | 递归解析 |
|---|---|---|
| 方向 | 从左到右遍历 | 从右到左递归 |
| 数据结构 | 显式栈 | 递归调用栈（隐式） |
| 直觉性 | 非常直观，和RPN定义完全一致 | 需要理解表达式树结构 |
| 面试推荐 | ⭐ 首选 | 展示深度理解的加分项 |

两者时间空间都是 O(n)。面试中写栈模拟即可，如果面试官追问还有没有其他方式，可以提递归解法。

## 易错点

1. **操作数顺序反了**
   - ✗ `int left = stk.top(); stk.pop(); int right = stk.top(); stk.pop();`
   - ✓ `int right = stk.top(); stk.pop(); int left = stk.top(); stk.pop();`
   - 对加法和乘法无所谓（交换律），但 `4 - 2` 和 `2 - 4` 结果截然不同！

2. **负数被误判为运算符**
   - ✗ 用 `token[0]` 是否为运算符来判断——`"-11"` 的第一个字符是 `-`
   - ✓ 直接用 `token == "+" || token == "-" || ...` 来判断，因为运算符一定是长度为 1 的字符串

3. **忘记处理除法向零截断**
   - 在 C++ 中这不是问题（默认行为），但在 Python 中 `//` 是向下取整，需要用 `int(a/b)` 代替

## 面试追问

**Q1: 为什么逆波兰表达式不需要括号就能无歧义求值？**
→ 因为运算符的位置隐含了运算优先级。在后缀表达式中，越靠前的运算符越先被执行。栈天然保证了这种执行顺序——先遇到的运算符先消耗操作数。

**Q2: 如果给你中缀表达式，怎么转成逆波兰表达式？**
→ 经典的 **调度场算法（Shunting Yard Algorithm）**：用两个结构——输出队列和运算符栈。遍历中缀表达式，数字直接入输出队列；运算符根据优先级决定是入栈还是先弹出栈内运算符到输出队列；左括号入栈，遇右括号弹出到左括号。这就是 LeetCode 224/227（基本计算器）系列的核心。

**Q3: 如果 tokens 数量非常大（百万级），能否减少空间开销？**
→ 可以用 `tokens` 数组本身当作栈（原地修改），用一个 `top` 指针模拟栈顶。遇到数字就放在 `tokens[top++]`，遇到运算符就在 `tokens[top-2]` 处放结果并 `top--`。这样额外空间 O(1)（不算输入本身）。
