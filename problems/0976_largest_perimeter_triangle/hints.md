# 976. 三角形的最大周长

## 核心思路

**贪心 + 排序**。要找最大周长的三角形，排序后从最大的三个数开始检查——如果满足三角不等式（两小边之和 > 最大边），它们的周长就是最大的。如果不满足，就向左移动一位，检查次大的三元组。

## 思维链

1. **读完题第一反应**：从数组中选三个数组成三角形，求最大周长。三角形条件是任意两边之和大于第三边。

2. **关键数学性质**：如果三个数已排序 `a <= b <= c`，那只需检查 `a + b > c` 即可。因为 `a + c > b` 和 `b + c > a` 在 `a <= b <= c` 时自动成立（c 是最大的，c + 任何正数 > 任何更小的数）。

3. **贪心直觉**：要周长最大，优先选最大的三个数 `nums[n-3], nums[n-2], nums[n-1]`。如果它们能组成三角形，周长最大。如果不能（最大边太大），那最大的那个数在任何三元组中都不可能满足条件（因为其他任意两个数之和只会更小），所以排除它，检查 `nums[n-4], nums[n-3], nums[n-2]`。

4. **为什么排序后只检查相邻三元组？** 因为排序后 `nums[i] <= nums[i+1] <= nums[i+2]`，如果 `nums[i] + nums[i+1] > nums[i+2]` 不成立，那 `nums[j] + nums[i+1] > nums[i+2]`（j < i）更不成立（nums[j] 更小）。所以不需要跳过元素去找"更好"的组合。

5. **算法**：排序后从右到左扫描，检查每组相邻三元组 `(nums[i-2], nums[i-1], nums[i])`，第一组满足 `nums[i-2] + nums[i-1] > nums[i]` 的就是答案。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 排序 + 贪心扫描 | 从大到小检查相邻三元组 | O(n log n) | O(1) | 必须写出 |

## 关键提示

1. **提示1**：三角形条件简化——对排序后的 `a <= b <= c`，只需检查 `a + b > c`。为什么其他两个不等式自动满足？

2. **提示2**：贪心选择最大的三个数。如果它们不构成三角形，那最大的数可以被"放弃"——因为它和任意两个更小的数组合，`a + b` 只会更小，更不可能满足 `a + b > c`。

3. **提示3**：排序后从右到左扫描，只需检查**相邻的三元组** `(nums[i-2], nums[i-1], nums[i])`。不需要检查非相邻的组合。为什么？

4. **提示4**：如果所有相邻三元组都不满足，返回 0。什么样的数组会导致这种情况？（提示：类似斐波那契数列的增长速度，每个元素 >= 前两个之和）

5. **提示5**：注意题目要求的是**周长**（三边之和），不是面积或边长。

```
贪心检查过程 (nums = [1, 2, 1, 10]):

排序后: [1, 1, 2, 10]

从右到左检查相邻三元组:

i=3: (nums[1], nums[2], nums[3]) = (1, 2, 10)
     1 + 2 = 3 > 10?  NO → 跳过

i=2: (nums[0], nums[1], nums[2]) = (1, 1, 2)
     1 + 1 = 2 > 2?   NO → 跳过 (注意: 等于不行, 必须严格大于)

没有满足条件的三元组 → 返回 0
```

```
成功的例子 (nums = [2, 1, 2]):

排序后: [1, 2, 2]

i=2: (nums[0], nums[1], nums[2]) = (1, 2, 2)
     1 + 2 = 3 > 2?   YES!
     周长 = 1 + 2 + 2 = 5

返回 5
```

## 解法详解

### 解法: 排序 + 贪心 — O(n log n) / O(1)

**思考过程**：
- 排序后，最大的三个数优先检查
- 如果不满足三角不等式，右移一位继续
- 第一组满足条件的相邻三元组就是最大周长

```
// 为什么只检查相邻三元组?
//
// 排序后: a[0] <= a[1] <= ... <= a[n-1]
//
// 假设 a[i-2] + a[i-1] <= a[i] (不满足)
// 那么对任何 j < i-2:
//   a[j] + a[i-1] <= a[i-2] + a[i-1] <= a[i]
//   → 也不满足!
//
// 所以如果 (a[i-2], a[i-1], a[i]) 不行,
// 不可能通过换更小的 a[j] 来满足
// → 只需检查相邻三元组
```

```cpp
class Solution {
public:
    int largestPerimeter(vector<int>& nums) {
        sort(nums.begin(), nums.end());

        // 从右到左检查相邻三元组
        for (int i = nums.size() - 1; i >= 2; i--) {
            if (nums[i - 2] + nums[i - 1] > nums[i]) {
                return nums[i - 2] + nums[i - 1] + nums[i];
            }
        }
        return 0;  // 无法构成三角形
    }
};
```

**关键点**：
- `nums[i-2] + nums[i-1] > nums[i]`：严格大于，不是 `>=`（等于时面积为零，退化成线段）
- 第一个满足条件的就直接返回——不需要继续找，因为后面的周长只会更小
- O(n log n) 来自排序，扫描只需 O(n)

## 贪心正确性证明

**命题**：排序后，第一组满足三角不等式的相邻三元组给出最大周长。

**证明**：
1. 排序后 `nums[0] <= nums[1] <= ... <= nums[n-1]`
2. 设第一组满足条件的是 `(nums[i-2], nums[i-1], nums[i])`
3. **周长最大性**：任何使用 `nums[j]`（j < i）的三元组，其三边之和 <= `nums[i-2] + nums[i-1] + nums[i]`（因为 nums[j] <= nums[i-2]）
4. **使用 `nums[k]`（k > i）的三元组呢？** 我们从右往左扫描过了 `nums[k]` 的相邻三元组但不满足条件，说明 `nums[k]` 作为最大边时，没有两个较小边能满足三角不等式。所以 `nums[k]` 不可能出现在任何有效三角形中。
5. 因此 `nums[i-2] + nums[i-1] + nums[i]` 是最大周长。

## 易错点

1. **三角不等式用了 >= 而非 >**
   ```cpp
   // 错误: nums[i-2] + nums[i-1] >= nums[i]
   // 正确: nums[i-2] + nums[i-1] > nums[i]
   // 等于时三点共线, 面积为零, 不是有效三角形
   ```

2. **只检查了最大的三元组就返回**
   ```cpp
   // 错误: 只检查 (nums[n-3], nums[n-2], nums[n-1])
   // 正确: 需要从右到左遍历所有相邻三元组
   // 例如 [1, 2, 3, 100], 最大三元组 (2,3,100) 不行, 但 (1,2,3) 也不行
   ```

3. **试图检查所有 C(n,3) 组合**
   ```cpp
   // 不需要! 排序后只需检查相邻三元组
   // 非相邻组合的周长更小, 且不可能是第一个满足条件的
   ```

4. **溢出风险**（本题不存在，但值得注意）
   ```cpp
   // nums[i] <= 10^6, 两个相加最多 2*10^6, int 足够
   // 但如果数值范围更大, 需要用 long long
   ```

## 面试追问

**Q1: 为什么只检查相邻的三个数就够了？**
→ 排序后 `a <= b <= c`。如果 `a + b <= c`（不满足），那用任何比 a 更小的数 `a'` 替换，`a' + b <= a + b <= c`，更不满足。所以对于每个 c，最佳的 a 和 b 就是紧挨着它的两个数。

**Q2: 时间复杂度的下界是什么？**
→ 排序的下界是 O(n log n)（基于比较的排序）。如果数值范围有限（如 <= 10^6），可以用计数排序 O(n + M) 优化到近线性。

**Q3: 如果要求最大面积而非最大周长呢？**
→ 更复杂。最大周长的三角形不一定有最大面积（如极扁的三角形周长大但面积小）。需要海伦公式计算面积，可能需要检查更多组合。

**Q4: 如果数组中有负数呢？**
→ 长度不能为负，所以可以先过滤掉非正数。或者题目保证 nums[i] >= 1。

**Q5: 能否不排序来做？**
→ 可以用快速选择找到最大的三个数，但这只是 O(n) 找到前三大，不保证满足三角不等式。如果前三大不满足，仍然需要检查其他组合，此时退化为排序。所以排序是最简洁的方法。
