# 748. 最短补全词

## 核心思路

从 licensePlate 中提取所有字母（忽略数字、空格，不区分大小写），统计每个字母的频次。然后在 words 数组中找到**最短的**包含这些字母（频次足够）的单词。这是一个经典的**字母频次匹配**问题，使用频次数组（哈希计数）即可解决。

## 思维链

1. **解析 licensePlate**：过滤非字母字符，转小写，统计每个字母出现次数 => 频次数组 `need[26]`
2. **逐词匹配**：对 words 中每个单词，统计频次数组 `have[26]`，检查是否对所有字母 `have[c] >= need[c]`
3. **选最短优先**：在所有满足条件的单词中，选长度最短的；长度相同取出现最早的
4. **复杂度分析**：licensePlate 长度 <= 7，words 最多 1000 个，每个最长 15 => 完全可以暴力

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 频次数组匹配 | O(n * L) | O(1) | 标准解法，简洁高效 |
| 排序 + 频次匹配 | O(n * L log L) | O(L) | 先按长度排序，找到第一个匹配即可提前退出 |

## 关键提示

1. **大小写不敏感**：licensePlate 中的字母统一转成小写处理
2. **忽略非字母**：licensePlate 中的数字和空格不参与匹配
3. **频次而非集合**：如果 licensePlate 有两个 's'，单词中也必须有至少两个 's'
4. **最短 + 最先**：多个最短的取第一个出现的（而非字典序最小）
5. **题目保证有解**：不需要处理无解情况

## 解法详解

### 解法一：频次数组匹配（推荐）

**思路**：建立 licensePlate 的字母频次数组 `need[26]`，然后对每个单词建立频次数组 `have[26]`，检查 `have[i] >= need[i]` 对所有 i 成立。在满足条件的单词中选最短的。

**步骤**：
1. **解析 licensePlate**：
   - 遍历每个字符
   - 如果是字母（`isalpha`），转小写后 `need[c - 'a']++`
   - 忽略数字和空格
2. **匹配检查函数**：
   - 对单词统计 `have[26]`
   - 检查 26 个字母是否都满足 `have[i] >= need[i]`
3. **选最短单词**：
   - 维护 `bestLen` 和 `bestWord`
   - 遍历 words，对每个满足条件的单词，如果长度 < bestLen 则更新

**复杂度分析**：
- 时间：O(P + n * L)，P 是 licensePlate 长度，n 是 words 数量，L 是平均单词长度
- 空间：O(1)（两个固定大小 26 的数组）

### 解法二：排序优先 + 提前终止

**思路**：先按长度排序 words，然后找到第一个满足条件的单词即可返回。

**注意**：排序必须是**稳定排序**（stable_sort），因为相同长度的单词需要保持原始顺序（取最先出现的）。

**步骤**：
1. 创建 (word, 原始下标) 对
2. 按 word 长度稳定排序
3. 从最短开始逐个检查
4. 第一个满足条件的就是答案

**缺点**：排序带来额外开销，且改变了原始顺序需要额外处理。

## 易错点

1. **大小写处理遗漏**：licensePlate 中可能有大写字母如 'P'，必须转成小写 'p'
2. **非字母字符未过滤**：直接对 licensePlate 统计频次会把数字和空格也算进去
3. **频次 vs 存在**：不是检查字母「是否存在」，而是检查「数量是否足够」。'aBc 12c' 需要两个 'c'
4. **最短 vs 最先的优先级**：先比长度，长度相同取先出现的。不能只跟踪 minLen 而忘了在相同长度时不更新
5. **words[i] 全小写**：题目保证 words 中的单词全是小写，所以匹配时不需要再转换
6. **空字符串边界**：虽然题目保证 words[i].length >= 1，但 licensePlate 可能只有数字和空格（不过题目不会出这种测试）

## 面试追问

1. **Q: 如果 licensePlate 可能非常长（比如 10^6 个字符），如何优化？**
   A: 解析 licensePlate 本身是 O(P) 不可避免。但可以用 bitmap 快速判断某个字母是否需要，减少逐词匹配时的常数。

2. **Q: 如果要找最短的同时字典序最小的补全词呢？**
   A: 在更新答案时，增加字典序比较条件：`len < bestLen || (len == bestLen && word < bestWord)`。

3. **Q: 如果 words 非常多（10^6 个），如何优化？**
   A: 按长度分桶，从最短的桶开始检查。找到第一个满足的就停止。

4. **Q: 这题和 Anagram 类题有什么关系？**
   A: Anagram 要求频次完全相等，本题只要求 `>=`（超集关系）。是 Anagram 的泛化版本。

5. **Q: 如何用 multiset 代替频次数组？**
   A: licensePlate 的字母放入 multiset，然后对每个单词的字母从 multiset 中 erase，如果能全部移除则满足。但效率不如频次数组。
