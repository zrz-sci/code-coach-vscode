# 634. Find the Derangement of An Array

## 核心思路

**错位排列 (Derangement)** 是组合数学经典问题：n 个元素的排列中，没有任何元素在其原始位置上的排列数。利用递推公式 `D(n) = (n-1) * (D(n-1) + D(n-2))` 进行动态规划求解，并对 `10^9 + 7` 取模。

## 思维链

1. **识别问题**：这是经典的错位排列 (Derangement / Subfactorial) 计数问题
2. **推导递推关系**：
   - 考虑元素 n，它不能放在位置 n，所以有 (n-1) 种选择，设放在位置 k
   - 对于元素 k，有两种情况：
     - 元素 k 放在位置 n（与元素 n "交换"）：剩下 n-2 个元素做错位排列 -> D(n-2)
     - 元素 k 不放在位置 n：等价于 n-1 个元素的错位排列 -> D(n-1)
   - 因此：`D(n) = (n-1) * (D(n-1) + D(n-2))`
3. **确定基态**：`D(1) = 0`（一个元素无法错位），`D(2) = 1`（[2,1]）
4. **优化空间**：只需要前两个状态，O(1) 空间即可
5. **注意取模**：n 可达 10^6，中间计算需要对 10^9+7 取模

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 推荐度 |
|------|-----------|-----------|--------|
| DP 递推（空间优化） | O(n) | O(1) | ⭐⭐⭐⭐⭐ |
| DP 递推（数组） | O(n) | O(n) | ⭐⭐⭐⭐ |
| 容斥原理公式 | O(n) | O(1) | ⭐⭐⭐ |

## 关键提示

1. **递推公式**：`D(n) = (n-1) * (D(n-1) + D(n-2))` 是核心，必须理解其组合意义
2. **取模陷阱**：`(n-1) * (D(n-1) + D(n-2))` 中乘法可能溢出 int，需要用 `long long`
3. **边界处理**：D(0) = 1（空排列视为一种错位排列），D(1) = 0
4. **容斥公式**：`D(n) = n! * sum_{k=0}^{n} (-1)^k / k!`，计算上等价但不如递推直观
5. **空间优化**：由于只依赖前两个状态，可以用两个变量滚动替代数组

## 解法详解

### 解法一：DP 递推 + 空间优化（推荐）

**思路**：利用递推公式，用两个变量 `prev2` (D(i-2)) 和 `prev1` (D(i-1)) 滚动计算。

```
D(1) = 0, D(2) = 1
D(i) = (i-1) * (D(i-1) + D(i-2)) % MOD
```

**递推公式的组合解释**：
- 元素 n 有 (n-1) 个可以放置的位置（除了位置 n）
- 设元素 n 放在位置 k，则：
  - 若元素 k 放在位置 n（"交换"）-> 剩余 n-2 个元素的错位排列 D(n-2)
  - 若元素 k 不放在位置 n -> 相当于 n-1 个元素的错位排列 D(n-1)
- 两种情况相加后乘以 (n-1) 种选择

**复杂度**：时间 O(n)，空间 O(1)

### 解法二：DP 数组

**思路**：与解法一相同，但使用数组存储所有中间状态。

```
dp[0] = 1, dp[1] = 0, dp[2] = 1
dp[i] = (long long)(i-1) * (dp[i-1] + dp[i-2]) % MOD
```

**复杂度**：时间 O(n)，空间 O(n)

### 解法三：容斥原理 / 另一种递推

**思路**：利用容斥原理可以导出另一个等价递推：

`D(n) = n * D(n-1) + (-1)^n`

验证：D(1) = 1*1 - 1 = 0, D(2) = 2*0 + 1 = 1, D(3) = 3*1 - 1 = 2

这个公式只需要一个前驱状态，代码更简洁，但取模时 (-1)^n 需要特殊处理。

**复杂度**：时间 O(n)，空间 O(1)

## 易错点

1. **int 溢出**：`(n-1) * (dp[i-1] + dp[i-2])` 三个 int 相乘可能超过 int 范围，必须转 `long long`
2. **取模位置**：乘法前取模、加法后取模都需要注意；`(a + b) % MOD` 在 a + b 未溢出时安全
3. **边界 n=1**：D(1) = 0，很容易忘记特判
4. **D(0) 的定义**：数学上 D(0) = 1（空排列），初始化时容易搞错
5. **公式记错**：`D(n) = (n-1) * (D(n-1) + D(n-2))` 不是 `n * (D(n-1) + D(n-2))`，系数是 n-1 不是 n

## 面试追问

**Q1: 请解释递推公式 D(n) = (n-1)(D(n-1) + D(n-2)) 的组合意义。**

考虑将元素 n 放置在排列中。它不能在位置 n，所以有 n-1 个位置可选，设放在位置 k。现在看元素 k 有两种选择：
- **放在位置 n**：n 和 k 互换位置，剩下 n-2 个元素各自不能在原位 -> D(n-2)
- **不放在位置 n**：相当于 n-1 个元素的错位排列（k "禁止"去位置 n 而非位置 k）-> D(n-1)

每种位置 k 的选择都产生 D(n-1) + D(n-2) 种排列，共 n-1 种位置选择。

**Q2: 如果 n 达到 10^9，还能用 O(n) 的方法吗？有没有更快的做法？**

O(n) 对 10^9 来说太慢。由于递推系数 (n-1) 随 n 变化，无法直接用恒定矩阵的快速幂。可以研究错位排列的渐近公式 D(n) = round(n!/e)（取最近整数），配合大数运算或对数近似。实际面试中 n 不超过 10^6，O(n) 完全够用。

**Q3: 错位排列在实际中有什么应用？**

- **信封问题 (Probleme des rencontres)**：n 封信放入 n 个信封，没有一封放对的方案数
- **Secret Santa / 抽签问题**：n 个人互相抽签，没有人抽到自己的方案数
- **密码学**：在某些密码协议中，错位排列用于保证"没有元素映射到自身"
- **概率论**：随机排列是错位排列的概率趋近于 1/e ≈ 0.3679
