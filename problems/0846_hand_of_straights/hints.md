# 846. Hand of Straights - 提示与解析

## 核心思路

给定一组牌和组大小 `groupSize`，判断是否能将所有牌分成若干组，每组恰好 `groupSize` 张连续数字。贪心策略：排序后从最小的牌开始，每次尝试以当前最小值为起点构建一组连续牌。使用有序 map 维护每个数字的剩余数量，每次从最小的未用完的数开始，尝试凑齐 groupSize 个连续数字。

## 思维链

1. **初步判断**：如果牌的总数不能被 groupSize 整除，直接返回 false。
2. **统计频次**：用有序 map（TreeMap / std::map）统计每个数字出现的次数。
3. **贪心构建**：从最小的数开始，尝试构建一个长度为 groupSize 的连续组 [x, x+1, ..., x+groupSize-1]。
4. **更新频次**：每成功构建一组，将这些数字的频次各减 1。若某个数字频次不够，返回 false。
5. **重复直到所有牌用完**：始终从当前最小的剩余数字开始尝试。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 推荐度 | 特点 |
|------|-----------|-----------|--------|------|
| 有序 Map + 贪心 | O(n log n) | O(n) | ⭐⭐⭐⭐⭐ | 最优解，直观 |
| 排序 + 哈希表贪心 | O(n log n) | O(n) | ⭐⭐⭐⭐ | 排序后用 unordered_map |
| 最小堆 + 贪心 | O(n log n) | O(n) | ⭐⭐⭐ | 用优先队列管理起始点 |

## 关键提示

1. **总数整除检查**：`hand.size() % groupSize != 0` 则直接 false，这是必要条件。
2. **贪心正确性**：最小的数只能作为某个组的起始元素，不可能放在中间或末尾，所以贪心策略是正确的。
3. **有序 Map 的优势**：`std::map` 自动排序，`begin()` 即为当前最小值，非常适合此类题目。
4. **频次不够 = 无解**：在构建某组时，若连续范围内某个数频次为 0，则无法分组。
5. **与 1296 题相同**：本题和 LeetCode 1296 (Divide Array in Sets of K Consecutive Numbers) 是完全相同的问题。

## 解法详解

### 解法一：有序 Map + 贪心（推荐）

**思路**：
使用 `std::map` 存储每个数字的出现次数。反复取最小的键作为组的起始值，尝试凑齐 groupSize 个连续值。每个值的频次减去起始值的频次（因为需要构建同等数量的组）。

**关键步骤**：
- 将所有牌的频次存入有序 map
- 循环取 map 的最小键 start
- 检查 start, start+1, ..., start+groupSize-1 是否都有足够频次
- 将对应频次减去 count(start)，若减为 0 则删除键

**复杂度分析**：
- 时间：O(n log n)，map 操作为 O(log n)，总共 O(n) 次操作
- 空间：O(n)

### 解法二：排序 + 哈希表

**思路**：
先对 hand 排序，然后用 unordered_map 存频次。遍历排序后的数组，对每个未用完的数字尝试作为组起始，构建连续组。

**复杂度分析**：
- 时间：O(n log n)，排序主导
- 空间：O(n)

### 解法三：最小堆

**思路**：
将所有不同的数字放入最小堆，每次取堆顶作为组起始。构建组后更新频次。

## 易错点

1. **忘记整除检查**：这是最基本的必要条件，遗漏会导致多余计算。
2. **有序 Map 中删除元素**：在遍历 map 时删除元素需要注意迭代器失效问题。
3. **频次不足的处理**：不仅要检查键是否存在，还要检查频次是否 >= 需要的数量。
4. **连续性断裂**：例如 [1,2,4,5,6,7] groupSize=3，第一组 [1,2,?] 缺少 3，应返回 false。
5. **重复数字的处理**：同一数字可能出现多次，必须用频次而非简单的存在性检查。

## 面试追问

1. **Q: 为什么贪心策略是正确的？**
   A: 最小的数只能作为某组的起始元素（它前面没有更小的数可以让它做中间元素）。所以必须用它开头组成一组，这个选择是唯一的。

2. **Q: 如果 groupSize = 1 怎么办？**
   A: 每张牌自成一组，直接返回 true。

3. **Q: 如果要返回具体的分组方案呢？**
   A: 在贪心过程中记录每次构建的组即可。

4. **Q: 与 LC 1296 的关系？**
   A: 完全相同的问题，不同表述。面试中可能以任一形式出现。

5. **Q: 能否用并查集做？**
   A: 不太适合。这是一个贪心问题，排序+频次计数更自然。并查集适合连通性问题。
