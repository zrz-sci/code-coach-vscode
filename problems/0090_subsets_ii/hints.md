# 90. 子集 II

## 核心思路

本题是 **78. 子集** 的进阶版：数组中可能包含**重复元素**，要求生成所有子集且**不能有重复子集**。核心难点在于：**如何在回溯过程中跳过会产生重复子集的分支**。

## 思维链

1. **读完题第一反应**：和 78. Subsets 一模一样，区别就是 nums 里有重复元素。如果直接用 78 题的模板，`[1,2,2]` 会生成两个 `[1,2]`（第一个2和第二个2各选一次），所以需要**去重**。

2. **最朴素的去重**：先生成所有 2^n 个子集，然后用 set 去重。能 work，但做了大量无用计算。

3. **瓶颈在哪**：暴力生成了所有子集再过滤，我们能不能在**生成过程中就跳过重复分支**？

4. **关键观察**：排序后，相同的元素会相邻。在同一层递归中，如果当前元素和前一个元素相同，说明"选当前元素"这个分支在前面已经探索过了，直接跳过。

5. **为什么排序+跳过同层重复是对的**：排序保证相同元素连续。同一层选择中，第一个 `2` 已经代表了"选一个2"的所有可能（它的子树会继续探索选第二个2的情况），所以第二个 `2` 在同层再选就是重复。

6. **另一种思路——迭代法**：每次来一个新数，在已有的所有子集末尾加上这个数。但遇到重复数时，只在**上一轮新增的子集**末尾添加，避免重复。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 回溯 + 排序去重 | 排序后同层跳过重复元素 | O(n·2^n) | O(n) 递归栈 | ⭐ 必须写出 |
| 迭代构建 | 逐元素扩展已有子集，重复元素只扩展上一轮新增部分 | O(n·2^n) | O(1) 额外 | 加分项 |
| 位掩码 + 去重 | 枚举所有 2^n 掩码，排序后跳过等价掩码 | O(n·2^n) | O(n) | 能说出即可 |

## 关键提示

1. **先排序**！排序是所有去重策略的前提，让相同元素相邻。

2. **同层去重 vs 同枝去重**：我们要跳过的是"同一层递归中，前面已经选过相同值"的分支。而"同一条路径上选多个相同值"是允许的（如 `[2,2]` 是合法子集）。

3. 去重条件：`i > start && nums[i] == nums[i-1]`。`i > start` 保证只跳过同层的重复，不影响同枝的深入。

4. **对比 78 题 Subsets**：唯一的代码差异就是多了排序 + 一行跳过条件。

5. 画出决策树，标出哪些分支被剪掉，能帮你真正理解去重逻辑。

## 解法详解

### 解法1: 回溯 + 排序去重 — O(n·2^n) / O(n) ⭐ 面试首选

**思考过程**：

这道题是"子集"系列的标准题型。从 78 题出发，我们已经知道回溯生成子集的模板：对于每个位置，选或不选，递归到下一层。

现在有重复元素，关键是：**在同一层递归的选择列表中，如果多个候选值相同，只选第一个**。

```
// nums = [1, 2, 2]（已排序）的决策树：
//
//                        []
//                /        |         \
//              [1]       [2]       [2] ← 跳过! i>start 且 nums[2]==nums[1]
//            /    \       |
//         [1,2]  [1,2]  [2,2]
//           |    ↑跳过!
//        [1,2,2]
//
// 同层重复: 在根节点的子选择中, 第二个2和第一个2值相同 → 跳过
// 同枝深入: [2] → [2,2] 是合法的, 因为它们在不同层
//
// 最终结果: [], [1], [1,2], [1,2,2], [2], [2,2]
```

为什么 `i > start && nums[i] == nums[i-1]` 能准确去重？
- `i > start`：说明 i 不是当前层的第一个选择（第一个选择 `i == start` 不跳过）
- `nums[i] == nums[i-1]`：和前一个相同，前一个已经展开了所有子树
- 两者结合 = 跳过同层重复选择

```cpp
class Solution {
public:
    vector<vector<int>> subsetsWithDup(vector<int>& nums) {
        vector<vector<int>> result;
        vector<int> path;
        sort(nums.begin(), nums.end()); // 排序是去重的前提
        backtrack(nums, 0, path, result);
        return result;
    }
    
private:
    void backtrack(vector<int>& nums, int start, vector<int>& path, 
                   vector<vector<int>>& result) {
        result.push_back(path); // 每个节点都是一个合法子集
        
        for (int i = start; i < nums.size(); i++) {
            // 同层去重: i > start 保证不是当前层第一个元素
            // nums[i] == nums[i-1] 说明和前一个值相同，前面已经处理过
            if (i > start && nums[i] == nums[i-1]) continue;
            
            path.push_back(nums[i]);
            backtrack(nums, i + 1, path, result); // i+1: 每个元素只能用一次
            path.pop_back(); // 撤销选择
        }
    }
};
```

**关键点**：
- 去重条件是 `i > start`，**不是** `i > 0`。`i > 0` 会导致同一条路径上也不能选相同值，`[2,2]` 就生成不了了。
- `push_back(path)` 在循环前面，因为空集也是子集。

### 解法2: 迭代构建 — O(n·2^n) / O(1) 额外空间

**从另一个角度思考**：

78 题的迭代法是：从空集开始，每来一个新数字，把它追加到已有的每个子集末尾，产生新子集。

```
// 78题 nums=[1,2,3] 的迭代过程:
// 初始:  [[]]
// 加1:   [[], [1]]
// 加2:   [[], [1], [2], [1,2]]
// 加3:   [[], [1], [2], [1,2], [3], [1,3], [2,3], [1,2,3]]
```

现在有重复元素，问题是加第二个 `2` 时，如果还是对所有已有子集添加，就会产生重复。

**关键观察**：当遇到重复元素时，只对**上一轮新增的子集**追加，而不是全部子集。

```
// nums = [1, 2, 2]（已排序）:
// 初始:  [[]]
// 加1:   [[], [1]]                    ← 新增: [1]
// 加2:   [[], [1], [2], [1,2]]        ← 新增: [2], [1,2]
// 加2':  对全部追加会得到 [2],[1,2],[2,2],[1,2,2]
//        但 [2] 和 [1,2] 已经有了！
//        所以只对上一轮新增的 [2],[1,2] 追加:
//        得到 [2,2], [1,2,2]  ✓
// 最终:  [[], [1], [2], [1,2], [2,2], [1,2,2]]
```

```cpp
class Solution {
public:
    vector<vector<int>> subsetsWithDup(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        vector<vector<int>> result = {{}};
        int prevNewStart = 0; // 记录上一轮新增子集的起始位置
        
        for (int i = 0; i < nums.size(); i++) {
            int size = result.size();
            // 如果当前元素和前一个重复，只从上一轮新增的子集开始追加
            // 否则从所有子集开始追加
            int start = (i > 0 && nums[i] == nums[i - 1]) ? prevNewStart : 0;
            
            prevNewStart = size; // 本轮新增的子集从 size 位置开始
            
            for (int j = start; j < size; j++) {
                vector<int> subset = result[j];
                subset.push_back(nums[i]);
                result.push_back(subset);
            }
        }
        return result;
    }
};
```

**关键点**：
- `prevNewStart` 变量记录"上一轮新增子集在 result 中的起始位置"
- 非重复元素 → 对全部已有子集追加（`start = 0`）
- 重复元素 → 只对上一轮新增的子集追加（`start = prevNewStart`）

### 解法3: 位掩码枚举 + 去重 — O(n·2^n) / O(n)

**思考过程**：

78 题可以用 0 到 2^n-1 的位掩码枚举所有子集。有重复元素时，不同掩码可能对应相同子集。

排序后，如果一个位掩码中选了 `nums[i]`（第 i 位为1），但没选 `nums[i-1]` 且 `nums[i] == nums[i-1]`（第 i-1 位为0），那么这个掩码代表的子集一定可以由另一个掩码（选 i-1 不选 i）生成，是重复的。

```cpp
class Solution {
public:
    vector<vector<int>> subsetsWithDup(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        int n = nums.size();
        vector<vector<int>> result;
        
        for (int mask = 0; mask < (1 << n); mask++) {
            bool duplicate = false;
            vector<int> subset;
            
            for (int i = 0; i < n; i++) {
                if (mask & (1 << i)) {
                    // 如果选了 i 但没选 i-1，且 nums[i]==nums[i-1]，则重复
                    if (i > 0 && nums[i] == nums[i - 1] && !(mask & (1 << (i - 1)))) {
                        duplicate = true;
                        break;
                    }
                    subset.push_back(nums[i]);
                }
            }
            
            if (!duplicate) {
                result.push_back(subset);
            }
        }
        return result;
    }
};
```

**关键点**：
- 去重规则：对于相同的元素，**必须从左到右连续选取**。选了第 i 个就必须选第 i-1 个（如果值相同）。
- 这保证了 `[2,2]` 只能用"选第1个2+选第2个2"表示，不能用"不选第1个2+选第2个2"。

## 解法对比

| | 回溯+排序去重 | 迭代构建 | 位掩码 |
|---|---|---|---|
| 思维模型 | 决策树剪枝 | 逐步扩展 | 组合数学 |
| 去重方式 | 同层跳过 | 限制追加范围 | 跳过等价掩码 |
| 代码难度 | ⭐ 最直觉 | 需理解 prevNewStart | 位运算需经验 |
| 适用面试 | ✓ 首选 | ✓ 变体考察 | 能加分 |
| 与78题差异 | +排序 +1行跳过 | +1个变量控制起点 | +1个判断条件 |

## 易错点

1. **去重条件写成 `i > 0` 而不是 `i > start`**
   - ✗ `if (i > 0 && nums[i] == nums[i-1]) continue;`
   - ✓ `if (i > start && nums[i] == nums[i-1]) continue;`
   - 原因：`i > 0` 会跳过**同一条路径**上的重复元素，导致 `[2,2]` 无法生成。`i > start` 只跳过**同一层**的重复。

2. **忘记排序**
   - ✗ 直接回溯，不排序
   - ✓ 先 `sort(nums.begin(), nums.end())`
   - 原因：去重逻辑依赖相同元素相邻，不排序则 `nums[i] == nums[i-1]` 无法检测到所有重复。

3. **迭代法中 prevNewStart 更新时机错误**
   - ✗ 在内层 for 循环之后更新 `prevNewStart = size`
   - ✓ 在内层 for 循环之前更新（因为本轮新增的子集从当前 size 位置开始）
   - 原因：如果在之后更新，`prevNewStart` 会包含本轮新增的子集，下一轮判断范围就错了。

4. **位掩码解法中 n 超过 20 时溢出**
   - 本题 n ≤ 10，所以没问题。但习惯上注意 `1 << n` 在 n ≥ 31 时会溢出 int。

## 面试追问

**Q1: 这道题和 78. Subsets 的区别是什么？代码改了哪里？**
> 区别：nums 可能有重复元素。代码只多了两处：① 排序 ② 回溯循环中加 `if (i > start && nums[i] == nums[i-1]) continue;`

**Q2: 为什么去重条件是 `i > start` 而不是 `i > 0`？能举例说明吗？**
> 用 `[1,2,2]` 举例。回溯到 start=1 时，选择列表是 `[2,2]`。选第一个2进入更深层是合法的（产生 `[1,2]`→`[1,2,2]`）。如果用 `i > 0`，选第二个2时 `i=2 > 0` 且 `nums[2]==nums[1]`，会跳过。但这里 `start=1, i=2, i > start` 才跳过，而当 `start=2, i=2, i == start` 不跳过，保证 `[1,2,2]` 能生成。

**Q3: 如果不用排序，还能去重吗？**
> 可以用 HashSet 存已生成的子集（转成 tuple 或 string 做 key），但时间和空间开销更大。排序 O(n log n) 在这里几乎免费（n ≤ 10），是最优选择。

**Q4: 如果要求输出按字典序排列呢？**
> 排序+回溯天然就是字典序输出（因为我们从小到大选择），不需要额外操作。
