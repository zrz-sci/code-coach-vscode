# 605. 种花问题 (Can Place Flowers)

## 核心思路

给定一个花坛数组 `flowerbed`（0 表示空，1 表示已种花）和一个整数 `n`，判断能否在不违反"相邻花不能种在一起"的规则下，再种入 `n` 朵花。

本质上就是一个**贪心问题**：从左到右扫描花坛，只要当前位置和左右邻居都是空的，就立刻种花。贪心地尽早种花不会影响后续的最优解。

## 思维链

1. **读完题第一反应** → 遍历花坛，对每个空位置检查左右是否都是空的。如果是就种花。
2. **为什么贪心是正确的？** → 假设位置 i 可以种花但我们跳过了它，那位置 i+2 也可能可以种。但不种 i 不会让我们多种一朵花——种 i 最差也是和跳过 i 一样好。尽早种花只会让后续有更多空间，不会更少。
3. **边界处理** → 首位置只需要检查右邻居，末位置只需要检查左邻居。用 `i == 0` 和 `i == n-1` 作为特殊条件。
4. **提前返回** → 一旦已种花数量 >= n，可以提前返回 true，不需要遍历完整个数组。
5. **n = 0 的情况** → 不需要种任何花，直接返回 true。

```
示例: flowerbed = [1,0,0,0,1], n = 1

位置0: 值=1 → 已种花，跳过
位置1: 值=0, 左=1 → 不满足，跳过
位置2: 值=0, 左=0, 右=0 → 种花! count=1, flowerbed=[1,0,1,0,1]
位置3: 值=0, 左=1 → 不满足，跳过
位置4: 值=1 → 已种花，跳过

count=1 >= n=1 → true ✓
```

```
示例: flowerbed = [1,0,0,0,1], n = 2

位置2: 种花 → count=1
其他位置都不满足

count=1 < n=2 → false ✓
```

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 贪心扫描 | 从左到右，能种就种 | O(m) | O(1) | ⭐⭐ 唯一正解 |
| 连续零计数 | 统计连续0的段长度 | O(m) | O(1) | 等价变体 |
| 补零法 | 两端加0简化边界 | O(m) | O(m) | 代码更简洁 |

（m 为花坛长度）

## 关键提示

1. **三个条件同时满足**：`flowerbed[i] == 0` 且左邻居为 0（或 i==0）且右邻居为 0（或 i==m-1）。
2. **种下花后要标记**：`flowerbed[i] = 1`，这样后续位置检查左邻居时会看到这朵新种的花。
3. **种花后可以跳一格**：种了位置 i 后，位置 i+1 一定不能种（因为它的左邻居已经是 1）。所以可以 `i += 2` 跳过一格来优化常数。
4. **提前返回**：`count >= n` 时立刻 return true，避免不必要的遍历。
5. **不要忘记 n=0 的情况**：不需要种花，直接 true。但大多数实现天然处理了这个情况（count=0 >= n=0）。

## 解法详解

### 解法1: 贪心扫描 — O(m) / O(1) ⭐⭐

**核心思想**: 从左到右扫描花坛，对每个位置检查"能否种花"的三个条件。如果满足就种下去。

```cpp
class Solution {
public:
    bool canPlaceFlowers(vector<int>& flowerbed, int n) {
        int count = 0;
        int m = flowerbed.size();
        
        for (int i = 0; i < m; i++) {
            if (flowerbed[i] == 0
                && (i == 0 || flowerbed[i - 1] == 0)
                && (i == m - 1 || flowerbed[i + 1] == 0)) {
                flowerbed[i] = 1;  // 种花并标记
                count++;
                if (count >= n) return true;  // 提前返回
            }
        }
        
        return count >= n;
    }
};
```

**关键点**:
- **贪心正确性**：尽早种花不会影响最优解。直觉：种 i 只会"禁用" i-1 和 i+1。如果不种 i，i+1 或 i+2 可能可以种，但最多也只是种 1 朵（不会比种 i 更好）。
- **短路求值**：`(i == 0 || flowerbed[i-1] == 0)` 利用短路避免越界。当 i==0 时不会访问 flowerbed[-1]。
- 时间 O(m)，空间 O(1)（只修改了原数组，没有额外空间）。

---

### 解法1b: 贪心 + 跳步优化 — O(m) / O(1)

**小优化**: 种花后下一个位置一定不能种（左邻居是刚种的花），所以直接跳两格。遇到已种花的位置也可以跳两格（它的右邻居一定不能种）。

```cpp
class Solution {
public:
    bool canPlaceFlowers(vector<int>& flowerbed, int n) {
        int count = 0;
        int m = flowerbed.size();
        
        for (int i = 0; i < m; ) {
            if (flowerbed[i] == 1) {
                i += 2; // 当前位置已种花，下一个一定不能种
            } else if (i == m - 1 || flowerbed[i + 1] == 0) {
                // 当前位置为空，且右边也为空（或已到末尾）
                // 注意：左边一定为空（要么 i==0，要么上一个位置是1导致跳了2格，要么上一个位置是0）
                count++;
                if (count >= n) return true;
                i += 2; // 种下后跳过下一格
            } else {
                i++; // 当前为空但右边是1，移到下一格
            }
        }
        
        return count >= n;
    }
};
```

**关键点**:
- 减少了不必要的条件检查，循环次数更少。
- 思路：遇到 1 跳两格，遇到 0 且右边是 0（或到边界）就种花并跳两格，否则前进一格。

---

### 解法2: 连续零计数 — O(m) / O(1)

**不同视角**: 统计连续 0 的段长度，计算每段能种多少花。

```
规则：连续 len 个零的段能种 (len-1)/2 朵花（如果两端都有花）。
但如果一端是花坛边界（不是花），可以多种 1 朵。

实际公式：对连续零的段 [l, r]
- 两端都是花：(len-1)/2  例如 1,0,0,0,1 → (3-1)/2 = 1
- 一端是边界：len/2      例如 0,0,0,1   → 3/2 = 1
- 两端都是边界：(len+1)/2 例如 0,0,0     → (3+1)/2 = 2

简化：在数组两端各加一个虚拟的 0，统一用 (len-1)/2。
```

```cpp
class Solution {
public:
    bool canPlaceFlowers(vector<int>& flowerbed, int n) {
        int count = 0;
        int zeros = 1; // 虚拟左边界的 0
        
        for (int bed : flowerbed) {
            if (bed == 0) {
                zeros++;
            } else {
                count += (zeros - 1) / 2;
                zeros = 0;
            }
        }
        zeros++; // 虚拟右边界的 0
        count += (zeros - 1) / 2;
        
        return count >= n;
    }
};
```

**关键点**:
- 不修改原数组（纯统计），但代码理解难度稍高。
- 两端的虚拟 0 统一了边界处理：初始 `zeros = 1`（左边界虚拟0），结束后 `zeros++`（右边界虚拟0）。

---

### 解法3: 补零法 — O(m) / O(m)

**简化边界**: 在花坛两端各添加一个 0，这样所有位置的检查逻辑统一（不需要 i==0 和 i==m-1 的特殊判断）。

```cpp
class Solution {
public:
    bool canPlaceFlowers(vector<int>& flowerbed, int n) {
        // 两端各加一个 0
        vector<int> f = {0};
        f.insert(f.end(), flowerbed.begin(), flowerbed.end());
        f.push_back(0);
        
        int count = 0;
        int m = f.size();
        for (int i = 1; i < m - 1; i++) {
            if (f[i] == 0 && f[i - 1] == 0 && f[i + 1] == 0) {
                f[i] = 1;
                count++;
                if (count >= n) return true;
            }
        }
        return count >= n;
    }
};
```

**关键点**:
- 代码最简洁，没有特殊边界判断。
- 缺点是需要 O(m) 额外空间复制数组。面试中通常用解法1（O(1) 空间）。

## 解法对比

|  | 贪心扫描 | 贪心+跳步 | 连续零计数 | 补零法 |
|--|---------|----------|----------|-------|
| 时间 | O(m) | **O(m)** | O(m) | O(m) |
| 空间 | **O(1)** | **O(1)** | **O(1)** | O(m) |
| 修改原数组 | 是 | 是 | **否** | 是(副本) |
| 代码简洁 | 中 | 中 | 低 | **高** |
| 面试推荐 | ⭐⭐ | ⭐ 优化 | 了解 | 了解 |

## 易错点

1. **忘记标记已种花的位置**：
   - ✗ 不设置 `flowerbed[i] = 1` → 后续位置以为左邻居是空的，多种花
   - ✓ 种花后必须 `flowerbed[i] = 1`

2. **边界越界**：
   - ✗ 不检查 `i == 0` 就访问 `flowerbed[i-1]` → 越界
   - ✓ 利用短路求值 `(i == 0 || flowerbed[i-1] == 0)`

3. **n=0 的情况**：
   - 大多数实现天然处理（count=0 >= n=0 为 true）
   - 但如果代码逻辑有问题可能返回 false，需要注意

4. **种花后不跳格导致重复种**：
   - 在解法1中不会出错（因为种了 i 后 flowerbed[i]=1，i+1 检查左邻居为1会跳过）
   - 但在解法1b中如果跳步逻辑写错可能出问题

5. **连续零计数的边界初始化**：
   - ✗ `zeros = 0` → 花坛开头的连续零少算一朵花
   - ✓ `zeros = 1`（模拟左边界虚拟0）

## 面试追问

**Q1: 贪心为什么是正确的？能证明吗？**
> 交换论证：假设最优解在位置 i 没种但在 i+2 种了。把 i+2 的花移到 i，不会违反规则（i 的左邻居在最优解中一定是空的，否则 i 不可能是空的候选位置），也不会减少总数。所以尽早种花的策略能达到最优。

**Q2: 如果不允许修改原数组怎么办？**
> 用解法2（连续零计数），不修改原数组，O(1) 额外空间。或者用一个变量记录上次种花的位置来代替标记。

**Q3: 如果花坛是环形的（首尾相连）怎么办？**
> 首尾相邻增加了约束。需要分两种情况：位置0种花 or 不种花，分别计算后取较大值。类似打家劫舍 II (198 → 213) 的环形处理。

**Q4: 如果要求最多能种多少花？**
> 就是本题取 n = INF 时 count 的值。贪心策略完全相同。

**Q5: 时间复杂度能优化到 O(m) 以下吗？**
> 不行。需要看每个位置至少一次才能确定状态。O(m) 已经是最优。
