# 84. 柱状图中最大的矩形

## 核心思路

本质上在问：对于每根柱子，以它的高度为矩形高度，最多能向左向右延伸多远？找到每根柱子的"左边界"和"右边界"（即左/右第一个比它矮的柱子），就能算出以该柱子为最矮柱子的最大矩形面积。

## 思维链

1. **读完题第一反应**：枚举所有可能的矩形？矩形由左右边界和高度决定。暴力做法：枚举每对左右端点 `(i, j)`，矩形高度 = 区间内最小高度，面积 = 高度 × 宽度。O(n²) 对甚至 O(n³)。

2. **换个角度思考**：与其枚举"左右边界再找最小高度"，不如**枚举每根柱子作为矩形的最矮柱子**。以柱子 `i` 的高度 `h[i]` 为高，向左找第一个 `< h[i]` 的位置 `left[i]`，向右找第一个 `< h[i]` 的位置 `right[i]`，面积 = `h[i] × (right[i] - left[i] - 1)`。

3. **瓶颈在哪**：对每根柱子都线性扫描找左右边界，是 O(n²)。能否快速找到"左/右第一个更小的元素"？

4. **单调栈登场**：「下一个更小元素」是**单调递增栈**的经典应用。维护一个栈底到栈顶递增的栈，当新元素比栈顶小时，栈顶元素的"右边界"就是新元素，"左边界"就是栈中它下面的那个元素。

5. **一次遍历搞定**：遍历过程中，每个元素入栈一次出栈一次，总时间 O(n)。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力枚举 | 对每根柱子线性扫描左右边界 | O(n²) | O(1) | 能说出即可 |
| 单调栈（两次遍历） | 分别求 left[] 和 right[] | O(n) | O(n) | 加分项 |
| 单调栈（一次遍历） | 出栈时直接计算面积 | O(n) | O(n) | ⭐ 必须写出 |

## 关键提示

1. **思考角度转换**：不要枚举"哪些柱子组成矩形"，而要枚举"每根柱子能撑起多大的矩形"——即以每根柱子为高度瓶颈，向两侧尽可能延伸。

2. **单调栈的本质**：维护一个**递增栈**（栈底到栈顶高度递增）。当遇到一根比栈顶矮的柱子时，栈顶柱子的"势力范围"到头了——右边界已确定。

3. **哨兵技巧**：在数组首尾各加一个高度为 0 的虚拟柱子，这样所有真实柱子最终都会被弹出处理，避免遍历结束后还要清栈的特殊逻辑。

4. **出栈时计算面积**：弹出栈顶 `mid` 后，宽度 = `当前下标 i - 新栈顶 - 1`，高度 = `heights[mid]`。

5. **ASCII 示意图——以 [2,1,5,6,2,3] 为例**：

```
     ┌─┐
   ┌─┤ │
   │ │ │   ┌─┐
┌─┐│ │ │┌─┐│ │
│ ││ │ ││ ││ │
│2│1│5│6│2│3│
 0  1  2  3  4  5
 
对于柱子 heights[3]=6:
  左边第一个 < 6 的是 heights[2]=5 (index=2)
  右边第一个 < 6 的是 heights[4]=2 (index=4)
  宽度 = 4 - 2 - 1 = 1, 面积 = 6 × 1 = 6

对于柱子 heights[2]=5:
  左边第一个 < 5 的是 heights[1]=1 (index=1)
  右边第一个 < 5 的是 heights[4]=2 (index=4)
  宽度 = 4 - 1 - 1 = 2, 面积 = 5 × 2 = 10  ← 最大！
```

## 解法详解

### 解法1: 暴力枚举 — O(n²) / O(1)

**思考过程**：最直觉的想法——以每根柱子为中心，向左右扩展，直到遇到比它矮的柱子为止。

```cpp
class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        int n = heights.size(), maxArea = 0;
        for (int i = 0; i < n; i++) {
            int left = i, right = i;
            // 向左找第一个比 heights[i] 小的
            while (left > 0 && heights[left - 1] >= heights[i]) left--;
            // 向右找第一个比 heights[i] 小的
            while (right < n - 1 && heights[right + 1] >= heights[i]) right++;
            maxArea = max(maxArea, heights[i] * (right - left + 1));
        }
        return maxArea;
    }
};
```

**关键点**：每根柱子最坏要扫描整个数组，如 `[1,1,1,...,1]` 全等高时退化到 O(n²)。n=10⁵ 时 TLE。

### 解法2: 单调栈（两次遍历预处理） — O(n) / O(n)

**从解法1优化**：解法1的瓶颈是对每根柱子都要线性扫描找左右边界。用单调递增栈可以 O(n) 一次性求出所有柱子的"左边第一个更小"和"右边第一个更小"。

```cpp
class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        int n = heights.size();
        vector<int> left(n), right(n);
        stack<int> stk;
        
        // 求每根柱子左边第一个比它矮的位置
        for (int i = 0; i < n; i++) {
            while (!stk.empty() && heights[stk.top()] >= heights[i])
                stk.pop();
            left[i] = stk.empty() ? -1 : stk.top();
            stk.push(i);
        }
        
        // 清栈，求右边第一个比它矮的位置
        while (!stk.empty()) stk.pop();
        for (int i = n - 1; i >= 0; i--) {
            while (!stk.empty() && heights[stk.top()] >= heights[i])
                stk.pop();
            right[i] = stk.empty() ? n : stk.top();
            stk.push(i);
        }
        
        int maxArea = 0;
        for (int i = 0; i < n; i++) {
            maxArea = max(maxArea, heights[i] * (right[i] - left[i] - 1));
        }
        return maxArea;
    }
};
```

**关键点**：
- `left[i] = -1` 表示左边没有比它小的（可以延伸到最左端）
- `right[i] = n` 表示右边没有比它小的（可以延伸到最右端）

### 解法3: 单调栈（一次遍历 + 哨兵） — O(n) / O(n) ⭐ 面试首选

**进一步优化**：在出栈的那一刻，左右边界都已知——左边界是新栈顶，右边界是导致出栈的当前元素。所以可以在出栈时直接计算面积，无需预处理两个数组。

加入首尾哨兵 `0`，省去边界判断。

```cpp
class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        // 首尾加哨兵：头部0确保栈不会空，尾部0确保所有柱子都被弹出
        heights.insert(heights.begin(), 0);
        heights.push_back(0);
        int n = heights.size(), maxArea = 0;
        stack<int> stk;
        
        for (int i = 0; i < n; i++) {
            // 维护单调递增栈：当前柱子比栈顶矮 → 栈顶柱子的右边界找到了
            while (!stk.empty() && heights[stk.top()] > heights[i]) {
                int h = heights[stk.top()];
                stk.pop();
                // 宽度 = 右边界i - 左边界(新栈顶) - 1
                int w = i - stk.top() - 1;
                maxArea = max(maxArea, h * w);
            }
            stk.push(i);
        }
        
        // 恢复原数组（面试中可以不恢复，这里是好习惯）
        heights.erase(heights.begin());
        heights.pop_back();
        
        return maxArea;
    }
};
```

**单调栈过程可视化**（以 `[0, 2, 1, 5, 6, 2, 3, 0]` 加哨兵后为例）：

```
i=0, h=0: 栈空, push 0           栈: [0]
i=1, h=2: 2>0, push 1            栈: [0, 1]
i=2, h=1: 1<2, pop 1             ← 弹出 h=2, w = 2-0-1 = 1, area = 2
           1>0? No, push 2       栈: [0, 2]
i=3, h=5: 5>1, push 3            栈: [0, 2, 3]
i=4, h=6: 6>5, push 4            栈: [0, 2, 3, 4]
i=5, h=2: 2<6, pop 4             ← 弹出 h=6, w = 5-3-1 = 1, area = 6
           2<5, pop 3             ← 弹出 h=5, w = 5-2-1 = 2, area = 10 ★
           2>1? No, push 5       栈: [0, 2, 5]
i=6, h=3: 3>2, push 6            栈: [0, 2, 5, 6]
i=7, h=0: 0<3, pop 6             ← 弹出 h=3, w = 7-5-1 = 1, area = 3
           0<2, pop 5             ← 弹出 h=2, w = 7-2-1 = 4, area = 8
           0<1, pop 2             ← 弹出 h=1, w = 7-0-1 = 6, area = 6
           0>0? No, push 7       栈: [0, 7]

最大面积 = 10 ✓
```

## 解法对比

| | 暴力 | 两次遍历单调栈 | 一次遍历+哨兵 |
|---|---|---|---|
| 时间 | O(n²) | O(n) | O(n) |
| 空间 | O(1) | O(n) — left[]+right[]+栈 | O(n) — 仅栈 |
| 代码量 | 最少 | 中等 | 最简洁 |
| 面试推荐 | ✗ | ✓ 思路清晰 | ⭐ 最优雅 |
| 要点 | 好理解但超时 | 分两步好理解 | 哨兵技巧需要熟练 |

## 易错点

1. **✗ 哨兵漏加**：不加尾部哨兵 `0`，遍历结束后栈中可能还有元素没处理（如全递增数组 `[1,2,3]`）。
   **✓ 正确做法**：尾部加 `0`，保证所有柱子都被弹出。

2. **✗ 宽度计算错误**：`w = i - mid`，这只算了右半部分。
   **✓ 正确做法**：`w = i - stk.top() - 1`，弹出 `mid` 后，新栈顶才是左边界。

3. **✗ 比较条件用 `>=` 导致重复计算**：在一次遍历版本中，`while` 条件用 `>=` 还是 `>` 会影响相等高度柱子的处理。
   **✓ 说明**：用 `>` 时，相等的柱子不弹出，最后弹出时宽度会自动覆盖正确范围，结果不影响正确性。用 `>=` 也可以，但要理解在有重复高度时同一个矩形可能被不同柱子重复计算（取 max 所以结果正确）。

4. **✗ 修改了原数组却没恢复**：`insert/push_back` 修改了输入引用。面试中面试官可能关心你是否注意到了 side effect。
   **✓ 可以用 `copy` 或事后恢复**，或者不加哨兵改用栈空时特殊处理。

## 面试追问

**Q1: 暴力法的瓶颈在哪？为什么单调栈能优化到 O(n)？**
> 暴力法对每根柱子都要向左向右线性扫描找边界，最坏 O(n) × n 根 = O(n²)。单调栈利用了一个关键性质：每个元素最多入栈、出栈各一次，所以总操作数是 O(n)。出栈时天然获得左右边界信息。

**Q2: 如果不加哨兵，遍历结束后怎么处理栈中剩余元素？**
> 遍历结束后栈中剩余元素说明它们右边没有更小的柱子，右边界就是 `n`。需要一个 while 循环逐个弹出处理，宽度 = `n - stk.top() - 1`。加哨兵就是为了避免这个额外逻辑。

**Q3: 这道题和 LeetCode 85（最大矩形）有什么关系？**
> 85 题是在 01 矩阵中找最大全 1 矩形。经典做法是逐行构建柱状图——每行往上连续 1 的个数作为柱子高度，然后对每行调用本题的 `largestRectangleArea`。所以 84 是 85 的核心子问题。

**Q4: 能否不用额外空间（栈）解决？**
> 理论上可以用分治 O(n log n)：找区间最小值，分左右子区间递归。但代码复杂且常数大，实际面试中单调栈是最优选择。
