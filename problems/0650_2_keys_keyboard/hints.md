# 650. 两个键的键盘

## 难度: Medium
## 标签: Math, Dynamic Programming

## 题目理解
初始屏幕上有一个 'A'，只能执行"复制全部"和"粘贴"两种操作。求得到恰好 n 个 'A' 的最少操作次数。

## 思路提示

### 提示 1: 观察规律
- n=1: 0 步（已经有了）
- n=2: 2 步（复制+粘贴）
- n=3: 3 步（复制+粘贴+粘贴）
- n=4: 4 步（复制+粘贴+复制+粘贴）
- n=6: 5 步（C+P+P 得到3，再 C+P 得到6）

### 提示 2: 质因数分解（数学解法）
- 答案等于 n 的所有质因数之和
- 例如 n=12=2*2*3，答案=2+2+3=7
- 直觉：每次"复制+粘贴p-1次"相当于乘以质因子 p，需要 p 步

### 提示 3: DP 解法
- `dp[i]` = 得到 i 个 'A' 的最少操作数
- 对于 i 的每个因子 j（j 能整除 i）：`dp[i] = min(dp[i], dp[j] + i/j)`
- `dp[j] + i/j` 的含义：先用 dp[j] 步得到 j 个 A，然后复制一次 + 粘贴 (i/j - 1) 次

### 提示 4: 贪心质因数分解
- 从最小质因子开始分解 n
- 每找到一个质因子 p，答案累加 p，n 除以 p
- 重复直到 n = 1

## 复杂度分析
- 质因数分解: 时间 O(sqrt(n))，空间 O(1)
- DP: 时间 O(n * sqrt(n))，空间 O(n)

## 关键点
1. 核心洞察：最少操作数 = n 的质因数之和
2. DP 状态转移：枚举因子，复制+多次粘贴
3. 数学解法更优，但 DP 更直观
