# 1143. 最长公共子序列

## 核心思路

本质上在问：两个字符串中，能找到的最长的"保持相对顺序但不必连续"的公共字符序列有多长？这是一个经典的二维 DP 问题——两个字符串的字符逐对比较，匹配则"继承+1"，不匹配则取两种"退一步"中的较大值。

## 思维链

1. **读完题第一反应**：子序列 ≠ 子串，不要求连续。最暴力的做法是枚举 text1 的所有子序列（共 2^m 个），逐一检查是否也是 text2 的子序列。指数级复杂度，完全不可接受。

2. **能否用递归描述？** 考虑从两个字符串的末尾往前看：
   - 如果 `text1[i-1] == text2[j-1]`，这个字符一定可以放入 LCS，问题缩小为 `text1[0..i-2]` 和 `text2[0..j-2]` 的 LCS。
   - 如果不相等，要么 text1 末尾字符不在 LCS 中，要么 text2 末尾字符不在 LCS 中，取两者较大值。

3. **暴力递归的瓶颈**：画出递归树会发现大量重叠子问题。比如 `solve(3,2)` 可能从 `solve(4,2)` 和 `solve(3,3)` 都调用到。→ 加 memo 即可！

4. **从记忆化到递推**：`dp[i][j]` 表示 `text1[0..i-1]` 和 `text2[0..j-1]` 的 LCS 长度。填表方向：从左上角到右下角，保证依赖的状态都已算过。

5. **空间优化**：`dp[i][j]` 只依赖 `dp[i-1][j-1]`、`dp[i-1][j]`、`dp[i][j-1]`，即只依赖上一行和当前行。可以用一维滚动数组 + 一个额外变量保存左上角值。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力递归 | 枚举所有子序列 | O(2^m · n) | O(m) | 能说出即可 |
| 记忆化搜索 | 递归+memo | O(m·n) | O(m·n) | 能说出即可 |
| 二维 DP | 递推填表 | O(m·n) | O(m·n) | ⭐ 必须写出 |
| 一维 DP（空间优化） | 滚动数组 | O(m·n) | O(min(m,n)) | 加分项 |

## 关键提示

1. **状态定义是关键**：`dp[i][j]` 代表 `text1` 的前 i 个字符与 `text2` 的前 j 个字符的 LCS 长度。注意是"前 i 个"而不是"第 i 个"，这样 `dp[0][...]` 和 `dp[...][0]` 天然为 0，不需要特殊处理。

2. **状态转移只有两种情况**：末尾字符相同 → 左上角+1；末尾字符不同 → 取上方和左方的较大值。想想为什么不需要考虑 `dp[i-1][j-1]`？（因为它一定 ≤ `dp[i-1][j]` 和 `dp[i][j-1]`）

3. **DP 表填充方向**：
```
//     ""  a  c  e
// ""   0  0  0  0
//  a   0  1  1  1
//  b   0  1  1  1
//  c   0  1  2  2
//  d   0  1  2  2
//  e   0  1  2  3
```

4. **空间优化的陷阱**：压缩到一维后，`dp[j-1]` 已经被当前行覆盖了，需要用一个变量 `prev` 提前保存旧的 `dp[j-1]`（即二维中的 `dp[i-1][j-1]`）。

5. **为什么匹配时只取左上角+1，不取上方或左方？** 因为如果 `text1[i-1] == text2[j-1]`，这一对字符加入 LCS 一定不会比不加差。数学上可以证明 `dp[i-1][j-1]+1 >= max(dp[i-1][j], dp[i][j-1])`。

## 解法详解

### 解法1: 暴力递归 — O(2^(m+n)) / O(m+n)

**思考过程**：最自然的想法——从两个字符串末尾开始，字符相同就同时往前缩，不同就分两种情况递归。

```cpp
class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        return solve(text1, text2, text1.size(), text2.size());
    }
    
    int solve(string& s1, string& s2, int i, int j) {
        if (i == 0 || j == 0) return 0;  // 任一字符串为空，LCS=0
        if (s1[i - 1] == s2[j - 1]) {
            // 末尾字符相同，必然在LCS中，两个都往前缩
            return 1 + solve(s1, s2, i - 1, j - 1);
        } else {
            // 不同，要么丢掉s1末尾，要么丢掉s2末尾
            return max(solve(s1, s2, i - 1, j), solve(s1, s2, i, j - 1));
        }
    }
};
```

**关键点**：这个解法会超时（指数级），但它定义了正确的递归结构，是后续所有优化的基础。

---

### 解法2: 记忆化搜索 — O(m·n) / O(m·n)

**从解法1优化**：递归过程中 `(i, j)` 的组合最多 m×n 种，但暴力递归会重复计算。加一个 memo 数组缓存即可。

```cpp
class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        int m = text1.size(), n = text2.size();
        // memo 初始化为 -1 表示未计算
        vector<vector<int>> memo(m + 1, vector<int>(n + 1, -1));
        return solve(text1, text2, m, n, memo);
    }
    
    int solve(string& s1, string& s2, int i, int j, vector<vector<int>>& memo) {
        if (i == 0 || j == 0) return 0;
        if (memo[i][j] != -1) return memo[i][j];  // 已计算过，直接返回
        
        if (s1[i - 1] == s2[j - 1]) {
            memo[i][j] = 1 + solve(s1, s2, i - 1, j - 1, memo);
        } else {
            memo[i][j] = max(solve(s1, s2, i - 1, j), solve(s1, s2, i, j - 1, memo));
        }
        return memo[i][j];
    }
};
```

**关键点**：memo 用 -1 初始化而不是 0，因为 LCS 长度可以为 0（合法结果），必须区分"未计算"和"计算结果为0"。

---

### 解法3: 二维 DP（递推） — O(m·n) / O(m·n) ⭐ 面试首选

**从记忆化到递推**：把递归翻译成 for 循环填表，消除递归栈开销。

```
// dp 填表方向与依赖关系:
//
//  dp[i-1][j-1]  dp[i-1][j]
//       ↘           ↓
//  dp[i][j-1] →  dp[i][j]
//
// 当 text1[i-1]==text2[j-1]: dp[i][j] = dp[i-1][j-1] + 1  (左上角+1)
// 当 text1[i-1]!=text2[j-1]: dp[i][j] = max(dp[i-1][j], dp[i][j-1])
//
// 示例: text1="abcde", text2="ace"
//
//     ""  a  c  e
// ""   0  0  0  0
//  a   0  1  1  1    ← 'a'=='a', dp[1][1]=dp[0][0]+1=1
//  b   0  1  1  1    ← 'b'≠'a','c','e', 取 max(上,左)
//  c   0  1  2  2    ← 'c'=='c', dp[3][2]=dp[2][1]+1=2
//  d   0  1  2  2
//  e   0  1  2  3    ← 'e'=='e', dp[5][3]=dp[4][2]+1=3
//
// 答案 dp[5][3] = 3
```

```cpp
class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        int m = text1.size(), n = text2.size();
        // dp[i][j]: text1前i个字符 与 text2前j个字符 的LCS长度
        // 多开一行一列，dp[0][...]=dp[...][0]=0 作为base case
        vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
        
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1[i - 1] == text2[j - 1]) {
                    // 两个末尾字符相同，LCS长度在"都去掉末尾"的基础上+1
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    // 不同，取"去掉text1末尾"或"去掉text2末尾"的较大值
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }
        return dp[m][n];
    }
};
```

**关键点**：
- 下标偏移：`dp[i][j]` 对应 `text1[i-1]` 和 `text2[j-1]`，因为 dp 数组多了一行一列作为 base case。
- 第 0 行和第 0 列全为 0，表示空字符串与任何字符串的 LCS 为 0。

### 解法4: 一维 DP（空间优化） — O(m·n) / O(min(m,n))

**从解法3优化**：观察依赖关系，`dp[i][j]` 只依赖上一行和当前行。可以用一维数组 + 一个变量 `prev` 保存"左上角"的旧值。

```
// 空间优化核心思想:
//
// 二维中: dp[i][j] 依赖 dp[i-1][j-1], dp[i-1][j], dp[i][j-1]
//
// 压缩到一维 dp[j]:
//   dp[j]   (更新前) = 旧的 dp[i-1][j]  → 即"上方"
//   dp[j-1] (更新后) = 新的 dp[i][j-1]  → 即"左方"
//   prev              = 旧的 dp[i-1][j-1] → 即"左上角" ← 需要额外保存!
//
// 每次更新 dp[j] 之前，先把旧的 dp[j] 存到 prev 里
// 这样下一轮 j+1 时，prev 就是 dp[i-1][j]，即新的"左上角"
```

```cpp
class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        int m = text1.size(), n = text2.size();
        // 让较短的字符串作为内层循环，节省空间
        if (m < n) return longestCommonSubsequence(text2, text1);
        
        vector<int> dp(n + 1, 0);
        
        for (int i = 1; i <= m; i++) {
            int prev = 0;  // prev 保存 dp[i-1][j-1]，即"左上角"
            for (int j = 1; j <= n; j++) {
                int temp = dp[j];  // 暂存旧值（更新前的dp[j]即dp[i-1][j]）
                if (text1[i - 1] == text2[j - 1]) {
                    dp[j] = prev + 1;  // 左上角 + 1
                } else {
                    dp[j] = max(dp[j], dp[j - 1]);  // max(上方, 左方)
                }
                prev = temp;  // 更新 prev 为下一轮的"左上角"
            }
        }
        return dp[n];
    }
};
```

**关键点**：`prev` 变量的更新时机极其重要——必须在修改 `dp[j]` 之前把旧值存起来。

## 解法对比

| | 暴力递归 | 记忆化搜索 | 二维 DP | 一维 DP |
|---|---|---|---|---|
| 时间 | O(2^(m+n)) | O(m·n) | O(m·n) | O(m·n) |
| 空间 | O(m+n) 栈 | O(m·n) | O(m·n) | O(min(m,n)) |
| 思维难度 | 低 | 低 | 中 | 中高 |
| 面试推荐 | 口头提及 | 可以先写 | ⭐ 首选 | 追问时写 |

**选择建议**：
- 面试时先写二维 DP，清晰易懂不容易出错。
- 面试官追问空间优化时，再讲一维滚动数组。
- 记忆化搜索和递推本质相同，面试时递推更常见（面试官更容易看懂）。

## 易错点

1. **下标偏移搞混**
   - ✗ `if (text1[i] == text2[j])` 配合 `dp[i][j]` 从 `i=0` 开始
   - ✓ `if (text1[i-1] == text2[j-1])` 配合 `dp[i][j]` 从 `i=1` 开始
   - 原因：dp 数组的第 0 行/列是 base case（空字符串），所以 `dp[i][j]` 对应的是 `text1` 的第 `i-1` 个字符。

2. **空间优化时忘记保存左上角**
   - ✗ 直接 `dp[j] = dp[j-1] + 1`（此时 `dp[j-1]` 已经是当前行的值，不是上一行的）
   - ✓ 用 `prev` 变量保存更新前的 `dp[j-1]`
   - 原因：一维数组中 `dp[j-1]` 在内层循环中已经被更新为当前行的值，但匹配时需要的是上一行的 `dp[j-1]`。

3. **空间优化时 prev 初始化位置错误**
   - ✗ `prev` 在两层循环外只初始化一次
   - ✓ `prev = 0` 必须在每一轮外层循环开始时重置
   - 原因：每新的一行，`dp[i][0]` 是 0，所以 `prev`（即 `dp[i-1][0]`）也应为 0。

4. **记忆化搜索用 0 初始化 memo**
   - ✗ `vector<vector<int>> memo(m+1, vector<int>(n+1, 0))` 然后 `if (memo[i][j] != 0) return`
   - ✓ 用 -1 初始化，因为 LCS 长度为 0 是合法结果
   - 原因：如果 memo 初始化为 0 且检查 `!= 0`，则 LCS=0 的情况永远不会被缓存。

## 面试追问

**Q1: 暴力法的复杂度是多少？瓶颈在哪？**
→ 暴力枚举 text1 所有子序列共 2^m 个，每个检查是否是 text2 的子序列需 O(n)，总计 O(n·2^m)。瓶颈：指数级枚举。递归方式稍好但仍有大量重叠子问题。

**Q2: 能否输出具体的 LCS 字符串，而不只是长度？**
→ 先跑一遍 DP 填完表，然后从 `dp[m][n]` 回溯：如果 `text1[i-1] == text2[j-1]`，该字符在 LCS 中，往左上走；否则往 `dp[i-1][j]` 和 `dp[i][j-1]` 中较大的方向走。时间 O(m+n)，空间 O(m+n) 存结果。

**Q3: 如果字符集很小（比如只有 DNA 四个字符 ACGT），有没有比 O(m·n) 更快的方法？**
→ 有。Hunt-Szymanski 算法将 LCS 问题转化为 LIS（最长递增子序列）问题，在匹配点稀疏时（即公共字符对较少）可以做到 O(r·log n)，其中 r 是匹配对数。但面试中一般不考察这个。

**Q4: 空间能否进一步优化到 O(1)？**
→ 不能。LCS 的状态转移需要至少一行的信息，O(min(m,n)) 已经是下界。

- **1092. 最短公共超序列** — 同样先求 LCS，然后在回溯路径时"合并"两个字符串。需要额外的路径恢复技巧（即 Q2 的追问）。
- **72. 编辑距离** — 同样的二维 DP 框架，区别在于状态转移：编辑距离的"不匹配"情况有三种操作（插入/删除/替换），转移方程变成 `min(上+1, 左+1, 左上+1)`，而 LCS 是 `max(上, 左)`。
- **300. 最长递增子序列 (LIS)** — 单序列版本的子序列 DP。LCS 是双序列比较，LIS 是单序列内部比较。掌握 LCS 后 LIS 的 DP 思路很自然。
- **718. 最长重复子数组** — 和 LCS 极其相似，区别：子数组要求连续，所以不匹配时 `dp[i][j] = 0`（而不是取 max）。只改一行代码。
