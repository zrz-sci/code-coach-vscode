# 643. 子数组最大平均数 I

## 核心思路

本质上就是在所有长度为 k 的连续子数组中，找到**元素之和最大**的那个（和最大 ↔ 平均数最大，因为 k 是定值）。

## 思维链

1. **读完题第一反应**：枚举所有长度为 k 的子数组，计算每个子数组的和，取最大值。这就是暴力法。
2. **暴力解的瓶颈在哪？** 对于每个起点 i，我们从 `nums[i]` 加到 `nums[i+k-1]`，每次都重新算 k 个数的和。但相邻两个窗口 `[i, i+k-1]` 和 `[i+1, i+k]` 之间有 k-1 个重叠元素，重复计算了！
3. **怎么突破？** 窗口从 i 滑到 i+1 时，只是**减掉左边出去的那个元素，加上右边进来的那个元素**。这就是固定大小滑动窗口的核心思想。
4. **具体做法**：先算前 k 个元素之和作为初始窗口，然后右边界每右移一位，`sum += nums[right] - nums[right - k]`，同时更新最大和。
5. **最后**：最大和 / k 就是答案。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力枚举 | 每个起点重新求 k 项之和 | O(n·k) | O(1) | 能说出即可 |
| 前缀和 | 预处理前缀和，区间和 = 差值 | O(n) | O(n) | 加分项 |
| 固定滑动窗口 | 窗口滑动时 O(1) 更新窗口和 | O(n) | O(1) | ⭐ 必须写出 |

## 关键提示

1. **平均数最大 ↔ 总和最大**：因为 k 固定不变，所以不需要每次都做除法，只在最后除一次即可。
2. **两个相邻窗口的关系**：`[0,1,2,3]` 和 `[1,2,3,4]` 共享了 `[1,2,3]`，只差了一个"出去"和一个"进来"的元素。
3. **整数溢出？** k ≤ 10⁵，元素 ≤ 10⁴，最大和 = 10⁹，int 足够。但返回值是 double，最后除法时注意类型转换。
4. **前缀和也能解**：`prefix[i] = nums[0] + ... + nums[i-1]`，区间 `[i, i+k-1]` 的和 = `prefix[i+k] - prefix[i]`。但滑动窗口更直接且空间更优。

```
滑动窗口过程（nums = [1,12,-5,-6,50,3], k = 4）:

窗口位置:                    窗口和:
[1, 12, -5, -6] 50  3       1+12-5-6 = 2
 1 [12, -5, -6, 50]  3      2 - 1 + 50 = 51   ← 最大
 1  12 [-5, -6, 50,  3]     51 - 12 + 3 = 42

最大和 = 51, 最大平均 = 51/4 = 12.75
```

## 解法详解

### 解法1: 暴力枚举 — O(n·k) / O(1)

**思考过程**: 最直觉的做法——对每个合法起点 i (从 0 到 n-k)，算出 `nums[i] + nums[i+1] + ... + nums[i+k-1]`，记录最大和。

```cpp
class Solution {
public:
    double findMaxAverage(vector<int>& nums, int k) {
        int n = nums.size();
        int maxSum = INT_MIN;
        
        for (int i = 0; i <= n - k; i++) {
            int sum = 0;
            for (int j = i; j < i + k; j++) {
                sum += nums[j];
            }
            maxSum = max(maxSum, sum);
        }
        
        return (double)maxSum / k;
    }
};
```

**关键点**: 当 n = 10⁵ 且 k = 5×10⁴ 时，内层循环要做约 5×10⁴ 次，总计约 2.5×10⁹ 次操作，会超时（TLE）。瓶颈就是**每个窗口都重新求和**。

### 解法2: 前缀和 — O(n) / O(n)

**从暴力优化**: 暴力法每次重新计算区间和，而前缀和可以用 O(1) 获取任意区间和。

```cpp
class Solution {
public:
    double findMaxAverage(vector<int>& nums, int k) {
        int n = nums.size();
        // prefix[i] = nums[0] + nums[1] + ... + nums[i-1]
        vector<int> prefix(n + 1, 0);
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }
        
        int maxSum = INT_MIN;
        for (int i = 0; i <= n - k; i++) {
            // 区间 [i, i+k-1] 的和 = prefix[i+k] - prefix[i]
            int sum = prefix[i + k] - prefix[i];
            maxSum = max(maxSum, sum);
        }
        
        return (double)maxSum / k;
    }
};
```

**关键点**: 时间优化到 O(n) 了，但额外用了 O(n) 空间存前缀和数组。对于本题来说不是最优选择，但前缀和是更通用的技巧——当你需要查询**任意长度**的区间和时，前缀和比滑动窗口更灵活。

### 解法3: 固定大小滑动窗口 — O(n) / O(1) ⭐ 面试首选

**核心观察**: 窗口从位置 i 滑到 i+1，和的变化量 = `nums[i+k] - nums[i]`。只需 O(1) 就能从旧窗口和推出新窗口和。

```cpp
class Solution {
public:
    double findMaxAverage(vector<int>& nums, int k) {
        // 第一步：计算初始窗口 [0, k-1] 的和
        int windowSum = 0;
        for (int i = 0; i < k; i++) {
            windowSum += nums[i];
        }
        
        int maxSum = windowSum;
        
        // 第二步：窗口右移，每次加上新进来的、减去出去的
        for (int i = k; i < (int)nums.size(); i++) {
            windowSum += nums[i] - nums[i - k];  // 进来 nums[i]，出去 nums[i-k]
            maxSum = max(maxSum, windowSum);
        }
        
        // 只在最后做一次除法，避免浮点运算积累误差
        return (double)maxSum / k;
    }
};
```

**关键点**: 这是固定大小滑动窗口的标准模板——先初始化第一个窗口，然后逐步滑动更新。O(n) 时间 + O(1) 空间，是本题的最优解。

## 解法对比

| | 暴力枚举 | 前缀和 | 滑动窗口 |
|---|---|---|---|
| 时间 | O(n·k) | O(n) | O(n) |
| 空间 | O(1) | O(n) | O(1) |
| 核心思想 | 每次重新算 | 预处理区间和 | 增量更新 |
| 适用场景 | 理解题意 | 需要查询任意区间 | 固定/可变窗口 |

**面试选滑动窗口**：时间和空间都最优，代码最简洁，且展示了你理解滑动窗口这个重要技巧。

## 易错点

1. **初始化 maxSum 为 0 而非第一个窗口的和**
   - ✗ `int maxSum = 0;` → 当所有元素都是负数时（如 `[-1,-2,-3], k=2`），maxSum=0 不会被更新，返回错误结果 0
   - ✓ `int maxSum = windowSum;` → 用第一个窗口的实际和初始化

2. **在循环中每次都做除法**
   - ✗ `maxAvg = max(maxAvg, (double)windowSum / k);` → 浮点比较有精度问题，且多余的浮点运算
   - ✓ 全程用整数 sum 比较，最后才除以 k

3. **滑动窗口的索引搞混**
   - ✗ `windowSum += nums[i] - nums[i - k + 1];` → 出去的元素位置算错
   - ✓ `windowSum += nums[i] - nums[i - k];` → 当 i 是新进来元素的下标时，出去的是 `i - k`

4. **返回值类型**
   - ✗ `return maxSum / k;` → 整数除法，会截断小数部分
   - ✓ `return (double)maxSum / k;` → 至少一个操作数转成 double

## 面试追问

**Q1: 暴力解能不能过？瓶颈在哪？**
暴力解 O(n·k)，n 和 k 最大都是 10⁵，最坏 10¹⁰ 次操作，远超时间限制。瓶颈在于每个窗口都重新求和，相邻窗口的重叠部分被重复计算了。

**Q2: 如果 k 不固定，而是要求所有长度 ≥ k 的子数组中的最大平均数呢？**
这是 LeetCode 644（子数组最大平均数 II），难度 Hard。不能简单用滑动窗口了，需要用**二分答案 + 前缀和**的技巧：二分猜一个平均值 mid，然后检查是否存在长度 ≥ k 的子数组平均值 ≥ mid。

**Q3: 如果窗口大小不固定，而是找"和 ≥ target 的最短子数组"呢？**
这是 LeetCode 209（长度最小的子数组），需要用**可变大小滑动窗口**：右边界扩展到满足条件，左边界尽量收缩以找到最短长度。
