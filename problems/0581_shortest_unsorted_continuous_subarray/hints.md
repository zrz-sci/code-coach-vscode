# 581. 最短无序连续子数组

## 核心思路

本质上在问：**数组的哪一段"不在正确位置上"？** 找出最左边和最右边"不在正确位置"的元素，它们之间的距离就是答案。

## 思维链

1. **读完题第一反应**：如果数组排好序了，"不正确"的部分一目了然。把原数组和排序后的数组对比，找出第一个和最后一个不同的位置即可。→ 排序对比法 O(n log n)。

2. **暴力解的瓶颈**：排序需要 O(n log n)，题目 Follow-up 要求 O(n)。能不能不排序就找到边界？

3. **关键观察**：
   - 数组可以分成三段：`左段(已排好) | 中段(需要排序) | 右段(已排好)`
   - 中段的**最小值**必须 ≥ 左段的所有元素，否则左边界还要往左扩
   - 中段的**最大值**必须 ≤ 右段的所有元素，否则右边界还要往右扩

4. **怎么 O(n) 找边界**：
   - 从左往右扫：维护已见过的最大值 `max_seen`，如果 `nums[i] < max_seen`，说明 `i` 这个位置"不对"，更新右边界
   - 从右往左扫：维护已见过的最小值 `min_seen`，如果 `nums[i] > min_seen`，说明 `i` 这个位置"不对"，更新左边界

5. **为什么这样做是对的**：在一个排好序的数组中，从左往右每个元素都应该 ≥ 前面所有元素。最后一个违反这个条件的位置就是右边界；对称地，第一个违反"从右往左递增"的位置就是左边界。

6. **另一种视角（单调栈）**：用递增单调栈从左到右扫，遇到更小的元素时不断弹栈，弹出的栈底索引就是左边界；对称地从右往左用递增栈找右边界。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 排序对比 | 排序后逐位对比 | O(n log n) | O(n) | 能说出即可 |
| 双指针扫描 | 从两端扫描找min/max边界 | O(n) | O(1) | ⭐ 必须写出 |
| 单调栈 | 用单调栈找左右边界 | O(n) | O(n) | 加分项 |

## 关键提示

1. **排序对比是最直觉的方法**：排序后的数组就是"正确答案"，原数组和它的第一个/最后一个不同位置就是边界。先把这个想清楚，再优化。

2. **O(n) 解法的核心问**：不排序怎么知道一个元素"不在正确位置"？→ 如果它比左边某个已经出现过的元素还小，或比右边某个将要出现的元素还大，它就不对。

3. **双向扫描的直觉**：从左往右，一个正确排序的数组每个元素都该是"到目前为止的最大值"。一旦不是，说明这个位置需要被排序。最后一个这样的位置就是右边界 `right`。

4. **特殊情况**：数组已经有序时，左右边界都不会被更新，需要正确返回 0。

5. 用 ASCII 理解示例：
   ```
   原数组:    [2, 6, 4, 8, 10, 9, 15]
   排序后:    [2, 4, 6, 8,  9,10, 15]
                  ↑              ↑
                left=1        right=5
   答案 = 5 - 1 + 1 = 5
   ```

## 解法详解

### 解法1: 排序对比 — O(n log n) / O(n)

**思考过程**：最直觉的想法 — 排序就是"正确答案"，和原数组一对比就知道哪里不对。

```cpp
class Solution {
public:
    int findUnsortedSubarray(vector<int>& nums) {
        vector<int> sorted_nums = nums;
        sort(sorted_nums.begin(), sorted_nums.end());
        
        int left = nums.size(), right = -1;
        for (int i = 0; i < nums.size(); i++) {
            if (nums[i] != sorted_nums[i]) {
                left = min(left, i);
                right = max(right, i);
            }
        }
        
        // 如果 right == -1，说明数组本身有序
        return right == -1 ? 0 : right - left + 1;
    }
};
```

**关键点**：这是理解题意最好的方式。瓶颈在排序 O(n log n)，但对于面试来说，先说出这个解法展示你理解了题目，再优化。

---

### 解法2: 双向扫描（双指针思想） — O(n) / O(1) ⭐ 面试首选

**从解法1优化**：排序的目的是找"每个元素的正确位置"，但我们其实只需要两个边界。关键观察：

- **右边界**：从左往右扫，维护 `max_seen`（到目前为止的最大值）。如果 `nums[i] < max_seen`，说明 `nums[i]` 在当前位置是"错的"（它应该在更前面），更新 `right = i`。
- **左边界**：从右往左扫，维护 `min_seen`（到目前为止的最小值）。如果 `nums[i] > min_seen`，说明 `nums[i]` 在当前位置是"错的"（它应该在更后面），更新 `left = i`。

```
// 可视化（从左往右找右边界）:
// nums:      [2, 6, 4, 8, 10, 9, 15]
// max_seen:   2  6  6  8  10  10  15
//                   ↑           ↑
//                4<6=错      9<10=错  → right=5 (最后一个"错"的位置)
//
// 可视化（从右往左找左边界）:
// nums:      [2, 6, 4, 8, 10, 9, 15]
// min_seen:   2  4  4  8   9  9  15
//                ↑
//              6>4=错  → left=1 (最后一个"错"的位置)
```

```cpp
class Solution {
public:
    int findUnsortedSubarray(vector<int>& nums) {
        int n = nums.size();
        int max_seen = INT_MIN, min_seen = INT_MAX;
        int left = -1, right = -1;
        
        for (int i = 0; i < n; i++) {
            // 从左往右：当前值应该 >= 之前所有值
            if (nums[i] < max_seen) {
                right = i;          // 这个位置"不对"，更新右边界
            } else {
                max_seen = nums[i]; // 更新最大值
            }
            
            // 从右往左：当前值应该 <= 之后所有值
            // 用 n-1-i 做镜像遍历，合并到同一个循环
            if (nums[n - 1 - i] > min_seen) {
                left = n - 1 - i;   // 这个位置"不对"，更新左边界
            } else {
                min_seen = nums[n - 1 - i];
            }
        }
        
        // left == -1 说明数组已有序
        return left == -1 ? 0 : right - left + 1;
    }
};
```

**关键点**：
- 两个方向可以写在同一个循环里（用 `i` 和 `n-1-i`），也可以写成两个循环，效果相同。
- `left` 和 `right` 初始化为 -1，作为"未更新"的标志。

---

### 解法3: 单调栈 — O(n) / O(n)

**另一种视角**：用递增单调栈找"被打乱的边界"。

- **找左边界**：从左到右维护递增栈，遇到比栈顶小的元素时，不断弹栈。弹栈弹到的最小索引就是左边界（这些被弹出的元素需要被重新排序）。
- **找右边界**：对称地，从右到左维护递增栈（即递减栈视角），弹栈弹到的最大索引就是右边界。

```
// 单调栈找左边界过程 (递增栈，存索引):
// nums:  [2, 6, 4, 8, 10, 9, 15]
//         i=0: 栈空，push 0        栈: [0]
//         i=1: 6>2, push 1         栈: [0,1]
//         i=2: 4<6, pop 1→left=1   栈: [0]     ← 6不该在4前面
//              4>2, push 2          栈: [0,2]
//         i=3: 8>4, push 3         栈: [0,2,3]
//         i=4: 10>8, push 4        栈: [0,2,3,4]
//         i=5: 9<10, pop 4→left=min(1,4)=1  栈: [0,2,3]
//              9>8, push 5          栈: [0,2,3,5]
//         i=6: 15>9, push 6        栈: [0,2,3,5,6]
// left = 1
```

```cpp
class Solution {
public:
    int findUnsortedSubarray(vector<int>& nums) {
        int n = nums.size();
        stack<int> stk;
        int left = n, right = -1;
        
        // 从左往右，递增栈找左边界
        for (int i = 0; i < n; i++) {
            // 栈顶元素比当前大 → 栈顶位置需要被重排
            while (!stk.empty() && nums[stk.top()] > nums[i]) {
                left = min(left, stk.top());
                stk.pop();
            }
            stk.push(i);
        }
        
        // 清空栈，从右往左找右边界
        while (!stk.empty()) stk.pop();
        
        for (int i = n - 1; i >= 0; i--) {
            // 栈顶元素比当前小 → 栈顶位置需要被重排
            while (!stk.empty() && nums[stk.top()] < nums[i]) {
                right = max(right, stk.top());
                stk.pop();
            }
            stk.push(i);
        }
        
        return right == -1 ? 0 : right - left + 1;
    }
};
```

**关键点**：单调栈的本质是找"逆序对的边界"——哪些元素因为逆序需要被纳入排序范围。

## 易错点

1. **`left` 和 `right` 的初始化**：
   - ✗ `left = 0, right = n - 1` → 数组已有序时会错误返回 `n`
   - ✓ `left = -1, right = -1`（或 `left = n, right = -1`），用特殊值标记"未更新"

2. **双向扫描中 max_seen 的更新逻辑**：
   - ✗ `if (nums[i] >= max_seen) right = i;` — 方向搞反了
   - ✓ `if (nums[i] < max_seen) right = i;` — 比最大值小说明位置不对

3. **等于的情况**：`[1, 3, 2, 2, 2]`
   - 相等元素不构成"错误"，`nums[i] < max_seen` 用严格小于是正确的
   - 如果用 `<=` 会误判相等元素为"不在正确位置"

4. **单调栈中存索引而不是值**：
   - ✗ 存值 → 无法得到边界位置
   - ✓ 存索引 → 弹栈时记录索引作为边界

## 面试追问

**Q1: 暴力怎么做？时间复杂度？**
排序后逐位对比，O(n log n) 时间 O(n) 空间。这能通过本题，但不是最优。

**Q2: 能否 O(n) 时间 O(1) 空间？（Follow-up）**
双向扫描：从左往右维护 max_seen 找右边界，从右往左维护 min_seen 找左边界。本质是"一个正确排序的数组，每个位置都应该是前缀最大值"。

**Q3: 如果数组中有大量重复元素，解法需要调整吗？**
不需要。双向扫描用严格不等号 `<` 和 `>` 比较，重复元素不会影响正确性。例如 `[1,3,2,2,2]`，`max_seen` 到索引1时为3，后续的2都满足 `2 < 3`，right 会被正确更新到索引4。

**Q4: 如果不是找"最短"，而是找"所有需要移动的元素个数"？**
排序后，统计 `nums[i] != sorted[i]` 的个数。注意这和"最短子数组长度"不同——子数组是连续的，但中间可能有些元素恰好在正确位置。
