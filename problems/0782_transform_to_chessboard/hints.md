# 782. Transform to Chessboard

## 核心思路

本题是一道数学观察题。关键洞察：在一个合法的棋盘中，每一行和每一列只有两种模式（互为补码），并且行列的交换操作是独立的。因此可以将二维问题拆分为一维的行排列问题和一维的列排列问题，分别求最小交换次数后相加。

## 思维链

1. **合法性判断**：首先需要判断给定棋盘是否有可能被变换为合法棋盘。
2. **行模式分析**：一个合法的棋盘只有两种行模式，且这两种模式互为取反（0 和 1 互换）。
3. **列模式分析**：同理，列也只有两种模式。
4. **数量约束**：两种行模式的数量差不超过 1（n 为偶数时相等，n 为奇数时差 1）。
5. **行列独立**：交换行不影响列的排列，交换列不影响行的排列，所以分别计算。
6. **最小交换**：用第一行/第一列与目标模式比较，计算不匹配位置数，除以 2 即为交换次数。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 数学 + 位运算 | O(n^2) | O(1) | 最优解，利用棋盘对称性质 |
| 暴力枚举 | O(n! * n^2) | O(n^2) | 枚举所有排列，不可行 |

## 关键提示

1. 一个合法棋盘只有两种不同的行（互为补码），列同理。
2. 验证条件：任意两行的 XOR 结果要么全 0 要么全 1。
3. 用 `board[0][0] ^ board[i][0] ^ board[0][j] ^ board[i][j] == 0` 验证矩形性质。
4. 第一行中 1 的个数必须是 n/2 或 (n+1)/2。
5. 行交换次数：看第一列有多少行不在正确位置（0/1 交替），除以 2。
6. 列交换次数：看第一行有多少列不在正确位置（0/1 交替），除以 2。
7. n 为偶数时有两种目标模式（0 开头或 1 开头），取交换次数较小的那个。

## 解法详解

### 解法：数学观察 + 贪心

**核心思想**：一个 n x n 的棋盘合法当且仅当满足以下条件：
- 每一行只有两种模式：某种模式 T 和它的补码 ~T
- 每一列也只有两种模式
- 两种行模式的出现次数分别为 n/2 和 (n+1)/2
- 两种列模式的出现次数同理

**验证合法性**：
利用矩形性质：对于任意 4 个位置 (r1,c1), (r1,c2), (r2,c1), (r2,c2)，它们的 XOR 必须为 0。实际上只需要检查 (0,0), (0,j), (i,0), (i,j) 即可。

**计算最小交换**：
- 检查第一行：统计 board[0][j] 与目标模式 j%2 不匹配的位置数 colMismatch
- 检查第一列：统计 board[i][0] 与目标模式 i%2 不匹配的位置数 rowMismatch
- n 为偶数时：取 min(mismatch, n - mismatch)，因为两种目标都可以
- n 为奇数时：mismatch 必须为偶数，且只有一种合法目标
- 每种方向的交换次数 = mismatch / 2

**详细步骤**：
1. 遍历矩阵验证所有 board[0][0]^board[i][0]^board[0][j]^board[i][j] == 0
2. 统计第一行和第一列中 1 的个数，验证数量合法
3. 计算行方向和列方向分别需要的最小交换次数
4. 返回两者之和

## 易错点

1. **n 的奇偶性影响目标选择**：n 为偶数时两种目标都可以选，n 为奇数时只有一种合法目标，必须分别处理。
2. **矩形验证容易遗漏**：只检查行列独立的条件不够，必须验证矩形性质确保行列都只有两种互补模式。
3. **交换次数的计算**：不匹配位置数必须是偶数才能通过交换修复，若为奇数说明不可能。
4. **混淆行交换和列交换**：行交换影响的是"第一列"的排列顺序，列交换影响的是"第一行"的排列顺序，容易搞反。
5. **1 的个数的验证**：第一行和第一列中 1 的个数必须分别满足 n/2 或 (n+1)/2，而不是任意值。

## 面试追问

1. **Q: 为什么行交换和列交换是独立的？**
   A: 交换两行不会改变任何一列的元素集合（只是顺序变了），同理交换两列不改变行的元素集合。因此行交换次数和列交换次数可以独立计算后相加。

2. **Q: 如何证明"只有两种行模式"是必要条件？**
   A: 棋盘的任意两行必须满足：对应位置要么完全相同，要么完全相反（因为每列交替 0/1）。所以所有行只有两种可能的模式。

3. **Q: n=30 时有 2^30 种可能的行模式，如何高效验证？**
   A: 只需要比较每一行与第一行的关系（XOR 为全 0 或全 1），O(n^2) 即可完成验证。

4. **Q: 如果允许同时交换行和列，能否减少总次数？**
   A: 不能。行交换和列交换解决的是不同维度的排列问题，它们没有交叉影响，无法通过"一次操作同时优化两个维度"来减少总数。

5. **Q: 这道题和排列的逆序对有什么关系？**
   A: 最小交换次数等于把当前排列变为目标排列所需的最少相邻交换数 / 2（这里是任意位置交换）。等价于计算排列中"错位"位置的数量除以 2。
