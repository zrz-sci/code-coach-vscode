# 726. 原子的数量 (Number of Atoms)

**难度**: Hard | **标签**: Stack, Hash Table, String, Sorting

## 核心思路

本题本质上是一个**嵌套括号表达式解析**问题。化学式中括号可以嵌套（如 `K4(ON(SO3)2)2`），遇到右括号后的数字需要乘到括号内所有原子的计数上。最自然的处理方式是使用**栈**：每遇到左括号就新建一个计数层，遇到右括号就弹出当前层并将乘积合并到上一层。最终将栈底的 map 按字典序输出即可。

核心难点在于**字符串解析**：需要正确提取原子名称（大写字母开头+若干小写字母）和跟随的数字（可能多位或没有，没有则默认为1）。

## 思维链

1. **观察结构**: 化学式是递归定义的 -- `formula = atom count | '(' formula ')' count | formula formula`
2. **选择数据结构**: 递归/嵌套结构天然适合用栈处理。每一层用一个 `map<string,int>` 记录原子计数
3. **解析策略**: 从左到右扫描字符串，根据当前字符类型分派：
   - 大写字母 => 开始解析一个原子名
   - `(` => 压入新的空 map
   - `)` => 弹出栈顶 map，解析后面的数字，乘以该数字后合并到新栈顶
4. **输出格式**: 将最终 map 按 key 字典序排列，拼接 "原子名+数量(>1时)"

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 栈 + HashMap | O(n + k log k) | O(n) | 主流解法，直觉清晰 |
| 递归下降解析 | O(n + k log k) | O(n) | 编译原理风格，代码更紧凑 |
| 正则表达式 | O(n + k log k) | O(n) | 部分语言适用，面试不推荐 |

其中 n 为 formula 长度，k 为不同原子种类数。

## 关键提示

1. 解析原子名时，第一个字符必须是大写字母，后面跟 0 或多个小写字母
2. 解析数字时，可能是多位数（如 `O14`），也可能没有数字（默认为 1）
3. 遇到 `(` 时，向栈中压入一个新的空 map；遇到 `)` 时，弹出栈顶 map
4. `)` 后面的数字要乘到弹出的 map 中每个原子的计数上，然后合并回当前栈顶
5. 最终输出时需要按原子名的字典序排列

## 解法详解

### 解法一：栈 + HashMap（推荐）

**思路**: 维护一个 `stack<map<string,int>>`。初始压入一个空 map。

- 遇到大写字母：解析完整原子名和后续数字，加入当前栈顶 map
- 遇到 `(`：压入新空 map
- 遇到 `)`：弹出栈顶 map，解析后续乘数，将弹出 map 中所有元素乘以乘数后加到新栈顶

最终栈中只剩一个 map，排序输出即可。

**时间复杂度**: O(n + k log k)，n 为字符串长度，k 为原子种类数  
**空间复杂度**: O(n)

### 解法二：递归下降解析

**思路**: 用全局索引 `i` 实现递归函数 `parse()`：
- `parse()` 返回一个 `map<string,int>`
- 循环中遇到大写字母就解析原子+数字
- 遇到 `(` 就递归调用 `parse()`，返回后解析乘数并合并
- 遇到 `)` 或字符串结束就返回当前 map

这种方法本质与栈相同，但用函数调用栈替代了显式栈。

**时间复杂度**: O(n + k log k)  
**空间复杂度**: O(n)

## 易错点

1. **忘记处理多位数字**: 像 `O14` 中 14 是两位数，需要循环读取所有连续数字
2. **没有数字默认为 1**: 原子后面没跟数字时计数为 1，不是 0
3. **括号后没有数字**: `(H2O)` 后面没跟数字，乘数应该默认为 1
4. **大小写混淆**: 原子名以大写开头，`Mg` 是一个原子而不是 `M` 和 `g` 两个
5. **输出格式**: 数量为 1 时不输出数字，只输出原子名
6. **栈初始化**: 初始时栈中必须有一个空 map 作为基础层
7. **合并逻辑遗漏**: 弹出括号层的 map 后，要加到（而非替换）当前栈顶的 map

## 面试追问

1. **如果化学式中可能包含无效字符或格式错误，你会如何处理？**
   - 在解析过程中增加状态机验证，检查括号匹配、原子名格式等，遇到非法输入抛出异常或返回错误码

2. **如果需要支持方括号 `[]` 和大括号 `{}`，代码需要怎么改？**
   - 只需将 `(` 和 `)` 的判断扩展为所有开闭括号类型，核心逻辑不变

3. **如何验证括号是否匹配？**
   - 维护括号计数器或在栈操作中检查：遇到 `)` 时栈中至少有 2 层（包括基础层），最终栈中恰好剩 1 层

4. **这道题与表达式求值（如计算器系列）有什么联系？**
   - 本质相同：都是用栈处理嵌套结构。计算器中栈存数字和运算符，本题栈存原子计数 map。括号处理逻辑完全一致

5. **能否用 O(1) 额外空间解决？**
   - 不能。嵌套括号深度不确定，需要栈来记录每层的原子计数状态
