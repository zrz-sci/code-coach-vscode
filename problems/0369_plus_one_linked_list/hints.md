# 369. 给单链表加一

## 题目理解

给定一个用单链表表示的非负整数（最高位在链表头），将这个整数加一后返回链表。

**本质**：单链表上的进位加法。难点在于进位是从低位向高位传播，但单链表只能从高位（head）向低位遍历。需要找到一种方法"反向传播进位"。

```
示例1: 1 -> 2 -> 3  =>  1 -> 2 -> 4
示例2: 9 -> 9 -> 9  =>  1 -> 0 -> 0 -> 0  (进位到新节点)
```

---

## 解法概览

| 解法 | 思路 | 时间复杂度 | 空间复杂度 | 推荐度 |
|------|------|-----------|-----------|--------|
| ⭐ 找最右非9节点 | 定位进位停止点，直接修改 | O(n) | O(1) | 面试首选 |
| 反转链表 | 反转 -> 加1 -> 再反转 | O(n) | O(1) | 经典思路 |
| 递归 | 递归到尾部，回溯时处理进位 | O(n) | O(n) | 简洁但费栈 |

## 渐进提示

### 提示 1 -- 进位的传播规律

加一时进位在什么情况下会发生？会传播到哪里？

<details>
<summary>展开</summary>

```
1 2 3 + 1 = 1 2 4     // 末尾不是9，只改最后一位
1 2 9 + 1 = 1 3 0     // 末尾是9，进位到倒数第二位
1 9 9 + 1 = 2 0 0     // 连续的9，进位传播到第一个非9
9 9 9 + 1 = 1 0 0 0   // 全是9，需要新建头节点
```

**规律**：从右往左找到第一个不是9的节点，将其 +1，后面所有的9变成0。如果全是9，在头部插入新节点1。

</details>

### 提示 2 -- 找"最右非9节点"

<details>
<summary>展开</summary>

遍历链表，维护一个指针 `notNine` 指向**从左到右最后一个值不是9的节点**。

```
1 -> 2 -> 9 -> 9
          ^
          notNine 指向 2 (最右的非9)

操作: 
  notNine->val++ => 3
  notNine之后所有节点->val = 0

结果: 1 -> 3 -> 0 -> 0
```

**特殊情况**：如果所有节点都是9（`notNine` 从未更新），需要创建新头节点。

**技巧**：用一个哨兵节点（dummy）初始值为0，放在 head 之前。`notNine` 初始指向 dummy。如果全是9，dummy 会被 +1 变成1，且它就是新的 head。

</details>

### 提示 3 -- 哨兵节点的妙用

<details>
<summary>展开</summary>

```
dummy(0) -> 9 -> 9 -> 9

遍历完: notNine = dummy (因为 9 都不更新它)

操作:
  dummy->val++ => 1
  dummy 之后所有节点 -> 0

结果: dummy(1) -> 0 -> 0 -> 0
返回 dummy (因为 dummy->val != 0)

如果没有进位到 dummy:
  dummy(0) -> 1 -> 2 -> 4
  返回 dummy->next (跳过 dummy)
```

判断逻辑：`return dummy->val == 0 ? dummy->next : dummy;`

</details>

## 关键思维模式

### 1. "最右非9节点" 模式

单链表加法的核心：找到进位停止的位置。所有 +1 的进位链都是"连续9的前一个非9节点"。

### 2. 哨兵节点处理头部变化

当操作可能改变链表头时（如 999+1=1000），用 dummy 节点统一处理，避免特判。

### 3. 反转法 vs 就地法

反转链表法更通用（适用于加任意数），但"找最右非9"更高效且空间O(1)。

## 完整代码 (C++)

```cpp
// 解法1: 找最右非9节点
class Solution {
public:
    ListNode* plusOne(ListNode* head) {
        // 哨兵节点
        ListNode* dummy = new ListNode(0);
        dummy->next = head;

        // 找最右的非9节点
        ListNode* notNine = dummy;
        ListNode* curr = head;
        while (curr) {
            if (curr->val != 9) notNine = curr;
            curr = curr->next;
        }

        // notNine +1, 之后的所有节点置0
        notNine->val++;
        curr = notNine->next;
        while (curr) {
            curr->val = 0;
            curr = curr->next;
        }

        // 如果 dummy 被进位了(全是9的情况)
        return dummy->val != 0 ? dummy : dummy->next;
    }
};
```

## 算法图解

### 示例1: 1 -> 2 -> 9 -> 9

```
Step 1: 添加哨兵
  dummy(0) -> 1 -> 2 -> 9 -> 9
  notNine = dummy

Step 2: 遍历找最右非9
  curr=1 (!=9): notNine -> 1
  curr=2 (!=9): notNine -> 2
  curr=9 (==9): skip
  curr=9 (==9): skip
  最终 notNine 指向值为2的节点

Step 3: 操作
  notNine->val++ => 3
  后续节点: 9->0, 9->0

结果: dummy(0) -> 1 -> 3 -> 0 -> 0
返回 dummy->next = 1 -> 3 -> 0 -> 0 ✓
```

### 示例2: 9 -> 9 -> 9 (全是9)

```
Step 1: 添加哨兵
  dummy(0) -> 9 -> 9 -> 9
  notNine = dummy

Step 2: 遍历找最右非9
  所有节点都是9, notNine 保持指向 dummy

Step 3: 操作
  dummy->val++ => 1
  后续节点: 9->0, 9->0, 9->0

结果: dummy(1) -> 0 -> 0 -> 0
返回 dummy = 1 -> 0 -> 0 -> 0 ✓
```

## 常见错误

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| ✗ 不用 dummy，特判全9情况 | ✓ 用 dummy 统一处理 | 减少代码分支，更不易出错 |
| ✗ 找最左非9节点 | ✓ 找最右非9节点 | 进位从右传播，在最右非9处停止 |
| ✗ 只修改 notNine，忘记后续置0 | ✓ notNine 后面所有节点置0 | 连续9变为0是进位的必然结果 |
| ✗ 返回 head | ✓ 判断 dummy->val 决定返回谁 | 全9时需要返回 dummy 作为新头 |

## 面试追问

**Q1: 如果是加 k（不是加1）怎么办？**
> "最右非9"技巧只适用于加1。加任意 k 需要反转链表，逐位相加处理进位，再反转回来。或者用栈模拟。

**Q2: 如果要求不能修改原链表，返回新链表？**
> 可以先复制链表，再在副本上操作。或者用递归方式，在回溯时构建新节点。

**Q3: 递归解法怎么写？**
> 递归到尾部返回进位1，回溯时 `sum = node->val + carry`，`node->val = sum % 10`，向上返回 `sum / 10`。如果最终还有进位，创建新头节点。时间 O(n)，空间 O(n)（栈深度）。
