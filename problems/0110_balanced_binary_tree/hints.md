# 110. 平衡二叉树

## 核心思路

本题本质上在问：**对于树中的每一个节点，它的左子树高度和右子树高度之差是否都不超过 1？** 关键在于怎么高效地获取每个节点的高度信息。

## 思维链

1. **读完题第一反应**：平衡二叉树的定义是"每个节点的左右子树高度差不超过 1"。那我需要知道每个节点的左右子树高度。
2. **最朴素的做法**：写一个 `height()` 函数求任意节点高度，然后对每个节点调用 `height(left)` 和 `height(right)` 做比较，递归检查所有节点。
3. **暴力解的瓶颈在哪？** 对于根节点，我算了一遍整棵树的高度；然后递归检查左子树时，又重新算了左子树的高度……大量重复计算！一棵倾斜树上复杂度退化到 O(n²)。
4. **怎么突破？** 能不能在**一次遍历中同时完成两件事**：①算高度 ②判断是否平衡？——用自底向上的后序遍历，先递归到底层，算出子树高度后"顺便"检查平衡条件，一旦发现不平衡就提前返回 -1 作为标记。
5. **总结**：自底向上只需 O(n)，每个节点只访问一次，信息从叶子向根汇聚。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 自顶向下（暴力） | 每个节点单独算高度再比较 | O(n log n)~O(n²) | O(n) | 能说出即可 |
| 自底向上（最优） | 后序遍历，高度+平衡判断合一 | O(n) | O(n) | ⭐ 必须写出 |

## 解法详解

### 解法1: 自顶向下（暴力） — O(n²) / O(n)

**思考过程**：最直觉的翻译——定义说"每个节点的左右子树高度差 ≤ 1"，那我就对每个节点分别算左右子树高度，比较差值，然后递归检查左右子树也满足条件。

```cpp
class Solution {
public:
    // 求以 root 为根的树的高度
    int height(TreeNode* root) {
        if (!root) return 0;
        return 1 + max(height(root->left), height(root->right));
    }
    
    bool isBalanced(TreeNode* root) {
        if (!root) return true;
        
        // 当前节点：左右子树高度差 ≤ 1
        int leftH = height(root->left);
        int rightH = height(root->right);
        if (abs(leftH - rightH) > 1) return false;
        
        // 递归检查左右子树也都平衡
        return isBalanced(root->left) && isBalanced(root->right);
    }
};
```

**关键点**：
- 时间复杂度分析：对根节点调用 `height()` 遍历了所有 n 个节点；然后对左子树调用 `isBalanced()` 又会对左子树的所有节点再算一遍高度……
  - 平衡树：每层 O(n)，共 O(log n) 层 → O(n log n)
  - 倾斜树（最坏）：O(n) + O(n-1) + ... = O(n²)
- 空间 O(n)：递归栈深度，最坏倾斜树时为 n。

### 解法2: 自底向上（最优） — O(n) / O(n) ⭐ 面试首选

**从解法1优化**：解法1的瓶颈是重复计算高度——`isBalanced(root)` 算了一遍高度，`isBalanced(root->left)` 又重新算。能不能**算高度的同时就判断平衡性**？

**核心设计**：改造 `height()` 函数，让它承担双重职责：
- 如果子树平衡 → 返回真实高度（≥ 0）
- 如果子树不平衡 → 返回 -1（作为"不平衡"的标记）

这样后序遍历一次就够了：先递归算出左右子树高度，如果任一子树返回 -1 或者当前高度差 > 1，就返回 -1；否则返回当前高度。

```cpp
class Solution {
public:
    // 返回值含义：
    //   >= 0: 子树平衡，返回高度
    //   -1:   子树不平衡
    int checkHeight(TreeNode* root) {
        if (!root) return 0;
        
        // 后序遍历：先处理左右子树
        int leftH = checkHeight(root->left);
        if (leftH == -1) return -1;   // 左子树已不平衡，提前终止
        
        int rightH = checkHeight(root->right);
        if (rightH == -1) return -1;  // 右子树已不平衡，提前终止
        
        // 当前节点：判断左右高度差
        if (abs(leftH - rightH) > 1) return -1;
        
        // 平衡，返回当前子树高度
        return 1 + max(leftH, rightH);
    }
    
    bool isBalanced(TreeNode* root) {
        return checkHeight(root) != -1;
    }
};
```

**执行过程**（示例1 `[3,9,20,null,null,15,7]`）：
```
//         3
//        / \
//       9   20
//           / \
//          15   7
//
// 后序遍历过程（自底向上）:
// checkHeight(9)  → 左0,右0 → |0-0|=0 ≤ 1 → 返回 1
// checkHeight(15) → 左0,右0 → |0-0|=0 ≤ 1 → 返回 1
// checkHeight(7)  → 左0,右0 → |0-0|=0 ≤ 1 → 返回 1
// checkHeight(20) → 左1,右1 → |1-1|=0 ≤ 1 → 返回 2
// checkHeight(3)  → 左1,右2 → |1-2|=1 ≤ 1 → 返回 3
// 最终返回 3 ≠ -1 → true
```

**执行过程**（示例2 不平衡的树）：
```
//         1
//        / \
//       2   2
//      / \
//     3   3
//    / \
//   4   4
//
// checkHeight(4左) → 返回 1
// checkHeight(4右) → 返回 1
// checkHeight(3左) → 左1,右1 → 返回 2
// checkHeight(3右) → 返回 1
// checkHeight(2左) → 左2,右1 → |2-1|=1 → 返回 3
// checkHeight(2右) → 返回 1
// checkHeight(1)   → 左3,右1 → |3-1|=2 > 1 → 返回 -1 !!!
// 最终返回 -1 → false
```

## 解法对比

| | 解法1: 自顶向下 | 解法2: 自底向上 |
|---|---|---|
| 遍历方向 | 从根到叶，对每个节点重新算高度 | 从叶到根，高度信息一次算清 |
| 时间 | O(n log n)~O(n²) | O(n) |
| 空间 | O(n) 递归栈 | O(n) 递归栈 |
| 核心差异 | height() 和 isBalanced() 分离 | 合二为一，用 -1 标记不平衡 |
| 面试推荐 | 说思路即可 | 必须写出 |

## 易错点

1. **✗ `checkHeight` 中没有提前终止**：
   ```cpp
   int leftH = checkHeight(root->left);
   int rightH = checkHeight(root->right);  // 即使 leftH == -1 也继续算右子树
   ```
   → ✓ **应该在 leftH == -1 时立即 return -1**，避免无意义的递归（虽然不影响正确性，但面试官会追问效率）。

2. **✗ 搞混"平衡"的定义——只检查根节点**：
   ```cpp
   bool isBalanced(TreeNode* root) {
       return abs(height(root->left) - height(root->right)) <= 1;  // 只检查了根！
   }
   ```
   → ✓ **每个节点都要满足**条件，所以暴力解中还需递归检查 `isBalanced(left) && isBalanced(right)`。

3. **✗ 空树返回 false**：空树是平衡的！`if (!root) return true`。

4. **✗ height 的 base case 返回 -1**：有些人习惯空节点高度为 -1（节点高度 = 边数），但本题中 -1 被用作"不平衡"标记，会产生冲突。这里统一用空节点返回 0（高度 = 节点层数）。

## 面试追问

**Q1: 暴力解的时间复杂度为什么不是 O(n)？**
> 因为 `height()` 被重复调用。对根节点调用 `height()` 已经遍历了全树，但之后 `isBalanced(root->left)` 又会对左子树重新调用 `height()`。最坏情况（倾斜树）每个节点被 `height()` 访问的次数是 O(n)，总共 O(n²)。

**Q2: 能否不用递归，用迭代实现？**
> 可以。用后序遍历的迭代版本（双栈法或标记法），配合一个 `unordered_map<TreeNode*, int>` 记录每个节点的高度。后序遍历保证处理当前节点时左右子树的高度已经算好。但代码复杂度高，面试中递归版本已经足够。

**Q3: 如果要求返回"最大不平衡度"（所有节点中左右高度差的最大值），怎么改？**
> 在自底向上的框架中，不用 -1 提前终止，而是维护一个全局变量 `maxDiff`，每次 `maxDiff = max(maxDiff, abs(leftH - rightH))`，最后返回 `maxDiff`。
