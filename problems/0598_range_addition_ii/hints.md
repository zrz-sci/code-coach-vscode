# 598. 区间加法 II (Range Addition II)

## 核心思路
每次操作都对左上角子矩阵加 1，最大值一定出现在所有操作的交集区域，即所有 a_i 的最小值乘以所有 b_i 的最小值。

## 思维链
1. 每次操作 [a, b] 影响的是 [0,a) x [0,b) 的左上角矩阵
2. 被所有操作覆盖的区域一定是所有操作区域的交集
3. 交集 = [0, min(a_i)) x [0, min(b_i))
4. 交集区域中的元素值 = ops.size()（最大值）
5. 最大值的个数 = min(a_i) * min(b_i)
6. 特判：ops 为空时所有元素都是 0（最大值），返回 m * n

## 解法概览表

| 解法 | 思路 | 时间复杂度 | 空间复杂度 | 难度 |
|------|------|-----------|-----------|------|
| 求交集 ⭐ | 取所有操作的 min(a) 和 min(b) | O(k) | O(1) | Easy |
| 暴力模拟 | 真的加 1 再遍历 | O(m*n*k) | O(m*n) | Easy |

## 关键提示
1. **不需要真正操作矩阵**: 只需要找交集大小
2. **交集是矩形**: 因为所有操作都从 (0,0) 开始
3. **空操作**: ops 为空时返回 m * n

## 解法详解

### 解法一：求交集 ⭐
遍历所有操作，维护行列的最小值。
```
minRow = m, minCol = n
for each [a, b] in ops:
    minRow = min(minRow, a)
    minCol = min(minCol, b)
return minRow * minCol
```
**为什么正确**: 只有被所有操作覆盖的位置才是最大值，而所有操作都从 (0,0) 开始，交集就是最小的那个矩形。

### 解法二：暴力模拟
创建 m x n 矩阵，执行每次操作后找最大值及其个数。纯模拟，面试中不推荐。

## 易错点

| ✗ 错误写法 | ✓ 正确写法 | 原因 |
|-----------|-----------|------|
| 初始化 minRow=0, minCol=0 | minRow=m, minCol=n | ops 为空时应返回 m*n |
| 不处理 ops 为空 | 先判断 ops.empty() 或用 m/n 初始化 | 空数组时最大值是 0，每个元素都是 0 |
| 返回 minRow + minCol | 返回 minRow * minCol | 是面积，不是周长 |

## 面试追问

**Q1: 如果操作不是从 (0,0) 开始而是任意矩形 [x1,y1,x2,y2]，怎么求最大值个数？**
需要用差分数组或扫描线。二维差分数组 O(m*n + k)，或对操作区间做坐标压缩后扫描。

**Q2: 如果 ops 数量极大（10^9），但矩阵很小（100x100），怎么优化？**
直接在 100x100 矩阵上模拟即可，O(m*n*k) 中 m*n 很小；或者用本题方法 O(k) 只扫一遍 ops。

**Q3: 这道题和"区间加法"(LC 370)有什么关系？**
370 是一维差分数组问题。本题由于所有操作都从 (0,0) 开始，退化为求交集，不需要差分。
