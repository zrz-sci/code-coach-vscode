# 538. 把二叉搜索树转换为累加树

## 核心思路

BST 的中序遍历（左→根→右）是升序的，那么**反向中序遍历**（右→根→左）就是降序的。按降序访问节点，边访问边累加，就能让每个节点的新值 = 自身值 + 所有比它大的值之和。

## 思维链

1. **读完题第一反应**：对每个节点，找出树中所有比它大的节点值求和，再加上自身。暴力做法是对每个节点都遍历整棵树，O(n²)。
2. **暴力解的瓶颈**：每个节点都要"找所有比它大的值"，重复遍历太多。能不能一次遍历就搞定？
3. **关键观察 — BST 的性质**：BST 中序遍历是升序 `[0,1,2,3,4,5,6,7,8]`。如果我反过来遍历（右→根→左），就得到降序 `[8,7,6,5,4,3,2,1,0]`。
4. **突破点**：按降序遍历时，我已经访问过的节点全部 ≥ 当前节点。只要维护一个"累加和"变量，每访问一个节点就把它的值加到累加和里，再把累加和赋给当前节点，一次遍历即可完成！
5. **递归 vs 迭代**：递归写反向中序很简单（先递归右子树，处理当前，再递归左子树）。迭代用栈模拟同样的过程。还有一种 Morris 遍历可以做到 O(1) 空间。

## 解法概览

## 关键提示

1. **BST 中序遍历是升序的** — 这是几乎所有 BST 题的核心性质。本题需要"所有大于等于当前值的和"，那反过来遍历就天然从大到小。

2. **画出反向中序的遍历顺序**，理解为什么累加和就是答案：
```
原始 BST:
        4
       / \
      1   6
     / \ / \
    0  2 5  7
        \    \
         3    8

反向中序 (右→根→左): 8, 7, 6, 5, 4, 3, 2, 1, 0
累加和变化:           8, 15, 21, 26, 30, 33, 35, 36, 36
每个节点的新值就是访问到它时的累加和!
```

3. **递归中维护全局状态**：累加和 `sum` 需要在递归调用间共享，可以用成员变量或引用传参。

4. **迭代版**：和标准中序迭代几乎一样，只是把"一路向左"改成"一路向右"。

5. **Morris 遍历的关键**：标准 Morris 中序是找前驱（左子树最右），反向 Morris 中序是找后继（右子树最左）。

## 解法详解

### 解法1: 暴力（两次遍历） — O(n) / O(n)

**思考过程**：最直觉的想法——先用中序遍历拿到升序数组，然后从右往左求后缀和（每个位置的值 = 自身 + 右边所有值），最后再遍历一次把新值写回树中。

```cpp
class Solution {
public:
    TreeNode* convertBST(TreeNode* root) {
        // 第一步：中序遍历收集所有值（升序）
        vector<int> vals;
        inorder(root, vals);
        
        // 第二步：计算后缀和
        // vals = [0,1,2,3,4,5,6,7,8]
        // 后缀和从右往左累加: [36,36,35,33,30,26,21,15,8]
        for (int i = vals.size() - 2; i >= 0; i--) {
            vals[i] += vals[i + 1];
        }
        
        // 第三步：再次中序遍历，把后缀和写回
        int idx = 0;
        assign(root, vals, idx);
        return root;
    }
    
private:
    void inorder(TreeNode* node, vector<int>& vals) {
        if (!node) return;
        inorder(node->left, vals);
        vals.push_back(node->val);
        inorder(node->right, vals);
    }
    
    void assign(TreeNode* node, vector<int>& vals, int& idx) {
        if (!node) return;
        assign(node->left, vals, idx);
        node->val = vals[idx++];
        assign(node->right, vals, idx);
    }
};
```

**关键点**：需要三次遍历（收集、算后缀和、写回），虽然时间是 O(n) 但空间 O(n) 且代码较繁琐。这个思路的价值在于帮你理解"累加树的本质就是后缀和"。

---

### 解法2: 反向中序递归 — O(n) / O(h) ⭐ 面试首选

**从解法1优化**：解法1要三步，能不能一步搞定？关键洞察：如果我按**右→根→左**的顺序遍历 BST，访问到的值就是从大到小的。我维护一个累加变量 `sum`，每次访问节点时先把 `sum` 加上当前值，再把 `sum` 赋给当前节点——一次遍历搞定！

```
遍历过程:
节点:  8 → 7 → 6 → 5 → 4 → 3 → 2 → 1 → 0
sum:   8   15  21  26  30  33  35  36  36
新值:  8   15  21  26  30  33  35  36  36
```

```cpp
class Solution {
public:
    int sum = 0;
    
    TreeNode* convertBST(TreeNode* root) {
        if (!root) return nullptr;
        
        // 先递归右子树（处理所有比当前大的值）
        convertBST(root->right);
        
        // 处理当前节点：累加并更新
        sum += root->val;
        root->val = sum;
        
        // 再递归左子树（处理所有比当前小的值）
        convertBST(root->left);
        
        return root;
    }
};
```

**关键点**：
- 递归三要素：
  - **返回值**：返回当前节点（方便链式调用，其实不用也行）
  - **终止条件**：`root == nullptr`
  - **单层逻辑**：右 → 累加 → 左（反向中序）
- `sum` 必须是成员变量或引用传参，因为它在所有递归调用间共享

---

### 解法3: 反向中序迭代（栈） — O(n) / O(h)

**思路**：用栈模拟反向中序遍历。标准中序迭代是"一路向左入栈"，反向中序就是"一路向右入栈"。

```
标准中序迭代:          反向中序迭代:
一路向左入栈           一路向右入栈
弹出 → 处理           弹出 → 处理
转右子树               转左子树
```

```cpp
class Solution {
public:
    TreeNode* convertBST(TreeNode* root) {
        stack<TreeNode*> stk;
        TreeNode* curr = root;
        int sum = 0;
        
        while (curr || !stk.empty()) {
            // 一路向右，把右链全部入栈
            while (curr) {
                stk.push(curr);
                curr = curr->right;
            }
            
            // 弹出栈顶（当前最大的未处理节点）
            curr = stk.top();
            stk.pop();
            
            // 累加并更新
            sum += curr->val;
            curr->val = sum;
            
            // 转向左子树
            curr = curr->left;
        }
        
        return root;
    }
};
```

**关键点**：和标准中序迭代代码的区别只有两处——`right` 和 `left` 互换。

---

### 解法4: Morris 反向中序遍历 — O(n) / O(1) 加分项

**从解法3优化**：栈占 O(h) 空间，Morris 遍历通过临时修改树的结构（线索化）来消除栈，O(1) 空间。

**Morris 反向中序的核心**：对于当前节点，找到其右子树的最左节点（即中序后继中的前一个），建立临时线索指回当前节点。

```cpp
class Solution {
public:
    TreeNode* convertBST(TreeNode* root) {
        TreeNode* curr = root;
        int sum = 0;
        
        while (curr) {
            if (!curr->right) {
                // 没有右子树：直接处理当前节点，转左
                sum += curr->val;
                curr->val = sum;
                curr = curr->left;
            } else {
                // 有右子树：找右子树的最左节点（后继的前驱）
                TreeNode* succ = curr->right;
                while (succ->left && succ->left != curr) {
                    succ = succ->left;
                }
                
                if (!succ->left) {
                    // 建立线索：让后继的最左指回当前
                    succ->left = curr;
                    curr = curr->right;
                } else {
                    // 线索已存在：说明右子树已处理完
                    succ->left = nullptr; // 恢复树结构
                    sum += curr->val;
                    curr->val = sum;
                    curr = curr->left;
                }
            }
        }
        
        return root;
    }
};
```

**关键点**：Morris 遍历面试中很少要求写出，但说出"可以用 Morris 做到 O(1) 空间"会是加分项。

**关键区别**：解法1把"理解问题"和"解决问题"分开（先中序收集，再算后缀和），解法2合二为一（反向遍历时直接累加）。面试时写解法2，但用解法1的思路解释"为什么反向中序+累加就是答案"。

## 易错点

1. **累加变量忘了用成员变量/引用**
   - ✗ `void dfs(TreeNode* node, int sum)` — sum 是值传递，递归返回后修改丢失
   - ✓ `void dfs(TreeNode* node, int& sum)` 或用成员变量 `int sum = 0;`

2. **中序方向搞反了**
   - ✗ 写成 左→根→右（标准中序），那 sum 累加的是"比当前小的值"
   - ✓ 必须是 右→根→左（反向中序），确保先处理大的值

3. **迭代版中 while 循环的内层方向写错**
   - ✗ `while (curr) { stk.push(curr); curr = curr->left; }` — 这是标准中序
   - ✓ `while (curr) { stk.push(curr); curr = curr->right; }` — 反向中序

4. **Morris 遍历忘了恢复树结构**
   - ✗ 建立线索后没有 `succ->left = nullptr;` 恢复，导致树变成图
   - ✓ 第二次访问时一定要断开线索

## 面试追问

**Q1: 这道题的本质是什么？和中序遍历有什么关系？**
> BST 中序遍历是升序。"大于等于当前值的和"就是升序数组的后缀和。反向中序遍历（降序）+ 前缀累加 = 后缀和。

**Q2: 如果树非常深（极度不平衡），递归会有什么问题？怎么解决？**
> 递归深度等于树高 h，极端情况 h=n（链状树）会栈溢出。解决方案：用迭代（显式栈），或 Morris 遍历（O(1) 空间，完全不怕深度）。

**Q3: 如果不是 BST 而是普通二叉树，每个节点要变成"大于等于它的所有节点值之和"，怎么做？**
> BST 性质不再可用。方案：先遍历求总和 S，然后中序遍历（升序），维护前缀和 prefix，每个节点新值 = S - prefix + 当前值。或者排序后用哈希表映射。

**Q4: 本题和 1038 题是什么关系？**
