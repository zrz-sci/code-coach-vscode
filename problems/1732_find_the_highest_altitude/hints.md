# 1732. 找到最高海拔

## 核心思路

这道题本质上就是**前缀和**：`gain` 数组存的是相邻点的"差值"，而我们要还原出每个点的"绝对海拔"（即前缀和），然后找最大值。

## 思维链

1. **读完题第一反应**：`gain[i]` 是相邻两点的海拔差，起点海拔为 0。那每个点的海拔就是从起点开始，把之前所有的 `gain` 累加起来。
2. **具体怎么算**：`altitude[0] = 0`，`altitude[1] = gain[0]`，`altitude[2] = gain[0] + gain[1]`……这不就是前缀和吗？
3. **需要额外数组吗**：我们只需要最大值，不需要存所有海拔。一边累加一边更新最大值就行，连前缀和数组都不用开。
4. **别忘了起点**：起点海拔是 0，它也是一个候选最大值（示例 2 的答案就是 0）。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 构建海拔数组 | 先算出完整海拔数组，再取 max | O(n) | O(n) | 能说出即可 |
| 滚动变量（前缀和优化） | 一边累加一边取 max，不存数组 | O(n) | O(1) | ⭐ 必须写出 |

## 关键提示

1. `gain` 是"差分数组"，海拔是它的"前缀和"。认识到这个关系，题目就解完了。
2. 起点海拔为 0，它也参与比较。如果所有 `gain` 都是负数，答案就是 0（示例 2）。
3. 不需要真正开一个数组存所有海拔，用一个变量滚动累加即可。

```
gain:     [-5,  1,  5,  0, -7]

altitude:  0   -5  -4   1   1  -6
           ↑                      
         起点=0                   

前缀和过程:
  cur = 0          → max = 0
  cur = 0+(-5)=-5  → max = 0
  cur = -5+1=-4    → max = 0
  cur = -4+5=1     → max = 1  ← 更新！
  cur = 1+0=1      → max = 1
  cur = 1+(-7)=-6  → max = 1
```

## 解法详解

### 解法1: 构建海拔数组 — O(n) / O(n)

**思考过程**：最直觉的做法——题目描述的就是前缀和，那我们先把所有海拔算出来存进数组，再遍历找最大值。

```cpp
class Solution {
public:
    int largestAltitude(vector<int>& gain) {
        int n = gain.size();
        vector<int> altitude(n + 1, 0);  // n+1 个点，起点海拔为 0
        for (int i = 0; i < n; i++) {
            altitude[i + 1] = altitude[i] + gain[i];  // 前缀和
        }
        return *max_element(altitude.begin(), altitude.end());
    }
};
```

**关键点**：数组大小是 `n+1` 不是 `n`，因为有 `n+1` 个点。

---

### 解法2: 滚动变量（前缀和空间优化） — O(n) / O(1) ⭐ 面试首选

**从解法1优化**：解法1开了一个数组，但我们只需要最大值，不需要记住所有海拔。用一个变量 `cur` 滚动累加，同时维护 `maxAlt` 即可。

```cpp
class Solution {
public:
    int largestAltitude(vector<int>& gain) {
        int cur = 0;       // 当前海拔，起点为 0
        int maxAlt = 0;    // 最高海拔，初始化为起点海拔 0
        for (int g : gain) {
            cur += g;                      // 累加得到当前点海拔
            maxAlt = max(maxAlt, cur);     // 更新最大值
        }
        return maxAlt;
    }
};
```

**关键点**：`maxAlt` 初始化为 0（起点海拔），而不是 `INT_MIN`。因为起点海拔 0 本身就是一个候选答案。

## 解法对比

| | 解法1（构建数组） | 解法2（滚动变量） |
|---|---|---|
| 时间 | O(n) | O(n) |
| 空间 | O(n) | O(1) |
| 代码量 | 略多 | 极简 |
| 适用场景 | 需要多次查询某个点的海拔 | 只需要最大值（本题） |

两种解法时间复杂度相同，但解法2省去了额外数组，是标准的**前缀和空间优化**套路。面试中直接写解法2即可。

## 易错点

1. **`maxAlt` 初始化错误**：
   - ✗ `int maxAlt = INT_MIN;` → 如果所有 gain 都是负数，会漏掉起点海拔 0 这个候选答案
   - ✓ `int maxAlt = 0;` → 起点海拔为 0，它本身就参与比较
   - 示例 2 中答案就是起点的 0

2. **混淆点数和边数**：
   - ✗ 以为有 n 个点 → 实际有 `n+1` 个点（解法1中数组大小）
   - gain 数组长度为 n，代表 n 条边，连接 n+1 个点

## 面试追问

**Q1: 这道题的数学本质是什么？**
→ `gain` 是差分数组，海拔是它的前缀和。求最高海拔就是求前缀和的最大值。

**Q2: 如果要求最低海拔呢？需要改哪里？**
→ 只需把 `max` 改成 `min`，`maxAlt` 改成 `minAlt`，初始值仍为 0。

**Q3: 如果起点海拔不是 0，而是任意值 `startAlt`，怎么改？**
→ `cur` 和 `maxAlt` 都初始化为 `startAlt` 即可，其余逻辑不变。

**Q4: 如果 gain 数组很长（10^9），但需要多次查询区间 [l, r] 内的最高海拔？**
→ 先计算前缀和数组，再用**稀疏表(Sparse Table)**或**线段树**支持 O(1) / O(log n) 的区间最值查询。
