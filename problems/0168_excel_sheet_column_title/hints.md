# 168. Excel 表列名称

## 核心思路

这道题本质上是**将十进制数转换为二十六进制数**，但有一个关键陷阱：普通的 26 进制是 0-25，而 Excel 列名是 1-26（没有 0），所以每次取余前需要先减 1。

## 思维链

1. **读完题第一反应**：这不就是进制转换吗？像把十进制转二进制一样，不断对 26 取余得到每一位。
2. **试一下普通 26 进制**：columnNumber=26 时，`26 % 26 = 0`，对应的字符应该是 `Z`，但 0 映射不到任何字母。columnNumber=27 时，`27 % 26 = 1` → `A`，`27 / 26 = 1` → `A`，得到 `AA`，看起来对？但 26 那个 case 就崩了。
3. **发现关键区别**：普通 26 进制的数字是 `0~25`，Excel 列名的数字是 `1~26`。没有 0 的存在！这意味着它是一种"偏移 1 的 26 进制"。
4. **怎么修正？** 每次取余前，先做 `columnNumber -= 1`，把范围从 `1~26` 映射到 `0~25`。这样 `余数 0` 对应 `A`，`余数 25` 对应 `Z`，完美！
5. **最后别忘了反转**：和所有进制转换一样，先得到的是低位字符，最后需要反转字符串。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 迭代取余 | 每次减1后对26取余，反转 | O(log₂₆n) | O(1) | ⭐ 必须写出 |
| 递归 | 递归处理 (n-1)/26，再拼接当前字符 | O(log₂₆n) | O(log₂₆n) | 能说出即可 |

## 关键提示

1. **和普通 26 进制的区别**：普通进制有 `0`，Excel 列名没有 `0`（A=1, 不是 A=0）。想想 `26` 应该映射为 `Z` 而不是 `A0`。
2. **关键操作 `columnNumber -= 1`**：在每次取余**之前**减 1，而不是只在最开始减一次。每一"位"都需要这个调整。
3. **反转字符串**：进制转换中先计算出的是最低位（最右边的字符），最后需要反转。
4. **验证边界**：用 `26`（→Z）、`27`（→AA）、`52`（→AZ）、`701`（→ZY）手动验证你的逻辑。

```
// 手动推演 columnNumber = 701 → "ZY"
// 
// 第1轮: 701 - 1 = 700, 700 % 26 = 24 → 'Y',  700 / 26 = 26
// 第2轮: 26 - 1 = 25,   25 % 26 = 25  → 'Z',   25 / 26 = 0
// 收集到: "YZ" → 反转 → "ZY" ✓
//
// 对比普通26进制（不减1）的错误结果:
// 第1轮: 701 % 26 = 25 → 'Z'(?), 701 / 26 = 26
// 第2轮: 26 % 26 = 0 → ???  没有字母对应0!
```

## 解法详解

### 解法1: 迭代取余 — O(log₂₆n) / O(1) ⭐ 面试首选

**思考过程**：进制转换的标准做法是不断取余+整除。关键区别在于 Excel 列名是 1-indexed 的 26 进制（没有 0），所以每轮循环开始前先 `columnNumber -= 1`，将当前位的范围从 `1~26` 调整到 `0~25`。

```cpp
class Solution {
public:
    string convertToTitle(int columnNumber) {
        string result;
        while (columnNumber > 0) {
            columnNumber--;  // 关键：从1-indexed调整为0-indexed
            result += ('A' + columnNumber % 26);  // 取最低位
            columnNumber /= 26;                    // 去掉最低位
        }
        reverse(result.begin(), result.end());  // 先得到的是低位，需要反转
        return result;
    }
};
```

**关键点**：`columnNumber--` 必须在 `% 26` **之前**执行，且每轮循环都要做，不是只做一次。

### 解法2: 递归 — O(log₂₆n) / O(log₂₆n)

**思考过程**：将问题分解——最后一个字符由 `(n-1) % 26` 决定，前面的部分由 `(n-1) / 26` 递归处理。和迭代本质一样，只是用递归自然得到正序结果，不需要反转。

```cpp
class Solution {
public:
    string convertToTitle(int columnNumber) {
        if (columnNumber == 0) return "";
        columnNumber--;  // 同样的调整
        // 递归处理高位 + 当前字符
        return convertToTitle(columnNumber / 26) + char('A' + columnNumber % 26);
    }
};
```

**关键点**：递归出口是 `columnNumber == 0`（不是 1），因为减 1 后整除可能变为 0。

## 解法对比

| | 迭代取余 | 递归 |
|---|---|---|
| 代码长度 | 稍长（需要反转） | 更简洁 |
| 空间 | O(1)（不算结果） | O(log₂₆n) 递归栈 |
| 可读性 | 直观 | 更优雅 |
| 面试推荐 | ⭐ 首选 | 能说出即可 |

两种方法本质完全相同，都是"减1 → 取余 → 整除"的循环。面试中推荐迭代，因为不用担心栈溢出（虽然 log₂₆(2³¹) ≈ 7 层，不会溢出）。

## 易错点

1. **✗ 忘记每轮都减 1**：
   ```cpp
   // 错误：只在循环外减了一次
   columnNumber--;
   while (columnNumber > 0) {
       result += ('A' + columnNumber % 26);
       columnNumber /= 26;  // 下一轮没有减1！
   }
   ```
   → **✓ 正确：每轮循环内部开头减 1**，因为每一位都是 1-indexed 的。

2. **✗ 用 `columnNumber >= 1` 的循环条件配合先取余后减1**：
   ```cpp
   // 错误：先取余再减
   result += ('A' + columnNumber % 26);  // 26 % 26 = 0 → 'A'? 应该是'Z'!
   columnNumber--;
   ```
   → **✓ 先减后取余**：`columnNumber--; result += ('A' + columnNumber % 26);`

3. **✗ 忘记反转结果（迭代版）**：
   ```
   701 → 先算出 'Y' 再算出 'Z' → "YZ"（未反转）
   ```
   → **✓ 最后 `reverse(result.begin(), result.end())`** 得到 `"ZY"`。

## 面试追问

**Q1: 为什么不能直接对 26 取余，必须先减 1？**
→ 因为 Excel 列名是 1-26 的编码（没有 0），而标准进制是 0-25。当 `columnNumber=26` 时，`26%26=0` 无法映射到字母。减 1 后 `25%26=25` 正确映射到 'Z'。

**Q2: 这道题的逆问题（列名 → 数字）怎么做？**
→ 即 LeetCode 171，从左到右遍历字符串，`result = result * 26 + (ch - 'A' + 1)`。注意这里是 `+1` 因为 A=1 不是 A=0。

**Q3: 如果 Excel 的列名改为从 A=0 开始（A=0, B=1, ..., Z=25, BA=26, BB=27），代码怎么改？**
→ 去掉 `columnNumber--` 即可，变成标准 26 进制转换。但注意此时 0 要输出 "A"，需要特殊处理。
