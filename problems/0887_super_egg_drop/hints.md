# 887. 鸡蛋掉落 (Super Egg Drop)

## 核心思路

经典的 **DP 换视角** 难题。直接定义 `dp(k,n)` = "k 个蛋 n 层楼的最少操作数" 虽然直观，但因为需要枚举在哪一层扔蛋，时间复杂度高达 O(k*n^2)，会 TLE。

**关键转换**：不问"k 个蛋 n 层楼需要多少次"，而是问"t 次操作、k 个蛋，最多能确定多少层楼？" 定义 `dp[t][k]` 为 t 次机会、k 个蛋最多能覆盖的楼层数。然后找最小的 t 使得 `dp[t][k] >= n`。

这个视角转换将"min-max"问题变成了简洁的递推，是本题最精妙之处。

## 思维链

1. **读完题第一反应**：这是一个经典的决策优化问题。有 k 个蛋、n 层楼，每次选一层扔蛋，蛋碎了往下找（蛋数-1），没碎往上找。要在最坏情况下最小化操作次数。

2. **朴素 DP 定义**：设 `f(k, n)` = k 个蛋、n 层楼的最少操作数。在第 x 层扔蛋：
   - 碎了：还需要 `f(k-1, x-1)` 次检查下面 x-1 层
   - 没碎：还需要 `f(k, n-x)` 次检查上面 n-x 层
   - 最坏情况：`max(f(k-1, x-1), f(k, n-x))`
   - 最优选择：`f(k, n) = min over x { 1 + max(f(k-1, x-1), f(k, n-x)) }`
   
3. **为什么朴素 DP 太慢？** 状态 O(k*n)，每个状态枚举 x 需要 O(n)，总共 O(k*n^2)。k 可达 100，n 可达 10000，约 10^9 会超时。虽然可以用二分搜索优化枚举到 O(k*n*logn)，但还有更优雅的方法。

4. **换视角：从"最少次数"到"最多楼层"**：
   - 设 `dp[t][k]` = 有 t 次机会、k 个蛋时，最多能确定的楼层数
   - 在某层扔蛋：
     - 碎了 → 往下找，剩 t-1 次、k-1 个蛋，能确定 `dp[t-1][k-1]` 层
     - 没碎 → 往上找，剩 t-1 次、k 个蛋，能确定 `dp[t-1][k]` 层
     - 当前层本身算 1 层
   - 递推：`dp[t][k] = dp[t-1][k-1] + dp[t-1][k] + 1`

5. **答案怎么找？** 从 t=1 开始逐步增加，直到 `dp[t][k] >= n`，此时的 t 就是答案。

6. **这个递推为什么正确？** 因为每扔一次蛋，无论碎不碎，我们都能"排除"一些楼层。碎了排除上面的可能性（但消耗一个蛋），没碎排除下面的可能性。所以 t 次机会、k 个蛋能探索的总楼层 = 碎的分支能探索的 + 没碎的分支能探索的 + 当前层。

## 逆向 DP 表

```
dp[t][k] = t 次操作, k 个蛋能确定的最多楼层数
递推: dp[t][k] = dp[t-1][k-1] + dp[t-1][k] + 1

             k=1    k=2    k=3    k=4
  t=0         0      0      0      0     (0次操作什么也确定不了)
  t=1         1      1      1      1     (1次只能确定1层)
  t=2         2      3      3      3     
  t=3         3      6      7      7
  t=4         4     10     14     15
  t=5         5     15     25     30
  t=6         6     21     41     56
  ...

计算过程详解 (以 k=2 为例):
  dp[1][2] = dp[0][1] + dp[0][2] + 1 = 0 + 0 + 1 = 1
  dp[2][2] = dp[1][1] + dp[1][2] + 1 = 1 + 1 + 1 = 3
  dp[3][2] = dp[2][1] + dp[2][2] + 1 = 2 + 3 + 1 = 6
  dp[4][2] = dp[3][1] + dp[3][2] + 1 = 3 + 6 + 1 = 10

验证示例:
  k=2, n=6: dp[3][2]=6 >= 6, 答案为 3 ✓
  k=3, n=14: dp[4][3]=14 >= 14, 答案为 4 ✓
  k=1, n=2: dp[2][1]=2 >= 2, 答案为 2 ✓

当 k=1 (只有1个蛋): dp[t][1] = t (只能从底层逐层往上试)
当 k>=t 时: dp[t][k] = 2^t - 1 (蛋足够多，等同于二分搜索)
```

```
填表方向示意图:

  dp[t][k] 依赖 dp[t-1][k-1] 和 dp[t-1][k]
  
       k-1    k
  t-1  [A]   [B]     A = dp[t-1][k-1] (碎了的分支)
                      B = dp[t-1][k]   (没碎的分支)
  t          [C]     C = A + B + 1
  
  填表顺序: t 从小到大逐行填，因为第 t 行只依赖第 t-1 行
  可以用滚动数组优化空间为 O(k)
```

## 关键提示

1. **视角转换是核心**：从"k个蛋n层楼的最少操作"转为"t次操作k个蛋的最多楼层"。面试时如果你直接说出这个转换，面试官会非常impressed。

2. **递推公式的直觉**：每次扔蛋就像做一个"实验"。实验结果有两种：碎或不碎。碎了你用剩下的资源探索下面，不碎你探索上面。所以总的可探索范围 = 下面 + 上面 + 当前 = `dp[t-1][k-1] + dp[t-1][k] + 1`。

3. **t 的上界**：最坏情况 t 不会超过 n（1个蛋从底层试到顶层）。实际上当 k>=2 时，t 增长很快（指数级），所以 t 通常很小。

4. **k=1 的特殊情况**：只有1个蛋，只能从1楼开始逐层往上扔，需要 n 次。这是递推的基本情况。

5. **数学联系**：`dp[t][k]` 实际上等于组合数之和 `C(t,1) + C(t,2) + ... + C(t,k)`。这可以用组合数学证明。

6. **空间优化**：因为 `dp[t]` 只依赖 `dp[t-1]`，可以用一维滚动数组。注意：需要从右往左更新（或使用 temp 数组），因为 `dp[t][k]` 需要 `dp[t-1][k]`（同一列的上一行）。

## 解法详解

### 解法1: 朴素 DP + 二分优化 -- O(kn logn) / O(kn)

**思考过程**：最直观的 DP 定义。`f(k, n)` = k 个蛋、n 层楼的最少操作数。枚举在第 x 层扔蛋：

```
f(k, n) = min over x=1..n { 1 + max(f(k-1, x-1), f(k, n-x)) }

关键观察：固定 k 和 n，当 x 增大时:
  f(k-1, x-1) 单调递增（下面楼层变多）
  f(k, n-x)   单调递减（上面楼层变少）
  
两条曲线一增一减，max 取较大者，最优的 x 在交叉点附近。
→ 可以用二分搜索找到最优的 x，将枚举从 O(n) 优化到 O(logn)。
```

```cpp
class Solution {
public:
    int superEggDrop(int k, int n) {
        // memo[k][n] = 最少操作次数
        vector<vector<int>> memo(k + 1, vector<int>(n + 1, -1));
        return dp(k, n, memo);
    }
    
private:
    int dp(int k, int n, vector<vector<int>>& memo) {
        if (n <= 0) return 0;
        if (k == 1) return n;  // 1个蛋只能逐层试
        if (memo[k][n] != -1) return memo[k][n];
        
        // 二分搜索最优的扔蛋层 x
        int lo = 1, hi = n, ans = n;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            int breakCase = dp(k - 1, mid - 1, memo);  // 碎了
            int noBreak = dp(k, n - mid, memo);         // 没碎
            
            if (breakCase < noBreak) {
                lo = mid + 1;
            } else {
                hi = mid - 1;
            }
            ans = min(ans, 1 + max(breakCase, noBreak));
        }
        
        return memo[k][n] = ans;
    }
};
```

**这个解法能通过，但不是最优的。** 时间 O(kn logn)。更优的做法是换视角。

### 解法2: 逆向 DP -- O(kn) / O(kn) ⭐ 面试首选

**视角转换**：不问"最少几次"，而问"t 次最多覆盖几层"。

**状态定义**：`dp[t][k]` = 有 t 次机会、k 个蛋时，能确定的最多楼层数。

**递推公式**：`dp[t][k] = dp[t-1][k-1] + dp[t-1][k] + 1`

```
直觉解释：你有 t 次机会、k 个蛋，在某层扔蛋：

  如果碎了 → 你还有 t-1 次、k-1 个蛋
    → 能往下确定 dp[t-1][k-1] 层

  如果没碎 → 你还有 t-1 次、k 个蛋
    → 能往上确定 dp[t-1][k] 层

  加上你当前扔的这一层 → 总共能确定:
    dp[t-1][k-1] + 1 + dp[t-1][k] 层
```

**答案**：找最小的 t 使得 `dp[t][k] >= n`。

```cpp
class Solution {
public:
    int superEggDrop(int k, int n) {
        // dp[t][j] = t 次操作、j 个蛋能确定的最多楼层
        vector<vector<int>> dp(n + 1, vector<int>(k + 1, 0));
        
        int t = 0;
        while (dp[t][k] < n) {
            t++;
            for (int j = 1; j <= k; j++) {
                dp[t][j] = dp[t-1][j-1] + dp[t-1][j] + 1;
            }
        }
        return t;
    }
};
```

**复杂度**：时间 O(t * k)，其中 t = O(n)（最坏情况 k=1 时 t=n），所以最坏 O(nk)。实际上 k>=2 时 t 增长很快，远小于 n。空间 O(nk)。

### 解法3: 逆向 DP 空间优化 -- O(kn) / O(k)

**优化思路**：dp[t] 只依赖 dp[t-1]，所以可以只保留一维数组。但要注意更新顺序：`dp[j] = dp_old[j-1] + dp_old[j] + 1`，需要用 dp_old 的值。所以要**从右往左**更新，或者用临时变量保存。

```cpp
class Solution {
public:
    int superEggDrop(int k, int n) {
        // dp[j] = 当前 t 次操作、j 个蛋能确定的最多楼层
        vector<int> dp(k + 1, 0);
        
        int t = 0;
        while (dp[k] < n) {
            t++;
            // 从右往左更新，防止覆盖需要的旧值
            for (int j = k; j >= 1; j--) {
                dp[j] = dp[j - 1] + dp[j] + 1;
                //      ^^^^^^^^     ^^^^
                //      碎(旧t-1)   没碎(旧t-1) + 当前层
            }
        }
        return t;
    }
};
```

**为什么从右往左？** 更新 `dp[j]` 时需要 `dp[j-1]` 的旧值（即 t-1 时的值）。如果从左往右更新，`dp[j-1]` 已经被覆盖为 t 时的新值了。从右往左更新时，`dp[j-1]` 还没被更新，保存的还是旧值。

### 解法4: 数学解（组合数） -- O(k logn) / O(1)

**数学观察**：`dp[t][k]` 其实等于组合数之和：
```
dp[t][k] = C(t,1) + C(t,2) + ... + C(t,k)
```

可以通过数学归纳法证明。这意味着我们不需要 DP 表，只要找最小的 t 使得组合数之和 >= n。

由于组合数之和关于 t 单调递增，可以二分搜索 t。

```cpp
class Solution {
public:
    int superEggDrop(int k, int n) {
        // 二分搜索最小的 t 使得 f(t,k) >= n
        int lo = 1, hi = n;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (computeFloors(mid, k) >= n) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }
    
private:
    // 计算 C(t,1) + C(t,2) + ... + C(t,k)
    long long computeFloors(int t, int k) {
        long long sum = 0;
        long long comb = 1;  // C(t, i)
        for (int i = 1; i <= k && i <= t; i++) {
            comb = comb * (t - i + 1) / i;
            sum += comb;
            if (sum >= 1e9) return sum;  // 防溢出，提前返回
        }
        return sum;
    }
};
```

## 深入理解：为什么换视角是必要的？

```
朴素视角:
  f(k, n) = min over x { 1 + max(f(k-1, x-1), f(k, n-x)) }
  
  问题：有 min 又有 max，还要枚举 x，三层嵌套
  状态空间 O(kn)，每个状态 O(n) 或 O(logn) 枚举
  
逆向视角:
  dp[t][k] = dp[t-1][k-1] + dp[t-1][k] + 1
  
  没有 min，没有 max，没有枚举，纯粹的递推
  状态空间 O(tk)，每个状态 O(1) 转移
  
关键洞察：把"约束"和"目标"互换
  朴素：约束=k个蛋n层楼, 目标=最小化操作数
  逆向：约束=t次操作k个蛋, 目标=最大化可确定楼层
```

## 易错点总结

1. **直接用朴素 DP 不优化**：O(kn^2) 一定超时。必须用二分优化或换视角。

2. **空间优化时更新方向错误**：滚动数组必须从右往左更新，否则会用到已被覆盖的新值。

3. **t 的循环没有正确终止**：while 循环条件是 `dp[t][k] < n`，不是 `<= n`。

4. **整数溢出**：组合数解法中，C(t,k) 可能很大，需要用 long long 或提前截断。

## 面试追问

**Q1: 朴素DP为什么可以用二分优化？**
> `breakCase = f(k-1, x-1)` 单调递增，`noBreakCase = f(k, n-x)` 单调递减，`max(两者)` 在交叉处取最小值，经典"凸函数找极值"可用二分。

**Q2: 逆向DP的递推和 Pascal 三角形有什么关系？能否用组合数直接计算？**
> `dp[t][k] = C(t,1)+C(t,2)+...+C(t,k)`，由 Pascal 恒等式 `C(t-1,i-1)+C(t-1,i)=C(t,i)` 可证。对 t 单调递增，可二分求解。

**Q3: 如果蛋有不同强度，还能用这个框架吗？**
> 不能。本题假设所有蛋强度相同（同一临界楼层 f），才有对称递推。若蛋强度不同，需要建模为信息论中的自适应搜索问题。
