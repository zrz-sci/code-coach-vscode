# 785. Is Graph Bipartite?

## 核心思路

二分图判定的经典方法是**二染色法**：尝试用两种颜色给图中所有节点染色，使得每条边的两个端点颜色不同。如果能成功染色则是二分图，否则不是。实现上可以用 BFS 或 DFS 遍历图并染色，也可以用并查集判断。注意图可能不连通，需要对每个连通分量都进行检查。

## 思维链

1. **二分图定义**：节点可以分为两组 A 和 B，使得每条边连接 A 中的节点和 B 中的节点。
2. **等价条件**：图是二分图 <=> 图中不存在奇数长度的环 <=> 图可以二染色。
3. **染色策略**：选择一个未染色节点，染色 0，其邻居染色 1，邻居的邻居染色 0...
4. **冲突检测**：如果某个邻居已经染了相同的颜色，说明存在奇环，不是二分图。
5. **多连通分量**：图不一定连通，需要对每个未染色的节点启动一次 BFS/DFS。
6. **并查集方法**：把每个节点的所有邻居放入同一集合，若节点和邻居在同一集合中则非二分图。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| BFS 染色法 | O(V + E) | O(V) | 最直观，层序遍历染色 |
| DFS 染色法 | O(V + E) | O(V) | 递归实现，代码简洁 |
| 并查集 | O(V + E * alpha(V)) | O(V) | 不需要显式染色 |

## 关键提示

1. 用数组 color[i] 存储每个节点的颜色：-1 表示未染色，0 和 1 表示两种颜色。
2. BFS: 起点染 0，从队列取出节点后，将所有未染色邻居染上相反颜色；若邻居已染相同颜色则返回 false。
3. DFS: 对当前节点染色后，递归处理所有邻居。若邻居未染色则染相反色并递归，若已染同色则返回 false。
4. 不要忘记处理**不连通的图**：主函数需要遍历所有节点，对每个未染色节点启动 BFS/DFS。
5. 并查集思路：对于节点 u，将 graph[u] 中的所有邻居 union 到一起。如果 u 和某个邻居属于同一集合，则非二分图。
6. 空图或没有边的图是二分图。

## 解法详解

### 解法一：BFS 染色法（推荐）

**详细步骤**：
1. 初始化 color 数组为 -1（未染色）。
2. 遍历所有节点 i：如果 color[i] == -1（未访问），从 i 开始 BFS。
3. 将 i 染色为 0，放入队列。
4. 从队列取出节点 u，遍历 u 的所有邻居 v：
   - 若 v 未染色：染 1-color[u]，入队。
   - 若 v 已染色且 color[v] == color[u]：返回 false。
5. 所有节点处理完毕后返回 true。

### 解法二：DFS 染色法

**详细步骤**：
1. 对每个未染色的节点调用 `dfs(node, color)`。
2. 在 DFS 中，先给当前节点染指定颜色。
3. 对每个邻居检查：未染色则递归（相反颜色），已染色则检查是否冲突。
4. 任何冲突返回 false。

### 解法三：并查集

**详细步骤**：
1. 初始化 parent 数组，每个节点为自身的父节点。
2. 对每个节点 u，遍历其邻居列表 graph[u]：
   - 将所有邻居 union 到同一组（union(graph[u][0], graph[u][j])）。
   - 检查 find(u) == find(graph[u][j])，若相等则返回 false。
3. 所有检查通过后返回 true。

**为什么正确**：二分图中，一个节点的所有邻居应该在同一侧（与该节点不同侧）。如果某个邻居和节点在同一集合中，说明它们在同一侧，违反了二分图性质。

## 易错点

1. **忘记处理不连通图**：只从节点 0 开始遍历是不够的，必须遍历所有未访问节点。一个连通分量是二分图不代表另一个也是。
2. **染色数组初始化**：不能初始化为 0，因为 0 是一种合法颜色。应该用 -1 或其他标记表示未访问。
3. **并查集中 union 的对象**：应该是"邻居和邻居" union 到一起（同一侧），而不是"节点和邻居"。
4. **自环的处理**：题目说明不存在自环，但如果存在自环，自环的节点一定不是二分图。
5. **BFS 中重复入队**：已经染色的节点不应该再入队，否则会导致效率下降和潜在错误。

## 面试追问

1. **Q: 二分图和奇环有什么关系？**
   A: 图是二分图 <=> 图中不存在奇数长度的环。证明：若存在奇环，环上的节点无法二染色；若无奇环，BFS/DFS 的染色过程一定不会冲突。

2. **Q: 如何输出二分图的两个分组？**
   A: 在染色过程中，color[i]=0 的节点为 A 组，color[i]=1 的节点为 B 组。

3. **Q: 时间复杂度中的 E 指什么？题目中如何计算？**
   A: E 是边数。在邻接表表示中，E = sum(graph[u].length) / 2，因为每条无向边被表示两次。

4. **Q: 如果图在动态变化（添加/删除边），如何高效维护二分图判定？**
   A: 使用扩展并查集（带权并查集），维护节点间的"奇偶距离"关系。添加边时检查两端点是否在同一组，时间接近 O(1)。

5. **Q: 二分图检测在实际中有什么应用？**
   A: 资源分配（如学生-课程匹配）、社交网络分析（好友/敌人关系）、图着色问题、编译器中的寄存器分配等。

6. **Q: 有向图的二分图判定和无向图有什么区别？**
   A: 有向图的二分图判定忽略方向，按无向图处理即可。若要求"有向二分图"（每条有向边从 A 到 B），则需要额外检查方向一致性。
