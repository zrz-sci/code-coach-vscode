# 770. 基本计算器 IV (Basic Calculator IV)

**难度**: Hard | **标签**: Stack, Recursion, Hash Table, Math, String

## 核心思路

本题要求对一个含有变量和常数的数学表达式进行符号化简。核心思想是将每个表达式元素（变量或常数）表示为**多项式**（Polynomial），然后通过递归解析表达式，对多项式执行加法、减法、乘法运算，最终输出化简后的标准格式。

关键抽象：用 `map<vector<string>, int>` 表示多项式，其中 key 是变量名的排序列表（代表一个项的变量因子），value 是该项的系数。常数项的 key 为空向量 `{}`。

## 思维链

1. **问题分析**: 这是一道表达式解析 + 多项式运算的综合题。需要处理括号、运算符优先级、变量替换。
2. **表示设计**: 将表达式中的每个 token 抽象为一个多项式对象，支持 +、-、* 操作。
3. **解析策略**: 使用递归下降解析器（或栈方法）处理运算符优先级：括号 > 乘法 > 加减法。
4. **变量替换**: 在解析之初，将已知变量用对应常数值替换。
5. **结果格式化**: 按照 degree 降序、字典序输出非零系数的项。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|-----------|-----------|---------|
| 递归下降解析 + 多项式运算 | O(2^n * n) | O(2^n * n) | 标准解法，最清晰 |
| 栈模拟 + 多项式运算 | O(2^n * n) | O(2^n * n) | 替代方案 |

> n 是变量个数，最坏情况下多项式项数可能为指数级。

## 关键提示

1. **多项式表示**: 每一项用变量名排序后的 vector<string> 作为 key，int 作为系数。常数项 key 为空 vector。
2. **乘法实现**: 两个多项式相乘，就是分别将所有项配对相乘——变量名列表合并排序，系数相乘。
3. **运算符优先级**: 先处理括号内表达式，然后乘法优先于加减法。
4. **变量替换时机**: 在 tokenize 阶段就将已知变量替换为整数值。
5. **输出排序规则**: 先按 degree 降序，degree 相同按变量名字典序升序。
6. **零系数清理**: 运算过程中和输出时都要过滤掉系数为 0 的项。

## 解法详解

### 解法一：递归下降解析 + 多项式运算

**思路**: 
- 定义 Poly 类型为 `map<vector<string>, int>`，表示多项式。
- 实现 `add(p1, p2)`, `sub(p1, p2)`, `mul(p1, p2)` 三个多项式运算。
- 使用递归下降解析器处理表达式：
  - `parseExpr()`: 处理加法和减法（最低优先级）。
  - `parseTerm()`: 处理乘法（较高优先级）。
  - `parseFactor()`: 处理括号和基本元素（最高优先级）。

**详细步骤**:
1. 将 expression 按空格 tokenize。
2. 将 evalvars 中的变量在 token 阶段替换为对应的整数值。
3. 递归下降解析：
   - 遇到 `(` 时递归解析括号内表达式。
   - 遇到数字则创建常数多项式 `{[] -> num}`。
   - 遇到变量则创建单变量多项式 `{[var] -> 1}`。
4. 收集结果多项式所有非零项，排序后格式化输出。

**复杂度**: 
- 时间: O(2^n * n)，n 为自由变量数量。多项式项数在最坏情况下为指数级。
- 空间: O(2^n * n)，存储多项式各项。

### 解法二：栈方法

**思路**:
- 使用两个栈：一个操作数栈（存放多项式），一个运算符栈。
- 遇到运算符时按优先级弹栈计算。
- 遇到 `(` 入栈，遇到 `)` 计算到上一个 `(`。
- 最终操作数栈中只剩一个多项式即为结果。

这种方法与递归下降本质相同，只是用显式栈代替了递归调用栈。

## 易错点

1. **乘法合并变量列表时必须重新排序**: `["a"] * ["b"]` 应得到 `["a","b"]`，但 `["b"] * ["a"]` 也应得到 `["a","b"]`，否则同类项无法合并。
2. **系数为 0 的项不输出**: 运算过程中可能出现抵消，必须在最终输出前过滤。
3. **系数为 1 仍需输出**: 题目要求 `1*e*e` 而不是 `e*e`，前导系数 1 不可省略。
4. **负数系数格式**: `-2*a*a` 中的负号是系数的一部分，不需要额外加括号。
5. **变量替换后的连锁反应**: 替换后 `e * e` 变成 `1 * 1 = 1`，但若 e 未被替换，结果应为 `1*e*e`。
6. **空表达式结果**: 当所有项系数为 0 时返回空数组 `[]`。
7. **多字母变量**: 变量名可能是 `temperature` 这样的多字母单词，不要假设只有单字母。

## 面试追问

1. **Q: 如何扩展支持除法运算？**
   A: 除法涉及有理函数（分子/分母都是多项式），需引入有理多项式类型，复杂度大幅增加。可以将除法限定为常数除法来简化。

2. **Q: 如果变量值是浮点数怎么办？**
   A: 将系数类型从 int 改为 double，注意浮点精度问题，可能需要设定 epsilon 判断零值。

3. **Q: 这种多项式表示的局限是什么？**
   A: 项数在最坏情况下指数级增长（2^n），不适合大量变量的场景。可考虑稀疏表示优化。

4. **Q: 如何验证化简结果的正确性？**
   A: 随机给各变量赋值，分别计算原始表达式和化简结果，验证数值一致。

5. **Q: 递归下降解析器相比正式的 parser generator 有何优劣？**
   A: 递归下降简单直观，适合简单文法；但不支持左递归，复杂文法需要改写。对本题足够。
