# 611. 有效三角形的个数

## 核心思路

三角形条件：任意两边之和大于第三边。排序后只需检查**最小两边之和 > 最大边**（另外两个条件自动满足）。然后用**排序 + 双指针**在 O(n^2) 内统计所有有效三元组。

## 思维链

1. **读完题第一反应** → 暴力枚举三元组，检查三角形条件。O(n^3) 三层循环。
2. **三角形条件能简化吗？** → 如果数组已排序（a <= b <= c），那么 a+c > b 和 b+c > a 自动成立（因为 c >= b >= a >= 0），只需检查 **a + b > c**。排序 O(n log n) 是值得的。
3. **怎么高效枚举？** → 固定最大边 c = nums[k]，然后在 [0, k-1] 中找满足 nums[i] + nums[j] > nums[k] 的 (i, j) 对数。
4. **双指针怎么用？** → 设 i=0, j=k-1。如果 nums[i]+nums[j] > nums[k]，那么 i 从 i 到 j-1 的所有值都满足（因为 nums[j] 够大），贡献 j-i 个，然后 j--。否则 i++ 增大较小边。
5. **时间复杂度** → 外层 O(n) 固定 k，内层双指针 O(n)，总 O(n^2)。比暴力 O(n^3) 好很多。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力 | 三层循环枚举 | O(n^3) | O(1) | 能说出即可 |
| 排序+二分 | 固定两边，二分找第三边 | O(n^2 log n) | O(1) | 中等 |
| 排序+双指针 | 固定最大边，双指针计数 | O(n^2) | O(1) | ⭐ 最优 |

## 关键提示

1. **只需检查一个条件**：排序后 a <= b <= c，a+c > b 和 b+c > a 自动成立（非负数），只需 a+b > c。这是排序的核心价值。
2. **双指针计数的关键**：当 nums[i]+nums[j] > nums[k] 时，i 到 j-1 的所有左端点都满足，一次性加 `j - i` 个，而不是逐个枚举。
3. **固定谁？** 固定最大边 nums[k]（从右往左），然后在 [0, k-1] 中找两个较小边。这样双指针是"对向指针"，操作最自然。
4. **注意 0 值**：数组可能包含 0，0 不能作为三角形的边。但不需要特殊处理——0 + 任何数 = 那个数 <= 最大边，不会满足 a+b > c。
5. **与 LC 15 (3Sum) 的对比**：同为排序+双指针处理三元组。区别：3Sum 找和为 0，本题找和大于第三边；3Sum 要去重，本题不需要（题目统计的是"选法数"而非"不同组合"）。

## 解法详解

### 解法1: 暴力枚举 — O(n^3)

**思考过程**: 枚举所有三元组，检查三角形三个条件。

```cpp
class Solution {
public:
    int triangleNumber(vector<int>& nums) {
        int n = nums.size(), count = 0;
        for (int i = 0; i < n; i++)
            for (int j = i + 1; j < n; j++)
                for (int k = j + 1; k < n; k++)
                    if (nums[i] + nums[j] > nums[k] &&
                        nums[i] + nums[k] > nums[j] &&
                        nums[j] + nums[k] > nums[i])
                        count++;
        return count;
    }
};
```

**关键点**: O(n^3) 太慢（n=1000 时约 10^9 次操作）。需要优化。

---

### 解法2: 排序 + 二分查找 — O(n^2 log n)

**从暴力优化**: 排序后固定两个较小边 a=nums[i], b=nums[j]，用二分查找在 (j, n-1] 中找最大的 c 使得 a+b > c。

```cpp
class Solution {
public:
    int triangleNumber(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        int n = nums.size(), count = 0;
        
        for (int i = 0; i < n - 2; i++) {
            for (int j = i + 1; j < n - 1; j++) {
                // 找最大的 k 使得 nums[i]+nums[j] > nums[k]
                int sum = nums[i] + nums[j];
                // lower_bound 找到第一个 >= sum 的位置
                int k = lower_bound(nums.begin() + j + 1, nums.end(), sum) 
                        - nums.begin();
                // [j+1, k-1] 都满足条件
                count += k - j - 1;
            }
        }
        
        return count;
    }
};
```

**关键点**: 排序后只需检查 a+b > c。二分查找的目标是找 `nums[k] >= sum` 的第一个位置，那么有效范围是 [j+1, k-1]。

---

### 解法3: 排序 + 双指针 — O(n^2) ⭐ 面试首选

**核心洞察**: 固定最大边 c = nums[k]，然后用双指针在 [0, k-1] 中找满足 a + b > c 的 (a, b) 对数。

```
// 示例: nums = [2,2,3,4] (已排序)
//
// k=3 (c=4): i=0, j=2
//   nums[0]+nums[2] = 2+3 = 5 > 4 ✓ → 贡献 j-i = 2-0 = 2 个 (即 [0,2] 和 [1,2])
//   j=1: nums[0]+nums[1] = 2+2 = 4 > 4? ✗ → i++
//   i=1 >= j=1 → 停
//
// k=2 (c=3): i=0, j=1
//   nums[0]+nums[1] = 2+2 = 4 > 3 ✓ → 贡献 j-i = 1-0 = 1 个 (即 [0,1])
//   j=0: i=0 >= j=0 → 停
//
// 总计: 2 + 1 = 3
```

```cpp
class Solution {
public:
    int triangleNumber(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        int n = nums.size();
        int count = 0;
        
        // 固定最大边 nums[k]，从右往左枚举
        for (int k = n - 1; k >= 2; k--) {
            int i = 0, j = k - 1;
            while (i < j) {
                if (nums[i] + nums[j] > nums[k]) {
                    // nums[i..j-1] + nums[j] 都 > nums[k]
                    // 因为 nums[i] 是最小的，只要它满足，
                    // i+1, i+2, ..., j-1 更大的数当然也满足
                    count += j - i;
                    j--;
                } else {
                    // 两边之和不够大，增大较小边
                    i++;
                }
            }
        }
        
        return count;
    }
};
```

**关键点**:
- 排序后 nums[i] <= nums[j] <= nums[k]，只需检查 nums[i] + nums[j] > nums[k]。
- 当条件满足时，i 到 j-1 的所有左端点都满足，一次加 `j-i` 个。
- 双指针每轮最多移动 O(k) 步，总时间 O(n^2)。

## 解法对比

| | 暴力 | 排序+二分 | 排序+双指针 |
|---|---|---|---|
| 时间 | O(n^3) | O(n^2 log n) | O(n^2) |
| 空间 | O(1) | O(1) | O(1) |
| 排序 | 不需要 | 需要 | 需要 |
| 面试推荐 | 起步 | 中等 | ⭐ 首选 |

## 易错点

1. **忘记排序就使用双指针**
   - ✗ 不排序直接双指针 → 无法利用单调性，双指针逻辑不成立
   - ✓ 必须先 `sort(nums.begin(), nums.end())`

2. **三角形条件检查不完整**
   - ✗ 未排序时只检查 a+b > c → 漏了 a+c > b 和 b+c > a
   - ✓ 排序后只检查 a+b > c 是正确的（其他两个自动满足）

3. **双指针计数时 count += 1 而非 count += j-i**
   - ✗ `count++` → 只计了一个有效组合，漏掉了 [i, j-1] 的所有有效组合
   - ✓ `count += j - i` → 一次性计入所有有效组合

4. **固定最小边还是最大边搞混**
   - ✗ 固定最小边 nums[i]，在 [i+1, n-1] 中双指针 → 不好统计"一次多少个"
   - ✓ 固定最大边 nums[k]，在 [0, k-1] 中双指针 → 满足条件时一次加 j-i 个

5. **数组包含 0 导致错误**
   - 实际上不需要特殊处理：0 + 任何非负数 = 那个数 <= 最大边，不会满足 a+b > c

## 面试追问

**Q1: 为什么固定最大边而不是最小边？**
→ 固定最大边 c 后，条件变为 a+b > c，这是对 a+b 的下界约束。双指针从两端向中间收缩时，a+b 从大到小递减，可以一次性统计满足条件的个数（j-i 个）。如果固定最小边，条件变为 b+c > a（总是成立）和 a+b > c，双指针方向不好统一。

**Q2: 时间复杂度能否优于 O(n^2)？**
→ 不太可能。这个问题在最坏情况下可能有 O(n^2) 甚至 O(n^3) 个有效三元组需要被统计，O(n^2) 已经是最优了。

**Q3: 如果要求输出所有有效三元组（不只是数量）？**
→ 在 count += j-i 的地方，改为循环输出 (nums[i'], nums[j], nums[k]) 其中 i' 从 i 到 j-1。注意此时输出本身可能是 O(n^3) 的。

**Q4: 与 3Sum 问题的对比？**
→ 结构相似：排序 + 固定一个 + 双指针。区别：3Sum 找和为 0，本题找和大于第三边；3Sum 需要去重（跳过重复组合），本题统计选法不需要去重。
