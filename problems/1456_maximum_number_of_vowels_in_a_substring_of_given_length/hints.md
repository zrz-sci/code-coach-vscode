# 1456. 定长子串中元音的最大数目

## 核心思路

**定长滑动窗口**：维护一个长度恰好为 k 的窗口，追踪窗口内元音字母的数量。窗口每次右移一步时，只需 O(1) 更新：检查新进入的字符和滑出的字符是否是元音。

## 思维链

1. **读完题第一反应** -- 枚举所有长度为 k 的子串，对每个子串统计元音数量，取最大值。这就是暴力解：O(n) 个子串，每个子串统计元音需要 O(k)，总共 O(n * k)。

2. **暴力解的瓶颈在哪？** -- 对每个子串都重新统计元音数量。实际上相邻两个窗口只差了一个字符：左边滑出一个、右边滑入一个。大部分字符是重复统计的。

3. **关键观察** -- 窗口从 `s[i..i+k-1]` 滑动到 `s[i+1..i+k]` 时：
   - 减去：`s[i]` 滑出窗口（如果是元音，计数 -1）
   - 加上：`s[i+k]` 滑入窗口（如果是元音，计数 +1）
   - 更新只需 O(1)！

4. **这就是定长滑动窗口** -- 窗口大小固定为 k，只需维护窗口内的元音计数。每次滑动更新 O(1)，总时间 O(n)。

5. **提前终止优化** -- 如果某个窗口的元音数已经等于 k（全是元音），可以直接返回 k，不需要继续滑动。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力枚举 | 每个子串重新统计 | O(n*k) | O(1) | 能说出即可 |
| 定长滑动窗口 | 增量式更新元音计数 | O(n) | O(1) | 必须写出 |

## 关键提示

1. **元音字母**：a, e, i, o, u（题目保证只有小写字母，不用考虑大写）。

2. **定长 vs 变长滑动窗口**：本题窗口大小固定为 k，属于定长窗口。不需要 while 循环收缩，只需在 `i >= k` 时减去滑出字符即可。变长窗口（如 LC 3）才需要 while 收缩。

3. **窗口满了才开始滑出**：当 `i >= k` 时，窗口左端的字符 `s[i-k]` 需要滑出。前 k 个字符只进不出，在构建初始窗口。

4. **提前终止**：如果 `cnt == k`，所有字符都是元音，不可能更大了，直接返回。

5. **窗口滑动过程图**（s = "abciiidef", k = 3）：

## 解法详解

### 解法1: 暴力枚举 -- O(n*k) / O(1)

**思考过程**：最直觉的做法 -- 枚举每个长度为 k 的子串，对每个子串从头统计元音数量。

```cpp
class Solution {
public:
    int maxVowels(string s, int k) {
        int n = s.size(), ans = 0;
        for (int i = 0; i <= n - k; i++) {
            int cnt = 0;
            for (int j = i; j < i + k; j++) {
                char c = s[j];
                if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') {
                    cnt++;
                }
            }
            ans = max(ans, cnt);
        }
        return ans;
    }
};
```

**瓶颈**：当 n = 10^5, k = 50000 时，O(n*k) 约 5*10^9，超时。而且大量重复计算：相邻两个窗口共享 k-1 个字符，却都重新统计了。

---

### 解法2: 定长滑动窗口 -- O(n) / O(1)（推荐）

**从暴力优化**：相邻窗口只差一个字符。维护一个元音计数 cnt，窗口右移时：
- 如果新加入的字符是元音：cnt++
- 如果滑出的字符是元音：cnt--
- 更新 ans = max(ans, cnt)

```
滑动窗口过程 (s = "leetcode", k = 3):

索引:  0  1  2  3  4  5  6  7
字符:  l  e  e  t  c  o  d  e
元音:  N  Y  Y  N  N  Y  N  Y

i=0: +l(N), cnt=0       窗口:[l]
i=1: +e(Y), cnt=1       窗口:[l e]
i=2: +e(Y), cnt=2       窗口:[l e e]      ans=2
i=3: -l(N), +t(N)       窗口:[e e t]      ans=2
i=4: -e(Y), +c(N) cnt=1 窗口:[e t c]      ans=2
i=5: -e(Y), +o(Y) cnt=1 窗口:[t c o]      ans=2
i=6: -t(N), +d(N) cnt=1 窗口:[c o d]      ans=2
i=7: -c(N), +e(Y) cnt=2 窗口:[o d e]      ans=2

答案: 2  ("lee", "eet", "ode" 都包含 2 个元音)
```

```cpp
class Solution {
public:
    int maxVowels(string s, int k) {
        auto isVowel = [](char c) {
            return c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u';
        };
        int cnt = 0, ans = 0;
        for (int i = 0; i < (int)s.size(); i++) {
            // 右端字符滑入窗口
            if (isVowel(s[i])) cnt++;
            // 窗口满了后，左端字符滑出（i >= k 时窗口已满）
            if (i >= k && isVowel(s[i - k])) cnt--;
            // 更新答案
            ans = max(ans, cnt);
        }
        return ans;
    }
};
```

**为什么是 O(n)**：只有一层 for 循环，每个字符恰好被访问两次（一次加入、一次滑出），总操作 2n。

**为什么空间 O(1)**：只用了两个整数 cnt 和 ans，不需要额外数据结构。

### 写法变体：显式双指针

上面的写法用单个指针 i 隐式管理窗口左端（i-k）。也可以显式使用左右指针：

```cpp
class Solution {
public:
    int maxVowels(string s, int k) {
        auto isVowel = [](char c) {
            return c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u';
        };
        // 初始化：计算第一个窗口 [0, k-1] 的元音数
        int cnt = 0;
        for (int i = 0; i < k; i++) {
            if (isVowel(s[i])) cnt++;
        }
        int ans = cnt;
        // 滑动：左端 left 滑出，右端 right 滑入
        for (int right = k; right < (int)s.size(); right++) {
            int left = right - k;
            if (isVowel(s[right])) cnt++;
            if (isVowel(s[left])) cnt--;
            ans = max(ans, cnt);
        }
        return ans;
    }
};
```

## 解法对比

| | 暴力枚举 | 定长滑动窗口 |
|---|---|---|
| 时间 | O(n*k) | O(n) |
| 空间 | O(1) | O(1) |
| 核心操作 | 每个窗口重新统计 | 增量更新 (+1/-1) |
| n=10^5, k=5*10^4 | TLE (~5*10^9) | 轻松通过 (~10^5) |

## 易错点

1. **窗口左端索引算错**：
   - 正确：当 `i >= k` 时，滑出 `s[i - k]`
   - 易错：写成 `s[i - k + 1]` 或 `s[i - k - 1]`
   - 验证：当 i=k 时，窗口 [1, k]，滑出 s[0] = s[i-k]

2. **忘记判断滑出字符是否是元音**：
   - 正确：`if (i >= k && isVowel(s[i - k])) cnt--;`
   - 易错：`if (i >= k) cnt--;`（不管是不是元音都减，导致 cnt 错误）

3. **元音判断遗漏**：
   - 正确：a, e, i, o, u 五个
   - 易错：漏掉 'u' 或多加了 'y'

4. **提前终止写错位置**：
   - 提前终止应在更新 ans 之后：`if (ans == k) return k;`
   - 这是可选优化，不写也不影响正确性

## 面试追问

**Q1: 这道题为什么是"定长"滑动窗口而不是"变长"？**
因为窗口大小始终固定为 k。定长窗口不需要 while 循环收缩，只在 `i >= k` 时减去一个字符。变长窗口（如 LC 3 最长无重复子串）窗口大小不固定，需要 while 循环找到合适的左边界。

**Q2: 暴力 O(nk) 能过吗？**
n 和 k 都可达 10^5，最坏情况 O(10^10)，完全不能过。这道题的核心就是用滑动窗口把 O(k) 的更新优化到 O(1)。

**Q3: 如果元音字符集很大（不止 5 个），如何优化 isVowel 判断？**
可以用 set/unordered_set 预存元音字符，查询 O(1)。或者用 bool 数组 `isVowel[128]`，下标为字符 ASCII 值。对于只有 5 个元音的情况，直接 if 判断最简洁。

**Q4: 如果要返回元音最多的子串本身（而非数量），怎么改？**
在更新 ans 时同时记录 bestLeft = i - k + 1。最后返回 `s.substr(bestLeft, k)`。
