# 767. 重构字符串

## 核心思路
本质上是一个**贪心调度问题**：每次都优先安排剩余数量最多的字符，同时避免和前一个字符相同。能否成功重排取决于一个简单的判断——**出现次数最多的字符是否超过了 ⌈n/2⌉**。

## 思维链

1. **读完题第一反应**：需要重新排列字符使得相邻不重复。什么时候一定不可能？→ 某个字符出现太多次，比如 "aaab" 中 'a' 出现 3 次，总长 4，放不下。
2. **判断可行性**：如果字符串长度为 n，某个字符出现次数 > ⌈n/2⌉ = (n+1)/2，那无论怎么摆都会有相邻重复 → 直接返回 ""。
3. **暴力想法**：全排列然后检查？n! 种排列，n=500 完全不可行。需要构造性的方法。
4. **贪心直觉**：每次挑**剩余最多**的字符来放，这样才不会让某个字符"积压"到最后无处可放。但如果最多的字符恰好和上一个相同怎么办？→ 放**第二多**的字符。
5. **用什么维护"最多"**？→ **最大堆（优先队列）**，每次取出频率最高的两个字符各放一个，然后把更新后的频率放回堆。
6. **另一种思路**：不用堆，直接**按频率排序后间隔放置** — 先填偶数位(0,2,4,...)再填奇数位(1,3,5,...)，从频率最高的字符开始填。这是 O(n) 的方法。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 最大堆贪心 | 每次取频率最高的两个字符交替放 | O(n log 26) ≈ O(n) | O(26) ≈ O(1) | ⭐ 必须写出 |
| 排序+间隔填充 | 按频率排序后先填偶数位再填奇数位 | O(n) | O(26) ≈ O(1) | 加分项 |
| 计数+间隔填充(无排序) | 直接找最大频率字符优先填充 | O(n) | O(26) ≈ O(1) | 加分项 |

## 关键提示

1. **不可能的判断条件**：某字符频率 > (n+1)/2 时一定无解。想想为什么是 (n+1)/2 而不是 n/2？
   - 提示：当 n=5 时，"aXaXa" 中 'a' 可以出现 3 次 = (5+1)/2 = 3，刚好可行。
2. **堆贪心的关键**：每轮要取出**两个**字符（频率最高和第二高），各放一个，再放回去。如果每次只取一个，无法避免连续相同。
3. **间隔填充的关键**：把频率最高的字符优先放到偶数索引位置 (0, 2, 4, ...)。偶数位填满后换奇数位 (1, 3, 5, ...)。这样天然保证相邻不同。
4. **为什么间隔填充一定对**？因为同一个字符被分散到了间隔位置，只要它的频率不超过 ⌈n/2⌉，它就不会溢出到相邻位。
5. 字符集固定为 26 个小写字母，所以所有涉及字符集大小的操作都是常数级。

## 解法详解

### 解法1: 最大堆贪心 — O(n log 26) / O(26) ⭐ 面试首选

**思考过程**：

我们需要每次决定"下一个放什么字符"。贪心策略是：**优先放剩余次数最多的字符**，这样能最大化地消耗高频字符，避免它们积压到后面无处可放。

但有个问题：如果上一个放的就是最多的那个字符怎么办？此时我们放**第二多**的。

这自然需要一个能快速获取"频率最大"和"频率第二大"的数据结构 → **最大堆**。

每一轮：
- 取出堆顶（频率最大）和第二个（频率第二大）
- 各放一个字符到结果中
- 频率减 1 后放回堆

```
// 示例: s = "aab"
// 初始堆: {a:2, b:1}
// 
// Round 1: 取出 a(2), b(1) → 结果 "ab" → 放回 a(1)
// Round 2: 堆中只剩 a(1) → 结果 "aba"
// 最终: "aba" ✓
```

```cpp
class Solution {
public:
    string reorganizeString(string s) {
        // 第一步：统计频率
        vector<int> freq(26, 0);
        for (char c : s) freq[c - 'a']++;
        
        // 判断可行性：任何字符频率 > (n+1)/2 则不可能
        int n = s.size();
        for (int i = 0; i < 26; i++) {
            if (freq[i] > (n + 1) / 2) return "";
        }
        
        // 第二步：建最大堆 (频率, 字符)
        priority_queue<pair<int,char>> pq;
        for (int i = 0; i < 26; i++) {
            if (freq[i] > 0) {
                pq.push({freq[i], 'a' + i});
            }
        }
        
        // 第三步：每轮取两个，各放一个
        string result;
        while (pq.size() >= 2) {
            auto [freq1, ch1] = pq.top(); pq.pop();
            auto [freq2, ch2] = pq.top(); pq.pop();
            
            result += ch1;
            result += ch2;
            
            // 频率减1后放回（只有频率>0才放）
            if (freq1 - 1 > 0) pq.push({freq1 - 1, ch1});
            if (freq2 - 1 > 0) pq.push({freq2 - 1, ch2});
        }
        
        // 如果堆里还剩一个字符（n为奇数时发生）
        if (!pq.empty()) {
            result += pq.top().second;
        }
        
        return result;
    }
};
```

**关键点**：
- 每轮必须取**两个**字符，不是一个。如果每次只取一个，你需要额外记录"上一个放了什么"来避免重复，逻辑更复杂。
- 堆中最后可能剩一个字符（当 n 为奇数时），直接追加到末尾。由于我们已经验证了可行性，这个字符一定不会和前一个相同。

### 解法2: 排序+间隔填充 — O(n) / O(26)

**从解法1优化**：堆的 log 因子虽然是 log26 ≈ 5 可以忽略，但间隔填充的思路更简洁，且不需要堆这个数据结构。

**核心观察**：如果我们把字符按频率从高到低排序，然后先填所有偶数位 (0, 2, 4, ...)，填满后再填奇数位 (1, 3, 5, ...)，那么**同一个字符一定不会相邻**。

```
// 示例: s = "aaabbc"  (n=6)
// 频率: a:3, b:2, c:1
// 按频率排序: a(3), b(2), c(1)
// 
// 结果数组: _ _ _ _ _ _  (索引 0-5)
// 
// 填 a(3): 先填偶数位
//   idx=0: a _ _ _ _ _
//   idx=2: a _ a _ _ _
//   idx=4: a _ a _ a _
// 
// 填 b(2): 偶数位已满(idx=6>=n), 转奇数位 idx=1
//   idx=1: a b a _ a _
//   idx=3: a b a b a _
// 
// 填 c(1):
//   idx=5: a b a b a c
// 
// 结果: "ababac" ✓ — 相邻字符都不同！
```

**为什么间隔填充保证正确？**

关键在于：同一个字符被放在间隔为 2 的位置上（如 0,2,4 或 1,3,5），所以同一个字符之间至少隔了一个位置，永远不会相邻。

那不同字符之间会不会相邻相同呢？不会，因为每个位置只放了一个字符。

唯一的风险是：偶数位填完后切换到奇数位时，最后一个偶数位和第一个奇数位（索引相差1）是否会填上同一个字符？只要频率最高的字符不超过 ⌈n/2⌉，它在偶数位就能放完，不会溢出到奇数位，所以不会发生冲突。

```cpp
class Solution {
public:
    string reorganizeString(string s) {
        int n = s.size();
        vector<int> freq(26, 0);
        int maxFreq = 0, maxChar = 0;
        
        for (char c : s) {
            freq[c - 'a']++;
            if (freq[c - 'a'] > maxFreq) {
                maxFreq = freq[c - 'a'];
                maxChar = c - 'a';
            }
        }
        
        // 可行性检查
        if (maxFreq > (n + 1) / 2) return "";
        
        // 按频率排序字符（频率高的先填）
        // 用 (频率, 字符) 对排序
        vector<pair<int,int>> charFreq;
        for (int i = 0; i < 26; i++) {
            if (freq[i] > 0) {
                charFreq.push_back({freq[i], i});
            }
        }
        // 按频率降序排列
        sort(charFreq.begin(), charFreq.end(), greater<>());
        
        // 间隔填充
        string result(n, ' ');
        int idx = 0;  // 从偶数位开始填
        
        for (auto& [f, ch] : charFreq) {
            for (int i = 0; i < f; i++) {
                result[idx] = 'a' + ch;
                idx += 2;
                // 偶数位填完后切换到奇数位
                if (idx >= n) idx = 1;
            }
        }
        
        return result;
    }
};
```

**关键点**：
- `idx` 从 0 开始每次 +2，超出范围后跳到 1（开始填奇数位）。
- 频率最高的字符**必须最先填**，确保它占据偶数位（这是最安全的位置）。

### 解法3: 计数+间隔填充(不排序) — O(n) / O(26)

**进一步简化**：其实不需要完整排序。我们只需要保证**频率最高的字符先填偶数位**，其余字符按任意顺序填即可。

```cpp
class Solution {
public:
    string reorganizeString(string s) {
        int n = s.size();
        vector<int> freq(26, 0);
        int maxFreq = 0, maxIdx = 0;
        
        for (char c : s) {
            freq[c - 'a']++;
            if (freq[c - 'a'] > maxFreq) {
                maxFreq = freq[c - 'a'];
                maxIdx = c - 'a';
            }
        }
        
        if (maxFreq > (n + 1) / 2) return "";
        
        string result(n, ' ');
        int idx = 0;
        
        // 第一步：先把频率最高的字符填到偶数位
        while (freq[maxIdx] > 0) {
            result[idx] = 'a' + maxIdx;
            idx += 2;
            freq[maxIdx]--;
        }
        
        // 第二步：其余字符按任意顺序继续间隔填充
        for (int i = 0; i < 26; i++) {
            while (freq[i] > 0) {
                if (idx >= n) idx = 1;  // 偶数位填完转奇数位
                result[idx] = 'a' + i;
                idx += 2;
                freq[i]--;
            }
        }
        
        return result;
    }
};
```

## 解法对比

| | 最大堆贪心 | 排序+间隔填充 | 计数+间隔填充 |
|---|---|---|---|
| 时间 | O(n log 26) ≈ O(n) | O(n + 26 log 26) ≈ O(n) | O(n) |
| 空间 | O(26) | O(26) | O(26) |
| 代码量 | 中等 | 中等 | 最少 |
| 思路直觉 | 最自然（贪心调度） | 需要想到间隔填充 | 间隔填充的简化版 |
| 面试推荐 | ⭐ 首选（好讲好写） | 加分 | 加分 |

**什么时候选哪个？**
- **面试首选堆贪心**：思路最自然，"优先安排最多的"很好解释，面试官容易认可。
- **间隔填充**作为 follow-up 或追问时给出，展示你对问题的更深理解。

## 易错点

1. **可行性判断用错公式**：
   - ✗ `if (maxFreq > n / 2)` — 当 n=5, maxFreq=3 时错误返回不可行（实际可行："aXaXa"）
   - ✓ `if (maxFreq > (n + 1) / 2)` — 正确的上界是向上取整

2. **堆贪心每轮只取一个字符**：
   - ✗ 取一个放一个，然后需要复杂的 prev 记录 → 容易写错
   - ✓ 每轮取两个，各放一个 → 天然避免连续相同

3. **间隔填充忘记切换到奇数位**：
   - ✗ `idx += 2` 但没有 `if (idx >= n) idx = 1` → 数组越界
   - ✓ 偶数位填满后必须切换起点为 1

4. **间隔填充没有把最大频率字符先填**：
   - ✗ 按字母顺序 a,b,c,... 依次填 → 可能导致高频字符溢出到相邻位
   - ✓ 必须先填频率最高的字符到偶数位

5. **堆中剩余一个字符忘记处理**：
   - ✗ while 循环结束后直接 return → n 为奇数时结果少一个字符
   - ✓ 循环结束后检查堆是否还有元素

## 面试追问

**Q1: 什么时候一定无解？怎么快速判断？**
> 统计频率，如果最大频率 > ⌈n/2⌉ 则无解。因为偶数位最多放 ⌈n/2⌉ 个字符（位置 0,2,4,...），一个字符超过这个数就必然相邻。

**Q2: 堆贪心法中，为什么每轮取两个而不是一个？**
> 取一个时，下一轮的堆顶可能还是同一个字符（因为它频率最高），就需要额外维护"上一个放了谁"的状态。取两个则天然保证这一轮放的两个字符不同，下一轮也不会和本轮冲突（因为两个都被消耗了一次）。

**Q3: 间隔填充法为什么必须把频率最高的字符优先填到偶数位？**
> 偶数位有 ⌈n/2⌉ 个槽位，奇数位有 ⌊n/2⌋ 个。频率最高的字符可能达到 ⌈n/2⌉，只有偶数位能容纳它。如果不优先填最高频字符，它可能跨越偶数位和奇数位的分界，在那个转折点产生相邻相同。

**Q4: 如果题目改成"任意相邻 k 个字符都不能相同"（k 不一定是 2），怎么改？**
> 这是 [358. Rearrange String k Distance Apart] 的变体。堆贪心法改为每轮取 k 个字符各放一个，用冷却队列（等待队列）来记录暂时不能用的字符。判断可行性变为：maxFreq > ⌈n/k⌉。
