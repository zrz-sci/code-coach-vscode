# 394. 字符串解码

## 核心思路

这道题本质上是一个**嵌套结构的解析问题**：`k[...]` 内部可能还有 `k[...]`，处理嵌套结构最自然的两种方式是**栈**和**递归**。

## 思维链

1. **读完题第一反应**：字符串里有 `数字[内容]` 的模式，需要把内容重复数字次。手动做的话就是从内到外展开嵌套括号——先处理最内层的 `k[str]`，替换后再处理外层。

2. **嵌套是关键难点**：如果没有嵌套（如 `3[a]2[bc]`），直接线性扫描就行。但有嵌套（如 `3[a2[c]]`）时，遇到 `[` 不知道对应的 `]` 在哪，需要先处理内层。

3. **什么数据结构天然处理"先进后出"的嵌套？** —— **栈！** 遇到 `[` 就把当前状态"存档"压栈，遇到 `]` 就"读档"弹栈并组装结果。这和括号匹配是同一个套路。

4. **另一个视角：递归**。`k[encoded_string]` 的结构天然就是递归定义的——`encoded_string` 内部可能还有 `k[...]`。所以可以用递归函数来解析：遇到 `[` 递归进去，遇到 `]` 返回。

5. **具体怎么用栈？** 维护两个信息：当前正在拼的字符串、当前的重复次数。遇到 `[` 时把这两个信息压栈，开始新的一层；遇到 `]` 时弹出上一层的信息，把当前字符串重复后拼到上一层后面。

6. **具体怎么递归？** 用一个全局索引 `i` 扫描字符串。遇到数字就解析完整数字，遇到 `[` 就递归调用，遇到 `]` 就返回当前结果。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 栈模拟 | 遇 `[` 压栈存档，遇 `]` 弹栈拼接 | O(N) | O(N) | ⭐ 必须写出 |
| 递归解析 | 递归处理嵌套结构，`[` 进 `]` 出 | O(N) | O(N) | ⭐ 必须写出 |

> N 是**解码后**字符串的总长度（因为要拼出完整字符串）

## 关键提示

1. **栈里存什么？** 不是存单个字符，而是存"遇到当前 `[` 之前已经拼好的字符串"和"当前 `[` 前面的重复次数"。

2. **数字可能是多位的**：`k` 的范围是 `[1, 300]`，所以 `100[a]` 是合法的，别只读一位数字。

3. **没有被括号包裹的普通字母**也是合法的（如 `abc3[cd]xyz`），直接追加到当前字符串即可。

4. **递归解法的关键**：用一个引用传递的索引 `i`，让所有递归层共享同一个扫描位置，遇到 `]` 时返回，调用者继续从 `]` 之后扫描。

5. **处理流程可视化**（以 `3[a2[c]]` 为例）：

```
扫描到 '3'  → 数字 = 3
扫描到 '['  → 压栈 {之前的串="", 重复次数=3}，重置当前串
扫描到 'a'  → 当前串 = "a"
扫描到 '2'  → 数字 = 2
扫描到 '['  → 压栈 {之前的串="a", 重复次数=2}，重置当前串
扫描到 'c'  → 当前串 = "c"
扫描到 ']'  → 弹栈: 当前串 = "a" + "c"×2 = "acc"
扫描到 ']'  → 弹栈: 当前串 = "" + "acc"×3 = "accaccacc"
```

## 解法详解

### 解法1: 栈模拟 — O(N) / O(N) ⭐ 面试首选

**思考过程**：嵌套括号 → 先进后出 → 栈。每次遇到 `[`，就把"当前层的上下文"存档到栈里，然后开始处理新的一层。遇到 `]` 时，从栈里恢复上一层的上下文，把当前层的结果重复 k 次后拼接到上一层。

```cpp
class Solution {
public:
    string decodeString(string s) {
        stack<pair<string, int>> stk; // <之前拼好的串, 重复次数>
        string currStr = "";          // 当前层正在拼的字符串
        int currNum = 0;              // 当前正在解析的数字
        
        for (char c : s) {
            if (isdigit(c)) {
                // 数字可能多位，逐位累积
                currNum = currNum * 10 + (c - '0');
            } else if (c == '[') {
                // 存档：把当前串和重复次数压栈
                stk.push({currStr, currNum});
                // 重置：开始新的一层
                currStr = "";
                currNum = 0;
            } else if (c == ']') {
                // 读档：弹出上一层的串和重复次数
                auto [prevStr, repeatCount] = stk.top();
                stk.pop();
                // 当前串重复 repeatCount 次，拼到上一层后面
                string repeated = "";
                for (int i = 0; i < repeatCount; i++) {
                    repeated += currStr;
                }
                currStr = prevStr + repeated;
            } else {
                // 普通字母，直接追加
                currStr += c;
            }
        }
        
        return currStr;
    }
};
```

**关键点**：
- 栈存的是 `pair<string, int>`，不是单个字符
- 遇到 `[` 时必须同时重置 `currStr` 和 `currNum`
- 数字累积用 `currNum * 10 + (c - '0')`，别忘了处理多位数

### 解法2: 递归解析 — O(N) / O(N)

**思考过程**：`k[encoded_string]` 本身就是递归定义的。把整个字符串看成一个递归表达式：遇到 `[` 就递归进入子问题，遇到 `]` 就返回子问题的结果。关键是用一个**共享的索引**来驱动扫描。

```cpp
class Solution {
public:
    string decodeString(string s) {
        int i = 0; // 共享索引
        return decode(s, i);
    }
    
private:
    string decode(const string& s, int& i) {
        string result = "";
        
        while (i < s.size() && s[i] != ']') {
            if (isdigit(s[i])) {
                // 解析完整数字
                int num = 0;
                while (i < s.size() && isdigit(s[i])) {
                    num = num * 10 + (s[i] - '0');
                    i++;
                }
                // 跳过 '['
                i++; 
                // 递归解析括号内的内容
                string inner = decode(s, i);
                // 跳过 ']'
                i++; 
                // 重复 num 次
                for (int j = 0; j < num; j++) {
                    result += inner;
                }
            } else {
                // 普通字母，直接追加
                result += s[i];
                i++;
            }
        }
        
        return result;
    }
};
```

**关键点**：
- `i` 必须是**引用传递**（`int& i`），这样所有递归层共享同一个扫描位置
- `while` 的终止条件是 `s[i] != ']'`，遇到 `]` 时返回，让调用者来跳过这个 `]`
- 递归调用后的 `i++` 跳过 `]`，这一步不能丢

## 解法对比

| | 栈模拟 | 递归解析 |
|------|--------|----------|
| 核心思想 | 显式用栈存档/读档 | 隐式用调用栈处理嵌套 |
| 代码风格 | 迭代，所有逻辑在一个循环里 | 递归，层次更清晰 |
| 面试推荐 | ⭐ 更通用，面试官更常见 | 代码更简洁优雅 |
| 扩展性 | 容易改成处理其他嵌套格式 | 天然适合语法解析类题 |

两种解法的时间和空间复杂度相同，面试中写哪个都可以，但建议至少能说出两种。

## 易错点

1. **多位数字没处理**：
   - ✗ `int num = s[i] - '0';` — 只读了一位，`100[a]` 会变成 `1` 次重复
   - ✓ 用 while 循环累积：`num = num * 10 + (s[i] - '0');`

2. **栈解法中 `[` 处忘记重置**：
   - ✗ 压栈后没有 `currStr = ""; currNum = 0;` — 下一层会和上一层混在一起
   - ✓ 压栈后立即重置两个变量

3. **递归解法中 `i` 不用引用**：
   - ✗ `string decode(const string& s, int i)` — 每层递归有自己的 `i`，返回后扫描位置没更新
   - ✓ `string decode(const string& s, int& i)` — 所有层共享同一个 `i`

4. **递归解法中 `]` 的跳过时机搞错**：
   - ✗ 在 `decode` 函数内部遇到 `]` 时 `i++` 后再返回 — 调用者也 `i++` 导致多跳
   - ✓ 约定：`decode` 返回时 `i` 指向 `]`，由调用者负责 `i++` 跳过

## 面试追问

**Q1: 你能不能不用额外空间（栈/递归栈）来做？**
→ 不太行。嵌套结构天然需要 O(嵌套深度) 的空间来记录上下文。但嵌套深度最多是字符串长度的一半（每层至少有 `k[` 和 `]`），所以空间最差 O(n/2) = O(n)。

**Q2: 如果输入可能不合法怎么办？比如括号不匹配、数字后面直接跟字母没有括号？**
→ 可以在解析前先做一次合法性检查：用栈验证括号匹配，同时检查 `[` 前必须有数字。或者在解析过程中遇到异常格式时抛出异常/返回错误。

**Q3: 如果结果字符串太长不能存在内存里，只能流式输出怎么办？**
→ 不能一次性拼接完整字符串，需要改成"惰性求值"：用栈记录嵌套结构和重复次数，然后用迭代器模式逐字符输出。本质上是把递归展开成迭代，用栈记录"当前在第几层、第几次重复、第几个字符"。
