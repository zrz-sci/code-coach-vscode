# 10. 正则表达式匹配

## 核心思路

本质上是一个**双序列匹配问题**：给定字符串 `s` 和模式 `p`，判断两者能否从头到尾完全匹配。难点在于 `*` 可以匹配零个或多个前面的字符，这意味着在每个 `x*` 处你需要做出**选择**——用它匹配0次、1次、2次...这天然形成了一棵递归决策树，而决策树中存在大量重叠子问题，因此可以用 DP 优化。

## 思维链

1. **读完题第一反应**：逐字符匹配。如果没有 `*`，只需从左到右一一比较（`.` 匹配任意字符）。但 `*` 让匹配变得不确定——`a*` 可以匹配 ""、"a"、"aa"、"aaa"...，我们不知道该用几次。

2. **暴力递归的思路**：定义 `match(i, j)` 表示 `s[i:]` 和 `p[j:]` 是否匹配。每次看 `p[j+1]` 是否是 `*`：
   - 如果是 `*`：要么跳过这个 `x*`（匹配0次），要么当前字符匹配后 `i` 前进一步（匹配1次以上）
   - 如果不是 `*`：当前字符必须匹配，然后 `i++, j++`
   
3. **暴力的瓶颈**：同一个 `(i, j)` 状态会被反复计算。例如 `s="aaa", p="a*a*a*"` 中，到达 `(1, 2)` 可以从多条路径到达。这是经典的**重叠子问题**。

4. **记忆化搜索优化**：加一个 `memo[i][j]` 缓存已计算过的结果，状态数 O(m×n)，每个状态 O(1) 转移，总时间 O(m×n)。

5. **转成自底向上 DP**：定义 `dp[i][j]` 表示 `s[0..i-1]` 和 `p[0..j-1]` 是否匹配（多一维便于处理空串），从后往前或从前往后填表。

6. **理解状态转移方程**：
   - 若 `p[j-1]` 是普通字符或 `.`：`dp[i][j] = match(s[i-1], p[j-1]) && dp[i-1][j-1]`
   - 若 `p[j-1]` 是 `*`：
     - 匹配0次：`dp[i][j] = dp[i][j-2]`（跳过 `x*` 这两个字符）
     - 匹配1次以上：`dp[i][j] = match(s[i-1], p[j-2]) && dp[i-1][j]`（消耗 s 的一个字符，`x*` 保留继续匹配）

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力递归 | 对 `*` 穷举匹配次数 | O(2^(m+n)) 最坏 | O(m+n) 栈深 | 能说出即可 |
| 记忆化搜索 | 递归 + memo 缓存 | O(m×n) | O(m×n) | ⭐ 必须写出 |
| 自底向上 DP | 二维 dp 填表 | O(m×n) | O(m×n) | ⭐ 必须写出 |
| DP 空间优化 | 滚动数组 | O(m×n) | O(n) | 加分项 |

> m = s.length(), n = p.length()

## 关键提示

1. **`*` 永远和前面的字符绑定**：不要单独处理 `*`，应该把 `x*` 看作一个整体。每次检查 `p[j+1]` 是否是 `*`，来决定走哪条分支。

2. **"匹配0次"是关键**：`x*` 可以匹配零次，相当于这两个字符不存在。很多人只考虑匹配一次或多次，忘了零次。

3. **空模式匹配空串**：`dp[0][0] = true`。但空串 `s=""` 可能匹配非空模式 `p="a*b*c*"`（每个 `x*` 都匹配0次），所以**第一行的初始化不全是 false**。

4. **`.` 不需要特殊处理**：定义一个 `isMatch(char a, char b)` 辅助函数，当 `b == '.'` 或 `a == b` 时返回 true，统一处理。

5. **DP 填表方向**：`dp[i][j]` 依赖 `dp[i-1][j-1]`（左上）、`dp[i][j-2]`（左两格）、`dp[i-1][j]`（上方），所以从上到下、从左到右填表。

```
// DP 依赖关系可视化:
//
// dp[i][j] 的值取决于:
//
//   当 p[j-1] != '*':
//     dp[i-1][j-1]  →  dp[i][j]
//         ↘
//
//   当 p[j-1] == '*':
//     dp[i][j-2]  → dp[i][j]    (匹配0次, 跳过 x*)
//         ←←
//     dp[i-1][j]  → dp[i][j]    (匹配1+次, 消耗s的一个字符)
//         ↑
```

## 解法详解

### 解法1: 暴力递归 — O(2^(m+n)) / O(m+n)

**思考过程**：最直觉的做法——从 `s` 和 `p` 的头部开始逐步匹配。遇到 `*` 时，尝试所有可能（匹配0次、1次、2次...），只要有一种方式能走通就返回 true。

```cpp
class Solution {
public:
    bool isMatch(string s, string p) {
        return dfs(s, p, 0, 0);
    }
    
    bool dfs(const string& s, const string& p, int i, int j) {
        // 模式用完了，检查字符串是否也用完
        if (j == p.size()) return i == s.size();
        
        // 当前字符是否匹配（i 还没越界 且 字符相同或 p[j] 是 '.'）
        bool firstMatch = (i < s.size()) && 
                          (s[i] == p[j] || p[j] == '.');
        
        // 下一个字符是 '*' → x* 模式
        if (j + 1 < p.size() && p[j + 1] == '*') {
            // 选择1: x* 匹配 0 次 → 跳过 p 的两个字符
            // 选择2: x* 至少匹配 1 次 → 当前字符必须匹配，i 前进
            return dfs(s, p, i, j + 2) ||           // 匹配 0 次
                   (firstMatch && dfs(s, p, i + 1, j)); // 匹配 1+ 次
        } else {
            // 普通匹配：当前字符必须匹配，双方各前进一步
            return firstMatch && dfs(s, p, i + 1, j + 1);
        }
    }
};
```

**关键点**：
- 为什么"匹配1+次"时 `j` 不动？因为 `x*` 可能还要继续匹配更多字符，所以保持在 `j` 位置。
- 最坏情况下每个位置分两个分支，指数级时间。

```
// 决策树示例: s="aab", p="c*a*b"
//
//                    (0,0)
//                   c*匹配0次
//                   /       
//               (0,2)        
//              a*匹配0次 / \ a*匹配1次(firstMatch? a==a ✓)
//            (0,4)      (1,2)
//            b==b? ✗   a*匹配0次 / \ a*匹配1次(a==a ✓)
//                     (1,4)      (2,2)
//                     a==b? ✗   a*匹配0次 / \ a*匹配1次(a==b? ✗)
//                              (2,4)
//                              b==b ✓ → (3,5) → j==5, i==3 ✓ TRUE!
```

### 解法2: 记忆化搜索 — O(m×n) / O(m×n) ⭐ 面试首选

**从解法1优化**：暴力递归中，同一个 `(i, j)` 可能从不同路径被重复计算。加一个 `memo` 数组缓存结果，确保每个状态只算一次。

```cpp
class Solution {
public:
    bool isMatch(string s, string p) {
        int m = s.size(), n = p.size();
        // memo[i][j]: 0=未计算, 1=true, -1=false
        vector<vector<int>> memo(m + 1, vector<int>(n + 1, 0));
        return dfs(s, p, 0, 0, memo);
    }
    
    bool dfs(const string& s, const string& p, int i, int j,
             vector<vector<int>>& memo) {
        if (memo[i][j] != 0) return memo[i][j] == 1;
        
        bool result;
        if (j == p.size()) {
            result = (i == s.size());
        } else {
            bool firstMatch = (i < s.size()) && 
                              (s[i] == p[j] || p[j] == '.');
            
            if (j + 1 < p.size() && p[j + 1] == '*') {
                result = dfs(s, p, i, j + 2, memo) ||
                         (firstMatch && dfs(s, p, i + 1, j, memo));
            } else {
                result = firstMatch && dfs(s, p, i + 1, j + 1, memo);
            }
        }
        
        memo[i][j] = result ? 1 : -1;
        return result;
    }
};
```

**关键点**：
- 状态数 (m+1)×(n+1)，每个状态只计算一次，转移 O(1)，总时间 O(m×n)。
- memo 用三态（0/1/-1）而不是 bool + visited，代码更简洁。

### 解法3: 自底向上 DP — O(m×n) / O(m×n) ⭐ 面试首选

**思考过程**：将记忆化搜索翻转为填表。`dp[i][j]` 表示 `s` 的前 `i` 个字符和 `p` 的前 `j` 个字符是否匹配。

```
// DP 填表过程示例: s = "aab", p = "c*a*b"
//
//      ""  c   *   a   *   b
//  ""   T  F   T   F   T   F
//  a    F  F   F   T   T   F
//  a    F  F   F   F   T   F
//  b    F  F   F   F   F   T  ← 答案
//
// dp[0][0] = T (空串匹配空模式)
// dp[0][2] = T (c* 匹配0次 → dp[0][0])
// dp[0][4] = T (a* 匹配0次 → dp[0][2])
// dp[1][3] = T (a==a → dp[0][2] = T)
// dp[1][4] = T (a* 匹配0次 → dp[1][3]=T, 或匹配1次 → dp[0][4]=T)
// dp[2][4] = T (a* 匹配1次 → a==a && dp[1][4]=T)
// dp[3][5] = T (b==b → dp[2][4]=T) ✓
```

```cpp
class Solution {
public:
    bool isMatch(string s, string p) {
        int m = s.size(), n = p.size();
        // dp[i][j]: s的前i个字符 与 p的前j个字符 是否匹配
        vector<vector<bool>> dp(m + 1, vector<bool>(n + 1, false));
        
        dp[0][0] = true; // 空串匹配空模式
        
        // 初始化第一行: 空串 s="" 与模式 p 的匹配
        // 只有 "x*y*z*..." 这种每对都匹配0次才能匹配空串
        for (int j = 2; j <= n; j++) {
            if (p[j - 1] == '*') {
                dp[0][j] = dp[0][j - 2]; // x* 匹配0次
            }
        }
        
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (p[j - 1] == '*') {
                    // 情况A: x* 匹配 0 次 → 跳过 x* 这两个字符
                    dp[i][j] = dp[i][j - 2];
                    // 情况B: x* 至少匹配 1 次 → 当前 s[i-1] 必须和 x 匹配
                    if (s[i - 1] == p[j - 2] || p[j - 2] == '.') {
                        dp[i][j] = dp[i][j] || dp[i - 1][j];
                    }
                } else {
                    // 普通字符或 '.': 当前字符匹配 + 前缀匹配
                    if (s[i - 1] == p[j - 1] || p[j - 1] == '.') {
                        dp[i][j] = dp[i - 1][j - 1];
                    }
                }
            }
        }
        
        return dp[m][n];
    }
};
```

**关键点**：
- 下标偏移：`dp` 中第 `i` 行对应 `s[i-1]`，第 `j` 列对应 `p[j-1]`。`*` 在 `dp` 中出现在 `j` 位置时，它前面的字符是 `p[j-2]`。
- 第一行初始化：`dp[0][j]` 只有当 `p[j-1]=='*'` 且 `dp[0][j-2]==true` 时才为 true。

### 解法4: DP 空间优化 — O(m×n) / O(n)

**从解法3优化**：`dp[i][j]` 只依赖当前行 `dp[i][j-2]` 和上一行 `dp[i-1][j-1]`、`dp[i-1][j]`，可以用一维数组 + 一个变量保存"左上角"。

```cpp
class Solution {
public:
    bool isMatch(string s, string p) {
        int m = s.size(), n = p.size();
        vector<bool> dp(n + 1, false);
        dp[0] = true;
        
        // 初始化: 空串 vs 模式
        for (int j = 2; j <= n; j++) {
            if (p[j - 1] == '*') dp[j] = dp[j - 2];
        }
        
        for (int i = 1; i <= m; i++) {
            bool prev = dp[0]; // prev = dp[i-1][j-1] 的上一轮左上角
            dp[0] = false;     // dp[i][0]: 非空串 vs 空模式 = false
            
            for (int j = 1; j <= n; j++) {
                bool temp = dp[j]; // 保存 dp[i-1][j]，下轮作为 prev
                
                if (p[j - 1] == '*') {
                    // 匹配0次: dp[i][j-2]
                    dp[j] = dp[j - 2];
                    // 匹配1+次: 当前字符匹配 && dp[i-1][j]（temp已被覆盖前保存了）
                    if (s[i - 1] == p[j - 2] || p[j - 2] == '.') {
                        dp[j] = dp[j] || temp;
                    }
                } else {
                    // 普通匹配: prev 就是 dp[i-1][j-1]
                    if (s[i - 1] == p[j - 1] || p[j - 1] == '.') {
                        dp[j] = prev;
                    } else {
                        dp[j] = false;
                    }
                }
                
                prev = temp; // 更新 prev 为本轮的 dp[i-1][j]
            }
        }
        
        return dp[n];
    }
};
```

**关键点**：
- `prev` 保存的是上一行的 `dp[i-1][j-1]`，在 `j` 向右移动前，先用 `temp` 保存 `dp[j]`（即 `dp[i-1][j]`），处理完当前格后 `prev = temp`。
- `*` 分支中的 `dp[j-2]` 是当前行的值（左两格），已经在本轮更新过，这是正确的（对应匹配0次时跳过 `x*`）。
- `*` 分支中 `temp` 代表 `dp[i-1][j]`（上方），对应匹配1+次，因为 `temp` 是覆盖前保存的旧值。

## 解法对比

| | 暴力递归 | 记忆化搜索 | 自底向上 DP | DP 空间优化 |
|---|---|---|---|---|
| 时间 | O(2^(m+n)) | O(m×n) | O(m×n) | O(m×n) |
| 空间 | O(m+n) | O(m×n) | O(m×n) | O(n) |
| 思维难度 | 低 | 低（加缓存） | 中（初始化） | 高（prev 维护） |
| 面试推荐 | 讲思路 | ✅ 首选 | ✅ 首选 | 追问时说 |

- **记忆化搜索 vs 自底向上 DP**：逻辑完全等价，记忆化更直觉（递归结构清晰），自底向上没有递归开销且更容易做空间优化。面试两种都行，选你更熟的。
- **空间优化**：这题 m, n ≤ 20，空间不是瓶颈，但面试官可能追问"能否 O(n) 空间"。

## 易错点

1. **`*` 的对象搞错**：
   - ✗ 把 `*` 当成独立字符处理，或认为 `*` 匹配任意字符
   - ✓ `*` 永远和前一个字符绑定，`a*` 是一个整体，匹配零个或多个 `a`

2. **第一行初始化遗漏**：
   - ✗ 认为 `dp[0][j]` 全为 false（空串不可能匹配非空模式）
   - ✓ `p = "a*b*"` 时，`dp[0][2] = true`、`dp[0][4] = true`（每个 `x*` 都匹配0次）

3. **`*` 匹配多次时 j 不动的原因写错**：
   - ✗ `dp[i][j] = dp[i-1][j-1]`（只匹配了1次就跳过了 `x*`）
   - ✓ `dp[i][j] = dp[i-1][j]`（`x*` 保留在原位，可能还要继续匹配更多字符）

4. **下标偏移错误**：
   - ✗ `p[j-1] == '*'` 时取前面字符用 `p[j-1]`
   - ✓ 应该用 `p[j-2]`（`*` 的前一个字符在 p 中的位置是 `j-2`，因为 dp 多了一维偏移）

5. **空间优化中 prev 更新时机错误**：
   - ✗ 先覆盖 `dp[j]` 再保存 `temp`，导致 `prev` 拿到的是新值
   - ✓ 必须先 `temp = dp[j]`，再更新 `dp[j]`，最后 `prev = temp`

## 面试追问

**Q1: 能否先讲讲暴力递归的思路？瓶颈在哪？**
> 从头部开始逐字符匹配，遇到 `x*` 时分两个分支（匹配0次 or 1+次）。瓶颈：同一个 `(i, j)` 状态被反复计算，最坏指数级。

**Q2: 怎么优化？状态转移方程是什么？**
> 加 memo 或自底向上 DP。`dp[i][j]` 定义为 s 前 i 个字符和 p 前 j 个字符是否匹配。转移分两种：`p[j-1]` 是 `*` 时看匹配0次和1+次；否则看当前字符是否匹配。

**Q3: 能否优化到 O(n) 空间？具体怎么维护？**
> 可以。`dp[i][j]` 只依赖当前行左边和上一行，用一维数组滚动。关键是用 `prev` 变量保存"左上角"旧值，每次更新 `dp[j]` 前先保存旧值。

**Q4: 如果模式中还支持 `+`（匹配一个或多个），怎么改？**
> `x+` 等价于 `xx*`，所以可以预处理展开。或者在 DP 转移中去掉"匹配0次"分支：`x+` 不能跳过，只有 `firstMatch && dp[i-1][j]` 这一条路。
