# LeetCode 880: Decoded String at Index

## 核心思路

本题要求在编码字符串解码后找到第 k 个字符。解码后的字符串可能极长（高达 2^63），因此绝对不能真正构建解码字符串。核心思路是**逆向回推**：先正向扫描计算解码后的总长度，然后从后向前逆向扫描，利用取模运算不断缩小 k 的范围，直到定位到某个具体字母。当遇到数字时，总长度缩小（除以该数字），k 也取模缩小；当遇到字母且 k 恰好为 0 时，该字母就是答案。

## 思维链

1. **观察规模**：k 最大 10^9，解码后字符串可能远超内存限制，所以必须避免实际构造字符串。
2. **正向扫描**：遍历编码字符串，维护当前解码长度 `size`。字母让 size+1，数字让 size 乘以该数字。
3. **确定搜索范围**：只需让 size >= k 即可停止正向扫描。
4. **逆向回推**：从停止位置往回扫描。遇到数字 d 时，size /= d，然后 k %= size（因为重复 d 次等价于取模）。遇到字母时，size--，若此时 k == 0 或 k == size，则该字母就是答案。
5. **取模的含义**：如果 k % size == 0，说明我们要找的是当前子串的最后一个字符（等价于第 size 个字符），这在下一步遇到字母时会被匹配到。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 逆向回推法 | O(n) | O(1) | 最优解，利用取模缩小搜索空间 |

其中 n 为编码字符串的长度（最大 100）。

## 关键提示

1. **不要构建解码字符串** -- 长度可能达到 2^63，任何尝试构建的方法都会超时或超内存。
2. **使用 long long** -- size 可能超出 int 范围，必须用 64 位整数。
3. **k % size == 0 的特殊处理** -- 当 k 整除 size 时，说明目标是当前重复段的最后一个字符。
4. **正向扫描可以提前停止** -- 只要 size >= k 就无需继续。
5. **逆向扫描时遇到字母的判断条件** -- k == 0 或 k == size（取模后 k 可能变为 0）。

## 解法详解

### 逆向回推法（Reverse Working）

**原理**：编码字符串中，数字代表重复。如果解码长度为 L，遇到数字 d，则之前的长度为 L/d。k 在重复段内的位置等价于 k % (L/d)。通过不断缩小，最终 k 会落到某个具体的字母上。

**算法步骤**：

1. **正向计算总长度**：
   - 遍历字符串 s，维护 size = 0
   - 若 s[i] 是字母，size++
   - 若 s[i] 是数字 d，size *= d
   - 当 size >= k 时可以停止

2. **逆向定位字符**：
   - 从当前位置 i 往回遍历
   - 若 s[i] 是数字 d：size /= d，k %= size
   - 若 s[i] 是字母：如果 k == 0 或 k == size，返回 s[i]；否则 size--

**正确性论证**：
- 数字 d 表示前面的串重复 d 次。如果 k > 前面串的长度，那么 k % 前面串长度就是等价位置。
- 当 k 缩小到 0 时，意味着我们要找的是当前子串的最后一个字符。遇到下一个字母且 k==0，该字母就是末尾字符。

**复杂度分析**：
- 时间：O(n)，两次遍历编码字符串
- 空间：O(1)，只用常数额外空间

## 易错点

1. **整数溢出**：size 必须用 `long long`，否则乘法运算会溢出。
2. **k 的 1-indexed 处理**：题目 k 是 1-indexed，在逆向时 k%size==0 意味着当前段的最后一个字符，而非第一个。
3. **忘记在字母分支中 size--**：如果不减少 size，逆向过程不会正确收缩。
4. **返回类型是 string**：需要返回 `string(1, s[i])` 而非 `char`。
5. **正向扫描未提前停止**：虽然不影响正确性，但如果 size 已经很大再乘以数字可能溢出（即使用 long long 也有风险）。

## 面试追问

1. **如果不限制 k 范围，解码长度可能超过 long long 怎么办？**
   - 可以在正向扫描时加一个上限检查，只要 size >= k 就停止，避免不必要的乘法。

2. **能否用正向模拟解决？**
   - 只有当 k 很小时可以正向模拟（边解码边计数），但最坏情况 k = 10^9 仍然太慢。

3. **如果编码字符串中连续出现多个数字（如 "a23"），如何处理？**
   - 每个数字独立处理：先 size *= 2，再 size *= 3。逆向时也是逐个数字处理。

4. **这道题的思想可以推广到哪些问题？**
   - 类似于约瑟夫环问题的逆向推导思想，以及所有"在虚拟大序列中定位元素"的问题。

5. **时间复杂度能否进一步优化？**
   - 已经是 O(n)，n 最大 100，无需进一步优化。
