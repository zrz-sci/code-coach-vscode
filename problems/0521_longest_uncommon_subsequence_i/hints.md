# 521. 最长特殊序列 I (Longest Uncommon Subsequence I)

**难度**: Easy | **标签**: String

## 核心思路

这是一道脑筋急转弯题。如果两个字符串不相等，较长的那个字符串本身就是答案（它是自己的子序列，但不是另一个的子序列）。如果相等，则不存在特殊序列。

## 思维链

1. "最长特殊序列" = 只是某一个字符串的子序列，不是两个都是
2. 如果 `a == b` → 任何 a 的子序列也是 b 的子序列 → 返回 -1
3. 如果 `a != b` → 较长的字符串本身就不可能是较短字符串的子序列 → 返回 `max(a.len, b.len)`
4. 即使长度相同但内容不同，每个字符串本身就是特殊序列 → 返回该长度

## 解法概览

| 解法 | 时间 | 空间 | 推荐 |
|------|------|------|------|
| 直接比较 | O(n) | O(1) | ⭐⭐⭐ |

## 关键提示

1. 这题的关键不是写代码，而是理解题意
2. 一个字符串本身就是自己的子序列
3. 如果 a != b 且 len(a) >= len(b)，那 a 本身就不可能是 b 的子序列（长度更长的不可能是短的子序列）

## 解法详解

### 解法1: 直接比较

```cpp
class Solution {
public:
    int findLUSlength(string a, string b) {
        if (a == b) return -1;
        return max(a.size(), b.size());
    }
};
```

## 易错点

| 错误 | 正确 |
|------|------|
| ✗ 尝试枚举所有子序列 | ✓ 直接比较两个字符串是否相等 |
| ✗ 认为长度相同就没有特殊序列 | ✓ 长度相同但内容不同，各自本身就是特殊序列 |
| ✗ 返回 `int` 但 `size()` 是 `size_t` 未转换 | ✓ 注意返回类型匹配（实际上 max 会自动处理） |

## 面试追问

- **Q1**: 这题的本质是什么？
  → 脑筋急转弯：如果字符串不同，较长者本身就是特殊序列
- **Q2**: 如果有多个字符串呢（LeetCode 522）？
  → 需要检查每个字符串是否是其他所有字符串的子序列，复杂度提升
- **Q3**: 如何判断一个字符串是否是另一个的子序列？
  → 双指针法，O(m+n) 时间
