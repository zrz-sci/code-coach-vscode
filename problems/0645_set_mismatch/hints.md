# 645. 错误的集合

## 核心思路

集合 `{1, 2, ..., n}` 中有一个数被重复了（占据了另一个数的位置），导致一个数重复、一个数缺失。需要找出 **[重复的数, 缺失的数]**。

这道题的核心挑战不在于"能不能做"，而在于"能否用 O(1) 额外空间做"。有三种经典思路：哈希计数（O(n) 空间）、原地标记（O(1) 空间，修改原数组）、数学求和/异或（O(1) 空间，不修改数组）。

## 思维链

1. **读完题第一反应** → 最直接：遍历一遍计数，出现 2 次的是重复数，出现 0 次的是缺失数。用数组或哈希表计数，O(n) 时间 O(n) 空间。
2. **能省空间吗？** → 数组的值域是 `[1, n]`，恰好可以映射到数组的索引 `[0, n-1]`。这意味着我们可以用"原地标记"技巧——把 `nums[i]` 对应的索引处取负来标记"这个数出现过"。
3. **原地标记怎么找重复和缺失？** → 第一遍遍历：对每个 `abs(nums[i]) - 1` 位置取负。如果发现目标位置已经是负数，说明这个值之前出现过 → 找到了重复数。第二遍遍历：仍然是正数的位置 `i`，说明 `i+1` 从没出现过 → 找到了缺失数。
4. **有没有不修改数组的方法？** → 数学法：`sum(nums) - sum(1..n)` 得到 `dup - missing`；`sum(nums^2) - sum(1^2..n^2)` 得到 `dup^2 - missing^2`，两个方程解两个未知数。或者用异或法（类似 LeetCode 136 的思路）。
5. **排序法可以吗？** → 排序后，相邻的重复元素就是重复数，缺失的可以通过和 `i+1` 对比找到。O(n log n) 时间 O(1) 空间（如果原地排序）。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 哈希计数 | 数组计数，找出现2次和0次的 | O(n) | O(n) | 基础入门 |
| 原地标记（取负） | 值→索引映射 + 取负标记 | O(n) | O(1) | ⭐ 面试首选 |
| 数学法（求和） | 利用和与平方和列方程 | O(n) | O(1) | 数学思维好 |
| 排序法 | 排序后线性扫描 | O(n log n) | O(1) | 简单但慢 |

## 关键提示

1. **值域 = 索引域**：数组中的值是 `1~n`，数组的索引是 `0~n-1`，`nums[i]-1` 恰好是一个合法索引。这是"原地标记"能工作的前提。
2. **取负标记的含义**：`nums[idx]` 为负 ⇔ 值 `idx+1` 已经被看到过。这是一种"用符号位做布尔标记"的技巧。
3. **abs() 的重要性**：遍历时必须用 `abs(nums[i])`，因为前面的步骤可能已经把某些位置取负了。
4. **返回顺序**：题目要求返回 `[重复数, 缺失数]`，注意不要搞反。
5. **数学法的溢出风险**：`sum(nums^2)` 在 n 很大时可能溢出 int。需要用 long long 或者 `dup^2 - missing^2 = (dup+missing)(dup-missing)` 的分解形式来避免。

## 解法详解

### 解法1: 哈希计数 — O(n) / O(n) 基础解法

**思考过程**: 最直觉——建一个计数数组 `count[1..n]`，遍历 nums 计数，然后找 count=2 的（重复）和 count=0 的（缺失）。

```
示例: nums = [1,2,2,4], n = 4

计数:
count[1] = 1, count[2] = 2, count[3] = 0, count[4] = 1
                        ↑                 ↑
                     重复=2             缺失=3

返回 [2, 3] ✓
```

```cpp
class Solution {
public:
    vector<int> findErrorNums(vector<int>& nums) {
        int n = nums.size();
        vector<int> count(n + 1, 0); // count[1..n]
        int dup = -1, missing = -1;
        
        for (int num : nums) {
            count[num]++;
        }
        
        for (int i = 1; i <= n; i++) {
            if (count[i] == 2) dup = i;
            if (count[i] == 0) missing = i;
        }
        
        return {dup, missing};
    }
};
```

**关键点**:
- 简单直接，几乎不可能写错。
- 空间 O(n)，不是最优。
- 面试时可以先说这个方案，再优化到 O(1) 空间。

---

### 解法2: 原地标记（取负） — O(n) / O(1) ⭐ 面试首选

**从解法1优化**: 不用额外的计数数组，而是直接在 nums 数组上"标记"。利用值域 [1,n] 到索引 [0,n-1] 的映射，把对应位置取负表示"已访问"。

```
示例: nums = [1,2,2,4], n = 4

第一遍（标记）:
i=0: val=|1|=1, idx=0, nums[0]>0 → 取负, nums=[-1,2,2,4]
i=1: val=|2|=2, idx=1, nums[1]>0 → 取负, nums=[-1,-2,2,4]
i=2: val=|2|=2, idx=1, nums[1]<0 → 已标记! dup = 2
i=3: val=|4|=4, idx=3, nums[3]>0 → 取负, nums=[-1,-2,2,-4]

第二遍（找缺失）:
i=0: nums[0]=-1 < 0 → 已标记
i=1: nums[1]=-2 < 0 → 已标记
i=2: nums[2]=2  > 0 → 未标记! missing = 2+1 = 3
i=3: nums[3]=-4 < 0 → 已标记

返回 [2, 3] ✓
```

```cpp
class Solution {
public:
    vector<int> findErrorNums(vector<int>& nums) {
        int dup = -1, missing = -1;
        int n = nums.size();
        
        // 第一遍: 标记 + 找重复
        for (int i = 0; i < n; i++) {
            int idx = abs(nums[i]) - 1;   // 值→索引映射
            if (nums[idx] < 0) {
                dup = abs(nums[i]);        // 已经标记过 → 重复!
            } else {
                nums[idx] = -nums[idx];    // 取负标记
            }
        }
        
        // 第二遍: 找缺失
        for (int i = 0; i < n; i++) {
            if (nums[i] > 0) {
                missing = i + 1;           // 未被标记 → 缺失!
            }
        }
        
        return {dup, missing};
    }
};
```

**关键点**:
- `abs(nums[i]) - 1` 是值到索引的映射。**必须用 abs()**，因为前面的步骤可能已经把某些 `nums[i]` 取负了。
- 发现 `nums[idx] < 0` 说明 `idx+1` 这个值之前已经出现过了，当前的 `abs(nums[i])` 就是重复值。
- 第二遍扫描中，仍然为正的 `nums[i]` 说明 `i+1` 从未出现 → 缺失值。
- **会修改原数组**，如果不允许修改，需要用数学法或额外空间。

### 解法3: 数学法（求和 + 平方和） — O(n) / O(1)

**不修改数组的 O(1) 空间方案**: 利用两个等式：

```
设重复数 = d, 缺失数 = m

等式1: sum(nums) - sum(1..n) = d - m
等式2: sum(nums^2) - sum(1^2..n^2) = d^2 - m^2 = (d+m)(d-m)

从等式1得: d - m = diff1
从等式2得: (d+m) = diff2 / diff1
解出: d = (diff1 + diff2/diff1) / 2
      m = d - diff1
```

```
示例: nums = [1,2,2,4], n = 4

sum(nums) = 1+2+2+4 = 9
sum(1..4) = 1+2+3+4 = 10
diff1 = 9 - 10 = -1  (即 d - m = -1)

sum(nums^2) = 1+4+4+16 = 25
sum(1^2..4^2) = 1+4+9+16 = 30
diff2 = 25 - 30 = -5  (即 d^2 - m^2 = -5)

d + m = diff2 / diff1 = -5 / -1 = 5
d - m = diff1 = -1

d = (5 + (-1)) / 2 = 2  ✓
m = 2 - (-1) = 3        ✓
```

```cpp
class Solution {
public:
    vector<int> findErrorNums(vector<int>& nums) {
        long long n = nums.size();
        long long sum_n = n * (n + 1) / 2;           // 1+2+...+n
        long long sum_n2 = n * (n + 1) * (2 * n + 1) / 6; // 1^2+2^2+...+n^2
        
        long long sum_nums = 0, sum_nums2 = 0;
        for (int num : nums) {
            sum_nums += num;
            sum_nums2 += (long long)num * num;
        }
        
        long long diff1 = sum_nums - sum_n;       // d - m
        long long diff2 = sum_nums2 - sum_n2;     // d^2 - m^2
        long long sum_dm = diff2 / diff1;          // d + m
        
        int dup = (int)(diff1 + sum_dm) / 2;
        int missing = dup - (int)diff1;
        
        return {dup, missing};
    }
};
```

**关键点**:
- **不修改原数组**，真正的 O(1) 额外空间。
- 必须用 `long long` 防止溢出（`n` 最大 10^4，`n^3` 约 10^12）。
- 公式推导需要一定的数学功底，面试中可以先解释思路再写代码。

---

### 解法4: 排序法 — O(n log n) / O(1)

**最朴素的方案**: 排序后线性扫描，相邻重复的就是重复数，缺失的通过与期望值对比找到。

```cpp
class Solution {
public:
    vector<int> findErrorNums(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        int dup = -1, missing = -1;
        int n = nums.size();
        
        // 找重复: 相邻相同
        for (int i = 1; i < n; i++) {
            if (nums[i] == nums[i - 1]) {
                dup = nums[i];
                break;
            }
        }
        
        // 找缺失: 求和差值
        long long sum = 0;
        for (int num : nums) sum += num;
        long long expected = (long long)n * (n + 1) / 2;
        missing = (int)(expected - sum + dup);
        
        return {dup, missing};
    }
};
```

**关键点**:
- 排序后找重复很简单，但时间 O(n log n)。
- 找缺失可以用 `期望总和 - 实际总和 + 重复数` 得到。
- 面试中不推荐，除非是作为思路的第一步。

## 解法对比

|  | 哈希计数 | 原地标记 | 数学法 | 排序法 |
|--|---------|---------|--------|-------|
| 时间 | O(n) | O(n) | O(n) | O(n log n) |
| 空间 | O(n) | **O(1)** | **O(1)** | O(1)/O(log n) |
| 修改原数组 | 否 | **是** | **否** | 是 |
| 代码复杂度 | ⭐ 最简单 | ⭐⭐ 中等 | ⭐⭐⭐ 需推导 | ⭐⭐ 中等 |

**面试选择**: 推荐先说哈希计数（表明理解题意），再写原地标记（展示O(1)空间技巧），最后提数学法（展示数学思维）。

## 易错点

1. **原地标记忘记取 abs()**：
   - ✗ `int idx = nums[i] - 1;` → 如果 nums[i] 已经被取负，idx 会是负数，越界！
   - ✓ `int idx = abs(nums[i]) - 1;` → 始终取绝对值

2. **返回顺序搞反**：
   - ✗ `return {missing, dup}` → 题目要求 [重复数, 缺失数]
   - ✓ `return {dup, missing}`

3. **数学法溢出**：
   - ✗ `int sum_n2 = n * (n+1) * (2*n+1) / 6;` → n=10^4 时溢出 int
   - ✓ 用 `long long`

4. **原地标记后忘记 nums[i] 可能为 0 的情况**：
   - 本题 `nums[i] >= 1`，不存在 0。但如果值域包含 0，取负标记就不可靠了（-0 == 0）。
   - 如果值域包含 0，改用"加 n"标记法替代取负法。

5. **数学法 diff1 为 0 的陷阱**：
   - 如果 `diff1 = 0`，说明 `dup == missing`，但题目保证了一个重复一个缺失，`dup != missing`，所以不会发生。

## 面试追问

**Q1: 原地标记法修改了原数组，如果不允许修改怎么办？**
> 用数学法（求和 + 平方和）或异或法。异或法：将 `nums[0..n-1]` 和 `1..n` 全部异或，得到 `dup XOR missing`。然后根据最低有效位将所有数分成两组，分别异或得到 dup 和 missing。

**Q2: 如果有两个数重复、两个数缺失呢？**
> 哈希计数法可以直接扩展。数学法需要三个方程（和、平方和、立方和）来解三个未知量——但这时候约束不够（4个未知量需要4个方程）。实际上两个重复两个缺失有额外约束（重复的和 = 缺失的和 + 原始差），具体要视题目而定。

**Q3: 原地标记法中，为什么用"取负"而不是其他标记方式？**
> 因为取负是可逆的（abs 恢复原值），不会丢失原始信息。其他方式：加 n（需要 mod n 恢复原值）、交换到正确位置（类似 LeetCode 41）。选择哪种取决于值域和约束。

**Q4: 这道题和 LeetCode 448（找缺失的数）有什么关系？**
> 几乎一样的技巧。448 只需要找缺失的数（不需要找重复的），所以只用取负标记 + 扫描正数位置就够了。本题多了"找重复数"的步骤——在取负时如果发现已经是负的，就知道重复了。

**Q5: 异或法的时间和空间复杂度？**
> 时间 O(n)，空间 O(1)，不修改数组。步骤：1) 全部异或得 `d XOR m`；2) 取最低有效位作为分组依据；3) 分组异或得出 d 和 m；4) 验证哪个是重复哪个是缺失。

## 相关题型

- **448. 找到所有数组中消失的数字** — 本题的"只找缺失"版本。使用完全相同的原地标记技巧，最后找正数位置即可。
- **287. 寻找重复数** — 本题的"只找重复"版本（但数组长度 n+1，值域 [1,n]）。可以用 Floyd 龟兔算法做 O(1) 空间。
- **136. 只出现一次的数字** — 异或法的经典应用。本题的数学法/异或法思路可以从这里迁移。
- **41. 缺失的第一个正数** — 更难的原地标记题。值域不定，需要先"归位"再扫描，但核心思路（索引=值的映射）相同。
