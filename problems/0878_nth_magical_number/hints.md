# 878. 第 N 个神奇数字

## 核心思路

"神奇数字"是能被 a 或 b 整除的正整数。求第 n 个这样的数。直接枚举不可能（n 可达 10^9），但观察到：对于任意数 x，小于等于 x 的神奇数字个数可以用**容斥原理**在 O(1) 算出：`count(x) = x/a + x/b - x/lcm(a,b)`。这个 count 函数关于 x 单调递增，所以直接**二分查找**最小的 x 使得 count(x) >= n。

## 思维链

1. **读完题第一反应** → n 最大 10^9，不可能一个一个枚举。需要数学方法或二分。
2. **关键观察** → "小于等于 x 的神奇数字个数" 是一个关于 x 单调递增的函数。如果能快速计算这个函数，就能用二分查找。
3. **容斥原理** → 小于等于 x 的 a 的倍数有 x/a 个，b 的倍数有 x/b 个，同时是 a 和 b 的倍数（即 lcm(a,b) 的倍数）有 x/lcm(a,b) 个。由容斥：count(x) = x/a + x/b - x/lcm(a,b)。
4. **二分范围** → 下界 = min(a,b)（第 1 个神奇数字），上界 = n * min(a,b)（最多这么大）。在此范围内二分找最小的 x 使得 count(x) >= n。
5. **取模注意** → 题目要求结果 mod 10^9+7，但二分过程中不能取模（取模会破坏单调性），只在最终答案上取模。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 二分 + 容斥 | 二分答案，容斥计算 count | O(log(n*min(a,b))) | O(1) | 唯一正解 |

## 关键提示

1. **LCM 计算**：`lcm(a,b) = a / gcd(a,b) * b`。注意先除后乘防溢出。gcd 用辗转相除法（C++ 标准库 `__gcd` 或自己写）。
2. **容斥公式**：`f(x) = x/a + x/b - x/lcm(a,b)`，其中除法都是整数除法（下取整）。这恰好等于 [1,x] 中能被 a 或 b 整除的数的个数。
3. **二分条件**：找最小的 x 使得 f(x) >= n。标准的"lower_bound"型二分。
4. **二分上界**：最大值不超过 `(long long)n * min(a,b)`。因为最差情况下所有神奇数字都是 min(a,b) 的倍数。
5. **取模时机**：二分搜索期间不取模。只在 return 时对最终的 mid 取模 10^9+7。

## 解法详解

### 解法1: 二分 + 容斥 — O(log(n*min(a,b))) / O(1)

**思考过程**: 定义 f(x) = [1,x] 中的神奇数字个数。f 单调递增，二分查找最小的 x 使得 f(x) >= n。

```
示例: n=4, a=2, b=3

lcm(2,3) = 6

f(x) = x/2 + x/3 - x/6

x=1: f=0+0-0=0
x=2: f=1+0-0=1  → 第1个: 2
x=3: f=1+1-0=2  → 第2个: 3
x=4: f=2+1-0=3  → 第3个: 4
x=5: f=2+1-0=3
x=6: f=3+2-1=4  → 第4个: 6 ✓

二分过程:
lo=2, hi=8 (4*min(2,3)=8)
mid=5: f(5)=3 < 4 → lo=6
mid=7: f(7)=4 >= 4 → hi=7... 继续...
最终找到 x=6
```

```cpp
class Solution {
public:
    int nthMagicalNumber(int n, int a, int b) {
        const int MOD = 1e9 + 7;
        long long lcm = (long long)a / __gcd(a, b) * b;
        
        long long lo = 1, hi = (long long)n * min(a, b);
        while (lo < hi) {
            long long mid = lo + (hi - lo) / 2;
            long long cnt = mid / a + mid / b - mid / lcm;
            if (cnt < n) {
                lo = mid + 1;
            } else {
                hi = mid;
            }
        }
        return lo % MOD;
    }
};
```

**关键点**:
- `lo + (hi - lo) / 2` 防止溢出。
- `cnt < n` 时 `lo = mid + 1`，否则 `hi = mid`。这是标准的 lower_bound 模板。
- `lo % MOD` 只在最后取模。

---

### 解法1 变体: 数学公式直接求解

```
容斥原理告诉我们，在一个 LCM 周期内，恰好有 L/a + L/b - 1 个神奇数字（L = lcm(a,b)）。
设 m = L/a + L/b - 1 = 每个 LCM 周期内的神奇数字个数。

第 n 个神奇数字大约在第 n/m 个周期附近:
  完整周期数 q = (n-1) / m
  周期内偏移 r = n - q * m
  
答案 = q * L + 第r个神奇数字（在 [1, L] 内找）

[1, L] 内最多 m 个神奇数字，可以合并排序 a 和 b 的倍数来找第 r 个。
但这种方法不如二分简洁，不推荐。
```

## 易错点

1. **整数溢出**：
   - n * min(a,b) 可能达到 10^9 * 4*10^4 = 4*10^13，必须用 long long。
   - lcm 计算时 a*b 可能溢出 int，先除 gcd 再乘。

2. **二分搜索期间取模**：
   - 二分过程中不能对 mid 取模！取模后数值变小，f(mid) 也变小，破坏单调性。
   - 只在 return 时取模。

3. **lcm 计算方式**：
   - `a / gcd(a,b) * b` 而非 `a * b / gcd(a,b)`。后者 `a*b` 可能溢出。

4. **二分边界**：
   - lo 从 1 开始（不是 0），因为正整数。
   - hi 用 `(long long)n * min(a,b)` 而非 `n * max(a,b)`（后者可能不够紧）。

## 面试追问

**Q1: 容斥原理为什么有效？如何证明？**
> 被 a 或 b 整除的数 = 被 a 整除的 + 被 b 整除的 - 被两者都整除的。被 a 和 b 都整除等价于被 lcm(a,b) 整除。这是集合论中的 |A ∪ B| = |A| + |B| - |A ∩ B|。

**Q2: 为什么二分一定能找到恰好等于 n 的位置？**
> f(x) 是非递减函数，且对于 a 或 b 的倍数 x，f(x) = f(x-1) + 1（跳跃增加1）。所以对于每个整数 k，一定存在 x 使得 f(x) = k。而 lower_bound 找的就是最小的 x 使得 f(x) >= n，此时 f(x) = n。

**Q3: 如果是三个数 a, b, c 的情况呢？**
> 容斥扩展为：count(x) = x/a + x/b + x/c - x/lcm(a,b) - x/lcm(a,c) - x/lcm(b,c) + x/lcm(a,b,c)。二分框架不变，只是 count 函数更复杂。

**Q4: 时间复杂度中的 log 的底是什么？**
> 二分的范围是 [1, n*min(a,b)]，所以是 O(log(n * min(a,b)))。对于 n=10^9, min(a,b)=2，大约 log2(2*10^9) 约 31 次循环，非常快。
