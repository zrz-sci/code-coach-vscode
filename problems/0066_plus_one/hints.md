# 66. 加一

## 核心思路

这道题本质上就是模拟**竖式加法中的进位传播**——从最低位（数组末尾）开始加 1，如果产生进位就继续往高位传播，直到没有进位为止。

## 思维链

1. **读完题第一反应**：这不就是把数组转成数字，加 1，再转回数组吗？但是等一下——数组长度最大 100 位，任何整数类型都装不下！所以必须在数组上直接操作。

2. **回忆小学竖式加法**：从个位（数组末尾）开始，当前位加 1，如果不到 10 就结束了；如果等于 10，当前位变 0，进位 1 继续往前传。

3. **什么时候进位会停？** 只要某一位加完后 < 10，进位就停了，后面的高位完全不受影响。

4. **最坏情况是什么？** 全是 9（如 [9,9,9]），进位一路传到最高位还要再进一位，数组要在最前面插入一个 1，变成 [1,0,0,0]。

5. **优化观察**：进位停止后，更高位不需要任何操作，可以直接返回。大部分情况下，只需要修改最后一位就结束了。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 通用进位模拟 | 用 carry 变量从末尾往前传播进位 | O(n) | O(1) | 能说出即可 |
| 提前终止优化 | 没有进位时立即返回 | O(n) | O(1) | ⭐ 必须写出 |
| 全9特判技巧 | 利用"只有全9才会增长数组长度"的性质 | O(n) | O(1) | 加分项 |

## 关键提示

1. **不要尝试把数组转成 int/long**——数组最长 100 位，会溢出。必须在数组上原地模拟加法。

2. **进位传播有传递性**：只有当前位是 9 时，加 1 才会产生新的进位。一旦遇到不是 9 的位，加完就可以直接返回了。

3. **数组长度增加的唯一情况**：所有位都是 9（如 99, 999, 9999）。此时结果一定是 10...0 的形式（1 后面跟 n 个 0）。

4. **模拟过程**（以 [9, 9] 为例）：
```
初始:    [9, 9]
处理末位: 9+1=10 → 置0, carry=1 → [9, 0]
处理倒2:  9+1=10 → 置0, carry=1 → [0, 0]
循环结束还有carry → 头部插入1 → [1, 0, 0]
```

5. **模拟过程**（以 [1, 2, 9] 为例）：
```
初始:    [1, 2, 9]
处理末位: 9+1=10 → 置0, carry=1 → [1, 2, 0]
处理倒2:  2+1=3 < 10 → 直接返回 → [1, 3, 0] ✓
```

## 解法详解

### 解法1: 通用进位模拟 — O(n) / O(1)

**思考过程**: 和竖式加法完全一致。用一个 carry 变量表示进位，从数组末尾往前扫。每一位做 `digit + carry`，取模得新值，整除得新 carry。循环结束如果还有 carry，在头部插入 1。

```cpp
class Solution {
public:
    vector<int> plusOne(vector<int>& digits) {
        int n = digits.size();
        int carry = 1; // 初始进位就是我们要加的那个 1
        
        for (int i = n - 1; i >= 0; i--) {
            int sum = digits[i] + carry;
            digits[i] = sum % 10;  // 当前位的新值
            carry = sum / 10;      // 传给更高位的进位
        }
        
        // 循环结束还有进位，说明原来全是9，需要扩展数组
        if (carry > 0) {
            digits.insert(digits.begin(), carry);
        }
        
        return digits;
    }
};
```

**关键点**: 这种写法是"加法的通用模板"，如果改成加任意数（不只是 1），只需修改初始 carry 值。适用于 LeetCode 2（两数相加）等题。

---

### 解法2: 提前终止优化 — O(n) / O(1) ⭐ 面试首选

**从解法1优化**: 解法1每次都要遍历完所有位。但实际上，一旦某一位加完 carry 后不产生新的进位（即 < 10），后面的高位全部不变，可以立即返回。

```cpp
class Solution {
public:
    vector<int> plusOne(vector<int>& digits) {
        int n = digits.size();
        
        // 从末尾往前，逐位处理进位
        for (int i = n - 1; i >= 0; i--) {
            digits[i] += 1;           // 加上进位（第一轮是+1，后续也是+1因为进位）
            
            if (digits[i] < 10) {
                return digits;        // 没有进位了，直接返回！
            }
            
            digits[i] = 0;           // 产生进位：当前位变0，继续往前传
            // 注意：这里不需要 carry 变量——因为能走到下一轮，进位一定是1
        }
        
        // 能走到这里，说明所有位都产生了进位（原来全是9）
        // 结果一定是 1 后面跟 n 个 0
        digits.insert(digits.begin(), 1);
        return digits;
    }
};
```

**关键点**: 
- 为什么不需要 carry 变量？因为我们加的是 1，进位也只可能是 1。只有当 `digits[i] == 10` 时才继续，而此时进位恰好就是 1。
- `digits.insert(digits.begin(), 1)` 是 O(n) 操作（需要移动所有元素），但只在全 9 时发生，实际几乎不触发。

---

### 解法3: 全9特判技巧 — O(n) / O(1)

**换个思路**: 利用一个观察——如果进位一直传播到最高位之前（即需要在前面加 1），那么原数一定是 999...9 的形式，结果一定是 1000...0。可以直接构造结果。

```cpp
class Solution {
public:
    vector<int> plusOne(vector<int>& digits) {
        int n = digits.size();
        
        for (int i = n - 1; i >= 0; i--) {
            if (digits[i] < 9) {
                digits[i]++;          // 不是9，加1就完事了
                return digits;
            }
            digits[i] = 0;           // 是9，变成0，继续
        }
        
        // 全是9的情况：构造一个 n+1 长度的数组
        // 第一位是1，其余全是0
        vector<int> result(n + 1, 0);
        result[0] = 1;
        return result;
    }
};
```

**关键点**: 这个写法避免了 `insert(begin(), 1)` 的 O(n) 元素移动开销（虽然两者整体都是 O(n)，但这个写法更干净）。判断条件从 `digits[i] + 1 < 10` 简化为 `digits[i] < 9`，因为我们加的始终是 1。

| 是否提前终止 | ❌ 每次遍历完 | ✅ 无进位即返回 | ✅ 无进位即返回 |

**面试建议**: 先写解法2，简洁且高效。如果面试官追问"如果加的不是 1 而是任意数呢？"，再转到解法1的通用模板。

## 易错点

1. **✗ 试图把数组转成数字再操作**:
```cpp
// 错误：100位数字会溢出 long long（最大约19位）
long long num = 0;
for (int d : digits) num = num * 10 + d;
num++;
```
✓ 必须在数组上原地模拟，不能转成数值类型。

2. **✗ 忘记处理全9进位的情况**:
```cpp
for (int i = n-1; i >= 0; i--) {
    digits[i]++;
    if (digits[i] < 10) return digits;
    digits[i] = 0;
}
return digits;  // 错误！[9,9] 会返回 [0,0] 而不是 [1,0,0]
```
✓ 循环结束后必须在头部插入 1，或者构造新数组 `[1, 0, ..., 0]`。

3. **✗ 遍历方向搞反，从高位开始加**:
```cpp
for (int i = 0; i < n; i++) // 错误：应该从 n-1 开始
```
✓ 加法从最低位（数组末尾）开始，`for (int i = n-1; i >= 0; i--)`。

4. **✗ insert 位置错误**:
```cpp
digits.insert(digits.end(), 1);  // 错误：插到了末尾
```
✓ 应该是 `digits.insert(digits.begin(), 1)`，进位是插在最高位（数组开头）。

## 面试追问

**Q1: 这道题的核心难点在哪？**
→ 不是加法本身，而是**进位的传播和终止**。大部分数加 1 不会进位，关键是处理连续 9 的情况。

**Q2: 如果不是加 1，而是加任意一位数 k（1-9），代码怎么改？**
→ 解法2中把第一次 `digits[i] += 1` 改成 `digits[i] += k`，后续进位仍然是 1，逻辑不变。

**Q3: 如果是两个大整数数组相加呢？（LeetCode 66 → LeetCode 2/415 的泛化）**
→ 用解法1的通用模板，同时遍历两个数组，`sum = a[i] + b[j] + carry`，模 10 得当前位，除 10 得进位。这就是 LeetCode 415（字符串相加）的思路。

**Q4: `insert(begin(), 1)` 的时间复杂度是什么？能优化吗？**
→ O(n)，因为要移动所有元素。可以用解法3的方式直接构造新数组 `vector<int>(n+1, 0); result[0]=1;` 避免移动。或者预先 `reserve` 空间，但 insert 本身的移动无法避免。
