# 470. Implement Rand10() Using Rand7() - 用 Rand7() 实现 Rand10()

## 题目理解

给定 API `rand7()`，等概率返回 `[1, 7]` 范围内的随机整数。要求实现 `rand10()`，等概率返回 `[1, 10]` 范围内的随机整数。

只能调用 `rand7()`，不能使用任何其他随机函数。

### 核心挑战

- `rand7()` 产生 7 种等概率结果
- 需要产生 10 种等概率结果
- 10 不整除 7，无法做简单直接的映射
- 必须保证**严格均匀分布**

### 约束

- `1 <= n <= 10^5`（n 是测试调用 rand10 的次数）

---

## 为什么不能直接映射？

```
rand7() 产生: {1, 2, 3, 4, 5, 6, 7}  各 1/7 概率

尝试 1: rand7() + rand7()
  范围 [2, 14]，但 P(sum=2)=1/49, P(sum=8)=7/49 → 分布不均匀!
  和的分布是"三角形"（类似掷两个骰子），不可用。

尝试 2: rand7() % 10 + 1
  7 种输入映射到 10 种输出 → 8, 9, 10 的概率为 0，不均匀!

结论: 7 种等概率结果无法直接均匀地分配到 10 个桶中。
```

---

## 核心思路: 拒绝采样 (Rejection Sampling)

**核心公式**: 用两次 `rand7()` 构造更大的均匀分布，然后截取 10 的倍数范围。

```
Step 1: (rand7() - 1) * 7 + rand7()  → [1, 49] 均匀分布 (49种)
Step 2: 只接受 [1, 40]，拒绝 [41, 49] 并重试
Step 3: (val - 1) % 10 + 1  → 映射到 [1, 10]
```

---

## 思维链 (Step-by-Step)

### Step 1: 扩大范围 — 7 进制编码

两次调用 `rand7()` 可以构造 7 * 7 = 49 种等概率组合：

```
row = rand7() - 1   → {0, 1, 2, 3, 4, 5, 6}
col = rand7()       → {1, 2, 3, 4, 5, 6, 7}
val = row * 7 + col → {1, 2, 3, ..., 49}

可视化 (7x7 网格, 每格概率 = 1/49):

        col = rand7()
        1   2   3   4   5   6   7
  r=0 | 1   2   3   4   5   6   7
  r=1 | 8   9  10  11  12  13  14
  r=2 |15  16  17  18  19  20  21
  r=3 |22  23  24  25  26  27  28
  r=4 |29  30  31  32  33  34  35
  r=5 |36  37  38  39  40 [41] [42]   ← 41-42 被拒绝
  r=6 |[43][44][45][46][47][48][49]   ← 43-49 全部被拒绝

49 种结果, 每种概率恰好 1/49 → 均匀分布!
```

本质: `(rand7()-1)` 是"高位"，`rand7()` 是"低位"，构成了一个 7 进制的两位数。

### Step 2: 截取 10 的倍数范围

```
49 种结果中需要选取 10 的倍数个，才能均匀映射到 [1, 10]

最大的 <= 49 的 10 的倍数 = 40

接受 [1, 40]  → 40种，拒绝 [41, 49] → 9种

映射:
  val ∈ [ 1, 10] → (val-1)%10+1 = {1,2,...,10}  各 4 种 val 对应
  val ∈ [11, 20] → 同上
  val ∈ [21, 30] → 同上
  val ∈ [31, 40] → 同上

每个目标值恰好对应 4 种源值 → P = 4/40 = 1/10 → 均匀!
```

### Step 3: 拒绝并重试

当 val 落入 [41, 49] 时，丢弃这次结果，重新调用两次 rand7() 再试。
用 `while(true)` 循环直到得到有效结果。

### Step 4: 概率分析

```
每轮:
  接受概率 p = 40/49 ≈ 81.6%
  拒绝概率   = 9/49  ≈ 18.4%

这是一个几何分布:
  P(第 k 轮成功) = (9/49)^(k-1) * (40/49)

期望轮数 = 1/p = 49/40 = 1.225 轮
每轮调用 2 次 rand7()
期望 rand7() 调用次数 = 2 * 49/40 = 2.45 次
```

### Step 5: 优化 — 利用被拒绝的值

被拒绝的 [41, 49] 包含 9 种等概率结果。这 9 种结果不应该浪费！

```
第一层: [1, 49] → 取 [1, 40], 拒绝 9 种
  被拒绝的 val - 40 ∈ [1, 9]

第二层: (val-41)*7 + rand7() → [1, 63]
  取 [1, 60] (60=10*6), 拒绝 [61, 63] 即 3 种

第三层: (val2-61)*7 + rand7() → [1, 21]
  取 [1, 20] (20=10*2), 拒绝 [21] 即 1 种

每层拒绝概率递减: 9/49 → 3/63 → 1/21
总拒绝概率: (9/49)*(3/63)*(1/21) ≈ 0.04%  → 几乎不会超过第三层
优化后期望 rand7() 调用 ≈ 2.19 次
```

---

## 均匀性数学证明

```
证明 (val - 1) % 10 + 1 在 [1, 10] 上均匀分布:

前提: val 在 [1, 40] 上均匀 (条件分布, 给定 val <= 40)

对于任意 target ∈ {1, 2, ..., 10}:
  满足 (val-1) % 10 + 1 == target 的 val 值:
  val = target, target+10, target+20, target+30
  共 4 个

P(result == target) = P(val=target) + P(val=target+10) + P(val=target+20) + P(val=target+30)
                    = 4 * (1/49) / (40/49)
                    = 4/40 = 1/10

对每个 target 都相同, 因此输出是均匀的。 QED
```

## 完整代码

### 解法一：基础拒绝采样（面试首选）

```cpp
// The rand7() API is already defined for you.
// int rand7();

class Solution {
public:
    int rand10() {
        while (true) {
            int row = rand7() - 1;   // [0, 6]
            int col = rand7();       // [1, 7]
            int val = row * 7 + col; // [1, 49], 49种等概率

            if (val <= 40) {
                return (val - 1) % 10 + 1; // [1, 10] 均匀
            }
            // val > 40: 拒绝, while 循环重试
        }
    }
};
```

### 解法二：优化拒绝采样（三层级联）

```cpp
class Solution {
public:
    int rand10() {
        while (true) {
            // 第一层: [1, 49], 取 [1, 40]
            int a = rand7(), b = rand7();
            int val = (a - 1) * 7 + b; // [1, 49]
            if (val <= 40) return (val - 1) % 10 + 1;

            // 第二层: 利用 9 种废弃值 + 新 rand7() → [1, 63]
            int c = rand7();
            val = (val - 40 - 1) * 7 + c; // [1, 63]
            if (val <= 60) return (val - 1) % 10 + 1;

            // 第三层: 利用 3 种废弃值 + 新 rand7() → [1, 21]
            int d = rand7();
            val = (val - 60 - 1) * 7 + d; // [1, 21]
            if (val <= 20) return (val - 1) % 10 + 1;
            // val=21: 极低概率, 回到 while 循环
        }
    }
};
```

## 关键提示序列

### Hint 1: 不能直接映射
> 7 种等概率结果无法均匀分配到 10 个桶中。10 不整除 7。

### Hint 2: 扩大范围
> 调用两次 rand7()，用 `(rand7()-1)*7 + rand7()` 构造 [1, 49] 的均匀分布（7 进制两位数）。

### Hint 3: 截取 10 的倍数
> 49 种中取前 40 种（40 = 10 * 4），每个 [1,10] 恰好对应 4 种源值，概率 = 4/40 = 1/10。

### Hint 4: 拒绝并重试
> [41, 49] 的 9 种结果被丢弃，while(true) 循环重新采样。

### Hint 5: 接受概率
> 每轮接受概率 40/49 ≈ 81.6%，期望 rand7() 调用次数 ≈ 2.45。

### Hint 6: 7 进制本质
> `(rand7()-1)*7 + rand7()` 等价于"高位 * 基数 + 低位"，这是 N 进制数的标准构造方式。每种组合等概率，正如十进制中 00-99 共 100 种等概率组合。

## 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| `rand7() + rand7()` | 和的分布是三角形，不均匀 | 用 `(rand7()-1)*7 + rand7()` |
| `rand7()*7 + rand7()` | 范围 [8, 56] 不是 [1, 49] | 第一个 rand7() 要减 1 |
| `val % 10 + 1` | 结果范围 [1, 10] 但不均匀（49%10 != 0） | 先截取 [1, 40] |
| 不做拒绝采样 | [1, 49] 直接 %10 不均匀 | 只接受 [1, 40] |

### 为什么 rand7() + rand7() 不均匀？

```
rand7() + rand7() 范围 [2, 14]

P(sum=2)  = 1/49   (只有 1+1)
P(sum=3)  = 2/49   (1+2, 2+1)
P(sum=8)  = 7/49   (1+7, 2+6, 3+5, 4+4, 5+3, 6+2, 7+1)
P(sum=14) = 1/49   (只有 7+7)

不同和的概率不同 → 不均匀! 和掷两个骰子一个道理。
```

## 信息论视角

```
rand7() 每次提供 log2(7) ≈ 2.807 bits 信息
rand10() 需要 log2(10) ≈ 3.322 bits

理论下界: 3.322 / 2.807 ≈ 1.183 次 rand7() 调用
基础方案: 2.45 次  (效率 ≈ 48%)
优化方案: 2.19 次  (效率 ≈ 54%)

差距来自拒绝采样浪费的信息 — [41,49] 的 9 种结果被丢弃了。
优化方案通过回收这些废弃值减少了浪费。
```

## 拓展：通用框架 randN() → randM()

**当 N < M 时**:
1. 构造 [1, N^2]：`(randN()-1)*N + randN()`
2. 找最大的 M 的倍数 k*M <= N^2
3. 接受 [1, k*M]，拒绝 [k*M+1, N^2]
4. `(val-1) % M + 1`

**当 N > M 时**（如 rand7 → rand5）:
- 直接拒绝采样：val = rand7()，只取 [1, 5]，拒绝 [6, 7]

## 面试追问

1. **期望调用次数是多少？** 基础版：每轮接受概率 40/49，期望轮数 49/40=1.225，每轮 2 次 rand7()，总计 2.45 次。优化版约 2.19 次。

2. **如何减少 rand7() 调用？** 三层级联优化：被拒绝的 [41,49] 有 9 种结果，与新的 rand7() 组合得 [1,63]，取 [1,60]；再拒绝的 3 种组合得 [1,21]，取 [1,20]。每层拒绝概率递减。

3. **信息论下界**：rand7() 提供 log2(7) ~ 2.807 bits，rand10() 需要 log2(10) ~ 3.322 bits，理论最少 1.183 次调用，但拒绝采样无法达到。

4. **通用框架 randN -> randM**：当 N < M 时，`(randN()-1)*N + randN()` 构造 [1, N^2]，截取 M 的最大倍数，取模映射。当 N > M 时，直接拒绝采样（如 rand7 -> rand5 只取 [1,5]）。
