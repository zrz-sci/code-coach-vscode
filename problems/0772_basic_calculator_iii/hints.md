# 772. 基本计算器 III

## 核心思路

这道题本质上是**实现一个支持四则运算和括号的表达式求值器**。核心挑战在于正确处理运算符优先级（`*`/`/` 优先于 `+`/`-`）和括号（括号内的子表达式先求值）。

## 思维链

1. **读完题第一反应**：这是 Basic Calculator 系列的综合版。224题只有 `+`/`-` 和括号，227题有 `+`/`-`/`*`/`/` 但无括号，772题全都有。能不能把两道题的技巧合并？

2. **回顾227题（无括号）的核心技巧**：用一个栈来处理优先级——遇到 `+`/`-` 时把数字（带符号）压栈，遇到 `*`/`/` 时立即和栈顶运算。最后栈里全是加减项，求和即可。

3. **括号怎么处理？** 括号的作用是"把一段子表达式当成一个数字"。所以遇到 `(` 时，我们需要**暂停当前计算，进入子表达式**；遇到 `)` 时，**子表达式求值完毕，把结果当成一个数字返回给外层**。

4. **两种实现方式**：
   - **递归法**：遇到 `(` 就递归调用自己处理子表达式，遇到 `)` 就返回。最自然。
   - **双栈法**：用一个数字栈和一个运算符栈，遇到 `(` 时在运算符栈打标记，遇到 `)` 时回退到标记位。经典的操作符优先级解析。

5. **递归法的细节**：用一个全局索引 `i` 遍历字符串。`calc()` 函数处理一个"层级"的表达式（到字符串末尾或遇到 `)` 结束）。内部逻辑复用227题的栈方法处理 `+`/`-`/`*`/`/`。

6. **双栈法的细节**：运算符优先级数值化（`+`/`-` = 1, `*`/`/` = 2）。新运算符入栈前，先把栈里优先级 >= 它的运算符都算掉。`(` 作为特殊标记入运算符栈，`)` 时算到 `(` 为止。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 递归 + 栈 | 遇括号递归，内部用227的栈法 | O(n) | O(n) | ⭐ 必须写出 |
| 双栈法 | 数字栈+运算符栈，优先级驱动 | O(n) | O(n) | ⭐ 必须写出 |
| 转后缀表达式 | 先转逆波兰，再求值 | O(n) | O(n) | 加分项 |

## 关键提示

1. **从 227 题出发**：如果你会做 227（无括号的 `+`/`-`/`*`/`/`），那 772 只需要加一层"括号处理"。先确保你理解 227 的栈方法。

2. **括号 = 递归子问题**：把 `(...)` 内部看作一个完整的子表达式，求值后返回一个数字。这天然适合递归。

3. **全局索引 vs 传参**：递归时需要一个"位置指针"让调用者和被调用者共享进度。用引用参数 `int& i` 或类成员变量。

4. **运算符优先级处理的关键**：`*`/`/` 要立即和前一个数运算，`+`/`-` 暂时不运算。这就是为什么用栈——栈顶存的是"待决定"的项。

5. **处理多位数字**：不要忘了数字可能有多位，需要 `while (isdigit(s[i]))` 循环累加。

```
表达式: 2*(5+5*2)/3+(6/2+8)

递归调用结构:
calc("2*(5+5*2)/3+(6/2+8)")
  │
  ├── 解析 2, 遇到 *
  ├── 遇到 ( → 递归 calc("5+5*2")
  │         ├── 5, +, 5, *, 2
  │         ├── 栈: [5, 10] → sum=15
  │         └── 返回 15
  ├── 2*15=30, 遇到 /, 解析 3 → 30/3=10
  ├── 遇到 +
  ├── 遇到 ( → 递归 calc("6/2+8")
  │         ├── 6, /, 2 → 3, +, 8
  │         ├── 栈: [3, 8] → sum=11
  │         └── 返回 11
  ├── 栈: [10, 11] → sum=21
  └── 返回 21
```

## 解法详解

### 解法1: 递归 + 栈 — O(n) / O(n) ⭐ 面试首选

**思考过程**：这是 227 题的自然延伸。227 题中我们用一个栈处理 `*`/`/` 的优先级：遇到 `*`/`/` 时立即运算，遇到 `+`/`-` 时暂存。现在加了括号，括号内是一个完整子表达式——递归求值后把结果当数字用就行。

用一个类成员变量 `i` 作为全局游标，`calc()` 函数处理一段表达式直到遇到 `)` 或字符串末尾。

```cpp
class Solution {
public:
    int i = 0; // 全局游标，递归共享
    
    int calculate(string s) {
        i = 0;
        return calc(s);
    }
    
    int calc(string& s) {
        stack<int> stk;
        int num = 0;
        char op = '+'; // 当前数字前面的运算符，初始为+
        
        while (i < s.size()) {
            char c = s[i++];
            
            if (isdigit(c)) {
                num = num * 10 + (c - '0'); // 处理多位数
            }
            
            if (c == '(') {
                num = calc(s); // 递归求括号内的值，当作一个数字
            }
            
            // 遇到运算符或字符串末尾或右括号，处理之前的 num
            if ((!isdigit(c) && c != ' ') || i == s.size()) {
                if (op == '+') stk.push(num);
                else if (op == '-') stk.push(-num);
                else if (op == '*') { int t = stk.top(); stk.pop(); stk.push(t * num); }
                else if (op == '/') { int t = stk.top(); stk.pop(); stk.push(t / num); }
                
                op = c;   // 更新运算符
                num = 0;  // 重置数字
            }
            
            if (c == ')') break; // 子表达式结束，返回给上层
        }
        
        int result = 0;
        while (!stk.empty()) { result += stk.top(); stk.pop(); }
        return result;
    }
};
```

**关键点**：
- `op` 初始化为 `'+'`，这样第一个数字会被当作 `+num` 压栈。
- 遇到 `(` 时递归，递归返回时 `i` 已经指向 `)` 之后（因为在循环里 `i++` 了）。
- `break` on `)` 确保子表达式只算到右括号为止。

### 解法2: 双栈法（运算符栈 + 数字栈）— O(n) / O(n)

**从解法1的角度看**：递归本质上是用"调用栈"来保存外层状态。我们可以显式用两个栈来模拟：一个存数字，一个存运算符。遇到 `(` 当作标记入运算符栈，遇到 `)` 回退到 `(`。

运算符优先级：`*`/`/` > `+`/`-`。**新运算符入栈前，把栈中优先级 >= 它的运算符先算掉**，保证高优先级先执行。

```cpp
class Solution {
public:
    int calculate(string s) {
        stack<int> nums;
        stack<char> ops;
        
        int i = 0, n = s.size();
        
        // 辅助函数：取栈顶两个数和一个运算符，计算并压回
        auto apply = [&]() {
            int b = nums.top(); nums.pop(); // 注意顺序：b在栈顶，是右操作数
            int a = nums.top(); nums.pop();
            char op = ops.top(); ops.pop();
            if (op == '+') nums.push(a + b);
            else if (op == '-') nums.push(a - b);
            else if (op == '*') nums.push(a * b);
            else nums.push(a / b);
        };
        
        auto precedence = [](char op) -> int {
            if (op == '+' || op == '-') return 1;
            if (op == '*' || op == '/') return 2;
            return 0; // '(' 优先级最低，不会被误弹
        };
        
        while (i < n) {
            if (s[i] == ' ') { i++; continue; }
            
            if (isdigit(s[i])) {
                int num = 0;
                while (i < n && isdigit(s[i]))
                    num = num * 10 + (s[i++] - '0');
                nums.push(num);
            }
            else if (s[i] == '(') {
                ops.push('(');
                i++;
            }
            else if (s[i] == ')') {
                // 算到匹配的 '(' 为止
                while (ops.top() != '(') apply();
                ops.pop(); // 弹出 '('
                i++;
            }
            else {
                // 是运算符：先把栈中优先级 >= 当前的算掉
                while (!ops.empty() && ops.top() != '(' 
                       && precedence(ops.top()) >= precedence(s[i])) {
                    apply();
                }
                ops.push(s[i]);
                i++;
            }
        }
        
        // 处理剩余运算符
        while (!ops.empty()) apply();
        
        return nums.top();
    }
};
```

**关键点**：
- `apply()` 中取操作数的顺序：先 pop 的是 b（右操作数），后 pop 的是 a（左操作数）。搞反了减法和除法就错了。
- `(` 的优先级设为 0，确保它不会在普通运算符入栈时被弹出，只在遇到 `)` 时被匹配。
- `>=` 而不是 `>`：同优先级的运算符从左到右结合，所以 `6-4-2` 应该先算 `6-4` 再算 `2-2`。

### 解法3: 转后缀表达式（逆波兰表达式）再求值 — O(n) / O(n)

**思路**：经典的两步法。先用 Shunting-Yard 算法把中缀表达式转成后缀表达式（无括号，运算顺序已确定），再用栈对后缀表达式求值（就是 LeetCode 150 题）。

本质上和解法2是同一个算法，只是拆成了两步。面试中一般不需要这么写，但理解它有助于理解编译原理。

```cpp
class Solution {
public:
    int calculate(string s) {
        // Step 1: 中缀转后缀 (Shunting-Yard)
        vector<string> postfix;
        stack<char> ops;
        int n = s.size();
        
        auto prec = [](char c) { return (c == '*' || c == '/') ? 2 : 1; };
        
        for (int i = 0; i < n; ) {
            if (s[i] == ' ') { i++; continue; }
            if (isdigit(s[i])) {
                string num;
                while (i < n && isdigit(s[i])) num += s[i++];
                postfix.push_back(num);
            } else if (s[i] == '(') {
                ops.push('('); i++;
            } else if (s[i] == ')') {
                while (ops.top() != '(') {
                    postfix.push_back(string(1, ops.top())); ops.pop();
                }
                ops.pop(); // 弹出 '('
                i++;
            } else {
                while (!ops.empty() && ops.top() != '(' && prec(ops.top()) >= prec(s[i])) {
                    postfix.push_back(string(1, ops.top())); ops.pop();
                }
                ops.push(s[i]); i++;
            }
        }
        while (!ops.empty()) {
            postfix.push_back(string(1, ops.top())); ops.pop();
        }
        
        // Step 2: 后缀表达式求值 (LC 150)
        stack<int> stk;
        for (auto& token : postfix) {
            if (token == "+" || token == "-" || token == "*" || token == "/") {
                int b = stk.top(); stk.pop();
                int a = stk.top(); stk.pop();
                if (token == "+") stk.push(a + b);
                else if (token == "-") stk.push(a - b);
                else if (token == "*") stk.push(a * b);
                else stk.push(a / b);
            } else {
                stk.push(stoi(token));
            }
        }
        return stk.top();
    }
};
```

## 解法对比

| | 解法1: 递归+栈 | 解法2: 双栈 | 解法3: 转后缀 |
|---|---|---|---|
| 核心思想 | 括号→递归，优先级→栈 | 所有状态显式用栈管理 | 先消除括号和优先级，再简单求值 |
| 代码量 | 最少 | 中等 | 最多 |
| 可读性 | 最好（递归自然表达嵌套结构） | 中等 | 两步分离，逻辑清晰但代码长 |
| 面试推荐 | ⭐ 首选 | ⭐ 备选（面试官可能追问非递归） | 加分项（编译原理背景） |
| 与系列题关系 | 227题加一层递归即可 | 224题加优先级即可 | 和 LC 150 结合 |

## 易错点

1. **运算符 `op` 的初始值必须是 `'+'`**
   - ✗ `char op = 0;` → 第一个数字不知道带什么符号入栈
   - ✓ `char op = '+';` → 第一个数字作为正数入栈

2. **双栈法中 `apply()` 操作数顺序搞反**
   - ✗ `int a = nums.top(); nums.pop(); int b = nums.top(); nums.pop();` → `a` 是右操作数但当成了左操作数
   - ✓ 先 pop 的是 `b`（右操作数），后 pop 的是 `a`（左操作数）
   - 对 `+` 和 `*` 无影响（交换律），但 `-` 和 `/` 会算错：`6-4` 变成 `4-6`

3. **递归法中 `(` 和运算符的处理顺序**
   - ✗ 在 `if (c == '(')` 中用 `else if`，导致括号后面的运算符触发"处理前一个num"逻辑时 num 已经被递归覆盖
   - ✓ `if (c == '(')` 先处理（设置 num），然后让后面的统一处理逻辑正常运行

4. **多位数字解析时忘了 `i` 自增**
   - ✗ 在双栈法中用 `for(int i=0; i<n; i++)` 然后内部又 `while(isdigit(s[i])) i++`，导致多加了一次
   - ✓ 外层 `while(i<n)` 手动控制 `i`

5. **整数除法截断方向**
   - C++ 的 `/` 对负数是向零截断（truncate toward zero），题目要求也是向零截断，所以直接用 `/` 就行
   - ✗ 用 `floor()` → 对负数 `-7/2` 得到 `-4` 而不是 `-3`

## 面试追问

**Q1: 如果只有 `+`/`-` 和括号（即 LC 224），你怎么做？**
→ 更简单：不需要栈来处理优先级，只需要维护一个 `sign` 和 `result`。遇到 `(` 把当前 result 和 sign 压栈，遇到 `)` 弹出恢复。

**Q2: 如果只有 `+`/`-`/`*`/`/` 没有括号（即 LC 227），你怎么做？**
→ 就是本题解法1中 `calc()` 函数去掉括号处理的部分。用一个栈，`*`/`/` 立即算，`+`/`-` 压栈延迟。

**Q3: 如果表达式可能有一元负号，如 `"-2+3"` 或 `"1+(-2)"` ，怎么处理？**
→ 在解析数字之前，检测当前位置的 `-` 是一元还是二元运算符。一元的情况：字符串开头、`(` 后面。此时把 `0` 作为左操作数插入即可（即 `-2` 变成 `0-2`）。

**Q4: 如果要支持浮点数怎么改？**
→ 数字解析部分加一个小数点处理逻辑，`int` 改成 `double`，除法不再需要截断。

**Q5: 如果表达式非常长且需要流式处理（不能一次性读入内存），递归法还能用吗？**
→ 递归法需要回溯所以不太适合纯流式处理。双栈法天然支持流式：每读一个 token 就处理，不需要全局索引。

## 相关题型

- **224. 基本计算器** — 只有 `+`/`-` 和括号。是 772 的子问题。复用递归框架，但不需要栈处理优先级（因为只有同优先级运算符）。
- **227. 基本计算器 II** — 有 `+`/`-`/`*`/`/` 但无括号。是 772 的子问题。复用栈处理优先级的技巧，但不需要递归。**772 = 227 + 括号递归**。
- **150. 逆波兰表达式求值** — 后缀表达式求值。是解法3的第二步。纯栈操作，没有优先级和括号问题。
- **394. 字符串解码** — 也是嵌套括号+递归的模式。复用"遇到 `[` 递归，遇到 `]` 返回"的框架。
