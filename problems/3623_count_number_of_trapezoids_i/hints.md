# 3623. 统计梯形的数目 I (Count Number of Trapezoids I)

## 难度: Medium | 标签: Geometry, Array, Hash Table, Math

---

## 题目理解

给定 2D 平面上的点数组 `points`，要求计算能组成**水平梯形**的四个点的方案数。

**水平梯形**的定义：
- 凸四边形
- **至少有一对水平边**（平行于 x 轴的边）
- 两条线平行当且仅当它们斜率相同

**关键观察**：
- "水平边" = 两个端点的 y 坐标相同
- "至少一对水平边" = 从同一 y 层取 2 个点形成水平边
- 需要从**两个不同的 y 层**各取 2 个点，才能形成四边形
- 答案对 10^9 + 7 取模

---

## 思维链

```
1. 读完题 --> 水平梯形 = 至少一对水平边的凸四边形
   水平边 = 两端点 y 坐标相同

2. 什么样的四个点构成水平梯形?
   - 从 y 层 y1 选 2 个点: (x1, y1), (x2, y1)  -> 上底 / 下底
   - 从 y 层 y2 选 2 个点: (x3, y2), (x4, y2)  -> 另一条边
   - y1 != y2 时，这两条水平线段构成梯形的两条平行边
   - 这四个点构成的四边形一定有至少一对水平边 -> 是水平梯形!

3. 会不会有非凸的情况?
   - 从两个不同 y 层各选 2 点，四点共面
   - 只要不退化(四点共线)，总能形成凸四边形
   - 四点来自两个不同 y 层 -> 不会四点共线
   - 但上底和下底可能重叠? 不会，y1 != y2

4. 计数:
   - 对每个 y 层, 有 c 个点, 可选 C(c, 2) 对水平边
   - 对任意两个 y 层 (y1, y2), 方案数 = C(c1, 2) * C(c2, 2)
   - 答案 = sum_{所有 y 层对} C(c1, 2) * C(c2, 2)

5. 优化求和:
   设 v_i = C(c_i, 2) 对每个 y 层
   sum_{i<j} v_i * v_j = (( sum v_i )^2 - sum v_i^2) / 2

   设 S = sum(v_i), Q = sum(v_i^2)
   答案 = (S^2 - Q) / 2

6. 模运算:
   除以 2 需要乘以 2 的模逆元
   inv2 = (MOD + 1) / 2 = 500000004 (当 MOD = 10^9 + 7)
```

## 解法一: 按 y 分组 + 组合计数 -- O(n) / O(n) 【推荐】

### 核心思路

```
Step 1: 按 y 坐标分组，统计每层点数
  y -> count
  例: points = [[1,0],[2,0],[3,0],[2,2],[3,2]]
  y=0 -> 3 个点
  y=2 -> 2 个点

Step 2: 计算每层的组合数 v_i = C(count_i, 2)
  y=0: v = C(3,2) = 3
  y=2: v = C(2,2) = 1

Step 3: 所有层对的乘积之和
  只有一对: (y=0, y=2) -> 3 * 1 = 3
  答案 = 3

通用公式 (多层时):
  S = v_1 + v_2 + ... + v_k
  Q = v_1^2 + v_2^2 + ... + v_k^2
  答案 = (S^2 - Q) / 2 mod (10^9 + 7)
```

### 图解

```
例 1: points = [[1,0],[2,0],[3,0],[2,2],[3,2]]

y=2:  .  *  *        (2个点, C(2,2) = 1 条水平线段)
      |
y=0:  *  *  *        (3个点, C(3,2) = 3 条水平线段)
      1  2  3

可能的梯形:
  上底从 y=2 选: {(2,2),(3,2)}  (1种)
  下底从 y=0 选: {(1,0),(2,0)}, {(1,0),(3,0)}, {(2,0),(3,0)}  (3种)
  总计: 1 * 3 = 3 个梯形 ✓

例 2: points = [[0,0],[1,0],[0,1],[2,1]]

y=1:  *     *        (2个点, C(2,2) = 1)
y=0:  *  *           (2个点, C(2,2) = 1)
      0  1  2

梯形数 = 1 * 1 = 1 ✓


多层示例:
假设 3 层: v1=3, v2=2, v3=4

S = 3 + 2 + 4 = 9
Q = 9 + 4 + 16 = 29
答案 = (81 - 29) / 2 = 26

验证: 3*2 + 3*4 + 2*4 = 6 + 12 + 8 = 26 ✓
```

### 代码

```cpp
class Solution {
public:
    int countTrapezoids(vector<vector<int>>& points) {
        const int MOD = 1e9 + 7;
        unordered_map<int, long long> cnt;
        for (auto& p : points) cnt[p[1]]++;

        long long S = 0, Q = 0;
        for (auto& [y, c] : cnt) {
            long long v = c * (c - 1) / 2 % MOD;
            S = (S + v) % MOD;
            Q = (Q + v % MOD * (v % MOD)) % MOD;
        }

        long long ans = (S % MOD * (S % MOD) % MOD - Q + MOD) % MOD;
        long long inv2 = (MOD + 1) / 2;
        ans = ans % MOD * inv2 % MOD;
        return (int)ans;
    }
};
```

## 数学推导详解

### 为什么 sum_{i<j} v_i * v_j = (S^2 - Q) / 2 ?

```
S^2 = (v_1 + v_2 + ... + v_k)^2

展开:
S^2 = sum_i v_i^2  +  2 * sum_{i<j} v_i * v_j
    = Q  +  2 * (我们要求的)

所以:
sum_{i<j} v_i * v_j = (S^2 - Q) / 2

这个恒等式在组合计数中非常常用!
```

### 模逆元

```
在模运算中 "除以 2" = "乘以 2 的模逆元"

2 的模逆元: 满足 2 * inv2 ≡ 1 (mod MOD) 的 inv2

当 MOD 是奇素数时:
  inv2 = (MOD + 1) / 2

验证: 2 * (10^9 + 8) / 2 = 10^9 + 8 ≡ 1 (mod 10^9 + 7) ✓

或者用费马小定理:
  inv2 = pow(2, MOD - 2, MOD)
```

| 5 | 模运算中如何除以 2？ | 乘以 2 的模逆元 |

## 易错点

1. **同一 y 层不能单独成梯形**
   - 必须从**两个不同的** y 层各选 2 点
   - 四个点全在同一 y 层 -> 退化为线段，不是梯形

2. **C(c, 2) 的溢出**
   - c 可达 10^5，C(c, 2) 可达约 5 * 10^9
   - 必须用 long long

3. **模运算的顺序**
   - `c * (c - 1) / 2` 中先除 2 再取模（因为 c*(c-1) 一定是偶数）
   - 或者先取模再乘模逆元
   - 注意 `v * v` 可能溢出，要先取模

4. **S^2 - Q 可能为负（模意义下）**
   - `(S * S % MOD - Q % MOD + MOD) % MOD` 加 MOD 防负

5. **点可能只有一个 y 层**
   - 如果所有点 y 坐标相同，没有两层 -> 答案为 0
   - S^2 = Q -> 结果自然为 0

6. **凸性**
   - 从两个不同 y 层各取 2 点，自动形成凸四边形
   - 不需要额外检查凸性

## 面试追问

1. **如果梯形不限于水平（允许任意方向的平行边），怎么做？**
   - 不再只按 y 分组，而是枚举所有点对的斜率
   - 将同斜率的线段分组，再用相同的组合计数思路
   - 斜率用 `(dy, dx)` 的最简分数表示避免浮点误差
   - 时间复杂度升至 O(n^2)

2. **如果要求是平行四边形而非梯形（两对平行边），怎么改？**
   - 需要从答案中减去"只有一对平行边"的情况
   - 或者直接枚举: 两层各取 2 点，且线段等长且中点重合
   - 经典几何计数，可用中点哈希实现 O(n^2)

3. **(S^2 - Q) / 2 这个公式还能用在哪些场景？**
   - 任何"枚举所有无序对 (i,j) 的 `f(i)*f(j)` 之和"都能用
   - 例: 数组中所有两数之积的总和 = `(S^2 - sum(a_i^2)) / 2`
   - 核心: 展开 `(sum v_i)^2 = sum v_i^2 + 2*sum_{i<j} v_i*v_j`

## 面试技巧

1. **先画图**: 在纸上画出几个点，标注 y 层，直观理解"水平梯形"
2. **推导公式**: 从暴力 O(Y^2) 双循环出发，推导出 (S^2 - Q) / 2 优化
3. **模运算三连**: 取模、防负、模逆元，展示对数论的掌握
4. **讨论边界**: 不足两层时答案为 0，某层只有 1 个点时 C(1,2) = 0
