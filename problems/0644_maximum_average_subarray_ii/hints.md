# 644. 子数组最大平均数 II (Maximum Average Subarray II)

**难度**: Hard | **标签**: Array, Binary Search, Prefix Sum

## 核心思路

本题要求找到长度 >= k 的连续子数组，使其平均值最大。暴力枚举所有可能长度的子数组是 O(n^2)，不够高效。关键洞察是：**平均值的答案具有单调性**——如果存在一个子数组的平均值 >= mid，那么对于任何 mid' < mid，同样存在。因此可以**二分搜索答案**，将优化问题转化为判定问题。

核心转化：对于一个猜测的平均值 mid，将每个元素减去 mid，问题变为"是否存在长度 >= k 的子数组，其和 >= 0？"。这是一个经典的前缀和 + 滑动窗口问题。

## 思维链

1. **观察答案范围**：最大平均值一定在 [min(nums), max(nums)] 之间
2. **二分答案**：猜测一个平均值 mid，判断是否可行
3. **转化为子数组和问题**：每个元素减去 mid 后，判断是否存在长度 >= k 的子数组和 >= 0
4. **前缀和优化判定**：计算前缀和数组，对于每个位置 i (i >= k)，我们需要 prefixSum[i] - min(prefixSum[0..i-k]) >= 0
5. **维护最小前缀和**：用一个变量追踪 prefixSum[0..i-k] 的最小值，O(n) 完成判定
6. **收敛精度**：二分迭代直到精度满足 1e-5

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 二分答案 + 前缀和 | O(n log(max-min)/eps) | O(1) | 最优解法，思维巧妙 |
| 暴力枚举 | O(n^2) | O(1) | 简单但超时 |

## 关键提示

1. **二分搜索答案的经典范式**：当答案本身具有单调性时，可以二分答案，将优化问题转化为判定问题
2. **减去 mid 的技巧**：将"平均值 >= mid"转化为"和 >= 0"，这是处理平均值问题的标准手法
3. **前缀和的最小值维护**：对于位置 i，我们只关心 prefixSum[0..i-k] 的最小值，不需要完整的单调队列
4. **浮点数二分的终止条件**：通常用 `right - left > 1e-5` 或固定迭代次数（如 100 次）
5. **初始边界**：left = min(nums), right = max(nums)，确保答案在范围内

## 解法详解

### 解法：二分答案 + 前缀和判定

**第一步：确定二分范围**
- 最大平均值不可能小于数组最小值，也不可能大于数组最大值
- 设 left = min(nums), right = max(nums)

**第二步：二分判定函数 check(mid)**
- 构造新数组 b[i] = nums[i] - mid
- 计算 b 的前缀和 prefixSum
- 对于每个 i >= k，检查 prefixSum[i] - min(prefixSum[0..i-k]) >= 0
- 关键：维护一个变量 minPrev 追踪 prefixSum[0] 到 prefixSum[i-k] 的最小值
- 如果存在任何满足条件的位置，说明 mid 可行

**第三步：二分收敛**
- 如果 check(mid) 返回 true，说明答案 >= mid，令 left = mid
- 否则令 right = mid
- 当 right - left < 1e-5 时停止

**为什么维护最小前缀和是正确的？**
- 我们需要找到长度 >= k 的子数组 [j+1, i] 使得 sum(b[j+1..i]) >= 0
- 即 prefixSum[i] - prefixSum[j] >= 0，其中 i - j >= k，即 j <= i - k
- 要让 prefixSum[i] - prefixSum[j] 最大，就需要 prefixSum[j] 最小
- 因此只需维护 prefixSum[0..i-k] 的最小值

## 易错点

1. **前缀和索引对齐**：prefixSum[0] = 0，prefixSum[i] = sum(b[0..i-1])，注意 0-indexed 和 1-indexed 的区别
2. **最小值更新时机**：在检查 prefixSum[i] 时，最小值只能包含 prefixSum[0] 到 prefixSum[i-k]，不能过早更新
3. **浮点精度**：使用 double 进行计算，二分终止条件设为 1e-5 或更小
4. **初始化 minPrev**：应初始化为 0.0（对应空前缀 prefixSum[0] = 0），不是 INT_MAX
5. **长度约束**：是 >= k 而非 == k，确保从 i = k 开始检查（子数组最短长度为 k）

## 面试追问

1. **Q: 为什么可以二分搜索平均值？**
   A: 因为判定函数具有单调性：如果存在平均值 >= mid 的子数组，那么对任何 mid' < mid 同样存在。答案从"存在"变为"不存在"有一个明确的分界点。

2. **Q: 时间复杂度中 log 部分的底是什么？**
   A: 是 log((max-min)/eps)，其中 eps = 1e-5。对于值域 [-10^4, 10^4]，大约是 log2(2*10^9) 约 31 次迭代。

3. **Q: 如果要求长度恰好等于 k 怎么办？**
   A: 那就是 LeetCode 643 (Maximum Average Subarray I)，直接用固定长度滑动窗口即可，O(n) 时间。

4. **Q: 能否用单调队列/单调栈优化？**
   A: 在本题中不需要，因为我们只需要前缀和的全局最小值（在合法范围内），一个变量就够了。如果约束是 k <= length <= m（有上界），则需要单调队列。

5. **Q: 这个二分答案的技巧还能用在哪些题目？**
   A: 最小化最大值/最大化最小值问题、分割数组的最大值 (410)、最大化路径的最小值等。
