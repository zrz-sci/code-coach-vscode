# 343. 整数拆分

## 核心思路

本质上问的是：把一个正整数 n 拆成若干个正整数之和，怎样拆才能使乘积最大？这是一个**最优子结构**问题 —— 每次拆分的决策会影响后续的最优解。

## 思维链

1. **读完题的第一反应**：n 可以拆成 2 个、3 个、...、n 个正整数，每种拆法对应一个乘积，要找最大的。最朴素的想法是枚举所有拆法。

2. **怎么枚举所有拆法？** 用递归：从 n 中拆出一个数 j（1 ≤ j ≤ n-1），剩下 n-j 可以选择**继续拆**或**不拆**。这就是一个递归结构。

3. **暴力递归的瓶颈**：大量重复计算。比如 `integerBreak(7)` 会多次计算 `integerBreak(4)`。这是经典的**重叠子问题** → 用 DP 或记忆化搜索。

4. **状态转移怎么定义？** `dp[i]` = 将正整数 i 拆分后的最大乘积。对于每个 i，枚举第一刀拆出 j，剩下 i-j 有两种选择：
   - 不再拆：乘积 = `j * (i-j)`
   - 继续拆：乘积 = `j * dp[i-j]`
   - 取两者的最大值。

5. **能不能不用 DP？** 可以！数学分析发现：**尽量拆出 3** 是最优策略。因为 2 和 3 是最优的"拆分因子"，而 3 比 2 更优（3×3 > 2×2×2 = 9 > 8）。

6. **数学解法的边界**：n=2 返回 1，n=3 返回 2（必须至少拆成 2 份），n=4 返回 4（拆成 2+2 比 3+1 好）。n≥5 时尽量拆 3。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力递归 | 枚举所有拆法 | O(n!) | O(n) 递归栈 | 能说出即可 |
| 动态规划 | dp[i] = max(j*(i-j), j*dp[i-j]) | O(n²) | O(n) | ⭐ 必须写出 |
| 数学贪心 | 尽量拆出3 | O(1) | O(1) | 加分项 |

## 关键提示

1. **"拆"还是"不拆"是关键**：拆出 j 后，剩下的 `i-j` 可以选择保持原样（不拆），也可以继续拆（用 dp[i-j]）。很多人漏掉了 `j * (i-j)` 这个不拆的情况。

2. **j 的枚举范围**：j 从 1 到 i-1 就够了（保证至少拆成 2 份），实际上 j 只需要到 i/2（对称性）。

3. **数学直觉**：试几个小例子：
   - 6 = 3+3 → 9；6 = 2+2+2 → 8；所以 3 比 2 好
   - 任何 ≥5 的因子都应该继续拆（5 = 2+3, 2×3=6 > 5）
   - 4 不拆和拆成 2+2 乘积一样（4 vs 2×2=4）
   - 1 绝对不能出现在拆分中（乘 1 不增加乘积）

4. **DP 填表过程**：
   ```
   i:    2  3  4  5  6  7  8  9  10
   dp:   1  2  4  6  9  12 18 27 36
   
   dp[4] = max(1×3, 1×dp[3], 2×2, 2×dp[2], 3×1, 3×dp[1]) = max(3,2,4,2,3,3) = 4
   dp[5] = max(1×4, 1×dp[4], 2×3, 2×dp[3], ...) = max(4,4,6,4,...) = 6
   ```

5. **为什么 dp[2]=1 而不是 2？** 因为题目要求至少拆成 2 份，2=1+1，乘积是 1。但 dp[i-j] 用到 dp[2] 时，是允许 "2 本身不拆" 的 —— 这就是为什么转移方程中要同时考虑 `j*(i-j)` 和 `j*dp[i-j]`。

## 解法详解

### 解法1: 暴力递归 — O(n!) / O(n)

**思考过程**：最自然的想法是递归 —— 每次拆出一个数 j，对剩余部分递归求解。这里的关键是"剩余部分可拆可不拆"。

```cpp
class Solution {
public:
    int integerBreak(int n) {
        // base case: n=1 时不能再拆，返回 1
        // 但注意：这里的递归函数含义是"i 拆分后的最大乘积"
        // 外层要求至少拆成2份，内层的子问题可以选择不拆
        int maxProduct = 0;
        for (int j = 1; j < n; j++) {
            // 两种选择：
            // 1. j * (n-j): 剩余部分 n-j 不再拆分
            // 2. j * integerBreak(n-j): 剩余部分继续拆
            maxProduct = max(maxProduct, max(j * (n - j), j * integerBreak(n - j)));
        }
        return maxProduct;
    }
};
```

**关键点**：这个递归有大量重复计算，比如 `integerBreak(5)` 会被不同的调用路径重复计算多次。

---

### 解法2: 动态规划 — O(n²) / O(n) ⭐ 面试首选

**从解法1优化**：暴力递归的瓶颈是重叠子问题。用 dp 数组自底向上填表，每个子问题只算一次。

**状态定义**：`dp[i]` = 正整数 i 拆分成至少 2 个正整数之和后的最大乘积。

**状态转移**：
```
dp[i] = max over j in [1, i-1] of { max(j * (i-j), j * dp[i-j]) }
```
- `j * (i-j)`: 只拆成 j 和 (i-j) 两份
- `j * dp[i-j]`: 拆出 j，剩下的 i-j 继续最优拆分

```
// DP 填表过程 (以 n=10 为例):
//
// dp[2] = max(1×1) = 1
// dp[3] = max(1×2, 1×dp[2], 2×1, 2×dp[1]) = max(2, 1, 2, 2) = 2
// dp[4] = max(1×3, 1×dp[3], 2×2, 2×dp[2], 3×1, 3×dp[1])
//       = max(3, 2, 4, 2, 3, 3) = 4
// dp[5] = max(..., 2×3, 2×dp[3], 3×2, 3×dp[2], ...)
//       = max(..., 6, 4, 6, 3, ...) = 6
// dp[6] = max(..., 3×3, 3×dp[3], ...) = max(..., 9, 6, ...) = 9
// dp[7] = max(..., 3×4, 3×dp[4], ...) = max(..., 12, 12, ...) = 12
// dp[8] = max(..., 3×dp[5], ...) = max(..., 18, ...) = 18
// dp[9] = max(..., 3×dp[6], ...) = max(..., 27, ...) = 27
// dp[10] = max(..., 3×dp[7], ...) = max(..., 36, ...) = 36 ✓
//
// 观察规律: dp[i] 的最优拆分总是拆出 2 或 3
```

```cpp
class Solution {
public:
    int integerBreak(int n) {
        // dp[i]: 将 i 拆成至少2个正整数之和的最大乘积
        vector<int> dp(n + 1, 0);
        dp[2] = 1; // 2 = 1+1, 乘积 = 1
        
        for (int i = 3; i <= n; i++) {
            for (int j = 1; j < i; j++) {
                // j*(i-j): 拆成两部分就不再拆了
                // j*dp[i-j]: 拆出j后，剩余部分继续最优拆分
                dp[i] = max(dp[i], max(j * (i - j), j * dp[i - j]));
            }
        }
        return dp[n];
    }
};
```

**优化**：内层循环 j 其实只需要枚举到 i/2（因为 j 和 i-j 是对称的），甚至可以只枚举 j=2 和 j=3（数学上可以证明只拆出 2 和 3 是最优的）：

```cpp
class Solution {
public:
    int integerBreak(int n) {
        vector<int> dp(n + 1, 0);
        dp[2] = 1;
        for (int i = 3; i <= n; i++) {
            // 数学优化: 只需枚举 j=2 和 j=3
            // 因为最优拆分因子只有 2 和 3
            dp[i] = max({2 * (i - 2), 2 * dp[i - 2], 
                         3 * (i - 3), 3 * dp[i - 3]});
            // 注意: i=3 时 i-3=0, 3*dp[0]=0 不影响结果
        }
        return dp[n];
    }
};
```

**关键点**：
- `dp[2] = 1` 不是 2！因为 2 **必须**拆成 1+1。
- 转移时 `j*(i-j)` 不能漏，否则像 dp[4] 就算不出 2×2=4（因为 dp[2]=1，2×dp[2]=2 不是最优）。

### 解法3: 数学贪心 — O(1) / O(1)

**数学推导**：
- 任何因子 ≥ 5 都应该继续拆（5 → 2+3, 2×3=6 > 5）
- 因子 4 拆不拆一样（4 = 2+2, 2×2=4）
- 因子 1 绝不能出现（乘1不增加乘积）
- 所以最优拆分只用 2 和 3
- **3 比 2 更优**：6 = 3+3 → 9；6 = 2+2+2 → 8
- 策略：尽量多拆 3，余数为 1 时退回一个 3 变成 2×2

```
// n 除以 3 的余数决定策略:
// 余数 0: 全拆成 3        → 3^(n/3)
// 余数 1: 拿出一个 3+1=4  → 3^(n/3-1) × 4
// 余数 2: 多一个 2         → 3^(n/3) × 2
//
// 例: n=10, 10/3=3余1 → 3^2 × 4 = 9×4 = 36 ✓
// 例: n=8,  8/3=2余2  → 3^2 × 2 = 9×2 = 18 ✓
// 例: n=9,  9/3=3余0  → 3^3 = 27 ✓
```

```cpp
class Solution {
public:
    int integerBreak(int n) {
        // 特殊情况: 必须至少拆成2份
        if (n == 2) return 1; // 1×1
        if (n == 3) return 2; // 1×2
        
        int quotient = n / 3;
        int remainder = n % 3;
        
        if (remainder == 0) {
            // n 恰好被 3 整除，全部拆成 3
            return pow(3, quotient);
        } else if (remainder == 1) {
            // 余 1: 3+1=4, 不如 2+2=4, 退回一个 3 换成两个 2
            return pow(3, quotient - 1) * 4;
        } else {
            // 余 2: 最后多一个 2
            return pow(3, quotient) * 2;
        }
    }
};
```

**关键点**：
- n=2 和 n=3 必须特判，因为它们不满足"尽量拆3"的策略（被强制要求至少拆2份）
- `pow` 返回浮点数，n ≤ 58 范围内不会有精度问题，但严谨起见可用整数快速幂

## 解法对比

| | 暴力递归 | 动态规划 | 数学贪心 |
|---|---|---|---|
| 时间 | O(n!) | O(n²) | O(1) |
| 空间 | O(n) 栈 | O(n) | O(1) |
| 思维难度 | 低 | 中 | 高（需数学推导） |
| 面试推荐 | 用来讲思路 | ⭐ 首选 | 加分项 |
| 关键 | 理解递归结构 | 理解"拆/不拆"两种选择 | 证明3是最优因子 |

- **面试场景**：先说 DP 解法，如果面试官追问"能否更优"，再给数学解法。
- **DP vs 数学**：DP 是通用解法（适用于各种变体），数学是针对本题的特殊优化。

## 易错点

1. **漏掉 `j * (i-j)` 的情况**：
   - ✗ `dp[i] = max(dp[i], j * dp[i-j]);` — dp[4] 会算出 3（1×dp[3]=1×2=2 或 2×dp[2]=2×1=2 或 3×dp[1]=3×1=3），而正确答案是 4
   - ✓ `dp[i] = max(dp[i], max(j * (i-j), j * dp[i-j]));` — 因为 2×2=4 来自 `j*(i-j)` 路径
   - **原因**：dp[i-j] 是"i-j 拆分后的最大乘积"，但 i-j 本身（不拆）可能更大

2. **dp[1] 的初始化**：
   - dp[1] = 0 或 dp[1] = 1 都可以（因为 1 不应出现在拆分中，而 `j*(i-j)` 已经覆盖了不拆的情况）
   - 但如果你只用了 `j*dp[i-j]` 而没有 `j*(i-j)`，dp[1] 的值就会出错

3. **数学解法忘记特判 n ≤ 3**：
   - n=3 时 3/3=1 余 0，`pow(3,1)=3`，但答案应该是 2（必须拆成 1+2）
   - n=2 时同理

4. **`pow` 的精度问题**：
   - ✗ `return (int)pow(3, quotient) * 2;` — 大数时 pow 的浮点误差可能导致少 1
   - ✓ 使用整数幂函数，或在本题范围内（n≤58, 3^18 < 4×10^8）精度足够

## 面试追问

**Q1: 基础理解** — dp[i] 的转移方程为什么要取 `j*(i-j)` 和 `j*dp[i-j]` 两者的 max？

> 因为 dp[i-j] 代表"i-j 继续拆分后的最大乘积"，而 i-j 本身不拆可能更大。比如 i-j=4 时，dp[4]=4（拆成2+2），但 4 本身也是 4；而 i-j=3 时，dp[3]=2（拆成1+2），但 3 本身是 3 > 2。所以"不拆"有时更优。

**Q2: 优化** — 内层循环能否优化？j 需要遍历到 i-1 吗？

> 不需要。数学上可以证明，最优的拆分因子只有 2 和 3。因此 j 只需要枚举 2 和 3，内层变成 O(1)，总时间降为 O(n)。甚至可以用数学公式直接 O(1) 求解。

**Q3: 变体** — 如果要求返回具体的拆分方案（不只是乘积），怎么做？

> 在 DP 的基础上增加一个 `choice[i]` 数组记录 dp[i] 取最优值时选的 j，然后从 `choice[n]` 反向回溯出完整拆分方案。或者直接用数学解法：尽量拆 3，余 1 时换成 2+2，余 2 时多一个 2。
