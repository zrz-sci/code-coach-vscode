# 312. 戳气球

## 核心思路

这道题本质上是一个**区间 DP** 问题：逆向思考，不考虑"先戳哪个"，而是考虑"最后戳哪个"——在区间 `(i, j)` 内，枚举最后一个被戳破的气球 `k`，这样 `k` 戳破时其左右邻居确定为 `i` 和 `j`（因为区间内其他气球都已经戳完了），从而消除了戳气球后邻居变化带来的依赖问题。

## 思维链

1. **读完题第一反应**：每次选一个气球戳破，获得 `nums[left] * nums[i] * nums[right]` 的硬币，然后气球消失、邻居变化。这是一个全排列问题——n 个气球有 n! 种戳破顺序，暴力枚举所有顺序取最大值。

2. **暴力解的瓶颈**：n! 的复杂度完全不可接受（n=300 时爆炸）。而且每次戳破一个气球后，剩余气球的邻居关系会变化，这让"正向模拟"非常难以分治或记忆化——因为子问题的定义取决于前面戳了谁。

3. **逆向思考的突破口**：如果我们不想"第一个戳谁"，而是想"**最后一个戳谁**"呢？假设气球 `k` 是整个数组中最后被戳破的，那么戳破 `k` 时，左右两侧已经没有其他气球了，`k` 的邻居就是边界的虚拟气球（值为 1）。而 `k` 左边的气球和右边的气球可以独立求解！

4. **推广到区间**：定义开区间 `(i, j)` 表示"只考虑 `i` 和 `j` 之间的气球"，在这个区间内枚举最后被戳破的气球 `k`。当 `k` 最后被戳时，区间 `(i, k)` 和 `(k, j)` 内的气球都已经戳完了，所以 `k` 的收益确定为 `nums[i] * nums[k] * nums[j]`。

5. **状态转移方程**：`dp[i][j] = max(dp[i][k] + nums[i]*nums[k]*nums[j] + dp[k][j])`，其中 `k` 取遍 `(i, j)` 内所有气球。

6. **遍历方向**：区间长度从小到大填表。`dp[i][j]` 依赖更短的区间 `dp[i][k]` 和 `dp[k][j]`，所以按区间长度递增枚举即可。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力回溯 | 枚举所有戳破顺序 | O(n!) | O(n) | 能说出即可 |
| 记忆化搜索 | 逆向思考 + 区间递归 + memo | O(n³) | O(n²) | ⭐ 必须写出 |
| 区间 DP（递推） | 自底向上填表 | O(n³) | O(n²) | ⭐ 必须写出 |

## 关键提示

1. **为什么"正向"（先戳谁）行不通？** 因为戳破一个气球后邻居关系变化，左右两部分不再独立——右边气球的邻居可能变成了左边还没戳的某个气球。

2. **逆向思维的关键**：在区间 `(i, j)` 内选"最后戳的"气球 `k`，此时 `(i, k)` 和 `(k, j)` 两个子区间已经戳完了，它们是**独立**的子问题。

3. **虚拟边界**：在 `nums` 两端各添加一个值为 `1` 的虚拟气球，统一边界处理。原问题变成求 `dp[0][n+1]`。

4. **区间 DP 的经典模板**：外层枚举区间长度 `len`，内层枚举左端点 `i`，最内层枚举分割点 `k`。

5. **DP 填表方向示意**（以 `nums = [3,1,5,8]`，添加边界后为 `[1,3,1,5,8,1]`）：
```
// 新数组 val = [1, 3, 1, 5, 8, 1]   (下标 0~5)
// dp[i][j] = 开区间 (i,j) 内能获得的最大硬币
//
// 填表方向: 区间长度从 2 开始（len=2时中间无气球，dp=0）
// len=3: dp[0][2], dp[1][3], dp[2][4], dp[3][5]
// len=4: dp[0][3], dp[1][4], dp[2][5]
// len=5: dp[0][4], dp[1][5]
// len=6: dp[0][5]  ← 这就是答案
//
// dp[i][j] 依赖: dp[i][k] 和 dp[k][j]，都是更短的区间
```

## 解法详解

### 解法1: 暴力回溯 — O(n! × n) / O(n)

**思考过程**: 最直觉的做法——每次从剩余气球中选一个戳破，递归处理剩下的。这就是枚举所有 n! 种戳破顺序。

```cpp
class Solution {
public:
    int maxCoins(vector<int>& nums) {
        // 暴力：枚举所有戳破顺序
        // n <= 300 时完全不可行，仅用于理解题意
        int n = nums.size();
        return dfs(nums);
    }
    
    int dfs(vector<int>& nums) {
        int n = nums.size();
        if (n == 0) return 0;
        
        int maxVal = 0;
        for (int i = 0; i < n; i++) {
            // 戳破 nums[i]，获得的硬币
            int left = (i - 1 >= 0) ? nums[i - 1] : 1;
            int right = (i + 1 < n) ? nums[i + 1] : 1;
            int coins = left * nums[i] * right;
            
            // 从数组中移除 nums[i]
            int saved = nums[i];
            nums.erase(nums.begin() + i);
            
            maxVal = max(maxVal, coins + dfs(nums));
            
            // 回溯：恢复
            nums.insert(nums.begin() + i, saved);
        }
        return maxVal;
    }
};
```

**关键点**: 这个解法只是为了理解题意。每次 erase/insert 是 O(n)，加上 n! 种排列，完全无法通过。但它清楚地展示了为什么"正向模拟"很难优化——戳破一个气球后数组结构变化，子问题无法被干净地定义和复用。

### 解法2: 记忆化搜索（区间 DP 自顶向下） — O(n³) / O(n²) ⭐ 面试首选

**从暴力到优化**: 暴力解的根本问题是"戳破气球后邻居变化导致子问题无法复用"。逆向思考——在区间 `(i, j)` 内选最后被戳的气球 `k`，此时 `k` 的左右邻居确定为 `val[i]` 和 `val[j]`，而两个子区间 `(i, k)` 和 `(k, j)` 互不影响。

```cpp
class Solution {
public:
    int maxCoins(vector<int>& nums) {
        int n = nums.size();
        // 添加虚拟边界: val = [1, nums[0], nums[1], ..., nums[n-1], 1]
        vector<int> val(n + 2);
        val[0] = val[n + 1] = 1;
        for (int i = 0; i < n; i++) val[i + 1] = nums[i];
        
        // memo[i][j] = 开区间 (i,j) 内能获得的最大硬币数
        vector<vector<int>> memo(n + 2, vector<int>(n + 2, -1));
        return solve(val, memo, 0, n + 1);
    }
    
    int solve(vector<int>& val, vector<vector<int>>& memo, int i, int j) {
        // 开区间 (i,j) 内没有气球可戳
        if (j - i < 2) return 0;
        if (memo[i][j] != -1) return memo[i][j];
        
        int best = 0;
        // 枚举 k 作为区间 (i,j) 内"最后"被戳的气球
        for (int k = i + 1; k < j; k++) {
            // k 最后被戳时，左右邻居就是 i 和 j（中间其他的都戳完了）
            int coins = val[i] * val[k] * val[j];
            int total = solve(val, memo, i, k) + coins + solve(val, memo, k, j);
            best = max(best, total);
        }
        return memo[i][j] = best;
    }
};
```

**关键点**: 
- 使用"开区间" `(i, j)` 定义状态，`i` 和 `j` 本身不属于区间内的气球，它们是边界。
- `k` 是"最后戳的"，所以戳 `k` 时其收益 = `val[i] * val[k] * val[j]`，这是确定的。

### 解法3: 区间 DP（递推，自底向上） — O(n³) / O(n²) ⭐

**从记忆化到递推**: 把递归翻译成循环。外层枚举区间长度（从小到大），保证计算 `dp[i][j]` 时其子区间已经算完。

```cpp
class Solution {
public:
    int maxCoins(vector<int>& nums) {
        int n = nums.size();
        // 添加虚拟边界
        vector<int> val(n + 2);
        val[0] = val[n + 1] = 1;
        for (int i = 0; i < n; i++) val[i + 1] = nums[i];
        
        // dp[i][j] = 开区间 (i,j) 内戳破所有气球能获得的最大硬币
        vector<vector<int>> dp(n + 2, vector<int>(n + 2, 0));
        
        // 枚举区间长度: len 是 j-i 的值
        // len=0,1 时开区间内无气球，dp=0（已初始化）
        // len >= 2 时开始有意义
        for (int len = 2; len <= n + 1; len++) {
            for (int i = 0; i + len <= n + 1; i++) {
                int j = i + len;
                // 枚举 k: 区间 (i,j) 内最后被戳的气球
                for (int k = i + 1; k < j; k++) {
                    dp[i][j] = max(dp[i][j],
                        dp[i][k] + val[i] * val[k] * val[j] + dp[k][j]);
                }
            }
        }
        
        return dp[0][n + 1];
    }
};
```

**DP 填表过程**（以 `nums = [3,1,5,8]` 为例）：
```
// val = [1, 3, 1, 5, 8, 1]   下标 0~5
//
// len=2 (区间内1个气球):
//   dp[0][2]: k=1 → 1*3*1 = 3                          dp[0][2] = 3
//   dp[1][3]: k=2 → 3*1*5 = 15                         dp[1][3] = 15
//   dp[2][4]: k=3 → 1*5*8 = 40                         dp[2][4] = 40
//   dp[3][5]: k=4 → 5*8*1 = 40                         dp[3][5] = 40
//
// len=3 (区间内2个气球):
//   dp[0][3]: k=1 → 0+1*3*5+15=30; k=2 → 3+1*1*5+0=8  dp[0][3] = 30
//   dp[1][4]: k=2 → 0+3*1*8+40=64; k=3 → 15+3*5*8+0=135  dp[1][4] = 135
//   dp[2][5]: k=3 → 0+1*5*1+40=45; k=4 → 40+1*8*1+0=48   dp[2][5] = 48
//
// len=4 (区间内3个气球):
//   dp[0][4]: k=1 → 0+1*3*8+135=159
//             k=2 → 3+1*1*8+40=51
//             k=3 → 30+1*5*8+0=70                      dp[0][4] = 159
//   dp[1][5]: k=2 → 0+3*1*1+48=51
//             k=3 → 15+3*5*1+40=70
//             k=4 → 135+3*8*1+0=159                    dp[1][5] = 159
//
// len=5 (区间内4个气球 = 原始全部):
//   dp[0][5]: k=1 → 0+1*3*1+159=162
//             k=2 → 3+1*1*1+48=52
//             k=3 → 30+1*5*1+40=75
//             k=4 → 159+1*8*1+0=167                    dp[0][5] = 167 ✓
```

## 解法对比

| | 暴力回溯 | 记忆化搜索 | 区间 DP 递推 |
|--|---------|-----------|-------------|
| 时间 | O(n! × n) | O(n³) | O(n³) |
| 空间 | O(n) | O(n²) | O(n²) |
| 思维难度 | 低（直接模拟） | 高（逆向思维） | 高（同左） |
| 面试推荐 | 开场说思路 | ⭐ 推荐 | ⭐ 推荐 |

记忆化搜索和递推本质相同，面试中记忆化搜索更好写、不容易搞错遍历方向。

## 易错点

1. **正向 vs 逆向思维混淆**：
   - ✗ 把 `k` 当成"第一个戳的"——这样 `(i,k)` 和 `(k,j)` 的边界会互相影响
   - ✓ `k` 是"最后一个戳的"——此时两个子区间的气球都已戳完，`k` 的邻居确定为 `val[i]` 和 `val[j]`

2. **忘记添加虚拟边界**：
   - ✗ 直接在原 `nums` 上做 DP，边界气球的邻居处理混乱
   - ✓ 构造 `val = [1, nums[0], ..., nums[n-1], 1]`，问题变成 `dp[0][n+1]`

3. **开区间 vs 闭区间搞混**：
   - ✗ `dp[i][j]` 定义为闭区间 `[i,j]` 内最大硬币——此时最后戳 `k` 时其邻居不是 `i` 和 `j` 本身
   - ✓ 用开区间 `(i,j)`，`i` 和 `j` 是边界不参与戳破，`k` 最后戳时邻居就是 `i` 和 `j`

4. **枚举区间长度时的范围错误**：
   - ✗ `for (int len = 1; ...)`——len=1 时开区间 `(i, i+1)` 内无气球，没有意义且不会出错但浪费
   - ✗ 更严重：遍历 `k` 的范围写成 `k = i` 到 `k = j`，应该是 `k = i+1` 到 `k = j-1`（开区间内部）

5. **记忆化搜索中的 base case**：
   - ✗ 忘记 `j - i < 2` 时返回 0，导致无限递归
   - ✓ 当 `j - i < 2` 时，开区间内没有气球，返回 0

## 面试追问

**Q1: 暴力解的复杂度是多少？为什么不能用贪心？**
> 暴力是 O(n!)。不能贪心是因为当前戳破一个气球会改变其他气球的邻居关系，贪心地选"当前收益最大的"不能保证全局最优。例如 [1,5,1] 中先戳 5 得 5 分，但先戳两边的 1（各得 5 分）再戳 5（得 5 分）总共 15 分更优。

**Q2: 为什么要"逆向思考"——选最后戳的而不是第一个戳的？**
> 选第一个戳的气球后，剩余气球的邻居关系变化，左右两部分不独立。而选最后戳的气球 k 时，(i,k) 和 (k,j) 内的气球已经全部戳完，k 的邻居确定为 i 和 j，两个子问题互不干扰——这正是 DP 需要的"子问题独立性"。

**Q3: 能否进一步优化时间复杂度？**
> 对于一般情况，O(n³) 已经是区间 DP 的最优时间复杂度（三重循环无法避免）。但在特殊输入下（如大量相同元素），可以做一些剪枝。此外，有些论文探讨过用 Knuth 优化将某些区间 DP 降到 O(n²)，但本题的转移不满足四边形不等式条件，因此 O(n³) 基本是最优的。

**Q4: 如果气球是环形排列怎么办？**
> 类似"环形 DP"的处理：把数组复制一倍展开成长度 2n 的链，对每个起点做区间 DP 后取最大值。或者枚举"断开点"，在每个线性版本上做区间 DP。
