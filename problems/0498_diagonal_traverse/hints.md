# 498. 对角线遍历

## 核心思路

矩阵中同一条对角线上的所有元素满足 `row + col` 值相同。问题本质就是：按 `row + col` 的值从 0 到 m+n-2 依次收集对角线上的元素，偶数对角线向上遍历（翻转），奇数对角线向下遍历。

## 思维链

1. **读完题第一反应**：对角线遍历就是"锯齿形"地沿对角线走。先观察规律——第0条对角线只有 `[0,0]`，第1条有 `[0,1],[1,0]`，第2条有 `[0,2],[1,1],[2,0]`……同一条对角线上 `r+c` 相同！

2. **朴素做法**：把所有对角线收集出来，偶数编号的翻转，奇数编号的保持原序，然后拼接。这需要额外空间存每条对角线。

3. **能否不存对角线直接模拟？** 如果我们直接在矩阵上"走"，向右上或左下移动，碰到边界就转向。关键是把转向规则想清楚。

4. **模拟的核心**：维护当前方向（向右上 or 向左下），每走一步检查是否越界，越界时根据具体情况决定转向到哪个位置。

5. **两种实现方式对比**：
   - **收集+翻转**：逻辑简单，不容易出错
   - **直接模拟**：不需要额外空间存对角线，但边界条件复杂

6. **边界转向的推导**：画图分析越界时的 4 种情况就能推出规则。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 收集对角线+翻转 | 按 r+c 分组，偶数组翻转 | O(m·n) | O(min(m,n)) 临时数组 | 能说出即可 |
| 直接模拟 | 模拟走路+边界转向 | O(m·n) | O(1) 额外 | ⭐ 必须写出 |

## 关键提示

- **提示1**：同一条对角线上，所有元素的 `row + col` 值相等。第 `d` 条对角线上 `r + c = d`。

- **提示2**：对角线编号 `d` 从 0 到 `m + n - 2`。当 `d` 为偶数时，方向是右上（r 减小，c 增大）；`d` 为奇数时，方向是左下。

- **提示3**：对于收集法——每条对角线自然遍历顺序是"左下到右上"（r 从大到小）。偶数对角线刚好需要这个顺序（或者从小到大收集后翻转）。

- **提示4**：对于模拟法——不要试图用一个统一的公式，而是分清 4 种越界情况：
  ```
  // 3x3 矩阵的遍历路径：
  //
  //  (0,0) → (0,1)   (0,2) → (1,2)
  //            ↙        ↗       ↙
  //         (1,0) → (2,0)   (2,1) → (2,2)
  //                   ↗
  //
  //  输出: 1, 2, 4, 7, 5, 3, 6, 8, 9
  ```

- **提示5**：模拟法中，向右上走越界时：如果 `c` 越右边界，必须下移一行（r++）；如果 `r` 越上边界，只需右移一列（c++）。注意要**先检查列越界再检查行越界**（因为角落处两个都越界时，优先级不同）。

## 解法详解

### 解法1: 收集对角线 + 翻转 — O(m·n) / O(min(m,n))

**思考过程**：

观察矩阵中对角线的规律：

```
//  矩阵 3x3:
//     c=0  c=1  c=2
// r=0  1    2    3      对角线编号 d = r + c
// r=1  4    5    6      d=0: [1]
// r=2  7    8    9      d=1: [2, 4]       ← 自然顺序是 r 从小到大
//                       d=2: [3, 5, 7]
//                       d=3: [6, 8]
//                       d=4: [9]
//
// 偶数对角线(d=0,2,4): 需要从右上到左下 → 翻转自然顺序
// 奇数对角线(d=1,3):   需要从左下到右上 → 保持自然顺序
```

每条对角线，`r` 的范围是 `max(0, d-n+1)` 到 `min(d, m-1)`。按 r 从小到大收集就是"右上→左下"的顺序。偶数对角线翻转一下即可。

```cpp
class Solution {
public:
    vector<int> findDiagonalOrder(vector<vector<int>>& mat) {
        int m = mat.size(), n = mat[0].size();
        vector<int> result;
        result.reserve(m * n);
        
        // 遍历每条对角线，d = r + c，范围 [0, m+n-2]
        for (int d = 0; d <= m + n - 2; d++) {
            // 临时存储当前对角线上的元素
            vector<int> diagonal;
            
            // r 的合法范围：r >= 0, r <= m-1, c = d-r >= 0, c <= n-1
            int r_min = max(0, d - n + 1);
            int r_max = min(d, m - 1);
            
            for (int r = r_min; r <= r_max; r++) {
                diagonal.push_back(mat[r][d - r]);
            }
            
            // 偶数对角线：需要"右上→左下"即 r 从小到大
            // 但我们收集时就是 r 从小到大，所以偶数要翻转变成 r 从大到小？
            // 等等——题目中偶数对角线是向右上走，即 r 递减、c 递增
            // 我们收集的顺序是 r 递增（左上到右下）
            // 所以偶数对角线需要翻转！
            if (d % 2 == 0) {
                reverse(diagonal.begin(), diagonal.end());
            }
            
            for (int val : diagonal) {
                result.push_back(val);
            }
        }
        
        return result;
    }
};
```

**关键点**：`r_min` 和 `r_max` 的推导——由 `0 <= r <= m-1` 和 `0 <= d-r <= n-1` 联合推出。

### 解法2: 直接模拟 — O(m·n) / O(1) ⭐ 面试首选

**从解法1优化**：解法1需要额外空间存每条对角线。直接在矩阵上模拟"走"的过程，碰到边界就转向，O(1) 额外空间。

**边界转向分析**（这是本题最核心的部分）：

```
// 方向1: 向右上走 (r-1, c+1)
// 越界情况:
//   Case A: c+1 > n-1 (超出右边界) → 只能下移: r++, 然后转为向左下
//   Case B: r-1 < 0 (超出上边界)   → 只能右移: c++, 然后转为向左下
//   注意: 右上角(0,n-1)同时触发A和B → 优先处理A（下移）
//
// 方向2: 向左下走 (r+1, c-1)  
// 越界情况:
//   Case C: r+1 > m-1 (超出下边界) → 只能右移: c++, 然后转为向右上
//   Case D: c-1 < 0 (超出左边界)   → 只能下移: r++, 然后转为向右上
//   注意: 左下角(m-1,0)同时触发C和D → 优先处理C（右移）
//
// 示例 3x3:
//  pos:  (0,0)→ 右上越界(r<0) → 转(0,1)→ 左下 → (1,0)→ 左下越界(c<0)
//        → 转(2,0)→ 右上 → (1,1) → (0,2) → 右上越界(c>n-1)
//        → 转(1,2) → 左下 → (2,1) → 左下越界(r>m-1)
//        → 转(2,2) → 结束
```

```cpp
class Solution {
public:
    vector<int> findDiagonalOrder(vector<vector<int>>& mat) {
        int m = mat.size(), n = mat[0].size();
        vector<int> result(m * n);
        
        int r = 0, c = 0;
        // goingUp = true 表示向右上走
        bool goingUp = true;
        
        for (int i = 0; i < m * n; i++) {
            result[i] = mat[r][c];
            
            if (goingUp) {
                // 向右上走 (r-1, c+1)
                if (c == n - 1) {
                    // Case A: 碰右边界 → 下移一行，转向
                    r++;
                    goingUp = false;
                } else if (r == 0) {
                    // Case B: 碰上边界 → 右移一列，转向
                    c++;
                    goingUp = false;
                } else {
                    // 正常右上移动
                    r--;
                    c++;
                }
            } else {
                // 向左下走 (r+1, c-1)
                if (r == m - 1) {
                    // Case C: 碰下边界 → 右移一列，转向
                    c++;
                    goingUp = true;
                } else if (c == 0) {
                    // Case D: 碰左边界 → 下移一行，转向
                    r++;
                    goingUp = true;
                } else {
                    // 正常左下移动
                    r++;
                    c--;
                }
            }
        }
        
        return result;
    }
};
```

**关键点**：边界检查的顺序至关重要！向右上走时，先检查 `c == n-1` 再检查 `r == 0`；向左下走时，先检查 `r == m-1` 再检查 `c == 0`。在角落处两个条件同时满足，顺序错了会越界。

## 解法对比

| | 解法1: 收集+翻转 | 解法2: 直接模拟 |
|---|---|---|
| 时间 | O(m·n) | O(m·n) |
| 额外空间 | O(min(m,n)) 存对角线 | O(1) |
| 代码复杂度 | 简单 | 边界条件多 |
| 适用场景 | 不要求空间优化时 | 面试追问空间优化 |
| 出错概率 | 低 | 中（边界顺序） |

**建议**：面试时先说解法1展示思路清晰，再给出解法2展示优化能力。

## 易错点

1. **边界检查顺序错误**（最常见！）
   - ✗ 向右上走时先检查 `r == 0` 再检查 `c == n-1` → 在右上角 `(0, n-1)` 处，会执行 `c++` 导致越界
   - ✓ 必须先检查 `c == n-1`，因为角落处应该下移（r++）而不是右移

2. **收集法中翻转方向搞反**
   - ✗ 奇数对角线翻转（应该是偶数翻转）
   - ✓ 画出 d=0 的对角线 `[1]`（只有一个元素），d=1 的对角线 `[2,4]` 应该是 `[2,4]` 顺序（左上→右下即 r 递增），而题目输出是 `[2,4]`（先 2 后 4），所以 d=1（奇数）不翻转 ✓

3. **r_min / r_max 推导错误**
   - ✗ `r_min = max(0, d - n)` → 当 d=n-1 时，r_min=0 但实际 c=d-0=n-1 是合法的，漏掉了 d-n+1
   - ✓ `r_min = max(0, d - (n-1))` 即 `max(0, d - n + 1)`

4. **结果数组大小**
   - ✗ 用 `push_back` 但没 `reserve` → 多次扩容影响性能
   - ✓ 提前 `reserve(m * n)` 或直接创建大小为 `m*n` 的数组

## 面试追问

**Q1: 你怎么发现同一对角线上的元素有什么共同特征？**
→ 观察坐标：(0,0), (0,1)和(1,0), (0,2)和(1,1)和(2,0)... 同一对角线上 r+c 相等。这是一个关键的数学观察。

**Q2: 模拟法中边界检查的顺序为什么重要？能否画图说明？**
→ 以 3x3 矩阵为例，在 (0,2) 处向右上走，r-1=-1 且 c+1=3 同时越界。如果先判断 r<0 就会 c++→c=3 越界。应该先判断 c==n-1 执行 r++→r=1，这样 (1,2) 是合法位置。

**Q3: 如果矩阵非常大（比如 10000×10000），但只要求输出第 k 条对角线的元素，怎么优化？**
→ 不需要遍历整个矩阵。第 k 条对角线上 r+c=k，r 的范围是 [max(0, k-n+1), min(k, m-1)]，直接遍历这个范围即可，时间 O(min(m,n))。

**Q4: 如果要反向对角线遍历（从右下角开始），代码怎么改？**
→ 最简单：正常遍历后把结果数组 reverse。或者模拟时从 (m-1, n-1) 开始，方向取反。
