# 326. 3 的幂 (Easy)

**Tags:** Recursion, Math

## 核心思路

判断整数 n 是否为 3 的幂次方。三种主要方法：**循环除法**、**数学取对数**、以及**整数范围内最大 3 的幂取余**。其中取余法是 follow-up 要求的无循环/递归解法。

## 思维链

1. 最直接：不断除以 3，看最终是否为 1
2. 数学法：用 log 计算指数，判断是否为整数 — 但浮点精度有坑
3. 巧妙法：int 范围内最大的 3 的幂是 3^19 = 1162261467，如果 n 是 3 的幂，则 3^19 % n == 0
4. 边界：n <= 0 直接返回 false（3 的幂都是正数）

## 解法概览

| 解法 | 时间 | 空间 | 推荐 | 说明 |
|------|------|------|------|------|
| 循环除法 | O(log n) | O(1) | ⭐ | 最直观 |
| 最大幂取余 | O(1) | O(1) | ⭐ | 无循环 follow-up |
| 数学对数 | O(1) | O(1) | - | 浮点精度问题 |

## 关键提示

1. **为什么取余法有效**：3 是质数，3^19 的因子只能是 3^0, 3^1, ..., 3^19。如果 n 能整除 3^19 且 n > 0，则 n 必是 3 的幂
2. **为什么 2 的幂不能这样做**：2 也是质数，同理可以用 2^30 % n == 0 来判断（LC 231）
3. **int 范围内最大 3 的幂**：3^19 = 1162261467，3^20 = 3486784401 > INT_MAX
4. **浮点陷阱**：log3(243) 理论等于 5，但 log(243)/log(3) 可能得到 4.99999...，floor 后变成 4

## 解法详解

### 解法一：循环除法 (推荐)

```cpp
class Solution {
public:
    bool isPowerOfThree(int n) {
        if (n <= 0) return false;
        while (n % 3 == 0) {
            n /= 3;
        }
        return n == 1;
    }
};
```

### 解法二：最大幂取余 — 无循环/递归 (Follow-up)

```cpp
class Solution {
public:
    bool isPowerOfThree(int n) {
        // 3^19 = 1162261467 是 int 范围内最大的 3 的幂
        return n > 0 && 1162261467 % n == 0;
    }
};
```

### 解法三：数学对数法 (有精度风险)

```cpp
class Solution {
public:
    bool isPowerOfThree(int n) {
        if (n <= 0) return false;
        double logVal = log(n) / log(3);
        // 用 round 而非 floor 来规避浮点精度问题
        return abs(logVal - round(logVal)) < 1e-10;
    }
};
```

## 易错点

| 错误写法 | 正确写法 | 原因 |
|----------|----------|------|
| ✗ 不检查 `n <= 0` | ✓ 先判断 `n > 0` | n=0 会死循环；负数不是 3 的幂 |
| ✗ `(int)(log(n)/log(3))` 直接判断 | ✓ 用 `round` 再验证 | 浮点截断，243 可能判断为非 3 的幂 |
| ✗ 用 6 的幂取余 | ✓ 必须用质数的幂 | 6 不是质数，6^k 的因子包含非 6 的幂 |
| ✗ 3^20 作为最大幂 | ✓ 3^19 = 1162261467 | 3^20 超出 int 范围 |

## 面试追问

**Q1: 如何不用循环/递归判断？**
→ 利用 int 范围内最大的 3 的幂 (3^19 = 1162261467)，判断 `n > 0 && 1162261467 % n == 0`。

**Q2: 这个方法对所有底数都适用吗？**
→ 只对质数底数适用。如果底数是合数（如 12），12^k 的因子包含非 12 的幂（如 4, 8），取余法不成立。

**Q3: 如何推广到判断"n 是否为 k 的幂"？**
→ 若 k 是质数：找 int 范围内最大的 k^m，判断 k^m % n == 0。若 k 是合数：只能用循环/递归或位运算特判（如 k 为 2 的幂时 `n & (n-1) == 0`）。
