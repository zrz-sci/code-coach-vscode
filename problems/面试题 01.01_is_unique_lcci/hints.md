# 面试题 01.01. 判定字符是否唯一

## 核心思路

判断字符串中是否所有字符都不相同。题目的**进阶挑战**是不使用额外数据结构——这直接指向**位运算**：用一个 `int` 的 26 个 bit 位代替哈希表，每一位标记对应字母是否出现过。

## 思维链

1. **读完题第一反应**：用 HashSet 记录出现过的字符，遍历时发现重复就返回 false。O(n) 时间 O(n) 空间。

2. **题目追问：不用额外数据结构？** 不能用 set/map/array。怎么标记字符是否出现？→ 用一个整数的 bit 位！26 个小写字母正好用一个 32 位 int 的低 26 位。

3. **鸽巢原理的提前返回**：只有 26 个小写字母，如果字符串长度 > 26，必然存在重复，直接返回 false。这是一个不需要额外数据结构的剪枝。

4. **排序解法**：先排序，再检查相邻字符是否相同。O(n log n) 时间，O(1) 额外空间（原地排序）。也满足"不用额外数据结构"但时间更慢。

5. **暴力双重循环**：对每对字符 (i, j) 检查是否相同。O(n^2) 时间 O(1) 空间。最朴素但面试不推荐。

## 位运算图示

```
字符串 "abc" 的处理过程:

初始: checker = 00000000 00000000 00000000 00000000

处理 'a' (val=0):
  检查: checker & (1 << 0) = 0 → 未出现
  标记: checker |= (1 << 0)
  checker = 00000000 00000000 00000000 00000001
                                              ^
                                              a

处理 'b' (val=1):
  检查: checker & (1 << 1) = 0 → 未出现
  标记: checker |= (1 << 1)
  checker = 00000000 00000000 00000000 00000011
                                             ^^
                                             ba

处理 'c' (val=2):
  检查: checker & (1 << 2) = 0 → 未出现
  标记: checker |= (1 << 2)
  checker = 00000000 00000000 00000000 00000111
                                            ^^^
                                            cba

全部遍历完，未发现重复 → 返回 true
```

```
字符串 "leetcode" 的处理过程:

处理 'l' (val=11): checker = ...100000000000  → OK
处理 'e' (val=4):  checker = ...100000010000  → OK
处理 'e' (val=4):  
  检查: checker & (1 << 4) = 00010000 ≠ 0 → 已出现!
  → 返回 false
```

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 位运算 | 用 int 的 bit 位做标记 | O(n) | O(1) | ⭐ 首选 |
| 哈希集合 | set 记录出现字符 | O(n) | O(n) | 基础方案 |
| 排序 + 相邻检查 | 排序后检查相邻 | O(n log n) | O(1) | 不用额外结构 |
| 暴力双循环 | 每对字符比较 | O(n^2) | O(1) | 仅作分析 |

> n = 字符串长度。因为只有小写字母，n <= 26 时才有可能全唯一。

## 关键提示

1. **位运算三板斧**：
   - `1 << val`：生成只有第 val 位为 1 的掩码
   - `checker & (1 << val)`：检查第 val 位是否为 1（已出现？）
   - `checker |= (1 << val)`：将第 val 位设为 1（标记出现）

2. **为什么一个 int 就够？** 26 个小写字母，int 有 32 位，绑绑有余。如果包含大写字母（52种）或所有 ASCII（128种），一个 int 不够，需要 `long long`（64位）或 `bitset`。

3. **鸽巢原理**：26 个字母最多出现 26 次不重复。字符串长度 > 26 时必定有重复，O(1) 返回 false。

4. **"不使用额外数据结构"的含义**：面试中，一般认为固定数量的变量（如一个 int）不算"额外数据结构"，但 array/set/map 算。

5. **排序解法的陷阱**：题目说 `0 <= len(s) <= 100`，但 `string` 作为参数传进来的是引用。如果原地排序会修改输入，需要讨论是否允许。

## 解法详解

### 解法1: 位运算 — O(n) / O(1) ⭐ 面试首选

**思路**：用一个 `int checker` 的低 26 位分别对应 a~z。遍历字符串，检查对应位是否已为 1，是则有重复，否则标记该位。

```cpp
class Solution {
public:
    bool isUnique(string astr) {
        // 鸽巢原理：超过26个字符必有重复
        if (astr.size() > 26) return false;
        
        int checker = 0; // 26个bit位标记a-z是否出现
        
        for (char c : astr) {
            int val = c - 'a';                  // 字母转为 0-25
            if (checker & (1 << val)) {         // 第val位已为1?
                return false;                    // 重复!
            }
            checker |= (1 << val);              // 标记第val位
        }
        
        return true; // 无重复
    }
};
```

**关键点**：
- 位运算 O(1) 检查和设置，总体 O(n)
- 一个 int 变量，O(1) 空间
- 满足"不使用额外数据结构"的进阶要求

### 解法2: 哈希集合 — O(n) / O(n)

**思路**：用 `unordered_set` 记录已出现的字符。

```cpp
class Solution {
public:
    bool isUnique(string astr) {
        if (astr.size() > 26) return false;
        
        unordered_set<char> seen;
        for (char c : astr) {
            if (seen.count(c)) return false;  // 已存在
            seen.insert(c);                    // 记录
        }
        return true;
    }
};
```

**关键点**：最直觉的解法，但使用了额外数据结构（set），不满足进阶要求。

### 解法3: bool 数组标记 — O(n) / O(1)

**思路**：用 `bool seen[26]` 标记每个字母是否出现。严格来说 `bool[26]` 是固定大小的，有些面试官认为它也是"额外数据结构"。

```cpp
class Solution {
public:
    bool isUnique(string astr) {
        if (astr.size() > 26) return false;
        
        bool seen[26] = {false};
        for (char c : astr) {
            int idx = c - 'a';
            if (seen[idx]) return false;
            seen[idx] = true;
        }
        return true;
    }
};
```

**关键点**：固定大小 O(26) 空间 = O(1)，但面试中可能被挑战"这算不算额外数据结构"。

### 解法4: 排序 + 相邻检查 — O(n log n) / O(1)

**思路**：排序后相同字符必相邻。遍历检查相邻字符是否相同。

```cpp
class Solution {
public:
    bool isUnique(string astr) {
        if (astr.size() > 26) return false;
        
        sort(astr.begin(), astr.end()); // 原地排序
        for (int i = 1; i < (int)astr.size(); i++) {
            if (astr[i] == astr[i - 1]) return false;
        }
        return true;
    }
};
```

**关键点**：
- 不需要额外数据结构（`sort` 是原地的）
- 但修改了输入字符串，可能需要讨论
- 时间 O(n log n) 比位运算慢

### 解法5: 暴力双循环 — O(n^2) / O(1)

**思路**：对每对 (i, j) 检查 `astr[i] == astr[j]`。最朴素，无额外空间。

```cpp
class Solution {
public:
    bool isUnique(string astr) {
        if (astr.size() > 26) return false;
        
        for (int i = 0; i < (int)astr.size(); i++) {
            for (int j = i + 1; j < (int)astr.size(); j++) {
                if (astr[i] == astr[j]) return false;
            }
        }
        return true;
    }
};
```

**关键点**：仅用于展示思路的递进，面试中说一下即可，不必写出。

## 易错点

1. **位运算方向搞反**
   - X `checker & (val << 1)` → 语法错误，应该是 `1 << val`
   - O `checker & (1 << val)` → 将 1 左移 val 位

2. **忘记鸽巢原理剪枝**
   - X 直接开始遍历，长度 100 的字符串浪费时间
   - O `if (astr.size() > 26) return false;`

3. **字符集假设错误**
   - X 假设包含大写字母但 int 只有 32 位
   - O 本题限定小写字母（中文题面明确说了），26 位够用

4. **排序解法修改了输入**
   - X 直接 `sort(astr.begin(), astr.end())` 但面试官要求不修改输入
   - O 讨论是否允许修改，或者先复制 `string copy = astr;`

5. **size() 返回 unsigned 导致越界**
   - X `for (int i = 1; i < astr.size(); i++)` 当 size=0 时 `0 < 0u` 为 false，OK
   - 但有些情况 `astr.size() - 1` 会溢出为极大值（unsigned 0 - 1）

## 面试追问

**Q1: 为什么选择位运算而不是 HashSet？**
→ 位运算 O(1) 空间，不需要额外数据结构（满足进阶要求）。位操作是 CPU 原生指令，比哈希表的哈希计算和内存分配更快。26 个字母刚好一个 int 装得下。

**Q2: 如果字符集不只是小写字母呢？**
→ 如果是 ASCII（128种字符），用两个 `long long`（2*64=128位）或 `bitset<128>`。如果是 Unicode，位运算不现实（字符集太大），只能用 HashSet。同时鸽巢原理的阈值也要调整（比如 128 个 ASCII 字符，长度>128 必重复）。

**Q3: 如何不用任何额外变量（包括 int checker）？**
→ 严格来说不可能（至少需要循环变量）。但如果题意是"不用集合/数组等容器"，一个 int 是可以接受的。或者用排序方法（只修改输入本身，不引入新容器）。

**Q4: 位运算 `checker |= (1 << val)` 和 `checker = checker | (1 << val)` 一样吗？**
→ 完全等价。`|=` 是复合赋值运算符，相当于先 OR 再赋值。

**Q5: 能否用 XOR 来做？**
→ 不能直接用。XOR 的特性是两次异或同一个值会抵消，但无法区分"出现 0 次"和"出现 2 次"。如果字符出现 3 次，XOR 结果和出现 1 次相同。位运算 OR 方案是正确的：OR 只管"是否至少出现一次"。
