# 672. Bulb Switcher II

## 核心思路

关键观察：每个开关按两次等于没按，所以每个开关的实际效果只有"按"或"不按"两种。4 个开关最多产生 2^4 = 16 种组合，但由于开关 1 = 开关 2 + 开关 3（翻转全部 = 翻转偶数 + 翻转奇数），所以实际独立开关只有 3 个，最多 2^3 = 8 种状态。再加上灯泡状态以 6 为周期循环（因为 LCM(1,2,3) = 6），所以只需考虑前 min(n,3) 个灯泡的状态。最终答案可以通过对 n 和 presses 分类讨论直接给出。

## 思维链

1. 每个开关按偶数次 = 没按，按奇数次 = 按一次。所以只关心每个开关按了奇数次还是偶数次
2. 4 个开关，每个有按/不按两种选择 -> 2^4 = 16 种组合
3. 但开关 1（全部翻转）= 开关 2（偶数翻转）+ 开关 3（奇数翻转），所以只有 3 个独立自由度
4. 实际最多 8 种不同状态
5. 灯泡的模式以 6 为周期（因为开关 4 影响 1,4,7,10,... 即 3k+1，周期为 LCM(2,3)=6）
6. 因此 n >= 3 后答案不再变化（取决于前 3 个灯泡的状态即可代表所有）
7. 同时，presses >= 3 后答案也稳定（因为只有 3 个独立开关，3 次按压可以覆盖所有组合）
8. 最终变成一个小规模的分类讨论问题

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 数学分类讨论 | O(1) | O(1) | 直接返回答案 |
| 暴力枚举 | O(1) | O(1) | 枚举所有 16 种开关组合 |

## 关键提示

1. 每个开关按两次抵消 -> 只关心奇偶性 -> 每个开关只有"开/关"两种有效状态
2. 开关 1 = 开关 2 XOR 开关 3（对每个灯泡位置的效果而言）
3. 因此只有 3 个独立开关，最多 2^3 = 8 种不同的灯泡模式
4. n 取 min(n, 3) 即可（因为模式周期为 6，而 3 个灯泡已足够区分所有状态）
5. presses 取 min(presses, 3) 即可（3 次按压可以实现所有有效组合）

## 解法详解

### 解法一：数学分类讨论（推荐）

n 取 min(n, 3)，presses 取 min(presses, 3) 后的完整分类：

**presses = 0**: 无论 n 多少，答案都是 1（初始状态不变）

**n = 1** (只有灯泡 1):
- presses = 1: 2 种（开关1/3/4 -> 关；开关2 -> 不变。即开/关两种）
- presses = 2: 2 种
- presses >= 3: 2 种

**n = 2** (灯泡 1,2):
- presses = 1: 3 种（[off,off], [on,off], [off,on]）
- presses = 2: 4 种（加上 [on,on]）
- presses >= 3: 4 种

**n >= 3** (3 个以上灯泡):
- presses = 1: 4 种
- presses = 2: 7 种
- presses >= 3: 8 种

### 解法二：暴力枚举验证

**思路**：枚举 4 个开关的所有 2^4=16 种按/不按组合。对于每种组合，检查按压总次数的奇偶性是否与 presses 兼容（即按压次数 <= presses 且差值为偶数）。计算每种组合对前 min(n,3) 个灯泡的最终状态，用 set 去重统计不同状态数。

**兼容性检查**：如果组合中按了 k 个开关，则需要 k <= presses 且 (presses - k) % 2 == 0（多余的按压次数可以通过同一个开关按两次抵消）。

## 易错点

1. **忘记 presses = 0 的情况**：0 次按压只有一种状态（全开），必须特判
2. **没有意识到开关按两次抵消**：误以为需要精确使用 presses 次，实际上多余次数可以通过重复按同一个开关消除
3. **n 和 presses 没有取上限**：n >= 3 和 presses >= 3 后答案不再变化，如果直接模拟大数值会复杂化
4. **开关依赖关系**：开关 1 = 开关 2 + 开关 3 的关系容易忽略，导致多算状态数
5. **混淆"恰好 presses 次"和"最多 presses 次"**：题目要求恰好按 presses 次，但由于可以重复按同一个开关，实际等价于"按 presses 次且每个开关按偶数或奇数次"

## 面试追问

1. **如何证明灯泡模式以 6 为周期？** 4 个开关的影响模式分别是周期 1, 2, 2, 3，LCM(1,2,2,3) = 6
2. **如果增加第 5 个开关（如翻转 3 的倍数位置），答案会怎么变？** 需要重新分析周期（LCM 可能变大）和独立性
3. **能否用线性代数解释？** 4 个开关操作向量在 GF(2) 上的秩为 3，所以状态空间维度为 3
4. **如果 n 和 presses 都很大，怎么高效计算？** 已经是 O(1) 了，分类讨论直接返回 8
5. **Bulb Switcher I 和 III 有什么关系？** 系列题但解法完全不同：I 是因数个数问题，III 是前缀最大值问题
