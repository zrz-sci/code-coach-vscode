# 2413. 最小偶倍数 (Smallest Even Multiple)

## 核心思路

求 2 和 n 的最小公倍数（LCM）。如果 n 是偶数，n 本身就是 2 的倍数，答案是 n；如果 n 是奇数，最小公倍数是 2n。本质上这是一道**数论基础题**，考察对 LCM/GCD 的理解，以及位运算技巧。

## 思维链

1. **读完题第一反应**：找一个最小的正整数，既是 2 的倍数又是 n 的倍数。这不就是求 LCM(2, n) 吗？

2. **分类讨论**：
   - 如果 n 是偶数（n % 2 == 0）：n 已经是 2 的倍数了，答案就是 n 本身。
   - 如果 n 是奇数（n % 2 == 1）：n 不是 2 的倍数，最小的同时是 n 和 2 倍数的数是 2*n。

3. **数学验证**：LCM(a, b) = a * b / GCD(a, b)。
   - GCD(2, 偶数) = 2 → LCM = 2 * n / 2 = n
   - GCD(2, 奇数) = 1 → LCM = 2 * n / 1 = 2n

4. **位运算技巧**：判断奇偶可以用 `n & 1`（最低位是 1 则为奇数）。乘以 2 可以用 `n << 1`。

5. **更优雅的一行写法**：`n * (1 + n % 2)` 或 `n % 2 == 0 ? n : 2 * n`。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 条件判断 | if-else 奇偶分支 | O(1) | O(1) | ⭐ 必须写出 |
| 数学公式 | n * (1 + n%2) | O(1) | O(1) | 一行代码 |
| 位运算 | n & 1 判断 + n << 1 翻倍 | O(1) | O(1) | 加分 |
| LCM 通用解 | LCM(2, n) = 2*n / GCD(2,n) | O(log n) | O(1) | 展示数论知识 |

## 关键提示

1. **这道题的本质是 LCM(2, n)**：最小公倍数。虽然对于 2 这个特殊值可以直接分类讨论，但理解 LCM 是关键。面试中能把这个简单题和 LCM/GCD 联系起来会加分。

2. **奇偶判断的三种方式**：
   - `n % 2 == 0`：最直觉，可读性最好
   - `n & 1 == 0`：位运算，效率更高（虽然编译器会优化）
   - `!(n & 1)`：更简洁的位运算写法

3. **为什么 n 是偶数时答案就是 n？** 因为偶数的定义就是 2 的倍数。一个数如果本身就是 2 的倍数，那它同时也是自身的倍数，所以它本身就是 2 和 n 的公倍数。而且不可能有比 n 更小的 n 的正整数倍数（1*n = n 已经是最小的正倍数了）。

4. **数学推广**：如果题目改成求 k 和 n 的最小公倍数（k 不一定是 2），就需要用通用公式 `LCM(k, n) = k * n / GCD(k, n)`。

5. **GCD 计算方法**：辗转相除法 `GCD(a, b) = GCD(b, a%b)`，直到 b=0 时返回 a。时间 O(log min(a,b))。C++17 提供了 `std::gcd` 和 `std::lcm`。

## 解法详解

### 解法1: 条件判断（if-else）— O(1) / O(1) ⭐ 面试首选

**思考过程**：最直觉的分类讨论。n 是偶数返回 n，n 是奇数返回 2n。

```cpp
class Solution {
public:
    int smallestEvenMultiple(int n) {
        // 偶数：n 本身就是 2 的倍数
        // 奇数：最小公倍数是 2 * n
        if (n % 2 == 0) {
            return n;
        } else {
            return 2 * n;
        }
    }
};
```

**关键点**：
- 代码极其简单，但面试中关键是**解释为什么**——展示你理解 LCM 的概念。
- 边界情况：n=1 → 2*1=2，n=2 → 2。都正确。

---

### 解法2: 三元运算符一行 — O(1) / O(1)

**简化解法1**：用三元运算符压缩成一行。

```cpp
class Solution {
public:
    int smallestEvenMultiple(int n) {
        return n % 2 == 0 ? n : 2 * n;
    }
};
```

---

### 解法3: 数学公式 — O(1) / O(1)

**观察规律**：`n * (1 + n % 2)` 可以统一处理：
- n 为偶数：`n * (1 + 0) = n`
- n 为奇数：`n * (1 + 1) = 2n`

```cpp
class Solution {
public:
    int smallestEvenMultiple(int n) {
        return n * (1 + n % 2);
    }
};
```

**为什么这个公式有效？**
- `n % 2` 对偶数返回 0，对奇数返回 1
- 加 1 后：偶数变成 1（乘以 1 不变），奇数变成 2（乘以 2 翻倍）
- 这是一个非常优雅的"无分支"写法

---

### 解法4: 位运算 — O(1) / O(1)

**用位运算实现**：`n & 1` 判断奇偶，`n << 1` 等价于 `n * 2`。

```cpp
class Solution {
public:
    int smallestEvenMultiple(int n) {
        // n & 1 == 0 → 偶数 → 返回 n
        // n & 1 == 1 → 奇数 → 返回 n << 1 (即 2*n)
        return (n & 1) ? (n << 1) : n;
    }
};
```

**位运算原理**：
- `n & 1` 提取 n 的最低位：偶数最低位为 0，奇数最低位为 1
- `n << 1` 左移一位等价于乘以 2
- 这种写法在底层编程和嵌入式开发中很常见

---

### 解法5: LCM 通用解 — O(log n) / O(1)

**通用方法**：使用 LCM 公式，即使题目改成 k 和 n 的最小公倍数也能解。

```cpp
class Solution {
public:
    int smallestEvenMultiple(int n) {
        // LCM(a, b) = a * b / GCD(a, b)
        return 2 * n / gcd_func(2, n);
    }
    
    // 辗转相除法求 GCD
    int gcd_func(int a, int b) {
        while (b) {
            int temp = b;
            b = a % b;
            a = temp;
        }
        return a;
    }
};

// C++17 简洁版：
// return lcm(2, n);  // <numeric> 中的 std::lcm
```

**辗转相除法的过程**（以 GCD(2, 6) 为例）：
- GCD(2, 6) → GCD(6, 2%6=2) 不对，要先保证 a >= b
- 实际上：GCD(2, 6) → a=2, b=6: a%b=2%6=2, swap → a=6, b=2
  → a%b=6%2=0, swap → a=2, b=0 → 返回 2
- LCM(2, 6) = 2*6/2 = 6 ✓

## 易错点

1. **忘记 n 本身可以是答案**
   ```cpp
   // ✗ 错误：总是返回 2*n
   return 2 * n;  // n=6 时应该返回 6 而不是 12
   
   // ✓ 正确：偶数时 n 本身就是答案
   return n % 2 == 0 ? n : 2 * n;
   ```

2. **位运算优先级问题**
   ```cpp
   // ✗ 错误：== 的优先级高于 &，导致 n & (1 == 0) → n & 0 → 0
   if (n & 1 == 0) return n;  // 编译器会警告，但逻辑已经错了
   
   // ✓ 正确：加括号
   if ((n & 1) == 0) return n;
   ```

3. **LCM 公式中的整数溢出（通用场景）**
   ```cpp
   // ✗ 潜在溢出：a * b 可能溢出（本题 n<=150 不会，但需养成习惯）
   return a * b / gcd(a, b);
   
   // ✓ 先除后乘避免溢出
   return a / gcd(a, b) * b;
   ```

4. **混淆 GCD 和 LCM**
   ```cpp
   // ✗ 用成了 GCD
   return gcd(2, n);  // GCD(2, 5) = 1，不是答案
   
   // ✓ 应该用 LCM
   return lcm(2, n);  // LCM(2, 5) = 10
   ```

5. **n=1 边界没有考虑**
   ```cpp
   // 验证：n=1 是奇数，答案应该是 2
   // n % 2 == 0 ? → 1 % 2 = 1 ≠ 0 → 2 * 1 = 2 ✓
   // n * (1 + n%2) → 1 * (1 + 1) = 2 ✓
   // 都能正确处理
   ```

## 面试追问

**Q1（基础理解）**：这道题的数学本质是什么？
> 求 LCM(2, n)。LCM(a, b) = a * b / GCD(a, b)。对于 a=2：如果 n 是偶数，GCD(2, n)=2，LCM=n；如果 n 是奇数，GCD(2, n)=1，LCM=2n。

**Q2（推广）**：如果改成求 k 和 n 的最小公倍数呢？
> 使用通用公式 `LCM(k, n) = k * n / GCD(k, n)`。GCD 用辗转相除法：`GCD(a, b) = GCD(b, a%b)`，时间 O(log min(a,b))。C++17 直接用 `std::lcm(k, n)`。注意先除后乘避免溢出。

**Q3（位运算深入）**：`n & 1` 和 `n % 2` 有什么区别？
> 功能上等价：都判断最低位。性能上在现代编译器下没有区别（编译器会自动将 `% 2` 优化为 `& 1`）。但对于负数行为不同：C++ 中 `-3 % 2 = -1`（保留符号），而 `-3 & 1 = 1`（纯位操作）。本题 n 为正数，无此问题。

**Q4（连续追问）**：如果给你 n 个数 a1, a2, ..., an，求它们的最小公倍数？
> 利用 LCM 的结合律：`LCM(a1, a2, a3) = LCM(LCM(a1, a2), a3)`。从左到右逐个合并即可。用 `reduce` 或 `accumulate` 实现很优雅。注意中间结果可能非常大，需要用 long long 或大数。

**Q5（GCD 的多种实现）**：除了辗转相除法，还有什么求 GCD 的方法？
> (1) 辗转相除法（欧几里得）：`GCD(a,b) = GCD(b, a%b)`，O(log min(a,b))。(2) 更相减损术：`GCD(a,b) = GCD(a-b, b)`（a>b），更慢但不需要除法运算。(3) 二进制 GCD（Stein 算法）：结合位移和更相减损术，避免大数除法，适合硬件实现。(4) 递归版本：`int gcd(int a, int b) { return b ? gcd(b, a%b) : a; }` 一行搞定。
