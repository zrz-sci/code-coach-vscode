# 228. 汇总区间

## 核心思路
本质上就是在一个有序无重复数组中，找出所有**连续递增子段**（每相邻两数差恰好为1），然后把每个子段格式化成字符串输出。

## 思维链
1. **读完题第一反应**：数组已排序且无重复，我需要把连续的数字合并成区间。比如 `[0,1,2,4,5,7]`，连续段是 `{0,1,2}`, `{4,5}`, `{7}`。
2. **怎么判断"连续"？**：相邻两个数差值为1就是连续的，差值 > 1 就说明断开了，这里就是一个区间的边界。
3. **自然的做法**：用一个指针标记每段的起始位置 `start`，然后让另一个指针 `i` 往后走，只要 `nums[i] == nums[i-1] + 1` 就继续走。一旦不满足，`[start, i-1]` 就是一个完整区间。
4. **格式化输出**：如果 `start == end`，输出 `"a"`；否则输出 `"a->b"`。
5. **复杂度**：每个元素只被访问一次，O(n) 时间，O(1) 额外空间（不算输出）。

这道题没有"暴力→优化"的过程，因为 O(n) 一次遍历就是最优解。区别在于写法风格：双指针 vs 单指针记录起点。

## 解法概览
| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 双指针 | start 记录区间起点，i 向前探索 | O(n) | O(1) | ⭐ 必须写出 |
| 单变量遍历 | 遍历时检查是否是区间尾部 | O(n) | O(1) | 能说出即可 |

## 关键提示
1. **数组已排序且无重复** — 这意味着连续段内的数字一定是公差为1的等差数列，判断"断裂"只需看 `nums[i] - nums[i-1] != 1`。
2. **不要忘记最后一段** — 循环结束时，最后一个区间还没被加入结果，需要在循环外处理。
3. **格式化注意**：`to_string()` 处理 int 转字符串，用 `"->"` 连接。
4. **边界**：空数组直接返回空列表。

```
示意图: nums = [0, 1, 2, 4, 5, 7]

索引:     0   1   2   3   4   5
值:       0   1   2   4   5   7
差值:         1   1   2   1   2
                      ↑       ↑
                    断裂!   断裂!

区间段:  [0------2] [4--5] [7]
输出:    "0->2"    "4->5"  "7"
```

## 解法详解

### 解法1: 双指针（start + i）— O(n) / O(1) ⭐ 面试首选

**思考过程**：最自然的思路——用 `start` 记住每段的起点，`i` 不断往后走直到断裂，然后把 `[start, i-1]` 记录下来，再让 `start = i` 开启新一段。

```cpp
class Solution {
public:
    vector<string> summaryRanges(vector<int>& nums) {
        vector<string> result;
        int n = nums.size();
        int i = 0;
        while (i < n) {
            int start = i;
            // 向后扩展，直到不再连续
            while (i + 1 < n && nums[i + 1] == nums[i] + 1) {
                i++;
            }
            // 此时 nums[start..i] 是一个连续段
            if (start == i) {
                result.push_back(to_string(nums[start]));
            } else {
                result.push_back(to_string(nums[start]) + "->" + to_string(nums[i]));
            }
            i++; // 跳到下一段的起点
        }
        return result;
    }
};
```

**关键点**：
- 内层 while 的条件是 `i + 1 < n`（先检查越界）**并且** `nums[i+1] == nums[i] + 1`（连续性）。
- 外层 `i++` 将指针移到下一段起点，不要忘记这一步！

### 解法2: 单遍历 + 记录起点 — O(n) / O(1)

**思考过程**：换个角度——遍历到每个元素时，检查它是不是某段的"结尾"（即下一个元素不存在或不连续）。如果是，就把从 `start` 到当前的区间输出。

```cpp
class Solution {
public:
    vector<string> summaryRanges(vector<int>& nums) {
        vector<string> result;
        int n = nums.size();
        if (n == 0) return result;
        
        int start = 0; // 记录当前区间起始索引
        for (int i = 0; i < n; i++) {
            // 判断当前元素是否是区间的末尾:
            // 1) 是最后一个元素，或
            // 2) 下一个元素不连续
            if (i == n - 1 || nums[i + 1] != nums[i] + 1) {
                if (start == i) {
                    result.push_back(to_string(nums[start]));
                } else {
                    result.push_back(to_string(nums[start]) + "->" + to_string(nums[i]));
                }
                start = i + 1; // 下一段从 i+1 开始
            }
        }
        return result;
    }
};
```

**关键点**：
- 这种写法用 for 循环，`start` 只在区间结束时更新，逻辑稍微不同但本质一样。
- 优点：不需要在循环体中手动 `i++` 两次，不容易写成死循环。

## 解法对比
| | 解法1: 双指针 | 解法2: 单遍历 |
|---|---|---|
| 循环结构 | while 嵌套 while | 单层 for |
| 指针移动 | 内层 while 跳过连续段 | 每次 i++ 走一步 |
| 出错风险 | 外层忘记 `i++` 导致死循环 | `start` 更新位置写错 |
| 面试推荐 | ⭐ 思路更直觉 | 代码更整洁 |

两种写法时间空间完全一样，面试时随便选一种写清楚即可。

## 易错点
1. **忘记最后一段区间**：
   - ✗ 在 for 循环中只在 `nums[i+1] != nums[i]+1` 时输出，但最后一个元素后面没有 `i+1`，最后一段丢失。
   - ✓ 解法2 中 `i == n-1` 这个条件就是专门处理最后一段的。解法1 中外层 while 自然不会遗漏。

2. **整数溢出**：
   - ✗ `nums[i+1] - nums[i] == 1` 当 nums 包含 `INT_MAX` 和 `INT_MIN` 附近的值时可能溢出。
   - ✓ `nums[i+1] == nums[i] + 1` 也有风险（`nums[i] = INT_MAX` 时 `nums[i]+1` 溢出），但题目约束数组长度最多20且值不重复，实际不会出问题。如果要严谨，用 `(long)nums[i+1] == (long)nums[i] + 1`。

3. **双指针写法忘记外层 i++**：
   - ✗ 内层 while 结束后直接回到外层 while 判断，`i` 没有前进，死循环。
   - ✓ 格式化完区间后，一定要 `i++` 移到下一段起点。

4. **空数组没判断**：
   - ✗ 直接访问 `nums[0]` 导致越界。
   - ✓ 解法1 的 while 条件 `i < n` 自然处理；解法2 需要 `if (n == 0) return {};` 或在 for 循环条件中自然跳过。

## 面试追问

**Q1: 这道题的时间复杂度是多少？能比 O(n) 更快吗？**
> O(n)，不能更快。每个元素至少需要看一次才能判断它属于哪个区间，所以 O(n) 是下界。

**Q2: 如果数组可能有重复元素怎么办？**
> 先去重再用同样的方法，或者在判断连续性时加上 `nums[i+1] == nums[i]`（相等也算连续）。去重后逻辑不变。

**Q3: 如果输入不是数组，而是一个数据流（streaming），元素按顺序到来，怎么做？**
> 维护当前区间的 `start` 和 `end`。每来一个新数字：如果等于 `end + 1`，扩展 `end`；否则，输出当前区间 `[start, end]`，开启新区间。这就是在线版本，O(1) 空间。

**Q4（进阶）: 如果要反过来做——给定区间列表，展开成数组？（即 LeetCode 228 的逆操作）**
> 解析字符串拿到 `[a, b]`，for 循环从 a 到 b 逐个加入数组。注意解析 `"->"` 分隔符。
