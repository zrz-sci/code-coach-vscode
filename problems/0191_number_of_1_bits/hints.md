# 191. 位1的个数

## 核心思路

本质上就是**计算二进制中1的个数**（Hamming Weight / popcount）。最经典的技巧是 `n & (n-1)` 可以消除最低位的1，每消一次计数加一，直到n变为0。

## 思维链

1. **读完题第一反应** → 逐位检查：每次看最低位是不是1，然后右移，循环32次。
2. **有没有更快的方法？** → `n & (n-1)` 这个操作的本质是把 n 最低位的1变成0。有几个1就循环几次，比固定32次快。
3. **还能更快吗？** → 分治法：把32位分组，每组内的1的个数用位运算并行计算，类似人口普查"分区统计再汇总"。
4. **Follow-up: 多次调用？** → 查找表或 `__builtin_popcount()`。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 逐位检查 | 循环32次，每次检查末位 | O(1) | O(1) | 能说出即可 |
| n & (n-1) | 每次消除最低位的1，循环次数=1的个数 | O(1) | O(1) | ⭐ 必须写出 |
| 分治法 | 位运算并行统计，5步完成 | O(1) | O(1) | 加分项 |

## 关键提示

1. **`n & (n-1)` 的魔法**：`n-1` 会把 n 最低位的1变成0，并把它右边的所有0变成1。`n & (n-1)` 的效果就是去掉 n 最低位的1，其余位不变。
   - 例：`n = 12 (1100)`，`n-1 = 11 (1011)`，`n & (n-1) = 8 (1000)`，去掉了最低位的1。
2. **为什么 `n & (n-1)` 比逐位检查好？** 如果 n 只有 k 个1，它只循环 k 次（而不是固定32次）。最坏情况相同（全是1），但平均情况更好。
3. **分治法的本质**：把"数1的个数"分解为"每2位中有几个1"→"每4位中有几个1"→...→"32位中有几个1"。
4. **内置函数**：C++ 的 `__builtin_popcount(n)` 编译器内置，通常直接对应CPU指令（如 x86 的 `POPCNT`），最快。

## 解法详解

### 解法1: 逐位检查 — O(1) / O(1)

**思考过程**: 最朴素的想法——检查每一位是不是1。

```cpp
class Solution {
public:
    int hammingWeight(int n) {
        int count = 0;
        for (int i = 0; i < 32; i++) {
            if (n & 1) count++;  // 检查最低位
            n >>= 1;             // 右移一位
        }
        return count;
    }
};
```

**关键点**:
- 固定循环32次，也可以用 `while (n)` 提前终止（因为高位的0不影响计数）。
- 也可以用 `n & (1 << i)` 检查第i位，效果一样。

---

### 解法2: n & (n-1) — O(1) / O(1) ⭐ 面试首选

**核心技巧**: `n & (n-1)` 一步去掉最低位的1。有几个1就循环几次。

```
示例: n = 11 (1011)
  第1次: n & (n-1) = 1011 & 1010 = 1010 (去掉末位的1), count=1
  第2次: n & (n-1) = 1010 & 1001 = 1000 (去掉次低位的1), count=2
  第3次: n & (n-1) = 1000 & 0111 = 0000 (去掉最后一个1), count=3
  n=0, 结束. 答案: 3 ✓

为什么 n & (n-1) 能去掉最低位的1？
  n     = ...1000  (最低位的1及其右边的0)
  n-1   = ...0111  (借位：最低位的1变0，右边的0全变1)
  n&(n-1)= ...0000  (最低位的1被清除，更高位不受影响)
```

```cpp
class Solution {
public:
    int hammingWeight(int n) {
        int count = 0;
        while (n) {
            n &= (n - 1);  // 消除最低位的1
            count++;
        }
        return count;
    }
};
```

**关键点**:
- 循环次数恰好等于1的个数，最优情况 O(1)（只有一个1），最坏 O(32)（全是1）。
- 这个技巧是位操作的经典考点，需要熟记。

---

### 解法3: 分治法 — O(1) / O(1)

**思路**: 并行计数。先数每2位中有几个1，再合并为每4位，再8位，再16位，最后32位。

```
示例: 8位简化 n = 10110100 (有4个1)
  第1步 (每2位统计): 01 10 01 00
         → 第0-1位有1个1, 第2-3位有2个, 第4-5位有1个, 第6-7位有0个
  第2步 (每4位合并): 0011 0001
         → 第0-3位共3个1, 第4-7位共1个1
  第3步 (每8位合并): 00000100
         → 第0-7位共4个1 → 答案: 4 ✓
```

```cpp
class Solution {
public:
    int hammingWeight(int n) {
        n = (n & 0x55555555) + ((n >> 1) & 0x55555555);  // 每2位中1的个数
        n = (n & 0x33333333) + ((n >> 2) & 0x33333333);  // 每4位中1的个数
        n = (n & 0x0f0f0f0f) + ((n >> 4) & 0x0f0f0f0f);  // 每8位中1的个数
        n = (n & 0x00ff00ff) + ((n >> 8) & 0x00ff00ff);  // 每16位中1的个数
        n = (n & 0x0000ffff) + ((n >> 16) & 0x0000ffff); // 32位中1的个数
        return n;
    }
};
```

## 易错点

1. **有符号右移的陷阱**：
   - ✗ 对 `int n` 做 `n >>= 1`，当 n 为负数时高位补1，导致死循环
   - ✓ 用 `n & (n-1)` 方法完全不依赖右移，或者用 `(unsigned)n >> 1`

2. **n & (n-1) 理解错误**：
   - ✗ 以为 `n & (n-1)` 是去掉最高位的1 → 实际是去掉**最低位**的1
   - ✓ 画出二进制理解：减1会把最低位的1变0，其右边的0变1

3. **分治法第一步理解错误**：
   - ✗ `n & 0x55555555` 不是"去掉偶数位"，而是"提取偶数位置上的bit值"
   - ✓ 第一步是把每2位看成一个小组，组内两个bit的**值相加**得到该组的popcount

4. **忘记返回类型**：
   - ✗ 返回 `bool` 类型（只判断是否有1） → 题目要求**个数**
   - ✓ 返回 `int`，计算具体有多少个1

## 面试追问

**Q1: `n & (n-1)` 还有什么应用？**
> 判断 n 是否是2的幂：`n > 0 && (n & (n-1)) == 0`。2的幂的二进制只有一个1，`n & (n-1)` 后变为0。

**Q2: Follow-up: 多次调用怎么优化？**
> 方法一：查找表。预计算0~255每个字节的popcount，拆成4个字节查表求和。
> 方法二：C++ 内置 `__builtin_popcount(n)`，通常映射到CPU的POPCNT指令，一条指令完成。

**Q3: 这个技巧和 190. Reverse Bits 有什么关系？**
> 分治法的mask完全一样（`0x55555555`, `0x33333333`, ...）。190题用来交换位置（移位+OR），191题用来累加计数（移位+ADD）。本质上都是"分治处理bit组"。

## 相关题型

- **190. 颠倒二进制位 (Reverse Bits)** — 同样的分治mask技巧，把加法换成交换。
- **231. 2的幂 (Power of Two)** — 直接用 `n & (n-1) == 0` 判断，只有一个1。
- **338. 比特位计数 (Counting Bits)** — 对 0~n 每个数计算 popcount，利用 `dp[i] = dp[i & (i-1)] + 1`。
- **461. 汉明距离 (Hamming Distance)** — 先异或，再对异或结果数1的个数，直接复用本题。
