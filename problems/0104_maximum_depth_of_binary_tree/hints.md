# 104. 二叉树的最大深度

## 核心思路

这道题本质上在问：**从根节点出发，最远能走多少层才能到达叶子节点？** 这是树的基本性质问题，理解它是解决所有树的深度/高度相关问题的基础。

## 思维链

1. **读完题第一反应**：从根到最远叶子的路径长度 = 最大深度。树是递归结构，能不能递归地解？
2. **递归直觉**：一棵树的最大深度 = 左子树最大深度和右子树最大深度中较大的那个 + 1（加上根节点自身这一层）。这就是经典的"自底向上"后序遍历思路。
3. **能不能不用递归？** 可以！用 BFS 层序遍历，数一共有多少层，最后的层数就是最大深度。
4. **还有别的方式吗？** DFS 迭代版，用栈模拟递归，同时记录每个节点所在的深度。
5. **三种方式的本质**：都是遍历整棵树，区别只在于遍历方式（递归DFS / 迭代DFS / BFS）和信息传递方式（返回值 / 栈记录 / 层计数）。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| DFS 递归（后序） | 左右子树深度取 max + 1 | O(n) | O(h) | ⭐ 必须写出 |
| BFS 层序遍历 | 逐层遍历，计数层数 | O(n) | O(w) | ⭐ 必须写出 |
| DFS 迭代（显式栈） | 用栈模拟递归，记录深度 | O(n) | O(h) | 能说出即可 |

> h = 树的高度（最坏 O(n)，平衡时 O(log n)），w = 树的最大宽度（最坏 O(n/2)）

## 关键提示

- **提示1**：想想一棵树的深度和它左右子树的深度有什么关系？能写出递推公式吗？
- **提示2**：递归终止条件是什么？空节点的深度是多少？
- **提示3**：如果不用递归，BFS 天然是"一层一层"处理的，数层数就是答案。
- **提示4**：DFS 迭代时，栈里需要存什么额外信息？（不只是节点，还有……）

**示例树的结构：**
```
//       3           深度1
//      / \
//     9   20        深度2
//        /  \
//       15   7      深度3
//
// 最大深度 = 3（路径: 3 → 20 → 15 或 3 → 20 → 7）
```

## 解法详解

### 解法1: DFS 递归（后序遍历，自底向上） — O(n) / O(h) ⭐ 面试首选

**思考过程**：树是递归定义的结构，天然适合递归求解。一棵树的最大深度 = max(左子树深度, 右子树深度) + 1。这就是后序遍历——先处理左右子树（拿到它们的深度），再处理当前节点（取 max + 1）。

```
// 递归过程可视化（示例1）:
//
//       3
//      / \
//     9   20
//        /  \
//       15   7
//
// maxDepth(3):
//   ├─ maxDepth(9):
//   │    ├─ maxDepth(NULL) → 0
//   │    └─ maxDepth(NULL) → 0
//   │    → max(0, 0) + 1 = 1
//   └─ maxDepth(20):
//        ├─ maxDepth(15):
//        │    ├─ maxDepth(NULL) → 0
//        │    └─ maxDepth(NULL) → 0
//        │    → max(0, 0) + 1 = 1
//        └─ maxDepth(7):
//             ├─ maxDepth(NULL) → 0
//             └─ maxDepth(NULL) → 0
//             → max(0, 0) + 1 = 1
//        → max(1, 1) + 1 = 2
//   → max(1, 2) + 1 = 3  ✓
```

```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        // 终止条件: 空节点深度为0
        if (!root) return 0;
        
        // 后序遍历: 先递归求左右子树深度，再合并
        int leftDepth = maxDepth(root->left);
        int rightDepth = maxDepth(root->right);
        
        // 当前树的深度 = 较深的子树 + 1（自身这一层）
        return max(leftDepth, rightDepth) + 1;
    }
};
```

**递归三要素：**
- **返回值**: int，表示以当前节点为根的子树的最大深度
- **终止条件**: `root == nullptr` 时返回 0
- **单层逻辑**: 取左右子树深度的较大值 + 1

**关键点**: 这是"自底向上"的思路——从叶子节点开始往上汇总信息。空节点返回 0 是 base case。

---

### 解法2: BFS 层序遍历 — O(n) / O(w) ⭐ 面试必会

**思考过程**：不用递归怎么办？最大深度 = 树有多少层。BFS 天然按层遍历，每处理完一层，深度计数器 +1，遍历完就得到答案。

```
// BFS 层序遍历过程:
//       3
//      / \
//     9   20
//        /  \
//       15   7
//
// 初始队列: [3]           depth=0
// 第1层处理: 弹出3, 加入9,20  → 队列[9,20]    depth=1
// 第2层处理: 弹出9,20, 加入15,7 → 队列[15,7]  depth=2
// 第3层处理: 弹出15,7, 无子节点 → 队列[]       depth=3
// 队列空, 返回 depth=3 ✓
```

```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (!root) return 0;
        
        queue<TreeNode*> q;
        q.push(root);
        int depth = 0;
        
        while (!q.empty()) {
            // 当前层的节点数量
            int levelSize = q.size();
            
            // 处理当前层的所有节点
            for (int i = 0; i < levelSize; i++) {
                TreeNode* node = q.front();
                q.pop();
                // 把下一层的节点加入队列
                if (node->left)  q.push(node->left);
                if (node->right) q.push(node->right);
            }
            
            // 处理完一层，深度 +1
            depth++;
        }
        
        return depth;
    }
};
```

**关键点**: 用 `levelSize` 在 while 循环内再套一个 for 循环来分层。这是 BFS 层序遍历的标准模板，后续很多题（如 102. 层序遍历、111. 最小深度）都用同样的框架。

### 解法3: DFS 迭代（显式栈） — O(n) / O(h)

**从解法1转化**：递归本质上就是系统帮你维护了一个调用栈。我们可以自己用一个显式栈来模拟这个过程。栈中需要存储的是 `(节点, 当前深度)` 这个二元组。

```
// DFS 迭代过程（前序遍历顺序）:
//       3
//      / \
//     9   20
//        /  \
//       15   7
//
// 栈: [(3,1)]                        maxD=0
// 弹出(3,1), maxD=1, 压入(20,2),(9,2)  栈: [(20,2),(9,2)]
// 弹出(9,2), maxD=2, 无子节点          栈: [(20,2)]
// 弹出(20,2), maxD=2, 压入(7,3),(15,3) 栈: [(7,3),(15,3)]
// 弹出(15,3), maxD=3, 无子节点         栈: [(7,3)]
// 弹出(7,3), maxD=3, 无子节点          栈: []
// 返回 maxD=3 ✓
```

```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (!root) return 0;
        
        // 栈中存储 (节点, 该节点所在的深度)
        stack<pair<TreeNode*, int>> stk;
        stk.push({root, 1});
        int maxD = 0;
        
        while (!stk.empty()) {
            auto [node, depth] = stk.top();
            stk.pop();
            
            // 每次弹出节点时更新最大深度
            maxD = max(maxD, depth);
            
            // 先压右再压左，这样左边先被弹出（前序遍历顺序）
            if (node->right) stk.push({node->right, depth + 1});
            if (node->left)  stk.push({node->left, depth + 1});
        }
        
        return maxD;
    }
};
```

**关键点**: 栈里不只存节点，还要存深度信息。这是迭代 DFS 处理"与深度相关"的问题的通用技巧。

## 解法对比

| | DFS 递归 | BFS 层序 | DFS 迭代 |
|---|---|---|---|
| 思维难度 | 最低，递归公式直觉 | 稍高，需要分层技巧 | 中等，栈+深度配对 |
| 代码量 | 3 行核心代码 | 约 12 行 | 约 10 行 |
| 空间 | O(h) 调用栈 | O(w) 队列最宽层 | O(h) 显式栈 |
| 适用场景 | 面试首选，最简洁 | 当你需要按层处理时 | 练习栈模拟递归 |
| 栈溢出风险 | 极端深树可能溢出 | 无此风险 | 无此风险 |

> **面试推荐**：先写递归解法（30秒写完展示基本功），然后主动说"我也可以用 BFS 层序遍历来做"展示多解能力。

## 易错点

1. **忘记处理空树**
   - ✗ 直接访问 `root->left`，当 `root == nullptr` 时崩溃
   - ✓ 第一行 `if (!root) return 0;`

2. **BFS 中不分层，直接计数节点**
   - ✗ 每弹出一个节点 `depth++`（这样 depth = 总节点数，不是层数）
   - ✓ 用 `levelSize = q.size()` 配合内层 for 循环来分层，每层结束后 `depth++`

3. **DFS 迭代忘记携带深度信息**
   - ✗ 栈里只存 `TreeNode*`，无法得知当前深度
   - ✓ 存 `pair<TreeNode*, int>`，第二个元素是该节点的深度

4. **混淆深度和高度**
   - 深度：从根到当前节点的距离（自顶向下数）
   - 高度：从当前节点到最远叶子的距离（自底向上数）
   - 根节点的高度 = 树的最大深度（对本题来说两个概念数值相同）

## 面试追问

**Q1（基础理解）**: "递归的时间和空间复杂度分别是多少？最坏情况什么时候发生？"
> 时间 O(n)：每个节点恰好访问一次。空间 O(h)：递归调用栈的深度。最坏 O(n) 发生在退化为链表（每个节点只有一个孩子）时。

**Q2（换种方式）**: "如果递归栈深度可能溢出（树极深），你怎么办？"
> 改用 BFS 层序遍历或 DFS 迭代（显式栈在堆上分配，不受调用栈限制），空间复杂度变为 O(w) 或 O(h) 但不会栈溢出。

**Q3（变体）**: "如果改成求最小深度（111题），代码需要改哪里？"
> 递归版不能简单把 `max` 改成 `min`！因为如果一个子树为空（深度 0），取 min 会错误地返回 0。需要额外判断：如果左子树空就只看右子树深度，反之亦然。BFS 版则更简洁——遇到第一个叶子节点（左右都空）直接返回当前层数。

**Q4（拓展）**: "如果不是二叉树，是 N 叉树呢？（559题）"
> 递归框架完全一样，只是把 `max(left, right)` 改成遍历所有 children 取最大值。BFS 版本几乎不用改。

## 相关题型

- **111. 二叉树的最小深度** — 复用同样的递归/BFS 框架，区别：递归版需要处理单侧子树为空的特殊情况（不能直接 `max` 改 `min`）；BFS 版找到第一个叶子就返回
- **559. N 叉树的最大深度** — 复用同样的递归思路，区别：children 从 left/right 变成一个 vector
- **110. 平衡二叉树** — 复用本题的递归求深度函数，在此基础上判断左右子树深度差是否 ≤ 1
- **102. 二叉树的层序遍历** — 复用解法2 的 BFS 分层模板，区别：不只计数，还要收集每层节点值
