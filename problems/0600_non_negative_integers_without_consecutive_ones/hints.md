# 600. 不含连续1的非负整数 (Non-negative Integers without Consecutive Ones)

## 核心思路
数位 DP + 斐波那契数列。将 n 转为二进制，从高位到低位逐位决策，利用斐波那契数列预计算"k 位二进制无连续 1 的数"的个数。

## 思维链
1. 问题转化：[0, n] 中二进制无连续 1 的数的个数 → 数位 DP
2. k 位二进制串（最高位为 1）中无连续 1 的个数 = fib(k+1)（斐波那契）
3. 预计算斐波那契数组 f[0..32]
4. 从 n 的最高位开始逐位扫描：
   - 当前位是 1：可以选 0（后续位自由）→ 加上 f[剩余位数]
   - 如果前一位也是 1：n 本身已含连续 1，停止
   - 当前位是 0：继续下一位
5. 如果扫描到最后都没有连续 1，n 自身也合法，结果 +1

## 解法概览表

| 解法 | 思路 | 时间复杂度 | 空间复杂度 | 难度 |
|------|------|-----------|-----------|------|
| 斐波那契+逐位统计 ⭐ | 二进制位从高到低，遇 1 累加 fib | O(log n) | O(log n) | Hard |
| 数位 DP（记忆化搜索） | dfs(pos, prev, tight) | O(log n) | O(log n) | Hard |

## 关键提示
1. **斐波那契关系**: 长度为 k 的无连续 1 二进制串数量 = fib(k+2)
2. **逐位决策**: 遇到 1 时，可以选 0（低位自由），也可以选 1（继续往下）
3. **连续 1 终止**: 如果 n 的二进制中出现连续两个 1，当前位选 1 后剩余部分不可能有合法数

## 解法详解

### 解法一：斐波那契 + 逐位统计 ⭐
```
预计算 f[0]=1, f[1]=2, f[i]=f[i-1]+f[i-2]
// f[k] = (k+1) 位二进制串中以 0 或 1 开头且无连续 1 的数量

将 n 转为二进制位数组 bits[]
result = 0, prevBit = 0
for i from 最高位 to 0:
    if bits[i] == 1:
        result += f[i]  // 当前位选 0 的合法数
        if prevBit == 1:
            return result  // 连续 1，n 本身不合法
    prevBit = bits[i]
return result + 1  // n 自身也合法
```

### 解法二：数位 DP（记忆化搜索）
```
dfs(pos, prev, tight):
    // pos: 当前位  prev: 上一位是否为 1  tight: 是否受上界约束
    if pos < 0: return 1
    if !tight && memo[pos][prev] != -1: return memo[pos][prev]
    limit = tight ? bits[pos] : 1
    result = 0
    for d in 0..limit:
        if d == 1 && prev == 1: continue  // 跳过连续 1
        result += dfs(pos-1, d==1, tight && d==limit)
    memo[pos][prev] = result (if !tight)
    return result
```

## 易错点

| ✗ 错误写法 | ✓ 正确写法 | 原因 |
|-----------|-----------|------|
| 忘记最后 +1 | `return result + 1` | 如果 n 本身合法，需要计入 |
| f[0]=0, f[1]=1 | f[0]=1, f[1]=2 | 这里 f 是无连续 1 的计数，不是标准 fib |
| 从低位到高位 | 从最高位到最低位 | 必须从高位开始决策 |
| 不检查连续 1 | `if prevBit == 1: return result` | 连续 1 后不需要继续 |

## 面试追问

**Q1: 为什么无连续 1 的计数和斐波那契有关？**
设 a(k) = k 位无连续 1 的二进制串数。最高位为 0 时有 a(k-1) 种；最高位为 1 时第二位必须为 0，有 a(k-2) 种。所以 a(k) = a(k-1) + a(k-2)，初值 a(1)=2, a(0)=1。

**Q2: 如果改为十进制无连续相同数字的非负整数个数呢？**
用标准数位 DP: dfs(pos, prevDigit, tight, leadingZero)。每位有 0-9 十种选择，跳过与前一位相同的数字。

**Q3: n 的范围是 10^18 怎么办？**
用 long long，斐波那契数组长度改为 64。算法本身 O(log n) 不受影响。
