# 764. 最大加号标志 (Largest Plus Sign)

## 核心思路

在一个 n x n 的网格中，除了给定的 mines 位置为 0 外其余都是 1，需要找到最大的十字形（加号）标志的阶数。**动态规划预处理四个方向的连续 1 的臂长**是本题的核心。对于每个位置 `(r, c)`，分别计算从该位置向上、向下、向左、向右连续 1 的个数，四个方向的**最小值**即为以该位置为中心的加号阶数。最终取所有位置的最大值。

## 思维链

1. **暴力思路**：对每个位置、每个可能的阶数 k，检查四个方向是否都有 k 个连续 1。时间 O(n^3)
2. **DP 优化**：预处理每个位置四个方向的连续 1 长度，将检查降为 O(1)
3. **单数组优化**：可以只用一个 n x n 数组，依次从四个方向扫描，每次取 min
4. **构建网格**：先初始化全 1 网格，再将 mines 位置设为 0
5. **四方向 DP**：
   - 从左到右扫描：`left[r][c] = grid[r][c] == 0 ? 0 : left[r][c-1] + 1`
   - 从右到左扫描：`right[r][c] = grid[r][c] == 0 ? 0 : right[r][c+1] + 1`
   - 从上到下扫描：`up[r][c] = grid[r][c] == 0 ? 0 : up[r-1][c] + 1`
   - 从下到上扫描：`down[r][c] = grid[r][c] == 0 ? 0 : down[r+1][c] + 1`
6. **合并结果**：`ans = max(min(left, right, up, down))` 遍历所有位置

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 四方向 DP（单数组优化） | O(n^2) | O(n^2) | 最优解，空间节省 |
| 四方向 DP（四数组） | O(n^2) | O(n^2) | 代码最清晰 |
| 暴力扩展 | O(n^3) | O(n^2) | 简单直接，可能超时 |

## 关键提示

1. **四方向连续 1 长度**：这是经典的 DP 预处理模式，类似于"炸弹人"问题
2. **取四方向最小值**：加号的阶数受限于最短的那条臂
3. **mines 用 set 存储**：将 mines 转为 HashSet 可以 O(1) 判断某位置是否为 0
4. **单数组技巧**：初始化 `dp[r][c] = n`，四次扫描时不断取 min，最终结果即为答案
5. **边界处理**：位于网格边缘的位置，某些方向的臂长天然受限
6. **阶数定义**：阶数 k 表示中心加上每条臂长为 k-1，所以阶数 1 就是单个格子本身

## 解法详解

### 解法一：四方向 DP + 单数组优化（最优解）

**思路**：使用一个 n x n 的 DP 数组，初始化为 n（最大可能臂长）。分别从四个方向扫描，维护当前方向的连续 1 计数，并不断将 `dp[r][c]` 与当前计数取 min。四次扫描后，`dp[r][c]` 就是以 `(r,c)` 为中心的最大加号阶数。

**步骤**：
1. 初始化 `dp[n][n]` 全部为 n
2. 将 mines 位置的 dp 值设为 0
3. 四次扫描（左右上下），每次维护连续 1 计数 `count`
4. 扫描时 `dp[r][c] = min(dp[r][c], count)`，遇到 mine 时 `count` 重置为 0
5. 结果取所有 `dp[r][c]` 的最大值

**时间复杂度**：O(n^2)，四次遍历网格  
**空间复杂度**：O(n^2)，DP 数组 + mines 集合

### 解法二：四数组版本

**思路**：分别用 `left`、`right`、`up`、`down` 四个数组存储每个位置四个方向的连续 1 长度，最后遍历取 min 的 max。

**步骤**：
1. 构建 n x n 网格，mines 位置为 0
2. 四次遍历分别填充 left/right/up/down
3. 最终遍历取 `min(left, right, up, down)` 的全局最大值

**优点**：逻辑更清晰，便于理解和调试  
**缺点**：需要四倍空间

### 解法三：暴力扩展法

**思路**：对每个非 mine 位置，从中心向四个方向逐步扩展，找到最大可行阶数。

**时间复杂度**：O(n^3)，每个位置最多扩展 O(n) 步

## 易错点

1. **mines 的坐标格式**：`mines[i] = [xi, yi]`，注意是行列坐标，不要搞反
2. **空 mines 数组**：当 mines 为空时，所有位置都是 1，答案为 `(n+1)/2`
3. **n=1 时的特殊情况**：如果 `mines = [[0,0]]` 则答案为 0，否则为 1
4. **DP 初始化**：单数组优化时，mines 位置必须初始化为 0 而非 n
5. **连续计数重置**：遇到 mine 时 count 要重置为 0，不是跳过继续
6. **结果含义**：返回的是阶数（order），不是臂长。阶数 1 就是单个格子
7. **set vs unordered_set**：使用 `set<int>` 会导致查找 O(log n)，用 `unordered_set` 可以 O(1)

## 面试追问

1. **Q: 如果不用 DP，暴力法的时间复杂度是多少？**
   A: O(n^3)。对每个位置 O(n^2) 个，每个位置最多扩展 O(n) 步检查四个方向

2. **Q: 能否用二分搜索优化？**
   A: 可以对每个位置二分加号阶数 k，但仍需要 O(1) 判断四个方向是否有 k 个连续 1，需要前缀和预处理。总时间 O(n^2 * log n)

3. **Q: 这个思路能否推广到"最大的 X 形"问题？**
   A: 可以，改为对角线方向的 DP：左上、右上、左下、右下四个方向的连续 1

4. **Q: 如果网格可以动态修改（翻转 0/1），如何维护答案？**
   A: 需要更复杂的数据结构，无法简单用 DP。可以考虑分块或对受影响的行列重新计算

5. **Q: 空间能否优化到 O(n)？**
   A: DP 数组至少需要 O(n^2)（因为需要同时存储所有位置的中间结果用于后续方向的 min 操作），所以 O(n^2) 是下界
