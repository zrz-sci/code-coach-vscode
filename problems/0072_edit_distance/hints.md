# 72. 编辑距离 (Edit Distance)

## 核心思路

本质上是一个**两个字符串匹配**的问题：给定三种操作（插入、删除、替换），求将 word1 变成 word2 所需的最少操作次数。这是经典的二维 DP 问题，也叫 **Levenshtein 距离**。

## 思维链

1. **读完题第一反应**：两个字符串，每次可以对 word1 做三种操作，求最少操作数。这是一个"最优决策"问题——每一步有多种选择，需要找到全局最优。→ 暴力递归穷举所有可能的操作序列。

2. **暴力递归怎么写？** 比较 word1[i] 和 word2[j]：
   - 如果相等，都往前走，不需要操作
   - 如果不等，三种选择：插入（j+1）、删除（i+1）、替换（i+1, j+1），取最小值+1
   - 这棵递归树最坏情况是 3^(m+n) 分支，完全不可行。

3. **发现重叠子问题**：递归过程中 `(i, j)` 这对参数会被反复计算。例如 `solve(2,3)` 可能从 `solve(1,2)` 的替换分支和 `solve(2,2)` 的删除分支都走到。→ **加备忘录**，记忆化搜索。

4. **翻译成递推**：定义 `dp[i][j]` = word1 前 i 个字符变成 word2 前 j 个字符的最少操作数。状态转移：
   - 字符相同：`dp[i][j] = dp[i-1][j-1]`
   - 字符不同：`dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])`

5. **初始化**：`dp[i][0] = i`（word1 前 i 个字符变成空串，需要删 i 次），`dp[0][j] = j`（空串变成 word2 前 j 个字符，需要插 j 次）。

6. **空间优化**：`dp[i][j]` 只依赖上一行和当前行的前一个，可以用一维数组 + 一个变量滚动。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力递归 | 穷举三种操作的所有组合 | O(3^(m+n)) | O(m+n) | 能说出即可 |
| 记忆化搜索 | 递归+备忘录 | O(m×n) | O(m×n) | 能说出即可 |
| 二维 DP | 自底向上填表 | O(m×n) | O(m×n) | ⭐ 必须写出 |
| 一维 DP（空间优化） | 滚动数组 | O(m×n) | O(min(m,n)) | 加分项 |

## 关键提示

1. **状态定义的关键**：`dp[i][j]` 代表的是 word1 的**前 i 个字符**（不是下标 i）和 word2 的**前 j 个字符**之间的编辑距离。所以 dp 数组大小是 `(m+1) × (n+1)`。

2. **三种操作的对应关系**：
   - 插入：`dp[i][j-1] + 1` — word1 前 i 个已经匹配 word2 前 j-1 个，再插一个字符匹配 word2[j]
   - 删除：`dp[i-1][j] + 1` — 删掉 word1[i]，看 word1 前 i-1 个怎么匹配 word2 前 j 个
   - 替换：`dp[i-1][j-1] + 1` — 把 word1[i] 替换成 word2[j]，然后看前面的

3. **字符相等时不需要操作**：`dp[i][j] = dp[i-1][j-1]`，但注意这**不一定**比其他三种操作小（实际上一定不会更大，因为其他路径多了一步操作）。

4. **空间优化的难点**：`dp[i-1][j-1]` 在一维数组滚动时会被覆盖，需要一个额外变量 `prev` 保存。

5. **填表方向**：从左到右、从上到下，保证 `dp[i-1][j-1]`、`dp[i-1][j]`、`dp[i][j-1]` 都已计算。

## 解法详解

### 解法1: 暴力递归 — O(3^(m+n)) / O(m+n)

**思考过程**：最自然的思路——站在 word1 的第 i 个字符和 word2 的第 j 个字符，看看当前字符是否匹配，不匹配就尝试三种操作，递归求解。

```cpp
class Solution {
public:
    int minDistance(string word1, string word2) {
        return dfs(word1, word2, word1.size(), word2.size());
    }
    
    // i: word1 前 i 个字符, j: word2 前 j 个字符
    int dfs(string& w1, string& w2, int i, int j) {
        // base case: 某个字符串为空
        if (i == 0) return j;  // word1 为空，需要插入 j 个字符
        if (j == 0) return i;  // word2 为空，需要删除 i 个字符
        
        // 字符相同，不需要操作，直接看前面的
        if (w1[i - 1] == w2[j - 1]) {
            return dfs(w1, w2, i - 1, j - 1);
        }
        
        // 字符不同，三种操作取最小
        return 1 + min({
            dfs(w1, w2, i, j - 1),     // 插入: word1 不动, word2 往前缩
            dfs(w1, w2, i - 1, j),     // 删除: word1 往前缩, word2 不动
            dfs(w1, w2, i - 1, j - 1)  // 替换: 都往前缩
        });
    }
};
```

**关键点**：这个解法能正确得出答案，但指数级时间复杂度，只能过非常短的字符串。它的价值在于帮我们理清递归结构，为 DP 打基础。

---

### 解法2: 记忆化搜索 — O(m×n) / O(m×n)

**从解法1优化**：递归过程中大量 `(i, j)` 被重复计算。加一个二维数组 `memo[i][j]` 记录已经算过的结果。

```cpp
class Solution {
public:
    int minDistance(string word1, string word2) {
        int m = word1.size(), n = word2.size();
        // -1 表示还没计算过
        vector<vector<int>> memo(m + 1, vector<int>(n + 1, -1));
        return dfs(word1, word2, m, n, memo);
    }
    
    int dfs(string& w1, string& w2, int i, int j, vector<vector<int>>& memo) {
        if (i == 0) return j;
        if (j == 0) return i;
        if (memo[i][j] != -1) return memo[i][j];  // 已经算过，直接返回
        
        if (w1[i - 1] == w2[j - 1]) {
            memo[i][j] = dfs(w1, w2, i - 1, j - 1, memo);
        } else {
            memo[i][j] = 1 + min({
                dfs(w1, w2, i, j - 1, memo),
                dfs(w1, w2, i - 1, j, memo),
                dfs(w1, w2, i - 1, j - 1, memo)
            });
        }
        return memo[i][j];
    }
};
```

**关键点**：时间从指数级降到 O(m×n)，因为每个 `(i, j)` 只计算一次。这和自底向上 DP 是等价的，只是遍历顺序不同。

---

### 解法3: 二维 DP（自底向上）— O(m×n) / O(m×n) ⭐ 面试首选

**从记忆化搜索翻译**：把递归改成 for 循环填表。

```
// dp 填表方向和依赖关系:
//
//        ""   r   o   s
//    ""   0   1   2   3      ← dp[0][j] = j (空串变成 word2 前 j 个)
//     h   1   1   2   3
//     o   2   2   1   2      dp[i][j] 依赖三个方向:
//     r   3   2   2   2        ↖ dp[i-1][j-1] (替换/相同)
//     s   4   3   3   2        ← dp[i][j-1]   (插入)
//     e   5   4   4   3        ↑ dp[i-1][j]   (删除)
//                    ↑ 答案
//
// 填表方向: 从左到右, 从上到下
```

```cpp
class Solution {
public:
    int minDistance(string word1, string word2) {
        int m = word1.size(), n = word2.size();
        // dp[i][j]: word1 前 i 个字符 → word2 前 j 个字符的最少操作数
        vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
        
        // base case: 空串变成另一个字符串
        for (int i = 0; i <= m; i++) dp[i][0] = i;  // 删除 i 次
        for (int j = 0; j <= n; j++) dp[0][j] = j;  // 插入 j 次
        
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (word1[i - 1] == word2[j - 1]) {
                    // 字符相同，不需要额外操作
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    // 三种操作取最小 + 1
                    dp[i][j] = 1 + min({
                        dp[i][j - 1],     // 插入
                        dp[i - 1][j],     // 删除
                        dp[i - 1][j - 1]  // 替换
                    });
                }
            }
        }
        
        return dp[m][n];
    }
};
```

**关键点**：
- 注意下标：`dp[i][j]` 对应 `word1[i-1]` 和 `word2[j-1]`，因为 dp 的第 0 行/列代表空串。
- 三种操作的含义要理解透：插入是"我假设在 word1 的当前位置插入了 word2[j]，所以 word2 匹配了一个字符 j-1"；删除是"跳过 word1[i]"；替换是"把 word1[i] 换成 word2[j]，两边都匹配了一个"。

### 解法4: 一维 DP（空间优化）— O(m×n) / O(min(m,n))

**从解法3优化**：`dp[i][j]` 只依赖 `dp[i-1][j-1]`（左上）、`dp[i-1][j]`（上）、`dp[i][j-1]`（左）。所以只需要一行数组，但左上角的值会被覆盖，需要用 `prev` 变量保存。

```
// 一维滚动过程 (以 "horse" → "ros" 为例):
//
// 初始 dp[]: [0, 1, 2, 3]  ← 对应 dp[0][0..3]
//
// 处理 'h': prev 保存左上角
//   j=1('r'): prev=0, dp[1]=min(dp[0]+1, dp[1]+1, prev+1)=1
//   j=2('o'): prev=1, dp[2]=min(dp[1]+1, dp[2]+1, prev+1)=2
//   j=3('s'): prev=2, dp[3]=min(dp[2]+1, dp[3]+1, prev+1)=3
//   dp[]: [1, 1, 2, 3]
//
// ... 继续处理 'o', 'r', 's', 'e' ...
```

```cpp
class Solution {
public:
    int minDistance(string word1, string word2) {
        int m = word1.size(), n = word2.size();
        // 确保 n 是较短的那个，节省空间
        if (m < n) return minDistance(word2, word1);
        
        vector<int> dp(n + 1);
        for (int j = 0; j <= n; j++) dp[j] = j;
        
        for (int i = 1; i <= m; i++) {
            int prev = dp[0];   // 保存 dp[i-1][0]，即左上角起始值
            dp[0] = i;          // dp[i][0] = i (删除 i 次)
            
            for (int j = 1; j <= n; j++) {
                int temp = dp[j];  // 保存当前值，下一轮作为 prev（左上角）
                
                if (word1[i - 1] == word2[j - 1]) {
                    dp[j] = prev;  // 不操作，等于左上角
                } else {
                    dp[j] = 1 + min({
                        dp[j - 1],  // 插入（左边）
                        dp[j],      // 删除（上边，还没被覆盖）
                        prev        // 替换（左上角）
                    });
                }
                
                prev = temp;  // 更新 prev 为下一个位置的左上角
            }
        }
        
        return dp[n];
    }
};
```

**关键点**：`prev` 变量的维护是这个优化最容易写错的地方。每次内层循环开始前，`dp[j]` 还是上一行的值（即"上方"），`prev` 是上一行上一列的值（即"左上角"），`dp[j-1]` 是当前行上一列的值（即"左方"，因为已经被更新了）。

## 解法对比

| | 暴力递归 | 记忆化搜索 | 二维 DP | 一维 DP |
|---|---|---|---|---|
| 时间 | O(3^(m+n)) | O(m×n) | O(m×n) | O(m×n) |
| 空间 | O(m+n) 栈 | O(m×n) | O(m×n) | O(min(m,n)) |
| 代码难度 | 简单 | 中等 | 中等 | 中等偏难 |
| 面试推荐 | 说思路 | 可以 | ⭐首选 | 追问时写 |

**核心递进关系**：暴力递归 → 发现重叠子问题 → 记忆化 → 翻译成填表 → 观察依赖关系做空间优化。这四步是所有 DP 题的通用学习路径。

## 易错点

1. **下标偏移**：
   - ✗ `if (word1[i] == word2[j])` — 当 i,j 从 1 开始时，对应的字符应该是 `[i-1]` 和 `[j-1]`
   - ✓ `if (word1[i-1] == word2[j-1])`

2. **初始化遗漏**：
   - ✗ 只初始化 `dp[0][j] = j`，忘了 `dp[i][0] = i`
   - ✓ 两个方向都要初始化，因为空串和非空串之间的编辑距离就是非空串的长度

3. **空间优化时 prev 更新顺序**：
   - ✗ 先更新 `dp[j]` 再保存 `temp = dp[j]`，导致 prev 拿到的是新值
   - ✓ 必须先 `temp = dp[j]`（保存旧值），再更新 `dp[j]`，最后 `prev = temp`

4. **字符相同时也做 min 操作**：
   - ✗ `dp[i][j] = 1 + min(dp[i-1][j-1], dp[i-1][j], dp[i][j-1])` — 相同字符也加了 1
   - ✓ 相同字符时 `dp[i][j] = dp[i-1][j-1]`，不加 1，不需要取 min（因为不操作一定不比操作差）

## 面试追问

**Q1: 能解释一下三种操作分别对应 DP 转移的哪一项吗？**

> - `dp[i][j-1] + 1`（插入）：word1 前 i 个字符已经变成了 word2 前 j-1 个字符，现在在 word1 末尾插入 word2[j]，完成匹配
> - `dp[i-1][j] + 1`（删除）：word1 前 i-1 个字符变成 word2 前 j 个字符，然后删掉 word1[i]
> - `dp[i-1][j-1] + 1`（替换）：word1 前 i-1 个变成 word2 前 j-1 个，然后 word1[i] 替换成 word2[j]
>
> 对称理解：word1 的插入等价于 word2 的删除，所以实际上"插入"和"删除"是对称的两个操作。

**Q2: word1 上的"插入"操作，为什么对应 `dp[i][j-1]` 而不是 `dp[i+1][j]`？**

> 因为 dp 定义的是"word1 前 i 个字符变成 word2 前 j 个字符"。插入一个字符不改变 word1 已有字符的匹配，只是多匹配了 word2 的一个字符。所以等价于"word1 前 i 个已经搞定了 word2 前 j-1 个，再多一步插入搞定 word2[j]"。

**Q3: 能否 O(min(m,n)) 空间？如果要输出具体操作序列呢？**

> - 空间优化到 O(min(m,n))：见解法4，用一维数组滚动。
> - 输出操作序列：需要保留完整的 dp 表，然后从 `dp[m][n]` 反向回溯路径。每一步看是从哪个方向转移过来的（左上/上/左），对应的操作就是（相同/替换、删除、插入）。空间无法优化，必须 O(m×n)。

**Q4: 如果只允许插入和删除（不允许替换），编辑距离是多少？**

> 替换可以看作"删一个+插一个"，代价为 2。所以不允许替换时，状态转移去掉替换项：`dp[i][j] = min(dp[i-1][j]+1, dp[i][j-1]+1)`，相同字符时仍然 `dp[i][j] = dp[i-1][j-1]`。结果等价于 `m + n - 2 * LCS(word1, word2)`，其中 LCS 是最长公共子序列长度。
