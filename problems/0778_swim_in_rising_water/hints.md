# 778. 水位上升的泳池中游泳 (Swim in Rising Water)

## 核心思路

本题要求从左上角到右下角的路径中，使路径上**最大高度最小化**。这是一个经典的**最小化路径最大值 (minimax path)** 问题，可以用三种范式解决：优先队列 BFS（Dijkstra 变种）、二分答案 + BFS/DFS 判定、并查集按权值排序合并。

## 思维链

1. **问题转化**：时间 `t` 即水位，要能通过某个格子，水位必须 >= 该格子的高度。所以答案 = 路径上所有格子高度的最大值的最小值。
2. **类比最短路**：这不是求最短路径，而是求"最大边权最小的路径"（minimax path）。可以把每个格子看作节点，高度看作"通过代价"。
3. **贪心直觉**：优先探索高度较低的格子，用最小堆维护候选格子。每次取出堆顶（当前最低水位的候选格子），更新答案为到目前为止路径上的最大高度。
4. **二分视角**：答案具有单调性——如果水位 `t` 能到达终点，那么 `t+1` 也一定能。因此可以二分答案 `t`，然后用 BFS/DFS 判定是否能只走高度 <= `t` 的格子从起点到终点。
5. **并查集视角**：将所有格子按高度排序，依次加入图中。每加入一个格子，和已加入的邻居合并。当起点和终点在同一连通分量中时，当前格子的高度就是答案。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 优先队列 BFS | O(n^2 log n) | O(n^2) | 最直观的解法，Dijkstra 变种 |
| 二分答案 + BFS | O(n^2 log n) | O(n^2) | 二分水位，BFS 判定连通性 |
| 并查集 | O(n^2 * alpha(n^2)) | O(n^2) | 按高度排序后逐步合并 |

## 关键提示

1. 每个格子的值唯一且在 `[0, n^2-1]` 范围内，这个性质对并查集解法很关键
2. 答案的下界是 `max(grid[0][0], grid[n-1][n-1])`——起点和终点的高度必须被覆盖
3. 优先队列 BFS 中，每个格子只需入队一次（visited 标记），不需要松弛操作
4. 二分答案的搜索范围是 `[max(grid[0][0], grid[n-1][n-1]), n*n - 1]`
5. n <= 50，数据量小，三种方法都能过

## 解法详解

### 解法一：优先队列 BFS（Dijkstra 变种）

**核心思想**：将起点放入最小堆，每次弹出当前水位最低的格子，更新答案为路径上的最大高度。当到达终点时返回答案。

**算法步骤**：
1. 将 `(grid[0][0], 0, 0)` 放入最小堆
2. 用 visited 数组防止重复访问
3. 每次弹出堆顶 `(h, r, c)`：
   - 更新 `ans = max(ans, h)`
   - 如果 `(r, c)` 是终点，返回 `ans`
   - 将未访问的四个邻居以其高度入堆
4. 返回 `ans`

### 解法二：二分答案 + BFS

**核心思想**：二分水位 `t`，对于每个猜测的 `t`，用 BFS 检查是否能只走高度 <= `t` 的格子从 `(0,0)` 到 `(n-1,n-1)`。

**算法步骤**：
1. 设 `lo = max(grid[0][0], grid[n-1][n-1])`，`hi = n*n - 1`
2. 二分 `mid = (lo + hi) / 2`
3. BFS 判定：从 `(0,0)` 出发，只走高度 <= `mid` 的格子，看能否到达 `(n-1,n-1)`
4. 能到达则 `hi = mid`，否则 `lo = mid + 1`
5. 返回 `lo`

### 解法三：并查集

**核心思想**：将所有格子按高度排序。按高度从小到大依次"激活"格子，每激活一个格子就和已激活的邻居合并。当起点和终点第一次连通时，当前高度就是答案。

**算法步骤**：
1. 建立 `(高度, 行, 列)` 的排序数组
2. 初始化并查集
3. 按高度从小到大遍历：
   - 激活格子 `(r, c)`
   - 与四个方向已激活的邻居做 union
   - 检查 `(0,0)` 和 `(n-1,n-1)` 是否连通
   - 若连通，返回当前高度

## 易错点

1. **优先队列比较方向**：这是最小堆（min-heap），C++ 默认 `priority_queue` 是最大堆，需要用 `greater<>` 或自定义比较器
2. **二分答案的初始范围**：下界不是 0，而是 `max(grid[0][0], grid[n-1][n-1])`
3. **visited 标记时机**：入堆时标记，不是出堆时标记，否则同一格子会被多次入堆
4. **并查集中的"已激活"判定**：必须先标记当前格子已激活，再检查邻居是否已激活
5. **混淆"最短路径"和"minimax 路径"**：这里不是 BFS 层数最小化，而是路径最大高度最小化

## 面试追问

1. **为什么不能用普通 BFS？**
   - 普通 BFS 找的是跳数最少的路径，不能保证路径上的最大高度最小。需要用优先队列按高度排序来贪心选择。

2. **这题和 Dijkstra 有什么区别？**
   - Dijkstra 维护的是路径权值之和的最小值，这题维护的是路径权值最大值的最小值。松弛条件从 `dist[v] = min(dist[v], dist[u] + w)` 变成 `dist[v] = min(dist[v], max(dist[u], w))`。

3. **三种解法哪种更优？**
   - 渐进复杂度相同。实际中优先队列 BFS 往往最快（可能提前终止），并查集代码最简洁，二分答案最容易理解。

4. **如果网格很大（n=10000），哪种方法最好？**
   - 并查集的常数因子最小（接近线性），适合大规模数据。优先队列 BFS 的 log 因子来自堆操作。二分答案的 log 因子来自二分。

5. **能否用 Kruskal 最小生成树的思想？**
   - 可以，并查集解法本质就是 Kruskal 的变体：按边权排序后逐步加边，直到特定节点对连通。
