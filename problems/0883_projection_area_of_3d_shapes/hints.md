# LeetCode 883: Projection Area of 3D Shapes

## 核心思路

本题要求计算由方块组成的 3D 形状在三个坐标平面（xy、yz、zx）上的投影面积之和。核心思路是分别理解三个投影的几何含义：**俯视图（xy 平面）** 是所有 grid[i][j] > 0 的格子数量；**正视图（yz 平面）** 是每一行的最大值之和；**侧视图（zx 平面）** 是每一列的最大值之和。只需一次遍历即可同时计算三个投影面积。

## 思维链

1. **理解三个投影方向**：
   - 从上往下看（俯视/xy 平面）：只要某格有方块（值 > 0），投影就占 1 个单位面积
   - 从前往后看（正视/yz 平面）：每一行中最高的方块决定该行的投影高度
   - 从侧面看（侧视/zx 平面）：每一列中最高的方块决定该列的投影高度

2. **数学公式**：
   - xy 投影 = count(grid[i][j] > 0)
   - yz 投影 = sum(max of each row)
   - zx 投影 = sum(max of each column)

3. **一次遍历**：在遍历矩阵时，同时维护行最大值、列最大值和非零计数。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 一次遍历法 | O(n^2) | O(n) | 最优解，同时计算三个投影 |
| 三次遍历法 | O(n^2) | O(1) | 代码更清晰，但常数稍大 |

其中 n 为网格的边长（最大 50）。

## 关键提示

1. **俯视图只看非零** -- grid[i][j] > 0 就贡献 1，不看具体高度。
2. **正视图是行最大值** -- 从前面看，同一行的方块会遮挡，只看到最高的。
3. **侧视图是列最大值** -- 从侧面看，同一列的方块会遮挡，只看到最高的。
4. **grid[i][j] = 0 表示空** -- 该位置没有方块，俯视图不计入。
5. **n x n 正方形网格** -- 行数和列数相同。

## 解法详解

### 解法一：一次遍历法

**原理**：在单次遍历中同时收集三个投影所需的信息。

**算法步骤**：

1. 初始化：
   - `top = 0`（俯视图面积）
   - `rowMax[i] = 0`（每行的最大值）
   - `colMax[j] = 0`（每列的最大值）

2. 遍历 grid[i][j]：
   - 如果 grid[i][j] > 0，top++
   - 更新 rowMax[i] = max(rowMax[i], grid[i][j])
   - 更新 colMax[j] = max(colMax[j], grid[i][j])

3. 结果 = top + sum(rowMax) + sum(colMax)

**复杂度分析**：
- 时间：O(n^2)，遍历整个网格
- 空间：O(n)，存储列最大值数组（行最大值可以在遍历行时累加）

### 解法二：三次遍历法

**原理**：分别计算三个投影面积，代码更直观。

**算法步骤**：

1. **俯视图**：双重循环统计 grid[i][j] > 0 的数量
2. **正视图**：对每行求最大值并累加
3. **侧视图**：对每列求最大值并累加

**复杂度分析**：
- 时间：O(n^2)
- 空间：O(1)

## 易错点

1. **混淆行和列的投影方向** -- 正视图（从前看）取每行最大值，侧视图（从侧看）取每列最大值。注意 grid[i][j] 中 i 是行，j 是列。
2. **忘记 grid[i][j] = 0 的情况** -- 值为 0 意味着没有方块，俯视图中不应计入。
3. **认为投影面积等于体积** -- 投影是"影子"，不是方块数量。体积是所有 grid[i][j] 的总和，但投影面积取决于遮挡关系。
4. **矩阵索引混淆** -- 确保行列遍历的方向与投影方向一致。
5. **n=1 的边界情况** -- 只有一个格子，三个投影分别是 1, grid[0][0], grid[0][0]（如果非零）。

## 面试追问

1. **如果网格不是正方形（m x n），如何修改？**
   - 行数和列数不同，分别处理。rowMax 大小为 m，colMax 大小为 n。其余逻辑不变。

2. **能否 O(1) 空间完成？**
   - 可以。分三次遍历：第一次统计俯视图，第二次逐行统计正视图，第三次逐列统计侧视图。

3. **如果要求体积而非投影面积？**
   - 体积就是 sum(grid[i][j])，更简单。

4. **如果方块可以浮空（不一定从底部开始堆叠）？**
   - 那俯视图不变（只看是否有方块），但正视图和侧视图需要考虑具体的方块位置，不能简单取最大值。

5. **三个投影面积的范围是多少？**
   - 俯视：最大 n^2 = 2500
   - 正视和侧视：最大 n * 50 = 2500 each
   - 总计最大 7500
