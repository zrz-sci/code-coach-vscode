# 849. 到最近的人的最大距离

## 核心思路

本质是一个**间隔分析**问题：找到所有空座位的连续段，对每段计算"坐在中间时距离最近人的最大距离"，注意**左端点和右端点**特殊处理（不用取一半）。

## 思维链

1. **读完题第一反应** → 坐在某个空位上，离最近的人的距离是多少？需要同时考虑左边和右边最近的人。对每个空位都算一遍取最大。
2. **暴力怎么做？** → 对每个 `seats[i] == 0`，向左向右扫描找最近的 1，取 min(左距离, 右距离)，再对所有空位取 max。O(n^2)。
3. **瓶颈在哪？** → 对每个空位都要扫描找最近的人，重复计算太多。能否预处理每个位置到最近人的距离？
4. **优化思路1: 两次遍历** → 正向遍历记录到左边最近人的距离，反向遍历记录到右边最近人的距离，取 min 得到每个空位到最近人的距离，再取 max。
5. **优化思路2: 分组间隔** → 找到所有有人坐的位置，相邻两人之间的空位段，最优座位在段的中点，距离为 `gap / 2`。首尾段特殊：如果左端无人或右端无人，可以坐在端点，距离为整个段长度。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力扫描 | 对每个空位左右查找最近人 | O(n^2) | O(1) | 能说出即可 |
| 两次遍历 | 正反各一次，记录每个位置到最近人的距离 | O(n) | O(n) | 可写 |
| 分组间隔法 | 收集有人座位，分析相邻间隔 | O(n) | O(k) | ⭐ 推荐 |
| 一次遍历 | 维护上一个有人位置，边遍历边更新 | O(n) | O(1) | ⭐ 最优 |

## 关键提示

1. **三种间隔类型**：左端空位段（`[0...first_person]`，距离 = first_person）、右端空位段（`[last_person...n-1]`，距离 = n-1-last_person）、中间段（距离 = gap/2）。
2. **为什么中间段取 gap/2？** 坐在两人之间的中点，到两边的距离相等且最大，即 `(right - left) / 2`（整除）。
3. **为什么端部段不用除以2？** 只有一侧有人，另一侧是墙壁，坐在最远端离最近人的距离就是整段长度。
4. **一次遍历技巧**：用 `prev = -1` 表示上一个有人的位置。遍历时遇到 `seats[i] == 1`，如果 `prev == -1` 则为左端段距离 `i`；否则为中间段距离 `(i - prev) / 2`。遍历完后处理右端段 `n - 1 - prev`。
5. **此题是 855 ExamRoom 的简化版**：ExamRoom 要求动态执行同样的操作。

## 解法详解

### 解法1: 两次遍历 — O(n) / O(n)

**思考过程**: 预处理每个位置到左边最近人和右边最近人的距离，然后取 min 得到该位置到最近人的距离。

```cpp
class Solution {
public:
    int maxDistToClosest(vector<int>& seats) {
        int n = seats.size();
        vector<int> left(n, n), right(n, n);
        // 正向：到左边最近人的距离
        for (int i = 0; i < n; i++) {
            if (seats[i] == 1) left[i] = 0;
            else if (i > 0) left[i] = left[i-1] + 1;
        }
        // 反向：到右边最近人的距离
        for (int i = n - 1; i >= 0; i--) {
            if (seats[i] == 1) right[i] = 0;
            else if (i < n - 1) right[i] = right[i+1] + 1;
        }
        int ans = 0;
        for (int i = 0; i < n; i++) {
            if (seats[i] == 0)
                ans = max(ans, min(left[i], right[i]));
        }
        return ans;
    }
};
```

**关键点**:
- `left[i]` 初始化为 n（足够大），如果 `seats[i]==1` 则为 0。
- 对空位取 `min(left, right)` 是因为最近人可能在左边也可能在右边。

### 解法2: 一次遍历 — O(n) / O(1) ⭐ 面试首选

**从解法1优化**: 不需要额外数组，只需维护上一个有人的位置 `prev`。

```
示例: seats = [1,0,0,0,1,0,1]
                               有人位置: 0, 4, 6

prev=-1:
  i=0: seats[0]=1, prev==-1 → 左端段, 距离=0(自己有人不算)
       更新 prev=0
  i=4: seats[4]=1, prev==0 → 中间段, 距离=(4-0)/2=2
       更新 prev=4
  i=6: seats[6]=1, prev==4 → 中间段, 距离=(6-4)/2=1
       更新 prev=6
遍历完: 右端段距离 = 7-1-6 = 0 (最后一位有人)

ans = max(0, 2, 1, 0) = 2 ✓
```

```cpp
class Solution {
public:
    int maxDistToClosest(vector<int>& seats) {
        int n = seats.size();
        int prev = -1, ans = 0;
        for (int i = 0; i < n; i++) {
            if (seats[i] == 1) {
                if (prev == -1)
                    ans = i;                     // 左端空位段
                else
                    ans = max(ans, (i - prev) / 2); // 中间段
                prev = i;
            }
        }
        ans = max(ans, n - 1 - prev); // 右端空位段
        return ans;
    }
};
```

**关键点**:
- `prev = -1` 作为哨兵值，区分"还没遇到第一个人"和"已经遇到过"。
- 左端段距离 = `i`（第一个有人位置到左墙的距离），不除 2。
- 右端段距离 = `n - 1 - prev`（最后有人位置到右墙的距离），不除 2。
- 中间段距离 = `(i - prev) / 2`，整除即可（奇数间隔中间位置偏近一侧）。

## 易错点

1. **端部间隔忘记特殊处理**：
   - 错: 所有间隔都除以2 → `[0,0,0,1]` 应该返回3而不是1
   - 对: 左端段和右端段不除以2

2. **prev 初始化错误**：
   - 错: `prev = 0` → 如果 `seats[0] == 0` 会误判
   - 对: `prev = -1` 作为哨兵，表示还没遇到过有人的位置

3. **忘记处理右端段**：
   - 循环结束后必须检查 `n - 1 - prev`，因为最后一个人到右墙的距离可能是最大的

4. **整除问题**：
   - `(i - prev) / 2` 是整除，这是正确的（向下取整）
   - 如果间隔为5（如位置1和6之间），最优位置在3或4，距离都是2

## 面试追问

**Q1: 如何处理没有空座位的情况？**
> 题目保证至少有一个空座位，所以不需要处理。但如果要健壮性，返回0即可。

**Q2: 如果座位可以动态变化（有人坐下/离开），怎么处理？**
> 这就是 LeetCode 855 ExamRoom 的场景。需要用有序集合（set）维护有人的位置，每次 seat() 时遍历有序集合找最大间隔，leave() 时从集合中删除。

**Q3: 能否用双指针？**
> 可以。让两个指针 left、right 分别指向最近的左侧和右侧有人位置，对每个空位取 min(i-left, right-i)。但实现上不如一次遍历简洁。

**Q4: 时间复杂度能否优于 O(n)？**
> 不能。需要检查每个座位至少一次来确定有人的位置分布。最优就是 O(n)。
