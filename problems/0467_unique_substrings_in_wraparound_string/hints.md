# 467. 环绕字符串中唯一的子字符串 - 提示

## 题目关键信息
- `base` 是 "abcdefghijklmnopqrstuvwxyz" 无限循环的字符串
- 求 `s` 中有多少个**不同的非空子串**也是 `base` 的子串
- 注意 z 后面接 a 也是连续的

## 提示 1 - 什么样的子串属于 base？
一个子串属于 base，当且仅当它是**连续递增的字母序列**（允许 z->a 的环绕）。例如 "xyz", "za", "abc" 都是 base 的子串。

## 提示 2 - 如何去重？
以某个字母结尾的所有合法子串，**长度越长包含的子串越多**。例如以 'c' 结尾的长度为 3 的连续子串 "abc"，包含了 "c", "bc", "abc" 共 3 个子串。

## 提示 3 - 核心思路
- 维护一个长度为 26 的数组 `dp[c]`，记录以字母 c 结尾的**最长**连续子串长度
- 遍历字符串，维护当前连续长度 `len`
- 如果当前字符是前一个字符的"下一个"（含环绕），`len++`，否则 `len = 1`
- 更新 `dp[c] = max(dp[c], len)`
- 最终答案 = `sum(dp)`

## 提示 4 - 为什么取 max 就能去重？
以字母 c 结尾、长度为 k 的连续子串，恰好包含 k 个不同子串。如果对每个字母只保留最长的那个长度，所有更短的子串都被包含在内，且不同字母结尾的子串集合互不相交。

## 复杂度
- 时间：O(n)
- 空间：O(1)（26 个字母的数组）
