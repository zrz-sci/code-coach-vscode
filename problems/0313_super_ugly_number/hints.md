# 313. 超级丑数 (Super Ugly Number)

## 核心思路

**超级丑数**是指其质因子都在给定的质数数组 `primes` 中的正整数。给定 n 和 primes，求第 n 个超级丑数。

本题是 **264. Ugly Number II**（质因子只有 2, 3, 5）的通用化版本。核心思想完全相同：**多指针 DP**，为每个质因子维护一个指针，每次取最小的候选值作为下一个丑数。

本质上等价于**合并 k 个有序链表**：每个质数 p 生成一个有序序列 `p*ugly[0], p*ugly[1], p*ugly[2], ...`，我们要将这 k 个有序序列合并成一个有序序列，取第 n 个。

## 思维链

1. **读完题第一反应**：和 264 题（Ugly Number II）是同一类题。264 题只有 3 个质因子（2, 3, 5），用 3 个指针。本题有 k 个质因子，用 k 个指针。

2. **暴力方法**：从 1 开始逐个数判断是否为超级丑数，直到找到第 n 个。判断一个数是否为超级丑数需要不断除以 primes 中的质因子。太慢。

3. **生成法而非判断法**：不要"判断一个数是不是丑数"，而是"按顺序生成丑数"。每个丑数乘以 primes 中的任一质数，都能产生新的丑数。问题变成：如何按顺序生成？

4. **多路合并的视角**：
   ```
   质数 2 生成序列:  1*2,  2*2,  4*2,  7*2,  8*2,  ...  (丑数序列 × 2)
   质数 7 生成序列:  1*7,  2*7,  4*7,  7*7,  8*7,  ...  (丑数序列 × 7)
   质数 13 生成序列: 1*13, 2*13, 4*13, 7*13, 8*13, ...  (丑数序列 × 13)
   质数 19 生成序列: 1*19, 2*19, 4*19, 7*19, 8*19, ...  (丑数序列 × 19)
   ```
   每个序列内部递增，合并 k 个有序序列取最小值。

5. **多指针法**：为每个质数维护一个指针 `idx[j]`，表示"primes[j] 下一个要乘的丑数下标"。每轮从 k 个候选值 `primes[j] * dp[idx[j]]` 中取最小值，赋给 `dp[i]`。所有产生该最小值的指针都前进（去重）。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 多指针 DP | k 个指针 + 取最小候选值 | O(n * k) | O(n + k) | ⭐ 面试首选 |
| 最小堆 | 堆维护 k 个候选值 | O(n * log k) | O(n + k) | k 很大时更优 |
| 合并 k 个有序链表 | 等价视角 | O(n * log k) | O(n + k) | 理解本质 |

## 关键提示

1. **dp[0] = 1**：1 是所有丑数序列的起点（1 没有质因子，所以它的质因子"空集"是任何集合的子集）。

2. **去重是关键**：当多个质数乘以各自指向的丑数产生相同结果时，这些指针都要前进。例如 `2*7 = 7*2 = 14`，如果只推进一个指针，14 会重复出现。

3. **用 long 避免溢出**：`primes[j] * dp[idx[j]]` 在 n 很大时可能溢出 int。用 `long long` 存储候选值。

4. **和 264 题的对比**：264 题的 primes = [2, 3, 5]，是本题 k=3 的特例。264 的三指针法就是本题的特化。

5. **堆优化的场景**：多指针法每轮要扫描 k 个候选值取最小，时间 O(k)。如果 k 很大（如 100），可以用最小堆维护 k 个候选值，每轮 O(log k) 取最小。但 k <= 100 时差别不大。

## 解法详解

### 解法1: 多指针 DP — O(n * k) / O(n + k) ⭐ 面试首选

**思路**：dp[i] 存第 i+1 个丑数。为每个质数维护指针 idx[j]，候选值为 primes[j] * dp[idx[j]]。每轮取最小候选值，所有产生该值的指针都前进。

```cpp
class Solution {
public:
    int nthSuperUglyNumber(int n, vector<int>& primes) {
        int k = primes.size();
        vector<int> idx(k, 0);  // 每个质数的指针
        vector<long> dp(n);
        dp[0] = 1;
        
        for (int i = 1; i < n; i++) {
            // 取 k 个候选值中的最小值
            long minVal = LONG_MAX;
            for (int j = 0; j < k; j++) {
                minVal = min(minVal, (long)primes[j] * dp[idx[j]]);
            }
            dp[i] = minVal;
            
            // 所有产生最小值的指针都前进（去重）
            for (int j = 0; j < k; j++) {
                if ((long)primes[j] * dp[idx[j]] == minVal) {
                    idx[j]++;
                }
            }
        }
        return (int)dp[n - 1];
    }
};
```

**关键点**：
- 候选值计算用 `(long)primes[j] * dp[idx[j]]`，避免 int 溢出
- 去重循环必须和取最小值分开（不能在取最小时就推进，因为需要比较所有候选值）

### 解法2: 最小堆 — O(n * log k) / O(n + k)

**思路**：用最小堆维护 k 个候选值，每次弹出最小值作为下一个丑数，然后将该质数的下一个候选值入堆。

```cpp
class Solution {
public:
    int nthSuperUglyNumber(int n, vector<int>& primes) {
        int k = primes.size();
        vector<long> dp(n);
        dp[0] = 1;
        
        // 堆中元素: {候选值, 质数下标, 丑数指针下标}
        // 按候选值排序的最小堆
        using T = tuple<long, int, int>;
        priority_queue<T, vector<T>, greater<T>> pq;
        
        // 初始化: 每个质数 * dp[0] = primes[j]
        for (int j = 0; j < k; j++) {
            pq.push({(long)primes[j], j, 0});
        }
        
        for (int i = 1; i < n; i++) {
            auto [val, j, idx] = pq.top();
            pq.pop();
            dp[i] = val;
            
            // 推入下一个候选值
            pq.push({(long)primes[j] * dp[idx + 1], j, idx + 1});
            
            // 去重: 如果堆顶和当前值相同，继续弹出
            while (pq.top() == make_tuple(val, get<1>(pq.top()), get<2>(pq.top())) 
                   || get<0>(pq.top()) == val) {
                auto [v2, j2, idx2] = pq.top();
                if (v2 != val) break;
                pq.pop();
                pq.push({(long)primes[j2] * dp[idx2 + 1], j2, idx2 + 1});
            }
        }
        return (int)dp[n - 1];
    }
};
```

**简洁版堆写法（用 set 自动去重）**：

```cpp
class Solution {
public:
    int nthSuperUglyNumber(int n, vector<int>& primes) {
        // 用 set 代替堆 + 手动去重
        set<long> candidates;
        candidates.insert(1);
        long cur = 1;
        
        for (int i = 0; i < n; i++) {
            cur = *candidates.begin();
            candidates.erase(candidates.begin());
            for (int p : primes) {
                candidates.insert(cur * p);
            }
        }
        return (int)cur;
    }
};
```

> 注意：这个简洁版虽然易懂，但候选集合可能增长到 O(n * k)，空间不如多指针法。

### 解法3: 和 264 题的对比

```

本题 (Super Ugly Number): primes = 任意质数组, k 个指针

264 题的代码 (特化版):

```

## 解法对比

| | 多指针 DP ⭐ | 最小堆 | set 简洁版 |
|---|---|---|---|
| 每轮取最小 | O(k) 线性扫描 | O(log k) 堆弹出 | O(log size) |
| 总时间 | O(n * k) | O(n * log k) | O(n * k * log(nk)) |
| 空间 | O(n + k) | O(n + k) | O(n * k) 最差 |
| k 小 (<=100) | **最优** | 稍慢(常数大) | 空间浪费 |
| k 大 (>>100) | 慢 | **最优** | 空间爆炸 |
| 面试推荐 | **首选** | k 大时说 | 理解等价性 |

## 易错点

1. **不去重导致丑数重复**
   - `2*7 = 14` 和 `7*2 = 14` 会同时出现
   - 必须检查所有候选值，凡是等于最小值的指针都要前进
   - 常见错误：只推进产生最小值的第一个指针

2. **int 溢出**
   - `primes[j] * dp[idx[j]]` 当两者都较大时会溢出 int
   - dp 数组或候选值计算要用 `long` / `long long`

3. **指针初始化**
   - 所有指针初始化为 0（指向 dp[0] = 1）
   - 忘记初始化会导致未定义行为

4. **dp[0] 不是 primes 中的数**
   - dp[0] = 1（1 是所有丑数序列的第一个）
   - 不要把 dp[0] 设成 primes[0]

## 面试追问

**Q1（和 264 的关系）**：这题和 Ugly Number II 有什么关系？
> 264 是本题 primes = [2, 3, 5] 的特例。264 用 3 个指针，本题推广到 k 个指针。算法框架完全相同。

**Q2（堆优化）**：多指针法每轮 O(k)，能否优化到 O(log k)？
> 用最小堆维护 k 个候选值，每轮堆弹出 O(log k)。当 k 很大时有意义。但本题 k <= 100，多指针法的 O(k) 常数更小。

**Q3（合并 k 个有序链表）**：为什么说这题等价于合并 k 个有序链表？
> 每个质数 p 产生一个有序序列：p*ugly[0], p*ugly[1], p*ugly[2], ...。这 k 个序列都是递增的。我们要把它们合并成一个有序序列并取第 n 个。这和 "23. Merge k Sorted Lists" 的本质完全一样。

**Q4（去重原理）**：为什么同时推进多个指针就能去重？
> 当 `primes[a] * dp[idx[a]] == primes[b] * dp[idx[b]]` 时，说明两个质数序列同时产生了同一个丑数。如果只推进一个，另一个下轮还会产生同样的值 → 重复。同时推进保证每个值只被选一次。

**Q5（空间优化）**：dp 数组能压缩吗？
> 不能简单压缩。因为 idx[j] 可能指向 dp 数组的任意位置（不一定是最近的几个），所以必须保留完整的 dp 数组。

## 相关题型

- **264. Ugly Number II** — 本题的特例（primes = [2,3,5]）。用 3 个指针的多路合并。复用完全相同的"多指针 + 取最小 + 去重"框架。
- **23. Merge k Sorted Lists** — 合并 k 个有序链表，本题的数据结构等价物。用最小堆合并。
- **263. Ugly Number** — 判断一个数是否为丑数（质因子只有 2,3,5）。本系列的基础题。
- **1201. Ugly Number III** — 找第 n 个能被 a/b/c 整除的数。用二分 + 容斥原理，思路不同但同属"丑数系列"。
- **378. Kth Smallest Element in a Sorted Matrix** — 类似的"有序矩阵中找第 k 小"问题，可以用堆或二分。
