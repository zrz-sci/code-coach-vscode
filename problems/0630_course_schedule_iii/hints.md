# 630. 课程表 III

## 难度: Hard
## 标签: Greedy, Array, Sorting, Heap (Priority Queue)

## 题目理解
有 n 门课程，每门课有持续天数 `duration` 和截止日期 `lastDay`。从第 1 天开始，不能同时上两门课，求最多能上多少门课。

## 关键观察
1. 贪心策略：按截止日期从早到晚排序，优先选截止日期早的课
2. 如果当前课程加入后超过截止日期，考虑替换掉已选课程中 duration 最大的
3. 替换后总时间减少，有可能腾出空间给后续课程
4. 用最大堆维护已选课程的 duration

## 解题思路

### 方法：贪心 + 最大堆
1. 按 `lastDay` 升序排序
2. 维护一个最大堆和当前总时间 `time`
3. 遍历每门课程 `[d, l]`：
   - 将其加入堆中，`time += d`
   - 如果 `time > l`，弹出堆顶（最长的课程），`time -= 堆顶值`
4. 堆的大小即为答案

### 为什么正确？
- 替换掉更长的课程，总时间不会变多，且课程数量不变
- 按截止日期排序保证了替换后依然满足所有约束

## 提示序列
1. 按截止日期排序，贪心地尝试选择每门课
2. 如果加入一门课后超时，能不能通过替换之前的某门课来腾出时间？
3. 替换掉已选课程中 duration 最大的那门（最大堆维护）

## 复杂度
- 时间：O(n log n)
- 空间：O(n)
