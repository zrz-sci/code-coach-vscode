# 22. 括号生成

## 核心思路

本质上是一个**受约束的排列生成问题**：在长度为 `2n` 的字符串中放置 `n` 个 `(` 和 `n` 个 `)`，约束条件是任意前缀中 `(` 的数量 ≥ `)` 的数量（即括号始终合法）。

## 思维链

1. **读完题第一反应**：要生成所有合法组合 → 穷举问题 → 暴力方法是生成所有 `2n` 长度的 `(`/`)` 排列，再逐一验证是否合法。
2. **暴力解的瓶颈**：总共 `2^(2n)` 种排列，大量是非法的（比如 `)))(((`），验证浪费了大量时间。
3. **如何突破**：与其先生成再验证，不如**在生成过程中就保证合法**。只要追踪已用的 `(` 和 `)` 数量，在每一步只做"一定不会违法"的选择 → 这就是回溯 + 剪枝。
4. **具体怎么做**：维护 `open`（已放左括号数）和 `close`（已放右括号数）两个计数器：
   - `open < n` 时，可以放 `(`
   - `close < open` 时，可以放 `)`
   - 当 `open == n && close == n` 时，得到一个合法结果
5. **另一个角度（DP）**：如果不用回溯，可以用 DP 思路 —— `dp[i]` 表示 `i` 对括号的所有合法组合，`dp[i]` 可以由 `dp[j]` 和 `dp[i-1-j]` 拼接而来：`"(" + dp[j] + ")" + dp[i-1-j]`。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力生成+验证 | 生成所有2^(2n)序列，逐个验证 | O(2^(2n) · n) | O(n) | 能说出即可 |
| 回溯+剪枝 | 递归构建，用open/close计数约束 | O(4^n/√n) | O(n) | ⭐ 必须写出 |
| 动态规划 | dp[i] = "(" + dp[j] + ")" + dp[i-1-j] | O(4^n/√n) | O(4^n/√n) | 加分项 |

> 时间复杂度说明：合法括号序列数量是第 n 个卡特兰数 C(2n,n)/(n+1)，渐近为 O(4^n/√n)。

## 关键提示

1. **约束条件想清楚**：什么时候能放 `(`？什么时候能放 `)`？关键不等式是 `close < open`（已放右括号数严格小于已放左括号数时，才能放右括号）。
2. **回溯三要素**：路径 = 当前已构建的字符串，选择列表 = `(` 或 `)`，结束条件 = 字符串长度达到 `2n`。
3. **DP 的递推关系**：想象最终结果的最外层括号一定可以表示为 `"(" + 内部 + ")" + 剩余`，这就是分治/DP 的入口。
4. **决策树可视化**（n=2）：
```
                    ""
                /        \
              "("         ✗ (不能先放右括号)
            /     \
         "(("     "()"
         /        /    \
       "(()"    "()("   ✗
        /         \
     "(())"     "()()"
```

## 解法详解

### 解法1: 暴力生成+验证 — O(2^(2n) · n) / O(n)

**思考过程**：最笨的办法 —— 长度 2n 的字符串每个位置可以是 `(` 或 `)`，穷举所有可能，然后写一个函数检查是否合法。

```cpp
class Solution {
public:
    vector<string> generateParenthesis(int n) {
        vector<string> result;
        string current(2 * n, ' ');
        generateAll(current, 0, result);
        return result;
    }
    
    void generateAll(string& current, int pos, vector<string>& result) {
        if (pos == current.size()) {
            if (isValid(current)) {
                result.push_back(current);
            }
            return;
        }
        current[pos] = '(';
        generateAll(current, pos + 1, result);
        current[pos] = ')';
        generateAll(current, pos + 1, result);
    }
    
    bool isValid(const string& s) {
        int balance = 0;
        for (char c : s) {
            if (c == '(') balance++;
            else balance--;
            if (balance < 0) return false; // 右括号多了
        }
        return balance == 0;
    }
};
```

**关键点**：
- 时间浪费严重：2^(2n) 个序列中只有极少数是合法的（卡特兰数量级）。
- 但这个思路展示了"什么是合法括号"的判断条件：任意前缀 `balance >= 0`，且最终 `balance == 0`。

### 解法2: 回溯+剪枝 — O(4^n/√n) / O(n) ⭐ 面试首选

**从解法1优化**：解法1的瓶颈是生成了大量非法序列再丢弃。如果在构建过程中就维护 `open`/`close` 计数，只走合法分支，就能跳过所有非法序列。

```
// 决策树 (n=3 的前几层):
//                           ""
//                     open=0,close=0
//                          |
//                         "("
//                     open=1,close=0
//                    /              \
//                 "(("             "()"
//             open=2,close=0    open=1,close=1
//              /       \            |
//           "((("     "(()      "()" 
//          o=3,c=0   o=2,c=1   → 继续...
//           |        /    \
//        "((()"  "(()" "(()("
//        ...     ...    ...
//
// 剪枝规则:
//   ① open < n → 可以放 '('
//   ② close < open → 可以放 ')'
//   (违反的分支直接不进入，省去大量无效搜索)
```

```cpp
class Solution {
public:
    vector<string> generateParenthesis(int n) {
        vector<string> result;
        string path;
        backtrack(result, path, 0, 0, n);
        return result;
    }
    
    void backtrack(vector<string>& result, string& path, 
                   int open, int close, int n) {
        // 终止条件：字符串长度达到 2n
        if (path.size() == 2 * n) {
            result.push_back(path);
            return;
        }
        
        // 选择1: 放左括号（前提：左括号还没用完）
        if (open < n) {
            path.push_back('(');
            backtrack(result, path, open + 1, close, n);
            path.pop_back();  // 撤销选择
        }
        
        // 选择2: 放右括号（前提：右括号数 < 左括号数，保证合法）
        if (close < open) {
            path.push_back(')');
            backtrack(result, path, open, close + 1, n);
            path.pop_back();  // 撤销选择
        }
    }
};
```

**关键点**：
- **为什么 `close < open` 保证合法？** 因为右括号数不超过左括号数 = 任意前缀中 `(` 数量 ≥ `)` 数量 = 括号永远不失衡。
- `open < n` 确保总共只用 n 个左括号；`close < open` 确保右括号不会多于左括号。当两者都等于 n 时自然得到合法结果。

### 解法3: 动态规划 — O(4^n/√n) / O(4^n/√n)

**另一个角度**：把问题看成递推 —— 已知 `dp[0], dp[1], ..., dp[i-1]` 的所有合法括号，如何构造 `dp[i]`？

**关键观察**：任何 `i` 对合法括号，都可以表示为：
```
"(" + dp[j] + ")" + dp[i-1-j]     (j = 0, 1, ..., i-1)
```
其中 `dp[j]` 是"与第一个 `(` 配对的 `)` 之间"的内容，`dp[i-1-j]` 是"配对的 `)` 之后"的内容。

```
// 递推过程:
// dp[0] = [""]
// dp[1] = ["(" + dp[0] + ")" + dp[0]] = ["()"]
// dp[2] = ["(" + dp[0] + ")" + dp[1]] → "()()"
//       + ["(" + dp[1] + ")" + dp[0]] → "(())"
//       = ["()()", "(())"]
// dp[3] = ["(" + dp[0] + ")" + dp[2]] → "()(())", "()()()" 
//       + ["(" + dp[1] + ")" + dp[1]] → "(())()"
//       + ["(" + dp[2] + ")" + dp[0]] → "((()))", "(()())"
//       = ["((()))", "(()())", "(())()", "()(())", "()()()"]
```

```cpp
class Solution {
public:
    vector<string> generateParenthesis(int n) {
        // dp[i] = i 对括号的所有合法组合
        vector<vector<string>> dp(n + 1);
        dp[0] = {""};  // 0 对括号 = 空字符串
        
        for (int i = 1; i <= n; i++) {
            for (int j = 0; j < i; j++) {
                // j 对括号放在第一个 '(' 和与之配对的 ')' 之间
                // i-1-j 对括号放在配对的 ')' 之后
                for (const string& inner : dp[j]) {
                    for (const string& outer : dp[i - 1 - j]) {
                        dp[i].push_back("(" + inner + ")" + outer);
                    }
                }
            }
        }
        
        return dp[n];
    }
};
```

**关键点**：
- 这个递推公式的正确性基于：第一个 `(` 总是存在的，它一定和某个 `)` 配对，中间和后面各自构成独立的合法括号组合。
- 时间和空间复杂度都是 O(4^n/√n)，因为需要存储所有结果。

## 解法对比

| | 暴力生成+验证 | 回溯+剪枝 | 动态规划 |
|---|---|---|---|
| 核心思想 | 先穷举再筛选 | 边构建边约束 | 递推拼接 |
| 时间 | O(2^(2n)·n) | O(4^n/√n) | O(4^n/√n) |
| 空间(不算结果) | O(n) | O(n) 递归栈 | O(4^n/√n) 存所有中间dp |
| 代码难度 | 简单 | 简单 | 中等 |
| 面试推荐 | ✗ | ✓ 首选 | 展示DP思维 |

回溯解法代码最简洁、效率最高（不存储中间结果），是面试首选。DP 解法展示了不同的思考角度，适合追问时展示。

## 易错点

1. **✗ 错误：`close < n` 作为放右括号的条件**
   ```cpp
   if (close < n) {  // 错！只限制了总数，没限制合法性
       path.push_back(')');
       backtrack(..., close + 1, ...);
   }
   ```
   **✓ 正确：`close < open`** —— 右括号数必须严格小于已放的左括号数，否则会产生 `)(` 这种非法前缀。

2. **✗ 错误：忘记撤销选择（回溯的核心）**
   ```cpp
   path.push_back('(');
   backtrack(...);
   // 漏掉 path.pop_back(); → 后续分支的 path 被污染
   ```

3. **✗ 错误：DP 解法中 `dp[0]` 初始化为空数组**
   ```cpp
   dp[0] = {};  // 错！dp[0] 应该有一个空字符串
   ```
   **✓ 正确：`dp[0] = {""}` —— 空字符串代表 0 对括号的唯一合法组合**，如果 dp[0] 为空，所有后续的双重循环都不会执行。

4. **✗ 错误：DP 内层循环范围写成 `j <= i`**
   ```cpp
   for (int j = 0; j <= i; j++)  // 错！j 最大到 i-1
   ```
   **✓ 正确：`j < i`** —— 因为 `j` 对在里面 + `(i-1-j)` 对在外面，总共用掉 `j + 1 + (i-1-j) = i` 对。

## 面试追问

**Q1: 你的回溯解法时间复杂度怎么分析？**
> 合法括号序列数是第 n 个卡特兰数 `C(2n,n)/(n+1)`，渐近为 `4^n / (n^(3/2) * √π)`。每个序列长度 2n，所以总时间 O(4^n / √n · n)。由于只生成合法序列，没有浪费。

**Q2: 如果不要求生成所有组合，只问有多少个合法组合，怎么做？**
> 直接用卡特兰数公式：`C(2n, n) / (n + 1)`。可以 O(n) 时间计算，不需要枚举。

**Q3: 如果要求生成含多种括号类型（如 `()[]{}`）的合法组合呢？**
> 回溯框架不变，选择列表从 2 种变成 6 种（3 种左括号 + 3 种右括号）。放右括号的条件变为：栈顶的左括号必须和当前右括号匹配。即用一个栈来维护当前未匹配的左括号序列。
