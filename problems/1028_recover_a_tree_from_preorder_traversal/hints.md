# 1028. 从先序遍历还原二叉树

## 核心思路

本题本质上是：**给你一个先序遍历的序列化字符串（用破折号数量表示深度），请你逆向还原出这棵二叉树**。关键在于如何利用"深度信息"来确定每个节点应该挂在哪个父节点的左子树还是右子树上。

## 思维链

1. **读完题第一反应**：这是先序遍历（根→左→右）的逆过程。字符串中每个节点都有"深度"信息（破折号数量），我需要按顺序解析出 `(深度, 值)` 对，然后重建树。

2. **怎么确定父子关系？** 先序遍历的性质：当我遇到一个深度为 `d` 的节点时，它的父节点就是最近一个深度为 `d-1` 的节点。问题是——它是父节点的左孩子还是右孩子？

3. **左右孩子的判断**：题目说"如果只有一个子节点，保证是左子节点"。所以在先序遍历中，深度 `d` 的节点要挂到深度 `d-1` 的节点上：如果左孩子为空就挂左边，否则挂右边。

4. **用什么数据结构追踪"祖先链"？** 我需要随时知道"从根到当前位置的路径"，这正是一个 **栈**！栈中保存从根到当前节点的路径，栈的大小就是当前深度+1。当新节点的深度比栈顶小时，弹栈回退到正确的父节点。

5. **另一种方式——递归**：先序遍历天然适合递归重建。维护一个全局指针扫描字符串，递归函数接受"期望深度"参数，如果当前解析出的深度等于期望深度，就创建节点并递归建左右子树。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 迭代（栈） | 用栈维护根到当前节点的路径，按深度弹栈找父节点 | O(n) | O(n) | ⭐ 必须写出 |
| 递归（DFS） | 递归函数接受期望深度，逐段解析字符串 | O(n) | O(n) | ⭐ 必须写出 |

> 这道题没有"暴力 → 优化"的演进，两种解法都是 O(n)，分别从迭代和递归两个角度理解同一个问题。

## 关键提示

1. **字符串解析是第一关**：先把"数破折号数量"和"读数字"这两步搞清楚。破折号连续出现的数量就是深度，紧跟其后的连续数字就是节点值。

2. **栈的含义**：栈中第 `i` 个元素（0-indexed）就是深度为 `i` 的节点。当新节点深度为 `d` 时，栈中应该恰好有 `d` 个元素，栈顶就是深度 `d-1` 的父节点。

3. **为什么弹栈是安全的？** 先序遍历保证：当你遇到深度为 `d` 的节点时，深度 > `d-1` 的祖先节点的子树已经全部处理完了，可以安全弹出。

4. **递归的"偷看"技巧**：递归版本需要先"偷看"下一个节点的深度，如果深度不匹配期望值，就不消费这段字符串，直接返回 null。

5. **示例树形结构**（示例1）：
```
输入: "1-2--3--4-5--6--7"

解析出的 (深度, 值) 序列:
(0,1) (1,2) (2,3) (2,4) (1,5) (2,6) (2,7)

还原的树:
        1
       / \
      2   5
     / \ / \
    3  4 6  7
```

## 解法详解

### 解法1: 迭代（栈）— O(n) / O(n) ⭐ 面试首选

**思考过程**：先序遍历是"根→左→右"，我们按顺序扫描字符串，每次解析出一个 `(depth, value)` 对。关键问题是确定这个新节点的父节点是谁。

观察：栈中始终维护"从根到当前正在构建的节点"的路径。当新节点深度为 `d` 时，它的父节点深度是 `d-1`，而栈中深度 ≥ `d` 的节点说明它们的子树已经构建完毕，应该弹出。弹到栈大小 == `d` 时，栈顶就是深度 `d-1` 的父节点。

```
栈操作过程（示例1: "1-2--3--4-5--6--7"）:

解析 (0, 1): 栈空, push 1           栈: [1]
解析 (1, 2): 栈大小1==深度1, 栈顶1的左孩子=2, push 2   栈: [1, 2]
解析 (2, 3): 栈大小2==深度2, 栈顶2的左孩子=3, push 3   栈: [1, 2, 3]
解析 (2, 4): 栈大小3>深度2, pop 3 → 栈大小2==深度2
             栈顶2的右孩子=4, push 4                    栈: [1, 2, 4]
解析 (1, 5): 栈大小3>深度1, pop 4, pop 2 → 栈大小1==深度1
             栈顶1的右孩子=5, push 5                    栈: [1, 5]
解析 (2, 6): 栈大小2==深度2, 栈顶5的左孩子=6, push 6   栈: [1, 5, 6]
解析 (2, 7): 栈大小3>深度2, pop 6 → 栈大小2==深度2
             栈顶5的右孩子=7, push 7                    栈: [1, 5, 7]
```

```cpp
class Solution {
public:
    TreeNode* recoverFromPreorder(string traversal) {
        stack<TreeNode*> stk;
        int i = 0, n = traversal.size();
        
        while (i < n) {
            // 第一步：数破折号 → 得到深度
            int depth = 0;
            while (i < n && traversal[i] == '-') {
                depth++;
                i++;
            }
            // 第二步：读数字 → 得到节点值
            int val = 0;
            while (i < n && traversal[i] != '-') {
                val = val * 10 + (traversal[i] - '0');
                i++;
            }
            
            TreeNode* node = new TreeNode(val);
            
            // 弹栈直到栈大小 == depth（栈顶就是父节点）
            while ((int)stk.size() > depth) {
                stk.pop();
            }
            
            // 挂到父节点上：左空挂左，否则挂右
            if (!stk.empty()) {
                if (stk.top()->left == nullptr) {
                    stk.top()->left = node;
                } else {
                    stk.top()->right = node;
                }
            }
            
            stk.push(node);
        }
        
        // 栈底元素就是根节点
        while (stk.size() > 1) stk.pop();
        return stk.top();
    }
};
```

**关键点**：
- 栈大小的含义：栈中有 `k` 个元素意味着栈顶节点的深度是 `k-1`。
- 弹栈条件是 `stk.size() > depth`，不是 `>=`。

### 解法2: 递归（DFS）— O(n) / O(n)

**思考过程**：先序遍历 = 根 + 左子树的先序遍历 + 右子树的先序遍历。这天然是一个递归结构。

递归函数 `dfs(expected_depth)` 的含义：尝试从当前位置解析一个深度为 `expected_depth` 的节点及其子树。如果当前位置的深度不匹配，返回 null。

关键技巧是用一个全局索引 `pos` 来追踪当前扫描到字符串的哪个位置。每次递归前先"偷看"深度，匹配了才消费。

```cpp
class Solution {
public:
    int pos = 0;  // 全局扫描指针
    
    TreeNode* recoverFromPreorder(string traversal) {
        return dfs(traversal, 0);
    }
    
    TreeNode* dfs(const string& s, int expectedDepth) {
        // 先"偷看"：数当前位置开始的破折号数量
        int depth = 0;
        int tempPos = pos;
        while (tempPos < (int)s.size() && s[tempPos] == '-') {
            depth++;
            tempPos++;
        }
        
        // 如果深度不匹配期望，说明这个节点不属于当前子树
        if (depth != expectedDepth) {
            return nullptr;  // 不消费字符串，pos 不动
        }
        
        // 深度匹配，正式消费：跳过破折号
        pos = tempPos;
        
        // 读取数字
        int val = 0;
        while (pos < (int)s.size() && s[pos] != '-') {
            val = val * 10 + (s[pos] - '0');
            pos++;
        }
        
        TreeNode* node = new TreeNode(val);
        
        // 先序遍历：先递归左子树，再递归右子树
        // 子节点的深度是 expectedDepth + 1
        node->left = dfs(s, expectedDepth + 1);
        node->right = dfs(s, expectedDepth + 1);
        
        return node;
    }
};
```

**关键点**：
- "偷看"机制：先用 `tempPos` 数破折号，不匹配就不动 `pos`，让调用者处理。
- 递归顺序天然保证先左后右：第一次调用 `dfs(expectedDepth+1)` 会消费左子树的所有节点，第二次调用消费右子树。

## 解法对比

| | 迭代（栈） | 递归（DFS） |
|---|---|---|
| 核心思想 | 显式用栈维护祖先路径 | 利用递归调用栈隐式维护 |
| 代码复杂度 | 稍多但逻辑清晰 | 简洁优雅 |
| 空间 | 显式栈 O(h) | 递归栈 O(h) |
| 面试推荐 | ⭐ 更容易解释清楚 | ⭐ 写起来更快 |
| 适用场景 | 树深度很大时避免栈溢出（可控） | 大多数面试场景 |

两种解法本质上做的是同一件事：按先序顺序扫描，用"深度"信息确定父子关系。栈版本显式管理路径，递归版本隐式管理。

## 易错点

1. **节点值不是个位数**：
   - ✗ `val = traversal[i] - '0'`（只读了一位）
   - ✓ 用 while 循环读取连续数字：`while (i < n && s[i] != '-') val = val*10 + (s[i++]-'0')`
   - 题目明确说值可达 10^9，必须处理多位数。

2. **根节点前没有破折号**：
   - 根节点深度为 0，字符串开头直接是数字，没有破折号。解析逻辑天然处理了这一点（数破折号数量为 0）。

3. **递归版本忘了"偷看"而直接消费**：
   - ✗ 直接移动 `pos` 数破折号，发现不匹配后无法回退
   - ✓ 用临时变量 `tempPos` 偷看，匹配了才让 `pos = tempPos`

4. **迭代版本返回根节点的方式**：
   - ✗ 直接返回 `stk.top()`（此时栈顶是最后处理的节点，不是根）
   - ✓ 要么弹栈到只剩一个，要么在创建第一个节点时就记录根

5. **`stk.size()` 返回 `size_t`（无符号），和 `int` 比较可能出问题**：
   - ✓ 显式转换 `(int)stk.size() > depth`

## 面试追问

**Q1: 字符串解析部分能不能用正则或 split？**
> 可以，但面试中手动解析更直接。关键是分两步：数破折号得深度，读数字得值。这里没有复杂的分隔符模式，手写反而更简单高效。

**Q2: 如果这道题改成"中序遍历还原"，能做吗？**
> 单独的中序遍历无法唯一确定一棵二叉树（即使知道深度也很难，因为根在中间位置不确定）。先序遍历能唯一还原是因为第一个元素一定是根，然后递归地第一个子元素是左子树的根。

**Q3: 如果节点可以有任意多个子节点（N 叉树），怎么改？**
> 核心变化：一个节点的子节点不再是最多两个。栈版本中，弹栈后不再是"左空挂左、否则挂右"，而是直接 `push_back` 到 `children` 列表。递归版本中，用 while 循环持续调用 `dfs(expectedDepth+1)` 直到返回 null。

**Q4: 能否不用额外空间（O(1)）？**
> 不能。树本身就需要 O(n) 空间来存储节点。栈/递归的 O(h) 额外空间是重建过程必需的，因为你需要知道从根到当前节点的路径。
