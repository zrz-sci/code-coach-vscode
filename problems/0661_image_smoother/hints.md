# 661. Image Smoother

## 核心思路

对矩阵中的每个像素，计算其 3x3 邻域（包含自身）内所有有效像素的平均值并向下取整。这是一个标准的卷积/滑动窗口操作。关键在于正确处理边界（不是所有像素都有完整的 8 个邻居）以及使用独立的结果矩阵避免读写冲突。

## 思维链

1. 题目要求对每个像素取 3x3 邻域的均值（向下取整）
2. 边界像素的邻域不完整，需要动态计算有效邻居数量
3. 不能在原矩阵上直接修改（否则已修改的值会影响后续计算）
4. 最简单的做法：创建新矩阵，双重循环遍历每个像素，对每个像素再用双重循环遍历 3x3 邻域
5. 优化方向：原地修改（利用值域 0~255 只需 8 位，int 还有高位可以存储新值）
6. 更高级优化：二维前缀和预处理，O(1) 查询任意矩形区域的和

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 暴力遍历 | O(m*n) | O(m*n) | 简单直观，推荐面试使用 |
| 原地修改（位编码） | O(m*n) | O(1) | 利用高位存储新值 |
| 二维前缀和 | O(m*n) | O(m*n) | 预处理后 O(1) 求区域和 |

## 关键提示

1. 对每个像素 (i,j)，遍历 (i-1,j-1) 到 (i+1,j+1) 的 9 个位置，跳过越界的
2. 同时累加有效像素的值 sum 和计数 count，最终结果 = sum / count（整数除法自动向下取整）
3. 必须使用新矩阵存储结果，不能直接修改原矩阵
4. 值域 0~255 只需 8 位；可以用 int 的高 8 位存新值，实现 O(1) 空间
5. dx/dy 方向数组技巧可以简化邻域遍历代码

## 解法详解

### 解法一：暴力遍历（推荐）

**思路**：创建同尺寸的结果矩阵。对每个像素 (i,j)，遍历其 3x3 邻域中的所有有效位置，累加像素值和有效像素计数，取平均值存入结果矩阵。

**遍历邻域的两种写法**：
- 写法 A：双重循环 for (ni = i-1; ni <= i+1; ni++) for (nj = j-1; nj <= j+1; nj++)，检查 ni 和 nj 的合法性
- 写法 B：使用 dx[] = {-1,-1,-1,0,0,0,1,1,1} 和 dy[] = {-1,0,1,-1,0,1,-1,0,1} 共 9 个方向

**整数除法**：C++ 中对正整数的 `/` 自动执行向下取整（截断），恰好符合题目要求。

### 解法二：原地修改（位编码）

**思路**：利用像素值 0~255 只占 8 位，而 int 有 32 位的特点。将新值编码到高位：`img[i][j] |= (newVal << 8)`。读取旧值用 `img[i][j] & 0xFF`，读取新值用 `img[i][j] >> 8`。

**步骤**：
1. 第一遍：计算每个像素的新值，编码到高位
2. 第二遍：将每个像素右移 8 位，得到最终结果

### 解法三：二维前缀和

**思路**：预计算前缀和数组 prefix[i][j] = sum of img[0..i-1][0..j-1]。然后对任意矩形区域 (r1,c1)-(r2,c2) 的和可以 O(1) 计算：`prefix[r2+1][c2+1] - prefix[r1][c2+1] - prefix[r2+1][c1] + prefix[r1][c1]`。

**适用场景**：当需要多次查询不同大小的窗口时特别高效；本题窗口固定为 3x3，优势不明显。

## 易错点

1. **边界处理遗漏**：角落像素只有 4 个邻居（含自身），边上像素有 6 个，不能固定除以 9
2. **在原矩阵上直接修改**：已修改的值会影响相邻像素的计算，导致错误结果
3. **count 初始化为 0 而非 1**：自身像素也要算在内，但如果遍历包含自身位置，count 从 0 开始是正确的
4. **向下取整理解错误**：C++ 整数除法对正数已是向下取整，不需要额外 floor()
5. **前缀和的下标偏移**：前缀和数组通常多一行一列（size (m+1)*(n+1)），下标映射容易出错

## 面试追问

1. **如果要支持任意大小的滤波器 kxk？** 二维前缀和方案直接适用，暴力法改为 k*k 邻域遍历
2. **如何实现高斯模糊而非均值模糊？** 使用加权平均，权重为二维高斯核
3. **能否做到真正的 O(1) 额外空间？** 可以，使用位编码方案（解法二）
4. **如果矩阵非常大（比如 10^6 x 10^6）怎么办？** 分块处理，或利用 SIMD/并行计算
5. **平滑操作的实际应用？** 图像去噪、特征提取预处理、边缘检测前的平滑
