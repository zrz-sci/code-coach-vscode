# 124. 二叉树中的最大路径和

## 核心思路

这道题本质上是：**在二叉树上找一条"拐弯路径"（可以从某个节点向左子树延伸、经过该节点、再向右子树延伸），使得路径上节点值之和最大。** 关键难点在于：路径可以在任意节点"拐弯"，但向上返回时只能选一条分支。

## 思维链

1. **读完题第一反应**：路径可以从任意节点出发、到任意节点结束，不一定经过根。这意味着我需要考虑以每个节点为"拐点"（最高点）的路径。

2. **暴力想法**：枚举每个节点作为路径的最高点，然后分别算它左子树能贡献的最大路径和、右子树能贡献的最大路径和。但如果对每个节点都单独递归左右子树，会有大量重复计算。

3. **瓶颈分析**：每个节点需要知道"从我的左孩子往下走，最多能收集多少"和"从我的右孩子往下走，最多能收集多少"。如果能在一次 DFS 中同时完成这两件事，就避免了重复。

4. **关键洞察 — 两件事的区分**：
   - **"经过我拐弯"的路径和** = 左贡献 + 我的值 + 右贡献 → 用来更新全局答案
   - **"经过我但继续往上"的贡献** = 我的值 + max(左贡献, 右贡献) → 返回给父节点
   
   这两件事在同一个递归函数中完成！

5. **处理负数**：如果某个子树的贡献 < 0，不如不要它（贡献取 0），这就是 `max(0, 子树贡献)` 的来源。

6. **最终方案**：一次后序遍历（自底向上），每个节点算两个值：一个更新全局最大值，一个返回给父节点。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| DFS（后序遍历 + 全局变量） | 每个节点算"拐弯路径和"更新答案，返回"单边最大贡献" | O(n) | O(h) | ⭐ 必须写出 |
| DFS（返回 pair） | 不用全局变量，返回 {最大路径和, 单边贡献} | O(n) | O(h) | 加分项 |

## 关键提示

1. **区分两个概念**：在节点 X 处，"以 X 为拐点的完整路径和"和"X 向上贡献给父节点的单边路径和"是两个不同的值。前者用来更新答案，后者用来返回。

2. **ASCII 示意图 — 为什么返回值只能选一边**：
```
        父
       /
      X        ← 如果 X 往上走到"父"，
     / \          路径不能同时包含左和右（否则路径会分叉）
    L   R      ← 所以返回给父的只能是 max(L, R) + X
```

3. **负数贡献的处理**：子树贡献如果是负数，宁可不走那边（取 0）。但节点自身的值即使是负数也必须包含（路径至少包含一个节点）。

4. **全局最大值的初始化**：初始化为 `INT_MIN` 而不是 0，因为所有节点值都可能是负数。

5. **示例 2 的推演**：
```
        -10
        / \
       9   20
          / \
         15   7

节点 15: 左=0, 右=0, 拐弯=15, 返回=15
节点  7: 左=0, 右=0, 拐弯=7,  返回=7
节点 20: 左=15, 右=7, 拐弯=15+20+7=42 ✓, 返回=20+15=35
节点  9: 左=0, 右=0, 拐弯=9, 返回=9
节点-10: 左=9, 右=35, 拐弯=9+(-10)+35=34, 返回=-10+35=25
全局最大: max(15, 7, 42, 9, 34) = 42 ✓
```

## 解法详解

### 解法1: 后序 DFS + 全局变量 — O(n) / O(h) ⭐ 面试首选

**思考过程**：树上的路径问题，自然想到递归。路径的最高点（拐弯处）可以是任意节点，所以我们在每个节点处计算"以它为最高点的最大路径和"。递归函数需要返回"从当前节点往下走的最大单边贡献"给父节点使用。

关键区分：
- **更新答案**：`node.val + leftGain + rightGain`（可以两边都走，形成拐弯路径）
- **返回给父**：`node.val + max(leftGain, rightGain)`（只能选一边，因为路径不能分叉）

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
    int maxSum;
    
    // 返回：从 node 出发往下走（单边）的最大贡献值
    int maxGain(TreeNode* node) {
        if (!node) return 0;
        
        // 后序遍历：先算左右子树的贡献
        // 如果贡献为负，不如不走（取 0）
        int leftGain = max(0, maxGain(node->left));
        int rightGain = max(0, maxGain(node->right));
        
        // 以当前节点为"拐点"的路径和（左+根+右）
        int pathSum = node->val + leftGain + rightGain;
        maxSum = max(maxSum, pathSum);
        
        // 返回给父节点：只能选一边 + 当前节点
        return node->val + max(leftGain, rightGain);
    }
    
public:
    int maxPathSum(TreeNode* root) {
        maxSum = INT_MIN;
        maxGain(root);
        return maxSum;
    }
};
```

**关键点**：
- `maxGain` 返回的是**单边贡献**（只选左或右），但在函数内部计算**拐弯路径和**（左+右）来更新全局答案。这两件事在同一个函数里完成是核心技巧。

### 解法2: 后序 DFS + 返回 pair（无全局变量） — O(n) / O(h)

**从解法1优化**：解法1 用了成员变量 `maxSum`，有些面试官更喜欢纯函数式风格。我们可以让递归函数返回一个 pair：`{以该子树内任意节点为拐点的最大路径和, 单边最大贡献}`。

```cpp
class Solution {
    // 返回 {子树内的最大路径和, 从root出发的单边最大贡献}
    pair<int, int> dfs(TreeNode* node) {
        if (!node) return {INT_MIN, 0};
        
        auto [leftMax, leftGain] = dfs(node->left);
        auto [rightMax, rightGain] = dfs(node->right);
        
        // 子树贡献为负则不选
        leftGain = max(0, leftGain);
        rightGain = max(0, rightGain);
        
        // 以当前节点为拐点的路径和
        int throughMe = node->val + leftGain + rightGain;
        
        // 子树内的全局最大 = max(左子树最大, 右子树最大, 经过当前节点拐弯)
        int bestInSubtree = max({leftMax, rightMax, throughMe});
        
        // 返回给父：单边贡献
        int gain = node->val + max(leftGain, rightGain);
        
        return {bestInSubtree, gain};
    }
    
public:
    int maxPathSum(TreeNode* root) {
        return dfs(root).first;
    }
};
```

**关键点**：
- 用 `pair` 避免全局变量，逻辑更清晰但代码稍长。
- `INT_MIN` 作为空节点的"最大路径和"——因为空子树没有路径。

## 解法对比

| | 解法1（全局变量） | 解法2（返回 pair） |
|---|---|---|
| 代码简洁度 | ✓ 更简洁 | 稍长 |
| 函数式纯净度 | 有副作用（改全局变量） | ✓ 无副作用 |
| 面试推荐 | ⭐ 首选，简洁易写 | 如果面试官追问"能否不用全局变量" |
| 时间/空间 | O(n) / O(h) | O(n) / O(h) |

两种解法本质完全相同，都是**一次后序 DFS**，只是信息传递方式不同。

## 易错点

1. **✗ 全局最大值初始化为 0** → **✓ 初始化为 `INT_MIN`**
   - 当所有节点都是负数时（如 `[-3]`），答案是 -3 而不是 0。初始化为 0 会得到错误答案。

2. **✗ 返回值也取 max(0, ...)** → **✓ 返回值可以为负**
   - `max(0, ...)` 只用于计算子树**贡献**时（表示"不走那边"），但返回给父节点时，`node->val + max(leftGain, rightGain)` 本身可以是负数（父节点会决定要不要走这边）。
   ```cpp
   // 错误：return max(0, node->val + max(leftGain, rightGain));
   // 正确：return node->val + max(leftGain, rightGain);
   // 负数的处理在父节点调用时通过 max(0, maxGain(child)) 完成
   ```

3. **✗ 忘记在递归内更新全局最大值** → 只在最后比较根节点是不够的
   - 最大路径可能在某个子树内部，完全不经过根节点（如示例 2 中 15→20→7）。

4. **✗ 拐弯路径和漏掉当前节点** → 路径和是 `leftGain + node->val + rightGain`，不是 `leftGain + rightGain`。

## 面试追问

**Q1: 基础理解** — 递归函数返回的是什么？和用来更新答案的值有什么区别？
> 返回的是"从当前节点出发、只往一个方向走的最大贡献"，因为向上传递时路径不能分叉。更新答案的值是"以当前节点为拐点、两边都走的完整路径和"。

**Q2: 优化追问** — 如果我不仅要最大路径和，还要返回具体路径上的节点，怎么改？
> 在递归时额外维护路径信息。每个节点记录"最优单边贡献对应的路径"，当更新全局最大时，拼接左路径 + 当前节点 + 右路径。空间从 O(h) 增加到 O(n)。

**Q3: 变体** — 如果路径必须经过根节点呢？
> 问题简化为：根节点 + max(0, 左子树最大深度和) + max(0, 右子树最大深度和)。只需一个简单的 DFS 求每棵子树的最大单边路径和即可，不需要全局变量。

**Q4: 如果是 N 叉树呢？**
> 思路类似：对所有子树的贡献排序，取最大的两个来"拐弯"更新答案。返回给父节点的只能是最大的那一个贡献 + 当前节点值。
