# 249. 移位字符串分组

## 核心思路

本质上是一个**分组问题**：两个字符串属于同一组，当且仅当它们的"相邻字符之差的序列"完全相同。我们需要找到一种方法为每个移位序列生成唯一的"指纹"（key），然后用哈希表分组。

## 思维链

1. **读完题第一反应**：同一个移位序列中的字符串，就是通过不断右移/左移变换得到的。比如 `"abc"` → `"bcd"` → ... → `"xyz"` → `"yza"` → ...。暴力做法是对每个字符串，生成它所有 26 种移位结果，然后两两比较是否匹配。

2. **暴力解的瓶颈**：两两比较需要 O(n²) 对，每对还要生成移位串，效率低。更重要的是——我们需要一个更聪明的方式来判断"两个字符串是否属于同一移位序列"。

3. **关键观察**：同一移位序列中的字符串，虽然每个字符在变，但**相邻字符之间的差值是不变的**！
   - `"abc"`：b-a=1, c-b=1 → 差值序列 `[1,1]`
   - `"bcd"`：c-b=1, d-c=1 → 差值序列 `[1,1]` ✓ 相同！
   - `"xyz"`：y-x=1, z-y=1 → 差值序列 `[1,1]` ✓ 相同！
   - `"az"`：z-a=25 → 差值序列 `[25]`
   - `"ba"`：a-b=-1 → 取模后 `= 25` → 差值序列 `[25]` ✓ 和 "az" 相同！

4. **解法成型**：把每个字符串的"差值序列"编码成一个字符串作为哈希表的 key，key 相同的字符串就属于同一组。

5. **另一种编码方式**：不用差值序列，也可以把每个字符串"归一化"——将首字母移位到 'a'，同组的字符串归一化后完全相同。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力比较 | 每对字符串检查是否能互相移位 | O(n²·L) | O(n·L) | 能说出即可 |
| 差值序列编码 + 哈希表 | 用相邻字符差值作为 key 分组 | O(n·L) | O(n·L) | ⭐ 必须写出 |
| 归一化编码 + 哈希表 | 将首字母统一移到 'a' 作为 key | O(n·L) | O(n·L) | ⭐ 必须写出 |

> n = 字符串个数，L = 字符串平均长度

## 关键提示

1. **想想什么在移位过程中是不变量**：每个字符都在变，但相邻字符的"间距"不会变——这就是分组的依据。

2. **取模要小心**：`s[i] - s[i-1]` 可能是负数（如 `'a' - 'z' = -25`），在模 26 的意义下应该是 1。C++ 中负数取模的结果可能也是负数，要加 26 再模 26。

3. **单字符字符串**：长度为 1 的字符串没有"差值"，它们的差值序列都是空串——所以 `"a"` 和 `"z"` 应该在同一组。

4. **编码要能区分**：如果直接把差值数字拼接（如 `1` 和 `12`），可能和 `11` 与 `2` 混淆。需要用分隔符（如逗号）隔开。

5. **可视化一下**：
   ```
   字符串      差值序列(mod 26)     key
   "abc"  →   [1, 1]           →  "1,1"
   "bcd"  →   [1, 1]           →  "1,1"    ← 同组！
   "xyz"  →   [1, 1]           →  "1,1"    ← 同组！
   "acef" →   [2, 2, 1]        →  "2,2,1"
   "az"   →   [25]             →  "25"
   "ba"   →   [(-1+26)%26=25]  →  "25"     ← 和 "az" 同组！
   "a"    →   []               →  ""
   "z"    →   []               →  ""        ← 和 "a" 同组！
   ```

## 解法详解

### 解法1: 暴力比较 — O(n²·L) / O(n·L)

**思考过程**：最直接的想法——遍历每对字符串，判断它们是否属于同一移位序列。如果字符串长度不同，直接跳过。长度相同时，计算第一个字符的偏移量，验证所有字符是否满足相同偏移。

```cpp
class Solution {
public:
    bool isSameGroup(const string& a, const string& b) {
        if (a.size() != b.size()) return false;
        if (a.empty()) return true;
        int shift = ((b[0] - a[0]) % 26 + 26) % 26;
        for (int i = 1; i < a.size(); i++) {
            if (((b[i] - a[i]) % 26 + 26) % 26 != shift) return false;
        }
        return true;
    }
    
    vector<vector<string>> groupStrings(vector<string>& strings) {
        int n = strings.size();
        vector<bool> used(n, false);
        vector<vector<string>> result;
        
        for (int i = 0; i < n; i++) {
            if (used[i]) continue;
            vector<string> group = {strings[i]};
            for (int j = i + 1; j < n; j++) {
                if (!used[j] && isSameGroup(strings[i], strings[j])) {
                    group.push_back(strings[j]);
                    used[j] = true;
                }
            }
            result.push_back(group);
        }
        return result;
    }
};
```

**关键点**：判断两个字符串是否同组时，不能只比较第一个字符的偏移量就结束——要验证每个位置的偏移量都一致。

---

### 解法2: 差值序列编码 + 哈希表 — O(n·L) / O(n·L) ⭐ 面试首选

**从解法1优化**：暴力比较的瓶颈是 O(n²) 的配对。如果我们能为每个字符串算出一个"指纹"，使得同组字符串指纹相同，就能用哈希表 O(1) 分组。

**核心不变量**：同一移位序列的字符串，相邻字符的差值序列（mod 26）完全相同。

```cpp
class Solution {
public:
    vector<vector<string>> groupStrings(vector<string>& strings) {
        unordered_map<string, vector<string>> groups;
        
        for (const string& s : strings) {
            string key = "";
            for (int i = 1; i < s.size(); i++) {
                // 关键：(diff + 26) % 26 处理负数情况
                int diff = ((s[i] - s[i - 1]) % 26 + 26) % 26;
                key += to_string(diff) + ",";  // 用逗号分隔防止歧义
            }
            groups[key].push_back(s);
        }
        
        vector<vector<string>> result;
        for (auto& [key, group] : groups) {
            result.push_back(move(group));
        }
        return result;
    }
};
```

**关键点**：
- 差值可能为负数，必须 `(diff + 26) % 26`
- 差值之间必须用分隔符隔开，否则 `[1,12]` 和 `[11,2]` 都变成 `"112"`

---

### 解法3: 归一化编码 + 哈希表 — O(n·L) / O(n·L)

**另一种视角**：不用差值序列，而是把每个字符串"归一化"到以 `'a'` 开头的形式。同组字符串归一化后完全相同。

```cpp
class Solution {
public:
    vector<vector<string>> groupStrings(vector<string>& strings) {
        unordered_map<string, vector<string>> groups;
        
        for (const string& s : strings) {
            string key = s;
            int shift = s[0] - 'a';  // 把首字母移到 'a' 需要左移的步数
            for (char& c : key) {
                // 每个字符都左移相同步数
                c = (c - 'a' - shift + 26) % 26 + 'a';
            }
            groups[key].push_back(s);
        }
        
        vector<vector<string>> result;
        for (auto& [key, group] : groups) {
            result.push_back(move(group));
        }
        return result;
    }
};
```

**关键点**：归一化时 `c - 'a' - shift` 可能为负数，要先 `+ 26` 再 `% 26`。

## 解法对比

| | 解法1 暴力比较 | 解法2 差值编码 | 解法3 归一化 |
|---|---|---|---|
| 时间 | O(n²·L) | O(n·L) | O(n·L) |
| 空间 | O(n·L) | O(n·L) | O(n·L) |
| 核心思想 | 直接两两比较 | 差值序列作 key | 归一化首字母作 key |
| 代码量 | 较多 | 简洁 | 最简洁 |
| 面试推荐 | ✗ | ✓ | ✓ |

解法2和解法3本质相同——都是找到"移位不变量"作为哈希 key。区别在于编码方式：
- **差值编码**：更直觉地体现了"不变量"的思想
- **归一化**：代码更简洁，key 就是一个可读的字符串

## 易错点

1. **负数取模**：
   - ✗ `(s[i] - s[i-1]) % 26` — 在 C++ 中 `'a' - 'z' = -25`，`-25 % 26 = -25`（不是 1）
   - ✓ `((s[i] - s[i-1]) % 26 + 26) % 26` — 先加 26 保证非负

2. **差值编码没有分隔符**：
   - ✗ `key += to_string(diff)` — `[1,12]` 和 `[11,2]` 都编码成 `"112"`
   - ✓ `key += to_string(diff) + ","` — 变成 `"1,12,"` 和 `"11,2,"`

3. **单字符字符串被遗忘**：
   - 长度为 1 的字符串差值序列为空，归一化后都是 `"a"`，它们确实应该在同一组
   - 如果你的 key 生成逻辑对空串有特殊处理要确保正确

4. **归一化时修改了原串**：
   - ✗ 直接在 `s` 上修改 — 后面还需要用原始字符串存入结果
   - ✓ 先 `string key = s` 复制一份再操作

## 面试追问

**Q1: 暴力解能过吗？瓶颈在哪？**
> 题目 n≤200，暴力 O(n²·L) 能过。但面试官想听的是 O(n·L) 的哈希分组。瓶颈在于两两比较的 O(n²) 配对。

**Q2: 你用差值序列做 key，能不能用别的方式？**
> 可以归一化到首字母为 'a'。也可以用元组 `(diff1, diff2, ...)` 作为 key（在 Python 中很自然，C++ 中可以用 `vector<int>` 配合自定义哈希）。核心都是找"移位不变量"。

**Q3: 如果字符集不是 26 个小写字母而是 Unicode，怎么处理？**
> 思路不变，但取模的基数从 26 变成字符集大小。如果字符集大小未知或很大，差值编码用分隔符的方式更通用。归一化方式需要知道字符集是循环的（有明确的"回绕"规则）。

**Q4: 如果字符串数量很大（百万级），有什么优化？**
> 可以先按长度分桶——不同长度的字符串一定不在同一组。这能减少哈希表的大小和碰撞概率。长度分桶后再对每个桶内做差值/归一化编码。
