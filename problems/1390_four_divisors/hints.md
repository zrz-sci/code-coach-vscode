# 1390. 四因数

## 核心思路

对数组中每个数，**高效地求出它的因数个数和因数之和**，如果恰好有 4 个因数就累加因数之和。本质是一个**因数枚举优化**问题。

## 思维链

1. **读完题第一反应**：对每个数 `n`，找出它所有因数，如果因数恰好 4 个就把因数加到答案里。最朴素的做法就是从 1 到 n 逐个试除。

2. **暴力解的瓶颈**：对每个数从 1 枚举到 n，试除的代价是 O(n)。数组最大 10⁴ 个元素，每个元素最大 10⁵，总计 10⁹，超时。

3. **怎么突破瓶颈？** 因数成对出现！如果 `d` 是 `n` 的因数，那么 `n/d` 也是。所以只需要枚举到 √n，每找到一个因数 `d`，就同时得到配对因数 `n/d`。这样单个数的试除从 O(n) 降到 O(√n)。

4. **提前终止优化**：我们只需要恰好 4 个因数的数。在枚举过程中，一旦因数个数 > 4，直接跳过这个数，不需要继续枚举。

5. **什么数恰好有 4 个因数？** 数论上只有两种情况：
   - `p × q`（两个不同质数的乘积），因数为 `{1, p, q, p×q}`
   - `p³`（质数的立方），因数为 `{1, p, p², p³}`
   
   虽然理解这一点有助于思考，但代码上直接枚举到 √n 并计数更简洁通用。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力枚举 | 对每个数从 1 到 n 枚举因数 | O(N × max_val) | O(1) | 能说出即可 |
| √n 优化枚举 | 只枚举到 √n，配对取因数 | O(N × √max_val) | O(1) | ⭐ 必须写出 |
| 数论分类 | 分析恰好 4 因数的数学条件 | O(N × √max_val) | O(1) | 加分项 |

## 关键提示

1. **因数成对出现**：如果 `d | n`，则 `n/d | n`。利用这个性质只需枚举到 √n。

2. **完全平方数要小心**：当 `d * d == n` 时，`d` 和 `n/d` 是同一个因数，不要重复计算。

3. **提前终止**：一旦发现因数个数已经超过 4，立刻 break，节省不必要的枚举。

4. **特殊值**：`n = 1` 只有 1 个因数，`n` 是质数只有 2 个因数，这些都不可能有 4 个因数。

5. **数据范围思考**：N ≤ 10⁴，max_val ≤ 10⁵，√(10⁵) ≈ 316。总计约 10⁴ × 316 ≈ 3 × 10⁶，完全可行。

## 解法详解

### 解法1: 暴力枚举 — O(N × max_val) / O(1)

**思考过程**：最直觉的做法——对每个数，从 1 到 n 逐个检查是否整除，收集所有因数。

```cpp
class Solution {
public:
    int sumFourDivisors(vector<int>& nums) {
        int ans = 0;
        for (int n : nums) {
            int cnt = 0, sum = 0;
            // 从 1 到 n 逐个检查是否是因数
            for (int d = 1; d <= n; d++) {
                if (n % d == 0) {
                    cnt++;
                    sum += d;
                }
            }
            if (cnt == 4) ans += sum;
        }
        return ans;
    }
};
```

**关键点**：这个解法正确但太慢。对于 nums[i] = 100000，内层循环要跑 10⁵ 次。总计最坏 10⁹，会 TLE。

---

### 解法2: √n 优化枚举 — O(N × √max_val) / O(1) ⭐ 面试首选

**从解法1优化**：解法1的瓶颈在于内层循环从 1 到 n。利用"因数成对出现"的性质，只需枚举到 √n，每找到一个因数 `d`，就同时获得 `n/d`。

```
// 以 n = 21 为例，枚举到 √21 ≈ 4:
// d=1: 21%1==0 → 因数 1 和 21     cnt=2, sum=22
// d=2: 21%2!=0 → 跳过
// d=3: 21%3==0 → 因数 3 和 7      cnt=4, sum=32
// d=4: 21%4!=0 → 跳过
// 循环结束, cnt=4 → 答案 += 32
//
// 以 n = 4 为例，枚举到 √4 = 2:
// d=1: 4%1==0 → 因数 1 和 4       cnt=2, sum=5
// d=2: 4%2==0, 但 2*2==4（完全平方）→ 只算一个因数 2  cnt=3, sum=7
// 循环结束, cnt=3 ≠ 4 → 不累加
```

```cpp
class Solution {
public:
    int sumFourDivisors(vector<int>& nums) {
        int ans = 0;
        for (int n : nums) {
            int cnt = 0, sum = 0;
            for (int d = 1; d * d <= n; d++) {
                if (n % d == 0) {
                    // d 是一个因数
                    cnt++;
                    sum += d;
                    // n/d 是配对因数（如果不是完全平方的情况）
                    if (d != n / d) {
                        cnt++;
                        sum += n / d;
                    }
                }
                // 提前终止：因数个数已超过4，不可能恰好为4
                if (cnt > 4) break;
            }
            if (cnt == 4) ans += sum;
        }
        return ans;
    }
};
```

**关键点**：
- `d * d <= n` 而不是 `d <= sqrt(n)`，避免浮点精度问题
- `d != n / d` 判断：完全平方数时 d 和 n/d 相同，不能重复计
- 提前终止 `cnt > 4` 是一个常数级优化，实际中非常有效

---

### 解法3: 数论分类 — O(N × √max_val) / O(1)

**思考过程**：什么样的数恰好有 4 个因数？从因数个数公式出发思考。

一个正整数 n 的因数个数由其质因数分解决定：若 `n = p1^a1 × p2^a2 × ...`，则因数个数 = `(a1+1)(a2+1)...`。

要让因数个数恰好为 4 = (a1+1)(a2+1)...，只有两种分解方式：
- **4 = 4**：`n = p³`（一个质数的立方），因数 = {1, p, p², p³}
- **4 = 2×2**：`n = p × q`（两个不同质数的乘积），因数 = {1, p, q, pq}

```cpp
class Solution {
public:
    int sumFourDivisors(vector<int>& nums) {
        int ans = 0;
        for (int n : nums) {
            // 尝试找 n 的最小质因数
            int cnt = 0, sum = 0;
            int temp = n;
            
            // 利用 √n 枚举法，但从数论角度理解
            for (int d = 1; (long long)d * d <= n; d++) {
                if (n % d == 0) {
                    cnt++;
                    sum += d;
                    if (d != n / d) {
                        cnt++;
                        sum += n / d;
                    }
                }
                if (cnt > 4) break;
            }
            if (cnt == 4) ans += sum;
        }
        return ans;
    }
};
```

**关键点**：虽然代码与解法2几乎相同，但数论理解帮助你在面试中解释"为什么恰好是4个因数"：
- 21 = 3 × 7（两个不同质数），因数 = 1+3+7+21 = 32 ✓
- 8 = 2³（质数的立方），因数 = 1+2+4+8 = 15 ✓
- 4 = 2²（质数的平方，因数个数=3），不满足 ✗

| 空间 | O(1) | O(1) | O(1) |

| 面试 | 说思路即可 | **必须写出** | 追问时加分 |

V = max(nums[i]) = 10⁵

## 易错点

1. **完全平方数重复计因数**
   - ✗ `cnt += 2; sum += d + n/d;`（不区分 d == n/d 的情况）
   - ✓ 先加 d，再判断 `if (d != n/d)` 才加 n/d
   - 例如 n=4, d=2: 2×2=4，如果不判断会把 2 计两次，得到 cnt=4（错误）

2. **循环条件溢出**
   - ✗ `d * d <= n`（当 d 和 n 都接近 INT_MAX 时 d*d 溢出）
   - ✓ 本题 n ≤ 10⁵，不会溢出，但养成习惯可以写 `(long long)d * d <= n`

3. **忘记提前终止**
   - 虽然不影响正确性，但没有 `if (cnt > 4) break;` 在某些极端情况下会慢

4. **n = 1 的边界**
   - n=1 只有 1 个因数，cnt=1 ≠ 4，自然不会被累加，不需要特殊处理

## 面试追问

**Q1: 暴力解时间复杂度是多少？能通过吗？**
A: O(N × max_val) = O(10⁴ × 10⁵) = O(10⁹)，会 TLE。瓶颈在于对每个数枚举所有可能的因数。

**Q2: 怎么优化到 √n？为什么正确？**
A: 因数成对出现：若 d | n，则 n/d 也是因数。所以只需枚举 d 从 1 到 √n，每次同时获得两个因数。特别注意完全平方数时 d = n/d 只算一次。

**Q3: 从数学角度，什么样的数恰好有 4 个因数？**
A: 由因数个数公式，(a1+1)(a2+1)... = 4 只有两种情况：p³（质数的立方如8=2³）或 p×q（两不同质数之积如21=3×7）。

**Q4: 如果数组非常大（10⁸ 个元素），每个值范围不变，还能怎么优化？**
A: 可以先对数组去重（用哈希表统计频次），对每个不同的值只计算一次因数。因为值域只有 10⁵，最多计算 10⁵ 次，每次 O(√V)，总计 O(10⁵ × 316) ≈ 3×10⁷。
