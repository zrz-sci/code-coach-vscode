# 402. 移掉 K 位数字

## 核心思路

**单调栈 + 贪心**：要让剩余数字尽可能小，就要让高位尽可能小。从左到右遍历，维护一个**单调递增栈**。当遇到比栈顶小的数字时，弹出栈顶（相当于删掉一个高位大数字），最多删 k 次。

## 思维链

1. **读完题第一反应** → 从 n 位数中删 k 位，剩 n-k 位。暴力枚举所有 C(n,k) 种删法？太慢。
2. **贪心直觉** → 高位的数字影响最大。如果高位有个大数字，后面跟着小数字，删掉大的一定更优。例如 "1**4**3..." 中删掉 4 变成 "13..."，比删掉 3 变成 "14..." 更小。
3. **什么时候删？** → 当前数字比前一个小的时候，说明前一个"太大了"，应该删掉前一个。这正是**单调递增栈**的模式。
4. **用栈维护** → 遍历每个数字 c：只要栈顶 > c 且 k > 0，就弹出栈顶（删掉它，k--）。然后将 c 入栈。
5. **遍历完 k 还没用完？** → 说明栈中是递增序列，从末尾删除剩余的 k 个（末尾是最大的）。
6. **前导零处理** → 删除后结果可能有前导零（如 "10200" 删 1 → "0200"），需要去掉。
7. **全删完的情况** → 结果为空串时返回 "0"。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 单调栈（贪心） | 维护递增栈，弹出大数字 | O(n) | O(n) | ⭐ 唯一正解 |

## 关键提示

1. **单调栈的方向**：维护**从底到顶递增**的栈。遇到比栈顶小的数字时弹出栈顶——这保证了高位尽可能小。
2. **k 的消耗**：每弹出一次栈顶，k 减 1。k 减到 0 后不再弹出，直接入栈。
3. **遍历结束后 k > 0**：说明栈内已经是递增的，此时从末尾删掉 k 个（最大的在末尾）。
4. **前导零**：用 `find_first_not_of('0')` 或手动跳过开头的零。
5. **空结果**：如果全部删完或只剩零，返回 `"0"`。

## 解法详解

### 解法: 单调栈（贪心）— O(n) / O(n) ⭐

**思考过程**: 贪心策略——高位越小越好。遇到"前面大后面小"的模式，删掉前面的大数字。用栈来追踪已保留的数字序列。

```cpp
class Solution {
public:
    string removeKdigits(string num, int k) {
        string stk; // 用 string 模拟栈（底部=开头，顶部=末尾）
        
        for (char c : num) {
            // 栈顶比当前大就弹出（删除高位大数字）
            // 条件：栈非空 && 还有删除额度 && 栈顶 > 当前字符
            while (!stk.empty() && k > 0 && stk.back() > c) {
                stk.pop_back();
                k--;
            }
            stk.push_back(c);
        }
        
        // 如果 k 还有剩余，从末尾删除
        // 此时栈内是递增序列，末尾最大
        while (k > 0) {
            stk.pop_back();
            k--;
        }
        
        // 去掉前导零
        size_t pos = stk.find_first_not_of('0');
        if (pos == string::npos) return "0";
        return stk.substr(pos);
    }
};
```

**关键点**:
- 用 `string` 模拟栈：`push_back` 入栈，`pop_back` 出栈，`back()` 看栈顶。比 `stack<char>` 方便，因为最后直接用 `stk` 作为结果。
- 三个 while 条件缺一不可：`!stk.empty()` 防空栈；`k > 0` 限制删除次数；`stk.back() > c` 保持递增。
- 遍历结束后 k 可能 > 0（输入本身递增，如 "12345"），此时从末尾删。
- `find_first_not_of('0')` 优雅地跳过所有前导零。

---

### 变体写法: 手动去前导零

```cpp
class Solution {
public:
    string removeKdigits(string num, int k) {
        string stk;
        
        for (char c : num) {
            while (!stk.empty() && k > 0 && stk.back() > c) {
                stk.pop_back();
                k--;
            }
            // 避免前导零：栈为空时不入零
            if (!stk.empty() || c != '0') {
                stk.push_back(c);
            }
        }
        
        // k 还有剩余，从末尾删
        while (k > 0 && !stk.empty()) {
            stk.pop_back();
            k--;
        }
        
        return stk.empty() ? "0" : stk;
    }
};
```

**关键点**: 在入栈时就跳过前导零（`stk.empty() && c == '0'` 不入栈），最后不需要再处理前导零。但要注意 k 的消耗还是正确的。

## 解法对比

本题只有一个核心解法（单调栈+贪心），两种写法的对比：

| | 后处理前导零 | 入栈时跳零 |
|---|---|---|
| 代码简洁度 | 更简洁 | 略复杂 |
| 前导零处理 | `find_first_not_of` | 入栈时判断 |
| k 消耗 | 完全一致 | 完全一致 |
| 推荐 | ⭐ 面试首选（不容易出错） | 变体 |

## 易错点

1. **忘记遍历后处理剩余的 k**
   - ✗ 遍历完就结束 → 输入 "12345", k=2 应该输出 "123"，但不处理 k 会输出 "12345"
   - ✓ 遍历后 `while (k > 0) stk.pop_back(), k--;`

2. **忘记去前导零**
   - ✗ 直接返回 stk → 输入 "10200", k=1 返回 "0200" 而非 "200"
   - ✓ `stk.substr(stk.find_first_not_of('0'))` 或入栈时跳零

3. **空结果返回空串而非 "0"**
   - ✗ return stk → 可能是空串 ""
   - ✓ return stk.empty() ? "0" : stk

4. **while 条件漏掉 k > 0**
   - ✗ `while (!stk.empty() && stk.back() > c)` → k 已经用完了还在弹出
   - ✓ `while (!stk.empty() && k > 0 && stk.back() > c)` → k 限制删除次数

5. **用 stack<char> 而非 string 模拟栈**
   - 虽然不是 bug，但 `stack<char>` 最后需要逐个 pop 再 reverse 拼字符串，不如直接用 `string` 方便

## 面试追问

**Q1: 为什么贪心策略正确？**
→ 高位数字对数值的影响最大。如果相邻两位 d_i > d_{i+1}，删掉 d_i 等于把 d_{i+1} 提到更高位，数值一定更小。单调栈保证每次删除都是"当前能做的最优选择"。

**Q2: 时间复杂度为什么是 O(n) 而不是 O(nk)？**
→ 虽然内层是 while 循环，但每个数字最多入栈一次、出栈一次。总的入栈次数 = n，总的出栈次数 <= n，所以总操作 O(n)。

**Q3: 如果要求"移掉 k 位后最大"呢？**
→ 把单调栈方向反过来：维护**单调递减栈**。遇到比栈顶大的数字时弹出栈顶（删掉高位的小数字），让高位尽可能大。

**Q4: 如果允许移除的 k 位不连续呢？**
→ 本题的 k 位就是不连续的。单调栈天然处理了这种情况——从不同位置删除数字。

**Q5: 与 LC 316/1081（去除重复字母/最小字典序）的关系？**
→ 都是"单调栈+贪心"的范式。316/1081 额外要求每个字符恰好出现一次（需要计数器），但核心的"遇到更小就弹出"逻辑完全一样。
