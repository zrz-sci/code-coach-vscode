# 70. 爬楼梯

## 核心思路

这道题本质上就是**斐波那契数列**：到达第 n 阶的方法数 = 到达第 n-1 阶的方法数 + 到达第 n-2 阶的方法数，因为你只能从这两个位置迈一步到达第 n 阶。

## 思维链

1. **读完题第一反应**：每一步有两个选择（爬1阶或2阶），所有选择组合起来就是一棵决策树。最朴素的做法是递归穷举所有可能的爬法。

2. **画出决策树发现重叠**：以 n=5 为例画递归树，发现 `climb(3)` 被计算了多次。这就是暴力递归的瓶颈——**大量重复计算**，时间复杂度是指数级 O(2^n)。

```
                    climb(5)
                  /          \
            climb(4)        climb(3)  ← 这个子问题
            /     \          /    \      被重复计算了
       climb(3)  climb(2)  climb(2) climb(1)
       /    \
  climb(2) climb(1)   ← climb(3)在左右子树都出现了
```

3. **消除重复计算**：用一个数组 memo 记录已经算过的结果。递归到 `climb(k)` 时先查表，有结果直接返回。这就是**记忆化搜索**，把 O(2^n) 降到 O(n)。

4. **翻译成递推（DP）**：既然 `f(n) = f(n-1) + f(n-2)`，直接从小到大用 for 循环填表，连递归栈都省了。

5. **空间优化**：`dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`，不需要整个数组，两个变量就够了。空间从 O(n) 降到 O(1)。

6. **数学解法（加分项）**：这就是斐波那契数列，可以用矩阵快速幂在 O(log n) 时间内求解。

## 关键提示

- **提示1**：站在第 n 阶往回看，你是从哪里来的？只有两种可能：从第 n-1 阶爬1步，或从第 n-2 阶爬2步。
- **提示2**：手算 n=1,2,3,4,5 的答案：1, 2, 3, 5, 8 —— 认出这个数列了吗？
- **提示3**：暴力递归的决策树中，很多子树是完全相同的。怎么避免重复计算？
- **提示4**：当 `dp[i]` 只依赖前两项时，你真的需要一整个数组吗？
- **提示5**：如果面试官追问 O(log n)，想想斐波那契数列的矩阵表示：`[[1,1],[1,0]]^n`。

## 解法详解

### 解法1: 暴力递归 — O(2^n) / O(n)

**思考过程**：每一步有两个选择，递归穷举所有可能。站在第 n 阶，我可能是从第 n-1 阶来的（走1步），也可能从第 n-2 阶来的（走2步）。所以 `ways(n) = ways(n-1) + ways(n-2)`。

```
// 递归树 (n=5):
//                     f(5)
//                   /      \
//               f(4)        f(3)
//              /    \       /    \
//          f(3)    f(2)   f(2)  f(1)
//         /   \   /  \   /  \
//       f(2) f(1) f(1) f(0) f(1) f(0)
//      / \
//   f(1) f(0)
//
// f(3) 被算了 2 次，f(2) 被算了 3 次 → 指数级浪费
```

```cpp
class Solution {
public:
    int climbStairs(int n) {
        // base case: 站在第0阶有1种方式(不动), 第1阶有1种方式
        if (n <= 1) return 1;
        // 从 n-1 走1步 + 从 n-2 走2步
        return climbStairs(n - 1) + climbStairs(n - 2);
    }
};
```

**关键点**：这个解法 n=45 时会超时（2^45 ≈ 3.5万亿次）。但它帮你理解了递推关系，这是所有后续优化的基础。

---

### 解法2: 记忆化搜索 — O(n) / O(n)

**从解法1优化**：解法1的瓶颈是同一个子问题被重复计算。加一个 memo 数组，算过的直接查表返回，每个子问题只算一次。

```cpp
class Solution {
public:
    int climbStairs(int n) {
        vector<int> memo(n + 1, -1);
        return dfs(n, memo);
    }
    
    int dfs(int n, vector<int>& memo) {
        if (n <= 1) return 1;
        // 查表：算过就不再算
        if (memo[n] != -1) return memo[n];
        // 记录结果再返回
        memo[n] = dfs(n - 1, memo) + dfs(n - 2, memo);
        return memo[n];
    }
};
```

**关键点**：memo 初始化为 -1（表示"未计算"），不能初始化为 0，因为 0 可能是合法结果（虽然这题不会，但养成好习惯）。

---

### 解法3: 递推 DP（自底向上）— O(n) / O(n) ⭐ 面试首选

**从记忆化到递推**：记忆化是"自顶向下递归 + 缓存"，递推是"自底向上循环填表"。逻辑完全等价，但省去了递归调用栈的开销。

```
// DP 填表过程 (n=5):
// i:     0  1  2  3  4  5
// dp[i]: 1  1  2  3  5  8
//              ↑
//              dp[2] = dp[1] + dp[0] = 1 + 1 = 2
//                 dp[3] = dp[2] + dp[1] = 2 + 1 = 3
//                    dp[4] = dp[3] + dp[2] = 3 + 2 = 5
//                       dp[5] = dp[4] + dp[3] = 5 + 3 = 8
// 填表方向: ← 从左到右，因为 dp[i] 依赖 dp[i-1] 和 dp[i-2]
```

```cpp
class Solution {
public:
    int climbStairs(int n) {
        if (n <= 1) return 1;
        vector<int> dp(n + 1);
        dp[0] = 1;  // 站在地面，1种方式（不动）
        dp[1] = 1;  // 到第1阶，只能走1步
        for (int i = 2; i <= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
        }
        return dp[n];
    }
};
```

**关键点**：`dp[0] = 1` 不是"0阶有1种爬法"这种物理意义，而是为了让 `dp[2] = dp[1] + dp[0] = 2` 算对。也可以理解为"空走法也算一种"。

---

### 解法4: 滚动变量（空间优化 DP）— O(n) / O(1) ⭐ 面试首选

**从解法3优化**：`dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`，不需要整个数组，两个变量交替滚动即可。

```
// 滚动过程:
// i=2: prev=1, curr=1 → next=2 → prev=1, curr=2
// i=3: prev=1, curr=2 → next=3 → prev=2, curr=3
// i=4: prev=2, curr=3 → next=5 → prev=3, curr=5
// i=5: prev=3, curr=5 → next=8 → prev=5, curr=8  ✓ 答案=8
```

```cpp
class Solution {
public:
    int climbStairs(int n) {
        if (n <= 1) return 1;
        int prev = 1, curr = 1;  // dp[0], dp[1]
        for (int i = 2; i <= n; i++) {
            int next = prev + curr;
            prev = curr;
            curr = next;
        }
        return curr;
    }
};
```

**关键点**：这是线性 DP 空间优化的经典模式。面试中写出这个版本会给面试官留下好印象。

---

### 解法5: 矩阵快速幂 — O(log n) / O(1)

**思考过程**：斐波那契递推可以写成矩阵形式：

```
| f(n)   |   | 1 1 |^(n-1)   | f(1) |
| f(n-1) | = | 1 0 |       × | f(0) |
```

矩阵的 n 次幂可以用快速幂在 O(log n) 时间内算出（和整数快速幂原理一样：把指数二进制分解）。

```cpp
class Solution {
public:
    // 2x2 矩阵乘法
    vector<vector<long long>> multiply(vector<vector<long long>>& A, 
                                       vector<vector<long long>>& B) {
        vector<vector<long long>> C(2, vector<long long>(2, 0));
        for (int i = 0; i < 2; i++)
            for (int j = 0; j < 2; j++)
                for (int k = 0; k < 2; k++)
                    C[i][j] += A[i][k] * B[k][j];
        return C;
    }
    
    // 矩阵快速幂
    vector<vector<long long>> matpow(vector<vector<long long>>& M, int n) {
        vector<vector<long long>> result = {{1, 0}, {0, 1}}; // 单位矩阵
        while (n > 0) {
            if (n & 1) result = multiply(result, M);
            M = multiply(M, M);
            n >>= 1;
        }
        return result;
    }
    
    int climbStairs(int n) {
        if (n <= 1) return 1;
        vector<vector<long long>> M = {{1, 1}, {1, 0}};
        auto result = matpow(M, n);
        return (int)result[0][0];  // M^n 的左上角就是 f(n+1) 对应的值
    }
};
```

**关键点**：n ≤ 45 时这个解法没有实际速度优势（常数大），但展示了数学思维。面试中如果被问"能否比 O(n) 更快"，这是正确答案。

| 空间 | O(n) 栈 | O(n) | O(n) | O(1) | O(1) |

| 面试推荐 | ✗ | 可以 | ✓ | ✓✓ | 加分 |

**选择建议**：面试时先说暴力思路展示理解，然后直接写**滚动变量版本**（解法4），简洁且最优。如果面试官追问更快的方法，再提矩阵快速幂。

## 易错点

1. **`dp[0]` 初始化错误**
   - ✗ `dp[0] = 0`（导致 dp[2] = dp[1] + dp[0] = 1，但正确答案是 2）
   - ✓ `dp[0] = 1`（"空走法"或理解为数学上的 base case）

2. **滚动变量更新顺序错误**
   - ✗ `curr = prev + curr; prev = curr;`（prev 被覆盖前没保存旧 curr）
   - ✓ 先算 `next = prev + curr`，再移动 `prev = curr; curr = next;`

3. **边界条件 n=1 漏处理**
   - 如果直接写循环 `for (int i = 2; i <= n; ...)`，当 n=1 时循环不执行，要确保返回值正确。

4. **递归没有 memo 导致超时**
   - n=45 时暴力递归会 TLE，记住一定要加缓存。

## 面试追问

**Q1（基础理解）**：为什么 `dp[i] = dp[i-1] + dp[i-2]`？
> 到达第 i 阶只有两种可能：从第 i-1 阶走 1 步，或从第 i-2 阶走 2 步。这两种来源互不重叠、覆盖所有情况，所以方法数相加。

**Q2（空间优化）**：能否用 O(1) 空间？
> 可以。dp[i] 只依赖前两项，用两个变量 prev 和 curr 交替更新即可（解法4）。

**Q3（时间优化）**：能否比 O(n) 更快？
> 可以。利用矩阵快速幂，将斐波那契递推写成矩阵乘法形式，O(log n) 求解（解法5）。

**Q4（变体）**：如果每次可以爬 1、2 或 3 步呢？
> 递推关系变为 `dp[i] = dp[i-1] + dp[i-2] + dp[i-3]`，base case 多一个 `dp[2] = 2`（或保持 dp[0]=1 自动推导）。滚动变量从 2 个变成 3 个。

**Q5（泛化）**：如果每次可以爬的步数从一个数组 `steps[]` 中选呢？
> 这就变成了**完全背包问题**：`for each i: for each s in steps: dp[i] += dp[i-s]`。
