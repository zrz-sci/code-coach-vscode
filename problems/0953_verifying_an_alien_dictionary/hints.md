# 953. Verifying an Alien Dictionary

## 核心思路

给定一组单词和一个外星字母表顺序，判断这些单词是否按该字母表的字典序排列。核心方法是**建立字母顺序映射表**，然后**逐对比较相邻单词**：对每对相邻单词，逐字符用映射表比较，找到第一个不同的字符判断顺序。如果所有前缀字符都相同，则较短的单词必须排在前面。

## 思维链

1. **建映射表**：order 字符串给出了字母的优先级，构建 order_map[c] = 该字母的优先级数字
2. **逐对比较**：只需比较 words[i] 和 words[i+1]（i 从 0 到 n-2），因为排序的传递性
3. **逐字符匹配**：对两个相邻单词，找到第一个不同字符的位置
4. **判断顺序**：如果 order_map[word1[j]] > order_map[word2[j]]，返回 false
5. **处理前缀情况**：如果所有公共部分都相同但 word1 比 word2 长，返回 false（"apple" > "app"）
6. **全部通过则返回 true**

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 映射表 + 逐对比较 | O(S) | O(1) | 标准解法，S=总字符数 |
| 替换字符后直接比较 | O(S) | O(S) | 将外星字母转为标准字母后用标准比较 |

## 关键提示

1. **只比较相邻对**：不需要两两比较所有对，排序的传递性保证了只需 n-1 次相邻比较
2. **映射表用数组**：26个字母用 `int order_map[26]` 比 hash map 更快
3. **前缀陷阱**：公共前缀完全相同时，短单词必须在前（"app" < "apple"）
4. **一旦找到不同字符就终止**：后面的字符不再重要
5. **空单词处理**：题目约束 words[i].length >= 1，不用担心空字符串

## 解法详解

### 解法一：映射表 + 逐对比较（推荐）

**思路**：先用 order 字符串建立每个字母的优先级映射。然后遍历相邻单词对，逐字符比较。

**步骤**：
1. 构建映射表：`order_map[order[i] - 'a'] = i`
2. 对每对相邻单词 (words[i], words[i+1])：
   - 逐字符比较，找第一个不同位置 j
   - 如果 order_map[w1[j]] > order_map[w2[j]]，返回 false
   - 如果 order_map[w1[j]] < order_map[w2[j]]，这对没问题，继续下一对
   - 如果所有公共字符都相同，检查 len(w1) <= len(w2)
3. 所有对都通过，返回 true

**复杂度**：
- 时间 O(S)：S 是所有单词的总字符数。每个字符最多被访问一次。
- 空间 O(1)：映射表大小固定为 26。

### 解法二：替换字符后用标准字典序比较

**思路**：将每个单词中的字母按映射替换为标准顺序的字母（如 order 中的第 0 个字母替换为 'a'，第 1 个替换为 'b' 等），然后直接用标准字符串比较 `<=`。

**步骤**：
1. 构建替换表：`replace[order[i] - 'a'] = 'a' + i`
2. 对每个单词，将其字母替换为标准顺序
3. 依次检查 transformed[i] <= transformed[i+1]
4. 如果有任何违反，返回 false

**复杂度**：时间 O(S)，空间 O(S)（存储替换后的单词）。

## 易错点

1. **忘记前缀检查**：两个单词公共部分完全相同，但较长的在前面，应返回 false。例如 ["apple", "app"] 在标准字典序下不合法
2. **映射方向搞反**：`order_map[order[i] - 'a'] = i` 是正确的（字母 -> 优先级），不是 `order_map[i] = order[i]`
3. **找到第一个不同字符后继续比较**：第一个不同字符就决定了顺序，不需要看后面
4. **比较所有单词对而非只看相邻**：相邻比较就够了，不需要 O(n^2) 两两比较
5. **混淆 order 下标和字母下标**：order[0] 是优先级最高（最小）的字母，不是 'a'

## 面试追问

1. **Q: 为什么只比较相邻对就够了？**
   A: 因为排序关系具有传递性。如果 w[0] <= w[1] 且 w[1] <= w[2]，则 w[0] <= w[2]。数学归纳法可证全部有序。

2. **Q: 如果要求按外星字典序排序（而不是验证），怎么做？**
   A: 用映射表作为自定义比较函数，调用 `sort(words.begin(), words.end(), customComp)`。复杂度 O(S * log n)。

3. **Q: 如果 order 不包含所有26个字母（部分字母未定义顺序），怎么处理？**
   A: 未定义的字母可以视为最大优先级（放最后），或者如果单词中出现了未定义的字母，需要报错。

4. **Q: 这道题和拓扑排序有什么关系？**
   A: 逆问题是 LC 269 Alien Dictionary —— 从排序好的单词列表中推断字母表顺序。那道题需要建图做拓扑排序。本题是已知顺序做验证，更简单。

5. **Q: 如果单词数量很大（10^6+），如何优化？**
   A: 当前算法已是最优 O(S)。如果需要频繁验证不同的 order，可以预处理单词的比较结果为有向图。
