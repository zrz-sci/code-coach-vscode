# 834. Sum of Distances in Tree - 提示与解析

## 核心思路

本题要求计算树中每个节点到所有其他节点的距离之和。暴力做法是对每个节点做一次BFS/DFS，时间复杂度O(n^2)。优化的关键在于**换根DP（Rerooting Technique）**：先以任意节点为根计算距离和，然后利用父子关系在O(1)内推导出相邻节点的距离和。当我们从节点u移动到其子节点v时，v的子树中所有节点距离减少1，子树外所有节点距离增加1，因此 `ans[v] = ans[u] - count[v] + (n - count[v])`。

## 思维链

1. **建图**：用邻接表表示无向树
2. **第一次DFS（自底向上）**：以节点0为根，计算每个节点的子树大小 `count[i]` 和以节点0为根时的距离和 `ans[0]`
3. **观察推导关系**：从父节点u到子节点v，v子树内 `count[v]` 个节点距离各减1，子树外 `n - count[v]` 个节点距离各加1
4. **第二次DFS（自顶向下）**：利用公式 `ans[v] = ans[u] - count[v] + (n - count[v])` 推导所有节点的答案
5. **边界处理**：n=1时直接返回 `{0}`

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 推荐度 | 说明 |
|------|-----------|-----------|--------|------|
| 换根DP（两次DFS） | O(n) | O(n) | ⭐⭐⭐⭐⭐ | 最优解，经典换根DP模板 |
| 暴力BFS/DFS | O(n^2) | O(n) | ⭐⭐ | 每个节点做一次遍历 |
| 树形DP + 前缀和 | O(n) | O(n) | ⭐⭐⭐⭐ | 本质同换根DP |

## 关键提示

1. **换根公式的推导**：当根从u移到子节点v时，v子树内的节点都"近了1步"，子树外的节点都"远了1步"
2. **count数组的含义**：`count[v]` 表示以v为根的子树节点数（含v自身）
3. **第一次DFS的目的**：计算出以某个固定根的距离和，为换根提供基础
4. **无向树转有向树**：DFS时通过记录parent避免回访
5. **ans[0]的计算**：在第一次DFS中，`ans[0] += count[child]` 的思路是自底向上累加深度贡献

## 解法详解

### 解法一：换根DP（两次DFS）⭐⭐⭐⭐⭐

**第一阶段 - 自底向上DFS：**
- 以节点0为根进行DFS
- 计算每个节点的子树大小 `count[node]`
- 同时计算 `ans[0]`：每个节点v对ans[0]的贡献就是v的深度

**第二阶段 - 自顶向下DFS：**
- 对于节点u的子节点v，利用公式 `ans[v] = ans[u] + n - 2 * count[v]`
- 公式简化自 `ans[v] = ans[u] - count[v] + (n - count[v])`

**为什么是两次DFS而不是一次？**
- 第一次DFS：只能得到"以0为根"的距离和，以及每个子树的大小
- 第二次DFS：利用已知的ans[parent]来推导ans[child]

### 解法二：暴力BFS ⭐⭐

对每个节点分别做一次BFS，统计到所有节点的距离和。简单但效率低。

## 易错点

1. **count初始化为1**：每个节点的子树大小至少包含自身，初始值应为1而非0
2. **无向图的邻接表**：添加边时需要双向添加
3. **DFS中parent判断**：不能只用visited数组，用parent参数更简洁
4. **换根公式符号**：`ans[v] = ans[u] + n - 2*count[v]`，注意是减去2倍的count[v]
5. **整数溢出**：n最大3*10^4，距离和最大约为n^2级别，用int足够但要注意

## 面试追问

1. **如果树变成有向图（DAG），如何修改？** - 需要拓扑排序 + 类似的DP转移
2. **如果边有权重，如何修改？** - count改为子树的权重和，公式相应调整
3. **能否只用一次DFS？** - 不能，因为换根需要先知道子树大小
4. **空间能否优化？** - 可以用DFS栈模拟递归，但总体O(n)无法再优化
5. **如果要求的是最大距离而非距离和？** - 需要求树的直径，不同的DP状态定义
