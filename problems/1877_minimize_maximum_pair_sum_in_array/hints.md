# 1877. 数组中最大数对和的最小值

## 核心思路

将长度为偶数的数组分成 n/2 对，使所有数对和中的**最大值最小**。核心策略：**排序后最大配最小**——用贪心+双指针在 O(n log n) 内解决。这是一道经典的 minimax 贪心问题。

## 思维链

1. **读完题第一反应**：把数组分成若干对，每对有一个和，求所有对中和的最大值。我们要选择一种分法，让这个最大值尽可能小。这是一个典型的 minimax 优化问题。

2. **直觉引导**：如果两个大数配在一起，它们的和会很大，拉高最大值。如果大数和小数配对，大数的"冲击"被小数"吸收"了。所以应该**大配小**。

3. **贪心策略 — 最大配最小**：排序后，最大的和最小的配对、第二大的和第二小的配对...这样每一对的和都被"均衡化"了。

4. **贪心正确性（反证法）**：
   - 假设最优解中不是最大配最小，即存在 a < b < c < d，且 (a,c) 和 (b,d) 是两对
   - 此时 max(a+c, b+d) = b+d（因为 b+d > a+c）
   - 如果改为 (a,d) 和 (b,c)，则 max(a+d, b+c)
   - 注意 a+d <= b+d（因为 a < b），且 b+c <= b+d（因为 c < d）
   - 所以 max(a+d, b+c) <= b+d = 原方案的最大值
   - 新方案不比原方案差！因此最大配最小的策略是正确的

5. **实现**：排序后双指针，left从头、right从尾，逐对取和，记录最大值。

```
贪心策略可视化:

排序后: [2, 3, 3, 5]

配对方式对比:
  方式A (最大配最小):  (2,5)=7   (3,3)=6    → max = 7 ✓
  方式B (顺序配对):    (2,3)=5   (3,5)=8    → max = 8
  方式C (随机):        (2,3)=5   (3,5)=8    → max = 8

排序后: [2, 3, 4, 4, 5, 6]

最大配最小:  (2,6)=8   (3,5)=8   (4,4)=8   → max = 8 ✓
顺序配对:    (2,3)=5   (4,4)=8   (5,6)=11  → max = 11
最小配最小:  (2,3)=5   (4,5)=9   (4,6)=10  → max = 10

直观理解:
  排序: [小 ... 大]
         ↗ ↙       (最小和最大配)
        ↗ ↙         (第二小和第二大配)
       ↗ ↙           ...
  
  这样每一对的和都趋于"平均"，避免出现极端大的对和
```

## 解法详解

### 解法: 排序 + 双指针 -- O(n log n) / O(1)

**思考过程**：minimax 问题 → 贪心直觉"大配小" → 排序后双指针对向遍历。

**实现步骤**：
1. 对数组排序
2. 双指针 left=0, right=n-1 对向移动
3. 每一步计算 nums[left] + nums[right]，取所有对和的最大值
4. left++, right-- 直到相遇

```cpp
class Solution {
public:
    int minPairSum(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        int res = 0;
        int left = 0, right = nums.size() - 1;
        while (left < right) {
            res = max(res, nums[left] + nums[right]);
            left++;
            right--;
        }
        return res;
    }
};
```

**执行过程详解**：

```
示例: nums = [3, 5, 4, 2, 4, 6]

排序后: [2, 3, 4, 4, 5, 6]
         L              R     → 2+6=8  res=8
            L        R        → 3+5=8  res=8
               L  R           → 4+4=8  res=8

答案: 8

示例: nums = [3, 5, 2, 3]

排序后: [2, 3, 3, 5]
         L        R    → 2+5=7  res=7
            L  R       → 3+3=6  res=7

答案: 7
```

## 关键提示

- **提示1**：这是一道 minimax 贪心题——最小化最大值。核心策略是排序后首尾配对。
- **提示2**：贪心的直觉是"均衡化"——让每一对的和尽量接近，避免出现特别大的对和。类似于"水桶效应的反面"。
- **提示3**：双指针只需一轮遍历（n/2次比较），瓶颈在排序的 O(n log n)。
- **提示4**：反证法证明正确性：任何非"最大配最小"的方案，都可以通过交换变得不更差。这是贪心交换论证的经典范式。
- **提示5**：`n` 保证是偶数，所以不用处理奇数情况。

## 易错点

1. **忘记排序**：直接双指针会得到错误结果，必须先排序。
2. **贪心方向搞反**：不是"最大配最大"，而是"最大配最小"。配对的目标是压低上界，不是让每对都大。
3. **返回值混淆**：返回的是**所有对和中的最大值**，不是对和的总和，也不是最小的那对。
4. **面试沟通**：需要能清晰说明为什么贪心是对的（反证法 or 交换论证），光说"直觉上大配小"不够。

## 贪心正确性的严格证明

**定理**：排序后最大配最小的策略产生所有合法配对方案中最小的最大对和。

**证明（交换论证）**：

设排序后数组为 `a[0] <= a[1] <= ... <= a[n-1]`。

假设存在一个最优方案 S* 不是"最大配最小"。那么存在四个位置满足：
- `a[i]` 和 `a[k]` 配对（i < k）
- `a[j]` 和 `a[l]` 配对（j < l）
- `i < j < k < l`（即不是首尾对称配对）

考虑交换为 `(a[i], a[l])` 和 `(a[j], a[k])`：
- `a[i] + a[l] <= a[j] + a[l]`（因为 i < j → a[i] <= a[j]）
- `a[j] + a[k] <= a[j] + a[l]`（因为 k < l → a[k] <= a[l]）
- 所以新方案中这两对的最大值 `<= a[j] + a[l]`（原方案中两对的最大值）

交换后不会更差。反复应用交换，可以从任何最优方案转化为"最大配最小"方案，且不增加最大对和。

## Follow-up 思考

1. **如果要最小化的是数对和的"总和"而非"最大值"呢？** 总和是固定的（等于数组总和），无论怎么配对都不变。
2. **如果数组长度是奇数呢？** 需要决定哪个元素落单，问题变得更复杂。
3. **如果是分成 k 组（每组不一定2个）呢？** 问题变为 k 分区问题，NP-hard 的变种。
