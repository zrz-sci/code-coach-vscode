# 409. 最长回文串 (Longest Palindrome)

## 核心思路

**贪心 + 字符计数**。回文串的对称结构决定了：除了正中间最多放 1 个字符外，其余字符都必须成对出现。贪心策略：统计每个字符频次，取每个频次的最大偶数部分（`count/2*2`），最后如果有任何字符有"剩余"（至少一个奇数频次字符），总长度再 +1（放中间）。

## 思维链

1. **回文串的字符规律** → 回文串左右对称。除了中心位置（可选），其余位置的字符都必须成对出现。
   - 偶数长度回文："abba" → a=2, b=2，全部成对
   - 奇数长度回文："abcba" → a=2, b=2, c=1，只有 c 出现奇数次且放在正中间
   - 规律：**最多一个字符出现奇数次**

2. **贪心策略** → 要让回文串尽量长，就要尽可能多用字符：
   - 出现 4 次的字符 → 全部用上（4 个）
   - 出现 5 次的字符 → 用 4 个（取偶数部分），剩 1 个
   - 出现 1 次的字符 → 用 0 个（无法配对），剩 1 个
   - 最后看有没有剩余字符 → 有就挑 1 个放中间

3. **编码技巧** → `count / 2 * 2` 就是"向下取整到最近偶数"的优雅写法。偶数不变，奇数减 1。

4. **判断 +1 的条件** → 如果 `result < s.length()`，说明有字符被"浪费"了（频次为奇数），可以挽救 1 个放中间。如果 `result == s.length()`，说明所有字符恰好都是偶数次，不需要 +1。

## 贪心过程可视化

```
输入: s = "abccccdd"

Step 1: 统计频次
┌──────┬──────┐
│ 字符 │ 频次 │
├──────┼──────┤
│  a   │  1   │
│  b   │  1   │
│  c   │  4   │
│  d   │  2   │
└──────┴──────┘

Step 2: 贪心取偶数部分
┌──────┬──────┬────────────┬──────┐
│ 字符 │ 频次 │ 取偶数部分 │ 剩余 │
├──────┼──────┼────────────┼──────┤
│  a   │  1   │ 1/2*2 = 0  │  1   │
│  b   │  1   │ 1/2*2 = 0  │  1   │
│  c   │  4   │ 4/2*2 = 4  │  0   │
│  d   │  2   │ 2/2*2 = 2  │  0   │
├──────┼──────┼────────────┼──────┤
│ 合计 │  8   │     6      │  2   │
└──────┴──────┴────────────┴──────┘

Step 3: 有剩余 (6 < 8) → +1 放中间

答案: 6 + 1 = 7

构造的回文串:
  左半: "dcc"   (d取1个, c取2个)
  中心: "a"     (从剩余中选1个)
  右半: "ccd"   (左半的镜像)
  结果: "dccaccd"  长度 = 7 ✓
```

```
另一个例子: s = "aabb"

频次: a=2, b=2
偶数部分: 2 + 2 = 4
result=4 == s.length()=4 → 无剩余，不+1

答案: 4 (如 "abba")
```

```
边界例子: s = "a"

频次: a=1
偶数部分: 0
result=0 < 1 → +1

答案: 1
```

## 回文串结构图

```
回文串的通用结构:

┌─────────────────────────────────────────────┐
│   左半部分      │   中心(0或1个)  │  右半部分   │
│ (偶数个字符对)  │                │ (左半的镜像) │
└─────────────────────────────────────────────┘

例: "dccaccd"
     ───  ─  ───
     左半 中 右半
     dcc  a  ccd

每个字符的"贡献":
  出偶数次 → 全部放入左右两半，每半各 count/2 个
  出奇数次 → count-1 个放入左右两半，剩 1 个
              可选择其中 1 个放中心
```

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试推荐 |
|------|------|------|------|---------|
| 频次数组 + 贪心 | count/2*2 求和 + 判断+1 | O(n) | O(1) | ⭐ 标准 |
| HashSet 配对法 | 遇到配对移除，计数 | O(n) | O(1) | 简洁 |
| 统计奇数字符数 | n - odd + min(odd,1) | O(n) | O(1) | 最短 |

## 关键提示

1. **区分大小写！** 题目明确说 *"Letters are case sensitive"*，`'A'` 和 `'a'` 是不同字符。用 `int freq[128]` 覆盖所有 ASCII 字符最安全。

2. **向下取偶数的两种写法**：
   ```cpp
   count / 2 * 2     // 整数除法向下取整再乘2
   count & ~1         // 位运算：清除最低位 (~1 = 0xFFFFFFFE)
   ```
   5 / 2 * 2 = 4     5 & ~1 = 4
   6 / 2 * 2 = 6     6 & ~1 = 6
   1 / 2 * 2 = 0     1 & ~1 = 0
   ```

3. **+1 判断条件的等价形式**：
   - `result < s.length()` — 有字符被浪费了，可以挽救 1 个
   - `hasOdd == true` — 存在至少一个奇数频次字符
   - 两者等价，因为"有字符被浪费" ⟺ "存在奇数频次字符"

4. **最简洁的数学公式**：
   ```
   odd = 出现奇数次的字符数量
   答案 = n - odd + min(odd, 1)
   
   解释: 每个奇数字符浪费 1 个(无法配对)
         但可以挽救 1 个放中间
         总浪费 = odd - min(odd, 1) = max(odd - 1, 0)
   ```

5. **不要用 `freq[26]`**：大小写混合时 `'a'-'z'` 和 `'A'-'Z'` 跨越不同 ASCII 范围（65-90 和 97-122），`freq[26]` 会索引越界。用 `freq[128]` 或 `freq[52]`（需手动映射）。

## 解法详解

### 解法 1: 频次数组 + 贪心 — 标准解法

**流程**：统计 → 取偶数部分求和 → 判断是否 +1。

```
for each char c in s:
    freq[c]++

result = 0
for each freq[i]:
    result += freq[i] / 2 * 2

if result < s.length():
    result++

return result
```

### 解法 2: HashSet 配对法

**直觉**：遍历字符串，维护一个"等待配对"的 set。
- 遇到 set 中已有的字符 → 配对成功！移除，result += 2
- 遇到 set 中没有的 → 加入等待
- 最终 set 非空 → result += 1

```
s = "abccccdd"
过程:
  'a' → set={a}
  'b' → set={a,b}
  'c' → set={a,b,c}
  'c' → 配对! set={a,b}, result=2
  'c' → set={a,b,c}
  'c' → 配对! set={a,b}, result=4
  'd' → set={a,b,d}
  'd' → 配对! set={a,b}, result=6
set 非空 → result=7
```

### 解法 3: 统计奇数字符数 — 代码最短

```
odd = 出现奇数次的字符个数 = 2 (a=1次, b=1次)
答案 = 8 - 2 + 1 = 7
```

## 易错点

1. **忘记大小写敏感**：把字符串转小写再处理 → 合并了本应分开的字符，结果偏大。

2. **+1 条件判断出错**：
   - ✗ 无条件 +1 → 当所有字符都是偶数次时（如 "aabb"），答案多 1
   - ✓ 只在有剩余字符时 +1

3. **频次数组大小不够**：
   - ✗ `freq[26]` → 大小写混合时越界或冲突
   - ✓ `freq[128]` 或 `unordered_map`

4. **混淆"构造回文串"和"计算长度"**：本题只需返回长度，不需要实际构造。

5. **空字符串**：约束保证 `s.length >= 1`，但面试中提及这个边界是加分项。

## 拓展：实际构造回文串

```
Step 1: 统计频次
Step 2: 左半 = 每个字符取 count/2 个
Step 3: 中心 = 如果有奇数次字符，选 1 个
Step 4: 右半 = reverse(左半)
Step 5: 结果 = 左半 + 中心 + 右半

s = "abccccdd"
左半 = "dcc" (d取1个, c取2个)
中心 = "a"
右半 = "ccd"
结果 = "dccaccd"
```

## 面试追问

**Q1: 如果字符集不限于英文字母（Unicode）？**
> 用 `unordered_map<char, int>` 替代固定数组，适应任意字符集。

**Q2: 如果要构造而非仅返回长度？**
> 见上方拓展。面试中能答出"左半 + 中心 + 反转左半"的框架即可。

**Q3: 与 #266 Palindrome Permutation 的关系？**
> #266 是判定版：能否重排成回文 ⟺ 最多 1 个奇数频次字符。本题是在此基础上求最长长度。
