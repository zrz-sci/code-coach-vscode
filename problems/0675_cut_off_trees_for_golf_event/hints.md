# 675. Cut Off Trees for Golf Event - 为高尔夫比赛砍树

## 核心思路

将问题拆成两部分：(1) 确定砍树顺序 (2) 求相邻目标间的最短路径。树必须从矮到高砍，因此把所有树按高度排序得到一个有序目标列表。从 (0,0) 出发，依次用 BFS 到达每棵目标树，将每段 BFS 的步数累加即为总答案。若任何一段不可达则返回 -1。

## 思维链

1. 读题：m x n 的网格，0 不可走，1 可走，>1 是树且可走。必须从矮到高砍树。
2. 砍树顺序固定 -> 贪心不需要选择，只需按高度排序。
3. 多段最短路：起点到第一棵树、第一棵到第二棵、...、第 k-1 棵到第 k 棵。
4. 每段用 BFS 求最短路（无权网格，BFS 就是最优）。
5. 任何一段 BFS 返回 -1 则整体不可达。
6. 时间复杂度分析：最多 m*n 棵树，每次 BFS 是 O(m*n)，总计 O(m^2 * n^2)。
7. 约束 m, n <= 50，最坏约 50^4 = 6.25 * 10^6，完全可接受。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|-----------|-----------|---------|
| 排序 + BFS | O(m^2 * n^2) | O(m * n) | 标准做法，面试首选 |
| 排序 + A* | O(m^2 * n^2) 最坏 | O(m * n) | 平均更快，但实现复杂 |
| 排序 + Hadlock's | O(m * n * T) | O(m * n) | 比 A* 实现更简单 |

## 关键提示

1. **树的收集与排序**：遍历网格，将所有 `forest[i][j] > 1` 的格子存为 `{height, row, col}`，按 height 升序排列。
2. **BFS 模板**：标准网格 BFS，四方向扩展，visited 数组防止重复访问，逐层扩展计步数。
3. **起点更新**：每段 BFS 的终点就是下一段 BFS 的起点。砍完树后该格子变成 1（可走），不影响后续 BFS。
4. **不可达剪枝**：若起点格子 `forest[0][0] == 0`，直接返回 -1。
5. **结构化分解**：把 BFS 抽成独立函数 `bfs(sr, sc, tr, tc)`，主函数循环调用，代码清晰。

## 解法详解

### 解法一：排序 + 多次 BFS（推荐）

**思路**：
- 收集所有树并按高度排序，得到目标序列 `trees[]`
- 从 `(0, 0)` 出发，依次 BFS 走到 `trees[0]`、`trees[1]`、... 、`trees[T-1]`
- 累加每段距离，任一段不可达则返回 -1

**BFS 细节**：
- 使用队列，每层扩展后步数 +1
- 到达目标坐标立即返回步数
- 起点 == 终点时返回 0

**复杂度**：
- 时间：O(T * m * n)，T 为树的数量，最坏 T = m*n，即 O(m^2 * n^2)
- 空间：O(m * n)，visited 数组

### 解法二：排序 + A* 搜索

**思路**：
- 同样按高度排序，但用 A* 代替朴素 BFS
- 启发函数 h = 曼哈顿距离到目标
- 优先级队列按 f = g + h 排序，g 为已走步数
- 平均情况下探索的节点数远少于 BFS

**注意**：最坏情况复杂度不优于 BFS，但实际表现通常更好。

## 易错点

1. **忘记排序**：题目要求从矮到高砍树，不排序会导致砍树顺序错误。
2. **起点不更新**：每次砍完树后，下一次 BFS 的起点应该是刚砍完的树的位置，而不是 (0,0)。
3. **visited 不重置**：每次 BFS 都需要全新的 visited 数组，不能复用上一次的。
4. **遗漏起点检查**：如果 `sr == tr && sc == tc`，不做 BFS 直接返回 0，否则队列中会漏掉起点格子。
5. **0 的处理**：`forest[i][j] == 0` 表示不可走，BFS 扩展时必须检查 `> 0`。
6. **树的起始值**：高度 > 1 才是树，高度 == 1 是空地，不要把 1 也当树收集。

## 面试追问

1. **Q: 如果网格非常大（如 1000x1000），如何优化？**
   A: 可以用 A* 搜索替代 BFS，利用曼哈顿距离作为启发函数，减少探索的节点数。也可以考虑双向 BFS。

2. **Q: 如果允许对角线移动（8方向），代码怎么改？**
   A: 修改方向数组为8个方向，BFS 其余逻辑不变。注意对角移动的步长仍为1步。

3. **Q: 如果有些树不需要砍（可选），求最小步数呢？**
   A: 变成 TSP（旅行商问题），NP-hard，需要用状态压缩 DP 或贪心近似。

4. **Q: 时间复杂度能否进一步优化？**
   A: 理论上可以预计算所有 pair 之间的距离（Floyd-Warshall），但空间 O(m^2 * n^2) 更大，实际意义不大。在本题约束下 BFS 已足够。

5. **Q: 如果两棵树高度相同怎么办？**
   A: 题目保证所有树高度不同。若允许相同高度，需要额外定义砍树顺序（如按位置排序）。
