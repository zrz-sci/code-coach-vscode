# 1281. 整数的各位积和之差

## 核心思路

一道纯粹的**数位分离**入门题：把一个整数的每一位数字拆出来，分别算乘积和求和，最后返回差值。关键操作就是 `n % 10` 取末位 + `n /= 10` 去掉末位。

## 思维链

1. **读完题第一反应** → 需要把整数 n 的每一位拆出来。拆位是基本功：`n % 10` 拿到最后一位，`n / 10` 去掉最后一位，循环直到 n 变成 0。
2. **需要什么变量？** → 两个累加器：`product`（各位数字之积，初始化为 1）和 `sum`（各位数字之和，初始化为 0）。
3. **循环怎么写？** → `while (n > 0)` 循环，每轮提取 `digit = n % 10`，然后 `product *= digit; sum += digit; n /= 10;`。
4. **有没有边界要考虑？** → n 的范围是 `[1, 10^5]`，最多 6 位数。n 是正整数，不需要处理负数或 0 的情况。
5. **最终结果** → 返回 `product - sum`。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 循环取模（推荐） | while 循环逐位取模分离 | O(d) | O(1) | 唯一标准写法 |
| 字符串转换 | 转成字符串逐字符处理 | O(d) | O(d) | 可提但不推荐 |
| 递归拆位 | 递归方式处理每一位 | O(d) | O(d) | 理解递归的练习 |

其中 d 是数字位数，最多为 6。

## 关键提示

1. **乘积初始化为 1，和初始化为 0**：这是乘法和加法各自的**幺元**。如果 product 初始化为 0，乘积永远是 0。
2. **取模操作 `% 10`** 提取的是最低位（个位），不是最高位。所以我们是从右往左一位一位处理的，但因为加法和乘法都满足交换律，顺序无所谓。
3. **整数除法 `/ 10`** 在 C++ 中对正整数天然向下取整，等价于"去掉末位"。
4. **n 的范围 [1, 10^5]** 意味着最大值为 99999，最多 5 位数，所以不会有任何溢出问题（int 绰绰有余）。
5. **不需要先知道 n 有几位数**：循环终止条件 `n > 0` 自动处理了任意位数。
6. **包含 0 的数字怎么办？** 比如 n=105，digit 依次是 5, 0, 1。product = 5*0*1 = 0, sum = 5+0+1 = 6，结果为 -6。当某位为 0 时乘积直接归零，这是正确行为。

## 解法详解

### 解法1: 循环取模 — O(d) / O(1) ⭐ 标准写法

**思考过程**: 这是处理整数数位的标准模板。核心就两个操作：`% 10` 取末位，`/ 10` 去末位。

```
示例: n = 234

第1轮: digit = 234 % 10 = 4
       product = 1 * 4 = 4,  sum = 0 + 4 = 4
       n = 234 / 10 = 23

第2轮: digit = 23 % 10 = 3
       product = 4 * 3 = 12, sum = 4 + 3 = 7
       n = 23 / 10 = 2

第3轮: digit = 2 % 10 = 2
       product = 12 * 2 = 24, sum = 7 + 2 = 9
       n = 2 / 10 = 0

循环结束: product - sum = 24 - 9 = 15 ✓
```

```cpp
class Solution {
public:
    int subtractProductAndSum(int n) {
        int product = 1, sum = 0;
        while (n > 0) {
            int digit = n % 10;  // 取最低位
            product *= digit;
            sum += digit;
            n /= 10;            // 去掉最低位
        }
        return product - sum;
    }
};
```

**关键点**:
- `product` 必须初始化为 1（乘法单位元），`sum` 初始化为 0（加法单位元）。
- 循环条件 `n > 0`，当 n 变为 0 时所有位都已处理完。
- 整个过程不需要知道 n 有几位，不需要额外数组存储，完美的 O(1) 空间。

---

### 解法2: 字符串转换 — O(d) / O(d)

**不同视角**: 把整数转成字符串，直接按字符遍历。每个字符减去 `'0'` 就得到对应的数字。

```
示例: n = 4421
str = "4421"

遍历:
  '4' - '0' = 4 → product = 1*4 = 4,  sum = 0+4 = 4
  '4' - '0' = 4 → product = 4*4 = 16, sum = 4+4 = 8
  '2' - '0' = 2 → product = 16*2 = 32, sum = 8+2 = 10
  '1' - '0' = 1 → product = 32*1 = 32, sum = 10+1 = 11

product - sum = 32 - 11 = 21 ✓
```

```cpp
class Solution {
public:
    int subtractProductAndSum(int n) {
        string s = to_string(n);
        int product = 1, sum = 0;
        for (char c : s) {
            int digit = c - '0';
            product *= digit;
            sum += digit;
        }
        return product - sum;
    }
};
```

**关键点**:
- `to_string()` 将整数转为字符串，额外使用 O(d) 空间。
- `c - '0'` 是字符转数字的标准技巧，利用 ASCII 码中 '0'~'9' 连续排列。
- 这种写法更直观，但面试中取模写法更能展示对数字运算的理解。

---

### 解法3: 递归拆位 — O(d) / O(d)

**递归视角**: 把"处理 n 的所有位"分解为"处理 n 的末位" + "递归处理 n / 10"。用引用参数传递 product 和 sum。

```cpp
class Solution {
public:
    int subtractProductAndSum(int n) {
        int product = 1, sum = 0;
        helper(n, product, sum);
        return product - sum;
    }
    
    void helper(int n, int& product, int& sum) {
        if (n == 0) return;
        int digit = n % 10;
        product *= digit;
        sum += digit;
        helper(n / 10, product, sum);
    }
};
```

**关键点**:
- 递归深度等于位数 d，不会栈溢出（最多 6 层）。
- 这只是循环的等价递归写法，实际面试不会用这种方式，但有助于理解递归拆解的思维。

## 解法对比

|  | 循环取模 | 字符串转换 | 递归拆位 |
|--|---------|-----------|---------|
| 时间 | O(d) | O(d) | O(d) |
| 空间 | **O(1)** | O(d) | O(d) 栈 |
| 代码量 | 6 行 | 7 行 | 12 行 |
| 面试推荐 | ⭐ 首选 | 可接受 | 不推荐 |

**面试选择**: 直接写循环取模。这是数位处理的基本功，面试官通常期望看到这种写法。

## 易错点

1. **product 初始化为 0**：
   - ✗ `int product = 0;` → 乘积永远为 0
   - ✓ `int product = 1;` → 乘法单位元

2. **循环条件写错**：
   - ✗ `while (n >= 0)` → 当 n=0 时还会执行一次，多乘一个 0，product 变成 0
   - ✓ `while (n > 0)` → n 为 0 时停止

3. **忘记 n /= 10**：
   - ✗ 只做了 `n % 10` 没有 `n /= 10` → 死循环
   - ✓ 取完末位后必须 `n /= 10` 去掉它

4. **字符串方法中 '0' 写成 0**：
   - ✗ `int digit = c - 0;` → 得到 ASCII 值（如 '4' 是 52）
   - ✓ `int digit = c - '0';` → 得到数字值 4

## 面试追问

**Q1: 如果 n 可以是 0，怎么处理？**
> 当 n=0 时，while 循环不会执行，product 仍为 1，sum 为 0，返回 1-0=1。但题目约束 n >= 1 所以不需要特殊处理。如果真要处理 n=0，可以在循环前加 `if (n == 0) return 0;`。

**Q2: 如果 n 可以是负数呢？**
> 题目明确 n >= 1。如果要支持负数，先取绝对值 `n = abs(n)` 再处理。C++ 中 `-7 % 10` 结果是 `-7`（不是 3），所以负数取模需要特别注意。

**Q3: 如果 n 非常大（超过 int 范围），怎么办？**
> 可以把 n 作为字符串输入，用字符串方法逐字符处理。或者用 `long long` 类型。注意乘积可能溢出：10^18 的 18 个 9 相乘是 9^18 约 1.5 * 10^17，刚好在 long long 范围内。

**Q4: 这道题的数位拆分技巧还能用在哪？**
> 非常多：LeetCode 7（整数反转）、LeetCode 9（回文数）、LeetCode 258（各位相加）、LeetCode 202（快乐数）都用到 `% 10` + `/ 10` 的数位拆分。这是处理整数的最基本模板。

## 相关题型

- **7. 整数反转 (Reverse Integer)** — 同样用 `% 10` 和 `/ 10` 逐位提取，把数字倒序拼回去。额外需要处理溢出检查。
- **9. 回文数 (Palindrome Number)** — 把后半部分反转，和前半部分比较。核心是同样的取模拆位。
- **258. 各位相加 (Add Digits)** — 反复把各位数字相加直到变成一位数。循环取模是基础操作，进阶可以用数学公式 `1 + (n-1) % 9`。
- **202. 快乐数 (Happy Number)** — 反复对各位数字求平方和，判断是否最终变为 1。数位拆分 + 快慢指针检测循环。
- **LeetCode 2535. 数组元素和与数字和的绝对差** — 类似思想，对数组中每个元素进行数位拆分。
