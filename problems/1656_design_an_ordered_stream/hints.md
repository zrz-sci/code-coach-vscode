# 1656. 设计有序流

## 核心思路

本质上就是一个**带指针的缓冲区**：数据乱序到达，你需要用一个数组暂存，然后用一个指针 `ptr` 从头开始，每次插入后尝试从 `ptr` 位置连续往后输出所有已到达的值。

## 思维链

1. **读完题第一反应**：数据乱序到来，但要按顺序输出。这和"按序打印"的场景很像 — 先到的不一定先输出，要等前面的到齐才行。
2. **需要什么数据结构？** 需要一个地方存放已到达但还没轮到输出的数据。由于 id 是 1~n 的整数，直接用一个大小为 n 的数组，按 id 放到对应位置即可。
3. **怎么知道该输出什么？** 维护一个指针 `ptr`，代表"下一个应该输出的 id"。每次 insert 后，检查 `ptr` 位置是否有值，如果有就连续往后收集，直到遇到空位。
4. **指针怎么更新？** 输出了一段连续的值后，`ptr` 停在第一个空位的位置，等待下次插入。
5. **复杂度分析**：每个元素最多被指针扫过一次（输出一次后指针就越过它了），所以 n 次 insert 的**总体**时间是 O(n)，均摊每次 insert 是 O(1)。

## 解法概览

| 解法 | 思路 | 时间（单次 insert） | 空间 | 面试 |
|------|------|------|------|------|
| 数组 + 指针 | 数组暂存，指针连续扫描输出 | 均摊 O(1) | O(n) | ⭐ 必须写出 |

> 这道题本身只有一种核心解法，关键在于理解指针的移动逻辑和均摊分析。

## 关键提示

1. **id 是 1 到 n 的整数** — 这意味着可以直接用数组下标映射，不需要哈希表（虽然用也行，但数组更直接）。
2. **指针 `ptr` 只会前进不会后退** — 这是均摊 O(1) 的关键：n 次调用总共最多移动 n 步。
3. **注意下标转换**：id 从 1 开始，数组下标从 0 开始。可以选择开 n+1 大小的数组避免 -1 操作。
4. **空字符串 vs 空位**：用空字符串 `""` 表示该位置还没有数据到达，这是判断是否连续的依据。

```
// 示例执行过程（ptr 用 ↓ 标注）:
//
// 初始:    [ _  _  _  _  _ ]     ptr=1
//           ↓
//
// insert(3,"ccccc"):
//          [ _  _  c  _  _ ]     ptr=1, stream[1]为空 → 返回 []
//           ↓
//
// insert(1,"aaaaa"):
//          [ a  _  c  _  _ ]     ptr=1, stream[1]="a" → 输出"a"
//              ↓                  ptr→2, stream[2]为空 → 停止
//                                返回 ["aaaaa"]
//
// insert(2,"bbbbb"):
//          [ a  b  c  _  _ ]     ptr=2, stream[2]="b" → 输出"b"
//                    ↓            ptr→3, stream[3]="c" → 输出"c"
//                                 ptr→4, stream[4]为空 → 停止
//                                返回 ["bbbbb","ccccc"]
//
// insert(5,"eeeee"):
//          [ a  b  c  _  e ]     ptr=4, stream[4]为空 → 返回 []
//                    ↓
//
// insert(4,"ddddd"):
//          [ a  b  c  d  e ]     ptr=4, stream[4]="d" → 输出"d"
//                             ↓   ptr→5, stream[5]="e" → 输出"e"
//                                 ptr→6, 越界 → 停止
//                                返回 ["ddddd","eeeee"]
```

## 解法详解

### 解法1: 数组 + 指针 — 均摊 O(1) / O(n) ⭐ 面试首选

**思考过程**：id 是 1~n 的连续整数，天然可以映射到数组下标。我们只需要：
- 一个数组 `stream[n]` 存储已到达的值
- 一个指针 `ptr` 记录"下一个应该输出的位置"
- 每次 insert 后，从 `ptr` 开始尝试连续输出

```cpp
class OrderedStream {
public:
    vector<string> stream;
    int ptr;  // 下一个应该输出的位置（1-indexed）
    
    OrderedStream(int n) {
        stream.resize(n + 1);  // 下标 1~n，0 位置不用
        ptr = 1;
    }
    
    vector<string> insert(int idKey, string value) {
        stream[idKey] = value;  // 放到对应位置
        
        vector<string> result;
        // 从 ptr 开始，连续收集非空的值
        while (ptr < (int)stream.size() && !stream[ptr].empty()) {
            result.push_back(stream[ptr]);
            ptr++;  // 指针只前进不后退
        }
        return result;
    }
};
```

**关键点**：
- `ptr` 是全局状态，跨 insert 调用持续前进
- while 循环不是每次都走很多步 — n 次调用总共最多走 n 步（均摊 O(1)）

## 解法对比

这道题解法单一，核心就是数组 + 指针。变体上可以用 `unordered_map` 代替数组，但由于 id 是连续整数，数组更高效。

| 存储方式 | 查找 | 空间 | 适用场景 |
|----------|------|------|----------|
| 数组 | O(1) 下标访问 | O(n) | id 是连续整数（本题） |
| 哈希表 | O(1) 均摊 | O(n) | id 范围很大/不连续 |

## 易错点

1. **下标偏移错误**：
   - ✗ `stream.resize(n)` 然后用 `stream[idKey]` — 当 idKey=n 时越界！
   - ✓ `stream.resize(n + 1)` 让下标 1~n 都可用

2. **ptr 初始值错误**：
   - ✗ `ptr = 0` — 题目说 id 从 1 开始，ptr 也应该从 1 开始
   - ✓ `ptr = 1`

3. **忘记判断空位的标准**：
   - ✗ 用 `stream[ptr] != nullptr` — C++ 中 string 不是指针
   - ✓ 用 `!stream[ptr].empty()`，默认构造的 string 是空串

4. **while 循环的边界**：
   - ✗ `while (ptr <= n && ...)` 但忘记存 n — 要么存 n 要么用 `stream.size()`
   - ✓ `while (ptr < (int)stream.size() && !stream[ptr].empty())`

## 面试追问

**Q1: 时间复杂度是多少？每次 insert 都是 O(1) 吗？**
> 单次 insert 最坏是 O(n)（比如最后一个到达的是 id=1，此时 ptr 从 1 扫到 n）。但 n 次 insert **总计**只移动 ptr n 步，所以**均摊**每次是 O(1)。

**Q2: 如果 id 的范围不是 1~n 而是任意整数（比如 10^9），怎么改？**
> 把数组换成 `unordered_map<int, string>`，查找 `ptr` 位置是否存在用 `map.count(ptr)`。其他逻辑不变。

**Q3: 如果要支持多线程并发 insert 呢？**
> `ptr` 和 `stream` 是共享状态，需要加锁（mutex）保护。或者用 lock-free 的方式：每个线程只写自己的 slot（原子操作），但 ptr 的推进需要 CAS 操作。
