# 917. 仅仅反转字母

## 核心思路

给定字符串 s，只反转其中的英文字母，非字母字符保持原位。本质上就是双指针问题——左右两个指针从两端向中间靠拢，遇到非字母就跳过，遇到两个字母就交换。和"移除元素后反转"的模式一样，只是多了一个"跳过非字母"的判断。

## 思维链

1. **读完题第一反应**：把所有字母提取出来，反转这个字母序列，然后按顺序填回原字符串中字母的位置。
2. **暴力解的瓶颈**：需要额外空间存储提取出的字母序列，空间 O(n)。能否原地完成？
3. **双指针优化**：用 left 和 right 两个指针分别从字符串两端出发。left 向右移动跳过非字母，right 向左移动跳过非字母。当两个指针都指向字母时，交换它们并同时移动。这和经典的"反转字符串"思路一样，只是多了跳过非字母的逻辑。
4. **为什么双指针有效？** 非字母字符不参与交换，始终待在原位。字母之间的相对顺序被完全反转——第一个字母和最后一个字母交换，第二个和倒数第二个交换，以此类推。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 提取-反转-填回 | 提取字母，反转后填回原位 | O(n) | O(n) | 能说出即可 |
| 栈辅助 | 字母入栈，再遍历一次弹出 | O(n) | O(n) | 了解 |
| 双指针 | 左右指针跳过非字母，交换字母 | O(n) | O(1) | 面试首选 |

## 关键提示

1. **判断是否是英文字母**：使用 `isalpha(c)` 函数，可以同时判断大写和小写字母。不需要手动写 `(c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z')`（虽然也可以）。
2. **双指针的移动逻辑**：left 和 right 都要先跳过非字母才能交换。注意检查 `left < right` 条件要贯穿整个循环，包括跳过非字母的内层循环。
3. **交换后两个指针都要移动**：swap 之后 left++ 和 right--，因为交换完的两个位置已经确定了最终值。
4. **字符串修改是原地的**：C++ 的 string 支持通过下标直接修改字符，不需要额外空间。

```
// 双指针过程示意 (s = "a-bC-dEf-ghIj"):
//
// 初始:  a  -  b  C  -  d  E  f  -  g  h  I  j
// left=0                                    right=12
//
// Step1: s[0]='a' 是字母, s[12]='j' 是字母 → 交换
//        j  -  b  C  -  d  E  f  -  g  h  I  a
//        left=1                          right=11
//
// Step2: s[1]='-' 跳过 → left=2
//        s[11]='I' 是字母, s[2]='b' 是字母 → 交换
//        j  -  I  C  -  d  E  f  -  g  h  b  a
//        left=3                       right=10
//
// Step3: s[3]='C', s[10]='h' → 交换
//        j  -  I  h  -  d  E  f  -  g  C  b  a
//        left=4                    right=9
//
// Step4: s[4]='-' 跳过 → left=5
//        s[5]='d', s[9]='g' → 交换
//        j  -  I  h  -  g  E  f  -  d  C  b  a
//        left=6                 right=8
//
// Step5: s[8]='-' 跳过 → right=7
//        s[6]='E', s[7]='f' → 交换
//        j  -  I  h  -  g  f  E  -  d  C  b  a
//        left=7              right=6 → left >= right, 结束
//
// 结果: "j-Ih-gfE-dCba" ✓
```

## 解法详解

### 解法1: 提取-反转-填回 — O(n) / O(n)

**思考过程**：最直觉——把所有字母提取到一个数组中，反转该数组，然后按顺序填回原字符串中的字母位置。

```cpp
class Solution {
public:
    string reverseOnlyLetters(string s) {
        // 提取所有字母
        string letters;
        for (char c : s) {
            if (isalpha(c)) letters += c;
        }
        
        // 反转字母序列
        reverse(letters.begin(), letters.end());
        
        // 填回原字符串的字母位置
        int idx = 0;
        for (int i = 0; i < (int)s.size(); i++) {
            if (isalpha(s[i])) {
                s[i] = letters[idx++];
            }
        }
        
        return s;
    }
};
```

**关键点**：逻辑清晰但需要 O(n) 额外空间存储字母序列。

---

### 解法2: 栈辅助 — O(n) / O(n)

**不同角度**：用栈的 LIFO 特性天然实现"反转"——先把所有字母入栈，然后遍历字符串时遇到字母就弹出栈顶（最后入栈的最先弹出，实现反转）。

```cpp
class Solution {
public:
    string reverseOnlyLetters(string s) {
        stack<char> stk;
        // 所有字母入栈
        for (char c : s) {
            if (isalpha(c)) stk.push(c);
        }
        
        // 遍历字符串，字母位置用栈顶替换
        string result;
        for (char c : s) {
            if (isalpha(c)) {
                result += stk.top();
                stk.pop();
            } else {
                result += c;
            }
        }
        
        return result;
    }
};
```

**关键点**：栈的 LIFO 自动完成了反转，代码简洁。但空间仍是 O(n)。

---

### 解法3: 双指针 — O(n) / O(1) 面试首选

**从前两个解法优化**：前两种方法都需要额外空间来存储字母。能否原地完成？用双指针！左指针从头开始，右指针从尾开始，两者都跳过非字母字符，遇到两个字母就交换。

```cpp
class Solution {
public:
    string reverseOnlyLetters(string s) {
        int left = 0, right = s.size() - 1;
        
        while (left < right) {
            // 左指针跳过非字母
            while (left < right && !isalpha(s[left])) {
                left++;
            }
            // 右指针跳过非字母
            while (left < right && !isalpha(s[right])) {
                right--;
            }
            
            // 两个指针都指向字母，交换
            if (left < right) {
                swap(s[left], s[right]);
                left++;
                right--;
            }
        }
        
        return s;
    }
};
```

**关键点**：
- 每个内层 while 都要检查 `left < right`，防止指针越界或交叉。
- swap 之后两个指针都要移动（left++ 和 right--），因为已经处理完了。
- 原地修改，空间 O(1)。

## 解法对比

| | 提取-反转-填回 | 栈辅助 | 双指针 |
|---|---|---|---|
| 时间 | O(n) | O(n) | O(n) |
| 空间 | O(n) | O(n) | O(1) |
| 核心思想 | 提取→反转→填回 | 栈的 LIFO 特性 | 左右指针跳过非字母 |
| 代码复杂度 | 简单 | 简单 | 简单 |
| 面试推荐 | 开场思路 | 了解 | **首选** |

**什么时候选哪个？**
- 面试直接写双指针，O(1) 空间是加分项。
- 如果紧张想不出双指针，用解法1也完全可以通过。

## 易错点

1. **内层 while 忘记检查 left < right**
   - 如果字符串全是非字母字符（如 "---"），不检查会导致 left 超过 right 甚至越界。

2. **isalpha 和手动判断的一致性**
   - `isalpha(c)` 等价于 `(c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z')`。两种写法都可以，但要确保大小写都包含。

3. **swap 后忘记移动指针**
   - 交换后如果不 left++ 和 right--，会在同一对字母上无限交换。

4. **修改原字符串 vs 返回新字符串**
   - 双指针解法直接修改输入字符串 s，然后返回 s。如果题目要求不修改原字符串，需要先拷贝一份。

## 面试追问

**Q1: 暴力解怎么做？用什么数据结构可以简化？**
> 提取所有字母到数组，反转后填回。或者用栈——字母入栈，遍历时遇到字母弹栈顶，LIFO 自动完成反转。

**Q2: 双指针的核心和经典反转字符串有什么区别？**
> 核心思想完全一样（左右指针向中间靠拢并交换），区别是多了"跳过非字母字符"的逻辑。

**Q3: 如果要求反转的不是字母而是数字呢？**
> 只需把 `isalpha` 换成 `isdigit`。模式完全一样。

**Q4: 如果字符串中只有一个字母或没有字母怎么办？**
> 只有一个字母时双指针 left == right 直接退出，不交换。没有字母时 left 一直跳到 >= right，也直接退出。两种情况都正确处理。
