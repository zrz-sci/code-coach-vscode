# 507. 完美数

## 核心思路

**因子枚举优化**：检查 num 的所有正因子之和是否等于 num 本身。关键优化是只枚举到 sqrt(num)，因为因子成对出现。

## 思维链

1. **理解完美数定义**：一个正整数等于其所有**真因子**（除自身外的正因子）之和，如 28 = 1+2+4+7+14
2. **暴力思路**：遍历 1 到 num-1 检查是否整除，O(n) 太慢
3. **因子成对优化**：如果 i 是 num 的因子，那么 num/i 也是。只需枚举到 sqrt(num)
4. **注意 1 的排除**：num=1 时不是完美数（因子和=0），需要特判
5. **注意完全平方**：当 i*i == num 时，i 只计入一次，不能重复加

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 推荐度 |
|------|-----------|-----------|--------|
| 枚举因子到 sqrt(n) | O(sqrt(n)) | O(1) | ⭐⭐⭐⭐⭐ |
| 欧几里得-欧拉定理 | O(1) | O(1) | ⭐⭐⭐ |

## 关键提示

- 完美数的定义排除了数字本身，所以 1 不是完美数（没有真因子）
- 已知的完美数很少：6, 28, 496, 8128, 33550336... 在 10^8 范围内只有 5 个
- 因子枚举时，i 从 2 开始（1 肯定是因子，提前加上），避免把 num 本身加进去
- 当 i*i == num 时，不能加两次 i

## 解法详解

### 解法1: 枚举因子到 sqrt(n)（推荐）

**思路**：从 2 到 sqrt(num) 枚举因子，累加因子对，最后检查总和是否等于 num。

```cpp
class Solution {
public:
    bool checkPerfectNumber(int num) {
        if (num <= 1) return false;
        
        int sum = 1; // 1 肯定是因子
        for (int i = 2; i * i <= num; i++) {
            if (num % i == 0) {
                sum += i;
                if (i != num / i) {
                    sum += num / i;
                }
            }
        }
        
        return sum == num;
    }
};
```

### 解法2: 欧几里得-欧拉定理（数学解法）

**思路**：所有偶完美数都满足 `2^(p-1) * (2^p - 1)` 的形式，其中 `2^p - 1` 是梅森素数。在 10^8 范围内直接枚举已知的完美数。

```cpp
class Solution {
public:
    bool checkPerfectNumber(int num) {
        // 10^8 范围内的所有完美数
        // 由欧几里得-欧拉定理：完美数 = 2^(p-1) * (2^p - 1)
        // p = 2: 6, p = 3: 28, p = 5: 496, p = 7: 8128, p = 13: 33550336
        return num == 6 || num == 28 || num == 496 || 
               num == 8128 || num == 33550336;
    }
};
```

## 易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| ✗ `for (int i = 1; i < num; i++)` | ✓ `for (int i = 2; i*i <= num; i++)` | 暴力 O(n) 太慢，要用 sqrt 优化 |
| ✗ 不特判 num <= 1 | ✓ `if (num <= 1) return false;` | 1 不是完美数 |
| ✗ 完全平方时因子加两次 | ✓ `if (i != num/i) sum += num/i;` | i*i==num 时只加一次 |
| ✗ sum 初始化为 0 | ✓ `sum = 1` | 1 是所有 >1 的数的因子，提前计入 |
| ✗ i 从 1 开始枚举 | ✓ i 从 2 开始 | i=1 配对的 num/1=num 本身会被错误加入 |

## 面试追问

**Q1: 为什么因子只需要枚举到 sqrt(n)？**

> 因为因子成对出现：如果 i 是 num 的因子，那么 num/i 也是。所以只需枚举较小的那个（i <= sqrt(num)），同时加上配对因子 num/i。

**Q2: 是否存在奇完美数？**

> 这是数论中的未解难题。截至目前，所有已知的完美数都是偶数，但尚未证明奇完美数不存在。如果存在，它必须大于 10^1500。

**Q3: 如何高效找出某个范围内所有完美数？**

> 利用欧几里得-欧拉定理，只需检查梅森素数 2^p - 1。对每个素数 p，检查 2^p - 1 是否为素数（Lucas-Lehmer 测试），如果是则 2^(p-1)*(2^p-1) 是完美数。
