# 172. 阶乘后的零

## 核心思路
计算 n! 末尾零的个数，本质是计算 n! 中因子 5 的个数——因为每个 10 = 2 * 5，而因子 2 的个数远多于 5。

## 思维链
1. **暴力思路**: 计算 n! 的值，然后数末尾零 → n 稍大就溢出，不可行
2. **末尾零的来源**: 每个末尾零来自一个因子 10 = 2 * 5
3. **因子 2 vs 因子 5**: 偶数贡献因子 2，每 5 个数才出现一个因子 5，所以因子 5 远少于因子 2
4. **关键洞察**: 末尾零的个数 = n! 中因子 5 的总个数
5. **计算因子 5**: n/5 给出 5 的倍数个数，n/25 给出额外贡献一个 5 的数（25=5^2），n/125 给出再额外贡献的...
6. **公式**: 答案 = n/5 + n/25 + n/125 + ... 直到 5^k > n

## 解法概览
| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 除5累加 ⭐ | 不断除以 5 并累加商 | O(log5(n)) | O(1) | 必知 |
| 逐个因子分解 | 对每个数分解因子 5 | O(n log5(n)) | O(1) | 了解 |

## 关键提示
1. **核心公式**: `count = n/5 + n/25 + n/125 + ...` 等价于不断 `n /= 5` 并累加
2. **为什么只数 5**: 因子 2 的数量总是 >= 因子 5 的数量，所以瓶颈在 5
3. **25 的特殊性**: 25 = 5*5 贡献 2 个因子 5，125 = 5^3 贡献 3 个，以此类推
4. **对数时间**: 循环只执行 log5(n) 次，对于 n=10^4 只需 5-6 次

## 解法详解

### 解法1: 除5累加 (推荐)

**思路**: 反复将 n 除以 5 并累加商。每次除以 5 统计了当前层级的 5 的倍数个数，同时自动处理了 25, 125 等高次幂。

```cpp
class Solution {
public:
    int trailingZeroes(int n) {
        int count = 0;
        while (n >= 5) {
            n /= 5;
            count += n;
        }
        return count;
    }
};
```

**思考过程**:
- n=25 时: 25/5=5 (5个5的倍数), 5/5=1 (1个25的倍数), 1/5=0 停止, count=6
- 验证: 25! 末尾确实有 6 个零

**复杂度**: 时间 O(log5(n)), 空间 O(1)

### 解法2: 逐个因子分解

**思路**: 对 1 到 n 的每个数，计算它包含多少个因子 5，全部加起来。

```cpp
class Solution {
public:
    int trailingZeroes(int n) {
        int count = 0;
        for (int i = 5; i <= n; i += 5) {
            int num = i;
            while (num % 5 == 0) {
                count++;
                num /= 5;
            }
        }
        return count;
    }
};
```

**思考过程**:
- 更直观但效率低——遍历所有 5 的倍数
- 适合理解问题本质，但面试中应直接给出解法1

**复杂度**: 时间 O(n/5 * log5(n)), 空间 O(1)

## 易错点
- ✗ 计算 n! 的值再数零 → 大数溢出
- ✓ 直接统计因子 5 的个数
- ✗ 只算 `n/5` 忘记 25, 125 等高次幂的贡献
- ✓ 循环除以 5 累加: `n/5 + n/25 + n/125 + ...`
- ✗ `while (n > 0)` 可能导致 n=1,2,3,4 时多算
- ✓ `while (n >= 5)` 确保只在有意义时计算

## 面试追问
- **Q1**: 为什么不需要数因子 2？
  - A: 偶数贡献因子 2，数量远多于因子 5 (n/2 > n/5)，所以 5 是瓶颈
- **Q2**: n! 中因子 2 的个数是多少？
  - A: 用同样的方法 n/2 + n/4 + n/8 + ...
- **Q3**: 如果改成求 n! 在 k 进制下末尾零的个数？
  - A: 对 k 做质因数分解，分别统计每个质因子的个数，取最小值
