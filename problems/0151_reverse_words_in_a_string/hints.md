# 151. 反转字符串中的单词

## 核心思路

本质上是**字符串分割 + 逆序拼接**的问题：把字符串按空格拆成单词，然后倒着拼回去。难点在于处理多余空格，以及能否做到 O(1) 额外空间（原地操作）。

## 思维链

1. **读完题第一反应**：把字符串按空格拆成单词数组，然后反转数组，再用空格拼起来。这是最自然的想法，利用语言内置的 split/reverse/join 就能搞定。

2. **想一想有没有不用额外数组的做法？** 如果我们从字符串尾部开始扫描，每遇到一个单词就直接追加到结果里，是不是就自然实现了"反转"？这就是**从后往前遍历**的思路。

3. **Follow-up 要求 O(1) 空间怎么办？** 上面两种方法都需要 O(n) 的额外空间存结果。如果字符串可变（C++ 的 `string` 是可变的），我们能否**在原字符串上操作**？

4. **关键洞察：两次反转** — 先把整个字符串反转，单词的顺序就对了，但每个单词内部的字母顺序是反的。再逐个单词反转回来就行！这就像翻扑克牌：先把整副牌翻过来，再把每张牌翻回正面。

5. **处理多余空格**：O(1) 空间方案需要在反转之前（或过程中）先去掉多余空格，用**双指针原地去重**，类似 LeetCode 26 删除有序数组中的重复项。

6. **总结三步走**：① 去除多余空格 → ② 反转整个字符串 → ③ 反转每个单词。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 分割+反转 | 拆词→反转数组→拼接 | O(n) | O(n) | 能说出即可 |
| 从后往前遍历 | 尾部开始逐词提取 | O(n) | O(n) | ⭐ 必须写出 |
| 原地三步法 | 去空格→全反转→逐词反转 | O(n) | O(1) | 加分项 (Follow-up) |

## 关键提示

1. **从后往前遍历**时，用双指针 `i` 和 `j` 定位每个单词的首尾，`j` 跳过空格找到单词尾，`i` 从 `j` 往前找到单词头，然后提取 `s[i+1..j]`。

2. **原地去空格**的技巧：用写指针 `write` 和读指针 `read`，遇到非空格字符就写入，单词之间只写入一个空格。这和"移除元素"/"删除重复项"的双指针模式一模一样。

3. **反转整个字符串后**，单词的相对顺序正确了，但每个单词内部是倒的。例如 `"blue is sky the"` → 反转 → `"eht yks si eulb"` → 逐词反转 → `"the sky is blue"`... 等等，这不对！应该是原串 `"the sky is blue"` → 反转 → `"eulb si yks eht"` → 逐词反转 → `"blue is sky the"` ✓

4. **单词之间的空格**：原地方案中，去空格是最容易写错的部分。单词之间要保留恰好一个空格，首尾不能有空格。

5. 处理边界：连续多个空格、前导空格、尾随空格——这三种情况都要正确处理。

```
示例："  hello   world  "

从后往前遍历:
       ←──────── 扫描方向
  "  hello   world  "
                 ↑  ↑
                 i  j    → 提取 "world"
        ↑    ↑
        i    j           → 提取 "hello"
  
  结果: "world hello"
```

## 解法详解

### 解法1: 分割 + 反转 — O(n) / O(n)

**思考过程**: 最直觉的做法——拆词、反转、拼接。很多语言有内置的 split 函数，但手动实现也不难。

```cpp
class Solution {
public:
    string reverseWords(string s) {
        // 1. 手动分割: 提取所有单词
        vector<string> words;
        int n = s.size();
        int i = 0;
        while (i < n) {
            // 跳过空格
            while (i < n && s[i] == ' ') i++;
            if (i >= n) break;
            // 找到单词的起点，向后扫到单词结尾
            int j = i;
            while (j < n && s[j] != ' ') j++;
            words.push_back(s.substr(i, j - i));
            i = j;
        }
        
        // 2. 反转单词数组
        reverse(words.begin(), words.end());
        
        // 3. 用单个空格拼接
        string result;
        for (int k = 0; k < words.size(); k++) {
            if (k > 0) result += ' ';
            result += words[k];
        }
        return result;
    }
};
```

**关键点**: 分割时用 `while` 跳过空格再提取单词，自然就过滤了所有多余空格。

---

### 解法2: 从后往前遍历 — O(n) / O(n) ⭐ 面试首选

**从解法1优化**: 解法1先分割再反转，其实我们从后往前扫描就自然得到逆序的单词，省去了反转步骤。

```cpp
class Solution {
public:
    string reverseWords(string s) {
        string result;
        int n = s.size();
        int j = n - 1;  // j: 从尾部开始扫
        
        while (j >= 0) {
            // 跳过尾部空格
            while (j >= 0 && s[j] == ' ') j--;
            if (j < 0) break;
            
            // 此时 j 指向某个单词的最后一个字符
            // i 从 j 往前找到单词的第一个字符
            int i = j;
            while (i >= 0 && s[i] != ' ') i--;
            // 单词是 s[i+1 .. j]
            
            // 加空格分隔（不是第一个单词时）
            if (!result.empty()) result += ' ';
            result += s.substr(i + 1, j - i);
            
            j = i;  // 继续往前扫
        }
        return result;
    }
};
```

**关键点**: `i` 最终会停在单词左边的空格位置（或 -1），所以单词起始是 `i+1`，长度是 `j - i`。

---

### 解法3: 原地三步法 — O(n) / O(1)（Follow-up）

**从解法2优化**: 解法2 需要 O(n) 空间存 result。Follow-up 要求 O(1) 额外空间，思路是**在原字符串上操作**：

1. **去除多余空格**（双指针原地压缩）
2. **反转整个字符串**
3. **逐个反转每个单词**

```
原始:   "  hello   world  "
Step1:  "hello world"          (去除多余空格)
Step2:  "dlrow olleh"          (整体反转)
Step3:  "world hello"          (逐词反转) ✓
```

```cpp
class Solution {
public:
    string reverseWords(string s) {
        // ======= Step 1: 去除多余空格 (双指针) =======
        int write = 0, n = s.size();
        for (int read = 0; read < n; read++) {
            if (s[read] != ' ') {
                // 单词之间加一个空格（不是第一个单词时）
                if (write > 0) s[write++] = ' ';
                // 拷贝整个单词
                while (read < n && s[read] != ' ') {
                    s[write++] = s[read++];
                }
            }
        }
        s.resize(write);  // 截断多余部分
        
        // ======= Step 2: 反转整个字符串 =======
        reverse(s.begin(), s.end());
        
        // ======= Step 3: 逐个反转每个单词 =======
        int start = 0;
        for (int i = 0; i <= s.size(); i++) {
            // 遇到空格或末尾，说明一个单词结束
            if (i == s.size() || s[i] == ' ') {
                reverse(s.begin() + start, s.begin() + i);
                start = i + 1;
            }
        }
        return s;
    }
};
```

**关键点**:
- Step 1 的双指针：`read` 跳过空格，遇到非空格时先判断是否需要加分隔空格，然后整词拷贝。
- `s.resize(write)` 是必须的，否则尾部会有垃圾字符。
- Step 3 遍历到 `i == s.size()` 是为了处理最后一个单词（它后面没有空格）。

## 解法对比

| | 分割+反转 | 从后往前遍历 | 原地三步法 |
|---|---|---|---|
| 时间 | O(n) | O(n) | O(n) |
| 空间 | O(n) | O(n) | O(1) |
| 代码量 | 中等 | 最少 | 最多 |
| 适合场景 | 快速实现 | 面试首选 | Follow-up |
| 核心技巧 | split+reverse | 双指针从尾扫 | 两次反转 |

**面试选择建议**: 先写解法2（简洁清晰），面试官追问 O(1) 空间时再给解法3。

## 易错点

1. **去空格时漏加单词间空格**
   - ✗ 直接拷贝非空格字符，结果 `"helloworld"`
   - ✓ 每个单词前（非第一个）加 `s[write++] = ' '`

2. **忘记 `s.resize(write)`**
   - ✗ 去空格后字符串尾部残留原来的字符，如 `"hello worldorld  "`
   - ✓ 必须 `s.resize(write)` 截断

3. **逐词反转时漏掉最后一个单词**
   - ✗ 循环条件 `for (int i = 0; i < s.size(); i++)` 且只在 `s[i]==' '` 时触发反转
   - ✓ 循环到 `i <= s.size()`，或在循环结束后额外处理最后一个单词

4. **从后往前遍历的 substr 长度算错**
   - ✗ `s.substr(i, j - i)` — 起点错了，`i` 是空格位置
   - ✓ `s.substr(i + 1, j - i)` — 起点是 `i+1`，长度是 `j - (i+1) + 1 = j - i`

## 面试追问

**Q1: 暴力解的思路是什么？复杂度？**
→ 分割成单词数组，反转，拼接。时间 O(n)，空间 O(n)。这已经是线性时间了，时间上没法优化。

**Q2: 如果要求 O(1) 额外空间（字符串可变），怎么做？**
→ 三步法：去空格 → 整体反转 → 逐词反转。关键洞察是"两次反转等于只反转顺序不反转内容"。

**Q3: 如果输入是 `char[]` 而不是 `string`，怎么处理？**
→ 思路相同，但不能用 `resize`，需要在末尾放 `'\0'` 并返回新长度。去空格用双指针更适合数组操作。（这就是 LeetCode 186 的场景）

**Q4: 如果单词之间需要保留原始空格数量，只反转单词顺序呢？**
→ 这是不同的问题变体。需要先记录空格模式，再反转单词顺序后按原空格模式填充。
