# 3354. 使数组元素等于零

## 核心思路

本题是一个**前缀和 + 数学推导**问题。表面上是复杂的弹球模拟，但核心洞察是：从位置 `i` (nums[i]==0) 出发的过程，本质上是一个"弹球"在左右反弹，每次遇到正数就消耗 1 并反弹。整个过程能使所有元素归零，当且仅当**左侧元素之和**与**右侧元素之和**的关系满足特定条件。

## 思维链

1. **读完题第一反应**：模拟整个过程。从某个 0 位置出发，选择左或右方向，遇到正数就减 1、反转方向、继续走。直到走出边界。如果最终所有元素都为 0 就是有效选择。

2. **暴力模拟可行吗？** 数组长度 <= 100，每个元素 <= 100，总和最多 10000。每次模拟最多走 ~总和 步。0 的位置最多 100 个，每个位置两个方向。总共 100 * 2 * 10000 = 2 * 10^6，暴力完全可行。

3. **但有没有更优雅的解法？** 观察弹球的行为：
   - 如果先向**左**出发，弹球会先消耗左边的元素，然后反弹消耗右边，再反弹消耗左边...交替进行。
   - 最终效果是：弹球像"扫帚"一样，从中心向两边交替清扫。

4. **关键数学推导**：设从位置 `i` 出发，左侧元素之和为 `L = nums[0] + ... + nums[i-1]`，右侧之和为 `R = nums[i+1] + ... + nums[n-1]`。
   
   - **先向左走**：弹球先清扫左边一轮（消耗一部分），反弹清扫右边一轮（消耗一部分），交替进行。最终能清零的条件是：`L == R` 或 `L == R - 1`。
     - `L == R`：完全平衡，左右交替刚好清完。
     - `L == R - 1`：右边比左边多 1，先向左再向右，最后一轮多清右边一个。
   
   - **先向右走**：对称地，条件是 `R == L` 或 `R == L - 1`。
     - `R == L`：完全平衡。
     - `R == L - 1`：左边比右边多 1。

5. **合并条件**：
   - `L == R` → 两个方向都有效 → 贡献 +2
   - `|L - R| == 1` → 恰好一个方向有效 → 贡献 +1
   - `|L - R| >= 2` → 两个方向都无效 → 贡献 0

6. **高效计算**：用前缀和。总和 `totalSum` 预计算，遍历时维护 `leftSum`，则 `rightSum = totalSum - leftSum`。O(n) 时间，O(1) 空间。

```
模拟示意 (nums = [1,0,2,0,3]):

位置1 (nums[1]=0): leftSum=1, rightSum=5, |diff|=4 → 0个有效
位置3 (nums[3]=0): leftSum=3, rightSum=3, diff=0 → 2个有效 ✓

答案: 0 + 2 = 2 ✓

验证位置3先向左:
  [1,0,2,0,3] → 遇到2→[1,0,1,0,3]→反弹右→遇到3→[1,0,1,0,2]→反弹左
  → 遇到1→[1,0,0,0,2]→反弹右→遇到2→[1,0,0,0,1]→反弹左
  → 走过0们→遇到1→[0,0,0,0,1]→反弹右→走过0们→遇到1→[0,0,0,0,0] ✓

验证位置3先向右:
  [1,0,2,0,3] → 遇到3→[1,0,2,0,2]→反弹左→遇到2→[1,0,1,0,2]
  → 反弹右→遇到2→[1,0,1,0,1]→反弹左→遇到1→[1,0,0,0,1]
  → 反弹右→遇到1→[1,0,0,0,0]→反弹左→走过0们→遇到1→[0,0,0,0,0] ✓
```

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力模拟 | 对每个0位置、每个方向完整模拟 | O(n * totalSum) | O(n) | 能说出即可 |
| 前缀和 + 数学 | 比较左右元素和的差 | O(n) | O(1) | ⭐ 必须写出 |

## 关键提示

1. **弹球过程的本质**：不需要真的模拟弹球。弹球从位置 i 出发，向左走一轮消耗一些，向右走一轮消耗一些，交替进行。最终效果等价于比较左右两侧的元素总和。

2. **前缀和一遍扫描**：`totalSum` 预计算一次。遍历时维护 `leftSum`，`rightSum = totalSum - leftSum`。不需要额外数组。

3. **条件的直觉理解**：
   - `L == R`：两边重量完全平衡，往哪边先走都能清完。像天平完全平衡。
   - `L == R + 1`：左边重一点，先向右走可以清完（先清轻的那边），先向左走不行。
   - `L == R - 1`：右边重一点，先向左走可以清完。

4. **遍历时 leftSum 的更新时机**：在检查完 `nums[i]` 之后再 `leftSum += nums[i]`。如果 `nums[i] == 0`，`leftSum` 不变。

5. **数据范围允许暴力**：n <= 100，元素 <= 100。如果想不到数学解法，暴力模拟也能 AC。面试时可以先说暴力再优化。

## 解法详解

### 解法1: 暴力模拟 — O(n * totalSum) / O(n)

**思考过程**：最直接的方式——对每个 `nums[i] == 0` 的位置，分别模拟向左和向右出发的完整过程。检查最终是否所有元素归零。

```cpp
class Solution {
public:
    int countValidSelections(vector<int>& nums) {
        int n = nums.size(), ans = 0;
        
        for (int i = 0; i < n; i++) {
            if (nums[i] != 0) continue;
            
            // 尝试两个方向
            for (int dir : {-1, 1}) { // -1=左, 1=右
                vector<int> arr(nums.begin(), nums.end()); // 拷贝
                int pos = i, d = dir;
                
                while (pos >= 0 && pos < n) {
                    if (arr[pos] == 0) {
                        pos += d; // 继续当前方向
                    } else {
                        arr[pos]--;  // 消耗
                        d = -d;      // 反转方向
                        pos += d;    // 新方向走一步
                    }
                }
                
                // 检查是否全部归零
                bool allZero = true;
                for (int x : arr) {
                    if (x != 0) { allZero = false; break; }
                }
                if (allZero) ans++;
            }
        }
        return ans;
    }
};
```

### 解法2: 前缀和 + 数学（最优解）— O(n) / O(1) ⭐

**思考过程**：通过分析弹球过程的数学本质，得出结论：有效性仅取决于左右元素和的差值。

```cpp
class Solution {
public:
    int countValidSelections(vector<int>& nums) {
        // 预计算总和
        int totalSum = 0;
        for (int x : nums) totalSum += x;
        
        int leftSum = 0, ans = 0;
        for (int i = 0; i < (int)nums.size(); i++) {
            if (nums[i] == 0) {
                int rightSum = totalSum - leftSum;
                if (leftSum == rightSum) {
                    // 完全平衡: 两个方向都有效
                    ans += 2;
                } else if (abs(leftSum - rightSum) == 1) {
                    // 差1: 恰好一个方向有效
                    ans += 1;
                }
                // 差 >= 2: 两个方向都无效, 不加
            }
            leftSum += nums[i];
        }
        return ans;
    }
};
```

**为什么差值 == 0 时两个方向都有效？**

设 L = R = S。先向左走：
- 第1轮向左：消耗左边 S 个单位（每个元素各被清一层）
- 弹回向右：消耗右边 S 个单位
- 全部清零。

先向右走，对称情况，也全部清零。

**为什么差值 == 1 时恰好一个方向有效？**

设 L = S, R = S+1。先向左走：
- 消耗左边 S → 弹回消耗右边 S → 右边还剩 1 → 弹回左边已经全 0 → 直接走出边界 → 右边还剩 1 → 无效！

先向右走：
- 消耗右边 S+1 中的 S+1（先消耗一部分）→ ... → 最终刚好清零 → 有效！

所以只有"先向重的那边走"才有效。

## 易错点

1. **leftSum 更新时机错误**：应该在判断 `nums[i] == 0` **之后**再 `leftSum += nums[i]`。如果先更新再判断，leftSum 就包含了 nums[i] 本身（虽然 nums[i]==0 时无影响，但逻辑上不清晰，而且如果条件判断放错位置会出 bug）。

2. **忘记 abs()**：条件是 `|L - R| == 1`，不是 `L - R == 1`。如果只检查 `L - R == 1` 会漏掉 `R - L == 1` 的情况。

3. **暴力模拟中忘记拷贝数组**：每次模拟会修改数组，必须先拷贝。如果直接在原数组上操作，第二个方向的模拟就是在被修改过的数组上进行。

4. **暴力模拟中方向反转后忘记移动**：反转方向后还需要 `pos += d` 走一步。题目说的是"反转方向并沿新方向走一步"，不是"反转方向后原地等待"。

5. **遗漏差值 >= 2 的情况**：差值 >= 2 时两个方向都无效，不要误加。

## 面试追问

1. **"如何从模拟观察到前缀和的规律？"**
   → 先手动模拟几个小例子（如 [1,0,1], [2,0,1], [1,0,2]），记录哪些有效。发现规律：有效性只和左右和的差有关。然后尝试证明（或直觉解释）弹球的交替消耗本质。

2. **"如果数组中没有 0 怎么办？"**
   → 题目保证至少有一个 0。但如果没有 0，答案就是 0（没有合法起点）。

3. **"如果允许从任意位置出发（不要求 nums[curr]==0），问题怎么变？"**
   → 复杂度大增，不能用简单的左右和比较。需要考虑起点本身的消耗，可能需要更复杂的模拟或 DP。

4. **"暴力模拟的时间复杂度具体是多少？"**
   → 每次模拟最多走 totalSum + n 步（每步要么消耗一个单位要么走过一个 0）。n <= 100, totalSum <= 10000，0 的位置最多 100 个，每个 2 个方向。总共约 100 * 2 * 10100 = 2 * 10^6，完全可行。

5. **"能否进一步优化到 O(1) 空间以外？"**
   → O(n) 时间已经是下界（至少需要读完整个数组）。O(1) 额外空间也已经最优。无法进一步优化。
