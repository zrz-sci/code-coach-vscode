# 36. 有效的数独

## 核心思路

这道题本质上是一个**重复检测问题**：遍历 9×9 棋盘上所有已填入的数字，检查每个数字是否在其所在行、所在列、所在 3×3 宫格中出现过重复。

## 思维链

1. **读完题第一反应**：需要检查三种约束——每行不重复、每列不重复、每个 3×3 宫格不重复。最直觉的做法就是分别遍历检查。

2. **暴力怎么做？** 分三轮遍历：第一轮逐行检查 9 行，第二轮逐列检查 9 列，第三轮逐个检查 9 个 3×3 宫格。每次用一个集合检测重复。这样虽然正确，但需要三次遍历。

3. **瓶颈在哪？** 其实没有算法层面的瓶颈（棋盘固定 9×9，复杂度是常数级），但能不能**一次遍历**就同时检查行、列、宫格三个约束？

4. **怎么优化？** 关键洞察：遍历到 `board[i][j]` 时，我们**同时知道**它属于第 `i` 行、第 `j` 列、第 `(i/3)*3 + j/3` 个宫格。所以可以预先准备 9 个行集合、9 个列集合、9 个宫格集合，一次遍历即可完成所有检查。

5. **宫格编号怎么算？** 这是本题唯一的技巧点。9 个 3×3 宫格按行列编号：

```
// 宫格编号 (boxIndex):
//  0 | 1 | 2
// ---+---+---
//  3 | 4 | 5
// ---+---+---
//  6 | 7 | 8
//
// 位于 (i, j) 的格子属于宫格: (i / 3) * 3 + (j / 3)
// 例如: (4, 7) → (4/3)*3 + 7/3 = 1*3 + 2 = 5 → 属于宫格 5 ✓
```

6. **用什么存"见过的数字"？** 可以用 `HashSet`，也可以用**位集合**（一个 int 的低 9 位分别代表数字 1-9 是否出现过），后者更紧凑。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 三次遍历 | 分别检查行、列、宫格 | O(81×3) | O(9) | 能说出即可 |
| 一次遍历 + HashSet | 同时用 27 个集合检查 | O(81) | O(27×9) | ⭐ 必须写出 |
| 一次遍历 + 位运算 | 用 int 位掩码代替集合 | O(81) | O(27) | 加分项 |

> 注：因为棋盘大小固定为 9×9，所有解法的时间和空间都是 O(1) 常数级。上面写出具体数字是为了对比。

## 关键提示

1. **宫格编号公式**：`boxIndex = (i / 3) * 3 + (j / 3)`，这是本题最核心的公式，建议在纸上画出 9 个宫格验证一下。

2. **跳过空格**：遇到 `'.'` 直接跳过，只对数字做检查。

3. **不需要检查数独是否可解**：题目明确说了只验证已填入的数字是否符合规则。

4. **用数组代替 HashMap**：因为数字只有 1-9，可以用 `bool[9]` 数组或位掩码代替 HashSet，效率更高。

5. **棋盘示意图** —— 宫格划分：
```
// 9×9 棋盘被划分为 9 个 3×3 宫格:
//
//  col:  0 1 2   3 4 5   6 7 8
// row 0 [5 3 .] [. 7 .] [. . .]   ← 宫格 0, 1, 2
// row 1 [6 . .] [1 9 5] [. . .]
// row 2 [. 9 8] [. . .] [. 6 .]
//        ------  ------  ------
// row 3 [8 . .] [. 6 .] [. . 3]   ← 宫格 3, 4, 5
// row 4 [4 . .] [8 . 3] [. . 1]
// row 5 [7 . .] [. 2 .] [. . 6]
//        ------  ------  ------
// row 6 [. 6 .] [. . .] [2 8 .]   ← 宫格 6, 7, 8
// row 7 [. . .] [4 1 9] [. . 5]
// row 8 [. . .] [. 8 .] [. 7 9]
```

## 解法详解

### 解法1: 三次遍历 — O(81×3) / O(9)

**思考过程**：最直觉的做法——题目要求检查三种约束，就分三轮分别检查。每轮用一个临时集合检测重复。

```cpp
class Solution {
public:
    bool isValidSudoku(vector<vector<char>>& board) {
        // 第一轮: 检查每一行
        for (int i = 0; i < 9; i++) {
            unordered_set<char> seen;
            for (int j = 0; j < 9; j++) {
                if (board[i][j] == '.') continue;
                if (seen.count(board[i][j])) return false;
                seen.insert(board[i][j]);
            }
        }
        // 第二轮: 检查每一列
        for (int j = 0; j < 9; j++) {
            unordered_set<char> seen;
            for (int i = 0; i < 9; i++) {
                if (board[i][j] == '.') continue;
                if (seen.count(board[i][j])) return false;
                seen.insert(board[i][j]);
            }
        }
        // 第三轮: 检查每个 3×3 宫格
        for (int box = 0; box < 9; box++) {
            unordered_set<char> seen;
            int startRow = (box / 3) * 3;
            int startCol = (box % 3) * 3;
            for (int i = startRow; i < startRow + 3; i++) {
                for (int j = startCol; j < startCol + 3; j++) {
                    if (board[i][j] == '.') continue;
                    if (seen.count(board[i][j])) return false;
                    seen.insert(board[i][j]);
                }
            }
        }
        return true;
    }
};
```

**关键点**：宫格遍历时，第 `box` 个宫格的起始行是 `(box/3)*3`，起始列是 `(box%3)*3`。这个映射很容易搞错。

---

### 解法2: 一次遍历 + HashSet/数组 — O(81) / O(27×9) ⭐ 面试首选

**从解法1优化**：解法1 需要三轮遍历，但其实遍历到 `(i, j)` 时，我们已经知道它属于哪一行、哪一列、哪个宫格。预先创建 27 个集合（9行+9列+9宫格），一次遍历同时检查三个约束。

```cpp
class Solution {
public:
    bool isValidSudoku(vector<vector<char>>& board) {
        // rows[i][d] = 第i行是否已出现数字d
        // cols[j][d] = 第j列是否已出现数字d
        // boxes[b][d] = 第b个宫格是否已出现数字d
        bool rows[9][9] = {false};
        bool cols[9][9] = {false};
        bool boxes[9][9] = {false};
        
        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                if (board[i][j] == '.') continue;
                
                int d = board[i][j] - '1'; // 数字1-9映射到索引0-8
                int boxIndex = (i / 3) * 3 + (j / 3);
                
                // 同时检查行、列、宫格三个约束
                if (rows[i][d] || cols[j][d] || boxes[boxIndex][d]) {
                    return false;
                }
                
                rows[i][d] = true;
                cols[j][d] = true;
                boxes[boxIndex][d] = true;
            }
        }
        return true;
    }
};
```

**关键点**：
- `board[i][j] - '1'` 而不是 `- '0'`，因为数字是 1-9，我们要映射到 0-8 索引
- `boxIndex = (i / 3) * 3 + (j / 3)` 是本题的核心公式

---

### 解法3: 一次遍历 + 位运算 — O(81) / O(27) 加分项

**从解法2优化空间表示**：解法2 用 `bool[9]` 数组记录出现的数字，但一个 int 有 32 位，完全可以用低 9 位分别代表数字 1-9。检查重复 = 检查某一位是否已被置位，用位与 `&` 即可。

```cpp
class Solution {
public:
    bool isValidSudoku(vector<vector<char>>& board) {
        // 每个 int 的第 k 位表示数字 (k+1) 是否出现过
        int rows[9] = {0}, cols[9] = {0}, boxes[9] = {0};
        
        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                if (board[i][j] == '.') continue;
                
                int bit = 1 << (board[i][j] - '1'); // 数字d对应第d-1位
                int boxIndex = (i / 3) * 3 + (j / 3);
                
                // 如果任意一个掩码中该位已经是1，说明重复
                if ((rows[i] & bit) || (cols[j] & bit) || (boxes[boxIndex] & bit)) {
                    return false;
                }
                
                // 置位：标记该数字已出现
                rows[i] |= bit;
                cols[j] |= bit;
                boxes[boxIndex] |= bit;
            }
        }
        return true;
    }
};
```

**关键点**：位运算版本只用 27 个 int 代替 27×9 个 bool，更紧凑。面试中展示位运算思维是加分项。

## 解法对比

| | 解法1 三次遍历 | 解法2 一次遍历+数组 | 解法3 一次遍历+位运算 |
|---|---|---|---|
| 遍历次数 | 3 次 | 1 次 | 1 次 |
| 空间 | 临时集合(每轮9个) | 27×9 bool | 27 个 int |
| 代码复杂度 | 长但直觉 | 简洁清晰 | 需要位运算基础 |
| 面试推荐 | 说思路即可 | ⭐ 首选 | 追问时展示 |

解法1 适合验证理解；解法2 是面试标准答案——简洁、正确、易解释；解法3 在解法2 基础上仅替换了存储方式，逻辑完全一致。

## 易错点

1. **字符转数字索引偏移错误**
   - ✗ `int d = board[i][j] - '0';` → 数字 1 映射到索引 1，数组需要开到 10
   - ✓ `int d = board[i][j] - '1';` → 数字 1 映射到索引 0，数组只需开到 9
   - 两种都可以，但要和数组大小匹配，不匹配就越界

2. **宫格编号公式写错**
   - ✗ `boxIndex = (i / 3) + (j / 3) * 3;` → 如果你的宫格是按"列优先"编号的就对，但通常约定"行优先"
   - ✓ `boxIndex = (i / 3) * 3 + (j / 3);` → 行优先编号: 0,1,2,3,...,8
   - 建议在纸上验证 `(0,0)→0`, `(0,3)→1`, `(3,0)→3`, `(4,7)→5`

3. **忘记跳过空格**
   - ✗ 不检查 `'.'` 直接算 `'.' - '1'` = -3，导致数组越界或逻辑错误
   - ✓ 遇到 `'.'` 必须 `continue`

4. **位运算版本用 `==` 代替 `&` 做检测**
   - ✗ `if (rows[i] == bit)` → 只有恰好只出现过这一个数字时才为 true
   - ✓ `if (rows[i] & bit)` → 检查该位是否已被置位，不影响其他位

## 面试追问

**Q1: 时间复杂度是多少？能更快吗？**
→ 棋盘大小固定 9×9，所以严格来说是 O(1)。如果推广到 N×N 的数独，一次遍历是 O(N²)，这已经是下界了（每个格子至少看一次）。

**Q2: 如果需要验证大量不同的数独棋盘，有什么优化思路？**
→ 可以考虑多线程并行：9 行、9 列、9 个宫格的检查可以独立并行进行。或者用 SIMD 指令一次处理多个格子的位运算检查。

**Q3: 如果进一步要判断数独是否可解（而不仅是已填数字是否合法），怎么做？**
→ 先做本题的合法性检查，如果合法再用回溯法（DFS）填空格尝试求解。每个空格尝试 1-9，用和本题一样的数据结构快速判断某个数字能否放置。这就是 LeetCode 37. Sudoku Solver。
