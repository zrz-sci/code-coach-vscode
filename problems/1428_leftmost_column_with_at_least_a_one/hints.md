# 1428. 至少有一个 1 的最左端列

## 核心思路

本质上是在一个**每行有序**的 0/1 矩阵中，找到所有行中**第一个 1 出现的最小列索引**。关键约束是不能直接访问矩阵、且 `get` 调用次数有限（≤1000），所以要利用"每行非递减"这个有序性来减少查询次数。

## 思维链

1. **读完题第一反应**：遍历每一列，从左到右扫，找到第一列里有 1 的就返回。→ 最坏情况每个格子都查一遍，`rows × cols` 次调用，最多 100×100 = 10000 次，超过 1000 限制。

2. **瓶颈在哪？** 逐列扫描没有利用"每行有序"的性质。每一行是 `000...0111...1` 的形态，找"第一个 1"就是一个经典的**二分查找左边界**问题。

3. **用二分优化**：对每一行二分找到第一个 1 的位置，取所有行的最小值。每行二分 O(log cols)，共 rows 行，总调用 `rows × log(cols)` ≈ 100 × 7 = 700 次，完全在限制内。

4. **能不能更优？** 观察矩阵结构：从**右上角**出发，如果当前格是 1 就往左走（尝试找更左的 1），如果是 0 就往下走（当前行不可能更左了）。这样每步要么 row+1 要么 col-1，总步数 ≤ rows + cols ≤ 200 次，比二分还少！

5. **为什么右上角遍历正确？** 因为每行有序，一旦某行在第 j 列是 0，那它左边也全是 0，不可能比 j 更左；一旦某行在第 j 列是 1，答案至多是 j，但可能更左，所以往左探索。这是一种利用行列双向单调性的搜索策略。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力逐列扫描 | 从左到右逐列检查是否有 1 | O(R×C) | O(1) | 能说出即可 |
| 每行二分查找 | 对每行二分找第一个 1，取最小列 | O(R×logC) | O(1) | ⭐ 必须写出 |
| 右上角线性遍历 | 从右上角出发，遇 1 左移，遇 0 下移 | O(R+C) | O(1) | 加分项 |

## 关键提示

- **提示 1**：每行都是 `0...01...1` 的形态。对于单独一行，找"第一个 1"你会怎么做？
- **提示 2**：如果用二分，算一下总调用次数：100 行 × log₂(100) ≈ 700 次，远小于 1000。
- **提示 3**：想象站在矩阵的右上角。当前格是 1 意味着什么？是 0 又意味着什么？你能确定往哪个方向走吗？
- **提示 4**：右上角遍历的本质——每次要么排除当前行（下移），要么收窄答案上界（左移），所以总步数是 O(R+C)。

```
// 矩阵示意 (行有序):
//   col: 0 1 2 3
// row 0: 0 0 0 1    ← 第一个1在col=3
// row 1: 0 0 1 1    ← 第一个1在col=2
// row 2: 0 0 0 0    ← 没有1
// row 3: 0 1 1 1    ← 第一个1在col=1  ← 全局最小
// 答案: 1

// 右上角遍历过程 (从 row=0, col=3 开始):
// (0,3)=1 → 左移 → (0,2)=0 → 下移
// (1,2)=1 → 左移 → (1,1)=0 → 下移
// (2,1)=0 → 下移
// (3,1)=1 → 左移 → (3,0)=0 → 下移
// row=4 越界，最后记录的最左列=1
```

## 解法详解

### 解法1: 暴力逐列扫描 — O(R×C) / O(1)

**思考过程**: 最直觉的想法——从第 0 列开始，逐列检查该列是否存在 1。第一个存在 1 的列就是答案。但最坏情况要查 R×C = 10000 次，超限。

```cpp
/**
 * // This is the BinaryMatrix's API interface.
 * // You should not implement it, or speculate about its implementation
 * class BinaryMatrix {
 *   public:
 *     int get(int row, int col);
 *     vector<int> dimensions();
 * };
 */
class Solution {
public:
    int leftMostColumnWithOne(BinaryMatrix &binaryMatrix) {
        vector<int> dim = binaryMatrix.dimensions();
        int rows = dim[0], cols = dim[1];
        
        // 从左到右逐列扫描
        for (int col = 0; col < cols; col++) {
            for (int row = 0; row < rows; row++) {
                if (binaryMatrix.get(row, col) == 1) {
                    return col;  // 找到最左列
                }
            }
        }
        return -1;
    }
};
```

**关键点**: 虽然逻辑正确，但调用次数可能达到 R×C = 10000，超过 1000 次限制。这个解法在面试中只用于说明思路，不能作为最终答案。

---

### 解法2: 每行二分查找 — O(R×logC) / O(1) ⭐ 面试首选

**从解法1优化**: 解法1的瓶颈是对每行线性扫描找第一个 1。但每行是有序的（0...01...1），这正是**二分查找左边界**的经典场景！对每行二分找到第一个 1 的位置，再取所有行的最小值。

```
// 二分找左边界示意 (以 row=[0,0,1,1] 为例):
// 目标：找第一个 1 的位置
// 
// Round1: [0, 0, 1, 1]  lo=0, hi=3, mid=1, val=0 → lo=2
//             ^
// Round2: [0, 0, 1, 1]  lo=2, hi=3, mid=2, val=1 → hi=2
//                   ^
// lo==hi==2 → 第一个1在 col=2
```

```cpp
class Solution {
public:
    int leftMostColumnWithOne(BinaryMatrix &binaryMatrix) {
        vector<int> dim = binaryMatrix.dimensions();
        int rows = dim[0], cols = dim[1];
        int ans = -1;
        
        for (int row = 0; row < rows; row++) {
            // 对当前行二分查找：找第一个 1 的列索引
            int lo = 0, hi = cols - 1;
            while (lo < hi) {
                int mid = lo + (hi - lo) / 2;
                if (binaryMatrix.get(row, mid) == 0) {
                    lo = mid + 1;  // mid 是 0，第一个 1 在右边
                } else {
                    hi = mid;      // mid 是 1，可能就是第一个 1，也可能更左还有
                }
            }
            // lo == hi，检查这个位置是否是 1
            if (binaryMatrix.get(row, lo) == 1) {
                ans = (ans == -1) ? lo : min(ans, lo);
            }
        }
        return ans;
    }
};
```

**进一步优化**: 可以用当前已知的最小列 `ans` 来缩小后续行的二分搜索范围，因为我们只关心是否有更左的 1。

```cpp
class Solution {
public:
    int leftMostColumnWithOne(BinaryMatrix &binaryMatrix) {
        vector<int> dim = binaryMatrix.dimensions();
        int rows = dim[0], cols = dim[1];
        int ans = cols;  // 初始化为 cols，表示还没找到
        
        for (int row = 0; row < rows; row++) {
            // 只在 [0, ans-1] 范围内搜索——因为 >= ans 的列已经不可能更优
            int lo = 0, hi = ans - 1;
            
            // 先快速检查：如果这行在 hi 位置是 0，整行不可能有更左的 1
            if (hi < 0 || binaryMatrix.get(row, hi) == 0) continue;
            
            while (lo < hi) {
                int mid = lo + (hi - lo) / 2;
                if (binaryMatrix.get(row, mid) == 0) {
                    lo = mid + 1;
                } else {
                    hi = mid;
                }
            }
            ans = lo;  // 这行的第一个 1 更靠左，更新答案
        }
        return ans == cols ? -1 : ans;
    }
};
```

**关键点**: 
- 二分模板使用 `lo < hi`（找左边界），不是 `lo <= hi`
- `hi = mid` 而不是 `hi = mid - 1`，因为 mid 处是 1，它可能就是答案
- 优化版用 `ans` 收窄搜索范围，实际调用次数更少

### 解法3: 右上角线性遍历 — O(R+C) / O(1)

**从不同角度思考**: 不要把每行独立处理，而是把整个矩阵当成一个整体。从右上角 `(0, cols-1)` 出发：
- 如果当前格是 **1**：说明这一列有 1，记录答案，但可能有更左的列也有 1 → **向左移动**
- 如果当前格是 **0**：由于本行有序，左边也全是 0，本行不可能在更左的位置有 1 → **向下移动**

每步要么 row+1（最多 R 次）要么 col-1（最多 C 次），所以总共 ≤ R+C 步。

```
// 完整遍历示意:
//   col: 0 1 2 3
// row 0: 0 0 0 [1]  ← 起点(0,3)=1, 记ans=3, 左移
//        0 0 [0] .  ← (0,2)=0, 下移
// row 1: 0 0 [1] .  ← (1,2)=1, 记ans=2, 左移
//        0 [0] . .  ← (1,1)=0, 下移
// row 2: 0 [0] . .  ← (2,1)=0, 下移
// row 3: 0 [1] . .  ← (3,1)=1, 记ans=1, 左移
//       [0] . . .   ← (3,0)=0, 下移
// row=4 越界 → 返回 ans=1
//
// 总共查询了 7 次 (≤ 4+4=8)
```

```cpp
class Solution {
public:
    int leftMostColumnWithOne(BinaryMatrix &binaryMatrix) {
        vector<int> dim = binaryMatrix.dimensions();
        int rows = dim[0], cols = dim[1];
        
        int row = 0, col = cols - 1;
        int ans = -1;
        
        while (row < rows && col >= 0) {
            if (binaryMatrix.get(row, col) == 1) {
                ans = col;   // 记录当前列，可能是答案
                col--;       // 尝试找更左的
            } else {
                row++;       // 当前行在这列是0，去下一行找
            }
        }
        return ans;
    }
};
```

**关键点**: 
- 为什么从右上角？因为向左是递减方向（可能找到更左的 1），向下是换行（当前行已经不可能更优）。两个方向分别对应"缩小答案"和"排除当前行"。
- 从左下角也行（对称的），但从左上角或右下角不行，因为两个方向的含义会冲突。

## 解法对比

| | 暴力逐列 | 每行二分 | 右上角遍历 |
|---|---|---|---|
| 时间 | O(R×C) | O(R×logC) | O(R+C) |
| 空间 | O(1) | O(1) | O(1) |
| API调用次数 | 最多 10000 | 最多 ~700 | 最多 200 |
| 是否超限 | ❌ 可能超 | ✅ 安全 | ✅ 最少 |
| 思路直觉性 | 最直觉 | 利用行有序 | 利用全局结构 |

**什么时候选哪个**: 面试中二分解法最稳妥——思路自然（有序→二分）、易于解释、不容易出错。右上角遍历是亮点加分，但需要解释清楚为什么只走 R+C 步且不漏解。

## 易错点

1. **二分时 `hi = mid - 1` 而不是 `hi = mid`**
   - ✗ `if (val == 1) hi = mid - 1;` — 可能跳过答案！当 mid 正好是第一个 1 时，`hi = mid - 1` 会把它排除
   - ✓ `if (val == 1) hi = mid;` — mid 可能是答案，保留在搜索范围内
   - 对应地，循环条件用 `lo < hi` 而不是 `lo <= hi`，否则会死循环

2. **二分后忘记检查 `lo` 位置是否真的是 1**
   - ✗ 直接 `ans = min(ans, lo);` — 如果整行都是 0，lo 会停在最后一个位置，但那里是 0
   - ✓ `if (binaryMatrix.get(row, lo) == 1) ans = min(ans, lo);`

3. **右上角遍历忘记更新 `ans`**
   - ✗ 遇到 1 直接 `col--` 但没记录 `ans = col`
   - ✓ 遇到 1 时先 `ans = col` 再 `col--`

4. **`dimensions()` 的返回值用错**
   - `dim[0]` 是行数 rows，`dim[1]` 是列数 cols，别搞反了

## 面试追问

**Q1: 暴力解为什么不行？瓶颈在哪？**
暴力逐列扫描最坏需要 R×C = 10000 次调用，超过 1000 次限制。瓶颈在于没有利用"每行有序"的性质，对每行做了线性扫描。

**Q2: 二分解法中，能否进一步减少调用次数？**
可以。用当前已知的 `ans` 来缩小搜索范围——后续行只在 `[0, ans-1]` 内二分。如果某行在 `ans-1` 位置是 0，可以直接跳过该行（一次调用就排除了）。最好情况可以远少于 R×logC。

**Q3: 如果不是 0/1 矩阵，而是每行非递减的整数矩阵，要找最左端包含 target 的列呢？**
本质相同——对每行二分查找 target 的第一次出现位置（`lower_bound`），取所有行的最小值。右上角遍历也可以适配：遇到 `>= target` 左移，`< target` 下移。

**Q4: 如果矩阵非常大（百万行），但 API 调用限制不变，怎么优化？**
右上角遍历 O(R+C) 在行数很大时也会超限。可以随机采样若干行做二分，先找到一个近似的最左列 `ans`，然后只对可能更优的行（即在 `ans-1` 位置有 1 的行）精确二分。这是一种启发式优化。
