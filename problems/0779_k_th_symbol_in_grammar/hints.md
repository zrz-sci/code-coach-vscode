# 779. 第K个语法符号 (K-th Symbol in Grammar)

## 核心思路

本题的关键在于发现**递归结构**：第 n 行的第 k 个字符由第 n-1 行的第 `ceil(k/2)` 个字符决定。如果 k 是奇数，结果与父节点相同；如果 k 是偶数，结果与父节点取反。进一步可以发现，答案等于 `k-1` 的二进制表示中 1 的个数的奇偶性。

## 思维链

1. **展开序列观察规律**：
   - 第 1 行: `0`
   - 第 2 行: `01`
   - 第 3 行: `0110`
   - 第 4 行: `01101001`
2. **发现父子关系**：第 n 行第 k 个字符由第 n-1 行第 `ceil(k/2)` 个字符生成。
   - 父节点为 0 -> 生成 `01`，第一个孩子和父节点相同，第二个取反
   - 父节点为 1 -> 生成 `10`，同理
3. **递推规律**：`f(n, k) = f(n-1, (k+1)/2) XOR (k 是否为偶数)`
4. **简化为 popcount**：递归到底就是统计 `k-1` 二进制中 1 的个数，奇数个 1 返回 1，偶数个返回 0。
5. **这其实是完全二叉树**：每层展开形成完全二叉树，从根到叶子的路径上，每次走右子树就翻转一次。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 递归法 | O(n) | O(n) 栈空间 | 最直观，但 n 可能没用到 |
| 迭代回溯法 | O(log k) | O(1) | 从 k 不断除 2 向上回溯 |
| Bit Manipulation | O(log k) | O(1) | 最优解，直接数 1 的个数 |

## 关键提示

1. 行号 `n` 其实没有实质作用——只要 `k <= 2^(n-1)` 合法即可。答案只取决于 `k`
2. 将 k 转换为 0-indexed（即 `k-1`），问题变成数二进制中 1 的个数
3. 完全二叉树视角：从根节点 0 出发，走左子树值不变，走右子树值翻转
4. 第 n 行其实是 Thue-Morse 序列的前 `2^(n-1)` 项
5. C++ 可以用 `__builtin_popcount(k-1) % 2` 一行搞定

## 解法详解

### 解法一：递归法

**核心思想**：第 n 行第 k 个字符取决于第 n-1 行第 `ceil(k/2)` 个字符。
- k 为奇数：与父节点相同
- k 为偶数：与父节点取反

**算法步骤**：
1. base case: `n == 1` 返回 0
2. 计算父节点 `parent = kthGrammar(n-1, (k+1)/2)`
3. k 为奇数返回 `parent`，偶数返回 `1 - parent`

### 解法二：迭代回溯法

**核心思想**：从第 k 个位置不断向上追溯到根。每次 k 为偶数时翻转一次。

**算法步骤**：
1. `flips = 0`（记录翻转次数）
2. 当 `k > 1`：如果 k 是偶数，`flips++`；然后 `k = (k+1)/2`
3. 返回 `flips % 2`

### 解法三：Bit Manipulation（推荐）

**核心思想**：答案 = `popcount(k - 1) % 2`。

**推导**：
- 从根到第 k 个叶子的路径，每次走右子树翻转一次
- 走右子树的判据：二进制中该位为 1
- `k-1` 的二进制表示中 1 的个数 = 从根到叶走右子树的次数
- 翻转偶数次结果为 0，奇数次结果为 1

## 易错点

1. **k 是 1-indexed**：题目明确 k 从 1 开始，在做 bit 操作时要用 `k-1`
2. **误以为 n 有用**：n 只是约束 k 的上限，算法中不需要用到 n
3. **递归方向搞错**：是从第 n 行回溯到第 1 行（自顶向下），不是从第 1 行生成到第 n 行（那样指数爆炸）
4. **奇偶判断时用错 k**：递归中是 `k` 的奇偶性决定翻转，不是 `n` 的
5. **整数溢出**：n 最大 30，第 30 行有 2^29 个元素，k 最大约 5*10^8，int 范围够用

## 面试追问

1. **为什么行号 n 不影响结果？**
   - 因为每一行都是上一行的确定性展开（0->01, 1->10），第 n 行第 k 个位置的值完全由回溯路径上的奇偶翻转决定，与 n 的具体值无关（只要 k 在范围内）。

2. **能否不用递归？**
   - 可以，用 `__builtin_popcount(k - 1) % 2` 或迭代回溯法，完全避免递归。

3. **这个序列有名字吗？**
   - 是的，这是 **Thue-Morse 序列**（也叫 Prouhet-Thue-Morse 序列），在组合数学和理论计算机科学中有重要地位。

4. **如果 n 特别大（比如 10^9），还能解吗？**
   - 完全没问题。n 不影响算法，只要 k 在 int/long 范围内就行。bit 操作法的时间只取决于 k 的位数。

5. **如何推广到 0 替换成 012、1 替换成 210 的情况？**
   - 三进制版本不再是简单的 popcount。需要递归/迭代回溯，每次根据 k 在三叉树中的位置做映射。
