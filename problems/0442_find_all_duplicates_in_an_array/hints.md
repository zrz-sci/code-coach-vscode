# 442. Find All Duplicates in an Array - 数组中重复的数据

## 题目理解

给定长度为 n 的整数数组 `nums`，其中所有整数都在 `[1, n]` 范围内，且每个整数最多出现两次。找出所有出现两次的整数。

### 关键约束

- 时间复杂度 O(n)
- 额外空间 O(1)（不含输出数组）
- 这两个约束直接排除了哈希表（O(n) 空间）和排序（O(n log n) 时间）

### 核心突破口

**值域 [1, n] 恰好和索引 [0, n-1] 形成一一映射！**

这意味着可以把数组本身当作一个"哈希表"，用索引位置来记录某个值是否出现过。

---

## 思路一：原地取反标记法（最优解）

### 核心思想

值 `v` 映射到索引 `v-1`。利用数组元素的**符号位**作为标记：
- 第一次遇到值 v：把 `nums[v-1]` 取反（变成负数，标记为"已访问"）
- 第二次遇到值 v：发现 `nums[v-1]` 已经是负数，说明 v 是重复元素

### 算法步骤

```
遍历 nums, 对于每个 nums[i]:
    1. val = abs(nums[i])       // 取绝对值 (可能已被前面取反过)
    2. idx = val - 1            // 值 v 映射到索引 v-1
    3. if nums[idx] < 0         // 该位置已被标记 → val 出现了第二次
           收集 val 到结果
       else
           nums[idx] = -nums[idx]  // 第一次遇到, 取反标记
```

### 详细推演（nums = [4, 3, 2, 7, 8, 2, 3, 1]）

```
初始:  [4,  3,  2,  7,  8,  2,  3,  1]
索引:   0   1   2   3   4   5   6   7

i=0: val=4,  idx=3, nums[3]= 7 > 0  → 取反 → [4,  3,  2, -7,  8,  2,  3,  1]
i=1: val=3,  idx=2, nums[2]= 2 > 0  → 取反 → [4,  3, -2, -7,  8,  2,  3,  1]
i=2: val=|-2|=2, idx=1, nums[1]= 3 > 0  → 取反 → [4, -3, -2, -7,  8,  2,  3,  1]
i=3: val=|-7|=7, idx=6, nums[6]= 3 > 0  → 取反 → [4, -3, -2, -7,  8,  2, -3,  1]
i=4: val=8,  idx=7, nums[7]= 1 > 0  → 取反 → [4, -3, -2, -7,  8,  2, -3, -1]
i=5: val=2,  idx=1, nums[1]=-3 < 0  → 重复! 收集 2
i=6: val=|-3|=3, idx=2, nums[2]=-2 < 0  → 重复! 收集 3
i=7: val=|-1|=1, idx=0, nums[0]= 4 > 0  → 取反 → [-4, -3, -2, -7,  8,  2, -3, -1]

结果: [2, 3]  ✓
```

### 为什么必须用 abs()？

因为前面的遍历可能已经把某些位置取反了。比如 i=2 时 `nums[2]` 已经被改成 `-2`，但原始值是 2。`abs(nums[i])` 恢复出原始的"值"信息。

### 为什么能保证 O(1) 空间？

我们利用了数组元素的**符号位**来存储"是否已访问"的额外信息。没有使用任何额外数据结构。虽然修改了原数组，但可以通过最后遍历一次 `nums[i] = abs(nums[i])` 恢复。

## 思路二：交换归位法（Cyclic Sort 变体）

### 核心思想

尝试把每个值 v 放到索引 v-1 的位置上（即 nums[0]=1, nums[1]=2, ...）。归位完成后，再扫描一遍：如果 nums[i] != i+1，说明 nums[i] 是重复出现的。

### 归位规则

```
while nums[i] != i+1 && nums[nums[i]-1] != nums[i]:
    swap(nums[i], nums[nums[i]-1])

停止条件:
  (1) nums[i] == i+1 → 已在正确位置
  (2) nums[nums[i]-1] == nums[i] → 目标位置已有相同值 → 说明重复
```

### 详细推演（nums = [4, 3, 2, 7, 8, 2, 3, 1]）

```
i=0: nums[0]=4, 应在idx=3
  swap(0,3) → [7, 3, 2, 4, 8, 2, 3, 1]   4归位到idx=3
  nums[0]=7, 应在idx=6
  swap(0,6) → [3, 3, 2, 4, 8, 2, 7, 1]   7归位到idx=6
  nums[0]=3, 应在idx=2
  swap(0,2) → [2, 3, 3, 4, 8, 2, 7, 1]   3归位到idx=2
  nums[0]=2, 应在idx=1, 但 nums[1]=3≠2
  swap(0,1) → [3, 2, 3, 4, 8, 2, 7, 1]   2归位到idx=1
  nums[0]=3, 应在idx=2, 但 nums[2]=3==nums[0] → 停止! (重复)

i=1: nums[1]=2, 2==1+1? 是 ✓ 跳过

... 后续类似处理 ...

归位后: [3, 2, 3, 4, 1, 2, 7, 8]  (近似, 具体取决于交换顺序)
扫描: nums[i] != i+1 的位置 → 收集 nums[i]
```

### 为什么 while 循环总时间是 O(n)？

每个元素**最多被交换一次到正确位置后就不再移动**。总共 n 个元素，所以所有 while 循环加起来最多 n 次交换。

## 思路三：加 n 标记法（另一种原地标记）

不用取反，而是给 `nums[v-1]` 加上 n。如果某位置的值 > 2n，说明被加了两次，对应的索引 + 1 就是重复的数。

```
第一遍: 遍历 nums[i], val = (nums[i]-1) % n, nums[val] += n
第二遍: 遍历 nums[i], 如果 nums[i] > 2*n → i+1 是重复数

推演 (n=8):
  i=0: val=(4-1)%8=3, nums[3]+=8 → 7+8=15
  i=1: val=(3-1)%8=2, nums[2]+=8 → 2+8=10
  ...
  i=5: val=(2-1)%8=1, nums[1]+=8 → 11+8=19 > 16=2n → 重复!
  i=6: val=(11-1)%8=2, nums[2]+=8 → 10+8=18 > 16=2n → 重复!
```

## 完整代码

### 解法一：取反标记法（面试首选）

```cpp
class Solution {
public:
    vector<int> findDuplicates(vector<int>& nums) {
        vector<int> result;
        for (int i = 0; i < (int)nums.size(); i++) {
            int val = abs(nums[i]);      // 取绝对值恢复原始值
            int idx = val - 1;            // 值 v → 索引 v-1

            if (nums[idx] < 0) {
                result.push_back(val);    // 已标记过 → 重复
            } else {
                nums[idx] = -nums[idx];   // 第一次 → 取反标记
            }
        }
        return result;
    }
};
```

### 解法二：交换归位法

```cpp
class Solution {
public:
    vector<int> findDuplicates(vector<int>& nums) {
        int n = nums.size();
        // 第一步: 交换归位
        for (int i = 0; i < n; i++) {
            while (nums[i] != i + 1 && nums[nums[i] - 1] != nums[i]) {
                swap(nums[i], nums[nums[i] - 1]);
            }
        }
        // 第二步: 收集不在正确位置的值
        vector<int> result;
        for (int i = 0; i < n; i++) {
            if (nums[i] != i + 1) {
                result.push_back(nums[i]);
            }
        }
        return result;
    }
};
```

### 解法三：加 n 标记法

```cpp
class Solution {
public:
    vector<int> findDuplicates(vector<int>& nums) {
        int n = nums.size();
        vector<int> result;

        for (int i = 0; i < n; i++) {
            int val = (nums[i] - 1) % n;
            nums[val] += n;
        }

        for (int i = 0; i < n; i++) {
            if (nums[i] > 2 * n) {
                result.push_back(i + 1);
            }
        }
        return result;
    }
};
```

| 方法 | 时间 | 空间 | 遍历次数 | 是否修改原数组 | 面试推荐 |
|------|------|------|---------|---------------|---------|
| 取反标记 | O(n) | O(1) | 1 次 | 是（可恢复） | **首选** |
| 交换归位 | O(n) | O(1) | 2 次 | 是（改变顺序） | 次选 |
| 加 n 标记 | O(n) | O(1) | 2 次 | 是（可恢复） | 了解即可 |
| 哈希集合 | O(n) | O(n) | 1 次 | 否 | 不满足空间要求 |

## 关键模式识别："值在 [1, n] 范围"题目家族

这是一个经典题目家族，核心技巧是**索引映射**（值 v → 索引 v-1）：

| 题号 | 题目 | 技巧 | 找什么 |
|------|------|------|--------|
| 41 | First Missing Positive | 交换归位 | 缺失的数 |
| 268 | Missing Number | 异或 / 数学 | 缺失的数 |
| 287 | Find the Duplicate Number | Floyd 快慢指针 | 唯一重复数 |
| **442** | **Find All Duplicates** | **取反标记** | **所有重复数** |
| 448 | Find All Numbers Disappeared | 取反标记 | 所有消失的数 |

**442 和 448 是"镜像题"**：
- 442：标记后，第二次遇到负数的值 → 重复
- 448：标记后，仍为正数的位置 → 消失

## 关键提示序列

### Hint 1: 约束决定方向
> O(n) 时间 + O(1) 空间，直接排除哈希表和排序。需要原地算法。

### Hint 2: 值域和索引的映射
> 值 v 在 [1, n] 范围，数组索引是 [0, n-1]。值 v 可以映射到索引 v-1。

### Hint 3: 数组当"哈希表"
> 把数组本身当作一个哈希表：值 v 的"状态"存储在 nums[v-1] 的符号位中。

### Hint 4: 取反标记
> 第一次遇到 v 时 nums[v-1] 取反。第二次遇到 v 时发现 nums[v-1] 已为负。

### Hint 5: 必须用 abs
> 遍历时 nums[i] 可能已被前面的操作取反，必须用 abs(nums[i]) 恢复原始值。

### Hint 6: 交换归位的替代方案
> 把每个 v 放到 nums[v-1] 位置上。归位后 nums[i] != i+1 的位置就是重复值所在。

## 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 忘记 abs() | nums[i] 可能已被取反,用负值做索引会越界 | 始终 abs(nums[i]) |
| 直接用 v 做索引 | 索引越界 (v 的范围是 [1,n] 不是 [0,n-1]) | idx = v - 1 |
| 交换归位时死循环 | nums[i]==nums[nums[i]-1] 时无限交换 | 加退出条件 |
| 混淆 442 和 448 | 442找重复, 448找消失, 逻辑不同 | 审清题意 |

## 复杂度分析

**取反标记法**：
- 时间 O(n)：一次遍历，每个元素 O(1) 操作
- 空间 O(1)：只用了数组本身的符号位，无额外数据结构

**交换归位法**：
- 时间 O(n)：虽然有嵌套 while，但每个元素最多被交换到正确位置一次
- 空间 O(1)：原地操作

## 面试追问

**Q1: 如果不允许修改原数组？**
- 只有一个重复数（LC 287）→ Floyd 快慢指针，O(n)/O(1)
- 多个重复数 → O(1) 空间几乎不可能，需要 O(n) 哈希集合

**Q2: 如果每个元素可以出现任意次？**
- 取反标记仍然有效。但第三次遇到时 nums[idx] 又变正，需要修改逻辑
- 更保险的做法：用 HashSet 去重结果，或改用加 n 标记法

**Q3: 如何恢复被修改的数组？**
- 遍历一次取绝对值：`for (auto& x : nums) x = abs(x);`

## 面试沟通建议

1. **先澄清约束**：O(n) 时间 + O(1) 空间 → 这直接排除哈希和排序
2. **提出关键观察**：值在 [1, n] 范围 → 可以利用索引映射
3. **画图演示**：用 [3, 1, 3, 2] 这样的小例子演示取反标记过程
4. **讨论 trade-off**：取反标记（一次遍历，最简洁）vs 交换归位（两次遍历，不影响值的顺序）
