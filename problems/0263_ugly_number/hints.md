# 263. 丑数

## 核心思路

**丑数**的定义：只包含质因数 2、3、5 的正整数（1 也是丑数，因为它没有任何质因数）。判断方法就是不断地把 n 中的 2、3、5 因子除干净，看最后剩下的是不是 1。

## 思维链

1. **读完题第一反应** → 需要判断 n 的质因数分解中是否只含有 2、3、5。如果含有 7、11、13 等其他质因子，就不是丑数。
2. **怎么判断"只含 2、3、5"？** → 反复除以 2 直到不能整除，再反复除以 3 直到不能整除，再反复除以 5 直到不能整除。如果最后结果是 1，说明所有因子都是 2/3/5 的组合。
3. **边界条件？** → n <= 0 不是丑数（丑数必须是正整数）。n = 1 是丑数（没有质因数，符合定义）。
4. **需要递归吗？** → 不需要。三个 while 循环就够了，每个循环把对应因子除干净。
5. **效率如何？** → 每次除法至少让 n 缩小一半（除以 2 的情况），所以循环次数最多 O(log n)，非常快。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 循环除因子（推荐） | 依次除尽 2/3/5，判断是否剩 1 | O(log n) | O(1) | ⭐ 标准写法 |
| 统一因子数组 | 用数组 [2,3,5] 遍历，更通用 | O(log n) | O(1) | 更优雅的写法 |
| 递归写法 | 递归除因子 | O(log n) | O(log n) | 理解即可 |

## 关键提示

1. **丑数必须是正整数**：n <= 0 直接返回 false。题目约束 n 可以是负数或 0！
2. **1 是丑数**：1 没有任何质因数，自然满足"不包含 2/3/5 以外的质因数"这个条件（空集满足所有条件）。
3. **除因子的顺序无所谓**：先除 2 再除 3 再除 5，或者先除 5 再除 3 再除 2，结果都一样。因为除法操作相互独立，每个 while 循环只管把自己的因子除干净。
4. **为什么只需要检查 2、3、5？** 一个正整数的质因数分解是唯一的（算术基本定理）。如果除完 2/3/5 后剩下的不是 1，说明 n 有其他质因子。
5. **为什么不需要检查 4、6、8 等合数？** 因为 4 = 2^2，6 = 2*3，等等。合数因子会被分解为质因子。反复除 2 就会自动把 4、8、16 等因子都除掉。
6. **时间复杂度分析**：n 最多除以 2 大约 log2(n) 次（约 31 次），除以 3 大约 log3(n) 次（约 20 次），除以 5 大约 log5(n) 次（约 14 次），总计不超过 65 次操作。

## 解法详解

### 解法1: 循环除因子 — O(log n) / O(1) ⭐ 标准写法

**思考过程**: 对于丑数 n，它的质因数分解形如 n = 2^a * 3^b * 5^c。我们的任务就是把 a 个 2、b 个 3、c 个 5 全部除掉，看最后是否等于 1。

```
示例: n = 6
  6 % 2 == 0 → 6 / 2 = 3
  3 % 2 != 0 → 结束除2
  3 % 3 == 0 → 3 / 3 = 1
  1 % 3 != 0 → 结束除3
  1 % 5 != 0 → 结束除5
  最终 n = 1 → 是丑数 ✓

示例: n = 14
  14 % 2 == 0 → 14 / 2 = 7
  7 % 2 != 0  → 结束除2
  7 % 3 != 0  → 结束除3
  7 % 5 != 0  → 结束除5
  最终 n = 7 ≠ 1 → 不是丑数 ✗（因为含质因子 7）

示例: n = 30
  30 / 2 = 15 → 15 / 3 = 5 → 5 / 5 = 1
  最终 n = 1 → 是丑数 ✓ (30 = 2 * 3 * 5)

示例: n = 1
  不进入任何 while 循环（1 不能被 2/3/5 整除）
  最终 n = 1 → 是丑数 ✓

示例: n = 0 或 n = -6
  直接返回 false（丑数必须是正整数）
```

```cpp
class Solution {
public:
    bool isUgly(int n) {
        if (n <= 0) return false;  // 丑数必须是正整数
        
        // 把所有因子 2 除干净
        while (n % 2 == 0) n /= 2;
        // 把所有因子 3 除干净
        while (n % 3 == 0) n /= 3;
        // 把所有因子 5 除干净
        while (n % 5 == 0) n /= 5;
        
        return n == 1;  // 如果只含 2/3/5 因子，除完后应该是 1
    }
};
```

**关键点**:
- 先处理 n <= 0 的边界，因为 0 不能取模（0 % 2 == 0 是成立的，会死循环），负数也不是丑数。
- 三个 while 循环分别除尽 2、3、5。顺序任意。
- 最后判断 n 是否等于 1。如果 n > 1，说明有其他质因子。

---

### 解法2: 统一因子数组 — O(log n) / O(1)

**更优雅的写法**: 用数组存储 [2, 3, 5]，用循环遍历。当因子列表需要修改（比如扩展为 [2, 3, 5, 7]）时只需改数组。

```cpp
class Solution {
public:
    bool isUgly(int n) {
        if (n <= 0) return false;
        
        for (int f : {2, 3, 5}) {
            while (n % f == 0) {
                n /= f;
            }
        }
        
        return n == 1;
    }
};
```

**关键点**:
- 逻辑和解法1 完全一样，只是用循环替代了三个独立的 while。
- 更具**扩展性**：如果丑数定义改为"只含质因数 2, 3, 5, 7"，只需把数组改为 `{2, 3, 5, 7}`。
- 面试中两种写法都可以，解法2 展示了"参数化"的编程习惯。

---

### 解法3: 递归写法 — O(log n) / O(log n)

**递归视角**: 如果 n 能被 2 整除就递归判断 n/2，能被 3 整除就递归判断 n/3，能被 5 整除就递归判断 n/5。

```cpp
class Solution {
public:
    bool isUgly(int n) {
        if (n <= 0) return false;
        if (n == 1) return true;
        
        if (n % 2 == 0) return isUgly(n / 2);
        if (n % 3 == 0) return isUgly(n / 3);
        if (n % 5 == 0) return isUgly(n / 5);
        
        return false;  // 不能被 2/3/5 整除且不为 1，不是丑数
    }
};
```

**关键点**:
- 递归深度最多 O(log n)，不会栈溢出。
- 注意这里 if 的顺序是优先除 2，除不动再试 3，再试 5。每次递归只除一个因子。
- 相比循环写法，递归有额外的栈空间开销，面试中不推荐。

## 解法对比

|  | 循环除因子 | 统一因子数组 | 递归写法 |
|--|-----------|-------------|---------|
| 时间 | O(log n) | O(log n) | O(log n) |
| 空间 | **O(1)** | **O(1)** | O(log n) |
| 扩展性 | 手动添加 while | ⭐ 修改数组即可 | 手动添加 if |
| 可读性 | 直观 | ⭐ 最简洁 | 略绕 |

## 易错点

1. **忘记处理 n <= 0**：
   - ✗ 直接进入 while 循环 → n=0 时 `0 % 2 == 0` 为 true，`0 / 2 = 0`，死循环！
   - ✓ 开头加 `if (n <= 0) return false;`

2. **认为 1 不是丑数**：
   - ✗ `if (n == 1) return false;` → 错！1 是丑数（没有任何质因数，满足条件）
   - ✓ 1 是丑数序列的第一个数

3. **只除一次而不是除干净**：
   - ✗ `if (n % 2 == 0) n /= 2;` → 只除了一个 2，如果 n=8 (2^3)，只除一次变成 4
   - ✓ `while (n % 2 == 0) n /= 2;` → 用 while 把所有 2 都除掉

4. **误判合数因子**：
   - ✗ 以为需要检查 4、6、8、9、10... → 不需要，它们都由 2、3、5 组成
   - ✓ 只检查 2、3、5 三个质因子就够了

## 面试追问

**Q1: 为什么不需要检查所有质数？**
> 因为我们只需要验证 n 的质因数是否全在 {2,3,5} 中。把 2、3、5 的因子全部除掉后，如果 n>1，说明有其他质因子。不需要找出那个质因子是谁。

**Q2: 如果定义改为"超级丑数"（给定质因子列表 primes），怎么改？**
> 把 [2,3,5] 换成 primes 数组即可。解法2 的数组写法天然支持这种扩展。这就是 LeetCode 313 (Super Ugly Number) 的相关问题。

**Q3: 如何找到第 n 个丑数？**
> 这是 LeetCode 264 (Ugly Number II)。用三指针法或最小堆：维护三个指针分别乘 2、3、5，每次取最小值作为下一个丑数。时间 O(n) 空间 O(n)。

**Q4: 时间复杂度为什么是 O(log n)？**
> 每次除以 2 至少让 n 减半，所以除以 2 的循环最多执行 log2(n) 次（约 31 次对于 int）。类似地除以 3 最多 log3(n) 次，除以 5 最多 log5(n) 次。总次数为 O(log n)。

**Q5: INT_MIN (-2^31) 取绝对值会溢出吗？**
> 会！`abs(INT_MIN)` 在 C++ 中是未定义行为，因为 2^31 超出了 int 范围。但本题中 n <= 0 直接返回 false，不需要取绝对值，所以没有这个问题。

## 相关题型

- **264. 丑数 II (Ugly Number II)** — 找第 n 个丑数。三指针法：维护三个指针分别乘以 2/3/5，每次选最小的。是本题的进阶应用。
- **313. 超级丑数 (Super Ugly Number)** — 质因子列表不再固定为 [2,3,5] 而是给定数组。用最小堆维护。
- **1201. 丑数 III** — 能被 a/b/c 整除的第 n 个正整数。用二分 + 容斥原理，和丑数系列的"除因子"思路不同。
- **204. 计数质数 (Count Primes)** — 判断质数的基础，和本题的"质因数分解"思想相关。
