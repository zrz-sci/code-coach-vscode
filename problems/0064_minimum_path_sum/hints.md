# 64. 最小路径和 (Minimum Path Sum)

## 难度: Medium
## 标签: Array, Dynamic Programming, Matrix

---

## 核心思路

这是一道经典的二维动态规划题。给定一个 m x n 的网格，每个格子有一个非负整数，只能向右或向下移动，求从左上角到右下角的最小路径和。

**关键洞察**：由于只能向右或向下走，到达每个格子 (i,j) 只可能从上方 (i-1,j) 或左方 (i,j-1) 来。因此每个格子的最小路径和 = 自身值 + min(上方最小路径和, 左方最小路径和)。

这种「无后效性」的结构天然适合 DP —— 当前状态只依赖于已经计算过的子问题，不存在循环依赖。

---

## 思维链（从暴力到最优，6步推导）

### Step 1: 暴力递归（自顶向下）
- 从 (0,0) 出发，每步有两个选择：向右或向下
- 递归地计算所有路径，取最小值
- 时间复杂度：O(2^(m+n))，指数级，大量重复计算

### Step 2: 发现重叠子问题
- 画递归树：到达 (i,j) 可以从 (i-1,j) 或 (i,j-1) 来
- 很多格子会被重复计算 -> 记忆化搜索
- 时间降到 O(mn)，空间 O(mn)（递归栈 + memo 数组）

### Step 3: 转为自底向上 DP
- 定义 dp[i][j] = 从 (0,0) 到 (i,j) 的最小路径和
- 转移方程：dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])
- 边界：dp[0][0] = grid[0][0]，第一行只能从左来，第一列只能从上来
- 时间 O(mn)，空间 O(mn)

### Step 4: 观察依赖关系，进行空间优化
- dp[i][j] 只依赖 dp[i-1][j]（正上方）和 dp[i][j-1]（正左方）
- 逐行处理时，dp[j] 更新前存的是上一行的值（即 dp[i-1][j]），dp[j-1] 是当前行已更新的值（即 dp[i][j-1]）
- 一维数组即可：dp[j] = grid[i][j] + min(dp[j], dp[j-1])
- 时间 O(mn)，空间 O(n)

### Step 5: 原地修改（空间 O(1)）
- 如果允许修改输入，直接在 grid 上累加
- grid[i][j] += min(grid[i-1][j], grid[i][j-1])
- 时间 O(mn)，空间 O(1)

### Step 6: 验证正确性
- 用例 1: grid = [[1,3,1],[1,5,1],[4,2,1]]
  - 路径 1->3->1->1->1 = 7 (最优)
  - 路径 1->1->5->1->1 = 9
  - 路径 1->1->4->2->1 = 9

## DP 状态转移表（核心！面试画此表加分）

### grid = [[1,3,1],[1,5,1],[4,2,1]]

```
原始 grid:          DP 表:
1  3  1              1  4  5
1  5  1     ->       2  7  6
4  2  1              6  8  7  <- 答案
```

**填表过程：**
```
dp[0][0] = 1
dp[0][1] = 1+3 = 4       (只能从左来)
dp[0][2] = 4+1 = 5       (只能从左来)
dp[1][0] = 1+1 = 2       (只能从上来)
dp[1][1] = 5+min(4,2) = 5+2 = 7
dp[1][2] = 1+min(5,7) = 1+5 = 6
dp[2][0] = 2+4 = 6       (只能从上来)
dp[2][1] = 2+min(7,6) = 2+6 = 8
dp[2][2] = 1+min(6,8) = 1+6 = 7  <- 最终答案
```

### 空间优化一维 DP 滚动过程：
```
初始(第0行): dp = [1, 4, 5]
处理第1行:   dp[0] = 1+1 = 2
             dp[1] = 5+min(dp[1]=4, dp[0]=2) = 5+2 = 7
             dp[2] = 1+min(dp[2]=5, dp[1]=7) = 1+5 = 6
             dp = [2, 7, 6]
处理第2行:   dp[0] = 2+4 = 6
             dp[1] = 2+min(dp[1]=7, dp[0]=6) = 2+6 = 8
             dp[2] = 1+min(dp[2]=6, dp[1]=8) = 1+6 = 7
             dp = [6, 8, 7]
答案 = dp[2] = 7
```

## 关键提示

1. **边界初始化是重点**：第一行只能从左来（前缀和），第一列只能从上来（前缀和）
2. **空间优化时注意更新顺序**：从左到右遍历，dp[j-1] 已是当前行的值，dp[j] 还是上一行的值
3. **原地修改的取舍**：面试中要主动询问"可以修改输入吗？"
4. **DP 三要素**：状态定义 -> 转移方程 -> 边界条件，缺一不可

## 解法详解

### Solution1: 二维 DP（标准解法）

**思考过程**：
- 定义 dp[i][j] 表示从 (0,0) 走到 (i,j) 的最小路径和
- 只能从上方或左方到达 -> dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])
- 第一行第一列特殊处理（只有一条路径）

```cpp
class Solution1 {
public:
    int minPathSum(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        // 创建 dp 表
        vector<vector<int>> dp(m, vector<int>(n));

        // 边界：起点
        dp[0][0] = grid[0][0];

        // 边界：第一列，只能从上方来
        for (int i = 1; i < m; i++)
            dp[i][0] = dp[i-1][0] + grid[i][0];

        // 边界：第一行，只能从左方来
        for (int j = 1; j < n; j++)
            dp[0][j] = dp[0][j-1] + grid[0][j];

        // 填表：从左到右，从上到下
        for (int i = 1; i < m; i++)
            for (int j = 1; j < n; j++)
                dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1]);

        return dp[m-1][n-1];
    }
};
```

**关键点**：
- dp 表的大小和 grid 相同
- 填表顺序保证了 dp[i-1][j] 和 dp[i][j-1] 在使用时已计算完毕

### Solution2: 一维 DP 空间优化（面试首选 ⭐）

**思考过程**：
- 观察到 dp[i][j] 只依赖当前行（dp[i][j-1]）和上一行（dp[i-1][j]）
- 用一维数组滚动更新：dp[j] 更新前 = 上一行的 dp[i-1][j]，dp[j-1] = 当前行的 dp[i][j-1]
- 特别注意：每行的 dp[0] 需要单独累加

```cpp
class Solution2 {
public:
    int minPathSum(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        vector<int> dp(n);

        // 初始化第一行
        dp[0] = grid[0][0];
        for (int j = 1; j < n; j++)
            dp[j] = dp[j-1] + grid[0][j];

        // 逐行更新
        for (int i = 1; i < m; i++) {
            // 第一列：只能从上方来
            dp[0] += grid[i][0];
            // 其余列：取上方和左方的较小值
            for (int j = 1; j < n; j++)
                dp[j] = grid[i][j] + min(dp[j], dp[j-1]);
                //                       ^上方     ^左方(已更新)
        }
        return dp[n-1];
    }
};
```

**关键点**：
- dp[j] 在更新前保存的是上一行的值 (dp[i-1][j])
- dp[j-1] 在当前循环中已经被更新为当前行的值 (dp[i][j-1])
- 这个更新顺序（从左到右）正好满足依赖关系

---

### Solution3: 原地修改（极致空间优化）

**思考过程**：
- 如果允许修改输入数组，可以直接在 grid 上做 DP
- grid[i][j] 累加后就变成了 dp[i][j]
- 空间 O(1)，但破坏了原始数据

```cpp
class Solution3 {
public:
    int minPathSum(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();

        // 初始化第一列
        for (int i = 1; i < m; i++)
            grid[i][0] += grid[i-1][0];

        // 初始化第一行
        for (int j = 1; j < n; j++)
            grid[0][j] += grid[0][j-1];

        // 填表
        for (int i = 1; i < m; i++)
            for (int j = 1; j < n; j++)
                grid[i][j] += min(grid[i-1][j], grid[i][j-1]);

        return grid[m-1][n-1];
    }
};
```

**关键点**：
- 面试中主动说明"这种方法会修改输入，需要确认是否允许"
- 如果调用方之后还需要原始 grid，就不能用这个方法

## 易错点（具体 Bug 示例）

### Bug 1: 忘记初始化第一行/第一列
```cpp
// 错误：直接从 (1,1) 开始填，dp[1][0] 和 dp[0][1] 未初始化
for (int i = 1; i < m; i++)
    for (int j = 1; j < n; j++)
        dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1]); // dp[i][0] = 0, 错误!
```

### Bug 2: 一维 DP 中忘记单独处理 dp[0]
```cpp
// 错误：dp[0] 没有在每行开头更新
for (int i = 1; i < m; i++) {
    // 缺少: dp[0] += grid[i][0];
    for (int j = 1; j < n; j++)
        dp[j] = grid[i][j] + min(dp[j], dp[j-1]);
}
// dp[0] 始终是第一行的值，导致结果错误
```

### Bug 3: 空间优化时更新顺序搞反
```cpp
// 错误：如果从右到左更新，dp[j] 会先被更新，dp[j+1] 用到的就不是上一行的值了
// 但本题从左到右是正确的，因为需要当前行的 dp[j-1]
// 注意区分：某些 DP（如 0-1 背包）需要从右到左更新
```

### Bug 4: 边界条件遗漏 m=1 或 n=1 的情况
```cpp
// 当 m=1 时，只有一行，结果就是第一行的前缀和
// 当 n=1 时，只有一列，结果就是第一列的前缀和
// 上面的代码已经正确处理，但要注意循环不会越界
```

## 面试追问递进链

### Q1: "能否输出最小路径的具体路径？"
**思路**：额外维护一个方向数组 `dir[i][j]` 记录每个格子是从上方还是左方来的，最后从 (m-1,n-1) 反向追踪到 (0,0)。
```
从终点反向追踪：
(2,2) <- (1,2) <- (0,2) <- (0,1) <- (0,0)
对应值：  1       1       1       3       1  -> 路径 1,3,1,1,1
```

### Q2: "如果可以向上下左右四个方向移动呢？"
**思路**：不再是 DAG，不能用简单 DP。变成最短路径问题：
- 所有权重非负 -> Dijkstra 算法，时间 O(mn log(mn))
- BFS + 优先队列

### Q3: "如果有些格子是障碍物（不可通过）呢？"
**思路**：dp[i][j] = INF 如果 grid[i][j] 是障碍物，否则正常转移。注意检查起点和终点是否为障碍。

### Q4: "如果要求恰好走 k 步到达终点？"
**思路**：增加一维状态 dp[i][j][k] = 恰好走 k 步到达 (i,j) 的最小路径和。注意 k = (m-1)+(n-1) 是固定的步数。
