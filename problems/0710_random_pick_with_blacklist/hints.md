# 710. 黑名单中的随机数 - 提示

## 题目关键信息
- 从 `[0, n-1]` 中等概率随机选一个**不在**黑名单中的数
- n 可达 10^9，不能创建大小为 n 的数组
- 要求最少调用随机函数

## 提示 1 — 核心思路：映射
有效数字个数 = `n - blacklist.size()`，设为 `M`。
如果我们在 `[0, M)` 范围内随机选一个数，就只需要调用一次随机函数。

> 关键问题：`[0, M)` 中有些数在黑名单里，怎么办？

## 提示 2 — 黑名单映射到尾部
将 `[0, M)` 范围内的黑名单数字，映射到 `[M, n)` 范围内的白名单数字。

具体做法：
1. 先找出 `[M, n)` 中**不在**黑名单的数字（可用 set）
2. 对 `[0, M)` 中每个黑名单数字，依次映射到上述白名单数字

## 提示 3 — pick 操作
1. 随机生成 `r = rand() % M`
2. 如果 `r` 在映射表中，返回 `map[r]`
3. 否则 `r` 本身就是合法的，直接返回

## 复杂度
- 构造：O(B log B)，B = blacklist.size()
- pick：O(1)
- 空间：O(B)
