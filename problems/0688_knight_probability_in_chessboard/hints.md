# 688. Knight Probability in Chessboard - 骑士在棋盘上的概率

## 难度：Medium

## 标签：Dynamic Programming, Matrix

---

## 核心思路

骑士从位置 (row, column) 出发，每步等概率选择 8 个 L 形方向之一。走出棋盘的骑士不再回来。求恰好走 k 步后仍在棋盘上的概率。这是一道经典的**概率 DP** 问题：定义 `dp[step][i][j]` 为骑士在第 step 步处于 (i,j) 的概率，通过概率扩散转移，最终将所有格子的概率求和即为答案。用滚动数组可以将空间从 O(k*n^2) 优化到 O(n^2)。

---

## 思维链

1. 骑士每步有 8 种等概率选择，每种概率为 1/8。
2. 如果从"步数"角度思考：第 0 步骑士在 (row, col) 的概率为 1.0，其余格子为 0。
3. 第 step+1 步：从所有格子 (i,j) 向 8 个方向"扩散"概率。如果 (ni, nj) 在棋盘内，则 `dp[step+1][ni][nj] += dp[step][i][j] / 8.0`。
4. 走到棋盘外的概率自然消失（不累加到任何位置），所以留在棋盘内的概率会逐步减小。
5. 最终答案 = `sum(dp[k][i][j])` 对所有 (i,j) 求和。
6. 由于每步只依赖上一步，可以用两个 n x n 矩阵交替使用（滚动数组）。

---

## 解法概览

| 解法 | 时间 | 空间 | 特点 |
|------|------|------|------|
| 正向概率扩散 DP | O(k * n^2) | O(n^2) 滚动 | 最直观，从当前位置向 8 方向扩散 |
| 反向概率收集 DP | O(k * n^2) | O(n^2) 滚动 | 每个位置从 8 方向收集概率 |
| 记忆化递归 (Top-down) | O(k * n^2) | O(k * n^2) | 代码简单但空间大 |
| 矩阵快速幂 | O(n^4 * log k) | O(n^4) | k 极大时理论更快，实际常数大 |

---

## 关键提示

### 提示 1 - 正向扩散 vs 反向收集
- **正向扩散**：对每个 (i,j)，将 `dp[i][j] / 8` 加到 8 个邻居。直觉是"从这里出发到那里"。
- **反向收集**：对每个 (ni,nj)，从 8 个来源收集 `dp[i][j] / 8`。直觉是"从那里来到这里"。
两种方式等价，正向扩散更直观，反向收集在某些实现中更方便。

### 提示 2 - 棋盘外的概率自动消失
不需要显式处理"走出棋盘"的情况。当目标位置 (ni, nj) 超出 [0, n) 范围时，直接跳过不累加。这部分概率就"丢失"了，恰好等于走出棋盘的概率。

### 提示 3 - 滚动数组优化
每一步只依赖上一步，不需要保留所有 k 步的状态。用两个 n x n 矩阵 `dp` 和 `ndp` 交替使用，每步开始时将 `ndp` 清零。

### 提示 4 - dp 跳过零值优化
如果 `dp[i][j] == 0`，说明骑士不可能在第 step 步处于 (i,j)，跳过该格子。在棋盘大、步数少的情况下，实际非零格子远少于 n^2，可显著减少计算。

### 提示 5 - 记忆化递归视角
定义 `prob(step, i, j)` = 骑士从 (i,j) 出发走 step 步后仍在棋盘上的概率。
- base case: `prob(0, i, j) = 1.0`（对棋盘内的位置），`prob(*, out, out) = 0`
- 转移: `prob(step, i, j) = (1/8) * sum(prob(step-1, ni, nj))` 对 8 个方向

## 解法详解

### 正向概率扩散 DP（推荐）

**状态定义：** `dp[i][j]` = 当前步骑士处于 (i,j) 的概率

**初始化：** `dp[row][column] = 1.0`，其余为 0

**转移（每步）：**
```
新建 ndp 全零矩阵
for each (i, j) where dp[i][j] > 0:
    for each direction (di, dj) in 8 directions:
        ni = i + di, nj = j + dj
        if (ni, nj) in bounds:
            ndp[ni][nj] += dp[i][j] / 8.0
dp = ndp
```

**答案：** k 步后 `sum(dp[i][j])` 对所有 (i,j)

**直觉：** 想象概率像水一样从起点"流"向四周。每一步，每个格子的水均匀分成 8 份流向邻居。流出棋盘的水消失。最后棋盘上剩余的水量就是答案。

### 记忆化递归

**定义：** `solve(k, r, c)` = 从 (r,c) 走 k 步仍在棋盘上的概率

```
solve(0, r, c) = 1.0  (任何棋盘内位置)
solve(k, r, c) = (1/8) * sum(solve(k-1, nr, nc)) for (nr,nc) in bounds
               + (1/8) * 0  for (nr,nc) out of bounds
```

用 `memo[k][r][c]` 缓存避免重复计算。

---

## 易错点

1. **概率除以 8 的时机**：在扩散时除，不是在收集时除。每个格子的概率分成 8 份流向 8 个方向。
2. **ndp 必须每步清零**：新一步的概率矩阵必须从全零开始，不能在旧矩阵上直接修改。
3. **浮点精度**：使用 `double` 即可，不需要特殊的精度处理。题目允许 10^-5 的误差。
4. **8 个方向不能写错**：L 形移动的 8 个偏移是 `{-2,-1}, {-2,1}, {-1,-2}, {-1,2}, {1,-2}, {1,2}, {2,-1}, {2,1}`。容易漏写或重复。
5. **k=0 时直接返回 1.0**：骑士初始位置在棋盘内（题目保证），0 步后概率为 1。
6. **不要用 int 存概率**：`dp[i][j]` 必须是浮点类型。
7. **记忆化递归的空间**：O(k * n^2) 可能很大（k=100, n=25 → 62500 个状态），但都在限制内。

## 面试追问

1. **如果棋盘不是正方形 (n x m) 怎么办？**
   → 直接将所有 n 替换为对应的行列限制即可，逻辑不变。

2. **如果某些格子是"陷阱"，骑士踩到后消失，怎么修改？**
   → 在扩散时，如果目标格子是陷阱，不累加概率（和走出棋盘一样处理）。或者在每步结束后将陷阱格子的概率清零。

3. **如果要求"恰好在第 k 步到达特定位置 (r2, c2)"的概率？**
   → 同样的 DP，但最终答案只取 `dp[k][r2][c2]`，不求和。

4. **矩阵快速幂怎么做？**
   → 将 n^2 个格子编号为状态，构建 n^2 x n^2 的转移矩阵 M（M[to][from] = 1/8 或 0），答案为 M^k * initial_vector。当 k 极大时比普通 DP 更快。

5. **如果每一步不是等概率而是有不同权重？**
   → 将 `/8.0` 替换为对应的权重归一化概率。其余逻辑不变。
