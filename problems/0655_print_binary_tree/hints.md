# 655. 输出二叉树 (Print Binary Tree)

**难度**: Medium | **标签**: Tree, DFS, BFS, Binary Tree

## 核心思路

分两步完成：**先求树高确定矩阵尺寸，再递归填充节点位置**。

矩阵的行数 `m = height + 1`，列数 `n = 2^(height+1) - 1`。根节点放在第 0 行的正中间 `(n-1)/2`，每个节点的左孩子在 `col - 2^(height-row-1)`，右孩子在 `col + 2^(height-row-1)`。整个过程就是递归地在矩阵的正确位置填写节点值。

## 思维链

1. **理解布局规则**：矩阵大小由树的高度决定，根据高度可以精确计算每个节点在矩阵中的列位置
2. **先求高度**：DFS 或 BFS 求树的高度 height（根节点为 0 层时的最大深度）
3. **计算矩阵尺寸**：行 = height + 1，列 = 2^(height+1) - 1
4. **初始化矩阵**：全部填充空字符串 ""
5. **递归填充**：从根节点开始，知道当前节点的 (row, col)，按公式计算左右子节点的列位置
6. **列偏移量递减**：每深入一层，左右孩子相对父节点的列偏移减半

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| DFS 求高 + DFS 填充 | O(n + m*n) | O(m*n) | 最直观，两次遍历 |
| BFS 求高 + DFS 填充 | O(n + m*n) | O(m*n) | BFS 求高更直观 |
| 一次 DFS（合并求高与填充） | O(m*n) | O(m*n) | 代码更紧凑 |

注：m*n 中 m = height+1，n = 2^(height+1)-1，矩阵本身占 O(m*n) 空间

## 关键提示

1. **高度定义**：本题中高度 height = 从根到最深叶子的边数。单节点树 height = 0，故矩阵 1 行 1 列
2. **列数公式**：`n = 2^(height+1) - 1`，即完美二叉树的节点数。这保证了布局的对称性
3. **列偏移公式**：在第 row 行的节点，其孩子的列偏移量为 `2^(height - row - 1)`。随层数增加，偏移量指数减小
4. **位运算加速**：`2^x` 可用 `1 << x` 实现，避免 pow 函数的浮点精度问题
5. **to_string 转换**：节点值需要转为字符串放入矩阵，注意负数会带负号

## 解法详解

### 解法一：两次 DFS（推荐）

**第一步：求树的高度**
```
getHeight(node):
    if node == null: return -1
    return 1 + max(getHeight(left), getHeight(right))
```
单节点返回 0，空树返回 -1。

**第二步：构建矩阵并递归填充**

1. 计算 `m = height + 1`，`n = (1 << (height + 1)) - 1`
2. 创建 m x n 的矩阵，初始全为 ""
3. 定义 `fill(node, row, col)`：
   - 如果 node 为 null，直接返回
   - `res[row][col] = to_string(node->val)`
   - 计算偏移 `offset = 1 << (height - row - 1)`
   - `fill(node->left, row+1, col - offset)`
   - `fill(node->right, row+1, col + offset)`
4. 调用 `fill(root, 0, (n-1)/2)`

### 解法二：BFS 层序填充

**思路**：使用队列进行层序遍历，每个队列元素记录 `(node, row, col)`。

**步骤**：
1. 同样先求高度，初始化矩阵
2. 队列初始 push `(root, 0, (n-1)/2)`
3. 每次取出 `(node, r, c)`：
   - `res[r][c] = to_string(node->val)`
   - 计算 `offset = 1 << (height - r - 1)`
   - 左孩子 push `(node->left, r+1, c-offset)`
   - 右孩子 push `(node->right, r+1, c+offset)`

## 易错点

1. **高度定义混淆**：有些题目中"高度"指节点数（高度=深度+1），本题 height 指边数。单节点树 height=0，矩阵为 1x1
2. **2 的幂计算用 pow 导致精度错误**：`pow(2, x)` 返回 double，转 int 时可能差 1。务必用 `1 << x`
3. **列数计算 off-by-one**：`n = 2^(height+1) - 1`，根的列 = `(n-1)/2`。不要漏掉 `-1`
4. **当 height=0 时偏移计算**：`offset = 1 << (0 - 0 - 1) = 1 << (-1)` 是未定义行为。但此时节点为叶子，不会有子节点递归，所以实际不会执行到。仍建议在递归中先判 null
5. **矩阵初始化**：必须全部填 ""（空字符串），不是 " "（空格）

## 面试追问

1. **Q: 为什么列数是 2^(height+1)-1 而不是其他值？**
   - A: 这是高度为 height 的完美二叉树的节点数。用这个宽度可以保证每一层的节点都有唯一的列位置，且布局对称。

2. **Q: 矩阵空间可以优化吗？**
   - A: 矩阵是输出要求，无法减少。但如果只需要某种格式化输出（非矩阵），可以用其他更紧凑的表示。

3. **Q: 如果树非常深（height=20），矩阵有多大？**
   - A: 行数 21，列数 2^21 - 1 = 2097151。约 4400 万个字符串。实际应用中可能需要稀疏表示。

4. **Q: 能否在一次遍历中同时求高度和填充？**
   - A: 可以，但需要先确定矩阵大小才能创建。可以第一遍 DFS 求高度，第二遍 DFS 填充。或者用动态扩展的数据结构，但会更复杂。

5. **Q: 这个布局方式和完全二叉树的数组表示有什么关系？**
   - A: 不同。完全二叉树的数组表示是层序紧凑存储（节点 i 的孩子在 2i+1, 2i+2），而本题的矩阵布局是为了"好看"的打印输出，每层列位置指数级展开。
