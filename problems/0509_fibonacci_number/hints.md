# 509. 斐波那契数

## 核心思路
这道题本质上就是 **动态规划的 Hello World**：当前状态只依赖前两个状态，是理解"暴力递归 → 记忆化 → 递推 → 空间优化"这条 DP 学习路径的最佳入门题。

## 思维链

1. **读完题第一反应**：题目直接给了递推公式 `F(n) = F(n-1) + F(n-2)`，最朴素的做法就是直接递归。
2. **暴力递归的瓶颈在哪？** 画出递归树就能看到大量重复计算——比如 `F(5)` 需要 `F(3)`，`F(4)` 也需要 `F(3)`，`F(3)` 被算了两次（实际上指数级重复）。
3. **怎么消除重复？** 用一个数组把算过的结果存起来，下次直接查表 → 记忆化搜索，时间从 O(2^n) 降到 O(n)。
4. **能否更简洁？** 既然递归是自顶向下填表，那我们反过来从小到大填表 → 递推 DP，省掉递归栈开销。
5. **还能再优化吗？** `dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`，不需要整个数组，两个变量就够了 → **空间 O(1)**。
6. **数学解法（加分）**：矩阵快速幂可以做到 O(log n)，但面试中一般不要求。

## 关键提示

1. **先画递归树**：画出 `fib(5)` 的递归调用树，你会立刻看到 `fib(3)` 被计算了 2 次，`fib(2)` 被计算了 3 次——这就是"重叠子问题"。
2. **记忆化 = 给递归加缓存**：把每次的计算结果存到数组里，下次遇到直接返回，一行代码就能把 O(2^n) 变成 O(n)。
3. **递推就是把递归翻译成循环**：从 `F(0)`, `F(1)` 开始往后推，顺序保证依赖的值已经算好。
4. **空间优化的关键观察**：`F(n)` 只需要 `F(n-1)` 和 `F(n-2)`，不需要记住所有历史值。
5. **边界条件**：`n=0` 和 `n=1` 是 base case，别忘了先处理。

```
递归树 fib(5):
                    fib(5)
                   /      \
              fib(4)       fib(3)       ← fib(3) 重复!
             /     \       /    \
         fib(3)  fib(2)  fib(2) fib(1) ← fib(2) 重复!
        /    \    /   \   /   \
    fib(2) fib(1) fib(1) fib(0) fib(1) fib(0)
    /   \
fib(1) fib(0)

共调用 15 次，其中大量重复。加 memo 后每个值只算一次，共 6 次。
```

## 解法详解

### 解法1: 暴力递归 — O(2^n) / O(n)

**思考过程**: 题目直接给了递推公式，最自然的做法就是翻译成递归代码。但这是一个**反面教材**——展示"不优化会多慢"。

```cpp
class Solution {
public:
    int fib(int n) {
        // base case：F(0)=0, F(1)=1
        if (n <= 1) return n;
        // 直接按定义递归，会有大量重复计算
        return fib(n - 1) + fib(n - 2);
    }
};
```

**关键点**: 时间复杂度是 O(2^n)，因为每次分裂两个子问题且大量重复。`fib(30)` 需要约 10 亿次操作，虽然 n≤30 勉强能过，但这不是好习惯。

---

### 解法2: 记忆化搜索（自顶向下 DP） — O(n) / O(n)

**从解法1优化**: 暴力递归的瓶颈是同一个 `fib(k)` 被反复计算。加一个 memo 数组，算过的直接返回。

```cpp
class Solution {
public:
    int fib(int n) {
        vector<int> memo(n + 1, -1); // -1 表示还没算过
        return helper(n, memo);
    }
    
    int helper(int n, vector<int>& memo) {
        if (n <= 1) return n;
        // 如果已经算过，直接返回缓存结果
        if (memo[n] != -1) return memo[n];
        // 算完后存入 memo，避免重复计算
        memo[n] = helper(n - 1, memo) + helper(n - 2, memo);
        return memo[n];
    }
};
```

**关键点**: 每个 `fib(k)` 只会被真正计算一次，之后都是 O(1) 查表。总共 n 个子问题，每个 O(1) 工作量，所以总时间 O(n)。

---

### 解法3: 递推 DP（自底向上） — O(n) / O(n)

**从解法2转换**: 记忆化是"自顶向下"，递推是"自底向上"——从已知的 `F(0)`, `F(1)` 开始，一步步推到 `F(n)`。

```
// DP 填表过程 (n=6):
// 索引:  0  1  2  3  4  5  6
// dp[]:  0  1  1  2  3  5  8
//              ↑  ↑
//              |  |__ dp[2] = dp[1] + dp[0] = 1+0 = 1
//              |_____ dp[1] = 1 (base case)
//
// 填表方向: 从左到右 →
// 依赖关系: dp[i] 依赖 dp[i-1] 和 dp[i-2]
```

```cpp
class Solution {
public:
    int fib(int n) {
        if (n <= 1) return n;
        vector<int> dp(n + 1);
        dp[0] = 0;
        dp[1] = 1;
        // 从小到大填表，保证 dp[i-1] 和 dp[i-2] 已经算好
        for (int i = 2; i <= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
        }
        return dp[n];
    }
};
```

**关键点**: 和记忆化搜索等价，但没有递归栈开销，代码也更简洁。

---

### 解法4: 滚动变量（空间优化 DP） — O(n) / O(1) ⭐ 面试首选

**从解法3优化**: `dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`，我们不需要整个数组，两个变量就够了。

```
// 滚动过程 (n=6):
// 初始: prev=0, curr=1
//
// i=2: next = 0+1 = 1  → prev=1, curr=1
// i=3: next = 1+1 = 2  → prev=1, curr=2
// i=4: next = 1+2 = 3  → prev=2, curr=3
// i=5: next = 2+3 = 5  → prev=3, curr=5
// i=6: next = 3+5 = 8  → prev=5, curr=8
//
// 返回 curr = 8 ✓
```

```cpp
class Solution {
public:
    int fib(int n) {
        if (n <= 1) return n;
        int prev = 0;  // F(i-2)
        int curr = 1;  // F(i-1)
        for (int i = 2; i <= n; i++) {
            int next = prev + curr;  // F(i) = F(i-2) + F(i-1)
            prev = curr;    // 窗口向前滑动
            curr = next;
        }
        return curr;
    }
};
```

**关键点**: 空间从 O(n) 降到 O(1)，这是线性 DP 空间优化的经典模式。面试中写出这个解法即可。

---

### 解法5: 矩阵快速幂 — O(log n) / O(1)

**思路**: 斐波那契递推可以表示为矩阵乘法：

```
| F(n)   |   | 1 1 |^(n-1)   | F(1) |   | 1 1 |^(n-1)   | 1 |
|        | = |     |       × |      | = |     |       × |   |
| F(n-1) |   | 1 0 |         | F(0) |   | 1 0 |         | 0 |
```

利用快速幂（反复平方法），矩阵乘法只需 O(log n) 次。

```cpp
class Solution {
public:
    // 2×2 矩阵用 vector<vector<int>> 表示
    using Matrix = vector<vector<int>>;
    
    // 2×2 矩阵乘法
    Matrix multiply(const Matrix& A, const Matrix& B) {
        return {
            {A[0][0]*B[0][0] + A[0][1]*B[1][0], A[0][0]*B[0][1] + A[0][1]*B[1][1]},
            {A[1][0]*B[0][0] + A[1][1]*B[1][0], A[1][0]*B[0][1] + A[1][1]*B[1][1]}
        };
    }
    
    // 矩阵快速幂：计算 M^p
    Matrix matPow(Matrix M, int p) {
        Matrix result = {{1,0},{0,1}}; // 单位矩阵
        while (p > 0) {
            if (p & 1) result = multiply(result, M); // 奇数次幂：乘一次 M
            M = multiply(M, M); // M = M²，指数减半
            p >>= 1;
        }
        return result;
    }
    
    int fib(int n) {
        if (n <= 1) return n;
        Matrix M = {{1,1},{1,0}};
        Matrix res = matPow(M, n - 1);
        // res[0][0] 就是 F(n)
        return res[0][0];
    }
};
```

**关键点**: 当 n 非常大时（如 10^18），只有矩阵快速幂能在合理时间内算出结果（需要取模）。本题 n≤30 不需要，但这是很重要的算法思想。

## 解法对比

| | 暴力递归 | 记忆化 | 递推 DP | 滚动变量 | 矩阵快速幂 |
|---|---|---|---|---|---|
| 时间 | O(2^n) | O(n) | O(n) | O(n) | O(log n) |
| 空间 | O(n) 栈 | O(n) | O(n) | **O(1)** | O(1) |
| 代码量 | 最少 | 中等 | 简洁 | **最简** | 较多 |
| 面试 | 展示理解 | 过渡 | 可接受 | **首选** | 加分 |

**核心演进路线**: 暴力递归 → 发现重叠子问题 → 记忆化 → 翻译成递推 → 发现只依赖前两个 → 滚动变量

这条路线适用于**所有线性 DP 题**，请务必掌握。

## 易错点

1. **忘记处理 n=0 的边界**
   - ✗ 直接 `dp[1] = 1` 开始循环，当 n=0 时数组越界或返回错误值
   - ✓ 开头加 `if (n <= 1) return n;`

2. **滚动变量的更新顺序搞反**
   - ✗ `prev = curr; curr = prev + curr;` — 此时 prev 已经被覆盖，curr 的值错误
   - ✓ 用临时变量：`int next = prev + curr; prev = curr; curr = next;`

3. **记忆化搜索忘了存结果**
   - ✗ `return helper(n-1, memo) + helper(n-2, memo);` — 没把结果存入 `memo[n]`
   - ✓ `memo[n] = helper(n-1, memo) + helper(n-2, memo); return memo[n];`

4. **DP 数组大小开错**
   - ✗ `vector<int> dp(n);` — 索引只到 n-1，访问 dp[n] 越界
   - ✓ `vector<int> dp(n + 1);`

## 面试追问

**Q1（基础理解）**: 暴力递归的时间复杂度是多少？为什么？
> A: O(2^n)。画出递归树，每一层几乎都分裂成两个子问题，树的高度是 n，所以节点数接近 2^n。严格来说是 O(φ^n)，其中 φ ≈ 1.618 是黄金比例。

**Q2（优化）**: 怎么从 O(2^n) 优化到 O(n)？优化的本质是什么？
> A: 加记忆化。本质是消除重叠子问题——`fib(k)` 只算一次就存起来，总共 n 个不同的子问题，每个 O(1) 工作量。

**Q3（空间优化）**: 能否做到 O(1) 空间？
> A: 可以。因为 `F(n)` 只依赖 `F(n-1)` 和 `F(n-2)`，用两个变量滚动更新即可，不需要整个 dp 数组。

**Q4（进阶变体）**: 如果 n 可以到 10^18，怎么办？
> A: 矩阵快速幂。将递推关系转化为矩阵乘法，用快速幂在 O(log n) 时间内完成计算。结果需要对大质数取模防溢出。
