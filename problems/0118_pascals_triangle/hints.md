# 118. 杨辉三角 (Pascal's Triangle)

## 核心思路

本质上是一道**模拟/递推**题：第 `i` 行第 `j` 个元素等于上一行第 `j-1` 和第 `j` 个元素之和，每行首尾固定为 1。逐行构建即可。

## 思维链

1. **读完题第一反应**：杨辉三角的规则很明确——每个数是它"左上方"和"右上方"的数之和。那最直觉的做法就是：一行一行地生成，每行根据上一行来算。
2. **怎么表达"左上方"和"右上方"？** 如果把三角形左对齐看成一个二维数组，第 `i` 行第 `j` 个元素 = 上一行的第 `j-1` 个 + 上一行的第 `j` 个。每行的第一个和最后一个元素都是 1。
3. **有没有更"数学"的做法？** 杨辉三角的第 `i` 行第 `j` 个元素就是组合数 C(i, j)。可以用组合数公式直接算每个元素，不依赖上一行。
4. **组合数怎么高效计算？** C(n, k) = C(n, k-1) * (n-k+1) / k，利用递推关系在 O(1) 内从同一行的前一个元素推出下一个。
5. **哪种适合面试？** 逐行递推最直觉、最好写、最不容易错，面试首选。组合数方法是加分项，展示数学功底。

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 逐行递推 | 每行根据上一行的值累加 | O(n²) | O(1)* | ⭐ 必须写出 |
| 组合数公式 | C(i,j) = C(i,j-1)*(i-j+1)/j | O(n²) | O(1)* | 加分项 |

> *空间备注：输出本身占 O(n²)，这里只算额外空间。

## 关键提示

- **提示1**：把杨辉三角"左对齐"画出来，观察下标关系：
  ```
  row0: [1]
  row1: [1, 1]
  row2: [1, 2, 1]
  row3: [1, 3, 3, 1]
  row4: [1, 4, 6, 4, 1]
  ```
  第 `i` 行有 `i+1` 个元素，`row[i][j] = row[i-1][j-1] + row[i-1][j]`。

- **提示2**：每行的首尾元素都是 1，只需要计算中间的元素（从 j=1 到 j=i-1）。

- **提示3**：如果你想用组合数方法，关键递推是 `C(n, k) = C(n, k-1) * (n - k + 1) / k`，同一行内从左到右递推，避免阶乘溢出。

- **提示4**：numRows 最小为 1，不需要处理空输入。但要注意第 0 行（只有一个 1）是 base case。

## 解法详解

### 解法1: 逐行递推 — O(n²) / O(1) ⭐ 面试首选

**思考过程**：杨辉三角的定义本身就是递推的——每个元素由上一行两个元素相加得到。所以最自然的做法就是：从第 0 行开始，一行一行往下构建。对于每一行，首尾填 1，中间的位置查上一行对应的两个元素求和。

```
杨辉三角的递推关系（左对齐视角）:

    j:  0   1   2   3   4
i=0:    1
i=1:    1   1
i=2:    1   2   1           ← row[2][1] = row[1][0] + row[1][1] = 1+1 = 2
i=3:    1   3   3   1       ← row[3][2] = row[2][1] + row[2][2] = 2+1 = 3
i=4:    1   4   6   4   1   ← row[4][2] = row[3][1] + row[3][2] = 3+3 = 6
```

```cpp
class Solution {
public:
    vector<vector<int>> generate(int numRows) {
        vector<vector<int>> triangle;
        
        for (int i = 0; i < numRows; i++) {
            // 第 i 行有 i+1 个元素，先全部初始化为 1
            // 这样首尾的 1 就不用单独处理了
            vector<int> row(i + 1, 1);
            
            // 只需要填中间的元素 (j 从 1 到 i-1)
            // 当 i <= 1 时，这个循环不执行，正好对应前两行 [1] 和 [1,1]
            for (int j = 1; j < i; j++) {
                // 核心递推：当前元素 = 上一行的左上 + 上一行的正上
                row[j] = triangle[i - 1][j - 1] + triangle[i - 1][j];
            }
            
            triangle.push_back(row);
        }
        
        return triangle;
    }
};
```

**关键点**：
- 初始化 `vector<int> row(i + 1, 1)` 巧妙地处理了首尾为 1 的边界，不需要额外的 if 判断。
- 内层循环 `j` 从 1 到 `i-1`，当 `i=0` 或 `i=1` 时循环体不执行，自动覆盖了 base case。

### 解法2: 组合数递推 — O(n²) / O(1) — 加分项

**从不同角度思考**：杨辉三角的第 `i` 行第 `j` 个元素在数学上就是组合数 C(i, j)。如果我们能直接算出 C(i, j)，就不需要依赖上一行的结果。

关键公式：**C(n, k) = C(n, k-1) × (n - k + 1) / k**

这意味着同一行内，知道前一个元素就能 O(1) 算出下一个。

```
以第4行为例:
C(4,0) = 1
C(4,1) = C(4,0) * (4-0) / 1 = 1 * 4 / 1 = 4
C(4,2) = C(4,1) * (4-1) / 2 = 4 * 3 / 2 = 6
C(4,3) = C(4,2) * (4-2) / 3 = 6 * 2 / 3 = 4
C(4,4) = C(4,3) * (4-3) / 4 = 4 * 1 / 4 = 1
→ [1, 4, 6, 4, 1] ✓
```

```cpp
class Solution {
public:
    vector<vector<int>> generate(int numRows) {
        vector<vector<int>> triangle;
        
        for (int i = 0; i < numRows; i++) {
            vector<int> row(i + 1);
            row[0] = 1;  // C(i, 0) = 1
            
            for (int j = 1; j <= i; j++) {
                // C(i, j) = C(i, j-1) * (i - j + 1) / j
                // 先乘后除，保证整除（组合数一定是整数）
                row[j] = (long long)row[j - 1] * (i - j + 1) / j;
            }
            
            triangle.push_back(row);
        }
        
        return triangle;
    }
};
```

**关键点**：
- 必须先乘后除：`row[j-1] * (i-j+1) / j` 顺序不能变，因为先除可能不整除。
- 用 `(long long)` 防止中间乘法溢出（虽然 numRows ≤ 30 时 int 够用，但这是好习惯）。
- 这种方法的优势：不需要存储上一行，每行独立计算。在只需要某一行时特别有用（对应 LeetCode 119）。

## 解法对比

| | 逐行递推 | 组合数递推 |
|---|---|---|
| **依赖关系** | 当前行依赖上一行 | 每行独立计算 |
| **实现难度** | 非常简单 | 需要知道组合数递推公式 |
| **溢出风险** | 无（只做加法） | 有（乘法可能溢出） |
| **扩展性** | 如果只需要第 n 行，仍需生成前面所有行 | 可以直接算第 n 行 |
| **面试推荐** | ⭐ 首选 | 追问"只要第 n 行"时使用 |

## 易错点

1. **内层循环边界写错**：
   - ✗ `for (int j = 0; j <= i; j++)` 然后里面加 if 判断首尾 — 冗余且容易出错
   - ✓ `for (int j = 1; j < i; j++)` 配合初始化全 1 — 简洁不易错

2. **下标越界访问上一行**：
   - ✗ `triangle[i-1][j]` 当 `j == i` 时越界，因为上一行只有 `i` 个元素
   - ✓ 内层循环到 `j < i` 就停，保证 `j` 不超过上一行的有效下标

3. **组合数方法中先除后乘导致精度错误**：
   - ✗ `row[j] = row[j-1] / j * (i - j + 1)` — 整数除法截断导致结果错误
   - ✓ `row[j] = (long long)row[j-1] * (i - j + 1) / j` — 先乘后除保证整除

## 面试追问

**Q1（基础理解）**：时间和空间复杂度分别是多少？
> 时间 O(n²)（总共 1+2+...+n 个元素），额外空间 O(1)（输出空间不计）。

**Q2（变体 — LeetCode 119）**：如果只需要返回第 n 行，不需要整个三角形，能否只用 O(n) 空间？
> 可以。用一个一维数组，每次从右往左更新（避免覆盖还需要用的旧值）：`row[j] = row[j] + row[j-1]`。或者用组合数递推方法直接算第 n 行。

**Q3（数学扩展）**：杨辉三角的第 n 行和二项式定理有什么关系？
> 第 n 行的元素就是 (a+b)^n 展开式的系数，即 C(n,0), C(n,1), ..., C(n,n)。
