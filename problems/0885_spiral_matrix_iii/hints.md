# LeetCode 885: Spiral Matrix III

## 核心思路

本题要求从给定起始位置开始，以顺时针螺旋方式遍历整个 rows x cols 的网格，返回所有格子的访问顺序。核心思路是**模拟螺旋行走**：按照 右->下->左->上 的方向循环，每两个方向后步长加 1。行走过程中可能走到网格外，此时继续行走但不记录。每走到一个网格内的位置就记录下来，直到收集满 rows * cols 个位置。

## 思维链

1. **螺旋方向规律**：顺时针方向依次为 右(0,1) -> 下(1,0) -> 左(0,-1) -> 上(-1,0)，四个方向循环。
2. **步长增长规律**：
   - 右走 1 步，下走 1 步
   - 左走 2 步，上走 2 步
   - 右走 3 步，下走 3 步
   - 左走 4 步，上走 4 步
   - 规律：每两个方向共享同一步长，每完成两个方向后步长 +1。
3. **边界处理**：行走过程中会走到网格外，此时不记录坐标但继续行走。
4. **终止条件**：当收集到 rows * cols 个坐标后停止。
5. **起始位置**：从 (rStart, cStart) 开始，该位置本身是第一个被访问的。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 直接模拟法 | O(max(R,C)^2) | O(R*C) | 最直观，按规律行走 |

其中 R = rows, C = cols。最坏情况下起点在角落，需要走约 (2*max(R,C))^2 步。

## 关键提示

1. **步长模式是 1,1,2,2,3,3,4,4,...** -- 每两个方向共享一个步长。
2. **方向循环：右下左上** -- 用方向数组 dirs = {{0,1},{1,0},{0,-1},{-1,0}} 表示。
3. **网格外不记录但继续走** -- 不能跳过网格外的步骤，否则螺旋形状会错乱。
4. **起始位置先记录** -- (rStart, cStart) 是第一个访问的位置，写入结果后再开始行走。
5. **终止条件是收集够 R*C 个位置** -- 不是走完某个圈。

## 解法详解

### 模拟法

**原理**：严格按照螺旋行走的规律模拟每一步，遇到网格内的位置就记录。

**算法步骤**：

1. **初始化**：
   - 结果数组 result，将起始位置 (rStart, cStart) 加入
   - 方向数组 dirs = {{0,1},{1,0},{0,-1},{-1,0}}
   - 当前方向索引 dir = 0（从右开始）
   - 当前步长 steps = 1
   - 已收集位置数 count = 1

2. **螺旋行走**：
   - 外层循环：count < rows * cols 时继续
   - 对每个方向，走 steps 步：
     - 更新当前位置 (r, c) += dirs[dir]
     - 如果 (r, c) 在网格内，记录到 result，count++
   - 切换方向：dir = (dir + 1) % 4
   - 每两个方向后，steps++

3. **返回 result**。

**步长增长的实现**：
```
方向 0（右）：走 steps 步
方向 1（下）：走 steps 步 -> steps++
方向 2（左）：走 steps 步
方向 3（上）：走 steps 步 -> steps++
```
即方向索引为奇数时，完成后 steps++。

**复杂度分析**：
- 时间：O(max(R,C)^2) -- 螺旋覆盖所有格子需要的总步数
- 空间：O(R*C) -- 存储结果数组

## 易错点

1. **步长增长时机错误** -- 应该每完成两个方向后加 1，不是每个方向后都加 1。具体来说，走完"右"和"下"后 steps 从 1 变为 2，走完"左"和"上"后 steps 从 2 变为 3。
2. **方向顺序错误** -- 必须是 右->下->左->上（顺时针），不能搞反。
3. **起始位置忘记记录** -- (rStart, cStart) 本身是第一个被访问的位置。
4. **网格边界判断错误** -- 0 <= r < rows && 0 <= c < cols。注意严格小于而非 <=。
5. **外层循环条件错误** -- 应该用已收集数量 count 作为终止条件，而非步长或圈数。
6. **走到网格外时跳步** -- 有的优化会尝试跳过网格外的步骤，但这增加了复杂度且容易出错。面试中建议直接模拟。

## 面试追问

1. **能否优化跳过网格外的步骤？**
   - 可以。当走到网格外时，计算沿当前方向还需多少步才能回到网格内，直接跳过这些步。但代码复杂度增加很多，面试中通常不要求。

2. **时间复杂度为什么是 O(max(R,C)^2) 而非 O(R*C)？**
   - 如果起点在角落，螺旋需要扩展到覆盖整个网格。螺旋半径约为 max(R,C)，总步数约为 (2*max(R,C))^2。很多步在网格外，但仍需模拟。

3. **和 LC 54（Spiral Matrix）有什么区别？**
   - LC 54 是从 (0,0) 开始，只在矩阵内螺旋，边界不断收缩。本题从任意点开始，可以走到网格外。

4. **如果要逆时针螺旋怎么办？**
   - 将方向改为 右->上->左->下 即可。

5. **如何验证结果正确性？**
   - 检查结果数组长度是否为 R*C，所有坐标是否在网格内，是否无重复。
