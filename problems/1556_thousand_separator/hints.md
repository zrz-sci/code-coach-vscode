# 1556. 千位分隔数 (Thousand Separator)

## 难度: Easy
## 标签: String

---

## 题目理解

给定一个非负整数 n，每隔三位添加一个点 "." 作为千位分隔符，返回字符串格式。

示例：
- n = 987 -> "987" (不到四位，不需要分隔符)
- n = 1234 -> "1.234" (四位数，千位后加点)
- n = 123456789 -> "123.456.789" (九位数，两个分隔符)
- n = 0 -> "0" (特殊情况)

注意：
- 分隔符是点 "."，不是逗号 "," (不同国家的千位分隔符不同)
- n 的范围是 [0, 2^31 - 1]，最大值 2147483647 有 10 位数

---

## 核心思路

将整数转为字符串后，有多种方式插入千位分隔符：

1. **从左到右遍历**: 转字符串后，判断当前位置到末尾的距离是否是 3 的倍数来决定是否插入分隔符
2. **从右到左构建**: 用计数器每 3 个字符插入一个分隔符，最后反转
3. **数学取模法**: 不转字符串，直接对数字取模提取每 3 位

---

## 思维链 (从观察到解法)

### 第一步: 确定分隔符位置
```
n = 1234567890 (10位)
字符串: "1234567890"
位置:    0123456789

分隔符应在: 位置 1 和 2 之间, 位置 4 和 5 之间, 位置 7 和 8 之间
结果: "1.234.567.890"

规律: 从右往左每 3 位一组，在组边界插入点
等价: 从左往右遍历时，当 (总长度 - 当前位置) % 3 == 0 时插入点 (跳过位置 0)
```

### 第二步: 选择实现方式

**方式 A (从左到右)**: 最直观
```
遍历 s = "1234567890", len = 10
i=0: 不插入(开头), 加 '1'
i=1: (10-1)%3 = 0, 插入 '.', 加 '2'  -> "1.2"
i=2: (10-2)%3 = 2, 不插入, 加 '3'     -> "1.23"
i=3: (10-3)%3 = 1, 不插入, 加 '4'     -> "1.234"
i=4: (10-4)%3 = 0, 插入 '.', 加 '5'  -> "1.234.5"
...
```

**方式 B (从右到左)**: 更直觉但需要反转
```
从右向左取字符，每取 3 个加一个点
"0987654321" -> "098.765.432.1" -> 反转 -> "1.234.567.890"
```

**方式 C (数学法)**: 不需要转字符串
```
n = 1234567890
n % 1000 = 890, n /= 1000 -> 1234567
n % 1000 = 567, n /= 1000 -> 1234
n % 1000 = 234, n /= 1000 -> 1
n % 1000 = 1,   n /= 1000 -> 0
拼接: "1" + "." + "234" + "." + "567" + "." + "890"
```

## 解法详解

### Solution1: 从左到右遍历

**核心**: 转为字符串后，从左到右扫描。当 `(s.size() - i) % 3 == 0` 且 `i > 0` 时，在当前字符前插入分隔符。

**为什么 `(s.size() - i) % 3 == 0` 有效？**
- `s.size() - i` 表示从位置 i 到末尾的字符数
- 当这个值是 3 的倍数时，说明后面刚好是完整的若干组(每组3位)
- 此时应在当前位置前加分隔符

```cpp
class Solution1 {
public:
    string thousandSeparator(int n) {
        string s = to_string(n);
        string res;
        for (int i = 0; i < (int)s.size(); i++) {
            if (i > 0 && (s.size() - i) % 3 == 0)
                res += '.';
            res += s[i];
        }
        return res;
    }
};
```

---

### Solution2: 从右到左构建

**核心**: 从字符串末尾开始取字符，用计数器 cnt 每满 3 个就插入一个分隔符，最后反转结果。

```cpp
class Solution2 {
public:
    string thousandSeparator(int n) {
        string s = to_string(n);
        string res;
        int cnt = 0;
        // 从右往左遍历
        for (int i = s.size() - 1; i >= 0; i--) {
            if (cnt > 0 && cnt % 3 == 0)
                res += '.';
            res += s[i];
            cnt++;
        }
        // 反转得到正确顺序
        reverse(res.begin(), res.end());
        return res;
    }
};
```

---

### Solution3: 数学取模法

**核心**: 不用 to_string，直接通过 n % 1000 和 n /= 1000 提取每三位数字，然后拼接。

```cpp
class Solution3 {
public:
    string thousandSeparator(int n) {
        if (n == 0) return "0";

        string res;
        while (n > 0) {
            int part = n % 1000;
            n /= 1000;

            string partStr = to_string(part);
            // 如果不是最高位的组，需要补前导零
            if (n > 0) {
                while (partStr.size() < 3)
                    partStr = "0" + partStr;
                partStr = "." + partStr;
            }
            res = partStr + res;
        }
        return res;
    }
};
```

```
n = 1234567

to_string: "1234567" (7位)

Solution1 (从左到右):
  i=0: 加 '1'          -> "1"
  i=1: (7-1)%3=0, '.2' -> "1.2"
  i=2: 加 '3'          -> "1.23"
  i=3: 加 '4'          -> "1.234"
  i=4: (7-4)%3=0, '.5' -> "1.234.5"
  i=5: 加 '6'          -> "1.234.56"
  i=6: 加 '7'          -> "1.234.567"

Solution2 (从右到左再反转):
  i=6: cnt=0, 加 '7'           -> "7"
  i=5: cnt=1, 加 '6'           -> "76"
  i=4: cnt=2, 加 '5'           -> "765"
  i=3: cnt=3, cnt%3=0, '.4'    -> "765.4"
  i=2: cnt=4, 加 '3'           -> "765.43"
  i=1: cnt=5, 加 '2'           -> "765.432"
  i=0: cnt=6, cnt%6=0, '.1'    -> "765.432.1"
  反转: "1.234.567"

Solution3 (数学法):
  n=1234567
  第一轮: part = 567, n = 1234, res = ".567"
  第二轮: part = 234, n = 1,    res = ".234.567"
  第三轮: part = 1,   n = 0,    res = "1.234.567"
```

## 易错点

1. **n = 0 特判**: to_string(0) = "0"，Solution1 和 Solution2 自动处理，但 Solution3 的 while(n>0) 循环不会执行，需要特判
2. **分隔符在开头**: i = 0 时不应插入分隔符，所以需要 `i > 0` 条件
3. **前导零补齐**: Solution3 中非最高位的三位组需要补前导零(如 1000007 -> "1.000.007"，不是 "1.0.7")
4. **int 溢出**: n 最大为 2^31 - 1 = 2147483647，不会溢出 int
5. **分隔符是点不是逗号**: 注意题目要求的是 "."

## 不同语言中千位分隔符的实际应用

| 国家/地区 | 千位分隔符 | 小数点 | 示例 |
|-----------|-----------|--------|------|
| 美国/英国 | , (逗号) | . (点) | 1,234,567.89 |
| 德国/法国 | . (点) | , (逗号) | 1.234.567,89 |
| 瑞士 | ' (撇号) | . (点) | 1'234'567.89 |
| 中国/日本 | 无(或逗号) | . (点) | 1,234,567.89 |

本题使用的是**欧洲大陆风格**的点分隔符。

## 面试追问递进链

1. **"不用 to_string 怎么做？"**
   -> Solution3 数学取模法，每次 n % 1000 提取三位

2. **"如果分隔符是可配置的呢？"**
   -> 把 '.' 改成参数 separator 即可

3. **"如果要处理负数呢？"**
   -> 检查符号位，取绝对值处理后加回负号

4. **"如果要处理小数呢？"**
   -> 先按小数点分割，只对整数部分加分隔符

5. **"locale 感知的数字格式化怎么实现？"**
   -> C++ 中可以用 `std::locale` 和 `std::numpunct` facet
