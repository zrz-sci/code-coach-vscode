# LCR 020. 回文子串

## 核心思路

统计字符串 `s` 中回文子串的**数量**（不是最长的，而是总共多少个）。核心思想是**中心扩展法**：枚举每个可能的回文中心，向两边扩展，每扩展成功一次就多一个回文子串。同主站 LeetCode 647 题。

## 思维链

1. **读完题第一反应** -- 暴力枚举所有子串 O(n^2)，逐个判断是否回文 O(n)，总共 O(n^3)。n=1000 时约 10^9，会超时。

2. **优化方向1: 中心扩展** -- 回文关于中心对称。枚举每个可能的中心（共 2n-1 个），从中心向外扩展。每成功扩展一步就发现了一个新的回文子串，所以扩展过程中直接计数。

3. **优化方向2: 动态规划** -- `dp[i][j]` 表示 `s[i..j]` 是否回文。如果是，count++。转移：`dp[i][j] = (s[i]==s[j]) && (j-i<2 || dp[i+1][j-1])`。时间 O(n^2) 空间 O(n^2)。

4. **最优选择** -- 中心扩展法：O(n^2) 时间 + O(1) 空间，代码最简洁。面试首选。

5. **和 LeetCode 5 的区别** -- LC5 要找最长回文子串（记录起始位置和长度），本题要统计所有回文子串的个数（扩展过程中计数）。框架完全一样，只是把 "记录最长" 改成 "累加计数"。

## 统一中心编码技巧

```
技巧: 用一个变量 center 从 0 到 2n-2 统一处理奇偶中心

  center = 0:  left = 0/2 = 0, right = 0 + 0%2 = 0  → expand(0, 0) 奇数
  center = 1:  left = 1/2 = 0, right = 0 + 1%2 = 1  → expand(0, 1) 偶数
  center = 2:  left = 2/2 = 1, right = 1 + 0%2 = 1  → expand(1, 1) 奇数
  center = 3:  left = 3/2 = 1, right = 1 + 1%2 = 2  → expand(1, 2) 偶数
  center = 4:  left = 4/2 = 2, right = 2 + 0%2 = 2  → expand(2, 2) 奇数

公式: left = center / 2
      right = left + center % 2

这样一个 for 循环就能处理所有中心，不需要分两次调用。
```

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 暴力 | 枚举所有子串判断回文 | O(n^3) | O(1) | 能说出即可 |

| Manacher | 利用已知回文对称性 | O(n) | O(n) | 加分项 |

## 关键提示

1. **回文中心有两种**: 单字符中心（奇数长度回文，n 个）和双字符中心（偶数长度回文，n-1 个），共 2n-1 个。统一编码: `left = center/2, right = left + center%2`。

2. **每次扩展成功 = 发现一个新回文**: 初始状态（单个字符或两个相等字符）是一个回文，每向外成功扩展一步，又发现一个更长的回文。所以在 while 循环内部 `ans++`。

3. **和 LC5 的框架完全一样**: LC5 是在扩展过程中记录最长回文的起始位置和长度，本题是在扩展过程中累加计数。

4. **DP 解法的遍历顺序**: `dp[i][j]` 依赖 `dp[i+1][j-1]`（更短的子串），所以要么按长度从小到大遍历，要么 `i` 从大到小遍历。

5. **Manacher 的计数方式**: Manacher 算法计算出每个中心的回文半径 `p[i]` 后，以该中心的回文子串数量 = `(p[i] + 1) / 2`（考虑预处理后的插入字符）。总数就是对所有 `p[i]` 求和。

## 解法详解

### 解法1: 中心扩展 (统一编码) -- O(n^2) / O(1)

**思路**: 用一个循环遍历所有 2n-1 个中心，统一处理奇偶。每个中心向外扩展，每次扩展成功就 count++。

```cpp
class Solution {
public:
    int countSubstrings(string s) {
        int n = s.size(), ans = 0;
        // 2n-1 个中心: 0,1,...,2n-2
        // center 为偶数 → 奇数长度回文; center 为奇数 → 偶数长度回文
        for (int center = 0; center < 2 * n - 1; center++) {
            int left = center / 2;
            int right = left + center % 2;
            while (left >= 0 && right < n && s[left] == s[right]) {
                ans++;      // 每次扩展成功就多一个回文
                left--;
                right++;
            }
        }
        return ans;
    }
};
```

### 解法2: 中心扩展 (分奇偶两次调用) -- O(n^2) / O(1)

```cpp
class Solution {
public:
    int countSubstrings(string s) {
        int n = s.size(), ans = 0;
        for (int i = 0; i < n; i++) {
            ans += expand(s, i, i);      // 奇数长度回文
            ans += expand(s, i, i + 1);  // 偶数长度回文
        }
        return ans;
    }

    int expand(const string& s, int left, int right) {
        int count = 0;
        while (left >= 0 && right < (int)s.size() && s[left] == s[right]) {
            count++;
            left--;
            right++;
        }
        return count;
    }
};
```

### 解法3: 动态规划 -- O(n^2) / O(n^2)

```cpp
class Solution {
public:
    int countSubstrings(string s) {
        int n = s.size(), ans = 0;
        // dp[i][j] = true 表示 s[i..j] 是回文
        vector<vector<bool>> dp(n, vector<bool>(n, false));

        // 按子串长度从小到大遍历
        for (int len = 1; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                if (s[i] == s[j] && (len <= 2 || dp[i+1][j-1])) {
                    dp[i][j] = true;
                    ans++;
                }
            }
        }
        return ans;
    }
};
```

## 易错点

1. **忘记偶数长度回文**: 只处理 `expand(i, i)` 会漏掉 "aa" 这样的偶数长度回文。必须同时处理 `expand(i, i+1)`。

2. **统一编码时 right 的计算**: `right = left + center % 2`，不是 `center / 2 + 1`。当 center 为偶数时 `right = left`（奇数长度），当 center 为奇数时 `right = left + 1`（偶数长度）。

3. **DP 遍历顺序**: `dp[i][j]` 依赖 `dp[i+1][j-1]`。如果 `i` 从小到大遍历，`i+1` 行还没算。必须按长度从小到大，或 `i` 从大到小。

4. **DP 中 len<=2 的特判**: 当 `len=1` 时 `dp[i][i]` 一定是 true。当 `len=2` 时只需 `s[i]==s[j]`，不需要查看 `dp[i+1][j-1]`（因为 `i+1 > j-1` 时子串为空）。

## 面试追问

**Q1: 这道题和 LeetCode 5 (最长回文子串) 有什么关系？**
-> 框架完全一样，都用中心扩展。LC5 在扩展时记录最长回文的位置和长度，本题在扩展时累加计数。可以说本题是 LC5 的简化版。

**Q2: 如果要求 O(n) 时间复杂度？**
-> 用 Manacher 算法。计算出每个中心的回文半径 p[i] 后，以该中心的回文子串数 = ceil(p[i] / 2)。对所有中心求和即为总数。

**Q3: 如果字符串有重复字符很多，有没有剪枝的可能？**
-> 中心扩展法中，如果多个连续相同字符，可以一次性跳过它们作为一个"大中心"。这在实际中可以显著加速，但最坏情况仍然 O(n^2)。

**Q4: DP 解法的空间能否优化到 O(n)？**
-> 如果按列遍历，dp[i][j] 只依赖上一个对角线位置 dp[i+1][j-1]，理论上可以用一维数组 + 临时变量优化。但实现较复杂，面试中不如直接用中心扩展（O(1) 空间）。
