# 790. 多米诺和托米诺平铺

## 核心思路

**状态机 DP** -- 将 2xN 的棋盘逐列扫描，每列有三种状态：两格都已填满、上格突出一格、下格突出一格。定义状态转移关系后可以推导出简洁的递推公式 `f[n] = 2*f[n-1] + f[n-3]`。理解这道题的关键在于搞清楚 tromino（L 形）的引入如何打破了普通 domino 铺砖的简单递推。

## 思维链

1. **读完题第一反应** -- 铺砖问题是经典 DP。纯 domino 的 2xN 铺砖有 `f[n] = f[n-1] + f[n-2]`（斐波那契），但现在加入了 L 形 tromino，递推关系一定会更复杂。

2. **暴力思路** -- 可以用状态压缩 DP，每列用 2 bit 表示两个格子的状态，但 2xN 的棋盘列状态只有 4 种，可以直接枚举转移。

3. **状态机建模** -- 扫描到第 i 列时，考虑从前面列"伸出来"到第 i 列的部分。每列的状态：
   - 状态 0：该列两格都空（都需要被填）
   - 状态 1：该列上格被前面的砖占了，下格空
   - 状态 2：该列下格被前面的砖占了，上格空
   - 状态 3：该列两格都被前面的砖占了（已填满）

4. **推导递推公式** -- 令 `f[n]` = 铺满 2xn 的方案数。通过分析最后一列（或最后几列）的放置方式，可以得到：
   - `f[n] = 2*f[n-1] + f[n-3]`

5. **直觉理解** -- `2*f[n-1]` 来自：在 2x(n-1) 已铺满的基础上，最后一列可以放 1 个竖 domino（1种），或者把 f[n-1] 中某些方案和 tromino 组合（需要仔细推导）。`f[n-3]` 来自两个 tromino 形成的 2x3 块的新方案。

## 递推公式推导

```
定义 f[n] = 铺满 2 x n 棋盘的方案数
定义 g[n] = 铺满 2 x n 棋盘但有一个角缺失的方案数（上角或下角对称，所以只算一种）

关键递推关系:
  f[n] = f[n-1] + f[n-2] + 2 * g[n-1]
  g[n] = f[n-2] + g[n-1]

其中:
  f[n-1]: 最后一列放一个竖 domino  |
  f[n-2]: 最后两列放两个横 domino  =
  2*g[n-1]: 最后位置放一个 tromino（上L或下L两种方向）

将 g[n] 消去后，可以得到:
  f[n] = 2 * f[n-1] + f[n-3]

验证:
  f[0] = 1 (空棋盘，一种方案)
  f[1] = 1 (一个竖domino)
  f[2] = 2 (两个竖domino 或 两个横domino)
  f[3] = 2*f[2] + f[0] = 2*2 + 1 = 5 ✓ (题目示例)
  f[4] = 2*f[3] + f[1] = 2*5 + 1 = 11
  f[5] = 2*f[4] + f[2] = 2*11 + 2 = 24
```

## 状态转移图示

```
铺砖方式分析 (2 x n 棋盘):

方式1: 最后一列放竖 domino → 剩余 2 x (n-1)
  ┌───┬─┐        ┌───┐ ┌─┐
  │   │X│   →    │   │+│|│    → f[n-1] 种
  │   │X│        │   │ │|│
  └───┴─┘        └───┘ └─┘

方式2: 最后两列放两个横 domino → 剩余 2 x (n-2)
  ┌──┬──┐        ┌──┐ ┌──┐
  │  │XX│   →    │  │+│==│    → f[n-2] 种
  │  │YY│        │  │ │==│
  └──┴──┘        └──┘ └──┘

方式3: 最后位置放 tromino (L形) → 会产生"突出"状态
  ┌──┬──┐        有两种方向（上L/下L），
  │  │XX│        每种都留下一个"缺角"状态 g[n-1]
  │  │X │        → 2 * g[n-1] 种
  └──┴──┘

合计: f[n] = f[n-1] + f[n-2] + 2 * g[n-1]

------

g[n] 的递推 (缺角状态):
  g[n] = g[n-1] + f[n-2]

  情况1: 在缺角状态上方放一个横 domino → g[n-1]
  情况2: 放一个 tromino 补全 → f[n-2]

------

消去 g[n], 推导 f[n] 的闭合递推:

  f[n] = f[n-1] + f[n-2] + 2 * g[n-1]
  f[n-1] = f[n-2] + f[n-3] + 2 * g[n-2]

  f[n] - f[n-1] = f[n-1] - f[n-3] + 2 * (g[n-1] - g[n-2])
                 = f[n-1] - f[n-3] + 2 * f[n-3]    (因为 g[n]-g[n-1] = f[n-2])
                 = f[n-1] + f[n-3]

  所以 f[n] = 2 * f[n-1] + f[n-3]
```

## 解法概览

| 解法 | 思路 | 时间 | 空间 | 面试 |
|------|------|------|------|------|
| 递推 DP (数组) | f[n] = 2*f[n-1] + f[n-3] | O(n) | O(n) | 推荐 |
| 递推 DP (滚动变量) | 只存最近 3 个值 | O(n) | O(1) | 最优 |
| 矩阵快速幂 | 用矩阵幂加速递推 | O(log n) | O(1) | 加分项 |

## 关键提示

1. **基础情况**: `f[0]=1, f[1]=1, f[2]=2`。特别注意 `f[0]=1` 表示空棋盘有 1 种铺法（什么都不放），这是递推的基础。

2. **取模**: 答案对 `10^9 + 7` 取模。注意 `2*f[n-1]` 可能溢出 int，用 `long long` 计算中间结果。

3. **递推公式来源**: `f[n] = 2*f[n-1] + f[n-3]` 不是凭直觉猜的，而是从状态机（f 和 g 两个状态的转移方程组）消元推导出来的。面试时如果能画出状态转移图就很加分。

4. **为什么不是简单的 f[n] = f[n-1] + f[n-2]**: 那是纯 domino（无 tromino）的递推。tromino 引入了"缺角"状态，使得递推变成三项。

5. **空间优化**: 因为 `f[n]` 只依赖 `f[n-1]` 和 `f[n-3]`（间隔最多 3），可以用 3 个变量滚动代替数组，空间 O(1)。

## 解法详解

### 解法1: 递推 DP (数组) -- O(n) / O(n)

```cpp
class Solution {
public:
    int numTilings(int n) {
        const int MOD = 1e9 + 7;
        if (n <= 2) return n;

        vector<long long> f(n + 1);
        f[0] = 1; f[1] = 1; f[2] = 2;

        for (int i = 3; i <= n; i++) {
            f[i] = (2 * f[i-1] % MOD + f[i-3]) % MOD;
        }
        return f[n];
    }
};
```

### 解法2: 递推 DP (滚动变量) -- O(n) / O(1)

```cpp
class Solution {
public:
    int numTilings(int n) {
        const int MOD = 1e9 + 7;
        if (n <= 2) return n;

        long long a = 1, b = 1, c = 2; // f[i-3], f[i-2], f[i-1]
        for (int i = 3; i <= n; i++) {
            long long cur = (2 * c % MOD + a) % MOD;
            a = b;
            b = c;
            c = cur;
        }
        return c;
    }
};
```

## 易错点

1. **base case 搞错**: `f[0]` 必须是 1 不是 0。空棋盘 = 1 种方案（什么都不放）。如果 `f[0]=0`，则 `f[3] = 2*2 + 0 = 4`，和正确答案 5 不符。

2. **取模时机**: `2 * f[i-1]` 在 `f[i-1]` 接近 `10^9` 时会超过 `2 * 10^9`，超出 int 范围。必须用 `long long` 或在乘法后立即取模。

3. **n=1 和 n=2 的特判**: 如果不做特判直接循环，`f[i-3]` 在 `i=3` 时访问 `f[0]` 是安全的，但要确保数组够大。

## 面试追问

**Q1: 这个递推公式 f[n] = 2*f[n-1] + f[n-3] 怎么来的？**
-> 定义两个状态：f[n] 是铺满 2xn 的方案数，g[n] 是 2xn 缺一个角的方案数。列出两个递推方程，消去 g 得到只含 f 的三项递推。（见上方详细推导）

**Q2: 如果 n 很大（比如 10^18），怎么优化？**
-> 用矩阵快速幂。将递推关系写成矩阵形式 [f[n], f[n-1], f[n-2]]^T = M * [f[n-1], f[n-2], f[n-3]]^T，其中 M 是 3x3 的转移矩阵。然后用快速幂在 O(log n) 时间内计算 M^n。

**Q3: 如果棋盘变成 3xN 呢？**
-> 3xN 棋盘用纯 domino 铺：n 为奇数时无解（总格数为奇数无法全用 2x1 覆盖）；n 为偶数时有递推公式。加入 tromino 后需要用更复杂的状态压缩 DP。
