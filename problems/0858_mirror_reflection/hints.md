# 858. Mirror Reflection

## 核心思路

本题描述了一个正方形镜面房间中的光线反射问题。关键技巧是将反射问题转化为直线延伸问题：不让光线反射，而是把房间沿镜面"展开"成无限网格。光线变成了一条直线，我们只需要找到这条直线第一次经过角落接收器的位置。

数学上，光线每次水平走 p 的距离，垂直走 q 的距离。我们需要找到最小的正整数 m 使得 m*q 是 p 的倍数，此时光线到达某个角落。令 lcm = LCM(p, q)，则垂直方向走了 lcm/q 步，水平方向到达 lcm/p 的奇偶性决定了左右墙，垂直 lcm/q 的奇偶性决定了上下位置。

## 思维链

1. **展开镜面**：想象把房间向上和向右无限展开，光线变成斜率为 q/p 的直线。
2. **寻找交点**：光线从 (0,0) 出发，到达 (m*p, m*q) 中第一个同时满足 x 是 p 的倍数且 y 是 p 的倍数的点。
3. **化简为 LCM**：光线在垂直方向每次上升 q，需要走 k 步使得 k*q 是 p 的整数倍。最小的 k = p / gcd(p,q)。
4. **判断接收器**：设 m = LCM(p,q)/q (垂直步数), n = LCM(p,q)/p (水平反射次数)：
   - m 奇, n 奇 -> 接收器 1（右上角）
   - m 奇, n 偶 -> 接收器 2（左上角）
   - m 偶, n 奇 -> 接收器 0（右下角）
5. **进一步简化**：不断将 p 和 q 同时除以 2，直到至少一个为奇数，然后根据奇偶判断。

## 解法概览

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 数学 (GCD/LCM) | O(log(min(p,q))) | O(1) | 最优解，纯数学推导 |
| 模拟反射 | O(p/gcd(p,q)) | O(1) | 直观但较慢 |
| 除2简化法 | O(log(max(p,q))) | O(1) | 最简洁的实现 |

## 关键提示

1. **展开思想**：光线反射等价于在展开的网格中画直线。这是处理镜面反射的经典技巧。
2. **GCD 的作用**：gcd(p, q) 决定了光线需要反射多少次才能到达角落。
3. **奇偶性判断接收器**：
   - 垂直反射次数(m)的奇偶决定光线在上方还是下方
   - 水平反射次数(n)的奇偶决定光线在右侧还是左侧
4. **除2技巧**：不需要显式计算 LCM，只需反复除以 2 直到 p 或 q 为奇数。

## 解法详解

### 解法一：数学推导 (GCD/LCM)

**思路**：

计算 g = gcd(p, q)。令 m = p/g（垂直方向的步数），n = q/g（水平方向的步数...实际上需要 LCM/q 和 LCM/p）。更准确地说：光线需要垂直走 m = p/gcd(p,q) 步到达角落，水平走 n = q/gcd(p,q) 步。然后根据 m 和 n 的奇偶判断接收器：
- m 偶, n 奇: 接收器 0
- m 奇, n 奇: 接收器 1
- m 奇, n 偶: 接收器 2

### 解法二：除2简化法（最简洁）

**思路**：

不断将 p 和 q 同时除以 2（当两者都是偶数时）。最终至少有一个是奇数：
- p 奇, q 奇 -> return 1
- p 奇, q 偶 -> return 0  (相当于 q 偶意味着到右下角)
- p 偶, q 奇 -> return 2

这个方法本质上等价于 GCD 方法，因为同时除以 2 就是在消除公因子中的 2。

### 解法三：模拟法

**思路**：

模拟光线的运动。用变量跟踪光线在垂直方向的位置，每步增加 q 然后对 2p 取模来模拟反射。当位置恰好为 0 或 p 时，光线到达某个接收器。

## 易错点

1. **接收器编号搞混**：0 是右下，1 是右上，2 是左上。注意左下角没有接收器。
2. **m 和 n 的定义混淆**：需要明确哪个是垂直步数、哪个是水平步数。
3. **GCD 计算中 p=q 的特殊情况**：此时光线直接到达接收器 1。
4. **模拟法中方向判断错误**：光线可能向上也可能向下反射，需要维护方向变量。
5. **除2法的终止条件**：是"至少一个为奇数"而不是"两个都为奇数"。

## 面试追问

1. **如何证明光线一定能到达某个接收器？**
   - 因为 p 和 q 都是正整数，LCM(p,q) 是有限的，光线最终会到达某个角落。

2. **如果房间不是正方形而是 a x b 的矩形呢？**
   - 需要找 LCM(a, q_vertical) 和 LCM(b, q_horizontal) 的关系，本质相同但需考虑两个维度。

3. **如果有多个接收器在不同位置呢？**
   - 展开法依然有效，只需检查直线路径上第一个命中的接收器位置。

4. **如何计算光线到达接收器前的总反射次数？**
   - 总反射次数 = m + n - 2（减去起点和终点）。

5. **p 和 q 的 GCD 与反射次数的关系？**
   - GCD 越大，反射次数越少；GCD 为 1 时反射次数最多。
